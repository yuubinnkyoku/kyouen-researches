# 反転平面の共円ゲームは楕円二次曲面上のMDS符号である

## 命題（持ち上げと共円の一次従属への翻訳）

`F = F_{q²} = F_q + F_q·u`、`α = u + u^q`、`β = u^{q+1}`（ともに `F_q`）とおく。
点 `z = a + b·u`（`a, b ∈ F_q`）と無限遠点 `∞` に対して

```
lift(z)  = (1 : a : b : N(z))      N(z) = z·z^q = a² + α·a·b + β·b²
lift(∞)  = (0 : 0 : 0 : 1)
```

と定めると、`lift` は `P¹(F_{q²})` から `PG(3,q)` の二次曲面

```
Q : X0·X3 = X1² + α·X1·X2 + β·X2²
```

への全単射である（`Q` の点は `q²+1` 個）。このとき

**四点が共円 ⇔ 四つの `lift` が一次従属（4×4 行列式が 0）。**

**証明**：円は `N(z − c) = r`（`c ∈ F_{q²}, r ∈ F_q`）の解集合である。`z = a + b·u` を代入して
展開すると `N(z) − 2·(a·c_a − β·b·c_b …) + const = 0` の形、すなわち `(1, a, b, N(z))` について
**一次**の方程式になる。したがって各円は `Q` の切断平面に対応する。逆に `∞` を含む円
（= `F_q`-アフィン直線）は `L(X1,X2) − c·X0 = 0` という平面で、`(0,0,0,1)` を通る。
よって「円全体」と「`Q` の切断平面全体」が対応し、4点が同一円上にあることは
4点が同一平面上にあること、すなわち一次従属であることに同値。□

数値検査：q=3,4,5,7 の**全4点組**（210 / 2,380 / 14,950 / 230,300 個）で
「共円」と「一次従属」が完全一致し、`lift` した点が `Q` の外に出ることも 0 件。

## 定理（共円ゲーム ＝ 楕円二次曲面上のMDS符号の長さ）

`S ⊂ P¹(F_{q²})`、`|S| = k` とする。`L(S)` を `lift` した列ベクトルからなる `4×k` 行列とすると

**`S` がアーク（どの4点も共円でない）⇔ `L(S)` のどの4列も一次独立。**

このとき `L(S)` が生成する `F_q` 上の符号 `C` を考える。非零符号語の重みは
`k − |{i : y·lift(z_i) = 0}|` であり、`y^⊥` は `PG(3,q)` の平面だから `Q` との交わりは
錐（1点）か円錐曲線（`q+1`点）で、アークの性質から**高々3列**しか含まない。
よって `d(C) ≥ k−3`、Singleton 上界 `d(C) ≤ k−4+1 = k−3` と合わせて `d(C) = k−3`。□

すなわち

> `K(q)` ＝ **「楕円二次曲面 `Q⁻(3,q)` の点だけを列に持つ `[k,4,k−3]` MDS符号の最大長」**

（双対の言葉では、`[k,k−4,5]` MDS符号の検査行列で全列が `Q⁻` 上にあるものの最大長）。
これは「共円ゲーム」を**符号理論の対象**に読み替える新しい入口である。従来の
「パリティ検査行列の任意3列独立」というメモ（K1058 の 10co 以前）は下界しか与えなかったが、
こちらは MDS の**長さの上界**として効く。

## 系（上界）

`M_4(q)` を `F_q` 上の4次元 MDS符号の最大長（= `PG(3,q)` の一般位置集合の最大サイズ）とすると

1. **`K(q) ≤ M_4(q)`**（無条件）。
2. **MDS予想（4次元, q ≥ 5）を仮定すると `M_4(q) = q+1`、したがって `K(q) ≤ q+1`。**
   `q` が素数なら Ball の定理により `M_4(q) = q+1` は無条件なので、
   **素数 `p ≥ 5` で `K(p) ≤ p+1`**。

これは K1058 の証明済み上界 `K ≤ q+3`（λ₂上界）と `K ≤ q+2`（`q ≡ 1 mod 4` の十字上界）を
すべての素数で改善する。ただし数値（下）は `K ≈ 0.65q` なので、まだ緩い。

## 読み取れること

**1. 小さい q では二次曲面の制約は空である。**
`PG(3,q)` の9点は（一般位置にあれば）必ずある二次曲面上に載る。実際、二次形式の空間は10次元で
9点は9個の一次条件なので、9点までは「ある二次曲面上」が自動的に成り立つ。
したがって `k ≤ 9` では「`Q⁻` 上」という制約は MDS の長さを削らない。数値もこれを裏づける：
`q=4` で `K = 5 = q+1`、`q=5` で `K = 6 = q+1`（ともに MDS 上界に一致）。
`q=9` では `K = 9`、`q=11` では `K = 9` でまだ上界に近い。

**2. 大きい q では制約が定数割合を削る。**
`K ≥ 10` になる `q ≥ 13` 以降で `K/q` が単調に下がり、`q=47` で 0.638。
つまり「楕円二次曲面の点だけを使う」という条件は、MDS 符号の長さを約35%削る。
これは新しい量 **`M_4^{Q}(q) := K(q)`（二次曲面制約付きMDS長）** と
`M_4(q) = q+1` の**ギャップ**の問題であり、符号理論側からは
「与えられた二次曲面上に列を取る MDS 符号はどこまで長くできるか」という問いになる。

**3. 双対の距離はいつも 5。**
双対符号は常に `[k, k−4, 5]` MDS、すなわち**二次曲面上の「5-アーク」**である。
`K(q)` は「最小距離5のMDS符号の、二次曲面に載る検査行列の最大長」とも言い換えられる。

## 限界

- 上界 `K ≤ q+1` は MDS予想に依存する（素数 q では Ball の定理で無条件）。
  `q ≥ 13` の `K` は下界のみで、真値は未確定。
- 「9点までは二次曲面上」は*ある*二次曲面上であり、`Q⁻`（楕円型）に限る制約はもっと強い。
  `k ≤ 9` で制約が空という主張は「MDS 長を削らない」という意味でのみ正しい。
- 持ち上げ模型の全数検査は `q ≤ 7`。`q ≥ 8` は構造からの証明（本文）に依る。
- `K(q)` の増大度は未確定（K1058 10co：見かけの指数 ≈0.85、証明済みの枠 `(6q)^{1/3} ≤ K ≤ q+3`）。
