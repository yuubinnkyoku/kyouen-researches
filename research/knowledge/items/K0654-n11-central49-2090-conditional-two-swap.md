# 中央49の条件付き証明義務を2,090類へ縮小

2,091類の現行計画から最大三証人交換を全数列挙すると、既知WIN6・WIN7を除外した採用可能281,872候補のうち44候補が七石義務を改善し、最良は2,090類だった。最良の除去・追加三証人に共通する一証人を相殺すると、**厳密な二証人交換**となる。追加二証人の合法七石子を独立4×4 Bareissと3×3差分整数行列式で照合し、五つの既存終局戦略も再生した。

| 指標 | 従来 | 今回 |
| --- | ---: | ---: |
| 六石証人 | 46 | 46 |
| 五石被覆 | 94/94 | 94/94 |
| 合法七石辺 | 2,984 | **2,983** |
| 相異なる七石証明義務 | 2,091 | **2,090** |
| 終局証明済みLOSS7 | 6 | **6** |
| この証明系列で未確保 | 2,085 | **2,084** |

交換の除外・追加鍵はJSON証明書に保存し、改変負例8件を拒否した。現行集中対象の六石は交換されず、合法七石子64類のうち2類が独立終局証明済み、62類が未検証である。

## 現行2,090類における二証人交換の全数監査（2026-11-03）

94五石類のうち通常92類は選択46六石類によって完全マッチングを作る。二つの証人を除去すると四つの通常五石類が解放されるため、その三通りの再マッチングを全列挙した。現行計画の五つの終局戦略と2,090七石類を再監査した後、交換候補を正確な3×3整数行列式とD4正準化で調べた。

| 検査 | 件数 |
| --- | ---: |
| 除去する二証人組 | 1,035 |
| 再マッチング候補 | 4,989 |
| 非自明かつ五石被覆を保つ候補 | 3,809 |
| 既知WIN6に衝突 | 9 |
| 既知WIN7に衝突 | 0 |
| 終局証明済みLOSS7六類を失う候補 | **470** |

したがって、**既知WIN6/7を除外し、既存の独立終局証明済みLOSS7六類を失わないという制約の下では、現行2,090類は最大二証人交換に対して局所最適**である。証明済み六類の喪失を許す交換や全被覆の大域最適性については主張しない。三証人交換は次節で別途検査した。旧計数は六類の**個数**だけを検査していたため、同数の別の終局証明済み類へ入れ替わる8候補を許していた。集合の包含検査に修正したCI [41534686470](https://github.com/yuubinnkyoku/kyouen-researches/actions/runs/41534686470) は成功した。
