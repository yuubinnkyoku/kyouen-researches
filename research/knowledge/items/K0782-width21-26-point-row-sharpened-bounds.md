## 証明の骨子

- **g₀計数補題**: 点行 y,y′ で e(y−y′) ∈ ℤ → X = e = 4D の分母 g₀ について
  全点行が mod g₀ で合同。X ∈ ℤ → 係数4証明書（(a,u) = (A, X) が証人・
  A ∈ ℤ は A − Xy₁ = s² + 4y₁² から）。g₀ = 2 → 同パリティ → 係数16証明書
  （(2s_y)² が完全平方）。g₀ ≥ 3 → |点行| ≤ ⌈w/g₀⌉ ≤ 9 < k。
  混合パリティ集合は標準形に強制（w=19,20 では ⌈20/3⌉ = 7 < 9）。
- **候補生成の完全性**: mod 9×11 を通る k 部分集合は全 81×121 (a,u) 対の
  窓マスク T の k 部分集合で尽くされる（自由 (a,u) が平行移動を吸収）。
  w=21..26 の候補は 11/34/9/22/7/28 個、**全て mod 19 の係数4証明書だけで全滅**。
  同パリティ候補は 0 個（クラス係数16最大 7..9 < k でも独立に全滅）。
  k+1 レベル: w=21..25 は候補 0・w=26 の 14 行候補 1 個も mod 19 で全滅
  （K0776 の 891 シフト窓 = 9 パラメータ対 × 99 シフトと整合）。
- **会計**: P = 2d+s ≤ 2(d+s)・s ≤ 2。P ≥ 2k−1 → d+s ≥ k・d ≥ k−1 ≥ 10 → C ∈ ℤ。
  点行 ≥ k の配置は候補のいずれかを含み、全候補全滅 → d+s ≤ k−1 → P ≤ 2k−2。
- **A = 0 の否定**: s_y² = y(d−4y)（d = −e）。同一 squarefree 部分の 2 行は
  d の有限因子分解を強制: 行 1,4 → d = 20（行 18/19 は d ≥ 72/76 が必要）・
  行 3,12 → d = 60 < 72・行 1,16 → d ∈ {68,260} は残り行で不成立・
  s6 は行 1,6 から s₁² = 6m²+20 ≡ 2 (mod 3) で矛盾。d ≤ 2×10⁶ 走査も 0 件。
- **標準形掃引の被覆**: R' ≤ 2×10⁷ → s_y, |2y+D| ≤ √R' ≤ 4472。
  行0集合は (s₀, s_ymax) ∈ [0,4472]²（A = s₀²）・非行0集合は (s_p,s_q) ∈ [0,4600]²
  （A ∈ [0,2×10⁷]・A ≡ 0,1 mod 4）で全配置を被覆。混合パリティから e 偶数が強制。
