# 容量余裕1のGrundy値の完全決定

降順状態を `x_1>=...>=x_w`、`h=d-1`、`n=w-h`、`b=x_h` とし、

```
x_1+...+x_h = r-1
```

である安全局面を考える。下位成分をすべて `b` まで埋めるのに必要な手数を

```
R = n*b - (x_{h+1}+...+x_w)
```

と置く。

この局面から容量境界へ移る子の Grundy 値の集合を `E(x)` とする。K0356 により `E(x)` は `{0}`, `{1}`, `{0,1}` のいずれかである。実際には次が成り立つ。

- 境界へ移っても新しい `h` 番目の値が `b` のままなら、その子の Grundy 値は `R mod 2`。
- 新しい `h` 番目の値が `b+1` になるなら、その子の Grundy 値は `(R+n) mod 2`。
- 後者が起こるのは、上位 `h` 成分で最小値 `b` が一意な場合だけであり、その場合は `x_h` 自身を1増やすことで必ずこの型の境界子が存在する。
- 最小値 `b` が一意なとき、前者の境界子も存在することと `x_{h-1}<m` は同値である。したがって
  `E(x)={0,1}` となるのはちょうど「`x_{h-1}>b`, `x_{h-1}<m`, `n` が奇数」の場合である。それ以外では `E(x)` は一元集合である。

このとき Grundy 値は完全に次で決まる。

```
E(x)={e}   なら g(x)=1-e,
E(x)={0,1} なら g(x)=2+(R mod 2).
```

従って容量余裕1では無条件に

```
g(x) <= 3.
```

特に `g=2,3` が現れるための必要十分条件も

```
x_{h-1}>x_h,  x_{h-1}<m,  w-h が奇数
```

であり、その条件下では `R` が偶数なら `g=2`、奇数なら `g=3` である。

## 証明

容量余裕1を保つ手は、下位成分のうち `b` 未満のものを1増やす手に限る。この手では上位 `h` 成分、`b`、および上記の境界子の「型」が不変で、`R` だけが1減る。

一方、容量境界へ移る手を考える。境界子で新しい `h` 番目の値が `b` なら、下位和は変わらず、K0356 の残り手数は `R` である。新しい `h` 番目の値が `b+1` なら、同じく下位和は変わらず、残り手数は `R+n` である。閾値が `b+1` に上がるには上位 `h` 成分の最小値 `b` が一意でなければならず、一意なら `x_h` を増やす手がこの型を与える。閾値 `b` を保つ境界手は、一意最小でない場合には存在し、一意最小の場合には上位 `h-1` 成分のどれかを増やせること、すなわち `x_{h-1}<m` と同値である。

K0352 の非自明領域では `hm>r` なので、容量余裕1局面から境界へ移る手は少なくとも1つ存在する。従って `E(x)` は空でない。

`R` に関して帰納する。

`E(x)={e}` の場合、余裕維持手を1回行うと境界子の唯一の Grundy 値は `1-e` に反転する。帰納法により、その余裕維持子自身の Grundy 値は `e` である。容量境界へ直接移る子もすべて Grundy 値 `e` なので、全子の Grundy 値集合は `{e}`、従って `g(x)=mex{e}=1-e` である。

`E(x)={0,1}` の場合は `n` が奇数であり、境界子だけで常に `0,1` の両方が現れる。余裕維持子では `R` が1減るため、帰納法により全ての余裕維持子は `2+((R-1) mod 2)` を持つ。よって `R` が偶数なら子の値集合は `{0,1,3}` で mex は2、`R` が奇数なら `{0,1,2}` で mex は3となる。すなわち `g(x)=2+(R mod 2)`。

基底 `R=0` では余裕維持手がなく、同じ式が境界子集合の mex から直接従う。

これにより、以前の子数だけを使う上界 `g<=k+2` は真だが非最適であり、容量余裕1については有限実験に依存せず `g<=3` が全称的に確定する。


## 終局までの手数集合も二点以下に完全決定できる

同じ容量余裕1局面から、現在局面を含めず終局までに行われる着手数を考える。上の記号で、その全可能値の集合を `L(x)` とする。

容量余裕を保つ手を `k` 回行ってから初めて容量境界へ入ると、その時点で下位を `b` まで埋める残り量は `R-k` である。境界へ入る手そのものを1手と数える。

- 新しい閾値が `b` の境界子へ入った場合、K0356 により境界後の残り手数は `R-k`。従って全長は
  `k+1+(R-k)=R+1`。
- 新しい閾値が `b+1` の境界子へ入った場合、境界後の残り手数は `R-k+n`。従って全長は
  `k+1+(R-k+n)=R+n+1`。

よって、余裕維持手を何回・どの下位成分に使ったかには依存せず、

```
L(x) ⊆ {R+1, R+n+1}.
```

しかも各値の実現条件は境界子の型の存在条件そのものである。従って厳密に

```
L(x) =
  {R+1, R+n+1}  （x_h=b が上位h成分で一意、かつ x_{h-1}<m）,
  {R+n+1}       （x_h=b が一意、かつ x_{h-1}=m）,
  {R+1}         （x_h=b が一意でない）.
```

特に、容量余裕1では終局までの手数の揺らぎは高々 `n=w-h` であり、二つの長さが共存する場合の差は常に厳密に `n` である。

これは二人通常プレイのGrundy公式とは別の情報である。例えば `n` が偶数なら二つの終局長は同偶奇なので勝敗だけは経路に依存しないが、3人以上の巡回版では `n` が人数の倍数でない限り二つの長さは異なる着手者に終局手を割り当て得る。ここから直ちに多人版の最適戦略までは決まらないため、その点は主張しない。


## 巡回 s 人版で終局手番が経路に依存しないための必要十分条件

同じ局面を、プレイヤー \(P_0,P_1,\ldots,P_{s-1}\) がこの順で巡回して1手ずつ着手する \(s\) 人版として見る。ここでは各プレイヤーの効用や均衡は仮定せず、**合法な全プレイ経路にわたって最後の着手者が同じか**だけを問う。

終局までの着手数が \(\ell\) なら、最後の着手者は \(P_{(\ell-1)\bmod s}\) である。上節より \(L(x)\) は一元集合、または

```
{R+1, R+n+1}
```

の二元集合であり、二元の場合は両方の長さが実際に合法経路で実現する。従って全合法経路で最後の着手者が一致することは

```
L(x) が一元集合、または s | n
```

と同値である。

上節の \(L(x)\) の分類を代入すれば、これは厳密に

```
x_h が上位 h 成分で一意最小でない
または x_{h-1}=m
または s | (w-h)
```

と同値である。

特に二種類の終局長が共存し、かつ \(s\nmid(w-h)\) なら、最後の着手者が異なる二つの合法プレイ経路が実際に存在する。これは単なる可能性の上界ではなく必要十分条件である。

ただし、この命題は多人ゲームの「勝者」や最適戦略を定義・決定するものではない。効用を入れた \(s\) 人非零和ゲームでは、どの終局長を各プレイヤーが選好し、途中でどの経路が均衡として実現するかは別問題である。


## Grundy 0 の子の完全分類

上の公式から、各合法手の行き先が Grundy 0 かどうかも再帰なしに決まる。

`E(x)={e}` の場合、証明中の帰納より、容量余裕を保つ全ての子も Grundy 値 `e` を持つ。容量境界へ直接移る全ての子も `e` である。従って、

- `e=1`、すなわち `g(x)=0` なら Grundy 0 の子は存在しない。
- `e=0`、すなわち `g(x)=1` なら全ての合法な子が Grundy 0 である。

`E(x)={0,1}` の場合は `n=w-h` が奇数で、余裕維持子の Grundy 値は `2+((R-1) mod 2)` だから 0 ではない。従って Grundy 0 の子は容量境界へ直ちに移る子のうち 0 型だけである。より具体的には、

- `R` 偶数（`g=2`）なら、新しい閾値を `b` に保つ境界子がちょうど Grundy 0。
- `R` 奇数（`g=3`）なら、新しい閾値を `b+1` に上げる境界子がちょうど Grundy 0。

従って容量余裕1では、Grundy 0 の子を局所量 `E(x),R` と境界子の型だけで完全判定できる。

## Grundy 2・3 局面の全子局面値と勝ち手数

この節は本項の `E(x)={0,1}`、すなわち容量余裕1、`b=x_h<x_{h-1}<m`、奇数 `n=w-h` の場合に限る。次の本数を **物理的な列への着手数** として定義する。

- `u=#{i<h:b<x_i<m}` （上位の `b` より高い非満杯列）
- `c=#{i<=w:x_i=b}` （全列のうち高さ `b` の列）
- `ell=#{i>h:x_i<b}` （下位の `b` 未満の列）

`R=nb-sum_{i>h}x_i` が偶数（親 `g=2`）なら、子局面の `g=0,1,2,3` の本数はそれぞれ厳密に `(u,c,0,ell)`。 `R` が奇数（親 `g=3`）なら `(c,u,ell,0)` である。従って **Grundy 0 へ進む勝ち手数は親 `g=2` では `u`、親 `g=3` では `c`** となる。

証明：`b` より大きく `m` 未満の上位列へ打つ `u` 手は容量境界へ移り、閾値 `b` を維持する。その子の Grundy は K0356 より `R mod2`。高さ `b` の列のどれかを増やす `c` 手は容量境界に移り、上位最小値が `b+1` になり、子の Grundy は `(R+n) mod2=1-(R mod2)`。下位の `b` 未満へ打つ `ell` 手は余裕1を維持し `R` を1減らすので、本項の既証明により `2+((R-1) mod2)` となる。この三群で全合法手が尽きる。□

注意：勝ち手数 `u` を一律 `h-1` としてはならない。上位に既に満杯の列があるからである。反例 `(w,h,m,r,x)=(4,3,2,4,(2,1,0,0))` は `g=2` だが `u=1<h-1=2`。これは **既存の勝ち手「型」分類の厳密な本数化** であり、`g>=4` 不在を全称的に証明するものではない。
