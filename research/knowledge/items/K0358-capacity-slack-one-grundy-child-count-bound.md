# 容量余裕1の一般上界

降順状態を `x_1>=...>=x_w`、`h=d-1`、`b=x_h` とし、上位h成分の容量余裕
`r-(x_1+...+x_h)` が1である安全局面を考える。

下位成分 `x_{h+1},...,x_w` のうち `b` 未満に実際に現れる異なる値の個数を

```
k = |{ x_i : i>h, x_i<b }|
```

とする。このとき

```
g(x) <= k+2.
```

## 証明

1手で上位h成分和が増える量は0または1なので、子は容量余裕1のままか容量境界のどちらかである。

容量境界へ移る子は K0356 により Grundy 値が0または1である。

一方、容量余裕1を保つ手では、下位成分のうち `b` 未満の成分を1増やすしかない。同じ値を持つ成分のどれを選んでも、増加後に再ソートすれば同じ降順状態になる。従って余裕1を保つ異なる子は高々k個である。

よって全子が供給できる異なる Grundy 値は高々 `k+2` 個である。mex が `k+3` 以上になるには `0,1,...,k+2` の `k+3` 個すべてが子に現れる必要があり不可能なので、`g(x)<=k+2`。

## 系

- `k=0` なら `g<=2`。
- `k<=1` なら `g<=3`。特に `w=h+1`、または `b<=1` なら常に `g<=3`。
- `k<=min(w-h,b)` なので、粗い全称上界 `g<=min(w-h,b)+2` も得る。
- 容量余裕1で `g>=4` が起こるには `k>=2`、従って `w-h>=2` かつ `b>=2` が必要である。

この定理だけでは `k>=2` の場合の一様な `g<=3` は示さない。有限走査で観測された容量余裕1の `g<=3` が全称的に成立するかは未解決である。
