# 幾何学的禁止条件を変える共円ゲームの拡張研究

## 位置づけと共通の規則

これは**研究候補を体系化した未解決課題**であり、全候補に共通する未解決の一つの定理を主張しない。議論の原記録は
[2026-10-22の幾何学的ルール変種案](../../log/2026-10-22-geometric-rule-variants-ideas.md)。
独立の数学的命題・有限結果が得られたら新しいK項目に分け、ここから参照する。

有限盤点集合の未占有点に交互に石を追加し、禁じた点組を完成させる手を敗着とする。安全な追加だけを合法手とする等価な有限通常プレイを用いる（[K0001](K0001-complete-call-rules.md)）。
**禁止する形、点数、座標軸の固定、退化した図形の採否、盤点集合**を明記しないまま異なる変種の勝敗を比較しない。

## 三次元と高次元の候補

| 名称 | 禁止集合の候補 | 区別すべき条件 |
|---|---|---|
| 3次元・共球のみ | 通常の有限半径の球面上の**5点** | 共面5点は必ずしも禁止しない |
| 3次元・共面のみ（4点版） | 同一平面上の**4点** | 4×4行列式 `det[x,y,z,1]=0` |
| 3次元・共面のみ（5点版） | 同一平面上の**5点** | 4点版とは異なる。5点全体のアフィン階数で判定 |
| 3次元・共球または共面 | 球面か平面上の**5点** | 既存の高次元q点版研究との重複に注意 |
| 3次元・共円柱 | 例えば同一の鉛直円柱面上の**4点** | 軸を鉛直に固定するか自由にするか |
| 3次元・共円錐 | 一つの円錐面上の一定点数 | 軸・頂点・開き角・退化例を確定してから点数を決める |
| d次元・共超球 | 同一の通常の超球面上の**d+2点** | 超平面への退化を勝手に含めない |
| d次元・共超平面 | 同一超平面上の**d+1点**または**d+2点** | 禁止点数ごとに別ゲームとして比較 |
| d次元・両方禁止 | 同一超球面か超平面上のq点 | qと盤形状により既存定理が適用できる |

ここでいう**4点共面のみ**は、4点 `(x_i,y_i,z_i)` の `det[(x_i,y_i,z_i,1)]` が0であることを禁止条件とする。3点共線を含む退化配置も禁止4点組になる。
一方、5点共球**のみ**には、単に持ち上げた5×5行列式が0という判定を転用できない。退化した共面配置を含むため、有限半径の球面が実在するかの追加判定が必要になる。

**既存の確定成果との関係**：

- [K0340](K0340-three-dimensional-prism-capacity-and-grundy.md)：3次元平行列盤での共球・共面q点禁止。特定の `q>2w` 領域では共球が発生せず、共面による容量条件へ縮約される。
- [K0352](K0352-general-dimensional-parallel-columns.md)：任意次元の平行列盤に関する一般化。
- [K0435](K0435-three-cube-five-point-lean-certificate-check.md)：3×3×3の共球・共面**5点両禁止版**で、839局面証明書のLean具体検査とその信頼境界。
- [K0502](K0502-even-cubes-q5-constructive-weak-solution.md)：共球・共面5点両禁止版の、偶数辺長立方格子に対する構成的後手必勝。
- [K0503](K0503-five-cube-q5-certified-weak-solution.md)：同じ両禁止版5×5×5の証明書による後手必勝。

従って「共球・共面5点両禁止版の3×3×3、5×5×5、偶数辺長」を本項で新しい未解決問題と呼ばない。
具体的な比較課題は、**共面のみ4点版の立方格子**、**共球のみ5点版と両禁止5点版の差**、**共円柱・共円錐の定義と勝敗**などである。これらについても既存文献全体に対する未解決性・新規性を断定しない。

## 二次元の候補

| 名称 | 一つのルール案 | 注意点 |
|---|---|---|
| 共放物線 | `y=ax²+bx+c` 上の**4点** | x軸固定と回転可を区別。係数の退化を確認 |
| 共楕円 | 非退化楕円上の**6点** | 任意回転を認めるか、軸を固定するか |
| 共双曲線 | 非退化双曲線上の**6点** | 退化した二直線を含めない版と比較 |
| 共二次曲線 | 一つの非零二次方程式 `Ax²+Bxy+Cy²+Dx+Ey+F=0` 上の**6点** | 円錐曲線の分類と退化条件を混同しない |
| 共長方形 | **4石が長方形の4頂点を構成** | 座標軸平行版と任意方向版を区別 |
| 共多項式 | `deg f <= k` のグラフ上の**k+2点** | 同じx座標を持つ点への判定を整理 |

禁止点数は上記の**提案規則**であり、全ての定義の下で最小の非自明な点数だという証明ではない。

共多項式の厳密な関数グラフ版とは別に、退化も含む
`det[x^d,x^(d−1),...,x,y,1]=0` のd+2点禁止版では、
[K0538](K0538-polynomial-lift-degree-parity-constructive-outcomes.md)が同列三点を利用した
次数d≥3の勝敗・初手条件を証明した。
各列三候補以上、総点数N≥d+1なら、偶数dで全初手勝ち、奇数dで全初手負け。
厳密な共多項式グラフ版の未解決性をこれで解消したとは扱わない。

### 二次形式パラメータ版（優先候補）

固定パラメータ `λ` について、相異なる4点の
`det[x_i²+λ y_i², x_i, y_i, 1]=0` を禁止とする。

- `λ=1` は標準の共円・共線4点禁止と一致する。
- `λ>0` は軸を固定した楕円型、`λ=0` は放物線型、`λ<0` は双曲線型の**退化も含めた**判定になる。
- 固定された4点組について行列式は `λ` の一次式 `aλ+b`。固定有限盤の禁止集合が変化しうるパラメータ値は有限個なので、候補値を正確に列挙して区間ごとにゲームを分類できる。

この係数版の現在の確定結果は [K0518](K0518-quadratic-form-small-board-parameter-classification.md) を参照。
2×2〜4×4の全実数λ、および交差項μxyを加えた3×3の全実数(λ,μ)を、有限禁止族への帰着と全安全局面mexで完全分類した。
特に4×4では全実数λのうちλ=1だけ後手勝ち。過去の会話の勝敗表自体を証拠として採用したのではなく、保存コードと別方式の行列式・ゲーム再帰で新たに照合した。
5×5の全実数λ分類は[K0534](K0534-quadratic-parameter-five-square-all-real-classification.md)で確定し、後手必勝のλは13個。
任意有理点盤の有限例外分類と任意二水平行不変性は[K0532](K0532-quadratic-parameter-finite-classes-and-two-row-invariance.md)。
λ=0の鉛直列盤の最良一様閾値と全Grundy公式は[K0533](K0533-degenerate-quadratic-strips-sharp-uniform-grundy-threshold.md)、
標準鉛直五列盤の真の公式安定化高さ6は[K0535](K0535-degenerate-quadratic-five-column-exact-stabilization.md)。
6×6以上や他の図形変種についての本項の研究課題は引き続き未解決。

## 優先順位と必要な証拠

1. **共面4点のみ**：2×2×2の全159安全局面は[K0526](K0526-cube-coplanar-four-all-safe.md)で強解決済み。次は3×3×3への展開。既知の共球・共面5点両禁止版と分けて比較。
2. **二次形式λ版**：小盤面の厳密勝敗を計算し、有限個のパラメータ切替点で全範囲を分類。
3. **共長方形4点版**：座標軸平行と任意方向、最大安全石数とGrundy数を比較。
4. **鉛直共円柱4点版**：射影による共円禁止と3次元勝敗の関係を調べる。
5. **共放物線・共楕円・共双曲線・共二次曲線・共多項式・共円錐**：軸・係数・退化条件を固定したうえで検算器を実装する。

各新結果は、**禁止組の正確な定義、対象盤、整数または有理数の判定器、実行コード、結果、可能なら独立検査**を `research/experiments/` に残す。有限観測を無界の数学的証明に昇格させない。

## 2026-10-24：共面4点のみ版の最小立方体を解決

[K0526](K0526-cube-coplanar-four-all-safe.md) は2×2×2の全159安全局面を、独立した整数行列式と排他的論理和による禁則検査・完全再帰で分類した。通常版とmisère版はともに空盤後手必勝で、最大安全石数5、最小極大石数4。これは共球・共面5点両禁止版の結論を転用したものではない。3×3×3以上や共球のみ版は引き続き研究対象。
