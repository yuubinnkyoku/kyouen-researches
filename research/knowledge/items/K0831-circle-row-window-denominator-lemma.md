## 補題（証明済み・全称）

真円 C が水平整数直線 y = c 上に2つの格子点を持つ（二重行）なら、その2点は中心 (α,β) に関して
x = α ± t で対称であり、x1, x2 ∈ ℤ から 2α = x1+x2 ∈ ℤ、u := x1−x2 = 2t ∈ ℤ>0。

二重行 y, y′（y < y′, δ′ := y′−y）に対し、t² = ρ²−(y−β)² から

  u² − u′² = 4(ρ²−(y−β)²) − 4(ρ²−(y′−β)²) = 4δ′(y+y′−2β)。

よって 2β = y+y′ − (u²−u′²)/(4δ′) ∈ ℚ（β の有理性）。
2β = p/q（既約）と置けば

  q(u²−u′²) = 4δ′(q(y+y′)−p)。

q(y+y′)−p ≡ −p (mod q) と gcd(p,q)=1 から gcd(q(y+y′)−p, q) = 1 なので、両辺の q での割り切れから

  **q | 4δ′**。

w 個の連続行に d ≥ 2 個の二重行があれば、間隔最小の対は δ′ ≤ ⌈(w−1)/(d−1)⌉ なので

  **q | 4⌈(w−1)/(d−1)⌉**。

### 帰結（7行版）

- 5 二重行（10点構成）: 隣接対 δ′=1 が存在 ⟹ q ∈ {1,2,4}。
- 4 二重行 + 2 接点行（10点構成のもう一方）: 6 行が 7 枠 ⟹ δ′ ≤ 2 の対 ⟹ q ∈ {1,2,4,8}。
- 接点行の Z 値は ±√R（縮小座標）で、両方が行窓（刻み 2q・幅 12q）に入るには 2√R ≤ 12q が必要で、
  かつ窓合同から q | √R・gcd(√R, q) = 1 ⟹ q = 1（R ≤ 36 に帰着）。

### 備考

- q ∈ {2,4} は 7 行では更に parity 論で排除できる（K0830 補題 L3: 窓の Z がすべて奇数のとき
  δ′=1 の対の u²−u′² が平方差として実現不能 or 二重行の u 同一 parity と矛盾）。
- 一般 w では q の候補集合は 4⌈(w−1)/(d−1)⌉ の約数に制限され、w = 8..14 の
  P(w) 解析（K0764 の open 帯）で探索を有限化する道具になる。
