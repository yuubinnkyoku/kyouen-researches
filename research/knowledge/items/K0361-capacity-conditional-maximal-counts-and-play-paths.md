# 任意の途中盤面からの極大盤面数と合法全対局経路数

K0352 の非自明な抽象容量ゲームで現在の各列占有数 `x=(x_1,...,x_w)` は降順、実際に石の置かれた位置集合 `P` は固定する。`h` は容量制約に使う列数、`r` はその上界、`m` は各列の点数。終局の共通最小占有数を `t` とする。

```
s = r-h*t
P_i(t;u,z)=sum_{k=max(0,x_i-t)}^{m-t}
           binom(m-x_i,t+k-x_i)*u^[k>0]*z^k
N_t(P)=sum_{j=0}^{h-1} [u^j z^s] product_i P_i(t;u,z).
```

すると **`N_t(P)` は今の盤面 `P` を含む、閾値 `t` の異なる極大安全盤面（各列内の占有位置まで区別）の正確な個数**である。非零となる `t` は K0352 の `A(x)<=t<=B(x)` の全整数に限り、範囲内ではすべて正。極大盤面の終局石数は `T_t=r+(w-h)t`。

**証明。** 閾値 `t` の極大盤面では全列に少なくとも `t` 点があり、`t` より多い列が高々 `h-1` 本、その増分和は `r-h*t`。列 `i` の終局数を `t+k` とすると、現在 `x_i` 個の占有点を含むように追加する位置の選択数は `binom(m-x_i,t+k-x_i)`。変数 `u` と `z` はそれぞれ増分正の列数と増分和を数える。従って積の上記係数が条件を満たす盤面を重複なく数える。□

**全対局経路数（無界全称公式）。** 今後の着手数 `ell_t=T_t-|P|` とすると、今の盤面から終局まで手を打ち切る**物理的に区別された合法着手列**のうち長さ `ell_t` のものは

```
H_t(P)=ell_t! * N_t(P)
```

通りである。実際に到達する終局の追加石集合を固定すれば、その `ell_t` 個の異なる位置の全順列が安全な終局盤面の部分集合しか経由しないため、すべて合法となる。一つの着手列の終局石集合は一意だから、異なる終局盤面間でも二重計上しない。□

したがって最後の着手者が `s>=2` 人巡回版の `P_j` となる完全プレイの**経路数**は `sum_{t=A}^B [ell_t>=1 and (ell_t-1) mod s=j]*ell_t!*N_t(P)`。これは最適戦略・均衡・確率的勝率を主張しない（等確率の完全着手列モデルだけには正規化して適用可）。

各 `P_i` の二項係数を一律1に置き換えると、実際の石位置ではなく、**ラベル付きの到達終局占有数ベクトルの個数**が得られる。

`x_i=0` の空盤に特殊化すれば K0354 の全極大盤面母関数へ一致し、同項の厳密な強化になっている。証明詳細と [独立再帰検証](../../experiments/capacity-conditional-terminal-count-20261008/README.md) を参照。有限完全検査は `3<=w<=6,1<=m<=4,2<=h<w,1<=r<h*m` の8,774局面と14,390個の終局サイズ別の対局本数に対し不一致0。
