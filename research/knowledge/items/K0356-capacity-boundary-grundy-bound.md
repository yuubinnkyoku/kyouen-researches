# 容量境界上のGrundy値の完全決定

K0352の容量ゲームで、降順占有数を
`x_1≥...≥x_w`、`h=d−1` とし、容量境界

[
x_1+cdots+x_h=r
]

上の安全局面を考える。さらに `b=x_h` と置く。

容量境界上で占有数 `a` の列を1増やす手が合法なのは `a<b` の場合に限る。
`a≥b` なら増加後の上位h成分和が `r+1` になる。一方 `a<b` なら
`a+1≤b` なので、増加後も上位h成分和は `r` のままである。

したがって合法手で変更できるのは下位 `w−h` 成分だけであり、その値は常に `b` 以下である。
特に上位h成分の多重集合と `b` は以後不変である。

下位成分をすべて `b` まで埋めるのに必要な残り手数を

[
R=(w-h)b-sum_{i=h+1}^{w}x_i
]

とする。任意の合法手は下位成分をちょうど1増やすので、必ず `R` を1減らす。
`R=0` なら合法手はなく、`R>0` なら `b` 未満の下位成分が存在するため少なくとも1手は合法である。
従って、どの手順を選んでも終局までの手数は厳密に `R` である。

Sprague–Grundy値について `R` に関する帰納法を行う。
`R=0` では `g=0`。また `R>0` の全ての子局面は残り手数 `R−1` を持つので、
帰納法により全て同じGrundy値 `(R−1) mod 2` を持つ。mexを取れば

[
oxed{g(x)=Rmod 2}.
]

したがって容量境界上では常に

[
oxed{g(x)in{0,1}}.
]

これは従来の上界
[
g(x)le min(w-h,x_h)
]
を真に強化する。

さらに通常プレイの `s≥2` 人巡回版でも、`R>0` なら現在手番を `P_0` とした最後の着手者、従って勝者は戦略によらず

[
P_{(R-1)mod s}
]

に固定される。2人misère版では最後に着手した側が負けるため、現在手番が勝つのは `R` が偶数のとき、かつそのときに限る（`R=0` を含む）。

この命題は容量に余裕のある局面
[
x_1+cdots+x_h<r
]
のGrundy値を制限しない。したがって任意次元容量ゲーム全体での `g≤3` 予想は依然として未証明である。
