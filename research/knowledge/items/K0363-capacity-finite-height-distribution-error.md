# 有限高さでの終局分布の定量的誤差評価と一次係数

K0362の逐次合法点一様モデル（物理的な空き点を各手等確率）を、各列の高さが有限の \`m>r\` のまま評価する。全安全占有局面は上位 \`h\` 列和 \`<=r\` を満たす。列数は \`w>h>=2\`、容量 \`r>=1\`、初期盤面の占有数は \`x\` とし、\`n=w-h\` とする。

\`\`\`
L = r+n*floor(r/h)-sum(x)
\`\`\`

は今後の最大合法着手数の上界である。高さ \`m\` の終局閾値分布を \`P_m\`、無限高さ極限で**毎手合法列を一様に選ぶ**終局閾値分布を \`P_infty\` とする。このとき全ての有限整数 \`m>r\` に対して

\`\`\`
d_TV(P_m,P_infty) <= min(1, L*r/(4*(m-r))).
\`\`\`

したがって個々の終局長の確率誤差も同じ上界以下で、\`m\` を大きくすると一様に \`O(1/m)\` で収束する。

**全称証明。** 任意の非終局の列占有局面 \`z\` で、合法な列の本数を \`k\`、それらの占有数の平均を \`zbar\` とする。列 \`i\` を選ぶ有限高さ確率 \`p_i=(m-z_i)/(k(m-zbar))\` と極限確率 \`1/k\` の差は \`(zbar-z_i)/(k(m-zbar))\`。各列占有数は \`[0,r]\` にあるので、合法列間の占有数の平均絶対偏差は高々 \`r/2\`（分散 \`<=r²/4\` と Cauchy–Schwarz）。従って1手の確率分布の全変動距離は高々 \`r/(4(m-r))\`。毎手、両モデルで同じ着手列を選べる最大結合を使い、全長高々 \`L\` の対局で初めて不一致になる確率を和集合評価すれば上式が従う。□

**一次漸近係数の全称閉再帰。** 終局閾値 \`t\` ごとの極限確率を \`F_t(z)\` とする。終局局面では \`F_t(z)=[z_h=t], D_t(z)=0\`。非終局局面で次の合法列集合を \`J\`、\`k=|J|\`、平均 \`zbar\` とすると

\`\`\`
F_t(z) = sum_{i in J} F_t(z+e_i)/k
D_t(z) = sum_{i in J}(D_t(z+e_i)+(zbar-z_i)*F_t(z+e_i))/k.
\`\`\`

任意の固定 \`w,h,r,x,t\` について

\`\`\`
P_m(t)=F_t(x)+D_t(x)/m+O(m^-2)
\`\`\`

が成立する。\`F_t,D_t\` は有限ゲーム木上の有理数だけの再帰で計算でき、\`sum_t D_t(z)=0\`。証明は一手確率の展開 \`p_i=1/k+(zbar-z_i)/(km)+O(m^-2)\` を全有限ゲーム木について終局から帰納するだけである。□

**次数の鋭さ。** \`(w,h,r,x)=(3,2,3,(0,0,0))\` では短い終局へ進む確率が

\`\`\`
P_m(short)=(m-1)*(m-2)/((3*m-1)*(3*m-2))
          =1/9-2/(9*m)+O(m^-2).
\`\`\`

従って一般に \`O(1/m)\` を \`O(1/m²)\` に改善できない（上界の定数が最適とは主張しない）。これは抽象容量ゲームの小例であり、\`q=r+1>2w\` を満たさないため幾何盤の例ではない。

詳細な全称証明と、K0362の確率再帰とは異なる前向き・後ろ向き有理数DPによる独立検算は [有限高さ誤差実験](../../experiments/capacity-height-finite-error-20261008/README.md) を参照。3<=w<=5, 1<=r<=5 の354初期局面、505終局閾値、1,416有限高さ比較のすべてで不一致0。
