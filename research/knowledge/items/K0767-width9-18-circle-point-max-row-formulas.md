## 証明の骨子

- **会計**: 円と水平線の交点 ≤ 2、接点行は幾何的に ≤ 2。P = 2d + s。
  盤外クリッピングは点数を減らすのみ → x ∈ ℤ で上界を取ってよい。
  **Vieta ケースでは P ≤ 2(d + s)**（これが K0072 の「t ≤ 上界 → P ≤ 2t+2」を
  「点行混合 ≤ 上界 → P ≤ 2·上界」に強化する観察）。
- **Vieta 整数化（K0072）**: 隣接二重行 → C, D, N ∈ ℤ、R = C²+D²−4N ∈ ℤ、
  各点行で s_y² = R−(2y+D)² ∈ ℤ → mod p で QR₀(p)（0 を含む。s_y ≡ 0 mod p を許す）。
- **混合除外証明書**: K0072 の証明書（`{i*i % mod}`、i=0 → QR は 0 を含む）は
  二重行のみでなく**接点行を混ぜた点行集合**に対しても必要条件を与える。
  第三の独立実装（直接 (R,D) 全走査・法毎 early-exit）で
  w=9..18 の全候補部分集合（36+120+165+220+715+2002+5005+11440+19448+43758）が
  すべて何れかの法で除外されることを再現（K0072 の 2 実装の候補総数 3038・79,651 と一致）。
- **非 Vieta カスケード**: 隣接二重行なし → d ≤ ⌈w/2⌉。点行ペアから 4(y−y′)(y+y′+D) ∈ ℤ。
  混合パリティ二重集合（g=1）は 4D ∈ ℤ → 標準形。純パリティ集合（g=2）に反対パリティ接点行が
  あれば 8D 偶数 → 標準形。純パリティ・接点なしは D = e/8 → 4 倍スケールで
  (2s)² = 4C²−16y²−2ey−16N → **mod 9 で A−7y²−Uy ∈ QR9**（g=2 形）。
- **w=15,16 の鍵**: 非隣接 d=8 は独立集合（w=15 は唯一・w=16 は純パリティ 2 つか混合パリティ）。
  s ≥ 1 はいずれも標準形 9 行に帰着し全除外。s=0 は P=16。Vieta は d+s ≤ 8。
  よって P(15), P(16) ≤ 16、witness 16 で等号。
- **w=17,18 の鍵**: Vieta d+s ≤ 9 → P ≤ 18。非 Vieta d=9 は w=17 では唯一 {0,2,…,16}（g=2）で
  g=2 形の窓カウントが **9 偶数行に最大 6 行**（全 (A,U) ∈ ℤ/9² 走査）で不可能。
  d=8, s≤2 は P ≤ 18。w=18 の混合パリティ非隣接 9 集合（g=1 標準形 9 行）は未監査だが
  P ≤ 18 の上界に影響しない。
