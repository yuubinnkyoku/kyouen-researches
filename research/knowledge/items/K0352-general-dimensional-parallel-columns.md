# 任意次元平行列盤の完全な極大配置分類

r=q−1、h=d−1、列占有数を降順にx_1≥...≥x_wとする。
超球面は各鉛直列と高々2点、非鉛直超平面は各列と高々1点しか交わらない。
q>2wなので禁止q点を作れるのは鉛直超平面だけである。
底面の一般位置から各鉛直超平面は高々h列を含み、任意のh底面点はアフィン独立なので実際に対応する鉛直超平面を持つ。
従って安全性は、全|I|=hについて sum_{i∈I}x_i≤r と同値。

hm≤rなら唯一の極大配置は全列満杯。
hm>rなら極大性は

x_1+...+x_h=r,  x_h=...=x_w=b

と同値である。可能なbはちょうど

max(0,r−(h−1)m) ≤ b ≤ min(m,floor(r/h))

の全整数で、終局サイズは穴のない等差数列

r+(w−d+1)b

となる。

非自明領域hm>rで終局サイズが一意なのは
r≡−1 mod(d−1) かつ m=floor(r/(d−1))+1 の場合に限る。
それ以外では極大サイズ差のgcdはw−d+1なので、K0339よりR人巡回版の敗者が戦略に依存しないことと R|(w−d+1) は同値。一意の場合は任意R≥2で固定される。

K0305より、全安全局面のGrundy値が0/1だけになるのは、終局サイズが一意か、w−d+1が偶数の場合に限る。その場合は終局サイズの共通偶奇をTとして g(S)=(T−|S|) mod2。終局サイズが複数かつw−d+1が奇数なら、異偶奇の極大配置が実在するため少なくとも一局面でg≥2となる。

d=3でK0340の容量・極大配置・二値Grundy条件を回収する。K0345/K0347の三次元固有の精密なGrundy閉公式までは一般化しない。

## 任意の途中局面から到達できる終局サイズ（下限を含む修正版）

非自明領域 `hm>r` の安全局面を降順に `x_1>=...>=x_w` とし、`n=w-h`, `b=x_h` とする。次を定義する。

```
L = max(0, r-(h-1)*m)
A(x) = max(b, L)
F_x(t) = sum_{i=1}^h max(x_i,t)
B(x) = max{t in {0,...,m}:F_x(t)<=r}
```

すると **到達可能な極大配置の閾値は厳密に `A(x), A(x)+1,...,B(x)`** であり、終局サイズと残り着手数の集合はそれぞれ

```
{r+n*t : A(x)<=t<=B(x)}
{r+n*t-|x| : A(x)<=t<=B(x)}
```

となる。`A(x)<=B(x)` が常に成立し、どの整数閾値にも穴はない。

**証明。** 閾値 `t` の極大配置は上位 `h` 成分和が `r`、下位 `n` 成分がすべて `t`、かつ上位最小値が `t` である。元の局面を含むなら `t>=b` と `F_x(t)<=r` が必要。さらに上位 `h-1` 列はそれぞれ高々 `m` なので `r<=(h-1)m+t`、すなわち `t>=L` も必要である。逆にこの三条件を満たす `t` には、最小の上位列をちょうど `t` とし、他の上位 `h-1` 列を `max(x_i,t)` から `m` まで増やして合計を `r` にできる。下位列は全て `t` にすれば、元の局面を含む極大配置が構成できる。下方閉性によりそこまでの合法経路もある。`F_x` は単調非減少だから上界までの全整数が実現する。□

**重要な訂正。** 従前この節にあった `b<=t<=B(x)` は下限 `L` を落としており、一般には誤りだった。例えば `w=3,h=2,m=2,r=3,x=(0,0,0)` では `b=0` だが `t=0` は不可能で、唯一の閾値は `t=1` である。上の全局面分類の下限 `max(0,r-(h-1)m)` とも整合する。

## 局所的な二値Grundy領域の必要十分条件

`sigma=r-sum_{i=1}^h x_i` を容量余裕、`c=|{i<=h:x_i=b}|` を上位 `h` 成分での最小値の重複度とする。前節より、終局サイズが一意なのは `B(x)=A(x)` と同値である。この条件は `F_x(A(x)+1)>r` で判定できる（`hm>r` なので `A(x)<m`）。

さらに、**`x` 以降の全ての到達可能な局面で Grundy 値が `0` または `1` に限られる**ための必要十分条件は

```
n=w-h が偶数、または B(x)=A(x)
```

である。このとき全後続局面は終局サイズの偶奇が共通なので、K0305 を部分ゲームに適用でき、

```
g(x) = (r+n*A(x)-|x|) mod 2
```

が成立する。さらに全合法手で Grundy 値は `0<->1` と反転する。従って `g(x)=1` なら **全合法手が Grundy 0 への勝ち手**、`g(x)=0` なら勝ち手は0本である。現在の合法手の本数は、`sigma>0` なら `#{i:x_i<m}`、`sigma=0` なら `#{i:x_i<b}` で直接数えられる。

逆方向も成立する。`n` が奇数かつ `B(x)>A(x)` なら、隣り合う二つの閾値の極大配置が実在し、そのサイズ差は奇数 `n`。もし全後続局面で二値Grundyなら K0305 に反する。従って必ず **少なくとも一つの到達可能な後続局面で `g>=2`** となる（現在の `g(x)>=2` を意味するわけではない）。

特に、上記の終局サイズ一意条件は次の局所量だけで判定できる。

- `b>=L` の場合：`B(x)=A(x)` は `sigma<c` と同値。実際 `F_x(b+1)=r-sigma+c`。
- `b<L` の場合：`B(x)=A(x)` は `r=hm-1` または `x_{h-1}=m` と同値。`F_x(L+1)=(L+1)+sum_{i<h}max(x_i,L+1)` と `r=(h-1)m+L` を比較すれば分かる。

従って **`sigma<c` は終局長一意の十分条件だが、一般には必要条件ではない**。以前のその必要十分主張は撤回する。例えば上記の `x=(0,0,0)` では `sigma=3,c=2` でも終局長が一意となる。

## 巡回 s 人版の途中局面からの最終手番

`s>=2` 人が順に着手するとき、現在の局面からの全合法経路で最後の着手者が同じであるための必要十分条件も、修正後の閾値範囲を用いて

```
B(x)=A(x) または s | (w-d+1)
```

である。`B(x)>A(x)` なら隣接した二つの終局長がともに実現し、差が厳密に `w-d+1` であるため、逆も成立する。これは終局手番の経路独立性であって、多人ゲームの最適戦略や均衡を主張しない。


修正の反例・独立再帰検証・有限完全列挙の条件は [容量終局閾値の訂正実験](../../experiments/capacity-terminal-interval-20261008/README.md) を参照。


## 非二値Grundy領域には容量余裕1の明示的な証人がある

上の `A(x),B(x)` を用い、非自明領域 `hm>r` で `n=w-h` が奇数、`B(x)>A(x)` とする。容量余裕 `sigma=r-sum_{i<=h}x_i` は正である。このとき **下位 `n` 列を動かさず上位 `h` 列を合計 `sigma-1` 回増やした、容量余裕1の後続局面 `y` で `g(y)∈{2,3}` となるものが構成できる**。単に「どこかの子孫に `g>=2`」という K0305 の帰結より強い。

**構成と証明。** `a=A(x)` と置く。`B(x)>a` なので `F_x(a+1)<=r` である。まず上位 `h-1` 列を `y_i=max(x_i,a+1)`、第 `h` 列を `y_h=a` にし、下位 `n` 列を元の `x_i` のままにする。上位和は `F_x(a+1)-1<=r-1`。一方 `a>=r-(h-1)m` より `r-1-a<(h-1)m` だから、上位 `h-1` 列だけをさらに増やして和を `r-1` にできる。全上位 `h-1` 列は `a` より大きく、少なくとも一本は `m` 未満なので `a=y_h<y_{h-1}<m` が成立する。

完成した局面は容量余裕1で、K0358 の両境界型が存在する。よって奇数 `n` に対し

```
g(y) = 2 + ((n*a - sum_{i>h}x_i) mod 2).
```

従って `g(y)=2` または `3` と明示的に決まる。上位成分の和は元の `r-sigma` から `r-1` に増えたので、必要な着手はちょうど `sigma-1` 回である。最終形は元の局面を成分ごとに含み、容量制約は単調なので、全着手列が合法である。□

`n` が偶数または `A(x)=B(x)` なら、前節により全子孫の Grundy 値は `0,1` に限られる。従って **容量余裕1の `g=2,3` 子孫が存在するための必要十分条件**は `n` が奇数かつ `B(x)>A(x)` であり、存在時には上記の浅い経路と `g(y)` の値まで構成的に求まる。

再帰式から独立に検査した再現コード・491,084局面の有限完全列挙は [容量終局閾値の実験](../../experiments/capacity-terminal-interval-20261008/README.md) の `check_slack_one_witness.py` に記録する。


## 容量余裕1の非二値証人の全閾値分類

上記の `A(x),B(x)` に対し、奇数 `n=w-h`、`sigma=r-sum_{i<=h}x_i>0` とする。下位 `n` 列を一度も増やさず、上位 `h` 列だけを `sigma-1` 回増やして到達する容量余裕1局面 `y` で、上位最小値が一意 `y_h=t<y_{h-1}<m`（K0358 の両境界型）となるものの閾値 `t` は、**厳密に `A(x),...,B(x)-1`** である。全ての `t` が実現する。

証明：`A<=t<B` なら `F_x(t+1)<=r`。上位 `h-1` 列を `max(x_i,t+1)`、第 `h` 列を `t` にして上位和を `r-1` まで埋められる。`t>=r-(h-1)m` により、そのとき `y_{h-1}<m` となるように埋められる。下位 `n` 列を保ち、元の局面を含むため、この `y` までの `sigma-1` 手は全て合法。逆に任意の該当 `y` では `t>=x_h`、かつ `y_{h-1}<m` と上位和 `r-1` から `t>=r-(h-1)m`、したがって `t>=A`。また `y_i>=max(x_i,t+1)`（`i<h`）から `F_x(t+1)<=r`、よって `t<B`。□

K0358 から、その閾値の証人は全て

```
g(y)=2+((n*t-sum_{i>h}x_i) mod 2).
```

従って `B=A` なら該当証人は存在せず、`B=A+1` なら `2` と `3` のどちらか一方だけ、`B>=A+2` なら**同じ `sigma-1` 手で Grundy 2 と3の両方が実際に到達可能**となる。数値の `2,3` は閾値 `t` を増やすたび交互に現れる。これは前節の一証人構成を全閾値に強める全称結果であり、証拠・独立検証は [容量終局閾値の実験](../../experiments/capacity-terminal-interval-20261008/README.md) に記録した。


## 飽和列除去と共通底上げ除去による局面同型

以下は `hm>r` の抽象容量ゲームの **任意の安全な途中局面以降の全ゲーム木** に関する構造定理であり、単に終局サイズだけの対応ではない。

1. 満杯列が `k<h` 本あり、降順で `x=(m^k,y)` なら、`(w,h,m,r;x)` の以後の手の木は `(w-k,h-k,m,r-k*m;y)` のものと完全に同型である。満杯列には今後着手できず、残り列のどの後続配置 `z` に対しても `sum(top_h(m^k,z))=k*m+sum(top_(h-k)(z))` なので、各手の合法性が一致する。Grundy 値、合法経路長、最後の着手者は全て保存され、`n=w-h` は不変。
2. `0<=a<=min_i(x_i)` なら、全占有数を `a` だけ下げる写像により `(w,h,m,r;x)` と `(w,h,m-a,r-h*a;x-a*1)` の以後の手の木が同型である。`m` と `r` の移動がそれぞれ `a,ha` だから上限・容量制約・全手が一対一対応する。特に `a=min_i x_i` によって最小占有数0へ正規化できる。

**鋭い系（`h-1` 列満杯）**：満杯列を全て除くと `h'=1, r'=r-(h-1)m<m` であり、残りの `n+1=w-h+1` 列は互いに独立に高さ `r'` まで進む。元の `x=(m^{h-1},y)` に対し

```
g(x)=((n+1)*(r-(h-1)*m)-sum(y)) mod 2.
```

全後続局面でこの偶奇式が成り立ち、勝ち局面の全合法手が Grundy 0、負け局面には Grundy 0 の合法手がない。奇数 `n` でも任意の容量余裕で厳密に二値解決できる。

**高次元からの完全縮約（`h-2` 列満杯）**：`k=h-2` なら `h'=2` のペア容量ゲームへ完全に落ちる。奇数 `n` の場合、残りの列数 `w'=n+2` は奇数だから、K0347 の全有限長二最大値公式を用いて、全 `m,r`・全安全局面の Grundy 値を厳密に計算でき、値は必ず0から3のいずれか。偶数 `n` は本項の二値Grundy分類で処理できる。したがって **任意次元の容量ゲームで `h-2` 本以上が既に満杯の領域は全Grundy強解決済み** とみなせる。ただしこれは抽象容量ゲームの同型であり、幾何学的に異なる盤同士が同形だと主張するものではない。

独立メモ化 mex 検査では飽和列除去66,444局面、共通底上げ44,484局面で一致した。[全称証明・再現検証器・大規模有限実験](../../experiments/capacity-normal-forms-20261008/README.md)を参照。なお幅10・高さ10と幅11・高さ11の合計96,618,981件での `g<=3`・偶数余裕二値の検算は **有限範囲に限る支持** であり、未証明の無界予想には昇格させない。
