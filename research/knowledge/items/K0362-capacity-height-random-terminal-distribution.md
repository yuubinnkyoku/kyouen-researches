# 高さ増大による終局分布：二つの自然なランダム対局モデルの厳密な乖離

固定した抽象容量条件 `w>h>=2, r>=1` と、固定した安全な初期石集合 `P`（各ラベル付き列の占有数 `x_i`）に対して、各列の点数 `m>=r` を増やす。`n=w-h`、K0352 の到達終局閾値を `A=x_h<=t<=B`、終局石数を `T_t=r+n*t`、追加着手数を `ell_t=T_t-|P|` とする。`m>=r` によって `A,B` は高さに依存しない。

閾値 `t` におけるラベル付き終局占有数ベクトルで元の占有数以上となるものの有限集合を `F_t(P)` とする。このとき（K0361）終局盤面数・完成着手列数は

```
N_t(m) = sum_{y in F_t(P)} product_i binom(m-x_i,y_i-x_i),
H_t(m) = ell_t! * N_t(m).
```

各二項係数は `m` の多項式で、`F_t(P)` は `m>=r` で一定。よって `N_t` は厳密に次数 `ell_t`、最高次係数は次の正の有理数である。

```
Lambda_t(P) = sum_{y in F_t(P)} product_i 1/(y_i-x_i)! > 0.
```

**全称定理1（完成対局一様）。** 元の盤面から終局までの**物理的な着手位置と順序を区別した全完成対局**から1つを一様に選ぶ。もし `B>A` なら、最大終局閾値 `B` を選ぶ確率は

```
Pr_complete(t=B)
 = 1 - C(P)*m^(-n) + O(m^(-n-1)),
C(P) = ell_(B-1)!*Lambda_(B-1)/(ell_B!*Lambda_B) > 0.
```

したがって非最長終局の確率は厳密に `Theta(m^(-n))` で、最大終局長に集中する。もし `B=A` ならもとから終局長は一種類なので確率1。証明は `ell_t=ell_A+n(t-A)` と上記多項式の次数比較で直ちに従う。

**全称定理2（逐次合法点一様）。** 毎手、現在合法な**実際の空き点**を一様に選ぶ。局面 `z` で着手可能な列集合 `L(z)` について、列 `i` が選ばれる確率は `(m-z_i)/sum_{j in L(z)}(m-z_j)`。固定 `r` では全後続占有数が高々 `r` なので、`m->infinity` で `1/|L(z)|` に収束する。全対局長は固定 `w,h,r` により有界で、よって終局分布は「合法な列を毎手一様に選ぶゲーム」の終局分布に収束する。K0352より各 `A<=t<=B` に少なくとも一つの合法経路が存在し、その経路の極限確率は正なので

```
Pr_sequential,limit(t)>0 for every A<=t<=B.
```

従って `B>A` の場合、**完成対局一様は最長終局へ集中するが、逐次一様は全到達終局長に正の極限確率を残す**。

**巡回s人への系**：`s>=2` 人が交代して打つとき、非終局からの最終着手者 `P_(ell_t-1 mod s)` は完成対局一様では最大終局長の担当者へ集中する。一方 `B>A` かつ `s\nmid n` なら、逐次一様極限では少なくとも二人の異なる最終着手者に正の確率が残る。これは合法対局の確率モデルに関する結論で、最適プレイの勝者・均衡を主張しない。

**厳密な小例**：`w=3,h=2,r=3,P=empty` で `m>=3` とすれば

```
Pr_complete(T=3) = (m-2)/(12*m^2+m-2) ~ 1/(12*m),
Pr_sequential(T=3) = (m-1)*(m-2)/((3*m-1)*(3*m-2)) -> 1/9.
```

長い終局（4石）の逐次モデル極限確率は `8/9`。この小例は `q=r+1>2w` を満たさず、抽象容量ゲームの例に限る。

**証明と独立検証**は [実験記録](../../experiments/capacity-height-bias-20261008/README.md)。`3<=w<=5, 1<=r<=5` の354局面・505閾値で次数と最高次係数の完全照合、および独立逐次確率再帰による354局面の極限分布・正値性を検証し、不一致0。有限実験を全称証明に読み替えていない。
