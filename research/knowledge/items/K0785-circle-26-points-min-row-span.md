## 命題（全称・証明済み）

円の格子点を連続整数行に配るとき、13二重行（26点）を含み**円の行中心を含む窓**
（中心窓）の最小幅：

- **E族**（(2x−A)²+(2y−B)²=2R′、A,B奇）: σ₁₃^center(E) = **43**。
  達成は **R′=1105（R=2210）型のみ一意**（例: (2x−105)²+(2y−105)²=2210 は
  行34..76 にちょうど13二重行）。次点 52（R′=1625=5³·13）も一意。
- **Z族**（=4R′、A,B偶）: σ₁₃^center(Z) = **58**（R′=1105）一意。次点 70（1625）。

一般化（K=13..26 二重行の中心窓 bestK、E族・Z族）：

- **E**: 13..16 → 43/44/46/48（@1105）、17..24 → 83/87/94/96/100/101/105/106（@5525）。
  **K=13..24 は全称**（完備性限界 B_E(bestK) ≤ 5.96×10⁷ ⊂ 掃引 6.2×10⁷）。
- **Z**: 13..16 → 58/65/66/67（@1105）、17..18 → 116/125（@5525）は**全称**。
- R′=5525=5²·13·17（R=11050）が E K=17..24 の共通証人で、K0791 の独立検証した
  11050円の窓計数下界（P(83)≥34 … P(106)≥48）と正確に対応。

## 証明の骨子（report §3 が正本）

各ペア (X,Y)（X²+Y²=R′、逆パリティ）に対し行オフセット c ∈ {s,d} = {X+Y, |X−Y|}
（s²+d²=2R′、s,d 奇）。窓幅 W₀ ⇒ 全 c は |c| ≤ C := 2(W₀−1)。

1. s 型があれば R′ ≤ (X+Y)² ≤ C²。同一ペアで s,d 両方小さくても R′ ≤ C²。
2. d 型のみなら、2相異な d₁≠d₂ ≤ C に対し (s₁−s₂)(s₁+s₂) = (d₂−d₁)(d₂+d₁)。
   s 奇・s₁≠s₂ ⇒ |s₁−s₂| ≥ 2 から s₁+s₂ ≤ C(C−2)/2。sᵢ ≥ √(2R′−C²) なので
   R′ ≤ C²((C−2)²+16)/32。W₀=43 で R′ ≤ 1,486,170 ≪ 掃引 11.3M。
3. 3mod4 素因数（t² 倍）は行オフセットを t 倍にスケールするだけなので
   最小円は 1mod4-smooth に限る（掃引の正当化）。

Z族は X ≥ √(R′/2) により窓内は Y 型のみ（R′ > 2C′² のとき）で
(X₁−X₂)(X₁+X₂) = Y₂²−Y₁² ≤ C′² ⇒ R′ ≤ C′⁴/4+C′²。

掃引は R′ ≤ 6.2×10⁷ の D≥7 全数（c8=890,634、D=7 は 5⁶/13⁶/17⁶ のみ）で
全 bestK を計算し、完備性限界内に反例がないことを機械保証する。
