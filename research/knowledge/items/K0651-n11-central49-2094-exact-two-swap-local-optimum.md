# 2,094七石類の最大二証人交換に対する局所最適性

K0650の46六石証人が作る2,094正準七石類について、**最大二証人の交換で義務数を減らせない**ことを厳密に検査した。

| 検査 | 結果 |
| --- | ---: |
| 六石候補 | 3,868類 |
| 交換候補 | 4,988組 |
| 幾何的に有効な非自明交換 | 3,808組 |
| 既知WIN6のため除外 | 9組 |
| 既知WIN7のため除外 | 0組 |
| 有効な交換 | 3,799組 |
| **2,094類未満への改善** | **0組** |
| 終局証明済みLOSS7との交差 | 6類 |

46証人は92個の通常五石頂点を完全マッチングする。二証人を外した4頂点の3通りの再結合を全列挙し、元の証人を一つ残す一証人交換も漏れなく含めた。終局戦略の独立再生を通過した後、選択証人は4×4整数行列式、代替候補は3×3整数行列式によって検査する。

**これは大域的最適性ではない。** 三証人交換は改善できる可能性があり、条件付きLOSS証人の勝敗は未証明である。二石局面 {49,60} と標準11×11空盤の勝敗は **UNKNOWN**。
