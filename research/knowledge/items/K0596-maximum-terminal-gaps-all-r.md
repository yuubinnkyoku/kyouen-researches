# 禁止集合r本での最大終局欠番はr−2個、達成構造はひまわり型に限る

任意のr>=3個の非空禁止集合E_iを持つ有限盤（総点数N）では、最小極大石数と最大極大石数の間に存在しない終局長の個数は高々 **r−2**。等号成立の必要十分条件は、E_iが非空の共通芯Cと、互いに素な非空花弁P_iからなること（ほかの点は全禁止集合の外にあってよい）。このとき終局長は厳密に **N−r, N−1** の二種類だけで、極大配置母関数は

    |C|u^(N−1) + (∏_i |P_i|)u^(N−r)

となる。証明は極大安全集合の補集合が極小横断集合であること、および極小横断集合の各点が私有の証人となる禁止集合を持つことに基づく。r=3のK0594、r=4のK0595の最大欠番型を、任意rへ拡張する。

整数平面上で、共円・共線の禁止q点集合がちょうどr個（r>=3,q>=4）あり、最大r−2個の終局欠番が生じる盤の**最小総点数**は

    N_min = r(q−2)+2.

すべてのr,qで達成できる。最小盤の極大配置母関数は

    (q−2)^r u^(r(q−3)+2) + 2u^(r(q−2)+1).

共通する有理2点を通るr本の異なる有理円を用い、各円にq−2個の有理点を一般位置で追加して整数化する。二つの異なる円・直線の交点は高々2点なので、この点数は下界でもある。

**新しい明示例**：r=5,q=4では最小12点が11×11格子内に実在し、禁止四点組は正確に5個、極大配置母関数は **32u^7+2u^11**。終局長8・9・10はすべて欠番。全495四点組、3315安全局面、空盤の通常・misère補助Grundy値(1,0)を独立に検算した。さらにr=3,4の全32896種類の0/1所属型を極小横断集合の直接列挙で検証した。

**証拠境界**：任意r,qの特徴づけと最小点数は数学的全称証明。所属型・整数座標・Grundyの確認は有限完全検査。12点は11×11格子の部分集合であり、標準11×11全121点盤の勝敗を解決しない。
