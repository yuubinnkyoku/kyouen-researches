# 敗者除外後の継続規則

## 命題・範囲

K0339は規則を「最初に合法手を失った一人を敗者として終了」に固定し、「敗者を取り除いて
継続する規則」を明示的に未解決として残した。本項は2つの自然な継続規則を定式化し、
それぞれに全称定理を与える。いずれの規則も**最初の排除まではK0339と厳密に同一**
（最初に合法手を失ったプレイヤーが第1敗者・手番は巡回・安全判定は不変）。

- **規則CASC（カスケード）**: 詰んだプレイヤーを排除し、盤面は変更しない。
  巡回順の次の残存者が着手を試みる。
- **規則REMO（石除去）**: 詰んだプレイヤーを排除し、**そのプレイヤーの所有石**
  （着手者が所有）を盤から取り除いて継続する。

**定理C（カスケード順位・全称）** 任意の有限下方閉配置ゲーム・任意の r≥2・任意の合法対局:
終端が極大安全位置 M（|M|=L）のとき、CASC の排除順は P_{L mod r}, P_{(L+1) mod r}, …
（巡回順に連続、計 r−1 人）で完全に決まり、生存者＝唯一の勝者は **P_{(L−1) mod r}、
すなわち最終着手者**。
*証明* 終端位置は極大なので排除後も含め誰も合法手を持たず、排除は着手不能者の
巡回連続に退化する。生存者は巡回順で第1敗者の一つ前＝最後に着手した者。□

帰結: (i) **「最終着手者＝勝者」は規約ではなく CASC の帰結**。
(ii) 可能生存者集合＝可能最終着手者集合 {(a+ℓ−1) mod r}、連合 Win_j＝「j が単独生存を
強制できる」ことと一致し、K0858 の Surv/Win 表がそのまま勝者表になる。
(iii) 全順位の戦略非依存性は L mod r の一意性、すなわち **r | Δ と同値**
（K0339の「敗者固定 ⟺ r|Δ」が敗者から全順位へ昇格）。

**定理D（一様盤の石除去完全決定性・全称）** 全極大安全集合が同サイズ C（Δ=0）なら、
REMO の全敗者列・生存者は **(C, r) のみで決まり幾何・戦略に非依存**で、次の明示計数再帰
で計算できる: 各フェーズで盤は現在サイズ s から C まで満たされる（一様性により
サイズ C の安全位置は常に極大・サイズ C 未満の安全位置は常に拡張可能なのでフェーズ長
ℓ=C−s は強制）、着手者は巡回順、詰むのは (開始+ℓ) mod k 番目、排除後にその所有石数だけ
盤が減る。全状態量（盤サイズ・巡回順・手番・各プレイヤーの石数）がこの再帰で閉じ、
幾何情報は入らない。帰納で r−1 フェーズ後に唯一の生存者が残る。□
出力表（C=1..12 × r=2..8 の敗者列・生存者）は audit json 参照。
2×m q=4 の一様盤（m=1,2,3 → C=2,3,4、m≥9 → C=6）は該当行を読むだけ。
r=2 では排除が1回で終わるため REMO≡CASC（生存者＝最終着手者、機械確認済み）。

**反例（r | Δ でも REMO は決定的でない）** 極大安全集合のサイズが {6,9}（Δ=3）の合成
下方閉族（A=6点、B=Aと3点を共有する9点集合、安全集合=A/Bの部分集合）で r=3:
第1敗者は K0339（3|3）により常に P_0 に固定されるが、**生存者は戦略依存** —
6点集合で終わる対局では敗者列 [P_0, P_1]・生存者 P_2、9点集合で終わる対局では
[P_0, P_2]・生存者 P_1。同じ族の CASC は決定的（生存者 P_2、定理C(iii)）。
よって定理Dの Δ=0 仮定は本質的で、「第1敗者固定（r|Δ）」は順位決定に十分でない。
実在盤の Δ は 0 か 1（44盤センサス）なので、Δ=1 盤では r≥2 で常に r∤Δ であり
そもそも第1敗者から非決定的であることも機械確認した。

**CASC と REMO は r≥3 で実際に異なる**: 2×3 q=4（C=4）の r=3 では CASC の生存者は P_0
（最終着手者）、REMO の生存者は P_2。

## 現在の根拠と限界

検証（`verify_elimination_continuation.py`・機械チェック336件全合格・2回実行バイト同一）:

- REMO は所有権を追跡した全対局木の完全列挙（メモ化DFS）で独立計算し、一様盤
  2×2/2×3 q=4・3×2 q=5（C=6 全盤）・2×4 q=5（C=8 全盤）・3×3 q=5（C=9 全盤）の
  r=2..6（盤により上限）で結果が常に単一かつ計数再帰の予測と完全一致。
  定理Cの第1敗者＝C mod r（凍結規則）も全件一致。
- CASC は9盤（一様: 2×2/2×3/3×3 q=4・2×4 q=5・3×2 q=5、非一様: 2×4/2×5/2×6/3×4 q=4）
  ×r=2..6 で、各結果の排除順が巡回連続構造・生存者＝最終着手者・
  可能敗者/可能最終着手者集合との一致・決定性 ⟺ r|Δ（Δ は既発表 audit の値）を全件確認。
- 合成反例族は r=2,3 で全対局列挙により確認（r=3: 2結果・生存者 {P_1,P_2}、
  第1敗者は常に P_0）。r=2 の REMO≡CASC も全盤で確認。
- 大盤（2×9..2×12 q=4・C=6）は所有権列挙の状態爆発のため総当たり検証から除外した
  （定理D自体がそれらを (C,r)=(6,r) 行として決定する）。

限界: 定式化したのは CASC/REMO の2規則のみ（リスタート規則・石の一部除去などは
主張しない）。非一様盤（Δ≠0）での REMO の決定性の必要十分条件は未解決
（反例が否定するのは r|Δ の十分性のみ）。順位以外の報酬規約・r人nimber は主張しない。
11×11 空盤・二石root {49,60}/{59,60}・S2 {59,60}・class1/class2/class4 は本項と無関係に
UNKNOWN/IN FLIGHT のまま。
