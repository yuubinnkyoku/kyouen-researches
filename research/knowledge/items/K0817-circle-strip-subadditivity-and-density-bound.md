## 命題（証明済み・全称）

P(w) を、真円が連続する w 本の整数水平行に含む格子点数の最大値とする。P(0)=0 と置くと、全ての a,b≥0 について

P(a+b) ≤ P(a)+P(b)。

したがって Fekete の補題により

λ := lim_{w→∞} P(w)/w = inf_{k≥1} P(k)/k

が存在する。さらに K0804 の全称結果 P(82)=32 から

0 ≤ λ ≤ 32/82 = 16/41。

また、K0791 の11050円 witness により **P(83)=34** である。

## 証明

真円と固定した水平整数直線との交点は高々2点である。よって P(w)≤2w であり、各 P(w) は有限である。

任意の真円 C と連続する a+b 本の整数行の窓 I を取る。I を先頭 a 行 I_a と残り b 行 I_b に分ける。行集合が互いに素なので

|C∩I| = |C∩I_a| + |C∩I_b| ≤ P(a)+P(b)。

この不等式は C と I に依存しないため、最大値を取って P(a+b)≤P(a)+P(b) を得る。a=0 または b=0 は P(0)=0 から自明である。

非負で有限な劣加法列 P(w) に Fekete の補題を適用すると極限 λ が存在し、下限表示も成り立つ。K0804 は全ての真円・全ての連続82行窓について P(82)=32 を証明しているから、λ≤P(82)/82=16/41。

## 幅83の完全決定

K0791 の円

(2x−105)²+(2y−105)²=11050

は、行集合

{0,1,5,6,9,12,19,23,28,30,42,50,55,63,75,77,82}

の各行に2点ずつ持つ。従って P(83)≥34。

一方、劣加法性より

P(83)≤P(82)+P(1)=32+2=34。

よって **P(83)=34**。この上界は全ての真円に適用され、下界は一つの明示円で達成される。

## 傾き16/41に対する最良の加法定数

w=82k+r（k≥0、0≤r<82）と書く。劣加法性と P(82)=32 から

P(w)≤32k+P(r)。

そこで

Δ(r)=41P(r)−16r

と置く。P(0)=0、P(1)=2、および results/fixed-width/pw_circle_point_max.csv の厳密値 P(2)..P(81) を用いると、

max_{0≤r<82} Δ(r)=568

であり、この最大値は r=26 のときだけ達成される（P(26)=24）。

従って

41P(w)−16w
≤41(32k+P(r))−16(82k+r)
=41P(r)−16r
≤568。

よって全ての w≥0 について

**P(w)≤(16w+568)/41**

が成り立つ。P(w) は整数なので、同値な整数上界は P(w)≤floor((16w+568)/41) である。

この加法定数は、傾き16/41を固定した範囲で最良である。実際、w=26 では P(26)=24 なので

P(26)−(16/41)·26=568/41。

従って、全幅で成立する同じ傾きの上界に対し、568/41より小さい加法定数は不可能である。

## 有限表との照合

results/fixed-width/pw_circle_point_max.csv の w=2..83 の82行、全行 proved-exact、P(82)=32、P(83)=34 を確認した。P(1)=2 と P(0)=0 を補い、a+b≤83 の3,570組全てで劣加法不等式を検査し、違反は0件だった。

さらに剰余 r=0..81 の全82値について Δ(r)=41P(r)−16r を整数演算で計算し、最大568が r=26 のみで達成されることを確認する。検証器は11050円の奇数座標解も直接列挙し、0..82行の34点・17二重行を再確認する。

これらの有限照合は表・witness・剰余最大値の整合性検査であり、全称劣加法性と全幅上界は上記の行分割・剰余分解による証明に依存する。
