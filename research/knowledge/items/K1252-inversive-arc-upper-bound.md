# 反転平面M(q)の弧はq奇数(q≥7)でq+1以下（無条件）

## 定理

`q` を奇数、`q ≥ 9` とする。Miquelian 反転平面 `M(q)` の弧（どの4点も同一円上にない
点集合）のサイズ `k` は

> **`k ≤ q`**

（Step 1–5 で `k ≤ q+1` を示し、Step 6 で `k = q+1` を排除する。）

## 証明

弧 `S` を楕円二次曲面 `Q⁻(3,q) ⊂ PG(3,q)` 上の点集合とみなす（K1250：`M(q)` の点＝`Q⁻` の点、
円＝切断平面、共円＝同一平面上）。したがって「弧」＝「どの4点も一次独立な集合」。

**Step 1（射影上界）** `P ∈ S`、`π` を `P` を含まない平面とし、`S\{P}` を `P` から `π` へ射影する。
`A,B,C` の像 `A',B',C'` が共線 ⟺ `P,A,B,C` が同一平面上、なので像は `PG(2,q)` のアーク。
`P,A,B` が共線なら4点従属になるので像は単射。`q` 奇数の `PG(2,q)` のアークは高々 `q+1` 点
（古典的）だから `k−1 ≤ q+1`、すなわち **`k ≤ q+2`**。

**Step 2（`k = q+2` と仮定する）** Step 1 の像はちょうど `q+1` 点のアーク、すなわち
`PG(2,q)` の oval。`q` 奇数では **Segre の定理**により oval は円錐曲線 `O`。
よって `S\{P}` は `P` を頂点とし `O` を底とする二次錐 `C_P` 上にあり、
さらに生成線（`P` と `O` の点を結ぶ直線）ごとにちょうど1点ずつ載る。

**Step 3（2つの錐の交わり）** `Q ∈ S`、`Q ≠ P`。同様に `S\{Q} ⊂ C_Q`。
`C_P, C_Q` は頂点の異なる二次錐だから相異なり、共通部分は4次曲線（Bezout）。
両者は直線 `PQ` を共通成分に持つ（`Q ∈ C_P` より `PQ` は `C_P` の生成線）ので

```
C_P ∩ C_Q = 直線 PQ ∪ Γ,   deg Γ = 3
```

`A ∈ S\{P,Q}` は `C_P` にも `C_Q` にも載るから `A ∈ PQ ∪ Γ`。`P,A,Q` が共線なら3点従属で
矛盾するので `A ∉ PQ`、したがって **`S\{P,Q} ⊂ Γ`**（`q` 点）。

**Step 4（`Γ` はねじれ三次曲線）** `Γ` が可約なら成分は直線と円錐曲線（または3直線）。
円錐曲線成分は平面上なので4点が同一平面上に来て矛盾、直線成分は3点共線で矛盾。
よって `Γ` は既約。既約3次曲線は平面3次曲線かねじれ三次曲線で、平面なら `q ≥ 4` 点が
同一平面上に来て矛盾。したがって **`Γ` はねじれ三次曲線（twisted cubic）**。
`C_P, C_Q` は `F_q` 有理なので `Γ` も `F_q` 有理。

**Step 5（矛盾）** `S ⊂ Q⁻` で `S\{P,Q} ⊂ Γ`、すなわち `Γ` は `Q⁻` 上に `q ≥ 7` 点を持つ。
もし `Γ ⊄ Q⁻` なら Bezout より `|Γ ∩ Q⁻| ≤ deg Γ · deg Q⁻ = 3·2 = 6 < q`。よって `Γ ⊂ Q⁻`。
ところが **`Q⁻(3,q)` は `F_q` 上有理な奇数次数曲線を持たない**：
`Q⁻` は滑らかな2次曲面で、閉包上 `P¹×P¹` と同型、`Pic = Z²` の2つの生成元
（2つの ruling の直線類）は Frobenius で入れ替わる（`Q⁻` は `F_q` 直線を持たない）。
したがって `F_q` 有理な因子類は `a(f₁+f₂)` の形で次数は `2a`、**偶数**。
`deg Γ = 3` は奇数なので矛盾。□

**Step 6（`k = q+1` の排除）** 同じ論法をもう一段使う。`|S| = q+1` と仮定し `P ∈ S` から
射影すると像は **`q`-アーク**。ここで古典的事実（Segre）：

> `q` 奇数の `PG(2,q)` の `q`-アークは必ず `(q+1)`-アークに含まれ、
> `(q+1)`-アークは円錐曲線である。

（「`(q+1)`-アーク＝円錐曲線」が Segre の定理、「`q`-アークは `(q+1)`-アークに含まれる」も
Segre による古典的結果。例えば *Complete arcs and algebraic curves in PG(2,q)*,
J. Algebra (1987) の要旨に短い証明が与えられている。）

よって像は円錐曲線 `C` に含まれ、Step 2–3 と同様に `S\{P} ⊂ C_P`（二次錐）がすべての `P` で
成り立ち、`P ≠ Q` に対して `S\{P,Q} ⊂ Γ`（`deg Γ = 3`）を得る。`|S\{P,Q}| = q−1` で
`q ≥ 9` なら `q−1 > 6 = deg Γ · deg Q⁻` なので Bezout から `Γ ⊂ Q⁻`。
Step 5 と同じく `Q⁻` は `F_q` 有理な奇数次数曲線を持たないので矛盾。□

## 系

`q` 奇数、`q ≥ 9` で

> **`(q+5)/2 ≤ K(q) ≤ q`**

（下界は Sonnino 1999 の `(q+5)/2`-弧構成、K1251）。
すなわち `K(q) = Θ(q)` で、`0.5q ≤ K(q) ≤ q`。
以前の「`K ≤ q+3`」「`K ≤ q+2`」「`K ≤ q+1`」はすべて **`q`（奇数 q ≥ 9、無条件）** に置き換わる。

**上界の sharp 性と適用範囲**：`K(5) = 6 = q+1` なので `K ≤ q` は **q=5 では成立しない**
（`6 > 5`）。定理の適用範囲が `q ≥ 9` であることと整合する。
厳密値 `K(7)=6, K(8)=7, K(9)=9` は `K ≤ q` を満たす（**q=9 で上界は tight**：`K(9)=q`）。
q ≥ 11 では数値が `≈0.65q` なので上界はまだ緩い。

**`q = 3` は真の例外**：`K(3) = 5 = q+2`（全数列挙で厳密）。Step 5–6 の Bezout 評価が
`q > 7` を必要とするため、定理の適用範囲（`q ≥ 9`）から外れる。
`q = 5` も範囲外で、`K(5) = 6 = q+1` は上界 `q` を超える（上界の最良性の証拠）。

## 数値との整合

検証済みの弧はすべて `K ≤ q` を満たす：
`q=13:10, 17:13, 19:14, 23:16, 29:20, 31:21, 37:25, 41:27, 43:28, 47:30, 49:32`
（いずれも `q` 以下）。厳密値 `q=7:6, 8:7, 9:9` も `K ≤ q` を満たす（q=9 は等号）。
また Step 2 の「射影が oval になる」は K1250 で**全証人について総当り検証済み**
（任意の1点からの射影が `PG(2,q)` のアークになる）。

## 限界

- **先行研究の可能性**：上界 `q`（q 奇数）自体が既知かは確認できていない。
  古典的 Segre の結果（`q`-アーク ⊂ `(q+1)`-アーク＝円錐曲線）を
  「2つの二次錐の交わり」に通す部分が本項の貢献で、新奇性の主張は控えめにする。
- 古典的事実（Segre の oval=conic と q-arc ⊂ conic、Bezout、楕円二次曲面の Picard 群と
  Frobenius の作用）を引用して使っている。標準的だが本項では独立証明していない。
- **`K ≤ q−1` へは同じ論法で進めない**：射影が `(q−1)`-アークになり、
  「`(q−1)`-アークは円錐曲線に含まれる」が必要だが、これは一般には偽
  （`(q+3)/2` 程度の非円錐 complete arc が存在する）。
- **偶数 `q` には拡張できていない**：Step 1 の上界が `q+3` になり、Step 2 の
  「oval = conic」も偶数では成り立たない（非円錐 oval が存在）。偶数側の最良は
  K1250 の MDS 経由 `K ≤ q+1`（MDS予想下）である。
- 上界 `q` は数値（`≈0.65q`）からはまだ緩い。定数 `liminf K/q`（`0.5` と `1` の間）が
  中心的な未解決問題。
