# 反転平面M(q)の弧はq≥7でq以下（無条件）

## 定理

`q ≥ 7` のすべての `q` について、Miquelian 反転平面 `M(q)` の弧（どの4点も同一円上にない
点集合）のサイズ `k` は

> **`k ≤ q`**

外部入力は2つの古典的分類定理のみ：
**Segre (1955)**「`q` 奇数の `PG(2,q)` の `(q+1)`-アークは円錐曲線、`q`-アークは円錐曲線に含まれる」
（すなわち `(q+1)`-アークは正規有理曲線）、
**Casse–Glynn (1982)**「`q = 2^m`（`m ≥ 3`）の `PG(3,q)` の `(q+1)`-アークは Frobenius ひねり
正規有理曲線に同値」。

証明は3通りを組み合わせる：

| 範囲 | 方法 | 節 |
|---|---|---|
| 奇数 `q ≥ 9` | 射影＋Segre の oval 定理＋2つの二次錐の交わり（Bezout）＋`Q⁻` に F_q 有理な奇数次数曲線がない | 下の「証明」 |
| 奇数 `q ≥ 7` | NRC を通る二次曲面の行列式が常に平方 `((ac−b²)/4)²` | 「系（正規有理曲線…）」 |
| 偶数 `q ≥ 8` | Casse–Glynn の分類＋弧を通る二次曲面の族の解析 | 「系（偶数 q…）」 |

**例外**：`K(3) = 5 = q+2`、`K(4) = 5 = q+1`、`K(5) = 6 = q+1`（すべて全数列挙の厳密値）。

## 証明

弧 `S` を楕円二次曲面 `Q⁻(3,q) ⊂ PG(3,q)` 上の点集合とみなす（K1250：`M(q)` の点＝`Q⁻` の点、
円＝切断平面、共円＝同一平面上）。したがって「弧」＝「どの4点も一次独立な集合」。

**Step 1（射影上界）** `P ∈ S`、`π` を `P` を含まない平面とし、`S\{P}` を `P` から `π` へ射影する。
`A,B,C` の像 `A',B',C'` が共線 ⟺ `P,A,B,C` が同一平面上、なので像は `PG(2,q)` のアーク。
`P,A,B` が共線なら4点従属になるので像は単射。`q` 奇数の `PG(2,q)` のアークは高々 `q+1` 点
（古典的）だから `k−1 ≤ q+1`、すなわち **`k ≤ q+2`**。

**Step 2（`k = q+2` と仮定する）** Step 1 の像はちょうど `q+1` 点のアーク、すなわち
`PG(2,q)` の oval。`q` 奇数では **Segre の定理**により oval は円錐曲線 `O`。
よって `S\{P}` は `P` を頂点とし `O` を底とする二次錐 `C_P` 上にあり、
さらに生成線（`P` と `O` の点を結ぶ直線）ごとにちょうど1点ずつ載る。

**Step 3（2つの錐の交わり）** `Q ∈ S`、`Q ≠ P`。同様に `S\{Q} ⊂ C_Q`。
`C_P, C_Q` は頂点の異なる二次錐だから相異なり、共通部分は4次曲線（Bezout）。
両者は直線 `PQ` を共通成分に持つ（`Q ∈ C_P` より `PQ` は `C_P` の生成線）ので

```
C_P ∩ C_Q = 直線 PQ ∪ Γ,   deg Γ = 3
```

`A ∈ S\{P,Q}` は `C_P` にも `C_Q` にも載るから `A ∈ PQ ∪ Γ`。`P,A,Q` が共線なら3点従属で
矛盾するので `A ∉ PQ`、したがって **`S\{P,Q} ⊂ Γ`**（`q` 点）。

**Step 4（`Γ` はねじれ三次曲線）** `Γ` が可約なら成分は直線と円錐曲線（または3直線）。
円錐曲線成分は平面上なので4点が同一平面上に来て矛盾、直線成分は3点共線で矛盾。
よって `Γ` は既約。既約3次曲線は平面3次曲線かねじれ三次曲線で、平面なら `q ≥ 4` 点が
同一平面上に来て矛盾。したがって **`Γ` はねじれ三次曲線（twisted cubic）**。
`C_P, C_Q` は `F_q` 有理なので `Γ` も `F_q` 有理。

**Step 5（矛盾）** `S ⊂ Q⁻` で `S\{P,Q} ⊂ Γ`、すなわち `Γ` は `Q⁻` 上に `q ≥ 7` 点を持つ。
もし `Γ ⊄ Q⁻` なら Bezout より `|Γ ∩ Q⁻| ≤ deg Γ · deg Q⁻ = 3·2 = 6 < q`。よって `Γ ⊂ Q⁻`。
ところが **`Q⁻(3,q)` は `F_q` 上有理な奇数次数曲線を持たない**：
`Q⁻` は滑らかな2次曲面で、閉包上 `P¹×P¹` と同型、`Pic = Z²` の2つの生成元
（2つの ruling の直線類）は Frobenius で入れ替わる（`Q⁻` は `F_q` 直線を持たない）。
したがって `F_q` 有理な因子類は `a(f₁+f₂)` の形で次数は `2a`、**偶数**。
`deg Γ = 3` は奇数なので矛盾。□

**Step 6（`k = q+1` の排除）** 同じ論法をもう一段使う。`|S| = q+1` と仮定し `P ∈ S` から
射影すると像は **`q`-アーク**。ここで古典的事実（Segre）：

> `q` 奇数の `PG(2,q)` の `q`-アークは必ず `(q+1)`-アークに含まれ、
> `(q+1)`-アークは円錐曲線である。

（「`(q+1)`-アーク＝円錐曲線」が Segre の定理、「`q`-アークは `(q+1)`-アークに含まれる」も
Segre による古典的結果。例えば *Complete arcs and algebraic curves in PG(2,q)*,
J. Algebra (1987) の要旨に短い証明が与えられている。）

よって像は円錐曲線 `C` に含まれ、Step 2–3 と同様に `S\{P} ⊂ C_P`（二次錐）がすべての `P` で
成り立ち、`P ≠ Q` に対して `S\{P,Q} ⊂ Γ`（`deg Γ = 3`）を得る。`|S\{P,Q}| = q−1` で
`q ≥ 9` なら `q−1 > 6 = deg Γ · deg Q⁻` なので Bezout から `Γ ⊂ Q⁻`。
Step 5 と同じく `Q⁻` は `F_q` 有理な奇数次数曲線を持たないので矛盾。□

## 系（正規有理曲線を使う別証明：`K ≤ q` は q=7 でも成り立つ）

`q` 奇数では **Segre (1955)** により `PG(3,q)` の `(q+1)`-アークはすべて
**正規有理曲線（NRC）** `{(1,t,t²,t³) : t ∈ F_q} ∪ {(0,0,0,1)}` に射影同値。

`K(q) ≤ q` は「`(q+1)`-アークが楕円二次曲面 `Q⁻` 上に載らない」ことと同値なので、
**NRC を通る二次曲面を全部列挙して型を判定**すればよい（`scripts/nrc_quadrics.py`）。
型は `F_q`-点の個数で判定できる：双曲型は `(q+1)²` 点、楕円型は `q²+1` 点。

| q | NRC を通る二次曲面（射影的） | 双曲型 | **楕円型** | 退化 |
|---:|---:|---:|---:|---:|
| 5 | 156（3次元族） | 120 | **20** | 16 |
| 7 | 57 | 49 | **0** | 8 |
| 9 | 91 | 81 | **0** | 10 |
| 11 | 133 | 121 | **0** | 12 |
| 13 | 183 | 169 | **0** | 14 |

- **`q ≥ 7` では楕円型が 0**（族は `q²+q+1` 個 = `q²` 個の双曲型 + `q+1` 個の退化型）。
  よって **NRC は楕円二次曲面上に載らない** ⟹ **`K(q) ≤ q`（奇数 q ≥ 7）**。

**これは実は証明できる（`q ≥ 7`、全数計算は不要）**：NRC を通る二次曲面は
（`q ≥ 7` では係数条件から）3パラメータ族

```
Q = a·(x0x2 − x1²) + b·(x0x3 − x1x2) + c·(x1x3 − x2²)      （up to scale）
```

で尽くされる。対称行列 `M`（非対角は `a_ij/2`）の行列式を計算すると

```
det M = h²·(a²c²h² + 2ab²ch² − ab²c + b⁴h²) = ((a·c − b²)/4)²      （h = 1/2）
```

すなわち **`det M` は常に平方**（または `ac = b²` で 0）。q 奇数では非退化二次曲面
`Q` に対し「双曲型 ⟺ `det M` が平方」なので（標準形 `x0x3−x1x2` は `det = 1/16`（平方）、
楕円型 `x0² − d·x1² + x2x3`（`d` 非平方）は `det = d/4`（非平方）。さらに `q = 7, 9, 11` で
ランダムな非退化二次曲面 218/228/232 個を点の個数と `det` の平方性で二重分類し
**不一致 0** を確認。`scripts/quadric_type_check.py`）、
**NRC を通る二次曲面は退化か双曲型のみ**。□

`q = 5` で楕円型が出るのは、次数 ≤ 6 の条件多項式が 5 点では消えきらず、族が3次元に
広がるため（上表の 156 個）。これが `K(5) = 6 = q+1` の構造的な理由である。
- **`q = 5` だけ楕円型が 20 個ある**。これは `K(5) = 6 = q+1`（全数列挙の厳密値）と完全に整合：
  q=5 では `(q+1)`-アーク＝NRC が楕円二次曲面上に載れてしまう。
- q=7 の `K ≤ q` はこの計算で確定する（本項 §Step 5–6 の Bezout 評価は `q > 7` を要するため
  q=7 をカバーしない）。数値も `K(7) = 6 ≤ 7`。

**一般の q について**：奇数の q は上の `det M` の計算で**任意の q ≥ 7 で証明済み**。
偶数 q の Casse–Glynn 側も証明済み（上の族の解析）＋ `q = 8, 16, 32` の全数計算で確認。
char 2 では「det が平方」の代わりに、族を `H` に同値変形する代入連鎖と
`Tr(τρ/(1+τρ)²) = 0` を使う。

## 系（偶数 q：Casse–Glynn 弧でも同じことが起きる）

`q = 2^m`（`m ≥ 3`）では **Casse–Glynn (1982)** により、`PG(3,q)` の `(q+1)`-アークはすべて
Frobenius ひねり正規有理曲線

```
A_e = {[1 : t : t^σ : t^{σ+1}] : t ∈ F_q} ∪ {[0:0:0:1]},   σ = 2^e, gcd(e,m) = 1
```

に射影同値。奇数 q と同様に、`A_e` を通る二次曲面を全数列挙して型を判定した
（`scripts/casse_glynn_quadrics.py`、型は `F_q`-点の個数で判定：双曲型 `(q+1)²`、
楕円型 `q²+1`、錐 `1+q(q+1)`）：

| q | e | アークを通る二次曲面 | 双曲型 | **楕円型** | 錐 |
|---:|---:|---:|---:|---:|---:|
| 8 | 1 | 73 = q²+q+1 | 64 = q² | **0** | 9 = q+1 |
| 8 | 2 (=m−1) | 73 = q²+q+1 | 64 = q² | **0** | 9 = q+1 |
| 16 | 1 | 273 = q²+q+1 | 256 = q² | **0** | 17 = q+1 |
| 16 | 3 (=m−1) | 273 = q²+q+1 | 256 = q² | **0** | 17 = q+1 |
| 32 | 1 | 1057 = q²+q+1 | 1024 = q² | **0** | 33 = q+1 |
| 32 | 2, 3 | **1（一意な二次曲面）** | **1** | **0** | 0 |
| 32 | 4 (=m−1) | 1057 = q²+q+1 | 1024 = q² | **0** | 33 = q+1 |

**証明（偶数 q ≥ 8、Casse–Glynn + 族の解析）**

`q = 2^m`（`m ≥ 3`）、`σ = 2^e`、`gcd(e,m) = 1` とする。`A_e` を通る二次曲面を
`Q = Σ_{i≤j} a_ij X_i X_j` と書き、`A_e` の点 `(1,t,t^σ,t^{σ+1})` を代入した多項式

```
P(t) = a00 + a01 t + a11 t² + a02 t^σ + (a03+a12) t^{σ+1} + a13 t^{σ+2}
     + a22 t^{2σ} + a23 t^{2σ+1} + a33 t^{2σ+2}
```

が `F_q` 上で消える条件を課す。

**(i) `e ∉ {1, m−1}` のとき**：`deg P ≤ 2^{e+1}+2 ≤ 2^{m−1}+2 < q`（`m ≥ 3`）なので
`P` は恒等的に 0。指数が重ならないので係数がすべて 0 になり、`Q = s(X0X3+X1X2) = sH`
のみ。`H` は双曲型だから、この場合は**唯一の二次曲面が双曲型**。

**(ii) `e ∈ {1, m−1}` のとき**：族は `q²+q+1` 個。`e = m−1`（σ = q/2）では

```
Q = s·H + r0·(X0X1 + X2²) + r1·(X1² + X2X3)
```

（`e = 1` は座標の入れ替え `X1 ↔ X2` で同じ形）。極形式の Pfaffian は
`Pf = s² + r0r1` なので**非退化 ⟺ `s² ≠ r0r1`**。`s ≠ 0` として `s = 1`、`ρ = r0/s`、
`τ = r1/s` と置く（`ρτ ≠ 1`）。線形変換

```
X0 = Y0 + τX2,   X1 = Y1,   X2 = Y2,
X3 = Y3 + τ²Y2 + τY0 + ρX1 + τX0
```

（順に適用）で `Q` は

```
Y0·Y3 + τ·Y1² + (1+ρτ)·Y1Y2 + ρ·Y2²
```

に移る（`Y1,Y2` の2次形式の係数は `a = τ, b = 1+ρτ, c = ρ`）。2次形式
`a u² + b uv + c v²`（`b ≠ 0`）は `Tr(ac/b²) = 0` のとき `u v` に同値であり
（`v²` の係数を消す代入が解ける条件）、ここでは

```
ac/b² = τρ/(1+τρ)² = u + u²,   u = τρ/(1+τρ)   ⟹ Tr = 0
```

が**恒等的に**成り立つ。よってこの2次形式は `Y1Y2` に同値で、
**`Q` は `H` に同値 ⟹ 双曲型**。退化メンバーは `s² = r0r1` の `q+1` 個（錐）のみ。

したがって `e ∈ {1, m−1}` でも楕円型は現れない。□

**検証**：上の代入連鎖を `q = 8` の全57非退化メンバー（`ρ = 0` や `τ = 0` を含む）で
数値確認し、全 `y` について両辺が一致、`Tr` 条件も全メンバーで成立
（`scripts/cg_hyperbolic_proof.py`）。**`q = 16` の全241非退化メンバーでも検証し、不一致 0**。

**楕円型は全ケースで 0** ⟹ **Casse–Glynn 弧は `Q⁻` 上に載らない** ⟹

構造の観察：`e ∈ {1, m−1}` のときは族が `q²+q+1` 個（`q²` 双曲型 + `q+1` 錐）になり、
それ以外の `e` ではアークは**一意な二次曲面**（双曲型）に載る。

**`e = m−1`（σ = q/2）の場合の族の形**：`Q(1,t,t^σ,t^{σ+1})` が `F_q` 上で消える条件は
（`t^q + t` で割り切れることから）3パラメータ族

```
Q = s·(X0X3 + X1X2) + r0·(X0X1 + X2²) + r1·(X1² + X2X3)      （up to scale）
```

で尽くされる（族全体で `q²+q+1` 個）。極形式の
**Pfaffian は `Pf = b01·b23 + b02·b13 + b03·b12 = r0·r1 + s²`** なので
**非退化 ⟺ `s² ≠ r0·r1`**、退化（錐）が `q+1` 個、非退化が `q²` 個。
非退化メンバーは `q=8` で数えると各々 `(q+1)² = 81` 点・**`2(q+1) = 18` 本の直線**を持ち
（双曲型二次曲面の最大本数）、`q=16, 32` でも点の個数が `(q+1)²` であることを確認済み。

**非退化な `q²` 個がすべて双曲型**であることは下の証明で示される
（`q = 8, 16, 32` の全数計算とも一致）。

> **`K(q) ≤ q`（偶数 q ≥ 8）**

（q=8 では数値も `K(8) = 7 ≤ 8`、q=4 は `K(4) = 5 = q+1` の例外で、Casse–Glynn の
分類が `m ≥ 3` を要することと整合。）

## まとめ：`K(q) ≤ q` は q ≥ 7 で成り立つ

| q | 上界 | 根拠 |
|---|---|---|
| 奇数 q ≥ 7 | `K ≤ q` | **証明**（Segre の NRC 定理＋NRC を通る二次曲面の行列式が平方＋双曲型判定）。
別証明：q ≥ 9 は射影＋2つの二次錐の交わり＋`Q⁻` に奇数次数有理曲線がない |
| q = 7 | `K ≤ q` | 計算（NRC を通る二次曲面に楕円型 0。Bezout 評価が `q > 7` を要するため） |
| 偶数 q ≥ 8 | `K ≤ q` | **証明**（Casse–Glynn の分類定理＋族の解析：`e ∈ {1,m−1}` は代入連鎖で `H` に同値、
それ以外は唯一の二次曲面 `H`）。`q = 8,16,32` の全数計算とも一致 |

**例外は小さい位数だけ**：`K(3) = 5 = q+2`、`K(4) = 5 = q+1`、`K(5) = 6 = q+1`（すべて厳密値）。
`q = 2` は盤全体（5点、円は3点）が弧で `K(2) = 5`。

## 系（ambient な `PG(3,q)` の理論から：偶数 q の上界）

`Q⁻(3,q)` 上の弧は `PG(3,q)` の「n-アーク」（どの4点も同一平面上にない集合）でもあるので、
ambient の上限 `m(3,q)` がそのまま効く。古典的事実

> `m(3,q) = q+1`（`q` 奇数 `> 3` は Segre 1955、`q = 2^h ≥ 8` は Casse–Glynn 1982）

から

> **`K(q) ≤ q+1`（すべての `q ≥ 4`、無条件）**

とくに **偶数 q ではこれが ambient からの上界**（以前の射影上界 `q+3` を改善）。
偶数 q ≥ 8 では下の Casse–Glynn の系によりさらに `K ≤ q` まで下がる。
`q=4` では `K(4) = 5 = q+1` で **tight**（全数列挙の厳密値）。
なお本項の射影+Bezout の議論（`K ≤ q+2` → `q+1` → `q`）は奇数 q で
`q+1` を再導出し、さらに `q` まで下げるのが貢献である。

## 系

`q` 奇数、`q ≥ 9` で

> **`(q+5)/2 ≤ K(q) ≤ q`**

（下界は Sonnino 1999 の `(q+5)/2`-弧構成、K1251）。
すなわち `K(q) = Θ(q)` で、`0.5q ≤ K(q) ≤ q`。
以前の「`K ≤ q+3`」「`K ≤ q+2`」「`K ≤ q+1`」はすべて **`q`（奇数 q ≥ 9、無条件）** に置き換わる。

**上界の sharp 性と適用範囲**：`K(5) = 6 = q+1` なので `K ≤ q` は **q=5 では成立しない**
（`6 > 5`）。定理の適用範囲が `q ≥ 9` であることと整合する。
厳密値 `K(7)=6, K(8)=7, K(9)=9` は `K ≤ q` を満たす（**q=9 で上界は tight**：`K(9)=q`）。
q ≥ 11 では数値が `≈0.65q` なので上界はまだ緩い。

**`q = 3` は真の例外**：`K(3) = 5 = q+2`（全数列挙で厳密）。Step 5–6 の Bezout 評価が
`q > 7` を必要とするため、定理の適用範囲（`q ≥ 9`）から外れる。
`q = 5` も範囲外で、`K(5) = 6 = q+1` は上界 `q` を超える（上界の最良性の証拠）。

## 数値との整合

検証済みの弧はすべて `K ≤ q` を満たす：
`q=13:10, 17:13, 19:14, 23:16, 29:20, 31:21, 37:25, 41:27, 43:28, 47:30, 49:32`
（いずれも `q` 以下）。厳密値 `q=7:6, 8:7, 9:9` も `K ≤ q` を満たす（q=9 は等号）。
また Step 2 の「射影が oval になる」は K1250 で**全証人について総当り検証済み**
（任意の1点からの射影が `PG(2,q)` のアークになる）。

## 限界

- **先行研究**：文献調査（2026-11-23、K1251 の文献節）によれば、反転平面の弧の上界
  （`k ≤ q` など）を述べた論文は**見つからない**。ambient な `PG(3,q)` では
  `m(3,q) = q+1`（Segre 1955 / Hirschfeld–Storme）から `K ≤ q+1` が出るのみ。
  したがって **`K ≤ q`（q 奇数, q≥9）は文献にない結果**と考えられる。
- 古典的事実（Segre の oval=conic と q-arc ⊂ conic、Bezout、楕円二次曲面の Picard 群と
  Frobenius の作用）を引用して使っている。標準的だが本項では独立証明していない。
- **`K ≤ q−1` へは同じ論法で進めない**：射影が `(q−1)`-アークになり、
  「`(q−1)`-アークは円錐曲線に含まれる」が必要だが、これは一般には偽
  （`(q+3)/2` 程度の非円錐 complete arc が存在する）。**q=9 で具体的に確認**：
  極大9-アークを1点から射影すると `PG(2,9)` の 8-アークになり（3点共線なし）、
  5点を通る円錐曲線は一意だが残り3点はその上にない（`scripts/projection_no_conic.py`）。
- **偶数 `q` には拡張できていない**：Step 1 の上界が `q+3` になり、Step 2 の
  「oval = conic」も偶数では成り立たない（非円錐 oval が存在）。偶数側の最良は
  K1250 の MDS 経由 `K ≤ q+1`（MDS予想下）である。
- 上界 `q` は数値（`≈0.65q`）からはまだ緩い。定数 `liminf K/q`（`0.5` と `1` の間）が
  中心的な未解決問題。
