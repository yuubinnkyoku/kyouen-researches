## 命題・範囲

全x>=4・全R>=0について、H(R;(x,4);11)のGrundy値0/1/2を次で完全分類する。
O[a,b]は区間内の奇数、I[a,∞)はa以上の全整数とする。

値2位置T(x):

| x | T(x) |
|---:|---|
| 4 | {1,3,5,7} |
| 5,6 | {1,3,5,7,9} |
| 7 | {1,3,5,7,9,11,13,15} |
| 8,9,10 | {1,3,5,7,9,11} |
| 11 | {1,3,5,7,9,11,17} |
| 12,13,14 | {1,3,5,7,9,11} |
| 15 | {1,3,5,7,9,11,19} |
| 16 | {1,3,5,7,9,11} ∪ O[19,31] |
| x>=17 | {1,3,5,7,9,11,19} |

値1位置P(x):

| x | P(x) |
|---:|---|
| 4 | ∅ |
| 5 | I[10,∞) |
| 6 | ∅ |
| 7 | {12,14} ∪ I[16,∞) |
| 8 | {12,14} |
| 9 | {12,14} ∪ I[16,∞) |
| 10 | {12,14,16} |
| 11 | {12,14,16} ∪ I[18,∞) |
| 12 | {12,14,16} |
| 13 | {12,14,16} ∪ I[18,∞) |
| 14 | {12,14,16,18} |
| 15 | {12,14,16,18} ∪ I[20,∞) |
| 16 | {12,14,16,18} |
| x>=18 even | {12,14,16,18} ∪ O[21,x+15] |
| x>=17 odd | {12,14,16,18} ∪ O[21,x+14] ∪ I[x+16,∞) |

従って
\[
H(R;(x,4);11)=
\begin{cases}
2,&R\in T(x),\\
1,&R\in P(x),\\
0,&\text{otherwise}.
\end{cases}
\]

tailは
\[
R\ge x+16\implies H(R;(x,4);11)=(x+4)\bmod2.
\]
またK0832の高さのみ縮約から
\[
R\le12\implies H(R;(x,4);11)=v_{\rm single}(x+4,11,R).
\]

## 証明

R=0ではH=0。R>=1の子は
\[
\begin{aligned}
A&=H(R-1;(x-1,4);11) &&(x\ge5),\\
B&=H(R-1;(x,3);11),\\
C&=1\oplus H(R-1;(x,4);10).
\end{aligned}
\]
Aはx外帰納、BはK1014、CはK1006で評価する。x=4では二つのトークン減少手が同じ(3,4);11子に合流するため、A/BをK1014のx=4行で同時に処理する。

x=7は高さx+y=zの行で13,15が現れる。x=11（x=z）では17が孤立点として現れ、x=15（x=z+y）でpin=19が現れる。x=16（x=z+y+1）は掃引行で、値2位置がO[19,31]へ広がる。x>=17ではpin=19に定着する。値1の基底点は{12,14,16,18}={z+1,z+3,z+5,z+7}のy個、帯開始は21=z+2y+2。掃引帯O[19,31]はO[pin,x+y+z]に一致する。x=17は署名E[22,32]が12となる一段の移行行だが、親のT/P式は奇数定常行と同じである。

全称性はx=4の基底、既証明B/C子、x>=5の外帰納、および上記全R署名帯表から従う。低R縮約と高R tailはK0832から独立に得られる。
