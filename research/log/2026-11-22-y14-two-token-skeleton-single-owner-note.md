## 事前の横断予想（y=6..13 の出版表からの外挿であり y=14 の証明ではない）

- tail 開始: R >= x+z+15 = x+z+y+1・値 (x+14) mod 2。y=14 は偶数 y で
  値1無限帯・tail 値1 は x 奇行（y=10/y=12 型・13 族連続の「y 偶奇が行型を
  決める」観察の 14 族目候補）。
- 基底点: {z+1, z+3, ..., z+27} の 14 点（基底点 y 点仮説 {z+1,..,z+2y-1} の
  y=14 版・14 例目候補）。
- マージ行: x <= z-15（S = x+14 <= z-1）。マージ命題一般形 x<=z-(y+1) の
  y=14 版（全称昇格済み y=1..13 の次）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+42)/2・pin offset o_pin∈[y+1,2y]=[15,28]
  かつ o_pin≡z+1 (mod 2) の統一式（y=5..13 の 9 族全称確定格子の y=14 外挿）から、
  奇zは d≡y≡2 (mod 4) {-10,-6,-2,2,6,10,14} の **7 行**・
  偶zは d≡y+2≡0 (mod 4) {-12,-8,-4,0,4,8,12} の **7 行**。
  偶y 族式の pin 行数 y/2 が両偶奇で初めて 7 行になる（y=12 は 6/6・y=10 は 5/5）。
  pin 行の mod 4 クラスは y≡2 (mod 4) で y=10 と同じクラス（{(d+3y) mod 4} は
  y とともに回転し、y=12 の d≡0 から d≡2 へ入れ替わる）。y=10 の場合と異なり
  y=12 出版正本の th 構造則が使えるため、初稿の予測精度は y=12 fit より
  高いことが期待される（判定材料）。
- 奇z I 帯行（d 偶 15 行・対角 d=-14 込み）: k(d) = floor((d+3y+2)/4)
  = floor((d+44)/4)・th(d) = 2k(d) + [d ≡ y (mod 4)]。y=14 では pin 行が
  d≡2 (mod 4) に移るため th=2k+1 が pin 行、skew（b 端点一致）行は d≡0 (mod 4)
  で th=2k。th は d=-14..14 の掃引で **連続整数 15..29**（y=12 の連続整数掃引型の
  2 族目）。「pin スロット = th-1」型（pin 行で pin が off=2k=th-1 をちょうど
  占有）は y=11/12/13 に続き **4 族連続候補**。偶y では pin 行の mod 4 クラスが
  y とともに回転しても th-1 スロット則が保たれるかが本 fit の主要な横断判定材料。
- base 行 k(d)=floor((d+3y+1)/4)=floor((d+43)/4)（y=10..13 の 4 族同一族式の
  5 族目候補・偶z base 行も同一式）・偶z I 帯行 k(d)=floor((d+3y-1)/4)
  =floor((d+41)/4)（y=11/12/13 の 3 族同一族式の 4 族目候補）・th=2k+1。
- 偶z の pin は base 行（偶 d）上の 2k+1 位置（y=11/12/13 の 3 族と同一 slot 則の
  4 族目候標・base 上端 2k-1 の +2 位置）。
- 対角行 d=-14: 値2上端 cap = z+y-[z≡y (mod 2)]（z odd: 偶offset [2,z+14]・
  z even: 奇offset [1,z+13]。偶y 族式・y=10/y=12 と同じ向き）。偶z 対角行の
  値1全欠如（y=8..13 で 6 族連続・全称確定）の y=14 での判定（7 族連続候補・
  fit level）。奇z 対角行は I 帯行として k=7・th=15（cap 引き込み）。
- 掃引行 d=15 / 定常行 d>=16: steady pin {z+28}（奇z）/{z+29}（偶z）・
  band 下端 offset 2y+2 = 30・掃引帯は偶offset [2y+z, x+z+14]（奇z）/
  奇offset [2y+z+1, x+z+14]（偶z）。最終 pin 行 d=14=y（奇z）は
  I[2y+z+1)=I[z+29) 型（y=6..13 連続の次）で pin z+28 は直後の定常 pin
  z+28 と同値（y=12/y=13 と同構造）。
- clip 窓 2y+2=30（10 族連続 tight 候補）と pin 格子統一式 pin=z+(d+3y)/2
  （10 族目）は全称段階の C4t/P で判定する。本 fit では有限範囲で
  band 下端 30・pin 行の格子配置のみ観測する。
- 奇z base 行（d 奇 14 行）・偶z base 行（d 偶 14 行）の k(d) はP = b_k 仅有り
  （b_k = 奇 offset {1,..,2k-1}）。飽和なし（k は高々 Y=14）。
