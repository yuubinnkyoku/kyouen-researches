## 1. 対象素数の選定

### 1.1 実測データ(クラス (1,1,3)、size = h−1、候補B CNF)

| 項目 | p=2207 | p=2531 | p=2647(参考、W21b) |
|---|---:|---:|---:|
| h = (p−1)/2 | 1,103 | 1,265 | 1,323 |
| 全 d(1..h)判定既知 | UNSAT 1,103/1,103(K0693) | UNSAT 1,265/1,265(K0702) | UNSAT 1,323/1,323(K0706) |
| h−1 での CNF vars | 14,320(実測) | 16,426(実測) | 14,544 は (0,1,2) の値(W21b §4.4) |
| h−1 での CNF clauses | 62,713(実測) | 73,541(実測) | 85,615 は (0,1,2) の値 |
| kept edges | 31,868(実測) | 38,160(実測) | 53,882 は (0,1,2) の値 |
| 100k 掃引での k 構造データ | なし(size h の一括 scan のみ) | なし | あり(W21b、1,323 件・SAT 0) |

p=2531 の CNF 数値は本作業で `t5_size_2531.py` を実行して取得した
(gen 84.6 s、build 1.70 s、edges=837,640)。p=2207 の CNF 数値は既存
`output/t5-assump-2207-1102-d735.json` の記録(vars 14,320、clauses 62,713、
kept 31,868、edges 639,621)。

### 1.2 決定: **第一対象 = p=2207**

理由:

1. **計算量**: p=2531 はクラス CNF が約 1.17 倍(clauses 62,713 → 73,541)。
   100k conflicts 到達時間もほぼ比例して増えると見込まれ、ラダー・W31 と
   CPU を共有する現状では不利 [INFERENCE]。
2. **判別力**: T5 の判定基準は「k = h−d の小さい側(tail)に易い UNSAT が現れるか」
   なので、比較は **h に依らず k の絶対値で直接できる**。p=2647 の窓の境界
   (k=6/7 と 44/45)を p=2207 の同一 k 点(k=0,6,7,20,44)で点検できる。
3. **既存データ**: p=2207 は全 d UNSAT が既知(K0693)なので size h では
   SAT は出ないはず。一方 size h−1 での充足可能性は未調査で、SAT が出れば
   A(2207) の下界情報として独立の価値がある。
4. **監査インフラ**: p=2207 は CNF 生成・照合ツール群が最も整備済み
   (`parabola-p2207-no-equality-witness-20261107/`)。

p=2531 は第一対象の結果を受けた第 2 段(確認用)に回す(§4)。

## 2. 部分スイープ設計(候補B方式)

### 2.1 方法

`search_shape_class_assump.py` 方式(クラス CNF 1 本 + assumption `B_d`)を
p=2207 に適用する。ただし本パイロットは **fresh-each**(点ごとに新規
Cadical195)で測定する。理由: 単一インスタンス掃引は学習済み節が次点に
持ち越され、難度序列が履歴に汚染されうる(K0722 と同根)。素数間比較には
履歴フリーの測定が要る。実測でも同一 d(d=735)が単一インスタンス方式で
UNKNOWN 50.3 s(`output/t5-assump-2207-1102-d735.json`)、fresh-each で
**SAT 20.8 s**(§3.1)と判定そのものが分かれたため、この選択は必須だった。

スクリプト: `t5_pilot_p2207.py`(Cadical195、100k conflicts/点、wall cap 300 s、
SAT 時は witness を全禁止四点と照合し `safe_against_edges` を記録)。

### 2.2 層別サンプリング

p=2647 の W21b 構造との対応(k = h−d):

| 層 | k(p=2647 での役割) | p=2207 での点(d = 1103−k) |
|---|---|---|
| 内側 tail(最遅層) | k=0..6 | k=0, 6 → d=1103, 1097 |
| 窓(連続 easy-UNSAT 層) | k=7..44 | k=7, 20, 44 → d=1096, 1083, 1059 |
| 中央(void 候補領域の代表) | k=276..827 相当 | d=276, 368, 551, 735, 827 |
| 下端 | (p=2647 で d=1..200 は UNSAT 3/100 と稀薄) | パイロットでは省略 |

### 2.3 計算量の見積もり

- 既知実測: p=2207 クラス (1,1,3) size1102 の UNKNOWN 点は 100k 到達まで
  34–53 s台(d=735 50.3 s、d=1103 53.5 s、v2 pilot d=1103/1097 53.3/47.4 s)。
- パイロット: 10 点 × ≤55 s ≒ **10 分強**(fresh-each 単プロセス + CNF 構築
  gen 約 1–2 分)。実際の総消費は §3.1 の合計(9 点 UNKNOWN/UNSAT が
  34–44 s 台、d=735 が 20.8 s)で約 6.5 分 [実測の合算]。
- tail 全域(k=7..44 全 38 点)の追試: 38 点 × ≤50 s ≒ **30 分弱**。
- full sweep(1,103 点): 単プロセスで 13–16 時間の帯 [INFERENCE]。

### 2.4 判定基準(一般化する/しないの区別)

- **G1(tail easy-UNSAT 窓の一般化)**: k=7..44 の標本点が UNSAT かつ易い
  (目安 1 s 未満。p=2647 窓内中央値 ≈ 0.06 s 相当)に終わる。
- **G2(内側最遅層の一般化)**: k=0..6 が 100k 消費で UNKNOWN かつ
  tail 内で最遅群を形成する。
- **G3(中央 void)**: 中央点が全て UNKNOWN で 40–50 s 帯(p=2647 の中央の
  UNKNOWN 中央値 40–50 s 相当)に留まる(易い UNSAT が中央に出ない)。
- **反証の扱い**: size h の主張(K0693)と衝突する SAT はこの掃引の size(h−1)
   では出得ない。size h−1 で SAT が出た場合は witness を全禁止四点集合と
  照合(スクリプトが実施)し、合致すれば「A(p) ≥ h−1 の構成的下界」
  として別途記録する。窓判定とは独立に扱う。
- **非対称性**: G1 が揃わなくても tail に易い UNSAT の集積があれば部分的肯定。
  一切出ない場合も「100k 予算不足」という代替説明が残るので、一般化否定とは
  区別して [INFERENCE] と明記する。

### 3.2 d=735 の SAT witness

- `witness_size` = 1,102、`safe_against_edges` = true(全 639,621 禁止四点
  集合と照合、被覆 0)。点 0 を含み、完全対は {735, 1472} の 1 個のみ
  (本作業での追加点検: pair 1..1103 のうち両要素が witness 内にあるのは
  735 のみ)、残り 1,099 pair は片側選択。クラス (1,1,3)(x=1, c=1, e=3)
  の制約どおり。
- これは **A(2207) ≥ 1,102 の構成的下界**。K0693 の A(2207) ≤ 1,104
  (size 1,103 の全 d UNSAT)とは矛盾しない。
- 対比: p=2647 の size 1322 (= h−1) 掃引では 1,323 点すべて UNSAT か
  UNKNOWN で **SAT 0 件**(K0768)。size h−1 で SAT が返る素数と
  返らない素数がある。[INFERENCE] p=2647 の A は 1,292(既知下界 K0711)
  と 1,322 の間にあり、size h−1 = 1,322 は上界ぎりぎりの未充足なのに対し、
  p=2207 の h−1 = 1,102 は充足 – ただし 1,102 と p=2647 の 1,292(下界)の
  間のギャップ(= 素数サイズ比 h 比で 0.83/0.98)から、p=2207 で
  h−1 が易しく出たのは「最適値からの距離」の差で説明できます
  [INFERENCE]。
- **fresh-each vs 単一インスタンスの判定差(実測)**: 同一問題 d=735 が
  単一インスタンス assumption 方式では UNKNOWN(50.303 s、
  `t5-assump-2207-1102-d735.json`)、fresh-each では SAT(20.786 s)。
  履歴・phase-saving の差かシード差かの切り分けは未実施 [INFERENCE]。
  候補B掃引の難度比較には fresh-each を使うべきという教訓。

### 3.3 判定(§2.4 基準の適用)

- **G2(内側最遅層)**: k=0,6 は 41.2/37.3 s で 100k 消費し UNKNOWN。
  標本内では tail 側の他のどの点より遅い。✓ 再現(p=2647 では
  内側 7 点が全体最遅 165–207 s 相当の位置)。
- **G1(tail easy-UNSAT 窓)**: k=7(37.1 s UNKNOWN)、k=44(34.6 s UNKNOWN)、
  k=20(**UNSAT 0.098 s / 855 conflicts**)。p=2647 の k=7..44 連続 38 点
  easy-UNSAT ランは、この 5 点標本では **再現しない**。k=20 の 1 点のみが
  易い UNSAT で、連続構造の証拠には不十分。
- **G3(中央 void)**: 中央 5 点中 4 点は UNKNOWN 34.4–44.4 s(d=735 の SAT
  を除く)。「易い UNSAT が中央に出ない」という意味では再現。ただし
  d=735 の easy SAT が void に一期の割り込みを入れた。
- **総合**: 第一対象 p=2207 の 10 点標本では、
  - 一般化する側: 内側最遅層(G2)、中央 void(G3)
  - 一般化しない側: tail 連続 easy-UNSAT 窓(G1)
  の混合。W21b の「tail に易い UNSAT 構造が少なくとも 2 種類重なっている」
  [INFERENCE] のうち「広い窓」は p=2647 固有の可能性が強まった
  [INFERENCE]。ただし tail 5 点の標本では窓の非存在は確定できず、
  k=7..44 全 38 点の掃引(§2.3、約 30 分)が次手。
