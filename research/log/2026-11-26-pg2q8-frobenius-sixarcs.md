# 2026-11-26 第25ラウンド: Frobenius が極大 6-キャップ 3 類を巡回置換

## 出発点

3 類が secant/tangent/external 統計・固定群作用・nucleus 配置で区別できなかった。
その理由を探るため、Frobenius 自己同型 φ(x,y,z)=(x²,y²,z²) の作用を調べた。

## 結果

- φ(A) は C の PGL 軌道に、φ²(A) は B の PGL 軌道に属する（probe 付き軌道 BFS）。
- φ³=id より φ(C)∈B, φ(B)∈A。すなわち **A→C→B→A の巡回置換**。
- **PΓL(3,8) は極大 6-キャップ全体に推移的**（単一軌道、固定群 24）。

## 意義

- 3 類が局所不変量で一致したのは半線型同値だから、と説明がついた。
- PGL では 3 類、PΓL では 1 類というきれいな構造。

## 検証（独立、5/5 PASS、不一致なし）

- 盤の順序・φ の全単射性・φ³=id・A/B/C/φ(A)/φ²(A) が極大 6-キャップであることを確認。
- 独自生成元 8 個で |PGL(3,8)| = 16,482,816（orbit-stabiliser 73·72·7·64·7）を確認。
- 軌道 BFS: A, B, C の軌道は各 686,784 で互いに素。φ(A) が C の、φ²(A) が B の軌道に属する
  ことを membership matrix と明示的な witness word で確認。
- **φ は orbit A の全 686,784 個を C へ、C を B へ、B を A へ写す（例外 0）**。
- φ は PGL を正規化し φ∉PGL、|<PGL,φ>| = 49,448,448 → PΓL = PGL⋊C3。
- 独立 C 国勢調査: 全極大 6-キャップ 2,060,352 が 3 軌道の和（外 0）→ PΓL 推移的。
- 算術: 3·16,482,816 = 49,448,448 = 2,060,352·24。
