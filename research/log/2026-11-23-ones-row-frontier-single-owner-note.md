## 主張（本宣言が保持する範囲・publish-then-execute）

**M-RC（全称・証明は本ノートで全文開示）**: 残余ゲーム H(R;X;z)（K0832/K1138系再帰）
の {1}^t（t 個の 1 の多重集合）に対して、j>=0・k>=0・z>=max(1, 2j−1)（R=z+2−2j>=1）
で状態

  A_j(k, z) := H(z+2−2j; {1}^k; z)

の値は次で完全に決まる:

- k 奇数（k>=1）:
  A_j(k,z) = 2  ⟨z 奇数 かつ z <= k+2j−2⟩
           = 1  ⟨z >= k+2j−1⟩
           = 0  ⟨その他⟩
- k 偶数（k>=0、k=0 を含む）:
  A_j(k,z) = 2  ⟨z 奇数 かつ z <= k+2j−3⟩
           = 0  ⟨その他⟩

**M-DIAG（M-RC の j=0 系）**: t>=1・z>=1 に対して H(z+2;{1}^t;z) は:
- t=1: 1（全 z）
- t=2: 0（全 z）
- t 偶数 >=4: 2 ⟨z 奇数, z<=t−3⟩ / 0 ⟨その他⟩
- t 奇数 >=3: 2 ⟨z 奇数, z<=t−2⟩ / 1 ⟨z>=t−1⟩ / 0 ⟨その他⟩

**M-SEP（M-DIAG + K0832 単一閉形式の帰結・分離法則）**: 統合窓
W(z,1)=max(z+1,2)（z>=1 では z+1）の窓端 R*=W+1（z>=1 は R*=z+2、z=0 は R*=3）で
{1}^t 行が窓端分離する（H(R*;{1}^t;z) != v(t,z,R*)）のはちょうど:

- t=1: なし（全 z で崩壊）
- t=2: なし（K1265 {1,1} 全R崩壊行と整合）
- t 偶数 >=4: S(t) = {0} ∪ {z 奇数: 1 <= z <= t−3}
- t 奇数 >=3: S(t) = {0} ∪ {z 奇数: 1 <= z <= t−2} ∪ {t−1, t}

S(t) 内の分離値: z=0 は親0 vs 単一1（T1・K1267）、z 奇数は親2 vs 単一0（T2・の
全 z への拡張）、奇数 t の {t−1,t} は親1 vs 単一0 と 親1 vs 単一2。

これは K1268 未解決課題（E5 疎パターン z>=2 の一般則）の全称解決である:
観測「t=3: {0..3}・t=5: {0,1,3,4,5}・t=7: {0,1,3,5,6,7}・偶数tは奇数階段」が
閉形式で完全に決まる。T1（z=0）と T2（z=1）は S(t) の第1・第2要素として従う。

## M-RC の証明（宣言時点での全文開示・mex 連鎖の強帰納）

記法: {1}^k の状態 (R,z) で可能な手は B手（1 を除去し z→z+1・予算 R−1）と
C手（z>=1 で 1 XOR H(R−1;{1}^k;z−1)）のみ（A手は a>1 のみ・1 には不適用）。
d := R−z とおくと B手は d→d−2、C手は d 不変。窓端 j=0（d=2）から到達可能な d は
偶数 2,0,−2,… のみ（d 奇数の状態は現れない）。空残余の値は 0（補題E: 帰納、
z=0 で mex(∅)=0・z>=1 で mex{1 XOR 0}=0）。z=0 では H(r;{1}^k;0)=min(r,k) mod 2
（C手不在・B手のみの Nim 値 = 単一トークン閉形式の z=0 節と一致）。

**命題の再掲**: R=z+2−2j>=1 の状態族 A_j(k,z)。j=0 では R=z+2>=3。子の d は
B手で −2（j+1 へ）、C手で d 不変（同 j の z−1 へ）:
  A_j(k,z) = mex( {A_{j+1}(k−1, z+1)} ∪ {1 XOR A_j(k, z−1)} )   (k>=1, z>=2)
特殊境界: (i) z = 2j−1（R=1）: 基底。(ii) z = 1 で j=0（R=3・T2 の状態）:
C子は z=0 の値 min(2,k) mod 2（k=1 のみ 1・他 0）。(iii) z = 2j−1 > 1（j>=1:
実はこれは R=1 基底そのもの）。z=1 は j∈{0,1} にしか現れず（R=3−2j>=1）、
j=1 は R=1 基底。よって境界は R∈{0,1} 基底と z=1/j=0 の C子だけ。

**強帰納法**: 予算 R についての強帰納（子はすべて R−1）。基底:
- R=0: 値 0。CFG でも z=2j−2（偶数）で k 奇数の 1 帯条件 2j−2 >= k+2j−1 は
  k<=−1 のみで不成立、k 偶数は 0。整合。
- R=1（z=2j−1, j>=1）: H(1;{1}^k;z>=1) = 2（k>=1・B子 0・C子 1・mex{0,1}=2）・
  H(1;∅;z)=0（補題E）。CFG: k 奇数 ⟹ z 奇数（2j−1）かつ z <= k+2j−2 ⟺ k>=1 で 2 ✓。
  k 偶数 >=2 ⟹ z <= k+2j−3 ⟺ k>=2 で 2 ✓。k=0 ⟹ 2j−1 <= 2j−3 不成立で 0 ✓。

**帰納段階 R>=2**: 子の値を CFG（帰納法の仮定）で評価する。B子
b := A_{j+1}(k−1, z+1):
- k 奇数（k−1 偶数: k=1 のときは k−1=0 で CFG は 2 帯が効かないため 0 永久整合）:
  b = 2 ⟺ z 偶数 かつ z+1 <= k+2j−2（z <= k+2j−3）、それ以外 0。
- k 偶数（k>=2・k−1 奇数）:
  b = 2 ⟺ z 偶数 かつ z <= k+2j−2、b = 1 ⟺ z >= k+2j−1、それ以外 0（z 奇数で
  z+1 <= k+2j−2 のとき 0）。
C子（予算 R−1>=1 のとき z>=2j）: c := A_j(k, z−1)、C選択肢値 = 1 XOR c。j>=1 で
z=2j ないし z>2j は通常評価。z=2j−1 は R=1 基底。z=1/j=0 は上記 (ii)。

場合分け（k 偶奇 × z 偶奇・領域）を機械的に列挙すると次の体系で全場合が閉じる
（閾値の偶奇に注意: k 偶なら k+2j−3 は奇数、k 奇なら k+2j−2 は奇数・k+2j−1 は
偶数。よって「z 偶数 = 閾値」型の空の場合は消える）:

**(1) k 奇数・z 偶数**: b ∈ {2 (z<=k+2j−3), 0}。c（z−1 奇数）は CFG(k 奇) より
c=2（z−1<=k+2j−2 ⟺ z<=k+2j−1）または c=1（z−1>=k+2j−1 ⟺ z>=k+2j）、0 には
ならない。目標: z 偶数 ⟹ 2 帯不成立 ⟹ 1 (z>=k+2j−1) / 0 (その他)。
- z <= k+2j−3: {b=2, 1 XOR c=1 XOR 2=3} = {2,3} → mex = 0 ✓（目標 0・
  なお z<=k+2j−1 を満たし 1 帯ではない）。
- z >= k+2j（中間 z=k+2j−1 は偶数=奇数で空）: {b=0, 1 XOR 1=0} = {0} → mex=1 ✓
  （目標 1）。
（k=1 でも同じ式が成立: b は 2 帯が常に不成立で 0、c は CFG(1) と同一式。）

**(2) k 奇数・z 奇数**: b=0（z 偶数条件に外れる）。c（z−1 偶数）は
c=0（z<=k+2j−1）/ c=1（z>=k+2j）。境界 z=2j−1 は R=1 基底（値 2・下記と整合）。
z=1/j=0/k>=3: c = min(2,k)%2 = 0 → {0, 1} → mex=2（目標: z=1<=k−2 ⟺ k>=3 で 2 ✓）。
z=1/j=0/k=1: c=1 → {0} → mex=1（目標: z>=k+2j−1=0 の 1 帯で 1 ✓）。
- z <= k+2j−2（目標 2・z 奇数）: c=0 → {0, 1} → mex=2 ✓
  （z=2j−1 のときは C子予算 0 で値 0 → 同一の {0,1} ✓・ただしそれは R=1 を
  与える帯で基底として確認済み）。
- z >= k+2j（目標 1・中間 z=k+2j−1 は偶数で z 奇数の領域は分割されない）:
  c=1 → {0, 1 XOR 1=0} = {0} → mex=1 ✓

**(3) k 偶数・z 奇数**: b = 1 ⟺ z >= k+2j−1、それ以外 0（z+1 偶数で 2 帯は不成立）。
c（z−1 偶数）= 0（k 偶の CFG は 2 帯が z−1 奇数を要求）→C選択肢 1。
z=1/j=0 の c = min(2,k)%2 = 0（k 偶 >=2）→ 同一。
境界 z=2j−1（R=1・k>=2）: {0, 1} → mex=2 = 基底値と CFG の 2 帯（2j−1<=k+2j−3 ⟺ k>=2）✓。
- z <= k+2j−3（目標 2）: b=0 → {0,1} → mex=2 ✓（z=2j−1 を含む・k>=2 ✓）
- z >= k+2j−1（目標 0）: b=1 → {1,1} = {1} → mex=0 ✓
- 中間 z=k+2j−2 は偶数で空。

**(4) k 偶数・z 偶数**: b = 2 ⟺ z <= k+2j−2、b = 1 ⟺ z >= k+2j（z 偶数側）、
（z>=k+2j−1 の奇数は (3) 側）。c（z−1 奇数）= 2 ⟺ z−1 <= k+2j−3 ⟺ z <= k+2j−2
→ C選択肢 3、それ以外 c=0 → 1。
- z <= k+2j−2: {b=2, 3} = {2,3} → mex=0 ✓（目標 0）
- z >= k+2j: {b=1, 1} = {1} → mex=0 ✓（目標 0）
- 境界 z=k+2j−1 は奇数で、(3) の場合に含まれる。
以上、全場合で mex が CFG 目標値と一致する。``（mex は集合 {0,1,2}\O の最小と

**M-DIAG**: j=0 の CFG そのもの。**M-SEP**: 単一側は K0832 出版閉形式:
