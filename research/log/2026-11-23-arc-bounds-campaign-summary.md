# 2026-11-23 反転平面の弧の上界：q+3 から q までの道のり（総括）

この一連のラウンドで、反転平面 `M(q)` の弧（どの4点も同一円上にない点集合）の最大サイズ
`K(q)` の**無条件上界**が `q+3` から `q`（`q ≥ 7`）まで下がった。その経過と判断の記録。

## 上界の階段

| 上界 | 範囲 | 方法 | 項 |
|---|---|---|---|
| `q+3` | 全 q | `λ₂` 上界（3-設計の一般論） | K1058 |
| `q+2` | q 奇数 | 1点からの射影で `PG(2,q)` のアーク（`A₂(q) = q+1`） | K1250 |
| `q+1` | q 奇数 q≥7 | 射影＋Segre の oval 定理＋**2つの二次錐の交わり**（ねじれ三次曲線）＋`Q⁻` に F_q 有理な奇数次数曲線がない | K1252 Step 5 |
| **`q`** | **q 奇数 q≥7** | **NRC を通る二次曲面の行列式が常に平方**（Segre の q-アーク定理と合わせる） | K1252 |
| `q+1` | 全 q≥4 | ambient `m(3,q) = q+1`（Segre 1955 / Casse–Glynn 1982） | K1252 |
| **`q`** | **偶数 q≥8** | Casse–Glynn 弧を通る二次曲面を全数分類（楕円型 0） | K1252 |

## 決め手になった3つの転換

1. **二次曲面辞書（K1250）**：`z ↦ (1:z:z^q:z^{q+1})` で `M(q)` を楕円二次曲面 `Q⁻(3,q)` に写すと
   「円＝切断平面」「共円＝同一平面上」。これで弧の問題が「`Q⁻` 上の一般位置集合」＝
   MDS 符号の問題になり、PG(3,q) の古典理論（arcs, ovals, NRC, Casse–Glynn）が全部使える。
2. **2つの二次錐の交わり**：射影が円錐曲線になる（q 奇数）ことを使い、2点からの射影の錐の交わりを
   Bezout で追うと残りがねじれ三次曲線になり、`Q⁻` が奇数次数の有理曲線を持たないことに矛盾。
3. **行列式が平方**：NRC を通る二次曲面の族 `a(x0x2−x1²)+b(x0x3−x1x2)+c(x1x3−x2²)` は
   `det M = ((ac−b²)/4)²` で、q 奇数では「双曲型 ⟺ det が平方」なので楕円型が現れない。
   これで q=7 も証明でカバーされ、`q ≥ 9` の制限が消えた。

## 数値・計算の役割

- **アーク・センサス**（アークのみを DFS で列挙、増分ブロッキング）で層サイズと `K` の厳密性を同時に取得。
  q=11 は 23億ノード・約1.2時間で `K(11) = 9` が厳密に決まり、`#8-arcs = 121,343,640` が
  6時間の部分集合全数列挙と一致した（二経路の検証）。
- **偶数 q** は Casse–Glynn の分類定理（`q=2^m`, `m≥3` で `(q+1)`-アークは Frobenius ひねり NRC に同値）
  を使い、`q=8,16,32` の全 `e` で楕円型 0 を確認。`e ∉ {1, m−1}` ではアークが一意な二次曲面に載る
  ので、残る証明のギャップは `e ∈ {1, m−1}` の族（陽に書ける: `s(X0X3+X1X2)+r0(X0X1+X2²)+r1(X1²+X2X3)`）
  に絞られた。

## 文献

- 下界の記録は Sonnino 1999 の `(q+5)/2`。後年の Hadnagy–Sonnino は `≈p/4` でより小さい。
- **反転平面の弧の上界を述べた文献は見つからない**（zbMATH 全文・OpenAlex・Crossref・arXiv 等を検索）。
  ambient の `m(3,q) = q+1` から出る `q+1` が唯一の文献由来の上界。

## 失敗した方向（記録）

- 構造化族（関数のグラフ、F_p-線型写像、`q=p²` の2次元 F_p/F_r-部分空間）は **q=9 以外で全滅**
  （K1251）。q=9 は上界 `K ≤ q` が tight な唯一の既知の位数で、極大アークが単一軌道。
- ランダム/ILS 探索は `≈0.65q` で頭打ち。q=11 で厳密値 9 と一致したので、少なくとも q=11 では
  探索は最適。q ≥ 13 で 0.65q が真値か探索限界かは未決着。

## 残る課題

1. 偶数 q・`e ∈ {1, m−1}` の族が双曲型であることの一般証明（`det` の類似が char 2 では Arf 不変量）。
2. `liminf K/q`（`0.5 ≤ · ≤ 1`、実測 `≈0.65`）。
3. q=9 だけ構造化族が極大アークを与える理由。
4. ゲームの反転機構（K1253）。
