# 2026-11-26 第23ラウンド: 極大 6-キャップ 3 類の nucleus 不変量（char 2 の落とし穴）

## 目的

3 つの極大 6-キャップ軌道（A={10,47,49,55,61,64}, B={17,27,30,44,52,70},
C={8,48,50,51,58,61}）を、5-部分集合の conic の nucleus 配置で区別できるか。

## 途中で見つけた誤り（重要）

最初の実装では、conic の polar を通常の対称行列 Q·A で計算していた。しかし
**標数 2 では平方項が polar から消える**ため、接線は交差項のみの線形形式

```
B(A,X) = q3(a_x y + a_y x) + q4(a_x z + a_z x) + q5(a_y z + a_z y)
```

で与えられる（q0,q1,q2 は寄与しない）。誤った polar では接線が conic と 0 点で交わり、
nucleus も正しく求まらず、**3 類が区別できたように見える偽の結果**が出た。

## 訂正後の結果

正しい polar では:
- 各接線は conic とちょうど 1 点で交わる。
- 9 本の接線はすべて 1 点（nucleus）で交わる。
- 各 5-部分集合 T について、conic C_T の nucleus N は
  **S の secant ちょうど 1 本上にあり**、直線 N-P（P は 6 点目）は C_T に接する
  → (k, on_sec) = (1,1)。

代表 A, B, C のいずれでも 6 個の 5-部分集合すべてが (1,1) で、ランダムな
射影変換で移したコピーでも同じ。**nucleus 配置も 3 類を区別しない**。

## 追加: nucleus の secant グラフ（第24ラウンド）

各 5-部分集合 T（6 点目を除いたもの）の conic の nucleus N が乘る secant を
ラベル付けすると、3 類とも次の構造になる。

- 6 個の nucleus は 6 点を **3 対にペア分け**する（各 nucleus は 1 本の secant 上）。
- 各対の secant は、その対の 2 点を通る直線。
- 各類の canonical form は `[(0,(0,1)),(1,(0,1)),(2,(2,3)),(3,(2,3)),(4,(4,5)),(5,(4,5))]`
  で一致（完全マッチング）。

A: {0,2},{1,5},{3,4}、B: {0,2},{1,3},{4,5}、C: {0,4},{1,2},{3,5} はラベル付けが
違うだけで、同型。**この不変量も 3 類を区別しない。**

## 追加: 固定群の 73 点全体への作用（第25ラウンド）

24 個の固定群要素を 73 点全体の置換として書き、cycle type の多重集合を比較した。

| cycle type（73 点） | 個数 |
|---|---|
| (1, 2,2,2,2, 4×17) | 6 |
| (1, 3×24) | 8 |
| (1×9, 2×32) | 9 |
| identity | 1 |

- **3 類すべてで同一**の cycle type 多重集合。
- 固定群の平面全体への作用も、この不変量では区別できない。

## 意義

- 3 類は secant/tangent/external 統計・固定群（S4 辺作用）・外部直線への作用・
  nucleus 配置のすべてで一致し、局所不変量では区別できないことが確定。
- 標数 2 の polar の正しい扱い（平方項の寄与なし）を記録。今後同種の計算の再発防止。
- 区別にはさらに大域的な不変量（平面全体への自己同型作用の比較など）が必要。
