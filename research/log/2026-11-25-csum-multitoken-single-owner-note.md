## §1 主張

- **T-CSUM（全称定理）**: ∀ n≥1、任意の n トークン多重集合 X（各堆 ≥1）、
  S := sum(X)、∀ z≥0、∀ k ≥ z+n−1 に対して
  **H(S+k; X; z) = S mod 2**。
  値は X の総和の parity のみに依存し、個別の堆構成に非依存、値 2 を取らない。
- **L-1（基底・公刊 K0832 閉形式からの導出）**: ∀ x≥1, z≥0, k≥z:
  H(x+k; (x); z) = x mod 2（§2 の 4 分枝スライス）。
- **L-2（空位置）**: ∀ R, z≥0: H(R; (); z) = 0（mex{1}=0 帰納、§2）。
- **C-SHARP（系・公刊 K1311 T-DB から厳密に従う）**: n≥2 では T-CSUM の
  閾値 k ≥ z+n−1 は下げられない。境界行 k=z+n−2 に T-CSUM 則に反する
  セルが必ず存在する（構成家族は §2 末尾、有限機械確認 D12）。
- **領域インターロック（記録）**: 公刊 K1311 T-DB（境界行 k=z+n−2、全多重集合、
  D(E,k) 則・E = 2·max(X)−S）と本項 T-CSUM（tail k≥z+n−1）を合わせると、
  **全多重集合・n≥2 の領域 k ≥ z+n−2 が完全確定**する。n=1 は L-1 で全域
  k≥z（=z+n−1）が確定済みであり本項被包。all-ones X=1^n では公刊 K0832
  tail 系の閾値 R≥2n+z−1 と k≥z+n−1 が一致（S=n）し、値 [n odd] も再現。
- **K1308 O3/F1 の解決**: K1308 に census 予想として登録されていた C-SUM
  （triples/mixed/quads 箱、同 D8 ボックス 2,364 点）は本項で定理になる
  （同ボックスを byte-faithful に D7 で再照合）。
- **K1311 C2 との関係**: K1311 ノート C2 は 3 層フレームの tail 層を
  「公刊 K0832 all-ones 系・接続記録のみ」と処理していた。公刊 tail 系が
  all-ones 族に限られる以上その処理は正しく、本項は一般多重集合版の証明を
  新たに供給する（K1311 を訂正するものではなく補完）。

規約: verdict 不消費。11×11 空盤・二石 root・S2・class 1/2/4 は全時点 UNKNOWN。

## §2 手証明

### L-2（空位置）

H(0; (); z) = 0（R=0 基底）。R≥1 のとき () には堆がないので子は
z≥1 の C 型のみ（値 1^H(R−1; (); z−1)）。R についての帰納で H(R−1;();z−1)=0
（R−1=0 は基底、R−1≥1 は帰納法の仮定）なので子値は 1、よって
H(R; (); z) = mex{1} = 0。z=0 なら子なしで mex(∅)=0。∎

### L-1（単一トークン tail）

固定: x≥1, z≥0, k≥z, R = x+k ≥ x+z。公刊 K0832 閉形式 single_token(x,z,R)
を 4 分岐で確認する。

1. z=0 枝: 値 min(R,x) mod 2。R=x+k ≥ x なので = x mod 2。
2. z=x 枝（x≥1 のとき): R = x+k ≥ x+x = 2x。分岐条件「R 奇数かつ
   R ≤ 2x−1」「R 偶数かつ R ≤ x−1」はいずれも不成立（R ≥ 2x）。
   残る枝の値 = x mod 2。
3. 1 ≤ z ≤ x−1 枝: m = q_odd(z) ≤ z < x ≤ x+z ≤ R なので「R ≤ m」も
   「m < R < x+z」も不成立。残る枝の値 = x mod 2。
4. z ≥ x+1 枝: m = q_odd(x) ≤ x < x+z ≤ R なので「R ≤ m」不成立。
   残る枝の値 = x mod 2。

よって全域で x mod 2。（D6 で L-1 を両エンジンに機械照合、D6 で n=1 の
エンジン子値の均一性 set(children)={1−claim} も点別確認。）∎

### T-CSUM（二重帰納）

Region(n) := {(R; X; z) : |X|=n, k := R − sum(X) ≥ z+n−1}。
P(n) :=「(R;X;z) ∈ Region(n) ⇒ H(R;X;z) = sum(X) mod 2」を主張する。
外側を n について、内側を R についての強帰納で示す。

**外側帰納の仮定**: P(n−1) を仮定（n=1 は前項 L-1 で確定済み）。P(n) を
R についての強帰納で示す。R < 2n−1 では Region(n) が空（sum(X)≥n と
k≥z+n−1≥n−1 より R≥2n−1）なので真空。

**帰納段階**: (R;X;z) ∈ Region(n)、S=sum(X)、c = S mod 2、k=R−S ≥ z+n−1。
子を型別に処理する（すべての子で R が 1 減る）。

- **A 型（v>1 を v−1 に）**: 子 (R−1; X′; z)。n 不変、S′=S−1、
  k′ = (R−1)−S′ = k 不変 ≥ z+n−1 なので子は Region(n) ∈ R−1。
  内側帰納法の仮定より子値 = S′ mod 2 = (S−1) mod 2 = **1−c**。
- **B 型（v=1 を除去）**: 子 (R−1; X″; z+1)。n′=n−1、S″=S−1、
  k″ = k 不変。必要な閾値は (z+1)+(n−1)−1 = z+n−1 ≤ k なので子は
  Region(n−1)。外側帰納法の仮定より子値 = S″ mod 2 = **1−c**。
  端末ケース: n=1 なら X=(1) に限られ S=1, c=1、継承位置は () で
  L-2 より値 0 = 1−c。n=2 なら継承は単一トークン x で、これは L-1 の
  実体（x mod 2 = S″ mod 2）。
- **C 型（z≥1 のときの子値 1^H(R−1; X; z−1)）**: k′=k−1, z′=z−1。
  必要な閾値は (z−1)+n−1、すなわち k ≥ z+n−1 が必要だがこれは仮定その
  もの。よって子は Region(n) ∈ R−1 で、内側仮定より H(R−1;X;z−1) =
  S mod 2 = c、子値 = 1^c = **1−c**。

n≥1 なので X は空でなく、A 型または B 型の子が少なくとも 1 つ存在し
opts ≠ ∅。上の表示ですべての子値が 1−c なので
opts = {1−c}（均一）であり、

- c=0 のとき mex{1} = 0 = c
- c=1 のとき mex{0} = 1 = c

よって H(S+k; X; z) = c = S mod 2。Region(n) の任意の位置で成立し、
R は任意なので P(n) が示された。任意の n で同様に進み T-CSUM 得。∎

（備考: D5 がこの型別子構成を申立表のみで機械再構成し、
mex(children) == 申立 == engine、かつ set(children) == {1−申立} を
n=2..5・z≤8・k∈{z+n−1, z+n, z+n+1} で点別確認している。）

### C-SHARP（系: 閾値の鋭さ）

公刊 K1308 Z-DIAG / K1311 T-DB の 3 分枝則 D(E,k)（E = 2·max(X) − S、
境界行 k=z+n−2 の値、値 2 は E=k+1 直線上ちょうど、E≥k+2 枝の値は
1−[E odd]）において、n≥2・z≥0 に対して 2 つの構成家族を取る。

1. X = (z+2n−1, 1^{n−1}): S = z+3n−2、E = 2(z+2n−1) − S = z+n。
   k = z+n−2 なので E = k+2（E≥k+2 枝）であり、[E odd] = [S odd]
   （差 2n−2 は偶数）より D 値 = **1−[S odd] ≠ [S odd]**。
2. X = (z+2n−2, 1^{n−1}): E = 2(z+2n−2) − S = z+n−1 = **k+1**
   なので D 値 = **2**。

いずれも T-CSUM 則の値 [S odd] と一致しないので、k=z+n−2 の行には
T-CSUM が成り立たないセルが n≥2 の全 (n,z) で必ず存在し、閾値
k ≥ z+n−1 は（値規約ごと）下げられない。n=1 については公刊 L-SDB の
x=z インスタンスが值 2 を与え、同様に鋭い。∎

（D12 が家族 1・2 を n=2..11・z=0..6 の 140 点で engine == D(E,k) ==
申立どおりと有限確認。なお境界行 k=z+n−2 の全称値そのものは K1311 T-DB
の帰属であり、本項は D 則を引用するのみ。）
