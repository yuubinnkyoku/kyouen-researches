# 2026-11-14 6行前線class-splitのdual-run交叉再現（高速レーン）

高速レーン（本レーン）は K0818 レジュームの自然な次歩として 6×20 q=8 の35正準クラス
class-split と 6×21 q=7 のwitness探索を計画・実行した（着手 13:40Z・完了 13:55Z/14:11Z）。
同じ時間帯に並走のencoding-symmetry系レーンが同一の計画を実行しており、彼らが
14:06Z（K0819: 6×20 全35クラス UNSAT）と 14:16Z（K0815 第7弾: 6×21 witness・
M_{6,7} ≥ 22）で先取りpushした。

本レーンは重複する成果（K0819・K0815第7弾・CSV更新）をpushせず、独立2実行の
詳細照合を [six-row-frontier-dual-run-20261114](../experiments/six-row-frontier-dual-run-20261114/report.md)
として残した:

- 共有32正準クラスすべて conflicts bit-exact・判定一致（不一致0）。
- 並走側のrecordsは5要素クラス3件を非正準鏡像ラベルで記録しているが、
  可満性は鏡映不変なので被覆は完全（32正準+3鏡像 ≡ 35正準）・全UNSAT一致。
- 6×21 witness（class{2}・35石・行構成 6,6,5,6,6,6）は両レーンとも
  conflicts 1,904,706 で同一のSAT解を発見。

  lex=H交叉確認（{1},{2}）も一致。

  lex=H追加2クラス（{1,2},{1,3}）・{1}/{2} fresh再実行 node-exact・
  6×22 q=7 {2} --krow=2:5 INDET・6×24 q=6 {1} と --krow=1:4 の INDET
  （(6,6) 前線の初のkrow細分割観測）。

教訓（運用）:
1. 同一主題の並走は push直前まで検出できない — 高頻度テーマ（K0818の
   「自然な次歩」）は複数レーンが同時に着手する。着手宣言を早期に出すか、
   意図的に1歩ずらす（例: 6×20 の次は 6×21 でなく 5×22 や 6×31 を先に）のが
   重複削減になる。
2. sat3.js系sweepのrecords.jsonl並行appendは壊れる（本レーンで発生・
   生ログから決定的再構築で復元）。1ワーカー1ファイルが確実。
3. 異なる実行環境で独立起動した2実行が全クラス衝突数まで一致した
   （n11系のcross-lane再現4回とは独立な5例目・sat符号化では初の全幅一致）。
