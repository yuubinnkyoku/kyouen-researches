# 2026-11-24 第2ラウンド: モーメント多項式（Farkas 証明書）で s-弧上界を改善

## 出発点

前ラウンドで `K_s(q)` スペクトル（K1274）と厳密値（K1275、
`K_4(8)=14` まで）を得た。残る課題は「上界の改善」と
「`K_q = (q−1)²`（τ_1 = 2q）の等号問題」だった。

## 新しい発想

厳密値の SAT 計算ではなく、**設計のモーメント等式を線形計画として使い、
その双対（Farkas 証明書）を多項式として取り出す**方向に切り替えた。

- `s`-弧 `S`（`|S|=n`）の円交点数分布 `t_r` は 4 本の等式 (M1)–(M4) を満たす。
- 多項式 `P(r)` を `{1, r, C(r,2), C(r,3)}` で展開し、
  `Σ P(r)t_r` をモーメントで置き換えると `Y_P(n,q)` になる。
- 可能なすべての `r` で `P(r) ≥ 0` なら `Y_P ≥ 0` が必要。
  臨界の `n` で `Y_P < 0` なら矛盾 → 上界。

線形計画の数値双対を観察すると、きれいな整数係数の多項式が見つかった:

```
P_s(r) = −(r−(s−3))(r−(s−2))(r−s)     （整数 0≤r≤s で非負）
Q(r)   = (r−1)(r−3)(r−4)               （整数 r≥1 で非負、ブロッキング用）
```

## 結果（証明済み）

1. **定理 A**: `K_4(q) ≤ 2q+1`（q ≥ 6）。旧 `2q+4` から 3 改善。
   `n=2q+2` で `ΣP_4 t_r = −4(q²−5q−2) < 0`。
2. **定理 B**: `K_s(q) ≤ (s−2)q`（5 ≤ s ≤ q−1, q ≥ 9）。
   旧 `(s−2)q + s` から**加法的な s を完全に消去**。
   `n=(s−2)q+1` で `ΣP_s t_r = −qW(s,q)`, `W=q(s−1)(s−4)−s(s−2)(s−3)−2 > 0`。
3. **定理 C**: `τ_1(q) ≥ 2q`（q ≥ 9）。
   `m=2q−1` で `ΣQ t_r = −2(q−8)(q−1) < 0`。
   Bruen–Rothschild (1985) の下界の初等的再証明。双対より `K_q ≤ (q−1)²`。

**改善表**（旧 = K1274 の設計上界）:

| s | 旧 | 新 | 改善 |
|---:|---:|---:|---:|
| 4 | 2q+4 | 2q+1（q≥6） | 3 |
| 5 | 3q+5 | 3q（q≥9） | 5 |
| 6 | 4q+6 | 4q（q≥9） | 6 |
| s | (s−2)q+s | (s−2)q | s |

**帰結**: `K_4(9) ≤ 19`（旧 22）、`K_5(9) ≤ 27`、`K_6(9) ≤ 36`、
`K_7(9) ≤ 45`、`K_8(9) ≤ 54`。上包絡は
`(s−2)q`（中域）、`(q−1)²`（s=q）、`q²+1`（s=q+1）。

## ブロッキング等号の探索（SAT、補助）

- q=4,5 でサイズ 2q のブロッキング集合を SAT が発見（2 エンジン、独立検証）。
  `τ_1(4)=8`, `τ_1(5)=10`、`K_q=(q−1)²` と整合。
- q=7,8,9,11 の `m=2q`（q=7 は m=15 も）は約 5〜20 CPU 分で未解決のまま中断。
  UNSAT 証明も証人も得られず。`τ_1(7) ∈ [14,17]` のまま。
- 理論的には、モーメント LP は q=4..8 で `2q−1` が実行可能なので、
  この方法では等号問題に届かないことが分かった。
