# 2026-11-24 第3ラウンド: 第2乗数族で s-弧上界を改善し、3-モーメント法の限界を確定

## 出発点

前ラウンド（K1291/K1292）で `K_4(q) ≤ 2q+1`、`K_s(q) ≤ (s−2)q`、
`τ_1 ≥ 2q` を得た。残っていた問いは「上界をさらに詰められるか」「どこで
打ち止めか」だった。モーメント法の教科書的な位置づけ（LP/Farkas）を踏まえ、
**乗数の空間そのものを厳密 LP で最適化する**方向に切り替えた。

## やったこと

1. **3-モーメント緩和の厳密 LP** (`moment_lp.py`)。
   制約行列は階数 4 なので、`b(n,q)` が列錐に入るかは 4 列部分集合の列挙で
   厳密に判定できる（Carathéodory）。`Fraction` のみ使用。
2. **LP 最適値の格子計算**。`s=4` は `q ≥ 7` でちょうど `2q+1`。
   つまり K1291 定理A はこの方法の最適であり、**改善不能**と分かった。
   `s=3` は `q+3`（K1291 の注記どおり）。
3. **最適乗数の抽出** (`moment_certificate.py`)。頂点列挙で `P ≥ 0`, `Y = −1`
   を満たす明示的乗数を出したところ、`q ≥ 11` では
   `P2_s(r) = −(r−(s−4))(r−(s−3))(r−s)` という**固定の 3 次式**が最適だった
   （`q` に依存しない）。K1291 の `P1_s` は `q = 9` で最適。
4. **第2乗数族の定理化** (K1293)。`P2_s` の非負性（根が連続整数）と
   `Y_{P2}` の 3 次性から `K_s(q) ≤ min((s−2)q, n₂(s,q))`。
   漸近形は `limsup K_s(q)/q ≤ s − 2 − d*(s)`、`d*(s) → 2/3`。
5. **`K_4(9)` の攻め**（未決）。反復貪欲＋強制挿入で 16 は即発見、
   `k=17` は 90 秒・150 秒・300 秒（45 万反復、2.3 万再開始）のいずれでも
   到達せず。SAT（cadical195、5-部分集合禁止 + 基数 + 3 点対称性破り）も
   `n=17` で 10–14 分タイムアウト。**`K_4(9) ∈ [16,19]` は据え置き**。

## 結果（すべて厳密整数・証明書つき）

- 新上界: `K_6(13)≤49`（旧52）、`K_7(16)≤74`（旧80）、`K_8(19)≤105`（旧114）、
  `K_9(25)≤161`（旧175）など。改善幅は最大 14。
- 漸近定数が `s−2` から `s−2−d*(s)` に下がり、`d* → 2/3`。
- `s=4` は改善しない（LP 最適 = `2q+1`）。
- 反例ではないが注意点: `q ≥ 19, s ≥ 8` では `min(P1,P2)` より LP 最適値が
  小さい（`(19,9)=122 < 123`, `(25,8)=135 < 137`, `(25,9)=157 < 161`）。
  第3乗数の族は未同定。K1294 に 3 例外として明記した。

## 検証

- 実 `s`-弧 8 例（`q=9,11,13,16`; `s=3..9`）で `Σ_r P(r)t_r = Y_P` が厳密一致。
  これが恒等式の実データ側の確認で、式の誤りを 2 回検出した（下記）。
- `P2_s(r) ≥ 0` を `s=4..9` で全数、`Y_{P2}(n₂+1,q) < 0` を全格子点で確認。
- `P1` の上界が K1291 の `(s−2)q` を再現（較正）。
- 盤面は `build_board.py` で再構成し設計パラメータを再検査。`q=9` の盤面は
  spectrum 実験の `board_q9.json` と集合一致（738 円）。

## 踏んだ落とし穴

- `(M2)` を `n(q+1)` と誤記し、全 `(s,q)` が「実行不能」になる誤結果を出した。
  実 `s`-弧の `t_r` 分布との照合で発覚（正しくは各点が `q(q+1)` 円なので `nq(q+1)`）。
- LP の頂点計算で行列を転置して組み、`q=9, s=4` で下界 16 が実行不能という
  矛盾が出て発覚。
- 3 次の Taylor 展開で `d³` の符号を落とした。
- penalty 型 SA は `k=16` でも届かず、反復貪欲＋強制挿入に置き換えた。
- `sat_arc.py` は自前 board に `special` が無く `KeyError`。

## 次の一手

1. `K_4(9)` の決着: 円ごとの基数制約の compact 符号化、最大性制約、
   または `τ_6` 側の被覆 ILP。16 が濃厚だが未証明。
2. 第3乗数の族の同定（`q ≥ 19, s ≥ 8`）。`min(P1,P2)` が LP 最適でない
   最小の格子点は `(19,9)`。
3. 漸近系の `O(1)` 項（`n₂(s,q) = (s−2−d*(s))q + O(1)` の定数）。
4. `K_s` の厳密値（`s ≥ 5`）は依然として SAT が重い。`q=9, s=5`（≤27）が次の現実的目標。
