# 2026-11-22 n11 S4 fresh-regeneration pass-1 raw audit (k001-k084)

## Scope

Read-only integrity audit of the current pass-1 checkpoint for the fresh-corpus regeneration lane, pinned to source commit `8155d21ec05cd9fc62a0ccd64fcb2d7ef1b7dfe1`. The previously audited `k021`–`k040` records were reused only after their input and raw output blob SHAs were confirmed unchanged from snapshot `37bc365ab89ace7b9315ef36eeb6f5048537d583` to the pinned checkpoint. No solver was run, no verdict was consumed, and no cache was merged.

The current main at audit publication is `a808d05a1997647fbe881634b7aaa767d219a310`. Its `n11-s4bd-fresh-corpus-regen-20261121` input and raw inventories are byte-identical by Git blob SHA to the pinned checkpoint: 101 input CSVs and 84 pass-1 raw outputs (k001–k084).

## Checks

For the 64 newly audited rows (k001–k020 and k041–k084), fetched raw input/output text at the pinned commit and checked:

- one non-comment input row with 11 fields and one `replay,` output row with 11 fields;
- `# replay_done rows=1` and no `replay_error`;
- exact decimal-string key equality between input and output (no JS Number conversion of 64-bit keys);
- five stones, order=0, share_tt=0, and is_or=0 in both input and raw output;
- legal count agrees across input/output and with the pinned corpus-def `legals` map;
- key belongs to `children106` or the `unclaimed2` set;
- budget=15,000,000, positive nodes within budget, nonnegative finite wall time;
- published result code is 2 for all non-target keys and 0 for `TARGET_S5` (the expected budget-exhausted UNKNOWN row).

All checks passed for 64/64 newly audited records. The existing k021–k040 audit log was also checked for current-file identity (input and raw blob SHA unchanged) and its 20/20 result is reused. The exact keys of k021–k040 were fetched and compared with the new 64-key set: all 84 keys are unique and each is in the frozen 106-child or unclaimed-two universe.

## Interpretation and limits

This establishes input/raw consistency, exact key matching, frozen-corpus membership, inventory completeness for the current checkpoint, and cross-record uniqueness. It does not independently validate the solver's game-theoretic verdicts or establish pass-2 determinism. No cache row is accepted or merged. Pass 1 remains incomplete: 17 of the 101 input keys (k085–k101) have no published pass-1 raw yet. The S4 closure, root {60,27} certificate, and empty-board outcome are not established by this audit.

The audit checker was executed in-session against fetched pinned raw text; no standalone audit script was committed. The source files are the reproduction inputs.
