# 横断法則の整理: 一般 tail の既証明性（レジーム補題の系）と一般マージの margin 塔分析（2026-11-20 高速レーン）

各族の出版 item（K1126..K1141）が「tail 開始族式 x+z+y+1 が y=2..N で全称確定」と
族ごとに記録し直しており、レジュームも「横断法則の一般証明は未着手」と記載し続けていた。
本ノートは既存の証明済み定理を照合して一般 tail が既に閉じていることを確認し、
一般マージ命題の証明構造を margin 解析で特定した結果を記録する。
新規の計算実験は含まない（引用はすべて出版済み item・報告）。

## 1. 一般 tail: K0832 の証明済みレジーム補題の系として既に全称確定

K0832（vertical-fiber degree reduction・全t全q最大値定理ほか）の構成要素のうち:

- **補題P（プレイ長・証明済み）**: 一般残余ゲームで L = ΣX + |X| + z は
  A/B/C いずれの手でもちょうど1減り、L >= 1 なら合法手が常に存在する。
  従ってプレイ長は手順によらず min(R,L)。
- **レジーム補題（証明済み・全t最大値定理）**: R >= L−1 では H = (L−n) mod 2 <= 1
  （n = |X| + z）。

この2つから、κ=1 の一般残余ゲーム（任意個トークンの任意有限多重集合 X・S=ΣX）に対して

**系（一般 tail・既証明）** R >= S + |X| + z − 1 ⟹ H(R;X;z) = S mod 2

が従う。族ごとの.tail 式と照合すると:

- 単一トークン（|X|=1）: 閾値 x+z = L−1（L=x+z+1）。K0832 単一トークン閉形式の
  レジーム枝「R >= L−1 で v = x mod 2」と一致。
- 全1族 X=(1^k)（|X|=k・S=k）: 閾値 2k+z−1。全1族主定理の系（tail・証明済み）と一致。
- 2トークン族 X=(x,y)（|X|=2）: 閾値 S+|X|+z−1 = x+y+z+1 = x+z+y+1。
  **族 item の tail 開始族式とちょうど一致**し、tail 値 (x+y) mod 2 = S mod 2 も一致。
- 3トークン以上の将来族（例: 3トークン閾値 S+z+2）も tail は本系で閉じている。

従って tail の全称性は族の増加に対して闭じており、族機械の tail 系チェック
（マージ系と同じく数百万点の独立再検証）は選択肢分解の部品・回帰テストとしては
意味があるが、命題の新規性はなく、以後の族 item・レジュームは本系を参照してよい。

## 2. 一般マージ命題の margin 塔分析（証明の鍵の特定）

マージ主張は S = x+y <= z−1（行 x <= z−y−1 と同値）で H(R;(x,y);z) = 単一トークン
閉形式の安定枝 stv(S,R)（K0832 の κ=1 縮約公式と同じ式）。y 非依存の証明を試みた
margin 解析（m := z−S >= 1）の結果:

- R に関する統一帰納ステップは、A/B 手の子を margin m+1、C 手の子を m−1 に写す
  （A/B 子の S は S−1、退去子は高さ z+1 の安定枝、C 子は同 S で z−1）。
- 親 margin m >= 2 は全ての子が margin m' >= 1 に落ち、帰納文「全 m >= 1 に対して
  マージ値 stv(S,R)」が正しければ閉じる（mex 恒等式は stv の有限場合表で機械検証可能）。
- しかし m = 1 の親（行 d = −y−1）の C 子は margin 0（対角行 d = −y・z_child = S）に
  落ち、マージ主張の範囲外。m = 1 層の mex 成立には対角行（margin 0・z = S スライス）の
  子値が R の全範囲で必要になる。
- 対角行 margin 0 自身の値は A/B 子（margin 1）と C 子（margin −1）を要求し、
  以下 margin −1, −2, ... と連なる「塔」になる。各層の値構造（base rank b_k・
  interval 開始 th(d) のジグザグ表・pin 行 d 範囲・band）は族ごとに非一様で、
  pin d 範囲の偶z側は y=9 で [−y+4,y+2] への例外的シフトが観測されている。

結論: 一般 y の単一トークン縮約閉形式に依らないマージ全称証明には
**margin 0 スライス z = x+y（対角行）の一般構造決定**が本質的な障害であり、
現状 y<=10 で族ごとの機械証明が到達している。本分析により、一般証明レーンの
直接の攻撃対象は「対角行（margin 0）の y 非依存特徴づけ（値2 cap
z+y−[z≡y mod 2] の全称性にある程度の粗い値パターンの一般化）」に特定された。

## 3. 横断 pin 観察の整理（y=5..10・実測表）

- 奇z pin 行 d 範囲: [−y+2, y]（y 奇: 5,7,9）/ [−y+4, y]（y 偶: 6,8,10）で
  6 族連続かつ d ≡ y (mod 4)。pin = z+(d+3y)/2・pin 行は値1表で pin 点を skip。
- 偶z pin 行 d 範囲: [−y+4, y−2]（y=5,7）/ [−y+2, y−2]（y=6,8,10）/
  [−y+4, y+2]（y=9 の例外・5行）で単純族式は存在しない。
- y=11 以降の fit は奇z側は族式予想 {[−9,11]・6行} を検定し、偶z側は
  データ駆動で決定する（[y=11 着手宣言](2026-11-20-y11-two-token-skeleton-single-owner-note.md) 参照）。
