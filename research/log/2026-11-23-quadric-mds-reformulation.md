# 2026-11-23 反転平面の共円ゲーム＝楕円二次曲面上のMDS符号

## 発想

反転平面盤の K を「アークの最大サイズ」として測ってきたが（K1058 10co）、
これは組み合わせの言葉のままでは上界が `q+3` で止まる。
そこで**盤そのものを符号理論に翻訳する**方向を試した。

## 手順と結果

`F = F_{q²} = F_q + F_q u`、`z = a + b u`、`N(z) = z·z^q = a² + αab + βb²`
（`α = u + u^q`, `β = u^{q+1}`）として

```
lift(z) = (1 : a : b : N(z)),   lift(∞) = (0:0:0:1)
```

と持ち上げると、像は `PG(3,q)` の二次曲面 `X0X3 = X1² + αX1X2 + βX2²`（`q²+1` 点）で、
**円はちょうど切断平面**になる。したがって
**4点共円 ⇔ 4つの lift が一次従属**。

- 模型の全数検査：q=3,4,5,7 の全4点組（210 / 2,380 / 14,950 / 230,300）で
  共円と一次従属が完全一致、不一致0、曲面外の点0。
- そこから：アーク ＝ どの4列も独立な 4×k 行列で全列が `Q⁻` 上。
  生成する符号は平面切断が高々3列しか含まないので `d ≥ k−3`、
  Singleton より `d = k−3`。**MDS符号である。**
- 結論：`K(q)` ＝ 楕円二次曲面に列を載せられる `[k,4,k−3]` MDS符号の最大長
  ＝ `[k,k−4,5]` MDS符号の（二次曲面上の）検査行列の最大長。

**上界**：`K ≤ M_4(q)`（4次元MDS符号の最大長、無条件）。
MDS予想（4次元, q≥5）より `M_4(q) = q+1`、したがって `K ≤ q+1`。
素数 q では Ball の定理で無条件。既存の `q+3` / `q+2`（q≡1 mod 4）を全素数で改善。

## 検証

全アーク証人（q=5..49、20個）を**円リストを使わず**、`Q⁻` 上の rank 計算だけで再検証。
すべて「全4点組が rank 4」＝ MDS `[k,4,k−3]` で、曲面外の点は0。
これまでの `arc_search_report.py`（円リストとの突き合わせ）とは独立な経路での確認になった。

## 読み取れること

1. 9点までは任意の一般位置集合が「ある二次曲面上」に載る（二次形式の空間が10次元、
   9点で9条件）。よって `k ≤ 9` では制約が空で、`K = M_4(q) = q+1` が q=4,5 で実現。
2. `q ≥ 13`（`K ≥ 10`）で `K/q` が 0.77 → 0.64 へ下がる。
   **楕円二次曲面の制約は MDS 長を約35%削る。**
3. 双対符号は常に `[k,k−4,5]`。つまり「二次曲面上の5-アーク」。

## 新しい問い

`M_4^{Q}(q) := K(q)`（二次曲面制約付きMDS長）と `M_4(q) = q+1` のギャップ。
符号理論の言葉では「与えられた楕円二次曲面上に列を取るMDS符号はどこまで長くできるか」。
これは MDS 符号とアークの理論の既存の枠（NRC・楕円二次曲面の ovoid）とは別の量で、
`K ≈ 0.65q` という測定値が最初のデータ点になる。

## 引き継ぎ

- `K ≤ q+1` は MDS予想依存（素数 q は無条件）。`q ≥ 13` の真値は未確定。
- 上界をさらに詰めるには「二次曲面上」の制約を使う必要がある。9点までは空なので、
  `k ≥ 10` の配置（＝ `q ≥ 13`）で初めて意味を持つ。
- k=8 の組み立ての食い違い（K1058 10cm–10cn）は依然未解決。
