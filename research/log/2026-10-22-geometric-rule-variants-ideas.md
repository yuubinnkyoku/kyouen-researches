この記録を根拠に新規K項目を起こしたり、未検証の勝敗を確定扱いしたりしない。

基本方針は、有限の点集合（例：2次元 `{0,...,n-1}^2`、3次元 `{0,...,n-1}^3`）の空点に交互に石を追加し、禁止される点の組を完成させる手を敗着とする「完全指摘」の通常プレイである。
安全な追加だけを合法手として、合法手のない側が負ける形で計算できる。
標準2次元共円ゲームは**4点共円・4点共線をともに禁止**する（[K0001](../knowledge/items/K0001-complete-call-rules.md)）。
各変種では「何点禁止か」「退化した図形を含めるか」「座標軸を固定するか」を必ず指定する。

## 1. 三次元の候補

| 仮称 | 禁止条件の候補 | 扱う際の注意 |
|---|---|---|
| **共球のみ** | **5石**が同一の通常の球面上 | 共面も禁止する版とは異なる。共線・共面の退化を勝手に禁止しない |
| **共面のみ（4点版）** | **4石**が同一平面上 | 最も直接的な平面の類似物。4点のアフィン行列式が0なら禁止 |
| **共面のみ（5点版）** | **5石**が同一平面上 | 4点版とは異なるゲーム。5点のアフィン階数が3以下なら禁止 |
| **共球・共面（5点版）** | **5石**が同一球面または同一平面上 | 既存の高q点版研究とつながる。標準立方格子のq=5の強解決を意味しない |
| **共円柱** | 例：**4石**が同一の鉛直円柱面上 | 円柱の軸を固定するか任意にするかで条件が変わる。鉛直軸固定ならxy射影の共円が手掛かり |
| **共円錐** | 同じ円錐面上の一定数の石 | 頂点・軸・開きの自由度を先に限定し、禁止点数を決める必要がある |

**4点共面版の整数判定**（相異なる4点 `p_i=(x_i,y_i,z_i)`）：

```text
det [[x1,y1,z1,1],
     [x2,y2,z2,1],
     [x3,y3,z3,1],
     [x4,y4,z4,1]] == 0
```

この条件では、例えば3点が一直線上にあると、その3点と任意の第4点は共面になる。通常の「一般位置」の制約よりかなり強くなる可能性がある。

**共球のみの注意**：5点の行列 `[x²+y²+z²,x,y,z,1]` の行列式が0、という判定だけでは共面退化も拾う。共球のみを扱うなら、実際に**有限半径の球面が存在すること**を別途確認する（共面も含める版なら行列の階数条件が使える）。
一方、共面のみには `[x,y,z,1]` のアフィン階数を使う。任意のq点を扱う際も、単独の小行列式だけで全点の共面・共球を判定したつもりにならないこと。

**既存成果との関係**：

- [K0340：3次元平行格子列の共球・共面q点禁止](../knowledge/items/K0340-three-dimensional-prism-capacity-and-grundy.md)。一般位置の底面、`q>2w` などの仮定下では共球禁止は実質発生せず、共面の容量条件へ縮約される。
- [K0352：任意次元の平行列盤](../knowledge/items/K0352-general-dimensional-parallel-columns.md)。幾何学的条件を満たす特殊盤について極大配置やGrundy数を扱う。
- **未着手候補として特に区別する対象**：4点共面のみ・標準 `n×n×n` 立方格子の空盤勝敗、共球のみq=5と共球・共面q=5の差、軸固定の共円柱版。ここに「未解決」とあるのは本記録での未検証を意味し、文献全体についての新規性の主張ではない。

## 2. 二次元で禁止する図形を変える候補

| 仮称 | 暫定的な定義 | 主な分岐 |
|---|---|---|
| **共放物線** | 例：`y=ax²+bx+c` の同じグラフに**4石**が乗ったら禁止 | x軸方向を固定するか、回転も認めるか。a=0等の退化の扱い |
| **共楕円** | 例：一般の**非退化な楕円**上に**6石**が乗ったら禁止 | 回転・長短軸を自由にするか、軸を固定するか |
| **共双曲線** | 例：一般の**非退化な双曲線**上に**6石**が乗ったら禁止 | 退化した2直線を含めるか、含めないか |
| **共二次曲線** | **6石**が同じ二次方程式 `Ax²+Bxy+Cy²+Dx+Ey+F=0` 上なら禁止 | 退化二次曲線を含むか。6×6係数行列の階数が入口 |
| **共長方形** | **4石**がある長方形の4頂点をちょうど構成したら禁止 | 辺を座標軸と平行に限定する版と、任意角度の版は別物 |
| **共多項式** | `y=f(x)`、`deg f <= k` に**k+2石**が乗ったら禁止 | xが等しい複数点を含む場合の判定に注意。kを変化させる族 |

上表の「4石・6石」は**研究のために採用する一つのルール案**であり、全ての自由度・退化の取り方について最小の非自明禁止数だという意味ではない。
特に「6石が同じ二次曲線」は、係数が零でない二次式の存在だけで判定すると楕円・双曲線・放物線や退化曲線を混在させる。各曲線のみに限定するなら判別式や実点の条件を別に検査する必要がある。
また、共長方形は4点が**ちょうど四隅**であることを意味し、単に一つの長方形の内部や辺にある4点ではない。

### 有望：二次形式の係数を動かす4点版

固定した実数または有理数パラメータ `lambda` に対し、次の4行4列行列式が0になる**相異なる4石**を禁止する：

```text
det [[x1²+lambda*y1², x1, y1, 1],
     [x2²+lambda*y2², x2, y2, 1],
     [x3²+lambda*y3², x3, y3, 1],
     [x4²+lambda*y4², x4, y4, 1]] == 0
```

- `lambda=1` では、共円または共線の標準4点禁止と一致する。
- `lambda>0` では軸を固定した楕円型（`lambda=1` が円型）。
- `lambda=0` では放物線型の方程式やその退化型。
- `lambda<0` では双曲線型の方程式やその退化型。

**重要**：これは「本当の楕円のみ」「本当の放物線のみ」を禁止する規則と同じではない。行列式ゼロは退化した直線等も含む。
固定盤面では上記行列式は `lambda` の一次式なので、禁止4点組が切り替わる候補値は有限個である。従って、整数や有理数の `lambda` を無差別に列挙せず、切替点を正確に求めて分類できる可能性がある。

会話中には `3×3`・`4×4` の各 `lambda` に対する勝敗表や「`4×4` の整数 `lambda` では `lambda=1` のみ後手勝ち」という**計算結果の主張**も出た。ただし実行コード・出力・独立検証の所在がこの記録では確認できないため、**未検証の参考情報**として扱う。再計算・再現物の保存前に既知結果として引用しない。

## 3. さらに高い次元

- **d次元共球**：通常の（有限半径の）超球面上に `d+2` 点が載ったら禁止、という基本案。
- **d次元共超平面**：`d+1` 点が一つの超平面上に載ったら禁止する版と、`d+2` 点版を区別する。
- **両方禁止**：同一点数qで共球・共超平面のいずれかを禁止。qと盤面の形によって既存[K0352](../knowledge/items/K0352-general-dimensional-parallel-columns.md)が適用できる領域がある。

三次元では「5点共球」と「4点共面」はそれぞれ自然な最小の非自明な対応だが、**同じ禁止点数で比較するには5点共面版**も必要になる。

## 4. 優先して試す順序（提案）

1. **共面のみ4点・立方格子**：`2×2×2` から全安全局面と空盤勝敗を厳密計算し、`3×3×3` では対称性・枝刈りを使って探索。共球のみ・両方禁止のq=5も同じ判定基盤で比較する。
2. **二次形式lambda版**：`lambda=-2,-1,0,1,2` などをまず小盤で比較。その後、4点組ごとの行列式を `a*lambda+b` として切替値を列挙し、固定盤面での勝敗が変化する点を厳密に分類する。
3. **共長方形4点**：軸平行版から着手し、任意向き版との差・最大安全石数・終局サイズ・Grundy数を比較する。
4. **鉛直共円柱4点**：xy射影の同一円条件で禁止族を作り、共球5点・共面4/5点と比較する。
5. **共放物線／楕円／双曲線／二次曲線／多項式／円錐**：上の定義分岐を先に固定してから、整数演算で禁止集合を生成する。

**必要な実験の形**：盤点・禁止組・ルール上の退化の扱い・対称性・全安全局面数・空盤勝敗・Grundy数の対象範囲・実行スクリプト・再現出力・独立検査を対にして `research/experiments/` に置く。有限実験の支持を無限盤面の一般定理と混同しない。一般定理や確定した有限結果として独立に参照できるものが出た時点で、既存項目と重複しないK項目の追加を検討する。
