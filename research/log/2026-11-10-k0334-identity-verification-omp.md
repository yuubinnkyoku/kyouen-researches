### 1.3 記号の定義

p を奇素数、h=(p−1)/2、Q_p = {(t, t² mod p) : 0 ≤ t < p} ⊂ {0,...,p−1}²。
パラメータ t の点を P_t = (t, t² mod p) と書き、座標は常に 0..p−1 の整数代表とする。
`forbidden_edges.cpp` の語法に合わせ、相異なる四パラメータ q={t_1,t_2,t_3,t_4}
(昇順に t_1<t_2<t_3<t_4)に対し:

- **完全対**: 対 i (1 ≤ i ≤ h)とはパラメータ集合 {i, p−i} のこと。
  四点が完全対を含むとは、ある i について {i,p−i} ⊂ q となること。
- **二完全対(台形辺)**: ある i≠j について q = {i,p−i,j,p−j} となること。
  `search_shape_class.py:77-81` は q の非零元を対へ落として重複が出るかで
  これを判定している(`pairs = [t if t<=h else p-t for t in pts]`)。
- **禁止四点**: P_{t_1},...,P_{t_4} が同一円または同一直線上にあること。
- **det**: 四点 (x_k,y_k) に対し
  D_cyc = det[[x_k²+y_k², x_k, y_k, 1]]_(k=1..4)  (共円・共線判定の 4×4)。
  `forbidden_edges.cpp:7-16` の `det()` は第4点で平行移動した 3×3 形
  D_enc = det[[x_k−x_4, y_k−y_4, (x_k−x_4)²+(y_k−y_4)²]]_(k=1..3) を計算する。

## 第2部 同一性の証明

### 2.0 方針

証明は三層に分ける。

- **補題A(座標変換)**: `forbidden_edges.cpp:7-16` の 3×3 行列式は、
  共円・共線判定の 4×4 行列式と**符号も含めて一致**する(環上の恒等式)。
  よって整数 det==0 は「整数平面で四点が同一円または同一直線上」と同値。
- **定理B(因数分解)**: パラメータ行列式
  `det[t^0, t^1, t^2, t^4] = (t_1+t_2+t_3+t_4)·∏_{i<j}(t_j−t_i)`(Z 上の恒等式)。
  パラメータ和は**ここで現れる**。証明は「交代多項式だから Vandermonde で割れる
  + 単項式一個の係数比較」で、Schur 多項式を持ち出さない。
- **系C(mod p 合同式)**: Q_p の四点について
  `D_cyc ≡ −(Σt)·V (mod p)`。V は p で割れないので `D_cyc≡0 ⟹ Σt≡0`。

行・列の基本変形と Vandermonde 行列式の標準事実のみを使う。
外部定理の引用は「Z[t] が UFD であること」「交代多項式が Vandermonde 積で
割れること」の二点だけで、いずれも標準的である。

### 2.1 補題A(3×3 形と 4×4 形の一致)

R を可換環、整数点 P_k=(x_k,y_k) ∈ R²(k=1,2,3,4)とし

    D_cyc = det [[x_k²+y_k², x_k, y_k, 1]]_(k=1..4),
    Δx_k = x_k−x_4, Δy_k = y_k−y_4, Δn_k = Δx_k²+Δy_k² (k=1,2,3)

と置く。このとき次が R 上の恒等式として成り立つ。

    D_cyc = det [[Δx_k, Δy_k, Δn_k]]_(k=1..3).                       (A)

**証明.** D_cyc の列に次の基本変形を施す(いずれも det を変えない)。

    c1 ← c1 − 2x_4·c2 − 2y_4·c3 + (x_4²+y_4²)·c4,
    c2 ← c2 − x_4·c4,
    c3 ← c3 − y_4·c4.

第 k 行(k=1..4)の新しい第1成分は

    x_k²+y_k² − 2x_4x_k − 2y_4y_k + (x_4²+y_4²) = Δx_k²+Δy_k² = Δn_k,

第2成分は Δx_k、第3成分は Δy_k である。k=4 では Δx_4=Δy_4=Δn_4=0 なので
第4行は (0,0,0,1)。この行で余因子展開すると第4行第4列の符号は
(−1)^(4+4)=+1 で、残る 3×3 は列順 (Δn,Δx,Δy) の

    det [[Δn_k, Δx_k, Δy_k]]_(k=1..3)。                              (A')

(A') の列を巡回置換して (Δx,Δy,Δn) にすると、3-巡回置換の符号は +1 なので

    det [[Δn_k,Δx_k,Δy_k]] = det [[Δx_k,Δy_k,Δn_k]]。

これはまさに `forbidden_edges.cpp` の `det()`(:15-17 の
`x0*(z1*n2−n1*z2) − z0*(x1*n2−n1*x2) + n0*(x1*z2−z1*x2)`)であり、
`x[]=Δx, z[]=Δy, n[]=Δn` と対応する。よって (A) が成り立つ。□

**系A1.** D_cyc = 0 ⟺ 四点が同一円または同一直線上にある(整数平面)。

**証明.** D_cyc = 0 は、零でない (A,B,C,D) で全 k について
A(x_k²+y_k²)+Bx_k+Cy_k+D=0 となるものが存在することと同値
(4×4 行列の非自明な零結合)。第4列がすべて 1 なので、
その解で A=B=C=0 ならば D=0 となり非自明性に反する。
よって A≠0 なら円、A=0 なら直線が四点を通る。逆に円・直線が四点を通れば
その方程式の係数が非自明な零結合を与える。□

この系により、`forbidden_edges.cpp` の整数 `det()==0` 判定は
「禁止四点」の定義と厳密に一致する(浮動小数や剰余は使っていない)。

### 2.2 定理B(パラメータ行列式の因数分解)

Z[t_1,t_2,t_3,t_4] において

    det[t_i^(d_j)]_(i,j=1..4),  (d_1,d_2,d_3,d_4) = (0,1,2,4)

を D と書き、V = det[t_i^(j−1)] = ∏_{i<j}(t_j−t_i) と置く。このとき

    D = (t_1+t_2+t_3+t_4)·V.                                          (B)

**証明.** (i) **交代性**: 二変数 t_i,t_j を入れ替えると D の二行が入れ替わり
D ↦ −D。よって D は交代多項式で、同次次数 0+1+2+4 = 7 の斉次多項式である。

(ii) **V による整除**: t_i = t_j を代入すると二行が一致し D=0。よって
D は各 (t_j−t_i) で割り切れる。Z[t_1..t_4] は UFD で、一次式 (t_j−t_i)
(i<j) は互いに同伴でない既約元だから、その積 V で割り切れる。
商 Q = D/V は対称多項式で、次数は 7−6 = 1、すなわち
Q ∈ Z[t_1..t_4] は対称かつ斉次一次。斉次一次の対称多項式のなす Z-加群は
Σt_i が張る階数1の自由加群なので、ある c ∈ Z で Q = c·(Σt_i)。

(iii) **係数比較**: 単項式 m = t_1^0 t_2^1 t_3^2 t_4^4 を考える。

- D における m の係数: D の展開項は置換 σ に対し sgn(σ)·∏_i t_i^(d_{σ(i)})。
  m の指数ベクトル (0,1,2,4) は四成分が相異なるので、d_{σ(i)} が t_i の
  指数に一致するには σ は一意(σ=id)に定まり、符号 +1。よって係数 1。
- (Σt)·V における m の係数: V = Σ_σ sgn(σ)∏_i t_i^(σ(i)−1) の各単項式の
  指数の多重集合は必ず {0,1,2,3} である。t_k を掛けて m になるには
  m−e_k の指数多重集合が {0,1,2,3} でなければならず、これは k=4 のとき
  のみ ((0,1,2,3) になる)。k=1,2,3 では負の指数が現れ不可能。
  m−e_4 = (0,1,2,3) の V における係数は σ=id の +1。よって係数 1。

両者とも 1 なので c = 1。□

**注意(重要)**: (B) は**整数多項式としての**恒等式である。すなわち
パラメータ t_i をそのまま整数として代入した行列式についての等式であり、
mod p で使うときは「t_i は 0..p−1 の整数代表、y 座標は t_i² mod p」という
**代表の取り方**を経由する。次項でその点を明示する。

### 2.3 系C(Q_p 上の合同式)

p を奇素数、q={t_1,t_2,t_3,t_4} ⊂ {0,...,p−1} を相異なる四点とし、
P_{t_k} = (x_k,y_k) = (t_k, t_k² mod p) を整数点とみなす。このとき

    D_cyc(q) ≡ −(t_1+t_2+t_3+t_4)·∏_{i<j}(t_j−t_i)  (mod p).        (C)

**証明.** p を法として y_k ≡ t_k² だから、D_cyc の第 k 行は mod p で

    (t_k²+t_k⁴, t_k, t_k², 1)

に等しい。よって D_cyc mod p は、行 (t²+t⁴, t, t², 1) の 4×4 行列式 A_p に等しい。
列変形 c1 ← c1 − c3 (det 不変)で A_p は行 (t⁴,t,t²,1) の行列式 B_p になる。
B_p の列の次数は (4,1,2,0) で、これを昇順 (0,1,2,4) に並べ替える置換は
位置1と位置4の互換だから符号 −1。したがって

    det B_p = −det[t^0,t^1,t^2,t^4] = −(Σt)·V   (定理B)。

最後に V の値は mod p で不変(p−1 次以下の整数の積)。□

**系C1(必要方向 = (P1)).** q が禁止四点ならば Σ_{k} t_k ≡ 0 (mod p)。

**証明.** 系A1 より D_cyc(q) = 0(整数)。系C より
(Σt)·V ≡ 0 (mod p)。各因子 t_j−t_i は 0 でない整数で |t_j−t_i| < p だから
p ∤ (t_j−t_i)。p は素数なので p ∤ V。よって Σt ≡ 0 (mod p)。□

これが W10 補題2 規則 (ii) が使う主張そのものである。
定理B の (iii) で係数比較に現れた m = t_1^0t_2^1t_3^2t_4^4 が、
「パラメータ和」が**どこから**現れるかを示している: 交代性だけでは商が
スカラー倍 c·V までしか決まらず、次数 7−6 = 1 の対称多項式が
一次の対称式(和)しかないこと、そして最高次の単項式の係数が 1 であることが
c=1 を与える。和は**次数差 1 の対称商**として現れる。

### 2.4 文3(原始整数方程式の t³ 係数)による別証明 = (P5)

系C1 の別ルートとして、K0334 文3 の議論を厳密化する。

q が禁止四点で、同一円上にある場合を考える(共線の場合は下記)。
円の原始整数方程式 A(x²+y²)+Bx+Cy+D=0, gcd(A,B,C,D)=1 を取る。
mod p で y≡t² を代入すると

    H(t) = A t⁴ + C t² + B t + D  (mod p)

が四つの相異なる根 t_k を持つ。H が零多項式でないことを示す:
H の係数がすべて 0 mod p なら p | A,B,C,D で原始性に反する。
よって H は非零で、その次数は 4 以下。根の個数(4)が次数を超えないので
deg H = 4、すなわち A ≢ 0 (mod p)。このとき H の t³ 係数は 0 なので、
四次多項式の根の和 = −(t³係数)/(t⁴係数) = 0、すなわち Σt ≡ 0 (mod p)。□

共線の場合: 直線 Bx+Cy+D=0 (gcd(B,C,D)=1)を mod p で代入すると
deg ≤ 2 の非零多項式が四つの根を持ち矛盾。よって Q_p に四共線点は存在しない
(これは K0333 の直線上限 k=2 の特殊化でもある)。

**この別証明の限界**: A ≢ 0 mod p の議論で原始性(整数)と「p が素数」を
使うため、円が存在しない共線ケースを切り分ける必要がある。
系A1→系C の道は場合分けが不要で、しかも `forbidden_edges.cpp` が実際に
計算している量(det)と直接対応するので、本 log の主証明はそちらを採る。

### 2.5 系D(完全対を含む禁止四点 = (P2))

q が禁止四点で {i,p−i} ⊂ q (1 ≤ i ≤ h)とする。残る二点を j,k とすると
系C1 より j+k ≡ −(i + (p−i)) = −p ≡ 0 (mod p)。

まず 0 ∉ q: もし q = {0,i,p−i,k} なら Σt ≡ k で、系C1 より k≡0、
k=0 となって相異性に反する。よって j,k ∈ {1,...,p−1} かつ j≠k。
j+k ≡ 0 かつ 0 < j,k < p より k = p−j。すなわち q = {i,p−i,j,p−j} で
二完全対である。□

これは W10 補題2 規則 (ii) の「残る2パラメータは k=p−j」の正当化であり、
同時に「0 を含む形は禁止四点になり得ない」という W10 の括弧書きも与える。

### 2.6 系E(二完全対は必ず禁止 = (P3))

1 ≤ i < j ≤ h に対し q = {i, p−i, j, p−j} を考える。整数点は

    (i, y_i), (p−i, y_i), (j, y_j), (p−j, y_j),   y_t = t² mod p。

**相異性**: y_i = y_j なら i²≡j² (mod p) より i≡±j。i,j ∈ [1,h] と i≠j から
i = p−j は起こらず(両方 h 以下なら和は p 未満)、i=j に矛盾。
よって y_i ≠ y_j、特に四点は相異なり、二本の水平線分(高さ y_i, y_j)を持つ
**等脚台形**である。x 座標の対称性から、四点は直線 x = p/2 に関して
対称である。

**共円性**: 二線分の中点は (p/2, y_i), (p/2, y_j)。中心を (p/2, c) と置くと
中心条件は

    (p/2−i)² + (c−y_i)² = (p/2−j)² + (c−y_j)²,

c について一次で、y_i≠y_j なので一意に実解 c を持つ。この c と半径で定まる
実円が四点を通る。よって q は禁止四点。□

**個数**: 対 i (1 ≤ i ≤ h)から2つ選ぶ組は C(h,2) 通りで、系D より完全対を含む
禁止四点は必ず二完全対だから、この種の辺の総数はちょうど C(h,2)。□

これが K0334 文6 の主張であり、**逆向き**(二完全対 ⇒ 禁止)を含む。
W10 §1.7 前提(1)(辺リストの完全性)の会計はこの数を必要とする。

### 2.7 系F(残る辺の構造 = (P4))

q が禁止四点で完全対を一つも含まないとする。系C1 より Σt≡0。
各 t について、t と p−t の両方が q に入ることはない(入れば完全対)。
0 ∈ q のとき: q = {0,a,b,c} で a+b+c≡0。もし a+b≡0 なら c≡0 で c=0、
相異性に反する。同様に任意の二つの和は 0 でない。よって a,b,c は
互いに異なる三つの対の一側ずつである。
0 ∉ q のとき: q = {a,b,c,d} で、どの二つも和が 0 でないので
四つの異なる対の一側ずつである。□

以上で K0334 本文の文2,3,5,6,7 の主張すべてに証明が付いた。

### 4.3 生成器の完全性(= 前提(1))——予告への決着

第3部末尾で「生成器の完全性の論理は本証明で閉じる」と予告した。
**結論: 予告どおり閉じる。ただし閉じるのは列挙アルゴリズムの論理であり、
実行の真正性は別の信頼境界として残る。**

`research/experiments/frontier-geometry-2026-10-05/forbidden_edges.cpp` の
`main` は、`i<j<k` を全走査し `l = (−(i+j+k)) mod p` を計算して
`l>k && det({i,j,k,l})==0` の行だけを出力する。この出力集合が全禁止四点
集合に一致することを、次の4点で示す。

1. **健全性(出力 ⊆ 禁止)**: 出力条件は整数 `det()==0`。補題A によりこの
   3×3 式は `D_cyc` に一致し、系A1 により `det=0 ⟺ 同一円または同一直線`。
   よって出力行の四点は禁止四点である。
2. **完全性(禁止 ⊆ 出力)**: q={t_1<t_2<t_3<t_4} が禁止四点なら系C1 より
   Σt ≡ 0。ゆえに `t_4 ≡ −(t_1+t_2+t_3) (mod p)`。`t_4` は 0..p−1 の
   一意な代表だから、ループ変数 (i,j,k)=(t_1,t_2,t_3) のときの `l` の計算値は
   `t_4` に一致し、`l > k` が成り立つ。ループは i<j<k を尽くすので、
   この行は必ず出力される。
3. **重複なし(全単射)**: 同一の 4-set の他の三つ組から得られる `l` は
   それぞれ `t_3, t_2, t_1` で、いずれも `k` より小さいため `l>k` を満たさない。
   よって 4-set と出力行は一対一。総数 928,389 は行数の意味でも重複を含まない。
4. **計算の完全性**: `y[i] = i*i % p` は Q_p の定義と一致。`det()` は
   `__int128_t` で評価され、入力検査 `p <= 100000` により座標と行列式の
   各中間積はその型の範囲に収まる(桁溢れなし)。よって `det` は厳密整数で
   評価され、浮動小数や剰余による丸めが入らない。

2 の一意性は K0334 文4「三点に対する禁止第四点は高々一つ」と同じ内容で
あり、これも系C1 の系として閉じる。4.1 の (P1) が、単に和条件を与える
だけでなく**第四点の一意性**を与えることが、生成器の `l` による絞り込みの
正当化そのものである。

したがって W10 前提(1)(辺リストの完全性)は「証明済み」へ格上げできる。
UNSAT 側が依拠する「辺の欠落がない」ことと、SAT 側の `safe_against_edges`
が依拠する「同一リストに基づく検査」の両方が、同じ論理で閉じる。

**予告との差分(明記)**: 閉じるのは**アルゴリズムの論理**であって、実行の
真正性ではない。残るのは次の3点で、いずれも数学的欠落ではない。

- (a) 走らせたバイナリが読んだソース(上記1ファイル)と同一であること。
- (b) `edges2647.txt` が 928,389 行であるという記録の真正性。
- (c) p=2647 での独立再列挙は行っていない。3.3 の
  「928,389 = C(h,2) + 53,886」の一致は (a)(b) を前提とした整合検査で
  あって、証明の一部ではない。完全性は 2 の論理で置き換えたため (c) は
