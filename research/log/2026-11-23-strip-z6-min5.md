- K1273 run log の見取りに「G6 のみ s>=6 で分解依存が残る」とあったが、K1273 出版

  D6(s)=v(s+4,6,11)**（deviant ゼロ・分解依存ゼロ）を探査で発見。梯子史上初の完全
  崩壊セル。床が本質で、Y=(4,) の (4,4)@R=11（出版前線 witness・親2 vs 単一1）が反例。
- 底 m=5 は H(12;X;6)。全 A手子の値が 1（ mex が 0 = 単一側）になる自明吸収構造
  （z=5 の m=4 底の「deviant の mex 吸収」と対照的）を確認。
