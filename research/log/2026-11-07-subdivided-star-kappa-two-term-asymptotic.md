# 2026-11-07 一辺細分星の切替閾値の二項漸近律

- 対象: `κ(r)`（終局長差多項式 `T_{k,r}` が奇数 `k` で初めて実根をもつ次数、K0677）。
  前回の `Θ(r log r)` 評価を先頭2項と定数まで精密化した。
- 方法: `M(k) = a^{k+1}k^k/(k+1)^{k+1}`（`a=1+1/(r+1)`）の両側対数評価
  `(k+1)/(r+1) - (k+1)/(2(r+1)^2) - ln(k+1) - 1 < ln M < (k+1)/(r+1) - ln(k+1) - 1 + 1/(2k)`
  を、`0<t<=1` の `t-t^2/2 < ln(1+t) < t` と `1-1/(2k) < k ln(1+1/k) < 1` から導いた。
  `Φ(k) = (k+1)/(r+1) - ln(k+1) - 1 - ln r` は `k = 2r ln r + r ln ln r + c r` で `c-(1+ln2)+o(1)` になる。
  したがって `c > 1+ln2` で2根、`c < 1+ln2` で根なしが十分大きい `r` で成り立ち、閾値が挟まれる。
- 結果: `κ(r) = 2r ln r + r ln ln r + (1+ln 2)r + o(r)`、特に `κ(r)/(r ln r) → 2`。
- 数値: 既存の厳密表 `r=2..1000`（サンプル再計算一致）に `κ(3000)=60,057`、`κ(10000)=225,393` を追加。
  比 `κ/(r ln r)` は 5.23 (r=4) → 2.565 (r=997) → 2.500 (r=3000) → 2.447 (r=10000)。
  残差率 `δ/r`（`δ=κ-(2r ln r+r ln ln r+(1+ln2)r)`）は 2.458 (4) → 0.519 (100) → 0.274 (1000) → 0.205 (10000) で、
  補正 `ln(1+(\ln\ln r+O(1))/(2\ln r))` の予測 0.202 (r=10^4) と整合。
- 検証: `r=3000,10^4` で `k=floor(2r ln r+r ln ln r+1.2r)` の根なしと `floor(...+2.5r)` の2根を厳密証明。
  両側評価は50桁 decimal で20点の内側性を監査（証明ではなく実装監査）。
- 限界: `o(r)` 項の明示評価は未証明。`κ` は離散関数のため残差率は単調でない（局所揺れあり）。
- 次: `o(r)` 項（予測 `r ln ln r/(2 ln r)` 型）の明示評価、`q=4` への応用、他構成の閾値への同型の漸近解析。
