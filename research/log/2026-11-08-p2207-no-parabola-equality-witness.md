# 2026-11-08 p=2207 で剰余放物線の等号証人が存在しない（反例候補）

- 対象: `Q_p = {(t, t² mod p)}` の安全最大 `A(p)`、等号 `A(p)=(p+3)/2`（K0097 / 未解決 K0101）。
- 発端: 2026-11-07 に 2003..2477 の 64 素数のうち 63 で等号証人を保存したが、**2207 だけ証人が出なかった**。
  深い d を走査した結果、**d=1..1103 の全 d で CNF が UNSAT** となった。
- 論理: サイズ `h+2` の安全集合は「`0` ＋ちょうど一つの完全対 `{d,p-d}` ＋他の各対の一側」に限られる
  （二完全対は等脚台形で共円、完全対なしでは `|S|<=h+1`）。K0334 が等号を `d` ごとの
  signed NAE3/4＋原点節 CNF の充足可能性と全奇素数で同値に還元しているので、
  全 d の UNSAT は `A(2207) <= 1104 < 1105` を意味する。
- 証拠:
  - `output/p2207_d_verdicts.json`: 全 1103 d の判定（UNSAT 1103・SAT 0・不明 0）と出所。
    d=1..288 はマルチプロセス版（衝突予算 200k, unknown 0）、d=289..1103 は cadical ログ
    （タイムアウト 4 件は衝突予算 2000 万で再判定）。
  - 別ソルバ: Glucose4 と Minisat22 が d=1,289,550,1103 で UNSAT。
  - 実装の全数照合: p=5,7,11,13,17,19,23 で Q_p の全安全集合（サイズ `(p+3)/2`）を列挙し、
    完全対 d の集合と CNF の SAT/UNSAT を全 d で比較して 7 素数すべて一致
    （p=23: 安全集合 8,064 個、d 集合は両者 {1..11}）。
  - 同一実装は隣接 63 素数で SAT 側の証人を作り、独立 4×4 検証器で共円 0 件を確認済み。
- 信頼境界: **UNSAT の DRAT 証明は未取得・未検査**。したがって status は `needs-review`（K0693）とし、
  K0101 は open のまま。cadical は DRAT を出力できるため、証明生成と独立検査が次の監査段階。
- 含意: 「全奇素数で等号」は p=2207 で否定される見込み。p=2207 が最初の反例候補であり、
  `A(2207)` の正確な値（1104 か、それ未満か）と、他の反例素数の分布は未確定。
