## 教訓・備考

- 環境障害越えのレジューム手順（中断実行が README に残す方式）が初めて機能した:
  「CNF 再生成 → 既存インスタンス較正再実行（bit-exact 確認）→ 残りを実行 →
  バッチ即 push」の順で、中断前証拠（29ログ）を1バイトも損失なく再利用。

  24−x5 ≤ 11）で k=5 分解は再び13点×2クラス。deciding 合計が漸減傾向を維持
  していれば 5×26 は本レーンの実用範囲内（見込み ~13M conflicts）。
