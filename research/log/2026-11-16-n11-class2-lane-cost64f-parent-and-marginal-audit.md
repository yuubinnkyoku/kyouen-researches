# 2026-11-16: cost-64f の親対応修正と三証明書の限界被覆監査

## 親の取り違えを修正

head 1435 の次候補調査スクリプト `next_target_presweep_head1435_v2_20261116.py` に、親ラベルを誤る箇所があった。`best_open_rows` を作る際、既に親情報を失った候補一覧を、二つのプロトコル親それぞれに再度結び付けていた。そのため、機械可読な `cheapest_open_rows_ranking` の先頭12行がすべて `00000000000000403800000008000000` の行として表示されていた。

候補選定そのものは壊れていない。推薦文は行が実際に属する親を別途照合しており、選ばれた6石局面は一貫して次のものだった。

`0000000000000080120a000000800000`

ただし、その直接のプロトコル親は共有側の

`00000000000000003800000008002000`

であり、従来の `s5_target` に記録されていた `00000000000000403800000008000000` ではない。後者は二親プロトコルの比較用の基準親で、この6石局面の直接の親ではなかった。

修正では `(parent, row)` の組を保ったまま並べ替える。さらに174個のS5親を全件走査し、6石局面から石を一つずつ除いた六つの5石部分集合をD4正準化して照合した。直接の親は次の二つだけで、どちらもclass-2マスクだった。

- `00000000000000003800000008002000`（head 1435で31行・辺費用2145）
- `0000000000000080120a000000000000`（43行・辺費用3167）

誤って記録されていた比較用親はこの集合に含まれない。候補順位表、claim、証明書manifestの親情報を訂正し、元のv2 blob SHAも残した。証明書本体のバイト列と各検証結果は変更していない。

## 三つのWIN7-D10証明書が閉じる行

cost-64fの3本（追加位置bit 39・72・107）について、head 1410 の残存6石一覧6438行を基準に、7石根から石を一つ除く全7通りを独立にD4正準化した。cost-65jの9行とcost-64dの16行を先に除外すると、新たに閉じる6石行は3行だった。

| 証明書 | 既存manifestに対する新規閉鎖 |
|---|---:|
| bit 39 | 1行（対象の6石局面） |
| bit 72 | 0行（bit 39と同じ行を覆う） |
| bit 107 | 2行（対象行に加えて別の2行） |
| **合計** | **3行** |

新規行の費用合計は194。これらは5個のS5親にまたがる7親行対応を持つ。親ごとの辺費用減少の合計は455で、同じ6石行が複数のS5親に属するため、固有行の費用減少194とは一致しない。5親はいずれも残存行が正で、S5親の個数は174のまま。

## 独立再構成と折り込み予測

独立BigInt実装で、既存のhead 1410→1419→1435を再構成した。6438行すべてのD4正準形と親数を確認し、head 1435の174親について残存行数・辺費用を全件照合した。cost-64fの3根はhead-1435の事前判定表でいずれも `open`。同表の757既存receipt根（743正準形）と4182 verdict正準形に対する衝突は認められず、既存harvestのWIN/REFUTED矛盾も0件だった。

| 指標 | 現在の確定head 1435 | 三証明書適用後の予測 |
|---|---:|---:|
| manifest閉鎖済み6石行 | 1,435 | 1,438 |
| 残存S5親 | 174 | 174 |
| 固有の残存S6行 | 6,413 | 6,410 |
| 固有行の候補辺費用合計 | 507,337 | 507,143 |
| open classが必要とするS6行 | 4,686 | 4,683 |
| その候補辺費用合計 | 371,251 | 371,057 |

需要指標は `c1=0 && c2+c4>=1` の行を数える。S5の `classes` はclass番号そのものではなく `{1,2,4}` のビットマスクとして扱った。

これは折り込みの予測であり、正準headの更新ではない。全チェーンの再実行と既存receiptとの完全な矛盾検査を行うまで、正準headは1435のままとする。今回の監査は証明書ファイル本体を再パースしたものではなく、公開manifestの根・被覆・既存BigInt/Bareiss検証記録を照合したもの。
