## §1 主張

**T-BB (universal)**: 座標は K1285/K1308/K1311 と同一。H(R; X; z), X 降順 (x1 ≥ … ≥ xn ≥ 1), S := ΣX, k := R−S, E := x1 − (x2+…+xn) = 2x1 − S。全 n ≥ 2、全 z ≥ 0、全降順多重集合 X について、**下帯頂行** k := z+n−3 (n≥2 で k≥−1、R = S+k ≥ 1) で:

```
u := E + z + n − 4
u ≥ 1      →  H = [E odd]      (python 偶奇、E の負も含む)
u = 0      →  H = 2
u ≤ −1     →  H = 1 − [E odd]
```

(i) 値は座標 (E, z) のみで決まり、個々の山の値に依存しない (単一座標崩壊。公刊 K1311 T-DB (境界行 k=z+n−2) の下帯版)。
(ii) n ≥ 3 では E は下に非有界 (例: X=(a,…,a) で E=−a→−∞)。ゆえに値 2 の線は E+z = 4−n、flip 領域は E+z ≤ 3−n で、いずれも無限半直線である。n=2 では E ≥ 0 制約 (E = x1−x2) によりこれらは 6 個の例外セル (E,z) ∈ {(2,0),(1,1),(0,2),(1,0),(0,1),(0,0)} に縮退する (最後の 6 番目は壁行 z=0, k=−1)。
(iii) n=2 への帰結として、公刊 K1310 の定数を系として再現する: 合同窓の縁 (a,a) (=E=0) で z≥3 → 0 / z=2 → 2 / z=1 → 1 (T-NCW-B bed 定数)、および非合同窓 k=z−1, z≥2 の T-NCW-P g*≤0 極 (g* = 2−z ≤ 0) の値 [g odd]。
(iv) **意味**: 公刊 T-CSUM (k ≥ z+n−1, K1312) と公刊 T-DB (k=z+n−2, K1311) と本 T-BB を合わせると、全 n≥2 の n 山面で k ≥ z+n−3 の全行が確定する。K1311 が登録した O-BBL (下帯 k ≤ z+n−3) は頂行が閉じ、残る open は k ≤ z+n−4 のみに縮小する (§5 O-BBL2)。
(v) K1311 OBS-BBL 凍結観測 (triples k=z 行、naive 両法則との不一致数 (80,80,68)→(80,0,0)) は本定理で完全に説明される: 機体 D9 が凍結表 7 行の完全再現と同一ドメインでの T-BB 不一致 0 を確認済み (宣言前探索 X9 と本機体合同)。

**L-BR1 (base lemma, 公刊 K0832 単一トークン閉形式のスライス)**: 全 x ≥ 1, Z ≥ 1 について v(x, Z, x+Z−2) = PB1(x,Z)、t := x+Z−3 として t ≥ 1 → [x odd] / t = 0 → 2 / t ≤ −1 → 1−[x odd]。証明側で n=2 の B 系承継子 (単一トークン、plane Z=z+1 ≥ 1、行 k=Z−2) を評価するのに使う。

**Typed 子恒等式 (全 n≥2・行 k=z+n−3 の全オプション)**: 各オプションは次のちょうどいずれかで、子はすべて除算 R−1 を持つ:
- (A-a) unique-top 縮小 x1 ≥ 2, x1 > x2 → 子 (n, z, k, E−1)
- (A-b) tied-top / tail 縮小 → 子 (n, z, k, E+1)
- (B) 1-heap 除去 → 子 (n−1, plane z+1, 同 k, E+1); n=2 の承継子は単一トークン (L-BR1 域)、n≥3 は (n−1) 面の行セル (k = (z+1)+(n−1)−3 ✓)
- (C) z ≥ 1 → オプション値 1 XOR 子値、子 (n, z−1, k−1, E)

## §2 手証明

### 2.1 L-BR1 (公刊閉形式からの直導)

公刊 K0832 単一トークン閉形式を R = x+Z−2 で切る。
- **Z ≥ x+1**: m = q_odd(x) ≤ x < x+Z−2 = R、例外は (x,Z)=(1,2) のみ (R=1=m は奇 → 2 = t=0 枝 ✓ t = x+Z−3 = 0)。他は R > m → x%2。t = x+Z−3 ≥ x−1: x≥2 → t≥1 → [x odd] ✓、x=1, Z≥3 → t ≥ 1 → 1 ✓。
- **Z = x**: R = 2x−2。x 偶: m = x−1 < R → x%2 = 0、t = 2x−3 ≥ 1 → [x odd] = 0 ✓。x 奇 ≥ 3: m = x < R → 1 ✓。x=1, Z=1: R=0 → 0 (閉形式 R=0 枝)、t = −1 → 1−[1 odd] = 0 ✓。
- **1 ≤ Z ≤ x−1**: m = q_odd(Z)。R−m = x+Z−2−q_odd(Z) ≥ x−1 ≥ 0、等号は (x,Z)=(2,1) のみ (R=m=1 奇 → 2 = t=0 枝 ✓ t = 0)。他は m < R < x+z 枝 → (R+z)%2 = (x+2Z−2)%2 = x%2、t = x+Z−3 ≥ 1 (x+Z=3 の (2,1) は t=0 枝で処理済み、(1,2) は本域外) → [x odd] ✓。本スライスに t ≤ −1 セルは存在しない。
4 枝すべて PB1(x,Z) と一致 ∎

### 2.2 Typed 子とその値

ρ := [E odd] とおく。子の (E',z',n') に対する子の u 座標を計算する (要点: A-a は u−1、A-b は u+1、B は u+1、C は u−1)。
- v(A-a) = PB(n, E−1, z) at u−1, 偶奇 [E−1 odd] = 1−ρ: 値は u≥2 → 1−ρ / u=1 → 2 / u≤0 → ρ。
- v(A-b) = PB(n, E+1, z) at u+1, 偶奇 [E+1 odd] = 1−ρ: 値は u≥0 → 1−ρ / u=−1 → 2 / u≤−2 → ρ。
- v(B) = PB(n−1, E+1, z+1) at u_B = (E+1)+(z+1)+(n−1)−4 = u+1, 偶奇 1−ρ: 値は u≥0 → 1−ρ / u=−1 → 2 / u≤−2 → ρ。n=2 の場合は L-BR1: t = x+(z+1)−3 = (E+1)+(z+1)−3 − 1 = u+... t = u+1 (x = (S+E)/2 = (x2+1+... n=2: X=(x1,1), E = 2x1−(x1+1) = x1−1 より x1 = E+1): PB1(E+1, z+1) の t = (E+1)+(z+1)−3 = E+z−1 = u+1 (n=2 は u = E+z−2)。ゆえに u≥0 → [x1 odd] = 1−ρ / u=−1 → 2 / u≤−2 → ρ — n≥3 の式と完全に一致 (L-BR1 が n=2 の B 承継に対して PB の u-代数をそのまま継承する)
- v(C) = 1 XOR PB(n, E, z−1) at u−1, 同偶奇 ρ: u≥2 → 1 XOR ρ = 1−ρ / u=1 → 1 XOR 2 = 3 / u≤0 → 1 XOR (1−ρ) = ρ。z=0 では C は存在しない。

**存在補題**: (i) n ≥ 2 なら (A-b ∨ B) は常に存在する (tail の最大値 v≥2 なら A-b、非頂行がすべて 1 なら (その 1 を除く B が存在)。すべて 1 でも B ✓)。厳密には: x2 ≤ 1 なら B (x2=1), x2 ≥ 2 なら A-b。(ii) tied (x2 = x1) ⟹ E = 2x1−S ≤ 2−n。(iii) E ≥ 3−n ⟹ unique top かつ A-a が存在 (x1 = (S+E)/2 ≥ (n+3−n)/2 = 3/2 → x1 ≥ 2、tied なら (ii) で矛盾)。

### 2.3 区域 mex 代数 (行全域、6 区域。各区域で opts の包含と存在要求を閉じる)

- **U1 (u ≥ 2), c = ρ**: 全子値 1−ρ。(i) より非空 → opts = {1−ρ} → mex = ρ ✓
- **U2 (u = 1), c = ρ**: opts ⊇ {1−ρ} (i), opts ⊆ {2 (A-a), 1−ρ, 3 (C)}。ρ=1 → 1−ρ=0 ∈ opts、opts ⊆ {0,2,3} → mex = 1 = ρ ✓; ρ=0 → 1−ρ=1 ∈ opts、opts ⊆ {1,2,3} → mex = 0 = ρ ✓
- **H (u = 0), c = 2**: v(A-a)=ρ, v(A-b)=v(B)=1−ρ, v(C)=ρ → opts ⊆ {ρ, 1−ρ} = {0,1}、非空 (i) → mex = 2 ✓ (存在要求なし)
- **I1 (u = −1), c = 1−ρ**: v(A-a)=ρ, v(A-b)=v(B)=2, v(C)=ρ → opts ⊆ {2, ρ}。2 は常に在 (i)。ρ の存在: z ≥ 1 → C; z=0 → E = 3−n で (iii) より A-a。opts = {2, ρ} → mex = 1−ρ (ρ=1 → mex{1,2}=0 ✓; ρ=0 → mex{0,2}=1 ✓)
- **I2 (u ≤ −2), c = 1−ρ**: 全子値 ρ (A-a: u−1≤−3, A-b/B: u+1≤−1, C: 1 XOR (1−ρ)) → opts = {ρ} 非空 (i) → mex = 1−ρ ✓
- **z=0 の補足**: U1/U2/H/I2 は C 欠落で影響なし。H の z=0 は E = 4−n ≥ 3−n → (iii) A-a ✓ (x1 ≥ 2)。I1 の z=0 は E = 3−n → (iii) ✓ (x1 ≥ 2)。n=2 の壁行 (z=0, k=−1) も行パケットに含まれ全区域で直ちに閉じる。

### 2.4 帰納 (単一 R 強帰納)

全 (n≥2, z≥0, X) の行セルを予算 R = S+z+n−3 について一括の強帰納とする。基底 R=1: 行セルで最小は (n=2, X=(1,1), z=0, k=−1): PB(2,0,0): u=−2 → 1; 直接計算 H(1;(1,1);0) = mex{0} = 1 ✓ (唯一のオプションは 1-heap 除去 → (1,) at plane 1, R=0 → 0)。n≥3 は R ≥ 3。帰納段: 2.2 の全子は行セル (A/B/C 方向、B は (n−1) 面) または n=2 の単一トークン承継 (L-BR1 → K0832 公刊閉形式、公刊済み・再証明不要) で、いずれも予算 R−1。2.3 の mex が各区域で claim を返す ∎

**T-BB 証明終**。注意: 帰納は単一 (R を横断する全行セル) で閉じる (K1311 T-DB が外側 n 帰納を要したのに対し、本定理では B 承継も含めて全子が R−1 に落ちるため)。

### 2.5 n=2 への縮退と公刊系 (検証・主張の関係)

n=2 では E = g = x1−x2 ≥ 0。(iii): 合同縁 (a,a) の bed 定数 z≥3 → u = z−2 ≥ 1 → [0 odd] = 0 / z=2 → u=0 → 2 / z=1 → u=−1 → 1−0 = 1 (K1310 T-NCW-B の再現・K1312 D7 と同一系の独立再導出)。非合同 k=z−1, z≥2: g ≥ 1 → u = g+z−2 ≥ 1 → [g odd] (K1310 T-NCW-P g*≤0 極の再現: g* = z−2k = 2−z ≤ 0)。壁行 (z=0, k=−1) は本包の新ドメイン (K1303 band の下の行として新規に閉じた)。機体 D4/D7 がこれらの合同性を数値で確認する。

## §5 open 登録

1. **O-BBL2 (新 open)**: 下帯の未確定層は **k ≤ z+n−4** に縮小。真の法則の形 (単一座標 (E,z) 崩壊がどこまで下に貫くか、2 の線と flip 領域の幾何、tail 側との接続) は未確定。OBS-BBL watershed は頂行で完全説明済みとなったため、観測関心は k=z−1 (=z+n−4, n=3) 行以下に移る。
2. **O-DB2 (接続更新)**: K1311 が登録した「B-move n−1 子が plane z+1 境界行に着地することの逆読みによる下帯 typing」は、本定理で B 承継が (n−1) 面の**頂行** (plane z+1, 同 k) に着地することが確定したため、逆方向の工具としてそのまま使える: 下帯深層 k ≤ z+n−4 の解析は plane z+1 の (n−1) 面頂行値 (T-BB 既知) からボトムアップで始められる。次回候補: 「k=z+n−4 行の (E,z) 座標崩壊の有無」を X2 型 census で最初に判定すること。
3. K0832 conjecture A (j=0)・C (j=1) は下帯 (k=z−1, k=z の n=3 行) にあり、conjecture C に該当する (n=3, k=z+1−3+2 = z … n=3 の頂行は k=z、これは今回閉じた; 残るは j=0 行)。正確には: K0832 conjectures A/C は n=3 の k=z−1, k=z に関するもの — **k=z (頂行, 本次)** は T-BB で閉じたため conjecture C が n=3 で解決した可能性がある。k=z の三重項値は PB(3, E, z): conjecture C の主張値との照合は次回しらみつぶしの高優先課題 (§6 記録、今回は主張_regex なし)。
