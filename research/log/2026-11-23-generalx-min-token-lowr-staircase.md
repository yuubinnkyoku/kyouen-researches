# 研究log: 一般X低Rミントークン階段定理（2026-11-23、K1264）

## 発見の経緯

本レーンの前段（宣言前探査・次回実行でも参照できるようここに正直に記録する）:

1. 2トークン (x,y) の低R一致領域の最初の破綻位置を系統掃引したところ、
   破綻が常に R=z+min(X)+1 と きわめて精密に相関する「階段」構造が見えた
   （y=1..7 で破壊高さ z+y+1、発見時は意味不明のオフセット 2..8 の階段）。
2. min(X)>=2 の場合、帰納子の「窓予算」R-1<=z+min(child)-1 が親の仮定
   R<=z+min と丁度噛み合うことに気づき、min=1 の B子（1トークン除去で
   z+1 に行く）以外は選択肢集合が完全一致する公理的帰納が立ちそうだと
   なった（アリティ自由）。
3. 残る障害を T1（混合）/T2（全1）の mex 恒等式に整理して機械検証した
   ところ（σ<=96/z<=45 bad 0）、実は **B子値≡A子値**（=補題Z）が全Gridで
   成り立っていることが判明した。閉形式帯表どころではなく mex 恒等式すら
   不要で、「単一トークン残余の z-shift 不変性 v(x,z+1,n)=v(x,z,n) (n<=z)」
   というたった一本の補題が証明の全解析的成分であることがわかった。
4. 補題Z自身も n についての純構造帰納で証明できる（子の組が補題Z自身の
   インスタンスで一致）。これで定理は完全に閉形式フリーになった。

## 証明

report.md 本文: 補題E（空残余0）→ 補題Z（z-shift不変性）→ 主定理
（R強帰納: min>=2リフト は選択肢集合完全一致、min=1基底は B子値が補題Zで
A子値に一致）。全称・アリティ自由・閉形式不使用。
