## 2. 前提の確認（客観量の不変性: 構造仮説の前提の排除）

仮説立ての前に、エンコーディング側の自明な説明を潰した。禁止四点は
`frontier-geometry-2026-10-05/forbidden_edges.cpp` の生成で、y=x² 上の4点
t1<t2<t3<t4、和 ≡ 0 (mod p)、円条件（Vandermonde 行列式 = 0）をすべて満たす組。
K0096 により和≡0 と円条件はほぼ同値。

**H0（棄却）: 「B_d を固定すると伝播だけで矛盾する」ローカル構造仮説。**
B_d の仮定は点 d, p−d を選択に入れる。unit propagation だけの手続き的矛盾は、
d と p−d を同時に含む節が-Clause DBに存在する場合にしか起こらない。
しかし d + (p−d) ≡ 0 なので、残る2点 a+b≡0 → 点集合は {d, p−d, a, p−a} → a と p−a は
同一pair → `search_shape_class.py` build() L69（`len(set(pairs)) < len(pairs)` でskip）
により節は生成されない。よって「d を固定した瞬間に禁止四点だけで決まる矛盾」は
**どの d でも起こり得ない**。実際、d=1 が 0.001–0.1 秒ではなく約 0.1–1 秒Resolverに
かかっていることも、純propagation（マイクロ秒）ではなく短い探索であることを裏付ける。
H0 は解析的に棄却。

**H'0（棄却）: 「d ごとの制約密度（d を含む禁止四点数）が d で変わる」仮説。**
d の片側 ±d の点を含むクラス相異なる triple {u<v<w}（符号込みで ±d ±u ±v ±w ≡ 0、
または 0 などの原点を含む四点も同様）を数えた。実装: /tmp/w9/deg3.py, deg5.py
（純Python、各d約3.5–7秒、UNSAT 19件＋UNKランダム30件）。結果:
**すべての d でちょうど 2,324,960**（min=max=median、sd=0）。Symmetric な和集合として、
和≡0 の四点の個数は符号の全割当で d に依らず厳密一定。したがって「d の違いによる
一次制約密度の差」はこの符号化レベルでは存在せず、H'0 棄却（より高次の相互作用
（組合せ分散）までは排除していない [INFERENCE]）。

## 3. 仮説（残留する算術的条件群）

H'0 の定数性により、群 Ball-and-chain 交互作用に依らない一次量は消え、残るのは
「具体的な四点の microstructure」。算数の候補を列挙的に数えた。標本は
UNSAT 19件 vs UNKNOWN 454件（超幾何検定、両側でなく上側 P(X≥k)）。

### H1: d ≡ 4 (mod 7)

| 条件 | UNSAT充足 | UNKNOWN充足 | 上側p |
|---|---:|---:|---:|
| d≡4 (mod 7) | 10/19 | 58/454 | **6.4×10⁻⁵** |
| d≡2 (mod 3) | 13/19 | 145/454 | 1.6×10⁻³ |
| d≡5 (mod 9) | 9/19 | 44/454 | **5.5×10⁻⁵** |
| H1∪H2（上2条件のOR） | 13/19 | 190/454 | 2.0×10⁻² |
| (d/7)=+1 | 12/19 | 192/454 | 0.060 |
| (d/p)=+1 | 9/19 | 235/454 | 0.73 |
| (d/p)=−1 | 10/19 | 219/454 | 0.44 |
| gcd(d, p−1)>1 | 11/19 | 327/454 | 0.94 |
| gcd(d, h=1323)>1 | 5/19 | 197/454 | 0.96 |
| 7 \| d | 3/19 | 64/454 | 0.52 |

（数えたスクリプト: /tmp/w9/resid.py 相当の再実行、2026-11-10 時点の19件で更新）

- **d≡4 (mod 7)** と **d≡5 (mod 9)** が単独で最も強い（p≈6×10⁻⁵）。UNSAT の
  過半数（10/19、9/19）をcoverし、UNKNOWN側の乖離率（58/454=12.8%、44/454=9.7%）
  は基礎 Bayes 比 4–5 倍。
- ただし多重検定の可能性は-delete-真剣に考慮すべき: 7 と 9 は h=1323=3³×7² の素因数に
  ちょうど一致しており、「mod 7 や mod 9 で选择了する条件を事前に選ばなかった」
  とは言えない（h の素因数 3, 7 は最有力の候補として真っ先に調べた）。事後に
  最良の cell を選んだ場合の p 値は名目より大幅に optimistic [INFERENCE]。
  それを割り引いても「完全な偶然」とまでは言い切れない水準（条件候補全体で
  大津数10–20 個を試したとしても Bonferroni で p < 0.001 程度は残る）。
- H1∪H2 の OR は UNSAT の 13/19 を取るが、covers しない UNSAT は
  **1, 231, 300, 345, 346, 448**（合計6件）。d=1 は d≡1 で、d≡4 (mod 7) のような
  非自明に見える代表元の minusc な d では「p−d あるいは h−d の側」が条件を満たすか
  見たが: p−1=2646≡0 (mod 7) で「7 \| p−1」... 
  p−d 側の (d/7) は d≡4 なら p−d ≡ 2646−4 ≡ 0 (mod 7) で「p−d が7で割り切れる」
  対応になっていない。条件の表现は d のみ。
- 注: probe1M で 0.022 秒の d=1300 は 1300 mod 7 = 6, mod 9 = 4。
  **H1, H2 のどちらも満たさない**のに最速クラスの UNSAT。よってこれらの合同条件は
  「即座にUNSAT」の必要条件ではない（d>700 のデータは probe1M に 1 点しかないため、
  鏡像側やその他の構造に使えるかはまだ不明 [INFERENCE]）。
  実は 1300 = p−1347 ≡ −h+23... p−d=1347 = h+24, h−d = 23 [計算]。
  23 は「小さい残差」という別の観察に繋がる（下記 H3）。

### H2: d の Legendre 記号 (d/p) および因数条件 — 弱い/棄却

(d/p)=+1: 9/19、0.73。完全に無相関。gcd 条件も無相関。2が原始根かどうかの
検証と、0 割り当ての割合のミスマッチも p−d 側の (p−d|p) は (−d|p) = (−1/p)(d/p)、
p≡3 (mod 4) なので (p−d|p)=−(d/p) に常に反転するだけで情報なし。棄却。

### H3: 「抵 d が p に対して special な小さい表現を持つ」仮説

UNSAT 19件のうち、d=1（h−d=1322 = h−1）、d=1300（h−d=23、probe1M）、d=231
（d と p−d=2416 が両方 h と大きい GCD 21 をもつ）など、「p−d の小さい」あるいは
「h±d の小さい」特殊な d が速い群に混ざる。相関はまだ標本小で定量化できない
（h−d ≤ 100 は現 UNSAT 19件中 d=1300 の probe1M 1件のみ full100k では 0件——
掃引が d=473 までしか済んでいないので、h−d が小さい d>1200 は全体で未テスト）。
「速い UNSAT の一部は h±d が小さい/滑らか」という観察はあるが、満足な統計ができない
まま [INFERENCE]。

### H4: ソルバ側（学習節・enterprise heuristic）の artifact 仮説

学習節は d 間で共有される設計のため、「早期の d で得た学習節が後の d を速くする」
順序 artifact の可能性がある。13早い群／遅い群の分布が上の合同条件に従う理由を
artifact で説明するのは困難（合同条件は学習の内容に現れる概念ではない）が、
この線の完全な排除には d 毎独立ソルバでの再現実験が必要でまだ行っていない。
逆に artifact なら「d を逆順で掃引すると別の d が速く落ちる」はずで、
反証テスト D で検証可能。
