# 2026-11-14 既知4素数の外側で新たな等号不達成素数 p=3719, p=3727 を発見（証明書つき）

## 発見の順序

1. 等号達成の証人を浅く探す走査（`d = h..h-5` の6通り、各45秒）を 3701..3899 に延長した。
2. **p=3719 と p=3727 だけが「タイムアウト0で不達成」**だった。既知の4素数（2207・2531・
   2647・3251）はこの走査では毎回タイムアウトしており、挙動が違った。
3. p=3719 について `d = h..h-23` の24通りを追加で走査 → **全24個が短時間UNSAT**（281秒、
   タイムアウト0）。前の4素数と違って「難しいUNSAT」ではなく「易しいUNSAT」だった。
4. サイズ `h+2` は `(x,c,e) = (1,1,0)` の一クラスしかないので、**単一CNF**を直接解いた:
   - p=3719（h=1859, size=1861）: 13,012変数・105,940節 → **UNSAT 2.0秒**
   - p=3727（h=1863, size=1865）: 13,040変数・100,592節 → **UNSAT 20.7秒**
5. 両方について DRAT を作り、`drat_check_incremental.cpp`（K0707の削除健全性修正版）で検査:
   - 3719: 23,750行 → **VERIFIED**（31.6秒）
   - 3727: 334,667行 → **VERIFIED**（929秒）

## 結果

```
A(3719) <= 1860 = h+1
A(3727) <= 1864 = h+1
```

- 一般上界 `(p+3)/2` を1下回る。既知4素数と同じ「等号不達成」の形。
- ただし **`h+1` に届くかは未判定**（2207 は届き、2531・2647・3251 は届かない）。

## 方法的な副産物

- 等号判定は **1素数1CNF** で済む（サイズ `h+2` のクラスが一意なため）。従来の `d` ごとの
  全走査（`h` 個のCNF）は不要。
- UNSAT 側（不達成）は速く、SAT 側（達成）は遅い。よって「速いUNSATで候補を拾ってから
  証明書を付ける」国勢調査が実用的。`census_h2_single_cnf.py` がその道具。
- 既知4素数が 2003..3500 の範囲で見つかっていたため「4個で全部」という印象があったが、
  範囲外にさらに2個あった。**不達成素数の分布はまだ分かっていない**（K0101の問いのまま）。

## 追記: 単一CNF国勢調査の最初の結果（3701..3739）

`census_h2_single_cnf.py --start 3701 --end 3739 --budget 300000` の結果:

| p | h+2 | 判定 | 時間 |
|---|---|---|---|
| 3701 | 1852 | unknown | 138.9 秒 |
| 3709 | 1856 | unknown | 161.8 秒 |
| **3719** | 1861 | **UNSAT** | 1.8 秒 |
| **3727** | 1865 | **UNSAT** | 18.6 秒 |
| 3733 | 1868 | unknown | 128.5 秒 |
| 3739 | 1871 | unknown | 134.9 秒 |

- 30万衝突では 6 素数のうち 2 つしか決まらない。UNSAT 側は 2 秒・19 秒と極端に速く、
  残り 4 つは「SAT かもしれない」側で時間切れになる。
- したがって国勢調査は「予算を上げて unknown を潰す」より、**UNSAT が速い素数を拾う**
  フィルタとして使うのが正しい。3701・3709・3733・3739 は未決のまま保留。

### 3741..3899 の走査（完走）

`census_h2_single_cnf.py --start 3741 --end 3899 --budget 300000` は **17 素数すべて unknown**
（各 104〜143 秒）。UNSAT は 1 つも出なかった。

まとめると 3701..3899 の 23 素数で:

| 判定 | 個数 | 素数 |
|---|---|---|
| UNSAT（不達成・証明書つき） | 2 | 3719, 3727 |
| unknown（30万衝突で未決） | 21 | 3701, 3709, 3733, 3739, 3741..3899 の17個 |

- 「例外は速い」という経験則どおり、この範囲の不達成素数は 3719 と 3727 の 2 個だけだった。
- ただし unknown の 21 個は「達成する」と決まったわけではない。SAT 側は証人密度が低く
  単一クエリでは遅いので、**未決は未決**として残す。

## 追記2: 3701..3899 の浅い走査（完走）と h+1 の部分判定

`probe_driver.py --start 3701 --end 3899 --max-doubles 6 --timeout 45` が完走した:

| 判定 | 個数 | 素数 |
|---|---|---|
| 達成（証人あり） | 3 | 3793 (d=1894, 1898点), 3803 (d=1901, 1903点), 3863 (d=1929, 1933点) |
| 不達成（タイムアウト0） | 2 | 3719, 3727 |
| 未決（タイムアウトあり） | 18 | 残り |

- **3793・3803・3863 は等号を達成する**（サイズ h+2 の証人を発見）。したがって
  3701..3899 には達成側と不達成側が混在している。不達成は 3719・3727 の2個だけ。
- 単一CNF国勢調査（30万衝突）では 3793・3803・3863 も unknown だった。SAT 側は
  単一クエリでは遅く、`d` を固定した走査の方が速いという既知の傾向と一致する。

### 3719・3727 の h+1（サイズ 1860・1864）の部分判定

| p | クラス | 判定 |
|---|---|---|
| 3719 | (1,0,0) | UNSAT |
| 3719 | (0,1,0) | UNSAT |
| 3719 | (1,1,1) | 未決（60秒で UNKNOWN） |
| 3727 | (1,0,0) | UNSAT |
| 3727 | (0,1,0) | UNSAT |
| 3727 | (1,1,1) | 未決（280秒で UNKNOWN） |

- 両素数とも (1,0,0) と (0,1,0) は UNSAT。(1,1,1) だけが残っており、
  これが UNSAT なら `A(3719) <= 1859`・`A(3727) <= 1863` に下がる。
- 既知4素数でも (1,1,1) は最も難しいクラスだった（2207 は SAT で 89 分、
  2531・3251 は UNSAT に 35〜98 分）。同じ難しさの壁に当たっている。

## 追記3: 3901..4099 の国勢調査で p=3967 を発見（3個目の新例外）

`census_h2_single_cnf.py --start 3901 --end 4099 --budget 300000` の途中経過で
**p=3967 が 0.2 秒で UNSAT**。即座に証明書を作成:

- 13,880変数・111,115節、DRAT 10,941行 → **VERIFIED**（7.8秒）

```
A(3967) <= 1984 = h+1
```

- 0.2 秒という速さは 3719（2.0秒）よりさらに極端で、「例外は易しいUNSAT」という
  経験則を強く裏づける。
- 3901..4099 の残りはまだ走行中。13 素数を処理した時点で UNSAT は 3967 の1個だけ。
