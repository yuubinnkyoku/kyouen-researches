# 高速レーン：特別中心選択確率の私有中心圧縮（2026-10-30）

## 対象と重複回避

main の AGENTS.md、research/knowledge/README.md、SCHEMA.md と既存の次の実験を確認した。

- split-one-hub-terminal-law-20261030：特別中心1個の選択確率と鋭い極値。
- split-k-center-uniform-legal-subset-dp-20261029：任意中心数を全て個別に扱う終局長分布。
- split-weighted-k-hub-subset-dp-20261030：私有中心群を圧縮するが、中心を一度も選ばない確率のみ。

上記の隙間である「私有中心群を圧縮したまま、任意個の特別中心それぞれの選択確率を厳密に求める」問題を選択した。

## 成果と検証境界

優先順位積分と包除原理から全称公式を証明。そこから終局長の確率母関数、任意人数の一様合法着手モデルの最終着手者分布を得た。

再現物：research/experiments/game-structure/split-marked-hub-terminal-law-20261030/README.md および verify.py。

検証器をローカルの Python で実行し、11,182構成の閉近傍削除厳密有理数再帰、160構成の全優先順位列挙、250構成の追加乱数検査が全て一致した。全称性の根拠は証明であって、この有限検査ではない。

私有中心数の総和を指数部から除いた一方、特別中心数 k に対する階乗的な順列和は残る。一般の幾何的共円残局への実現可能性も未確認。11×11への直接の枝刈り効果は未測定。

## 次に実行可能な課題

1. 同じ公式を部分集合動的計画法へ変形し、k に関する階乗依存を 2^k 型へ削減できるか調べる。
2. 固定次数・近傍交差条件で、特別中心選択確率の鋭い極値を探す。
3. knowledge正本への昇格には生成物再構築と check / tests が必要。今回の環境では全体の uv 同期・CI を実行していないため、未実施とする。
