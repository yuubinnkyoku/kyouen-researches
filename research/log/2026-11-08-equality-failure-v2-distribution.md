# 2026-11-08 等号不達成の剰余分布（v2(p−1) 仮説の検定、否定的）

- 対象: 2003..3100 の 135 素数（`witnesses_2143_2500`, `2503_2700`, `2701_2900`, `2901_3100`）。
  指標は浅い d 走査（d=h..h-6）での証人の有無。浅い失敗 16 件。
- 2 進付値ごとの達成数（浅い走査）:

| v2(p−1) | 達成/総数 | 浅い失敗 |
|---|---|---|
| 1 | 56/66 | 10 (15%) |
| 2 | 29/33 | 4 (12%) |
| 3 | **20/20** | 0 (0%) |
| 4 | 6/7 | 1 (14%) |
| 5 | 5/6 | 1 (17%) |
| 6, 7 | 3/3 | 0 (0%) |

- 見かけ上は v2 が大きいほど失敗が少ない（v2=3 で 0/20）。
- **検定**: 相関統計（Cochran–Armitage 型）の permutation test（20,000 回）で
  **r = −0.087、p = 0.37**。→ 現在の標本では **統計的に有意ではない**。
  最頻クラスの比較（v2=1 の 10/66 対 v2=3 の 0/20）でも Fisher の正確検定は p≈0.1 程度。
- 結論: 「v2(p−1) が大きいと等号不達成が少ない」という傾向は、今のデータでは
  偶然と区別できない。前回の「1 mod 8 は失敗しない」という観察（0/30）は、
  2897・3041 などの反例と検定の結果から **撤回**する。
- 注意:
  - 指標が「浅い失敗」であり、全数走査で確定した不達成は 2207 と 2531 の 2 例だけ。
  - 走査窓（d=h..h-6）の取り方に依存する指標なので、分布の議論は限定的。
  - 標本を増やすには 3100 以上の走査と、候補素数の全数走査による確定が必要。
- 次: 指標を「全数走査で確定した不達成」に切り替えて標本を増やす（高コスト）、
  または 3100 以上の浅い走査を続けて 300 素数規模にする。
