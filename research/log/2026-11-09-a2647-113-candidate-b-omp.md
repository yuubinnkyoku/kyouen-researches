## 1. 実装

`research/experiments/parabola-p2207-no-equality-witness-20261107/search_shape_class_assump.py`

- `search_shape_class.build(p, edges, x, c, e)` を import し、クラスCNF（4値対変数
  `v(i,kind) = 4i-4 + {B:1,N:2,L:3,H:4}`、exactly-one、`c` 個の B、`e` 個の N、
  点変数 `a_t = aux+t` と禁止四点節）をそのまま使う。エンコーダは複製せず単一の実装を共有。
- ソルバはクラスあたり `Cadical195` を1個だけ生成し、全節を bootstrap。`d` ごとに
  `conf_budget(--budget)` → `solve_limited(assumptions=[v(d,"B")])`。
- 被覆の理論: `c=1` では `B_d` は排反な分割（ちょうど1個の完全対）なので
  `d=1..h` の全 UNSAT ⇔ クラス UNSAT。`c=0` では完全対が存在しないため d 掃引は無意味で、
  `d=0` の1レコードを assumption なしで解く（`--ds` は無視）。`Classes` 列挙は元スクリプトと
  同一（x∈{0,1}, c∈{0,1}, e = x+c+h-size）。
- 結果レコードは `{class, d, sat, unknown, seconds, budget}`。SAT 時はモデルから
  点集合を復元して `{witness_size, safe_against_edges, points}` を付ける。復元は元スクリプトと
  同じ規則（B→両点, L→低側 i, H→高側 p-i, x=1 で 0 を追加）。`safe_against_edges` は
  **禁止四点全件（928,389 個、0 を含む辺も含む）を直接照合**する独立検査で、
  CNF の x=0 枝刈りとは無関係に判定する。
- 再開: クエリごとに `--output` を書き直し、既存レコードの `(class,d)` をスキップする。
  出力先は引数必須で、既存 `output/shape_class_*.json` には書き込まない設計。
- `--ds` は `"1..20"` / `"1,50,100"` / 範囲と列挙の混在を受け付ける。

### 検証で分かったこと

- `c=1` の assumption 分割は両方の素数で完全に一致した。不一致は0件。原因特定を要するバグは
  発生しなかった。
- 全 d を回した総時間はクラスCNF単体と同オーダーで、**短くはならない**
  （p=211 の SAT クラスで sweep 合計 0.01–0.05秒、クラス単体 0.00–0.03秒）。
  この規模ではすべての CNF がミリ秒で解けるため学習節共有の効果は測定不能。
  効果の有無は p=2647 のスモークでしか判断できない（§3）。
- SAT 側の復号も検査した: p=101 size 49 の `(1,1,3)` / `(0,1,2)` で
  `witness_size=49`（= size）かつ `safe_against_edges=True`、`(0,0,1)` の `c=0` 経路でも
  `d=0` の1レコードで `witness_size=49`, `safe=True`。

## 4. 本実行（全 d 掃引）の所要見積もり

- 実測（100k conflicts/query）: d=1 = 1.094秒 UNSAT、d=2..5 = 32.5, 32.7, 38.6, 36.1秒すべて
  UNKNOWN。d≥2 の中央値 ≈35秒。仮に全 1322 d が同じ難度だと **1322 × 35秒 ≈ 12.9時間**、
  これに 1323 回目の再起動コストはない（単一ソルバ）。ただし d=1 の 1.1秒は「UNSAT 枝の
  一部は極端に速い」ことを示すので、実分布は二峰性の可能性がある（[INFERENCE]）。
- 判断基準（W3 設計の候補B）: 50 d のうち 45 以上が <2秒、最大 <30秒 →
  残り 1273 d を掃引（見込み 1–2時間）。中央値 >10秒 または 1件でも >300秒 → 中止。
- 現スモークでは **5件中4件が 30秒超（UNKNOWN）**。判断基準の「中央値 >10秒」に該当し、
  W3 の基準では **本実行は中止**が正しい判定。ただしこの予算 100k は「1クエリで決着させる」
  には小さすぎる可能性があるため、本実行前に `--budget` 1M–10M で代表 d
  （1,50,100,...,1300）を測り、「決着するまで解く」コストを見る必要がある。
  決着させる予算が 1 d あたり数百秒必要なら 1323 d の掃引は非現実的で、候補A
  （fixed-d ternary、より小さいCNF）との比較が先。
- 再開の確認: 同一 `--output` で同じ `--ds 1..5` を再実行すると全5件が
  `already recorded, skip` でスキップされ、レコード数は5のまま（壁時計 64秒は
  928,389 個の禁止四点再生成のみ）。再開性は実測で確認済み。

- 注意（W3 から引き継ぎ）: assumption 下の UNSAT は単体の DRAT 証明にならない。
  監査可能な receipt が必要なら、d ごとに CNF を書き出して候補A の方式で証明を取る。
  このスクリプトの `safe_against_edges` は SAT 側の幾何検査のみを提供する。
