## §1 主張

座標は K1311/K1314 と同一: H(R; X; z), X 降順 (x1 ≥ … ≥ xn ≥ 1), S := ΣX, k := R−S, E := 2x1−S。
**第3行**: k := z+n−5 (n=1 のとき文献規約により R=x+z−4)。今回のマージ座標は **w := E+z** (K1314 の w2 := E+z+n−5 と定数差 n−5、同一行内では同値)。補助量: **j** := 1-heap の個数、**m2** := 2 以上の最小 heap、**c2** := 2-heap の個数。

### L-BR3 (GRID-VERIFIED 転写補題)

n=1 スライス (単一トークン, 行 k = z−4, R = x+z−4) について

```
H_canonical(x+z−4; (x,); z) == single_token(x, z, x+z−4)
```

が格子 x ≤ 30, z ≤ 30 (R ≥ 0 の 924 セル全て) で成立 (WA / D1)。これは**公刊 K0832 閉形式の行オフセット −4 での転写**であって新定理ではなく、格子範囲の機械照合である (全称主張は公刊閉形式そのもの既知)。

### OBS-BBL3 (観測 — 凍結格子に限る)

第3行の値 H(S+z+n−5; X; z) について、以下を凍結掃引格子 (§3) で**観測**した。

(a) **生層 (E,z) 非崩壊** (negative observation): 同一 n 内で全インスタンスを (E,z) にマージすると多値セルが n=3: 17 / n=4: 21 / n=5: 48 / n=6: 61 / n=7: 90 個生じ、第2行 T-BB2 のような生層崩壊は**起こらない**。正しい層化は (n, j) である。

(b) **クラス (n,j) 層化でほぼ崩壊**: クラス (6,0), (6,1), (7,1)…(7,7) は掃引域内で**多値セル 0 (完全崩壊)**。残余の多値セル: (7,0) 33 個 (後述 2-族衝突帯 w ∈ [−17,−15])、n≤5 と (6,2)/(6,4) の少数 (例外族・壁補正, 凍結 .out に全列挙)。

(c) **族アンカー 3 ピース則**: クラス (n,j) 内は 1〜4 個の**族** (tail-family) に分かれ、族ごとに定数 A (w-座標の 2-line 位置) が決まり、

```
V(E, w) = 2            if w == A       (2-line)
V(E, w) = [E even]     if w  < A       (左高原)
V(E, w) = [E odd]      if w  > A       (右高原)
```

各行の 2 の位置で A を測ると、**n=4..8 の全クラス・全族で 3 ピース則の実違反 0** (掃引域内 5,779 本の単一 2 行; n=8 は j=0/1/2 の 464 本を含む)。法則適合だが族モーダル A から外れる少数行 (off-level 外れ値: n=4 で 8 行, n=5 で 2 行) は宣言済みリスト (.out `off_level_ex`)。

(d) **族アンカー表と tail ラダー**:

```
j=0 の代表アンカー η(n) (モーダル):  n=3: 1, n=4: 0, n=5: −5, n=6: −10, n=7: −15/−17 (2族)
A_{n,j} shape (n≤7):  η(n) + 2j − 2·[j ≥ n−3]   (flat spot を 1 個含む: n=4 j=1, n=5 j=2, n=6 j=3, n=7 j=4)
n=7 (7,0):  m2=2 → A=−15、m2≥3 → A=−17   (hi=8 追加掃引で 639+636 票の完全分離・凍結外声明)
n=8 j=0 (4 族ラダー):  c2≥2 → −20 / c2=1 → −22 / m2=3 → −24 / m2≥4 → −26
n=8 j=1 (2 族):  −18 / −20、j=2 (1 族): −16
```

(7,0) の 2 族は衝突帯 w ∈ [−17,−15] の正体そのものである (b の 33 多値セルは全てこの帯)。

(e) **抑制 (壁効果)**: ライン位置 z* = A−E ≤ 0 (E ≥ A) の行は窓内に 2 を持たず、全域 [E odd] (右高原) を読む。この説明モデルの反例 (E < A なのに 2 なし) は n≥4 の掃引域で 0 行。壁得失点族: n=3 の (t+3,t,1)・(t+2,t,2) 族は z=0 セルを右高原に吸収 (36 行・全て宣言済み)。(2^4,1,1) と (2,2,1^4)/(3,3,1^4) は窓内で山全体が消失する一方、top が 3〜4 以上の同型 (3,3,2,2,1,1)/(4,4,1,1,1,1) は z*=0 でラインが出る (V_LAW 定数に固定)。

### CONJ-BBL3 (予想 — 未証明・明示的な免責)

**全部のインスタンス・全部の n ≥ 3** について、行 k=z+n−5 の値は (c) の 3 ピース則に族アンカー A(X) で従う (A は (n, j, tail 構造) で決まる; ラダーの一般規則は未確定)。観測・格子由来であり、全称定理としての主張はしない。証明方針の見通し: T-BB2 と同じ typed-children 構造で、第3行セルの子は第2行 (plane z+1) の既知値に着地する (K1314 の B 承継 typing: n−1=1 → L-BR2, 2 → L-2, ≥3 → T-BB2) ので、ボトムアップの単一 R 強帰納が組めるはずである。

## §4.5 主張の区別

- L-BR3 は公刊 K0832 閉形式の**転写の格子照合** (grid-verified)。新規の数学的内容は含まない。
- OBS-BBL3 の (a)–(e) は全て**凍結掃引格子上の観測**。格子外 (heap 上限・z 上限外・n≥9) への射影は CONJ-BBL3 という名の**予想のみ**。

- 11×11 空盤・二石 root・S2・class 1/2/4 は全時点 UNKNOWN・verdict 不消費 (定型)。
