## 事前の横断予想（y=6..12 の出版表からの外挿であり y=13 の証明ではない）

- tail 開始: R >= x+z+14 = x+z+y+1・値 (x+13) mod 2。y=13 は奇数 y で
  値1無限帯・tail 値1 は x 偶行（y=9/y=11 型。y 偶奇が行型を決める）。
- 基底点: {z+1, z+3, ..., z+25} の 13 点（基底点 y 点仮説の y=13 版）。
- マージ行: x <= z-14（S <= z-1）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+39)/2・pin offset o_pin∈[y+1,2y]=[14,26]
  かつ o_pin≡z+1 (mod 2) の統一式（y=11: 偶[12,22]6行/奇[13,21]5行・
  y=12: 偶…は d 基準で {14,16,18,20,22,24}・{13,15,17,19,21,23} を全て再現）から
  奇z d≡1 (mod 4) {-11,-7,-3,1,5,9,13} の 7 行・偶z d≡3 (mod 4) {-9,-5,-1,3,7,11}
  の 6 行を予想（奇z7行は y 奇族初の 7 行）。
- 奇z pin 行（I 帯行）の pin スロット = th-1 型（y=11/y=12 と揃うかが
  K1152 指名の横断判定材料）・偶z pin 行（base 行）は pin が 2k+1 上端外側。
- 対角行 d=-13: 値2上端 cap = z+y-[z≡y (mod 2)]（z odd: 偶offset [2,z+12]・
  z even: 奇offset [1,z+13]）。偶z 対角行の値1全欠如（y=8..12 で5族連続）の
  y=13 での判定を data-driven で（6 族連続候補）。
- 掃引行 d=14 / 定常行 d>=15: steady pin {z+26}（奇z）/{z+27}（偶z）・
  band 下端 offset 2y+2 = 28・掃引帯は偶offset [2y+z, x+z+13]（奇z）/
  奇offset [2y+z+1, x+z+13]（偶z）。
- base 行 k(d)=floor((d+3y+1)/4)=floor((d+40)/4)・偶z I 帯行 k(d)=floor((d+3y-1)/4)
  =floor((d+38)/4)（y=11/12 と同一族式）・奇z I 帯行 th=2k+1（y=11 型）。
  最終 pin 行 d=y=13（奇z）は I 帯を pin（offset 26）を skip して z+27 から
  （I[2y+z+1) 型・6 族連続候補）。
