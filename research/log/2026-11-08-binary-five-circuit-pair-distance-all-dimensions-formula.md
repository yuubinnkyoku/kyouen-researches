# 二値立方体5点アフィン回路の固定二頂点同時出現数：全次元公式

2026-11-08。AGENTS.md、knowledge README、generated/summary.md と直前の有限完全列挙記録を確認。既存の距離別有限表を全次元に拡張する数学的証明。**既存の5点回路の星形特徴づけ・対蹠対一意性を前提とする帰結**であり、それらの独立証明ではない。

## 命題

$d\ge 3$、$1\le k\le d$ とする。$\{0,1\}^d$ のハミング距離 $k$ の固定した二頂点 $u,v$ をともに含む5点**アフィン回路**（5点がアフィン従属で任意の真部分集合は独立）の個数を $C_d(k)$ とする。すると

$$
\boxed{C_d(k)=2\left\{\begin{matrix}k\\3\end{matrix}\right\}
+3^{d-k}-2^{d-k+1}+1
+(2^{k+1}-4)(2^{d-k}-1)}
$$

である。$\left\{\begin{smallmatrix}k\\3\end{smallmatrix}\right\}=(3^k-3\cdot2^k+3)/6$ は第2種スターリング数。$k=1,2$ でも式は有効。

## 証明（全次元）

ビット反転・座標置換で $u=0$、$v$ の1座標集合を $D$（$|D|=k$）としてよい。既証の星形特徴づけによれば、各5点回路には一意の変動座標集合 $T$ と、その3個の非空・互いに素なブロックへの分割 $T=A\sqcup B\sqcup C$ がある。5頂点は中心 $z$、反対頂点 $c$、3葉 $z\oplus A,z\oplus B,z\oplus C$ であり、$c=z\oplus T$。変動しない座標は5点で共通。

固定二頂点の星形での役割を四つに分類する。

1. **中心と反対頂点**：$T=D$、3非空ブロックの無順序分割が $S(k,3)$ 通り。中心を $u,v$ から選ぶ2通りで $2S(k,3)$。
2. **中心と葉**：$D$ はちょうど一つのブロック。残りの変動集合 $J=T\setminus D$ は $[d]\setminus D$ の部分集合で、$|J|=j\ge2$。$J$ を残る二つの非空ブロックに無順序分割する $(2^j-2)/2$ 通り、中心の選択が2通り。合計 $\sum_{j\ge1}\binom{d-k}{j}(2^j-2)=3^{d-k}-2^{d-k+1}+1$。
3. **反対頂点と葉**：$D$ は葉に対応しない二つの非空ブロックの和集合。$J=T\setminus D$ は葉ブロックなので非空。$D$ の無順序二分割 $(2^k-2)/2$ 通り、反対頂点の選択2通り。合計 $(2^k-2)(2^{d-k}-1)$。
4. **異なる二葉**：$D$ はその二葉のブロックの和集合。残る第三ブロック $J$ は外部の非空部分集合。二葉への $D$ の非空分配は $2^k-2$ 通り（$u,v$ が固定され区別できる）。合計 $(2^k-2)(2^{d-k}-1)$。

四分類は互いに排反かつ尽くす。合計が命題の式となる。星形表示の一意性により重複計数はない。□

## 検算・範囲

式を整数演算で評価すると、$d=3$ では $(2,4,2)$、$d=4$ では $(12,14,14,12)$、$d=5$ では $(50,40,40,40,50)$。直前の整数階数による全5点集合の独立完全列挙と完全一致する。これらの有限検査は証明そのものではなく独立照合である。

検算用Python（標準ライブラリのみ）：

```python
from math import comb
expected = {3:[2,4,2], 4:[12,14,14,12], 5:[50,40,40,40,50]}
for d, row in expected.items():
    got = []
    for k in range(1,d+1):
        s = (3**k-3*2**k+3)//6
        c = 2*s + 3**(d-k)-2**(d-k+1)+1 + (2**(k+1)-4)*(2**(d-k)-1)
        got.append(c)
    assert got == row, (d,got)
```

なお $k=d$ なら $C_d(d)=2S(d,3)$、$k=1$ なら $C_d(1)=3^{d-1}-2^d+1$ となる。総回路数 $N_d$ と整合する必要条件は $\sum_{k=1}^d 2^{d-1}\binom dk C_d(k)=10N_d$ である。
