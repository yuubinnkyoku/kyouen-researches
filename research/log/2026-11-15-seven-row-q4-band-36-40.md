# (7,4) witness帯が構成的限界35を超える — m=36..40 全幅 SAT・M_{7,4} 下界 36→41

Date: 2026-11-15
Lane: 高速レーン（sat3 streaming census レーンの続き）
Experiment: research/experiments/seven-row-q4-witness-band-36-40-20261115/ (main push済み)

## 概要

sat3（sat2.js と byte-identical の streaming census・前ログ参照）で、K0827 構成的
延伸帯の先端 m=35 の先を SAT 探索した。**m=36..40 の全5幅で行欠損極大 witness が
発見**され、(7,4) の witness 帯が構成的限界を超えて延びていることが確定した。

## 結果

- m=36..40 全幅 SAT（kissat 117..402 conflicts・生成6.0〜7.9s・200s cap）。
- 全 witness 20石・行マルチセット {3,3,3,3,3,3,2}・js+py 2系統検証 PASS。
- m=40 は 8,101,031 clauses・CNF 155MB・kissat 27.8s。
- **M_{7,4} ∈ [41, 1929]** に更新（下界36→41・上界 K0068/K0318 のまま）。
- witness 探索の前線は **7×41**（未実施・不在主張ではない）。

## 意義

- K0827 の構成的延伸（blocking-coverage・config CA/CB・coverage 35）は構成手法上の
  限界でしかなかった: SAT 探索はその先にも witness を見つける。
  witness の行構造が {3,3,3,3,3,3,2} のマルチセットで不変なまま帯が延びている点は、
  より遠方の構造（周期的延伸の可能性）を示唆する観察として記録に値する。
- +1幅ずつの掃引よりも大幅プローブ（m=50, 60, ...）が情報効率が高い。
  sat3 の dedup Set は m=50 生成で OOM（rc 137・全円キー保持のため）。
  **≥q点円のみ Set に登録する修正で出力不変のまま縮小可能**
  （q点未満の円は三つ組が1つしかなく再遭遇しない）— 次バッチの最優先課題。
