# d=6 の依存7点組：固定頂点を通る個数の厳密監査値（2026-11-08）

## 結論と証拠の範囲

K0568 の完全列挙が与える依存7点組総数 D=255,036,992 を入力とすると、二値立方体 V_6 の**任意の固定頂点**を含む依存7点組の数は厳密に

\[
D_v=\frac{7D}{64}=27,894,671
\]

となる。また独立7点組の固定頂点通過数は

\[
I_v=\binom{63}{6}-D_v=67,945,521-27,894,671=40,050,850.
\]

これは **K0568 の全数列挙結果を前提とする数学的帰結**であり、依存判定器を独立に再実行した結果ではない。K_6≤9 の証明にもならない。

## 証明

V_6 の平行移動群 (Z/2Z)^6 は頂点推移的に作用する（各座標の反転）。この作用は実アフィン変換 x_i→1−x_i なので、7点のアフィン従属性を保存する。したがって各頂点 v に接続する依存7点組数 D_v は一定。依存7点組とその所属頂点の接続対を数えると 64D_v=7D。独立7点組は固定頂点を選んだ後の残り6点を63点から選ぶ \binom{63}{6} 通りから差し引く。

## 再現と利用

Python標準ライブラリだけで整数検算できる。

```python
from math import comb
D = 255_036_992
assert (7 * D) % 64 == 0
Dv = (7 * D) // 64
Iv = comb(63, 6) - Dv
assert (Dv, Iv) == (27_894_671, 40_050_850)
assert 64 * (Dv + Iv) == 7 * comb(64, 7)
```

今後、依存7点組の生成器を固定頂点に制限して検証するとき、この値を追加の厳密な整合性条件として使える。ただし元の全数値を使った代数的検算は、元の列挙の独立監査ではない。
