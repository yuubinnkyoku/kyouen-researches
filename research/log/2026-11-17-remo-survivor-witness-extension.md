# 2026-11-17 生存者列最小周期r=2..32（小witness棄却）と定理Wの全C強化

対象: `remo-uniform-witness-theorem-20261117` / K0925
レーン: 高速レーン（K0922レジューム項「witness C=1の全称証明」の実行中に
並走K0924が同項目を出版したため、本項は差分成果に再焦点化）

## 発見順・経緯

1. **出発点**: K0922 の「witness C=1 の全称性」OPEN と r ≥ 17 の
   最小性 OPEN に着手。K0919 定理PER の必要性方向の道具
   （均一オフセット帰納）を**逆向きに走らせる**と witness 証明に
   なることに気づく: 条件列 M_1: r|d、M_h: k_h(k_h+1)|d
   （lcm はちょうど Q(r)）の最初の失敗 h* の前では 2 つの run
   E(C,r), E(C+d,r) がフェーズロックし（一様整数オフセット
   D_h = d/(k_h+1)・ℓ差 X_h = d/(k_h+1)）、h* でだけ敗者添字が
   X_{h*} mod k_{h*} ≠ 0 だけずれる。h* が存在するのは Q(r) ∤ d
   のとき、かつそのときに限る。プロトタイプで全C 121,550ペア・
   C=1 16,478ペアを確認。
2. **全C強化**: 帰納ステップが C を一切参照しないため、差は
   **すべての C ≥ 1** で同じ位置 h* に生じる（elim列では全Cが
   witness）。
3. **並走との衝突と再焦点化**: 検証器実装中に並走レーンが
   **K0924**（定理W・C=1版・系MPV・r=2..40 witness機械検証）を
   出版したのを確認。主張が重複するため、本項を差分成果へ再
   焦点化: (a) 全C版（定理W+・K0924に明示的にはない強化）、
   (b) **生存者列の r ≤ 32 拡張**、(c) h*(Q/p) 算術。
   同じ定理Wに独立到達したことは相互検証として W1/W2 に
   位置づけた（K0924 M1/M2 と r ≤ 24 で完全一致）。
4. **生存者列の拡張（本項の主成果）**: K0924 は生存者列を
   「r ≥ 17 は窓走査が必要で未到達」と残したが、これは
   **手法の誤り**: K0922 補題DIV（gcd閉包・列汎用）により
   最小周期 m(r) | Q(r) なので、**各真約数 d を1つの witness C
   で棄却すれば十分**で [1, Q(r)] の完全走査は不要。実際には
   witness は小さく（≤ 150・観測最大 28 = r=29・すべて r−1
   以下）、Q(32) ≈ 1.44e14 の真約数 18,431 個を含む全 72,397
   個の棄却に成功（定理S32）。r ≤ 16 は K0922 出版監査の
   wit_max と d=Q/p の [w_elim, w_sv] 表と完全一致。
5. **h* の算術**: d = Q/p では k(k+1) | Q が常に成り立つため
   失敗条件は v_p(k(k+1)) = v_p(Q) と書け、フェーズ順が k の
   降順であることから h* = 1（v_p(r) = v_p(Q) のとき）以外は
   r+1 − max{k ≤ r−1: v_p(k(k+1)) = v_p(Q)} と閉形式化できる
   （r=2..24 の全 (p,r) で一致）。検証器初回実行で M_1 場合分け
   （r が素数冪のとき r 自身が p の全冪を持つ）の欠落が W6 の
   不一致として露見し修正。
6. **有限観察**: wit_max_sv ≤ r−1 が r ≤ 32 全域で成立・
   witness 最大の d は h*=1（M_1失敗）の Q/m 型に集中。
   「有界 witness 予想が示せれば生存者側の全称最小性も閉じる」
   を次課題として記録。
7. **検証器**: W0-W6+TWIN の 8 チェック。W4 は結論だけでなく
   帰納の全段（フェーズ痕跡ごとの手番・敗者・一様オフセット・
   ℓ差・h* での添字差）を直接検査し違反 0。監査 JSON は
   assemble 二重実行と 2 回の別プロセス実行（うち 1 回
   --no-cache 全再計算）で byte 同一（sha256 b3733ed5…）。

## つまずき（検証器開発中の失敗と修正）

- W3 の d 集合に Q の倍数（d=Q+2 は 2|Q で常に倍数・ほか
  Q+80 の小さい r）が混入し elim 一致を「違反」と誤検出 →
  非倍数フィルタで修正。
- W5 の w_elim 定義を「最初の差位置==1」と誤実装（正しくは
  「C=1 で敗者列が異なる」・差位置は h* であって 1 とは限らない）
  → K0922 ピン照合で発見し修正。
- W6 の閉形式に M_1 場合分け（v_p(r) = v_p(Q)）が欠落
  → h* 走査との不一致で発見し修正。
- K0924 番号取得は並走に先を越された（本体レポート作成前に
  気づき番号空間を再確認して K0925 へ変更・K0921事故の
  「push前に番号空間全体で確認」教訓に従い実害なし）。
