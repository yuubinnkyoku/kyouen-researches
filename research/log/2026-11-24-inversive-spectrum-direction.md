# 2026-11-24 新しい方向: 円インターセクション・スペクトル K_s(q) と Steiner 3-設計の (s,d) 双対

## 出発点

- 前セッションまでに反転平面の弧の上界 `K(q) ≤ q`（q ≥ 7、K1252）と
  q ≤ 11 の厳密値、非 Miquelian 盤のデータが確定していた。
- 本ラウンドの目標は「今までにない発想の方向性」。1 個の数 `K(q)` を
  さらに磨くのではなく、**問いの形を変える**ことを選んだ。

## 新しい方向（着想）

弧の定義「どの円とも高々 3 点で交わる」の **3 を変数 s に置き換える**:

```
K_s(q) = max{ |S| : |S∩C| ≤ s for every C },      s = 1..q+1.
```

- `s = 3` が従来の弧。`s = q+1` は全点集合。
- 補集合を取ると `K_s(q) = q²+1 − τ_{q+1−s}(q)`。ここで `τ_d` は
  **d 重ブロッキング数**（各円と d 点以上で交わる最小集合）。
  つまりスペクトルは「ブロッキング集合の階層」と厳密に双対。
- 設計のモーメント 2 本だけで一般上界が出る:
  任意の Steiner 3-(v,k,1) 設計で `K_s ≤ (s−2)λ_2+2`, `τ_d ≥ dλ_2`
  （`λ_2 = (v−2)/(k−2)`）。反転平面では `λ_2 = q+1`。
- K1252 の深い定理は `τ_{q−2} ≥ (q−2)(q+1)+3` と読める。
  すなわち線形上界が **d = q−2 でのみ 3 だけ破れる**。
  「線形設計上界からの超過」`e_d = τ_d − d(q+1)` を新しい不変量として提案した。

## 実施内容

1. **文献調査（サブエージェント）**: s-弧（≤ s per block）は反転平面文献に
   見つからない。設計一般では (α,n)-arc（Sane–Shrikhande–Singhi 1985）、
   射影平面では (k,n)-arc（Ball 1996）が同値な枠組み。
   ブロッキング集合は Bruen–Rothschild (1985) と Kiss–Marcugini–Pambianco (2005)
   が `τ_1 ≥ 2q` を証明済み（q ≥ 4）。この事実は当初の「τ_1 = 2q」予想を
   「上界 `K_q ≤ (q−1)²` は既知、等式が q=4,5 で成立」に修正した。
2. **定理の証明**（K1274）: 一般形 + 反転平面特殊化 + 双対 + excess。
3. **SAT 厳密計算**（K1275）: 盤面は出版済み `inversive_fast.build_circles`。
   CNF = 円ごとの (s+1)-部分集合禁止 + 基数 ≥ n + 3 点対称性破り。
   貪欲下界から n を上げ、最初の UNSAT で厳密値。
4. **独立検証**:
   - q ≤ 5 は SAT 非依存の全探索と一致。
   - 最終 UNSAT は cadical195 と glucose3 の 2 エンジン。
   - 全証人を SAT 非依存チェッカで盤面に照合。
   - モーメント等式のランダム監査（`bound_audit.py`）。
   - **別実装サブエージェント**（`independent/`）が独自の体模型で円族を
     再構成（q=7 で 350/350 一致）し、C の完全列挙・分枝限定
     （q=7 は 3-推移性 117600/117600 を確認して 3 点固定）で
     `K_4(4)=9`, `K_5(5)=16`, `K_4(7)=13` を再確認。
     discrepancies 0、モーメント 200 試行×3 盤で失敗 0、全実行 5.5 秒。
5. **較正**: q=9,s=3 で既知 K(9)=9 を再現、q=3,4,5 の K_3 も一致。

## 結果（2026-11-24 時点）

厳密値:

```
K_4(4)=9, K_4(5)=10, K_4(7)=13, K_5(5)=16, K_3(9)=9（較正）
```

部分境界:

```
14 <= K_4(8) <= 15   (n=16,17,18 UNSAT; n=18 は 2 エンジン)
16 <= K_4(9) <= 22
K_7 >= 33, K_8 >= 45, K_9 >= 57   (s=q 行、明示的証人)
```

発見:

- `K_q(q) = (q−1)²` が q=4,5 で成立（`τ_1 = 2q` が tight）。
- q=8,4 の上界 16 は一般上界 20 より 4 小さい。
- `s = q+1` の 1 段だけが全点集合に到達する相転移。
- K1252 の tight 例 q=9 は `e_{q−2} = 3` を達成する。
