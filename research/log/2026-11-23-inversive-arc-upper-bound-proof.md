# 2026-11-23 反転平面アークの上界 q+1（q 奇数, q≥7）の証明

## 何をしたか

K1250 の射影上界 `K ≤ q+2`（q 奇数）から、等号ケース `k = q+2` を排除して
**`K ≤ q+1`（q 奇数, q ≥ 7、無条件）** を証明した。詳細は K1252。

## 証明の骨格

1. **射影**：`P ∈ S` から平面 `π` へ射影すると `S\{P}` は `PG(2,q)` のアーク（サイズ `k−1`）。
   `q` 奇数で `PG(2,q)` のアークは高々 `q+1` 点 → `k ≤ q+2`。
2. **等号ケース**：`k = q+2` なら射影はちょうど `q+1` 点の oval。q 奇数では
   **Segre の定理**でこれは円錐曲線。よって `S\{P}` は `P` を頂点とする二次錐 `C_P` 上。
3. **2つの錐の交わり**：`P,Q ∈ S` に対し `C_P ∩ C_Q` は（Bezout 4次）直線 `PQ` を共通成分に持ち、
   残りは3次曲線 `Γ`。`S\{P,Q}` は `Γ` 上（`PQ` 上には来ない：3点共線は従属）。
4. **`Γ` の形**：可約なら直線成分（≤2点）と平面円錐曲線成分（≤3点）で `q` 点は載らない。
   平面3次曲線なら4点が同一平面上。よって `Γ` は**ねじれ三次曲線**（twisted cubic）。
5. **矛盾**：`Γ` は `Q⁻` 上に `q ≥ 7` 点を持つので Bezout（3·2 = 6）より `Γ ⊂ Q⁻`。
   ところが楕円二次曲面は `F_q` 有理な**奇数次数曲線を持たない**：閉包上 `P¹×P¹`、
   `Pic = Z²` の2生成元（2つの ruling）は Frobenius で入れ替わり、不変類の次数は偶数。
   `deg Γ = 3` は奇数で矛盾。□

**`q = 3` は真の例外**：`K(3) = 5 = q+2`（厳密値）。Step 5 の Bezout 評価が `q > 6` を必要とする。

## 意義

- 無条件上界が `q+3`（λ₂）→ `q+2`（射影）→ **`q+1`（q 奇数, q≥7）** と締まった。
  K1058 の「上界改善が最大の課題」に対する答えの一つ。
- MDS 予想経由（K1250）でも `q+1` が出ていたが、こちらは**予想に依存しない**。
  つまり「楕円二次曲面上に列を持つ4次元MDS符号の長さは `q+1` 以下」が、
  MDS予想抜きで（q 奇数なら）従う。
- 下界 `(q+5)/2`（Sonnino 1999）と合わせて **`(q+5)/2 ≤ K ≤ q+1`**。
  残る問題は定数 `liminf K/q`（`0.5〜1`、我々の測定は `≈0.65`）。

## 注意

- 引用した古典的事実（Segre の oval=conic、Bezout、楕円二次曲面の Picard 群と
  Frobenius の作用）は本項では独立証明していない。
- 上界 `q+1`（q 奇数）は**文献に既にある可能性**がある（Sonnino の論文全文を取得できず）。
  本項の貢献は「自己完結の証明を与えたこと」に留め、新奇性は主張しない。
- 偶数 `q` へは拡張できていない（射影上界が `q+3` になり、非円錐 oval も存在するため）。

## 引き継ぎ

- 偶数 `q` の無条件上界改善（現在 `q+3`、MDS予想下で `q+1`）が次の課題。
- `liminf K(q)/q` の決定（下界 `0.5`、上界 `1`、測定 `0.65`）。
- k=8 の組み立ての食い違い（K1058 10cm–10cn）は依然未解決。
