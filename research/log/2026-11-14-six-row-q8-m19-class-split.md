# 2026-11-14 高速レーン — 6×19 q=8 欠損極大不在の class-split UNSAT 証明（K0818）

## 背景

- 前回（高速レーン第7回）のレジューム: (6,8) 前線は 6×19（K0815 kissat 単発255s・4.52M conflicts 未決着）。
- K0816（並走five-rowレーン）が 5×20 q=7 の全19正準クラス不在を列挙機+クラス分割SATの2系統で確定。
  同じ「クラス分割」の考えを w=6 に移し、列挙機なしでSAT単独系統＋交差符号化で攻めるのが本回の主題。
- K0817 は別レーンが取得済みだったため本成果は K0818。

## 主成果

**6×19 q=8 に行欠損の極大安全配置は存在しない**（全35行鏡映正準欠損クラスが
class-split SAT で UNSAT・kissat 4.0.4・計15,492,764 conflicts）。K0815 が残した
6×19 未決着を決着。(6,8) の witness 幅は「18あり・19なし」と確定し、
**M_{6,8} ∈ {19} ∪ [21,371]**（下界19はK0815 witness・上界371不変）。
- 運用: 実行環境リセット1回（ワークスペース消滅・6×19スイープ初回分と
  5×22/6×21のINDET観測のrawを喪失）— 6×19スイープ35クラス+全制御を決定的再実行で
  bit-exact復元（conflicts数一致でreproducibilityの傍証にもなった）。
  **成果は逐次pushが正解**（再実行に約25分を要した）。

## 手法と検証

- sat3.js: K0810 sat.js census + sat2.js counter に class 単元節を追加
  （rows∈D は ≤q−2、rows∉D はちょうどq−1）。--krow/--minpos/--lex=H も実装。
- 被覆: 欠損配置の正確な欠損行集合 D が非空部分集合で全欠損配置を分割し、
  行鏡映で35正準クラスに圧縮。
- 交差: 4難クラス {1},{2},{1,2},{2,3} を --lex=H（別節構造）で再UNSAT。
- 制御: 2×8 SAT（5石・K0796再発見）・2×9 UNSAT（M_{2,4}=9整合）・
  6×18 class{1} SAT 41石（K0815 witness盤・511,895 conflicts bit-exact）・
  6×23 q=6 class{1} SAT 29石（K0815 extend6 witness盤をSATで再発見・
  verifyConfig + Python Fraction 2系統PASS・77,932 conflicts）。
- **小盤ground-truth検証**: 3×7/3×8/2×8/2×9/3×9 q=4 全正準クラス19インスタンスが
  全mask列挙の欠損クラス集合と SAT/UNSAT 19/19 一致 — class分割ロジックのend-to-end証明。
