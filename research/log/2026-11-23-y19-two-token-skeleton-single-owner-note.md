## 事前の横断予想（y=6..18 の出版表からの外挿であり y=19 の証明ではない）

- tail: x 偶行（S=x+19 奇 ⇔ x 偶・奇数 y 型で y=1..17 奇数族と同型）・
  R >= x+z+20 = x+z+y+1・値 (x+19) mod 2。tail 開始族式 x+z+y+1 の
  **19 族目候補**（fit level）。box 内の tail 帯は R∈[x+z+20, x+z+40] の
  21 点深（R cap 2y+2=40 拡張の成果）。
- 基底点: {z+1, z+3, ..., z+37} の 19 点（基底点 y 点仮説 {z+1,..,z+2y-1} の
  **19 例目候補**）。
- マージ行: x <= z-20（S = x+19 <= z-1）。マージ命題一般形 x<=z-(y+1) の
  y=19 版（全称確定 y=1..17 の次・fit level **19 族目候補**）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+57)/2・pin offset o_pin=(d+57)/2∈[y+1,2y]=[20,38]
  かつ o_pin≡z+1 (mod 2) の統一式から、奇z は d≡3 (mod 4) の
  **{-17,-13,-9,-5,-1,3,7,11,15,19} の 10 行**・偶z は d≡1 (mod 4) の
  **{-15,-11,-7,-3,1,5,9,13,17} の 9 行**。y 奇族式の pin 行数 (y+1)/2 が
  奇z では 8→9→**10** と増加し、y=19 で **pin 行が 10 行に達する初の族**
  （偶z は (y-1)/2 = 9 で 7→8→9 の継続）。
  **d=-17・d=-13（ともに奇z 行）と d=-15（偶z 行）の 3 行が box 内到達不可能**

  d=-15 は z>=34〔偶z〕を要求し box z<=30 内では幾何学的に到達不能）。

  y=18 は奇z d=-14・偶z d=-16 の 1+1）。監査の pin ゲートは box 内可観測
