## 確認された骨格要素（z ∈ {8,9,10,15,16,21,22}, d = -10..14, R ≤ min(z+34, x+z+26),
offset = R - z ≤ 30、6,613 点の走査で読み取り。z を変えての相対 offset 不変を確認）

- **梯子（ladder）**: 奇 z: O[1,z] / 偶 z: O[1,z-1]（族共通、y 依存なし）✓
- **対角行 d=-y=−10**: 上限 R ≤ z+10（奇 z）/ z+9（偶 z）。すなわち
  cap = z+y-1 if z≡y (mod 2) else z+y。y=9の z+8/z+9、y=8の z+8/z+7 と同一規則 ✓
- **ピン行（T 内の飛び値）**: 位置 pin = z + (d+3y)/2（y=8/9/10で同一式）。
  奇 z は d ≡ y (mod 4)（y=10: d ∈ {-6,-2,2,6,10}、5行、offsets 12,14,16,18,20）、
  偶 z は d ≡ y+2 (mod 4)（y=10: d ∈ {-8,-4,0,4,8}、offsets 11,13,15,17,19）。
  いずれも実測と一致（例: 偶 z=22 の d=0 → pin offset 15 = (0+30)/2 ✓）。
  連続測定: 奇 z ピン下端 offset は y=8:10, y=9:10, y=10:12（y偶: y+2, y奇: y+1）、
  上端 2y。行数は floor((y+1)/2)。
- **sweep 行 d = y+1 = 11**: 奇 z: O[2y+z, x+z+y] = offsets 20..x+10 偶刻み、
  偶 z: O[2y+1+z, x+z+y] = offsets 21..x+10 奇刻み。実測 z=21: {20,22,24,26,28,30}、
  z=22: {21,23,25,27,29} ✓
- **steady pin d ≥ y+2 = 12**: T = ladder ∪ {z+2y}（奇 z）/ {z+2y+1}（偶 z）。
  実測 o12..o14: {20}, e12..e14: {21} ✓
- **BASE = {z+1, z+3, ..., z+2y-1}**: y=10 では 10 点（offsets 1..19 奇）。
  sweep/steady 行で全出現を確認 ✓
- **band**: 下端 z+2y+2 = z+22、上端 x+z+y、R ≡ z (mod 2)、steady pin 位置は除外。
  実測 e11..e14 偶 z: P の偶 offset 22,24,...、奇 z: 偶 offset 22..   ✓
  （= clip 2y+2 = 22 が band 下端として y=10 でも継続、6族連続の見込み）
- **最終ピン行 d=y=10（奇 z）**: P = base ∪ {z+2y+1} ∪ I[z+2y+2]。
  実測 o10 z=21: P = offsets 1..19 奇 ∪ {21} ∪ 22..（全区間）✓（y=9 の d=9 行の同一形）
- **P の無限区間行（I[...]）と有限行の交代**: 区間行は tail と両立する
  x-parity の行のみ（y=10: tail 値 (x+10)%2、ゆえに奇 z では x 奇 = d 偶行が区間、
  実測: o-5, o-1, o3, o8 等。y=9 では x 偶 = d 奇行であり、 族ごとに交代が
  半周期ずれる）。

## 法則の直接的定点試験

- **merge 則**: x ≤ z-11（= z-(y+1)）で H(R;(x,10);z) == single_token(x+10,z,R):
  z=12..27, x=10..z-11, R ≤ x+z+16 → **1,512 点 bad 0**。
  境界 x=z-10（merge の外）は 420 点中 39 点で single_token と不一致
  （= 境界位置がちょうど x = z-11 であることの確認）。
- **tail 則**: d ≥ 12 の行で R ≥ x+z+11（= x+z+y+1）で値 (x+10)%2
  （= (x+y)%2）: z=13..26, d=12..15, w=11..16 → **336 点 bad 0**。

## 一般化候補（y=7..10 の4族でentreprise的に成立する式）

- pin = z + (d+3y)/2、d-class ≡ y (mod 4)（奇 z）/ ≡ y+2 (mod 4)（偶 z）
- 対角 cap = z + y - [z ≡ y (mod 2)]
- BASE = {z+1..z+2y-1} 奇、band = [z+2y+2, x+z+y] (R≡z)、tail = (x+y)%2 for
  R ≥ x+z+y+1、merge 境界 x ≤ z-y-1、sweep d=y+1、steady pin z+2y+[z偶]
- clip 窓 2y+2: y=5..9 tight 済み、y=10 では band 下端 z+2y+2 として出現

これらが**任意の y で成り立つか**は今後の全称目標（当面は次族の fit で
帰納的に裏付けを増やす方針）。
