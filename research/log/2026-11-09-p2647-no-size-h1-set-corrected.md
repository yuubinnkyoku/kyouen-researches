# 2026-11-09 p=2647 のサイズ h+1 = 1324 の集合は存在しない（A(2647) <= 1323）

## 訂正について

- 直前の記録 [2026-11-09-p2647-no-1104-set.md](2026-11-09-p2647-no-1104-set.md) は、
  スクリプト名（p=2207 用の `search_1104_shape_*`）に引きずられて「1104」と書いたが、
  **p=2647 では h = 1323、h+1 = 1324** である。正しい主張は次の通り。
  - 誤: 「p=2647 で 1104 石が存在しない → A(2647) <= 1103」
  - 正: 「p=2647 でサイズ h+1 = 1324 の石が存在しない → **A(2647) <= 1323 = h**」
- 1104 という数字は p=2207（h=1103）の h+1 であり、p=2647 とは無関係だった。

## 正しい結果

サイズ h+1 の集合は `x + c - e = 1`（x: 0 を含む、c: 完全対数、e: 空対数）から 3 形状に限られる。

| 形状 | 内容 | p=2647（h+1=1324） | p=2207（h+1=1104） |
|---|---|---|---|
| (a) | `0` ＋各対一側（完全対なし） | **UNSAT** | **UNSAT** |
| (b) | `0` なし、一完全対＋各対一側 | **UNSAT**（0.2 秒、71,078 節） | **UNSAT** |
| (c) | `0` ＋一完全対＋一空対 | **UNSAT**（8.2 秒、79,017 節） | 未決 |

- **p=2647: 3 形状すべて UNSAT → サイズ 1324 の集合は存在せず `A(2647) <= 1323 = h`**。
  これは上界 `(p+3)/2 = 1325` より 2 小さい。並行レーンの構成下界 `A(2647) >= 1292`（K0711）と併せると
  **1292 <= A(2647) <= 1323**。
- p=2207: 形状 (a), (b) は UNSAT、形状 (c) は未決（長時間の単一 CNF）。

## エンコーダのメモ

- 形状 (b): 各対を {BOTH, LOW, HIGH} の 3 値、BOTH はちょうど 1 個。点の選択を補助変数
  `a_t <=> side_t or BOTH` で表し、原点を含まない禁止四点だけを節にする（0 が無いので原点辺は不要）。
  台形辺（二完全対）は BOTH=1 の制約から冗長なので落とす。
- 形状 (c): 各対を {BOTH, NONE, LOW, HIGH} の 4 値、BOTH=1 かつ NONE=1。原点を含む辺も節にする。
- サイズ h+1 の分類は全形状を尽くすので、3 形状が UNSAT ならそのサイズの集合は存在しない。
