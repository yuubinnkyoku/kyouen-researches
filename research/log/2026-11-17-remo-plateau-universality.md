# 2026-11-17 プラトー全称化 E6U（K0926）

## 発見の経緯

K0925 出版後のレジューム項目「有界 witness 予想の機構」の解析中、r=2..12 の生存者表 sv(C,r) を並べたところ、C <= r-1 の範囲で sv(C,r) = P(C)（K0919 の P(C) ピン列）が行ごとに一致していることに気づいた。これは K0919 実験E6 の「プラトー S(C,r) は r >= C で一定（C <= 24 機械）」の観察と同じ現象だが、表を眺めると構造が読み取れた: run (C,r) はフェーズ1で P_C を落とし、以降 s=C が一定のため ell=0 の「零石カスケード」で上側の石0プレイヤー P_{C+1}..P_{r-1} が順に自動除去される（各フェーズで turn = C mod k = C が C < k の間成立し li = C が常に上側先頭を指す）。これが補題CAS。

さらに r と r+1 の run が同じ正準状態 K_C = (active=[0..C-1], 全1石, 手番0) に合流することから、合流カップリング S(C,r) = S(C,r+1) が示され、帰納で全 r >= C のプラトー E6U が従う。K0919 E6 の open（C <= 24 有限）を全称証明で解決した。

## 内容

- 補題CAS（全称・証明つき）: 零石カスケードの構造。機械検証 r=2..40 × C=1..r-1 全数で違反0。
- 定理E6U（全称・証明つき）: すべての C >= 1, r >= C で S(C,r) = S(C,C) = P(C)。COUPLE（合流と以後の (k,ell,li,loser) 列の完全一致）を r=2..60 × C=1..r-1 全数で直接機械検証、E6U 本体も r=2..60 × C <= min(r-1,40) 全数 + r in {61,97,128}。
- 系: P(C) は r 非依存の普遍関数として正当化、C >= 2 で P(C) = 正準状態 K_C からの生存者。有界 witness 窓 [1,r-1] の生存者列は P(1..r-1) で、K0925 有界 witness 予想は「Q(r) の各真約数 d に対し ∃C in [1,r-1]: S(C+d,r) != P(C)」と同値（WITCONN r=2..24 全真約数で確認・欠落0、r <= 32 は K0925 wit_max_sv から継承）。
- W(d) パターン探索: witness の値は d mod r 単独では決まらない。h*=1 の d = Q/m 型集中は K0925 どおりだが、一般の d に対する単純閉形式は見つからず、主張していない。
