## 事前の横断予想（y=6..12 の出版表からの外挿であり y=13 の証明ではない）

- tail 開始: R >= x+z+14 = x+z+y+1・値 (x+13) mod 2。y=13 は奇数 y で
  値1無限帯・tail 値1 は x 偶行（y=11 型）。
- 基底点: {z+1, z+3, ..., z+25} の 13 点（基底点 y 点仮説の y=13 版）。
- マージ行: x <= z-14（S <= z-1）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+39)/2・pin 行の d は奇z d≡y≡1 (mod 4)・
  偶z d≡y+2≡3 (mod 4)。d 範囲の族式外挿は y=11 の観察則（奇z [-y+2,y]・
  偶z [-y+4,y-2]）から奇z {-11,-7,-3,1,5,9,13} の7行・偶z {-9,-5,-1,3,7,11}
  の6行を予想するが、y=13 固有の過渡は probe データから決定する。
- 対角行 d=-13: 値2上端 cap = z+y−[z≡y (mod 2)]（z odd: 帯 o∈[2,12]・
  z even: o∈[1,13]）。偶z 対角行の値1全欠如（y=8..12 で5族連続）の y=13 での
  判定を data-driven で。
- 掃引行 d=Y+1=14 / 定常行 d>=15: steady pin {z+26}（奇z）/{z+27}（偶z）・
  band 下端 offset 2y+2 = 28・掃引帯は奇z o∈[26, x+13]（偶offset）/
  偶z o∈[27, x+13]（奇offset）。I 行の無限帯開始は y 奇族の 2k+1 型
  （y=10 の 2k 型と対照）。
- K1152 横断観察の判定材料: 奇 z I 帯 th=ceil((d+3y+1)/2) の連続整数掃引と
  「pin スロット=th-1」型（y=11/12 で揃い）が y=13 で揃うか否か。
- clip 窓族式候補 2y+2 = 28（y=5..12 で8族連続 tight・fit 段階では予想のみ）。
