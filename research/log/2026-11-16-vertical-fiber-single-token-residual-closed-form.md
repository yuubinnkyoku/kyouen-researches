# 2026-11-16 単一未飽和ファイバー残余閉形式（κ=1）

高速レーン。[前回の全t最大値定理](2026-11-16-vertical-fiber-all-t-grundy-max.md)が未解決として残した「どの(R;X;z)で残余mex H=2となるか」の第一段階として、未飽和ファイバー1本（単一トークン）の残余値 H(R;(x);z) を全称閉形式で決定した。

## 選定

- 最新main（開始時 HEAD 1828b78b、n11レーンの着地が並走中）と K0832・README・全t定理のreportを確認し、残余閉形式は単一トークンでも未解決・重複なしと確認。
- κ=1の残余再帰は自己完結（H1の子しか持たず、Theorem Tの証明と同じ帰納構造）で、高速レーンの範囲で全称証明まで完結可能と判断。
- 2トークン・一般Xは状態数が増え、cap補題で有限にはなるが今回の1回では証明まで書き切れないため次回課題とした。

## 判定と証明

- 単一トークン閉形式は z=0 / z=x / 1≤z≤x−1 / z≥x+1 の4ケース・帯構造で完全決定される（reportの定理）。値2は「奇数R かつ R ≤ μ(x,z)」に限られ、μ は z=x のとき 2x−1、それ以外は min(x,z) 以下の最大奇数。これは全t最大値定理の残課題（H=2の特徴づけ）の単一トークン切片の完全解である。
- 一般補題2件を同時に確定: 空ファイバー補題 H(R;();z)=0、cap補題 H(R;X;z)=H(R;cap_{R+1}(X);z)（一般多重集合・R帰納で証明、51,975状態で監査）。cap補題により固定Rの残余状態空間は有限になり、一般XへのDP拡張の道が開けた。
- U座標（U = H ⊕ (z mod 2)）でC手のflipがB手へ移動し、1トークンを含まないXではflipが完全に消えることをremarkとして記録。

## 失敗と修正（記録）

- 初版のケース2（z=x）で「偶数R ≤ L−2 → 0」という誤った帯を入れた。V1（グリッド639,584件）で731件、V3（mex恒等式）で570件の不一致が発生し、全てこのケース2由来と特定。正しくは「偶数R ≤ x−1 → 0、偶数R ≥ x → x mod 2」。
- 根本原因は値表の文字列を目視で読んだこと。本レーンで文字列の目視読みはこれで4回目の誤読であり、以後すべて機械的比較で確定させる（今回も不一致リストの[x,z,R,F,H]を出力してプログラム的に特定した）。
- セッション中に実行環境がリセットされローカルの検証器が一度消失した。事前に取得済みのファイル内容出力から忠実に再構築し、再実行でaudit JSONがbyte-identicalであることを確認してから反映した。
