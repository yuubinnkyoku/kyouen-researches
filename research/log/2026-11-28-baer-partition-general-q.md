## 結果

1. **Bruck の Baer 分割定理を q=2,3,4,5,7,8,9 で定義直接・全数機械検証**
   (2つの独立実装・全不変量一致): PG(2,q^2) は Singer 部分群
   <g^(q^2-q+1)> の点軌道により q^2-q+1 枚 (q=2:3, 3:7, 4:13, 5:21, 7:43,
   8:57, 9:73) の disjoint Baer 部分平面 (各 q^2+q+1 点) に分割される。
   各軌道は全直線と 1 または q+1 点で交わり、(q+1)-secant は
   ちょうど q^2+q+1 本。per-orbit 直線プロファイル:
   q=2 {1:14,3:7} / q=3 {1:78,4:13} / q=4 {1:252,5:21} / q=5 {1:620,6:31}
   / q=7 {1:2394,8:57} / q=8 {1:4088,9:73} / q=9 {1:6552,10:91}。
2. **新規 t=2 上界 (witness = 軌道 2 枚の union、全直線交差 >=2 を機械検証)**:
   **PG(2,25) <= 62, PG(2,49) <= 114, PG(2,64) <= 146, PG(2,81) <= 182**
   (いずれも < 3q^2)。PG(2,9) <= 26・PG(2,16) <= 42 は K1373 と同一値を
   独立 witness で再現。
3. **系 (証明つき)**: 分割の k (<= q^2-q+1) クラスの union は
   k(q^2+q+1) 点の k 重ブロッキング。k=2 全 q・k=3 (q=4, 全直線交差 >=3)
   を機械検証。
4. **K1373 の条件付き補題の全域化**: Bruck の定理 (引用: arXiv:2403.13734v2
   Lemma 2.4 / J. Combin. Des. 2024, DOI 10.1002/jcd.21956) により
   disjoint Baer 対はすべての素体冪 q で存在 → **すべての q >= 3 で
   PG(2,q^2) の t=2 min <= 2(q^2+q+1) < 3q^2 が無条件成立**。
   「min = 3n」パターンは平方位数 n >= 9 ですべて不成立。
5. 較正: q=3 の 26 点 witness の直線プロファイル **{2:65, 5:26} は
   K1373 の PG(2,9) witness と完全一致** (別の disjoint Baer 対で同型)。
   q=2 は K1372 Fano census プロファイル {1:14,3:7} と一致。

## 開示 (バグ・障害・理論修正)

1. **パラメータ化の理論誤り (結果出版前に自律検出)**: 初回スクラッチは
   「点 = ker N の μ-元」としたが、K* 剰余類が μ-元を含むとは限らない
   (cube map が全射でない q ≡ ±1 mod 3 で失敗)。剰余類 {gamma^i K*} の
   直接パラメータ化に修正してから実行。
2. **環境リセット 1 回** (既知の file-loss モード) で第1作業 tree 消滅。
   宣言の方法記述から両実装を再実装し再実行した。
3. **多項式剰余の符号バグ** (+v*pp[j]、正しくは -v*pp[j]): 標数 2 でのみ
   符号が一致するため GF(2^n) は全て正しく動いていた。再実装中の
   impl2 q=5 (GF(5^6)) で fail-closed assert (gK^{Q-1} == 1) が捕捉。
   併せて **polygcd の正規化漏れ** (gcd が定数 2 のとき [1] と判定できず
   find_irreducible が GF(5) の全候補を拒否) を発見・修正。
   修正後に生成元位数の完全検証を追加して全 q 再実行。本キットの数値は
   全て修正後コードによる (標数 2 の結果は修正前後で不変であることも確認済み)。
4. 主張の区別: Bruck の定理は引用 (自前の全称証明ではない)。自前の寄与は
   q <= 9 の有限全数機械検証と witness。下界は主張しない。
   標準 11x11 空盤・19 central-reply roots・二石 root {60,27}・
   第三手 {100,108}・S2・全 closure class は全時点 UNKNOWN・verdict 不消費。
