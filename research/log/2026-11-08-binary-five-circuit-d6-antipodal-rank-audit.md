# d=6 二値5点アフィン回路の独立階数監査（2026-11-08）

## 目的
既存の星形判定器を使わず、6次元の全5点集合についてアフィン階数で回路を判定し、変動座標上の対蹠頂点対が一意という定理を監査する。既存の d=6 支持数検査は星形判定に依存していた。

## 手順
`research/experiments/binary-five-circuit-support-audit-20261108/d6_antipodal_rank.cpp` は 64 頂点からの全 C(64,5)=7,624,512 組を列挙。5点のアフィン階数が4であり、どの4点部分集合も階数4の場合のみ極小アフィン従属（回路）と認定する。階数は素数101の有限体で消去する。対象行列は成分0/1、最大5次の小行列式の絶対値は Hadamard 不等式で 5^(5/2)<101 なので、有理数上と同じ階数を返す。判定後、全点で固定の座標を除いた変動座標上で対蹠な頂点対の個数を直接数える。

## 実行
`g++ -O3 -std=c++17 d6_antipodal_rank.cpp -o audit && ./audit`

検査に用いた同じ消去法・全列挙の試験実行結果（約2.3秒）：

```
7624512 22400 22400 0 180
0 0 0 1280 5760 9600 5760
```

1行目は「全5点集合・回路・対蹠対ちょうど1組の回路・違反・固定対(0,63)を含む回路」。2行目は変動座標数0..6別の回路数。

全22,400回路で一意性が成立。固定対を含む回路は180個で、既存の 2 S(6,3)=180 と一致。支持数分布も既存の星形判定器の 1280,5760,9600,5760 と一致する。

## 証拠の範囲
これは d=6 の有限完全列挙であり、全次元定理の独立した全称証明ではない。既存の星形判定器を使わないため、実装の独立性は改善する。知識正本への昇格、リポジトリ全体の回帰検査は未実施。
