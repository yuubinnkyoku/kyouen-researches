# 2026-11-07 剰余放物線の等号証人を 2003..2477 へ保存拡張

- 対象: `Q_p = {(t, t² mod p)}` の安全最大 `A(p)` の等号 `A(p)=(p+3)/2`（K0097、未解決は K0101）。
- 起点: K0101 の 2026-10-17 記録は 2003..2143 を独立検査したと述べるが、証人が repo に未保存だった。
  5..2000 の保存証人（`parabola-equality-extension-20261016`）との間に記録の穴があった。
- 方法: `forbidden_edges.cpp` で禁止四点を整数行列式で厳密列挙し、`clauses_for_pair(p, edges, d)` で
  signed NAE3/4＋原点節の CNF を作り、cadical（WSL、呼び出しごとに `timeout`）で `d=h, h-1, ...` を試す。
  SAT モデルを `{0,d,p-d} ∪ 各対の一方` に戻して等号証人とする。
  独立検証は `verify_witnesses.cpp --modular-filter`（generic 4×4 Leibniz、探索側 3×3 と独立）。
  ジョブ実行環境で pipe が残らないよう、生成器と cadical の出力はファイル経由にした（`probe_driver.py`）。
- 結果: 2003..2477 の奇素数 64 個のうち **62 個**で等号証人を構成・保存。
  `d ≠ h` の例外は 2027, 2399, 2477 の `d = h-1`（他 59 は `d=h`）。
  **2207**（`d=h..h-120` の 121 個を試行、120 UNSAT・1 タイムアウト）と
  **2351**（`d=h..h-5` の大半が 45-240 秒でタイムアウト）は予算内で未発見。非存在の証拠ではない。
- 検証: 全 62 証人で `p n covered checked` を出力（出口 0）。対象四点 4,201,666,014,750 組、
  `sum≡0 mod p` の候補 1,852,639,759 組に直接整数行列式を適用し共円 0 件。
- 含意: 既存の 5..2000 と合わせ **5..2203 の全奇素数**で等号証人が存在（2207 が最初の未発見素数）。
  2213..2477 も 2207, 2351 を除いて証人あり。K0097 の連続範囲を 5..2000 から 5..2203 へ更新した。
  全奇素数での等号（K0101）と `d=h` 例外の特徴づけは未解決のまま。
- 限界: 2207, 2351 は未解決。SAT 予算に依存する探索結果で、非存在や `d` の一意性は主張しない。
  監査は保存証人の安全性のみを検査する。
- 次: 2207 の深い d 走査（h-120 以遠）と 2351 の別ソルバ／長時間予算、`d=h` 例外の分布的特徴づけ。
