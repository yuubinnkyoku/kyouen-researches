# 2026-11-08 剰余仮説の検定（mod 8, mod 12, v2(p−1)）— いずれも有意でない

- 対象: 2003..3100 の 136 素数（浅い d 走査 d=h..h-6 での証人の有無、失敗 16 件）。
  全数走査で確定した不達成は 2207 と 2531 の 2 例のみで、以下は「浅い失敗」を指標にした分析。

## 観察された分布

| クラス | 失敗/総数 | 率 |
|---|---|---|
| v2(p−1)=1 | 10/66 | 15% |
| v2(p−1)=2 | 4/33 | 12% |
| v2(p−1)=3 | 0/20 | 0% |
| p≡1 mod 12 | 1/33 | 3% |
| p≡5 mod 12 | 5/36 | 14% |
| p≡7 mod 12 | 4/32 | 12% |
| p≡11 mod 12 | 6/35 | 17% |
| (p mod 4, p mod 3)=(1,1) | 1/33 | 3% |
| (1,2) | 5/36 | 14% |
| (3,1) | 4/32 | 12% |
| (3,2) | 6/35 | 17% |

## 検定

- v2(p−1) の相関（Cochran–Armitage 型）: r = −0.087、permutation p = **0.37**。
- mod 12 の 4 クラス chi-square: χ² = 3.57、permutation p = **0.32**。
- いずれも **統計的に有意でない**。「p ≡ 1 mod 8（または 1 mod 12）は失敗しにくい」という
  観察は、現在の標本では偶然と区別できない。2897・3041（≡1 mod 8）の失敗例も反証になっている。

## 検出力の見積り

- 失敗率 15% 前後で 3% 対 17% を識別するには、1 クラスあたり 150〜200 素数が必要（粗い見積り）。
  現在は 1 クラス 20〜36 素数で、検出力が足りない。
- したがって「剰余による特徴づけ」を主張するには、あと数倍の素数範囲（3100..6000 程度）の
  浅い走査、または確定した不達成を数十例そろえる必要がある。

## 次の一手

- 浅い走査を 3100 以上へ延ばして標本を増やす（1 素数 3〜5 分、1 プロセスで継続可能）。
- 候補素数の全数走査による確定（p≈2800 では CNF が難しい場合があり、コスト高）。
- 剰余ではなく、証明サイズ・近接違反数などの連続量と不達成の関係を調べる。
