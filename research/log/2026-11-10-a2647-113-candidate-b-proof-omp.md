## 第1部: 候補Bの正当性（健全性・完全性）の証明

### 1.1 記号とエンコーディングの定義

p を奇素数、`h = (p-1)/2`、点集合の universe は放物線
`Q_p = {P_t = (t, t² mod p) : 0 <= t < p}`。
対 i（1 <= i <= h）は点対 `{i, p-i}` を指す。`build(p, edges, x, c, e)`
（search_shape_class.py:34-74）は次の CNF を構成する。

- **対変数**（:37-39）: `v(i,kind) = 4i-4 + {B:1, N:2, L:3, H:4}`。
  B=両点選択、N=両方不選択、L=低側 i のみ、H=高側 p-i のみ。
- **exactly-one**（:42-46）: 各対 i について `[B,N,L,H]` と6個の両立禁止節
  `[-a,-b]`。よって任意の充足割当で対 i の4変数はちょうど1つ真。
- **B の個数 = c、N の個数 = e**（:47-53）: `CardEnc.equals(both, c)`、
  `CardEnc.equals(none, e)`（seqcounter 符号化、補助変数は 4h+1 以降）。
- **点変数** `a_t`（t = 1..p-1、:55-62）: `a_t ↔ (side_t ∨ B_{pair(t)})` を3節
  `[-a,s,b]`, `[a,-s]`, `[a,-b]` で符号化。ここで `pair(t) = t (t<=h)`,
  `pair(t) = p-t (t>h)`、`s = v(pair, L)` または `v(pair, H)`。
  点 0 には変数がない（decode 側で x=1 のとき明示的に加える）。
- **禁止四点節**（:63-72）: `edges`（forbidden_edges.exe が生成する禁止四点
  = 共円または共線な4点パラメータの組）の各 q について、
  (i) `0 ∈ q` かつ `x=0` → 捨てる。
  (ii) q の非零点が同じ対に2つ所属 → 捨てる。
  (iii) 残りは `[-a_t for t in q, t != 0]` を追加する。
  `kept` は追加した節数（p=2647, (1,1,3) で 53,886）。

クラス列挙は `e = x + c + h - size`、`x∈{0,1}`、`c∈{0,1}`（resolve_classes、
assump 側 :64-79。正本 main も同一式）。(1,1,3) は size 1322, h 1323 のとき
`e = 1+1+1323-1322 = 3`。

候補B（assump :138-174）は、この CNF を単一の `Cadical195` に載せ
（:145）、クラスごとに `sweep = [0] if c==0 else ds`（:146）とし、
各 d について `solve_limited(assumptions=[v(d,"B")])`（:152-155）を呼ぶ。
`ds` の既定は `1..h`（parse_ds :45-47）。`conf_budget` で予算を切り、
戻り値は SAT=True / UNSAT=False / UNKNOWN=None。

### 1.2 補題1（割当と点集合の対応）

CNF の充足割当 M に対し、decode（assump :82-94）の規則
`B→{i,p-i}`、`L→{i}`、`H→{p-i}`、`N→∅`、`x=1 で 0 を追加`
で点集合 S(M) を定めると、exactly-one によりこの写像は
「割当で真な対変数の列」と「各対の4択1つの選択」の全単射であり、

  `|S(M)| = x + 2·#B + 1·(#L+#H) = x + 2c + (h - c - e) = x + c + h - e = size`

（#B=c、#N=e は基数制約、#L+#H = h − c − e は exactly-one）。
クラス式 `e = x+c+h-size` と合わせ、**クラスCNFのモデルはサイズ size の
点集合と一対一に対応する**（aux 変数と cardinality 補助変数は
点選択を変えない: `a_t ↔ 選択` は3節で完全に固定され、
seqcounter 補助変数は #B=c, #N=e を強制するだけ）。

### 1.3 補題2（禁止四点節の捨て規則の健全性）

禁止四点の特徴付け（K0334 で既知: 放物線上の相異なる4点が共円または共線
⇔ 4パラメータの和 ≡ 0 mod p。背後は整数4×4行列式が mod p で
非零の Vandermonde 積とパラメータ和の積に一致すること）を使う。

- **規則 (i)**（`0∈q, x=0`）: S(M) は点 0 を含まない（decode は x=0 で
  0 を加えない）ので q ⊄ S(M) が常に成り、節は不要。健全。
- **規則 (ii)**（同じ対に2点）: q が `i` と `p-i` を含むとする。
  q が禁止四点なら和条件より残る2パラメータ j,k は `j+k ≡ -(i+p-i) = -p ≡ 0`、
  すなわち `k = p-j`。つまり q は**2つの完全対**からなる台形辺である
  （0 を含む形は `0+i+(p-i)+j = p+j ≡ j ≠ 0` で禁止四点になり得ない）。
  クラス列挙は c ∈ {0,1} なので、#B=c の割当で S(M) が2つの完全対を
  同時に含むことはない。よって q ⊄ S(M) が常に成り、節は不要。健全。
  （正本 docstring 「Trapezoid edges are redundant because c <= 1」の根拠。）
- **規則 (iii)**（追加する節）: `a_t ↔ (t ∈ S(M))`（補題1）なので
  `[-a_t1, ..., -a_tk]` は「q の非零点がすべて選択される」ことを禁止する。
  x=1 のとき 0 は常に選択されるので、q ⊆ S(M) ⇔ 節が偽。

**結論**（辺リストが正しいという前提のもとで）:
`S(M) が禁止四点を1つも含まない ⇔ M がすべての追加節を満たす`。
したがって**クラスCNFが充足可能 ⇔ 形状 (x,c,e) の安全集合
（サイズ size、完全対 c 個、空対 e 個、x=1 なら 0 を含む）が存在する**。

### 1.4 定理（候補Bの完全性）

c=1 とする。クラスCNFが充足可能なら、ある d ∈ {1..h} が存在して
`CNF ∧ B_d` も充足可能である。

証明: M を充足割当とする。基数制約 `#B = 1` と exactly-one の両立禁止
`[-B_i, -B_j]`（:45-46）により、M で真な B 変数は**ちょうど1つ**存在し、
それを `B_d` とする。M は CNF の全節を満たし、かつ `B_d` を真にするので
`CNF ∧ B_d` を充足する。□

d は一意（witness となる対）。これが「B_d たちが割当空間を分割する」
ことの本体である: モデル集合を `M_d = {M : M ⊨ CNF, B_d 真}` と書くと、
`M_1, ..., M_h` は互いに素（2つ真の B は両立禁止節に反する）で、
∪ M_d = 全モデル（ちょうど1つの真の B が存在）。つまり
`CNF = ⋁_d (CNF ∧ B_d)` がモデル集合の意味で成り立つ。

### 1.5 定理（候補Bの健全性）

ある d で `CNF ∧ B_d` が充足可能なら、クラスCNFは充足可能である。

証明: assumption は一時的な単位節の追加にすぎない。`solve_limited`
の semantics において `assumptions=[B_d]` 下の SAT は
`CNF ∧ {B_d}` のモデルを返し、`∧ B_d ⊨ CNF`（連言強化）なので
そのモデルは CNF をも充足する。□

さらに、スクリプトの SAT 側報告は自己検証的である: SAT のとき
`decode` で点集合を復号し（:161）、**生成した全 928,389 禁止四点と
直接照合**する（:122, :164-165, `safe = not any(q <= cs for q in edge_sets)`）。
この検査は CNF の x=0 枝刈り・台形辺捨て・a_t 符号化のいずれにも
依らず、辺リストそれ自体を根拠に S が安全であることを確認する。
`witness_size == size` も記録で確認できる（W7 で p=101/211 の全 SAT
クラスで実測済み）。よって SAT 側の主張は「エンコーディングの健全性」
とは独立に、証人点集合+幾何検査だけで第三者が検証できる。

### 1.6 帰結（全 d 掃引の判定定理）

c=1 のとき、決定的な（UNKNOWN を返さない）ソルバ呼び出しを仮定すると:

  `すべての d ∈ {1..h} で CNF ∧ B_d が UNSAT ⇔ クラスCNF が UNSAT`

証明: (⇐) 1.4 と対偶: クラス SAT ならある d で SAT。逆に全 d UNSAT なら
クラス SAT ではない（あるモデルは必ずどこかの M_d に入る）。
(⇒) 1.5 と対偶。□

- **c=0 の場合**: 完全対は存在しない（#B=0）ので B_d による分割は空分割に
  なり意味を持たない。スクリプトは `sweep=[0]`、`assumptions=[]` の
  1クエリ（:146, :152）とし、これはクラスCNFそのものの判定である。
  1クエリの SAT/UNSAT がそのままクラス判定。
- **UNKNOWN の扱い**: `solve_limited` は予算切れで `None` を返す。
  UNKNOWN は UNSAT でも SAT でもない。上の同値は
  「全 d の戻り値が False」ときにのみクラス UNSAT を含意し、
  UNKNOWN が1つでも残っている d 範囲については何も主張しない。
  これは実行記録の読み方として重要: full100k の掃引では
  UNSAT 20件・UNKNOWN 485件（d=1..505、第3部参照）であり、
  この時点で「クラス UNSAT」と言う根拠にはならない。

### 1.7 前提と限界（要追加検証として明示）

上の証明は次の前提の上に立つ。それぞれが独立に検証済みであるかどうかを
区別して述べる。

1. **辺リストの完全性**: forbidden_edges.exe が Q_p の禁止四点を過不足なく
  列挙すること。UNSAT 側の正当性はこの前提に依存する（SAT 側は
  `safe_against_edges` が同一リストを根拠に検査するので、証人の安全性は
  「リストの過剰」には左右されないが「リストの欠落」には左右される）。
  和条件にもとづく生成器の健全性は K0334/K0712 の証明と小素数での全列挙
  回帰（K0712 の 19,392 三値割合一致）で支持されるが、p=2647 の
  928,389 辺の完全性の独立再列挙は本証明の範囲外。**要追加検証**（既存
  の geometry 検査資産との突合は K0711 の下界検査で実績あり）。
2. **台形辺捨て**: 和条件（K0334）と c<=1 のみから導いた（1.3 規則(ii)）。
  これは論理として閉じている。仮に和条件の証明を本証明に取り込むなら
  K0334 の「行列式 = Vandermonde積 × 和」の合同式確認が必要。
3. **基数符号化の正しさ**: pysat `CardEnc.equals`（seqcounter）の健全性・
  完全性は外部ライブラリの性質であって、本証明では前提とする。
  小規模での直接照合（K0712 の 444 cardinality ケース）が支持検査。
4. **ソルバの健全性**: Cadical195 が UNSAT を返すなら入力CNFが本当に
  UNSAT であること、および assumption の semantics が 1.5 の解釈通り
  であること。これも前提であり、監査可能な形にするには第2部の DRAT 証明
  が必要（assumption-UNSAT は単体の DRAT 証明にならない、§4 留保）。
5. 実験的検証（W7: p=101 の31クラス、p=211 の48クラスで完全一致）は
  上の論理の**支持検査**であって証明の一部ではない。本部はエンコーディング
  定義からの論理として独立に成立する。

## 第2部: (1,1,3) 判定を監査可能にする証明書計画

前提: 全 d 掃引（d=1..1323, c=1）が完走した将来の時点で、
「クラス (1,1,3) は UNSAT、ゆえに A(2647) <= 1322」を第三者が監査する。

### 2.1 assumption-UNSAT のレコードだけでは不足な理由

full100k / probe1m の JSON レコードが保持するのは
`{class, d, sat, unknown, seconds, budget}`（assump :157-159）であり、
このうち判定に使える主張は「Cadical195 が予算内で UNSAT と報告した」
という**ソルバの内部状態の報告**である。これを第三者検証可能にするには
次がすべて欠けている:

1. **UNSAT の証明がない**。通常モードの CaDiCaL は DRAT 形式の
   反駁証明を出力できるが、assumption（`solve_limited` の仮定）は
   証明オブジェクトに含まれない。assumption はソルバ内で一時的な
   単位節として振る舞うため、「CNF ∧ B_d が UNSAT」であることは
   学習節の上では使われているが、DRAT ファイル自体は
   **元のクラスCNFに対する空節の導出**として valid である保証がなく、
   通常そのような導出は存在しない（クラスCNF単体は SAT の可能性を
   排除できない – 実際、d 掃引が全 UNSAT になるまで決まらない）。
   これは W7 log §4 の既知の留保である。
2. **検証対象のCNFが固定されていない**。レコードには `vars/clauses/kept`
   の件数しかなく、CNF バイト列そのものが監査者の手にない。
   件数一致だけでは節の内容の同一性を保証しない。
3. **再現性がない**。学習節の共有する単一ソルバの探索は、
   呼び出し順（d の順序、再開の切り方）に依存し、
   `seconds` 以外に check 可能な出力がない。

したがって監査可能な UNSAT 判定のためには、**d ごとに独立な CNF を
ディスクに固定し、それぞれについて独立な DRAT 反駁を取り、独立な
チェッカで検証する**のが要請される。

### 2.2 候補A方式（d 固定 CNF + DRAT 証明）の手順

クラス (1,1,3) の CNF は 17,180 変数 / 90,891 節 / kept_edges 53,886
（full100k/probe1m JSON の `classes` フィールド実測値）。手順:

1. **CNF 生成**: `build(2647, edges, 1, 1, 3)` の出力に単位節 `[B_d]`
   （`v(d,"B") = 4d-3`）を追加した `cnf_d` を書き出す。
   d=1..1323 について 1,323 ファイル。
   代替（より小さいCNF）: K0712 の三値（L/H/E）+ `d` 固定の直接投影節
   `T_d` の方式。こちらは exactly-one を3変数に縮約する分小さく、
   同等の全称証明（K0712）を持つ。(1,1,3) は空対 e=3 の数制約を
   別途付ける必要がある点だけが差分。
2. **求解**: 各 `cnf_d` を CaDiCaL で解き DRAT 証明を出力
   （`-o proof_d.drat` 相当、正本の候補Aの呼び出しに従う）。
   全部 UNSAT であることを求解側が報告する必要がある。
   **注意**: full100k の UNSAT 20件は 0.08–46.2 秒で UNSAT を返す一方、
   485件は UNKNOWN である。仮定としている「全 d UNSAT」自体が
   未確定であり、本計画はその時点での話である。
3. **検証**: 各 `proof_d.drat` を DRAT-trust / drat-trim 相当の
   チェッカで検証し、`VERIFIED` と終了コード0を記録する。
   チェッカのソース SHA256 を記録に残す。
4. **集計と公式化**: 1,323 件すべて VERIFIED なら、
   第1部の定理によりクラス (1,1,3) は UNSAT。
   同様の監査済み UNSAT が (0,1,4), (1,0,4), (0,0,5)（サイズ 1322 の
   残りクラス、e = x+c+h-1322 で算出）にも必要で、4クラス合計で
   「サイズ 1322 に安全集合なし」= A(2647) <= 1322。

**件数とサイズの概算（既存の実績値に基づく）**:
repo 内のサイズ 1323 クラス（p=2647, d=1..1323）の DRAT 監査
`drat_audit_full_2647_34249932790a9e9d.json` の実績:

- 1,323 レコードすべて `verified: true`（checker_out "VERIFIED", rc=0）
- proof_lines: 合計 8,038,838 行、最大 52,650 行、中央値 1,177 行
- 求解: 合計 377.5 秒。DRAT チェック: 合計 9,968.9 秒（最大 79.3 秒/件）

チェック本体は 1 件あたり数秒–1分強で、単純合計約 2.8 時間
（並列化すれば実時間は1/NCPU）。proof_lines は DRAT 形式の
行数であるため、ファイルサイズは行あたり数十–数百バイトとすると
1 クラスあたり数百 MB オーダー以下に収まる見込み
（[INFERENCE] - 行数の実測はあるがバイト数は実測していないため、
保存容量は要確認）。d 固定の (1,1,3) CNF はサイズ 1323 の d 固定
CNF と同規模（90,891 節 vs 53,886 節の kept_edges は x=1 の枝刈り分
だけ小さい）なので、チェック時間も同オーダーと予想される
（[INFERENCE] - 実測ではなく、同型監査からの外挿）。

### 2.3 SAT が出た場合の証明書

ある d で `CNF ∧ B_d` が SAT なら、その時点でクラス (1,1,3) は SAT
（第1部 1.5）であり、A(2647) >= 1322 が確定する。この場合の証明書は
**ソルバ証明よりもはるかに軽い**:

1. **証人点集合**: SAT モデルから decode した点集合
   `points`（assump :161, :167）をそのまま保存。
2. **幾何検査**: 証人候補 S について、独立実装の整数幾何検査器
   （K0711 の `verify_subset.cpp` 相当 - 4×4 整数行列式、または
   K0334 の和条件フィルタ+行列式の二段構え）で
   「S の任意の4点が共円・共線でない」ことを全 C(|S|,4) 組で検査。
   |S|=1322 なら C(1322,4) ≈ 1.26×10^11 組で、和条件フィルタを
   使えば実行可能（K0711 の 1296 点証人で 44,277,012 候補に絞った
   実績値がそのまま規模の指針）。
3. **十分性の根拠**: 第1部 1.5 のとおり、SAT 報告の検証にエンコーディング
   の健全性は不要である。S が安全な点集合として実在し、
   `witness_size` が 1322 であれば、それ自体が
   「クラス (1,1,3) が充足可能」の完全な証明になる。
   エンコーディングの completeness は不要（証人の実在が命題の実現）。
   したがって「SAT の証明書 = 点集合 + 独立幾何検査」で十分。

### 2.4 知識体系（K0711/K0712 形式）との接続

- K0711 は p=2647 の上下界 1296 <= A(2647) <= 1322 の proposition
  item。上界 1322 の根拠は「サイズ 1323 の 4 形状クラス UNSAT」
  （ソルバ主張 + receipts）である。(1,1,3) はその**下のサイズ 1322**
  の未決着クラスであり、これが UNSAT と確定すれば上界はむしろ
  **1321 に強まる**（サイズ 1322 に安全集合が存在しなくなるため）。
  逆に SAT なら 1296 <= A(2647) = 1322 に確定する。
  つまり (1,1,3) 判定は K0711 の上下界を直接更新する知識にあたる。
- K0712 は「原点+完全対固定の安全集合は三値SATへ厳密還元できる」
  proposition（status: proved, 全称証明つき）。候補Bの `B_d` assumption
  は「d が完全対である場合の分割」であり、第1部の定理と K0712 の
