# 2026-11-22 n11 S4 fresh-regeneration pass-1 raw audit (k021-k040)

## Scope

Read-only integrity audit of the 20 first-pass replay records `k021`–`k040` in the fresh-corpus regeneration lane. All inputs and outputs were fetched at the pinned snapshot commit `37bc365ab89ace7b9315ef36eeb6f5048537d583` (pass-1 raw checkpoint k021-k040). No solver was run, no verdict cache was changed, and no claimed key was probed.

## Checks

For each of the 20 input/output pairs:

- exactly one non-comment input row and one `replay,` output row;
- `# replay_done` present, and no `replay_error`;
- input/output key, stone count, and legal-move count agree **as exact decimal strings**;
- order=0, is_or=0, budget=15,000,000, result=2, and nodes ≤ budget;
- the key belongs to the frozen 106-child boundary `children106` in `corpus-def.json`.

The 106 child pairs were extracted from JSON as decimal token strings, not parsed through JavaScript Number. This matters: the 64-bit key masks exceed Number's exact-integer range. An initial Number-based membership attempt falsely reported non-membership; it was discarded and the checks were rerun with exact strings.

All checks passed: **20/20 input/output rows and 20/20 exact child-boundary memberships**, zero mismatch.

## Interpretation / limitations

This confirms raw-file/input consistency, completed-row markers, and frozen-boundary membership for the first-pass records. It does **not** validate the solver verdict independently, establish pass-2 determinism, or authorize cache consumption. The fresh-regeneration lane's acceptance gates remain in force; S4 closure, 119/119 move coverage, and the regenerated root certificate are not established by this audit.
