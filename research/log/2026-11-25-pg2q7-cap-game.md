# 2026-11-25 第9ラウンド: PG(2,7)・AG(2,7) のキャップ・ゲーム完全解

## 出発点

第8ラウンドで K1298 の parity 特性定理から「`PG(2,7)` の s=2 は極大アークが
6 と 8（両方偶数）なので Grundy は {0,1}」と予測した。今回は完全計算で確かめ、
さらに `AG(2,7)` のキャップ・ゲームも解いた。

## 手法

既存の `grundy_full.c`（s=3 固定）を **s 可変**にしたコピー
`scripts/grundy_s.c` を作成（`if (++cnt[c] == s_cap)`、位相 2 の
`popcount(mask & cmask[c]) >= s_cap`、s はコマンドライン引数）。64-bit マスクで n≤64。

## 結果

### PG(2,7), s=2

- 安全局面 **2,446,460**（Python DFS の独立カウントと一致）。
- 極大: サイズ **6: 625,632**、**8: 16,758**（円錐曲線）。中間サイズなし。
- 完全 Grundy: `0: 1,347,823 / 1: 1,098,637`（偶数/奇数サイズの数に一致）。
  `G(∅)=0`、misère=1。**予測どおり graded で {0,1}**。

### AG(2,7), s=2（v=49）

- 安全局面 **1,108,724**。
- 極大: **6: 271,656**、**7: 2,352**、**8: 6,174**。パリティ混在。
- 完全 Grundy: `0: 581,827 / 1: 477,505 / 2: 49,392`。`G(∅)=0`、misère=1。
- 定理の予測どおり Grundy 2 が出現。

## 意義

- 同じ q=7 でも PG はパリティ一様（6,8）で {0,1}、AG は 7 を含み混在で 2 が出現。
  盤の幾何（極大アークのサイズのパリティ）がそのままゲームの複雑さになる。
- キャップ・ゲームの完全 Grundy を v=57 / 49 まで拡大（2.45M / 1.11M 局面）。

## 検証

- キャップ数は Python DFS とエンジンで一致。PG の Grundy 分布が偶数/奇数サイズの
  数に一致することを確認。
- サブエージェント独立検証を依頼（結果は追記）。
