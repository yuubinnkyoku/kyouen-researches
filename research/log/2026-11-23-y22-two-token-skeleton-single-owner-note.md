## 事前の横断予想（cand22 コード意味論からの機械確認であり y=22 の証明ではない）

以下はすべて seed コード翻訳（cand20 → cand22）の機械的語・族式外挿であり、
出版物の表からの読み替えではなく cand22 コードの意味論から宣言前に機械確認済み
（verify_structure_y22.py・raw エンジンは deep smoke 1 回を除き未使用）:

- tail: x 奇行（S=x+22 奇 ⇔ x 奇・偶数 y 型で y=10..20 と同型）・
  R >= x+z+23 = x+z+y+1・値 (x+22) mod 2。tail 開始族式 x+z+y+1 の
  **22 族目候補**（fit level）。
- 基底点: {z+1, z+3, ..., z+43} の **22 点**（基底点 y 点仮説の
  **22 例目候補**）。
- マージ行: x <= z-23（S = x+22 <= z-1）。マージ命題一般形
  x<=z-(y+1) の y=22 版（全称確定 y=1..21 の次・fit level **22 族目候補**）。
  box 内 0 行は事前導出。
- pin 格子: pin = z+(d+66)/2 = z+(d+3y)/2・pin offset o_pin=(d+66)/2∈[23,44]:
  z 偶奇で d の mod-4 クラスは y=20 の 0/2 からローテーションし、y=22 は
  奇z が d≡2 (mod 4) の **{-18,-14,-10,-6,-2,2,6,10,14,18,22} の 11 行**・
  偶z が d≡0 (mod 4) の **{-20,-16,-12,-8,-4,0,4,8,12,16,20} の 11 行**。
  **両偶奇が同時に 11 pin 行に到達するのは系列初**（y=21 が単一偶奇側で
  初の 11 に到達した直後・奇z 側 11 行の偶数 y 族での初到達でもある）。
  **box 外 pin 行は合計 6 行で各偶奇側とも 3 行は系列初**: 奇z は
  d=-18（z>=40）・d=-14（z>=36）・d=-10（z>=32）の 3 行、偶z は
  d=-20（z>=42）・d=-16（z>=38）・d=-12（z>=34）の 3 行が box 内

  (42,22)/(38,22)/(34,22)〔偶z〕の生値全点照合（R<=130）に委任する。
- pin スロット: 奇z pin 行は I 行（d 偶）上の off=2k=th-1 をちょうど占有
  （「pin スロット=th-1」y=11..21 の 11 族連続の続き **12 族目候補**・11 行
  すべてで 2k(d)=o_pin(d) の算術的恰好を seed コード翻訳から機械確認済み）。
  偶z pin 行は base 行（d 偶）上の 2k+1 位置（base 上端 2k-1 の +2 位置・
