### 2.0 記法と基本補題

ゲームの規約 (K1138 出版再帰の転写・kit engine と同一 bytes): 位置 H(R;X;z)
の選択肢は (A) トークン v>1 を v→v−1 (R→R−1・z 不変)、(B) トークン 1 の除去
(R→R−1・z→z+1)、(C) z>=1 のとき平面 z→z−1 (子の値に 1^ を適用)。
H(0;X;z)=0。mex をとる。

基本補題 (いずれも出版済み、本ノートで再証明しない):
- **(B1) K0832**: 単一トークン閉形式 v(x,z,R) = H(R;(x);z) (全称)。
- **(B2) K1312 L-2**: H(R;();z) = 0 (全称)。
- **(B3) K1264 階段定理**: 空でない任意の有限多重集合 X・z>=0・
  0 <= R <= z+min(X) に対し H(R;X;z) = v(ΣX,z,R) (全称)。
- **(B4) K1319 §1/§2**: z=14 floor-9 セル表 F14f9..A214f9
  (F14f9 = {14: 1・他 v(s+1,14,16)}・G14f9 = {12: 0・14: 2・他
  v(s+2,14,17)}・E14f9 = {12: 1・他 v(s+3,14,18)}・D14f9 = {10: 0・12: 2・他
  v(s+4,14,19)}・C14f9 = {10: 1・他 v(s+5,14,20)}・B14f9 = {10: 2・他
  v(s+6,14,21)}・A14f9 = v(s+7,14,22) (deviant なし)・A214f9 = v(s+8,14,23)
  (deviant なし)・いずれも床 9・s ∈ {0}∪{9..}・アリティ任意・全称) と定理
  T-Z14 (m>=9: H(m+15;X;14)=v(ΣX,14,m+15)・全称)。紙面証明は K1319 宣言
  ノート §2 に全文出版。本ノートの battery D3 はその表を engine に対して
  独立再照合する — K1319 公式検証の完了状態に依存しない。

**補題 S-rec (全称・2 行証明)**: x >= 2 のとき
H(R;(x);z) = mex{ v(x−1,z,R−1), [z>=1] 1^v(x,z−1,R−1) }。
x = 1 のとき H(R;(1);z) = mex{ 0, [z>=1] 1^v(1,z−1,R−1) }。

C 手の子は 1^H(R−1;(x);z−1) = 1^v(x,z−1,R−1)。∎

すなわち **s=0 は全 9 セルで崩壊しており条件を一切必要としない**。

### 2.1 諸定義と選択肢の列挙 (全 j に共通・全称)

  >= 10 > j−1 なので min は j−1)。
  j=1 の B 手 (1 の除去): 子 (16; Y; 16)。**補題 BB** により子の値
