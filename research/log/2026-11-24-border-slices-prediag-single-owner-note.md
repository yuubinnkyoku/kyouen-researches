## 用語・記法（repo 標準に準拠）

- 局面: H(R; X; z)。X = 多重集合、R = 予算（残り手数）、z = pass 残数。
  H は Grundy 値。手は A（トークン w>1 を w−1 へ・R → R−1）/ B（row-1
  トークン除去: z → z+1・R → R−1）/ C（pass: z≥1 で子の値は 1 XOR・
  R → R−1）。正当な局面は R ≥ 0（R<0 の cell は存在しない）。
- ペア: X = (m, m+g)、g ≥ 1。**対角座標** k := R − 2m − g。**δ座標**
  δ := R − 2m（本ノートが導入する z0 面の崩壊座標）。
- 床: b_z(j) := H(2m+j; (m,m); z)。b_z が m に依存するかは主張の一部。
- 単一トークン閉形式 v(x, z, R)（K0832 公刊・機体 engine_block に verbatim 収録）。
  q_odd(z) = z（z 奇数）/ z−1（z 偶数）。読み: z=0 は min(R,x)%2。
  z=x: R 奇数かつ R ≤ 2x−1 → 2、R 偶数かつ R ≤ x−1 → 0、他は x%2。
  1 ≤ z ≤ x−1: m := q_odd(z)、R ≤ m → (R 奇数 ? 2 : 0)、m < R < x+z →
  (R+z)%2、他は x%2。z ≥ x+1: m := q_odd(x)、R ≤ m → (R 奇数 ? 2 : 0)、
  他は x%2。
- [P] = 1 if P else 0。
- 有限観測 (OBS) と全称定理 (THM) を明確に区別する。

## §2 証明

### §2.0 型付き子解析と帰納の原理

ペア P = (R; (m, m+g); z) の手は次の型のみ（族の閉性・エンジン規則
 A/B/C の直接の場合分け）:

- **fall**（下側トークン m、m ≥ 2）: P → (R−1; (m−1, m+g); z)。
  gap が g+1 になり、対角座標 k は不変、δ は δ+1。
- **B**（m = 1 の下側除去）: P → (R−1; (g+1); z+1) 単一トークン。
- **compress**（上側トークン m+g、g ≥ 2）: P → (R−1; (m, m+g−1); z)。
  gap g−1、k 不変、δ−1。
- **corner**（上側トークン m+1、g = 1）: P → (R−1; (m, m); z) 床。
- **C**（z ≥ 1）: P → (R−1; (m, m+g); z−1)、値は 1 XOR。

全ての子は予算 R−1。よって主張パケット（T-PD0・T-B0・T-Z1・T-B1・T-Z2・
T-B2・および単一トークン閉形式〔公刊 K0832・帰納外〕）に対し
**R に関する強帰納法**で同時証明できる（面間依存 z2 → z1 → z0 も常に
予算 R−1 の下位参照）。基底部: R = 0 では選択肢集合は空で H = 0
（正しい: z0 は f0(−2m) = 0〔m ≥ 1 で −2m は偶数 ≤ 0〕、その他の面の
 主張は R = 0 では空位〔k ≤ −3 / j ≤ −2m の範囲外〕）。

各主張の帰納段で「子の値の集合の mex が主張値に一致する」ことを
case analysis で確認する。この mex 算術そのものを機体 verify_k1286 の
typed 機構（D2/D3/D4/D5/D6: 申立テーブル**のみ**から子の値を構成し
mex を取り、主張値とエンジン値の双方と照合）が有限範囲で機械照合する。
以下の case 表は手証明の全 case に対応する。

### §2.1 B-uniformity 補題（L-BU0/1/2・K0832 からの直接計算）

m = 1 の B 子（単一トークン w = g+1、予算 t = R−1、面 z+1）の値が、
m ≥ 2 の fall 子に対応する表の値と一致すること:

- **L-BU0**（z0 面）: ∀ w ≥ 2, 0 ≤ t ≤ w: v(w, 1, t) = f0(t)。
  証明: w ≥ 2 で z = 1 は 1 ≤ z ≤ x−1 の場合、m := q_odd(1) = 1。
  t = 0 は R=0 値 0 = f0(0)。t = 1 ≤ m: R 奇数 → 2 = f0(1)。
  2 ≤ t < w+1: (t+1)%2 = [t even] = f0(t)（t ≥ 2 の f0 は [even]）。
  t = w+1 以降は本ノートで使わない（B 子の予算は常に t = δ+1 = R−1 で、
  z0 帯では R ≤ 2m+g、m=1 では t ≤ g+1 = w が成立）。
- **L-BU1**（z1 面）: ∀ w ≥ 2, k ∈ {−1,0,1}: v(w, 2, w+k) = Z1(k, w)。
  証明: w = 2 は z = x の場合: t = w+k ∈ {1,2,3}: t 奇数かつ ≤ 2x−1 = 3
  → 2（k=−1: Z1(−1,2)=2 ✓、k=1: Z1(1,2)=2 ✓）、t = 2 は偶数かつ
  ≤ x−1 = 1 に非該当 → x%2 = 0 = Z1(0,2) ✓。w ≥ 3 は 2 ≤ z ≤ x−1
  の場合、m := q_odd(2) = 1、t = w+k ≥ 2 > m、t < x+z = w+2:
  値 (t+2)%2。k=−1 (t=w−1): (w+1)%2 = [w even] = Z1(−1,w)（w ≥ 3）✓。
  k=0 (t=w): (w+2)%2 = [w odd] = Z1(0,w)（w ≥ 2）✓。
  k=1 (t=w+1): (w+3)%2 = [w even] = Z1(1,w)（w ≥ 3）✓。
- **L-BU2**（z2 面）: ∀ w ≥ 2, k ∈ {0,1,2}: v(w, 3, w+k) = Z2(k, w)。
  証明: w = 2 は z ≥ x+1 の場合、m := q_odd(2) = 1、t = w+k ≥ 2 > m →
  値 x%2 = 0: Z2(0,2)=0 ✓ Z2(1,2)=[2 odd]=0 ✓ Z2(2,2)=0 ✓。
  w = 3 は z = x の場合: t ∈ {3,4,5}: t 奇数かつ ≤ 2x−1 = 5 → 2
  （t=3: Z2(0,3)=2 ✓、t=5: Z2(2,3)=2 ✓）、t=4: 偶数かつ ≤ x−1 = 2
  に非該当 → x%2 = 1 = Z2(1,3) = [3 odd] = 1 ✓。w ≥ 4 は 3 ≤ z ≤ x−1
  の場合、m := q_odd(3) = 3、t = w+k ≥ 4 > m、t < x+z = w+3:
  k=0: (w+3)%2 = [w even] = Z2(0,w)（w ≥ 4）✓。k=1: (w+4)%2 =
  [w odd] = Z2(1,w) = [w odd] ✓。k=2: (w+5)%2 = [w even] =
  Z2(2,w)（w ≥ 4）✓。

機体 D2c/d/e が w ≤ 30 で閉形式・表・エンジンの三方照合を行う。

### §2.2 T-PD0 + T-B0（z0 面・自己完結）

帰納段: P = (R; (m, m+g); 0)、1 ≤ R ≤ 2m+g、δ = R−2m。
選択肢はちょうど2つ（A または B の「下側」と、compress または corner
の「上側」）:

- 下側: m ≥ 2 なら fall 子 → δ' = δ+1 のペア（予算 R−1 ≤ 2(m−1)+(g+1)
  なので帯内）→ 帰納値 f0(δ+1)。m = 1 なら B 子 → 単一トークン
  v(g+1, 1, R−1) = f0(δ+1)（L-BU0: t = R−1 で、m=1・R ≤ 2+g より
  t ≤ g+1 = w、t ≤ w 成立）。
- 上側: g ≥ 2 なら compress 子 → δ' = δ−1 → f0(δ−1)。g = 1 なら
  corner 床 (m,m)@(R−1; 0)、slice j = δ−1 ≤ 0 → T-B0 帰納値 f0(δ−1)。

ゆえに H(P) = mex{ f0(δ+1), f0(δ−1) }。δ についての場合分け:

| δ | 子の値集合 | mex | f0(δ) |
|---|---|---|---|
| 1 | {f0(2), f0(0)} = {1, 0} | 2 | 2 ✓ |
| 0 | {f0(1), f0(−1)} = {2, 1} | 0 | 0 ✓ |
| 2 | {f0(3), f0(1)} = {0, 2} | 1 | 1 ✓ |
| ≥3 奇 | {1, 1} | 0 | 0 ✓ |
| ≥4 偶 | {0, 0} | 1 | 1 ✓ |
| −1 | {f0(0), f0(−2)} = {0, 0} | 1 | 1 ✓ |
| ≤−2 偶 | {1, 1}（δ±1 は奇 ≤ −1）| 0 | 0 ✓ |
| ≤−3 奇 | {0, 0}（δ±1 は偶 ≤ −2）| 1 | 1 ✓ |

全 δ ≥ −2m（R ≥ 0）で一致。基底部 R = 0: mex ∅ = 0 = f0(−2m)（m ≥ 1
で −2m ≤ 0 偶数）。∎（z0 面はどの子も z0 に留まるので自己完結）

床 T-B0 の帰納段: (R; (m,m); 0)、R = 2m+j、j ≤ 0、R ≥ 1。2 トークンが
同値なので選択肢は1種類のみ: m ≥ 2 なら A 子 (m−1, m)@R−1（gap 1、
δ_child = j+1、帯内）→ f0(j+1)。m = 1 なら B 子 v(1, 1, R−1):
t = j+1 ∈ [0, 1]（R ≥ 1 → j ≥ −1）、v(1,1,0) = 0 = f0(0)、
v(1,1,1) = 2 = f0(1)（ともに閉形式の z = x の場合）。よって
H = mex{f0(j+1)}: j = 0 → mex{2} = 0 = f0(0)、j ≤ −1 なら
f0(j+1) は (j+1 の偶奇) で [j+1 even] → 子 0 → mex 1 = f0(j) = [j odd]
= 1（j 奇数 ✓）、[j+1 odd] → 子 1 → mex 0 = [j even] ✓。∎

- C: z1 床 (m,m)@(R−1; 1)、slice j−1 → **1 XOR b1(j−1)**。

mex 表:

- m ≥ 2: j=0: {Z2(0,1)=1, 1⊕b1(−1)=1⊕0=1} → {1} → mex 0 = b2(0) ✓;
  j=1: {Z2(1,1)=1, 1⊕b1(0)=0} → {0,1} → mex 2 = b2(1) ✓;

  j=2 (R=4): {v(1,3,3)=1, 1⊕b1(1)=1} → {1} → mex 0 ✓ ∎

### §2.5 well-founded 性

全帰納段で全ての子は予算 R−1（fall/B/compress/corner/C いずれも）。
