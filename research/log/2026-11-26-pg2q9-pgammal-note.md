# 2026-11-26 第27ラウンド: q=9 の PΓL に関する構造メモ＋統合チェック

## PG(2,9) の 5-キャップは PΓL でも融合しない

- PGL(3,9) の 5-キャップ軌道は 2 個で、サイズは **10,614,240** と **4,245,696**（K1305）。
- Frobenius φ（GF(9): x→x³、位数 2）は PGL を正規化するので、φ は PGL 軌道を
  同じサイズの PGL 軌道に写す。
- 2 つの軌道はサイズが異なり、同サイズの他の軌道はないため、φ は各軌道を保存する。
  → **PΓL(3,9) でも 5-キャップは 2 軌道**（融合しない）。
- 同様に、q=9 の conic 6-キャップの 2 クラス（10,614,240 と 1,769,040）も
  サイズが異なるため φ で保存される。
- 注意: 「サイズの割り算」だけでは融合を排除できない（K1330 の検証で判明）。
  ここでは **φ が PGL 軌道を同サイズの軌道に写す** ことを使っている。
