# 単一オーナー宣言: 7×7 極大安全配置の k=8 以降の行の空/非空判定（SATブロック方式）（2026-11-22）

- 宣言時刻: 2026-11-22T08:16:56Z（実時計測）
- 観測HEAD（宣言時点の最新main）: `d9c59583662df5f1b98d81c5bc9487aa8eb2edca`
- 単一オーナー: 本ノートをpushする高速レーンセッション（他セッションは本スコープに着手しないこと）
- 対象: 標準共円盤（q=4・禁止四点組=同一線上または同一円上の4点）の **7×7 盤の
  石数 k=8 の行（8石極大安全配置の存在/不在）**、予算が許せば k=9 以降へ段階的に
  伸ばす。n=8 の k=9 行は延伸対象（INDET満了は正直に記録する）。

## 既知事実（再現・引用であって本宣言の新規主張ではない）

1. 7×7 の7石極大安全配置の完全カタログは16配置・D4軌道2（K1224・出版済み）。
   SAT符号化（enc_sat2 v2.1出版正本）での全解列挙は lex-leader 2モデル:
   O1 `[10,13,14,17,19,21,45]`・O2 `[18,21,22,26,31,32,38]`（0-based cell index、
   c = x + 7y）。
2. n7 k=6 以下は完全列挙で見つからず s_7=7（K1224・出版済み）。
3. よって at-most-k（k≥8）符号化のモデルで石数≤7のものは、lex-leader制約上
   この2モデルに限られる。

## 方式（本宣言のスコープ）

- 符号化: 出版正本 enc_sat2.mjs v2.1（byte同一・sha256記録）をそのまま使い、
  **O1・O2 の2ブロック節**（各モデルの7石全部立を禁止する各7リテラル節）を付加した
  CNF を kissat 4.0.4（公式 linux-amd64・md5 `3a5eba830aa6008a604fcc9bbe99a325` /
  sha256 `21da5d984e38b74f620f14c62442f834f27b9158decdb722540d97f98aac93a1` でピン。
  repo内バイナリ再出版なし）で解く。
- 健全性: ブロック節は「7石ちょうどO1/O2である割当」のみを除去する。既知事実3により
  at-most-kの≤7石モデルはO1/O2のみなので、ブロック後のat-most-8モデルは全て
  石数8ちょうど（k>8の走行は直前の行が空だった場合のみ意味を持ち、その場合も
  同じ議論で石数はkちょうど）。UNSATなら行は空、SATなら witness が行の非空虚。
- 補題不要: 「極大安全集合族は反鎖」等の構造補題は本方式の健全性には使わない
  （O1/O2を含む8石安全配置は存在し得ないという主張は使わず、ブロックが除去するのは
  割当のみで、行判定は純粋に「at-most-k ∖ 既知≤7石モデルの残り」の充足性）。
- 注意（主張の限定）: 行の空/非空は行ごとの判定であり、**M_7 の確定を意味しない**
  （3×3の例のとおり行は空みを持ち得る: n3は行5のみ非零・行1..4は空、K1225）。
  非空なら M_7 ≥ k が従うのみ。空の行は「k石ちょうどの極大安全配置が不在」の意味で
  あり「全行を確定した」ではなく、空行の連鎖で打ち切る。

## 受入条件（acceptance conditions）

1. **較正（陽性対照）**: ブロックなし at-most-7 が SAT でモデルが O1 と一致すること
   （本環境で実況済み・記録する）。かつ O1・O2 をブロックした at-most-7 が
   UNSAT（2ショット一致）であること（≤7石モデルがO1/O2のみであることの再導出）。
2. **UNSAT主張**: 各行のUNSATは default と `--shuffle=42` の独立2ショットで
   同じ判定であること。単独ショットのUNSATは出版しない。
3. **SAT witness**: SATの場合は witness を出版正本 verify_witness.py（独立Leibniz幾何・
   Integer行列式）で SAFE+MAXIMAL 検証し、1石除去の tamper 対照（非極大化）を
   全石について実施して受理すること。
4. **決定性**: CNF は決定的生成で、sha256 を記録し再現可能性を保証すること。
   INDET満了は正直にINDETとして記録し、続行しない。
5. **過大主張の禁止**: 得られた行判定だけを主張する。M_7、n≥9盤面、
   標準11×11空盤・二石root・S2・closure class は本スコープ外（UNKNOWNのまま）。
