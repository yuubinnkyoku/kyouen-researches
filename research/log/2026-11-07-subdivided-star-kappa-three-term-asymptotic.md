# 2026-11-07 一辺細分星の切替閾値の漸近展開（二項 → 三項）

- 対象: `κ(r)`（終局長差多項式 `T_{k,r}` が奇数 `k` で初めて実根をもつ次数、K0677）。
  K0677 の `Θ(r log r)` 評価を先頭3項と誤差の次数まで精密化した。
- 方法: `M(k) = a^{k+1}k^k/(k+1)^{k+1}`（`a=1+1/(r+1)`）の両側対数評価
  `(k+1)/(r+1) - (k+1)/(2(r+1)^2) - ln(k+1) - 1 < ln M < (k+1)/(r+1) - ln(k+1) - 1 + 1/(2k)`
  を、`0<t<=1` の `t-t^2/2 < ln(1+t) < t` と `1-1/(2k) < k ln(1+1/k) < 1` から導いた。
  `Ψ(k) = (k+1)/(r+1) - ln(k+1) - 1 - ln r` は `k = 2r ln r + r ln ln r + c r` で `c-(1+ln2)+o(1)`。
  閾値は実根最小点が `y_*=ka/(k+1)` から指数的にしか離れないことから `Ψ(κ) = (ln r+O(ln ln r))/r` で決まり、
  `T = k/r`、`x = (ln ln r+μ)/(2 ln r)` とおくと `μ = 1+ln 2 + x + O(ln r/r + x^2)`。
  さらに `x = (ln ln r+1+ln 2)/(2 ln r) + O(ln ln r/(ln r)^2)` を代入して三項が決まる。
- 結果: `κ(r) = 2r ln r + r ln ln r + (1+ln 2)r` に続く第3項は `r(ln ln r+1+ln 2)/(2 ln r)`。
  誤差は `O(r(ln ln r)^2/(ln r)^2)`。特に `κ(r)/(r ln r) → 2`、`κ(r)/(2r ln r) - 1` から
  `2r ln r + r ln ln r + (1+ln 2)r + o(r)` 版も同時に従う。
- 数値: 既存の厳密表 `r=2..1000`（サンプル再計算一致）に `κ(3000)=60,057`、`κ(10000)=225,393`、
  `κ(30000)=744,937` を追加。比 `κ/(r ln r)`: 5.23 (r=4) → 2.565 (r=998) → 2.500 (r=3000) →
  2.447 (r=10000) → 2.409 (r=30000)。
  三項公式の誤差は +11.3 (1000)、-8.3 (3000)、-73.0 (10000)、-243.2 (30000) で
  `r(\ln\ln r)^2/(\ln r)^2` の 0.16 倍以内。残差の三項項比は 1.043 → 0.988 → 0.966 → 0.959 と 1 に近づく。
- 検証: `r = 3000, 10000, 30000` で `k=floor(2r ln r+r ln ln r+1.2r)` の根なしと `floor(...+2.5r)` の2根を厳密証明。
  両側評価は50桁 decimal で20点の内側性を監査（証明ではなく実装監査）。
- 限界: 誤差の定数は明示していない（数値では r>=1000 で 0.16 未満）。`κ` は離散関数のため残差率は単調でない。
- 次: 誤差定数の明示、`q=4` への応用、他構成の閾値への同型の漸近解析、`κ(r)` の計算量改善（より大きい r の厳密値）。
