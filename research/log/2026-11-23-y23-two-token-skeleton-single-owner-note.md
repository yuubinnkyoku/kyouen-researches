## 事前の横断予想（cand23 コード意味論からの機械確認であり y=23 の証明ではない）

- tail: x 偶行（S=x+23 奇 ⇔ x 偶・奇数 y 型で y=11..21 と同型）・
  R >= x+z+24 = x+z+y+1・値 (x+23) mod 2。tail 開始族式 x+z+y+1 の
  **23 族目候補**（fit level・y<=22 までは全称確定済み）。

  **23 例目候補**）。
- マージ行: x <= z-24（S = x+23 <= z-1）。マージ命題一般形
  x<=z-(y+1) の y=23 版（全称確定 y=22 の次・fit level **23 族目候補**）。
  box 内 0 行は事前導出。
