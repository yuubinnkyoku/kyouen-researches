  (m+1)=((m−1)+2) 上位 >=1 → T-II(m−1) >= 2 →
  mex{0, >=2} = 1 ✓。else → E(m) = 0 ✓。
- **L3(m)（δ3 high-gap → 0）**: X = (m, U)（mult(m)=1・
  U ⊆ [m+2,∞)・U≠∅・high-gap: (m+1)-トークン不在）で
  H(2m+3;X;0)=0。
  証明: 子は予算 2m+2 = δ2 行。
  (a) stair（A on u∈U, u>=m+2）: 子は (m, U′, u−1>=m+1) 形
  で mult(m)=1 は保存 → arm-1 mixed → H1(m) = 1
  （u−1=m+1 でも arm-1・mixed とも保存）。

  2j+4 = δ4 行: U >= m+2 = j+3 → T-C4(j) ≠ 0
  （条件 (i): 全残余 >=j+3）。
  → opts に 0 が現れない（(a)=1 精確、(b)≠0）→
  値 = 0 ✓（m=1 は J2: 行1では (b) の代わりに B 子
  (s⃗)@4 z1 = 1（F5・v）で同じく 0 が現れない）。
- **C4(m) / C4b(m)（δ4 側 → ≠0）**: X = (m, U)（mult(m)=1・
  m+1 不在・U≠∅）で (i) U >= m+3 または (ii) U ∩ [m+2,∞) ≠∅
  ∧ U ∩ [m+3,∞) ≠∅ のとき H(2m+4;X;0) != 0。
  証明: 子は予算 2m+3 = δ3 行。stair on big（u>=m+3）:
  子 (m, U′, u−1>=m+2): m+1 不在・残余 >=m+2 →

  （両ケースで >=m+3 の stair 先が存在する: (i) 全部、
  (ii) big が1つ。）（m=1 は J3 ✓。）

### 2.4 系 T-B0′（K1281 T-B0 の無条件昇格）

K1281 §2.1 の II-1（帯ステップ）・II-2（対角ステップ）・II-3
（前線）の証明をそのまま再利用する。それらは帰納的に
P-band(m−1)・P-diag(m−1)・Q(m−1) を使い、Q(m−1) は
H1(m−2) と P-diag(m−1) を使う。K1281 では H1 が仮説だったため
全体が「H1 ⟹ T-B0」の含意だったが、T-H1 により H1 は全行で
定理となり、含意の仮説が消える。よって
(i) 帯+対角崩壊 H(R;X;0)=v(Σ,0,R)（∀m>=2・R∈[m+1,2m]）と
(ii) 前線分類（mixed→2・allm a>=2→0・∀m>=2）は無条件定理と
なる。行2の窓 w∈{1,2}（R=3,4）の部分は既刊（K1270/K1278
T_A）ですでに無条件であり、梯子の出発点を成す。

### 2.5 証明の閉性・未解決部分の明示

依存グラフ（行 m 内・行間を含む）:
```
行1: J1..J5 (床 F0–F6 のみから導出)
行 m>=2:  P-band(m) ──> P-diag(m) ──> Q(m), Qallm(m)
              │(行m−1)  │(Q(m−1))     │(H1(m−1), P-diag(m))
              v         v             v
            …         …          E(m) ──> II(m) ──> H1(m) ──> LC(m)
                                            (E:II(m−1)) (E,H1) (Q,Qallm,L3(m−1))
            II(m−1) …                                    │
                                                          v
                                              L3(m) ──> C4(m) (L3(m))
```
循環なし: 各矢印は行 m−1 以下または同一行内の先行ノードのみを
指す（E(m) → II(m−1)、H1(m) → L3(m−1)、L3(m) → C4(m−1)、
C4(m) → L3(m)）。予算は各ステップで 1 ずつ減るため、大域予算
帰納でも整合する。

**未解決（open・過大主張しない）**:
1. **C-II2**: T-II の exact 値 = 2（916 点観測）。証明には
   {0,1} ⊆ opts に加えて fall 子（pure-c2@δ3 クラス: C4b
   値）≠2 が必要。fall 子は行 m−1 の (j+2)^c-big 型で、
   本宣言の定理群の値域外（pure-count ladder 領域）。
2. **allm-δk (k>=2)**: a=3 → 1・a∈{2,4,5..} → 0 は観測
   （census・explore）。注意すべき構造: allm**前線** (m^a)
   の fall 子 (m−1, m^{a−1}) は行 m−1 の δ2 行（予算 2m =
   2(m−1)+2）で、arm-1 mixed として H1(m−1)=1 が適用でき
   る — これが Qallm 証明そのものである（済み）。一方
   allm**δ2** (a>=2) の fall 子 (m−1, m^{a−1}) は行 m−1 の
   **δ3 行**（予算 2m+1 = 2(m−1)+3）で評価され、pure-c1@δ3
   クラス（例 (2,3,3)@7=0）になる: これは arm-1 mixed の
   m+1 トークンが「行 m−1 の j+2」となる構造であり要する T-L3
   条件（m+1 トークン不在）を満たさず、値は pure-count
   ladder 領域に入る → 本宣言の対象外・open。
3. **H2 / T-B1（z1 側）**: K1281 の H2 は open のまま。
   行1基底 J2–J5 の z1 類似（F4/F5）は本宣言の F 補題にあるが、
   z1 前線・δ3 の一般則は本宣言の対象外。
4. **F14b**: (1^t t>=2, 2^u)@4（>=3 なし）: 観測値 1
   （(1,1,2)@4=1）。min=1 starved 領域の一部として open。
