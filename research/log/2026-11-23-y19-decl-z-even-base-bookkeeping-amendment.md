## 訂正対象と訂正内容

宣言ノートの該当記述:

> 偶z base 行（d 奇 17 行・d∈[-17,17]）: k(d) = floor((d+3y+1)/4) = floor((d+58)/4)
> で d=17 は k=18（Y 未満）。y=17 の d=17 飽和（k=17=Y）と対照的に、y=19 の偶z base
> 上端は k=18 で飽和しない（base 上端 d=Y-2=17 の族式依存・fit で確認する予想として登録）。
>
> （奇z base 行（d=18）と奇z I 行（d=19・k=19）の 2 箇所が k=Y に到達する点が過去族と異なる …）

機械 census による実態（cand19.py の行分類通り・生値検証済み）:

- 偶z の生残 d 域は **[-18, 19]** で（d=-19 は対角行として別扱い・d>=Y+2=21 は定常・d=20 は掃引）、
  偶z base 行は **d 奇 19 行・d∈{-17,-15,...,19}**。宣言の「17 行・[-17,17]」は上端の d=Y 行（d=19）を見落とし、かつ [-17,17] の奇 d 行数も 17 と誤算（正しくは 18）したという
  行域算術の誤り（正しくは 19 行・d∈[-17,19]・上端 d=19=Y）。
- **上端行 d=19 = Y は k = floor((19+58)/4) = 19 = Y で飽和**。偶z base 上端の飽和は
  出版 y=17（d=17）・y=18（d=18）と同型の族式どおりであり、「偶z base 上端は飽和しない」という
  宣言の予想は誤り。d=17（k=18）は行域の途中の非飽和行で、この観察自体は正しい。
- したがって **k=Y 到達は 3 行**（奇z base d=18・奇z 最終 I 行 d=19・偶z base 上端 d=19）で、
  出版 y=17 の 3 行（z-odd base d=16・z-odd I d=17・z-even base d=17）と**同型の族パターン**。
  宣言の「2 箇所 k=Y は過去族と異なる」という記述もこの見落としに起因する誤り。
