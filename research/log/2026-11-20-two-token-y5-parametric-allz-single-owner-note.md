## 予備観察（有限probe・z=0..24・x=5..40・R<=x+z+45・2026-11-20実施）

y=5 行センサス（z=0..24・x=5..40・R<=x+z+45・生二重再帰 H_canonical）で横断法則候補を検証した。
いずれも有限観察であり全称主張ではない（cand5 導出後に全称証明へ昇格させる）。

1. **tail（族式継続・3点確認）**: 全 z=0..24・x=5..40 で R >= x+z+6 のとき H(R;(x,5);z) = (x+5) mod 2。
   36,000点・不一致0。開始式 x+z+y+1（y=5: x+z+6）と値式 (x+y) mod 2 がy=2..5の4族連続で一致
   （y=2: K1099・y=3: K1104・y=4: K1112 全称済み）。y=5 は値1無限帯が偶数x行に戻る（y 偶で反転する規則の継続）。
2. **マージ行（対角線下）**: x <= z-6（S=x+5<z）で H = single_token(x+5,z,R)。
   7,875点・不一致0（y=1,2 は K1101・y=3 は K1104 系・y=4 は K1112 系で全称済み）。
3. **値1基底点 y 点仮説の y=5 成立（観測）**: 定常域 z+7<=x で基底点 {z+1,z+3,z+5,z+7,z+9}（y=5点・2,750点・不一致0）。
   pin と衝突する行クラスでは高々1点欠ける（z+9=pin 2y+z-1 の行など）。
4. **掃引行 x=z+6=2y の族式**: 帯 O[2y+z, 2z+2y+1]（奇z: O[z+10,2z+11]）・O[2y+z+1, 2z+2y+1]（偶z: O[z+11,2z+11]）。
   奇z 掃引帯下端 2y+z は y=4 と同じく孤立 pin を含み、帯本体は 2y+z+2 は過ぎない（y4 の観察の継続）。
5. **定常 pin**: 奇z 2y+z=z+10・偶z 2y+z+1=z+11（y=2..4 と同じ族式）。前倒し pin 2y+z-2（奇z・行 x=z+1=z+y-4）・
   2y+z-1（偶z・行 x=z+3=z+y-2）も y=2..4 の位置式 x=z+y-4 / x=z+y-2 の継続。偶z の pin 2y+z-3（行 x=z-1=z+y-6）は
   y=4（{z+5}@x=z-2）と同型の位置式 x=z+y-6 で継続（値は z+7）。
6. **中間帯下端 2y+z+2=z+12（値1・O_z）**: 定常行で観測成立（下端の族式は y=3,4 の観測と同じく 2y+z+2）。

cand5 の行クラス表（z偶奇別・c=x-z 類別）は probe 全行で構造が定数オフセットで説明できることを
確認済み（ladder 上端・pin 位置・基底点数・flat interval 下端・帯が全て行クラスで固定）。
対角行 c=-5: 奇z 上端 z+4・偶z 上端 z+5。値1は奇z でのみ {z+1,z+3,z+5}∪I[z+6,∞)（偶z は空）。
y=4 では対角行の値1は z 偶奇によらず常に空だったため、奇z 側に値1が現れる点が本項の新規差分。
