# 高速レーン実行ログ: クリティカルストリップ z=5・min>=4 スライス（K1273） 2026-11-23

## 0. 選定（高速レーンの方針ど）

前回レーンでは min>=2 クリティカルストリップの z∈{0,1}（K1270）と z∈{2,3,4}（K1272）が
全称証明され、min=3 の z=4 底と T-B の m>=3 帰納が利用可能になった。残る「情報価値が最も高く
こちら側だけで完結できる」未解決は z*(4)=6 の手前、すなわち m=4 行のバンド上端 z=5
スライス（K1268 予想 C1 の直近の未確定セル）である。9 × m>=5 底の z=5 も併せて取れる
可能性が探査で裏付けられたため、主題を

> H(m+6;X;5)=v(ΣX,5,m+6) for all m>=4, min(X)=m

に固定した。この1本で K1268 予想 C1 の m=4 行が全域 z∈{0..5} で閉じる（K1270+K1272+本項）。
11×11 長期レーン（Part CI takeover・宣言 f35ef5ae）は非接触。

## 1. 前線探査（紙・机上・宣言ノートに全開示）

- m>=3 の R=z+m+1 窓を z=5 に写したとき、子は 2 ステップ下の z=3 窓（K1272 T-B の
  直接適用対象）と z=4 の F/D 表（K1272 出版 Lemma F・D）に落ちるため、梯子は
  F5/G/E の3レベルで閉じると見積もった。
- F5 セル H(7;{1}∪Y;5) の場合分けを行うと、C手子が出版 Lemma F の z=4 表に落ち、
  値が 1/0/1/0/2（s=0/3/4/5/6+）になることを紙面で確認した。
- G セル H(8;{2}∪Y;5) では A-on-2 子が F5 セルに、C手子が出版 Lemma D（z=4）に落ちる。
  R2 形崩壊は丁度 Y=(4,) で破れ、G(4)=0 != v(6,5,8)=1（z=4 の deviant D(4)=2>崩壊と
  方向が逆であることに注意）。
- E セル H(9;{3}∪Y;5) の deviant も丁度 Y=(4,) で、E(4)=2 != v(7,5,9)=0。
  **このセル H(9;{4,3};5) こそが K1268 の出版前線 witness (4,3)@R*=9 そのもの**である
  （親 H(10;{4};5)=v(4,5,10)=2 の選択肢に 0 が現れない、の分離セル）。前線 witness が
  閉形式梯子の内部に位置づけられたのは今回が初めて。
- m=4 底は H(10;{4}∪Y;5)。E セルの deviant E(4)=2 は mex に吸収される（0 を埋めない。
  K1272 の D(4)=2 吸収と同型）。
- m>=5 帰納段は、A手子が a>m 縁でちょうど K1264 階段定理の窓端等式に、a=m で帰納仮定
  C(m−1,5) に落ち、C手子が 1^v(ΣX,4,m+5)（出版 T-B・z=4）で固定されるため、
  選択肢集合が単一側と一致する。
- 探査の結論として、z=5 スライスは 3 補題+底+帰納の5部構成で全称証明できると確定した。

  - z=6 strip: m∈{5..8} で 96/96 形状すべて崩壊、m=4 は (4,4) の1点のみ分離
    （witness (4,4)@R=11・親 2 vs 単一 1）。z=6=z*(4) が前沿であることの再確認。
