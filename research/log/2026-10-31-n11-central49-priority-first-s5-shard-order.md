# 2026-10-31：中央49の最初の四石証人を優先し、均一費用モデルで必要作業枠551→23

最新main `a765181b21879e1067d732b0cfa49efad748a08d`（開始時）、AGENTS.md、research/knowledge/README.md、K0023、K0329、中央19初手の実験README、中央49のS5共有・4分割の実装と直近log、既存の安全なS5 cache mergeを確認した。標準11×11空盤は **UNKNOWN**。

## 課題

既存のS5正準鍵による4worker分割は2,525類を632/631/631/631類に割り当て、重複を完全に除去している。しかし鍵の辞書順に作業すると、28個の未証明S4のうち最も子が少ない証人を早期に閉じることが難しい。

選択したS4 `00000000000000401002010000000000` は第三手36・40・70・72を単独で被覆し、合法S5子92類のうち既知LOSS5が1類、未判定S5が**91類**。この91類は他のS4と共有しない。28個の未証明S4の中で未判定子数は最少。

## 厳密な仕事順序の比較

固定のS4証人31類と二系統のS5 cache（Git blob `2dccf42b92337cbcbfb62ea5c77db487b1ad8ead`、`9887a18c0788d26507be7e8e191c26817634a6b6`）を用い、合法S5子を整数幾何・D4で再生成して比較した。

| 指標 | 辞書順の従来案 | 優先91類を先頭にする案 |
| --- | ---: | ---: |
| 未判定S5の総数 | 2,525 | 2,525 |
| worker別の総数 | 632 / 631 / 631 / 631 | 632 / 631 / 631 / 631 |
| worker間の重複 | 0 | 0 |
| 優先S4の未判定S5のworker別件数 | 22 / 23 / 23 / 23 | 23 / 23 / 23 / 22 |
| 最後の必要S5の作業枠 | **551** | **23** |

「作業枠」は各workerが1件ずつ処理する均一費用モデルの逐次順位であり、実際の秒数・探索ノード数ではない。91類を4workerで処理するには少なくとも `ceil(91/4)=23` 枠を要する。優先案はこの下界を達成し、他の未証明S4も未判定子数が91以上なので、**この固定31証人集合で最初のS4が閉じ得る作業枠の下界**に達する。

ただしS5子の判定がすべてLOSSになることが条件である。WINが一つでも出れば、この証人はLOSSではなくなる。優先順は証明の成功確率・実測時間の最適化ではなく、成功時に最初の証明を完成できる最速順序を確保するもの。
