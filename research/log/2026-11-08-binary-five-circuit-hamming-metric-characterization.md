# 二値5点アフィン回路のハミング距離だけによる必要十分判定（2026-11-08）

## 結論（全次元、数学的証明）

相異なる5点集合 S⊂{0,1}^d がアフィン回路であるための必要十分条件は、S に順序付きの2点 (c,z) が存在し、残りの3点を a,b,e として、ハミング距離 δ に関して次をすべて満たすことである。

1. 各 x∈{a,b,e} に対し δ(c,x)+δ(x,z)=δ(c,z)。
2. 各異なる x,y∈{a,b,e} に対し δ(x,y)=δ(x,z)+δ(y,z)。
3. δ(a,z)+δ(b,z)+δ(e,z)=δ(c,z)。

この判定は座標ごとの少数派対グラフも線形代数も構成せず、10個の二点間距離だけで実行できる。順序付き対 (c,z) の探索は最大20通りでよい。条件を満たす (c,z) は一意であり、逆向き (z,c) は一般には条件を満たさない。

## 証明

第1条件より各 x はハミング最短路上の点である。すなわち x と z の異なる座標集合 A_x は、c と z の異なる座標集合 D の部分集合となる。第2条件より A_a,A_b,A_e は互いに素（対称差の大きさが和になることと同値）。第3条件よりこれらは D を分割する。5点が相異なるので各 A_x は非空。各変動座標では z と c が異なり、3つの葉のうちちょうど1点だけが z と異なる。少数派対は (c,a),(c,b),(c,e) のいずれかで、3種類とも現れる。したがって既証の星形必要十分定理により S は5点アフィン回路。

逆に5点回路では既証の星形定理により星の中心 c、孤立点 z と3葉 a,b,e が存在する。各座標の少数派対は星の3辺のいずれかであり、z との差の支持集合 A_a,A_b,A_e は互いに素で、変動座標を分割する。よって三条件を満たす。唯一性は既証の対蹠対一意性に加え、3葉の差集合が非空であることから従う。逆向きにすると3葉の z からの差集合は互いに素にならない。
