# 2026-11-02：旧1,980七石計画の七つの確定WIN6を除外し、2,301七石類の条件付き被覆を構成

最新main、AGENTS.md、knowledge README、K0624/K0626/K0627/K0628/K0638、中央49の旧1,980計画・18置換・検証器・関連logを確認した。

## 第三の衝突だけでは足りなかった

直前の`2026-11-02-n11-central49-1980-third-win6-fail-closed-audit.md`では、旧1,980類計画の3個の確定WIN6との衝突を記録した。しかし、終局WIN7の**全七石親**を逆向きに列挙すると、旧46六石証人に含まれる既知WIN6は実際には**7類**だった。

| 根拠 | 旧46証人との交差 |
| --- | --- |
| K0624：共有七石からの七親 | 2類 |
| K0627：第一の共有七石からの七親 | 1類 |
| K0628：第二の共有七石からの七親 | 2類 |
| K0638：元先手WIN7からの七親 | 2類 |
| **合計** | **7類** |

K0638は七石 `0000000000000020380a100000000000` の元先手WINを終局まで証明している。その七点のいずれかを取り除いた六石局面は、元先手が除いた点へ合法に戻せるので同じ七石戦略を使える。七親は相異なるD4正準類で、旧19 WIN7からの117親および従来の独立終局証明21類とは重複しない。これにより、K0638から**新規六石WIN6を少なくとも6類追加導出できる**（ただし七親それぞれの終局戦略の個別再生は今回行っておらず、K0638の固定WIN7証明に依存する）。

旧1,980計画の残り39証人だけでは94五石類のうち14類が未被覆になる。旧46証人から3類だけを除いた仮の2,145七石計画は、残りのWIN6を見落としていたため**採用せず、manifest・検証器・workflowを撤回した**。この研究記録は前の記録を上書きせず、より完全な交差監査として残す。

## 新しい46六石・2,301七石の条件付き構成

94個の五石局面から合法な六石正準類3,868を3×3整数幾何で再構成し、旧46証人のうち確定WIN6七類を除いた。残る39類を固定し、14個の未被覆五石局面を七つの六石証人で再被覆する候補を探索した。

旧19類の比較WIN7、K0624/K0627/K0628の共有WIN7、K0638のWIN7を合わせた23七石局面から、六石親の相異なる145類を除外。旧証人に含まれる衝突は7類で、新しい候補はその145類と交わらない。

| 指標 | 旧計画（失効） | 新しい条件付き構成 |
| --- | ---: | ---: |
| 六石証人 | 46 | **46** |
| 五石被覆 | 94/94 | **94/94** |
| 確定WIN6を誤採用 | **7類** | **0類** |
| 七石合法辺 | 2,972 | **2,992** |
| 相異なる七石類 | 1,980 | **2,301** |
| 既知WIN7衝突 | 未更新 | **0類** |

新構成は`conditional_s6_cover_46_post_seven_win6_repair_2301.json`に固定した。追加七証人は、既存39証人の七石集合との重複を考慮した重み付きマッチングから選択した。候補探索は厳密な大域最小性の証明ではない。旧1,980類より321類増えるが、旧集合は既に不可能であり、新しい2,301類は**証明に使える可能性を残した条件付き計画**である。

`verify_central49_post_seven_win6_repair_2301.py`は、旧18置換の独立4×4整数Bareiss監査を継承し、新しい七証人の全合法七石子を同じ独立整数幾何で再計算する。94/94被覆、46証人、2,992辺・2,301類、既知WIN6/WIN7非衝突、UNKNOWN境界を検査する。専用CI `.github/workflows/n11-central49-post-seven-win6-repair-2301.yml`も追加した。**CI成功を確認するまでは独立監査済みと断定しない。**

既存の`verify_repaired_s6_1980.py`と`audit_repaired_s6_1980_shared_reuse.js`も七つの衝突を報告するよう修正し、歴史的幾何の再現を現行の証明義務と混同しないようにした。

新規六石LOSS・四石LOSS・二石root閉鎖は0。選択した新46六石のLOSSは全て未証明であり、**標準11×11空盤の勝敗はUNKNOWN**。
