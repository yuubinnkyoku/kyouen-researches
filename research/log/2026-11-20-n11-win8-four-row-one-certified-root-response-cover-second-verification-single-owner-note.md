# n11 WIN8 4親行・K1096単独証明根の応答被覆再検証（単一オーナー宣言）

2026-11-20。既存の4行二手応答被覆計画を、K1096の証明書だけを固定済み根として扱う形に組み替え、別実装で独立検査する。本作業の対象は幾何・組合せ被覆計画であり、ゲーム値の判定ではない。

## 既存の単一オーナー作業との分離

- K1097（第4ラウンド再解決）の独立第二検証は別レーンが所有する。本作業はその再解決機械を変更・再実行しない。
- WIN8証明書抽出の単一オーナー対象（K1096 root `...08003180`、別root `...08180000`、別root `...0810000a`）には着手しない。
- 4親行二手応答被覆には別の単一オーナー宣言が見当たらないことをmain上で確認した。本作業は既存の応答被覆計画の独立再検証・証明状態の整理に限定する。

## 範囲

1. K1085の残余72行正本、K1097のWIN8候補16根・REFUTED-D10 50根、既存149-root応答被覆計画、K1096証明書・監査正本を内容hashで固定する。
2. 対象4つのS6親行の合法初手義務（row, first_move）を独立に再導出する。
3. 4親行から2石を加えて得るsafe8 D4軌道を全数再構築する。4点共円/共線判定は4×4整数行列式のBareiss消去で実装し、既存検証器の24項展開とは別経路を取る。
4. K1097の既知REFUTED-D10 50軌道を除外し、候補宇宙・既知WIN8交差を照合する。
5. K1096 root `00000000000000003800000008003180` だけを「証明書検証済みの固定根」とする。K1095 root `0000000800000000380000000810000a` はWIN8-D10候補にすぎないため固定根に数えず、追加証明が必要な候補側へ移す。
6. K1096の8 obligationsを除く296 obligationsについて、全ての非固定候補が高々2 obligationsを覆うことを全候補で検査する。
7. 既存計画の147追加根にK1095候補根を加えた148根が、296 obligationsを重複なく完全被覆するか検査する。成立すれば、下界148と構成148が一致し、K1096だけを既証明根とする149根の最小幾何計画になる。
8. 同一入力・同一コードで再実行可能な監査JSONと再現コードを出版する。
