# 2026-11-12 幅6 円の8点上界 P(6)=8 の全称証明（高速レーン）

## 背景

- K0760（q107）: 幅6 chord census で m ≤ 70 の全危険円が7点・8点のみ
  （9点以上なし・総数 ~26/m 線形）。これは有限観測だった。
- q108 レジューム候補 (4)「censusのm>70延長・9点円探索・K0072 mod9補題の幅6版」に着手。

## 判断: 有限延長ではなく全称証明へ

m>70 のcensus延長は有限事実を伸ばすだけと判断し、「9点円は存在しない」の
**全称命題**を直接狙った。結果として K0072 mod9 補題の幅6版（剰余分類の独立再現）に
加え、**接点行が存在すれば二重行は高々3** という初等的整数論の新補題で
P(6) = 8 が全称証明できた（q=9..12 の M_{6,q}=q−1 が副産物として新規確定）。

## 証明の構造（reports/width6-circle-eight-point-bound.md 参照）

1. P = 2d + s。s ≤ 2（接点は disc(y)=0 の y-2次式）。
2. d ≤ 4: 連続二重行ペア → D, M ∈ ℤ（Vieta還着）→ mod9 剰余分類
   （9³ 通り、worst 4）。K0072 中核の独立再現で項目は自己完結。
3. d=4 ∧ s≥1 排除: 接点 → C 偶 → disc(y)/4 = t(y₀+y+D) = s²。
   D=e/f から **f | t**（h=2fy₀+e と gcd(h,f)=1 が鍵）→ 4つの非零 t∈[−5,5]
   で f∈{1,2}。
   - f=2: t=±2 が必要 → (h−4) と −(h+4) が両方正の平方数 → 和 −8 で矛盾。
   - f=1: 同符号論 → t∈{1..5}, g>5。**t=3 は mod3 で全てと非両立**
     （4通りすべて剰余2に落ちる）。残る {1,2,4,5} は (1,4)→a²−u²=3→g=5
     の一意分解を含み矛盾。
4. P ≤ 8。6×13 census の 8点円 102 本（K0760 再現）で等号成立。
