# 2026-11-12 幅6 円の8点上界 P(6)=8 の全称証明（高速レーン）

## 背景

- K0760（q107）: 幅6 chord census で m ≤ 70 の全危険円が7点・8点のみ
  （9点以上なし・総数 ~26/m 線形）。これは有限観測だった。
- q108 レジューム候補 (4)「censusのm>70延長・9点円探索・K0072 mod9補題の幅6版」に着手。

## 判断: 有限延長ではなく全称証明へ

m>70 のcensus延長は有限事実を伸ばすだけと判断し、「9点円は存在しない」の
**全称命題**を直接狙った。結果として K0072 mod9 補題の幅6版（剰余分類の独立再現）に
加え、**接点行が存在すれば二重行は高々3** という初等的整数論の新補題で
P(6) = 8 が全称証明できた（q=9..12 の M_{6,q}=q−1 が副産物として新規確定）。

## 証明の構造（reports/width6-circle-eight-point-bound.md 参照）

1. P = 2d + s。s ≤ 2（接点は disc(y)=0 の y-2次式）。
2. d ≤ 4: 連続二重行ペア → D, M ∈ ℤ（Vieta還着）→ mod9 剰余分類
   （9³ 通り、worst 4）。K0072 中核の独立再現で項目は自己完結。
3. d=4 ∧ s≥1 排除: 接点 → C 偶 → disc(y)/4 = t(y₀+y+D) = s²。
   D=e/f から **f | t**（h=2fy₀+e と gcd(h,f)=1 が鍵）→ 4つの非零 t∈[−5,5]
   で f∈{1,2}。
   - f=2: t=±2 が必要 → (h−4) と −(h+4) が両方正の平方数 → 和 −8 で矛盾。
   - f=1: 同符号論 → t∈{1..5}, g>5。**t=3 は mod3 で全てと非両立**
     （4通りすべて剰余2に落ちる）。残る {1,2,4,5} は (1,4)→a²−u²=3→g=5
     の一意分解を含み矛盾。
4. P ≤ 8。6×13 census の 8点円 102 本（K0760 再現）で等号成立。

## 検証

- 全有限段階を機械検証（scripts/width6_circle_bound.ts）:
  mod9分類 worst 4、|g|≤10⁶ で f=1 の4倍 t 平方は 0 件（最大3・例 g=10:{1,2,5}）、
  f=2 両方正平方数 0 件、d=5 スポット 0 件、census 116/176 再現一致。
- **端末例 x²+y²=25**: 行0,3,4 二重（±5,±4,±3）+ 行5 接点 = 7 点。
  代数の g=10・t={1,2,5} と完全一致し、接点フレームワークの健全性を
  具体例で確認（制御の f1_examples g=10 と同一）。

## 教訓

- 「有限観測（census）→ 構造の不安定要因（接点/二重行の判別式整数性）を特定 →
  剰余分類で全称証明」の経路が今回一発で通った。K0760 の census が
  「7/8点しかない」観測を先に持っていたことが帰着先の形（2d+s）を示した。
- f | t の導出（gcd(h,f)=1）は判別式差の整数性から出る普遍的な道具で、
  w≠6 への一般化（接点補題版・2接点版）に使える見込み。
- t=3 の非両立は mod3 のみで落ちる（4通りすべて剰余2）。剰余法の選定は
  「どの t の組が落ちられるか」の小盤面実験で決まる。

## レジューム・接続

- **11×11 長期レーンへの接続**: 9点円が幅6で全 m 存在しないことは、
  幅11の9点円探索（存在は知られておりK0072体系の外）とは独立だが、
  「円の点数が行幅で一様に押さえられる」構造の幅6インスタンス。
- 次の候補:

      2接点・剰余分類の再設計が必要。w=7 で9点円が存在するかは未解決）。
  (2) K0761 レジューム: 6×13 全1,212鏡映代表の完全列挙・6×20/21/22。
  (3) q=8 の幅6: 8点円が実在するため危険曲線のまま。8点円の構造分類

# 2026-11-12 幅8 円の構造定理 P(8)=12・素数オフセット補題（同セッション続き2）

## 成果

- K0764 の直後に w=8 に拡張。**P(8) = 12・可能サイズ {7,8,10,12}・9以上は偶数のみ**
  を全称証明（K0765）。新規の鍵は**素数オフセット補題**: 接点フレーム t(g−t)=s² で
  t = p（素数）なら g ≡ 0 (mod p) となり、他の二重行 t' は −t'² ≡ QR(p)、
  すなわち p ≡ 1 (mod 4) を要求する。p = 7 ≡ 3 (mod 4) は w=8 で t=7 を完全孤立させる。
- witness は K0764 と同一円 (2x−7)²+(2y−7)²=50 の8行版（12点・6二重行・8×8で実在、
  census でも 8×8 の12点円はこの1本のみ）。
- **P(w) = w+2 が w=6,7,8 で確定**。9以上の奇数サイズは w ≤ 8 で全滅
  （接点補題: 接点付きの二重行は常に ≤ 3 — t=3 の mod3 孤立性が w=6 で効き、
  w=7 では (3,6) Pell が現れるが被覆論で、w=8 では t=7 の素数補題で落つく）。

- **訂正**: K0764 の初出では「q≥13 は K0025 と重複」と書いたが、w=7 の 2w=14 なので
  K0025 は q ≥ 15 から。q=13,14 も K0764 の新規範囲（同コミットで訂正済み）。
