## §1 主張

座標は K1285/K1308/K1311 と同一。H(R; X; z), X 降順 (x1 ≥ … ≥ xn ≥ 1), S := ΣX, k := R−S, E := 2x1−S。

**T-BB2 (universal, n≥3)**: 全 n ≥ 3、全 z ≥ 0、全降順多重集合 X (≥3 山) について、**下帯第2行** k := z+n−4 (R = S+k ≥ 2 が自動的に成立、最小は (1,1,1)@z=0 の R=2) で:

```
E ≤ z+n−4    →  H = [E odd]      (領域 1)
E = z+n−3    →  H = 2            (2-line)
E ≥ z+n−2    →  H = 1−[E odd]    (領域 3)
```

(i) 例外セルはちょうど 2 個、いずれも X=(1,1,1): **z=0 → 0、z=1 → 2**。z≥2 では一般則に合流する ([E odd] = 1)。
(ii) w := E+z+n−5 と置くと、値は **(E, w) のみの関数**として全 n≥3 でマージできる (宣言前探索 WA の凍結実測: 後述ドメインで多値セルは (E,w)=(−1,−3)→{0,1} と (−1,−2)→{1,2} の 2 個のみで、第 2 成分は常に (1,1,1) 例外セルから来る)。K1313 §5.2 の問い「(E,z) 単一座標崩壊がどこまで貫くか」への回答: 同一 n 内では (E,z) で決まるが (n=3 のみ、探索 WA の 2 多値セル)、**n をまたぐ正しいマージ座標は (E,w) であり (E,z) ではない**。
(iii) E は n≥3 で下に非有界なので、領域 1 と領域 3 は無限。
(iv) **意味**: 公刊 T-CSUM (k≥z+n−1, K1312) + 公刊 T-DB (k=z+n−2, K1311) + 公刊 T-BB (k=z+n−3, K1313) + 本次 T-BB2 (k=z+n−4) で、**全 n≥3 の全多重集合について k≥z+n−4 が完全確定**。n=2 は下記 L-2/PB2 で k≥z−2=z+n−4 が確定するので、**全 n≥2 で k≥z+n−4 が閉じた**ことになる (n=2 は行の法則の形が異なるため別補題)。残余 open は **k ≤ z+n−5** (n≥3) / k ≤ z−3 (n=2 plane 系) に縮小 (§5 O-BBL3)。

**L-2 (universal, n=2, plane Z≥1, 行 k=Z−2, R=S+Z−2 ≥ 1)**: 2 山全セルについて

```
bed (a,a):  2 ⟺ (a,Z)=(1,1)、それ以外 0
pair (m+g,m), g≥1:
    Z ≤ g−2 → [g even]   /  Z = g−1 → 2  /  Z ≥ g → [g odd]
```

**PB2 (universal, n=2, plane 0, 壁行 k=−2, R=S−2 ≥ 0)**: 2 山全セル (a≥b≥1)、g=a−b として

```
g ≤ 2 → [g odd]   /  g = 3 → 2   /  g ≥ 4 → [g even]
```
(床 (1,1) は R=0 終端で値 0 = [g odd] と整合。)

**L-BR2 (base lemma, 公刊 K0832 単一トークン閉形式のスライス)**: 全 x≥1, Z≥0、行 k=Z−3 (R=x+Z−3 ≥ 0) について

```
R = 0 → 0
2 ⟺ (Z=x≥2) or (1,3) or (3,1)
Z ≥ x+1 → [x odd]   /  Z ≤ x−1 → [x even]
```

**L-0 (universal, 空多重集合)**: 全 R≥0, z≥0 で H(R; (); z) = 0。

**Typed 子恒等式 (全第2行セル)**: 各オプションは次のちょうどいずれかで、子はすべて除算 R−1 を持ち**ふたたび第2行族**に属する:
- (A-a) 頂の縮小: x1≥2 かつ x1>x2 のとき頂 x1 を 1 減らす → 子 (n, z, 同k, E−1)
- (A-b) 非頂の縮小: x1=x2≥2 (頂の 1 コピーを減らす場合を含む) または非頂山 ≥2 のとき → 子 (n, z, 同k, E+1)
- (B) 1 山の除去: 値 1 の山を取り除く (X がすべて 1 なら (1,1,1) 型では頂を含む) → 子 (n−1, plane z+1, 同k, E+1)。n−1=1 の承継は L-BR2 セル (L-2/PB2 親では k=z−2=(z+1)−3 ✓)、n−1=2 は L-2 セル (plane z+1≥1 ✓ 常に L-2 であって PB2 には着地しない)、n−1≥3 は T-BB2 セル (k=(z+1)+(n−1)−4 ✓)
- (C) plane-down: z≥1 → オプション値 1 XOR 子値、子 (n, z−1, k−1, E)。**Z=1 の L-2 セルの C 子だけは plane 0 に降りて PB2 セル (k=−2) に着地する** (第2行族の内部インターフェース)。

**系 (K0832 3トークン過渡帯・k=0 奇数スライス R=2x−1 の予想 A/B/C)**: Y≥W≥1, z≥0, X=(x,Y,W) について
- **系A (予想A, j=0)**: x=Y+W+z なら H(2x−1; X; z) = **2 常に**。このとき E=z で、セルは n=3 面の第2行 2-line (E=z+n−3=z) 上にある。本次 T-BB2 の 2-line に一致し、例外セル (1,1,1) は Y,W≥1 より x=Y+W+z≥2となるため到達不能 (X=(1,1,1) は x=1 を要求する)。
- **系B (予想B, j=2)**: x=Y+W+z+2 なら H = 2 常に。E=z+2 でセルは n=3 面の境界行 k=z+1 (=z+n−2) 上: 公刊 T-DB の 2-line (Dlaw(E=z+2, p=z+1)=2) に一致。
- **系C (予想C, j=1)**: x=Y+W+z+1 なら H = 2 ⟺ z=0 (z≥1 では値 ∈{0,1} で 2 でない)。E=z+1 でセルは n=3 面の頂行 k=z (=z+n−3) 上: 公刊 T-BB に帰着し u=E+z+n−4=2z、u=0→2、u≥1→[E odd]=[z+1 odd]≠2。
- 帯条件 x<R<S+z+2 の検証: R=2x−1=S+E−1 なので R<S+z+2 ⟺ E<z+3 (A: E=z ✓ / B: E=z+2 ✓ / C: E=z+1 ✓)、R>x ⟺ x≥2 ✓ (Y,W≥1 より x≥2)。**統一予想 U (k≥1 スライス) は第3行以下 (k_row = E−1−2k ≤ z+n−5) に位置し open のまま** (§5)。

## §2 手証明

### 2.1 型付き子の D-座標代数

第2行セル (n, z, k=z+n−4, E) の子の D 座標:
- (A-a): (E−1, D+1)、子の偶奇 1−ρ
- (A-b)/(B): (E+1, D−1)、子の偶奇 1−ρ (B は面 (n−1, z+1) でも z'+n'−4 = z+n−4 なので D は同じ定義で D−1)
- (C): (E, D−1)、同偶奇 ρ、オプション値は 1 XOR 子値

子の値 (子が T-BB2 セル = n≥4 の B 子、または A/C 子全般)。表は例外セル (1,1,1)@z∈{0,1} を子に持たない親に対するもの (§2.6 の族を参照):
- v(A-a) at (E−1, D+1): D≥−1 → 領域1子: 1−ρ / D=−2 → 2-line子: 2 / D≤−3 → 領域3子: ρ
- v(A-b) at (E+1, D−1): D≥1 → 1−ρ / D=0 → 2 / D≤−1 → ρ
- v(C) at (E, D−1): D≥1 → 1 XOR ρ = 1−ρ / D=0 → 1 XOR 2 = 3 / D≤−1 → 1 XOR (1−ρ) = ρ

**n=3 の B 子は L-2 セル** (2 山、plane z+1≥1) であり、上の T-BB2 代数の代わりに L-2 の (g, Z') 座標 (g := E+1, Z' := z+1) で評価する (§2.5 の法令を再帰的に差し込む):
- v(B) = [ z ≤ E−2 → ρ (=[E+1 even]=[g even]) / z = E−1 → 2 (Z'=g−1) / z ≥ E → 1−ρ (=[g odd]) ]
- E = −1 のとき (床ケース、親 (a,a,1)): 子は床 (a,a)@Z'、値 0 = 1−ρ (ρ=1)。a≥2 なら一般式の z≥E と一致 ((1,1,1)@0 親は例外族 §2.6)。
- 補足: n=3 で B が存在するなら E ≥ −1 (1 山を含む親で E = x1−x2−1 または 2−n 型、最小は (1,1,1) の −1)。ゆえ E≤−2 の親は B を持たず、n=3 B 子の g 座標は常に well-defined。

存在補題:
- (E1) (A-b ∨ B) は常に存在する: すべての山が 1 なら B が存在する (n≥2)。それ以外のとき頂 x1≥2 であり、x1>x2 なら A-a、x1=x2 (tied, ≥2) なら A-b (頂の 1 コピーを減らす)、非頂山に ≥2 があれば A-b。
- (E2) tied top (x1=x2) ⟹ E = 2x1−S ≤ 2x1 − (2x1+n−2) = 2−n。
- (E3) 例外セル (1,1,1)@{0,1} を子に持つ非例外親は有限個: A-a からは親 (2,1,1)@{0,1} のみ (n 保存・E−1、子が (1,1,1) ⟺ 親 (2,1,1))、B からは親 (1,1,1,1)@0 のみ (B 子の heap 数は n−1=3 ⟺ n=4、E+1=−1 ⟺ E=−2 ⟺ (1,1,1,1)、かつ子 plane z+1∈{0,1})、C からは親 (1,1,1)@{1,2} のみ (同一多重集合)。
- (E4) 領域別の tied/x1=1 排除: D∈{0,−1,−2} の各行で E はそれぞれ z+n−4, z+n−3, z+n−2 に固定される ((E2) の tied 上限 E ≤ 2−n と比較して): D=0 で tied なら z ≤ 6−2n となり z≥0 からは (n,z)=(3,0) のみ (E=−1、床 (a,a,1)@0 = §2.6 の族 F5)。D=−1 では z ≤ 5−2n < 0、D=−2 では z ≤ 4−2n < 0 (n≥3) で tied 不可能。D∈{−1,−2} で x1=1 (全て 1 の E=2−n) なら E = z+n−3 または z+n−2 からそれぞれ z = 5−2n, z = 6−2n < 0 となり不成立。(1,1,1) の E=−1 は D = z ≥ 0 なので D∈{−1,−2} には現れない。

### 2.3 L-BR2 (公刊 K0832 閉形式の R=x+Z−3 スライス直導)

公刊 single_token(x, z, R) (K1257 検証機に転写済みの K0832 閉形式) に R = x+Z−3 を代入して各枝を確認する:

- **R=0**: 閉形式先頭枝により 0 ✓ (セル (1,2),(2,1),(3,0))。
- **Z=0** (x=R+3≥4): min(R,x)=R=x−3 < x → (x−3)%2 = 1−x%2 = [x even] ✓ (Z≤x−1 枝)。
- **Z=x≥2** (R=2x−3): 第3枝: R 奇 (✓) かつ R ≤ 2x−1 (✓, x≥1) → 2 ✓。
- **1≤Z≤x−1**: m=q_odd(Z)。
  - R ≤ m のとき: 2 (R 奇) / 0 (R 偶)。帯 R=x+Z−3、x≥Z+1 より R ≥ 2Z−2、よって m ≥ R ≥ 2Z−2 ⟹ q_odd(Z) ≥ 2Z−2 は Z≤2 のみ: Z=1: R≤1 ⟺ x≤3: (2,1) は R=0 処理済、(3,1) は R=1, m=1, 奇 → **2** ✓ (例外 (3,1))。Z=2: m=1 < R (x≥3 → R≥2) で不該当。よってこの帯の R≤m は (3,1) と R=0 のみ。
  - m < R < x+Z (常に入る: R=x+Z−3 < x+Z かつ R>m なら): (R+Z)%2 = (x+2Z−3)%2 = (x−3)%2 = [x even] ✓ (Z≤x−1 枝)。
- **Z≥x+1**: m=q_odd(x)。
  - R ≤ m のとき: 帯 R ≥ 2x−2、m ≤ x より x ≤ 2。x=1: Z≥2, R=Z−2 ≤ m=1 ⟺ Z≤3: Z=2 は R=0 済、Z=3 は R=1, 奇 → **2** ✓ (例外 (1,3))。Z≥4 は R≥2>m 不該当。x=2: Z≥3 → R=Z−1≥2 > m=1 不該当。x≥3: R ≥ 2x−2 ≥ x+1 > m 不該当。
  - それ以外: x%2 = [x odd] ✓ (Z≥x+1 枝)。
4 分枝・例外 2 個・R=0 をすべて確認し、L-BR2 主張と一致する (∎)。機体 D7 は L-BR2 を claim==engine==公刊閉形式で 577 セル照合する。

### 2.7 帰納の組み立て (単一 R 強帰納)

帰納域 := {T-BB2 セル (n≥3, X, z)} ∪ {L-2 セル (n=2, X, Z≥1)} ∪ {PB2 セル (n=2, plane 0)} ∪ {L-0 セル}。L-BR2 セルと空集合の B 子 (plane は増えても多重集合は空) は公刊 K0832 閉形式・§2.2 により域の**外**で既知とする。

§2.1 の型付き子により、域内セルの全オプションは除算 R−1 を持ち、かつ帰納域 ∪ {L-BR2, L-0} のいずれかに落ちる: A 子は同一の行の第2行セル、B 子は (n−1) 面の第2行セル (n−1=2 は plane z+1≥1 で常に L-2、n−1=1 は L-BR2、n−1≥3 は T-BB2)、C 子は (z−1) plane の第2行セル (n=2, Z=1 のときだけ PB2 に着地) で z=0 では存在せず、空多重集合の子は L-0。よって R に関する単一の強帰納で全定理が同時に閉じる。

基底 R=0: PB2 (1,1) は終端 0 (= 主張 ✓); L-2 は R=S+Z−2 ≥ 2+1−2 = 1 で R=0 セルなし; T-BB2 は R=S+z−1 ≥ 3+0−1 = 2 で基底なし ((1,1,1)@0 は R=2); L-0/L-BR2 は域外。帰納段: 各域の領域代数 (§2.4–2.6) は子の値を「R−1 での主張」としてのみ参照して閉じる ∎

**T-BB2/L-2/PB2/L-BR2/L-0 証明終**。

### 2.8 系 A/B/C の導出

§1 に記載のとおり: 系A は T-BB2 の 2-line (D=−1, E=z) に厳密一致 ((1,1,1) は X=(x,Y,W), Y,W≥1 で到達不能、帯条件は E<z+3 自明)。系B は行 k=導出: R=2x−1 = S+(z+1)−1 → k=z+1 = z+n−2 (n=3): 公刊 T-DB の Dlaw(E=z+2, p=z+1)=2。系C は行 k=z=z+n−3 (n=3): 公刊 T-BB の u=E+z+n−4=(z+1)+z−1=2z より z=0 → u=0 → 2、z≥1 → u≥1 → [E odd]=[z+1 odd]∈{0,1}≠2。いずれも帯条件 x<2x−1<S+z+2 を満たす (∎)。

### 2.9 n=2 面と公刊則との接続

L-2/PB2 は n=2 面の第2行 (plane 法 k=Z−2 / 壁行 k=−2)。n=2 頂行は公刊 (K1313 経由の T-BB n=2 = K1310 T-NCW 系) で既知。よって n=2 も k≥z+n−4 が閉じ、O-BBL2 の n=2 側は全部解消。機体 D8 は公刊アンカー (T-BB n=2/n=3、T-DB、T-CSUM、K0832 単一トークン閉形式) を転写照合し、D7 は L-BR2 を claim==engine==公刊閉形式で照合する。
