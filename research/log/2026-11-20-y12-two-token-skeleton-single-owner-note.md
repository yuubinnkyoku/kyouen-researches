## 事前の横断予想（y=6..11 の出版表からの外挿であり y=12 の証明ではない）

- tail 開始: R >= x+z+13 = x+z+y+1・値 (x+12) mod 2。y=12 は偶数 y で
  値1無限帯・tail 値1 は x 奇行（y=10 型。y 偶奇が行型を決める）。
- 基底点: {z+1, z+3, ..., z+23} の 12 点（基底点 y 点仮説の y=12 版）。
- マージ行: x <= z-13（S <= z-1）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+36)/2・pin 行の d は奇z d≡y≡0 (mod 4)・
  偶z d≡y+2≡2 (mod 4)。奇z の d 範囲は族式 [−y+4,y] から {-8,-4,0,4,8,12} を
  予想。偶z は族式が非一様のため probe データから決定する。
- 対角行 d=-12: 値2上端 cap = z+y−[z≡y (mod 2)]（z odd: O[1,z+12]・z even: O[1,z+11]）。
  偶z 対角行の値1全欠如（y=8/9/10/11 で4族連続）の y=12 での判定を data-driven で。
- 掃引行 d=13 / 定常行 d>=14: steady pin {z+24}（奇z）/{z+25}（偶z）・
  band 下端 offset 2y+2 = 26・掃引帯は [z+24, x+z+12]（奇z・o even）/
  [z+25, x+z+12]（偶z・offset 偶奇は ladder parity）。
- I 行の無限帯開始: y 偶族は offset 2k（y=10 型・y 奇族の 2k+1 と対照）。
  最終 pin 行 d=y=12（奇z）は I 帯を pin（offset 24）を skip して z+25 から。

## 範囲外の明示

3トークン以上・y>=13 族・固定幅・q点版安定化長・fold 系・q5-m22・y=11 正本監査 part2 は対象外。
