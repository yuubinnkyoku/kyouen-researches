## 事前の横断予想（y=6..15 の出版表からの外挿であり y=16 の証明ではない）

- tail: x 奇行（S=x+16 偶・偶数 y 型 y=10/12/14 と同型・「y 偶奇が行型を決める」
  観察の 16 族目候補）・R >= x+z+17 = x+z+y+1・値 (x+16) mod 2。
  tail 開始族式 x+z+y+1 の次の確定候補（y=2..15 の 14 族連続に続く
  **15 族目候補**〔tail開始族式の連続集計では y=2..16 の15族〕）。
- 基底点: {z+1, z+3, ..., z+31} の 16 点（基底点 y 点仮説 {z+1,..,z+2y-1} の
  16 例目候補）。
- マージ行: x <= z-17（S = x+16 <= z-1）。マージ命題一般形 x<=z-(y+1) の
  y=16 版（全称確定 y=1..15 の次・fit level 16 族目）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+48)/2・pin offset o_pin∈[y+1,2y]=[17,32]
  かつ o_pin≡z+1 (mod 2) の統一式（y=5..15 の 11 族全称確定格子の y=16 外挿）から、
  奇zは d≡0 (mod 4) {-12,-8,-4,0,4,8,12,16} の **8 行**・
  偶zは d≡2 (mod 4) {-14,-10,-6,-2,2,6,10,14} の **8 行**。
  y 偶族式の pin 行数 y/2 が 5→6→7→**8** と増加し y=16 で初めて両偶奇 8 行に
  到達するかが y=10/12/14 に対する y=16 の主要な行数則判定材料
  （偶数 y 系列のデータ点としては第4点）。
  最終 pin 行 d=16=y が偶y族で初めて上端 d=y に達した I[2y+z+1)=I[33) 型
  （10 族連続の **11 族目候補**）で pin z+32 = 2y+z は直後の定常 pin と同値。
- 奇z I 帯行（d 偶 17 行・対角 d=-16 込み）: k(d) = floor((d+50)/4)
  = floor((d+3y+2)/4)（y 偶族則: y=12 の floor((d+38)/4)・y=14 の
  floor((d+44)/4) の系列）・th = 2k + [d≡0 (mod 4)]（pin 行〔d≡y mod 4〕は
  th=2k+1・skew 行〔d≡2 mod 4〕は th=2k・skew 行は slot=2k-1 が b_k 上端点と

  恰好が要る）。

## 範囲外の明示

標準 11×11 の空盤勝敗・二石 root・S2 {59,60} には一切言及しない。
3トークン以上・y>=17 族・固定幅・q点版安定化長・fold 系・n11 batch 系
（Part AY/AZ/BA）は対象外（y=16 全称証明段階も本宣言の範囲外・別宣言とする）。
y=11（K1143）part2 保留案件にも着手しない。横断法則（基底点・tail 開始・
マージ・clip 窓・pin 格子・対角行規則・I 帯 th/shift）の一般補題化レーンとも
本 fit は非接触（本 fit の結果は一般補題化レーンの偶数 y 系列第4データ点と
なる）。既に別オーナー宣言が main に存在する経路には着手しない。
本宣言と競合する y=16 族宣言が main に存在する場合は本宣言を撤回して譲る。
