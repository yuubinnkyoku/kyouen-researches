## 事前の横断予想（y=6..17 の出版表からの外挿であり y=18 の証明ではない）

- tail: x 奇行（S=x+18 奇・偶数 y 型 y=10/12/14/16 と同型）・
  R >= x+z+19 = x+z+y+1・値 (x+18) mod 2。tail 開始族式 x+z+y+1 の
  **18 族目候補**（y=2..17 の 17 族連続の続き・fit level）。
  box 内の tail 帯は R∈[x+z+19, x+z+38] の 20 点深。
- 基底点: {z+1, z+3, ..., z+35} の 18 点（基底点 y 点仮説 {z+1,..,z+2y-1} の
  **18 例目候補**）。
- マージ行: x <= z-19（S = x+18 <= z-1）。マージ命題一般形 x<=z-(y+1) の
  y=18 版（全称確定 y=1..17 の次・fit level 18 族目候補）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+54)/2・pin offset o_pin∈[y+1,2y]=[19,36]
  かつ o_pin≡z+1 (mod 2) の統一式（y=5..17 全称確定格子の y=18 外挿）から、
  奇zは d≡2 (mod 4) {-14,-10,-6,-2,2,6,10,14,18} の **9 行**・
  偶zは d≡0 (mod 4) {-16,-12,-8,-4,0,4,8,12,16} の **9 行**。

  **偶z pin 行が初めて 9 行に達する**（y=16 で両偶奇 8 行に初めて揃い、
  y=18 で両偶奇 9 行に揃うかが偶数 y 系列第5データ点の主要な行数則判定材料）。

  d=-16（偶z行）は z>=34 を要求するため、**両方とも box z<=30 内では
