## スコープと主張（実行前に確定）

対象は 2トークン残余ゲーム H(R; X; z)（出版正本エンジン H_ordered/H_canonical、K1138転写系列、y18全称機 verify_y18_universal.py SHA-256 正本から照合のうえ逐語再録）。X は降順トークン多重集合、σ=ΣX、z は非負整数。

1. **FR-X（frontier reduction 補題・証明予定、status: proved）**: 全称帰納（σ の強帰納 + z-tower の k 再帰）で示す: 「境界行 b_X(R') = H(R'; X; σ) が以下の前沿条件 F±X（有限・R'<=2σ、R'>=2σ+1 は出版 tail R>=σ+|X|+z-1→σ mod 2 で自動）を満たすならば、z>=σ+1 の全状態で H(R;X;z) = ST(σ,z,R)（ST=出版単一トークン z 非依存プロファイル single_token_val）」。F±X（σ even）: b_X(odd<=σ-1)≠1, b_X(even<=σ)==0, b_X([σ+1,2σ])≠1。（σ odd）: b_X(odd<=σ-2)≠1, b_X(even<=σ-1)==0, b_X([σ,2σ])≠0。k=0 前沿での mex 比較は 27ケース表（t=0 で mex({0,1^b}) 同値 ⟺ b==s、t≠0 で mex({t,1^b}) 同値 ⟺ [b==1]==[s==1]）に完全還元され、これを機械列挙検証する。アリティ非依存（κ=1 の出版単一トークン理論が κ=0 基底）。従来の y族ごとの全領域検証器（~690万点）に対し、族追加ごとの検証コストを境界行のパリティ有限検査に削減する効率補題。
2. **GX-M（一般Xマージ法則・観察）**: 3/4/5トークンでも z>=σ+1 で H(R;X;z)=ST(σ,z,R)。監査範囲: 3トークン σ<=12 全列挙、4トークン σ<=10 全列挙、5トークン σ<=8 全列挙、ストレッチ標本（(7,5,3),(8,4,2),(10,7,5),(12,9,3),(9,8,7),(6,5,4,3),(8,6,4,2),(5,4,3,2,1),(7,7,7,7,3)）、z∈{σ+1,σ+2}、R<=σ+z+4。予想点数 5,080。出版生エンジン vs 出版閉形式 single_token_val、bad 0 予想。
3. **F±X の 3/4/5トークン監査（観察）**: 同族の境界行 z=σ、R<=2σ+2 で F±X を直接検査。予想: 全 bad 0（プレフライト58族で既に bad 0 を確認済み）。
4. **BSL（2トークン境界行法則・観察）**: 族 (x,y), x>=y>=1 の境界行 b(R)=H(R;(x,y);S), S=x+y について: (i) R < R* := x+2y+1+(x mod 2) で b(R) = s(R)（出版単一トークン閉形式 single_token(S,S,R)）、(ii) R>=R*-1 で b(R)=S mod 2（出版 tail より早期の tail onset、(x,y)=(1,1) は R*>2σ で乖離窓がそもそも空）、(iii) b と s の最初の乖離は R* ちょうど（(1,1) を除く）、(iv) 乖離は窓 [R*,2σ] に局限。監査範囲（高速 DP 列エンジン・出版生エンジンと全セル交叉検証のうえ）: y=1..30 × x=y..y+12、R<=2S+6。予想点数: (i) 21,060 (ii) 10,140 (iii) 389+特例1 (iv) 390。
5. **F±（2トークン前沿条件・観察+証明済み族では理論帰結）**: 同範囲で R<=2S+2 の F± を検査、予想 29,640 点 bad 0。さらに証明済み闭形式 cand17/cand18（K1240/K1242 proved）自身の境界行が BSL/F± に一致することを x<=y+40 で機械確認（9,266 セル）: y<=19 の証明済み族では F± が族閉形式の帰結であることの傍証。
6. **2トークンマージ法則の DP 大掃引（観察; y<=19 は出版全称で既知）**: y=1..30 × x=y..y+12 × z∈{S+1,S+2} × R<=2S+6: H=ST の再検査、予想 63,180 点 bad 0。y=20..30 の 390 族分は新規 raw/DP 証拠（y=20/21 は各 fit レーンの raw anchor と独立な再導出）。生エンジン三点照合を y∈{20,22,24,26,28,30} × x∈{y,y+2} の 12族で実施。
7. **low-R 一般X縮約（観察）**: R<=z+1 で H(R;X;z)=single_token(σ,z,R)（κ=1 出版縮約の一般X拡張）。3/4/5トークン σ<=10/9/7 全列挙+ストレッチ、z∈0..σ+3、予想 5,984 点 bad 0。
8. **エンジン交叉検証**: 新規 DP 列エンジン（dp_engine.py・empty値恒等0の inline 証明つき）を出版生エンジンと全セル照合: (6,4),(9,7),(12,12) 既に 212,409 セル bad 0（非公式プレフライト）に加え (20,20),(24,24),(28,26) の全セル照合を公式監査に組み込む。出版単一トークン閉形式の生エンジン raw アンカー（x<=24、全 z サブボックス、~1.4万点）も実施。
