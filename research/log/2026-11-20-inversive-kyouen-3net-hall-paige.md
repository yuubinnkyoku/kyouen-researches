# 反転平面の共円ゲームを3-ネットに翻訳し、τ₃ = q−1 を証明した

2026-11-20。`finite-field-kyouen-20261120` の一連の作業（第117〜122部）の記録。

## 発見の順序

### 1. Steiner 設計への一般化（三分法）

`AG(2,q)` と反転平面がどちらも Steiner 3-設計であることに気づき、
一般の `t-(v,s,1)` 設計でゲームを定義した。

**三分法**：`t ≥ 4` なら `K = 3`（自明化定理）、`t = 3` が新しい領域、
`t = 2` は古典的 `(k,3)`-アーク。

9つの設計（`PG(2,2..5)`, `AG(3,2)`, 反転平面 q=3,5, Witt `S(3,6,22)`,
`S(4,5,11)`, `S(5,6,12)`）で検証、すべて成立。

**一般上界** `K ≤ λ₂ + 2`、**一般下界** `K = Ω((v/s)^(1/3))` を証明。

### 2. 交差比による 3-ネット翻訳

`P¹(F_{q²})` の4点が共円 ⟺ 射影的交差比が `P¹(F_q)` に入る。
同次座標で書くのが必須（非斉次で書くと q=3 で 72/210 が不一致になった）。

`S = {0,1,∞} ∪ T` と正規化すると、族 B（2点条件）は
`F_{q²}\F_q` の3つの分割 `(P₀, P₁, P_∞)` に関する横断条件になる。
各分割は q クラス × サイズ q−1 で、これは **3-ネット**である。

### 3. ラテン方陣の完全公式

`F_{q²} = F_q[w]`、`w² = d`（非平方）とすると

```
c = (d − a·b)/(a − b)
```

q = 3,5,7,9 で全セル一致。関係式は `ab + ac − bc = d` と同値で
`b ↔ c` 対称。

### 4. ノルム1トーラスと `Z_{q+1}` の加法表

`A = 1/a` と置くと `A = (S + T)/(1 + d·S·T)`、これはノルム1トーラス
`T_d`（位数 `q+1` の巡回群）の群法則。

`A ↦ (A + w)/(A − w)` が `P¹(F_q) → T_d` の全単射を与え、
指数座標で `α(1/a) = α(1/b) + α(1/c)`。

**つまり 3-ネットは `Z_{q+1}` の加法表そのものである。**

### 5. `τ₃ = q−1` の証明

横断とは「全単射 `σ: Z_{q+1} → Z_{q+1}` で `α ↦ α − σ(α)` も全単射」、
すなわち **`Z_{q+1}` の完全写像**。

`q` 奇数なら `q+1` は偶数。`Z_{q+1}` の Sylow 2-部分群は位数 `≥2` の
巡回群なので、**Hall–Paige の定理（1955）**により完全写像は存在しない。

よって `τ₃ = q−1`。系として **`K ≤ q+2`（すべての奇数 q）**。

## 失敗した試み（記録）

1. **`AG(2,q)` を `mod q` 算術で構成**：これはトーラス `Z_q²` であり、
   `AG(2,q)` と一致するのは素数 q のみ。q=4,8,9 の結果は無効だった。
   反転平面から派生させて作るのが正しい。
2. **交差比を非斉次なメビウス極限で計算**：`∞` の扱いを誤り q=3 で
   72/210 が不一致。同次座標の 2×2 行列式で書くのが正しい。
3. **トーラスのパラメータ表示 `(1 + w·A)/(1 − w·A)`**：加法関係が
   2/20 しか成立しない。正しくは `(A + w)/(A − w)`。
4. **`M_a(t) = (d − at)/(a − t)` が固定点を持たないという主張**：誤り。
   固定点は `(t − a)² = a² − d` の解で、`(q−1)/2` 個の `a` で2個存在する。
5. **族 C を「3点が同じ `P_a` クラスに入る」と特徴づける**：誤り。
   `P_a` のクラスはサイズ `q−1` で、3点が入り得る。族 C は
   「3点が錨を通る円上にある」という高次条件で、横断条件からは導けない。

## 検証

`final_consistency.py` が6つの主張を一括検証し、全チェック通過：

- C1: 交差比の鍵事実（q ≤ 7、247,840 個の4点組、不一致 0）
- C2: ラテン方陣の公式（q = 5,7,9 で全セル一致）
- C3: トーラス還元（全単射＋加法関係、q = 5,7,9）
- C4: `τ₃ = q−1`（奇数）/ `q`（偶数）（q ≤ 9）
- C5: `K ≤ q+2`（修正済み厳密値 10 個）
- C6: 3-ネットの分割構造（q ≤ 9）
