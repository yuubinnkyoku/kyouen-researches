## 事前の横断予想（y=6..16 の出版表からの外挿であり y=17 の証明ではない）

- tail: x 偶行（S=x+17 奇・奇数 y 型 y=9/11/13/15 と同型）・
  R >= x+z+18 = x+z+y+1・値 (x+17) mod 2。tail 開始族式 x+z+y+1 の次の
  確定候補（17 族目候補）。
- 基底点: {z+1, z+3, ..., z+33} の 17 点（基底点 y 点仮説 {z+1,..,z+2y-1} の
  17 例目候補）。
- マージ行: x <= z-18（S = x+17 <= z-1）。マージ命題一般形 x<=z-(y+1) の
  y=17 版（全称確定 y=1..16 の次・fit level; box 内は空）。
- pin 格子: pin = z+(d+3y)/2 = z+(d+51)/2・pin offset o_pin∈[y+1,2y]=[18,34]
  かつ o_pin≡z+1 (mod 2) の統一式（y=5..16 の 12 族全称確定格子の y=17 外挿）から、
  奇zは d≡1 (mod 4) {-15,-11,-7,-3,1,5,9,13,17} の **9 行**・
  偶zは d≡3 (mod 4) {-13,-9,-5,-1,3,7,11,15} の **8 行**。
  y 奇族式の pin 行数が奇z (y+1)/2 は 6→7→8→**9** に増加・偶z (y-1)/2 は
  5→6→7→**8** に増加するかが y=11/13/15 に対する y=17 の主要な行数則判定材料
  （9 pin 行族は初到達）。
  最終 pin 行 d=17=y が奇z pin 行の上端（I[2y+z+1)=I[35) 型・**12 族目候補**）で
  pin z+34 = 2y+z は直後の定常 pin と同値。

  = floor((d+3y+1)/4)（y 奇族則: base 行と同一族式）・th = 2k+1
  （y 奇族の 2k+1 ペア反復型が y=11/13/15 に続き継続するか）。

  y=11..16 の 6 族連続に続く **7 族目候補**（y=17 では pin 行 d≡1 (mod 4) の
  9 行すべてで格子一致が要る）。対角行 d=-17 は I 帯行として k=8・th=17。
