# 2026-11-02：第二の終局証明を後退閉包し、元先手WINを256,561生局面まで再利用

対象は標準11×11・完全指摘・通常プレイ、第二の六石終局証明 `terminal_s6_60_strategy.b64`（復号14,440バイト、SHA-256 `debb5464282eb28e6a30496f8728515433d6f9507ffdeeda1eeaf04e3c5d7de4`）。

元の固定戦略は22,364到達局面、元先手の戦略指定14,440局面、相手非終局4,982局面、終局2,942局面、辺34,055本で、元先手敗北終局は0。既存Python検査器とは別に、4×4整数行列式を余因子展開するC++実装で全応手を再生した。

## 新しい構造的再利用

勝ちが確定した局面集合 `W` を出発点に、次を繰り返す。

- 石数偶数（元先手番）：合法な一手の子が `W` にあれば、その局面も元先手WIN。
- 石数奇数（相手番）：合法な**全**一手の子が `W` にあれば、その局面も元先手WIN。合法手0の終局も含む。
- 新しい候補は `W` の局面から一点を除去して列挙する。既存局面より前の石数だけを追加するため、帰納的に健全。

追加件数は反復順に **83,556 / 19,589 / 99,467 / 7,567 / 22,511 / 291 / 1,216 / 0**。8回目でこの候補生成規則に関する閉包に達した。

新しい六石生局面6個は既にK0628で共有七石から持ち上げて証明した親局面であり、**新規の六石正準WIN類を6類追加したわけではない**。大部分の増加は石数10〜16の中間局面で、既存証明を他の探索へ再利用できる候補である。

独立C++検証器 `verify_terminal_s6_60_closure.cpp` と、固定SHAを検査して一時復号・コンパイル・実行する `verify_terminal_s6_60_closure.py` を保存。手元では約17秒・約110MBで全数を再現した。専用CI `n11-central49-terminal-s6-closure.yml` の結果は完了後に確認する。

**限界**：これは既存終局証明からの局所的な後退閉包であり、盤面全体の256,561局面を新たに探索した結果ではない。既存の全勝敗cacheへの統合、二石root閉鎖、六石LOSS証明はいずれも未実施。条件付き46証人・2,207七石類の計画を変更する証拠もない。標準11×11空盤勝敗は**UNKNOWN**。
