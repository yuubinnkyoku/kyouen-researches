# 2026-11-07 一辺細分星の接触二重根の不存在（全 q）

- 対象: `T_{k,r}(u) = u^{k+1} + (r+2)u^k + (r+1)^k u + r(r+1)^{k+1}`、`r = q-3`、奇数 `k >= 3`。
- 起点: `graph-star-subdivided-star-general-odd-threshold-20261105/proof.md` が最後に残した未解決点
  「整数 r>=2、奇数 k>=3 で F_{k,r} の接触二重根が存在しないことを代数的に示すか、反例を見つける」。
- 方法: 接触条件 `F = F' = 0` から2次式 `(B)` を導き、その判別式が
  `Δ(r,k) = ((r^2-2)k + (r^2+2r+2))^2 - 4r(r+1)(r+2)` と因数分解することを見つけた。
  - `Δ` が非平方なら `(B)` は既約。共役根も `F' = 0` を満たすが、`F'` の正根は一意（`y^{k-1}((k+1)y-ka)-1` は
    `y_*=ka/(k+1)` まで `<= -1`、以後狭義増加し `F'(a)=a^k-1>0`）なので矛盾。ゆえに接触 ⟹ `Δ` は平方。
  - `Δ` が平方なら `A = (r^2-2)k + P` は `ab = r(r+1)(r+2)` なる約数和 `a+b`。よって `A <= 2R+1/2`、`k < 2r+9`。
  - `r >= 4` では `M(2r+7) < r-a`（`M(k)=max H = a^{k+1}k^k/(k+1)^{k+1}`、`a^{2r+8} <= e^{16/5} < 34`、
    `34/(2r+8) <= 17/8 < 8/3 <= r-a`）なので奇数 `k <= 2r+7` で `F > 0`。接触の必要条件と矛盾。
  - `r = 1,2,3` は奇数 `k` の有限個で `Δ` が平方でないことを確認（約数対の解析で全奇数解なし）。
- 結果: 定理A（全 `r>=1`・奇数 `k>=3` で接触二重根なし）と定理B（`r>=2` で実根数は常に 0 か 2、
  `κ(r)` を境に 0 個 → 2 単根の単一切替）。先行の q ごとの境界表はすべて定理B の実現例となる。
- 系: `r>=4` で `r floor(log2 r)-1 < κ(r) <= 5(r+1)ceil(log2(r+1))+1`、すなわち `κ(r)=Θ(r log r)`。
  下界は `L=floor(log2 r)` と `k0 = rL 以下の最大奇数` に対し `ln M(k) <= L - ln(k+1) < ln(r-a)` から `κ(r) > k0 >= rL-1`。
  上界は `n=ceil(log2(r+1))`、`k` を `5(r+1)n` 以上の最小奇数とすると `M(k) > a^{k+1}/(e(k+1))` かつ
  `ln a^{k+1} >= 5ln(r+1)(1-1/(2(r+1)))` より `M(k) > r`、したがって `F(y_*)<0`。
  `r>=400` は初等評価、`4<=r<=400` は `kappa_two_sided` の両端厳密検査。
- 検証: `verify_no_contact_double_root.py`（完全整数・有理数演算）。
  判別式恒等式 1,500 組、`M(2r+7)<r-a` を `r=4..4000`、約数和条件 `r<=300`（接触候補 0）、
  平方判別式 `r<=200`（0 件）、`κ(r)` 表（各境界は M 上界または接線上界、浮動小数点は候補提案のみ）。
  既発表の q=21..210 の 190 行を `regress_existing_boundaries.py` で再計算し全行一致（q201-q210 の追加表も含む）。
- 含意: `q>=5` の全 q で「実根0個 → 相異なる負の単実根2個」の切替が1回だけであることが無条件に従う。
  接触重根を避ける有限計算は `r=1,2,3` の3例だけで、残りは代数的証明である。
- 限界: `κ(r)` の閉形式・漸近定数は未証明（`Θ(r log r)` の二側評価まで）。`q=4`（`r=1`）は `F(1) = 1-a < 0` のため別領域で、
  常に負の実根をもち「0個」の相は現れない。標準格子盤・ゲーム勝敗への主張ではない。
- 次: `κ(r) / (r log r)` の極限と定数改善、`q=4` の実根構造の分類、終局長分布の単峰性への応用検討。
