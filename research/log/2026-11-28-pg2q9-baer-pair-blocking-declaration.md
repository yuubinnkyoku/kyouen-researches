## 目的

K1371 レジューム (d): 「q=9平面のBaer部分平面対による3q未満2重ブロッキング探索
(PG(2,9) 27 vs 26以下・理論+実験)」。K1371 は「Baer部分平面の対による3q未満候補は
q≤9で未発見」と記録したが、それは局所探索ベースであり、Baer対の系統的censusは
未実施だった。本作業はBaer対を全数censusしてこの候補問題を厳密に決定する。

## 手法（宣言後に実行するもの）

1. **盤構成** (`scripts/boards9.py`): GF(4)/GF(9)/GF(16) を多項式環
   (GF(4)=GF(2)[x]/(x²+x+1), GF(9)=GF(3)[i]/(i²+1), GF(16)=GF(2)[a]/(a⁴+a+1))
   で独立構成し、PG(2,q²) の点・直線・design検査 (2-(v,q²+1,1)) を検証。
   Baer基底 = 部分体 GF(q) 有理点 (|B| = q²+q+1)。
2. **Baer性検査** (`scripts/baer.py::verify_baer_base`): 全直線との交差が
   {1, q+1} のみ (Baer性)・内部design 2-(q²+q+1, q+1, 1)。fail-closed。
3. **PGL(3,q²) 軌道**: 生成元 (初等変換 E_ij(c)・対角・座標交換) による
   点置換でBFS全列挙。|PGL| = (q²³-1)(q²³-q²)(q²³-q²²)/(q²-1) との
   軌道-安定化群整合 (整数割り切り) を検証。
4. **対censusと2重ブロッキング判定**: full mode (PG(2,4): 360軌道・
   PG(2,9): 7,560軌道) は全対 (C(N,2)) の交差census + 2重ブロッキング
   直接判定。補題: |A∩L|≥2 かつ |B∩L|≥2 なる直線では
   |(A∪B)∩L| ≥ max ≥ 2 なので、判定は A・B の solo line (交差1の直線)
   だけでよい (fail-closed: witnessは全直線popcountで再検査)。
   PG(2,16) はサンプリング (seed固定 20261128・3,000歩のランダムウォーク)
   として開示。
5. **AG制限スキャン** (`scripts/ag_scan.py`): disjoint Baer 対の union を
   ℓ∞ の選択付きで AG(2,9) に制限した場合の2重ブロッキング可能性を
   サンプリング (3,000対 × 91直線)。
6. **再検証** (`scripts/verify_baer.py`): 盤再構成による witness 定義直接
   再検査・軌道サイズ再計算 (生成元順序変更)・ counting lower bound
   (k ≥ ceil(2n/(q²+1))) の計算。

## Non-claims

- 「すべての素素数べき q≥3 で PG(2,q²) に disjoint Baer 対が存在する」は
  本実験では機械検証 (q=2,3 のfull census・q=4 のサンプリング) のみで、
  一般証明はしない (次項で一般条件付き補題として整理する)。
- PG(2,9) の min の下界は counting bound (19) のみ。SAT による締め付けは
  実施しない (重い・長期レーン向け)。
- witness の「最小性」は Baer 対に限定した最小性 (全 2 重ブロッキング集合の
  最小性ではない)。
- verdict 不消費: 標準11×11空盤・19 central-reply roots・二石root {60,27}・
  第三手 {100,108}・S2・全closure class は全時点 UNKNOWN。

## 期待される一般補題 (宣言時点・実測が上を置き換える)

Baer 部分平面 A, B ⊆ PG(2,q²) が disjoint なら A∪B は size 2(q²+q+1) の
2重ブロッキング (各直線が A・B に各≥1点)。2(q²+q+1) < 3q² ⟺ q ≥ 3。
よって「PG(2,n) の t=2 min = 3n」は n が平方数 (n=q², q≥3) かつ disjoint
Baer 対が存在する限り成り立たない。q=2 (n=4) では 2(4+2+1)=14 > 12=3n で
改善なし (実際 min=12・Baer対最小 union 13)。
