# 奇数列の長盤: 空盤のmod4則と奇数rの全Grundy公式

2026-10-05 (JST)。これは `proof.md` の占有数縮約を受けて、そこで残した
奇数列数の空盤勝敗を閉じる続編である。有限観測からの外挿ではなく、
以下のmex帰納と明示的な応答戦略が根拠となる。

## 対象と結論

相異なる底面点 `B⊂Z²` はどの三点も共線でなく、`w=|B|≥3` は奇数。
盤は `B×{0,...,m−1}`、同一超平面または超球面上のq点を禁止する通常プレイ。
`q>2w`, `r=q−1`, `m≥r` とする。この三次元変種の安全性は
占有数 `x=(x_1,...,x_w)` の全ペア条件 `x_i+x_j≤r` と同値である。
`|x|=Σ_i x_i`、`a=max_i x_i` と書く。

**定理。空盤は `q≡2 (mod4)` のとき、かつそのときに限り先手勝ち。**
空盤Grundy値はその場合1、その他は0である。

さらに `r=2k+1` が奇数なら、全安全局面について正確に

```
a≤k:
    g(x)=(k+1−|x|) mod2.

a≥k+1:
    最大列は一意。その他の列のgapを y_i=r−a−x_i と置き、
    g(x)=2 (min_i y_i mod2)+(Σ_i y_i mod2).
```

後者は `0,1,2,3` を取り得る。無界Grundy数という主張ではない。
偶数rについてここでは空盤勝敗を確定し、全安全局面の閉公式を主張しない。
長さ条件 `m≥r` は本続編の仮定であり、短盤の公式へ拡張しない。

## 1. 支配列の先には「一つまたは全部を一つ減らす」ゲームがある

この節はrの偶奇を問わない。`a>r/2` なら最大列は一意である。
他の列は `x_i≤r−a<a`。その列同士の和は高々 `2(r−a)<r` なので、
合法性を支配するのは最大列とのペア制約だけである。

他列を一つ増やす手は、対応する `y_i=r−a−x_i` を一つ減らす手であり、
`y_i>0` のとき、かつそのときに限り合法。
最大列を増やす手は、全てのyを一つ減らす手であり、全 `y_i>0` のとき、
かつそのときに限り合法。m≥rなので列の盤端はこの手を追加で制限しない。
最大列は以後も最大のままである。

従って残る有限ゲームは、偶数個 `n=w−1` の非負整数gapに対して、
「正のgapを一つ減らす」または「全gapが正なら全てを一つ減らす」ゲームと
同型である。gapの総和を基準に帰納できる。

## 2. 偶数個のgapゲームの全Grundy値

偶数n≥2と `y∈Z_{≥0}^n` に対し

```
h(y)=2 (min(y) mod2)+(Σy mod2)
```

を証明する。`t=min(y)`、`e=Σy mod2` と書く。
一つを減らす手はeを反転する。全てを減らす手はnが偶数なのでeを保ち、
tの偶奇を反転する。従って全ての手で候補値が変わる。

- 候補0: 値0へ行く手がないのでmexは0。
- 候補1: tは偶数、e=1。t=0なら正のgapを一つ減らし、最小値0を保って
  候補0へ行く。t>0なら全gapが等しいことはe=1と両立しないため、tより
  大きいgapを一つ減らして最小値tを保ち、候補0へ行く。値1へ行く手はない。
- 候補2: tは正の奇数、e=0。全てを減らす手で候補0へ、最小gapを一つ
  減らす手で候補1へ行ける。値2へ行く手はない。
- 候補3: tは正の奇数、e=1。全てを減らす手で候補1へ、最小gapを一つ
  減らす手で候補0へ行ける。全gapが等しくはないので、tより大きいgapを
  一つ減らして候補2へも行ける。値3へ行く手はない。

各場合で0から候補値の一つ手前までが後続に全て存在し、候補値自身は
存在しない。終局y=0を含めてmex帰納が成立する。
これは選択肢の分類そのものであり、計算された表に依存しない。

## 3. 奇数rの低占有領域

`r=2k+1` とし、全列 `x_i≤k` の領域を考える。
`z_i=k−x_i≥0` と置く。
`z_i>0` の列への追加はそのgapを一つ減らし、低占有領域に留まる。
`z_i=0` の列への追加も常に合法であり、その列がk+1となって支配列領域へ
移る。この後続の他列gapは正確に `(z_j)_{j≠i}` である。

低占有領域の候補を `f(z)=1−(Σz mod2)` とする。
領域内の手では候補が反転する。支配列へ出る手の値は前節から

```
2 (min_{j≠i} z_j mod2)+(Σz mod2).
```

となるため、その偶奇はΣzと一致し、常にf(z)と逆である。

f=0なら全後続の値は1または3なのでmexは0。
f=1なら値1の後続はなく、正のgapがあれば領域内の手で値0へ行ける。
全gapが0なら支配列へ出る手が終局（値0）を与える。従ってmexは1。
Σzについての帰納で `g(x)=f(z)` が従う。wが奇数なので
`Σz≡k−|x| (mod2)`、したがって主張した低占有公式になる。

空盤では `g(0)=(k+1) mod2`。これは `r≡1 (mod4)`、すなわち
`q≡2 (mod4)` のとき1である。

## 4. 偶数rの空盤には常に合法な二手応答がある

rを偶数とする。後手は先手が増やした列をもう一度増やす。
後手の手番終了時には全列の占有数を偶数に保つ。

先手が第i列を `x_i→x_i+1` としたとする。先手手前の全 `x_i+x_j` は
偶数であり、先手手後は奇数でr以下だから、元の和はr−2以下である。
従って後手が同じ列を増やした後の全ペア和もr以下。
合法な先手手では `x_i≤r−2` なので、追加後も `x_i+2≤r≤m`。
盤端にも遮られず、空点を一つ選べる。

有限ゲームで先手の全ての合法手に後手が合法な手を返せるため後手が最後に
動き、空盤はP局面、g=0。r偶数はq奇数に対応する。前節と合わせて全qの
空盤勝敗が確定する。

## 5. 明示的なnimber3と検算の範囲

q>2w、w≥3が奇数、r=2k+1ならk≥3。
占有数 `(k+1,k−2,k−1,...,k−1)` の支配列gapは
`(2,1,...,1)`。偶数個のgapの和は奇数、最小は1なのでg=3。
これと全公式により、奇数rの全安全局面に現れる最大Grundy値は正確に3。

`odd_root_verify.py` は別のラベル付き完全mex DPで小パラメータの全安全占有数
を検査し、共有占有数DPでもより大きな奇数列数を照合する。gap補助ゲームも
別に全列挙する。保存先は `odd-root-output.json`。
有限検算は実装の確認であり、無界なw,q,mへの根拠は上記証明である。
二次元標準盤のGrundy無界性や11×11勝敗は対象でなく、後者はUNKNOWN。
