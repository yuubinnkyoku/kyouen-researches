# 10×10 20石安全集合のSAT判定 — K0141 (K_10 ≥ 20?) へのSAT/カット攻撃 (2026-11-15 高速レーン)

## 位置づけ

`K_10` (10盤の最大安全サイズ) は `19 ≤ K_10 ≤ 23` (K0035・K0141)。
K0141の次ステップに明記されている「SAT/ILP with stronger cuts」を実行する。
既往の B&B (243M節点)・MILP (HiGHS) はいずれも未決着。

## 符号化

- 変数: セル選択 x_c (100個) + 逐次カウンタ。
- 禁止4点組: 独立整数行列式符号化 (4×4 determinant rows (x²+y², x, y, 1)、
  差分行3×3展開)。**F_10 = 54,441 が K0057 の既刊値と厳密一致**
  (符号化の独立クロスチェック)。
- at-least-k: 双方向 (定義的) 逐次カウンタ s(i,j) ⟺ 「x_1..x_i のうち ≥j 個が選択」。
  前置カウント意味論がモデル論理帰結 (両向きの節が存在)。
- 節: 1個の禁止4点組 = 4リテラル節 (¬a∨¬b∨¬c∨¬d)。

### カット (published局所排除定理のSAT埋め込み)

saturation-20261003-extra の完全列挙により確定済みの
(X1) |S∩T|≥10 なる安全20点集合は存在しない (T = 19石安全極大)
(X2) |S∩U|≥10 なる安全集合の最大サイズは19 (U = ほぼ安全20点、禁止4点組は唯一)
を、D4対称性 (安全・サイズ・交差を保存する全単射) で全8像に拡張し、
T・Uの16個のD4像それぞれに **at-most-9交差制約** (at-least-10カウンタの
否定ユニット) として埋め込んだ。カット版のUNSATは
(X1)/(X2) の完全列挙 (C++探索器・節点数照合つき) を前提とする。

### |S∩T| = j 完全場合分割 (split_ge20cuts.py + n10_split_driver.sh)

- CNF 内の T 恒等像カットブロック (19セル逐次カウンタ・k=10) の
  s(19,j) = 2480+j (block offset 2300) を使い、
  **|S∩T| = j (j = 0..9)** をピンする完全排反場合分割を作る
  (各サブCNF = base CNF + ユニット1〜2節。j=0 は ¬s(19,1)、
  j≥1 は +s(19,j) ∧ ¬s(19,j+1))。
- j=0..9 はカットの許容値域 (|S∩T|≤9) を完全に被覆するため、
  **10サブインスタンス全 UNSAT ⟺ base CNF UNSAT**。
- 各サブインスタンスの判定は `n10_split_records.jsonl` に1行ずつ記録
  (key = tj0..tj9・comma-anchored skip・同一 CAP の INDET 再実行は skip)。
  環境リセット越えで完了分が失われない (単発実行との決定的な差)。
- driver は `bash n10_split_driver.sh` (CAP 環境変数・既定 3600s)。
  実行優先度は (4,22,5) 掃引・その x2 分割の合間。
- 全 UNSAT の暫定解釈は単発版と同一: K_10 ≤ 19 (X1/X2 の完全列挙前提)。
- base CNF 再生成 md5 照合済み (584087313e50ec614e3c35c1935d224e)・
  制御 K1-K4 再実行 PASS・10サブCNF の md5 は split_gen.log 記載。
