# 2トークン残余ゲーム z=8・y=1 境界切片の全Grundy分類（K0983）

- 日付: 2026-11-19
- 対象: 抽象残余ゲーム H(R;(x,y);z)（R手残余・トークン多重集合 X、通常値 z、周期基底 S）のうち、2トークン X=(x,1)・z=8・境界 y=1 のスライス。全 x≥1・全 R≥0。
- 状態: **全称定理（全x・全Rで証明済み）**
- 関連: K0832（残余ゲームHの再帰・Theorem T・単一トークン全z公式・tail定理・高さのみ縮約）、K0977（z=7・y=1境界切片の全Grundy分類。C子の評価に使用）、K0978..K0982（z=7・y=2..6境界切片）

## 記法

- Vₓ(R) を位置 (R;(x,1);8) の選択肢（子のGrundy値）の集合と書く。
- O[a,b]={n: a≤n≤b, n奇}, E[a,b]={n: a≤n≤b, n偶}, I[a,∞)={n: n≥a}。
- 署名は子の値集合の昇順文字列: 01={0,1}, 23={2,3}, 03={0,3}, 02={0,2}, 13={1,3}, 12={1,2}, 023={0,2,3}, 123={1,2,3}, 0={0}, 1={1}。

**値1位置（H=1となるRの集合 P₈⁽¹⁾(x)）:**

残りは値0。R=0 は常に H=0。tail は **R≥x+10 ⟹ H=(x+1) mod 2** であり、K0832 の一般tail定理（2トークンでは R≥S+|X|+z−1=x+10）と整合する。

R≤9 の値は高さのみ縮約定理（K0832）で全 x について一意に H=v(x+1,8,R) と決まり、上表の R≤9 部分と一致する（値2がR∈{1,3,5,7}∪{x=7では9}、値1がR=9（x=9では8以外は偶数x=2,4,6,8の冪I帯）、x≥11では9）。x依存の構造は R=9 以降に現れ、x≥11 では値2の第5点が9でなく**11**になる（z=7との違い）。

## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,1) における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,1);8)
- **B手**（値1のトークンを除去、通常値は z+1=9）: 子 = H(R−1;(x);9)（単一トークン）
- **C手**（z を 8→7 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,1);7)

x=1 では X=(1,1) で A手が存在せず、2本の除去手は同一の子 (1);9 に帰着する（B手とC手のみ）。

子の値はそれぞれ既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K0832 の単一トークン z=9 公式、C子は K0977 の z=7・y=1 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** 本証明で使う既証明の公式:

- 単一トークン v(x,9,r)（K0832）: x≤8 は z≥x+1 枠、x=9 は z=x 枠、x≥10 は 1≤z≤x−1 枠（m=qod(9)=9, L−1=x+9）。特に x≥10 では r≤9 の奇偶で {2,0}、9<r<x+9 で (r+9) mod 2、r≥x+9 で x mod 2。
- z=7・y=1（K0977）: x≥8,x≠9 の値域 T₇={1,3,5,7,9}（x=9はO[1,17]）、P₇(x) は x 奇数で {8}∪O[11,x+8]、x 偶数で {8}∪O[11,x+9]∪I[x+10,∞)。C子の値は 1⊕h₇(x,r) で h₇∈{0,1,2} に対し {1,0,3} に写る。

**Step 3（署名帯表）.** V₁..V₁₁ は個別に、x≥12 は奇偶2行の定常形に落ちる（x=11 は値は奇数定常行と同一だが署名が一部異なるため個別行）。全 x≥1 で各行が R≥1 を矛盾なく被覆する。r=R−1 と書くと各帯は cand(x−1,r), v_single(x,9,r), 1⊕h₇(x,r) の3値の代入で確定する（後述の機械監査 V3 が x≤2000・2,053,000点で照合）。

帯の現れ方の根拠（定常行の導出、x≥12 偶数行の全帯。r=R−1）:

- 奇数R∈{1,3,5,7}: r 偶数≤6 は T_A∪P_A 外で A=0、B子も r≤9 偶で0、C=1⊕h₇=1（r∉T₇∪P₇）。V={0,1}、値2。
- 偶数R∈{2,4,6,8}: r 奇数≤7 は T_A={1,3,5,7,11}⊂で A=2、B子 r 奇≤9 で2、C=1⊕2=3（r∈T₇(x)）。V={2,3}、値0。
- R=9: A=0（8∉T_A∪P_A(x−1奇)）、B=0（r=8≤9偶）、C=0（r=8∈P₇(x)）。V={0}、値1。
- R=10: A=1（r=9∈P_A(x−1)={9}∪…）、B=2（r=9 奇≤9）、C=1⊕2=3（r=9∈T₇(x)）。V={1,2,3}、値0。
- R=11: A=0（r=10∉T_A∪P_A）、B=1（中間帯 (10+9) mod 2）、C=1（r=10∉T₇∪P₇）。V={0,1}、値2。
- R=12: A=2（r=11∈T_A={1,3,5,7,11}）、B=0（(11+9) mod 2）、C=0（r=11∈O[11,x+9]⊆P₇(x)）。V={0,2}、値1。
- 奇数R∈O[13,x+9]（r 偶数∈E[12,x+8]）: A=1（r∈E[12,x+8]=P_A(x−1) の偶数帯）、B=1（中間帯 (r+9)mod 2、r 偶）、C=1（r∉T₇∪P₇）。V={1}、値0。
- 偶数R∈E[14,x+8]（r 奇数∈O[13,x+7]）: A=0（r 奇数∉T_A・P_A の偶数帯外）、B=0（中間帯 r 奇）、C=0（r∈O[13,x+7]⊆O[11,x+9]=P₇(x)）。V={0}、値1。
- R≥x+10（r≥x+9）: A=0（子スライス x−1（奇数）の P は偶数帯 E[12,x+8] に限り有限、r≥x+9 で外）、B=x mod 2=0（r≥x+9=x+z でtail）、C=0（r=x+9 は O[11,x+9] 内、r≥x+10 は I[x+10,∞)⊆P₇(x)）。V={0}、値1。

この導出は x≥12 の全偶数について一様に成り立つ（使っているのは子公式の帯境界が x の1次式であることのみ）。x≥13 奇数行も同様で、A子スライス x−1 が偶数になると P_A={9}∪E[12,x+7]∪I[x+9,∞)（無限偶数帯つき）となり、末帯 R≥x+10 の V={1}（A=1, B=1, C=1）で値0に反転する。x=1..11 の個別行は同じ代入をそのまま実行したものである。

**Step 4（mex評価と Theorem T）.** K0832 の Theorem T により、奇数Rの親では値は mex{0,1}=2, mex{0}=1, mex{1}=0, mex∅=0 に限り、偶数Rの親の値は高々1である。上表の署名に mex を施すと次の一意対応で値が決まる:

| 署名 | {0,1} | {2,3} | {0,3} | {0,2} | {1} | {0} | {1,3} | {1,2} | {0,2,3} | {1,2,3} |
|---|---|---|---|---|---|---|---|---|---|---|
| 値 | 2 | 0 | 1 | 1 | 0 | 1 | 0 | 0 | 1 | 0 |

この規則を Step 3 の帯表に機械適用すると主定理の T₈⁽¹⁾/P₈⁽¹⁾ が正確に再構成される（例: x≥12偶 の E[14,x+8]:0 → 値1 が P の偶数帯 {9}∪E[12,x+8] を与え、R≥x+10:{0} → 値1 が P の I[x+10,∞) を与え、x≥13奇 の R≥x+10:{1} → 値0 が P の有限性と tail の (x+1)mod 2=0 を与え、R=11:{0,1} → 値2 が T の第5点 11 を与える）。

**Step 5（tail整合）.** 定常行の末帯で V は偶奇2値に退化し、R≥x+10 で H=(x+1) mod 2 となる。これは K0832 の一般tail定理の 2トークン・z=8 場合（R≥S+|X|+z−1=x+10、H=S mod 2=x+1 mod 2）と独立に一致する。 □

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は z=6（K0877）の {1,3,5,9}、z=7（K0977）の {1,3,5,7,9} に対し z=8 では **{1,3,5,7,11}**。ラダー {1,3,…,qod(min(x+1,z))}={1,3,5,7}（qod(8)=7）に第5点が加わる形だが、その位置は z=6→9, z=7→9, z=8→11 と単純な1次則に乗らない。2族予想（ラダー・家族B・家族A）での特徴づけは今後の課題。
- 値1位置の基本構造は z=6 の {7}∪E[10,..]、z=7 の {8}∪O[11,..] に対し z=8 では **{9}∪E[12,..]** で、基底点 z+1・帯開始 z+4・偶奇が z 毎に反転する。tail開始はいずれも **x+z+2**（R≥x+10）で K0832 一般tailと一致。
- x=10 の例外 T₁₀={1,3,5,7}∪O[11,19] の機構: B子 v_single(10,9,·) の中間帯 9<r<19 が r 偶で1を供給し、C子の P₇(10) は r 偶数（≥10）では不在のため C=1 が揃い、r∈E[10,18] で A=0・B=1・C=1 の V={0,1} が続く。r=18 で B の中間帯が尽きて値が0/1に落ちる。z=7 の x=9 例外（A子の無限P帯起因）とは発生機構が違い、**B子中間帯×C子不在**で起きる初の例。
- x=11 では署名が R∈E[14,20] で {0} から {0,2} に変わるが値は不変（A子がスライス x−1=10 の例外T帯 O[11,19] 内で 2 を供給）。例外が署名に1スライス写像するが値に影響しないことを示す。
- x=7 は T₈(7)={1,3,5,7,9} と z==x−1 枠（高さのみ縮約 v_single(8,8,·) の R奇≤15→2）そのもので、x=8 は P=I[9,∞)（冪の無限平坦化）、x=9 は A子スライス x−1=8 の無限値1帯で R≥11 が全て0に沈み T の第5点が生じない初の x。

## 適用範囲と限界

- 本定理は **z=8・y=1 の境界切片のみ**。z=8 の y≥2 は未証明。z≥9・y≥1 の全Grundy閉形式も未解決。
- 有限監査（V1..V9）は検証手段であり、定理の主張は上記 Step 1..5 の帰納構成による。監査は帯表の転写ミス・実装バグの検出を目的とする。
- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
