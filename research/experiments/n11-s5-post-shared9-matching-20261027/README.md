# 11×11：共有9石WIN証明を反映した14根の再最適化

2026-10-27。標準q=4・完全指摘・通常プレイ。**11×11空盤はUNKNOWN**。

前回の5石候補 00000000000000821080000000000020 の条件付き14根計画では、全合法7→8辺548本のうち独立終局証明で32本を確保し、516本が未証明だった。ただしこれは固定した計画の値であり、最小性は未確認だった。

この実験は5個の9石WIN証明書（全85個の10石子を独立3×3・4×4整数幾何で終局再計算）から導いた8石WIN45類を、以前の証明限定8石WIN集合と合併する。凍結した未完探索のWINラベルを証明には使わない。既知8石LOSSと矛盾する場合は停止する。

未被覆6石子27類、合法7石候補853類、既知LOSSで除外される67類、残り786類を再列挙。各7石候補の費用を「未証明8石子数」とし、2個の6石子を同時に扱える組343種類と単独候補27種類について、28頂点の最小重み完全対応をNetworkXで解く。

## 再現

    python3 -m pip install 'networkx==3.4.2'
    python3 research/experiments/n11-s5-post-shared9-matching-20261027/verify.py --negative

verify.py は先に共有9石証明書の終局再計算と改変拒否を実施し、audit.js が既存証明限定集合、全候補費用、固定14根の516辺、WIN/LOSS衝突を監査する。最小重み完全対応で得られた最適値・14根の局面キー・固定計画との差分は標準出力のJSONに記録する。

この最小値は「既知WIN/LOSS証明集合・7石14根・各根の全合法8石子をWINとして示す方式」に限る。7石候補自体のWINや5石局面のWIN、二石root、空盤の勝敗を証明するものではない。**空盤UNKNOWN**。
