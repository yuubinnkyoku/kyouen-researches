# 一辺細分星：負値臨界次数の漸近主項を確定（2026-11-05）

## 結論（数学的全称証明）

整数 `r=q-3≥2` に対して、奇数 `k≥3` のうち
`F_{k,r}(y)=r-y-(1+1/(r+1)-y)y^k` がある実数 `y` で負になる最小値を `κ₋(r)` とする（既存の一般臨界次数の定義）。

**定理：**
```
lim_{r→∞} κ₋(r) / (r log r) = 2.
```
したがって既存の `Θ(r log r)` の上下界に残っていた係数 `2` 対 `4` の隔たりを、漸近的に解消する。

## 証明

`s=r+1`, `a=1+1/s` と置く。既存の下界
```
κ₋(r) > log(s(r-a))/log(a)
```
より `liminf κ₋(r)/(r log r)≥2`。

上界は `r>e^4` で `L=log r`, `δ=L^{-1/2}`,
```
y_r = 1+(1-δ)/s = a-δ/s
```
を採用する。すると `1<y_r<a` かつ
```
F_{k,r}(y_r) = r-y_r-(δ/s)y_r^k < r-(δ/s)y_r^k.
```
従って
```
k > log(sr/δ)/log(y_r)
```
を満たす任意の奇数 `k≥3` では `F_{k,r}(y_r)<0`。
この右辺より厳密に大きい最小の奇数を `k_r` とすれば
```
κ₋(r) ≤ k_r ≤ log(sr/δ)/log(y_r)+2
```
（十分大きな `r` では右辺の閾値は3以上）。

`s/r→1`, `δ→0` なので
```
log(sr/δ) = 2 log r + (1/2)log log r + o(1),
log(y_r) = (1-δ)/s + O(s^{-2}),
r log(y_r) → 1.
```
従って `limsup κ₋(r)/(r log r)≤2`。下界と合わせて極限は2。

## 証拠境界

- 無限個の整数 `r` に対する解析的な漸近定理。数値実験からの外挿ではない。
- `κ₋` は**負値出現**の閾値。接触二重根の不存在は未証明なので、実根出現の閾値と同一とは主張しない。
- 有限の各 `q` における正確な切替次数や、次の漸近補正項は未決定。
