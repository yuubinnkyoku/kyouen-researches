# プラトーの全称化: 生存者 S(C,r) = S(C,C) = P(C) の全称証明（K0926）

対象: K0859 定理Dの数え上げ再帰（一様盤・零リセット・閉形式双対run (C,r)）。
実験日: 2026-11-17。検証器: `verify_plateau_universality.py`（stdlibのみ・決定的・`--no-cache`で全再計算）。監査: `output/plateau_universality_audit.json`（sha256 `ef83446fd64ad65c4cfb307f13dae8e6b8c0e641872ffb89a13990134b0c5221`・4,748B・pure ASCII・二重実行でbyte同一）。

## 要約

K0919実験E6の有限観察「プラトー S(C,r) は r >= C で一定（C <= 24機械）」を全称証明する。

**補題CAS（零石カスケード・全称・証明つき）** 1 <= C <= r-1 の run (C,r) は次のとおり進む:

- フェーズ1: k=r, s=0, ell=C, q=0, t=C。位置 (0+i) mod r (i < C)、すなわち P_0..P_{C-1} が1個ずつ受け取り、li = C により敗者は P_C。
- フェーズ j = 2..r-C: 手前の状態は active = [0..C-1] ∪ [C+j-1..r-1]（長さ r-j+1）、counts は P_0..P_{C-1} が1、他0、s=C、ell=0、turn = C mod (r-j+1) = C（C < r-j+1 が j <= r-C で成立）。よって li = C、active[C] = P_{C+j-1} が敗者（石を一度も受け取っていない）。カスケードは P_{C+1}, ..., P_{r-1} を順に除去する。
- 結果: フェーズ r-C の後に正準状態 K_C = (active=[0..C-1], counts全1, turn = C mod C = 0) に到達する。C=1 の場合は active=[0] となり生存者 P_0 で即終端（フェーズ数 r-1）。

**定理E6U（プラトー全称化・全称・証明つき）** すべての C >= 1, r >= C に対して S(C,r) = S(C,C) = P(C)。

証明（合流カップリング）: C <= r-1 とする。run A = (C,r) は補題CASによりフェーズ r-C で正準状態 K_C に到達し、run B = (C,r+1) は同じくフェーズ r-C+1 で K_C に到達する（Bのカスケードは P_{C+1}..P_{r} を除去する。各カスケードフェーズ j <= r+1-C で turn = C mod (r+2-j) = C が成立）。以降の展開は状態 (active, counts, turn) のみで決定論的に決まり、両者は同一の K_C から同一に進む。よって S(C,r) = S(C,r+1)。C <= r-1 は r >= C+1 と同値なので、r に関する帰納（出発点 S(C,C)）によりすべての r >= C で S(C,r) = S(C,C)。∎

## 系

1. **P(C) は r 非依存の普遍関数として正当化される**: K0919で導入した P(C) := S(C,C) は単なる対角線上の値ではなく、任意の r >= C の生存者と一致する。C=1 のとき P(1) = 0（すべての r >= 1）。
2. **P(C) の新しい特徴づけ**: C >= 2 に対し P(C) は正準状態 K_C（C人の全員1石・手番0）からの生存者に等しい。
3. **有界witness窓の書き換え**: K0925の有界witness観察（wit_max_sv <= r-1, r <= 32）により、窓 [1, r-1] の生存者列はちょうど (P(1), ..., P(r-1)) である。よってK0925有界witness予想「各真約数 d of Q(r) に対し S(C,r) != S(C+d,r) となる C が [1, r-1] 内に存在」は、E6Uのもとで **「Q(r) の各真約数 d に対し C in [1, r-1] で S(C+d, r) != P(C) となるものが存在」** と同値に書き直せる。この窓形式を r=2..24 の全真約数について機械確認した（WITCONN・欠落0）。Witness の値そのものは d mod r 単独では決まらない（d=Q/m 型の h*=1 集中はK0925どおりだが、一般の d に対する単純閉形式は確認できず、本実験では主張しない）。
