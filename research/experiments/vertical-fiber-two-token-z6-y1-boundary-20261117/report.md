# 2トークン残余ゲーム z=6・境界 y=1 の全Grundy分類

- 日付: 2026-11-17
- 対象: 抽象残余ゲーム \(H(R;(x,y);z)\)、\(x\ge y\ge1\)、固定 \(z=6\)、境界 \(y=1\)
- 状態: **全称定理**。全称性は \(R\) に関する強帰納法と、全 \(x\) を覆うA/B/C選択肢署名表による。
- 位置づけ: K0873で閉じた \(z=5\) 全スライスから一段進め、\(z=6\) の \(y=1\) 切片を全 \(x,R\) で決定する。\(y\ge2\) は主張しない。

## 主定理

\[
G_x(R):=H(R;(x,1);6)
\]
と置く。偶数・奇数区間を
\[
E[a,b]=\{R\in\mathbb Z:a\le R\le b,\ R\equiv0\pmod2\},
\quad
O[a,b]=\{R\in\mathbb Z:a\le R\le b,\ R\equiv1\pmod2\}
\]
と書き、\(I[a,\infty)=\{R\in\mathbb Z:R\ge a\}\) とする。空区間は空集合である。

値2位置 \(T_6^{(1)}(x)\) は
\[
\boxed{
T_6^{(1)}(x)=
\begin{cases}
\{1\},&x=1,\\
\{1,3\},&x\in\{2,3\},\\
\{1,3,5\},&x=4,\\
\{1,3,5,7\},&x=5,\\
\{1,3,5\},&x\in\{6,7\},\\
\{1,3,5\}\cup O[9,15],&x=8,\\
\{1,3,5,9\},&x\ge9.
\end{cases}}
\]

値1位置 \(P_6^{(1)}(x)\) は
\[
\boxed{
P_6^{(1)}(x)=
\begin{cases}
\varnothing,&x\in\{1,3,5\},\\
I[4,\infty),&x=2,\\
I[6,\infty),&x=4,\\
I[7,\infty),&x=6,\\
\{7\},&x=7,\\
\{7\}\cup E[10,14]\cup I[16,\infty),&x=8,\\
\{7\}\cup E[10,x+7],&x\ge9\text{ odd},\\
\{7\}\cup E[10,x+6]\cup I[x+8,\infty),&x\ge10\text{ even}.
\end{cases}}
\]

**定理.** 任意の整数 \(x\ge1\)、\(R\ge0\) について
\[
\boxed{
H(R;(x,1);6)=
\begin{cases}
2,&R\in T_6^{(1)}(x),\\
1,&R\in P_6^{(1)}(x),\\
0,&\text{otherwise}.
\end{cases}}
\]
が成立する。

## 証明

### 1. A/B/C再帰

\(R=0\) は終局で値0。\(R\ge1\) では、\(x\ge2\) のとき親の選択肢値集合は
\[
V_x(R)=
\left\{
H(R-1;(x-1,1);6),\
H(R-1;(x);7),\
1\oplus H(R-1;(x,1);5)
\right\}.
\]
順にA手・B手・C手である。\(x=1\) では二つのトークンがともに1なので、A手はなく、二つのB手は同じ単一トークン子を与える。従って
\[
V_1(R)=
\left\{
H(R-1;(1);7),\
1\oplus H(R-1;(1,1);5)
\right\}.
\]

A子には \(R\) 強帰納仮説、B子にはK0832の単一トークン全称公式、C子にはK0873の \(z=5\) 全称公式の \(y=1\) 切片を使う。いずれも \(R-1\) の値なので、帰納の順序は保たれる。

### 2. mexを決める原理

K0832のTheorem Tより、全残余状態で \(H\le2\)、偶数残容量の親では \(H\le1\) である。

- 親 \(R\) が奇数なら、子の残容量 \(R-1\) は偶数。A子とB子は0または1、C子も \(1\oplus\{0,1\}\subseteq\{0,1\}\) となる。従って \(V_x(R)\subseteq\{0,1\}\)。このとき mex は \(V=01\) なら2、\(V=0\) なら1、\(V=1\) または空なら0。
- 親 \(R\) が偶数なら、親値自体が高々1。従って \(0\in V_x(R)\) なら値1、\(0\notin V_x(R)\) なら値0である。

ここで \(0,1,2,3\) の数字列は集合を表す略記であり、例えば \(023=\{0,2,3\}\) である。

### 3. 全 \(x\) を覆う選択肢署名表

単一トークンB子の式は \(x=7\) で \(z=x\)、\(x=8\) で \(z=x-1\)、\(x\ge9\) で \(1\le z\le x-1\) の場合へ切り替わる。C子のK0873境界式にも \(x=2,\ldots,7\) の例外がある。これらをまとめた \(V_x(R)\) は次の通りである。各行は \(R\ge1\) の全てを覆う。

| \(x\) | 選択肢値集合 \(V_x(R)\) |
|---:|---|
| 1 | \(R=1:01;\ R=2:23;\ R\ge3:1\) |
| 2 | \(R=1,3:01;\ R=2:23;\ R=4:03;\ R\ge5:0\) |
| 3 | \(R=1,3:01;\ R=2,4:23;\ R\ge5:1\) |
| 4 | \(R=1,3,5:01;\ R=2,4:23;\ R=6:03;\ R\ge7:0\) |
| 5 | 奇数 \(R\le7:01;\) 偶数 \(R\le6:23;\ R\ge8:1\) |
| 6 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\ R=8:023;\ R\ge9:0\) |
| 7 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\) 偶数 \(8\le R\le14:123;\) その他 \(R\ge8:1\) |
| 8 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\ R=8:123;\) 奇数 \(9\le R\le15:01;\) その他 \(R\ge9:0\) |
| 9 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\ R=8:123;\ R=9:01;\) 偶数 \(10\le R\le16:02;\) その他 \(R\ge10:1\) |
| \(x\ge10\) 偶数 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\ R=8:123;\ R=9:01;\ R=10:02;\) 奇数 \(11\le R\le x+7:1;\) 奇数 \(R\ge x+9:0;\) 偶数 \(R\ge12:0\) |
| \(x\ge11\) 奇数 | \(R=1,3,5:01;\ R=2,4,6:23;\ R=7:0;\ R=8:123;\ R=9:01;\ R=10:02;\) 奇数 \(R\ge11:1;\) 偶数 \(12\le R\le x+7:0;\) 偶数 \(R\ge x+9:1\) |

この表は、A子へ帰納式、B子へ単一トークン \(z=7\) 公式、C子へK0873の \(z=5,y=1\) 公式を代入して得る。\(x\ge10\) では \(x\) の偶奇と \(R\) の偶奇、および \(R\) と \(x+7\) の大小だけが残るため、表の最終2行が全ての \(x\) を覆う。

奇数 \(R\) の行に前節のmex規則を適用し、偶数 \(R\) の行では0の出現だけを見ると、上記の \(T_6^{(1)}\) と \(P_6^{(1)}\) が得られる。基底 \(R=0\) と合わせて \(R\) 強帰納が閉じる。∎

## 適用範囲と限界

- 証明対象は抽象残余ゲームの \(z=6,y=1\) 切片、全 \(x,R\) である。
- \(z=6,y\ge2\) と \(z\ge7\) の全Grundy分類は未解決。
- これはK0832の残余ゲームの結果であり、標準二次元共円ゲームの固定幅安定化長へ直接転送しない。
