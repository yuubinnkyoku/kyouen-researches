# 任意次元の鏡映戦略と3次元・5点禁止版の有限強解決（2026-10-16）

対象は点を一石ずつ追加する通常プレイで、相異なる q 点が共通のアフィン超平面または超球面に入ることを禁止する変種。2次元標準 q=4 と区別する。本項は全称的な鏡映定理と、3次元 q=5 の有限完全列挙を分けて記録する。

## 全称定理：任意次元で偶数辺があれば、奇数qの空盤は後手勝ち

d>=2、奇数 q>=3。有限点集合 P⊂R^d がある超平面鏡映 τ で不変で、τ の固定点が P に存在しないとする。共超平面・共超球面をそれぞれ、または両方を禁止する q 点ゲームでは、**任意の τ 対称な安全局面は P（次手番側負け）**。特に、整数直方格子のどれか一辺の点数が偶数なら空盤は後手勝ち。

**証明。** τ 対称で安全な占有集合 S に対して、先手の合法着手 p の後に τ(p) を返す。応手で初めて禁止される超平面または超球面 C があると仮定する。

C が p を含まなければ、鏡映した τ(C) は S∪{p} の中にすでに禁止 q 点を含み、p の合法性に反する。

C が p と τ(p) を両方含めば、C は鏡映で不変である。実際、超平面は二点間の鏡映面への法線方向を含むためその超平面自身が τ 不変であり、超球面は両点を通るため球心が鏡映面上にあり τ 不変になる。したがって S∩C は鏡像対のみからなり偶数個。しかし応手で初めて q 点へ達するには S∩C が q-2 個（奇数）でなければならず矛盾する。以後も後手は合法な鏡映応手を続け、必ず勝つ。□

これは既存 K0304 の平面の円・直線についての結果と K0337 の一般ブロック禁則への拡張限界を踏まえた高次元版。個々の禁止 q 点集合の対称性ではなく、幾何的な超平面・超球面全体の鏡映不変性を使用する。

## 3次元 q=5：有限全局面の厳密計算

点 p=(x,y,z) を (x²+y²+z²,x,y,z,1) へ写す。5点が共通のアフィン平面または球面に乗ることと、持ち上げた5x5整数行列式が0になることは同値。5点からの零化式の x²+y²+z² の係数が0なら平面、非零なら球面である。

3x3x3の全二石局面351件は立方体の48個の座標軸置換・座標反転によって20軌道に分かれ、**全20軌道でg=0**。従って、3x3x3空盤では先手の初手に対して**後手がどこに応じても**後手の勝ちが確定する。3x3x3の終局局面は57,296件、終局石数は4・6・7・8。

## 再現・独立検証

- exact_solver.cpp：5x5整数行列式を Bareiss の割り切り除去で判定。4石組から禁止追加点を前計算。安全局面を列挙し石数降順の mex 動的計画法で評価する。
- independent_verify.py：差分4x4整数行列式を24置換の符号付き和として判定。別の列挙・再帰 mex を使い、48対称変換で二石20軌道を独立計数。
- 二方式で禁止5点組、全安全局面、終局数、全石数別Grundy頻度、351二石g=0が一致。
- Pythonの3x3x3全状態を十進mask昇順に「mask,g」改行列としてハッシュ化した SHA-256 = 63d6f4a8931dd35925deb5bbd51d5cb23d2e22b6143aa67c5775c5400051b09c。

リポジトリルートから実行：

    g++ -O3 -std=c++17 research/experiments/highdim-q5-cubes-20261016/exact_solver.cpp -o /tmp/q5_3d
    /tmp/q5_3d 3 3 3
    python3 research/experiments/highdim-q5-cubes-20261016/independent_verify.py 3 3 3

**限界。** 3x3x3の数値は全安全局面を列挙した有限結果であり、「すべての奇数辺格子で後手勝ち」は未証明。20二石軌道の勝敗を探索に頼らない短い戦略で説明する問題も未解決。超平面・超球面混合の一般高次元禁止組数の公式もこの結果からは従わない。


## C. 対称性で圧縮した独立検査可能な勝敗証明書

3x3x3の全351個の二石局面を立方体対称性で20軌道にまとめ、その全てがPであることを示す**839局面・1130関係のAND/OR証明書**を構築した（certificate.b64）。内訳は2石20、3石101、4石69、5石371、6石278局面。Pラベル367件、Nラベル472件。

証明書の各レコードはlittle endian 4-byte符号なし整数で、値を (canonical_bitmask << 1) | label とする。label=0はP、1はN。盤上の点は itertools.product(range(3),repeat=3) の順番で0..26を付番。certificate.b64はこれを昇順に並べたバイト列のbase64。

**verify_certificate.pyは全205506安全局面のGrundy数を一切計算しない。** 幾何学的な禁止5点組と48個の立方体対称変換を整数演算で再生成し、証明書の各局面の安全性・canonical性をチェックする。全P局面の全合法子が証明書内でNとラベルされ、全N局面には少なくとも1つ証明書内でPとラベルされた合法子があることを確かめる。着手ごとに石数が増えるので、この条件から後ろ向き帰納法で全ラベルが正しいと確定する。全二石軌道20件がPであることを確認すれば、空盤後手勝ちが従う。

圧縮証明書の生バイト列SHA-256:
1ae0a113582046e73c2849afda9b6e7e4b500a8b13b7d1df31ad80e0ff0e80f4。

再現：

    python3 research/experiments/highdim-q5-cubes-20261016/verify_certificate.py

本証明書は有限盤の厳密な証明であり、任意辺長の奇数辺立方格子についての全称証明ではない。
