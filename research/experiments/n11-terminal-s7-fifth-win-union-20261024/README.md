前段の `n11-terminal-s7-four-win-union-20261024` は、9石WIN 120根・8石直接WIN 74根・4個の7石WIN証明に由来する
8石WIN **1,175類**を統合していた。一方、2026-10-15に独立終局証明された
`n11-s7-fifth-terminal-20261015/fifth-s7-win-terminal.cert` の
7石WIN根 `00000000000400001000401108400000` はまだ統合されていなかった。

その証明書は全35個の合法8石子それぞれに9石WIN証人を指定している。
35個の8石WINは既存1,175類と**重複0**。証明書中の9石証人は23類。
元の独立C++・Python検証では、468個の相異なる10石WIN終局葉を再計算済み。
**今回新たに終局計算したわけではない。**
