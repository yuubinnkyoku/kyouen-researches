# 3トークン過渡帯の拡張: 予想Uのk=1..8・対角線OK表のm=9/m=10確定・偶数統一形の発見

2026-11-16。前報「3トークン過渡帯の値2位置」（K0832・`vertical-fiber-three-token-transient-band-20261116`）の直接の拡張として、残余ゲーム H(R;X;z)（κ=1）について次の3点を新たに確定した。全て有限監査による支持であり、全称性は未証明である。

## 成果1: 予想Uの k 範囲を 1..3 から 1..8 へ拡大

前報の予想U（k≥1・帯条件 x<R<S+z+2、R>z+1 内で H(R;(x,y,w);z)=2 ⟺ (j=0∧w=1: z≥2k) または (それ以外: 2(k+1−j−w)≤z≤2(k+1−j−w)+1)、y非依存）を k=4,5,6,7,8 の全グリッド（前報と同一の y≤13・w≤min(y,6)・z≤15・j≤7）で双方向照合した。計35,764ケース・不一致0。予想Uはk=1..8の全スライスで反例なし。

k=0（R=2x−1）が統一形の外の特異形（予想A/B/C）であることの構造的説明候補——k=0 では R+1=2x が最大トークンの2倍に一致し cap_{R+1} が非自明に効かない——は、k≥1 側で統一形が k=8 まで安定していることで補強された。

## 成果2: 対角線OK表の m=9 確定

対角線 2x_max=S+z・R=2x_max−1（X=(x_max,)∪rest・x_max=sum(rest)+z・rest昇順）について、m=9 のOK条件を確定した:

**m=9: H(R;X;z)=2 ⟺ rest[:7]=(1,1,1,1,1,1,1)（z 任意）。**

広域抽出グリッド tmax=4・zmax=9 の全1,650ケースで双方向照合し、族の高z陽性（z≤20・末尾トークン1..4の84ケース中44ケース帯内）でも全て値2。族外のOKは0件。抽出トークン上限は前報の m=7→4・m=8→3 の傾向から m=9 では tmax=4 を採用した。

これにより奇数族の一般予想「m≥5 奇数のOK ⟺ rest[:m−2]=(1^{m−2})（z 任意）」が m=5,7,9 の3点で支持された。m=3 の「常にOK」はこの族の外（rest[0]≥2 でもOK）であり、前報どおり例外として区別する。

## 成果3: 対角線OK表の m=10 確定と偶数統一形の発見

m=10 のOK条件を抽出グリッド tmax=4 で確定した:

- **z=1**: OK ⟺ rest[:8]=(1,1,1,1,1,1,1,1)
- **z=0**: OK ⟺ (rest[:7]=(1⁷)∧rest[7]=2) ∨ (rest[:6]=(1⁶)∧rest[6]=2∧rest[7]=2)
- **z≥2**: OK なし

z=0,1 の440ケース・z≥2 の不在165ケースで双方向照合・不一致0。

m=6・m=8 の既存OK表（前報・36,958照合済み）と m=10 の今回の抽出を並べると、**偶数 m=2r≥6 のOK条件が次の統一形に従う**ことが見えた:

- **z=1**: OK ⟺ rest[:2r−2]=(1^{2r−2})
- **z=0**: OK ⟺ (rest[:2r−3]=(1^{2r−3})∧rest[2r−3]=2) ∨ (rest[:2r−4]=(1^{2r−4})∧rest[2r−4]=2∧rest[2r−3]=2)。ただし m=8 のみ、さらに rest=(1⁷) もOK（特例）。
- **z≥2**: OK なし

この統一形をそのまま実装し、m=6（2,520ケース・tmax=6・zmax=9）・m=8（252ケース・tmax=3・zmax=6）・m=10（440ケース・tmax=4・z=0,1）で H と直接双方向照合した。全て不一致0。m=6・m=8 では前報のOK表と同じグリッドで統一形が H と一致するため、統一形が前報OK表と同値であることも従う。

z=0 層の2項は「1が連なる接頭辞の直後に2がある（接頭辞長 2r−3）」または「接頭辞長 2r−4 で2が2個並ぶ」のいずれかを要求し、末尾側（rest[2r−2] 以降）は値を問わない。z=0 の全1rest=(1^{2r−1}) は m=6・m=10 ではOKでなく、m=8 のみOKである。この m=8 特例の説明は未解決の観察として残す。m=4 のOK条件は統一形の外の例外形（前報どおり・rest[:2]≠(1,1) がそのままOKになる特異なz=0層）であり、統一形は m≥6 を対象とする。
