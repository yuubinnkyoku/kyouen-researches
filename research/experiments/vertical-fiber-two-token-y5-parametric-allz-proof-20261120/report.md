## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数。q_odd(k) は k を奇数に切り下げた値（k 奇なら k、
k 偶なら k-1）。q_odd(x+5) はマージ行のラダー上端である（S=x+5 の偶奇は x と
逆なので、実際には x 奇なら x+5・x 偶なら x+4）。

## 定理（値2集合 T_z(x)、値1集合 P_z(x)）

H(R;(x,5);z)=2 ⟺ R∈T_z(x)、=1 ⟺ R∈P_z(x)、それ以外で 0（R=0 は常に 0）。

### 値2位置 T_z(x)（常に奇数位置＋高々1つの孤立pin／掃引帯）

z 奇数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-6 | O[1, q_odd(x+5)]（単一トークン値そのもの・マージ行） |
| x=z-5 | O[1, z+4]（対角行 S=z の連続上端） |
| x∈{z-4, z-2, z-1, z, z+2, z+3, z+4} | O[1, z] |
| x=z-3 | O[1, z] ∪ {z+6}（内側前倒し孤立pin） |
| x=z+1 | O[1, z] ∪ {z+8}（前倒し孤立pin・位置式 x=z+y-4・R=2y+z-2） |
| x=z+5 | O[1, z] ∪ {z+10}（外側前倒しpin・R は定常pin 2y+z と同じ位置） |
| x=z+6 | O[1, z] ∪ O[z+10, 2z+11]（掃引行） |
| x>=z+7 | O[1, z] ∪ {z+10}（定常pin 2y+z） |

z 偶数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-6 | O[1, q_odd(x+5)] |
| x=z-5 | O[1, z+5]（対角行 S=z、連続上端） |
| x∈{z-4, z-3, z-2, z, z+1, z+2, z+4, z+5} | O[1, z-1] |
| x=z-1 | O[1, z-1] ∪ {z+7}（前倒し孤立pin・R=2y+z-3・位置式 x=z+y-6） |
| x=z+3 | O[1, z-1] ∪ {z+9}（前倒し孤立pin・R=2y+z-1・x=z+y-2） |
| x=z+6 | O[1, z-1] ∪ O[z+11, 2z+11]（掃引行） |
| x>=z+7 | O[1, z-1] ∪ {z+11}（定常pin 2y+z+1） |

z=0..5 でも例外行は発生しない（判定不能クラスは x>=5 制約で空になり、同じ
テンプレートがそのまま適用される。例: z=0 では対角行 x=z-5=-5・前倒しpin行
x=z-1, z+3 は範囲外、x=5 行（d=5）は T=∅・P=基底点 {1,3,5,7,9}、掃引行 x=6 の帯は O[11,11]={11}、定常行 x>=7 の
pin は {11}。census の z<=4 行と一致）。
奇数 z の掃引帯 O[z+10, 2z+11] は孤立 pin {z+10}（=定常 pin 2y+z）と
帯本体 O[z+12, 2z+11]（下端 2y+z+2）の和に等しい（K1112 の
「奇数zの掃引帯下端 2y+z+2」の分解の y=5 版）。

基底5点とは {z+1, z+3, z+5, z+7, z+9}=[z+1, z+2y-1] のことである。値1基底点は

全称表で連続 5 例）。中間帯の偶奇は常に z に追従する（O_z）。
偶数 z の掃引行（x=z+6）は奇数 z と異なり値1の帯・tail を持つ（y=3・y=4 の
偶 z 掃引行と同じ、掃引行 P の z 偶奇依存は y=3..5 で共通）。
T∩P=∅ は全点で成立（検証器が全照合点で assert）。

### tail

全 z>=0・x>=5 で R >= x+z+6 のとき H(R;(x,5);z) = (x+5) mod 2。
すなわち偶数 x 行は tail で 1、奇数 x 行は tail で 0（y=5 は奇数 y なので
値1無限帯は偶数 x 行に戻る。y=2・y=4 と逆・y=1・y=3 と同じ。tail 値式
(x+y) mod 2 が y の偶数性で切り替わるため）。tail 開始 x+z+6 = x+z+y+1 は
y=2..5 の 4 族連続で族式が全称確定した（K1112 の予想を延長）。

## マージ系（対角線下・y=5 の全称昇格）

x<=z-6（すなわち S=x+5 <= z-1 < z）の全行で

  H(R;(x,5);z) = single_token(x+5, z, R)  （K0832 出版単一トークン閉形式）

が全 R>=0 で成り立つ。明示的には値2位置は O[1, q_odd(x+5)]、値1位置は
x 偶 のみ I[x+6, ∞)、行全体が z 非依存になる。K1101 が y∈{1,2} で全称証明し
y>=3 を有限センサス観察にとどめていたマージ命題は、y=3（K1104 の系）・
y=4（K1112 の系）に続き y=5 も本定理の閉形式から直ちに従う
（single_token の z>=S+1 場合とマージ行の T/P が一致する。S=x+5 の偶奇が
x と逆なので、S 奇（x 偶）の行が値1無限帯 I[q_odd(S)+1,∞) = I[x+6,∞) を
持ち、S 偶（x 奇）の行は値1なし。マージ命題は y=1..5 で全称確定）。
監査機械は全グリッド・probe 点でこの系を直接照合した
（総 1,655,267 点・不一致 0）。

**K1112 レポートのマージ行 P 表の erratum**: 本研究の y=5 マージ行導出の
過程で、出版済み y=4 レポート（K1112 experiment report.md）のマージ行 P の
偶奇ラベル（z 奇表・z 偶表の2箇所ずつ）と本文説の割り当てが反転している
ことが生エンジンの直接照合（z=20・26 の x 奇偶両方の行）で確定した。
正しくは S=x+4 の偶奇は x と同じなので、S 奇（x 奇）の行が値1無限帯
I[x+5, ∞) を持ち、S 偶（x 偶）の行が値1なし（tail「奇数 x 行は tail で 1」
との整合でもある）。K1112 の検証器・閉形式コード（cand4）は最初から正しく、
本 y=5 検証器の C1b（48,411 点）が y=4 閉形式の逐語転写を raw 再照合して
bad 0 を与えている。上記の反転は報告レポートの表記のみの誤りであり、
別コミットで修正した（定理の主張・証明・監査には影響しない）。

## 選択肢分解と x=5 での合流

R>=1 のとき

- A = H(R-1; (x-1,5); z)（x>=6；x=5 では 2 つの減少手が同一多重集合
  (4,5)≡(5,4) 子に合流し A≡B = H(R-1;(4,5);z) = cand4(z,5,R-1)、
  すなわち K1112 の z 行 x=5 閉形式。H は多重集合にしか依存しない）
- B = H(R-1; (x,4); z) = cand4(z, x, R-1)（K1112 全称閉形式）
- C = 1 ⊕ H(R-1; (x,5); z-1)（z>=1）

であり H(R;(x,5);z)=mex{A,B,C}（z=0 では C なし）。

## 証明構成（K1023/K1099/K1104/K1112 と同型の機械化）

1. **選択肢分解の健全性**: A/B/C の列挙が素再帰の選択肢値集合と一致することを
   raw エンジン（順序保持・降順正準化の二重再帰）で錨止めする（C3・1,568点）。
   カーネルの B（y=4 子）・単一トークン閉形式・x=5 の合流子 (4,5)≡(5,4) も
   raw 照合で錨止め（C1b・48,411点）。
2. **恒等式**: cand5 は上表そのものであり、恒等式
   cand5(z,x,R) = mex{A,B,C}（子は閉形式で評価、C は cand5(z-1,・,・) の
   z 外帰納）が R に関する帰納の本体。z=0..48・x=5..56・R<=x+z+40 の全点
   240,786（C2）、深部 tail z∈{60,72,84,96,108,120,240,400}（C2b・10,104）、
   z=0..120・x=5..120・R<=x+z+16 の全点 1,943,986（C12）で直接照合する。
   マージ系・tail 系も全グリッド点で照合。
3. **型機械**: 型 = (x==5 ビット, z==0 ビット, z%2, x%2, R%2, 6差分族

   実現型 27,182 個を完全列挙し、各型で（値, 子値列）効果ベクトルが型内で

## 値の構造（y=2..5 の横断観察・一般称主張ではない）

- **値1基底点 y 点仮説の y=5 確定**: 基底点は y 個 {z+1, z+3, ..., z+2y-1}
  が y=1..5 の全称表で確定（y=5 は本項で 5 点 {z+1,..,z+9}）。y>=6 は予想。
- **tail 開始式 x+z+y+1 の y=2..5 確定**: y=2 の x+z+3・y=3 の x+z+4・
  y=4 の x+z+5・y=5 の x+z+6 が族式 x+z+y+1 で統一（4族連続の全称確定）。
  tail 値 (x+y) mod 2 も 4 族連続（y 偶で値1無限帯が奇数 x 行、y 奇で
  偶数 x 行）。
- **マージ行の境界**: マージ行は S=x+y <= z-1、すなわち x<=z-y-1
  （y=4: x<=z-5・y=5: x<=z-6）で、対角行 x=z-y が最初の非マージ行。
  マージ命題（K1101）は y=1..5 で全称確定。マージ行の値1無限帯は
  S 奇の行（x+y 奇）に出る。
- **掃引行 x=z+y+1 と帯 O[2y+z, 2z+2y+1]（奇z）/O[2y+z+1, 2z+2y+1]（偶z）**:
  y=2..5 共通の族式。y=5 では帯下端の偶奇依存が消える（奇z でも
  2y+z に孤立 pin が乗る形で帯本体は 2y+z+2 から。y=4 と同様）。
- **中間帯（値1）**: 本項では O_z[2y+z+2, x+z+y] = O_z[z+12, x+z+5]。
  族式は y=3,4,5 の 3 族連続。
- **定常 pin と前倒し pin**: 定常 pin は奇数 z 2y+z・偶数 z 2y+z+1 で
  y=2..5 共通。奇数 z の前倒し pin は y=3,4,5 で位置式 x=z+y-4・R=2y+z-2
  が 3 族連続（y=5 ではこれに内側 {z+6} at x=z+y-8・外側 {2y+z} at x=z+y の
