# 一様盤REMO計数再帰の最小周期（r=2..16・両列・割り切り補題DIV）

実験: `remo-uniform-minimal-period-20261117`（2026-11-17）
対応項目: K0921

## 命題

K0859定理Dの計数再帰 E(C,r)（Δ=0一様盤・終端サイズC・r人・
K0919定理PERの対象と同一の再帰）について:

**定理MP（機械・r=2..16・完全走査）**: 敗者全列（elimination列）と
生存者列の**それぞれ**のC方向最小周期は、r=2..16の全rで
**ちょうど Q(r) = lcm(1..r)** である。すなわち Q(r) のすべての
真約数 d についてある C ∈ [1, Q(r)] が存在し E(C+d,r) ≠ E(C,r)
（該当列で）が成立する。r=10..16 が本項の新規範囲、r=2..9 は
K0919 E3 の独立再現（M7・交差検証）。

**補題DIV（全称・証明つき）**: E(·,r) の周期の全体 Per(r) は
ある最小周期 m(r) の正の倍数全体に一致し、m(r) | Q(r)。
とくに「必要性方向（周期は Q(r) の倍数に限る）」は「最小性
m(r) = Q(r)」と同値であり、**真約数棄却だけで全rの両方向が
決定できる**。

**証明（補題DIV）**: T1, T2 ∈ Per(r) とすると g = gcd(T1,T2)
も周期である。実は Bezout 表示 g = a·T1 − b·T2（a,b ≥ 0）から、
任意の C ≥ 1 に対し E(C + a·T1) = E(C)（T1周期をa回、添字は
C から上向きなので全て ≥ 1）かつ E(C + g) = E(C + a·T1 − b·T2)
= E(C + a·T1 − (b−1)·T2) = … = E(C + a·T1)（T2周期をb回、
添字は C+g ≥ 1 から上向きなので全て ≥ 1）。よって E(C+g) = E(C)。
Per(r) は Q(r) ∈ Per(r) ゆえ空でなく最小元 m(r) を持つ。任意の
T ∈ Per(r) に対し gcd(T, m(r)) ∈ Per(r) は m(r) の約数で、
最小性から gcd(T, m(r)) = m(r)、ゆえ m(r) | T。∎

**witness C=1 の観察（有限・r=2..16）**: elimination列に限ると、
Q(r) の**すべての**真約数 d が C=1 で棄却される
（E(1+d, r) ≠ E(1, r)）。部分機構: E(1,r) の敗者列は
(1,2,…,r−1)・生存者0 であり、C = 1+d の第1敗者はオフセット
(1+d) mod r に位置するから、r ∤ d なら第1フェーズで既に異なる。
r | d である真約数（深い場合）も r ≤ 16 では全て C=1 で棄却
される。全rでのこの観察の全称性は OPEN（証明課題）。

**P(C) = 1 ⟺ C 素数 予想（有限支持 C ≤ 300・予想としてのみ提案）**:
P(C) = S(C,C)（生存者のプラトー列・K0919 E6）は C ≤ 300 で
「C が素数なら P(C) = 1・C が合成数なら P(C) ≠ 1」が完全に成立
（素数 62 個すべて P=1・合成数 237 個すべて P≠1・C=1 は P=0）。
機構は未解明であり、閉形式・全称性は主張しない。
P(C) = C−1 となる C のリスト（61個・C ≤ 300）も観察として監査JSON
に記録する（構造規則は未同定）。

## 機械チェック（7/7合格・決定的・stdlibのみ・新規スイープなし）

- **M1**: Q(r) ピン照合（r=10..16）と Q(r) | r!。
- **M2**: verbatim再帰 == 閉形式双子（r=10..16・C ∈ [1,200] 全数
  ＋ stride-997 層化61点 ＋ [Q/5, 2Q−1] 大型アンカー8点・
  敗者全列と生存者で照合・1,811ペア・不一致0）。
- **M3**: 定理PERアンカー E(C+Q(r),r) = E(C,r)（r=10..16・
  C ∈ [1,Q(r)] 全数・1,859,760ペア・不一致0。周期性自体は
  K0919の全称証明済み・本項は機械アンカー）。
- **M4**: 均一オフセット帰納データ検査（T=Q(r)・M2サンプル1,811点・
  フェーズごとの k/t/li/敗者/手番同一・一様オフセット D_h・
  閉形式 X_1=T, X_h=T/(k_h+1)・受領シフト X_h/k_h・敗者はちょうど
  q_h 個受領・違反0）。
- **M5**: 最小性（r=10..16・Q(r) の全真約数1,049個が敗者全列と
  生存者列の両方で棄却・witness走査は [1, Q(r)] の完全窓。
  走査窓の完全性: g_d(C) := [E(C+d,r) ≠ E(C,r)] は定理PERにより
  Q(r) 周期なので、棄却witnessは [1, Q(r)] に必ず現れる）。
- **M6**: P(C) 列 C=1..40 が K0919 E6 ピンと完全一致し C ≤ 300
  に拡張（有限観察）。「P(C)=1 ⟺ C 素数」観察と P(C)=C−1
  リストを記録。閉形式は主張しない。
- **M7**: K0919 E3 の独立再現（r=2..9・全真約数132個が両列で
  棄却・出版結果と完全一致・witness記録付き）。

witness走査の窓は K0919 E3（C ∈ [1, Q−d]）を [1, Q] に拡張して
いる（完全性の根拠は上記 g_d の Q 周期性）。

## 限界

- 本項は **Δ=0一様盤（定理D域）の主張**であり、非一様盤には
  一切言及しない（K0859の合成反例のとおり非一様盤では r|Δでも
  生存者が戦略依存になり得る）。
- 最小性は r ≤ 16 の機械確定。r ≥ 17 では Q(r) が周期である
  こと自体は全称証明済み（K0919）だが最小性・必要性方向は OPEN。
  r=17 は Q(17) = 12,252,240（2Q 窓の約2,450万評価・
  約20分以上と推定・メモリも1GiB環境では窓を分割する必要がある）。
- 補題DIVは全称だが「m(r) = Q(r)（全r）」は含まない
  （r ≤ 16 のみ機械確定）。
- P(C) の素数観察は有限観察（C ≤ 300）であり予想としてのみ
  提案。証明なし。
- witness C=1 の観察も有限観察（r ≤ 16）であり全称主張しない。
- 11×11空盤・クラスフロンティアは本項と無関係でUNKNOWNのまま。
