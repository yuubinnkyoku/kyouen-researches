## 数学的根拠と有限計算の境界

K0567の5進差分定理により、任意の (tge1) に対し (P_t=4cdot5^t)、(D_t=max(5,t)) と置くと、(dge D_t) で

[
5^tmid E_{d,5}quadLongleftrightarrowquad dmod P_tin R_t
]

が成立する。(R_t) は常に4個の剰余類であり、(R_1={1,2,3,4})。各剰余は (r+jP_t (j=0,dots,4)) のうち**ただ1個**に持ち上がる。この無界の主張は既存の数学的証明であり、今回の計算からの外挿ではない。

K0561の厳密指数公式 (120E_{d,5}=sum_a c_a a^d) に対し、各段階の5候補を法 (5^{t+1}) で判定した。分母120をそのまま扱う合成法の剰余計算と、分母5を除き24の逆元を掛ける5進法の剰余計算を照合した。小次元では二項反転で得る係数とStirling数漸化式による第三の整数計算とも一致した。**三方式とも同じK0561の係数に依存する**ため、幾何学的な独立再証明ではない。
