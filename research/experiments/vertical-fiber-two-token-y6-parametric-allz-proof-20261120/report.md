## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数。q_odd(k) は k を奇数に切り下げた値（k 奇なら k、
k 偶なら k-1）。d = x - z、S = x + 6 と書く。マージ行のラダー上端 q_odd(S)
は S=x+6 の偶奇が x と同じため x 奇なら x+6・x 偶なら x+5 になる
（y=5 までの奇数 y とは逆の寄り方）。

## 定理（値2集合 T_z(x)、値1集合 P_z(x)）

b3 = {z+1, z+3, z+5}、b4 = b3∪{z+7}、b5 = b4∪{z+9} とする。

### tail

全 z>=0・x>=6 で R >= x+z+7 のとき H(R;(x,6);z) = (x+6) mod 2。
すなわち奇数 x 行は tail で 1、偶数 x 行は tail で 0（y=6 は偶数 y なので
値1無限帯は奇数 x 行。y=2・y=4 と同型・y=1,3,5 と逆。tail 値式
(x+y) mod 2 が y の偶数性で切り替わるため）。tail 開始 x+z+7 = x+z+y+1 は

## 選択肢分解と x=6 での合流

R>=1 のとき

- A = H(R-1; (x-1,6); z)（x>=7；x=6 では 2 つの減少手が同一多重集合
  (5,6)≡(6,5) 子に合流し A≡B = H(R-1;(5,6);z) = cand5(z,6,R-1)、
  すなわち K1126 の z 行 x=6 閉形式。H は多重集合にしか依存しない）

## 値の構造（y=2..6 の横断観察・一般称主張ではない）

- **値1基底点 y 点仮説の y=6 確定**: 基底点は y 個 {z+1, z+3, ..., z+2y-1}
  が y=1..6 の全称表で確定（y=6 は本項で 6 点 {z+1,..,z+11}・連続 6 例）。
  y>=7 は予想。
- **tail 開始族式 x+z+y+1 の y=2..6 確定**: 5 族連続の全称確定。tail 値
  (x+y) mod 2 も 5 族連続（y 偶で値1無限帯が奇数 x 行・y 奇で偶数 x 行。
  マージ行の値1無限帯も同じ S=x+y 偶奇に従い、y=6 では S=x+6 の偶奇が x と
  同じため x 奇の行に出る）。
- **マージ行の境界 x<=z-y-1**: y=1..6 の 6 族で確定（y=6: x<=z-7）。
  対角行 x=z-y が最初の非マージ行。マージ命題（K1101）は y=1..6 で全称確定。
- **掃引行 x=z+y+1 と帯 O[2y+z, 2z+2y+1]（奇z）/O[2y+z+1, 2z+2y+1]（偶z）**:
  y=2..6 共通の族式（y=6: O[z+12, 2z+13]/O[z+13, 2z+13]）。
- **中間帯（値1）**: O_z[2y+z+2, x+z+y]（y=6: O_z[z+14, x+z+6]）。
  族式は y=3..6 の 4 族連続。
- **定常 pin 2y+z（奇z）/2y+z+1（偶z）**: y=2..6 共通（y=6: {z+12}/{z+13}）。
- **前倒し pin の格子構造（本項で新たに判明した統一）**: これまで行ごとに
  ばらばらに記録されていた前倒し pin の位置が、pin 行 x では
  (x-y)+z ≡ 2 (mod 4) が成り立ち、pin 値が格子公式
  pin = 2y + ((x-y)+z)/2 で与えられることで統一される。
  y=6 では奇z の pin 行 d∈{-2,2,6}（pin z+8, z+10, z+12）・偶z の pin 行
  d∈{-4,0,4}（pin z+7, z+9, z+11）。遡って調べると y=5 の全 pin 行
  （奇z d∈{-3,1,5}→pin z+6,z+8,z+10・偶z d∈{-1,3}→pin z+7,z+9）も
  同一の格子公式で説明できる（(x-y)+z≡2 mod 4 ・pin=2y+((x-y)+z)/2）。
  pin 行の d は z 偶奇で決まる剰余類 d ≡ y (mod 4)（奇z）・
  d ≡ y+2 (mod 4)（偶z）に乗る（y=6 は奇z d≡2・偶z d≡0、
  y=5 は奇z d≡1・偶z d≡3 の実測と一致）。y>=7 への一般式の有力候補である
  （y<=6 の全称表からの観察・一般証明は今後の課題）。
- **対角行 S=z（x=z-y）の連続上端の格子規則 r = z+y - [2(z-y)≡0 (mod 4)]**:
  y=6 の行（奇z 上端 z+6・偶z 上端 z+5）まで y=2..6 の
