# 反転平面の円インターセクション・スペクトル K_s(q) と、Steiner 3-設計の (s,d)-双対

実験ディレクトリ: `research/experiments/inversive-spectrum-20261124/`（2026-11-24）

## 0. 要旨

これまでの反転平面研究は「弧の最大サイズ `K(q)`」という **1 個の数**を扱い、
`K(q) ≤ q`（q ≥ 7、K1252）という深い上界を得た。本実験はこれを
**円との交点数 `s` の関数**へ一般化し、さらに任意の **Steiner 3-設計**へ拡張する。

```
K_s(q) = max{ |S| : |S ∩ C| ≤ s  for every circle C }        (1 ≤ s ≤ q+1)
τ_d(q) = min{ |X| : |X ∩ C| ≥ d  for every circle C }        (0 ≤ d ≤ q+1)
```

`s = 3` が従来の弧である。主結果:

1. **一般定理（Steiner 3-(v,k,1) 設計、証明）**: `λ_2 = (v−2)/(k−2)` とすると
   - `2 ≤ s ≤ k` の任意の s-弧（各ブロックと ≤ s 点）は `|S| ≤ (s−2)λ_2 + 2`、
   - `1 ≤ d ≤ k−2` の任意の d 重ブロッキング集合は `|X| ≥ d·λ_2`。
   証明はブロック交点数に関する 2 本のモーメント等式のみ。
2. **反転平面への特殊化**: `λ_2 = q+1` より

   ```
   K_s(q) ≤ (s−2)(q+1) + 2        (2 ≤ s ≤ q+1)
   τ_d(q) ≥ d(q+1)                (1 ≤ d ≤ q−1)
   K_s(q) = q²+1 − τ_{q+1−s}(q)   (双対・同値)
   ```

   `s = q+1` で `K = q²+1`、`d = q−1` で `τ = q²−1`（両方 tight）。
3. **深い定理の双対読み**: K1252 の `K_3 ≤ q` は
   `τ_{q−2} ≥ (q−2)(q+1) + 3` と同値。一般上界 `d(q+1)` が
   **`d = q−2` でのみ 3 だけ破れる**、という構造になる。
4. **新しい厳密値（SAT 2 エンジン + 独立全探索 + 独立証人検査）**:
   `K_4(4) = 9`, `K_4(5) = 10`, `K_4(7) = 13`, `K_5(5) = 16`。
   較正 `K_3(9) = 9`（既知値と一致）、`K_3(3,4,5)` も再現。
5. **部分結果**: `14 ≤ K_4(8) ≤ 15`（n=16,17,18 の UNSAT を確認）、
   `16 ≤ K_4(9) ≤ 22`。`s = q` 行: `K_7 ≥ 33`, `K_8 ≥ 45`, `K_9 ≥ 57`。
6. **既知の強い下界との接続**: Bruen–Rothschild (1985) と
   Kiss–Marcugini–Pambianco (2005) により `τ_1(q) ≥ 2q`（q ≥ 4）。
   よって `K_q(q) ≤ (q−1)²`。q=4,5 では本実験の厳密値が `(q−1)²` に一致する
   （ブロッキング集合が極小）。q ≥ 7 は未解決。

## 1. 定義・用語・基本性質

`M(q)` を位数 `q`（素数冪）の Miquelian 反転平面とする: 点 `q²+1`、円 `q+1` 点、
円の総数 `q(q²+1)`、各点対はちょうど `q+1` 円に載り、各 3 点は一意な円に載る
（3-(q²+1, q+1, 1) 設計、`λ_2 = q+1`）。

**用語**: 設計一般で「各ブロックと高々 α 点で交わる集合」は
**(α,n)-arc**（Sane–Shrikhande–Singhi 1985）と呼ばれる。射影平面では
(k,n)-arc（Ball 1996）が同値。本稿の「s-弧」はこの意味で、反転平面の
「k-arc（= k 点の弧）」という既存語とは別物である（文献ノート参照）。

- `s = 1`: `K_1 = 1`（どの 2 点も円に載る）。
- `s = 2`: `K_2 = 2`（どの 3 点も一意な円に載る）。
- `s ≥ q+1`: `K_s = q²+1`（全点集合）。
- 単調性 `K_s ≤ K_{s+1}`、双対 `K_s + τ_{q+1−s} = q²+1`。
- 既存の弧は `K_3 = K`（K1250–K1252）。

## 2. 主定理（一般形と反転平面）

**定理 2.1（Steiner 3-(v,k,1) 設計）.** 各点対が `λ_2 = (v−2)/(k−2)` ブロックに
載り、各 3 点が一意なブロックに載るとする。

(i) `2 ≤ s ≤ k` の任意の s-弧 `S` は `|S| ≤ (s−2)λ_2 + 2`。
(ii) `1 ≤ d ≤ k−2` の任意の d 重ブロッキング集合 `X` は `|X| ≥ d·λ_2`。
(iii) 双対: `K_s + τ_{k−s} = v`。とくに `τ_{k−2} = v−2`（2 点集合の補集合）。

**証明.** `S` を `n` 点の s-弧とし、`t_j` を `S` とちょうど `j` 点で交わるブロック数
とする。2 本のモーメント等式:

```
(1)  Σ_{j≥2} C(j,2) t_j = C(n,2) λ_2      （各点対は λ_2 ブロックに載る）
(2)  Σ_{j≥3} C(j,3) t_j = C(n,3)          （各 3 点は一意なブロックに載る）
```

`s`-弧なので `j ≤ s` のみ寄与。`2 ≤ j ≤ s` で

```
C(j,2) ≥ (3/(s−2)) C(j,3)
```

（`j=2` は両辺 0、`j≥3` は `C(j,2)/C(j,3) = 3/(j−2) ≥ 3/(s−2)`、`j=s` で等式）。
したがって

```
C(n,2)λ_2 = Σ C(j,2)t_j ≥ (3/(s−2)) Σ C(j,3)t_j = (3/(s−2))C(n,3)
          = C(n,2)·(n−2)/(s−2),
```

`λ_2 ≥ (n−2)/(s−2)`、すなわち `n ≤ (s−2)λ_2 + 2`。□

(ii) は `d = k−s` として (i) と双対 `τ_d = v − K_{k−d}`:
`τ_d ≥ v − [(k−d−2)λ_2 + 2] = λ_2(k−2) − (k−d−2)λ_2 = dλ_2`。□
（`v−2 = λ_2(k−2)` を使った。）

**系 2.2（反転平面）.** `λ_2 = q+1`, `k = q+1`, `v = q²+1` より

```
K_s(q) ≤ (s−2)(q+1) + 2     (2 ≤ s ≤ q+1)
τ_d(q) ≥ d(q+1)             (1 ≤ d ≤ q−1)
τ_{q−1}(q) = q²−1           （tight, 2 点集合の補集合）
```

**注意 2.3.**
- `s = 3` では `K_3 ≤ q+3`。K1252 はこれを 3 改善して `K_3 ≤ q`（q ≥ 7）。
  すなわち「深さ 3」はこの線形上界からのちょうど 3 の超過。
- `d = 1` では既知の Bruen–Rothschild 型下界 `τ_1 ≥ 2q`（q ≥ 4）の方が
  `d(q+1) = q+1` より強い。一般上界 `dλ_2` は **d が大きい領域**で有効で、
  `d = q−1` で tight、`d = q−2` で K1252 が 3 改善する、という構造。

## 3. 双対の意味: excess 関数

**定義 3.1.** `e_d(q) := τ_d(q) − d(q+1)`（`1 ≤ d ≤ q−1`）。

- `e_d ≥ 0`（定理 2.1）、`e_{q−1} = 0`。
- `e_1 ≥ q−1`（Bruen–Rothschild の `τ_1 ≥ 2q` より。q ≥ 4）。
- `e_{q−2} ≥ 3`（K1252。q ≥ 7）。
- 有限データ（下の表）: `e_2(4)=2`, `e_2(5)=4`, `e_3(5)=2`,
  `e_4(7)=5`, `e_7(9)=3`。

`e_d` は「線形設計上界からの超過」であり、`d` が小さいほど大きく
（`e_1 ~ q`）、`d = q−1` で 0 になる。深い定理は `d = q−2` の超過が
**ちょうど 3** であることを主張する。この関数の形を決めるのが新しい問題である。

### 4.1 読み方

- `K_4`: 9, 10, 13（q=4,5,7）。定理上界 12, 14, 18。deficit 3, 4, 5。
- `K_q(q) = (q−1)²` は q=4,5 で成立。Bruen–Rothschild より一般に
  `K_q(q) ≤ (q−1)²`。q ≥ 7 で等式が成り立つかは未解決。
- `s = q+1` でのみ全点集合に到達する（相転移）。

## 5. 手法と検証

- **盤面**: 出版済み `finite-field-kyouen-20261120/scripts/inversive_fast.py` の
  `build_circles`（SHA-256 を board JSON に記録）。設計パラメータを検査し、
  q ≤ 5 では独立実装 `inversive_all_q.build_inversive_plane`（三重ループ）と集合一致。
- **SAT 厳密計算**: 変数 `x_p`、円ごとの (s+1)-部分集合禁止節、
  基数 `Σx_p ≥ n`（sequential counter）、3 点対称性破り
  （PGL(2,q²) の 3-推移性より `∞,0,1` を含むとしてよい）。
  `n` を貪欲下界から 1 ずつ上げ、最初の UNSAT で厳密値を確定。
  最終 UNSAT は **cadical195 と glucose3 の 2 エンジン**で確認。
- **独立全探索**: `scripts/brute_force.py`（SAT 非依存）で q ≤ 5 の値を再計算し一致。
- **証人検査**: `scripts/verify_witness.py`（SAT 非依存）で全証人を盤面 JSON に照合。
- **モーメント監査**: `scripts/bound_audit.py` が (i) 点ごとの不等式、
  (ii) ランダム集合での 2 本のモーメント等式、(iii) 全厳密値と定理上界の整合を検査。
- **独立再検証（SAT 非依存・別実装）**: `independent/verify_all.py` が
  独自の体模型で円族を再構成し（q=7 で 350/350 一致）、C の完全列挙・分枝限定
  （q=7 は 3-推移性 117600/117600 を確認して 3 点固定）で
  `K_4(4)=9`, `K_5(5)=16`, `K_4(7)=13` を再確認。discrepancies 0、
  モーメント検証 200 試行 × 3 盤で失敗 0（`independent/results.json`）。
- 依存: SAT はリポジトリ外の一時 venv の `python-sat`（1.9.dev25）。
  リポジトリの `uv.lock` は変更していない。

## 6. 予想・観察（オープン）

1. **`τ_1(q) = 2q` か**（q ≥ 6）。Bruen–Rothschild で `≥ 2q` は既知。
   本実験の上界は q=7: 17, q=8: 20, q=9: 25 で、まだ 2q に達していない。
   等価に **`K_q(q) = (q−1)²` か**。q=4,5 は成立。
2. **excess の形**: `e_1 ≥ q−1`, `e_{q−1}=0`, `e_{q−2} ≥ 3`。
   `e_d` を q の関数として決める。K1252 は `e_{q−2}=3` を q=9 で達成している
   （`K_3(9)=9`）。
3. **`K_4(q)` の漸近**: 9, 10, 13（q=4,5,7）、上界 `2q+4`。
   `K_4(q) = 2q + O(1)` か、傾きは 2 未満か。
4. **`s`-共円ゲーム**: 円に `s+1` 点目を打てないゲーム（`s=3` が従来の共円ゲーム）。
   最大手数は `K_s`。`s=4` の Grundy は未計算。

## 9. 文献ノート（2026-11-24 のサブエージェント調査）

- **s-弧の一般化**: 「各ブロックと高々 α 点」の枠組みは
  S. S. Sane, S. S. Shrikhande, N. M. Singhi, "Maximal arcs in designs",
  *Graphs Combin.* 1 (1985) 97–106 の (α,n)-arc。射影平面版は
  S. Ball, "Multiple blocking sets and arcs in finite planes",
  *J. London Math. Soc.* (2) 54 (1996) 581–593 の (k,n)-arc。
  本稿の `K_s(q)` の一般上界 `(s−2)(q+1)+2` は、この文献調査では
  見つからなかった（一般 3-(v,k,1) 形も同様）。
- **反転平面の弧**: A. Sonnino, "Large k-arcs in inversive planes of odd order",
  *J. Geom.* 66 (1999) 187–191（(q+5)/2 構成）。
  É. Hadnagy, A. Sonnino, "Complete arcs in inversive planes over prime fields",
  *Discrete Math.* 255 (2002) 181–188。弧の上界 `K ≤ q` は文献に見つからない。
  A. Kurtulus, "On arcs in a finite Möbius plane", *J. Inst. Math. Comput. Sci.*
  16 (2003) 1–4 は要旨のみで未確認（初等的上界の可能性）。
- **ブロッキング集合**: A. A. Bruen, B. L. Rothschild, "Lower bounds on blocking
  sets", *Pacific J. Math.* 118 (1985) 303–311（反転平面で `|S| ≥ 2q`、q ≥ 9）。
  G. Kiss, S. Marcugini, F. Pambianco, "On blocking sets of inversive planes",
  *J. Combin. Des.* 13 (2005) 268–275（q ≥ 4 に拡張、極小集合の分類）。
- **分類定理**: B. Segre, *Canad. J. Math.* 7 (1955) 414–416（q 奇数の oval は円錐曲線）;
  B. Segre, *Ann. Mat. Pura Appl.* (4) 39 (1955) 357–379（PG(3,q) の (q+1)-arc は NRC）;
  L. R. A. Casse, D. G. Glynn, *Geom. Dedicata* 13 (1982) 157–163
  （q 偶数の Frobenius ひねり NRC）。
- **一般位置集合**: F. Pavese, "On 4-general sets in finite projective spaces",
  arXiv:2305.13838（4-general set = どの 4 点も平面上にない）。
  ovoid 上に制限した最大サイズの決定は見つからない。
