# 反転平面の円インターセクション・スペクトル K_s(q)（宣言・2026-11-24）

## 目的

反転平面 `M(q)`（点 `q²+1`、円 `q+1` 点、3-(q²+1,q+1,1) 設計）上の
**s-弧**を「どの円とも高々 `s` 点で交わる点集合」と定義し、その最大サイズ

```
K_s(q) = max{ |S| : |S ∩ C| ≤ s  for every circle C }
```

を調べる。`s = 3` が K1250–K1252 の通常の弧 `K(q) = K_3(q)` である。
本実験は「1 本の定理」だった弧の上界を **s に関するスペクトル**へ一般化する
新しい研究方向の最初の測定を行う。

## 予想される一般上界（本実験で証明・検証する命題）

`2 ≤ s ≤ q+1` に対し

```
K_s(q) ≤ (s-2)(q+1) + 2.
```

証明（設計のモーメント 2 本）: `t_j` を S とちょうど `j` 点で交わる円の個数とすると

- `Σ_{j≥2} C(j,2) t_j = C(n,2)(q+1)`（各点対は `q+1` 円に載る）
- `Σ_{j≥3} C(j,3) t_j = C(n,3)`（各 3 点は一意な円に載る）

各 `j ≤ s` で `C(j,2) ≥ (3/(s-2)) C(j,3)` なので
`C(n,2)(q+1) ≥ (3/(s-2)) C(n,3)`、すなわち `n ≤ (s-2)(q+1)+2`。
`s = q+1` では全点集合が許され `K_{q+1} = q²+1` で上界は tight。

## 本実験で確定させる値（SAT による厳密値）

- 較正: `K_3(q)` が K1058/K1251 の既知値（q=3:5, 4:5, 5:6, 7:6, 8:7, 9:9）と一致すること。
- 新規: `K_4(q)`（5 点共円を禁止）を q=3,4,5,7,8,9 で厳密に。
- 補助: `K_5(q)`、`K_q(q)`（= `q²+1 - τ₁`、τ₁ は円をブロックする最小集合）を小さい q で。

## 方法と独立性

- 盤面は出版済み `finite-field-kyouen-20261120/scripts/inversive_fast.py` の
  `build_circles` で構成（SHA-256 を記録）。設計パラメータ（各点対が q+1 円、
  各 3 点が一意な円）を検査し、q ≤ 5 では別実装 `inversive_all_q` の
  三重ループ構成と集合一致を確認する。
- 厳密値は CNF（円ごとの (s+1)-部分集合禁止 + 基数 ≥ n）を 2 種の SAT ソルバで解く。
  SAT 側の証人（明示的な点集合）は pysat に依存しない独立チェッカで検証する。
- q ≤ 5 の値は SAT を使わない全探索（独立実装）と一致させる。
- 上界 UNSAT 側は 2 ソルバ（glucose3 と cadical153）で一致を確認する。
