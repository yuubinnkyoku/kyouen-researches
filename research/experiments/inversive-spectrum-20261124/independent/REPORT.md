# Independent verification: exact K_s(q) for (4,4), (5,5), (7,4)

Experiment: `research/experiments/inversive-spectrum-20261124`
Verifier directory: `independent/`
Data source: the three board JSON files `output/board_q4.json`, `board_q5.json`,
`board_q7.json` (keys `q`, `v`, `b`, `blocks`).

**Independence.** `scripts/spectrum_sat.py` and `scripts/brute_force.py` were not
opened or reused. The search code here was written from scratch: Python
standard library for loading/checks and two small C programs (`exhaust.c`,
`q7_bb.c`) compiled with gcc. Cryptographically this is not a proof of
non-reuse, but the algorithms and encodings are different from the published
SAT/brute-force route.

## Command

From the repository root:

```sh
python research/experiments/inversive-spectrum-20261124/independent/verify_all.py
```

This compiles `exhaust.exe` and `q7_bb.exe` with `gcc -O2`, runs the supporting
symmetry scripts, performs all searches, verifies every witness against the
JSON board, and writes `independent/results.json`. Recorded wall time of the
full run: **5.46 s** (C search time is reported separately below).

Supporting scripts can also be run alone:

```sh
python research/experiments/inversive-spectrum-20261124/independent/field_model.py
python research/experiments/inversive-spectrum-20261124/independent/verify_symmetry.py
```

## Upper bounds (why no larger set exists)

All boards were first checked to be exactly the stated incidence structure:
`v=q^2+1`, `b=q(q^2+1)`, every circle has `q+1` distinct points, every point
lies on `q(q+1)` circles, **every pair lies on exactly `q+1` circles**, and
**every triple lies on exactly one circle**. These are the only design facts
used below.

### q=4, s=4 and q=5, s=5: complete exhaustion

`exhaust.c` enumerates, by increasing index, every subset of the requested size
whose intersection with every circle is at most `s`; pruning only removes
points that would push an already-full circle over the limit. The recursion is
exhaustive over all `n`-subsets.

- `q=4, s=4`: number of valid 10-subsets = **0** (9,318 search nodes).
  Number of valid 9-subsets = 2,040; the first one is the witness above.
- `q=5, s=5`: number of valid 17-subsets = **0** (646,444 search nodes).
  Number of valid 16-subsets = 3,900; the first one is the witness above.

Since the constraint is monotone (a subset of a valid set is valid), absence of
a valid set of size `n+1` rules out every larger size. Hence the maxima are
exactly 9 and 16.

An independent Python DFS prototype (`explore.py`) produced the identical
counts and identical node counts (2,040 / 0 and 3,900 / 0), as well as the same
witnesses.

### q=7, s=4: verified Möbius symmetry + exhaustive branch-and-bound

Because exhaustive enumeration of all 14-subsets of 50 points is impossible,
the upper bound uses the board's symmetry. It is rigorously established by
computation in two steps:

1. **Coordinate model (`field_model.py`).** With labels read as
   `L = b + 7a` for the field element `a + b*alpha` of `GF(49)`
   (`alpha^2 = 6`), and `49 = infinity`, the set of all 350 Baer sublines of
   `PG(1,49)` is generated by a BFS orbit of `PG(1,7)` under PGL(2,49)
   generators. The generated set of 350 circles is **exactly equal** to the
   350 blocks of `board_q7.json`. (The other two nonsquare choices for
   `alpha^2`, 3 and 5, do not match.)
2. **3-transitivity (`verify_symmetry.py`).** The three Möbius maps
   `x -> x+1`, `x -> lambda*x` (`lambda = (1,2)`), `x -> 1/x` are each checked
   to map the entire block set onto itself (hence they are automorphisms of
   the given board). A BFS on ordered triples starting from `(0,7,49)` reaches
   **all 117,600 = 50·49·48** ordered triples. Therefore the automorphism group
   generated by these maps is 3-transitive on the 50 points.

Consequently, for any hypothetical valid 14-set `S`, some automorphism maps an
ordered triple of `S` to `(0,7,49)`, producing a valid 14-set containing
`(0,7,49)`. It therefore suffices to search only sets containing this fixed
triple.

`q7_bb.c` performs a complete depth-first branch-and-bound over all supersets
of `{0,7,49}` of size 14. The upper bound at each node is the moment bound:
with current chosen set `A`, free candidates `U`, circle capacities
`r_B = 4 - |A cap B|`, and any completion `X subset U` of size `m`, the exact
design identities

```
sum_B C(|X cap B|,2) = 8*C(m,2)      (pairs lie on q+1=8 circles)
sum_B C(|X cap B|,3) = C(m,3)        (triples lie on one circle)
```

combined with `|X cap B| <= r_B` give

```
8*C(m,2) <= sum_B C(r_B,2),    C(m,3) <= sum_B C(r_B,3).
```

If `|A| + max{m satisfying these}` is below 14, the node is pruned. Circles
that reach capacity 4 force all their remaining points out of `U`. The search
is exhaustive.

- Target 14, fixed `(0,7,49)`: **UNSAT**, **2,088,623 nodes**,
  **1.70 s** C time.
- Independent repeat with fixed `(0,8,49)`: **UNSAT**, **2,082,143 nodes**,
  1.68 s C time.
- Target 13, fixed `(0,7,49)`: SAT, 3,105 nodes, 0.002 s; the found witness is
  the size-13 set listed above.

A separate Python branch-and-bound prototype (`search_q7.py`) reproduced the
same UNSAT result and exactly the same node count 2,088,623 (145.6 s in
Python), providing an implementation cross-check.

Thus no 14-set exists, and the 13-set witness gives `K_4(7) = 13`.

## Moment-identity checks

For each board, 200 random sets `S` (random size 0..v, fixed seed) were checked
for

```
sum_C C(|S cap C|,2) = C(|S|,2)*(q+1)
sum_C C(|S cap C|,3) = C(|S|,3)
```

Results: maximum absolute difference **0** for both identities in every trial
for q=4, q=5 and q=7 (no failures). This is 200 trials each (task required at
least 100 for q=5 and q=7).

  cross-checks.

- `results.json` — machine-readable record of this run.
- `run.log` — captured console output of the final `verify_all.py` run.
