## 手法と検証

- **系A**: 基点差分行 (Δw,Δx,Δy) の一次形式 comp·u_d=0 による全四点組走査 (C(169,4)=33.9M〜C(256,4)=174.8M)。先頭三つ組の2次元外積で共線/共円を分類。
- **系B**: 独立実装。3×3差分行列式を余因子展開 (a(ei−fh)−b(di−fg)+c(dh−eg)) で直接計算する全四点組走査。ループ構造・式展開とも系Aと独立。n=13..16の各々で系Aと総数完全一致。
- **共線分の4系一致** (n=12..16 各n): 系Aの共線計数 = 方向別最大線分の構成走査 = M(t) 閉形式 = round4 の閉形式 D_n。
  M(t) = [n−(t−1)a]₊[n−(t−1)b]₊ − [n−ta]₊[n−tb]₊ (原始方向 (a,b)、a≥1、b≥0、符号は |b| で2重化、軸は別扱い)、ちょうどt点の線数は M(t)−M(t+1)。
- **較正**: n=12 は系Aが F=158,426・D=17,154で batch-08 公開値を厳密に再現。
- **検証境界**: 正規化曲線カタログ (第3系) は n≥12 では未実施。全 3点以上円のキー保持が本実験環境のメモリ上限を超えるため。n≥12 の総数は 2つの独立全走査の完全一致と共線分の4系一致による。
- 比率 (C_n/n^5 の 0.568→0.695 単調増加、F_n/n^6 の単調減少、D_n/F_n≈0.108 の横ばい) は有限観測であり、漸近形や収束時点の主張はしない (C_n=Θ(n^5) は K0056)。
