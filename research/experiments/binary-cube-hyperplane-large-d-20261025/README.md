# 二値超立方体・共超平面禁止版の高次元安全配置

2026-10-25、main `df0deea8` を基準に作業。
[K0552](../../knowledge/items/K0552-binary-hypercube-d-plus-three-witnesses.md)は
d=6..10でd+3石の安全配置を証明し、d≥11を未解決として残した。
本実験はその直接延長である。

## 対象ゲーム

二値超立方体 $V_d=\{0,1\}^d$ 上で、相異なる $d+1$ 点が一つの実アフィン超平面に
載ること（退化を含む）を禁止する通常プレイの配置問題。
安全 = 任意の $d+1$ 点がアフィン独立。点は頂点番号 $x$ の下位 $d$ ビットを座標とする。

## 手法

1. **探索器** `search.cpp`：無作為順の貪欲。頂点をシャッフルして先頭から走査し、
   追加しても一般位置が保たれる頂点だけを採る。すべての判定は
   $p=2^{61}-1$ 上の掃き出しで行う。
   $d\le 24$ ではHadamard限界 $(d+1)^{(d+1)/2}\le 25^{12.5}<p$ のため
   行列式は $\bmod p$ で消えることと整数で消えることが同値であり、
   探索器の受理は過不足なく正しい。
   hyperplane法：$|S|\ge d$ では $S$ の全 $d$ 点部分集合の張る超平面の
   整数法線（余因子零ベクトル）を前計算し、候補は法線との内積が
   全て非零なら受理する。
2. **検証器1** `verify_exact.py`：全 $\binom{m}{d+1}$ 個の $d+1$ 点部分集合の
   増広行列式をPython整数のBareiss消去で厳密計算し、非零を確認。
   さらに双対検査として $m\times(d+1)$ 増広行列の左零空間の整数基底
   $N$（$t=m-d-1$ 行）を取り、全 $t\times t$ 列小行列式が非零であることを
   確認する（matroid双対性により全称の最大小行列式非零と同値）。
3. **検証器2** `verify_mod.cpp`：全部分集合を $p=2^{61}-1$ 上の掃き出しで検査。
   同じHadamard論証で整数での非特異と同値。実装・算法とも検証器1と独立。

## 制御

- 既知の d=6..10 証人（K0552の`controls.txt`）は両検証器で合格し、
  min/max行列式の絶対値も旧results.mdと一致した。
- d=5, m=8 は2000再試行で全滅（$K_5=7$ の既知上界と整合）。
- 探索器は d=6, m=9 で41再試行・5msの新証人を発見した。

## 小素数の教訓

旧来の $p=1009$ 検証は $d\le10$ では問題なく機能したが、高次元では
非零の行列式がたまたま $1009$ の倍数になる偽失敗が起こる
（d=15, m=20で実際に発生）。検証素数はHadamard限界超えとし、
同値性を明示的に仮定する方式に置き換えた。

## 再現

```sh
g++ -std=c++17 -O2 -Wall -Wextra -o /tmp/hlsearch search.cpp
g++ -std=c++17 -O2 -Wall -Wextra -o /tmp/hlverifymod verify_mod.cpp
bash run_probe.sh                      # d=6..20 の並列probe
python3 verify_exact.py witnesses.txt
/tmp/hlverifymod witnesses.txt
```

run_probe.sh は次元ごとに m=d+3 から上限 m=d+8 まで、
1サイズあたり再試行300・90秒の予算で貪欲を試み、
2サイズ連続失敗で打ち切る。d=21..24は再試行1000・600秒で実行した。

## 証拠の意味

- 各証人について「全 $d+1$ 点部分集合がアフィン独立」が二つの独立な
  厳密算法で完全検証済み。よって $K_d\ge m$ は証明済みの下界。
- 貪欲が予算内に到達できなかったサイズは**上界ではない**。
  到達失敗は限界の経験的指標にすぎない。
- $K_d$ の上界・全 $d$ への一般化・Grundy値は対象外。
