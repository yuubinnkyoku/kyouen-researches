# z=16・y=2 2トークン境界切片の全Grundy分類（K1042）

- 日付: 2026-11-19
- 対象: κ=1残余ゲーム \(H(R;(x,2);16)\)、全 \(x\ge2\)・全 \(R\ge0\)
- 状態: **全称定理**
- 依存: K0832、K1023（B子）、K1032（C子）

## 命題

\(O[a,b]\) は区間内の奇数、\(I[a,\infty)\) は \(a\) 以上の全整数とする。

Grundy値2の位置集合 \(T(x)\):

| x | \(T(x)\) |
|---:|---|
| 2 | \(\{1,3\}\) |
| 3, 4 | \(O[1,5]\) |
| 5, 6 | \(O[1,7]\) |
| 7, 8 | \(O[1,9]\) |
| 9, 10 | \(O[1,11]\) |
| 11, 12 | \(O[1,13]\) |
| 13 | \(O[1,15]\) |
| 14 | \(O[1,17]\)（h=z行・孤立上端17） |
| 15 | \(O[1,15]\) |
| 16 | \(O[1,15]\cup\{19\}\)（前倒しd格子点19） |
| 17, 18 | \(O[1,15]\) |
| 19 | \(O[1,15]\cup O[21,37]\)（掃引行） |
| \(x\ge20\) | \(O[1,15]\cup\{21\}\) |

Grundy値1の位置集合 \(P(x)\):

| x | \(P(x)\) |
|---:|---|
| 偶数 \(x\le14\) | \(\varnothing\) |
| 奇数 3, 5, 7, 9, 11, 13 | \(I[x+3,\infty)\) |
| 15, 17 | \(\{17,19\}\cup I[20,\infty)\) |
| 16 | \(\{17\}\) |
| 18 | \(\{17,19\}\) |
| 奇数 \(x\ge19\) | \(\{17,19\}\cup E[22,x+19]\cup I[x+20,\infty)\) |
| 偶数 \(x\ge20\) | \(\{17,19\}\cup E[22,x+18]\) |

ここで \(E[a,b]\) は区間内の偶数とする。従って
\[
H(R;(x,2);16)=
\begin{cases}
2,&R\in T(x),\\
1,&R\in P(x),\\
0,&\text{otherwise}.
\end{cases}
\]

一般tailはK0832から
\[
\boxed{R\ge x+19\implies H(R;(x,2);16)=(x+2)\bmod2.}
\]
また高さのみ縮約から
\[
R\le17\implies H(R;(x,2);16)=v_{\rm single}(x+2,16,R).
\]

## 構造の注記

- **pin=21=2y+z+1**（偶数zラダー \(O[1,z]\cup\{z+2y+1\}\)）。掃引行は \(x=z+y+1=19\)、
  掃引行上の値2帯は \(O[1,z]\cup O[\text{pin},x+y+z]=O[1,15]\cup O[21,37]\)。
- **h=z行 \(x=z-y=14\) の孤立上端17**: \(q_{\rm odd}(2y+(d+z)/2)=q_{\rm odd}(18)\)
  （\(d=12=x-y\)・\(d+z=28\equiv0\pmod4\)）。偶数z型h=z行孤立上端は
  K1028 の z=14・x=12 上端15（\(q_{\rm odd}(16)\)）・K1031 の z=14・y=4・x=10 上端17
  に続く。内部値 \(2y+(d+z)/2=18\) が偶数の際に \(q_{\rm odd}\) で丸まる偶数z型
  （d+z≡0 mod 4）の3例目。
- **x=16（x=z行）の前倒し点19**: \(d=14\)・\(d+z=30\equiv2\pmod4\) のd格子点
  \(2y+(d+z)/2=4+15=19\)。K1028 の z=14・x=14 前倒し点17（\(d=12\)・\(d+z=26\equiv2\)）と
  同じ x=z 行の型で偶数zでは2例目。奇数z（K1032）ではこの点が \(x=z+y\) のpin行に
  現れて \(2y+z\) と一致したのに対し、偶数zではラダーpin \(2y+z+1=21\) と分離して
  \(x=z\) 行に現れる。
- **値1基底点 \(\{17,19\}=\{z+1,z+3\}\)**: y点仮説2点型は K1019 の {13,15}（z=12）、
  K1025 の {14,16}（z=13）、K1028 の {15,17}（z=14）、K1032 の {16,18}（z=15）に続き
  5例目。y=2ではz=12..16の5連続で \(\{z+1,z+3\}\) が確定し、偶数zでは3例目。
- **値1中間帯は \(z+2y+2=22\) 開始の偶帯**: 帯の偶奇はzに追従し（偶数z→偶数位置）、
  奇数行は \(E[22,x+19]\cup I[x+20,\infty)\)、偶数行は有限 \(E[22,x+18]\)。
  無限I帯は奇数x行のみで、tail \(R\ge x+19\) の値 \((x+2)\bmod2\) が1になる行と一致する
  （「I帯はtail値1の行にだけ現れる」一般則のy=2・偶数z型確認）。値1基底点は
  x=16で1点・x=18で2点・x=15,17で\(\{17,19\}\cup I\) と段階出現する。
- 移行行: x=17（偶帯署名「023」群）、x=18掃引前行（奇帯「1」・偶帯「123」交互）、
  x=19掃引行（奇帯「01」・偶帯「0」交互）、x=20移行行（奇帯「1」・偶帯「02」交互）、
  x≥21奇数/x≥22偶数で定常化（帯構造は行偶奇完全共通・帯上端のみ \(x+17\)/\(x+16\) 入替）。
  h=z行 x=14（奇17/19署名「1」・偶16署名「23」）も静的表の特異点。

## 証明

子分解は
\[
A=H(R-1;(x-1,2);16),\quad
B=H(R-1;(x,1);16),\quad
C=1\oplus H(R-1;(x,2);15).
\]
BはK1023のパラメトリック全称公式、Cは1⊕K1032。x=2では二つのトークン減少手が同じ多重集合
\((1,2)\equiv(2,1)\) に合流して単一の子値となり、K1023のx'=2行（z=16）を帰納基底として使う。
x≥3ではAをx外帰納で閉じる。全 \(R\ge1\) は検証器内の完全A/B/C署名帯表
（静的行 \(x=2..20\)・定常閉形式 \(x\ge21\)・各行が \(R=1..x+17\) を互いに素に被覆）と
mex対応表で被覆し、\(R\ge x+19\) はK0832一般tail、\(R\le17\) はK0832高さのみ縮約で閉じる。
