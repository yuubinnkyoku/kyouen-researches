# 6点純三点辺の全型（2^20完全列挙）についての34周期証明（2026-11-08）

## 背景と範囲

K0684は「任意の固定rank3残余核に長道を付けたGrundy列は最終的に34周期」という
核サイズ無界の予想。`rooted-core-six-pure-triple-six-edges-20261107` は6点の純三点辺が
高々6本の全60460件（根付き732型）を全長認証した。本実験はそれを **6点純三点辺の全型** へ拡張する。

6点の三点集合は20種類あり、三点辺同士は包含関係を持たないので、その任意の部分族は
自動的にclutter（包含極小残余族）になる。従って合法な純三点辺核は全部分族

```
2^20 = 1048576
```

件すべてである。根0を固定する根付き同型（S5・120元）で畳んだ型数はBurnsideの補題で

```
(1/120) Σ_{g∈S5} 2^{c(g)} = 10688
```

（c(g)はgが20三点集合上に誘導する置換のcycle数。分布は
cycle数4が24元・6が50元・8が20元・12が15元・14が10元・20が1元）。
これは抽样ではなく有限族の**完全列挙**である。

## 方法

`rooted-core-tail-periodicity-20261107/engine.py` の正確な再帰をそのまま使う。

1. 高速orbit列挙：20ビットmaskを昇順に走査し、未visitのorbit最小元を代表として
   120元の像を全てvisit済みにする。remap呼び出しは約120×10688回で済み、全1M回の
   canonical化を避けられる。各代表をengine.canonicalで正規化し10688型を得る。
   このパイプラインが高々6本でcommittedの732型と集合一致することを事前検証した。
2. 5点以下の全513型はK0682の証明済み表を既知部分問題として再利用
   （0..1069は保存整数値、それ以後は500からの周期34で延長。全長証明済み値の利用）。
3. 新規10688状態を核の小さい順・長さの二重帰納で生成。適応的停止：
   `start = max(500, 各状態の最終周期破綻+1)`、`needed = 2*start+69` とし、
   長さ≥neededかつ窓 `start..2*start+35` で道列と全状態列の周期34一致を確認した時点で
   停止する。K0682の有限窓定理がそれ以上の全長を保証するので、無駄な長さ計算を避けられる。
4. 独立検証：高々6本の型は sibling 実験で全732型長さ0..6を原始subset mexで監査済み。
   本実験では7本以上の型から無作為400型・長さ0..6（2800条件）を原始subset mexで照合する。

## 限界

- これは「6点・純三点辺」の完全な有限定理であり、K0684の核サイズ無界の全称証明ではない。
- 二点辺を含む一般clutterや7点以上の核は含まない。
- 固定seed統計ではなく、決定的に再現する全列挙として扱う。
