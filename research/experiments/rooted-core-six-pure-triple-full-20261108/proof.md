# 有限族の全長周期証明（6点・純三点辺・全型）

核の意味・正確な再帰・有限窓定理はK0682と同じ。ここでの新規主張は次の有限族に限る。

## 命題（有限・完全）

6頂点上の三点集合20種類の**任意**の部分族（純三点辺核）と指定根に対し、
根に長さLの二点禁止道を付けた通常Grundy列 f_C(L) は

```
f_C(L+34) = f_C(L)  for all L >= 637
```

を満たす。三点辺同士は包含を持たないので全部分族が自動的にclutterであり、
raw入力 2^20 = 1048576 件すべてを被覆する。根付き同型（根0固定・S5）で10688型。
開始637はこの族全体の共同上界で、個々の核の最小開始ではない（最悪状態の最終周期破綻は636）。

## 型数え上げ（Burnside）

根付き同型型数はBurnsideの補題で厳密に

```
(1/120) Σ_{g∈S5} 2^{c(g)} = 10688
```

c(g)はgが20三点集合上に誘導する置換のcycle数。120元のcycle数分布は
4が24元・6が50元・8が20元・12が15元・14が10元・20が1元。
数列挙は20ビットmaskの昇順走査でorbit最小元を代表とし、120像をvisit済みにする方法で
remap約120×10688回のみ。各代表をengine.canonicalで正規化して10688型を得る。
このパイプラインが高々6本で sibling 実験の732型と集合一致することを事前検証した。

## 証明の構造

1. **既知部分問題**：5点以下の全513型はK0682で全長証明済み。その保存整数値
   0..1069はそのまま、それ以後は500からの周期34で延長して使う。証明済み値の利用であり
   観測prefixの外挿ではない。全513型が全6点族の根残し閉包に現れる（閉包11201状態）。
2. **新規状態の閉包**：10688型の根を残す着手で到達する状態を `closure()` で列挙すると
   11201状態。うち5点以下513状態は既知表に一致し、新規は6点10688状態のみ。
   根残し核内手は必ず頂点数を減らすので、6点状態同士の同一長さ依存は無い。
3. **二重帰納**：核の頂点数の小さい順・長さの昇順で正確な再帰を計算。各手の
   （根着手・根禁止・根残し核内手・道_split）を `engine.play` の残余更新で分離。
4. **有限窓認証（適応停止）**：各状態の最終周期破綻 `last_period_failure(seq,34)` から
   `start = max(500, max+1)`、`needed = 2*start+69`。実測は `start=637`・`needed=1343`。
   長さ≥neededかつ窓 `start..2*start+35`（637..1311）で道列と全10688状態列の周期34一致を
   assertで確認した時点で停止。K0682の有限窓定理により、この族と全到達状態は全長で637以降34周期。
5. **独立基底検証**：高々6本の全732型・長さ0..6は sibling 実験で原始subset mex監査済み。
   本実験は7本以上の型から固定seed無作為400型・長さ0..6（2800条件・596850安全状態）を
   再帰を使わない原始subset mex `direct()` で照合し一致。

## 監査範囲と限界

- `output/audit.json` の `jointly_certified=true`、`joint_start_candidate=637`、
  `values_needed_through=1343`、`direct_subset_checks=2800` が有限証明の機械可読証拠。
  全10688状態の必要整数値0..1343を保存する。
- 一般核（二点辺混在・7点以上・無界サイズ）への拡張は証明しない。K0684は予想のまま。
- 数値 `maximum_grundy_in_prefix=29` はこの族のprefix上界であり、核によらない一様上界ではない。
- 計算は決定的で再現可能。標準ライブラリのみ。全長求解は約65分（チェックポイント再開対応）。
