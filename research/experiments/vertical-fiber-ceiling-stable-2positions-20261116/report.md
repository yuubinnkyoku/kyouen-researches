# 天井トークン付き残余ゲームの値2位置分類（全m予想・有限監査）

実験日: 2026-11-16 (JST)。レーン: 高速レーン（κ=1 残余ゲームの一般多重集合構造）。

## 1. 背景と定義

κ=1 残余mex `H(R;X;z)`（K0832 本文の再帰: A手は v≥2 を v−1、B手は 1 を除去して z+1、C手は z≥1 で z−1 かつ値 1⊕子、H(0)=0、mex）について、
cap補題（証明済み）`H(R;X;z)=H(R;cap_{R+1}(X);z)` から、値 `R+1` 以上のトークンはすべて `R+1` に置換可能であり、
複数の天井トークンは互いに区別できない（各レベルで常に1個として振る舞う）。

そこで **天井ゲーム** を

```
T_inf(X;z) := { R >= 1 : H(R; X ∪ {R+1}; z) = 2 }
```

と定義する（X は正整数の有限多重集合、m=|X|）。これは元ゲーム
`H(R;X;z)` のうち「最大トークンが R+1 以上に capped される」スライスそのものであり、
2トークン族の家族A（定常位置）・3トークン族の「安定コア」を一般化する対象である。

## 2. 主張

X を昇順 `t_0 <= t_1 <= ... <= t_{m-1}` に並べ、`δ_A(u)` を u 以上の最小奇数とする。

### 2.1 ラダー（証明済み定理からの系）

```
L(z) := { 奇数 R <= z+1 } から R = z+1 を除いた集合
```

**これは予想ではなく系である。** 導出: R ≤ z+1 では高さのみの縮約（K0832 証明済み:
`H(R;X;z)=H(R;(ΣX);z)`）と cap補題により
`H(R; X∪{R+1}; z) = H(R; (R+1); z)`（単一トークン a=R+1）。
証明済み単一トークン閉形式（値2 ⟺ 奇数 R ≤ μ(a,z)、z=a で μ=2a−1、それ以外 μ=min(a,z)以下最大奇数）に
a=R+1 を代入すると、R ≤ z+1 の範囲で値2 ⟺ R 奇数 かつ R ≠ z+1 かつ R ≤ z+1。
検証器 A0/A0b がこの導出をエンジンと証明済み閉形式の両面から照合する。

### 2.2 位置族 P（予想・本実験の主対象）

```
P(X;z) := { p_j : j = 0..m-1 }
p_0 = 2 t_0 + δ_A(z)
p_1 = 2 t_1 + δ_A(z+1)
p_j = 2 t_j + p_{j-2} + 2     (j >= 2)
```

同値な閉形式: `p_j = 2 (t_j + t_{j-2} + t_{j-4} + ...) + δ_A(z+j)`（和は j から 2 ずつ下がる同符号列）。

**予想（天井値2分類）:** 任意の m ≥ 0、任意のトークン多重集合 X、任意の z ≥ 0 について

```
T_inf(X;z) = L(z) ∪ P(X;z)
```

m=0 では P=∅ であり T_inf(∅;z) = L(z) は上記の通り証明済み定理のみから決まる。
したがって本予想の新しい内容は m ≥ 1 の P 部分（両包含）である。
P の位置はすべて奇数（Theorem T と整合）で、常に R ≥ z+2（ラダーと重ならない）。

### 2.3 元ゲームへのブリッジ（予想の系）

cap補題から、任意のトークン多重集合 X について

```
H(R; X; z) = H(R; X_{≤R} ∪ {R+1}; z)    (X_{≤R} := X のうち値が R 以下のトークンの多重集合)
```

が成り立つ（R+1 以上のトークンは天井に合流する）。よって予想から:

- 2トークン族 `X=(x,y)`、`x ≥ y`、`R ∈ [max(z+2, y), x−1]`（y は capped されない範囲）:
  `H(R;(x,y);z)=2 ⟺ R = 2y + δ_A(z)`。家族Aの定常位置がcap境界の内側で完全であること、
  およびその帯に家族Bの過渡位置が現れないことが言える。
- 3トークン族 `X=(x,y,w)`、`R ∈ [max(z+2, y), x−1]`:
  `H(R;(x,y,w);z)=2 ⟺ R ∈ {2w+δ_A(z), 2y+δ_A(z+1)}`。本実験の探索で最初に発見した
  「安定コア」がブリッジの m=2 場合に相当する。

## 3. 導出過程

1. **3トークン x-スイープ**: `X=(x,y,w)` で固定 (y,w,z)・d1=x−y を 0..40 で動かし帯を観察すると、
   帯は d1 の増加に対し有限の過渡の後に一定の「安定コア」へ収束すること、およびコアが
   `{2w+q_o(z+1), 2y+δ_A'(z)}`（q_o(k)=k以下最大奇数、δ_A'(z)=z+1以上最小奇数）であることが
   ファイル出力とプログラマティック比較で確定した。
2. **直接定義への置換**: 安定コアは cap補題により `H(R;(R+1,y,w);z)` の値2位置そのもの。
   1001状態（w≤7, y≤11, z≤12）で予想と0不一致。
3. **k=2 への還元**: 同じ直接定義で `H(R;(R+1,y);z)` を検査すると
   `{2y+δ_A(z)}`（156状態・0不一致）。2トークン家族Aの定常位置の対角線スライスと一致。
4. **k=4,5 で規則の確定**: `H(R;(R+1,t2,t1,t0);z)` は3位置、基底は `2t_0, 2t_1, 2(t_2+t_0)`、
   オフセットは `δ_A(z), δ_A(z+1), δ_A(z+2)`。k=5（4実トークン）で候補A
   `2(t_3+t_1)+δ_A(z+3)` が候補B `2(t_3+t_0)+δ_A(z+3)` に全勝（120テスト）。
   これにより再帰 `p_j = 2t_j + p_{j-2} + 2` が確定した。
5. **m=6,7 での確認**: 予想を m=6,7（225状態）まで拡張し全一致。
   なお初期の m=6/7 テストは入力タプルの昇順/降順を取り違えたテスト側バグで
   全面的な「不一致」を出した。予想ではなくテストの誤りであり、教訓として
   「入力の順序規約は検証器内部で正規化する」ことを本検証器に反映した
   （`pred_positions` は内部で必ず `sorted(X)` を取る）。
6. **遠方tail・高z**: 予想位置の最大値（~2Σt+z+O(1)）を大きく超える
   Rmax（マージン+150）でも追加位置なし。z≤40 でも破綻なし。
   これは天井ゲームでは高余裕縮約 `z ≥ S+R−1` が R ≥ z+2 では決して発動しない
   （S が R+1 を含み R とともに増える）ため、2トークン族とは違って
   tail定理でも上側が閉じない中、値2位置が有限集合に留まることを意味し、
   予想の非自明な一部である。

## 4. 既知結果との整合

- **単一トークン閉形式（証明済み）**: m=0 はその系（A0b で値レベル照合・0不一致）。
- **高さのみの縮約 R ≤ z+1（証明済み）**: ラダー導出の中間ステップ。
- **Theorem T（証明済み・値2は奇数Rのみ）**: P の全位置が奇数であることと整合（A8）。
- **2トークン族閉形式予想（未証明）の家族A**: m=1 はその「x=R+1 対角線」スライス。
  z=0 では家族A（および全Grundy値）が別レーンで証明済みであり、
  m=1 の z=0 場合 `T_inf((y);0) = {2y+1}` は証明済み定理と完全に一致する。
- **2トークン z=0 スライス定理（証明済み）**: `x>y かつ R=2y+1` のみ値2。
  cap境界の外側も含む全帯の主張であり、本予想のブリッジ（R ≤ x−1 側）と補完関係。
- **全1族系A（証明済み）**: X=(1^m) の天井ゲームは別ゲーム（天井トークン付き）なので
  直接の系ではないが、A3 で all-ones X を全 m≤7・z≤12 で監査し予想と一致。

## 6. 未証明範囲と次課題

- **P 部分の全称証明は未解決。** 有望な経路: R 前進帰納（全1族 U 定証明と同じ枠組み）。
  天井ゲームの状態遷移は `Ĥ(R,X,z) = mex{Ĥ(R−1,X,z), …トークン手…, 1⊕Ĥ(R−1,X,z−1)}`
  であり、A手（天井）が常に同じ (X,z) を返す自己参照構造をもつ。
  `p_j = 2t_j + p_{j-2} + 2` の「2つ飛ばし」構造は奇数・偶数インデックスの2本の独立列を示唆し、
  何らかの分解定理の存在が疑われるが未達。
- **ブリッジ範囲外（過渡位置）**: 3トークン族の `R > x` 帯（2トークン家族Bに相当）は
  今回扱っていない。探索メモでは過渡位置は `R = 2x + c`（c 奇数）の族に分散し、
  主族 `R=2x−1` は `d1 ≥ ⌊z/2⌋+2` で現れることが観測済み。次課題。
- 有限監査は全称証明の代替ではない。ただしラダー部分（m=0 を含む）は
  証明済み定理のみから導出される系であり、その部分は全称的に成立する。
