子の値はそれぞれ既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K1003 の z=10・y=1 全称定理、C子は K0988 の z=9・y=2 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

## 構造的な観察（補足メモ、証明不要）

- 値1の基底点列は {11,13}={z+1,z+3}（y=1 は {z+1}、z=9・y=2 は {10,12}={z+1,z+3}）。**基底点は z+1 から始まる奇数ステップ列 {z+1,z+3,…,z+2y−1} の最初の y 個**であるという仮説が z=9,10 の y=1,2 で成立する。y=3 では {11,13,15} が予想される（検証課題）。
- 値1の有限帯の開始は 16=z+2y+2（y=1: 14=z+4、z=9,y=2: 15=z+6）。帯の偶奇は **z の偶奇で決まり**（z=10 偶 → E 帯、z=9 奇 → O 帯）、y=1・y=2 の両方で x の偶奇によらない。帯の末端は x の偶奇で ±1 し、tail値 1 の行（(x+y) 奇、すなわち y=2 では x 奇）に I[x+13,∞) が接続し、tail値 0 の行（x 偶）は有限で閉じる。y=1 とちょうど偶奇が反転する。
- 定常値2位置は z=9,y=1（{1,3,5,7,9,11}）、z=10,y=1（{1,3,5,7,9,13}）に続き z=10,y=2 では **{1,3,5,7,9,15}**。ラダー {1,3,…,qod(z)} に定常ピン 2y+z+[z偶] が加わり、ピンは 13→15 と y 増分で+2 ずつ上昇する。y=1 のピン13は11を飛び越えたが、y=2 のピン15は11・13を飛び越し、飛び越えられた点がちょうど値1基底点 {11,13} と一致する（ピンの直前までの奇数点が基底点側に占有される構造）。
- 掃引行は x=z+y+1=13、掃引帯 O[15,25]=O[2y+11,x+y+z]=O[pin,x+y+z]。機構は 3族比較則（K1001記録）どおり A子×B子×C子の積。y=1（x=12・帯O[13,23]）との差分は +2 ずつで、z=8,9,10・y=1,2 の6観察で則が貫徹。
- 前倒し格子: d≡(10−z) mod 4=0 (mod 4) の行 x=y+d で高さ 2y+5+2k。y=2 では d=8（x=10）の点13（高さ2y+9=13）が生存し T₁₀⁽²⁾(10) の例外点になる。y=1 の d=8（x=9）の点11に対応し、**前倒し生存点の x=y+8 は y に追随**する（高さの 2 増分と相殺）。x=14（d=12）の高さ 2y+11=15 は定常ピンに一致して単独定着する。d=0,4（x=2,6）の点は高さのみ縮約の m=qod(x+2) 抑制で消える。
- x=8（高さ h=x+y=10=z）は T={1,3,5,7,9,11} の例外行。R=11 が値2になるのは高さのみ縮約の z=h 枠（O[1,2h−1] 型値2）で、z=9,y=2 の x=7（高さ9=z）行・z=10,y=1 の x=9（高さ10=z）行と同じ機構。**高さ h=x+y=z の行では R=z+1=11 が必ず値2**となる規則が 3観察で成立（一般化候補）。
- x∈{2,4,6,8} の P=∅（偶書き込みなし行）は z=9,y=2 の x∈{2,4,6}（K0988）に x=8 を加えた形。x が z+h に達するまで偶数行は値1を持たない。
- 高さのみ縮約の一般化: R≤z+1 で H(R;(x,y);z)=v_single(x+y,z,R) は 2トークン一般の観察として z=10,y=2（x≤500・R≤11）と z=9,y=2（x≤300・R≤10）で機械照合した。並走レーンの「z=10低残余帯」出版（R=0..11・tail R≥x+y+11 の全称証明）と本項の R≤11 列は完全一致し、**K1002 の未証明帯は y=2 について消滅**した（K1002 の一様式に対する y=2 の16点逸脱が本項で別個の正解形として確定）。
