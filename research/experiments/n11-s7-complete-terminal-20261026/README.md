## 完全なAND/OR証明

7石局面は後手番なので、元先手WINを示すには**全34類の合法8石子**について元先手WINが必要。`s8-witness.tsv` は34類すべてに合法な9石WIN証人を指定し、`s9-roots.keys` は相異なる9石証人17類を列挙する。9石局面は後手番なので、全合法10石子の元先手WINを要求する。17類の9石根から生じる合法10石子は延べ360辺、相異なる360類。全360類を独立の整数幾何・空の局面表から終局まで探索し、**360類すべて元先手WIN**。よって9石17類→8石34類→7石1類の元先手WINが成立する。

3×3整数行列式と、独立した4×4 Bareiss整数行列式を使用。全合法着手集合・対称正準形・葉ごとの勝敗・探索状態数が一致。探索状態数は各実装合計28,029（共有局面表での新規状態数であり、勝敗距離ではない）。根・証人・葉のSHA-256と葉ごとの状態数・合法手数を固定。欠落、重複、不正な証人を拒否する負の試験6件を含む。証明は凍結勝敗表、df-pn途中統計、既存の8石WIN証明に依存しない。

## 以前の証明との関係

前回の証明限定7石監査では、対象の合法8石子34類のうち13類が既に証明済みで、残り**21類が未被覆**だった。今回の自己完結証明は34類すべてを改めて終局まで検証した。`audit.js` は過去の未被覆21類と今回の証明対象を照合し、証明済み8石LOSS77類・凍結LOSS294類との矛盾を拒否する。さらにこの7石WINを合法証人に持つ6石親7類を列挙する。ただし、6石親の研究全体に対する純増は未集計。
