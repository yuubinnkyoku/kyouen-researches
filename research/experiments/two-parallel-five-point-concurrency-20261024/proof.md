# 各5点以下の二平行線を横断する共通点円の鋭い上限4

2026-10-24。全称数学的証明。有限の多項式恒等式は標準ライブラリで別途厳密検査する。

## 定理

相異なる二本の平行線LB,LCそれぞれに相異なる実数位置の点を高々5個指定する。
両線上にない任意の点Pについて、Pを通り、各線の指定点を2点ずつ通る相異なる円は高々4本。
この上限4は実現する。点Pを通る円の同和弦energyに追加条件を置かない。

## 1. 五円なら二つの五角形型が強制される

五円が存在すると仮定し、その五円だけを選ぶ。
各線の円・点接続は計10個。5点以下へ配分すると共有円対数は少なくとも5。
二円がPのほかに二つの指定点を共有すれば同じ円になるので、各円対は二線合計で高々1指定点しか共有しない。
全10円対に対して共有数の合計は最低10だから、すべて等号となる。
各線にはちょうど5個の使用点があり、各点はちょうど2円に属し、各円対は二線合計ちょうど1点を共有する。

B線上の共有点を円頂点間の辺と見れば、5頂点の単純2正則グラフとなるから五角形C5。
C線側はその補グラフで、やはりC5。
円を巡回順にi=0,...,4とラベルし、Bの円iの弦を(bi,b(i+1))とする（添字はmod5）。
Cの円iの弦は(ci,c(i−2))と置ける。

## 2. 五つの弦和による正規化

平行移動・等方拡大・必要なら上下反転でBの高さを

`b=(0,1,v,w,z)`

とできる。これは昇順ラベルではなく、上のC5順序である。
v,w,zは0,1とも相互とも異なる。線はx=0,d、d>0。P=(du,a)、u≠0,1。
同一円の平行弦の縦座標和は同じなので、

`ci+c(i−2)=bi+b(i+1)`。

奇数巡回のこの一次系は一意で、

`c=(v−z+1, v+w, w+z−1, −v+z, 1−w)`。          (2)

5点cも相異なる。
各円について `si=bi+b(i+1), pi=bi*b(i+1), δi=ci*c(i−2)−pi` とすると

`d²u(u−1)+a²−si*a+δi*u+pi=0`。               (3)

基準円0の式を引くと、i=1,...,4について

`(s0−si)a+(δi−δ0)u+(pi−p0)=0`。              (4)

Mをこの4×3係数行列とする。整合性のため全3×3小行列式は零。

## 3. 二つの小行列式だけで黄金比型へ帰着する

次の三次式を置く。

```
F2 = v²w−v²−vw²−2vwz+2vw+2vz−v+w²z+wz²−2w−2z+2
F4 = −v²w+v²+vw²+2vwz−2vw−2vz²+v−w²z−wz²+2wz+2z³−2z²
```

Mの行を0..3とすると、直接展開で

`det M[0,1,3] = −v(−v−w+z)F2`,
`det M[1,2,3] = w(v+w−1)F4`。

v,w≠0。また `−v−w+z=c4−c0`、`v+w−1=c2−c3` は相異なるC点の差なので非零。
従ってF2=F4=0。

さらに展開恒等式

`F2+F4=−2(z−1)(vz−w−z²+1)`

とz≠1から `w=vz−z²+1`。
α=v−zと置けば `v=z+α, w=zα+1`。
この代入で

`F2=−z(α+1)(z−1)(α²−α−1)`。

z,z−1≠0であり、`c1−c0=z(α+1)≠0` なので、

`α²−α−1=0`。                                (5)

この帰着は一般位置だけを扱うものではなく、除いた因子はすべて指定点の相異性から非零である。

## 4. 一次系の一意性と負の線間距離

(4)のa,uに関する係数階数は2である。
もし1以下なら、s0=1とs1=1+vは異なるので、整合性からpiはsiの一次式 `pi=h*si+k` となる。
すると五角形のすべての辺で `(bi−h)(b(i+1)−h)=k+h²`。
右辺が非零なら高さ差は二つの値を交互に取るが、奇数巡回のため全biが同じとなる。
右辺が零なら各辺はbi=hの頂点を必要とするが、相異なる5頂点のうち高々1点では全5辺を覆えない。
いずれも矛盾。よってa,uは一意に決まる。

(5)を用いると、5本の式(3)すべてを満たす代数的な値は

`a=(α+2)(z+1)/5, u=(4−3α)/5,`

`d²=−(α+1)[z²+(α−1)z+1]`。                  (6)

直接代入しα²=α+1で整理すれば全残余が零になる。
a,uの一意性により、実際の共通点があるならこれらの値でなければならない。
(5)からα+1=α²>0、α+2=α²+1>0、`u(u−1)=1/5`。特にu≠0,1。
さらに

`z²+(α−1)z+1=[z+(α−1)/2]²+(α+2)/4 > 0`。

従って(6)のd²は必ず負となり、d>0に反する。
五円は存在せず、上限は4。□

## 5. 四円を実現する厳密な例

B線x=0に高さ `(-20,-10,0,5,20)`、C線x=10に高さ `(-15,-10,-5,0,10)` を置く。
整数点P=(12,−4)は次の相異なる4円を共有する。

```
x²+y²+15y−100=0
x²+y²+20x−400=0
x²+y²−10x+10y=0
x²+y²−15x−5y=0
```

各円は両線に指定点2個ずつを持ち、Pへの代入はすべて零。
同和弦対の全円は9本あり、Pを通るのはこの4本だけ。
したがって指定点と共通点をすべて整数座標に制限しても、上限4は実現する。

さらにenergyを小さくした別の厳密例もある。
B線x=0に高さ `(-40,-32,-24,-16,0)`、C線x=√71に高さ `(-37,-35,-27,-5,13)` を置く。
`P=(2√71/5,−154/5)` とする。
各線から二点ずつ通る円は同和弦対から6本あり、そのうちPを通るのは次の4本。

|s|δ|p|
|---:|---:|---:|
|−72|15|1280|
|−40|−209|384|
|−32|135|0|
|−24|−481|0|

円の式は `x²+y²+(δ−71)x/√71−sy+p=0`。
Pへ代入して25倍すると `23290+770s+10δ+25p=0` となり、4本で厳密に成立する。
各円は二線上に指定された異なる2点ずつを持つので実在する非退化円で、4係数組は相異なる。
よって上限4は鋭い。

## 検証と限界

`verify.py` は標準ライブラリの有理係数多項式を自前で展開し、16恒等式と改変拒否を確認する。
黄金比型への帰着にGroebner基底の出力を信頼する必要はない。
鋭さの2例はPythonと独立C++で候補9円・6円すべてを整数演算し、Pを通る円がそれぞれちょうど4本と確認する。
各線6点以上の一般化、一点三円上界、任意三平行線ゲームの16候補十分性は本定理には含めない。

## 帰結：各線2〜5点の最大数の完全表

各線の指定点数の上限をnB,nCとすると、線外一点を共有する上記円の最大数は次の通り。
指定点をちょうどその数に限定しても同じ値であり、全例を整数座標で実現できる。

|nB＼nC|2|3|4|5|
|---|---:|---:|---:|---:|
|2|1|1|1|1|
|3|1|1|2|2|
|4|1|2|2|3|
|5|1|2|3|4|

k本の円の各線上での接続は2k個。
2k=nq+r、0≤r<nと書くと、n点への配分による共有円対数の最小値は

`m(n,k)=(n−r)q(q−1)/2+r*q(q+1)/2`。

二円は二線合計で高々1点しか共有できないので
`m(nB,k)+m(nC,k)≤k(k−1)/2` が必要。
表の各上限より1本多いkをこの式に入れると、(5,5)以外はすべて矛盾となる。
(5,5)のk=5だけは等号のため、本文の五円代数排除を使う。
さらに多い本数があるならそのk本だけを取り出せるので、これで上界を尽くす。

下界は第5節の一つの整数5点×5点例の部分集合だけで全16欄を実現する。
`verify.py` はその676個の部分集合対をすべて整数計算し、各サイズの最大と達成する座標をreceiptに保存する。
この有限計算は下界の明示例の確認であり、任意実数配置に対する上界は上の数学的証明である。
