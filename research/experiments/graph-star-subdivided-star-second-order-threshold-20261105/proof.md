# 一辺細分星：奇数次数の負値臨界値の二次漸近項（2026-11-05）

## 定理（全称解析的漸近証明）

整数 r=q−3≥2 に対する既存の奇数次数負値閾値 κ₋(r) について、s=r+1、a=1+1/s と置くと

```
κ₋(r) log(a) = 2 log r + log log r + O(1)  (r→∞).
```

したがって

```
κ₋(r) = 2(r+1)log r + (r+1)log log r + O(r).
```

既存の先頭係数2の定理を二次項まで強める。標準格子盤ではなく、K0648のグラフ型構成に関する結果である。

## 証明

F_{k,r}(y)=r-y-(a-y)y^k とする。負値が起きるのは 1<y<a に限られる（既存の一般臨界次数の証明）。この区間では r-a<r-y<r-1。正の関数 H_k(y)=(a-y)y^k の最大値は、微分により y*=ka/(k+1) において

```
H_k^* = a^{k+1} k^k/(k+1)^{k+1}.
```

ただし y*>1 は k>s に対して成立する。したがって k>s の場合、

* H_k^*≤r-a なら F は負値を取らない。
* H_k^*>r-1 なら y* で F<0。

さらに k>s の範囲で H_k^* は k に対して厳密増加する。これは y*>1 であり、同じ y* を k+2 に代入すると H_{k+2}(y*)>H_k(y*) となるためである。

k が r log r の定数倍であるとき、厳密な式から一様に

```
log H_k^* = (k+1)log a - log(k+1) + k log(1-1/(k+1))
          = k log a - log k - 1 + O(1/s+1/k).
```

ここで k=(2 log r+log log r+C)/log a を考える。log a=1/s+O(s⁻²) より

```
log k = log r + log log r + log 2 + o(1),
log H_k^* = log r + C - log 2 - 1 + o(1).
```

ゆえに C を十分大きな正定数に取れば H_k^*>r-1、十分小さな負定数に取れば H_k^*<r-a となる。整数の奇数次数への丸めは高々2で、k log a の誤差は o(1)。H_k^* の単調性を用いて初めて負値を取る奇数 k を上下から挟める。よって

```
κ₋(r)log a=2log r+log log r+O(1).
```

最後に 1/log(1+1/s)=s+O(1) を代入する。証明終。

## 証拠境界

- 無限個の整数 r に対する全称的な漸近定理であり、有限実験からの外挿ではない。
