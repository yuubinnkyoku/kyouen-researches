# 2×k×m・4点共面禁止版：全正整数の空盤と全初手を分類

2026-10-24。盤は {0,1}×{0,…,k−1}×{0,…,m−1}（k,m≥1）。任意の共面四石を禁止し、通常Grundyを g、終局値1からmexを計算するmisère補助値を h とする。以下の表で「初手後」は、盤の任意の一石局面の (g,h) を指す。

| 条件 | (g,h)(空盤) | 初手後の (g,h) |
|---|---|---|
| (k,m)=(1,1) | (0,1) | 全2点で (1,0) |
| min(k,m)=1、max(k,m)≥2 | (1,0) | 全2km点で (0,1) |
| (k,m)=(2,2) | (0,0) | 全8点で (2,1) |
| min(k,m)=2、max(k,m)≥3 | (1,0) | 全2km点で (0,1) |
| (k,m)=(3,3) | (1,0) | 8点 (0,1)、2点 (2,1)、8点 (3,1) |
| k,m≥3、(k,m)≠(3,3) | (0,1) | 全2km点で (1,0) |

3×3断面の8点 (0,1) は各層の四隅、2点 (2,1) は各層の中央、8点 (3,1) は各層の辺中央。座標軸の交換で k,m の順序は無関係。

## 全称証明（既存無界定理＋独立した有限完全列挙）

1. min(k,m)=1：全点が一平面上にある。安全集合は石数 L=min(3,2km) 以下の全部で、g(S)=(L−|S|) mod 2、h(S)=1−g(S)。空盤・初手後の式が直ちに従う。
2. min(k,m)=2、max(k,m)≥3：K0527の無界・全局面定理により g(S)=(5−|S|) mod 2、h(S)=1−g(S)。断面2×2の例外は2×2×2の全159安全局面の完全列挙（K0526と本実験の二方式）で (g,h)(空)=(0,0)、全8初手後=(2,1)。
3. k,m≥3、k+m≥10：K0530の無界・全局面定理により、空盤=(0,1)、一石局面=(1,0)。これは任意の初手についての数学的全称証明。
4. k,m≥3、k+m≤9：軸交換を除くと 3×3、3×4、3×5、3×6、4×4、4×5 の6盤だけ。下記の二方式で安全集合を漏れなく列挙し、全合法手のmexを逆順に計算して表を確定。したがって有限境界も厳密であり、無界への外挿は行わない。

これで全正整数 k,m を尽くす。通常版の先手勝ちは min(k,m)=1<max(k,m)、min(k,m)=2<max(k,m)、または (3,3) に限る。misère版の先手勝ちは (1,1)、または k,m≥3 かつ (k,m)≠(3,3) に限る。2×2×2では両ルールとも後手勝ち。

## 独立検算

- direction_audit.cpp：各層内の2点組の原始方向を使い、共線三石・両層の平行線分を排除して全安全局面を生成。2層にまたがる共面4点は、3+1型なら層内共線三石、2+2型なら平行な二線分であることを使用。
- determinant_audit.cpp：各新規点と既存三点の整数行列式を直接計算し、添字昇順で安全局面を生成。方向の正規化や前者の幾何分解を使わない。
- 両方式とも全合法子の値から通常mexを計算し、終局のみ1を基底とするmisère mexも独立に計算する。2×2、3×3、3×4、3×5、4×4、3×6、4×5の7盤で全安全局面数・空盤・初手値の分布が完全一致した。前者は薄い1×t、2×tの追加標本も検算。

再現：
```sh
g++ -O3 -std=c++17 direction_audit.cpp -o /tmp/kyouen-direction
/tmp/kyouen-direction
g++ -O3 -std=c++17 determinant_audit.cpp -o /tmp/kyouen-determinant
/tmp/kyouen-determinant
```
