# 一辺細分星 q=21〜23 の奇数次数実根切替（2026-11-05）

## 定理（全称解析＋厳密整数比）

一辺細分星の終局長差多項式
`T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}`
において、`r=q-3`、奇数 `k>=3` とする。

| q | 実根なし（奇数 k） | 相異なる負の単実根がちょうど2個（奇数 k） |
|---|---|---|
| 21 | 3<=k<=173 | k>=175 |
| 22 | 3<=k<=185 | k>=187 |
| 23 | 3<=k<=197 | k>=199 |

さらに各行の「実根なし」は、その行の q 以上の**任意の整数 q** に対しても成立する。

## 証明

`a=(r+2)/(r+1)`、`u=-(r+1)y` とおく。既存の符号解析（q=20 の証明を参照）により、実根は負であり、候補は `1<y<a` のみ。その区間で根の方程式は
`F_{k,r}(y)=r-y-(a-y)y^k=0`。
`H_k(y)=(a-y)y^k` の `[1,a]` 上の最大点は `y_k=ka/(k+1)`（以下の k では `1<y_k<a`）。

各 q に対し、表の非存在側の最大奇数次数 `k_-` について
`H_{k_-}(y_{k_-})<r-a`
を厳密な有理数比較で確認した。したがって `[1,a]` 全域で `F_{k_-,r}>0`。固定 `y>1` に対する `y^k` の単調性から、すべての奇数 `3<=k<=k_-` に実根はない。

存在側の最小奇数次数 `k_+=k_-+2` について
`F_{k_+,r}(y_{k_+})<0`
を厳密な有理数比較で確認した。一方、`F(1)=r-1-1/(r+1)>0`、`F(a)=r-a>0`。中間値定理で少なくとも2個の異なる負根を得る。奇数 k の `T_{k,r}(-x)` の非零係数の符号変化は2回なので、デカルトの符号法則により負根は重複度込みで高々2個。ゆえに両根は単根で、他の実根はない。固定 `y_{k_+}>1` で `F_{k,r}` は k とともに減少するので、すべての奇数 `k>=k_+` に拡張できる。

固定 `y>1` に対して `F_{k,r}(y)` は r に関して狭義増加（導関数 `1+y^k/(r+1)^2>0`）。また r が増えると候補区間 `(1,a)` は縮む。よって各非存在結果は q 以上の全整数 q に拡張される。

## 再現（Python 3、浮動小数点不使用）

```python
from fractions import Fraction as Q
for q, km, kp in [(21,173,175), (22,185,187), (23,197,199)]:
    r = q - 3
    a = Q(r+2, r+1)
    ym = a * km / (km+1)
    yp = a * kp / (kp+1)
    assert 1 < ym < a and 1 < yp < a
    assert (a-ym)*ym**km < r-a
    assert r-yp-(a-yp)*yp**kp < 0
```

6個の有理数不等式は整数演算で検査済み。有限点の標本検査ではなく、最大値の解析と単調性による全称証明である。
