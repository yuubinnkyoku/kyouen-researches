# 標準11×11・四つの7石WIN局面と6石WINの独立終局証明

2026-10-20。q=4・完全指摘・通常プレイ。WIN/LOSSは元の先手固定視点。

直前の `research/log/2026-10-20-n11-s8-lift238.md` に記録された「S6の49個のS7子のうち45 LOSS、残り4 UNKNOWN」は誤り。残り4件は **2026-10-15の `all_s7_win_17.txt` に既にWINとして収録済み** で、当時の `s6_rank_51571.tsv` にも `49 45 4 0` (total,LOSS,WIN,UNKNOWN) と明記されていた。従ってS6は既知証拠を正しく合成するだけでも元先手WINであり、今回新しく4局面を解いたわけではない。

本パッケージは、この4件のS7 WINを**既存cacheなし**で再証明したもの。独立C++直接終局探索と、Pythonの禁止部分集合による別実装が、証明に必要な全2670個の相異なるS10 WIN葉について勝敗・合法手数・探索状態数で一致した（状態数計569,993）。4件のS7に対する全165個のS8応手辺（相異なる159局面）を網羅し、各S8 WINに一つのS9 WINを指定、129個の相異なるS9 WINに対する全S10子辺を列挙して検証した。

4つのS7 WINのいずれかが、S6 `00000000041000001000401000100000` の合法子なので、このS6はWIN。S6をLOSSとする証明の候補に採用してはいけない。四つのS7 WINは旧17件の再認定・証拠強化であり、新規クラス数は0。二石rootの新規閉鎖なし、空盤はUNKNOWN。

`bash reproduce.sh` でC++をコンパイル・再実行し、証明書JSONを再構成してバイト比較したうえで、Pythonが幾何・全子境界・2670終局葉を独立検証する。Pythonの並列度は`WORKERS=4`を既定とする。`SHA256SUMS` は全固定ファイルのハッシュ一覧。C++で試行したが証明書に採用しなかったS10局面は、独立検証済みとは主張しない。

負例検査はS7応手欠落、S9終局子欠落、違法S8→S9辺、S10探索状態数の改変を拒否する。`s7_win_17_snapshot.txt` はrepo mainの既知一覧を照合用に保存したもので、新規証明の前提としては使用しない。
