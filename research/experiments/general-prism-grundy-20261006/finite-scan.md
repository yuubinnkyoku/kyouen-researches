# 任意次元平行列容量ゲームの有限 Grundy 探索

2026-10-06。K0352 の「余剰列数が奇数ならどこかで Grundy >=2」という境界の先を調べた高速レーン有限実験。

## 対象

K0352 の占有数ゲームだけを直接列挙した。パラメータは

- 3 <= w <= 9
- 2 <= h=d-1 < w
- h <= r=q-1 <= 12
- 1 <= m <= 8

で、降順占有ベクトル
`m >= x_1 >= ... >= x_w >= 0`
のうち
`x_1+...+x_h <= r`
を全て調べた。同じ占有数の列は交換可能なので、合法手は一成分を1増やして再ソートした状態への遷移として計算した。

2016 個のパラメータ組、合計 298643 個の降順安全占有状態を完全列挙した。

## 結果

この有限範囲では全局面で

```
0 <= g <= 3
```

であり、Grundy 4 以上は一件も無かった。最大値3は実際に出現する。

追加の範囲外 spot check
`(w,h,r,m)=(10,5,20,12),(9,8,20,12),(12,6,18,10),(8,3,20,15)`
でも最大値はそれぞれ 3,3,1,3 だった。

## 証拠水準

これは有限完全列挙＋追加 spot check であり、**任意パラメータで g<=3 という全称定理ではない**。
K0345 の三次元奇数列で現れた最大 Grundy 3 が、K0352 の任意次元容量ゲームにも残る可能性を強く示すが、現時点では予想に留める。

次の高情報価値課題は、降順状態からの子局面の Grundy 集合が {0,1,2,3} の4値全てを同時に含めないことを、交換可能列と上位h成分容量だけから示せるかどうかである。
