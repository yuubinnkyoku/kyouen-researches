# ひまわり型 r 容量制約：終局長の等差数列と奇数 r の強解決

## 全称定理

有限集合を互いに素な H, P_1,...,P_r, Z に分割する。|H|=c、|P_i|=x_i、|Z|=z、r≥2、1≤p_i≤x_i とする。安全集合 S は全 i について |S∩(H∪P_i)|≤p_i を満たすものとする。J=min(c,p_1,...,p_r) とおく。

**定理 A**：極大安全集合の石数別母関数は

```
P(u) = Σ_{j=0}^J C(c,j) (∏_{i=1}^r C(x_i,p_i-j)) u^{z+Σ_i p_i-(r-1)j}.
```

従って終局石数は正確に z+Σp_i-(r-1)j（0≤j≤J）であり、最小極大石数 s=z+Σp_i-(r-1)J、最大安全石数 K=z+Σp_i、s と K の間の欠番数は (r-2)J。全合法着手履歴数は Σ_k [u^k]P(u)·k!。

**定理 B**：r が奇数なら、任意の安全局面 S の通常Grundy値 g と終局値を1とする misère 補助mex値 h は

```
g(S) = (z+Σ_i p_i-|S|) mod 2,    h(S) = 1-g(S).
```

### 証明

極大集合では Z は全点占有される。j=|S∩H| とすると、各 P_i の占有数 a_i は a_i≤p_i-j。もし a_i<p_i-j なら、x_i≥p_i により P_i に未占有点があり、それを合法追加できる。よって極大なら a_i=p_i-j が全 i で成立する。逆にこれらが成立すれば全制約が飽和し、Z に空きがないため極大である。可能な j は0からJまで全てであり、各場合の選択数は C(c,j)∏C(x_i,p_i-j)。これで定理Aを得る。

r が奇数なら r-1 は偶数で、全極大集合の石数は L=z+Σp_i と同じ偶奇を持つ。任意の安全 S からの全終局までの残り着手数は L-|S| と同じ偶奇。ゲーム木の高さに関する帰納法により、全ての子が残り着手数の反対偶奇を持つので通常 mex はその偶奇を返す。終局値1の misère 補助mexも同様に反転する。よって定理B。

## 二制約連続性の鋭さ

r=2 なら公差1で、K0588の終局長連続性と整合する。しかし r=3、c=t、x_i=p_i=t とすると

```
P(u) = Σ_{j=0}^t C(t,j)^4 u^{3t-2j}.
```

終局長は t,t+2,...,3t だけで、欠番が **t 個** ある。三つの容量制約だけで、欠番数は無界になる。これは抽象的容量制約の主張であり、任意 t の三円による平面実現は主張しない（異なる平面円・直線の交点数は高々2）。

## 平面の整数11点・q=4での実現

次の11点を添字順に置く。

```
0 ( 0, 0)  1 ( 2, 0)
2 ( 6,-6)  3 (-4,-6)  4 ( 6,-4)
5 ( 2,-6)  6 ( 4,-2)  7 (-2,-4)
8 ( 3, 3)  9 (-1, 1) 10 ( 0, 4)
```

三つの円は

- x²+y²−2x+10y=0（添字0,1,2,3,4）
- x²+y²−2x+6y=0（添字0,1,5,6,7）
- x²+y²−2x−4y=0（添字0,1,8,9,10）

である。11点の全 C(11,4)=330 四点組について整数4×4行列式 det[(x²+y²,x,y,1)] を置換24通りの符号付き和で計算すると、ゼロになるのは三円の各5点から選ぶ C(5,4) 組、合計15組だけである。共線4点も同じ判定に含まれる。従って q=4 の禁止条件はちょうどこの三つの5点集合の容量3制約である。

r=3、c=2、x_i=p_i=3、z=0 を代入すると

```
P(u) = 27u^5 + 54u^7 + u^9.
```

**終局長は5・7・9のみで、6・8は欠番**。s=5、K=9。通常 g(S)=(9-|S|) mod 2、misère h(S)=1-g(S) であり、空盤(g,h)=(1,0)。11初手は全て通常版で勝ち手、misère版では負け手。

## 独立検査と限界

`verify.py` は二〜四制約の2016構成について、全ビット集合の点別追加判定から極大配置数を直接列挙し、母関数と照合する。平面例では全330四点組の整数行列式、全2048部分集合、全1262安全局面の通常・misère再帰mexを検査する。結果：

```
PASS abstract=2016 cases; planar forbidden4=15; safe=1262; maximal=82; g(empty)=1, h(empty)=0
```

全称性は上の数学的証明に基づき、有限列挙は独立監査。平面11点の幾何同値は330組の**有限完全列挙**による。標準11×11格子とは異なる11点の整数配置であり、11×11の空盤勝敗は導かない。11×11残局へ使う場合は、残余禁止条件がこの容量制約だけであることを別途確認する必要がある。
