# seven-row-upper-bound-tail-analysis-20261115

K0342 型 tail 評価（K0332 が (5,7) の上界 200→158 に使った同和弦 energy + Melchior 反転）
が 7行族の K0318 上界 U_{7,5..8}=1142/862/708/651 を改善できるかの事前評価。
結論: **ほとんど改善しない（q5 −2・q6 −9・q7/q8 ±0）。q≥7 では LP 構造により
y-cap に完全不感性。** 上界改善の本命は三つ組予算 Q 自体の削減。
本実験は知識昇格しない（本 README は一次資料・現在知識の正本は knowledge）。

## 再現（scripts/lp_analysis.ts・純TS整数演算）

K0318 予算 LP `H=max{2x+y : d0x+d1y<=Q, y<=Y}`（d0=C(r,3), d1=C(r-1,3),
Q=C(6r,3)-6C(r,3), N=6r）の整数最適値を w=7・q=5..8 で総当たりで再現:
H=1138/857/702/644 → **U=1142/862/708/651・公開上界と全件一致**（較正）。
対照: (5,7) で K0332 の Melchior per-s cap 22・E_6=29・Y_pair=135 を再現。

## Melchior 反転 y-cap（有効だが LP でほぼ消える）

種類1円（対象行の石 s を通る blocker 円）は s 中心の反転でちょうど r-1 点の
直線に写る。Melchior の一般式（K0107 と同一・K0332 §3 と同じ導出）より
per-s cap は floor((C(6r,2)-3)/(C(r-1,2)+(r-1)-3)) = **91/61/52/47**
（q=5/6/7/8・K0318 旧 cap 92/72/63/57 から改善・(5,7) では 22 を再現）。
行間点対 cap floor(P/e)=120/93/67/61 と併用して Y=273/244/260/282。
LP 反映後の U は **1140/853/708/651**。

## LP 構造による q≥7 の不感性（本分析の主結果）

d1/d0=(r-3)/r は r≥6 で ≥1/2。このとき d0(2x+y)/2 ≤ d0x+d1y ≤ Q より
H ≤ 2Q/d0 が常に成立し、q=7・q=8 では 2Q/d0=702/644 がちょうど整数で
y=0 で達成される。よって **y-cap を 0 まで縮めても U_{7,7}=708・U_{7,8}=651
は 1 も動かない**。y-cap 系の改良（Melchior・点対・その他）は q≥7 で原理的に
無価値であることが確定した。

## 同和弦 energy 事象は w=7 では非束縛

K0332 の成功の本質は w=5 では blocker 円の外部石プロファイルが
2+2+2（種類0）・2+2+1（種類1）に**強制**され、全円が ≥1 の弦事象を消費する
点にあった。w=7・6外部行では 0 事象プロファイル（2石行 k2≤1）が常に可能:
- q=5/6/7: 種類0 (2,1,1,...)/(1,1,...)・種類1 (2,1,...)/(1,1,...) は k2≤1。
- q=8: 種類0 は鳩の巣で 2石行を持ち、mod9（下記）により 6外部行全占有不可 →
  プロファイルは (2,2,2,1)/(2,2,1,1,1) のみで k2≥2（最小1事象）。しかし
  事象総予算 15·E_7=705 ≫ 三つ組上限 322 で束縛しない。種類1 (2,1,1,1,1) は0事象。

行対事象予算は 15·E_r = 120/240/435/705（E_r は K0342 の鋭い energy
8/16/29/47・等差数列で鋭い）。

## K0072 mod9 の 7行版（再利用可能な構造事実）

K0072（5行すべてに格子点を持ち 2点行を持つ円は不可能）は 7行盤では
「7行すべてに格子点」条件にそのまま適用できる（y=0..6 ⊇ y=0..4・円の方程式
x²+y²+Bx+Cy+D=0 の正規化と 81 組 (C mod9, N mod9) 検査は行数に依存しない）。帰結:
- 種類1 blocker 円（対象行に空点 p と石 s の 2点 → 2点行）は 6外部行の
  ≥1 行を格子点レベルで完全に回避する（外部石の行占有 ≤5 行）。
- 2石行を持つ種類0円は 6外部行を格子点で全占有できない（p∈L と合わせ7行）。
- q=8 では r=7 > 6 = 外部行数 なので非水平直線 blocker は存在しない
  （各外部行 ≤1点・計 ≤6 < r=7）。よって q=8 の種類0 blocker はすべて円。

## 次の候補（Q 削減・未実施）

上界を動かすには三つ組予算 Q の削減しかない。具体候補: 3つの外部石が定める円が
7行すべてに格子点を持ち 2点行を持つなら、mod9 によりその三つ組を含む blocker 円は
存在しない → そのような三つ組を利用可能予算から除外できる。除外個数の
全称下界（adversary の石配置での最小化問題）は未実施・次課題。
y-cap・弦事象系の評価は本分析で閉じた。
