# 一辺細分星：奇数 k≥11・q=5 は実根2個、k=11,13・q≥6 は実根0個（2026-11-05）

## 対象と結論（全称証明）

既存の一辺細分星の終局長差多項式
```
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}, r=q-3
```
について、奇数 k≥11、r=2（q=5）なら実根は**ちょうど2個**（ともに負の単根）。また k∈{11,13}、整数 r≥3（q≥6）なら**実根0個**。これは標準格子盤の勝敗についての主張ではない。

## 共通の実根上界

奇数 k に対して T の正の実根はない。u=-x, x>0 とすると、T(-x) は x の降冪順に符号が +,--,+ であり、デカルトの符号法則により正の x の根は重複度込みで高々2個。従って負の u の根は高々2個。

y=x/(r+1)、a=(r+2)/(r+1) とすると
```
T(-x)/(r+1)^{k+1}=F_{k,r}(y)=y^k(y-a)+r-y.
```

## r=2、奇数 k≥11：実根ちょうど2個

a=4/3。y=0 では F=2>0、y=a では F=2-a=2/3>0。一方 y=6/5 において
```
F_{k,2}(6/5)=4/5-(2/15)(6/5)^k
             ≤4/5-(2/15)(6/5)^11 < 0.
```
最後の不等式は (6/5)^11>6 と同値で、6^11=362797056 > 6·5^11=292968750 から整数演算で従う。中間値の定理により (0,6/5) と (6/5,4/3) に各1根。デカルトの上界2と合わせてちょうど2根、しかも両方単根。□

## r≥3、k=11,13：実根なし

a≤5/4、r-a≥7/4、かつ a<r。0<y<a で y^k(a-y) の最大値は
```
k^k a^{k+1}/(k+1)^{k+1} ≤ a^{k+1}/(k+1)
 ≤ (5/4)^{k+1}/(k+1) < 7/4 ≤ r-y.
```
最後の厳密不等式は k=11,13 のそれぞれについて整数演算で確かめられる（下記検算）。従って F>0。a≤y≤r では2項とも非負で同時に零にはならない。y>r では y>r≥3>1、y-a>y-r なので y^k(y-a)>y-r、従って F>0。y=0 と u≥0 も明らかに正。□

## 独立の整数検算

```python
assert 6**11 > 6*5**11
for k in (11,13):
    assert 5**(k+1) < 7*(k+1)*4**k
```

この結果は既存の k≤9 の分類とは異なる領域を扱う。特に q=5 で k=9 は実根0個だったが k≥11 の奇数では実根2個へ切り替わる。q≥6 の k≥15 の分類は本証明からは従わない。
