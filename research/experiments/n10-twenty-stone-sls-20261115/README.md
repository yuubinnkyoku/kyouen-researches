# 10×10 20石安全集合の確率的局所探索 (SLS) — K0141 の未実施 next-step 実行 (2026-11-15 高速レーン・sandbox)

## 位置づけ

`K_10 ∈ [19,23]` (K0035・K0141)。K0141 の next steps に明記された
「stochastic local search」は本実験まで未実施だった
(round57 の半径8削除探索は決定的局所探索であり別物)。
本記録は 2026-11-15 16:05Z の実行環境停止 (bash・file_system 停止・GitHub API のみ生存) 中に
Vibe TS sandbox (run_typescript) で実行した SLS 一式である。
SAT/カット攻撃 (n10-twenty-stone-sat-20261115・ge20_cuts) と直交し、
証人を発見すれば即 `K_10 ≥ 20` が確定する位置づけの補完ルートだった。

## 手法

- 禁止4点組の列挙: C(100,4)=3,921,225 を整数判定
  (4×4行列式 |x²+y², x, y, 1| の差分3×3展開・三つ組ごとにdetの一次式を前計算。
  全係数 |Δ|≤162 で double 演算でも厳密)。
- エネルギー E(S) = S に含まれる禁止4点組の個数 (E=0 が安全20石)。
- 増分機構: 違反組リスト (O(1) 追加/削除) と、全空セルの追加コスト addcost[] の増分維持。
  1 move ≈ 2×~2,178 反復で「全80空セルからの堅密最良追加」が評価できる。
- move: 違反組のメンバー (85%) またはランダム石 (15%) を除去し、
  最良空セル (greedy) またはランダム空セル (noise) を追加。
  受容は WalkSAT (常に受容) と Metropolis (アニーリング) の2方式を使い分けた。
- E≤8 では違反組全メンバー×全空セルの最良 swap を全走査し、停滞時に kick (2-4 swap)。
- E=1 到達時: 単一 swap 修復の全走査 (4メンバー×80空セル)。
  修復不能なら有界 2-swap escape (第1 swap は新規違反 ce≤1 の候補のみ・
  第2 swap は greedy 全走査、元設定へ復帰)。
- 決定的 PRNG (mulberry32) と自前の反復単位 (units) 予算により、
  sandbox のプロセス安全deadline 下でも決定的に打ち切れる。
  全 run が PRNG seed から bit 再現可能 (sandbox の record/replay 機構と独立)。
- 証人 (E=0) を発見した場合は第2経路 (4×4行列式の独立展開) での全 C(20,4) 検証を
  同一 call 内で実行する設計 (今回は不発動)。

## 結果と限界

- **証人 (E=0 の20点集合) は不獲得**。`K_10 ∈ [19,23]` は不変。
  本記録は有界な負の証拠であり `K_10 ≤ 19` を意味しない。
  SLS の規模 (~3.5×10^5 move) は先行 B&B (243M節点) より小さい。
- **E=1 近接配置の catalog は U のみ**: 全 run を通じて E=1 を観測した20点集合は
  published の U ただ一つだった (U basin 外では E=1 に到達しなかった)。
  X2 の U 的役割を果たしうる第2の近接配置 (新しい cut 族候補) は
  この規模では見つからなかった。
- **U basin の堀 (ヒューリスティック観察・全称主張なし)**: U からの 2-6 swap
  摂動に対するアニーリングは E≈5-8 で停滞し、サンプル点 (16-1024 move間隔) で
  E≤2 に戻る頻度が低かった。X2「|S∩U|≥10 で安全集合なし」と整合する局所構造。

## sandbox 運用の記録 (他レーンへの留意点)

- sandbox の `Math.random()`/`Date.now()` は呼び出しごとに操作予算 (1,024回) を消費し、
  `Date.now()` は replay で凍結値を返す。**決定的 PRNG の自前実装と
  move/units 数による自己予算管理が必須**。時間ベースの打ち切りは sandbox では機能しない。
- プロセンス安全deadline (分数程度) を超えると結果が没収される。
  units 予算を段階的に較定し、本レーンでは 5×10^8 units/call で安定動作した。
- 全 run が決定的 (PRNG seed 固定) であるため、seed を記録する限り
  第三者が bit 一致で再現できる (生成物は output/sls_runs_20261115.json)。
