# \(t=2,\ q=6\) 純ファイバーゲームの全局面Grundy分類

## 設定

有限集合 \(B\)、高さ集合 \(A\) を取り、\(w=|B|\ge2,\ m=|A|\ge2\) とする。底面跡制約は置かず、各ファイバー上で零多項式にならない \(z\) 次数2以下の多項式超曲面による6点共存を禁止する。

K0832の厳密占有縮約により、安全条件は
\[
C(c):=\sum_{b\in B}\min(c_b,2)\le5
\]
であり、着手は一成分を1増やす操作と一致する。以下、占有数の正の部分を降順に並べた多重集合を \((\cdots)\) と書く。

## 定理

幅2では容量制約は自動的に満たされ、二つの独立な長さ \(m\) の鎖の直和になる。幅3では全終局が \((m,m,1)\) である。さらに \(m\) が偶数なら、幅 \(w\ge3\) の全終局の石数は奇数である。従って
\[
G(S)=
\begin{cases}
|S|\bmod2,&w=2,\\
(|S|+1)\bmod2,&w=3\text{ または }m\text{ 偶数}.
\end{cases}
\]

残る \(w\ge4,\ m\) 奇数の場合も、全安全局面を次の表で完全分類できる。ここでは \(a\ge b\) とする。

| 占有数の形 | Grundy値 |
|---|---:|
| \(()\) | \(1\) |
| \((a)\) | \((m-a)\bmod2\) |
| \((1,1)\), \(w=4\) | \(2\) |
| \((a,b)\ne(1,1)\) | \((a+b+1)\bmod2\) |
| \((1,1,1)\), \(w=4\) | \(1\) |
| \((1,1,1)\), \(w\ge5\) | \(0\) |
| \((a,1,1)\), \(a\ge2\) | \(2+((m-a)\bmod2)\) |
| \((a,b,1)\), \(a\ge b\ge2\) | \((a+b)\bmod2\) |
| \((1,1,1,1)\), \(w=4\) | \(0\) |
| \((1,1,1,1)\), \(w\ge5\) | \(2\) |
| \((a,1,1,1)\), \(a\ge2\) | \((a+1)\bmod2\) |
| \((1,1,1,1,1)\), \(w\ge5\) | \(0\) |

この表は \(m\ge3\) の奇数についてのもの。容量5以下の安全局面には、これ以外の占有型は存在しない。

従って最大Grundy値は
\[
\max_{S\text{ safe}}G(S)=
\begin{cases}
1,&w=2,\\
1,&w=3,\\
1,&w\ge4,\ m\text{ 偶数},\\
3,&w\ge4,\ m\text{ 奇数}.
\end{cases}
\]
特に \(t=2,q=6\) でGrundy値3が現れる最小の幅・高さは \(w=4,m=3\) である。

## 証明

### 終局の石数が同じ場合

有限通常プレイゲームで、ある局面から到達できる全ての終局の石数が同じ偶奇 \(\varepsilon\) を持つなら、
\[
G(S)=(\varepsilon-|S|)\bmod2
\]
である。終局からの帰納法で、全ての子局面のGrundy値が同じ0または1になり、その mex は反対の値になる。

幅2では各列が独立な鎖なので、
\[
G(S)=((m-c_1)\bmod2)\oplus((m-c_2)\bmod2)
=|S|\bmod2.
\]

幅 \(w\ge3\) の終局では、容量が5未満なら空列を開始するか、占有数1の列を2へ進めるか、占有数2以上かつ未満杯の列を進められる。従って終局では容量が5で、各占有数は \(0,1,m\) のいずれかである。幅3なら唯一の形は \((m,m,1)\) で石数 \(2m+1\) は奇数。幅 \(w\ge3\) かつ \(m\) 偶数なら、可能な終局型は
\[
(m,m,1),\quad(m,1,1,1),\quad(1,1,1,1,1)
\]
のうち幅に収まるものだけであり、石数はそれぞれ \(2m+1,m+3,5\)。全て奇数である。

### \(w\ge4,\ m\) 奇数の場合

容量条件 \(C(c)\le5\) から、安全な正占有多重集合は空、単独列 \((a)\)、二列 \((a,b)\)、三列 \((a,1,1)\) または \((a,b,1)\)（後者は \(a,b\ge2\)）、四列 \((a,1,1,1)\)、五列 \((1,1,1,1,1)\) に限られる。

まず \((a,b,1)\), \(a\ge b\ge2\) は容量5を使い切り、二つの飽和列だけを進められる。終局 \((m,m,1)\) の値は0で、後ろ向きに
\[
G(a,b,1)=(a+b)\bmod2.
\]
同様に \((a,1,1,1)\), \(a\ge2\) は残る一列だけの鎖なので
\[
G(a,1,1,1)=(a+1)\bmod2.
\]

\((a,1,1)\), \(a\ge2\) からは、(i) \(a\) を増やす、(ii) 単独列を2にして \((a,2,1)\) へ移る、(iii) 第四列を開始して \((a,1,1,1)\) へ移る、の三種がある。(ii),(iii) の子の値は \((a+2)\bmod2\) と \((a+1)\bmod2\) で0と1を一つずつ含む。(i) があるときの値は2または3の一方であり、これを加えた mex は
\[
G(a,1,1)=2+((m-a)\bmod2).
\]
\(a=m\) の場合も (ii),(iii) の値が0と1なので mex は2となり、同じ式が成立する。

三単独列 \((1,1,1)\) では、列を2へ進める子 \((2,1,1)\) の値は3。幅4なら第四列を開始した \((1,1,1,1)\) の値は0、幅5以上なら値は2である。従って三単独列の値は幅4で1、幅5以上で0。四単独列からは \((2,1,1,1)\) へ進める。幅4ではそれだけなので mex は0、幅5以上では五単独列（終局値0）にも進めるので mex は2。五単独列は終局で値0。

二列 \((a,b)\) について、\(b\ge2\) なら、既存列を増やす手と第三列を開始する手 \((a,b,1)\) の子は全て \((a+b)\bmod2\) であり、mex は \((a+b+1)\bmod2\)。\(b=1,a\ge2\) なら、既存列を増やす子は \((a+3)\bmod2\)、第三列を開始する子 \((a,1,1)\) は2または3である。mex は \((a+2)\bmod2\)。最後に \((1,1)\) では、列を2へ進める子は0、第三列開始の子は幅4で1・幅5以上で0なので、mex は幅4で2、幅5以上で1となる。

単独列 \((a)\), \(a\ge2\) からは同じ列を増やす手と第二列開始の手だけがあり、両方の子の値は \(a\bmod2\)。従って mex は \((m-a)\bmod2\)。\((1)\) の子は \((2)\)（値1）と \((1,1)\)（値2または1）なので mex は0。空局面の唯一の子型は \((1)\) で値0だから、空局面の値は1。以上で全安全型を覆った。∎

## 最小のGrundy値3の局面

\[
w=4,\quad m=3,\quad c=(2,1,1,0)
\]
を取る。合法な子は
\[
(3,1,1,0),\quad(2,2,1,0),\quad(2,1,1,1)
\]
であり、閉形式から値はそれぞれ \(2,0,1\)。従って
\[
G(2,1,1,0)=\operatorname{mex}\{0,1,2\}=3.
\]
幅3以下では終局石数の偶奇が固定され、\(m\) 偶数でも全終局の石数が奇数なので、Grundy値3は現れない。よって幅・高さとも最小の証人である。

## 独立した有限監査

再帰 mex を二つの表現で独立に計算した。

- 正占有数を降順に並べた多重集合：\(2\le w\le12,\ 2\le m\le20\)、209組・36,860状態。
- 幅 \(w\) のラベル付き占有ベクトル：\(2\le w\le8,\ 2\le m\le9\)、56組・137,004状態。

両方式とも閉形式との不一致は0件。多重集合のGrundy値分布は \(0:18,070,\ 1:17,899,\ 2:486,\ 3:405\)、ラベル付きでは \(0:65,962,\ 1:63,018,\ 2:4,274,\ 3:3,750\)。状態数も独立の組合せ式と一致した。監査集計と検証器のSHA-256は output/audit.json に記録した。

有限監査は上の全称証明の代替ではない。対象は底面跡制約のない抽象ファイバーゲームであり、標準二次元の3×m・q=6ゲームを解決したものではない。
