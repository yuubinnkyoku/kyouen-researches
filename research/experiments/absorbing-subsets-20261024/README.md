# 小さい吸収集合の勝敗判定と多項式持ち上げゲーム

2026-10-24。全称証明は[proof.md](proof.md)。現在の知識の正本はK0537・K0538。
共通占有集合へ一点ずつ追加し、q点禁止集合の完成を避ける通常プレイを扱う。

## 吸収集合の全称戦略

Tを含むすべてのq点集合が禁止されるとき、Tをここでは吸収集合と呼ぶ。
盤点数N≥q−1なら、Tの完成後の終局は厳密にq−1石。

- q=2rなら、r点以下の吸収集合が一つあれば先手必勝。先手は遅くとも2|T|−1手で完成できる。
- q=2r+1なら、各点を含むr+1点以下の吸収集合があれば後手必勝。
  後手は初手点を含む集合を選び、遅くとも2(|T|−1)手で完成できる。

このサイズ条件は両方とも鋭い。
q+1点のV=A⊔Fで禁止族を `{V\{f}:f∈F}` とすると、
偶数qで|A|=r+1,|F|=rなら一つ大きい吸収集合があっても後手勝ち。
奇数qで|A|=|F|=r+1なら、一つ大きい吸収集合の族が全点を覆っていても先手勝ちとなる。
どちらも全qに対する構成的証明であり、小さい有限例からの推測ではない。

この判定が保証するのは勝敗であり、空盤Grundy値の具体値ではない。
実際、有限監査の偶数qの正例は空盤値2だった。

## 多項式行列式版への応用

d≥3、q=d+2点の `det[x^d,x^(d−1),...,x,y,1]=0` を禁止する有限平面点盤で、
同じx座標の三点は行列の階数から吸収集合になる。
N≥d+1のもとで、偶数d≥4は同列三点が一組あれば先手勝ち、
奇数d≥3は全点が三点以上の列に属せば後手勝ち。
全列三点以上なら、偶数dでは全初手が勝ち手、奇数dでは全初手が負け手となる。
任意の列位置・高さ間隔で成立し、長盤への安定化条件を必要としない。

これは退化も禁止する行列式版であり、厳密な関数グラフ上のq点だけを禁止する版とは別。
d=2には三点完成の手数が間に合わないため適用できない。

## 有限独立監査

[verify.py](verify.py)はq=2,...,12の正例・鋭さ反例、計22族・32,637安全局面について、
全subset DPと独立残余禁止集合mexの個別値を完全照合する。
吸収条件そのものも全q点集合を使って検査する。

[polynomial.py](polynomial.py)は9盤・14,089安全局面で同じ二方式の個別値を照合。
全9,187個のq点組の行列式を、整数Bareiss法と独立有理数消去法で一致させた。
適用条件内の7盤は全て理論の勝敗・初手条件と一致。
条件外のd=2盤と、初手点を覆えない奇数d盤も区別して保存した。

```sh
uv run --locked python research/experiments/absorbing-subsets-20261024/verify.py
uv run --locked python research/experiments/absorbing-subsets-20261024/polynomial.py
```

[results.json](results.json)は抽象ゲーム、[polynomial.json](polynomial.json)は幾何ゲームの全監査結果。
Python標準ライブラリだけで再現できる。全称性は手順と階数の証明による。
