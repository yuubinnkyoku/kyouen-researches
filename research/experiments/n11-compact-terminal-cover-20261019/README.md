# 11×11：18個の8石LOSSを184葉で共同証明（圧縮・選択的検証）

標準q=4、完全指摘、通常プレイ。勝敗は元先手固定視点。**空盤勝敗はUNKNOWN**。新たな二石root閉鎖はない。

2026-10-19の既存18根・184葉の証明を、終局検証の対象を厳密に減らして再構成した。18根の合法9石子は387個、全合法10石境界は3,044個。

- 9石義務に重み0・1/2・1を与える。10石境界のうち重み和が1を超える672局面についてだけ、合法な11石勝ち手とその後の終局再帰により**WIN**を独立検証した。
- 残り2,372局面は、勝敗を計算しなくても重み和が1以下。半重み義務の同時被覆グラフを、この2,372局面**すべて**から作ると、連結成分は13・19・46・125頂点。重み1の義務81個と合わせ、必要な10石LOSS葉は少なくとも `81+7+10+23+63=184` 個。
- 184個の選択済み10石LOSS葉を終局まで独立再計算し、全387義務を被覆した。従って**全合法10石境界に対して184葉が大域最小**（10石への一手応手形式に限定）。
- 選択する184葉を費用（終局再帰のメモ化状態数）で再最適化し、17,797 → **15,290状態**（**14.09%減**）。70葉を交換した。SciPy/HiGHS整数計画で費用最適15,290（上下界一致）を確認したが、**費用最適性の独立証明は付属しない**。184という葉数の最小性は整数計画器に依存しない。
- 終局計算を要する10石局面は従来の3,044件から**856件**（672件のWIN排除証人＋184件のLOSS葉）へ削減、**71.88%減**。単体Python検証は手元で22.38秒（1プロセス）。WIN証人の11石以降の再帰は18,295状態、LOSS葉は15,290状態。

`compact_proof184.py` は18根、184葉、双対重み、672個のWIN証人を圧縮内蔵し、標準ライブラリのみで全合法境界の独立再列挙、証明書の完全性、184葉の最小性、必要な856件の終局検証を行う。外部勝敗表・最適化器は不要。
