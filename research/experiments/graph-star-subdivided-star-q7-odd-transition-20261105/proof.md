# 一辺細分星：q=7 の奇数 k における実根数の厳密な切替（2026-11-05）

## 結論（数学的全称証明）

既存の一辺細分星の終局多項式
[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1},quad r=q-3
]
について、**q=7 (r=4)、奇数 k≥3** では次が成立する。

* 3≤k≤27：実根は0個。
* k≥29：負の実根がちょうど2個（いずれも単根）。

従って厳密な切替は k=27 と k=29 の間にある。標準格子盤の勝敗に関する結論ではない。

## 証明

奇数 k として u=-(r+1)y と置けば
[
F_{k,r}(y)=T_{k,r}(-(r+1)y)/(r+1)^{k+1}
=y^k(y-a)+r-y,qquad a=1+1/(r+1).
]
正の u に対して T>0。r=4 なら a=6/5 である。

y≥a では F>0：a≤y≤r なら各項非負であり、y>r なら y>1 かつ y-a>y-r より y^k(y-a)>y-r。0≤y<a では
[
F_{k,4}(y)=4-y-y^k(6/5-y).
]
関数 y^k(a-y) の [0,a] における最大値は
[
B_k=rac{k^k}{(k+1)^{k+1}}(6/5)^{k+1}.
]
3≤k≤27 の奇数13個について B_k<14/5=4-a が成り立つ。下記の整数演算で各不等式を独立に検査できる。従ってこの領域では F>0 で実根はない。

一方 y=7/6 において
[
F_{k,4}(7/6)=17/6-(1/30)(7/6)^k.
]
整数不等式 7^{29}>85\cdot6^{29} より F_{29,4}(7/6)<0。7/6>1 なので奇数 k≥29 でも負値である。F(0)=4>0 と F(6/5)=14/5>0 の間に異なる2つの正根が存在する。デカルトの符号法則（F の係数符号 +,-,-,+）により、正根は重複度込み高々2個。従ってこの2根は単根であり、他の実根は存在しない。□

## 厳密整数検算（浮動小数点不使用）

```python
for k in range(3, 28, 2):
    assert 6**(k+1)*k**k < 14*5**k*(k+1)**(k+1), k
assert 7**29 > 85*6**29
```

この有限検算は全称証明のうち13個の整数不等式だけを担う。無限の k≥29 への拡張は y=7/6>1 の単調性による。

## 接続・残件

既存の q=5（k=11 で切替）、q=6（k=21 で切替）に続き、q=7 でも正確な切替を確定した。q≥8 の切替と、q を変数とする一般式は未解決。既存の r 単調性から、q≥7 の奇数 k≤27 に実根がないことも従う。
