## 0. 問題

K0946が予想として残した **PRIME-M**（値1軌跡非空⟹M素数）と **PARITY**
（素数Mのヒットは偶数）を、E状態の追跡構造の完全解明によって**全称証明**する。
副産物としてK0945で「連分数様無限再帰」に見えていた値1判定が
**1段のリレーに崩壊**し、値1軌跡が純算術（約数・spf）に完全還元される。

## 1. 補題RELAY-REDUCE（β≥2のE状態の値α+1判定・全称・紙上証明）

**設定**: E状態E(P;α,β)（β≥2）、k₀=α+β、**T = P(k₀+1)+β**。
監視V=位置α（[P+1]先頭・不変量T）、N₁=位置α+1（不変量T−1）。
**k_T := Tの[2,k₀]内最大約数**（無ければ0）、
**k_{T−1} := T−1の[2,k₀]内最大約数**（無ければ0）、
**P_d := ⌊T/(k_T+1)⌋**、**P′ := P_d + ⌊P_d/k_T⌋ + 1**。

**主張**: **σ_E(P;α,β) = α+1 ⟺ [k_{T−1} < k_T ∧ k_Tが素数 ∧ spf(P′) ≥ k_T]**。

**証明**:

(追跡固定点性) E-form遷移（K0941定理C）のもとで、敗者がVでもN₁でもない
フェーズでは、新状態E(P′′;α′′,β′′)の正規化は追跡対(V,N₁)を
(α′′, α′′+1)に保つ。実際、r<α敗者（[P]ブロック死亡）では新フレームはr+1
始まりで旧α→α−r−1=α′′・旧α+1→α−r=α′′+1。r≥α（r∉{α,α+1}）では
旧i>rは新i−r−1に、旧i<rは旧i+k−1−rに写り、α′′=β+2α−r−1=k₀+α−r−1
に対し旧α→α+k₀−1−r=α′′・旧α+1→α′′+1。よってK0939 END-INVの不変量
保存（V-TRACK・K0948）をN₁に逐語適用でき、**N₁の死亡円サイズは
k | T−1 を満たす最大のk**（位置α+1の石数恒等式N=P(k+1)+β−1は
K0939のV恒等式の1つ隣のperson版で、遷移の局所性により同型に保存される）。

(場合分岐) 円サイズはk₀,k₀−1,…,2と降下し各サイズでちょうど1人死亡する。
gcd(T,T−1)=1よりk_T≠k_{T−1}。

- **k_{T−1} > k_T**: N₁はVより先に（円サイズk_{T−1}で）死亡。この時点で
  状態はE-formのまま（V生存）でN₁の追跡固定点性が有効なのでN₁の死亡は確定。
  σ_E≠α+1。
- **k_{T−1} < k_T**: Vが先に円サイズk_Tで死亡する。死亡フェーズ時点の状態は
  E(P_d; α_c, β_d)（β_d = T mod (k_T+1)・T = P_d(k_T+1)+β_d、
  P_d = ⌊T/(k_T+1)⌋）で、Vは位置α_c、r=P_d mod k_T = α_c（⟺k_T|T）。
  遷移は(P_d+1+q_d, β_d+2α_c−r−1, 0) = (P′, k_T−1, 0)（P′=P_d+1+⌊P_d/k_T⌋）、
  **新状態は一様E(P′; k_T−1, 0)で、新フレームは旧α_c+1始まり、
  N₁はちょうど新位置0（監視）に落ちる**。以降のN₁の生死はU0-CLASSIFY
  （K0948）で完全決定され、**N₁生存 ⟺ k_T素数 ∧ spf(P′) ≥ k_T**
  （n+1=k_T・pot P′）。∎

## 2. 定理VALUE-ONE-CHAR（σ_Z値1のmain regime判定・全称）

**設定**: M≥2, K>M, K=(M+1)s+M+1+κ、κ=K mod (M+1)、s=⌊(K−M−1)/(M+1)⌋。
**main regime**: κ∈[0,M−2] かつ (s,κ)≠(0,0)。
k₀ := M(s+1)+κ−1、Y := (M+1)(s+1)+κ+1、**T = MY**。

**主張**: main regimeで **σ_Z(M,K)=1 ⟺ [k_{T−1}<k_T ∧ k_T素数 ∧ spf(P′)≥k_T]**
（k_T・k_{T−1}・P_d・P′はT=MY・k₀に対する§1の量）。

**証明**: K0946 ONE-CHAR-GENERAL（全称証明済み）よりσ_Z(M,K)=1 ⟺
σ_E(M;κ,M(s+1))=κ+1。tail E(M;κ,M(s+1))の第1フェーズはbump
（q,r=divmod(M,k_t)、k_t=κ+M(s+1)>M=r>κ=α）で遷移
(M+1, M(s+1)+2κ−M−1, M−κ)、すなわち新状態E(M+1; β₁, β)、
β₁=M(s+1)+2κ−M−1・β=M−κ≥2（⟺κ≤M−2・main regimeの正体）。
値1候補（tail位置κ+1）は新位置β₁+1（旧κ+1≤M−1<r=Mなのでwrap写像
κ+1+k_t−1−r=2κ+M(s+1)−M=β₁+1）に落ち、追跡固定点性より以後の正規化でも
位置α′+1を保つ。σ_tail=κ+1 ⟺ σ_E(M+1;β₁,β)=β₁+1 ⟺ RELAY-REDUCEを
E(M+1;β₁,β)に適用。この状態のTは
T=(M+1)(k₀+1)+(M−κ)=M((M+1)(s+1)+κ+1)=MY（k₀=β₁+β）で**
§1の設定と一致する**。∎

**特殊ケースK=M+1（s=κ=0）**: tail E(M;0,M)の第1フェーズは
q,r=divmod(M,M)=(1,0)で敗者=位置0、新状態E(M+2;M−1,0)（一様）に
値1候補（旧位置1）が位置0として落ちる。よって
**σ_Z(M,M+1)=1 ⟺ σ_E(M+2;M−1,0)=0 ⟺ M素数 ∧ spf(M+2)≥M**（U0-CLASSIFY）。
（K0946のEXCL-2（κ=M−1）とK0948のEXCL-1（κ=M）で他の剰余は除外済み。）

## 3. 補題P′-SIMPLIFY（main regimeのP′の閉形式・全称）

**主張**: main regimeで素数k_T>Mなら、Y″:=Y/k_T（整数）として
**(i) Y″≥2, (ii) MY″≤k₀, (iii) P′ = M·Y″**（β_d:=T mod (k_T+1)≠0）。
k_T=M（このとき(M+1)∤Y）なら **P′ = Y**。

**証明**: k_T>M素数ならk_T∤M（Mの素因数≤M<k_T）なのでk_T|Y、T=M·k_T·Y″。

(i) Y″=1ならY=k_T=(M+1)(s+1)+κ+1≤k₀=M(s+1)+κ−1で(s+1)≤−2が矛盾。
(ii) Y″≤Y/(M+1)=(s+1)+(κ+1)/(M+1)<s+2なので整数でY″≤s+1。
κ≥1ならMY″≤M(s+1)≤k₀。κ=0（このときs≥1）でY″=s+1なら
Y=k_T(s+1)より(k_T−M−1)(s+1)=1、すなわちs=0で矛盾。ゆえY″≤sで
MY″≤Ms≤Ms+M−1=k₀。
(iii) P′=⌊(T−β_d)/k_T⌋+1=⌊(T+k_T−β_d)/k_T⌋
=M·Y″+1−⌈β_d/k_T⌉。β_d∈[0,k_T]なのでβ_d≥1ならP′=MY″。
β_d=0とすると(k_T+1)|T=k_T·MY″より(k_T+1)|MY″、よってMY″≥k_T+1。
しかしMY″はTの約数で(ii)よりMY″∈[2,k₀]なので、k_TがTの[2,k₀]内
最大約数であることからMY″≤k_T。矛盾。ゆえβ_d≥1でP′=MY″。∎
（証明の中核: **β_d=0は約数の大きさ関係で不可能**。）

k_T=Mのときも同様にP′=⌊(T+M−β_d)/M⌋=Y+1−⌈β_d/M⌉で、
β_d=T mod (M+1)=MY mod (M+1)≡−Y (mod M+1)なのでβ_d=0 ⟺ (M+1)|Y。
main regimeではY=(M+1)(s+1)+κ+1・κ+1∈[1,M−1]なので(M+1)∤Y、ゆえβ_d≥1でP′=Y。∎

## 4. 定理HIT-KT-EQ-M（ヒットはk_T=Mに限る・全称）

**主張**: main regimeでσ_Z(M,K)=1なら **k_T=M**（したがってMは素数）。

**証明**: main regimeではM|T=MYかつ2≤M≤k₀（k₀−M=Ms+κ≥1）なのでk_T≥M。
素数k_T>Mと仮定するとP′-SIMPLIFYよりP′=M·Y″で
**spf(P′)=min(spf(M),spf(Y″))≤spf(M)≤M<k_T**、ゆえRELAY条件の
spf節が必ず不成立でヒットしない。ゆえヒットはk_T=Mのみ、
このときRELAY条件の素数節からM素数。∎

## 5. 定理PRIME-M（K0946予想の全称証明）

**主張**: M≥2, K>M, σ_Z(M,K)=1 ⟹ **Mは素数**。

**証明（組立）**: K>Mを剰余で場合分け。
- K=M+1: §2特殊ケースよりM素数が必要。
- κ=M−1: K0946系EXCL-2（全称証明済み）でσ_Z≠1。
- κ=M: K0946系EXCL-1帰着+K0948系U0-NEVER（全称）でσ_Z≠1。
- κ∈[0,M−2]（main regime）: VALUE-ONE-CHAR+HIT-KT-EQ-MよりM素数が必要。∎

**系（死後frame位置の必要条件の全称化）**: K0941定理Bの死後状態
Z(w+1, n−t)について、n−t>w+1ならσ_Z(w+1,n−t)=1は
n−t≢w,w+1 (mod w+2)（K0946証明済み）に加えて**w+1合成なら成立しない**
（K0946ではPRIME-M経由の予想だった）。

**系SIMPLE-CHAR（値1軌跡の最終形）**: main regimeで
**σ_Z(M,K)=1 ⟺ M素数 ∧ k_T=M ∧ k_{T−1}<M ∧ spf(Y)≥M**。
（k_T=M ⟺ MがT=MYの[2,k₀]内最大約数、k_{T−1}<M ⟺ MY−1に[2,k₀]内
約数がなければM未満、spf節はP′=Y（§3）。全条件がM・Y・
その約数のみの純算術。）特殊ケースK=M+1はM素数∧spf(M+2)≥M。

## 6. 定理PARITY（K0946予想の全称証明）

**主張**: 素数M≥3なら値1ヒットKは全て偶数。M=2の奇数ヒットはK=3のみ。

**証明**: M≥3素数（奇数）でM+1は偶数、K=(M+1)s+M+1+κ≡κ (mod 2)。
- K=M+1は偶数。
- κ=M−1, κ=Mは除外済み（M−1は偶数だがEXCL-2、κ=Mは奇数でEXCL-1）。
- main regimeでκが奇数ならY=(M+1)(s+1)+κ+1=偶+偶=偶、
  よってspf(Y)=2<MでSIMPLE-CHARのspf節が不成立。ゆえκ偶、K偶。
M=2: main regimeはκ=0のみでK=3(s+1)・s≥1。SIMPLE-CHARのspf節は
常に成立（spf(Y)≥2）、ヒットにはk_T=2が必要。K奇 ⟺ s偶とすると
s≥2偶のとき(3s+4)/2は6s+8=2(3s+4)=4·((3s+4)/2)の約数で
(3s+4)/2≥5・(3s+4)/2≤2s+1（s≥2）なのでk_T≥(3s+4)/2>2で不成立。
s=0はK=3で§2特殊ケース（2素数∧spf(4)=2≥2）の唯一の奇数ヒット。∎

## 8. 発見の経緯とK0945との対比

- K0945レジュームで「tail→bump→E(M+1;·,·)連分数様再帰」と見えていた
  値1判定は、本項の追跡固定点性+リレー分析により**1段のbump+1段の
  リレー（V死亡→一様化→U0-CLASSIFY）で閉じる**ことが判明した。
- 決定的な観察は P′ = ⌊(T+k_T−β_d)/k_T⌋ の閉形式評価で、main regimeでは
  P′ = M·(Y/k_T) または Y に坍縮し、spf節が spf(M) または spf(Y) の
  純算術判定になること。合成Mの「障壁」の正体は
  **spf(P′)≤spf(M)<k_T** の自動失敗だった（K0946次課題2の解決）。
