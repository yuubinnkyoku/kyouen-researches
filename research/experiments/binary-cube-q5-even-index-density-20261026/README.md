# 5点超平面切片の偶数周期短縮倍率：12合同類と素数密度1/16

2026-10-26。二値超立方体の5点超平面切片数 `E_{d,5}` を対象とする。最新main（2d391ff）、AGENTS.md、knowledge/README.md、未解決一覧とK0567を確認。既存の1億未満の周期調査とは別に、全素数に適用できる合同類定理を証明し、既存度数表を独立監査した。標準平面共円ゲームの空盤勝敗についての主張ではない。

## 全称定理

素数 `p>32` について、`E_{d,5} mod p` の最小周期を `L_p`、短縮倍率を `I_p=(p-1)/L_p` とする。K0567の既証明定理から

```
L_p = lcm(ord_p(2), ord_p(3), ord_p(5), ord_p(7))
```

である。次の4条件は同値である。

1. `I_p` は偶数。
2. `L_p | (p-1)/2`。
3. 2,3,5,7がすべて法pの平方剰余である。
4. `p mod 840` は次の12類のいずれか：

```
1, 121, 169, 289, 311, 361, 479, 529, 551, 671, 719, 839
```

**証明。** 最初の2条件は`I_p=(p-1)/L_p`から同値。2番目は4底それぞれについて `a^((p-1)/2)≡1 (mod p)` と同値であり、Eulerの判定法から3番目と同値。平方剰余相互法則により、p>7について

- `(2/p)=1` ⇔ `p mod 8 ∈ {1,7}`。
- `(3/p)=1` ⇔ `p mod 12 ∈ {1,11}`。
- `(5/p)=1` ⇔ `p mod 5 ∈ {1,4}`。
- `(7/p)=(p/7)(-1)^((p-1)/2)`。ここで `(p/7)=1` ⇔ `p mod 7 ∈ {1,2,4}`。

法8,12,5,7の最小公倍数は840。これらを`gcd(r,840)=1`の全192剰余類に適用すると、許される類は上記12個ちょうどである。□

**無限個存在・密度。** 12類はいずれも840と互いに素なので、Dirichletの算術級数定理から各類に素数が無限個存在する。さらに算術級数の素数定理により、素数全体のうち短縮倍率が偶数であるものの自然密度は厳密に

```
12 / φ(840) = 12 / 192 = 1/16
```

となる。補集合（短縮倍率が奇数）の密度は15/16。これは有限計算の外挿ではなく、既存の周期定理と既知の数論定理からの**無条件の数学的結論**。奇数の短縮倍率にも3以上があり得るので、「短周期素数全体の密度が1/16」とは主張しない。

## 独立した有限監査

`verify.py` は既存の周期度数表を入力せず、奇数篩で素数を列挙して12剰余類を直接数える。100万未満では、合同類・Euler判定・4底の共通位数の直接短縮を全件照合する。

| 範囲 | 対象素数数 | 偶数短縮倍率の素数数 |
| --- | ---: | ---: |
| 32<p<10^6 | 78,487 | 4,831 |
| 32<p<10^8 | 5,761,444 | **359,464** |

後者は既存の`binary-cube-q5-period-index-100m-20261026/output.txt`の短縮倍率度数表で偶数倍率を合計した359,464と一致した。独立した素数合同類計数による監査である。1億未満の件数は有限完全計算、密度1/16は無界の数学的定理と区別する。

```sh
python3 verify.py 1000000
python3 verify.py 100000000
```

両実行で`PASS`を確認。標準ライブラリのみ、整数演算のみ、最大約50MBの篩を使用。

## 限界

短縮倍率の2での可除性を完全分類するが、奇数因子・4以上の2冪の分布や4底同時Wieferich素数の存在は未解決。素数p<=32にはこの4生成元周期定理を適用しない。
