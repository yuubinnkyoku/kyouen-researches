# PG(2,7) と AG(2,7) のキャップ・ゲーム（v=57, 49）完全解（宣言・2026-11-25）

## 目的

第8ラウンドで K1298 の parity 特性定理から「`PG(2,7)` の s=2 ゲームは
極大アークが 6 と 8（両方偶数）なので Grundy は {0,1}」と予測した。
これを完全計算で確かめ、あわせて `AG(2,7)` のキャップ・ゲームも解く。

## 手法

- エンジン: 既存 `grundy_full.c`（s=3 固定）を **s 可変**にしたコピー
  `scripts/grundy_s.c`（ブロックが s 点に達したら残りを禁止、以外は同一）。
  64-bit マスクで n≤64。usage: `grundy_s board.txt s`。
- 盤: `projective-blocking-kyouen-20261125/output/board_pg2q7.txt`（PG(2,7), v=57）と
  `s-parameter-kyouen-20261125/output/board_ag2q7.txt`（AG(2,7), v=49、PG 盤から導出）。
- キャップ数は独立に Python DFS でも数え、一致を確認。
  PG(2,7): 2,446,460、AG(2,7): 1,108,724。

## 結果

### PG(2,7), s=2

- 安全局面 2,446,460（サイズ 0..8）。
- 極大: サイズ **6: 625,632**、**8: 16,758**（円錐曲線）。中間サイズなし。
- 極大サイズは両方偶数 → K1298 の定理より Grundy は {0,1} と予測。
- 完全 Grundy: `0: 1,347,823 / 1: 1,098,637`（＝偶数/奇数サイズの数）。
  `G(∅)=0`、misère=1。予測どおり **graded**。

### AG(2,7), s=2

- 安全局面 1,108,724（サイズ 0..8）。
- 極大: サイズ **6: 271,656**、**7: 2,352**、**8: 6,174**。パリティ混在。
- 完全 Grundy: `0: 581,827 / 1: 477,505 / 2: 49,392`。`G(∅)=0`、misère=1。
- パリティ混在のため Grundy 2 が出現（定理の予測どおり）。

## 意義

- v=57 / 49 の盤を完全解。キャップ・ゲームの完全 Grundy は
  PG(2,7) で 2.45M、AG(2,7) で 1.11M 局面。
- 予測（PG(2,7) は {0,1}）が完全計算で確認された。
- 同じ q=7 でも PG はパリティ一様（6,8）で {0,1}、AG は 7 を含み混在で 2 が出現。
  盤の違いがそのままゲームの複雑さになる。
