# PG(2,7)・AG(2,7) のキャップ・ゲーム完全解

実験ディレクトリ: `research/experiments/pg2q7-cap-game-20261125/`（2026-11-25）

## 0. 要旨

s=2（キャップ・ゲーム）を q=7 の射影・アフィン平面で完全に解いた。

| board | v | safe | 極大サイズ（個数） | パリティ | G(∅) | misère | Grundy 分布 |
|---|---:|---:|---|---|---:|---:|---|
| PG(2,7) s2 | 57 | 2,446,460 | 6 (625,632), 8 (16,758) | 偶数一様 | 0 | 1 | 0:1,347,823, 1:1,098,637 |
| AG(2,7) s2 | 49 | 1,108,724 | 6 (271,656), 7 (2,352), 8 (6,174) | 混在 | 0 | 1 | 0:581,827, 1:477,505, 2:49,392 |

- `PG(2,7)`: 極大アークは 6 と 8 のみ（両方偶数）で**パリティ一様**（サイズは 2 種類、
  graded ではない）、Grundy は偶数/奇数サイズの数に一致。第8ラウンドの予測
  「PG(2,7) の s=2 は {0,1}」が完全計算で確認された。
- `AG(2,7)`: 完全 7-キャップが 2,352 個あり**パリティ混在**。
  定理の予測どおり Grundy 2 が 49,392 局面に出現。
- 同じ q=7 でも PG と AG で複雑さが分かれる（アフィン盤はパリティ混在）。

## 1. エンジン

既存の `grundy_full.c`（s=3 固定）を s 可変にしたコピー
（`scripts/grundy_s.c`）。変更点は

```c
if (++cnt[c] == s_cap) { ... }          // 追加時
if (cnt[c] == s_cap) { ... }            // 削除時
if (__builtin_popcountll(mask & cmask[c]) >= s_cap) illegal |= cmask[c];
```

と `s` をコマンドライン引数で受ける点のみ。64-bit マスクで n≤64。

## 2. 検証

- キャップ数は Python DFS の独立カウント（PG: 2,446,460、AG: 1,108,724）と一致。
- 極大カウント・Grundy 分布はエンジン出力。PG はパリティ一様のため分布が
  偶数/奇数サイズの数に一致することを確認。
- 独立検証（別実装、76 チェック全 PASS）: 盤の公理、2 実装による集合列挙の
  チェックサム一致、2 種の極大性判定、C(__int128)/Python の全数 DP 一致、
  30 局面/盤の再帰照合を確認。PG は全 2,446,460 局面で `G(S)=|S| mod 2`（不一致 0）、
  AG は Grundy 2 の 49,392 局面がすべてサイズ 5 であることを確認。
  数値の不一致なし（`independent/REPORT.md`, `independent/comparison.json`）。

## 3. 限界

- s=2 のみ（s=3 は PG(2,7) では局面数が大きすぎる）。
- PG(2,8)（v=65）は 64-bit マスクを超える（128-bit 版が必要）。
