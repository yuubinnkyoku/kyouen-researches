# Witt 設計 W_24 の s-スペクトル（宣言・2026-11-25）

## 目的

5-(24,8,1) 設計 W_24（759 個の octad）上の共演ゲーム「各ブロックと高々 s 点」を
s=2..7 で完全に解き、極大安全集合の構造と Grundy 分布を求める。
K1298 の parity 特性定理（Grundy `{0,1}` ⟺ 極大サイズのパリティ一様）の
設計盤での系統的な検証になる。

## 手法

- s 可変エンジン `grundy_s.c`（`pg2q7-cap-game-20261125/scripts/`、旧 `grundy_full.c` の
  s パラメータ化。64-bit マスク、n≤64）で全安全局面を列挙し、サイズ降順 DP。
- 出力は `design-kyouen-witt-20261125/output/grundy_w24_s{2..7}.txt`。
- 構造の同定は `scripts/summarize_spectrum.py`（octad の 6-部分集合、
  octad 対の対称差による dodecad 生成、極大性検査）。

## 構造

- **s=2,3,4**: 任意の (s+1)-点集合はある octad に含まれる（W_24 は 5-設計で
  λ_3, λ_4, λ_5 > 0）ため、極大安全集合はちょうど **すべての s-点集合**
  （276 / 2,024 / 10,626）。
- **s=5**: 極大安全集合は **どの octad にも含まれない 6-点集合**
  （`C(24,6) − 759·C(8,6) = 134,596 − 21,252 = 113,344`）。
- **s=6**: 極大安全集合はちょうど **2,576 個の dodecad**（Golay 符号の重み 12 の語）。
  octad 対（交差 2）の対称差として生成し、全 2,576 個が s=6 で安全かつ極大である
  ことを確認。dodecad はすべての octad と偶数個（≥2）で交わる。
- **s=7**: 極大安全集合は octad を含まない 12-点集合（1,020,096）と 13-点集合
  （30,912）。12 と 13 でパリティ混在 → 定理より Grundy 2 が出現（2,606,912 局面）。
- **s=8**: 全集合が安全（自明）。

## 意義

- parity 特性定理の予測（混在は s=7 のみ、そこだけ Grundy 2）が完全に一致。
- 共演ゲームの極大集合として **dodecad（Golay 符号の重み 12 語）** が現れる
  という新しい設計論的・符号理論的リンク。

## 検証

- 独立実装 2 系統（Python / C）で s=2..7 の全データを一致確認（5/5 PASS、不一致 0）。
- s=6 は C(24,12)=2,704,156 個の全 12-点集合を走査し、極大＝dodecad 2,576 個を完全に確定。
- s=7 も 7,932,035 局面を 2 実装で一致確認。s=8 は解析的（全集合、K=24）。
