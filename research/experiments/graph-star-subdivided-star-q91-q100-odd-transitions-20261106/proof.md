## 全称証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) と置く。負根の方程式は
\(F(y)=r-y-(a-y)y^k=0\) である。\(0<y\le1\) では
\(F(y)\ge r-y-(a-y)=r-a>0\)。
\(y\ge a\) では \(F(y)=r-y+(y-a)y^k>0\)：
\(a\le y\le r\) は明らかで、\(y>r\) では
\((y-a)y^k>(y-a)y>y-r\)（\(r\ge88\)）。
したがって根候補は \(1<y<a\) のみ。

\(H(y)=(a-y)y^k\) の最大点は \(y_*=ka/(k+1)\)。
非存在境界 \(k_-\) で \(H(y_*)<r-a\) を示せば \(F>0\)。
存在境界 \(k_+\) で \(F(y_*)<0\) を示せば
\(F(1),F(a)>0\) なので少なくとも2個の負根がある。
\(T(-x)\) の符号変化は2回だからデカルトの符号法則で負根は重複度込み高々2個。ゆえに2個は単根。
正の実根は係数がすべて正なので存在しない。

\(1<y<a\) では \(k\) が増すほど \(F\) は厳密減少する。
従って境界の間に奇数がないことから全奇数次数へ拡張できる。
さらに \(r\) を増すと \(r-y\) が増加し \(a-y\) が減少するため、各非存在結論は同じ \(k\) に対する任意の \(q'\ge q\) にも成立する。

## 厳密整数検査

\(A=k(r+2)\)、\(B=(k+1)(r+1)\) とすると \(y_*=A/B\)。
非存在側の十分条件は
\((r^2-2)(k+1)B^k>(r+2)A^k\)。
存在側の必要十分条件 \(F(y_*)<0\) は
\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)。
次のコードは各境界の20個の不等式を整数のみで検査する。

```python
bounds = [[91,1117],[92,1133],[93,1147],[94,1161],[95,1177],[96,1191],[97,1205],[98,1221],[99,1235],[100,1251]]
for q, kp in bounds:
    r = q - 3
    for k, existence in ((kp-2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if existence:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
        else:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
print("20 exact inequalities passed")
```
