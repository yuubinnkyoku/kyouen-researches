# 11×11：条件付き14根の24子以上9石候補を選択して終局証明（2026-10-28）

標準q=4、完全指摘、通常プレイ。**11×11空盤UNKNOWN**。

既存のn22（890類）、n23-priority（256類）、n23-remaining（157類）の固定証明書から、証明限定8石WIN **5,292類**、保存14根の未証明8石子 **126類／126辺**を再構築した。上流の勝敗証明書は専用CIで別途終局再検証する。本実験の候補選択は上流の証人バイト列のSHA-256と順序ハッシュを検査するが、上流の終局再帰を本実験内では再実行しない。

未証明8石子に接続し、既存9石証明と重複しない**24子以上の9石候補2,039類**を抽出。未証明8石子への接続数を優先し、子数と重複被覆を抑える貪欲選択で32類を固定した。選択した32類が接続する未証明8石子は67類。ただしこれは**勝敗を無視した潜在的な接続**であり、証明済み被覆ではない。
