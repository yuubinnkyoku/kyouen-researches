# 四つの共円四点禁則だけでGrundy値5を実現する6×6内の11点配置

2026-10-18。対象は**任意に選んだ有限整数点集合を盤とする**完全指摘・通常プレイであり、6×6の36点全体を盤とする標準ゲームの空盤値を主張しない。

## 主結果

整数格子の `0<=x,y<=5` に含まれる次の11点集合を盤とする。

```
(0,0), (0,4), (1,1), (1,3), (3,1), (3,2),
(3,4), (4,1), (4,5), (5,0), (5,2)
```

相異なる4点が同一直線または同一円に載るときに限り、その4点を禁止集合とする。この盤の禁止四点組は**ちょうど次の4組**であり、4組はいずれも真の円上の4点（共線ではない）である。

```
E0 = {(0,0),(0,4),(1,1),(1,3)}
E1 = {(0,0),(1,1),(4,1),(5,0)}
E2 = {(3,1),(3,4),(4,1),(5,2)}
E3 = {(3,2),(3,4),(4,1),(4,5)}
```

空盤のGrundy値は `g(empty)=5`。全 `2^11=2048` 部分集合のうち安全なのは **1635** 個で、Grundy値0,1,2,3,4,5の安全局面数は順に

```
585, 586, 224, 230, 9, 1
```

である。5となるのは空盤のみ。上の11点と4禁則は有限の**厳密な実現証人**であり、近似円判定や乱数による推測ではない。

## 点数と包含正方形の最小性（限定された量化）

**任意の有限盤で、禁止集合が高々4個かつ各4点なら、空盤のGrundy値5を実現するには少なくとも11点必要である。** 4禁則の所属型 `t=1,...,15` の点数を `c_t` とし、

```
sum(c_t for t if t & (1<<j)) == 4   (j=0,1,2,3)
```

を満たす非負整数ベクトルを全列挙すると4079種類になる。禁則に含まれない自由点はGrundy値とのxor偶奇しか変えない。4禁則を重複させた場合も含め、自由点なし・点数10以下の全型では空盤値は4以下、11点で5が実現する。3禁則以下の場合は重複して4本に拡張できるため同じ下界が成り立つ。Pythonの頂点bit集合DPと独立C++の所属型残点数DPが一致した。これは任意有限盤の全称命題を**有限型へ帰着して完全列挙した証明**である。

さらに、**11点かつ禁止四点組が高々4個という条件の下では、それらを含む軸平行整数正方形の最小辺長（格子点数）は6**である。5×5の25点から11点を選ぶ全 `C(25,11)=4,457,400` 通りを調べると、禁止四点組の最小個数は **5**（達成する11点集合は8通りで、正方形の二面体対称群D4のちょうど1軌道）である。よって5×5に4禁則以下の11点盤は存在しない。一方、上の6×6内の証人が上界を達成する。

この「6が最小」は**11点・禁止四点組4個以下**という限定付きであり、5個以上の禁止集合を許す任意の11点ゲームのGrundy値については何も主張しない。

## 独立検証の仕組み

- `verify_geometry.py`: 3点を通る円の整数係数を解き、3点共線の場合は直線判定に分岐する。11点の全330四点組を検査し、メモ化した安全局面のmex再帰を実行。5×5では、増加順の点追加に際して新しく完成する禁則を数え、5本目が生じた枝だけを打ち切る。11点まで達する候補は0個。探索訪問数は414881状態。
- `verify_independent.cpp`: 異なる実装として、4点の `[x²+y²,x,y,1]` 行列式を直接計算する。11点の全2048状態を降順の密配列DPで解く。5×5は枝刈りなしで全4457400通りを列挙し、826個の禁止四点組の包含数を直接集計。最小5、達成8通り。
- `verify_abstract.py` と `verify_abstract_independent.cpp`: 4禁則の4079所属型を頂点bit集合方式と残点数方式で独立に全列挙。両方で10点以下に空盤Grundy値5がないことを確認。

実行例:

```sh
python research/experiments/geometric-four-q4-grundy-five-20261018/verify_geometry.py
g++ -O3 -std=c++17 research/experiments/geometric-four-q4-grundy-five-20261018/verify_independent.cpp -o /tmp/q4-geometric-verify
/tmp/q4-geometric-verify
python research/experiments/geometric-four-q4-grundy-five-20261018/verify_abstract.py
```

C++の抽象型検査器は同ディレクトリの `verify_abstract_independent.cpp` を同様にビルドする。JSON結果と標準出力を保存している。

## 適用範囲と残課題

今回の11点盤は6×6標準盤から25点を**取り除いて盤点集合を変更したもの**であり、標準6×6の安全局面で25点が占有済みという意味ではない。標準正方形盤のGrundy値の無界性（K0327）を証明するものでも、11×11探索に直ちに適用できる局面を与えるものでもない。

ただし、抽象的な4禁則での上限5が、共円・共線という整数格子の幾何制約を課しても達成可能だと分かった。次の具体的な問いは、**標準正方形盤の合法な残余局面で、この4禁則型を孤立成分として実現できるか**である。そこは未確認。
