# 単一未飽和ファイバー残余閉形式の全称決定（κ=1）

- 日付: 2026-11-16（高速レーン）
- 対象: 全t純ファイバーゲーム最大値定理（K0832・Theorem T）の残余mex H(R;X;z) のうち、未飽和ファイバーが1本（Xが単一トークン）の場合の完全閉形式
- status: 定理は全称証明済み（本文のRに関する強帰納）。有限監査（V0〜V5+V3b、計8,706,159照合・不一致0・二回実行でbyte-identical）は独立確認であり、全称性は証明による。
- 前提: 残余ゲームの定義・再帰は[全t最大値定理](../vertical-fiber-all-t-grundy-max-20261116/report.md)に従う。

## 概要

残余ゲーム H(R;X;z)（R=残容量、X=未飽和ファイバーの余剰トークンの多重集合、z=レベルM−1の計数）について、|X|=1の場合の値 v(x,z,R) := H(R;(x);z) を全パラメータ (x≥1, z≥0, R≥0) で閉形式で完全決定した。あわせて

1. **空ファイバー補題**: H(R;();z) = 0（全R, z）。
2. **cap補題**: H(R;X;z) = H(R;cap_{R+1}(X);z)。トークン値 ≥ R+1 はすべて R+1 に置換してよい（一般多重集合Xで成立）。従って各Rで残余状態空間は有限。
3. **U座標の注意**: U := H ⊕ (z mod 2) と再座標化すると、C手のflipが消え、代わりにB手（トークン1除去→z+1）がflipを担う。1トークンを含まないXではUゲームはflipなしになる。
4. **系（H=2の特徴づけ・単一トークン）**: 全t最大値定理が未決定のまま残した「どの(R;X;z)でH=2となるか」の単一トークン切片が完全決定される（下の系1）。
5. **実験的観察**: 全1トークン族 X=(1^k) の偶数zでの「遠方の2」の位置の観察（未証明、有限観察として明記）。

## 設定

残余ゲームの再帰（[全t最大値定理](../vertical-fiber-all-t-grundy-max-20261116/report.md)で確立済み・tとMに非依存）:

- H(0;X;z) = 0。
- R ≥ 1 の着手（各手で R は1減る）:
  - **A手**（x ≥ 2 のトークン）: x → x−1。
  - **B手**（x = 1 のトークン）: トークンを除去し z → z+1。
  - **C手**（z ≥ 1）: z → z−1、値に 1 を XOR。
- H(R;X;z) = mex(子の値集合)。

単一トークン v(x,z,R) の選択肢:
- x ≥ 2: { v(x−1,z,R−1) } ∪ ({ 1⊕v(x,z−1,R−1) } if z ≥ 1)
- x = 1: { H(R−1;();z+1) } ∪ ({ 1⊕v(1,z−1,R−1) } if z ≥ 1) = {0} ∪ …

## 補題1（空ファイバー）

**H(R;();z) = 0（全R ≥ 0, z ≥ 0）。**

証明: Rに関する強帰納。R=0は定義。R ≥ 1: X=()なのでA手・B手は存在せず、z ≥ 1なら唯一の手はC手で値 1⊕H(R−1;();z−1) = 1⊕0 = 1、z=0なら着手なし。いずれもmexは0（mex{1}=0、mex∅=0）。∎

## 補題2（cap補題、一般多重集合）

**cap_c(X) := 各トークンを min(x,c) に置換した多重集合とすると、H(R;X;z) = H(R;cap_{R+1}(X);z)。**

証明: Rに関する強帰納。R=0は自明。R ≥ 1 とし、レベル R−1 で cap 係数 (R−1)+1 = R に対して成り立つとする（IH）。X のトークン x と cap 後の R+1（x ≥ R+2 のとき）を比べる:

- **A手（x ≥ 2）**: 元のXからの子は Y₁ = X−x+(x−1)、cap後からの子は Y₂ = cap_{R+1}(X)−(R+1)+R。x−1 ≥ R+1 ≥ R なので IH（子のレベル R−1 での cap 係数は R）より、Y₁ のトークン x−1 は R に cap でき、cap_R(Y₁) = cap_R(Y₂)。他のトークンも同型。従って子の値は等しい。
- **B手（x = 1）**: R ≥ 1 より cap は 1 に触れない。同一の子。
- **C手**: X は変わらず同一の子。

全選択肢の値集合が一致するので mex も一致する。∎

有限監査 V4: 部分積 ≤ 8・要素数 ≤ 4 の全多重集合 × z ≤ 6 × R ≤ 14 の 51,975状態で H(R;X;z) = H(R;cap_{R+1}(X);z) を直接照合し、違反0。

**系（有限性）**: cap補題より、H(R;·;·) を計算するのに必要な状態は「トークン数 ≤ R、各トークン ≤ R+1、z ≤ R」に制限される。各固定Rに対して残余ゲームは有限状態で完全に決定可能であり、一般Xの閉形式探索の基盤になる。

## 注意（U座標）

U(R;X;z) := H(R;X;z) ⊕ (z mod 2) と置くと、C手の子のU値は
U(R−1;X;z−1) = H(R−1;X;z−1) ⊕ ((z−1) mod 2) = (1⊕H(R−1;X;z−1)) ⊕ (z mod 2)、
すなわち**C手からflipが消える**。代わりにB手の子 (X−1; z+1) のU値は U ⊕ 1 となり、flipはB手に移る。また R=0 の境界値は U(0;X;z) = z mod 2 になる。mexは集合への一様XORと可換なので U も同様の再帰で決まる。**1トークンを含まないXではB手が存在せず、Uゲームはflipなしの純粋なreduce-onlyゲームになる**。単一トークン閉形式の (R+z) mod 2 交互領域はU座標では純R偶奇になる。

## 定理（単一トークン閉形式）

x ≥ 1, z ≥ 0, R ≥ 0, L = x+z+1, q(k) := k以下最大の奇数（oddround）とする。v(x,z,R) = H(R;(x);z) は次で完全決定される。

**ケース1（z = 0）**: v = min(R,x) mod 2。

**ケース2（z = x ≥ 1）**:
- v = 2 ⇔ R 奇数 ∧ R ≤ 2x−1
- v = 0 ⇔ R 偶数 ∧ R ≤ x−1
- それ以外（R偶数 ≥ x、またはR奇数 ≥ 2x+1）: v = x mod 2

**ケース3（1 ≤ z ≤ x−1）**: m = q(z) として
- R 奇数 ∧ R ≤ m → v = 2
- R 偶数 ∧ R ≤ m → v = 0
- m < R < L−1 → v = (R+z) mod 2
- R ≥ L−1 → v = x mod 2

**ケース4（z ≥ x+1）**: m = q(x) として
- R 奇数 ∧ R ≤ m → v = 2
- R 偶数 ∧ R ≤ m → v = 0
- R > m → v = x mod 2

### 系1（単一トークンでのH=2の特徴づけ）

H(R;(x);z) = 2 ⟺ R が奇数 ∧ R ≤ μ(x,z)、ただし
μ(x,z) = 2x−1 (z=x) / q(z) (1≤z≤x−1) / q(x) (z≥x+1)、z=0ではH=2は不成立。
すなわち値2は奇数Rでのみ、z=xのとき最も深く（R=2x−1まで）現れ、z≠xでは min(x,z) 以下の最大奇数まで現れる。

### 系2（構造定理との整合）

- 偶数Rでは常に v ≤ 1、奇数Rでは常に v ≤ 2（Theorem Tと整合）。
- レジーム R ≥ L−1 では v = x mod 2。これは全t最大値定理のレジーム閉形式 H = (L−n) mod 2（n = |X|+z = 1+z、L−n = x）の単一トークン場合の回収である。
- v の値域は {0,1,2} であり、値2は上記の μ 未満の奇数Rに限る。

## 証明

Rに関する強帰納。基底 R=0: 全ケースで v=0（ケース1: min(0,x)%2=0、ケース2: R偶数≤x−1、ケース3/4: R偶数≤m）。帰納段階では子の値はすべて R−1 で既知（A手の子は(x−1,z)、C手の子は(x,z−1)、x=1のB手の子は空ファイバーで補題1より0）。以下、p := x mod 2、q' := q(x−1) と置き、ケースごとに選択肢集合のmexが主張値と一致することを確認する。各々の恒等式は有限ボックス V3（x,z≤40, R≤90; 151,290件）・V3b（x,z≤150, R≤320; 7,296,320件）で全数機械照合済みであり、以下の記述はその無限量化和である。

**ケース1（z=0）**: x=1なら選択肢は {0}（B手）で mex=1 = min(R,1)%2（R ≥ 1）。x ≥ 2 なら唯一の子は (x−1,0,R−1): R ≤ x のとき子の値は R−1 mod 2 で mex = R mod 2、R ≥ x+1 のとき子の値は (x−1) mod 2 で mex = x mod 2 = p。∎（ケース1）

**ケース2（z = x ≥ 1）**: A手の子 (x−1, x, R−1) はケース4（トークンx−1、閾値 q'）、C手の子 (x, x−1, R−1) はケース3（閾値 q'、L'' = 2x）。x=1ならB手が0を供給する。

- **R 奇数 ≤ 2x−1（主張2）**: 子のRは偶数。
  R−1 ≤ q' なら A手の子は偶数Rで閾値以下ゆえ 0、C手の子も 0（C手の値は 1）。mex{0,1} = 2。
  R−1 > q' なら A手の子はケース4の「閾値超え」で (x−1) mod 2 = 1−p、C手の子はケース3の中間帯 (R−1 < L''−1 = 2x−1、R ≤ 2x−1 より成立) で (R−1+x−1) mod 2 = (R+x) mod 2 = 1⊕p ゆえ C手の値は p。mex{1−p, p} = 2（0と1がともに現れる）。x=1のときこの帯はR=1のみで、選択肢 {0(B), 1⊕v(1,0,0)} = {0,1}、mex=2。✓
- **R 偶数 ≤ x−1（主張0）**: R−1 は奇数で R−1 ≤ x−2 ≤ q'（x偶数なら q'=x−1、奇数なら q'=x−2）。A手の子は奇数Rで閾値以下ゆえ 2、C手の値は 3。mex{2,3} = 0。✓
- **それ以外（主張 p）**:
  R 奇数 ≥ 2x+1: A手の子は (x−1)%2 = 1−p、C手の子は L''−1 = 2x−1 ≤ R−1 でレジーム値 p、C手の値 1⊕p = 1−p。mex{1−p} = p。
  R 偶数、x奇数: R ≥ x+1 なら A手の子は奇数Rで閾値 q'=x−2 を超え (x−1)%2 = 0、C手の子は中間帯またはレジームで値 p = 1、C手の値 0。mex{0} = 1 = p。
  R 偶数、x偶数、R = x: A手の子のRは x−1 = q'（奇数、閾値以下）で 2、C手の子も奇数Rで閾値 q' 以下で 2、C手の値 3。mex{2,3} = 0 = p。
  R 偶数、x偶数、R ≥ x+2: A手の子は奇数Rで閾値超え (x−1)%2 = 1、C手の値も 1（子の値 (R+x) mod 2 = 0 またはレジーム値 p = 0）。mex{1} = 0 = p。✓

**ケース3（1 ≤ z ≤ x−1）**: このケースでは x ≥ 2 が保証されB手はない。A手の子は z ≤ x−2 ならケース3（閾値 q(z)、L' = x+z）、z = x−1 ならケース2。C手の子は z=1 ならケース1、z ≥ 2 ならケース3（閾値 q̃ := q(z−1) = q(z)（z偶数）/ q(z)−2（z奇数））。

- **R 奇数 ≤ m（主張2）**: 子のRは偶数。A手の子は（両型とも）偶数Rで閾値以下ゆえ 0。C手の子は z=1 なら R=1 で値 0、z ≥ 2 なら偶数R: q̃ < R−1 のときも子の値は (R−1+z−1) mod 2 = 0（R=m奇数、z奇数のとき q̃ = m−2, R−1 = m−1 = q̃+1 の場合だけだが、このとき q+z は偶奇同族で0になる）。いずれもC手の値は 1。mex{0,1} = 2。✓
- **R 偶数 ≤ m（主張0）**: 子のRは奇数で閾値（A手の子の q または 2x−1、C手の子の q̃）以下。A手の子の値は 2、C手の値は 3。mex{2,3} = 0。✓
- **m < R < L−1（主張 (R+z) mod 2 =: t）**:
  R 奇数: t = 1⊕(z mod 2)。子のRは偶数で q を超える（R ≥ m+2、m奇数）。A手の子は中間帯で (R−1+z) mod 2 = 1−t、z=x−1型の子はレジーム外帯で z mod 2 = 1−t。C手の子は（z=1なら min(R−1,x)%2 = 0、z ≥ 2なら中間帯 (R−1+z−1) mod 2 = t）で C手の値は 1−t。mex{1−t} = t。✓
  R 偶数: t = z mod 2。A手の子は奇数R: R = m+1 のとき閾値以下で 2、それ以外（R ≥ m+2）は中間帯で (R−1+z) mod 2 = 1−t。z=x−1型では子のR = R−1 ≤ 2z−1 = 2x−3（R < L−1 = 2x より）で常に2。C手の値は、R = m+1 ∧ z偶数のとき（子のR = m が q̃ に一致）3、それ以外は 1−t。
  一般の組合せ {1−t, 1−t} は mex = t、特異点 R = m+1 では {2, 3}（z偶数; mex = 0 = t）または {2, 0}（z奇数; mex = 1 = t）、z=x−1型では {2, 1−t}（mex = t）。いずれも主張値 t に一致。✓
- **R ≥ L−1（主張 p）**: A手の子のRは ≥ L−2 = x+z−1 = L'−1（z=x−1型では 2z−1 を超えレジーム）で子の値は (x−1) mod 2 = 1−p。C手の子は z=1 なら min(R−1,x)%2 = p（R−1 ≥ x）、z ≥ 2 なら L''−1 = L−2 ≤ R−1 でレジーム値 p、C手の値は 1⊕p = 1−p。mex{1−p} = p。✓

**ケース4（z ≥ x+1）**: A手の子はケース4（トークンx−1、閾値 q'）。C手の子は z−1 = x ならケース2、z−1 ≥ x+1 ならケース4（閾値 q(x)）。

- **R 奇数 ≤ m = q(x)（主張2）**: 子のRは偶数。A手の子: q = x のとき（x奇数）R−1 ≤ x−1 = q'+1、q = x−1 のとき（x偶数）R−1 ≤ x−2 < q' で、いずれも閾値以下で 0（境界 R = x = m のときも子は奇数... R=x=m 奇数ゆえ x奇数、子のR = x−1 > q' = x−2 でも (x−1)%2 = 0）。C手の子は両型とも偶数Rで閾値（2x−1 または q(x)）以下で 0、C手の値 1。mex{0,1} = 2。x=1ではこの帯は R=1 のみで選択肢 {0(B), 1⊕v(1,z−1,0)} = {0,1}。✓
- **R 偶数 ≤ m（主張0）**: 子のRは奇数で閾値以下。A手の子 2、C手の値 3。x=1ならこの帯は R=0 のみ（基底）。mex{2,3} = 0。✓
- **R > m（主張 p）**:
  R 奇数: A手の子は偶数Rで閾値超え (x−1) mod 2 = 1−p。C手の子（両型とも）は偶数Rで閾値超えで p、C手の値 1⊕p = 1−p。mex{1−p} = p。x=1（p=1）ではR奇数≥3でB手が0を供給し mex{0,0} = 1。✓
  R 偶数: A手の子は奇数R。x偶数で R = x（= q+1）のとき子のR = x−1 = q' で閾値以下、子 2（それ以外は 1−p）。x奇数では R ≥ x+1 > q'+1 で常に 1−p。C手の値は、子のRが奇数で閾値以下の場合（x偶数・R=x、x奇数・R ≤ 2x、x=1・R=2）だけ 3、それ以外は 1−p。組合せは {2,3}（x偶数・R=x: mex = 0 = p）、{1−p, 3}（x奇数・R ≤ 2x: mex{0,3} = 1 = p）、{1−p, 1−p}（一般: mex{1−p} = p）。✓

以上で全ケース・全帯のmexが主張値と一致し、強帰納が完結する。∎

## 実験的観察（未証明・有限観察）

**全1族の「遠方の2」**: X = (1,1,…,1)（k個）、z = 2j、k ≥ 2j+1、R ≤ 60 の範囲で、2を取るRの集合は
{1, 3, …, 2j−1} ∪ {2k−2j+1}
と観察される。すなわち近傍の2は奇数R ≤ 2j−1（単一トークン・ケース3と同じ q(2j) 帯で、(1^k)があたかも「トークン k」のように振る舞う）に現れ、加えて「遠方の2」がちょうど R = 2k−(2j−1) に1点現れる。データ: k ≤ 8, j ≤ 3, R ≤ 60（例: k=8,z=2: {1,15}、k=5,z=4: {1,3,7}、k=7,z=6: {1,3,5,9}）。k ≤ 2j では遠方の2は観察範囲で消えるか位置がずれる（例: k=4,z=6: {1,3,5,7}）。**これは有限観察であり、全称主張ではない。** z=0の全1族（k≥2でR≡1 mod 4の位置に1が立つ周期構造）も観察されたが同様に未証明。

## 11×11レーンへの接続（メモ）

cap補題は探索の枝刈りに使える: 残余評価でトークン値 ≥ R+1 のものは区別不要。単一トークン閉形式は、飽和鎖のXOR x=0・未飽和ファイバー1本という局面（値2の出現が勝敗を左右するクラス）のGrundy値を盤面パラメータなしで即値評価することを可能にする。全t最大値定理のwitness状態が使う残余条件 H(1;X;z)=2 の単一トークン側は、本定理より H(1;(x);z)=2 が z ≥ x+1（または z=x）で常に成立することとして閉形式で確定済みになる。
