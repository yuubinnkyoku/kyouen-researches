## 2. 証明

スコープ: 素数M≥5・main regime・t≥2・kodd=4・a≥1・smoothヒット・γ枝。
（t≥2でk₀ = Mt+κ−1 ≥ 2M−1 > M であり窓は非退化。）

### 補題GZ（γ ⟹ zone-2）

q = p₂p₃ はNの奇約数で p₂p₃ ≥ M。TWO-ZONE（t≥2）により
2^a·q ≤ M−1 または q > k₀。前者は
2^a·p₂p₃ ≥ 2M > M−1 で不成立。ゆえに **p₂p₃ > k₀**。∎

### 補題EX（p₁スケール約数のzone-2排除）

各 i∈{1,2,3,4} に対し、N = 2^a·(p₁pᵢ)·R_i を multiset の相補積で
定義する（i=1: R₁=p₂p₃p₄・i=2: R₂=p₃p₄・i=3: R₃=p₂p₄・i=4: R₄=p₂p₃）。
すべての場合で **R_i ≥ p₂p₃ ≥ M**:
i=1は余因子p₄≥1、i=2はp₃≥p₂・p₄≥p₃、i=3はp₄≥p₃、i=4は定義のとおり。

いま p₁pᵢ > k₀ と仮定する。このとき
R_i = (MY−1)/(2^a·p₁pᵢ) < MY/(2^a·k₀) = (M/2^a)·(Y/k₀)
= (M/2^a)·(1+(t+2)/k₀)   〔§1の恒等式〕。

(M/2^a)(1+(t+2)/k₀) < M ⟺ t+2 < (2^a−1)·k₀ であり:

- a=1: t+2 < k₀ ⟺ (M−1)t+κ > 3。M≥5・t≥2で (M−1)t ≥ 8 > 3。✓
- a≥2: (2^a−1)k₀ ≥ 3k₀ かつ 3k₀−(t+2) = (3M−1)t+3κ−5 ≥ 14·2−5 > 0。✓

ゆえに R_i < M となり R_i ≥ M と矛盾。したがって
**p₁pᵢ ≤ k₀ (∀i∈{1,2,3,4})**。∎

### 定理SIX-ZONE

q = p₁pᵢ はNの奇約数（multiset内の相異なる位置の積）で、補題EXにより
q ≤ k₀。TWO-ZONEの二分法で zone-2（q > k₀）は排除済みゆえ zone-1:
**2^a·p₁·pᵢ ≤ M−1、すなわち c·pᵢ ≤ M−1 (∀i)**。
i=1で 2^a·p₁² ≤ M−1、i≥2で pᵢ ≤ (M−1)/c。∎

a=1・p₁=3では c=6 となり「N/2 = 3p₂p₃p₄ の全奇素因数 ≤ (M−1)/6」。
これが「six zone」の上限壁である。

### 定理P2-LOWER

補題GZより p₂p₃ > k₀（整数なので p₂p₃ ≥ k₀+1）、SIX-ZONE（i=3）より
p₃ ≤ (M−1)/c。ゆえに
p₂ ≥ (k₀+1)/p₃ > k₀/p₃ ≥ c·k₀/(M−1)。
k₀ = Mt+κ−1 ≥ (M−1)t+1（t≥2）なので
c·k₀/(M−1) ≥ c·t + c/(M−1) > c·t。
整数形 **p₂·(M−1) > c·k₀** も同様に従う（p₂ ≥ (k₀+1)/p₃ >
k₀/p₃ ⟹ p₂(M−1) > c·k₀・検証器C6は整数で判定）。
a=1・p₁=3では **p₂ > 6t**。∎

### 定理SHARP-V

Y = (N+1)/M = (c·p₂p₃p₄+1)/M。SIX-ZONE（i=2,3,4）より
p₂,p₃,p₄ ≤ (M−1)/c なので

Y ≤ (c·((M−1)/c)³+1)/M = ((M−1)³/c²+1)/M。

一方 Y = (M+1)t+κ+1 ≥ (M+1)t+1 > (M+1)t（κ≥0）。ゆえに

  (M+1)t < ((M−1)³/c²+1)/M、すなわち
  **t·c²·M·(M+1) < (M−1)³+c²**。

κは Y > (M+1)t の評価にしか現れないため、**κ=0のγ行にも無条件で成立**
（K0961 γ sharpがκ≥1を要求したのと対照的）。∎

### K0961 γ sharpとの比較（鋭さ）

κ≥1の旧上界は t ≤ (M−2)/c²。新上界は
t < ((M−1)³+c²)/(c²M(M+1))。新 < 旧 ⟺

(M−1)³+c² < M(M+1)(M−2) = M³−M²−2M ⟺ **c² < 2M²−5M+1**。

c=6（a=1・p₁=3）では 2M²−5M−35 > 0 ⟺ M ≥ 6。すなわちcensus全行で
新上界は厳密に鋭い。改良量は厳密値
(M−2)/c² − ((M−1)³+c²)/(c²M(M+1)) = **(2M²−5M−35)/(c²M(M+1))**
（c=6で ≈ 1/18 ≈ 0.0556・実測 [0.05546, 0.05554]・検証器は
float一致を1e-9で確認）。

κ=0のγ行に対しては旧capが t ≤ (M−2)/(2^a·c)（K0961 γ sharp κ=0版）なので
新上界 ≈ M/c²·(M−1)/(M+1) は **3倍（2^a因子分）厳密化**。

### 系（six zone・帯構造）

a=1・p₁=3のとき、SIX-ZONE+P2-LOWER+GZは
6t < p₂ ≤ p₃ ≤ p₄ ≤ (M−1)/6・p₂p₃ > k₀・6p₂p₃p₄ ≡ −1 (mod M)
を与える。帯の非空性 6t < (M−1)/6 から
