# 残余23行の三行被覆根を第三の幾何計算で再導出（2026-11-20）

## 結果

K1097の8根被覆不可能性証明書で使われた「三つの行にはP‴上の三行被覆根がない」という前提を、既存の二つの3×3行列式判定とは別の方法で再導出した。**3行それぞれについて、三行を同時に含み得る8石根をすべて列挙し、その全てが「共円四点を含む」か「REFUTED-D10の除外済み根」のどちらかに分類される。**

- 残余23行から異なる3行を選ぶ組: 1,771組
- 各組のD4向き8³通り: 906,752通りを全列挙
- 3行の和集合の大きさ: 8〜14。8未満は0件
- 和集合が8点の向き組: 3,384件、D4正準根は423個
- 423根の安全性: 安全316・共円四点を含む107
- 安全316根のうち、REFUTED-D10除外50根に含まれるもの: 19
- P‴に残る三行被覆根: **297個**。全てちょうど3行を被覆する

したがって、三行被覆数の総和は (891=3\times297)。23行ごとの件数も既存判定正本と全23件一致した。

## 方法と再現

- 入力はK1097再解決正本、K1102独立第二検証正本、8根被覆判定正本から転記した23行・除外50根・既存の23行別件数。出典SHA-256は入力JSONに記録した。
- 3行のD4向き全組合せを直接列挙する。既存の「23行に空き2点を加える」宇宙生成器は使わない。
- 共円判定は4×4行列式を24置換の符号付き積で展開する。既存の二つの3×3判定式は呼び出さない。
- 候補根ごとに8石から6石を選ぶ28通りをD4正準化し、被覆行を再導出する。
- Python標準ライブラリのみ。別作業場所3回（通常・隔離HOMEかつ `PYTHONHASHSEED=random`・別HOMEと固定seed）で監査JSONがバイト単位一致した。

実行:

```sh
python3 scripts/audit_zero_triple_providers.py \
  --input input/residual23-provider-input.json \
  --output output/third-geometry-audit.json
```
