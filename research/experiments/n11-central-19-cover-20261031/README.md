# 11×11：未解決19初手の中央応手に必要な四石クラス数（幾何学的最小値）

標準11×11の未確定初手19軌道それぞれについて、第二手を中央60に固定し、全119第三手を合法な四石クラスで覆う**幾何学的集合被覆**を解いた。

| 幾何学的最小クラス数 | 初手代表 | 軌道数 |
| --- | --- | ---: |
| **31** | 16, 38, 49, 24, 0, 48, 12, 5, 36 | **9** |
| **56** | 26, 25, 3, 13, 2, 14, 15, 4, 1, 37 | **10** |

各rootの第三手119点に対し、四石クラスは回転・反転で同値なものを一つと数える。各クラスの8像のうち指定二石を含む像から第三手を逆算する。全19 rootで相異なる合法四石クラスは合計 **96,330** 件。

**最小性の証明書**は各rootについて二種類を保存している。

1. 上界：31個または56個の合法四石クラス鍵。全119第三手を覆う。
2. 下界：第三手62点または112点に重み1/2を与える双対証明。全合法四石クラスの重み和は1以下。したがって必要クラス数は31以上または56以上。

独立監査器はPython/SciPyの最適化結果を信用せず、**4×4整数行列式**とD4の8変換で全クラスを再生成し、上界・下界の双方を検査する。証明書は圧縮JSONのbase64表現で、通常のテキストファイルとしてGit管理する。

```sh
node research/experiments/n11-central-19-cover-20261031/verify.js
```

発見時はPython 3・SciPy 1.17のHiGHSで各rootの線形計画と0/1整数計画を解き、独立のNode検証器で19件・96,330クラスの全不等式と全被覆を検査した。検証器はNode標準ライブラリだけで動き、整数計画器・キャッシュ・solver・S5判定は不要。

**重要な限界：** 四石クラスがLOSSであるとは一切仮定・証明していない。これは幾何学的に可能な最少証人数であり、既知LOSSクラスの再利用・既知WINによる候補除外・S5探索費用を考慮した最少数ではない。中央応手が勝ち応手かどうか、二石rootや空盤の勝敗は確定しない。**11×11空盤はUNKNOWN。**

既存のK0335は中心・隅rootの一般的な幾何被覆を扱う。本実験は中央応手を持つ未解決19初手を個別に全数監査したもの。

## 保存済みWIN5証人による四石LOSS候補の除外（2026-10-31）

幾何学的最小被覆の全候補96,330件（19 rootへの帰属を重複込みで数える）に、二系統の保存済み厳密S5判定cacheを突き合わせた。WIN5が合法子にあるS4は元先手固定視点でWINとなるため、**S4 LOSS証明の候補から除外できる**。

- 固定S5 cache 5,851行と別系統5,700行をWIN/LOSS衝突検査付きで統合すると、相異なる5,853類（WIN 161類）。WIN5から合法な一石除去で得られるWIN4証人は555類。
- 未解決19中央応手rootの合法S4クラスの延べ96,330件のうち、**804件（相異なる393クラス）**が既知WIN4証人と一致する。
- 従ってLOSS4として選択可能な候補は延べ**95,526件**。最多除外は初手12の120/3,389件、次いで48の112/3,377件、16の103/3,402件。
- 19 root別の全数値を検証器の `rootStats` に固定。従来の幾何学的31/56クラス下界は依然有効だが、WIN4を除いた集合で同数の被覆が存在するかは**別問題**。既存幾何証明書の選択S4にWIN4が含まれるかも `selectedWitnessConflicts` として出力する。

```sh
node research/experiments/n11-central-19-cover-20261031/audit_win4_exclusion.js
```

監査器は固定Git blobのSHA-1、全S5鍵のD4正準性・合法性・重複・極性、WIN5→WIN4親子関係、19 rootの全合法S4クラス、WIN/LOSS衝突を独立整数幾何で再計算する。元の最小被覆監査器は4×4置換行列式、本監査器は差分3×3行列式を使用する。重複S5鍵を逆極性へ改変した負例も拒否する。

**信頼境界：** S5のWINは過去のsolver-trusted exact判定であり、今回新たに終局まで証明したものではない。除外数は証明計画の候補削減であって、S4 LOSSの新規証明でも、31/56の最適性の勝敗制約下での維持でもない。新しい二石rootの閉鎖は0件、11×11空盤は**UNKNOWN**。

## WIN4を除外しても56類の最小被覆を保てる10 root（2026-10-31）

既知WIN5から導いた555類のWIN4をLOSS4候補から除外しても、**幾何学的最小値が56類だった10個の中央応手rootでは、最小56類の被覆がすべて実現可能**である。保存した `win4-safe-56-certificate.json` は、初手代表 `26,25,3,13,2,14,15,4,1,37` それぞれについて、WIN4と衝突しない相異なる56個のS4クラス鍵を含む（合計560個、root間の重複を含む）。

各rootの119第三手は選択56類のD4像で全被覆される。既存の `certificate.json.gz.b64` の112個の重み1/2の双対証明は、候補除外後にも有効であるため、**WIN4除外を課した幾何被覆の最小値は厳密に56**。独立監査は4×4整数行列式による合法クラス再列挙、保存S5キャッシュのSHA-1固定・WIN/LOSS衝突検査、選択クラスの非WIN4確認、全第三手被覆、全クラスの双対制約を再計算し、改変証明書を拒否する。

```sh
node research/experiments/n11-central-19-cover-20261031/verify_win4_safe_56.js
```

残る9 root（幾何最小31類）で、WIN4除外後も31類で被覆できるかは未確定。**56類の選択S4はLOSSと証明されたわけではない**。S5 WINラベルは既存solver-trusted判定に依存するため、この成果は「既知WIN4を避けた幾何学的証明計画の実現可能性」であり、二石rootの勝敗証明ではない。空盤勝敗は**UNKNOWN**。
