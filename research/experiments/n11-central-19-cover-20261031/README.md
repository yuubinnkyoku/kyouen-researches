# 11×11：未解決19初手の中央応手に必要な四石クラス数（幾何学的最小値）

標準11×11の未確定初手19軌道それぞれについて、第二手を中央60に固定し、全119第三手を合法な四石クラスで覆う**幾何学的集合被覆**を解いた。

| 幾何学的最小クラス数 | 初手代表 | 軌道数 |
| --- | --- | ---: |
| **31** | 16, 38, 49, 24, 0, 48, 12, 5, 36 | **9** |
| **56** | 26, 25, 3, 13, 2, 14, 15, 4, 1, 37 | **10** |

各rootの第三手119点に対し、四石クラスは回転・反転で同値なものを一つと数える。各クラスの8像のうち指定二石を含む像から第三手を逆算する。全19 rootで相異なる合法四石クラスは合計 **96,330** 件。

**最小性の証明書**は各rootについて二種類を保存している。

1. 上界：31個または56個の合法四石クラス鍵。全119第三手を覆う。
2. 下界：第三手62点または112点に重み1/2を与える双対証明。全合法四石クラスの重み和は1以下。したがって必要クラス数は31以上または56以上。

独立監査器はPython/SciPyの最適化結果を信用せず、**4×4整数行列式**とD4の8変換で全クラスを再生成し、上界・下界の双方を検査する。証明書は圧縮JSONのbase64表現で、通常のテキストファイルとしてGit管理する。

```sh
node research/experiments/n11-central-19-cover-20261031/verify.js
```

発見時はPython 3・SciPy 1.17のHiGHSで各rootの線形計画と0/1整数計画を解き、独立のNode検証器で19件・96,330クラスの全不等式と全被覆を検査した。検証器はNode標準ライブラリだけで動き、整数計画器・キャッシュ・solver・S5判定は不要。

**重要な限界：** 四石クラスがLOSSであるとは一切仮定・証明していない。これは幾何学的に可能な最少証人数であり、既知LOSSクラスの再利用・既知WINによる候補除外・S5探索費用を考慮した最少数ではない。中央応手が勝ち応手かどうか、二石rootや空盤の勝敗は確定しない。**11×11空盤はUNKNOWN。**

既存のK0335は中心・隅rootの一般的な幾何被覆を扱う。本実験は中央応手を持つ未解決19初手を個別に全数監査したもの。

## 中央応手 {49,60} の最初の四石証明を優先する4並列順序（2026-10-31）

前節のS5子単位4分割は2,525類を632/631/631/631類に重複なく配るが、**辞書順に実行すると、最も安い四石証人すら最後の必要なS5が非常に後ろにある**。証人 `00000000000000401002010000000000` は未判定S5が最少の91類（既知LOSS5は1類）で、他の証人と未判定S5を共有しない。第三手36,40,70,72を単独で覆う。

| 指標 | 既存の辞書順 | 優先証人を先頭にする順序 |
| --- | ---: | ---: |
| 相異なる未判定S5 | 2,525 | 2,525 |
| worker別総件数 | 632/631/631/631 | 632/631/631/631 |
| worker間の重複 | 0 | 0 |
