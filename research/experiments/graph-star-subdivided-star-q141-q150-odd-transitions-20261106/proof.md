## 結論（各 q の全奇数 k≥3）

対象は \(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}\)、\(r=q-3\)。

## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおくと、負根条件は \(F_k(y)=r-y-(a-y)y^k=0\)。\(0<y\le1\)、\(a\le y\le r\)、\(y>r\) には根がない（\(r\ge138\)）。根は \(1<y<a\) のみに存在しうる。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大となる。非存在境界 \(k_-\) で \(H_{k_-}(y_*)<r-a\) を示せば根はない。存在境界 \(k_+=k_-+2\) で \(1<y_*<a\) かつ \(F_{k_+}(y_*)<0\) なら、両端の正値から少なくとも2根がある。\(T_{k,r}(-x)\) の符号変化は2回なのでデカルトの符号法則によりちょうど2個、いずれも単根。正根は係数が全て正なのでない。\(1<y<a\) では \(y^k\) が k に関して厳密増加するため、両境界から全奇数次数へ拡張される。

以下の検査は浮動小数点を一切使わない。\(A=k(r+2), B=(k+1)(r+1)\) と置く。非存在側の十分条件は \((r^2-2)(k+1)B^k>(r+2)A^k\)、存在側は \((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)。この20境界を全て厳密な整数演算で検証した。

```python
bounds = [[141,1877],[142,1893],[143,1909],[144,1925],[145,1939],[146,1955],[147,1971],[148,1987],[149,2003],[150,2019]]
for q, kp in bounds:
    r = q - 3
    for k, exists in ((kp-2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if exists:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
    print(q, "pass")
```
