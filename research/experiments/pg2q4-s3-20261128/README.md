# PG(2,4) s=3 の完全 Grundy スペクトル（錐法）

- 盤: PG(2,4)（21 点・21 直線、各 5 点）。s=3（各直線と高々 3 点）。
- 三角形 F={0,1,5} の錐（5,038 局面）で完全 DP。PGL(3,4) は三角形に推移的、
  サイズ ≥4 のキャップは三角形を含むので `N_m(g)=N_3·T_m(g)/C(m,3)`（N_3=1,120）。
- 一直線上の 3-キャップ（210 個）は別の錐（{0,1,2}）で G=0 を確認。
- k=0,1,2 は mex 連鎖。
