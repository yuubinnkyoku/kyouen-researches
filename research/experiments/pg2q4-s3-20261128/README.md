# PG(2,4) s=3 の完全 Grundy スペクトル（錐法）

- 盤: PG(2,4)（21 点・21 直線、各 5 点）。s=3（各直線と高々 3 点）。
- 三角形 F={0,1,5} の錐（5,038 局面）と、一直線 3-キャップ {0,1,2} の錐（3,809 局面）で完全 DP。
- 3-キャップは 2 軌道（三角形 1,120 個・一直線 210 個）。**両方を二重数え上げに含める**:
  `1,120·T_m(g) + 210·U_m(g) = C(m,3)·N_m(g)`。
  （当初は三角形のみで数えて 22,660 個を過少に数えた。検証で指摘され訂正。）
- k=0,1,2 は mex 連鎖。
