# 3×5・二次形式4点禁止版の全実数 λ 分類（2026-10-23）

対象は整数格子 `B={(x,y):0≤x≤4, 0≤y≤2}` の15点。
4点が `det[x²+λy²,x,y,1]=0` を満たすとき禁止（共線などの退化も含む）。
安全な点追加だけを合法手とする通常プレイ。これは標準共円ゲームそのものではない。

## 厳密な結果

空盤Grundy値 `g(∅)` は、任意の実数 `λ` に対して次の通り。

- `g=0`: λ ∈ {−3,−2,−1,0,1}。
- `g=2`: λ ∈ {3/2,2}。
- `g=3`: λ ∈ {−4,−3/2,3,5}。
- `g=1`: それ以外の全実数。

したがって後手必勝係数は上記5値に限られる。g=3のうち λ=−4 は勝ち初手が (2,1) の1手のみ。
係数 λ=1（標準共円・共線4点禁止）では g(∅)=0。

## 全実数を有限計算に帰着する証明

固定した4点組の行列式は整数係数の `A+Bλ`。
`A=B=0` なら常時禁止、`B≠0` なら禁止が発生するのはただ一つの有理数 `−A/B`。
全1365組から得られる例外値は正確に次の31個。

`−12,−9,−8,−7,−6,−11/2,−5,−4,−7/2,−3,−5/2,−2,−3/2,−1,−1/2,0,1/2,1,3/2,2,3,7/2,4,5,6,13/2,8,17/2,9,11,12`

残りのすべての実数で禁止4点組の集合は一致する。
この一般型と31例外型の計32型について、15点の32768部分集合を完全に調べた。
安全局面を上から順にmex計算し、空盤値・全安全局面数・極大石数分布・勝ち初手を得た。
一般型では安全局面7062、λ=0では3668、λ=1では4672。
全32型の安全局面数合計は191024。

## 再現と独立検査

```sh
python3 classify.py > results.json
python3 independent.py results.json
# PASS 32 parameter types; 191024 safe positions
```

`classify.py` は3×3差分行列式の係数抽出、禁止部分集合の上向き伝播、全安全局面の下向きmex。
`independent.py` は別実装の4×4置換行列式を整数で直接計算し、
合法追加の上からの再帰で全安全局面を再訪する。
全32型で空盤値・安全局面数・禁止4点組数・勝ち初手集合が一致した。

また既存3×4分類との整合確認として、同じ座標規約の4列×3行盤で
一般型0、λ=−1で1、λ=0で1、λ=1で2を確認した。
これは有限完全列挙と有限帰着による固定盤の厳密分類であり、
任意の盤サイズへの全称定理ではない。
