# 一辺細分星 q=71〜80 の奇数次数実根切替（2026-11-06）

## 定理（全称、境界算術は厳密整数検査）

\(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}\)、\(r=q-3\)、奇数 \(k\ge3\) とする。

| q | 実根なしの最大奇数 k | 負の相異なる単実根2個の最小奇数 k |
|---|---:|---:|
| 71 | 827 | 829 |
| 72 | 841 | 843 |
| 73 | 855 | 857 |
| 74 | 869 | 871 |
| 75 | 883 | 885 |
| 76 | 897 | 899 |
| 77 | 913 | 915 |
| 78 | 927 | 929 |
| 79 | 941 | 943 |
| 80 | 955 | 957 |

各行の左側の非存在結論は同じ k 範囲について任意の q'≥q にも成り立つ。

## 証明

\(u=-(r+1)y\), \(a=(r+2)/(r+1)\) とすると、負の実根は \(F(y)=r-y-(a-y)y^k=0\) に対応する。\(u\ge0\) では多項式は正。\(y\le0\) は u≥0 に対応する。\(0<y\le1\) では \(F(y)\ge r-y-(a-y)=r-a>0\)（ここでは r≥68）。\(y\ge a\) では \(F(y)=r-y+(y-a)y^k>0\)：\(y\le r\) は明白、\(y>r\) は \(y^k>y\) と \((y-a)y>y-r\)（\(y\ge r\ge68\)）から従う。従って根は \(1<y<a\) のみ。

\(H(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大となる。非存在境界 k_- で \(H(y_*)<r-a\) を示せば全 \(3\le k\le k_-\) に根はない（\(y>1\) における単調性）。存在境界 k_+ で \(F(y_*)<0\) を示せば \(F(1)>0,F(a)>0\) より二つの根があり、\(T(-x)\) の符号変化が2回なのでデカルトの符号法則によりそれらは単根かつ全実根である。k を増やすと F は減るので全奇数 k≥k_+ に拡張する。q を増やすと r-y は増し a-y は減るので非存在結論は上位 q にも伝播する。

## 整数のみの境界検査

\(A=k(r+2), B=(k+1)(r+1)\) とおく。\(y_*=A/B\)。非存在側の十分条件 \(H(y_*)<r-a\) と存在側の \(F(y_*)<0\) はそれぞれ次の整数不等式と同値：

\[
(r^2-2)(k+1)B^k>(r+2)A^k,
\]
\[
(rB-A)(r+1)(k+1)B^k<(r+2)A^kB.
\]

以下は浮動小数点を用いない再現検査であり、20件すべて通過した。各境界は隣接する奇数であり、上記単調性により全称定理になる。

```python
bounds = [(71,829),(72,843),(73,857),(74,871),(75,885),
          (76,899),(77,915),(78,929),(79,943),(80,957)]
for q, kp in bounds:
    r = q-3
    for k, existence in ((kp-2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A < (r+2)*B//(r+1) + 1
        if existence:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
print("20 exact boundary inequalities passed")
```

注：接触二重根の一般 q における不存在は未解決。本証明は q=71..80 の全奇数 k に限る。先行 q=61..70 の証明および独立 Fraction 監査を参照。
