## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) と置くと、負根の方程式は
\(F(y)=r-y-(a-y)y^k=0\) である。
\(0<y\le1\) では \(F(y)\ge r-a>0\)。
\(a\le y\le r\) では \(F(y)>0\)。
\(y>r\) では \((y-a)y^k>(y-a)y>y-r\) から \(F(y)>0\)。
したがって根の候補は \(1<y<a\) のみ。

\(H(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大となる。
\(k_-=k_+-2\) において \(H(y_*)<r-a\) なら \(F(y)>0\) が全域で成立する。
\(k_+\) において \(F(y_*)<0\) なら \(F(1),F(a)>0\) より少なくとも2個の負根が存在する。
\(T_{k,r}(-x)\) の係数の符号変化は2回なので、デカルトの符号法則より負根はちょうど2個、いずれも単根である。
正根は多項式の係数が全て正であるため存在しない。
\(1<y<a\) では \(y^k\) が \(k\) とともに増加するため \(F(y)\) は減少する。
従って境界の確認で全奇数 \(k\ge3\) が覆われる。

## 独立再実行可能な整数検査

\(A=k(r+2), B=(k+1)(r+1)\) と置く。非存在側は強い十分条件
\((r^2-2)(k+1)B^k>(r+2)A^k\) を使い、
存在側は \((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\) を使う。
どちらも整数の厳密比較である。

```python
bounds = [[121,1567],[122,1583],[123,1599],[124,1613],[125,1629],[126,1645],[127,1659],[128,1675],[129,1691],[130,1707]]
for q, kp in bounds:
    r = q - 3
    for k, yes in ((kp - 2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if yes:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
        else:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
print("20 exact inequalities passed")
```
