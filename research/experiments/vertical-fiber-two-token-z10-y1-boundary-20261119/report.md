## 記法

- Vₓ(R) を位置 (R;(x,1);10) の選択肢（子のGrundy値）の集合と書く。

## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,1) における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,1);10)
- **B手**（値1のトークンを除去、通常値は z+1=11）: 子 = H(R−1;(x);11)（単一トークン）
- **C手**（z を 10→9 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,1);9)

x=1 では X=(1,1) で A手が存在せず、2本の除去手は同一の子 (1);11 に帰着する（B手とC手のみ）。

子の値はそれぞれ既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K0832 の単一トークン z=11 公式、C子は K0985 の z=9・y=1 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** 本証明で使う既証明の公式:

- 単一トークン v(x,11,r)（K0832）: x≤10 は z≥x+1 枠（m=qod(x)、r≤m 奇偶で {2,0}、それ以外で x mod 2）、x=11 は z=x 枠（r 奇≤2x−1=21 で2・r 偶≤10 で0・それ以外 x mod 2）、x≥12 は 1≤z≤x−1 枠（m=qod(11)=11、中間帯 11<r<x+11 で (r+11) mod 2、r≥x+11 で x mod 2）。
- z=9・y=1（K0985）: 値域は T₉(x)={1,3,5,7,9,11}（x=11は…∪O[13,21]、x≤9は個別）、P₉(x) は x≥13 奇数で {10}∪O[13,x+10]、x≥12 偶数で {10}∪O[13,x+11]∪I[x+12,∞)、x≤11は個別。C子の値は 1⊕h₉(x,r) で h₉∈{0,1,2} に対し {1,0,3} に写る。

帯の現れ方の根拠（定常行の導出、x≥14 偶数行の全帯。r=R−1）:

- 奇数R∈[15,x+11]（r 偶∈[14,x+10]）: A=1（r∈E[14,x+10]⊆P_A）、B=1（中間帯 (r+11) mod 2=1）、C=1（r 偶は P₉ の奇数帯外、h₉=0）。V={1}、値0。**R=x+11（r=x+10）も同じ {1} で値0**（偶数行の孔）。
- R≥x+12（r≥x+11）: A=0（P_A 有限確定、r∈T_A 外）、B=0（r≥x+11=x+z' で単一トークンtail、x mod 2=0）、C=0（r∈I[x+12,∞)⊆P₉(x) → h₉=1 → 1⊕1）。V={0}、値1。

**Step 4（mex評価と Theorem T）.** K0832 の Theorem T により、奇数Rの親では値は mex{0,1}=2, mex{0}=1, mex{1}=0, mex∅=0 に限り、偶数Rの親の値は高々1である。上表の署名に mex を施すと次の一意対応で値が決まる:

この規則を Step 3 の帯表に機械適用すると主定理の T₁₀⁽¹⁾/P₁₀⁽¹⁾ が正確に再構成される（例: x≥14偶 の E[16,x+10]:0 → 値1、R≥x+12:{0} → 値1 が I[x+12,∞) を与え、x≥15奇 の R≥x+12:{1} → 値0 が P の有限性と tail の 0 を与え、R=13:{0,1} → 値2 がピン13を与え、x=12 の O[13,23]:01 → 値2 が掃引帯を与える）。

**Step 5（tail整合）.** 定常行の末帯で V は偶奇2値に退化し、R≥x+12 で H=(x+1) mod 2 となる。これは K0832 の一般tail定理の 2トークン・z=10 場合（R≥S+|X|+z−1=x+12、H=S mod 2=(x+1) mod 2）と独立に一致する。 □

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は z=7（{1,3,5,7,9}）、z=8（{1,3,5,7,11}）、z=9（{1,3,5,7,9,11}）に対し z=10 では **{1,3,5,7,9,13}**。ラダー {1,3,…,qod(z)}（qod(10)=9）に定常ピン 2y+z+[z偶]=2+10+1=13 が加わる。**ピンは11（z+1）と13の間で11を選ばず13に単独定着**し、z=9までの「第5・6点が2つずつペアをなす」系列（9,9,11,11）は z=10 で 13 に一段飛びになる。
- 前倒し格子: d≡(10−z) mod 4=0 (mod 4) の行 x=y+d で高さ 2y+5+2k。y=1 では d=8（x=9）の高さ 2y+9=11 のみが生存（x=9 は x+1=10=z で高さのみ縮約が z=x 枠となり O[1,2x−1] の値2を R≤11 内で与える）、d=0（x=1）の 7・d=4（x=5）の 9 は高さのみ縮約（m=qod(x+1)≤5）で抑制され、d=12（x=13）で高さ 2y+11=13 がピンに到達して以後 d≥12 で単独定着する。K1002 の z=10 y≥6 一様式の前倒し格子（d=0,4,8）と枠組みは同一で、低yでは高さのみ縮約の抑制により前倒し点が失われる。
- 掃引行は x=z+2=12、掃引帯 O[13,23]=O[2y+11,2x−1]=O[pin,x+y+z]。機構は z=8・z=9 と同じく A子（x=11行では有限 P={11}）×B子中間帯（v_single(12,11,·)、中間帯は 11<r<23）×C子奇数帯（P₉(12)={10}∪O[13,23]∪I[24,∞)）の積で、R 偶∈E[14,22] で V={0}、R 奇∈O[13,23] で V={0,1} が交互に並ぶ。掃引開始 13=pin・終端 23=X。
- 値1位置の基本構造は z=6..9 と同じ族則が成立: 基底点 z+1=11、帯開始 z+4=14、偶奇は z 偶（z=6 枠 E[10,..]・z=8 枠 E[12,..]・z=10 枠 E[14,..]）で E 帯。tail開始は x+z+2=x+12 で一般tail x+y+z+1 に一致。

- 本定理は **z=10・y=1 の境界切片のみ**。z=10 の y=2..5 は未証明（y=2 は A=x外帰納・B子=本項・C子=1⊕K0986(z=9,y=2) の三子が揃い着手可能）。y≥6 は K1002 の一様式候補のまま（有限センサスのみ）。
