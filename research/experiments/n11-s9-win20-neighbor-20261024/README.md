# 標準11×11：9石WINの近傍20根から8石WINを154件追加

2026-10-24。標準q=4、完全指摘、通常プレイ、**元先手固定視点**。
標準11×11空盤の勝敗は **UNKNOWN**。

既存の独立終局証明済み9石WIN根7件（`n11-s9-win7-expansion-20261024`）から、
一石を除去して別の合法点へ置く近傍をD4正準化し、相異なる9石候補1,963件を生成した。
合法10石子の少ない順に111件を局所調査し、20件の9石WINを発見。
候補の探索結果を証明に流用せず、**選択した20根の全合法10石子**を別途終局まで検証した。

C++の4×4整数行列式による独立終局再帰は233葉すべてWIN、
個別探索状態数の合計4,985。Pythonの別実装（3×3整数行列式、
部分集合終局再帰）も233葉すべてWINで、合法手数の不一致は0。
PythonとC++の探索状態数は表現が異なるため一致条件にしない。
D4正準化した20根、全233葉、167親の固定一覧を保存する。
9石はAND節点なので全子WINから20根WIN、
8石はOR節点なので9石WIN子を持つ167親もWINとなる。

## 再現

リポジトリ直下で実行：

```sh
bash research/experiments/n11-s9-win20-neighbor-20261024/reproduce.sh
```

既存C++終局検証器をコンパイルし233葉を再分類した後、
`verify.py` が既存の独立Python幾何・終局再帰で全子を再生成し、
全233葉のWINと合法手数、167親の証人、凍結LOSSとの無矛盾を確認する。
`audit_coverage.py` は既存93根由来の750親と凍結13,501件との
**指定比較集合**に対する154件・1,232辺の差分を検査する。
凍結cacheの勝敗は新しい証明の前提にせず、重複・矛盾と被覆比較にのみ用いる。
負例として10石子一覧の欠落とC++勝敗行の改変を拒否する。

候補選別に用いた未完探索は証明ではない。証明書は選択した20根と
その全合法10石子の終局判定にのみ依存する。
新しい7石WIN/LOSS、6石局面、二石root、空盤の勝敗確定はない。
標準11×11空盤は **UNKNOWN**。
