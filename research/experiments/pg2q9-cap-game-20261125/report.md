# PG(2,9) のキャップ国勢調査: 初のパリティ混在

実験ディレクトリ: `research/experiments/pg2q9-cap-game-20261125/`（2026-11-25）

## 0. 要旨

`PG(2,9)`（91 点、91 直線、各 10 点）の s=2 キャップを全数列挙した。

- キャップ総数 **128,917,712**（サイズ 0..10）。
- 極大キャップ: **6 (707,616), 7 (2,021,760), 8 (5,307,120), 10 (58,968)**。
- **初のパリティ混在**（7 が奇数）→ 定理より Grundy ≥2 が存在。独立検証で
  局面 **{0,1,10,20,32,39} が Grundy 2** であることを直接確認。
  9 の極大は 0。
- **極大サイズに奇数（7）が現れ、初めてパリティ混在**。K1298 の定理より
  Grundy ≥2 が存在する（完全分布は未計算）。
- 構成的恒等式: 10-キャップは円錐曲線 `9⁵−9² = 58,968` で全極大、
  9-キャップは `58,968×10` で全部円錐曲線内、非極大 8-キャップは
  `58,968×C(10,8) = 2,653,560`。

## 1. 手法

- GF(9)=GF(3)[x]/(x²+1) 上で PG(2,9) を構成（91 点、直線は 2D 部分空間、
  点対一意性・点次数・直線サイズを全数検査）。
- n>64 対応の国勢調査 `cap_census.c`（`pg2q8-cap-game-20261125/scripts/`）で
  全キャップを列挙し、サイズ別総数と極大数（追加可能点なし）を数える。
  位置マスクも DP も不要。所要は約 3 分。

恒等式（全数で確認）:

- `58,968 = 9⁵ − 9²`（PG(2,9) の円錐曲線数）＝ 10-キャップ数。
- 9-キャップ数 `589,680 = 58,968 × 10`（すべて円錐曲線の 9-部分集合）。
- 非極大 8-キャップ `2,653,560 = 58,968 × C(10,8)`（円錐曲線内）。
- したがって極大 8-キャップは `7,960,680 − 2,653,560 = 5,307,120`。

## 3. 意義

- q≤8 の PG では極大キャップはすべて偶数（パリティ一様）だったが、
  **q=9 で初めて完全 7-アークが 2,021,760 個現れ、パリティ混在**になる。
  K1298 により Grundy ≥2 の存在が定理から従う。
- 「PG(2,q) の完全アークのパリティ」が q にどう依存するかの新しいデータ点。
- 1.29 億局面の完全 Grundy は将来の課題（orbit 圧縮など）。ただし 4-キャップ
  {0,1,10,20} の残余 1,868 局面は完全計算済みで、Grundy 2 の実例を含む。

## 3.5 完全アークの PGL(3,9) 軌道（追記）

極大キャップ（完全アーク）の各サイズについて、PGL(3,9) の生成元（GF(9) の
transvection・対角・置換、8 個）による軌道サイズを C の BFS で計算した。

| サイズ | 極大キャップ数 | 軌道サイズ | 単一軌道? | 固定群の位数 |
|---:|---:|---:|---|---:|
| 6 | 707,616 | 707,616 | ✓ | 60 |
| 7 | 2,021,760 | 2,021,760 | ✓ | 21 |
| 8 | 5,307,120 | 5,307,120 | ✓ | 8 |
| 10 | 58,968 | 58,968 | ✓ | 720 |

- **PG(2,9) の完全 6-, 7-, 8-, 10-アークはそれぞれ PGL(3,9) の単一軌道**。
  すべての完全アークが同サイズ内で射影同値。
- 固定群の構造: 6-アーク **A5 = PSL(2,5)**、7-アーク **Frobenius C7:C3**、
  8-アーク **D4**、10-アーク **PGL(2,9)**（位数 720、円錐曲線上で鋭 3-推移。S6 ではない）。
- 9-アークは存在しない（すべて円錐曲線に延長）。
- 開始に使った完全アーク: 6: {4,9,20,32,69,84}、7: {16,47,51,56,60,80,82}、
  8: {32,39,42,47,56,59,84,87}、10: {6,9,27,32,34,37,45,75,77,82}。
- 独立検証: 独自生成元 14 個で軌道サイズを再現、第 2 の完全アークとの明示的射影変換
  （60/21/8/720 要素）を構成、固定群の構造を同定（全タスク PASS、不一致 0）。

## 4. 検証（独立、全タスク PASS、不一致 0）

- 盤: 91 点/91 直線、4095 点対・直線対の一意性を確認。独自の GF(9) 構成
  （91 個の非零ノルムの零集合）と明示的な点置換で同型。`|PGL(3,9)| = 42,456,960`。
- 列挙: 独立 C（u128 マスク DFS、75.9 秒）が全サイズ一致。事前に PG(2,3)/PG(2,8)/
  PG(2,5)/PG(2,7) の既知分布で検証。拡張恒等式 `ext[k]=(k+1)·cnt[k+1]`、
  点のランダム再ラベルでも全統計一致（順序独立性）。
- 極大: 2 種類の判定を全 128,917,712 キャップに適用し一致。
  極大 6:707,616 / 7:2,021,760 / 8:5,307,120 / 9:0 / 10:58,968。
- 円錐曲線: 対称 3×3 形式の全列挙で 10-キャップ = 円錐曲線（58,968）を集合として一致確認。
  各円錐曲線は 10 接線・45 割線・36 外線。9-キャップ = 円錐曲線の 9-部分集合、
  非極大 8-キャップ = 8-部分集合、を集合等価で確認。
- **Grundy 2 の明示局面**: 4-キャップ {0,1,10,20} の残余ゲーム（1,868 局面、極大拡大
  6/7/8/10）の完全 Grundy は `{0:684, 1:1064, 2:120}` で、局面
  **{0,1,10,20,32,39} が Grundy 2**。定理からの存在証明に加え、実際の局面で確認された。
- 250 キャップのスポットチェック（9-キャップは追加可能点 1、極大 6/7/8 は 0、
  非極大 8 は 2）も一致。
