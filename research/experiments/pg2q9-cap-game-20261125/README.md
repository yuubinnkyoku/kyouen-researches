# PG(2,9) のキャップ国勢調査 — 初のパリティ混在（宣言・2026-11-25）

## 目的

q=9 の射影平面 PG(2,9)（91 点、91 直線、各 10 点）で s=2 キャップ・ゲームの
国勢調査を行い、極大キャップのサイズ・パリティを求める。
q≤8 では PG の極大キャップはすべて偶数だった（q=2,3,4,5,7,8）。
q=9 で初めて**奇数サイズの極大キャップ（完全 7-アーク）**が現れるかを確認する。

## 手法

- `scripts/build_pg2q9.py`: GF(9)=GF(3)[x]/(x²+1) 上で PG(2,9) を構成
  （点対一意性を全数検査）。
- `../pg2q8-cap-game-20261125/scripts/cap_census.c`: n>64 対応の s=2 国勢調査
  （全キャップを列挙し、サイズ別総数と極大数を数える。位置マスク不要）。

## 結果

- キャップ総数 **128,917,712**（サイズ 0..10）。
- 極大キャップ: **6 (707,616), 7 (2,021,760), 8 (5,307,120), 10 (58,968)**。
  サイズ 9 の極大は 0（すべて延長可能）。
- **パリティ混在**（7 が奇数）→ K1298 の parity 特性定理より Grundy ≥2 が存在。
  完全 Grundy 分布は未計算（1.29 億局面の DP は別途）。
- 構造的恒等式（全数で確認）:
  - 10-キャップ = 円錐曲線 = `9⁵ − 9² = 58,968`（すべて極大）。
  - 9-キャップ = `58,968 × 10`（すべて円錐曲線内）。
  - 非極大 8-キャップ = `58,968 × C(10,8) = 2,653,560`（円錐曲線内）。
  - 極大 8-キャップ = 5,307,120。
- **完全 7-アークが 2,021,760 個存在**（q≤8 の PG では存在しなかった）。

## 意義

- `PG(2,q)` の s=2 で「極大キャップはすべて偶数」という q≤8 のパターンが
  **q=9 で破れる**ことを発見。
- 国勢調査だけで Grundy ≥2 の存在を定理から判定（完全分布は将来）。
- q とパリティの関係を調べる新しいデータ点。

## 検証

- 盤の公理（点対一意性・点次数・直線サイズ）を構成時に全数検査。
- 構造的恒等式（円錐曲線数・9-キャップ・8-キャップの分解）を全数で確認。
- 独立検証を依頼（結果は追記）。
