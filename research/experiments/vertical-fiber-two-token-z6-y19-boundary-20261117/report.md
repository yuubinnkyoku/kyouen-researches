# 2トークン残余ゲーム \(z=6,\ y=19\) 切片の全Grundy分類

## 定理

\[
H(R;(x,19);6),\qquad x\ge19,\ R\ge0
\]
のGrundy値は常に \(0,1,2\) である。値2となる残容量は

\[
\boxed{
T_{19}(x)=\{1,3,5\}\cup
\begin{cases}
\{41\}&x=19,\\
\{43\}&x=23,\\
\{45,47,49,51\}&x=26,\\
\{45\}&x\ge27,\\
\varnothing&\text{その他}.
\end{cases}}
\]

値1の位置を、区間内の奇数・偶数の集合
\[
O[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv1\pmod2\},\quad
E[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv0\pmod2\}
\]
および \(I[a,\infty)=\{r\in\mathbb Z:r\ge a\}\) で表すと、

\[
\boxed{
P_{19}(x)=
\begin{cases}
O[7,39],&x=19,\\
O[7,\infty)\cup E[42,\infty),&x=20,\\
O[7,41],&x=21,\\
O[7,\infty)\cup E[44,\infty),&x=22,\\
O[7,41],&x=23,\\
O[7,\infty)\cup E[44,\infty),&x=24,\\
O[7,43],&x=25,\\
O[7,43]\cup E[46,50]\cup I[52,\infty),&x=26,\\
O[7,43]\cup E[46,x+25],&x\ge27\text{ 奇数},\\
O[7,43]\cup E[46,x+24]\cup I[x+26,\infty),
  &x\ge28\text{ 偶数}.
\end{cases}}
\]

値0の位置は、値1・値2の位置以外である。また一般tail定理から

\[
\boxed{
R\ge x+26\implies H(R;(x,19);6)=(x+19)\bmod2
}
\]

を得る。

## 再帰と依存

親の選択肢を

\[
\begin{aligned}
A&=H(R-1;(x-1,19);6),\\
B&=H(R-1;(x,18);6),\\
C&=1\oplus H(R-1;(x,19);5)
\end{aligned}
\]

とする。\(x=19\) ではA/Bの子はトークンを降順正準化すると同じ \((19,18)\) 状態になるため、K0910で評価できる。\(x\ge20\) ではAは同じ \(y=19\) 切片の \(R\) 強帰納仮説、BはK0910、CはK0873の \(z=5\) 全Grundy公式で評価できる。

K0832のTheorem Tにより、奇数Rの親の選択肢値は \(\{0,1\}\) に含まれ、偶数Rの親のGrundy値は高々1である。したがって奇数親では署名が \(\{0,1\}\) ならmexは2、\(\{0\}\) なら1、\(\{1\}\) なら0。偶数親では署名に0が含まれるときだけmexが1となる。

## 選択肢署名表

以下はA/B/Cの値集合である。区間は両端を含み、奇数R列では奇数だけ、偶数R列では偶数だけを読む。表は \(1\le R\le x+25\) を覆う。

| x | 奇数Rの署名 | 偶数Rの署名 |
|---:|---|---|
| 19 | 1..5:{0,1}; 7..39:{0}; 41:{0,1}; 43:{1} | 2..6:{2,3}; 8..44:{1} |
| 20 | 1..5:{0,1}; 7..45:{0} | 2..6:{2,3}; 8..40:{1}; 42:{0,2,3}; 44:{0} |
| 21 | 1..5:{0,1}; 7..41:{0}; 43..45:{1} | 2..6:{2,3}; 8..46:{1} |
| 22 | 1..5:{0,1}; 7..47:{0} | 2..6:{2,3}; 8..40:{1}; 42:{1,2}; 44..46:{0} |
| 23 | 1..5:{0,1}; 7..41:{0}; 43:{0,1}; 45..47:{1} | 2..6:{2,3}; 8..48:{1} |
| 24 | 1..5:{0,1}; 7..49:{0} | 2..6:{2,3}; 8..42:{1}; 44:{0,2,3}; 46..48:{0} |
| 25 | 1..5:{0,1}; 7..43:{0}; 45..49:{1} | 2..6:{2,3}; 8..42:{1}; 44..50:{1,2,3} |
| 26 | 1..5:{0,1}; 7..43:{0}; 45..51:{0,1} | 2..6:{2,3}; 8..42:{1}; 44:{1,2,3}; 46..50:{0} |
| 27 | 1..5:{0,1}; 7..43:{0}; 45:{0,1}; 47..51:{1} | 2..6:{2,3}; 8..42:{1}; 44:{1,2,3}; 46..52:{0,2} |
| x≥28 | 1..5:{0,1}; 7..43:{0}; 45:{0,1}; 47..U:{1} | 2..6:{2,3}; 8..42:{1}; 44:{1,2,3}; 46:{0,2}; 48..V:{0} |

最終行では
\[
U=\begin{cases}x+24&x\text{ 奇数}\\x+25&x\text{ 偶数}\end{cases},\qquad
V=\begin{cases}x+25&x\text{ 奇数}\\x+24&x\text{ 偶数}\end{cases}.
\]

表はK0910の \(z=6,y=18\) 公式とK0873の \(z=5\) 公式を再帰へ代入し、A子の \(y=19\) 公式を \(R\) 強帰納で置いたときの区間端点を比較して得る。\(x=19\) のA/B合流、\(x=20,\ldots,27\) の過渡域、\(x\ge28\) の偶奇別定常域を分けた。最終行の端点は \(x\) の偶奇で交互に1ずれるため、両列を別々に書いている。

奇数親の署名から値2は基本ラダー \(\{1,3,5\}\)、\(x=19\) の41、\(x=23\) の43、\(x=26\) の45,47,49,51、\(x\ge27\) の45に限られる。偶数親では値2は生じない。値1位置は、奇数親では署名 \(\{0\}\)、偶数親では0を含む署名を取り出すと上の \(P_{19}(x)\) になる。

\(1\le R\le x+25\) は表で尽くされ、\(R\ge x+26\) は一般tail定理で覆われる。\(R=0\) は終端値0。よって \(R\) に関する強帰納が閉じ、表示した全Grundy分類が全 \(x\ge19,R\ge0\) で成立する。∎

## 3族値2位置予想との一致

3族値2位置予想を \(z=6,y=19\) に特殊化し、\(d=x-19\) とする。

- 基本ラダーは \(\{1,3,5\}\)。
- 家族BのEXTは \(d=0,4\) で、それぞれ41,43。
- 家族Aのランは \(d=7\) で45,47,49,51。
- 家族Aの定常位置は \(d\ge8\) で45。

これは証明した \(T_{19}(x)\) と一致する。ただし、これは固定切片 \(z=6,y=19\) の定理であり、3族予想全体の証明ではない。

## 適用範囲と限界

証明対象は抽象残余ゲームの固定切片 \(z=6,y=19\)、全 \(x\ge19,R\ge0\)。\(z=6,y\ge20\)、\(z\ge7\) の全Grundy分類、3族値2位置予想全体、標準二次元共円ゲームの固定幅・q点版の真の安定化長は未解決である。
