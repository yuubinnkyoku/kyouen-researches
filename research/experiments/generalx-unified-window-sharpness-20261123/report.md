## 記法・定義域

残余ゲーム H(R;X;z) は K1264/K1265 と同一の再帰（A手: a>1 を a−1・B手: a=1 を
除去し z->z+1・C手: z>=1 で 1 XOR H(R−1;X;z−1)・mex）。エンジン・閉形式は
出版 K1264 検証器から SHA ゲート付き機械抽出（後述・手転写ゼロ）。

統合窓 W(z,m) := max(z+m, 2)。K1264 階段定理（R<=z+min(X)）と K0832 の
R<=2 全z 条款の併用で、任意の空でない X（min(X)=m）に対し R<=W(z,m) で
H(R;X;z)=v(ΣX,z,R) が保証される（K1264 report 系 3 の出版帰結）。

## T1 の証明（宣言ノートに先行開示した一様 mex 連鎖・再掲）

- 段1: H(1;{1}^j;2) = 2 for j>=1（B子 0・C子 1・mex{0,1}=2。j=0 は 0）。
- 段2: H(1;{1}^k;0) = 1 for k>=1（B子のみ・C手不在・mex{0}=1）。
- 段3: H(2;{1}^k;1) = 1 for k>=1（B子 H(1;{1}^{k−1};2)∈{0(k=1),2(k>=2)}・
  C子 1^1=0・mex はいずれも 1）。
- 結論: H(3;{1}^t;0) = mex{1} = 0 for t>=2。v(t,0,3)=min(3,t) mod 2 より
  t=2 は 0（崩壊）・t>=3 は 1（分離）。∎

2トークン対照点（セル (0,1)・宣言前紙面計算）: (2,1)@(z=0,R=3):
A子 H(2;(1,1);0)=0・B子 H(2;(2);1)=v(2,1,2)=1 より親 mex{0,1}=2、
単一 v(3,0,3)=1 で分離。窓端 W(0,1)=2 では H(2;(2,1);0)=0=v(3,0,2)。

## T2 の証明（宣言後・run 中の紙面発見・開示）

全ての t>=3 に対して H(3;{1}^t;1) = 2 および v(t,1,3) = 0:

- 段(a): H(1;{1}^j;z) = 2 for j>=1, z>=2（B子 0・C子 1・mex{0,1}=2）。
- 段(b): H(2;{1}^k;z) = 0 for k>=2, z>=2
  （B子 H(1;{1}^{k−1};z+1)=2〔段(a)〕・C子 1^H(1;{1}^k;z−1)=1^2=3〔z−1>=1・段(a)〕
  ・mex{2,3}=0）。
- 段(c): H(1;{1}^k;0) = 1 for k>=1（段2 と同一）。
- 段(d): H(2;{1}^t;0) = 0 for t>=2（B子 H(1;{1}^{t−1};1)=2〔段(a)の z=1〕・
  mex{2}=0）。
- 段(e): t>=3 のとき k=t−1>=2 なので
  H(3;{1}^t;1) = mex({H(2;{1}^{t−1};2)=0〔段(b)〕,
  1 XOR H(2;{1}^t;0)=1〔段(d)〕}) = mex{0,1} = 2。
- 段(f): 単一 v(t,1,3): t>=3 で 1<=z=1<=t−1・m̃=q_odd(1)=1・
  1<3<t+1 より m̃<R<x+z 帯で値 (3+1) mod 2 = 0。∎
- t=2 境界: 段(b) の条件 k>=2 が崩れ、H(2;{1};2)=v(1,2,2)=1 から
  H(3;{1}^2;1)=mex{1,1^0=1}=0=v(2,1,3)=0（崩壊・K1265 と整合）。

補足機械照合（宣言後・audit 外の追加点検・値は公開値として本 report に記録）:
t=3..16 すべてで親 2（両エンジン一致）vs 単一 0・t=2 は 0=0。T1 側は
t=13..16 でも親 0 vs 単一 1。証明連鎖アンカー（H(2;{1}^k;2)=0 for k<=12・
H(1;{1}^j;>=2)=2 for j<=12・H(2;{1}^k;0)=0）は両エンジンで全一致。

## セル別鋭さ census の結果

### 前線法則（frontier law・観測: 250/250 セルで例外 0）

E3（z=0..24 × m=1..10 × d=0..60・境界は R*=W(z,m)+1）と E3b（z=25,26 × m<=8 ×
d<=24・出版 K1264 C4 掃引域の補完）の合計 266 セルで:

**セル (z,m) が 2トークン witness を持つ ⟺ m=1 または z >= z*(m) := 2m−2+(m mod 2)**

m>=2 の陰性セルはちょうど z=0..z*(m)−1 の帯（94 セル・m 毎の個数は
2/5/6/9/10/13/14/17/18 = 各 m の z*(m) そのもの・E3 範囲 z<=24 内で全て収まる）。
この前線法則は出版観察の統一説明になる: K1264 C4 の「y>=9 で境界+1 分離が
希薄化」は y>=9 では z>=2y−1（奇）必要で掃引域 z<=26 のうち z=17..26 のみ、
K1259-K1262 の「破壊高さ R=z+7 が y=6 行で全 z 共通」は z*(6)=10、
Z 切片 witness (12,6)@z=17..20・(14,6)@19・(16,6)@20 はいずれも z>=z*(6)=10 側。

つまり偶数 m の前線 witness は X=(m,m)（対角線 L2）・奇数 m は X=(m+1,m)

### 対角線 L1/L2 の宣言外 m への採引（E6）と宣言予想の判定

宣言で「L1 m=11..20・L2 m=11..22 の両線とも親値 2」を予想値として事前登録した。
**結果: 予想は偶奇で分かれた（部分的反証・これは fail ではなく事前登録予想の判定）**:

- **L1（X=(m+1,m)@z=2m−1, R*=3m）**: 奇数 m=11,13,15,17,19 は親 2（分離）・
  偶数 m=12,14,16,18,20 は親 1 = 単一 1（非分離）。
- **L2（X=(m,m)@z=2m−2, R*=3m−1）**: 偶数 m=12,14,16,18,20,22 は親 2（分離）・
  奇数 m=11,13,15,17,19,21 は親 0 = 単一 0（非分離）。
- 単一値の閉形式パリティ予想 (5m−1)/(5m−3) mod 2 は 22/22 点で成立。

前線法則（奇 m の鋭さ下界 z>=2m−1・偶 m の下界 z>=2m−2）と完全整合:
非分離側のセルは前線未満（z<z*(m)）なので 2トークン witness が存在しない
筈の位置にちょうど乗っている。

### 陰性バンド（94 セル）: 拡張掃引・アリティ電池ともに未解決（open）

E4: 陰性セル 94 個すべてについて d=61..200 拡張（13,160 点）とアリティ>=3 電池
（{m}^3・{m}^4・{m}^5・(m,m,m+1)・(m,m,m+2)・(m,m,2m)・(m,m,m,m+1)・
m=1 用 {1}^t t=9..12・計 658 点）を検査した結果: **2トークン witness も
アリティ witness も 1 つも発見されず、全電池点で窓端等式 bad 0**。

よって { (z,m) : m>=2, z < 2m−2+(m mod 2) } は「バッテリーおよび d<=200 の
範囲では witness 未発見」の open セル集合である。**2トークンに限れば、
出版 y<=22 族閉形式（K1248・K1256/K1257・全称確定）が全 d を決定するため、
陰性バンド内の 2トークン非分離は全 d で成立する（引用レベルの帰結・本実験では
d<=200 を機械確認）**。アリティ>=3 は未開拓であり、次の open problem になる:

**予想 C1（open・cell-level window extension）**: m>=2・z < z*(m) のセルでは
R*=z+m+1 でも全ての X（min(X)=m）で H(R*;X;z)=v(ΣX,z,R*) が成立する
（すなわち統合窓より真に 1 だけ広い保証崩壊域が低zバンドに存在する）。
成立すれば K1264 階段定理の窓の banded 拡張になる。反例はアリティ>=3 の
witness で与えられるはずで、本電池範囲では発見されなかった。

### {1}^t 行の min=1 アリティ census（E5・観測）

t=3..8 × z=0..24・R*=W(z,1)+1 での分離 presence（T1/T2 の z>=2 側の構造）:

- z=0 と z=1 は t=3..8 の全てで分離（T1・T2 があらゆる t で成立する傍証）。
- それ以上の z は t 依存の疎なパターン:
  t=3: z∈{0,1,2,3}・t=4: {0,1}・t=5: {0,1,3,4,5}・t=6: {0,1,3}・
  t=7: {0,1,3,5,6,7}・t=8: {0,1,3,5}（分離時の値は audit.json 記載）。
- m=1 のセル自体は 2トークン (x,1) で全セル鋭い（高密度: セル (0,1) では
  d=1..60 が全て分離）ため、{1}^t 行は cell sharpness には必須でない
  「アリティ構造」の観測（K1264 課題 4 のデータ）。
