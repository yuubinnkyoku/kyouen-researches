# ヒマワリ型残余ゲームの閉形式

任意のh≥1個の極小禁止辺が E_i=C∪P_i で、花芯Cと各非空花弁P_iが互いに素とする。c=|C|、p_i=|P_i|、P=Σp_i、N=c+P、m=min p_i。

空局面の通常Grundy値Gは、h奇数なら(N−1) mod 2。h偶数なら、c<mでN mod 2、c>mで(N−1) mod 2、c=mで2+(P mod 2)。自由点f個の追加はf mod 2とのxor。したがってG≤3。h偶数ではc=1、p_1=...=p_(h−1)=1、p_h=2でG=3。

証明：h奇数では極大安全集合のサイズがN−1またはN−hで同偶奇なのでK0305による。h偶数はNに関する帰納法。c=0では独立な単一禁止辺のxorでN mod 2。c≥1では、花芯着手はcを1減らし、p_i>1の花弁着手はp_iを1減らす。p_i=1の花弁着手では花芯だけが残余禁止辺となり、他の花弁が自由になるので子の値はN mod 2。c<mでは花芯着手の値が(N−1) mod 2、花弁着手は同値または2/3でmex=N mod 2。c>mでは花弁着手の値がN mod 2、花芯着手は同値または2/3でmex=(N−1) mod 2。c=mでは花芯と最短花弁への着手で子に0,1が揃う。最短でない花弁への着手は2+((P−1) mod 2)となる。全花弁が最短ならP=hmは偶数でmex=2、それ以外はmex=2+(P mod 2)。帰納法完了。

標準格子での任意の型の実現可能性、11×11探索の速度改善は主張しない。
