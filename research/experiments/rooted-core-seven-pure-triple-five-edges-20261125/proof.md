# 有限族の全長周期証明（7点・純三点辺・五本以下）

核の意味・正確な再帰・有限窓定理はK0682と同じ。ここでの新規主張は次の有限族に限る。

## 命題（有限・完全）

7頂点上の三点集合C(7,3)=35種類のうち高々5本からなる全てのclutter（純三点辺、根0固定の
根付き同型）と指定根に対し、根に長さLの二点禁止道を付けた通常Grundy列 f_C(L) は

```
f_C(L+34) = f_C(L)  for all L >= 571
```

を満たす。根付き同型で924型（Burnsideの補題でも独立に924を確認）、raw入力384168件を
全て被覆する。開始571はこの族と全残留状態の共同上界であり、個々の核の最小開始ではない
（最悪状態の最終周期破綻は570）。

## 証明の構造

1. **既知部分問題**：5点以下の全513型はK0682で全長証明済み。その保存整数値を
   0..1069はそのまま、それ以後は500からの周期34ブロックで延長して使う。これは
   証明済み値の利用であり、観測prefixの外挿ではない。
2. **新規状態の閉包**：924型の根を残す着手で到達する状態を `closure()` で列挙すると
   2948状態。うち5点以下344状態は既知表に一致し、新規は2604状態
   （7点924状態＝初期型そのもの、6点1680状態＝残余子）。
   **6点残余子のうち1379状態は三点辺の退化に由来する二点辺混在clutterである**
   （着手点を含む三点辺は `remap` で二点辺へ縮退する。二点辺は純三点辺族の包含構造を
   持たないため出版済み6点監査の範囲外であり、これらは本実験が初めて値を確定した）。
   残る301状態は純三点辺のままで、出版済みの6点全型監査・6点×6本以下監査の両方に
   全長完全一致で現れる。
3. **二重帰納**：状態の（根を残す）残余更新で `engine.play` に従い、長さの昇順で
   正確な再帰を計算（`solve_core.solve`）。既知344状態値は基底表から遅延拡張。
4. **有限窓認証**：各新規状態の最終周期破綻から `start = max(500, max+1)`、
   `needed = 2*start+69`。実測は `start=571`・`needed=1211` で、窓
   `start..2*start+35`（571..1177）について道列と全2604状態列の周期34一致を確認。
   K0682の有限窓定理により、この族と全到達状態は全長で571以降34周期
   (`jointly_certified=true`)。族全体のprefix上Grundy最大は33で、これは
   **二点辺混在の6点残留状態 `[6,[3,6,13,24,44]]`（二点辺3本＋三点辺2本・L=208）が
   唯一担う**。7点初期型自身の最大は27（6点純triple残留も27）。
5. **独立基底検証**：階層化無作為標本400状態（17層・seed 7）×長さ0..6で、再帰を
   使わない原始subset mex `direct()` とレコード値の一致（2800検査・安全状態922862）。
6. **同型検証**：枚挙の型数924をBurnside軌道数計算で独立導出（`verify_enum.py` E3）し、
   軌道安定化子の総和 Σ720/|Aut| = 384168 がraw件数と一致（E4）することで、
   選抜表と全ラベル入力の対応を群論的に確認。

## 監査範囲と限界

- `output/shards/part00..05.json` の `jointly_certified=true`、`joint_start_candidate=571`、
  `values_needed_through=1211` が有限証明の機械可読証拠。6シャードは
  `combine_records.py` で正規の単一ファイル（sha256
  `5a1efeba3f55dd0a4d82421ecea5b8245f99bf8844c1f1cd53365dfdf9bd1bc2`）に再結合できる。
- 7点の純三点辺でも6本以上、7点での二点辺混在・8点以上・無界サイズへの拡張は
  証明しない。K0684（一般固定核の全称34周期）は予想のまま。
- 数値 `maximum_grundy_in_prefix=33` はこの族のprefix上界であり、核によらない
  一様上界ではない。
- 開始571は6点×6本以下族（前回実験）と同じ値だが、本族の最悪状態
  `[6,[3,13,22,28,49]]` は二点辺混在の新規状態である（同値の再出現であり
  6点族の最悪状態とは別状態）。
- Grundy最大33を二点辺混在状態が唯一担う観測は、二点辺が純三点辺族より
  高いGrundy値を生成しうる最初の実証であり、混在核への一般予想の材料になる
  （全称主張ではない）。
