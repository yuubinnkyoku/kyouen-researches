# 長い固定幅盤の misère 補助 mex と通常 Grundy 値の完全交換則

2026-10-24。**証拠：全称数学的証明。** 有限完全列挙は独立照合であり、無界結論の根拠ではない。

## 記法

通常値 `g(S)=mex{g(S+p)}` は終局0。最後の合法手を打つ側が負ける misère 版の補助値 `h(S)=mex{h(S+p)}` は終局1。後者は直和の Sprague–Grundy 値ではなく、`h=0` が手番側負けを表す補助 mex である。

`τ(0)=1, τ(1)=0, τ(k)=k (k≥2)` とおく。

## 定理A：二次形式版・任意の実数係数

`D(w,m)={0,...,m−1}×{0,...,w−1}` 上の、四点の `det[x²+λy²,x,y,1]=0`（退化を含む）を禁止するゲームで、`λ∈R` とする。

`T_w=3+2{C(3w−2,3)−(w−1)}`（`T_1=3`）とすれば、**全ての `w≥1, m≥T_w, λ∈R`、全安全局面Sで**

```
h(S)=τ(g(S)).
```

空盤は misère 版では**偶数幅で先手勝ち、奇数幅で後手勝ち**（通常版と逆）。

奇数幅では全局面で通常版と misère 版の勝敗が反転する。偶数幅では、**通常 Grundy 値が2の二石局面だけが例外で、両ルールとも手番側勝ち**。その他の全局面は勝敗が反転する。

従って「両ルールとも手番側勝ち」の局面数は偶数幅に限り、既存の二石nimber2計数公式から次のように完全に決まる：

* `λ=0,w≥4`: `m C(w,2)`（`w=2` なら0）。
* `λ=−(a/b)²`（既約正整数 `a,b`）: `2[3N₂+Σ_{k≥4}N_k]`, `N_k=(m−ka)_+(w−kb)_+`。
* その他の実数λ: 0。

### 証明

既存の[全幅長盤定理](../quadratic-pencil-all-width-phase-20261024/README.md)により、`C=3w` とすると `m≥T_w` の極大安全配置は持ち上げ階数2の三石配置またはC石配置に限られ、四石以上の局面は必ずC石まで延長できる。

1. `|S|≥4` では終局までの手数が `C−|S|` に固定され、`g=(C−|S|) mod 2`、`h=(C−|S|+1) mod 2=τ(g)`。
2. 三石で持ち上げ階数2なら終局なので `(g,h)=(0,1)`。階数3なら全子が四石以上で `(g,h)=((C−3) mod2,(C−2) mod2)`。
3. `w` 奇数なら両種類の三石とも `(g,h)=(0,1)`。全二石は三石へ進めるため `(1,0)`、一石は `(0,1)`、空盤は `(1,0)`。
4. `w` 偶数なら階数3の三石は `(1,0)`、階数2の三石は `(0,1)`。任意の二石は非共線な第三石を加えて階数3にできる（同じ行の二石なら別行、異なる行の二石なら片方の行の別横座標）。従って階数2の三石へ延長できる二石は `(g,h)=(2,2)`、そうでない二石は `(0,1)`。
5. 偶数幅の一石には、同じ行の別の石を加えれば階数2の三石へ延長できない二石局面 `(0,1)` が得られる。他の二石も `(0,1)` または `(2,2)` なので、一石は `(1,0)`、空盤は `(0,1)`。全局面を尽くした。□

例外の個数は[既存の二石nimber2定理](../quadratic-pencil-two-stone-nimber2-20261024/README.md)から従う。

## 定理B：標準q点版・任意の固定幅

標準の「q点が共線または共円なら禁止」（`q≥4`）に対し、[固定幅十分長さ定理](../../knowledge/items/K0024-fixed-width-q-point-threshold.md) の `m≥T_{w,q}` を仮定する。全極大安全配置が `C=(q−1)w` 石なので、全安全局面で

```
g(S)=(C−|S|) mod 2,
h(S)=(C−|S|+1) mod 2=τ(g(S)).
```

misère 空盤は `(q−1)w` が偶数なら先手勝ち、奇数なら後手勝ち。二石例外はない。

既存の鋭い閾値を適用すると、`3×m,q=5,m≥12` は misère 先手勝ち、`4×m,q=8,m≥11` も先手勝ち、`3×m,q=4,m≥24` は後手勝ち。

## 有限完全列挙と限界

`python3 research/experiments/quadratic-pencil-misere-phase-20261024/verify.py`

検証器は有理数係数を整数にスケールした3×3差分行列式で禁止四点組を全列挙し、全安全局面の通常mex（終局0）とmisère補助mex（終局1）を**別々に**再帰計算する。

閾値内の `1×3,1×4,2×9`（3係数）, `2×10` の計**54,088安全局面**では交換則不一致0。閾値未満の `3×4,λ=−1`, `3×5,λ=0`, `4×4,λ=−1` ではそれぞれ交換則不一致4、8、91。結果は `results.json`。

長盤の全局面を直接列挙したわけではない。定理Aの無界部分は既存の極大配置・Grundy定理と上記のmex帰納に、定理Bは既存のq点固定幅定理に依存する。
