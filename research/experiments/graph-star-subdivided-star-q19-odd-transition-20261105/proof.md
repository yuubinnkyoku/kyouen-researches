# 一辺細分星 q=19 の奇数次数実根切替（2026-11-05）

## 定理（全称解析＋厳密有理数不等式）

[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
]
について r=q-3、奇数 k≥3 とする。

1. q=19 では奇数 3≤k≤151 に実根はない。
2. q=19 では奇数 k≥153 に相異なる負の単実根がちょうど2個ある。
3. 任意の整数 q≥19、奇数 3≤k≤151 に実根はない。

## 証明

既存の q=18 の証明と同じ変数変換 u=-(r+1)y を用いると、負の実根の候補は 1<y<a=1+1/(r+1) に限られ、その条件は
[
F_{k,r}(y)=r-y-(a-y)y^k=0
]
である。正の u には根がない。

r=16、a=18/17 とする。k=151 に対し H(y)=(a-y)y^{151} は [1,a] で最大値
[
H^*=(a-y_*)y_*^{151},qquad y_*=rac{151a}{152}
]
を取る。厳密な有理数比較で H^*<16-a が成立する。したがって全 y∈[1,a] で H(y)≤H^*<16-a≤16-y、つまり F_{151,16}(y)>0 である。y>1 において H は k に単調増加するため、奇数 3≤k≤151 でも根はない。

k=153 では y=153a/154 を選ぶと F_{153,16}(y)<0 が厳密に成立する。k を増やすと F は減少するため、全奇数 k≥153 でも負値が存在する。一方 F(1)>0、F(a)>0 なので少なくとも2個の相異なる根がある。T_{k,r}(-x) の符号変化は2回であるからデカルトの符号法則より重複度込みで高々2根。従って2個の単実根である。

r≥16 について、候補区間 (1,1+1/(r+1)) は (1,18/17) に含まれ、固定 y>1 で F_{k,r} は r に関して狭義増加する（導関数 1+y^k/(r+1)^2>0）。従って q≥19 にも非存在が及ぶ。

## 再現（Python 3、整数比のみ）

```python
from fractions import Fraction as Q

r = 16
a = Q(18, 17)
k = 151
y = a * k / (k + 1)
assert (a - y) * y**k < r - a

k = 153
y = a * k / (k + 1)
assert 1 < y < a
assert r - y - (a - y) * y**k < 0
```

**証拠区分:** 全称解析的証明と厳密有理数不等式。一般 q の接触二重根不存在は主張しない。前回 q=18 と異なり、今回の非存在側は区間分割を要しない。
