## 命題候補（observed・有限範囲で確定・全称は未証明）

すべての z>=0・x>=12・R>=0 に対して H(R;(x,12);z) = cand12(z,x,R)。cand12 は以下の z 偶奇別 T/P 集合表
（`cand12.py` が正本・Y=12・b_k = 奇 offset {1,3,...,2k-1}・offset o = R-z・d = x-z）。

### 値2集合 in_T12（probe 71,672 点で mismatch 0・probe box 内に値3は出現せず値域 {0,1,2}）

- ラダー: 奇z 奇R O[1,z]／偶z 奇R O[1,z-1]（族式どおり・y=10/y=11 と同一）
- マージ行 x <= z-13: O[1, q_odd(x+12)]（= 単一トークン single_token(x+12,z,R) の値2そのもの）
- 対角行 d = -12: 奇z 偶offset [2, z+12]／偶z 奇offset [1, z+11]（cap = z+y-[z≡y (mod 2)] の y=12 値。
  偶y 族式・y=10 と同じ向き。偶z 対角行は値1を一切持たない）
- 前倒し pin 格子行（pin = z+(d+36)/2 = z+(d+3y)/2・pin 行の d は y 偶族で 奇z d≡y≡0 (mod 4)・偶z d≡y+2≡2 (mod 4)）:
  - 奇z: d ∈ {-8,-4,0,4,8,12} = [-y+4, y]（**6行**・y=6/8/10 に続き y 偶族式 4 族的確定・y11 の 6 行と同数）→ pin ∈ {z+14,z+16,z+18,z+20,z+22,z+24}
    （最終 pin 行 d=12=y・pin z+24 = 2y+z は直後の定常 pin と同値）
  - 偶z: d ∈ {-10,-6,-2,2,6,10} = [-y+2, y-2]（**6行**・y=6/8/10 の偶y 族式 4 族的確定）→ pin ∈ {z+13,z+15,z+17,z+19,z+21,z+23}
    （y=11 偶z は 5 行だったので偶z側 pin 6 行は本族が初例）
- 掃引行 d = 13 = y+1: 奇z 偶offset [z+24, x+z+12]（= O[2y+z, x+z+y]∩(offset偶)）＝ x=z+13 偶で base 型／
  偶z 奇offset [z+25, x+z+12]（= O[2y+z+1, x+z+y]∩(offset奇)・x=z+13 奇で I 型）
  （y=10/y=11 と同じ族式・帯の偶奇は offset 基準・偶z 掃引帯は pin 格子の延長線上にあり末項 z+25 は定常 pin と同値）
- 定常行 d >= 14: {z+24}（奇z）/{z+25}（偶z）（2y+z／2y+z+1）

### 値1集合 in_P12（probe 全点で mismatch 0・Tとの重複 0）

- マージ行: S=x+12 が奇（= x 奇）のとき I[q_odd(S)+1, ∞)。y=12 は偶数 y 型で値1無限帯は x 奇の行
  （y=10 と同型・y=11 の逆）。tail 値も奇数 x 行。
- 基底点: base12 = b12 = {z+1,z+3,...,z+23}（12 点）。基底点 y 点仮説 {z+1,...,z+2y-1} の y=12 版が
  有限全範囲で確定（y=1..12 連続の 12 例目）。
- 奇z 行別構造（d 偶 = x 奇行は I 型、d 奇 = x 偶行は base。k は2式・th は pin 衝突の mod 4 則）:
  - I 帯行 d ∈ {-12,-10,-8,-6,-4,-2,0,2,4,6,8,10,12}（d 偶 13 行・対角を含む）:
    k(d) = floor((d+38)/4)（= 6,7,7,8,8,9,9,10,10,11,11,12,12・飽和なし）・
    **th(d) = ceil((d+37)/2) = ceil((d+3y+1)/2) で d=-12..12 の掃引ごとに 13,14,15,...,25 の全整数を1回ずつ通る**
    （th 表の単一式化・y=10 の th=2k・y=11 の th=2k+1 がほぼ偶数/奇数ペアだったのに対し y=12 は連続整数掃引）。
    P = b_k(d) ∪ I[th(d), ∞)。**pin スロット (d+3y)/2 = th(d)-1** は
    d ≡ 0 (mod 4)（pin 行・{-12 対角 cap 引き込みを含む}）では偶 offset の値2 pin を担い、
    d ≡ 2 (mod 4) では奇 offset の b_k 上端点（値1）と一致する。この th-1 スロット交替が
    T/P 重複 0 を実現する pin-Th衝突構造。
  - base 行 d ∈ {-11,-9,-7,-5,-3,-1,1,3,5,7,9,11}（d 奇 12 行）: P = b_k(d) のみ。k = floor((d+37)/4) = floor((d+3y+1)/4)
    （= 6,7,7,8,8,9,9,10,10,11,11,12）。
  - d=13（掃引・x 偶）: base12 のみ（掃引 T 帯が偶offset [z+24, x+z+12] を占有し band は置けない・tail も x 偶で値0）
  - d>=14（定常）: base 型（d 偶）は b12 ∪ 偶offset [z+26, x+z+12]（= O_z[2y+2+z, x+z+y]∩(offset偶)）・
    I 型（d 奇）は b12 ∪ 偶offset band ∪ tail（x 奇）
- 偶z 行別構造（d 奇 = x 奇行は I 型、d 偶 = x 偶行は base。**base k = 奇z と同一式 floor((d+3y+1)/4)・
  I 帯行は k(d) = floor((d+35)/4) = floor((d+3y-1)/4)（y=11 の偶z I 帯式 floor((d+32)/4)=floor((d+3y-1)/4) と同一族式）**:
  - d=-12（対角）: 値1なし（偶z 対角行は R<=z+11 の奇数列を値2で占有し z+12 以降は全て値0。
    y=8/y=9/y=10/y=11 に続き **5 族連続**）
  - I 帯行 d ∈ {-11,-9,-7,-5,-3,-1,1,3,5,7,9,11}（d 奇 12 行）: k(d) = floor((d+35)/4)（= 6,6,7,7,8,8,9,9,10,10,11,11）・
    th = 2k+1（= 13,13,15,15,17,17,19,19,21,21,23,23）で P = b_k ∪ I[2k+1, ∞)。
    pin はすべて偶z base 行（偶 d）側にあるため I 帯開始との衝突は存在しない
    （y=12 偶zの pin 《off 13..23 奇》は base 上端 2k-1 の +2 位置）
  - base 行 d ∈ {-10,-8,-6,-4,-2,0,2,4,6,8,10,12}（d 偶 12 行）: P = b_k(d) のみ。k = floor((d+37)/4) = floor((d+3y+1)/4)
    （= 6,7,7,8,8,9,9,10,10,11,11,12・d=12 は b12 に到達し飽和なし）
  - d=13（掃引）と d>=14（定常）: b12 ∪ 偶offset [z+26, x+z+12] ∪ tail（x 奇で tail 有効）。
    掃引 T 帯は奇offsetを占有するため偶offset band と共存
- tail: x 奇 のとき I[x+z+13, ∞)（= x+z+y+1）。tail 値 (x+12) mod 2。
  probe 71,672 点中 tail 領域 R>=x+z+13 は 13,888 点全一致。

### 初稿からの修正点（fitting 反復の記録）

初稿（y=10 外挿・PINS/k 定数を素直に引き伸ばしたもの）は probe 71,672 点中 240 点不一致・overlap 48 で、
すべて z 偶数の非マージ行と z 奇数の pin 板衝突に集中していた。修正は次の 3 点:

1. 偶z base 行（d 偶）の k: (d+33)//4 → **(d+37)//4**（全 box で確定）
2. 偶z I 帯行（d 奇）の k: (d+36)//4 → **(d+35)//4**、I 開始: off >= 2k → **off >= 2k+1**（13 行全部で th ペア 13,13,15,15,...,23,23）
3. 奇z I 帯行の th: 固定 2k → **ceil((d+37)/2)**（pin 行 d≡0 (mod 4) では pin が off=th-1 を占有するため P は th を 1 つ後ろに下げる）。
   これで z 奇数 pin 6 行・対角行・最終 pin 行 d=12 の T/P 重複 48 が 0 になった。

修正後の th/構造の生値確認: z=21 x=13（d=-8）で off13=1・off14=2(pin)・off15..=1、z=13 x=15（d=2）で
off19=1・off20=1・off18=0、z=17 x=29（d=12）で off23=1・off24=2(最終pin)・off25..=1、
z=25 x=13（対角）で off12=2(cap)・off13..=1、z=10 x=22（偶z d=12）で b12 のみ、
z=0 x=13（偶z d=13）で pin(slot off25)・tail off>=26 が全て1 などが生値と整合した。

## y=10/y=11 出版表との横断判定（有限範囲・全称ではない）

- tail 開始式 x+z+y+1: y=12 で一致（x+z+13・y=2..12 の 11 族連続の予想を支持）
- tail 値 (x+y) mod 2・値1無限帯の x 偶奇: y=12 は偶数 y 型（x 奇の行）で y=10 と同型
  （y 偶奇が行型を決ける観察 12 族連続）
- マージ命題 x<=z-(y+1): y=12 で一致（x<=z-13・probe 1,428 点＋回帰 16,542 比較）
- 基底点 y 点仮説 {z+1,..,z+2y-1}: y=12 で 12 点が一致（y=1..12 連続の 12 例目）
- 対角行上端格子規則 cap = z+y-[z≡y (mod 2)]: y=12 で全 probe z 一致（奇z z+12／偶z z+11）
- 定常 pin 2y+z／2y+z+1: y=12 で一致（z+24/z+25）
- pin 統一式 pin=z+(d+3y)/2〔d≡y (mod 4)（奇z）・d≡y+2 (mod 4)（偶z）〕: y=12 で成立（**8 族連続**）。
  pin 行数は 奇z 6 行（y 偶族式 [-y+4,y] の 4 族的確定）・偶z 6 行（偶y 族式 [-y+2,y-2] の 4 族的確定）
- 偶z 対角行の値1全欠如: y=8/9/10/11 に続き **5 族連続**
- 最終 pin 行 d=y の I[2y+z+1) 型（奇z d=12: b12 ∪ I[z+25)・pin z+24 skip）: y=6/8/9/10/11 に続き **6 族連続**
- band 下端 2y+2 = 26: 定常・掃引帯の偶 offset band 下端として出現（y=10: 22・y=11: 24・y=12: 26）
- base 行 k(d)=floor((d+3y+1)/4): y=10・y=11・y=12 の 3 族で base 行（各族の行型反転込み）すべて同一族式
  （y=10 z-odd/z-even base・y=11 z-odd/z-even base・y=12 z-odd/z-even base で全て成立）
- 偶z I 帯行 k(d)=floor((d+3y-1)/4): y=11・y=12 の 2 族で同一族式（y=10 は floor((d+3y+3)/4) で異なる）
- 奇z I 帯行 th: y=10 は 2k・y=11 は 2k+1・y=12 は **ceil((d+3y+1)/2) の連続整数掃引**（13,14,...,25）で
  pin スロット (d+3y)/2 = th-1 との衝突 mod 4 則を伴う（一般化は margin 塔分析の観察対象）
