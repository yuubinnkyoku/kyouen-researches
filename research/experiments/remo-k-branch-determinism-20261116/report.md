## 設定と規約

REMO（K0859 の規則）: r 人が P_0, P_1, … の巡回で空きセルに石を置く。
着手は「置いた集合がある枝 A_i の部分集合のまま」である限り合法。
置いた集合が初めてある枝 A_i と一致した時点（極大到達）、
**手番に直面しているプレイヤー**（= 枝を完成させた者の次の手番者）が敗者と
なり、敗者の石がすべて取り除かれる。取り除いた後も極大なら鎖的に次の
手番者も敗者（チェーン規則）。残り 1 人で終了、アウトカムは
(排除順序, 生存者)。プレイヤー表記は 0-indexed（P_0, P_1, P_2）、
監査 JSON の `survivors` 等と一致する。

k 枝点族: k 個の極大集合 A_1, …, A_k（どの A_i も他の部分集合でない）。
atom: 空でない S ⊆ {1..k} に対し a_S = ちょうど
{A_i : i ∈ S} に属するセル数。k=3 では mask 順
{1},{2},{12},{3},{13},{23},{123} の 7 個（添字は mask−1）。
シングルトン atom a_{ {i} } ≥ 1 が極大性（どの枝も他の部分集合でないこと）を
保証する。枝サイズ C_i = Σ_{S ∋ i} a_S、全セル数 N = Σ_S a_S、
γ = a_{123}（共通コア）。サイズ多重集合は昇順ソートで正規化する。
プロファイルの正規化: 分枝置換（k=3 では S_3 の6元）による同値で簡約
（走査は正規形のみ。N ≤ 13 の正規形プロファイル数 3790 は
Burnside で独立検証済み: fix(id)=19448、fix(置換)=1064×3、
fix(3-cycle)=50×2、(19448+3·1064+2·50)/6 = 3790）。

チェーンプロファイル: a_{123} = γ、シングルトンが C_i − γ、他の atom は 0。

## 定理 E′（軌道簡約・全称）

**主張.** k 枝点族上のセルレベル REMO のアウトカム集合は atom プロファイル
(a_S)_S と (k, r) のみで決まる。より強く、任意のゲーム状態は
「atom ごとの着手者別占有カウント + 手番者 + 生存者集合」の計数状態まで
簡約でき、計数状態が等しい2状態のアウトカム集合は等しい。
領域計数ゲーム（実装 `region_game_k`）はこの簡約そのものであり、
セルレベルゲームと同じアウトカム集合を返す。

**証明.** 状態の十分統計量であることを構造的帰納法で示す。

(a) *極大性*: 置かれたセル集合 P について P = A_i ⟺
「A_i 内の占有カウントの総和 = C_i」かつ「A_i 外の atom の占有カウントが
すべて 0」。どちらも計数状態で決まる。

(b) *合法手*: 空きセル c（属する atom を m とする）が合法 ⟺
ある i が存在して P ⊆ A_i かつ m が枝 i を含む。P ⊆ A_i は
「枝 i を含まない atom の占有カウントがすべて 0」と同値で計数状態で
決まり、m の枝帰属は atom で決まる。よって**合法な atom の集合**は
計数状態で決まり、同一合法 atom 内のどのセルに置いても
次の計数状態は同一である。

(c) *排除*: 敗者の石の全削除はカウントの消去であり計数状態で決まる。
削除後の極大性判定（チェーン規則の発火）も (a) と同様。

(d) *終了条件*: 生存者集合の要素数はカウントの零と手番で決まる。

(b) により「同じ atom の中のどのセルか」という情報は次状態に受け継がれず、
帰納法で全アウトカムが計数状態の関数になる。ゲームは有限で終局するので
帰納法は健全である（実装のメモ化再帰と同じ DAG 上の構造的帰納法）。□

K0860 の定理 E は k=2 の場合に相当する。本実験では E′ を k=3（r=3, 4、
チェーン+ペア atom 混合サンプル 16 インスタンス）、k=4（r=3、
3 重複合プロファイル・セル状態 84）でセルレベルと領域ゲームの
全アウトカム一致を機械確認した（`cell_vs_region_k3`, `k4_varied_profile`）。
**注意**: E′ は「atom プロファイルまで決まる」ことのみを言う。
プロファイルからさらに (サイズ, γ) へ坍縮できるかは別問題で、
k=2 では可能（K0860 定理 E）、k=3 では下記の通り**偽**である。

## 定理 F′（3枝共通コア族・r=3 の閉形式・全称）

**主張.** チェーンプロファイル、C1 ≤ C2 ≤ C3、min C_i ≥ 3、0 ≤ γ < C1 とする。
r = 3 の REMO アウトカム集合は次で与えられる。各第1終端枝
L1 ∈ {C1, C2, C3} に対し:

- 第1敗者 λ = L1 mod 3（手番者が L1 個目の石で枝を完成させ、次の手番者 λ が
  極大局面に直面する）。この時点で λ は o = ⌊L1/3⌋ 個の石を持ち、
  残る sp = L1 − o = ⌈2L1/3⌉ 個は生存者2人の石で、すべて A_i 上にある。
- 第2段階（2人で交互に置く）の終端枝を L2 とすると、
  第1排除後の総着手数はちょうど m = L2 − sp である。
  dip（枝の切り替え）は残り石すべてがコア（γ セル）上にあるときのみ
  合法で、その条件は sp ≤ γ、すなわち **o ≥ L1 − γ** と同値。
  このとき L2 ∈ {C1, C2, C3} が任意に取れる（コア ⊆ A_j、
  sp ≤ γ < C1 ≤ C_j より m = L2 − sp ≥ 1）。
  dip しない（またはできない）場合 L2 = L1 で m = o。
- 第2敗者 μ = (λ + 1 + (m mod 2)) mod 3（2人交互なので m 手後に
  手番に直面するのは λ+1（m 偶）または λ+2（m 奇））。
- 生存者 σ = (−λ − μ) mod 3。アウトカムは ((λ, μ), σ)。

**dip タイミング不変性（本証明の要）**: 第1排除後にコア上へ t 個
追加で置いてから dip しても、第2終端までの総着手数は
t + (L2 − sp − t) = L2 − sp で不変であり、μ, σ は dip の
時点に依らない。よって閉形式では即時 dip だけを列挙すればよい。

**証明スケッチ**: 第1段階で枝 i が最初に埋まるまでの着手数は L1 で
決まり、手番と所有数は巡回のみで決まる（どのセルに置いたかは
E′ により無関係）。第1排除後、A_i の空きセルは敗者の石があった o 個。
dip の可否は「生存者2人の石がすべてコア上に置ける」ことと同値で、
これは sp ≤ γ と必要十分（コア γ セルのうち sp を生存者が占め、
残りはすべて敗者の石で埋まる構成が取れる。
逆に sp > γ ならコア外に生存者の石が残り、P ⊆ A_j が成立しない）。
dip 後は P ⊆ A_j が保たれ枝 j 以外は合法でなくなるので L2 で確定、
m 手後に第2極大で μ が排除され r=3 なので終局。
o ≥ ⌊C1/3⌋ ≥ 1 なので第1排除直後に極大が残ることはなく、
チェーン規則は r=3・k=3 では発火しない。□

機械検証: サイズ格子 C1 ∈ 3..5, C2 ≤ 7, C3 ≤ 9 の 55 三つ組 ×
全有効 γ の 207 インスタンスで、領域ゲームと閉形式の
`determined / survivors / first_losers / orders / order_determined`
が完全一致（mismatch 0, skip 0）。第1敗者は全インスタンスで
{C_i mod 3} と一致（K0339 の剰余公式とも整合）。

## 系: 3枝チェーンの4分体無限族（全称）

F′ に (C1, C2, C3) = (6u, 9u, 12u) および (6u, 12u, 18u) を代入する。
いずれも C ≡ 0 (mod 3) なので λ = 0（第1敗者は常に P_0）で、
Δ = C3 − C1 は 6u ≡ 0 (mod 3)（K0339 の r|Δ と整合）。

**(6u, 9u, 12u), u ≥ 1**: o = 2u, 3u, 4u、sp = 4u, 6u, 8u。
各 L1 について locked パスの m は 2u, 3u, 4u。
- u 偶: すべての m（locked と自由 dip L2 ∈ {6u, 9u, 12u} の
  m = L2 − sp ∈ {2u, 5u, 8u} ∪ {2u, 4u, 6u} ∪ {4u, u, 6u}）
  がすべて偶 → μ = 1、σ = 2。**全パス生存者 P_2 で決定的**。
- u 奇: locked パスだけでも L1 = 6u なら σ = 2、
  L1 = 9u なら m = 3u 奇 → σ = 1 で、**γ によらず非決定的 {P_1, P_2}**。
- よって決定性 ⟺ u 偶（γ 無関係・全称）。

**(6u, 12u, 18u), u ≥ 1**: 各 L1 の locked m = 2u, 4u, 6u、
自由 dip の m ∈ {2u, 8u, 14u} ∪ {4u, 10u} ∪ {6u} はすべて偶。
よって全パス μ = 1, σ = 2、**常に決定的・生存者 P_2**（γ 無関係・全称）。

機械確認: u ∈ {1, 2} × 全 γ で領域ゲーム・閉形式・上記判定が一致
（36 インスタンス）。u に関する無限部分は上の mod 計算が証明する。

## Δ=0（同一枝サイズ）と K0859 定理 D

枝サイズがすべて等しい（Δ=0）の一様点族では、REMO の全敗者順と生存者は
K0859 定理 D の漸化式（公開表 (C, r)）で決まる。本実験は
Δ=0 の 3枝点族への適用範囲を機械確認した:

- k=3 ペア走査 (N ≤ 13) 中の Δ=0 プロファイル 146 個すべて:
  生存者単一かつ全敗者順も定理 D の値に一致（atom 構造によらない）。
- k=2 チェーン C = 2..8 ×全γ× r ∈ {3,4}（70 インスタンス）、
  k=3 チェーン C = 3..7（50）、k=4 チェーン C ∈ {2,3}（10）:
  すべて生存者・全敗者順が定理 D 一致。

新規の主張ではないが、k ≥ 3 で atom 構造（ペア atom・三重 atom の配分）を
変えても崩れないことを 146 プロファイルで確認した点が今回の増分である。

## センサス: 3枝チェーン格子（有限）

- **r=3**: C1 ∈ 3..5, C2 ≤ 7, C3 ≤ 9、55 三つ組 ×全γ = 207 インスタンス。
  決定的 35、うち排除順まで決定的 15、非決定的 172。
  最小非決定チェーン: (3,3,4) γ=0（生存者 {P_1, P_2}）。
  γ 依存（同じサイズで γ により決定性が変わる）する三つ組は
  この格子内では (3,3,8) のみ: γ=0, 1 は決定的 [P_1]、γ=2 は非決定。
  「決定的だが排除順は2通り」の例として (3,3,8) γ ∈ {0,1} がある。
- **r=4, 5, 6**: C1 ∈ 3..5, C2 ≤ 6, C3 ≤ 7 の 103 インスタンスずつ
  （予算スキップなし）。決定的 25 / 18 / 18。いずれの r でも
  最小非決定は (3,3,4) γ=0。r=3 の閉形式は r ≥ 4 では
  チェーン規則が発火し得るため適用外（センサスのみ）。

## 主発見: (サイズ, γ) 非坍縮 — 有限反例（N ≤ 13, r=3, k=3）

K0860 定理 E により k=2 ではアウトカムは (C1, C2, γ) のみで決まる。
k=3 でこれが崩れる: **サイズ多重集合と γ が同一でも atom プロファイルが
違えば決定性が変わる**。全プロファイル走査（セル数 N ≤ 13、正規形
3790 個・Burnside 検証済み、決定的 523・非決定的 3267、スキップ 0）で
(サイズ, γ) キーごとの決定性の不一致を 15 キー検出した
（サイズのみでの不一致は 7 多重集合）。

不一致 15 キーのうち最小のもの（決定的側の最小セル数 11）:

| sizes | γ | 決定的側 (atoms, セル数) | 生存者 | 非決定的側 (atoms, セル数) | 生存者 |
|---|---|---|---|---|---|
| (2,3,8) | 0 | (1,1,1,7,0,1,0) 11 | [1] | (1,1,0,5,1,2,0) 10 | [1,2] |
| (2,3,8) | 1 | (1,2,0,7,0,0,1) 11 | [1] | (1,1,0,6,0,1,1) 10 | [1,2] |
| (3,3,8) | 0 | (1,1,1,6,1,1,0) 11 | [1] | (1,1,0,4,2,2,0) 10 | [1,2] |
| (3,3,8) | 1 | (1,1,1,7,0,0,1) 11 | [1] | (1,1,0,5,1,1,1) 10 | [1,2] |
| (8,8,9) | 3 | (1,1,2,2,2,2,3) 13 | [1] | (1,1,3,2,1,2,3) 13 | [0,1,2] |
| (8,8,9) | 5 | (1,1,2,4,0,0,5) 13 | [1] | (1,1,1,2,1,1,5) 12 | [0,1,2] |

完全な 15 キー一覧は `output/remo_k_branch_audit.json` の
`pair_scan_r3.sizes_gamma_disagreements` を参照（各キーに両側の
最小セル witness と生存者を記録）。読み取り方の要点:

- **同一セル数の最軽ペア**: サイズ (8,8,9)・γ=3 で
  決定的 (1,1,2,2,2,2,3)（13 セル、生存者 [P_1]）と
  非決定的 (1,1,3,2,1,2,3)（13 セル、生存者は 3 人全員 [P_0,P_1,P_2]）。
  セル数・サイズ・γ が完全に一致し決定性だけが異なる。
- 15 キーすべてにサイズ 8 または 9 の「大枝」とサイズ 2–3 の小枝が
  含まれる（この走査範囲での観察。普遍主張ではない: 走査はセル数
  N ≤ 13 基準なので、サイズ ≤7 でセル数の大きいプロファイルは
  未走査である）。
- witness の構造: 決定的側は小枝→大枝の重なり（{13},{23} atom）が
  薄く（=1 前後）分散する配置、非決定的側は重なりが厚く集中する配置に
  現れる傾向がある（定性観察）。
- これらの witness 5 件（両側＋チェーン (3,3,8) γ=0）は
  セルレベルゲームとの全アウトカム一致でも確認済み
  （定理 E′ の実例）。

**γ 依存（サイズのみでは決まらない）**: 7 多重集合
(2,3,8), (2,8,9), (3,3,8), (3,8,8), (3,8,9), (8,8,9), (8,9,9)
で γ により決定性が変わる。チェーン (3,3,8) は γ=0,1 で決定的 [P_1]、
γ=2 で非決定 {P_1, P_2}（上の格子と同じ現象がペア走査でも現れる）。

**帰結のまとめ**: k=3 の決定性は少なくとも atom プロファイル全体を
必要とし（E′ の意味でそれで十分）、「サイズ+γ」への坍縮は不可能。
一方チェーンプロファイルに限れば F′ により (C1, C2, C3, γ) の閉形式がある。
残る問い: (i) ペア atom を含む族の決定性の特徴づけ、
(ii) サイズ ≤7 での不一致の有無（要・広域走査）、
(iii) 15 キーで「決定的側は常に [1]・小枝サイズ 2–3」という
観察の安定性、はいずれも未解決。

## 限界

- センサス・走査はすべて**有限**（N ≤ 13、チェーン格子は上記範囲）。
  普遍的なのは E′・F′・4分体系・(K0859 定理 D に帰着する Δ=0) のみ。
- r ≥ 4 の 3枝チェーンは閉形式なし・センサスのみ（チェーン規則の
  発火のため F′ の議論がそのままでは使えない）。
- (サイズ, γ) 非坍縮は反例の列挙であり、特徴づけではない。
- 11×11 空盤・クラスフロンティアは本実験と無関係で UNKNOWN のまま。
