# 2トークン残余ゲーム \(z=6,\ y=21\) 切片の全Grundy分類

## 定理

\[
H(R;(x,21);6),\qquad x\ge21,\ R\ge0
\]
のGrundy値は常に \(0,1,2\) である。値2となる残容量は

\[
\boxed{
T_{21}(x)=\{1,3,5\}\cup
\begin{cases}
\{45\}&x=21,\\
\{47\}&x=25,\\
\{49,51,53,55\}&x=28,\\
\{49\}&x\ge29,\\
\varnothing&\text{その他}.
\end{cases}
}
\]

奇数・偶数の区間を
\[
O[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv1\pmod2\},\qquad
E[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv0\pmod2\}
\]
と書き、無限区間も同様に定める。値1となる残容量は

\[
\boxed{
P_{21}(x)=
\begin{cases}
O[7,43],&x=21,\\
O[7,\infty)\cup E[46,\infty),&x=22,\\
O[7,45],&x=23,\\
O[7,\infty)\cup E[48,\infty),&x=24,\\
O[7,45],&x=25,\\
O[7,\infty)\cup E[48,\infty),&x=26,\\
O[7,47],&x=27,\\
O[7,47]\cup E[50,\infty)\cup O[57,\infty),&x=28,\\
O[7,47]\cup E[50,56],&x=29,\\
O[7,47]\cup E[50,x+27],&x\ge30\text{ 奇数},\\
O[7,47]\cup E[50,\infty)\cup O[x+29,\infty),&x\ge30\text{ 偶数}.
\end{cases}}
\]

値0の位置は \(T_{21}(x)\) と \(P_{21}(x)\) の補集合である。一般tail定理から

\[
\boxed{R\ge x+28\implies H(R;(x,21);6)=(x+21)\bmod2}
\]
も成り立つ。

## 再帰と依存

親の選択肢値を
\[
\begin{aligned}
A&=H(R-1;(x-1,21);6),\\
B&=H(R-1;(x,20);6),\\
C&=1\oplus H(R-1;(x,21);5)
\end{aligned}
\]
とする。

\(x=21\) ではAの子のトークン対 \((20,21)\) が降順正準化で \((21,20)\) となり、Bの子と同一状態になるのでK0913で評価できる。\(x\ge22\) ではAを同じ \(y=21\) 切片の \(R\) 強帰納仮説、BをK0913、CをK0873の \(z=5\) 全Grundy公式で評価する。

K0832のTheorem Tにより、奇数Rの親では選択肢値が \(\{0,1\}\) に含まれ、偶数Rの親のGrundy値は高々1である。したがって奇数親の署名 \(\{0,1\},\{0\},\{1\}\) のmexはそれぞれ \(2,1,0\)。偶数親では署名に0が含まれるときだけ値1となり、含まれなければ値0となる。

## 選択肢署名表

各欄は \(\{A,B,C\}\) の値集合である。端点を含み、奇数R列では奇数だけ、偶数R列では偶数だけを読む。表は \(1\le R\le x+27\) を覆う。

| x | 奇数Rの署名 | 偶数Rの署名 |
|---:|---|---|
| 21 | 1..5:{0,1}; 7..43:{0}; 45:{0,1}; 47:{1} | 2..6:{2,3}; 8..48:{1} |
| 22 | 1..5:{0,1}; 7..49:{0} | 2..6:{2,3}; 8..44:{1}; 46:{0,2,3}; 48:{0} |
| 23 | 1..5:{0,1}; 7..45:{0}; 47..49:{1} | 2..6:{2,3}; 8..50:{1} |
| 24 | 1..5:{0,1}; 7..51:{0} | 2..6:{2,3}; 8..44:{1}; 46:{1,2}; 48..50:{0} |
| 25 | 1..5:{0,1}; 7..45:{0}; 47:{0,1}; 49..51:{1} | 2..6:{2,3}; 8..52:{1} |
| 26 | 1..5:{0,1}; 7..53:{0} | 2..6:{2,3}; 8..46:{1}; 48:{0,2,3}; 50..52:{0} |
| 27 | 1..5:{0,1}; 7..47:{0}; 49..53:{1} | 2..6:{2,3}; 8..46:{1}; 48..54:{1,2,3} |
| 28 | 1..5:{0,1}; 7..47:{0}; 49..55:{0,1} | 2..6:{2,3}; 8..46:{1}; 48:{1,2,3}; 50..54:{0} |
| 29 | 1..5:{0,1}; 7..47:{0}; 49:{0,1}; 51..55:{1} | 2..6:{2,3}; 8..46:{1}; 48:{1,2,3}; 50..56:{0,2} |
| \(x\ge30\) | 1..5:{0,1}; 7..47:{0}; 49:{0,1}; 51..\(U_o\):{1} | 2..6:{2,3}; 8..46:{1}; 48:{1,2,3}; 50:{0,2}; 52..\(U_e\):{0} |

最終行の端点は
\[
U_o=\begin{cases}x+26&x\text{ 奇数},\\x+27&x\text{ 偶数},\end{cases}
\qquad
U_e=\begin{cases}x+27&x\text{ 奇数},\\x+26&x\text{ 偶数}.\end{cases}
\]
である。x=29を独立行にしたのは、A子が例外切片x=28を参照するためである。x≥30ではA子・B子・C子がそれぞれ定常式に入り、各区間端点はxの一次式で比較できる。よって最終行は有限標本からの外挿ではない。

奇数親の \(\{0,1\}\) 署名から値2位置が得られ、偶数親ではTheorem Tにより値2は生じない。値1位置は奇数親の \(\{0\}\) 署名、偶数親で0を含む署名、およびtailを合わせると上の \(P_{21}(x)\) となる。表の範囲外 \(R\ge x+28\) は一般tail定理、\(R=0\) は終局値0で覆われる。従ってRに関する強帰納が閉じ、全 \(x\ge21,R\ge0\) で分類が成立する。∎

## 3族値2位置予想との一致

K0832の3族予想を \(z=6,y=21\) に特殊化し、\(d=x-21\) とする。

- 基本ラダーは \(\{1,3,5\}\)。
- 家族BのEXTは \(d=0,4\) で、それぞれ45,47。
- 家族Aのランは \(d=7\) で49,51,53,55。
- 家族Aの定常位置は \(d\ge8\) で49。

従って今回の \(T_{21}(x)\) と一致する。これはz=6,y=21特殊化の全称証明であり、3族予想全体の証明ではない。

## 適用範囲と限界

証明対象は抽象残余ゲームの固定切片 \(z=6,y=21\)、全 \(x\ge21,R\ge0\)。z=6,y≥22、z≥7の全Grundy分類、3族値2位置予想全体、標準二次元共円ゲームの固定幅・q点版の真の安定化長は未解決である。
