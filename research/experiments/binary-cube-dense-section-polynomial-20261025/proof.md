# 二値超立方体の正密度超平面切片：有限支持と次元多項式

2026-10-25。実係数・全次元の全称証明。K0558の根拠。
「切片」とは超平面そのものではなく、頂点集合との交点 `H∩{0,1}^d` のこと。

## 定理（任意の固定密度）

`0<δ≤1/2` を固定する。二値超立方体 `V_d={0,1}^d` の、実アフィン超平面による**異なる非空頂点切片**のうち、頂点数が `δ 2^d` 以上であるものの個数を `P_δ(d)` とする。

```text
K_δ = max { k>=1 : C(k,floor(k/2))/2^k >= δ }.
```

この最大値は有限である。非負整数 `c_{δ,k}`（`1≤k≤K_δ`）が存在し、**すべての `d≥1`** で

```text
P_δ(d) = sum_{k=1}^{K_δ} c_{δ,k} C(d,k).
```

ここで `c_{δ,k}` は `{0,1}^k` 上でちょうど `k` 座標を本質的に使う超平面切片のうち、頂点数が `δ 2^k` 以上のものの個数である。範囲外の二項係数は0。

従って正密度を固定したとき、切片集合の個数は次元 `d` の（次数高々 `K_δ` の）整数値多項式であり、その係数は有限個の有理数線形代数の判定から**原理的に厳密計算可能**である。超平面の個数を数える主張ではない。

## 証明

1. 法線 `a=(a_1,...,a_d)≠0` の非零座標集合を `I`、その大きさを `k` とする。各 `a_i` の符号を座標反転で正に直す。同じ部分和を持つ `{0,1}^k` の割当集合は、正の重みについて真の包含関係を持たない反鎖である。Spernerの定理より、一つの高さに載る割当は高々 `C(k,floor(k/2))` 個。残る `d-k` 座標は自由だから、切片密度は高々 `C(k,floor(k/2))/2^k`。中央二項係数の比率は `k→∞` で0となるので、`|H∩V_d|≥δ 2^d` なら `k≤K_δ`。
2. **支持集合の一意性**：切片 `P=H∩V_d` は非空。もし `i∉I` なら、`P` 内の任意の頂点の第 `i` 座標を反転しても `P` に留まるため、`P` は第 `i` 方向の辺を含む。逆に `i∈I` なら、その方向の隣接2頂点がともに超平面上に載ることはない。ゆえに `I` は `P` 自体から一意に復元できる。
3. 支持 `I` を指定すると切片は必ず `A×{0,1}^{d-k}`（座標を並べ替えた表示）となる。`A` は `{0,1}^k` 上の全座標非零法線による切片であり、密度は `|A|/2^k`。支持の一意性により、異なる `I` または異なる `A` は異なる `P` を与える。よって `C(d,k)c_{δ,k}` を足せばよい。
4. **係数の計算可能性**：`A⊂{0,1}^k` を全列挙する。`A≠∅` として `L=aff(A)`、`U=L-L` と置く。次の3条件は、`A` が全座標非零法線を持つ超平面の正確な頂点切片であるための必要十分条件である。
   - `dim U<k`。
   - `L∩{0,1}^k=A`。
   - どの標準基底ベクトル `e_i` も `U` に入らない。

   必要性は明らか。十分性は、`U^⊥` の中で `a_i=0`（各 `i`）または `a·(v-v_0)=0`（`v∈V_k\A`, `v_0∈A`）となる有限個の**真の**線形部分空間を避けて `a` を選べばよいことによる。有限個の真部分空間は実線形空間を覆えず、さらに有理ベクトルも選べる。すると `a·x=a·v_0` の頂点切片はちょうど `A` で、全 `a_i≠0`。3条件は整数行列の階数で判定できる。□

## 密度 1/4 以上：既存分類から得られる明示式

K0556は密度 `>1/4` の切片を全分類し、K0557は密度 `=1/4` の異なる頂点切片を全分類した。これらは密度で互いに素なので合計できる。

```text
P_{1/4}(d)
 = d(d+1) + 8 C(d+1,4) + 32 C(d+1,6) + 128 C(d+1,8)
   + 4 C(d,2) + 16 C(d,3) + 92 C(d,4) + 80 C(d,5)
 = 2 C(d,1) + 6 C(d,2) + 24 C(d,3) + 100 C(d,4)
   + 112 C(d,5) + 32 C(d,6) + 128 C(d,7) + 128 C(d,8).
```

`K_{1/4}=8`（`C(8,4)/256=70/256>1/4`, `C(9,4)/512=126/512<1/4`）。
係数 `(c_1,...,c_8)=(2,6,24,100,112,32,128,128)`。
`d=1,...,10` の値は `2,10,48,240,922,2786,7184,16848,37410,80234`。

**独立した有限検算**：`verify_affine_hulls.py` は法線を列挙せず、`k≤4` の全頂点部分集合を調べ、上記の3条件を階数で判定する。結果は

```text
k=1: {1:2}             -> c_1=2
k=2: {1:4,2:2}         -> c_2=6
k=3: {2:16,3:8}        -> c_3=24
k=4: {4:92,6:8}        -> c_4=100
PASS
```

階数は法101で求めるが、対象は `k≤4`、行列成分は `-1,0,1` なのでHadamard上界から非零小行列式の絶対値は16以下。従って法101での階数は有理数体上の階数と一致する。これが有限完全列挙であることと、任意次元の多項式性が上の数学的証明に依存することを区別する。

## 限界

- `δ<1/4` の係数は**まだ算出していない**。多項式性・有限アルゴリズムのみ全称確定。
- `P_δ(d)` は頂点切片集合の数であり、法線や実超平面の数、禁止q点組の数、ゲームの勝敗・Grundy値ではない。
- `δ` は固定正数。例えば `q` を固定して `d→∞` とすると `δ=q/2^d→0` なので、この次数一様有界性は適用できない。
- 1/4の係数 `k≥5` はK0556・K0557の**既存の全称分類からの帰結**。独立な部分集合列挙は `k≤4` に限る。
