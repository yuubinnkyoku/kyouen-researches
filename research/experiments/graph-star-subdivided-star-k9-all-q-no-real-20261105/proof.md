# 一辺細分星：k=9 の全 q≥5 における実根不存在（2026-11-05）

## 定理（全称証明）

K0648 の終局長差多項式
[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1},qquad r=q-3
]
は、**k=9、任意の整数 r≥2（q≥5）で全実数 u に対して正**。したがって10根すべて非実根（重複度込み）。

r=2 は既存の [k=9,q=5 の証明](../graph-star-subdivided-star-k9-q5-no-real-20261104/proof.md) により成立。以下では新しい領域 r≥3 を証明する。

## r≥3 の証明

u≥0 では全係数が非負で定数項が正なので T>0。u=-x<0、y=x/(r+1)>0、a=(r+2)/(r+1)=1+1/(r+1) と置く。k=9 は奇数なので
[
rac{T_{9,r}(-x)}{(r+1)^{10}}=F_r(y):=y^9(y-a)+r-y.
]
r≥3 より 1<a≤5/4<r。

* 0<y<a: 最大値評価 y^9(a-y)≤a^{10}/10≤(5/4)^{10}/10=1953125/2097152<7/4≤r-a≤r-y。従って F_r(y)>0。最初の評価は y^9≤a^9 と a-y≤a だけでは得られないが、微分による真の最大値 9^9 a^{10}/10^{10}≤a^{10}/10 を用いる（9^9≤10^9）。
* a≤y≤r: y^9(y-a)≥0、r-y≥0。両者は同時には零にならない（a<r）。
* y>r: y^9>1 かつ y-a>y-r>0 だから y^9(y-a)>y-r、従って F_r(y)>0。

よって全実数で T_{9,r}(u)>0。r=2 の既証明と合わせ、全 q≥5 で成立する。□

## 検算と境界

有理数比較は整数演算のみで検証可能：
```python
from fractions import Fraction
assert Fraction(5,4)**10 / 10 == Fraction(1953125,2097152)
assert Fraction(1953125,2097152) < Fraction(7,4)
```

この証明は数値根探索に依存しない全称証明。グラフ型一辺細分星についての結論であり、標準格子盤についての結論ではない。奇数 k≥11 の全 q に関する実根数分類は依然未解決。
