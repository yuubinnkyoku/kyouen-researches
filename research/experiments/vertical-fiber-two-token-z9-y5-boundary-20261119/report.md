# 2トークン残余ゲーム z=9・y=5 の全Grundy分類（K0992）

- 日付: 2026-11-19
- 対象: H(R;(x,5);9)、全 x>=5・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0990（z=9,y=4）、K0991（z=8,y=5）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

| x | T_9^(5)(x) |
|---:|---|
| 5,7,8,9,11,12,13 | {1,3,5,7,9} |
| 6 | {1,3,5,7,9,15} |
| 10 | {1,3,5,7,9,17} |
| 14 | {1,3,5,7,9,19} |
| 15 | {1,3,5,7,9} ∪ O[19,29] |
| x>=16 | {1,3,5,7,9,19} |

| x | P_9^(5)(x) |
|---:|---|
| 5,7 | E[10,14] |
| 6 | E[10,14] ∪ I[16,∞) |
| 8 | E[10,16] ∪ I[17,∞) |
| 9,11 | E[10,16] |
| 10,12 | E[10,18] ∪ I[19,∞) |
| 13,15 | E[10,18] |
| 14 | E[10,18] ∪ I[20,∞) |
| x>=17 odd | E[10,18] ∪ O[21,x+14] |
| x>=16 even | E[10,18] ∪ O[21,x+15] ∪ I[x+16,∞) |

全てのx>=5・R>=0で、H(R;(x,5);9)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailは

    R >= x+15  =>  H(R;(x,5);9) = (x+5) mod 2.

値2の定常位置は{1,3,5,7,9,19}。x=15だけはO[19,29]が一時的に加わる。z=9族の定常値2位置の第6点はz+2yで、y=1..5では11,13,15,17,19が5点連続で成立する（{1,3,5,7,9}∪{z+2y}型）。x=6,10,14では第6点が15,17,19と前倒しで現れ、x>=16で19に定着する。値1の頭部E[10,18]={10,12,14,16,18}=z+1+2i (i=0..4)はz=9族のy=1..5各切片を貫く偶数帯で、z=8族の奇数帯に対応する。x=15の掃引帯はz=9族の掃引位置x=z+y+1と掃引範囲O[2y+9,2y+19]に一致する。x>=16偶数行にはtailの1側（x偶数行）にI[x+16,∞)が付くが、I帯の付く行はy=4では奇数行・y=5では偶数行とyの偶奇で交互する。x=16はA子が掃引行x=15を横切る過渡行で、定常は奇数x>=17・偶数x>=18から始まる。

## 証明

R=0は終局で値0。R>=1,x>=6の選択肢は

    A = H(R-1;(x-1,5);9)
    B = H(R-1;(x,4);9)
    C = 1 xor H(R-1;(x,5);8)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0990、CはK0991で評価できる。x=5では二つのトークン減少手が同じ(x,4)子（最大トークン5）に合流するため、A=B=K0990のx=5行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

各行はAに帰納仮説、BにK0990、CにK0991を代入した子値集合である。x>=17奇数行とx>=18偶数行では、帯端だけがxに依存し、署名は一定である。これはAがx-1行の閉形式、B・Cがx行の閉形式で、21<=R<=x+14の全域で帯ごとに子値が定数となることによる。x=15は掃引行、x=16はA子が掃引行x=15を横切る過渡行で、x=16の偶数帯E[22,30]の署名12（mex 0）だけが定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+14を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+15ではK0832の高R tail定理を各子に適用できる。x偶数ならA=B=C=0で親値1、x奇数ならA=B=C=1で親値0となり、親tail (x+5) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=9,y=5切片のみを扱う。z=8,y>=6、z=9のy>=6、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=9族の定常第6点 z+2y の一般化（y=1..5の5点連続）も観察であり証明ではない。I帯のy偶奇交互も観察であり、次切片での検証課題である。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
