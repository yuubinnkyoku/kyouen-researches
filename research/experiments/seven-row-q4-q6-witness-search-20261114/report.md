# 7×m q=4,5,6 行欠損witness探索 — 新ファミリー3種の witness 帯と下界

日付: 2026-11-14（高速レーン第9回・第3バッチ）

## 主張

いずれも 7×m・q点共円/共線禁止・行欠損の極大安全配置（満容量 7·(q−1) 石に
対しある行 ≤ q−2 石）。3ファミリーとも CSV・knowledge に未記載で、
本実験が最初の結果である。

1. **(7,6)**: 欠損極大witness が **m=6..26 の全幅で存在**。
   - m=6..15 は深欠損（20..33石・deficiency 15..2）、
     m=16..25 は単一欠損 **34石**（ある行のみ4石）、
     **m=26 は33石（2欠損・rows 5/5/5/5/5/3/5・441,809 conflicts）**。
   - よって **M_{7,6} ≥ 27**（上界 862 = K0318 代入・w7_upper_bounds.json。
     M ∈ [27, 862]）。前線 7×27。
2. **(7,5)**: 欠損極大witness が **m=5..22 の全幅で存在**。
   - m=5..15 は深欠損（14..26石・deficiency 14..2）、
     m=16..22 は単一欠損 **27石**（m=20 のみ25石・rows 4/1/4/4/4/4/4 の深欠損行）。
   - よって **M_{7,5} ≥ 23**（上界 1142。M ∈ [23, 1142]）。前線 7×23。
3. **(7,4)**: 欠損極大witness が **m=4..14 の全幅で存在**。
   - m=4..9 は 8..11石（deficiency 13..10）、m=12..14 は **15石**
     [3,3,3,3,1,1,1] 型（deficiency 6）。
   - よって **M_{7,4} ≥ 15**。上界は **K0068 の一般 q=4 偶奇定理
     T_7 = 3+2{C(19,3)−6} = 1929**（K0318 代入 U=1929 と一致。
     M ∈ [15, 1929]）。前線 7×15。
4. すべての witness は census 不使用 sat.js verifyConfig と Python Fraction
   独立実装の **2系統検証で safe+maximal+行欠損 PASS**（records.jsonl の
   jsVerify/pyVerify すべて true）。

## 手法と検証

- 符号化: `seven-row-inband-families-20261114/scripts/sat2.js`（K0810 census +
  sequential counter + 極大性）を verbatim。q ≤ w のため genfast.js は不適用
  （半整数中心保証は q ≥ w+1 に依存）。def 単一節 ∨¬rowGe[y] は
  「総石数 < 7(q−1) ⟺ ある行 ≤ q−2」の完全符号化。
  census は m ≥ q を要求し、実際に各ファミリーの最小探索幅は m=q とした。
- ソルバ: kissat 4.0.4 公式 linux-amd64 バイナリ（変更なし・240s cap）。
- 検証: decode_verify.js（census 不使用 verifyConfig）+ verify_witness.py
  （Python Fraction・独立実装）の 2系統。
- 決定性: 同一コード・同一バイナリで (7,7) 実験（seven-row-q7-witness-search-20261114）
  の m=24 再実行が conflicts bit-exact を確認済み。
  本バッチの全インスタンスは sat2.js から決定的に再生成可能。
- 上界: (7,4) の 1929 は K0068（T_w=3+2{C(3w−2,3)−(w−1)}）の全称証明と
  w7_upper_bounds.json の packing_U の一致により二重に裏づけられる。

## 観測（全称主張ではない）

- **q ≤ w の 7行族では m=q から継続的に witness が存在**し、
  欠損度は幅とともに浅くなるが消えない（少なくとも上記範囲）。
  (7,7)（q=w）と合わせ、q ≤ w では witness-free 帯が現れる前に
  深欠損から単一欠損への移行が観測される。
  (7,8)..(7,10)（q > w）では witness-free 帯が出現した後の前線（7×25/7×101）
  とは対照的。K0318 上界（862/1142/1929/708）は witness がいずれ消えることを
  保証する。
- (7,4) の m=4 witness は 8石（rows 3/1/1/1/0/2/0）で、
  標準 q=4 ルールの固定幅盤における深欠損の極端な例。

## 正直な負記録・未走査

- 各ファミリーの前線以降（7×27 q6・7×23 q5・7×15 q4）は未走査。
- sat2.js 全三つ組censusの実用範囲は n=7m ≈ 200 前後（q=6 は m=26 で
  生成に約2分・q=4 は curves が多く m=15 以降で生成が急速に重くなる）。
  それ以上は帯状censusの一般化（genfast の q ≤ w 版）が必要。

## 範囲と限界

有限機械検証（census 完全性とソルバ正確性まで）。数論的証明ではない。
M の確定には前線以降の評価と上界の改善（K0342 型 tail 評価）が残る。
