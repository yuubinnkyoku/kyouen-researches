# z=17・y=2 2トークン境界切片の全Grundy分類（K1044）

- 日付: 2026-11-19
- 対象: κ=1残余ゲーム \(H(R;(x,2);17)\)、全 \(x\ge2\)・全 \(R\ge0\)
- 状態: **全称定理**
- 依存: K0832、K1023（B子）、K1042（C子）

## 命題

\(O[a,b]\) は区間内の奇数、\(E[a,b]\) は区間内の偶数、\(I[a,\infty)\) は \(a\) 以上の全整数とする。

Grundy値2の位置集合 \(T(x)\):

| x | \(T(x)\) |
|---:|---|
| 2 | \(\{1,3\}\) |
| 3, 4 | \(O[1,5]\) |
| 5, 6 | \(O[1,7]\) |
| 7, 8 | \(O[1,9]\) |
| 9, 10 | \(O[1,11]\) |
| 11, 12 | \(O[1,13]\) |
| 13, 14 | \(O[1,15]\) |
| 15 | \(O[1,19]\)（h=z行・連続上端19） |
| 16, 17, 18 | \(O[1,17]\)（奇数zラダー基部） |
| 19 | \(O[1,17]\cup\{21\}\)（pin行 \(x=z+y\)） |
| 20 | \(O[1,17]\cup O[21,39]\)（掃引行 \(x=z+y+1\)） |
| \(x\ge21\) | \(O[1,17]\cup\{21\}\) |

Grundy値1の位置集合 \(P(x)\):

| x | \(P(x)\) |
|---:|---|
| 偶数 \(x\le14\) | \(\varnothing\) |
| 奇数 3, 5, 7, 9, 11, 13 | \(I[x+3,\infty)\) |
| 15 | \(\{18,20\}\cup I[21,\infty)\) |
| 16 | \(\{18\}\) |
| 17 | \(\{18,20\}\cup I[21,\infty)\) |
| 18 | \(\{18,20\}\) |
| 19 | \(\{18,20\}\cup I[22,\infty)\) |
| 20 | \(\{18,20\}\) |
| 奇数 \(x\ge21\) | \(\{18,20\}\cup O[23,x+20]\cup I[x+21,\infty)\) |
| 偶数 \(x\ge22\) | \(\{18,20\}\cup O[23,x+19]\)（有限） |

従って
\[
H(R;(x,2);17)=
\begin{cases}
2,&R\in T(x),\\
1,&R\in P(x),\\
0,&\text{otherwise}.
\end{cases}
\]

一般tailはK0832から
\[
\boxed{R\ge x+20\implies H(R;(x,2);17)=(x+2)\bmod2.}
\]
また高さのみ縮約から
\[
R\le18\implies H(R;(x,2);17)=v_{\rm single}(x+2,17,R).
\]

## 構造の注記

- **pin=21=2y+z**（奇数zラダー \(O[1,z]\cup\{2y+z\}\)、K1032 の z=15,y=2 と同じ奇数z型）。
  掃引行 \(x=z+y+1=20\) の値2帯は \(O[1,z]\cup O[\mathrm{pin},x+y+z]=O[1,17]\cup O[21,39]\)、
  \(x\ge21\) で \(O[1,17]\cup\{21\}\) に定着する。pin 21 の数値は偶数z（K1042）の
  \(2y+z+1=21\) と一致するが由来が異なる。
- **h=z行 \(x=15\) の連続上端19**: \(d=13=x-y\)・\(d+z=30\equiv2\pmod4\) で
  上端 \(2y+(d+z)/2=4+15=19\)（奇数のため \(q_{\rm odd}\) 丸めなし・連続帯 \(O[1,19]\)）。
  K1032 の z=15,y=2・x=13（\(d=11\)・\(d+z=26\equiv2\)・上端 \(17=4+13\)）と同じ
  「d+z≡2 で上端が連続帯に伸びる」奇数z型。偶数z型 K1042 の x=14
  （\(d+z=28\equiv0\)・上端 \(q_{\rm odd}(18)=17\)=z+1 で孤立）と対照的で、
  d+z mod 4 の2値格子規則（≡2→\(2y+(d+z)/2\) 連続、≡0→\(z+1\) 孤立）の実例。
- **pin行・掃引行の偶奇**: pin 21 は \(x=z+y=19\) 行に現れ（K1037 z=11,y=5 の
  「前倒しpin行 \(x=z+y\)」型と一致）、掃引行は \(x=z+y+1=20\)。
- **値1基底点 \(\{18,20\}=\{z+1,z+3\}\)**: y点仮説2点型は K1019（z=12）、K1025（z=13）、
  K1028（z=14）、K1032（z=15）、K1042（z=16）に続き6例目。y=2ではz=12..17の6連続で
  確定し、奇数zではz=13・15に続き3例目。
- **値1中間帯は \(z+2y+2=23\) 開始の奇帯**: 帯の偶奇はzに追従し（奇数z→奇数位置）、
  奇数行は \(O[23,x+20]\cup I[x+21,\infty)\)、偶数行は有限 \(O[23,x+19]\)。
  無限I帯は奇数x行のみで、tail \(R\ge x+20\) の値 \((x+2)\bmod2\) が1になる行と一致する
  （「I帯はtail値1の行にだけ現れる」一般則のy=2・奇数z型確認）。値1基底点は
  x=16で1点・x=18,20で2点・x=15,17で \(\{18,20\}\cup I\) と段階出現する。
- **帯被覆の隙間なし**: 署名帯表は各行 \(R=1..x+19\) を完全に被覆し、tailは \(R\ge x+20\)
  から始まるため、z=16型（被覆 \(R\le x+17\)・tail \(x+19\)・隙間行 \(R=x+18\)）と異なり
  被覆とtailの間に隙間行がない。閉形式帯は奇数行 (1,23,x+18,"0")/(0,24,x+19,"1")、
  偶数行 (1,23,x+19,"0")/(0,24,x+18,"1")。過渡行は x=15（h=z行・\(R\ge20\) で署名"0"連続）、
  x=21（偶帯署名"12"が残る移行行）で、静的表 x=2..22 に含める。
  x≥23奇数/x≥24偶数で帯構造は行偶奇完全共通・帯上端のみ \(x+18\)/\(x+19\) 入替。

## 証明

子分解は
\[
A=H(R-1;(x-1,2);17),\quad
B=H(R-1;(x,1);17),\quad
C=1\oplus H(R-1;(x,2);16).
\]
BはK1023のパラメトリック全称公式（z=17行）、Cは1⊕K1042。x=2では二つのトークン減少手が同じ多重集合
\((1,2)\) に合流して単一の子値となり、K1023のx'=2行（z=17）を帰納基底として使う。
x≥3ではAをx外帰納で閉じる。全 \(R\ge1\) は検証器内の完全A/B/C署名帯表
（静的行 \(x=2..22\)・定常閉形式 奇数\(x\ge23\)/偶数\(x\ge24\)・各行が \(R=1..x+19\) を
互いに素に被覆）とmex対応表で被覆し、\(R\ge x+20\) はK0832一般tail、\(R\le18\) は
K0832高さのみ縮約で閉じる。
