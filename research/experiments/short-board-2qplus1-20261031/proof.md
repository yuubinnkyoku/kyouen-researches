# 平面q点禁止ゲームの二担い手領域の鋭い上限とN=2q+1

## 全称定理

q≥7とし、相異なる実平面点の集合Pについて、q点以上を含む円・直線を「担い手」と呼ぶ。|P|≤3q−7なら担い手は高々二本。境界は鋭く、任意のq≥7で|P|=3q−6かつ担い手がちょうど三本ある整数格子盤が存在する。

特にq≥8、|P|=2q+1の二担い手A,Bを|A|=q+u、|B|=q+v、u≥v≥0、c=|A∩B|、z=|P\(A∪B)|とすると

```
c∈{0,1,2},  u+v≤c+1,  z=1+c−u−v
```

であり、以下の12型に限られる。すべて整数格子上で実現できる。

| (u,v) | c | z |
|---|---|---|
| (0,0) | 0,1,2 | 1,2,3 |
| (1,0) | 0,1,2 | 0,1,2 |
| (1,1) | 1,2 | 0,1 |
| (2,0) | 1,2 | 0,1 |
| (2,1) | 2 | 0 |
| (3,0) | 2 | 0 |

禁止q点組の個数は、担い手なしなら0、一本ならC(m,q)（q≤m≤2q+1）、二本ならC(q+u,q)+C(q+v,q)。従って可能な値の集合は正確に

```
{0} ∪ {C(m,q):q≤m≤2q+1}
    ∪ {2, q+2, 2(q+1), C(q+2,2)+1,
         C(q+2,2)+q+1, C(q+3,3)+1}.
```

## 幾何学的証明

異なる円・直線の交点数は高々2。三本の担い手があれば包除原理より和集合は少なくとも3q−6点。従って|P|≤3q−7では不可能。

鋭さには半径5の円C1（中心(0,0)）、C2（中心(6,0)）と半径2の円C3（中心(2,−5)）を用いる。各二円の交点は、C1∩C2={(3,4),(3,−4)}、C1∩C3={(0,−5),(100/29,−105/29)}、C2∩C3={(2,−3),(162/41,−187/41)}。6点は相異なり三円共通点はない。各円に他の二円上にない有理点をq−4個ずつ追加すると、各円はq点、全点数は6+3(q−4)=3q−6。他の円・直線は各元の円と高々2点で交わるので全点集合と高々6点でしか交わらず、q≥7なら新しい担い手にはならない。座標の分母を払えば整数格子盤。

N=2q+1、q≥8なら2q+1≤3q−7。二担い手の共通点数c≤2と|A∪B|=2q+u+v−c≤2q+1よりu+v≤c+1。非負整数u≥vを列挙すれば表の12型を得る。二つの担い手のq点部分集合は重複しないため、上記fの式が成立する。

12型の整数実現には半径5の二有理円を使い、c=0,1,2に応じて中心を(0,0)と(12,0),(10,0),(6,0)に置く。各円の固有有理点を必要数選び、外部のz≤3点を両円外に選ぶ。ほかの円・直線は二円から高々4点、外部から高々3点しか含められず、q≥8では担い手にならない。一本の場合は円上にm点を選び、残りを有限個の既定曲線を避けて有理点から順次選ぶ。担い手なしも同様。

## 全安全局面の強解法と極大配置

二担い手の固有点群をx=|A\B|、y=|B\A|、共有点をc、外部点をzとする。各群の占有数(i,j,t,e)に対し安全条件はi+t≤q−1、j+t≤q−1。合法手は対応する群に未選択点があり安全を保つ場合のi,j,t,eいずれか一つの増加。合法子なしでは(g,h)=(0,1)、それ以外では子の通常値・misère補助値を別々にmexする。群内置換はゲーム木の同型なので、全安全局面の値と勝ち初手がこの再帰で厳密に求まる。

c≤2より状態数は(x+1)(y+1)(c+1)(z+1)=O(N³)。N=2q+1の12型ではz≤3なのでO(q²)。各状態の子は高々4種。一本以下なら全終局長が固定され、残手数の偶奇で直接解ける。

極大安全集合では必ずe=z。さらにi<xならi+t=q−1、j<yならj+t=q−1、t<cならi+t=q−1またはj+t=q−1が必要十分。従って石数Lの極大配置数は

```
M_L = Σ C(x,i) C(y,j) C(c,t) · [L=i+j+t+z]
```

（総和は上記安全・極大条件を満たす組のみ）。全完了着手履歴数はΣ_L M_L·L!、r人巡回で最後の着手者が勝つ場合は終局長Lに対し勝者番号1+((L−1) mod r)。

## 検証と限界

verify.pyはq=8の12型について、各点を区別したビット集合の直接再帰と四群の占有数再帰を全1,510,740安全局面で照合（不一致0）。極大配置数も別の組合せ式と比較し、12型の有理円構成は三点から全円・直線を再構成して担い手を直接確認した。q=7、N=15の鋭さの有理構成も検査した。

q=8,9,10,11,20,50の空盤値には共通規則が観測されるが、無界qの閉公式は未証明であり主張しない。大盤の途中局面では占有済み点による小さい残余禁止集合が生じるため、残点数だけで本定理を適用してはならない。
