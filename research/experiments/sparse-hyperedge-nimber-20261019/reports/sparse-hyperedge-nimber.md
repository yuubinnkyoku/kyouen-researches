# 残余禁止辺が少ない共円ゲームのGrundy上界（2026-10-19）

## 命題（全称証明）

任意の有限点集合に対する通常プレイの一点追加禁止集合ゲームを考える。安全局面の未着手点を頂点とし、完成させてはならない禁止集合の残りを辺とする残余超グラフを取る。包含関係で冗長な辺は除いてよい。残余辺の個数を `h` とすると、現在のGrundy値は

\[
  g \le \begin{cases}1&h=0,\\ 2^h-1&h\ge1.\end{cases}
\]

この上界は盤の大きさ、円・直線の座標、禁止点数qには依存しない。特に禁止辺が2本以下なら、**どの安全局面でも `g≤3`**。これは計算量の上界ではなく、取り得るGrundy値そのものの上界である。

## 証明

各未着手頂点 `v` の署名を、残余辺 `E_1,...,E_h` のうち `v` を含む辺の番号集合 `σ(v)` とする。`σ(u)=σ(v)` なら、各残余辺は `u,v` の双方を含むか、双方を含まない。したがって `u,v` の交換は残余超グラフの自己同型であり、`u` と `v` への着手後の局面は同型である。合法な着手に限って考えると、同じ署名の着手先は同じGrundy値を持つ。

空署名の頂点は全禁止辺に無関係で、任意の順序で必ず着手できる。非空署名の頂点だけからなるゲームと、空署名の頂点数 `z` 個の独立した自由手ゲームとの直和である。よって `g=g_core xor (z mod 2)`。

非空署名は高々 `2^h−1` 種類なので、coreの任意の局面で子の異なるGrundy値は高々 `2^h−1` 種類。`mex` の定義から `g_core≤2^h−1`。`h≥1` の場合、`2^h−1` は下位 `h` ビットがすべて1であり、これ以下の整数を1とxorしても同じ範囲にとどまる。従って元の局面も `g≤2^h−1`。`h=0` は自由手だけなので `g=z mod 2≤1`。証明終。

なお残余辺に単点辺がある場合、その点への着手は違法になるが、合法な着手先の数を減らすだけなので議論は変わらない。残余辺のうち他の辺を含む冗長な辺を除去しても合法手集合は変わらない。

## 2辺で上界3を達成する整数座標の例

7点を次の順序で取る。

```
0: ( 3, 4)
1: (-5, 0)
2: (-4,-3)
3: (-4, 3)
4: ( 1, 0)
5: ( 2,-3)
6: ( 6,-5)
```

4点が共円または共線となる組は **`{0,1,2,3}` と `{0,4,5,6}` のちょうど2つ**。前者は `x²+y²=25`、後者は `(x−6)²+y²=25` に属する。すべての35組について整数4×4行列式で確認でき、他の共円・共線4点組はない。

安全局面 `S={1,4,5}`（石の座標は `(-5,0),(1,0),(2,-3)`）では `g(S)=3`。4つの合法手 `0,2,3,6` の子Grundy値は順に `1,2,2,0` で、mexは3となる。したがって `h=2` の上界は鋭い。

## 独立検証と限界

- `scripts/verify_sparse_hyperedge.py`: Pythonの整数行列式で35個の4点組を検査し、bitmaskによる全安全局面再帰と、別の3変数 `(共通点数, 辺1専有点数, 辺2専有点数)` による再帰を照合。さらに6頂点・相互に包含しない2辺の超グラフ **1,180個** の全安全局面で `g≤3` を検証。
- `scripts/verify_two_circle.cpp`: 独立したC++整数行列式と降順部分集合動的計画法で、7点の全128部分集合を処理。禁止4点組2個、安全局面113個、空盤 `g=1`、`S` で `g=3`。安全局面のGrundy分布は `g=0:38, g=1:42, g=2:15, g=3:18`。
- 上界は上の数学的な全称証明に依存し、有限検査を全称証明として扱わない。7点の達成例の完全性は、有限35組の厳密な行列式検査で確定する。

## 11×11との接続

残余超グラフの辺が少ない局面では、Grundy値の取り得る範囲を即座に制限できる。特に残余辺2本以下なら `g≤3`。これは根の勝敗を決めるものではなく、局所的なnimberの監査と探索枝の不変量として利用できる。署名ごとの対称性は既存の双子点圧縮（K0336）と整合するが、今回の主張は**残余辺の本数だけから導く一様な数値上界**である。
