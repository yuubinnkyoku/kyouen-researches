# 2トークン残余ゲーム z=6, y=24 切片の全Grundy分類

## 定理

\[
H(R;(x,24);6),\qquad x\ge24,\ R\ge0
\]
のGrundy値は常に \(0,1,2\) である。値2となる残容量は
\[
\boxed{
T_{24}(x)=\{1,3,5\}\cup
\begin{cases}
\{51\}&x=24,\\
\{53\}&x=28,\\
\{55,57,59,61\}&x=31,\\
\{55\}&x\ge32,\\
\varnothing&\text{その他}.
\end{cases}}
\]

奇数・偶数の区間を
\[
O[a,b]=\{r:a\le r\le b,\ r\equiv1\pmod2\},\quad
E[a,b]=\{r:a\le r\le b,\ r\equiv0\pmod2\}
\]
とする。上端省略は無限区間である。値1となる残容量は
\[
\boxed{
P_{24}(x)=
\begin{cases}
O[7,49],&x=24,\\
O[7,\infty)\cup E[52,\infty),&x=25,\\
O[7,51],&x=26,\\
O[7,\infty)\cup E[54,\infty),&x=27,\\
O[7,51],&x=28,\\
O[7,\infty)\cup E[54,\infty),&x=29,\\
O[7,53],&x=30,\\
O[7,53]\cup E[56,\infty)\cup O[63,\infty),&x=31,\\
O[7,53]\cup E[56,x+30],&x\ge32\text{ 偶数},\\
O[7,53]\cup E[56,\infty)\cup O[x+32,\infty),&x\ge33\text{ 奇数}.
\end{cases}}
\]
\(R=0\) では値0、それ以外は \(T_{24}\) 上で2、\(P_{24}\) 上で1、残りで0となる。一般tail定理から
\[
\boxed{R\ge x+31\implies H(R;(x,24);6)=(x+24)\bmod2}
\]
も成り立つ。

## A/B/C再帰

\[
\begin{aligned}
A&=H(R-1;(x-1,24);6),\\
B&=H(R-1;(x,23);6),\\
C&=1\oplus H(R-1;(x,24);5).
\end{aligned}
\]
\(x=24\) ではA子 \((23,24)\) とB子 \((24,23)\) が正準化後に同一状態となり、K0917で評価できる。\(x\ge25\) ではAを同じ切片のR強帰納、BをK0917、CをK0873のz=5全Grundy公式で評価する。

K0832のTheorem Tにより、奇数Rの親の選択肢値は \(\{0,1\}\) に含まれる。署名 \(\{0,1\},\{0\},\{1\}\) のmexはそれぞれ2,1,0。偶数Rの親値は高々1なので、選択肢集合に0がある場合だけ親値1となる。

## 全選択肢署名

次表は \(1\le R\le x+30\) を覆い、各区間は表記した偶奇のRだけを含む。署名は \(\{A,B,C\}\) の値集合で、01は \(\{0,1\}\)、23は \(\{2,3\}\) を表す。

| x | 奇数R | 偶数R |
|---:|---|---|
| 24 | 1–5:01; 7–49:0; 51:01; 53:1 | 2–6:23; 8–54:1 |
| 25 | 1–5:01; 7–55:0 | 2–6:23; 8–50:1; 52:023; 54:0 |
| 26 | 1–5:01; 7–51:0; 53–55:1 | 2–6:23; 8–56:1 |
| 27 | 1–5:01; 7–57:0 | 2–6:23; 8–50:1; 52:12; 54–56:0 |
| 28 | 1–5:01; 7–51:0; 53:01; 55–57:1 | 2–6:23; 8–58:1 |
| 29 | 1–5:01; 7–59:0 | 2–6:23; 8–52:1; 54:023; 56–58:0 |
| 30 | 1–5:01; 7–53:0; 55–59:1 | 2–6:23; 8–52:1; 54–60:123 |
| 31 | 1–5:01; 7–53:0; 55–61:01 | 2–6:23; 8–52:1; 54:123; 56–60:0 |
| 32 | 1–5:01; 7–53:0; 55:01; 57–61:1 | 2–6:23; 8–52:1; 54:123; 56–62:02 |
| \(x\ge33\) | 1–5:01; 7–53:0; 55:01; 57–\(U_o\):1 | 2–6:23; 8–52:1; 54:123; 56:02; 58–\(U_e\):0 |

最終行の端点は
\[
U_o=\begin{cases}x+30&x\text{ 奇数}\\x+29&x\text{ 偶数}\end{cases},\quad
U_e=\begin{cases}x+29&x\text{ 奇数}\\x+30&x\text{ 偶数}\end{cases}.
\]
\(x=32\) の偶数Rでは56–62全体の署名が \(\{0,2\}\) となり、一般行の56だけが \(\{0,2\}\)、58以降が \(\{0\}\) という形とは異なる。従って定常署名は \(x=33\) から始まる。\(x=33\) はA子が例外切片x=32を参照する遷移行として直接処理し、\(x\ge34\) ではA/B/Cが定常式に入り、端点の偶奇比較で全xを覆う。

奇数親では署名01が値2、0が値1、1が値0を与える。偶数親では署名に0が含まれる場合だけ値1となる。署名表、終局R=0、一般tail定理を合わせて上の \(T_{24},P_{24}\) が得られ、R強帰納が閉じる。

## 3族値2位置予想との一致

K0832の3族予想をz=6,y=24に特殊化する。ラダーは \(\{1,3,5\}\)。家族BのEXT条件はd=x−yが偶数で \(6+d\equiv2\pmod4\) となるd=0,4で、それぞれ51,53を与える。PT角は \(y=(6-d)/2\) を要するため現れない。家族Aはd=7で55,57,59,61のラン、d≥8で定常位置55を与える。従って \(T_{24}\) と一致する。これは当該切片の証明であり、3族予想全体の証明ではない。

## 適用範囲と限界

証明対象は抽象κ=1残余ゲームのz=6,y=24切片、全x≥24,R≥0に限る。z=6,y≥25、z≥7の全Grundy分類、3族値2位置予想全体、標準二次元共円ゲームの固定幅・q点版の真の安定化長は未解決である。
