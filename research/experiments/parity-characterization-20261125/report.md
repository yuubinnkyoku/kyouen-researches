# parity 特性定理: Grundy ∈ {0,1} ⟺ 極大安全集合のパリティ一様

実験ディレクトリ: `research/experiments/parity-characterization-20261125/`（2026-11-25）

## 0. 定理（K1298 の必要十分化）

有限な盤（点集合とブロック族）上の共演ゲーム（局面 = 各ブロックと高々 `s` 点、
手 = 1 点追加、通常プレイ）について、次は同値:

- **(a)** すべての局面の Grundy 値が `{0,1}`。
- **(b)** すべての極大安全集合のサイズのパリティが一様。
- **(c)** 任意の局面 `S` について、`S` の極大拡大のサイズのパリティが一様。

さらに (b) のとき共通パリティ `p` で `Grundy(S) = (p−|S|) mod 2`、
misère 勝利は `(p−|S|)` が偶数のとき。

### 証明の要点

- (b)⇒(a): 完全プレイの長さが `p−|S|` に固定されるので、深さの帰納で mex が
  `(p−|S|) mod 2` になる（K1058 §6 の同一サイズ版の一般化）。
- (a)⇒(c): 全 Grundy が `{0,1}` なら、Grundy 0 の局面の子はすべて 1、
  Grundy 1 の局面の子はすべて 0。極大局面は 0 なので、極大プレイに沿って値が
  交互に並び、終点までの距離のパリティは `Grundy(S)` で決まる。
- (c)⇒(b): 空盤で自明。

**系（局所形）**: 局面 `S` 以下の部分ゲームが `{0,1}` に限ることは、
`S` の極大拡大のパリティ一様と同値。

## 1. 意味

- **Grundy 2 以上の出現は「極大安全集合のパリティ混在」とちょうど同値**。
  ゲームの複雑さは Grundy を計算せずに極大集合のパリティだけで判定できる。
- これまでの全データが説明される:
  - パリティ一様 → `{0,1}`: 設計ボード（同一サイズ）、`PG(2,q)` s=2
    （すべて最大サイズ）、`AG(2,4)` s=2（4,6 の偶数一様）。
  - パリティ混在 → Grundy ≥2: `AG(2,5)` s=2（5,6）、`AG(2,4)` s=3（8,9）、
    `AG(2,5)` s=3（9,10,11、Grundy 4）、`PG(2,4)` s=4（12,13,14,16）、
    反転平面 `M(q)`（q≥5、Grundy 2/3）。
- K1058 §6 の「全極大が同一サイズ」は (b) の特別な場合。本定理は
  「サイズは違ってよい」ことと「逆（必要性）」を加える。

## 2. 小盤による検証

`scripts/verify_small_boards.py`:

- n=4: 2-ブロック族（2^6）・3-ブロック族（2^4）の全族、s=2,3。
- n=5: 2-ブロック族（2^10）・3-ブロック族（2^10）・4-ブロック族（2^5）の全族、s=2,3。
- n=6,7,8: ランダムなブロック族（サイズ 2..4、固定 seed、800/400/150 盤）、s=2,3,4。
- 各盤で (a)⇔(b)、局所形（n≤5 は全局面、n≥6 は各盤 40 局面を抽出）、
  パリティ一様時の Grundy/misère 公式を検査。

結果:

| 項目 | 値 |
|---|---:|
| 検査した盤 | 8,360 |
| パリティ一様（uniform） | 5,263 |
| パリティ混在（mixed） | 3,097 |
| Grundy が {0,1} のみ | 5,263 |
| 違反 | **0** |

uniform と only-{0,1} の個数が完全に一致し、Grundy/misère 公式・局所形にも
違反はなかった（`output/verification.json`）。

## 3. 限界

- 小盤（n≤8）と s≤4 の範囲。定理自体は全有限盤で証明済み。
- ランダム族は固定 seed の標本で、n≥6 の網羅ではない。
- Grundy の「大きさ」（2 以上がどこまで大きくなるか）は本定理では決まらない。
