# parity 特性定理の小盤検証（宣言・2026-11-25）

## 定理（K1298）

有限ハイパーグラフ盤の共演ゲーム（各ブロックと高々 s 点、1 点追加、通常プレイ）で
次は同値:

- (a) すべての局面の Grundy 値が `{0,1}`;
- (b) すべての極大安全集合のサイズのパリティが一様;
- (c) 任意の局面 S の極大拡大のパリティが一様。

(b) のとき `Grundy(S) = (p−|S|) mod 2`、misère 勝利は `(p−|S|)` 偶数。

## 本実験

小盤で (a)⇔(b)、局所形、Grundy/misère 公式を全数・ランダムに検査する。

- n=4: 2-ブロック族・3-ブロック族の全族（2^6, 2^4）を s=2,3 で。
- n=5: 2-ブロック族（2^10）、3-ブロック族（2^10）、4-ブロック族（2^5）を s=2,3 で。
- n=6,7,8: ランダムなブロック族（サイズ 2..4、固定 seed）を s=2,3,4 で。
- 各盤で: 極大集合のパリティ集合、全局面の Grundy、局所形（S の上の部分ゲームが
  {0,1} ⇔ S の極大拡大のパリティ一様）、パリティ一様時の公式を検査。
