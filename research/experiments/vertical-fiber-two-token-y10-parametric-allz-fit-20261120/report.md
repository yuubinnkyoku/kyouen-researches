## 命題候補（observed・有限範囲で確定・全称は未証明）

すべての z>=0・x>=10・R>=0 に対して H(R;(x,10);z) = cand10(z,x,R)。cand10 は以下の z 偶奇別 T/P 集合表
（`cand10.py` が正本・Y=10・b_k = 奇 offset {1,3,...,2k-1}・offset o = R-z・d = x-z）。

### 値2集合 in_T10（probe 72,261 点で mismatch 0・probe box 内に値3は出現せず値域 {0,1,2}）

- マージ行 x <= z-11: O[1, q_odd(x+10)]（= 単一トークン single_token(x+10,z,R) の値2そのもの）
- 対角行 d = -10: 奇z O[1, z+10]／偶z O[1, z+9]（cap = z+y-[z≡y (mod 2)] の y=10 値。偶z 対角行は値1を一切持たない）
- 前倒し pin 格子行:
  - 奇z: d ∈ {-6,-2,2,6,10}（d≡y≡2 (mod 4)・d∈[-y+4,y]・5行）→ pin(d) = z+(d+3y)/2 = z+(d+30)/2 ∈ {z+12,z+14,z+16,z+18,z+20}
  - 偶z: d ∈ {-8,-4,0,4,8}（d≡y+2≡0 (mod 4)・d∈[-y+2,y-2]・5行）→ pin(d) ∈ {z+11,z+13,z+15,z+17,z+19}
  - d > y の同 residue 行（奇z d=14,18,...・偶z d=12,16,...）は steady pin に一致: {z+20}（奇z）/{z+21}（偶z）
- 掃引行 d = 11 = y+1: 奇z 偶offset [z+20, x+z+10]（= O[2y+z, x+z+y]∩(R≡z (mod 2))）／
  偶z 奇offset [z+21, x+z+10]（= O[2y+z+1, x+z+y]∩(R≢z (mod 2))）
  （掃引帯の偶奇は R ではなく offset の偶奇で決まる点に注意。y=10 fit の初稿 255 点不一致はすべてこの偶奇基準の誤りだった）
- 定常行 d >= 12: {z+20}（奇z）/{z+21}（偶z）（2y+z／2y+z+1）

pin 統一式 pin = z+(d+3y)/2〔(x-y)+z≡2 (mod 4)・pin 行の d は奇z d≡y (mod 4)・偶z d≡y+2 (mod 4)〕は
y=5..9 に続き y=10 でも成立（6 族連続）。ただし pin 行の d 範囲は y=10 では
奇z [-y+4,y]={-6,..,10}（y=9 [-y+2,y]={-7,..,9} の左端 +2 シフト）・
偶z [-y+2,y-2]={-8,...,8}（y=9 [-y+4,y+2]={-5,..,11} から y=8 と同じ形へ復帰）と族ごとに変動し、
pin 行数は奇z・偶zとも 5 行（y=9 に続き 2 族連続 5/5）。d 範囲の一般式は未確定（横断観察）。

## y=1..9 全称表からの横断予想の y=10 での判定（有限範囲・全称ではない）

- tail 開始式 x+z+y+1: y=10 で一致（x+z+11・10 族連続の予想を支持）
- tail 値 (x+y) mod 2 と値1無限帯・tail の x 偶奇: y=10 は偶数 y 型（x 奇の行）で y=2,4,6,8 と同型
  （y 偶奇が型を決める 10 族連続の観察。y 奇は x 偶の行）
- マージ命題 x<=z-(y+1): y=10 で一致（x<=z-11・probe 3,630 点＋回帰 18,795 比較）
- 基底点 y 点仮説 {z+1,..,z+2y-1}: y=10 で 10 点が一致（y=1..10 連続の予想を支持）
- 対角行上端格子規則 cap = z+y-[z≡y (mod 2)]: y=10 で全 probe z 一致（奇z z+10／偶z z+9）
- 定常 pin 2y+z／2y+z+1: y=10 で一致（z+20/z+21）
- pin 統一式 pin=z+(d+3y)/2: y=10 で成立（6 族連続）。ただし pin 行 d 範囲は
  奇z 偶zとも 5 行で、奇z [-y+4,y]・偶z [-y+2,y-2]（y=9 は奇z [-y+2,y]・偶z [-y+4,y+2] と互いに逆に寄る）。
  d 範囲の族ごとの遷移（y=7 偶z 3行 [-y+4,y-2]・y=8 偶z 4行 [-y+2,y-2]・y=9 偶z 5行 [-y+4,y+2]・
  y=10 偶z 5行 [-y+2,y-2]）に単純な族式はなく、一般証明は今後の課題。
- 偶z 対角行の値1全欠如: y=8/y=9 に続き 3 族連続
- 最終pin行 d=y の値1追加点帯 2y+z+1: y=10 奇z d=10 行の I[z+21) で確認（y=6/y=8/y=9 と同じ最終pin行パターン・4 族連続）
- band 下端 z+2y+2 = clip 窓族式候補 2y+2 の y=10 値 22: band の下端として出現（y=5..9 の 5 族連続 tight に対応。
  型機械 ±22/番兵±23 の tight 判定は次段階）
- 掃引帯 O[2y+z, x+z+y]（奇z・偶offset）／O[2y+z+1, x+z+y]（偶z・奇offset）:
  y=10 でも族式どおり（offset 基準の偶奇。y=9 では R 基準と offset 基準が一致していたため表記上の差が出ない）
- survey の予備 onset 観察（log 記載）のうち偶z の値は fit と一致、奇z の速報値
  （d=-5→14・d=1→17・d=3→17・d=9→20）は fit では成立せず（d=-5: b6・d=1: b8・d=3: b8・d=9: b10 は値1終端・I 帯なし）、
  99,579 点の全点照合に基づく本 fit がこれらを置き換える（survey の窓 30 による読み取り限界の明示どおり）。
