# 2トークン残余ゲームの高さ \(z=4\) スライス：全Grundy値の閉形式（予想）

- 日付: 2026-11-16
- 対象: K0832 の \(\kappa=1\) 残余ゲーム \(H(R;X;z)\)、\(X=(x,y)\)、\(x\ge y\ge1\)、\(z=4\)
- status: **有限監査済みの予想**。全称性は未証明。根拠は (i) 二重エンジンとの全状態照合、(ii) 子の値を閉形式のみから構築した帰納ステップ機械検査、(iii) 既証明スライス・単一トークン閉形式とのアンカー照合、(iv) tail・偶奇構造検査、のいずれも有限範囲である。\(z=3\) と同型の強帰納で閉じる見込みが強いが、選択肢表の全称化（全パラメータ場合分けの記述）は次の課題。
- 位置づけ: 既証明の \(z=0,1,2,3\) に続く第5スライスの候補。K0832 の3族予想の \(z=4\) スライスと整合する。

## 予想（閉形式）

\[
S=x+y,\qquad d=x-y
\]
と置く。

値2の位置集合を
\[
T_4(x,y)=
\begin{cases}
\{1\},&(x,y)=(1,1),\\
\{1,3,2y+3\},&d=2,\\
\{1,3,S,S+2,S+4\},&d=5,\\
\{1,3,2y+5\},&d\ge6,\\
\{1,3,S+1\},&d=0\text{ かつ }y=2,\\
\{1,3\},&\text{それ以外}.
\end{cases}
\]

値1の位置集合を \(P_4\) とする（\(T_4\) との交わりは空として読む）。
\[
P_4=
\begin{cases}
\{R:\ R\text{ は奇数},\ 5\le R\le S+1\}\setminus T_4,&d=0,\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+3\}\cup\{R:R\ge2y+4\}\cup\{4\},&d=1\ (\{4\}\text{ は }(x,y)=(2,1)\text{ のみ}),\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+1\},&d=2,\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+3\}\cup\{R:R\ge2y+4\},&d=3,\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+3\},&d=4,\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+3\}\cup\{R:\ R\text{ は偶数},\ 2y+6\le R\le S+5\}\cup\{R:R\ge S+6\},&d\ge5\text{ が奇数},\\
\{R:\ R\text{ は奇数},\ 5\le R\le2y+3\}\cup\{R:\ R\text{ は偶数},\ 2y+6\le R\le S+4\},&d\ge6\text{ が偶数}.
\end{cases}
\]

**予想.** 任意の \(x\ge y\ge1\)、\(R\ge0\) について
\[
H(R;(x,y);4)=
\begin{cases}
2,&R\in T_4(x,y),\\
1,&R\in P_4(x,y),\\
0,&\text{それ以外}.
\end{cases}
\]

### 具体例

| \((x,y)\) | \(d\) | 値2となる \(R\) | 値1となる \(R\) |
|---|---:|---|---|
| (10,10) | 0 | 1, 3 | 奇数 5〜21 |
| (12,10) | 2 | 1, 3, 23 | 奇数 5〜21 |
| (13,10) | 3 | 1, 3 | 奇数 5〜23、24以上全て |
| (15,10) | 5 | 1, 3, 25, 27, 29 | 奇数 5〜23、偶数26〜30、31以上全て |
| (16,10) | 6 | 1, 3, 25 | 奇数 5〜23、偶数26〜30 |

tail \(R\ge S+5=S+z+1\) では \(H=S\bmod2\) となり、既知の tail 境界と整合する（1,200点の独立確認）。

## 導出と構造

\(x\le24\)・全 \(y\le x\)・\(0\le R\le S+10\) の全状態を二重エンジンで計算し、\(d\) クラス別に値の位置を整列して抽出した。閉形式は初期抽出後、散点照合で1箇所の誤読（(12,1) の \(S+1\) を値1に含めるべき所を除外していた）を除き完全一致した。

\(z=3\) との比較:

- ラダー \(\{1,3\}\) は全 \(d\) に現れる（\(q_o(4)=3\)）。
- EXT族（\(\delta=(z+d)/2\)、\(z+d\equiv2\pmod4\)、\(d\le z\)）は \(z=4\) では \(d=2\) の1点 \(2y+3\) のみ。\(z=3\) の \(d=3\)（\(S=2y+3\)）、\(z=2\) の \(d=0\)（\(2y+1\)）と同型である。
- \(d=z+1\) のランは \(z=3\) の \(d=4\)（3点 \(2y+3,2y+5,2y+7\)）に対し、\(z=4\) では \(d=5\) の3点 \(S,S+2,S+4=2y+5,2y+7,2y+9\) に移る。点数は3点で保存。
- 定常点（\(d\ge z+2\)）は \(\delta_A=\)「\(z\) 以上の最小奇数」に一致: \(z=3\) で \(2y+3\)、\(z=4\) で \(2y+5\)。
- PT角 \(y^\ast=(z-d)/2\) は \(z=4\) では \((2,2)\)（\(d=0\)）と \((3,1)\)（\(d=2\)）。\((2,2)\) では \(S+1=5\) が値2に加わる。\((3,1)\) では EXT点 \(2y+3=5\) と一致し、それ以上の間隔は有限範囲では観測されない。
- 値1の高い側の帯は \(d\) の偶奇で質が変わる: 奇数 \(d\ge5\) では偶数帯 \([2y+6,S+5]\) の後に無限尾 \([S+6,\infty)\) が続くが、偶数 \(d\ge6\) では偶数帯は \(S+4\) で止まる。\([S+5,\infty)\) の tail 定理 \(H=S\bmod2\) と整合する。

これらは全て K0832 の3族予想の \(z=4\) スライスと一致する。

## 帰納ステップ機械検査

\(z=3\) の証明と同じ強帰納構造が \(z=4\) でも閉じるかを、子の値を**閉形式のみ**から構築して機械検査した:

- A子（トークンを1減らす、\(z=4\) のまま）: 本予想 \(F_4\) 自身（帰納仮説相当）。
- B子（トークン1を除去、\(z\to5\)）: 残る状態は常に単一トークン \((\,\cdot\,)\)・高さ5なので、既証明の単一トークン閉形式 \(H(\cdot;(s);5)\)。
- C子（\(z\to3\)）: \(1\oplus F_3\)、ただし \(F_3\) は既証明の \(z=3\) 閉形式。

すなわち帰納の子はすべて既証明閉形式（単一トークン \(z=5\)、\(z=3\) スライス）と帰納仮説 \(F_4\) だけで構成され、\(z=3\) 証明と同じ閉じた構造である。\(x\le24\)・全 \(y\le x\)・\(1\le R\le S+8\) の9,900状態すべてで、閉形式から構築した選択肢値集合の mex が候補 \(F_4\) と一致した（不一致0）。この機械検査は「選択肢表の偶奇場合分けが有限範囲で空きなく閉じる」ことの確認であり、全称証明の骨格が \(z=3\) と同型であることを強く示唆するが、表の全パラメータでの書き下ろし（=証明本文）がまだ書かれていないため、証明ではない。

## 限界と次の課題

- 本記録は予想であり、全称定理ではない。有限監査・機械検査は全称性の根拠ではない。
- 全称化の道筋: \(z=3\) 報告書と同じ強帰納の選択肢表を \(d\) クラス別に全パラメータで書き下ろす。帰納の子は既証明閉形式と帰納仮説のみで閉じ、機械検査（9,900点・不一致0）は表が空きなく閉じることを示唆するが、書かれた表が全称証明となる。
- 次の自然課題は (a) \(z=4\) 選択肢表の書き下ろしによる昇格、(b) \(z=5\) スライスの閉形式抽出。
- 標準二次元の共円ゲームの勝敗、固定幅安定化長、3トークン族の全分類は主張しない。
- K0832 の3族予想の \(z=4\) 部分は本予想と整合するが、3族予想自体は引き続き未証明。
