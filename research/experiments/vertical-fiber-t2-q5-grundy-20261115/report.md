# \(t=2,\ q=5\) 純ファイバーゲームの全局面Grundy分類

## 設定

有限集合 \(B\)、高さ集合 \(A\) を取り、
\[
w=|B|\ge3,\qquad m=|A|\ge2
\]
とする。底面跡制約は置かず、各ファイバー上で零多項式にならない \(z\) 次数2以下の多項式超曲面による5点共存を禁止する。

K0832の厳密占有縮約により、占有ベクトル \(c=(c_b)_{b\in B}\) の安全条件は
\[
C(c):=\sum_{b\in B}\min(c_b,2)\le4
\]
であり、着手は一成分を1増やす操作と一致する。

安全状態の非空ファイバー数は高々4で、占有数の多重集合は次のいずれかである。

- \(()\)：空。
- \((a)\)：一列だけ非空。
- \((a,b)\)：二列が非空。\(1\le a,b\le m\) は任意。
- \((a,1,1)\)：三列が非空。\(1\le a\le m\)。
- \((1,1,1,1)\)：四列が各1石。

この形の有限性が、全局面の分類を可能にする。

## 定理

\(p_a=(m-a)\bmod2\) とする。Grundy値は占有数の多重集合だけで決まり、次の表で完全に与えられる。

| 占有数の形 | Grundy値 |
|---|---|
| \(()\) | \(1\) iff \(w=3\) かつ \(m\) 奇数。それ以外は \(0\) |
| \((1)\) | \(m\) 偶数なら \(1\)。\(m\) 奇数なら \(w=3\) で \(0\)、\(w\ge4\) で \(2\) |
| \((a),\ a\ge2\) | \(p_a\) |
| \((1,1)\) | \(m\) 奇数かつ \(w=3\) のとき \(1\)。それ以外は \(0\) |
| \((1,b),\ b\ge2\) | \(m\) 偶数なら \(b\) 偶数で \(1\)、奇数で \(0\)。\(m\) 奇数なら \(b\) 偶数で \(3\)、奇数で \(2\) |
| \((a,b),\ a,b\ge2\) | \(p_a\oplus p_b\) |
| \((1,1,1)\) | \(m\) 偶数なら \(1\)。\(m\) 奇数なら \(w=3\) で \(0\)、\(w\ge4\) で \(2\) |
| \((a,1,1),\ a\ge2\) | \(p_a\) |
| \((1,1,1,1)\) | \(0\) |

したがって
\[
\boxed{\max_{c\text{ safe}}G(c)=
\begin{cases}
1&m\text{ 偶数},\\
3&m\text{ 奇数},
\end{cases}}
\qquad(w\ge3,m\ge2).
\]
特に \(m\) 奇数ではGrundy値3が必ず現れ、\(m\) 偶数では全局面のGrundy値は0または1だけである。

## 証明

各占有型の遷移を整理する。以下、同じ占有型へ移る複数の着手はGrundyの選択肢集合では一つにまとめる。

### 1. 二つの飽和列

\((a,b)\), \(a,b\ge2\) では容量4を使い切る。新しい列は開始できず、二列の占有数をそれぞれ \(m\) まで進めるだけである。二つの鎖の直和なので
\[
G(a,b)=p_a\oplus p_b.
\]

### 2. 一つの飽和列と一つの単独石

\(x_b:=G(1,b)\)（\(2\le b\le m\)）と置く。\((1,b)\) からの合法手は、

- 単独石の列を2にして \((2,b)\) へ進む。
- \(b\) の列を \(b+1\) に進める（\(b<m\)）。
- \(w\ge3\) なら第三列に単独石を置き \((b,1,1)\) へ進む。

第三の子は、飽和列だけを進める鎖なので値 \(p_b\)。第一の子は \(p_2\oplus p_b\)。従って
\[
x_b=\operatorname{mex}\bigl(
\{p_2\oplus p_b,\ p_b\}
\cup
(\{x_{b+1}\}\text{ if }b<m)
\bigr).
\]

終端 \(b=m\) では \(p_m=0\) だから、
\[
x_m=\operatorname{mex}\{p_2\}.
\]
\(m\) 偶数なら \(p_2=0\) なので \(x_m=1\)。\(m\) 奇数なら \(p_2=1\) なので \(x_m=2\)。

- \(m\) 偶数では \(p_2=0\) であり、再帰は \(x_b=\operatorname{mex}\{p_b,x_{b+1}\}\)。後ろから帰納すると \(x_b=1\)（b偶数）、\(0\)（b奇数）。
- \(m\) 奇数では \(p_2=1\) であり、\(p_b\) と \(p_2\oplus p_b\) は0と1の両方を取る。終端値2から逆向きにmexを取ると、\(x_b=3\)（b偶数）、\(2\)（b奇数）。

これで表の \((1,b)\) が得られる。

### 3. 三列・四列

\((a,1,1)\), \(a\ge2\) は容量4を使い切っている。単独石を進めると容量5になり不合法で、空列も開始できない。従って値は鎖の長さの偶奇 \(p_a\)。

\((1,1,1,1)\) は終局で値0。

\((1,1,1)\) の値を \(y\) とする。各単独列を2に進めると \((2,1,1)\) となり値 \(p_2\)。また \(w\ge4\) なら第四列を開始して終局 \((1,1,1,1)\)（値0）へ進める。よって
\[
y=\operatorname{mex}\bigl(\{p_2\}\cup
(\{0\}\text{ if }w\ge4)\bigr).
\]
従って、\(m\) 偶数なら \(y=1\)、\(m\) 奇数なら \(w=3\) で \(0\)、\(w\ge4\) で \(2\)。

### 4. 二つの単独石

\((1,1)\) からは、どちらかを2にする \((2,1)\) への手と、\(w\ge3\) なら第三列を開始する \((1,1,1)\) への手がある。前者の値は \(x_2\)、後者の値は \(y\)。従って
\[
G(1,1)=\operatorname{mex}\{x_2,y\}.
\]
上で得た値を代入すると、\(m\) 奇数かつ \(w=3\) のときだけ1で、他は0となる。

### 5. 一列と空局面

\(A_a:=G(a)\) と置く。\(a\ge2\) では、同じ列を進めるか、第二列を開始するかの二種類だけなので
\[
A_m=\operatorname{mex}\{x_m\},\qquad
A_a=\operatorname{mex}\{A_{a+1},x_a\}\quad(2\le a<m).
\]
上の \(x_a\) の式から逆向きに帰納して \(A_a=p_a\) を得る。

単独1石 \((1)\) では、同じ列を2に進める \((2)\) と、第二列を開始する \((1,1)\) が選択肢となる。従って
\[
A_1=\operatorname{mex}\{A_2,G(1,1)\}.
\]
場合分けにより、\(m\) 偶数なら1、\(m\) 奇数なら \(w=3\) で0、\(w\ge4\) で2。

空局面の全ての子は同じ値 \(A_1\) を持つため、
\[
G(())=\operatorname{mex}\{A_1\},
\]
すなわち \(A_1=0\) のとき1、それ以外は0である。

以上で全ての安全占有型を覆った。表の値は0〜3に限られ、\(m\) 奇数では \((1,2)\) の値が3、\(m\) 偶数では全て0または1。∎

## 最小のGrundy値3の局面

\(w=3,m=3\)、占有ベクトル \(c=(2,1,0)\) を取る。この局面の合法手は三つの型に分かれ、子は

\[
(3,1,0),\quad(2,2,0),\quad(2,1,1)
\]

となる。上の分類から、それぞれのGrundy値は
\[
2,\quad0,\quad1.
\]
従って
\[
G(2,1,0)=\operatorname{mex}\{0,1,2\}=3.
\]

これは \(t=2,q=5\) の範囲で、幅・高さともに最小のGrundy値3の証人である。\(w=2\) では第三列を開始できず、今回の定理の分類とは異なる。

## 有限監査

二つの独立表現で再帰mexを実行した。

1. **ラベル付き占有ベクトル**：各 \(c\in\{0,\ldots,m\}^w\) を直接列挙し、容量条件だけで安全性を判定。
2. **正占有数の多重集合**：組合せ重複を列挙し、異なる占有数を1増やす手と新列開始だけで遷移を生成。

範囲は両方とも \(3\le w\le12,\ 2\le m\le16\) の150パラメータ組。

- ラベル付き表現：723,780状態
- 多重集合表現：11,135状態
- 閉形式との不一致：両方式とも0
- 最大Grundy値：偶数mで1、奇数mで3
- 最小証人 \((w,m,c)=(3,3,(2,1,0))\) の子値：\(\{0,1,2\}\)

状態数の独立確認式は
\[
1+wm+\binom w2m^2+
\binom w3\bigl(1+3(m-1)\bigr)+\binom w4.
\]
内訳は空、単独列、二列、三列型 \((a,1,1)\)、四単独列である。

監査出力のSHA-256：
`9cf68cbf35119784e61a2a56c4d5d3bd22301b33d38599db437d2ace79bd8b8f`

この有限監査は再帰実装の照合であり、全称性は上記の遷移場合分けとmex帰納法による証明に依存する。

## 適用範囲と限界

- 底面跡制約なし、\(t=2,q=5,w\ge3,m\ge2\)。
- K0832の「各ファイバー上で零多項式にならない」条件を維持する。
- \(w=2\)、\(q\ge6\)、底面跡制約ありにはそのまま適用しない。
- これは抽象ファイバー多項式ゲームの定理であり、標準二次元の3×m・q=5幾何ゲームの定理ではない。
