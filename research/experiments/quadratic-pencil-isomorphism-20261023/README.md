# 3×3二係数版207型のハイパーグラフ同型分類（2026-10-23）

現在の結論の正本は K0563。

`research/log/2026-10-23-ten-minute-hypotheses.md` の候補03
「3×3二係数版の全207型は少数のハイパーグラフ同型類に縮むか」への回答。
対象は K0518 の二係数分類（`det[x²+λy²+μxy, x, y, 1]=0`、3×3、全実数 `(λ,μ)` の
31直線・175交点・207禁止族型）である。

## 同型の定義

2つの型が同型であるとは、9点 `{(x,y): 0<=x,y<3}`（順序は `y*3+x`）の置換で
一方の禁止4点組の族を他方へ正確に移せるときをいう。
幾何的な合同や係数平面上の変換ではなく、ラベル付きハイパーグラフの同型である。
同型な型は全安全局面のGrundy値・初手値（置換経由）・終局分布が一致するが、
逆は成り立たない（下記）。

## 方法

外部ライブラリを使わない単一スクリプト `isomorphism.py` で、次をすべて厳密に行う。

1. 整数行列式から31直線・175交点・207族を再生成する。行列式は
   4×4置換展開と、最終点差分による3×3行列式の2経路で計算し、全係数の一致を assert する。
2. 再生成結果を K0518 の公開値と回帰照合する：直線表（係数と追加辺数）、
   型の内訳（generic 1・直線 31・交点 175）、空盤Grundy頻度 `g=0:31, g=1:142, g=2:16, g=3:18`、
   および `two-parameter.json` の個別ケース5件の全プロファイル。
3. 同型分類は2方式で独立に行い、分割の一致を assert する。
   - 方式1：不変量（辺数・次数列・対共次数列・三点共次数列）で bucket 分けし、
     共次数による枝刈り付き全探索 backtracking で同型を判定する。
     得られた同型はすべて証人置換を保存し、直接代入で再検査する。
   - 方式2：色精密化（次数から開始する安定色付け）＋色保存再ラベル付けの
     最小符号化による canonical form。
4. 各代表について自己同型群の位数も全探索で数える。

## 結果

- **207型は46同型類に縮む。** 類サイズの分布は
  `1:7類, 2:13類, 4:16類, 8:4類, 10:1類, 12:4類, 20:1類`。
- 内訳は generic が単独1類、直線型31件が8類、交点型175件が37類。
  **直線型と交点型が同じ類に入ることは一度もなかった。**
- 最大類は辺数4・空盤 `g=1` の交点型20件からなる類。
  直線型では、追加辺2の型が3類（サイズ10・8・4）に分かれる。
- 単独類は7件：generic（辺0）、直線 `λ=1`（辺5、`g=0`）、直線 `μ=0`（辺9）、
  直線 `λ=0`（辺18、`g=0`）、交点 `(λ,μ)=(1,0)`（辺14）、
  交点 `(-1,0)`（辺29、活性直線7本）、交点 `(0,0)`（辺45、活性直線8本、`g=0`）。
- Grundyプロファイル（安全局面数・空盤値・初手値の多重集合・Grundy頻度・
  終局石数分布の組）は各同型類上で一定だった（必要条件の確認）。
  しかし相異なるプロファイルは45種類しかなく、**同型でない2類が
  プロファイル全体を共有する例がちょうど1組ある**：
  代表 `(λ,μ)=(1/3,-1/6)`（活性直線 `(1,2,0)`, `(2,-2,-1)`、類サイズ12）と
  代表 `(1/3,-2/3)`（活性直線 `(1,2,1)`, `(2,1,0)`、類サイズ8）。
  両者は辺数4、安全局面416、空盤 `g=1`、初手値すべて0、最大安全石数7、
  終局分布 `{6:2, 7:9}`、Grundy頻度 `{0:192, 1:192, 2:16, 3:16}` まで一致するが、
  自己同型群の位数が 4 と 8 で異なり同型ではない。
  つまり候補03の注意どおり、Grundy一致（この場合はプロファイル全体の一致）から
  同型は結論できない。

全類の代表・所属型・証人置換・自己同型位数は `isomorphism-results.json` に保存した。

## 限界

- 3×3二係数版だけの有限完全計算であり、4×4二係数版や他の盤・規則への外挿ではない。
- 同型は点ラベルの置換によるもので、係数平面のどの変換が同型を誘導するか
  （候補06・07の反射・反転による説明）は未解決のまま残る。
- Lean証明書はない。信頼境界は K0518 と同じく規則定義とPython実行系に残るが、
  本実験の分類自体は2方式の一致と証人置換の直接再検査で裏付けている。
