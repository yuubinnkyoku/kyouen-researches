# q=191〜200 奇数次数切替の独立有理数監査（2026-11-06）

## 対象と結果

先行資料 `research/experiments/graph-star-subdivided-star-q191-q200-odd-transitions-20261106/proof.md` の10組20境界を、先行の整数不等式を直接使わずに `fractions.Fraction` で監査した。全件 PASS。

この監査は境界の**厳密な算術検証**であり、先行の解析的単調性・根数上界の独立再証明ではない。一般の q で接触二重根がないという主張も導かない。

## 方法

`r=q-3`、`a=(r+2)/(r+1)`、`y_*=ka/(k+1)`、`H=(a-y_*)y_*^k` を有理数で直接計算する。各 q の非存在境界 `k_-` では `1<y_*<a` と `H<r-a`、存在境界 `k_+=k_-+2` では `1<y_*<a` と `H>r-y_*` を検査する。端点の符号 `F(1)>0,F(a)>0` も有理数で確認する。

```python
from fractions import Fraction

rows = [
    (191,2675),(192,2691),(193,2707),(194,2723),(195,2739),
    (196,2755),(197,2773),(198,2789),(199,2805),(200,2821),
]
for q, km in rows:
    r = q - 3
    a = Fraction(r + 2, r + 1)
    f1 = Fraction(r - 1) - (a - 1)
    fa = r - a
    assert f1 > 0 and fa > 0
    for k in (km, km + 2):
        y = Fraction(k, k + 1) * a
        assert 1 < y < a
        H = (a - y) * y ** k
        if k == km:
            assert H < r - a
        else:
            assert H > r - y
    print(q, "PASS")
```

実行済み: q=191,192,193,194,195,196,197,198,199,200 のすべてで PASS。浮動小数点演算なし。計算は `python` 標準ライブラリのみ。

## 信頼境界と次の課題
