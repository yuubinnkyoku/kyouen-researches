# PG(2,8)・AG(2,8) のキャップ・ゲーム — 国勢調査と parity 定理（宣言・2026-11-25）

## 目的

q=8 の射影平面 PG(2,8)（73 点）とアフィン平面 AG(2,8)（64 点）で s=2 キャップ・
ゲームを解く。2^73 / 2^64 の状態空間は DP 不可能なので、**全キャップの国勢調査**
（サイズ別総数と極大数）を行い、K1298 の parity 特性定理
（極大サイズのパリティ一様 ⇒ `Grundy(S)=(p−|S|) mod 2`）で完全解を得る。

## 手法

- `scripts/build_pg2q8.py`: GF(8)=GF(2)[x]/(x³+x+1) 上で PG(2,8) を構成し、
  AG(2,8) は 1 直線を無限遠線として除いて導出。点対一意性・点次数を全数検査。
- `scripts/cap_census.c`: n>64 でも動く s=2 国勢調査。増分カウントで全キャップを
  列挙し、サイズ別の総数と極大数（追加可能点なし）を数える。位置マスク不要。
- 極大サイズがすべて偶数なら K1298 より `Grundy(S)=|S| mod 2`。

## 結果（予定）

- PG(2,8): キャップ 19,550,350、極大 6 (2,060,352) と 10 (32,704)、すべて偶数。
- AG(2,8): キャップ 9,136,801、極大 6 (959,616)、8 (20,160)、10 (12,544)、すべて偶数。
- いずれも `Grundy(S)=|S| mod 2`、`G(∅)=0`、misère 勝ち。
