# 抽象禁止集合ゲーム：Grundy値4の最小点数と群膨張の偶奇商

2026-10-19。対象は抽象的な有限禁止集合ゲームの通常プレイであり、標準の整数格子盤に実現できることは主張しない。研究repoのmain `e53c9d3fd1ec8e64757d985f9e3c78926bed931f`、AGENTS.md、knowledge/README.md、未解決一覧を確認し、既存K0344（交換可能class圧縮）およびK0339（r人終局gcd）と区別した。

## 定理A：空局面Grundy値4の最小点数は6

高々5点の任意の抽象禁止集合ゲームの空局面では `g<=3`。6点の禁止集合

```
{0,1}, {0,2}, {1,4}, {1,5}, {2,3,4}, {2,3,5}
```

では `g(empty)=4` であり、6つの初手の子Grundy値は点番号順に `(1,0,0,2,3,3)` である。従って最小点数は厳密に6。

**下界の完全性：** 包含極小禁止集合の族は包含関係に関する反鎖であり、逆にどの反鎖もゲームを定める。空の禁止集合は空局面を不正にするので除外する。1点禁止集合は、その点を初めから除いたゲームと同じであるため、点数が少ない場合へ帰着する。従って2点以上の禁止集合のみからなる反鎖を全列挙すれば漏れがない。`verify_minimum.cpp` は反鎖を全生成し、各反鎖の全 `2^n` 部分集合を独立にmex計算する。

| n | 反鎖数 | g=0 | g=1 | g=2 | g=3 | g>=4 |
|---:|---:|---:|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 | 0 | 0 | 0 |
| 2 | 2 | 1 | 1 | 0 | 0 | 0 |
| 3 | 9 | 4 | 2 | 3 | 0 | 0 |
| 4 | 114 | 46 | 22 | 22 | 24 | 0 |
| 5 | 6894 | 1814 | 2850 | 390 | 1840 | 0 |

これは標本計算ではなく、対象となる全ての有限構造を尽くした**計算機援用の全称証明**。6点の存在例は64部分集合の有限完全検査で確定する。

## 定理B：任意の基底超グラフの群膨張の厳密商再帰

基底点集合 `[k]` の禁止超グラフH（空辺なし）をとり、各基底点iを互いに素な `n_i>=1` 点の群 `V_i` に置き換える。基底禁止辺eごとに、eに属する各群から1点ずつ選んだ全横断集合を禁止する。安全局面Sで点を置いた群集合をA、置いた群に残る自由点数を `f=sum_{i in A}(n_i-|S∩V_i|)` とする。

基底の安全群集合Aに対して次の帰納式を定める：

```
F(A) = mex { ((n_i-1) mod 2) xor F(A union {i})
             : i not in A and A union {i} is safe in H }
g(S) = (f mod 2) xor F(A)
```

終端ではmex(空)=0。これは**数学的な全称証明**を持つ。既に点を置いた群の残点は、どの将来手順でも制約に影響しない自由点であり、自由点f個のゲームはGrundy値 `f mod 2` の独立成分である。未使用群iを初めて使う着手は1手を消費し、残り `n_i-1` 個の自由点を新たに作る。通常プレイの直和則とmex定義を適用して上式を得る。基底群状態は高々 `2^k` 個であり、`F(A)<=k-|A|`、従って `g(S)<=k-|A|+1`。

特に空局面の値は各群サイズの偶奇だけに依存し、サイズを2増減しても（正の範囲なら）変わらない。極大安全配置は基底Hの極大安全群集合Aを選び、その群をすべて埋めたものに限る。終局石数は `sum_{i in A}n_i`。r人巡回版の敗者固定判定は既存K0339の極大サイズ差gcd判定を適用できる。

この再帰は既存K0344の交換可能class圧縮と整合する、**特殊な群膨張に対する明示的な計算式**であり、K0344より一般的な圧縮定理を主張しない。以前の完全多部横断型は、Hが完全t一様超グラフの場合として含まれる。

## 独立検証

- `verify.py`: 禁止横断集合を全て明示し、ラベル付き部分集合のmexを直接計算。33,618例、801,016安全局面、102,286極大集合を照合。
- `verify_independent.cpp`: 横断集合を生成せず、各群の占有数ベクトルの別の再帰を計算。34,218例、566,285安全占有数状態、104,652極大状態を照合。5群の追加標本はPythonとは別。
- `verify_minimum.cpp`: 1〜5点の全反鎖と6点の証人を別実装で完全検査。n=5では6,894構造を尽くす。

```
python3 verify.py
g++ -std=c++17 -O2 -Wall -Wextra -Werror verify_independent.cpp -o /tmp/verify_blowup && /tmp/verify_blowup
g++ -std=c++17 -O2 -Wall -Wextra -Werror verify_minimum.cpp -o /tmp/verify_minimum && /tmp/verify_minimum
```

実際の正方形格子の残余局面にこの構造がどれだけ現れるか、また11×11探索を高速化するかは未測定。標準盤の空盤Grundy値4の最小nを主張するものではない。
