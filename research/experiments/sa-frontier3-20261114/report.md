# SAフロンティア第3弾 — M_{6,5}≥29（6×28の22石欠損極大witness・(6,5)初の2石欠損）と新前線6×29の抵抗（2026-11-14 高速レーン）

## 概要

K0811 レジューム「(6,5) m=28 の長時間攻撃」を実施。SA 機（`sa-frontier-extension-20261114/scripts/sa_machine.js`
= K0808 census・census不使用独立検証器の verbatim 移植）は無改変で、新規ドライバ
`variant_attack.js`（単一ケース・SAパラメータ明示指定・JSONL即時追記）と
`reverify.js`（results.jsonl から witness を読み出して別プロセスで独立検証）のみ追加。

## 主結果: M_{6,5} ≥ 29

**6×28 に22石の欠損極大witness を発見**（満容量24・2石欠損・seed 303・
T0=1.5, maxRemoveFrac=0.45, sampleK=36・412,141 iter・74.1秒）。

witness 座標（(x,y)・w=6, m=28, q=5）:
`[[9,0],[12,0],[14,0],[19,0],[6,1],[10,1],[14,1],[22,1],[8,2],[14,2],[17,2],[23,2],[5,3],[12,3],[16,3],[20,3],[7,4],[16,4],[4,5],[12,5],[14,5],[16,5]]`
行構成 4,4,4,4,2,4（行4が2石 = q−2 を下回る2石欠損）。

- in-machine 独立検証: safe+maximal PASS（worstLine=4, worstCirc=4）。
- **別プロセス再検証**（reverify.js・results.jsonl から witness を復元）: PASS。
- これは (6,5) で初めての2石欠損（従来の23石は1石欠損）であり、
  m=28 での初の欠損witness。**23石連続帯 6×22..6×27 は 6×28 の22石に更新され、
  M_{6,5} ∈ [28,658] は M_{6,5} ∈ [29,658] に更新**。
- 並走レーン（sa-frontier2・第2弾）は同一 m=28 を計10実行（50-65秒）で非発見の
  記録を push 済みだったが、いずれも T0≥2.0 系の構成のみ。本発見は
  T0=1.5/mrf=0.45/sK=36 構成で非発見帯を突破 — 非発見が不在を意味しない
  最も直接的な再実証（10 run 抵抗→74秒で発見）。

## SAT（K0810 機 verbatim・補助測定）

- 6×28 q=5 の census: 240 直線 + 4,274 円（SA 機・SAT 機の両 census 完全一致）。
- 6×28 row-deficient SAT はシングルコマンド予算（280秒）で encoding+CDCL とも
  決着せず（6×22 q=5 ですら 120秒で決着しない）。**6×29 の UNSAT（取れれば
  M_{6,5}=29 の確定）は本環境の単発予算を超えるため長期レーン向けの残作業**
 （sa-frontier2 の SAT timeout 観測（(6,8) m=18・(6,6) m=21）と整合）。

## 制御

- 2×8 q=4 → 5石witness・独立検証 PASS（K0796 再発見・機材再構築の健全性確認）。
- 6×28 census が SA 機と SAT 機（独立実装2系統）で一致。

## 手法メモ

- (6,5) m=28 はパラメータ帯によって発見難度が激変する: T0≥2.0 系は
  10 run・延べ~10分で非発見（sa-frontier2）に対し T0=1.5/mrf=0.45/sK=36 は
  74秒で発見。SA の抵抗記録にはパラメータ構成の併記が必須。
- 6×27 までは23石（1石欠損）しか知られていなかった帯で、m=28 で初めて
  2石欠損が出現 — 欠損量の m 非単調性の初のデータ点。
- m=29 は8 run・多様化込みで全て満容量。M_{6,5}=29 予想（ヒューリスティック・
  非不在証明）は SAT UNSAT が唯一の決着手段。

## レジューム

1. 6×29 q=5 の SAT UNSAT（K0810 機・長時間）→ M_{6,5}=29 確定なら
   CSV の (6,5) 行を exact-threshold に格上げ。
2. (6,6) m=22・(5,7) m=20 の長時間 SA/SAT。

   一般 w での構造族としての一般化可能性。
