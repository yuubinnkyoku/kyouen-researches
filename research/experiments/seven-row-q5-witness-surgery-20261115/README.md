# (7,5) witness surgery — m=33 witness からの2石移動で 7×34 witness（M_{7,5} ≥ 35）

日付: 2026-11-15 / レーン: 高速レーン（bash・SAT環境不通のため純TS完結）

## 概要

seven-row-q5-q8-sat-frontier-20261115 の (7,5) m=33 witness（27石・rows [3,4,4,4,4,4,4]・
triple-verified）を種に、7×34 盤で唯一の未遮断セル T=(33,0) を遮断する少数石再配置
（**witness surgery**）を探索し、**7×34 の 27石単一欠損 witness を2つ発見**した。
**M_{7,5} ∈ [35, 1142]**（上界は K0318 U=1142 不変）。SAT を使わない構成的下界更新。

## 手法

- **depth-1（1石移動）**: T を通る「ちょうど3石」の曲線（行0直線 + 5本の円）上の盤内
  空き格子点 sp への1石移動 s→sp を全列挙（939組み合わせ・安全 106）。増分判定で
  移動後の未遮断セル集合 U を計算。**単独moveでは U=∅ なし**（|U|=1 が2件）。
  列挙は完全: T が base で未遮断 ⟹ T を通る曲線はすべて ≤3石 ⟹ 移動後の T 遮断曲線は
  「ちょうど3石曲線 + 移動石」に限る。
- **depth-2（2石移動）**: depth-1 の各状態について、残り全セルを遮断する第2moveを探索
  （sp2 が未遮断セル各自を通る3石曲線上にあるという必要条件で絞り込み・5,673組み評価）。
  **2 witness を発見**:
  - **winA**: base −(25,5) −(20,4) +(8,5) +(2,4)
  - **winB**: base −(25,5) −(20,4) +(23,5) +(2,4)
  いずれも 27石・rows [3,4,4,4,4,4,4]・7×34 全211空セル遮断。2つとも同一の第2move
  (20,4)→(2,4) を持ち、第1moveの行5内水平移動のみが異なる。
- **範囲**: depth-2 は「どちらか1つの move が単独で T を遮断する」全組み合わせをカバー
  するが、両新石が同一の2石 T-曲線上に乗るケースは未探索。**7×34 の他の witness の
  不在、および 7×35 の不在は主張しない**。
- 増分 U 計算は探索の高速化専用（spot-check で総当たりとの不一致が残るため、採用は
  総当たり検証通過済みの候補のみ。witness の正当性は総当たり検証のみに依存する）。

## 検証（純TS完全整数演算・独立実装・repo コード不使用・census不使用・SAT不使用）

winA/winB とも:
1. **安全性**: C(27,5)=80,730 の5点部分集合全列挙 — 共線/共円上に5点なし（q=5）。
2. **極大性**: 7×34 全211空セルについて、各セルを通る直線・円の q−1=4 石被覆 — 未遮断 0。
3. **行欠損**: rows [3,4,4,4,4,4,4]（行0が3石 ≤ q−2）。
4. **7×35 profile**: 7×35 盤では cell (34,0) のみ未遮断 — surgery 反復の次の出発点。

全中間値は < 2^53 の完全整数演算（IEEE-754 厳密）。
**独立第二TS実装による再検証: PASS（両witness）** — 部分集合列挙と手法が完全に異なる実装
（ペア方向グループ化による直線カウント + ペア決定円への 4×4 整数行列式共円判定）で
safety（最大直線/円石数 4 < q=5）・7×34 maximality（211/211 遮断）・rows [3,4,4,4,4,4,4]・
7×35 profile（(34,0) のみ未遮断）をすべて再現。base m=33 witness による較正
（7×33 未遮断 0・7×34 で (33,0) のみ）および部分集合法によるスポット交叉確認も実施（2026-11-15）。
