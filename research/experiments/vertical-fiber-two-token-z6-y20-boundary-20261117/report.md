# 2トークン残余ゲーム \(z=6,\ y=20\) 切片の全Grundy分類

## 定理

\[
H(R;(x,20);6),\qquad x\ge20,\ R\ge0
\]
のGrundy値は常に \(0,1,2\) である。値2となる残容量は

\[
\boxed{
T_{20}(x)=\{1,3,5\}\cup
\begin{cases}
\{43\}&x=20,\\
\{45\}&x=24,\\
\{47,49,51,53\}&x=27,\\
\{47\}&x\ge28,\\
\varnothing&\text{その他}.
\end{cases}}
\]

区間内の奇数・偶数の集合を
\[
O[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv1\pmod2\},\qquad
E[a,b]=\{r\in\mathbb Z:a\le r\le b,\ r\equiv0\pmod2\}
\]
と書き、無限区間も同様に \(O[a,\infty),E[a,\infty)\) とする。値1となる残容量は

\[
\boxed{
P_{20}(x)=
\begin{cases}
O[7,41],&x=20,\\
O[7,\infty)\cup E[44,\infty),&x=21,\\
O[7,43],&x=22,\\
O[7,\infty)\cup E[46,\infty),&x=23,\\
O[7,43],&x=24,\\
O[7,\infty)\cup E[46,\infty),&x=25,\\
O[7,45],&x=26,\\
O[7,45]\cup E[48,\infty)\cup O[x+28,\infty),
  &x\ge27\text{ 奇数},\\
O[7,45]\cup E[48,x+26],
  &x\ge28\text{ 偶数}.
\end{cases}}
\]

値0の位置は \(T_{20}(x)\) と \(P_{20}(x)\) の補集合である。またK0832の一般tail定理から

\[
\boxed{
R\ge x+27\implies H(R;(x,20);6)=(x+20)\bmod2
}
\]
を得る。

## 再帰と依存

親の選択肢値を
\[
\begin{aligned}
A&=H(R-1;(x-1,20);6),\\
B&=H(R-1;(x,19);6),\\
C&=1\oplus H(R-1;(x,20);5)
\end{aligned}
\]
とする。

\(x=20\) ではAの子のトークン対 \((19,20)\) は降順正準化で \((20,19)\) となり、Bの子と同一状態になるためK0911で評価できる。\(x\ge21\) ではAを同じ \(y=20\) 切片の \(R\) 強帰納仮説、BをK0911、CをK0873の \(z=5\) 全Grundy公式で評価する。

K0832のTheorem Tにより、奇数Rの親の選択肢値は \(\{0,1\}\) に含まれ、偶数Rの親のGrundy値は高々1である。従って、

- 奇数Rでは選択肢署名 \(\{0,1\},\{0\},\{1\}\) のmexはそれぞれ \(2,1,0\)。
- 偶数Rでは署名に0が含まれるときだけ親値が1となり、0を含まなければ親値は0。

## 選択肢署名表

各欄はA/B/Cの値集合である。区間端点を含み、奇数R列では奇数だけ、偶数R列では偶数だけを読む。表は \(1\le R\le x+26\) を覆う。

| x | 奇数Rの署名 | 偶数Rの署名 |
|---:|---|---|
| 20 | 1..5:{0,1}; 7..41:{0}; 43:{0,1}; 45:{1} | 2..6:{2,3}; 8..46:{1} |
| 21 | 1..5:{0,1}; 7..47:{0} | 2..6:{2,3}; 8..42:{1}; 44:{0,2,3}; 46:{0} |
| 22 | 1..5:{0,1}; 7..43:{0}; 45..47:{1} | 2..6:{2,3}; 8..48:{1} |
| 23 | 1..5:{0,1}; 7..49:{0} | 2..6:{2,3}; 8..42:{1}; 44:{1,2}; 46..48:{0} |
| 24 | 1..5:{0,1}; 7..43:{0}; 45:{0,1}; 47..49:{1} | 2..6:{2,3}; 8..50:{1} |
| 25 | 1..5:{0,1}; 7..51:{0} | 2..6:{2,3}; 8..44:{1}; 46:{0,2,3}; 48..50:{0} |
| 26 | 1..5:{0,1}; 7..45:{0}; 47..51:{1} | 2..6:{2,3}; 8..44:{1}; 46..52:{1,2,3} |
| 27 | 1..5:{0,1}; 7..45:{0}; 47..53:{0,1} | 2..6:{2,3}; 8..44:{1}; 46:{1,2,3}; 48..52:{0} |
| 28 | 1..5:{0,1}; 7..45:{0}; 47:{0,1}; 49..53:{1} | 2..6:{2,3}; 8..44:{1}; 46:{1,2,3}; 48..54:{0,2} |
| \(x\ge29\) | 1..5:{0,1}; 7..45:{0}; 47:{0,1}; 49..\(U_o\):{1} | 2..6:{2,3}; 8..44:{1}; 46:{1,2,3}; 48:{0,2}; 50..\(U_e\):{0} |

最終行は
\[
U_o=
\begin{cases}
x+26&x\text{ 奇数},\\
x+25&x\text{ 偶数},
\end{cases}
\qquad
U_e=
\begin{cases}
x+25&x\text{ 奇数},\\
x+26&x\text{ 偶数}.
\end{cases}
\]

\(x=20\) の合流境界、\(x=21,\ldots,28\) の過渡域、\(x\ge29\) の定常域を分けた。最終行ではAの子も定常式に入り、BはK0911の定常式、CはK0873の \(d=x-20\ge9\) の式に入る。各式をA/B/Cへ代入して区間端点を比較すると、表示した署名が \(x\) の偶奇ごとに得られる。従って最終行は有限標本からの外挿ではなく、一次式の端点比較による場合分けである。

奇数親の署名 \(\{0,1\}\) から値2位置は基本ラダー \(\{1,3,5\}\)、\(x=20\) の43、\(x=24\) の45、\(x=27\) の47,49,51,53、\(x\ge28\) の47に限られる。偶数親ではTheorem Tにより値2は生じない。値1位置は奇数親の署名 \(\{0\}\) と、偶数親で0を含む署名から上の \(P_{20}(x)\) になる。

表が \(1\le R\le x+26\) を覆い、\(R\ge x+27\) は一般tail定理で覆われる。\(R=0\) は終局値0。よってRに関する強帰納が閉じ、全 \(x\ge20,R\ge0\) で分類が成立する。∎

## 3族値2位置予想との一致

K0832の3族予想を \(z=6,y=20\) に特殊化し、\(d=x-20\) とする。

- 基本ラダーは \(\{1,3,5\}\)。
- 家族BのEXTは \(d=0,4\) で、それぞれ43,45。
- 家族Aのランは \(d=7\) で47,49,51,53。
- 家族Aの定常位置は \(d\ge8\) で47。

従って今回の \(T_{20}(x)\) と一致する。これは \(z=6,y=20\) の特殊化を全称証明したものであり、3族予想全体の証明ではない。
