# 三行二次形式版 λ=0 の最大安全石数：真の開始長8

2026-10-23。標準共円ゲームではなく、退化も含めた四点行列式
`det[x²+λy²,x,y,1]=0` を禁止する変種である。
現在の知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。

## 定理（全称的な盤長範囲）

`D(3,m)={(x,y):0≤x<m, y∈{0,1,2}}` とし、`K(m;λ)` を最大安全石数とする。

1. **λ=0 の場合、K(m;0)=9 となる必要十分条件は m≥8。**
2. `K(7;0)=8` である。
3. **任意の実数 λ とすべての m≥8 に対して K(m;λ)=9。**
   この「すべての実数係数で9石を置ける」ための一様な最小開始長は8。

これは **最大** 安全石数の定理であり、最小極大石数 `s`、全極大配置の一様終局長、Grundy値の安定化長を主張しない。

## 証明

どの実数λでも同一水平行の四点では `y²,y,1` が定数列になり、`x²+λy²,x,y,1` の行列式は0。したがって安全配置の各行には高々3点、`K≤9`。

λ=0 で m=8 の次の9点は安全である（各行は横座標集合）：

```text
y=0: {0,1,3}
y=1: {2,4,6}
y=2: {2,5,7}
```

独立した4×4整数行列式による126個の四点部分集合の検査では、禁止四点組が0。これは有限個の明示的な整数等式・不等式による証人である。m≥8 でも同じ9点が使えるため `K(m;0)=9`。

m=7 で9点安全な配置が存在するなら各行ちょうど3点である。各行の3点の選び方は `C(7,3)=35` 通り、合計 `35³=42,875` 通りを尽くす。付属の `verify.py` は次の禁止四点組の必要十分条件を整数演算で検査する：

- 二行に2点ずつ：二行の横座標の二点和が等しい。
- 三行に `(2,1,1)` 点：二重点を `a,b`、他の二行の点を `c,d` とすると、二重点が `y=0,1,2` の順に
  `-ab+2(a+b)c-(a+b)d-2c²+d²=0`、
  `-2ab+(a+b)(c+d)-c²-d²=0`、
  `-ab-(a+b)c+2(a+b)d+c²-2d²=0`。
- 一行に4点：必ず禁止。一行に3点＋別行1点は（横座標が相異なる限り）禁止されない。

42,875通りのうち9点安全配置は0。式による判定は m=2..5 の全2,001四点組について、独立したBareiss整数行列式と照合した。よって m=7 で `K≤8`。上記の9点証人から `(7,2)` を除けば m=7 内の8点安全配置が得られ、`K(7;0)=8`。m≤7 は7列盤に埋め込めるため、9石には届かない。

最後に、λ≠0 については既存 [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md) の **m=7・全実数λの74禁止族型の完全列挙**が `K(7;λ)=9` を示している。m≥7 へ同じ証人を埋め込める。λ=0 の上記結果と合わせて、すべての実数λ・m≥8で `K=9`。m=7,λ=0 が一様開始長8の鋭さを示す。□
