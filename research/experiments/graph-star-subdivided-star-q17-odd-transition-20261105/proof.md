# 一辺細分星 q=17 の奇数次数実根切替（2026-11-05）

## 定理（解析的全称証明＋厳密有理数不等式）

一辺細分星の終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
について r=q-3=14、奇数 k≥3 とする。

1. q=17 では奇数 3≤k≤129 に実根はない。
2. q=17 では奇数 k≥131 に相異なる負の単実根がちょうど2個ある。
3. 任意の整数 q≥17、奇数 3≤k≤129 に実根はない。

## 証明

先行する q=16 の証明と同じ変数変換 u=-(r+1)y により、負の実根は 1<y<a=1+1/(r+1) に限られ、その零点条件は
\[
F_{k,r}(y)=r-y-(a-y)y^k=0
\]
となる。正の u に根はない。

r=14、a=16/15 とする。固定 y∈(1,a) において (a-y)y^k は k に関して単調増加する。したがって k=129 で F>0 を示せば全奇数 k≤129 でも成立する。

H(y)=(a-y)y^{129} は [1,a] で一意の最大点 y_*=129a/130 を持つ。区間 [1,a] を100等分し、各 [l,h] で z=min(max(y_*,l),h) とすると H(y)≤H(z)。下記の検査により全100区間で H(z)<14-h≤14-y を厳密に確認した。よって k≤129 に根はない。

k=131 では y=131a/132=524/495 を選ぶと F_{131,14}(y)<0 を厳密に確認できる。固定 y>1 で k を増すと F は減少するため、全奇数 k≥131 で同じ点が負値を与える。F(1)>0、F(a)>0 より区間内に少なくとも二根がある。T_{k,r}(-x) の係数符号変化は2回であり、デカルトの符号法則から重複度込みで高々二根。従って相異なる負の単根がちょうど二つ存在する。

さらに r≥14 では候補区間 (1,1+1/(r+1)) は (1,16/15) に含まれ、固定 y>1 で F_{k,r}(y) は r に関して厳密増加する（偏導関数 1+y^k/(r+1)^2>0）。したがって q≥17、奇数 k≤129 にも非存在が及ぶ。

## 再現（Python 3、浮動小数点不使用）

```python
from fractions import Fraction as Q

r, k = 14, 129
a = Q(16, 15)
star = a * k / (k + 1)
for i in range(100):
    l = 1 + (a - 1) * Q(i, 100)
    h = 1 + (a - 1) * Q(i + 1, 100)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = Q(524, 495)
assert y == a * 131 / 132
assert 1 < y < a
assert r - y - (a - y) * y**131 < 0
```

**証拠区分:** 全称解析と100区間の有理数厳密不等式。一般 q の接触二重根不存在や格子盤の勝敗は主張しない。
