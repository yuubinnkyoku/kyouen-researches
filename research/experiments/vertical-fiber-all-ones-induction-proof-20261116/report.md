# 全1トークン族 h=U の全称帰納証明 — シグネチャ完全性ギャップの解消

報告日: 2026-11-16。対象はK0832縮約後の抽象残余ゲーム \(H(R;X;z)\)（κ=1）の全1族 \(X=(1^k)\) であり、標準二次元幾何ゲームの勝敗は一切主張しない。前報（vertical-fiber-all-ones-residual-structure-20261116）の残課題「実現シグネチャ全体が有限で尽きることの一般証明」を閉じ、**統一スライス閉形式 \(U\) の全称定理化**を完了した。

## 主定理

\(q(n)\) を \(n\) 以下の最大奇数、\(U(k,z,R)\) を前報W6の統一スライス閉形式（z≥1、本report付録に verbatim）、\(U_0(k,R)=\)（\(k\ge1\wedge R\ge1\) なら \([U(k-1,1,R-1)=0]\)、他は0）とする。全1族のGrundy値

\[
h(k,z,R)=\operatorname{mex}\{\,h(k-1,z+1,R-1)\ [k\ge1],\ \ 1\oplus h(k,z-1,R-1)\ [z\ge1]\,\},\quad h(\cdot,\cdot,0)=0
\]

について:

\[
\boxed{\ \forall k,z\ge0,\ \forall R\ge0:\quad h(k,z,R)=\begin{cases}U(k,z,R)&z\ge1\\ U_0(k,R)&z=0.\end{cases}\ }
\]

**系A（2位置の完全閉形式）** \(h(k,z,R)=2\iff R\in T(k,z)\)、ただし \(z=0\): \(T=\varnothing\); \(z\) 奇: \(T=\{1,3,\dots,q(k)\}\); \(z\ge2\) 偶: \(T=\{1,3,\dots,q(\min(k,z))\}\cup(\{2k-z+1\}\cap[1,\infty))\)。**系B（スライス閉形式）** \(z\in\{1,2\}\) の4式（前報W3）。両者とも主定理の \(U\) への代入で機械演繹される（E6・E7）。

## 証明の構造

\(R\) についての前進帰納。

**(i) 基底 \(R=0\)**。\(h=0\)（定義）。\(U(k,z,0)=0\)（全 \(k\ge0,z\ge1\)）: z奇では \(R=0\) 偶で \(k\) 偶なら \(0\equiv z+1\ (\mathrm{mod}\,4)\wedge z+1\le0\) は偽で0、\(k\) 奇なら \(0\le\min(z-3,k-1)\)（\(z\ge3\wedge k\ge1\)）または \(R\equiv z-1\wedge z-1\le0\le2k-z-1\)（\(z=1\wedge k\ge1\)）で0、残る \(k=0\)（全0）も0。z偶では \(0\notin\{奇\}\cup\{2k-z+1\}\)（z偶なら far は奇で0と不一致、かつ \(0\le2k-z-1\) 枝には入らない）、\(k\) 奇なら \(R\) 偶 \(\wedge R\le k-1\)（\(k\ge1\)）で0、\(k\) 偶は0。よって \(U(\cdot,\cdot,0)\equiv0\)。\(U_0(k,0)=0\)（ガード）。機械確認: box全4,225状態（B0）。

**(ii) \(z=0\) ステップ（自明）**。\(h(k,0,R)=\operatorname{mex}\{h(k-1,1,R-1)\}\stackrel{\mathrm{IH}}{=}\operatorname{mex}\{U(k-1,1,R-1)\}=[\,U(k-1,1,R-1)=0\,]=U_0(k,R)\)（mex of 単一値 \(v\) は \([v=0]\)）。

**(iii) \(z\ge1\) ステップ**。\(\tilde U(k,z-1,R-1)=U(k,z-1,R-1)\)（\(z\ge2\)）または \(U_0(k,R-1)\)（\(z=1\)）と置くと、帰納仮説より \(h(k,z,R)=\operatorname{mex}\{U(k-1,z+1,R-1)\ [k\ge1],\ 1\oplus\tilde U\ [z\ge1]\}\)。ステップ恒等式

\[
\operatorname{mex}\{U(k-1,z+1,R-1)\,[k\ge1],\ 1\oplus\tilde U(k,z-1,R-1)\,[z\ge1]\}=U(k,z,R)
\]

が全 \((k,z,R)\) で成り立てば \(h=U\) が閉じる。以下の補題1〜3から、この恒等式の検証は**有限な3,803シグネチャ類の完全列挙**に帰着し、全類で機械検証済みである（S3・C1）。

### 補題1（アトム表）

評価点を \(P=(k,z,R)\)、\(B=(k-1,z+1,R-1)\)、\(C=(k,z-1,R-1)\)、\(G=(k-1,1,R-1)\)（\(U_0\) の内側）の4点とする。\(U\)・\(U_0\)・mex引数ガードの全分岐条件は、各点の局所座標 \((a,b,c)\) について次の18比較アトムと5合同アトムで書ける: 比較は \(a,b,c\) の係数 \(\in\{-2..2\}\)・定数項 \(|{\cdot}|\le3\) の線形不等式、合同は \(\equiv\pmod2\)（\(a,b,c\) の奇偶）と \(c\equiv b\pm1\pmod4\)。検証子 `verify_induction_proof.py` の `L_ATOMS`/`L_CONGS` が全表である（構成上、\(U\) のソースの全分岐を1:1に列挙）。

**witness座標** \(s=R-k,\ s_2=R-z\) に置換すると、各（アトム×点）は線形代数で
\[
\alpha s+\beta s_2+\gamma R\ \le\ t\quad(\text{整数 } t,\ |t|\le5)
\]
の形に帰着する（\(k=R-s,\ z=R-s_2\) の代入は恒等変換）。実行結果、比較アトムはちょうど**15族**に整理される（閾値は |t|≤5）:

| (−2,0,1) | [1] | | (1,−1,0) | [−2,0,1] |
| (−2,1,0) | [−3,−1,1] | | (1,0,−1) | [−2,−1] |

合同アトム（各点の \(a\bmod2\)・\(b\bmod2\)・\(c\bmod2\)・\(c-b\equiv\pm1\ (\mathrm{mod}\,4)\)）はすべて \((s\bmod4,\ s_2\bmod4,\ R\bmod4)\) の関数に帰着する（例: P点の \(c-b\equiv3\) は \(s_2\equiv3\)、G点は \(R-2\equiv3\)、B点は \(s_2-2\equiv3\) など）。

**シグネチャ** \(\sigma(k,z,R)\) := 15族の比較ビット列（族ごとのパック値）+\((s\bmod4,s_2\bmod4,R\bmod4)\)。補題1により、\(U\)・\(U_0\)・ガードの4点での値はすべて \(\sigma\) のみで決まる（**シグネチャ決定性**）。実装上は二重経路で確認: `U_tab`（決定木をアトム表経由でwitness側から読む転写版）と published `U` の一致（S2: box全点×4評価点+ランダム、1,273,760照合・0不一致）およびアトム毎の両側真偽一致（S2_atom_equiv: 1,520,000照合・0不一致）。

### 補題2（R方向の安定化）

\((k,z)\) を固定すると各比較族の値は \(x=(\alpha+\beta+\gamma)R-(\alpha k+\beta z)\) で \(R\) の1次関数（\(\alpha+\beta+\gamma\ne0\) の族のみ変動）。全ての変動族の最終反転点の最大値 \(\mathrm{maxBP}(k,z)\le2k+z+3\) を超えると比較ビットは \(R\) について定数となり、シグネチャは剰余 \((R\bmod4)\) のみで4周期になる。ボックスは \(R\le\mathrm{maxBP}(k,z)+6\) まで掃引し、全剰余類を含む。

### 補題3（被覆補題 — 実現シグネチャの有限性と box 被覆）

到達可能集合は \(\{(s,s_2,R):\ R\ge1,\ s\le R,\ s_2\le R\}\)（\(k,z\ge0\) の翻訳）。**全ての実現シグネチャは \(|s|,|s_2|\le48,\ R\le152\) の到達可能点で実現される**。証明: \(R\) 非依存の族は座標 \(s,\ s_2,\ d=s-s_2,\ v=2s-s_2\)（\(-s_2,-v\) は重複）のみに依存し、その位置クラスは「層」（座標が \(\le5\) の閾値のどれかの値に固定）か「半直線」（座標が全閾値を超えて自由）のいずれかである。層に固定された座標は値 \(\le5\) に自動的に固定され（元の遠い点と同じ剰余を持つ層内代表は、層の要素自体が \(\le5\) なので必ず小さい）、自由座標は \([2..13]\) の範囲で任意の剰余を持つ代表を選べる（半直線の境界 \(\le5\)）。族間の矛盾（例: \(s\) の層と \(s_2\) の層から導かれる \(d\) が \(d\) の層と不一致）は細胞を空にするだけで、遠方実現が存在する細胞は必ず小さい代表を持つ。次に \(R\) 依存の8族 \((\alpha,\beta,\gamma),\ \gamma\ne0\) の位置は \(R\) の区間で、その境界は \(R^\ast=(t-\alpha s-\beta s_2)/\gamma\)、よって \(|R^\ast|\le2\cdot48+48+5=149\)。有界クラスは \(R\in[-149,149]\) に含まれ、半直線クラスの代表は \(R^\ast+\{0..3\}\le152\) で取れる。到達可能性 \(R\ge\max(s,s_2,1)\) は \(R\le152\) 側で充足可能。∎（機械側でこの結論を三尺度で独立確認: 下記C1）

### 帰納の完了

S3: ボックス \((k,z)\in[0,64]^2,\ R\in[1,\mathrm{maxBP}+6]\) の全318,930点で、ステップ恒等式を published `U` と `U_tab` の両経路で検証（**0不一致**）。ボックスが実現するシグネチャ集合 \(C_{\mathrm{box}}\) はちょうど **3,803種**。C1: witness掃引（\(|s|,|s_2|\le160,\ R\le320\)、到達可能のみ、比較ビット一定区間×剰余代表の完全列挙）の実現集合 \(C_{\mathrm{wit}}\) もちょうど3,803種で \(C_{\mathrm{box}}=C_{\mathrm{wit}}\)（双方向包含チェック 0/0）、さらに大規模掃引（\(|s|,|s_2|\le224,\ R\le512\)）でも \(C_{\mathrm{sat}}=C_{\mathrm{wit}}\)（新規出現0）。補題3により全実現シグネチャは掃引範囲に代表を持ち、C1により全てボックス内で実現される。ゆえに**全実現シグネチャでステップ恒等式が検証済み**であり、シグネチャ決定性（補題1）により任意の \((k,z,R)\) での恒等式が従う。帰納 (i)+(ii)+(iii) により主定理成立。∎

なお前報W7のシグネチャ圧縮検証（2,158種・飽和グリッド5種）は本証明の独立の先駆であり、本reportの cell 分解（3,803類・完全列挙）がその形式ギャップを閉じる。
