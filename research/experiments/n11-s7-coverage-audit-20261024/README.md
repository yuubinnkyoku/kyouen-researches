# 標準11×11：既存68個の9石WIN証明から7石証明の不足辺を順位付け

2026-10-24。元先手固定視点・完全指摘・通常プレイ。**空盤勝敗はUNKNOWN**。

目的は巨大な7石根を再探索することではなく、すでに独立終局証明された9石WIN根（29+27+2+10）の8石WIN親と、凍結済み8石WIN一覧を合成し、7石AND局面で**何本の合法8石子がまだ被覆されていないか**を正確に数えること。未被覆は「LOSS」ではなく、指定証拠集合に対するUNKNOWNである。

## 再現

リポジトリ直下で次を実行する。

```sh
python3 research/experiments/n11-s7-coverage-audit-20261024/test_geometry.py
python3 research/experiments/n11-s7-coverage-audit-20261024/verify_terminal_witnesses.py
python3 research/experiments/n11-s7-coverage-audit-20261024/analyze.py --output /tmp/n11-s7-gaps.json
```

`test_geometry.py` は別実装の整数円方程式を、既存の `terminal_geometry.py` の行列式・合法手・D4正準化と突き合わせる。主処理は8石WIN/LOSS衝突を拒否し、入力件数・正準性・最終集計値・最良候補の鍵を検査する。JSONは入力SHA-256と不足8石鍵を含み、選択的な次段階の証明計画に渡せる。

## 2026-10-24：終局証明だけを根拠とする被覆の切り分け

凍結済み8石WIN 13,501件を**一切勝敗の根拠に使わず**、独立終局検証済み9石WIN 68根の1石除去だけで得られる8石WIN **538件**について、具体的な9石証人を1件ずつ固定した。そこから1石除去で得られる7石→8石の相異なる合法辺は **4,304本**、7石親は **1,850件**。これは前節の「凍結集合に対する増分4,040本」と異なる指標で、残り264本も既存凍結8石WINと重複するが、今回は終局証明に基づく証人が付く。終局証明だけで全合法8石子が覆われる7石局面は0件。

凍結7石WIN/LOSS一覧のどちらにもない最有力7石局面 `00000000100000021081000020000020` は、合法8石子36件中、**10件すべてが上記9石終局証明を根拠にWINと保証される**。残り26件はこの証拠集合では未被覆（UNKNOWN）。したがってこの候補の10/36という被覆自体は凍結8石cacheの信頼性に依存しない。なお、未分類候補を選ぶために凍結7石一覧は参照するが、その勝敗を証明の前提にはしない。

`analyze.py` は `terminal_s8_witnesses`（正準8石鍵→証明済み9石鍵）と上位候補の `terminal_s8` をJSONに出力する。新設 `verify_terminal_witnesses.py` は別の4×4整数行列式による幾何実装で538証人の合法な包含関係、4,304辺、1,850親、最有力候補の10/36、改変証人の拒否を再検査する。**9石根の終局WIN自体は4組の既存証明書を前提とする**ため、必要ならそれぞれの再現手順で再検査すること。

この成果は「独立証明を根拠とする7石辺の出所追跡」であって、7石局面の新規WIN/LOSS確定でも二石rootの閉鎖でもない。**11×11空盤はUNKNOWN。**
