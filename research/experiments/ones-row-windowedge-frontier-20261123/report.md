## 主張（宣言から不変）

**M-RC（全称）**: j>=0・k>=0・z>=max(1, 2j−1)（R=z+2−2j>=1）に対して

A_j(k, z) := H(z+2−2j; {1}^k; z) は

- k 奇数（k>=1）: 2 ⟺ z 奇数 ∧ z <= k+2j−2 / 1 ⟺ z >= k+2j−1 / 0 その他
- k 偶数（k>=0 を含む）: 2 ⟺ z 奇数 ∧ z <= k+2j−3 / 0 その他

**M-DIAG（j=0）**: t>=1・z>=1 で
- t=1: 1 / t=2: 0
- t 偶数 >=4: 2（z 奇数 ∧ z<=t−3）/ 0
- t 奇数 >=3: 2（z 奇数 ∧ z<=t−2）/ 1（z>=t−1）/ 0

**M-SEP（分離法則）**: 統合窓端 R*=W(z,1)+1（z>=1: R*=z+2・z=0: R*=3）で
{1}^t 行が単一トークン帰結から分離するのはちょうど:

- t=1: なし / t=2: なし（K1265 整合）
- t 偶数 >=4: S(t) = {0} ∪ {z 奇数: 1<=z<=t−3}
- t 奇数 >=3: S(t) = {0} ∪ {z 奇数: 1<=z<=t−2} ∪ {t−1, t}

分離値: z=0 は親0 vs 単一1（T1・z 奇数帯は親2 vs 単一0（T2 の全 z 拡張）・
奇数 t の {t−1, t} は親1 vs 単一0・親1 vs 単一2。

## 証明（宣言ノート全文開示のもの・正本は宣言ノート）

強帰納（予算 R 減少）: 子は B手で A_{j+1}(k−1,z+1)（d=R−z が −2・d 偶数族の
中に閉じる・d 奇数の状態は窓端 d=2 から到達不能）、C手で同じく A_j(k,z−1)。
基底 R=0（値 0）と R=1（H(1;{1}^k;z>=1)=2・空残余 0・補題E 帰納）。場合分け
(1) k 奇・z 偶 → B子 2/0、C子 2/1 → {2,3}→0 か {0}→1。 (2) k 奇・z 奇 →
B子 0、C子 0/1 → {0,1}→2 か {0}→1・z=1/j=0/k=1 の境界も {0}→1。
(3) k 偶・z 奇 → B子 0/1、C子 0 → {0,1}→2 か {1}→0。 (4) k 偶・z 偶 →
B子 2/1、C子 2/0 → {2,3}→0 か {1}→0。すべて CFG 目標値と一致（閾値の
偶奇により中間の空の場合は消える）。単一側は K0832 出版閉形式:
1<=z<=t−1 で v(t,z,z+2)=0・z=t で 2・z>=t+1 で t%2。∎（詳細は宣言ノート）

## 意味（K1268 未解決課題の解決・他項目との関係）

- **K1268 課題「E5 {1}^t 行の疎パターンの一般則」: 解決**（全称・証明付き）。
  観測「t=3: {0..3}・t=5: {0,1,3,4,5}・t=7: {0,1,3,5,6,7}」は S(t) の
  t=3,5,7 の値そのもの。偶数 t の奇数階段 {0..t−3} と奇数 t の {t−1,t} ペア
  が一般則。
- **T1（K1267・z=0）と T2（並走仮採番 K1269・z=1）の一般化**: S(t) の
  z=0・z=1 要素。T2 の t 偶数側（z=1 ∈ 階段 1<=t−3）も M-SEP に含まれる。
- **K1265 整合**: t=2 の分離なし。t=1 も分離なし（{1}^1 = 単一トークンそのもの）。
- **min>=2 側（並走仮採番 K1270・z∈{0,1} banded）との関係**: {1}^t は
  min(X)=1 であるため banded window の外の「 assures されない」行で、
  それでも窓端から出発した階段構造が全 z で陽に決まることを示す。
- 標準 11×11 空盤・二石 root・S2・class 1/2/4 への影響: なし（本領域は
  残余ゲームの構造定理・11×11 はどの時点でも UNKNOWN のまま）。
