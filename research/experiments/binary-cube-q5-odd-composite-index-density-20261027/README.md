# 5点超平面切片：奇数合成数での周期短縮倍率の密度と独立性

2026-10-27。対象は二値超立方体の5点超平面切片数 `E_{d,5}`。K0567の4生成元周期定理と、先行する奇素数冪の密度定理を前提とする。**平面共円ゲームの勝敗ではない。**

## 新しい全称定理

素数 `p>32` に対して

$$
L_p=\operatorname{lcm}_{a\in\{2,3,5,7\}}\operatorname{ord}_p(a),
\qquad I_p=(p-1)/L_p
$$

とする。**任意の奇数 `n>=1`** について、`n\mid I_p` となる素数の自然密度は

$$
\boxed{\delta(n)=\frac1{\varphi(n)n^4}.}
$$

特に、互いに素な奇数 `m,n` について

$$
\delta(mn)=\delta(m)\delta(n).
$$

すなわち、異なる奇素数冪が `I_p` を割り切る条件は、**素数全体の自然密度に関して独立**である。例えば `15\mid I_p` の密度は `1/405000`、`21\mid I_p` の密度は `1/2333772`。奇素数冪だけでなく、複数の奇素数を同時に課す問題を解決する。

## 証明

`n=1` は自明なので `n>1` とする。`F=Q(ζ_n)`、
`K=F(2^(1/n),3^(1/n),5^(1/n),7^(1/n))` と置く。`K/Q` は4つの二項式の分解体で有限Galois拡大である。

**補題（奇数円分体内の有理正数の根の独立性）。**
奇素数 `ℓ`、`r>=1`、`μ_{ℓ^r}⊂F` で `F/Q` がアーベルGalois拡大とする。`a_i` が互いに異なる正の有理素数なら

$$
\prod_i a_i^{e_i}\in F^{\times\ell^r}
\quad\Longrightarrow\quad
\ell^r\mid e_i\quad(\forall i).
$$

**補題の証明。** `x^(ℓ^r)=A=∏a_i^{e_i}` とする。`x^(ℓ^{r-1})` は `A` の `ℓ` 乗根であり、`μ_ℓ⊂F` なので正の実根 `α=A^(1/ℓ)` も `F` に属する。ある `e_i` が `ℓ` の倍数でなければ、`X^ℓ-A` は有理数体上既約である（その素数での付値が `ℓ` と互いに素）。`Q(α)/Q` は実体だが他の根は非実なので非正規拡大となる。しかしアーベルGalois拡大 `F/Q` の全中間体はGalois拡大。矛盾。従って `e_i=ℓf_i`。

`B=∏a_i^{f_i}` とすると `x^(ℓ^{r-1})/B∈μ_ℓ`。`μ_{ℓ^r}⊂F` によりこの根号因子は `F` 内で `ℓ^{r-1}` 乗根を持つため、`B∈F^{×ℓ^{r-1}}`。帰納法で全ての `e_i` が `ℓ^r` の倍数になる。□

いま `n` は奇数であり、各 `ℓ^r||n` について `μ_{ℓ^r}⊂F`。`∏a_i^{e_i}∈F^{×n}` なら補題により `ℓ^r|e_i`。全ての `ℓ` について成り立つから `n|e_i`。よって `2,3,5,7` の類は `F^×/F^{×n}` で完全に独立し、Kummer理論より

$$
[K:F]=n^4,\qquad [K:\mathbb Q]=\varphi(n)n^4.
$$

有限個の分岐素数を除き、`p` が `K` で完全分解することは `p≡1 (mod n)` かつ `2,3,5,7` が全て法 `p` の `n` 乗剰余であることと同値。これは `n|I_p` と同値（有限体乗法群の巡回性）。Chebotarev密度定理により完全分解素数の自然密度は `1/[K:Q]`。これで公式が従う。互いに素な奇数についての独立性は `φ` と `n^4` の乗法性による。□

**重要な範囲：** `n` は奇数。偶数 `n` では円分体に平方根が含まれ得るため、上の次数計算をそのまま使わない。例えば既存の2冪密度公式は別形である。

## 独立した有限完全検査

`direct.cpp` は素数篩と `a^((p-1)/n) mod p` による直接合同判定。`independent.cpp` は最小素因子篩で `p-1` を因数分解し、4底の共通位数 `L_p` を割り下げて `I_p` を直接求める。後者は `n` 乗剰余の直接判定を使用しない。両方式とも浮動小数点を使わない。

`32<p<10^8` の全 **5,761,444素数**について一致：

| n | 該当素数数 | 最初の該当素数 | 定理による自然密度 |
|---:|---:|---:|---:|
| 3 | 35,089 | 5,113 | 1/162 |
| 5 | 2,251 | 67,651 | 1/2,500 |
| 7 | 364 | 865,957 | 1/14,406 |
| 9 | 120 | 960,643 | 1/39,366 |
| **15** | **14** | **7,992,421** | **1/405,000** |
| **21** | **3** | **27,251,659** | **1/2,333,772** |
| 35 | 0 | なし | 1/36,015,000 |
| 45 | 0 | なし | 1/98,415,000 |
| 63 | 0 | なし | 1/（φ(63)63⁴） |
| 105 | 0 | なし | 1/（φ(105)105⁴） |

既存の奇素数冪の全件数（3,5,7,9）も再現した。小さい範囲 `p<10^7` でも両方式が全10条件で一致し、`15|I_p` は1件（7,992,421）、`21|I_p` は0件。生の出力は `output.txt` に保存。

```sh
g++ -O3 -std=c++17 direct.cpp -o /tmp/q5_odd_direct
g++ -O3 -std=c++17 independent.cpp -o /tmp/q5_odd_independent
/tmp/q5_odd_direct 100000000
/tmp/q5_odd_independent 100000000
```

**根拠の区別：** 密度と独立性はKummer理論・Chebotarevを用いた全称数学的証明。素数数・最初の証人・0件という記録は指定区間の有限完全計算であって、無限範囲の不存在ではない。Lean形式検証や二値超立方体の独立幾何列挙は行っていない。
