# 全二点型の偶数重複：私有葉数が不均一でもGrundy数は奇数葉の個数だけで決まる（2026-10-28）

## 定理（数学的全称証明）

抽象的な二点残余禁止ゲーム（Node Kayles）を考える。クリーク `C={c_1,...,c_k}` を置き、各二点組 `{c_i,c_j}` に**正の偶数個** `r_ij∈{2,4,6,...}` の独立点を置いて、各点を `c_i,c_j` だけに接続する。さらに `c_i` に任意の `t_i≥0` 個の私有葉を付ける。独立側には辺を置かない。`r_ij` も `t_i` も頂点ごとに不均一でよい。

`b=|{i:t_i は奇数}|` とすると、通常プレイのGrundy数は厳密に

| 条件 | `g(G)` |
|---|---:|
| `k=0` | 0 |
| `k=1, t_1=0 または奇数` | 1 |
| `k=1, t_1>0 かつ偶数` | 2 |
| `k=2, b=0,1,2` | 順に 2,3,0 |
| `k≥3, b=0` | 1 |
| `k≥3, 0<b<k, b 偶数` | 2 |
| `k≥3, 0<b<k, b 奇数` | 3 |
| `k≥3, b=k` | `k mod 2` |

となる。特に、**`k≥3` では `r_ij` の値にも、私有葉が0か正の偶数かにも依存せず、`k` と奇数枚の葉を持つクリーク頂点数 `b` だけで決まる**。任意の頂点数について `g(G)≤3` で、`k=2,b=1` または `k≥3,0<b<k,b` 奇数で上界3を達成する。

先行結果 [`complete-pair-incidence-uniform-leaves-20261028`](../complete-pair-incidence-uniform-leaves-20261028/README.md) は二点型が**1個ずつ**で私有葉数が一様な場合。本結果は**正の偶数個ずつ**で、個数も私有葉数も不均一な別の全称族を解く。`r_ij=0` や奇数の二点型を混在させた一般の次数2分割グラフについての主張ではない。

## 三種類の初手と厳密再帰

各 `i` の葉数の偶奇を `ε_i=t_i mod 2` とする。`F_j^+(b')` は、この定理の対象族でクリークが `j` 点、すべての私有葉数が**正**、そのうち奇数が `b'` 点のときのGrundy数を表す。下記の帰納法により、これが個々の正の葉数・偶数の `r_ij` に依存しないことを同時に証明する。`F_0^+(0)=0`, `F_1^+(0)=2`, `F_1^+(1)=1`。

1. **クリーク頂点 `c_i` を選ぶ**：クリーク全体が消え、残る二点型独立点は偶数個の和なので、孤立点の偶奇は `b−ε_i (mod 2)`。子Grundy値はこの0または1。
2. **`c_i` の私有葉を選ぶ**（`t_i>0`）：`c_i` とその葉が消え、`t_i−1` 枚の葉が孤立する。残る各クリーク頂点 `c_j` には旧二点型 `r_ij` 枚が新たな私有葉として付く。`r_ij` は正の偶数なので、残る葉数は**正**かつ偶奇不変。子Grundy値は `F_{k−1}^+(b−ε_i) xor ((t_i−1) mod 2)`。
3. **`{c_i,c_j}` 型独立点を選ぶ**：`c_i,c_j` が消え、両者の私有葉と同型の残り `r_ij−1` 個が孤立する。各残存クリーク点 `c_l` には `r_il+r_jl` 枚の私有葉が加わり、正かつ偶奇不変。子Grundy値は `F_{k−2}^+(b−ε_i−ε_j) xor ((ε_i+ε_j+1) mod 2)`。

残る二点型の重複数は元の正の偶数のままであり、帰納法の対象族に留まる。以上は頂点ごとの実際の選択肢を漏れなく分類した厳密な再帰で、実験的な仮定を含まない。

## 全称証明

`k=0,1,2,3,4` は上の三種類の再帰から、私有葉数を `0 / 正の奇数 / 正の偶数` に分類して直接計算できる。`k=2,3,4` の `b=0,...,k` に対応する値はそれぞれ

- `k=2`: `[2,3,0]`
- `k=3`: `[1,3,2,1]`
- `k=4`: `[1,3,2,3,0]`

であり、0と正の偶数の区別によって値は変わらない。`k=1` は、葉なしの一点が1、正の奇数枚なら1、正の偶数枚なら2である。

`k≥5` とし、より小さいクリークについて定理が成立すると仮定する。三種類の子Grundy値へ帰納仮定を代入すると、**子値の集合**は次の表になる。`0<b<k` では奇数葉の頂点と偶数葉の頂点がともに存在するため、クリーク初手だけで0と1が現れる。

| 条件 | 全初手後の子Grundy値集合 | mex |
|---|---|---:|
| `b=0` | `{0}` | 1 |
| `0<b<k, b 奇数` | `{0,1,2}` | 3 |
| `0<b<k, b 偶数` | `{0,1,3}` | 2 |
| `b=k, k 奇数` | `{0}` | 1 |
| `b=k, k 偶数` | `{1}` | 0 |

第三の値が必ず現れることも確認できる。`b` が正の偶数なら、奇数葉を持つ頂点の葉を選んだ子が `F_{k−1}^+(b−1)=3`。`b` が3以上の奇数なら、同じ操作で `F_{k−1}^+(b−1)=2`。`b=1` では偶数葉の頂点が少なくとも `k−1≥4` 個あるので、その2頂点間の二点型を選べば `F_{k−2}^+(1) xor 1=3 xor 1=2`。ほかの選択肢も上記再帰と帰納仮定に代入すれば表の集合を超えない。`b=0` と `b=k` ではすべての子値が表の一値に一致する。

よって各行のmexが定理の式に一致し、数学的帰納法で**全 `k`、全 `t_i≥0`、全正の偶数 `r_ij`** に成立する。
