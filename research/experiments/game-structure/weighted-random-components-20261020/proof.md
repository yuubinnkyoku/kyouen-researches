# 無作為合法着手の終局分布は独立な残局成分ごとに厳密に分解する

2026-10-20。**全称定理（数学的証明）**。以下は有限な単調禁止集合ゲーム（標準共円ゲームの任意の安全残局を含む）についての主張であり、11×11の実際の残局に非自明な成分分解が現れるという主張ではない。

## 設定

残余候補点の有限集合を `V`、空でない禁止部分集合の族を `F` とする。選択済み集合 `S` が合法とは、どの `F∈F` も `F⊆S` を満たさないこと。各未選択かつ現在合法な点 `v∈V_i` を、正の重み `c_i(S)w_v` に比例する確率で選ぶ。ここで `w_v>0` は固定し、`c_i(S)>0` は現在の全体局面 `S` に任意に依存してよい。ただし同じ成分内では共通の倍率とする。合法手がなくなったら終局する。

`V=V_1 ⊔ ... ⊔ V_k` と分割でき、**すべての禁止集合がいずれか一つの `V_i` に完全に含まれる**とする。`A_i` を成分 `i` で最終的に選ばれる集合、`A` を全体の最終集合とする。

## 定理

1. `A_1,...,A_k` は確率変数として独立であり、各 `A_i` の分布は成分 `i` のみで固定重み `w_v` による無作為合法着手を行った場合の分布に等しい。成分ごとの倍率 `c_i(S)` は、各成分の終局分布を変えない。
2. 従って、終局石数の確率母関数 `P(z)=E[z^|A|]` は `P(z)=∏_i P_i(z)` と因数分解する。特に期待手数は加法的、異なる成分の終局手数の共分散は0。
3. `B_i=P_i(-1)=Pr(|A_i| even)-Pr(|A_i| odd)` とおけば、全体の終局手数が奇数となる確率は `(1-∏_i B_i)/2`。通常プレイでこの残局から先に打つ人が無作為着手で勝つ確率も同じ。

重みをすべて1にすれば、合法手の一様無作為選択を含む。二点禁止残局では、禁止辺を持つ競合グラフの連結成分がそのまま分解単位になる。一般の共円残局では、選択済みの石を条件に残余の禁止集合を縮約し、サイズ1の禁止集合による即時違法点を除いた後、残った禁止超辺が成分をまたがないことを確認する必要がある。

## 証明（全称）

まず各成分 `i` に、他成分と独立な乱数列をあらかじめ割り当てる。成分 `i` が呼ばれるたびに、その成分内の現在合法な点から固定重み `w_v` に比例して一つ選ぶ。この乱数列と成分内の採用履歴だけで、成分 `i` の最終採用集合 `A_i` が決まる。

一方、全体局面 `S` で成分 `i` が次に呼ばれる確率を

`c_i(S) Σ_{v∈V_i:合法}w_v / Σ_j c_j(S) Σ_{u∈V_j:合法}w_u`

とし、呼ばれた成分内で `w_v` 比例選択をすれば、全体での点 `v∈V_i` の選択確率は正確に `c_i(S)w_v / Σ_{u:合法}c_{component(u)}(S)w_u` となる。つまり元の逐次無作為着手と同じ分布である。

成分の呼び出し順序が他成分の状態に依存しても、**各成分の内部での選択列は変わらない**。有限個の点しかないため、全体の終局時には全成分がそれぞれ終局している。従って `A_i` は独立に用意した各成分の乱数列だけの関数であり、相互に独立。第1項が従う。

`|A|=Σ_i |A_i|` と独立性から `E[z^|A|]=∏_i E[z^|A_i|]`。期待値の線形性から期待手数の加法性が従う。最後に `(-1)^|A|=∏_i (-1)^|A_i|` の期待値を取ると偶奇差は `∏_i B_i` なので第3項も従う。□

**補助的な見方：** `c_i(S)=1` の場合、各点に独立な指数時計 `Exp(w_v)` を置いて到着順に貪欲採用する構成でも同じ分布を得る。時計は成分ごとに独立であり、上の分解を別の角度から説明できる。

## 厳密な例

二つの独立な3頂点道 `P3 ⊔ P3` を考える。各道の中央点の重みをそれぞれ3と4、端点の重みをそれぞれ `(1,2)` と `(1,5)` にする。

一つの道は中央点が最初に選ばれたときだけ1手で終局し、それ以外は両端が選ばれて2手で終局する。したがって各道の確率母関数は

```
P_1(z) = (1/2)z + (1/2)z^2
P_2(z) = (2/5)z + (3/5)z^2
P(z) = (1/5)z^2 + (1/2)z^3 + (3/10)z^4.
```

期待終局手数は `31/10`、先に打つ人の無作為着手勝率は `1/2`。これは「極大配置を均等に抽選する」モデルとは異なる。

## 独立検算と限界

`verify.py` は、2〜7頂点・2成分・正の整数重み・成分内の任意の禁止超辺（サイズ2以上）を持つ330例について、以下の三方式を有理数で照合した。

- 全点集合上の合法手確率再帰（固定重み、および全体局面依存の成分倍率）。
- 成分ごとの確率再帰の直積。
- 全順列の重み付き到着順序確率 `∏_j w_{π_j}/Σ_{h≥j}w_{π_h}` と、各順列での貪欲採否判定。

すべての**終局集合ごとの確率**が完全一致し、局面依存倍率の場合にも成分直積と一致した。偶奇差の積公式も一致した。6頂点の例では上の厳密分布と期待値を照合した。これは実装検証であって、全称性の根拠は前節の数学的証明である。

11×11への接続：既存の残局集合で、残余禁止超グラフの連結成分分解を検出できれば、無作為着手の終局分布を成分ごとの計算と多項式の積へ縮約できる。実残局での分解頻度・計算時間改善は未測定。成分内での点どうしの重み比まで局面依存で変える場合には、この定理は無条件には適用できない。
