# 局所適応着手と大域的な手番配分の分離定理

2026-10-20。対象: 有限の下方閉配置ゲーム（共円ゲームの残局を含む）。

## 結論（全称数学的証明）

残余点が互いに交わらない $V_1,\ldots,V_k$ に分かれ、禁止集合が複数の $V_i$ にまたがらないとする。各成分 $i$ に、**その成分の過去の着手順序だけ**に依存する確率的着手規則 $\pi_i(v\mid h_i)$ を固定する。各規則は現在の合法点上の確率分布である。成分をどの順で着手させるかは、**全成分の既観測の着手履歴に依存する任意の大域的な確率的配分規則**でよい。ただし未終了成分だけを選び、局所の次の乱数を事前に見ず、局所の着手分布を変更しない。

各成分を単独で最後まで実行した際の終局配置を $T_i$、その石数確率母関数を $P_i(z)$ とすると、全ゲームを終了まで進めた際の $T_1,\ldots,T_k$ は**独立**で、

$$
 \Pr(T_1=t_1,\ldots,T_k=t_k)=\prod_i\Pr(T_i=t_i),\qquad
 P(z)=\prod_i P_i(z).
$$

特に大域配分が非一様・履歴依存・無作為であっても成立する。成分の選択確率を各点の固定重みの総和から計算する必要はない。成分内部の確率も、**固定点重みには限らず**、着手順序を含む局所履歴に任意に依存してよい。

### 証明

各成分ごとに、他成分とは独立な無限乱数列を前もって用意する。成分 $i$ が呼ばれたときは、その成分専用の乱数列の未使用部分を用い、現在の局所履歴 $h_i$ に従って $\pi_i(\cdot\mid h_i)$ から次の合法点を選ぶ。大域配分がどの成分を選んでも、成分 $i$ の **局所着手列そのもの** は、同じ乱数列で成分 $i$ を単独実行した着手列と一致する。局所の着手可否は他成分の石に影響されず、どの成分も有限回で終わるからである。全成分の局所着手列は独立乱数列の関数なので独立。終局配置もその関数であり、母関数は積となる。□

証明に勝敗の最適性やGrundyの排他的論理和は不要。各局所規則は履歴依存でもよいが、**大域履歴によって同じ成分の次の点の相対確率を変えてはならない**。

## r人巡回版の確率的敗者分布（K0339とは異なる量）

最初に合法手を失うプレイヤーを敗者とする $r\ge2$ 人巡回対戦で、現在プレイヤーを $a$、追加手数を $L$ とすると、敗者は $(a+L)\bmod r$。したがって、$P(z)$ を $z^r-1$ で割った余りの係数が、各敗者の**確率**になる。成分の $P_i(z)$ も最初から $z^r-1$ を法として計算し、巡回畳み込みすればよい。K0339は全対局で敗者が固定される必要十分条件を与えるが、こちらは固定されない場合も確率分布を厳密計算する。

局所規則が占有集合のみに依存するなら、各成分の母関数は安全な部分集合 $S$ 上の後ろ向き再帰で計算できる。一般の順序依存規則では局所着手履歴を状態とする必要がある。**大域の直積状態を探索する必要はない。**

## 小例（厳密な有理数）

各成分を3頂点パスとし、端の二点は両立し、中央点は両端と両立しない。成分Aの初手は中央を確率 $1/2$、各端を $1/4$ で選ぶ。成分Bの初手は3点一様で選ぶ。中央なら1石で終了、端なら他端も選んで2石で終了するので

$$
P_A(z)=\tfrac12 z+\tfrac12 z^2,\quad
P_B(z)=\tfrac13 z+\tfrac23 z^2,\quad
P(z)=\tfrac16 z^2+\tfrac12 z^3+\tfrac13 z^4.
$$

3人巡回でプレイヤー0から始めたとき、敗者0,1,2の確率はそれぞれ $1/2,1/3,1/6$。成分の手番を、すでに置かれた石数に応じて履歴依存で偏らせても同じ結果になる。

## 条件の鋭さ：成分内の選択を他成分に依存させると失敗

同じ3頂点パスを2成分A,Bとし、まずBを完了させる。Bは確率 $1/2$ で中央、確率 $1/2$ で端から始める。Aでは、**Bが中央で終わった場合は中央**、**Bが両端で終わった場合は端**を選ぶ。両成分の終局サイズの周辺分布はともに $1/2$ ずつであるが、合計サイズ分布は

$$
P_{\mathrm{actual}}(z)=\tfrac12 z^2+\tfrac12 z^4,
$$

一方、誤って独立と仮定すると $\tfrac14 z^2+\tfrac12 z^3+\tfrac14 z^4$ となる。したがって**成分を選ぶ順番の大域依存は許されるが、成分内部の選択確率の大域依存は一般には許されない**。

## 応用と未解決

残局の禁止超グラフが分解できた場合、無作為着手だけでなく局所適応的な着手規則に対しても、終局配置分布・期待終局長・分散・r人敗者分布を各成分ごとに求められる。実際の11×11残局における成分分解の頻度と、局所状態数削減の実測は未検証。相手の最適応手が他成分の履歴に依存する**戦略的多人ゲーム**の勝敗独立性は主張しない。
