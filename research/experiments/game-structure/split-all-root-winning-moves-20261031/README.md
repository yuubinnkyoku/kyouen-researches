# 任意の分割グラフの全勝ち初手を偶奇・二点被覆だけで決定（2026-10-31）

## 定理（数学的全称証明）

通常プレイの Node Kayles を有限単純分割グラフ `G=(C∪I,E)` で考える。`C` は完全グラフ（`k=|C|≥0`）、`I` は独立集合（`m=|I|≥0`）。各中心 `c∈C` の独立側次数を `d(c)=|N(c)∩I|`、各独立点 `x∈I` の中心近傍を `S_x=N(x)∩C` とする。**初期局面のGrundy数に関する仮定は置かない**。

**中心 `c` が勝ち初手である必要十分条件**は `d(c) ≡ m (mod 2)`。

**独立点 `x` が勝ち初手である必要十分条件**は、`T_x=C\S_x` として、次の通り。

- **`m` が奇数**：`T_x` の全中心の `d(c)` が奇数。空集合 `T_x=∅` も許す。つまり、**`x` は偶数次数の中心をすべて覆う**。
- **`m` が偶数**：`T_x` が非空、`T_x` の全中心の `d(c)` が偶数、かつ **`x` と異なるどの独立点 `y` も `S_x∪S_y=C` を満たさない**。つまり、`x` は奇数次数の中心をすべて覆い、残る中心は非空で、ほかの一点との二点被覆がない。

中心数・独立点数・各近傍の大きさ・同一近傍の重複に上限はない。ビット集合で近傍を表せば、`O(km + m²⌈k/W⌉)` 程度の時間（`W` は機械語のビット幅）で**全勝ち初手をGrundy再帰なしで判定できる**。

## 証明

中心 `c` を選ぶと全中心が消え、残るのは `m-d(c)` 個の孤立点だけ。よって子局面のGrundy数は `(m-d(c)) mod 2`。これが0となる条件が中心の式。

独立点 `x` を選ぶと `x` と `S_x` の中心が消え、`T_x` の中心と `I\{x}` の独立点からなる分割グラフが残る。残った各中心 `c∈T_x` は元々 `x` と非隣接なので、その独立側次数は **元の `d(c)` と等しい**。独立点数は `m-1`。

`T_x=∅` なら子は `m-1` 個の孤立点であり、子のGrundy数が0である条件は `m` が奇数。

`T_x≠∅` なら、既存の[初期Grundy数0/1の必要十分条件](../split-root-parity-iff-20261030/README.md)をこの子局面に適用する。子のGrundy数が0であるためには、全残存中心次数が同じ偶奇 `d` を持ち、`d=1` または残存中心に全隣接する独立点が存在せず、さらに `1 xor ((m-1) mod 2) xor d=0` が必要十分である。最後の等式は `d=m mod 2` と同値。

`m` が奇数なら `d=1` なので全域点の追加条件は不要。`m` が偶数なら `d=0` なので、`I\{x}` の中に `T_x` 全体へ隣接する点 `y` が存在しないことが必要十分。これは `S_x∪S_y≠C` と同値。`T_x=∅` の場合を合わせれば定理を得る。有限列挙による外挿ではなく、既存の数学的全称定理からの論理的帰結である。

## 系：中心の全初手が負けの場合

`k≥1` とする。中心の全初手が負けとなるのは、全 `d(c)` が `m` と逆の偶奇のとき。

- `m` が偶数なら全中心次数が奇数であり、勝ち初手は**存在しない**。根はP局面。
- `m` が奇数なら全中心次数が偶数であり、勝ち初手になれる独立点は **全中心に隣接する点に限る**。そのような点があれば、ちょうどそれらが勝ち初手。なければ根はP局面。

つまり、**勝ち初手が一つも中心にないのに先手勝ち**となる唯一の仕組みは「`m` が奇数・全中心次数が偶数・全域独立点あり」である（`k≥1`）。

## 具体例

- `k=3, S_x=(7,7,0)`（中心の3ビット近傍、`m=3`）。中心次数はすべて2で、中心3手は全て負け初手。全域点である独立点2個だけが勝ち初手。名前付き頂点の直接mex再帰で `g(G)=3`。
- `k=2, S_x=(3,3)`（`m=2`）。中心次数は両方2で、中心2手だけが勝ち初手。二つの独立点はいずれも残余中心が空となり、勝ち初手ではない。直接mex再帰で `g(G)=2`。
- `k=3, S_x=(3,5,6,0)`（`m=4`）。根 `g(G)=1` で勝ち初手は中心3個と孤立独立点1個。この例は既存の `g=1` 特化定理と一致する。

## 独立検証

[verify.py](verify.py) は**個々の名前付き頂点に閉近傍削除を行う独立のmex再帰**と、上記の偶奇・被覆判定を比較する。`k=0..5` の明示範囲を完全列挙し、さらに `k=1..9,m=0..14` の固定乱数5,000構成を照合する。

実行：`python3 research/experiments/game-structure/split-all-root-winning-moves-20261031/verify.py`

実行結果：**114,847構成、根のGrundy数0の構成6,361、最大観測Grundy数3、全勝ち初手の集合に不一致0件**。有限検査は実装監査であり、全称性の根拠は上の数学的証明。

本結果は既存の `g(G)=1` の場合の全勝ち初手分類を、**初期Grundy数を仮定しない全分割グラフ**へ拡張する。抽象グラフに関する結果であり、整数格子上の共円ゲーム残局としての実現可能性、11×11への適用可能性は未確認。knowledge正本への昇格、生成索引再構築、全体CIは未実施。
