# 分割グラフの通常・misère Grundy交換則と全勝ち初手（2026-10-31）

## 数学的全称定理

有限単純グラフ上の通常プレイ Node Kayles（着手頂点の閉近傍削除）で、通常Grundy数を `g`（終端0）、misère補助mex値を `h`（終端1、非終端は子のmex）とする。`τ(0)=1, τ(1)=0, τ(j)=j (j≥2)` と定める。

**定理A（一般の交換補題）**：合法後続に閉じた有限impartialゲーム族で、任意の非終端 `g=0` 局面に `g=1` の子が存在するなら、族の全局面で `h=τ(g)` が成立する。特に、**任意の有限分割グラフとその全到達局面**でこの交換則が成り立つ。

従って分割グラフのmisère後手必勝条件は、通常Grundy数が**ちょうど1**であること。通常 `g=0` はmisèreでは先手必勝、`g≥2` も先手必勝。補助mex値 `h` に通常Grundy数の直和xor則を適用してはならない。

**定理B（misèreの全勝ち初手）**：分割グラフ `G=(C∪I,E)` で `C` は完全グラフ、`I` は独立集合、`k=|C|≥0, m=|I|≥0` とする。中心 `c` の独立側次数を `d(c)`、独立点 `x` の中心近傍を `S_x`、`T_x=C\S_x` とする。misèreでの勝ち初手は次の必要十分条件で決まる。

- 中心 `c`：`d(c) ≢ m (mod 2)`。
- 独立点 `x`、`m` 偶数：`T_x` の全中心の `d(c)` が奇数（`T_x=∅` も許す）。すなわち `x` が偶数次数の中心をすべて覆う。
- 独立点 `x`、`m` 奇数：`T_x≠∅`、`T_x` の全中心の `d(c)` が偶数、かつ `x` 以外のどの `y∈I` も `S_x∪S_y=C` を満たさない。

`k=0`（孤立点だけ）、`m=0`（完全グラフだけ）も含む。次数偶奇と二点被覆だけで全勝ち初手を判定でき、Grundy再帰は不要。

**系（misère後手必勝局面の閉条件）**：`k=0` なら `m` が奇数のときに限りP局面。`k≥1` なら、全中心の `d(c)≡m (mod 2)` が成立し、さらに「`m` が奇数、または全中心に隣接する独立点が存在しない」ときに限りP局面。これは通常 `g=1` の既存必要十分条件から直ちに従う。

**強解決**：合法手を進めた後も残余グラフは分割グラフなので、残余の中心集合・独立集合を更新して同じ条件を繰り返せる。よって任意の分割グラフについてmisèreの全到達局面の勝敗と全勝ち手を多項式時間で決定できる。例えば中心次数の計算と二点被覆の全照合を素朴に行っても `O(km+m²k)` 時間で済む。

## 証明

**交換補題**。終端では `g=0,h=1`。子で交換則が成立すると仮定する。非終端 `g=0` では全子の通常値が非零なので交換後の子の `h` に1は現れず、仮定により通常値1の子があるので `h=0` は現れる。よって `h=1`。`g=1` では子の通常値0があり1はなく、交換後は `h=1` があり0はないので `h=0`。`g≥2` では子の通常値に0,1,...,g−1がすべてありgはない。0と1の交換はこの集合を保つので、子のmisère値のmexもg。ゲーム木高さの帰納法で従う。

**分割グラフへの適用**。Node Kaylesの後続は誘導部分グラフなので分割性を保つ。非空分割グラフに中心があれば、その中心を選んだ子は孤立点だけで通常値は0か1。元が `g=0` なら子の値0はあり得ず、必ず1。中心がなければ元は孤立点集合であり、`g=0` の非終端は正の偶数個の孤立点からなる。どの子も奇数個の孤立点で通常値1。交換補題を適用できる。

**勝ち初手**。misèreで子がPとなるのは `h(child)=0`、すなわち `g(child)=1` のとき。中心を選ぶと `m-d(c)` 個の孤立点が残るので、奇数なら勝ち手。独立点 `x` を選ぶと中心 `T_x` と `m−1` 個の独立点が残り、`c∈T_x` の次数は元の `d(c)` と同じ。`T_x=∅` なら子の通常値は `(m−1) mod 2`。`T_x≠∅` なら既存の[分割グラフ根Grundy 0/1の必要十分条件](../split-root-parity-iff-20261030/README.md)を適用する。子の値1の条件は、全残存中心の次数偶奇が同じ `e`、`e=1` または残存独立点に全域点なし、さらに `1 xor ((m−1) mod 2) xor e=1`。従って `e=(m−1) mod 2`。`m` 偶数なら `e=1` で追加条件なし、`m` 奇数なら `e=0` で全域点不在が必要。全域点の存在は `S_x∪S_y=C` となる別の独立点 `y` の存在と同値。これで定理Bを得る。

## 境界・具体例

`k=3, S_x=(7,7,0)` では `g=h=3`。通常の勝ち初手は全中心に隣接する独立点2個だけだが、**misèreの勝ち初手は中心3個だけ**。

`k=7, S_x=(3,3,5,5,9,9,33,48,80)` では `g=h=5`、`k=7, S_x=(3,3,4,4,5,9,9,16,33,33,64,64,68,80,84)` では `g=h=8`。交換則は小さいGrundy値だけの偶然ではない。

任意グラフへの拡張は誤り。二つの3頂点星の直和 `P3 ⊔ P3` は `g=h=0` で交換則に反する。本結果は抽象グラフ上の定理であり、整数格子上の共円ゲーム残局が常に分割グラフになるとは主張しない。
