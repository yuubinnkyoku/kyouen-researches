# 二点型が高々5組欠ける分割グラフ：k≥7の統一Grundy公式（2026-10-28）

## 結論（無限族の計算機援用全称証明）

通常プレイの二点禁止ゲーム（Node Kayles）を、クリーク `C={c_0,...,c_{k-1}}` と独立集合からなる分割グラフで考える。独立側の各頂点はクリークのちょうど1点（私有葉）または2点（二点型）に隣接する。私有葉数 `t_i≥0`、二点型の重複数 `r_ij≥0` は任意で、**二点型が欠ける組 `r_ij=0` は高々5組**とする。

```text
u   = (sum_i t_i + sum_{i<j} r_ij) mod 2
z_i = (t_i + sum_{j!=i} r_ij) mod 2
```

**任意の `k≥7` で**
```text
g(G) = 1 xor u xor z_0   (すべての z_i が等しい場合)
g(G) = 2 + u             (z_i が混在する場合)
```
が成立する。特に `g(G)≤3`。孤立点が `f` 個別に存在する場合は `f mod 2` を xor する。

既存の[欠損4組・k≥6の定理](../four-missing-pairs-k6-plus-induction-20261028/README.md)の真の拡張である。**`k=6` には欠損5本星の反例がある**ので、`k≥7` はこの欠損数に対して鋭い。

## 新しい有限補題と反例

### 補題A：k=6、欠損5組

欠損5組の単純グラフは6頂点上で15同型型（ラベル付き `C(15,5)=3003`）。各型で存在する10二点型の個数を1/2、6つの私有葉数を0/1/2に縮約する。各型 `2^10·3^6=746496` 構成、**全15型で11,197,440構成**を、予想公式を子に代入しない厳密なmex再帰で完全列挙した。

結果は以下のとおり。

- 欠損5本星 `{01,02,03,04,05}` 以外の14型では、**全重複数・全私有葉数で公式が成立**。
- 欠損5本星でも、**星の中心に私有葉が1個以上あれば公式が成立**。この条件下の正規化代表 `2^10·2·3^5=497664` 件に不一致なし。
- 中心葉が0の5本星では、正規化代表 `2^10·3^5=248832` 件中 **241,024件が公式に不一致**。これ以外には不一致なし。
- 各同型型の実際の値の分布は `g=0,1,2,3` の順に `(11680,11680,361568,361568)`。したがって `k=6`・欠損5組の**全構成で `g≤3`**。

明示的な17頂点の反例：クリーク `K_6`、欠損組 `{01,02,03,04,05}`、残る10組に独立点各1個、私有葉は `c_1` に1個のみ。このとき `u=1`、`z=(0,1,0,0,0,0)` なので公式は `3` を予測するが、**実際は `g=2`**。名前付き全17頂点の閉近傍を削除する独立再帰でも確認した。`c_0` にさらに私有葉1個を加えると公式は再び成立する。

### 補題B：k=5、欠損5組、全頂点に私有葉あり

5頂点上の欠損5組は6同型型（ラベル付き `C(10,5)=252`）。残る5二点型の個数を1/2、5私有葉数を1/2として、**`6·2^5·2^5=6144` 代表を独立したPythonのmex再帰で完全列挙**した。公式との不一致は0。

よって **`k=5`、欠損がちょうど5組でも、すべてのクリーク頂点に私有葉が1個以上あれば公式が成立**。欠損4組以下は既存の[k=5完全分類](../four-missing-pairs-k5-classification-20261028/README.md)を用いる。欠損4本星の場合も中心に私有葉があれば公式が成立することは[既存の補題](../four-missing-pairs-k6-plus-induction-20261028/README.md)で確認済み。

どちらの有限補題も、既存の[偶奇・存在による縮約補題](../two-missing-pairs-arbitrary-multiplicities-20261028/README.md)により、正規化代表だけで任意の非負整数重複数を覆う。

## k≥7の数学的帰納法

独立点を選んだ後に消えるクリーク点集合を `B`（大きさ1または2）とする。生存クリーク頂点 `i∉B` では、消えたクリーク点に隣接していた二点型が私有葉へ変わるため、`z'_i=z_i` が保たれる。親の独立点総数の偶奇を `u`、子の残存クリークに接続する独立点数の偶奇を `u'`、新たな孤立点数の偶奇を `δ` とすれば、選択した独立点1個を除いて `δ=u xor u' xor 1`。

子の残存クリークについて公式を適用できるなら、独立点初手の子値は次のいずれかになる。

- 残存 `z` が一様 `s`：`u xor s`。
- 残存 `z` が混在：`u xor 3`。

クリーク点 `i` を初手に選んだ子値は常に `u xor z_i`。

**k=7での子局面の例外回避。** 独立点初手で残るクリークは6点または5点。

- 6点残るとき：欠損5本星が残れば、その中心 `c` と消した1点 `x` の二点型は必ず存在する（欠損5組は全て残存6点内）。その点は新しい私有葉になるので `t'_c>0`。補題Aを適用できる。5本星以外は補題Aまたは既存の欠損4組以下の定理を適用。
- 5点残り、内部欠損がちょうど5組：元の欠損5組を使い切っているため、消した2点と残存5点の間の二点型はすべて存在する。残存5点の**各点に少なくとも2個の新しい私有葉**が生じ、補題Bを適用できる。
- 5点残り、内部欠損が4組：唯一の例外候補は欠損4本星。残存中心 `c` から消した2点 `x,y` への二点型が両方欠けるなら欠損は合計6組となり矛盾。少なくとも一方が新しい私有葉を作るため既存の中心葉正の補題を適用できる。その他の欠損形および3組以下は既存のk=5定理が適用できる。

**k=8での子局面の例外回避。** 1点消去後はk=7の結論を適用する。2点消去後はk=6。欠損5本星が残る場合、その中心と消した2点の間の二点型はいずれも存在し、中心に私有葉が生じる。補題Aを適用できる。

**k≥9** では1点・2点消去後ともクリークが7点以上なので帰納仮定を直接適用できる。

最後にmexを計算する。`z_i` が一様なら全ての初手の子値は `u xor z_0` で、mexは `1 xor u xor z_0`。混在するならクリーク初手から子値0と1が出る。`k≥7` では同じ `z` 値の頂点が少なくとも4点あり、その内部の6二点組のうち欠損は高々5組。**少なくとも1組の二点型が存在**し、それを選んでも同値2点と異値1点が残るため、子値 `u xor 3` が出る。他の子値は0、1、`u xor 3` に限られ、mexは `2+u`。帰納法が閉じる。
