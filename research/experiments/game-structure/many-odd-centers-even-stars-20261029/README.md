# 任意個の奇数中心・互いに交わらない偶数星のGrundy数（2026-10-29）

## 新しい全称定理

通常プレイの Node Kayles を、クリークと独立集合からなる分割グラフで考える。独立点はクリークの1点または2点にだけ隣接する。本結果は[単一中心](../odd-center-even-star-sharp-transition-20261028/README.md)・[二中心](../two-odd-centers-even-stars-20261028/README.md)を**任意の中心数**へ拡張する。

整数 $h\ge1$, $m\ge0$, $p_1,\ldots,p_h\ge0$ を取る。クリークは次の頂点からなる。

- 中心 $c_1,\ldots,c_h$。各中心の私有葉は任意の**正の奇数**枚。
- 中心 $c_i$ に属する $p_i$ 個の枝先。枝先自身の私有葉は0枚で、各枝先と $c_i$ に共通に隣接する二点型独立点は任意の**正の偶数**個。
- $m$ 個の補助クリーク頂点。それぞれ任意の**正の偶数**枚の私有葉を持つ。

ほかの二点型はなく、全クリーク頂点は互いに隣接する。中心同士や異なる星の間には二点型を置かない。$r=|\{i:p_i\ge3\}|$（枝が3本以上の「重い」中心数）、$P=\sum_i p_i+m$ とする。

**定理（全称証明）：** 個々の奇数・偶数重複数が不均一でも、Grundy数は

$$
\boxed{
g(G)=
\begin{cases}
h\bmod2,&P=0,\\
3,&P>0,\ h\text{ が奇数},\ r\le(h-1)/2,\\
2,&P>0,\ h\text{ が奇数},\ r\ge(h+1)/2,\\
2,&P>0,\ h\text{ が偶数},\ r<h/2,\\
4,&P>0,\ h\text{ が偶数},\ r=h/2,\\
3,&P>0,\ h\text{ が偶数},\ r>h/2.
\end{cases}}
$$

特に**この無限族では中心を何個増やしても $g\le4$ であり、$g=5$ は実現しない**。偶数個の中心のちょうど半数が重いときだけ $g=4$ になる（$P>0$）。$h=3$ では重い中心が0〜1個なら3、2〜3個なら2（$P=0$ の例外は1）。$h=4$ では重い中心が0〜1個なら2、2個なら4、3〜4個なら3（$P=0$ の例外は0）。

## 全初手の厳密な再帰

$G_h(\mathbf p,m)$ を上記グラフの値とする。独立した孤立点1個の寄与はxor 1。中心の奇数葉、枝の正の偶数重複、補助頂点の正の偶数葉という条件から、全初手の子の値は次の通り。

| 初手 | 子の値 |
|---|---|
| 中心クリーク頂点 | $(h-1)\bmod2$ |
| 枝先または補助クリーク頂点（存在する場合） | $h\bmod2$ |
| 中心 $i$ の私有葉 | $G_{h-1}(\mathbf p\setminus p_i,m+p_i)$ |
| 中心 $i$ の二点型枝（$p_i>0$） | $G_{h-1}(\mathbf p\setminus p_i,m+p_i-1)$ |
| 補助頂点の私有葉（$m>0$） | $1\oplus G_h(\mathbf p,m-1)$ |

ここで「二点型枝」は、中心と枝先の両方に隣接する独立点を選ぶ手を指す。中心の私有葉を選ぶと中心が消え、元の枝先には正の偶数枚の私有葉が残る。二点型独立点を選ぶと中心と枝先が消え、中心の奇数葉と選んだ型の残り奇数枚が**合計偶数個**の孤立点になる。補助頂点の私有葉を選ぶと、その型の残りが奇数個の孤立点になる。従って上表は重複数の具体値に依存しない。

$P=0$ の場合は、奇数葉付きクリークのみであり、$G_h=h\bmod2$。実際、中心を選んだ子は $(h-1)\bmod2$、中心葉を選んだ子は $G_{h-1}$ で、$G_0=0$ から帰納的に従う。

## 全称証明

$h=1$ と $h=2$ は既存の[一中心](../odd-center-even-star-sharp-transition-20261028/README.md)・[二中心](../two-odd-centers-even-stars-20261028/README.md)の全初手分類による定理と一致する。$h\ge3$ は中心数に関する帰納法と、固定した中心数での $m$ に関する帰納法を用いる。

$P>0$ の場合、中心を選んだ子は常に $(h-1)\bmod2$。枝先・補助頂点が存在するので $h\bmod2$ も現れる。中心葉・二点型を選ぶ子は中心数 $h-1$、重い中心数 $r$ または $r-1$（削除した中心が重い場合）となる。これらの子で $P'=0$ になる例外は、$P=0$ の既知の値 $(h-1)\bmod2$ を取るだけで、中心を選ぶ子と重複する。したがって以下では $P'>0$ の子を考えれば十分である。

**$h=2a+1$（奇数、$a\ge1$）の場合：** 中心を選ぶ子から0、枝先・補助頂点から1が現れる。$h-1=2a$ の帰納法の仮定によれば、中心葉・二点型の非例外子は、残る重い中心数 $r'$ が $a$ 未満なら2、$a$ なら4、$a$ 超なら3。

- $r<a$：非例外子に2が現れ、3は現れない。子の値は0,1,2（および例外の0）で、mexは3。
- $r=a$：重い中心を消すと2、軽い中心を消すと4が現れる。3は現れず、mexは3。
- $r\ge a+1$：どの非例外子も3または4で、2は現れない。mexは2。

**$h=2a$（偶数、$a\ge2$）の場合：** 中心を選ぶ子から1、枝先・補助頂点から0が現れる。$h-1=2a-1$ の帰納法の仮定によれば、非例外子は $r'<a$ なら3、$r'\ge a$ なら2。

- $r<a$：3が現れ、2は現れない。mexは2。
- $r=a$：重い中心を消すと3、軽い中心を消すと2が現れる。mexは4。
- $r>a$：2が現れ、3は現れない。mexは3。

各場合の「現れる」は、該当する中心の私有葉を選べばよい。$r=0$ で $P>0$ のときも、$m>0$ なら任意の中心葉、$m=0$ なら $p_i>0$ の中心葉を選べば非例外子になる。$r=a$ では重い中心と軽い中心がともに存在する。その他の例外子はすでに存在する0または1と重複する。

最後に $m>0$ の補助葉の手を確認する。$m-1$ に対する帰納法で、その子の値 $1\oplus G_h(\mathbf p,m-1)$ は、奇数 $h$ の軽い側なら2（$P=1,\sum p_i=0$ の場合だけ0）、重い側なら3、偶数 $h$ の軽い側なら3（同じ例外で1）、ちょうど半数なら5、重い側なら2である。いずれも既存の子の値か、mexを変えない5である。従って上記のmexが全 $m$ で維持される。これで**任意の $h,p_i,m$ および任意の指定された奇数・偶数重複数**について証明が閉じる。

## 独立した名前付き頂点検証

[verify_named.py](verify_named.py) は各独立点を別々の頂点として実際に構築し、すべての初手で閉近傍を削除してmexを計算する。上記の星の再帰や中心数帰納法を計算には使わない。

2026-10-29 にPython 3で局所実行した結果：

- 1〜7中心、枝数0〜3、補助頂点0〜1、均一な葉数・重複数のうち所定の頂点数上限を満たす構成、および中心1〜4の不均一な重複数を含む**155構成**を全手再帰で照合。すべて一致。
- 中心数別件数：1:16、2:33、3:34、4:32、5:18、6:11、7:11。最大98,672状態（22頂点の不均一例）。
- 追加の境界6構成も照合。例えば $(p_1,p_2,p_3,p_4)=(0,0,3,3)$、$m=0$ は26頂点で **$g=4$**（125,240状態）。$(0,3,3)$ は24頂点で $g=2$（59,704状態）。
- 合計**161構成、公式との不一致0**。これは全称証明とは別の有限検算である。

実行方法：Python 3で本ディレクトリの verify_named.py を実行する。
