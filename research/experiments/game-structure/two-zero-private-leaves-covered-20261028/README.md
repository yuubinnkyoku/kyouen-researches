# 私有葉ゼロを2頂点まで許す分割グラフのGrundy統一公式（2026-10-28）

## 定理（計算機援用全称証明）

通常プレイの Node Kayles を、クリーク $C=\{c_0,\dots,c_{k-1}\}$ と独立集合 $I$ からなる分割グラフで考える。各独立点のクリーク側近傍はちょうど1点または2点とする。$t_i\ge0$ は $c_i$ の私有葉数、$r_{ij}\ge0$ は近傍が $\{c_i,c_j\}$ である独立点数とする。

**仮定：** $k\ge3$、私有葉数 $t_i=0$ の頂点は高々2個、かつ **全クリーク頂点に独立側の隣接点が存在する**（$t_i+\sum_{j\ne i}r_{ij}>0$）。

$
u=\left(\sum_i t_i+\sum_{i<j}r_{ij}\right)\bmod2,\qquad
z_i=\left(t_i+\sum_{j\ne i}r_{ij}\right)\bmod2.
$

このとき、欠損二点型の配置・数および重複数に制限なく、

$
\boxed{g(G)=
\begin{cases}
1\oplus u\oplus z_0,&z_0=\cdots=z_{k-1},\\
2+u,&\text{それ以外}
\end{cases}}
$

が成立する。特に **$g(G)\le3$**。独立側の孤立点が別途ある場合、その個数の偶奇を最後に xor する。

前回の「全 $t_i\ge1$」から、**2頂点まで私有葉がなくてもよい**ところへ拡張した。私有葉ゼロの頂点は二点型の隣接点を少なくとも1個持つ必要がある。

**孤立クリーク頂点の補正：** $t_i=0$ かつ全 $r_{ij}=0$ の頂点は、グラフ全体で孤立している。これらを $h$ 個削除し、残るクリークサイズ $k-h\ge3$ なら、上記公式を残りのグラフ $G'$ に適用して $g(G)=(h\bmod2)\oplus g$G'$$。したがって $k\ge5$ かつ私有葉ゼロが高々2頂点なら、孤立点を先に取り除くことで **全構成のGrundy数を閉形式で決定**できる。

## 全称証明

1. **偶奇縮約。** 既証明の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同一の非空近傍を持つ独立点の個数は、0・正の奇数・正の偶数に分類し、代表値0,1,2で厳密に置き換えられる。したがって $k=3,4$ の全基底は有限。
2. **基底。** $k=3$ の636構成、$k=4$ の50,400構成（全 $t_i\in\{0,1,2\}$、全 $r_{ij}\in\{0,1,2\}$、私有葉ゼロ高々2、全クリーク頂点に独立側隣接点あり）を、予測式を使わないmex再帰で完全列挙し、不一致0。別方式の名前付き頂点の閉近傍削除でも $k=3$ 全636構成と $k=4$ の192標本が一致した。
3. **帰納仮定の保存。** $k\ge5$ とし、独立点 $x$ のクリーク近傍 $B$（サイズ1または2）を消す。残るクリークは $k-|B|\ge3$。元の私有葉を持つ生存頂点はそれを保持する。元の私有葉がゼロの生存頂点も、$x$ はその頂点に隣接しないため、その頂点の元の二点型隣接点は削除されず、生存クリークに対する二点型または新しい私有葉として残る。したがって「私有葉ゼロ高々2、全クリーク頂点が独立側に隣接」の条件は子にも保存される。クリーク初手は独立点のみの子になる。
4. **子の値。** 生存クリーク頂点の $z_i$ は不変。親で非孤立な独立点数の偶奇を $u$、独立点 $x$ を選んだ後で非孤立な独立点数の偶奇を $u'$ とすると、新たに孤立した点の偶奇は $u\oplus u'\oplus1$。帰納仮定と孤立点のxor則より、独立点初手の子値は、生存 $z$ が一様 $s$ なら $u\oplus s$、混在なら $u\oplus3$。クリーク頂点 $c_i$ 初手の子値は $u\oplus z_i$。
5. **mex。** 全 $z_i=s$ なら、すべての子値が $u\oplus s$ なので $g=1\oplus u\oplus s$。混在ならクリーク初手から0と1がともに現れる。$k\ge5$ では多数派の $z$ 値を持つ頂点は少なくとも3個であり、私有葉ゼロは全体で高々2個だから、その多数派から私有葉を持つ頂点を1個選べる。その私有葉を打てば多数派も少数派も残り、子の値 $u\oplus3$ が実現する。他の子値は \(\{0,1,u\oplus3\}\) に含まれる。ゆえに $g=\operatorname{mex}\{0,1,u\oplus3\}=2+u$。帰納法が閉じる。

**条件の鋭さ（小さいkでの反例）：** $k=4$、$t=(1,0,0,0)$、$r_{01}=r_{02}=r_{03}=2$、その他の $r=0$ では全クリーク頂点に独立側隣接点があるが、真の $g=2$、統一公式の予測は3。$k=5$ で $t=(1,0,0,0,1)$、同じ (r) とすると真の $g=4$、予測は2。したがって私有葉ゼロを3頂点まで無条件に増やすことはできない。ただし、すべての (k\ge6) で3頂点が最適な境界だと主張するものではない。
