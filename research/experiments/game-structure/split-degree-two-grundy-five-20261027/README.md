# 連結な次数2分割グラフのGrundy値5：最小15頂点（2026-10-27）

## 結論

抽象的な二点残余禁止ゲーム（Node Kayles）の競合グラフが、クリーク `C` と独立集合 `I` に分割でき、**各 `v∈I` のクリーク内次数が1または2**であるとする。クリークは空でないものとし、このグラフは連結である。

**計算機援用の全称的な最小性定理：** この族でGrundy値5を実現する最小頂点数は **15**。14頂点以下の全対象では `g≤4` が成立する。15頂点・31辺の明示例で等号を達成する。

既存の[13頂点・24辺のg=4証人](../split-degree-two-grundy-four-20261027/README.md)にクリーク点と次数2の独立点を1つずつ追加した構成である。従来の「独立側次数2ならg≤4か」という問いに**連結な反例**を与える。孤立点追加によるxor 1とは異なる。

## 明示証人と全初手

`C={c0,c1,c2,c3,c4,c5}` は6点クリーク。独立点 `I={a,x1,y1,x2,y2,x3,y3,b,z}` のクリーク内近傍を、`c_i` に対応する第 `i` ビットの整数で表す。

`(a,x1,y1,x2,y2,x3,y3,b,z)=(1,3,3,5,5,9,9,16,48)`

つまり、`a` は `c0` のみに、`x_j,y_j` は `c0,c_j` に、`b` は `c4` のみに、`z` は `c4,c5` に隣接する。クリーク内15辺・交差16辺の合計31辺。全独立点は次数1または2で、孤立点はない。

頂点順 `(c0,c1,c2,c3,c4,c5,a,x1,y1,x2,y2,x3,y3,b,z)` の全初手後Grundy値は

`(0,1,1,1,1,0,2,2,2,2,2,2,2,4,3)`

である。したがって `mex{0,1,2,3,4}=5`。独立した個別頂点の閉近傍除去再帰は808状態でこの15個の子値を検査した。

特に `b` を選ぶと `c4` が消え、`z` は `c5` の私有葉になるので、残りは前回の13頂点・g=4証人と同型になる。`z` を選ぶと `c4,c5` が消え、`b` は孤立点になる。残りのクリーク4点側の値は2なので `2 xor 1=3`。

## 任意の分割グラフをクリーク部分集合だけで解く全称再帰

以下は独立側の次数上限を必要としない、**計算に依存しない数学的全称定理**である。

`C` の部分集合 `X` に対し、`H_X` を、`X` と、元の独立点のうち `N(v)∩X≠∅` である点だけからなる誘導部分グラフとする。`h(X)=g(H_X)`、`p(X)=#{v∈I:N(v)∩X≠∅} mod 2`、`d(c)=#{v∈I:c∈N(v)} mod 2` と置く。`h(∅)=0`。

独立点のクリーク内近傍を `s(v)` と書くと、非空 `X` について

\[
 h(X)=\operatorname{mex}\left(
 \{p(X)\mathbin{\mathrm{xor}}d(c):c\in X\}
 \cup
 \{h(X\setminus s(v))\mathbin{\mathrm{xor}}p(X)
 \mathbin{\mathrm{xor}}p(X\setminus s(v))\mathbin{\mathrm{xor}}1:
 v\in I,\ s(v)\cap X\ne\varnothing\}
 \right).
\]

**証明：** クリーク点 `c` を選ぶとクリークは全消去され、`c` に隣接しない活動中の独立点だけが残る。その偶奇が `p(X) xor d(c)`。独立点 `v` を選ぶと `X'=X\setminus s(v)` が残り、`H_{X'}` の外で新たに孤立した独立点は `p(X)-p(X')-1` 個（偶奇で計算）である。独立成分のxor則から第二の子値が従う。全合法手を尽くし、`|X'|<|X|` だから帰納法で厳密に計算できる。

同じ署名の独立点は着手候補として1種類だけでよい。出現する非空署名の種類数を `t`、`k=|C|` とすると、単純実装は `O(2^k(k+t)+kt)` 時間・`O(2^k+t)` 補助記憶で済む。署名ごとの個数は**0か、正の奇数か、正の偶数か**だけが必要。次数2では `t≤k+\binom{k}{2}`。孤立点がある場合は、その個数の偶奇を最後にxorする。

## 13・14頂点の有限完全列挙

固定した `k=|C|`、`m=|I|` について、次数1または2の非空近傍署名は `T=k+\binom{k}{2}` 種類。独立点の順序を無視した全署名多重集合は

\[
 \binom{T+m-1}{m}
\]

種類であり、`verify_census.cpp` はこれらを**全生成して全ての値を計算**する。`k≤4` は既存の[クリーク4以下の全称上界3](../split-clique-four-five-20261027/README.md)により除外できる。

13頂点 **3,199,506**、14頂点 **16,185,742**、合計 **19,385,248** 個の署名多重集合を完全評価した。グラフ同型類の数ではなく、クリークの頂点名を固定した数である。全て `g≤4`。

**12頂点以下の排除：** 独立点がある連結分割グラフに、ある独立点と同じ非空近傍を持つ独立点を**2個**追加してもGrundy値は変わらず、連結性・次数上限2も保たれる。これは既存の[K0336の独立双子点の偶奇圧縮](../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)の逆向きである。もし12頂点以下に値5の例があれば、2点ずつ増やして13頂点または14頂点にも値5の例ができるが、上の完全列挙に反する。独立点がない場合はクリークで `g=1`。よって最小値は15。

## 再現と検証境界

- [verify_census.cpp](verify_census.cpp)：19,385,248多重集合の完全生成・上記再帰による全分類。`--dump-g4` で値4の220多重集合を全出力。
- [verify_independent.py](verify_independent.py)：クリーク部分集合再帰を使わず、**個別頂点の閉近傍を直接削除**する独立メモ化再帰。15頂点証人の全初手、13・14頂点それぞれ500個の固定乱数標本、値4の220例を照合し、全一致。

`verify_census.cpp` の完全生成器そのものを別実装で全件再生成したわけではない。**数学的な有限帰着＋1つの完全列挙器**が最小性の証明であり、独立再帰による検査は明記した範囲に限る。

再現コマンド：

~~~sh
c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/split-degree-two-grundy-five-20261027/verify_census.cpp -o /tmp/split_degree2_census
/tmp/split_degree2_census --dump-g4 > /tmp/split_degree2_g4.txt
python3 research/experiments/game-structure/split-degree-two-grundy-five-20261027/verify_independent.py /tmp/split_degree2_g4.txt
~~~

環境変数 `ONLY_N=13`、`ONLY_K=6` などで特定の行だけを再計算できる。二項係数による全生成件数も確認する。

**適用境界：** 抽象的な二点禁止グラフの定理であり、標準整数格子での実現は未確認。11×11の探索には、全極小残余禁止集合が二点で、競合グラフがこの形に分割できる場合だけ適用可能。実際の出現頻度・速度改善は未測定。knowledge正本への昇格は生成索引を再構築・検査できる環境で行う（generatedを手編集しない）。
