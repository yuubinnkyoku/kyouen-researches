# 奇数全中心型と混合私有葉：Grundy数は奇数私有型の中心数だけで決まる（2026-10-29）

## 定理（計算機非依存の全称証明）

通常プレイ Node Kayles の有限分割グラフ G を考える。中心 C は n≥2 頂点のクリーク、残りの独立集合の各頂点は空でない部分集合 S⊆C をちょうど近傍とする。型 S の重複数を m(S) とする。

仮定は以下の三つだけである。

1. 全中心型 m(C) は正の奇数。
2. 2≤|S|<n の全ての真部分集合型は任意の非負偶数枚。
3. 単点型 m({c}) は各 c ごとに任意の非負整数（0・偶数・奇数を混在させてよい）。

単点型が奇数枚の中心の集合を O={c∈C:m({c}) が奇数}、r=|O| とする。このとき

$$
\boxed{g(G)=\begin{cases}
1 & r=0,\\
2 & r>0\text{ かつ奇数},\\
3 & r>0\text{ かつ偶数}.
\end{cases}}
$$

中心数、偶数型の種類数・重複数・交差、単点型の偶数部分に上限はない。孤立点が z 枚あるときは右辺と (z mod 2) の bitwise xor を取る。n=1 は単点型と全中心型が同一になるのでこの命題には含めない。

特に奇数私有葉を持つ中心が一つもなければ、全中心型が奇数枚ある限り、その他の独立点をいくら偶数枚ずつ加えても g=1 である。一方、全中心に奇数私有葉がある場合は既存の奇数私有葉＋奇数全中心型定理を復元する。

## 数学的証明

任意の非空 R⊆C について、R と交わる型の独立点だけを残した非孤立核を H_R とし、h(R)=g(H_R)、h(∅)=0 とする。R と交わらなくなった独立点は孤立点として xor 分離する。

R に残る奇数私有型中心数を r_R=|O∩R| とする。全中心型が奇数で、真の非単点型は全て偶数だから、H_R の独立点総数の偶奇は

$$p(R)=(r_R+1)\bmod2\quad(R\ne\varnothing),\qquad p(\varnothing)=0.$$

中心 c∈R を選ぶと、他の中心も全て消える。残る孤立点の偶奇は p(R) xor p({c})=r_R xor 1_{c∈O}（この式の xor は偶奇の排他的論理和）である。

型 S の独立点を選び T=S∩R≠∅、Q=R\setminus T、a=|O∩T| とする。Q=∅ なら子の値は p(R) xor 1=r_R mod 2。Q≠∅ なら子の値は

$$h(Q)\ \mathrm{xor}\ p(R)\ \mathrm{xor}\ p(Q)\ \mathrm{xor}\ 1
=h(Q)\ \mathrm{xor}\ ((a+1)\bmod2).$$

|R| に関する強い帰納法で h(R) が上の r_R の公式に従うことを示す。

- r_R=0：中心の手も、全中心型の手も0。ほかの独立点の手は Q=∅ なら0、Q≠∅ なら h(Q)=1 を xor 1 して0。従って子の値は {0}、mex=1。
- r_R>0 が奇数：奇数私有型を持つ中心を選べば0、全中心型を選べば1が得られる。ほかの独立点の手は、Q=∅ なら1、Q≠∅ で a が偶数なら r_Q は正の奇数で h(Q) xor 1=3、a が奇数なら r_Q は偶数で h(Q)∈{1,3}。中心の手も0か1。子に2は現れないので mex=2。
- r_R>0 が偶数：全中心型を選べば0、奇数私有型を持つ中心を選べば1が得られる。さらにその中心の単点型を選べば、r_R≥2 なので Q≠∅、a=1、r_Q は正の奇数で子の値 h(Q)=2。ほかの独立点の手は Q=∅ なら0、Q≠∅ で a 偶数なら h(Q)∈{1,3} xor 1∈{0,2}、a 奇数なら h(Q)=2。中心の手も0か1。子に3は現れないので mex=3。

全ての手を尽くし、各場合に必要な子の値の存在も示した。これで全非空 R の公式が帰納的に成立し、R=C で定理を得る。

## 独立検証と範囲

verify.py は二つの異なる方法を照合する。

- 型の重複数・生存中心集合による再帰：上の p(R) を計算し、中心・独立点の全着手から mex を求める。全非空 R について公式を検査する。
- 名前付き頂点の直接再帰：各独立点を実際に別頂点として生成し、閉近傍削除のビット集合再帰で mex を求める。孤立点は xor で分離する。型別再帰の状態遷移を再利用しない。

完全列挙は n=2 で4、n=3 で64、n=4 で896構成（n=4 は真の非単点型を高々2種類、各2枚）。加えて n=3,4,5,6 各70件の固定乱数標本で、私有型0/1/2/3枚、全中心型1/3/5枚、その他の偶数型2/4枚、孤立点0/1/2枚を含める。合計1244構成で両再帰と公式が一致、最大名前付き再帰状態数1277。不一致0。

再現：Python 3 標準ライブラリのみ。

    python3 research/experiments/game-structure/odd-universal-mixed-private-parity-20261029/verify.py

期待出力：

    PASS named_and_quotient_cases=1244 exhaustive_by_n={2: 4, 3: 64, 4: 896} max_named_states=1277

条件の必要性の例：n=3、全中心型1枚、ほかの型なしなら g=1 だが、二点型 {0,1} を奇数1枚追加すると g=2（直接再帰で確認）。したがって真の非単点型を無条件に許すことはできない。
