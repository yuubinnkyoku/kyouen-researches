# 5中心・偶数三点型消去：奇数型は全種類、混在型は8種類まで（2026-10-29）

## 結論（抽象分割グラフの通常 Node Kayles）

5個の中心がクリークをなし、各中心に**正の奇数枚**の私有葉を持つ。独立集合側のほかの点は、2個以上の中心を近傍とする型ごとに任意個配置する。孤立点は除く（あれば独立成分として xor する）。任意の三点型 `T` を固定し、`G+2T` をその型の点を2枚追加したグラフとする。

次の**いずれか**が成立すれば、`g(G)=g(G+2T)`。

1. **奇数型の無制限分類**：`T` 以外のすべての非私有型の重複数が0または正の奇数である。型の種類数に制限はない（最大25種類）。
2. **混在型の8種類定理**：`T` 以外で正の重複数を持つ非私有型が**高々8種類**である。各型の重複数は奇数・偶数を問わず任意の正の整数。

`T` が元から正の重複数を持つ場合は、[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)だけで2枚追加の不変性が従う。したがって、実際に検査すべき場合は `T=0` から `T=2` の比較だけである。

この結果は、[先行する混在型6種類の定理](../five-even-triple-mixed-six-types-20261029/README.md)を厳密に拡張する。奇数型だけなら6種類という制限を**完全に撤廃**し、偶数型の共存を許す場合も6種類から8種類へ広げる。

## 無限族から有限基底への証明

K0336の独立双子点の正の偶奇縮約により、各私有葉の正の奇数重複は1へ、その他の各正の奇数重複は1へ、各正の偶数重複は2へ還元できる。これは元のゲームのGrundy数を保つ**全称的な数学的補題**である。

中心の置換で `T={0,1,2}` としてよい。5中心の非私有型は `2^5-1-5=26` 種類で、`T` 以外に25種類ある。`T` を保つ中心の置換群は `S_3 × S_2`（12元）。各型集合をこの群の辞書順最小の代表へ移し、代表について重複数の全組合せを検査する。置換はゲームの同型を保つ。

- **奇数型だけ**：全 `2^25=33,554,432` 個の二値基底を、**2,892,160**個の型集合代表へ縮約。各代表を完全検査した。軌道サイズの総和が厳密に33,554,432となることも別途確認した。
- **混在型・高々8種類**：`Σ_{k=0}^8 C(25,k)2^k=351,669,411` 個の三値基底を、**30,940,545**個の「型集合代表×重複数割当」へ縮約。すべて検査した。各 `k` について、型集合の軌道サイズの和が `C(25,k)`、代表ごとの割当数が `2^k` であることを確認した。

どちらも、追加前後のGrundy数が**全代表で一致し、不一致0件**だった。これは単なる無作為実験ではなく、**K0336による無限族の数学的還元＋有限基底の完全列挙**による、計算機援用の限定全称証明である。

## 正確なGrundy再帰

生存中心の集合を `R`、独立点の近傍型 `S` の個数を `a[S]` とする。`p(R)=Σ_{S∩R≠∅}a[S] (mod 2)`、`d(c)=Σ_{S∋c}a[S] (mod 2)` とおく。中心を選んだ子の値は `p(R) xor d(c)`、独立型 `S` を選んだ子の値は

`h(R\\S) xor (p(R) xor p(R\\S) xor 1)`

であり、これらの `mex` が `h(R)`、`h(∅)=0` である。これは閉近傍削除後の孤立点を xor で分離した、通常 Node Kayles の厳密な再帰である。

`T` を2枚追加しても `p(R)` と `d(c)` は変化しない。違いは `R∩T≠∅` のときに独立型 `T` を選ぶ選択肢が加わることだけである。[verify.cpp](verify.cpp) は追加前後の `h(R)` を同時に、`R=1..31` の全状態について計算する。型の集合と重複数の割当を列挙し、全代表で根の値を比較する。

## 独立検証と再現

[verify_independent.py](verify_independent.py) は実際に名前付き頂点を作り、全頂点の閉近傍を直接削除して `mex` を計算する別方式である。固定乱数種の**134構成**（`k=0..8,10,12`、0枚と2枚の両方）を照合し、不一致0件だった。大きな重複数を持つ全構成の独立全件照合ではなく、**標本による独立監査**である。完全性は上記の数学的還元とC++の全軌道代表列挙に依存する。

リポジトリ直下で実行：

```sh
c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/five-even-triple-odd-complete-mixed-eight-20261029/verify.cpp -o /tmp/five-triple-verify
/tmp/five-triple-verify odd
/tmp/five-triple-verify mixed8
python3 research/experiments/game-structure/five-even-triple-odd-complete-mixed-eight-20261029/verify_independent.py
```

局所実行：奇数型の全代表約4.2秒、混在型の全代表約20.3秒、独立標本約11.2秒。コンパイラはC++17、Pythonは3.11系。全体CI・knowledge正本の項目追加・生成索引の再構築は未実施。
