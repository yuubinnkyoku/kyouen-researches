# 奇数私有葉＋奇数全中心型：任意の偶数近傍型を許すGrundy閉形式（2026-10-29）

## 定理（数学的全称証明）

中心集合 C は n≥1 頂点のクリークで、残りは独立集合 I とする。I の各頂点は非空の中心部分集合 S⊆C をちょうど近傍とする「型 S」に属する。各中心の単点型は正の奇数枚、全中心型 C も正の奇数枚、それ以外の全ての型は任意の非負偶数枚（0,2,4,…）とする。n=1 では単点型と全中心型が一致するので、その型の合計枚数を正の偶数とする。

通常 Node Kayles（頂点と閉近傍を消去）のGrundy数は、中心数に上限なく

$$
\boxed{g(G)=\begin{cases}2&n\text{ が奇数},\\3&n\text{ が偶数}.\end{cases}}
$$

したがって、**全中心型が奇数なら、ほかの偶数近傍型は種類数・重複数・交差に制限なく0枚へ消去できる**。孤立点が z 枚あれば、上式に (z mod 2) を xor する。整数格子上での実現可能性は主張しない。

## 数学的証明（有限実験に依存しない）

生存中心集合 R⊆C に少なくとも一つ隣接する独立点だけを残した非孤立核のGrundy数を h(R)、h(∅)=0 とする。R と交わらない型の点は孤立点として xor 分離できる。

r=|R|≥1 のとき、非孤立独立点の個数の偶奇は、各単点型の奇数枚が r 回、全中心型の奇数枚が1回、その他の偶数型が0回寄与するので

$$
p(R)=(r+1)\bmod2,\quad p(\varnothing)=0,\quad p(\{c\})=0.
$$

全ての着手を分類する。

* 中心 c∈R を選ぶと全中心が消え、残る独立点は孤立する。子の値は p(R) xor p({c}) = (r+1) mod 2。
* 独立点の型 S を選び、t=|S∩R|≥1 とする。t=r なら子の値は p(R) xor 1 = r mod 2。
* 1≤t<r なら Q=R\S は非空で、子の値は h(Q) xor (p(R) xor p(Q) xor 1) = h(Q) xor ((t+1) mod 2)。

r=1 では中心の手が0、独立点の手が1で h(R)=mex{0,1}=2。r≥2 で帰納法により、全ての小さい非空 Q に対して h(Q)=2（|Q|奇数）、3（|Q|偶数）と仮定する。すると 1≤t<r の独立点の手は、t の偶奇にかかわらず r 奇数なら3、r 偶数なら2になる。

全中心型が正の奇数枚あるため t=r の手は必ず存在し、各中心の私有葉があるため r≥2 なら t=1<r の手も必ず存在する。従って子の値集合は正確に、r≥3 奇数なら {0,1,3}、r≥2 偶数なら {0,1,2}。それぞれ mex は2、3である。追加の偶数型は既存の子の値しか生まず、全称帰納法が完了する。

この閉形式は、元の型の点数を保ったまま R に制限した全非孤立核にも成り立つ。任意の合法途中局面に同じ式が成り立つという主張ではない。

## 再現と独立検証

[verify.py](verify.py) は、(1) 型別・生存中心集合の厳密再帰と、(2) **全頂点を名前付きで生成して閉近傍を削除する独立再帰**を実装する。

n≤4 の全てのサイズ2以上の型について追加枚数0/2を完全列挙（n=1,2,3,4 でそれぞれ1,2,16,2048、合計2067構成）。各構成の全生存中心集合で閉形式を確認した。独立方式では不均一な正の奇数私有葉・全中心型、正の偶数他型、孤立点も含めて220構成を照合した。不一致0、名前付き再帰の最大記憶状態数32768。独立方式による2067件の全件再計算ではない。

リポジトリ直下で実行：

    PASS exhaustive_even_type_patterns=2067 independent_named_cases=220 max_named_states=32768

## 条件の鋭さと既存研究との関係

n=3、私有葉各1枚・全中心型1枚・ほかの型なしでは g=2。奇数二点型 {0,1} を1枚追加すると g=3、同型を2枚追加した場合は g=2（型別と名前付きの両再帰で確認）。「その他の型は偶数枚」という条件を無条件には外せない。

[K0305](../../../knowledge/items/K0305-binary-grundy-iff-maximal-parity.md) の全局面Grundy二値性とは別の現象であり、[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) の双子点縮約より強い「2枚→0枚」消去をこの特殊族で証明する。[多群公式](../partitioned-centers-multigroup-universal-parity-20261029/README.md) と異なり、群型の分割条件を全く要求しない。
