# 全二点型を持つクリークと一様な私有葉のGrundy閉形式（2026-10-28）

## 結論（数学的全称定理）

抽象的な二点禁止ゲーム（Node Kayles）で、次の分割グラフ H(k,t) を考える。k,t は非負整数。

- クリーク C={c_1,...,c_k} を置く。
- C の**すべての二点組** {c_i,c_j} に対し、ちょうど1個の独立点 e_ij を置き、両端だけに隣接させる。
- 各 c_i にちょうど t 個の私有葉を置く。独立点同士には辺を張らない。

F(k,t)=g(H(k,t)) は次の**閉形式**で与えられる。

| 条件 | F(k,t) |
|---|---:|
| k=0 | 0 |
| k=1, t=0 または t が奇数 | 1 |
| k=1, t>0 が偶数 | 2 |
| k=2, t が偶数 | 1 |
| k=2, t が奇数 | 3 |
| k=3 | 0 |
| k=4 | t mod 2 |
| k>=5, t が偶数 | 1 iff k mod 4 が1または2、そうでなければ0 |
| k>=5, t が奇数 | 1 iff k mod 4 が0または1、そうでなければ0 |

特に私有葉のない全二点型グラフでは、**任意の k>=1 に対して**
`g(H(k,0)) = 1 iff k mod 4 in {1,2}; otherwise 0`。

したがって k>=5 では、任意個の一様な私有葉を加えても g<=1 であり、t の正確な値は偶奇しか影響しない。これは全称定理であり、有限実験からの外挿ではない。

## 三種類の初手に関する厳密な再帰

F(0,t)=0。k>=1 に対して、初手の子Grundy値は次の三種類に尽きる。

1. **クリーク点** c_i を選ぶ：クリークは全消去され、他の k-1 頂点の葉 (k-1)t 個と、その二点間の C(k-1,2) 個の独立点だけが孤立して残る。子値 `A=((k-1)t+C(k-1,2)) mod 2`。
2. **私有葉**（t>0）を選ぶ：そのクリーク点と葉を消し、残り t-1 葉が孤立する。元の二点型独立点のうち当該クリーク点に接続していた k-1 個は、残存クリーク各点の私有葉へ変わる。子値 `B=F(k-1,t+1) xor ((t-1) mod 2)`。
3. **二点型独立点**（k>=2）を選ぶ：その両端のクリーク点を消し、両端に付属した 2t 葉が孤立する（偶数個）。残るクリーク各点に二点型独立点由来の葉が2個ずつ増える。子値 `D=F(k-2,t+2)`。

従って `F(k,t)=mex({A} ∪ ({B} if t>0) ∪ ({D} if k>=2))`。この再帰は全称的に導かれ、有限列挙を必要としない。なお、二点型独立点を選んだとき、両端と残存クリークを結ぶ独立点は**孤立せず葉になる**。これを孤立点と誤認した単純な F(k-2,0) 再帰は誤りである。

## 閉形式の全称証明

k=0..4 は上の三種類の再帰に代入して直接得られる。k>=5 では、三種類の初手の子値が**すべて同じ0または1**になることを k で帰納的に示す。k=5,6,7,8 は上の再帰と k<=4 の値で直接確かめられる。

k>=9 では k-1>=8, k-2>=7 なので帰納法の閉形式が使える。A の偶奇、B の t+1 の偶奇反転、D の k-2 の剰余を代入すると、三種類の子値は次の表の同じ値 Q に一致する（t=0 では B は存在しない）。

| k mod 4 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| t 偶数: Q | 1 | 0 | 0 | 1 |
| t 奇数: Q | 0 | 0 | 1 | 1 |

例えば A は C(k-1,2) が奇数 iff k mod 4 in {0,3} と (k-1)t mod2 から直ちにこの表になる。D=F(k-2,t+2) は k-2 の剰余が2だけずれるので Q に等しく、B=F(k-1,t+1) xor ((t-1) mod2) も t の偶奇を反転させれば Q に等しい。ゆえに F(k,t)=mex({Q})=1-Q であり、表の閉形式がすべての k,t に成立する。
