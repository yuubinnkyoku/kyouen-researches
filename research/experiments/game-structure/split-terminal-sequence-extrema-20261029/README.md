# 分割グラフの全終局着手列の計数と、交差辺数を固定した鋭い上下界（2026-10-29）

## 定理1：終局列の母関数（数学的全称証明）

有限分割グラフ G のクリーク C と独立集合 I への分割を固定し、k=|C|、m=|I|、d(c)=|N(c)∩I| とする。通常プレイの Node Kayles で、**着手する頂点の順序まで区別した**終局着手列を数える。F_G(z)=Σ_L a_L z^L とする。k≥1 なら

[
oxed{F_G(z)=sum_{cin C}(m+1-d(c))!,z^{m+1-d(c)}
+mathbf1_{min_c d(c)>0},m!,z^m.}
]

k=0 なら F_G(z)=m! z^m（m=0 では空の着手列を1通りと数える）。

したがって、終局長 L の列数は
[
a_L=L!left(#{c:d(c)=m+1-L}
+mathbf1_{L=m}mathbf1_{min_c d(c)>0}ight).
]
これは終局長の**集合**だけでなく、各長さへの到達列数まで決定する。r人が巡回して最後の着手者だけが勝つとき、空でない着手列のうちプレイヤー j (1≤j≤r) が最後に着手する列数は Σ_{L≥1, 1+((L-1) mod r)=j} a_L。全着手列を等確率で選ぶというモデルでの確率は、この数を F_G(1) で割ったもの。**各局面で合法手を一様選択する確率とは異なる**。

### 証明

合法な着手済み頂点集合は独立集合であり、終局は極大独立集合と一致する。中心 c を含む極大独立集合は M_c={c}∪(I\N(c)) のみで、大きさ m+1-d(c)。中心を含まない極大独立集合は I のみで、これが極大である必要十分条件は全 d(c)>0。これらの集合は互いに異なる。極大独立集合の頂点を任意の順序で着手しても各手は合法で、最後に必ず終局になるので、サイズ L の集合はちょうど L! 列を与える。

## 定理2：k,m と交差辺数 E を固定した終局列数の厳密な最小値・最大値

k≥1、m≥0、0≤E≤km とする。f_m(d)=(m+1-d)! と置く。次数列 (d_1,...,d_k) の各項は0以上m以下で、Σd_i=E。任意のそのような次数列は、各中心が I の任意の d_i 点と結ぶことで実現できる。

次の二つの操作を定義する。

- B(n,l,u,t)：n個の整数を [l,u] 内に取り、和を t として、差が高々1になるよう均等化した列。
- X(n,l,u,t)：同じ条件で、まず u を可能な限り並べ、残りは高々1個の中間値と l だけにした列。

不可能な引数の候補は除外する。n=0 では t=0 のときだけ空列を許す。任意の次数列 D に対し H(D)=Σ_{d∈D} f_m(d) とする。

候補 A（次数0の中心が存在）は E≤(k−1)m の場合に限り可能で、
[
A_{min}=f_m(0)+H(B(k-1,0,m,E)),qquad
A_{max}=H(X(k,0,m,E)).
]
候補 B（全中心の次数が正）は E≥k の場合に限り可能で、
[
B_{min}=H(B(k,1,m,E))+m!,qquad
B_{max}=H(X(k,1,m,E))+m!.
]
**求める最小値は存在する候補の下限 A_min,B_min の小さい方、最大値は上限 A_max,B_max の大きい方**である。各候補を実現するグラフが存在するので、上下界は鋭い。m=0,1、k=1 の境界例も上記の規約で扱える。

### 証明

定理1より、列数は H(D)+1_{min D>0}m!。各クラス A/B で第2項は一定。f_m(d) は整数区間0≤d≤mで厳密に離散凸である。実際、内部点1≤d≤m−1で n=m+1−d とすると
[
f_m(d-1)-2f_m(d)+f_m(d+1)=(n-1)!(n^2-n+1)>0.
]
したがって次数差が2以上の2項を均等化すると H は減少し、逆に一方を端へ押し出すと H は増加する。Aの最小では0の中心を一つ固定して残りを均等化し、Aの最大では0を残したまま端へ寄せる（E≤(k−1)m なので X に0が残る）。Bは [1,m] 上で同様に均等化・端寄せする。A/Bの全候補を比較すれば主張が従う。

## 系：交差辺の追加に対する単調性

k,m を固定し、C–I間の辺を1本追加しても、終局着手列総数 F_G(1) は増えない。次数 d→d+1 による f_m の減少は正で、追加によって I が初めて極大になる場合のボーナス m! を差し引いても減少分が m·m! 以上ある（そのとき旧 d=0）。m≥2 なら常に厳密に減少し、m=1 の最後の0次数消滅だけは同数になりうる。これは着手列の総数についての性質であり、Grundy数の単調性は主張しない。
