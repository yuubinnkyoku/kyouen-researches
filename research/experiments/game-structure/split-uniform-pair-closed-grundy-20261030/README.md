# 全中心対に同数の独立点を付けた分割グラフのGrundy閉公式（2026-10-30）

## 定理（中心数・重複数に上限なし）

通常プレイの Node Kayles（選んだ頂点とその隣接頂点を削除するゲーム）を考える。中心集合 C は k>=0 頂点のクリーク。C の異なる各2点 {u,v} にちょうど c>=1 個の独立点を付け、各独立点は u,v にだけ隣接する。独立点同士は非隣接。このグラフを P(k,c) とする。

**全称閉公式**：k=0 では g=0。c が奇数なら、k>=1 に対し

```text
g(P(k,c)) = 1  (k mod 4 = 1,2)
          = 0  (k mod 4 = 0,3)
```

c が正の偶数なら、g(P(2,c))=2、それ以外の k>=1 では g(P(k,c))=1。

したがって奇数重複では中心数4の周期、偶数重複では中心数3以上の全空盤がGrundy数1となる。これは全 k,c に関する数学的証明であり、有限標本からの外挿ではない。

## 対称状態と厳密な再帰

H(k,t,c) を、k 個の生きた中心のクリークに、各生存中心対あたり c 個の共有独立点と、各生存中心あたり ct 個の私有独立点を付けたグラフとする。t>=0 は削除済み中心数を表す補助変数。孤立点は除いて定義する。h(k,t)=g(H(k,t,c)) とおく。

h(0,t)=0。k>=1 で、次の値の集合の mex が h(k,t) である。

1. 中心を選ぶ子：`c*((k-1)*(k-2)/2+(k-1)*t) mod 2`。
2. t>0 のとき私有独立点を選ぶ子：`h(k-1,t+1) xor ((ct-1) mod 2)`。
3. k>=2 のとき共有独立点を選ぶ子：`h(k-2,t+2) xor ((c-1) mod 2)`。

これが全着手を尽くす。中心を選べば他の中心も消え、残る独立点は孤立する。私有点を選ぶと中心1個が消え、ct-1 個の点が新たに孤立する。共有点を選ぶと中心2個が消え、c-1+2ct 個が新たに孤立する。孤立点は1点あたりGrundy数1なので、奇偶の排他的論理和で正確に扱える。いずれも残りの非孤立部分は記した H と同型。

## 再帰を解いた全状態の閉表

k=0 は全行0。以下の各行は k=1、k=2、k>=3 の順。[a,b] は k mod 4 が a または b なら1、それ以外なら0を表す。

| c の偶奇 | t | k=1 | k=2 | k>=3 |
|---|---|---:|---:|---|
| 奇数 | t=0 | 1 | 1 | [1,2] |
| 奇数 | 正の偶数 | 2 | 1 | [1,2] |
| 奇数 | 奇数 | 1 | 3 | [0,1] |
| 偶数 | t=0 | 1 | 2 | 1 |
| 偶数 | t>0 | 2 | 2 | 1 |

**証明**：k=0,1,2,3,4 は上の再帰へ直接代入して確認できる。k>=5 では私有点・共有点の子の中心数がそれぞれ k-1>=4、k-2>=3 なので、帰納法の閉表を適用できる。各子の値は c mod 2、t mod 2（ただし t=0 の有無も区別）、k mod 4 だけで決まり、4つの剰余を mex に代入すると表の k>=3 列に一致する。これは有限の場合分けを伴う数学的帰納法である。t=0 と t>0 の違いは私有点着手の有無として保持している。P(k,c)=H(k,0,c) と置けば定理を得る。
