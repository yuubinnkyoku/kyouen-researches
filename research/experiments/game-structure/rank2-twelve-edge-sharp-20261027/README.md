# 二点残余禁止辺12本以下の鋭いGrundy上界（2026-10-27）

**計算機援用の全称定理：** 有限一点追加・通常プレイの安全局面で、包含極小残余禁止集合がすべて2点集合であり、その本数が **12本以下** なら、任意個の自由点を許しても **Grundy数は7以下** である。この上界は鋭い。11辺までの分類と12辺の森限定結果を、閉路のある12辺グラフも含めて拡張した。

`(6773,6645,5233,5198,2887,2588,161,18)`。連結で値7をとるのは18類である。9〜11辺の全度数は既存分類と一致した。

## 全称帰着と計算機援用証明

二点禁止辺だけの継続ゲームは、競合グラフの独立集合に頂点を追加するNode Kaylesと一致する。孤立点は独立な一手ゲームで、任意個追加したときのGrundy値は核の値と孤立点数の偶奇とのxorである。

**連結グラフの完全生成：** 辺が2本以上ある任意の連結単純グラフは、閉路を含む場合には閉路上の一辺を削除しても連結であり、木の場合には葉とその接続辺を削除すれば連結性を保つ。逆向きに、(1)既存の非隣接二頂点を結ぶ辺の追加、(2)既存頂点への新しい葉の追加、の二操作で、1辺グラフからすべての連結グラフを生成できる。

各辺数で候補を生成し、次数・各頂点の隣接次数多重集合・三角形数による**同型不変な必要条件**で仕分け、最後は全単射のバックトラックによる**厳密な同型判定**で重複を除いた。特徴量だけで同型とみなすことはない。

**非連結グラフの完全生成：** 任意の孤立点なしグラフは、連結非同型類の多重集合として一意に表される。各連結類の辺数 `e`、Grundy値 `z` に対して、辺数とxor値を状態とする重複使用可能な動的計画法で全多重集合を数えた。したがって12辺の全52,944類が網羅される。連結成分のGrundy値のxor則により、表の上界は任意の局面に適用できる。

**検証：** [verify_connected.cpp](verify_connected.cpp) は各連結代表の根のGrundy値を、残存頂点から閉近傍を消す再帰と、占有済み独立集合を増やす再帰の二方式で**29,503類を含む全連結代表について個別照合**する。非連結の度数表は各連結類を一つずつ取り込む動的計画法で求める。[verify_composition.py](verify_composition.py) は連結代表を辺数・Grundy値でまとめた後、重複組合せ `C(c+k-1,k)` を使う**別の数え上げ**で1〜12辺の全度数を照合する。実行結果は [results.txt](results.txt)。

```sh
c++ -std=c++17 -O3 research/experiments/game-structure/rank2-twelve-edge-sharp-20261027/verify_connected.cpp -o /tmp/rank2_twelve
/tmp/rank2_twelve
python3 research/experiments/game-structure/rank2-twelve-edge-sharp-20261027/verify_composition.py
```

手元のC++二再帰・動的計画法は約2.2秒で完了し、Pythonの別の多重集合計算も全度数が一致した。11辺までの既知度数とも全一致。**ただし12辺の連結同型類生成自体を別実装で独立生成する検証は未実施**である。二再帰と二計数法の一致は、この生成独立性を意味しない。

## 適用範囲

抽象的な**二点のみ**の残余禁止集合ゲームの定理。三点以上の極小残余辺がある局面や、misère、多人数ゲームには直接適用しない。標準整数格子に12辺証人を実現できるか、11×11の探索時間が短縮するかは未確認。12辺を超える一般グラフの鋭い上界は未確定。
