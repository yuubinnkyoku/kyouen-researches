# 任意有限整数点盤の共円ゲーム残余勝敗判定はPSPACE完全

2026-10-19。**数学的全称証明**（既存K0348の整数幾何構成と既知のNode Kayles PSPACE完全性を組み合わせた新しい系）。盤面は任意有限点集合で、初期安全占有集合を入力に含む。標準の正方形全格子盤や空盤面の勝敗問題は対象外。

## 主定理：頂点数v・辺数eのグラフをv+e+1点で符号化

既存K0348（`research/experiments/geometry-frontier-followup-20261005/graph_cover_reduction.md`）では、任意の有限単純グラフ G=(V,E) に対し、`v+e+1` 個の整数格子点の有限盤 B を多項式時間で作れ、**禁止4点組が正確に**

`{p,s_u,s_v,s_e}`（各辺 e={u,v} に一つ）

だけとなることが証明されている。全点集合に三共線はなく、各禁止4点組は真の円である。

ここで、**新たに初期占有集合を `S={p}∪{s_e:e∈E}` と選ぶ**。Sには禁止4点組の4点全部が入らず安全。各頂点点 s_v は単独で合法。残余禁止集合は厳密に `{s_u,s_v}`（e={u,v}∈E）のみで、3点・4点の残余禁止集合はない。従って、任意の独立集合 X⊆V に対して、S∪{s_v:v∈X} の合法な継続手とGrundy値は、G上のNode Kayles（独立集合配置ゲーム）に**全状態で一致**する。

これにより任意の有限単純グラフが、余分な合法点を一つも生じさせず、指定した安全局面の残余二点禁止グラフとして実現できる。元のK0348は一空点の故障耐性と頂点被覆数を扱っており、この**Node Kaylesへの全状態同型**は別の帰結である。

## 計算量の帰結

**決定問題**：二進整数座標の任意有限点集合Bと、指定された安全占有集合Sを入力として、標準4点禁止・完全指摘・通常プレイで手番側が勝てるかを判定する。

この問題は **PSPACE完全**。PSPACE所属は、最大手数が|B|で、各合法手を整数行列式で多項式空間判定でき、深さ優先探索も多項式空間で済むため。PSPACE困難性は、既知のNode Kayles勝敗判定のPSPACE完全性（Schaefer 1978）から、K0348の多項式時間・多項式ビット長の幾何構成と上記の全状態同型を通じた多項式時間帰着で従う。

さらに、入力を「盤面の三点が一切共線でない」「禁止4点組は全て円で、共通点pを含む」「初期占有集合Sはpと各辺固有点だけ」という特殊形に制限してもPSPACE困難である。この制限を満たす盤の検証には多項式時間の全三点・全四点行列式検査を使える。

引用：Schaefer, *On the complexity of some two-person perfect-information games*, JCSS 16 (1978), 185–225. Node KaylesのPSPACE完全性は Kobayashi, *On Structural Parameterizations of Node Kayles* (arXiv:2003.11775) でも明記されている。

## 別証明：有理円の逐次追加によるv+2e点構成

2026-10-19。**数学的全称証明**。適用範囲は「盤面を任意の有限整数格子点集合に選べる」変種であり、標準の正方形盤全体の残余局面への実現は主張しない。

## 定理

任意の有限単純無向グラフ `G=(V,E)` (`|V|=v`, `|E|=e`) に対し、相異なる `v+2e` 個の整数格子点からなる有限盤 `B` と安全な占有集合 `S⊂B`, `|S|=2e` が存在し、次を満たす。

1. `B` 内で同一円または同一直線上にある4点集合は、各辺 `uv∈E` に対応する `{u,v,a_uv,b_uv}` **だけ**である。
2. `S={a_uv,b_uv:uv∈E}`。未占有の `V=B\S` は全点が合法であり、残余禁止集合はちょうど `E`（2点集合）である。3点以上の残余禁止集合は存在しない。
3. 従って `g_B(S)` は `G` 上の独立集合配置ゲーム（Node Kayles と等価）のGrundy値と一致する。

円だけで全ての意図した4点集合を実現でき、意図しない共円4点・共線4点は一つもない。整数座標のビット長を多項式に抑える決定的構成も可能である。

## 証明

**候補点。** グラフの頂点を `p_i=(i,i²)` (`1≤i≤v`) とする。放物線上の相異なる3点は共線でない。また相異なる正の4整数 `i,j,k,l` が共円なら、ある `A,B,C` について `t⁴+B t²+A t+C` がそれらを根に持つ。しかし三次項が0なので根の和は0となり、正整数4個と矛盾する。従って候補点間に禁止4点組はない。

**一辺の追加。** 既に処理した辺の各々に固有の錨点2個を追加済みで、既存点に生じる禁止4点組は意図したものだけとする。新辺 `uv` の候補点 `p_u,p_v` を通る円を `C` とする。二点を通る円の中心は有理数の垂直二等分線上を動く。第三の既存点 `z≠p_u,p_v` がその円に属する中心は高々1個である。従って `C` を有理円として選び、**その円上の既存点を `p_u,p_v` の2個だけ**にできる。

有理点を通る有理円には、直線の有理傾きを用いる有理パラメータ表示によって、相異なる有理点が無限個ある。最初の錨点 `a_uv∈C` を選ぶ際、既存の任意の3点との禁止4点組を避ける。既存3点が非共線なら、それらを通る円は `C` と異なるので交点は高々2個。共線ならその直線と `C` の交点は高々2個。有限個の候補を避ければよい。

次の錨点 `b_uv∈C` も同様に選ぶ。ただし既存3点のうち `{p_u,p_v,a_uv}` の円は `C` 自身なので、この1組との共円は意図的に許す。ほかの既存3点は `C` 上に3点同時にはないため、避けるべき点は再び有限個である。したがって、新しく生じる禁止4点組は `{p_u,p_v,a_uv,b_uv}` だけ。帰納法が閉じる。

**整数化。** 最後に全有理座標の分母の最小公倍数を掛ける。相似変換は共円・共線性を保存する。錨点はどの禁止4点組にも2個しか含まれないので `S` は安全で、各候補点も単独では合法。未占有候補の二点 `u,v` を同時に置くと禁止となる条件は `uv∈E` に正確に一致する。□

**有界探索と座標の大きさ。** 各辺で新円の中心を垂直二等分線上の整数パラメータ `t=1,2,...` で探せば、既存点数 `N` に対し不適な `t` は高々 `N−2` 個。錨点は円上の有理傾き `m=1,2,...` で探す。既存3点組それぞれが高々2個の不適点を指定するため、`m≤2·C(N,3)+N+5` の探索で足りる。各辺の有理演算の分子・分母のビット長は `poly(v+e)`、共通分母の積のビット長も `O((v+e)log(v+e))` 程度に抑えられる。よって構成は入力グラフの大きさに対して多項式時間で行える（素朴な実装は高速ではない）。


`verify_graph_realization.py` は、円の有理パラメータによる一般構成、全4点組の厳密検査、残余ゲームと独立集合ゲームの値の比較を行う。P4、C5、K4、空グラフ5点を検査した。`independent_p3_audit.cpp` はPythonの有理演算を使用せず、上記P3証人の35組を128ビット整数行列式で独立検査し、再帰で `g=2` を照合する。

## 限界・既存研究との関係

- これは任意の**有限点盤**の定理。標準 `n×n` 盤には `B` 以外の格子点も存在し、合法な追加手を生む可能性があるため、標準盤の `R(S)` を指定グラフと完全一致させたことにはならない。旧仮説 B232 の正方形盤版は依然未解決。
- 先行の有限実験（小盤の33/34グラフ類）は、標準正方形盤を対象としており、本定理と矛盾しない。
- Node Kayles の任意のグラフを埋め込めるが、ここから標準正方形盤のGrundy値無界性を導くことはできない。
- 実験は全称証明の代用ではなく、構成手順と具体証人の独立監査である。
