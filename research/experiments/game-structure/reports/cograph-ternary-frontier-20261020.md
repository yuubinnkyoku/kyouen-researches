# 余グラフ二点禁止残局：Grundy 0〜63 の最小頂点数と全称構成

2026-10-20。対象は抽象的な二点禁止残局（競合グラフ上の独立集合追加ゲーム）のうち、余グラフ（cograph）に限る。標準整数格子の実現可能性、11×11空盤の勝敗は主張しない。既存の60頂点までの署名全列挙・Grundy 8〜15最小値を400頂点まで延長した。

## 全称定理：任意のGrundy値を実現する構成

有限グラフGについて、`O(G)={g(G-N[v]):v in V(G)}`、`g(G)=mex O(G)` とする。空グラフのgは0。`+`を頂点非交差和、`*`を完全結合とすると、

- `O(G+H)={x xor g(H):x in O(G)} ∪ {g(G) xor y:y in O(H)}`
- `O(G*H)=O(G) ∪ O(H)`

が成立する（前者は独立なゲームのxor則、後者は片方の着手で他方が全て消えることから従う）。

`A_0=K_1` とし、`A_(k+1)=(A_k+A_k)*A_k` と定める。帰納的に

```
|V(A_k)| = 3^k,
g(A_k) = 2^k,
O(A_k) = {0,1,...,2^k-1}.
```

実際、`A_k+A_k` はg=0で、子の値集合は `{2^k,...,2^(k+1)-1}`。これと `A_k` を完全結合すると、子の値集合が `{0,...,2^(k+1)-1}` となる。

従って任意の正整数 `g=Σ b_k 2^k` (`b_k∈{0,1}`) に対して、`b_k=1` の `A_k` を頂点非交差和で並べれば、**Grundy値が厳密にgで、頂点数が `F(g)=Σ b_k 3^k` の余グラフ**を構成できる。g=0は空グラフで実現する。これは全gへの数学的証明であり、最小性の一般証明ではない。

## 400頂点以下の完全列挙（計算機援用証明）

空グラフを除く1〜400頂点の全余グラフについて、子値集合の異なる署名を完全列挙した。各nで署名数は**ちょうどn**、全てのnで新署名が**ちょうど1種類**増えた。Grundy値1〜63の最小頂点数は、例外なく上の `F(g)` と一致した。g=0の非空余グラフでの最小値は2、空グラフを許せば0。

|---:|---:|---|
| 8 | 27 | 旧60頂点列挙と一致 |
| 16 | 81 | 今回の400頂点完全列挙 |
| 32 | 243 | 今回の400頂点完全列挙 |
| 48 | 324 | 今回の400頂点完全列挙 |
| 63 | 364 | 今回の400頂点完全列挙 |

### 完全性の根拠

任意の非空余グラフは1頂点、またはより小さい余グラフ2個の非交差和・完全結合で構成される。上の二式は署名だけで閉じるため、各nの全署名を `a+(n-a)` (`1≤a≤n/2`) の全署名対から生成すれば漏れがない。異なるグラフでも署名が同じなら、その後の任意の合成で同じ署名を生むため、署名単位の重複排除は安全。

C++は各頂点数nを順に完全列挙し、64bitの子値集合で保持する。独立Pythonは「既知署名を組み合わせて新署名の最小頂点数を優先度付きキューで確定」する別方式を用いる。全署名は真の双子頂点（隣接する交換可能点）を複製して任意の大きい頂点数へ持ち上げられる。真の双子を選べば両方消え、外部点を選べば両方残るか両方消えるため、元の全ての子局面のGrundy値も不変。よって最小頂点数がn以下の署名集合は、n頂点で実現できる署名集合に等しい。

C++が列挙した全80,200個の「nと署名」の組（n=1..400、総数Σn）をPythonの集合と**完全一致**で照合した。両方式で各nの署名数n、g≤63の最小値と `F(g)` の一致を検証した。C++は64bitに収まらない子値が出た場合に停止する。400頂点以下ではその停止条件に達しなかった。

### 再現

```sh
g++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/scripts/cograph_ternary_20261020.cpp -o /tmp/cograph_ternary
/tmp/cograph_ternary 400 --dump > /tmp/cograph_signatures_400.txt
python research/experiments/game-structure/scripts/cograph_ternary_independent_20261020.py --max-n 400 --cpp-dump /tmp/cograph_signatures_400.txt
```

**限界：** `F(g)` が全gで最小か、全nで署名数がnかは未証明。400までの一致を無限の定理に昇格させない。これは抽象余グラフの完全列挙であって、整数格子残局としての実現可能性は別問題。
