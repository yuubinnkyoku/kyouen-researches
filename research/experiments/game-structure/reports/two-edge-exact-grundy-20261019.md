# 2本の極小禁止辺を持つ継続ゲームのGrundy値：完全閉形式

2026-10-19。対象は**有限下方閉配置ゲームの通常プレイ**であり、幾何的な共円配置である必要はない。`main` の K0305（全局面二値性）・K0336（独立双子）・K0344（交換可能類の圧縮）とは異なり、**今いる局面の値**を、禁止辺がちょうど2本の場合に直接与える。

## 定理

現在合法な点集合 `V` 上の包含極小残余禁止辺が、相異なる比較不能な2辺 `E1,E2` だけとする。次の4領域の大きさを

- `a = |E1 \\ E2| >= 1`, `b = |E2 \\ E1| >= 1`,
- `c = |E1 ∩ E2| >= 0`, `f = |V \\ (E1 ∪ E2)| >= 0`,
- `n = a+b+c+f`, `m = min(a,b)`, `M = max(a,b)`

と書く。各辺の大きさは2以上とする（`c=0` かつ `a=1` のような一元辺も、抽象ゲームとしては式が成立する）。この局面の通常Grundy値 `g` は

\[
\boxed{
 g=\begin{cases}
  2+((M-c+f)\bmod 2),&c=m>0,\\
  (n-1)\bmod 2,&c>m,\\
  (n-2)\bmod 2,&c<m.
 \end{cases}}
\]

特に `g=2` または `3` であるための必要十分条件は **`c=min(a,b)>0`**。`g=3` はさらに `M-c+f` が奇数の場合に限る。2辺の大きさにかかわらず `g<=3` であり、4点上の `E1={0,2}, E2={1,2}, V={0,1,2,3}` では `g=3` が達成される。

`c=0`（辺が交わらない）なら `g=(n-2) mod 2`。2辺のどちらかが他方に含まれる場合は極小化後に1辺だけになり、ここでの仮定から外れる。

## 証明（全称）

1. `f` 個の自由点は他の点に制約を与えず、単一手ゲームの `f` 個の直和である。Sprague–Grundyの直和則により `g(a,b,c,f)=g(a,b,c,0) xor (f mod 2)`。右辺の閉形式は `0/1` と `2/3` の間でそれぞれ偶奇が反転するため、以下 `f=0` で十分。
2. `c=0` では2辺が互いに素で、どの極大局面も各辺からちょうど1点ずつ残す。したがって終局までの手数は常に `n-2`、`g=(n-2) mod 2`。`a=0,c>0` または `b=0,c>0` という帰納途中の境界では片方の辺が他方に含まれる。極小辺だけを残すと終局までの手数は常に `n-1` で、`g=(n-1) mod 2`。
3. `a,b,c>=1` で帰納法を使う。全3種類（Aだけ、Bだけ、共通C）の着手が合法であり、いずれも該当する個数を1減らす。`a<=b` としてよい。`n=a+b+c` とする。
   - `c<a`：Cへの着手の子は必ず `(n-3) mod 2`。A/Bへの着手の子は、等号境界 `c=min(a',b')>0` に入る場合だけ `2/3`、それ以外は `(n-3) mod 2`。したがって子に `(n-2) mod 2` はなく、反対の二値が存在するので `mex=(n-2) mod 2`。
   - `c>a`：Aへの着手の子は必ず `(n-2) mod 2`（`a=1` なら境界 `a'=0`）。B/Cへの着手の子は、等号境界に入る場合だけ `2/3`、それ以外は `(n-2) mod 2`。よって `mex=(n-1) mod 2`。
   - `c=a`：Aへの着手の子は `(n-2) mod 2`、Cへの着手の子は `(n-3) mod 2`（`c=1` なら素な2辺への境界）。従って子には0と1の両方がある。`b=a` ならBへの着手も二値で `mex=2`。`b>a` ならBへの着手の子は `2+((b-1-a) mod 2)`、したがって `mex=2+((b-a) mod 2)`。

すべての合法な子を網羅したので帰納が閉じる。

## 再現と独立監査

- `verify_two_edges.py`: **占有ビット集合そのもの**を状態とし、両辺の完成を禁じる通常mex。`a,b>=1,c>=0,f=0,1,2,n<=14` の全1105パラメータ組で閉形式と一致。`g=0,1,2,3` の件数は `472,489,72,72`。
- `verify_two_edges.cpp`: 上記とは独立の**4領域の残数再帰**でmexを計算。`a,b>=1,c>=0,a+b+c<=60,f=0..3` の全143960組で一致。値別件数は `69660,69660,2320,2320`。再帰の内部状態は157880。

これらは全称証明の補助検算であり、有限範囲の一致から定理を主張しているわけではない。共円盤で2本の残余禁止辺が生じた場合には、その局面をこの式で定数時間判定できる。**大規模盤の探索速度改善は未測定**であり、禁止辺の全構築費用も別途必要。
