# 独立行容量領域の勝敗別合法手数分布と条件付き平均

2026-10-16。**全称数学的証明**と**有限完全列挙による独立照合**。対象は `w` 本の各行に `m` 個の区別可能な点があり、各行の石数が `a=min(m,r)` 以下であること**だけ**が安全条件となる容量ゲーム (`w,m,r>=1`)。標準共円ゲームでは、行間をまたぐ禁止集合が存在しないと証明済みの固定幅・高 `q` 領域だけに適用する。一般の長方形盤へ無条件に拡張しない。

## 全称定理：二変数母関数

安全局面 `S` の満容量からの不足石数を `d=wa-|S|`、合法手数を `ell(S)` とする。合法手数は、満杯でない行 `i` の空点数 `m-k_i` の総和である。`z` は不足石数、`t` は合法手数を記録する変数とすると、**物理的な石集合**の個数を数える多項式は厳密に

```
F_{m,a}(z,t)^w,
F_{m,a}(z,t) = C(m,a) + sum_{k=0}^{a-1} C(m,k) z^(a-k) t^(m-k).
```

すなわち `[z^d t^ell] F^w` は不足 `d`、合法手 `ell` の安全局面数に等しい。容量ゲームは全極大集合が `wa` 石であるため、Grundy値は `d mod 2`。従って勝ち局面の合法手数分布は `(F(1,t)^w-F(-1,t)^w)/2`、負け局面は `(F(1,t)^w+F(-1,t)^w)/2` の `t` 係数で厳密に得られる。これは各局面の勝敗と合法手数の**同時分布**である。

## 全称定理：勝敗別の合法手総数と平均

`m>r` とし、次の整数を置く。

```
S = sum_{k=0}^r C(m,k)
D = C(m-1,r)
A = m * sum_{k=0}^{r-1} C(m-1,k)
B = m * C(m-2,r-1)
```

勝ち・負け局面数を `W,L`、それぞれの局面全体での合法手数の総和を `T_W,T_L` とすると、

```
2W   = S^w - D^w
2L   = S^w + D^w
2T_W = w (A S^(w-1) + B D^(w-1))
2T_L = w (A S^(w-1) - B D^(w-1)).
```

特に `m>r` の全整数 `w,r>=1` について

```
T_W / W > T_L / L
```

が**厳密に**成立する。勝ち局面を一様に選んだときの合法手数の平均は、負け局面を一様に選んだときより常に大きい。ただし各勝ち局面が各負け局面より多くの合法手を持つという意味ではない。

`m<=r` の場合は全 `wm` 点が自由で、`F=(1+zt)^m`。`wm>=2` なら勝敗は半数ずつ、勝敗別平均合法手数は**どちらも `wm/2`** で一致する。`wm=1` のときのみ勝ち側1、負け側0。

## 漸近的な偏り

`w,r` を固定して `m→∞` とすると、

```
P(勝ち) = wr/m + O(m^-2),
E[合法手数 | 勝ち] = m-r+1 + O(m^-1),
E[合法手数 | 負け] = wr(wr-1)/m + O(m^-2).
```

負け局面の大半は既に終局であり、勝ち局面の大半は**一行だけ1石不足**している。負け局面での合法手の主寄与は不足石数がちょうど2の局面から生じる。

## 証明

各行の `k` 点配置は `C(m,k)` 通りで、満杯 (`k=a`) なら合法手は0、未満杯なら `m-k`。独立行の直積で多項式が `w` 乗になる。満容量までの手数は全着手列で `d` に固定されるため、後退帰納で `g=d mod2`。

`m>r` では二項係数の交代和恒等式から `F(1,1)=S`、`F(-1,1)=D`。`t` による微分を `t=1` で評価すると、

```
F_t(1,1) = m sum_{k=0}^{r-1} C(m-1,k) = A,
F_t(-1,1) = -m C(m-2,r-1) = -B.
```

`w` 乗の微分を取り、偶奇射影すれば四つの閉公式が得られる。`N=S^w,U=D^w,T=w A S^(w-1),V=w B D^(w-1)` とおくと、条件付き平均の差は

```
E[ell | W] - E[ell | L] = 2(T U + V N)/(N^2-U^2) > 0.
```

ここで `S>D>0`、`A,B>0` なので厳密に正である。`m<=r` の場合は `wm` 個の独立した二値選択に帰着し、`wm>=2` では偶奇別に空点数の平均がともに `wm/2` となる。

漸近式は各行の不足 `j` の配置数 `C(m,r-j)` が満杯の配置数 `C(m,r)` に対して `O(m^-j)` であることから従う。勝ち局面の主項は不足1 (`w` 通りの行選択) で、合法手数は `m-r+1`。負け局面で非零の合法手を持つ主項は不足2であり、(i) 一行が2不足: `w r(r-1)/m²`、(ii) 二行が各1不足: `C(w,2)r²/m²` の相対頻度を持つ。各場合の合法手数の主項はそれぞれ `m,2m` なので、係数は `wr(r-1)+w(w-1)r²=wr(wr-1)` となる。次の不足数は偶数では4以上であり、誤差は `O(m^-2)`。

## 独立検証と適用範囲

`verify.py` は物理的な行ビット集合を全て直接列挙して各局面の不足石数・合法手数を数え、別実装の多項式畳み込みと全係数を照合する。`w=1..4,m=1..5,r=1..5` のうち `wm<=16` の**95条件、延べ317,253安全局面**で一致。閉公式・厳密平均不等式も全条件で照合した。

例えば `w=3,m=8,r=4` では `W=2,143,936, L=2,186,811`、勝ち局面の合法手総数 `20,698,992`、負け局面 `20,110,992`。条件付き平均はそれぞれ約 `9.65467`, `9.19649`。

この証明は「各行容量以外に禁止集合がない」という仮定に依存する。固定幅版への適用は、例えば既存 K0025 の `q>2w` 領域、K0072 の分離領域、その他幾何的に独立行へ帰着できることが証明済みの領域に限る。行をまたぐ共円禁止が残る一般の `w×m` には適用しない。
