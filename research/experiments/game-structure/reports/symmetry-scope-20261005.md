## 1. 奇数 q だけでは任意の遺伝的配置ゲームへ延長できない

K0304 の旧本文は「遺伝的な q 点禁止配置ゲーム」と書いていた。しかし既存の証明資料
`q48-odd-q-reflection.md` は、有限平面点集合の円・直線禁止ゲームを証明している。
その証明には「鏡像二点を含む円・直線は鏡映不変」という幾何学的条件が必要である。
この範囲の取り違えを修正する。元の幾何定理は反証されていない。

**反例族。** 奇数 q≥3 を任意に取り、頂点集合 V={0,…,q}、対合 τ(i)=i xor 1 とする。
禁止 q 点集合を二つだけ設ける:

\[
 E_2=V\setminus\{2\},\qquad E_3=V\setminus\{3\}.
\]

τ は固定点を持たず、E₂ と E₃ を交換するのでルールを保つ。頂点を鏡映軸の両側に
対として置けば、この対合を実際の平面鏡映として実現することもできる。ただし禁止辺は
幾何学的な円・直線から指定したものではなく、任意の禁止族である。

安全集合 S=V\{0,1} は τ 不変で q−1 点を持つ。追加点0、1は共に合法だが、
両方を追加すると V になって禁止辺を含む。一点追加後は終端だから

\[
g(S)=\operatorname{mex}\{0\}=1.
\]

従って「奇数 q・固定点なし・ルールを保つ対合・対称な安全局面」だけでは P を保証しない。
この反例族は q+1 頂点であり最小である。固定点なし対合の頂点数は偶数なので、q 以下なら
高々 q−1 頂点となり、禁止 q 点集合自体が存在しない。対称局面の残り点数は偶数で、その
自由追加ゲームは P だからである。

**空盤も N。** 先手が2を選ぶと、E₃の残り q−1 点の全占有が禁止され、E₂はその禁止条件に
包含されるので冗長になる。以後どの極大継続も総石数 q となり、q が奇数なので先手が勝つ。
実際の値 g(∅)=1 も次の縮約再帰で証明できる。R=V\{2,3} の残り点数を a、{2,3} の
占有数を b とする。b=1,2 では残り手数がそれぞれ a、a−1 に固定されるので値は各偶奇。
b=0 では a=0 で0、a=1で2、a≥2では a偶数で1、a奇数で0となることが一段再帰から帰納できる。
空盤では a=q−1 が偶数である。

独立検算は q=3,5,7,9 の全安全集合それぞれ13、61、253、1021個について、ビットマスク mex
再帰と集合による層別 P/N 再帰を照合している。一般反証の根拠は上記の構成と証明であり、
有限四例から奇数 q 全体を推測していない。

## 2. 鏡映戦略を保証する抽象的な十分条件

有限頂点集合 V 上の「ブロック」族 C を考える。各ブロックに q 点が占有されることを禁じる。
固定点なし対合 τ が V とブロック族を保ち、さらに次を満たすとする:

> あるブロック B が p と τ(p) の両方を含むなら、τ(B)=B。

q が奇数なら、任意の対称安全集合 S は P である。

*証明。* 合法 p の応手 τ(p) が初めてブロック B を満たすと仮定する。B が p を含まなければ、
τ(B) が S∪{p} に既に q 点を持ってしまう。B が両方を含めば B は τ 不変であり、S∩B は
偶数点である。応手後に初めて q 点へ達するには応手前が q−1 点、S∩B が q−2 点でなければ
ならないが、後者は奇数なので矛盾する。応手後は再び対称安全局面となり、有限性により後手が勝つ。□

平面の円・直線族はこの条件を満たす。円なら鏡像二点を結ぶ弦の垂直二等分線が鏡映軸なので
中心が鏡映軸上にあり、直線なら鏡像二点を結ぶ線自体が鏡映不変となる。
この十分条件は q 点一様ハイパーグラフの対合不変性より強い。上の二禁止辺の族はこれを満たさない。

## 3. 標準正方形盤の高対称安全集合は高々五石

以下は標準 q=4・円と直線の両方を禁止する B_n 上の結果である。D4 は盤中心を固定する
八つの正方形対称操作の抽象群とし、n=1でもその八要素を数える。
S の安定化群の位数が4以上である安全集合を完全に分類する。

**分類定理。** 非空かつ中心一点ではない高対称安全集合は、次のどちらかに限られる:

- 中心を通る水平・垂直二軸上の反対点対を、各軸から高々一対ずつ選ぶ。
- 中心を通る二対角線上の反対点対を、各軸から高々一対ずつ選ぶ。

n が奇数なら中心を追加してもしなくてもよい。同じ中心距離の二点対を両軸から同時に選ぶことは
できない。n が偶数の場合、水平・垂直軸は格子点を通らないので前者は空集合だけになる。
上記条件を満たす全ての集合は安全であり、中心以外の点を含むものの安定化群は正確に位数4である。

*証明。* D4 の位数4以上の部分群は、四分回転群 C4、軸二鏡映の Klein 四元群、対角二鏡映の
Klein 四元群、D4 の四つである。C4 が含まれる場合、中心以外の点の回転軌道には同一円上の
四点があるため、その軌道を安全集合に含められない。従って S は空または中心一点。

Klein 群の場合、二鏡映軸の外の点は四点軌道となり、各点の中心距離が同じなので四点共円である。
軸上の非中心点は反対点の二点軌道。各軸から二対以上を選べば四点共線になる。両軸で一対ずつを
選んだ四点が共円になる必要十分条件は、二対の中心距離が一致することである。これ以外の四点組は、
中心を含む場合は三点共線かつ残る一点が線外にあるので円にも直線にも載らない。
従って記載した条件は必要十分である。□

**正確な個数。** n=2t+1 では各軸の距離選択が t 種類で、向き一種あたり中心なしの選択数は
1+2t+t(t−1)=t²+t+1。中心の有無で倍にし、二向きの共通集合である空・中心を除くと

\[
N_{\ge4}(n)=4(t^2+t+1)-2=n^2+1 \qquad(n\text{ 奇数}).
\]

n=2t では対角二軸の t 種類の半整数距離だけが使えるので

\[
N_{\ge4}(n)=t^2+t+1=n^2/4+n/2+1 \qquad(n\text{ 偶数}).
\]

特に高対称安全集合の最大石数は奇数 n≥5で5、偶数 n≥4で4。それ以外の安全集合の安定化群は
高々位数2なので、全着手軌道はサイズ1か2である。

**K0186 への帰結と限界。** g=h≥3 の局面で小さい勝ち手軌道がない可能性を調べるには、
各 n の上記 O(n²) 個だけを調べればよい。全安全集合の列挙は不要である。ただし各候補の g,h を
求める残余ゲームは依然大きくなり得る。今回この無界全称命題は決着していない。

五石の高対称集合は中心と両軸の二点対を含むため、両軸はそれぞれ三石で満ちている。
小軌道点は中心またはその二軸上だけなので、全て占有済みまたは四点共線を作る違法点である。
従ってこの族にはサイズ1/2の合法手自体がない。K0186 はこの族について g=h≥3 が起きないことを
必要とする。これは単なる「勝ち手が軌道上にある」という対称性論だけでは解けない境界である。
