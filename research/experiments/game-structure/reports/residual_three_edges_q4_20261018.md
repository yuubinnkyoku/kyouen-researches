# 残余禁止集合が高々3個・各4点以下ならGrundy値は3以下（2026-10-18）

## 定理（全称・有限型の完全列挙による計算機支援証明）

有限集合 `B` 上で石を1点ずつ追加し、与えられた禁止集合を完成させる手を合法手から除く通常プレイを考える。任意の安全局面 `S` で、残余禁止集合を包含関係で極小化し、その集合族を `H` とする。

**`H` が高々3集合からなり、各集合の大きさが1〜4なら、その局面のGrundy値は必ず0,1,2,3のいずれかである。** 禁止集合がない場合も自由点数の偶奇で0か1となる。

とくに標準の4点共円・共線ゲームでは、残余の極小禁止集合が3個以下の局面を、**禁止集合に属する高々12点上の `2^12=4096` 状態の完全再帰**と、それ以外の自由点数の偶奇で厳密に解ける。これは元の盤面が11×11以上でも成り立つ。ただし実際の11×11探索での出現頻度・高速化は未測定。

上限3は鋭い。例えば8点上の禁止4点組

```
{0,2,3,7}, {1,2,3,7}, {4,5,6,7}
```

の空盤は `g=3` である。

## 全称性の根拠

禁止集合に現れない自由点 `Z` は独立な単点ゲームであり、そのGrundy値は `|Z| mod 2`。Sprague–Grundyの直和定理により、禁止集合が使う点だけの値とのXORで合成できる。`g_core<=3` なら `g_core XOR (|Z| mod 2)<=3` である。

禁止集合数 `k=1,2,3` とし、各点がどの禁止集合に属するかを非空のビット集合 `t in {1,...,2^k-1}` で分類する。同じ `t` の点は区別する必要がない。各型の個数 `c_t` は0〜4の整数であり、禁止集合 `i` のサイズは

```
size(i) = sum(c_t for t if t & (1<<i))
```

である。極小禁止集合は互いに包含しないので、任意の異なる `i,j` について `i` に属し `j` に属さない型の点が少なくとも1個必要である。これらの条件は必要十分。`k=3` では `5^7=78,125` 個の候補ベクトルを走査するだけで、すべての有限盤の該当残余ゲームを網羅する。

各 `c` について残点数ベクトル `r=(r_t)` に対し、禁止集合が完成しない状態だけを許し、

```
G(r) = mex { G(r-e_t) : r_t>0 and r-e_t is safe }
```

を残点数昇順に評価する。元の盤面での全安全局面は、ある `r` に一意に対応する。`r` の範囲は各成分0〜`c_t` なので有限であり、各 `G(r)` の再帰は必ず総残点数を減らす。この再帰と完全な型列挙が証明書であり、未探索の盤面サイズはない。

## 完全列挙の結果

| 極小禁止集合数 | 型数（集合に番号あり） | 集合番号の交換も同一視 | 全安全局面の最大Grundy |
|---:|---:|---:|---:|
| 0 | — | — | 1 |
| 1 | 4 | 4 | 1 |
| 2 | 30 | 20 | 3 |
| 3 | 641 | 167 | **3** |

`k=3` の641型について、空盤Grundy値の分布は `g=0:262, g=1:258, g=2:61, g=3:60`。各型の全安全局面に現れる最大Grundy値の分布は `0:1, 1:263, 2:24, 3:353`。すべての禁止集合が**ちょうど4点**の場合は番号付き68型、番号交換同一視25型。

## 独立検証

1. `residual_three_edges_q4_20261018.py`: 7種類までの残点数ベクトル上でメモ化再帰。全 `r` を検査し、641型を含む `k<=3` の675型を分類。自由点は直和として扱う。
2. `residual_three_edges_q4_independent.cpp`: 型ごとに各点を独立したビットに展開し、最大12点の全 `2^n` 部分集合を逆順に走査して直接mexを計算。Pythonと全分類度数が一致。

両者とも、`k=1` は4型、`k=2` は30型、`k=3` は641型で、各型の空盤値と全安全局面最大値の度数が完全一致した。検証コードと機械可読な出力を保存した。

## 適用限界を示す反例

各禁止集合が4点以下という条件は外せない。次の7点上の3集合はサイズが4,5,5で、空盤 `g=4`：

```
{1,3,5,6}, {0,1,4,5,6}, {2,3,4,5,6}
```

初手後のGrundy値は点0〜6の順に `3,1,3,1,2,0,0` となり、mexは4。さらに8点上のサイズ4,5,6の3集合

```
{1,4,6,7}, {0,1,5,6,7}, {2,3,4,5,6,7}
```

では初手後の値が `2,0,4,4,0,3,1,1` となり、空盤 `g=5`。いずれも直接部分集合mexで独立に再計算可能。**禁止集合数3だけではGrundy値3以下を主張できない。**

この定理は抽象的な残余集合ゲームの定理であり、上の鋭さの例が実際の格子円・直線として実現できるとは主張しない。
