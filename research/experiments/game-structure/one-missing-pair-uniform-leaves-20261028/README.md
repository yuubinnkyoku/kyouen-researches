# 二点型が一組だけ欠けた分割グラフのGrundy数（2026-10-28）

## 定理：葉数の偶奇に依存する周期4

通常プレイの二点禁止ゲーム（Node Kayles）を考える。$m\ge2$ 頂点のクリーク $C=\{a,b,c_1,\ldots,c_{m-2}\}$ の各二点組、**ただし $\{a,b\}$ を除く**、にちょうど1個の独立点を接続する。さらにクリーク各頂点に一様に $t\ge0$ 個の私有葉を付ける。独立側に辺はない。このグラフを $H_{m,t}$ とする。

**全称定理：** $p=t\bmod2$ とすると

$$
\boxed{g(H_{m,t})=\begin{cases}
1-p,&m=2,\\
3,&m\ge3,\ m\equiv0\pmod4,\\
3-p,&m\ge3,\ m\equiv1\pmod4,\\
2,&m\ge3,\ m\equiv2\pmod4,\\
2+p,&m\ge3,\ m\equiv3\pmod4.
\end{cases}}
$$

特に **$m\ge3$ なら $g\in\{2,3\}$ で必ず先手必勝**。勝ち初手はクリーク頂点だけで選べる。特別頂点 $a,b$ を選んだ子の値は

$$
A_s=\left(\binom{m-1}{2}+(m-1)t\right)\bmod2,
$$

通常頂点 $c_i$ を選んだ子は $A_r=A_s\oplus1$。ゆえに $A_s=0$ なら $a$、$A_s=1$ なら任意の $c_i$ が勝ち手。

これは[全二点型・偶奇混在の閉形式](../complete-mixed-pair-incidence-20261028/README.md)を、ちょうど一組の二点型が欠けた別の族へ拡張した結果である。ただし二点型の個数は本定理では各1個、葉数は一様に限定する。

## 全称証明

$h(m,t)=g(H_{m,t})$ と書く。$m\ge7$ とし、$m-1,m-2$ において閉形式が成立すると仮定する。初手は次の六種類に尽きる。$[x]_2=x\bmod2$ とする。

| 初手 | 子のGrundy値 |
|---|---|
| 特別クリーク頂点 | $A_s=[\binom{m-1}{2}+(m-1)t]_2$ |
| 通常クリーク頂点 | $A_r=A_s\oplus1$ |
| 通常頂点どうしの二点型 | $B_{rr}=h(m-2,t+2)$ |
| 通常頂点の葉（$t>0$） | $B_{rl}=h(m-1,t+1)\oplus[t-1]_2$ |
| 特別頂点と通常頂点の二点型 | $B_{sr}=2+[(m-2)t+1+\binom{m-2}{2}]_2$ |
| 特別頂点の葉（$t>0$） | $B_{sl}=(2+[(m-1)t+(m-2)+\binom{m-1}{2}]_2)\oplus[t-1]_2$ |

説明：クリーク頂点を選ぶと全クリークが消え、残る独立点は孤立点になる。特別頂点と通常頂点の子では、欠けた $ab$ 型がちょうど1個だけ非隣接側にあるため、残る孤立点の偶奇が反転する。

通常頂点の葉を選ぶと、その通常頂点が消え、残る各クリーク頂点の葉が1枚増え、元の葉 $t-1$ 枚は孤立する。通常どうしの二点型なら通常頂点2個が消え、残る各クリーク頂点の葉が2枚増え、元の葉 $2t$ 枚が孤立する。

特別頂点を含む葉または二点型を選ぶと、欠けた $ab$ 型が消え、残存クリークの**全ての二点型が存在**する。前者では残存特別頂点の葉数が $t$、通常頂点が $t+1$、後者ではそれぞれ $t+1,t+2$ となる。葉の偶奇が混在するため、既存の[全二点型定理](../complete-mixed-pair-incidence-20261028/README.md)の $g=2+u$ を使って最後の二式を得る。孤立点の寄与はxorで合成する。

$\binom n2\bmod2$ は $n\bmod4$ のみで決まる。帰納仮定を四つの $B$ に代入すると、存在する全ての $B$ が**同一の値2または3**になる。

| $m\bmod4$ | $t$ 偶数時の $B$ | $t$ 奇数時の $B$ | $g$（偶数 / 奇数） |
|---:|---:|---:|---:|
| 0 | 2 | 2 | 3 / 3 |
| 1 | 2 | 3 | 3 / 2 |
| 2 | 3 | 3 | 2 / 2 |
| 3 | 3 | 2 | 2 / 3 |

$t=0$ のとき葉初手は存在しないが、残る二点型初手の値は表と一致する。$A_s,A_r$ は必ず $0,1$ の両方を含むので、全子値集合は $\{0,1,B\}$。そのmexは $B=2$ なら3、$B=3$ なら2。これで $m\ge7$ の帰納段階を証明した。

### 有限基底

$m=2,3,4,5,6$ は直接再帰で検証する。各クリーク頂点に付いた私有葉は、同じ非空linkを持つ独立双子点なので、[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により任意の $t\ge0$ を $t=0,1,2$ のいずれかに厳密に圧縮できる。

| $m$ | $t=0$ | $t=1$ | $t=2$ |
|---:|---:|---:|---:|
| 2 | 1 | 0 | 1 |
| 3 | 2 | 3 | 2 |
| 4 | 3 | 3 | 3 |
| 5 | 3 | 2 | 3 |
| 6 | 2 | 2 | 2 |

15組すべてをクリーク生存部分集合の厳密再帰で完全検査し、うち14組は名前付き全頂点の閉近傍削除による**別方式**でも一致した。$m=6,t=2$ は名前付き全頂点再帰が非常に大きいため、別方式照合は未実施。追加で $m=7,t=0$ を名前付き全頂点再帰で検証した。したがって証拠水準は **数学的帰納法＋有限基底の計算機援用証明** であり、単なる周期の数値観測ではない。
