# 偶数個ずつの独立双子点を持つ分割グラフのGrundy閉形式（2026-10-27）

## 新しい全称定理

二点残余禁止ゲーム（Node Kayles：頂点を選び、その閉近傍を消す通常プレイ）を考える。有限単純グラフ G を、空でないクリーク C と独立集合 I に分割する。各 v∈I の **クリーク内近傍** を署名 s(v)=N(v)∩C と呼ぶ。

**仮定：空でない署名 s⊆C は、すべて0個または正の偶数個だけ出現する。** 空署名（孤立点）は f 個でよい。クリークの大きさ、独立点の次数、偶数個の具体的な個数には上限を設けない。

このとき、全グラフのGrundy値は

$$
\boxed{g(G)=
\begin{cases}
2\mathbin{\mathrm{xor}}(f\bmod2),&
\text{署名 }s=C\text{ が出現する},\\
1\mathbin{\mathrm{xor}}(f\bmod2),&
\text{それ以外}
\end{cases}}
$$

である。特に **|C|≥3 かつ各独立点のクリーク内次数が高々2** なら、非孤立署名が全て偶数個ずつである限り

$$g(G)=1\mathbin{\mathrm{xor}}(f\bmod2).$$

孤立点がなければ、頂点数に関係なく **常に g=1（先手勝ち）** となる。これは既存の次数2分割グラフの g=4,5 証人とは矛盾しない。両証人には奇数個出現する署名がある。

## 計算に依存しない数学的証明

任意の X⊆C に対して H_X を、X と、独立点のうち s(v)∩X≠∅ のものだけからなる誘導部分グラフとし、h(X)=g(H_X) とする。H_X の各非空署名の多重度も偶数である。空集合について h(∅)=0。

**主張：任意の非空 X⊆C について、X を含む元の非空署名が存在するとき h(X)=2、存在しないとき h(X)=1。** |X| に関する帰納法で証明する。

- クリーク点 c∈X を選ぶと、クリークは全て消える。残る独立点は各署名型ごとに0個または偶数個で、すべて孤立点である。従って、この手の子局面のGrundy値は **0**。
- 独立点 v（署名 s、s∩X≠∅）を選ぶと、残るクリークは Y=X\s となる。H_Y に含まれない独立点は孤立する。各署名型の個数は偶数だが、選んだ v だけが消えているので、孤立点の合計は **奇数**。従って子局面の値は **h(Y) xor 1**。
- Y=∅ となるのは X⊆s の場合に限り、このとき子値は 0 xor 1=**1**。
- Y≠∅ なら帰納法で h(Y)∈{1,2} なので、子値は **0 または3**。

以上から、全初手後の値集合は常に0を含み、1を含むのは X⊆s となる署名が出現するときに限る。ほかに現れうるのは3だけであり、2は現れない。従って mex はそれぞれ2または1で、帰納法が閉じる。

X=C として孤立点を除いた公式を得る。元の孤立点 f 個は独立成分で、Grundy値 f mod 2 を xor すれば全体の公式となる。証明終わり。

**注意：** 署名型が偶数個ずつという仮定は、同じ型を2個に圧縮できるという既存の独立双子点の定理（K0336）と整合するが、この証明では多重度の偶奇を直接用いている。クリーク点の手で残る偶数個の孤立点と、独立点の手で残る奇数個の孤立点の差が核心である。

## 独立検証

[verify.py](verify.py) は、上の H_X の再帰を実装せず、**個々の名前付き頂点の隣接ビット集合を作り、閉近傍を削除する別のGrundy再帰**で公式を検査する。孤立点は再帰内で別成分として xor する。各署名型は0個または2個とし、さらに自由な孤立点数 f=0,1 を両方調べた。

| 範囲 | 署名構成数 | f込みの検査数 | 判定 |
|---|---:|---:|---|
| |C|=1,2,3、全非空署名の全選択 | 2+8+128=138 | 276 | 全一致 |
| |C|=4、次数1または2の全署名の全選択 | 1,024 | 2,048 | 全一致 |
| |C|=4,5,6、全次数の固定乱数標本 | 120+80+30=230 | 460 | 全一致 |
| **合計** | **1,392** | **2,784** | **不一致0** |

乱数標本では最大5種類の署名を選び、各2個とした。境界検査として、クリーク1点に葉を1個付けると g=1、同じ葉を2個付けると g=2 となり、偶数仮定を落とせないことも確認した。

再現：

    python3 research/experiments/game-structure/split-even-twin-signatures-20261027/verify.py

完全列挙の主張は上表の有限範囲に限る。無界の定理は上の数学的帰納法で証明されており、有限検査からの外挿ではない。

## 適用境界・次の問い

これは **抽象的な二点禁止競合グラフ** の定理である。標準整数格子の共円ゲームでは、残余の全極小禁止集合が二点であり、かつ競合グラフに上記の分割と署名偶数性がある局面だけに適用できる。三点以上の極小残余禁止集合がある局面、misère、終局石数には適用しない。実際の11×11探索での出現率・速度効果は未測定。

次数2分割グラフで署名偶数性を外したときに g=6 以上を実現できるかは未解決のまま。この結果は偶数署名という大きな部分族を閉形式で解決するが、一般族の一様上界は主張しない。
