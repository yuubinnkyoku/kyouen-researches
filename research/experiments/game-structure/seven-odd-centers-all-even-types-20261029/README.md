# 7奇数中心・全21種類の偶数二点型の消去（2026-10-29）

## 定理（数学的縮約＋有限完全列挙）

通常プレイの抽象 Node Kayles 分割グラフを考える。7個の中心はクリークをなし、各中心には任意の**正の奇数**枚の私有葉がある。中心対 `ij` の両端にだけ隣接する独立点の枚数 `c_ij` は任意の非負整数とし、それ以外の頂点・辺はない。

`c_ij` が奇数である中心対を辺とする単純グラフ `P` を作る。このとき

```
g(G) = g(G_P) <= 3.
```

ここで `G_P` は各中心に私有葉1枚を持ち、`P` の各辺に二点型1枚を持つグラフ。**正の偶数二点型は種類数の制限なく、すべて0枚に置き換えてよい。** 7中心について前回残った「7種類以上」の穴がなくなった。

`P` の1,044同型類の値分布は `g=0,1,2,3` が順に `27,27,495,495`（先行研究による全分類）。

## 証明の有限化

1. [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) の全称補題により、各私有葉は1枚、各奇数二点型は1枚、各正の偶数二点型は2枚に縮約できる。**2枚から0枚への消去はK0336では証明されない**。
2. 7中心の21対について、三値（0,1,2）の割当を考える。奇数二点型（値1）からなる単純グラフ `P` の全 `2^21` ラベル付き構成を、隣接頂点交換が生成する `S_7` の軌道で1,044代表へ分ける。
3. 各代表 `P` の非辺の**すべての部分集合**を偶数二点型（値2）に置く。奇数対と偶数対は重ならない。したがって、任意の三値割当は代表のいずれかに置換同型で移り、漏れがない。
4. 各代表と偶数対の選択について、近傍型の個数を用いる mex 再帰で `g(G)=g(G_P)` を完全照合した。各 `d` を独立実行してメモリを解放する。

## 独立検証

別実装 `verify_named_samples.cpp` は、各構成を**最大56個の名前付き頂点**の隣接ビット集合で構築し、閉近傍削除を直接再帰する。孤立頂点だけを xor の偶奇で除く。各奇数グラフ代表・各 d について、辞書順の最初と以後200件ごとの偶数対選択を照合した。7–21種類で**51,363構成、不一致0**。

これは有限完全列挙器と異なる局面表現による独立標本照合であり、**新規9,576,220構成すべての独立再計算ではない**。完全列挙の健全性は `verify_quotient.cpp` の実装と軌道生成に依存する。全称性はK0336と有限全被覆の組合せに依存し、単なる有限標本の外挿ではない。

## 再現

リポジトリ直下から：

```sh
g++ -O3 -std=c++17 research/experiments/game-structure/seven-odd-centers-all-even-types-20261029/verify_quotient.cpp -o /tmp/seven-quotient-all
for d in $(seq 7 21); do /tmp/seven-quotient-all "$d" || exit 1; done

g++ -O3 -std=c++17 research/experiments/game-structure/seven-odd-centers-all-even-types-20261029/verify_named_samples.cpp -o /tmp/seven-named-all
/tmp/seven-named-all
```

dをまとめて同一プロセスで処理するとメモリが増えるため、完全列挙器は1回につき1つのdを検査する。件数不一致・Grundy不一致は非零終了。

## 限界

7中心のこの**抽象分割グラフ族**についての全称定理であり、一般の分割グラフ、8中心以上、偶数または0枚の私有葉、3中心以上に接続する独立点、整数格子上での実現可能性を含まない。11×11空盤勝敗には直結しない。
