# 5中心・偶数三点型消去：他の近傍型が6種類以下なら偶数型の共存を許す（2026-10-29）

## 新しい計算機援用の限定全称定理

抽象分割グラフの通常 Node Kayles を考える。中心 `C={0,1,2,3,4}` はクリークで、各中心に正の奇数枚の私有葉がある。独立側の残りの点は、中心の2点以上からなる任意の非空近傍型に接続し、同じ型の重複数は任意の非負整数とする。孤立点は含めない（あれば独立成分として xor する）。

任意の三点型 `T` を固定し、**T以外に正の重複数を持つ非私有近傍型が高々6種類**であるとする。このとき、T型の独立点を**2枚追加してもGrundy数は変化しない**。T以外の型には奇数重複も正の偶数重複も自由に共存できる。各型の重複数には上限を設けない。

この主張は中心数5に限定される。中心数6以上、T以外が7種類以上、私有葉0枚または偶数枚、整数格子での実現可能性は主張しない。

## 無限族から有限基底への厳密な還元

既存の [K0336：同一linkの独立双子点の正の偶奇圧縮](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、各私有葉の正の奇数枚は1枚へ、T以外の各型の正の奇数枚は1枚へ、正の偶数枚は2枚へ縮約できる。Tが元から正の個数で存在するなら、2枚追加はK0336だけで不変である。したがって**Tが0枚から2枚になる場合だけ**を調べればよい。

中心の置換対称性によりTをビット集合 `0b00111` に固定できる。中心の大きさ2以上の型は `2^5-1-5=26` 種類、T以外は25種類。うち0〜6種類を選び、各型の重複数を1または2にする全基底数は

$$
\sum_{j=0}^{6}\binom{25}{j}2^j=13\,256\,611.
$$

全基底について、Tを0枚と2枚にしたGrundy数を**厳密なmex再帰**で比較した。対称性による代表間引きは行っていない。

| T以外の正の型数 | 基底数 | 不一致 |
| ---: | ---: | ---: |
| 0 | 1 | 0 |
| 1 | 50 | 0 |
| 2 | 1,200 | 0 |
| 3 | 18,400 | 0 |
| 4 | 202,400 | 0 |
| 5 | 1,700,160 | 0 |
| 6 | 11,334,400 | 0 |
| **合計** | **13,256,611** | **0** |

Tが0枚の場合のGrundy数分布は `g=0,1,2,3` の順に **333,204 / 487,448 / 6,315,363 / 6,120,596** であり、この有限基底では4以上は出なかった。Tが0枚と2枚の場合は値が一致する。ただし、Tが奇数枚のケースの値域はこの表から主張しない。

## 検証器の再帰と独立検証

[verify.cpp](verify.cpp) は生存する中心の部分集合 `R`（最大31個の非空状態）を使う。型Sの個数を `a[S]` とし、`p(R)=sum_{S∩R≠∅} a[S] mod 2`、`d(c)=sum_{S∋c}a[S] mod 2` とする。`h(∅)=0`、`R≠∅` について、中心cを選ぶ子の値は `p(R) xor d(c)`、Rに交わる独立型Sを選ぶ子の値は

$$
h(R\setminus S)\ \mathrm{xor}\ \bigl(p(R)\ \mathrm{xor}\ p(R\setminus S)\ \mathrm{xor}\ 1\bigr).
$$

後者の括弧は、中心が消えたため孤立した独立点の個数から、選んだ1点を差し引いた偶奇である。中心を選ぶと他の中心はすべて消え、残る非隣接の独立点だけが孤立する。独立型を選ぶとRは真に小さくなるので、この再帰は通常 Node Kayles の閉近傍削除と同値であり、有限の部分集合順序で全状態を計算できる。

独立の [verify_independent.py](verify_independent.py) は**名前付き頂点をすべて生成し、閉近傍を直接削除**する方式で、型0・1種類の全51基底と、型2〜6種類から固定乱数種で各35基底、合計226基底を追加前後それぞれ照合した。不一致は0。独立方式は**標本照合**であり、13,256,611基底の全件独立照合ではない。有限基底の全称性はK0336とC++の全列挙に依存する。

再現（リポジトリ直下）：

```sh
c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/five-even-triple-mixed-six-types-20261029/verify.cpp -o /tmp/five-triple
/tmp/five-triple
python3 research/experiments/game-structure/five-even-triple-mixed-six-types-20261029/verify_independent.py
```

局所実行結果：C++ 13,256,611基底・不一致0（約20秒）、Python 226基底・不一致0（約10秒）。全体CI・knowledge正本の更新・生成索引の再構築は未実施。

## 先行結果との差分と残る問題

[先行する5中心の限定定理](../even-triple-support-bounded-orbits-20261029/README.md) は、T以外の正の型を奇数重複に限り、7種類以下を扱っていた。今回は種類数を6以下とする代わりに、**ほかの偶数近傍型が同時に存在してよい**という新しい範囲を完全検査した。[4中心の全偶数型分類](../four-odd-centers-even-support-complete-20261029/README.md) とも矛盾しない。

最も直接的な次の課題は、5中心でT以外が7種類以上、かつ他の偶数型が共存する場合に反例が存在するか、または種類数制限を外す一般証明ができるかである。これは抽象分割グラフの結果で、11×11の勝敗を確定するものではない。
