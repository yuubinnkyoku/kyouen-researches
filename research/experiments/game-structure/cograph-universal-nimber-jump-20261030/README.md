# 全域頂点1個によるGrundy数の無界ジャンプ：コグラフの明示構成（2026-10-30）

## 全称定理（数学的証明）

有限単純グラフ上の通常プレイ Node Kayles を考え、`g(G)` をGrundy数、`O(G)={g(G-N[v]):v∈V(G)}` を初手後のGrundy数の集合とする。`⊔` は非交和、`∨` は完全結合（両側の全頂点間に辺を追加）を表す。`K1` は1頂点グラフ。

**任意の有限グラフ G と c≥1 に対して**

`O(G∨K_c)=O(G)∪{0}`。

したがって `g(G)>0` なら `g(G∨K_c)=g(G)`。`g(G)=0` なら `g(G∨K_c)=min{j≥1:j∉O(G)}`。特に全域頂点を追加してGrundy数が減ることはない。

**さらに、その増加幅に一様な上界は存在しない。** 具体的には、任意の整数 p≥0 に対して `3^p−1` 頂点のコグラフ `B_p` と `3^p` 頂点のコグラフ `A_p=B_p∨K1` が存在し、

```
O(B_p) = {1,2,...,2^p−1},  g(B_p)=0,
O(A_p) = {0,1,...,2^p−1},  g(A_p)=2^p.
```

従って **たった1頂点を追加して `0→2^p`** と変わる。ここで `p=0` の `B_0` は空グラフとし、空集合の範囲は空集合と解釈する。コグラフとは `K1` から非交和と完全結合を有限回繰り返して作るグラフである。

## 証明（有限実験には依存しない）

`mex` を非負整数の最小欠番とする。Node Kayles の定義から `g(G)=mex O(G)` である。初手をどちらの成分で打つかで場合分けすると

```
O(G∨H) = O(G) ∪ O(H),
O(G⊔H) = {x xor g(H):x∈O(G)} ∪ {g(G) xor y:y∈O(H)}.
```

完全結合の場合は一方で着手すると他方が全て消え、非交和の場合は着手しなかった成分が残るためである。`O(K1)={0}` なので、冒頭の全域追加則が従う。

構成は `A_0=K1, B_0=∅` から始め、次の式で帰納的に定める。

```
D_p = A_p ⊔ A_p,
B_(p+1) = B_p ∨ D_p,
A_(p+1) = B_(p+1) ∨ K1.
```

帰納法の仮定で `g(A_p)=2^p`、`O(A_p)={0,...,2^p−1}` なら、非交和の公式から

```
g(D_p)=2^p xor 2^p=0,
O(D_p)={2^p,...,2^(p+1)−1}.
```

`B_p` の初手値は `1,...,2^p−1` なので、完全結合の公式により `O(B_(p+1))={1,...,2^(p+1)−1}`、従って `g(B_(p+1))=0`。最後に `K1` と完全結合すると初手値0が加わり `g(A_(p+1))=2^(p+1)`。`p=0` は `B_0` が空、`A_0=K1` なので成立する。頂点数は `|A_(p+1)|=3|A_p|`、`|B_p|=|A_p|−1` であり、`|A_p|=3^p` となる。すべての構成がコグラフであることも帰納法で従う。

**注意:** この構成は「最小頂点数でGrundy値を実現する」ものではない。既存の最小頂点数研究と競合せず、全域頂点1個による変化の無界性を証明する。
