# 二点禁止残局：閉路のGrundy値の完全周期分類

2026-10-19。**抽象的な二点禁止集合ゲーム**に関する計算機援用全称証明。
標準正方形盤に任意の閉路が実現することは主張しない。

## 定理

有限単純グラフの独立集合を一点ずつ増やす通常プレイを考える。
`P_n` は `n` 頂点の道（`P_0` は空グラフ）、`C_n` は `n>=3` 頂点の閉路、`g` はSprague–Grundy値とする。

1. 任意の `n>=3` で `g(C_n)=1` と `g(P_(n-3))=0` は同値。それ以外では `g(C_n)=0`。特に**閉路の値は常に0か1**。
2. 任意の `n>=38` について、

   ```text
   g(C_n)=1  <=>  n mod 34 in {7,11,23,27,31}.
   ```

   `3<=n<=37` の勝ち閉路長は正確に `{3,7,11,17,23,27,31,37}`。
3. **34は閉路Grundy列の最小最終周期、38は周期34の最小開始長**。
4. 最大次数2以下のグラフの任意の閉路成分は、直和のGrundy値へ0か1しか寄与しない。従って閉路成分群の寄与は、上記で値1となる成分数の偶奇だけで計算できる。

## 全称証明

### 閉路を打った後は必ず道

`C_n` で頂点を一つ選ぶと、その頂点と両隣が除かれ、残りは `P_(n-3)`。全合法手の子のGrundy値は同じなので、

```text
g(C_n)=mex({g(P_(n-3))})
       =1 if g(P_(n-3))==0 else 0.
```

### 道の周期34を有限計算から無限に延長する補題

`a_n=g(P_n)` とおく。`a_0=0`, `a_1=1`。`n>=2` では、両端を選ぶ手と内点を選ぶ手を区別すると、

```text
a_n=mex( {a_(n-2)} union
         {a_i xor a_(n-3-i) : 0<=i<=n-3} ).
```

**有限証明書：** この整数再帰を `n=173` まで計算し、次の88等式を全検査する。

```text
a_(n+34)=a_n  (52<=n<=139).
```

この88等式だけで `a_(n+34)=a_n` が**すべての `n>=52`**に成立する。
実際、`n>=174` で `a_n=a_(n-34)` を強い帰納法で示す。端点手の値は `a_(n-2)=a_(n-36)`。
内点手の分割は `i+j=n-3>=171`。両方が85以下なら和は170以下なので、必ず片方が86以上。その片方から34を引けば52以上の添字に留まり、帰納法によりXOR値は不変で、`n-34` の分割に写る。
逆に `n-34` の内点分割は `i+j=n-37>=137` であり、片方が52以上。その添字に34を足せば `n` の分割を得る。帰納法によりXOR値は不変。
従って双方の子Grundy値集合が一致し、mexも一致する。帰納法は有限証明書を初期区間として成立する。

### 閉路の最小開始点と最小周期

道の周期から閉路は `n>=55` で34周期となる。`38<=n<=54` の17等式 `g(C_(n+34))=g(C_n)` を上記再帰で直接確認すると、**n>=38** まで延長できる。

`38<=n<=71` の34個の値を計算すると、値1の長さの34を法とする剰余は `{7,11,23,27,31}` だけ。`g(C_37)=1` だが `g(C_71)=0` なので、周期34の開始は38より早くできない。

周期34の二値列がそれより短い最終周期も持つなら、34との最大公約数も周期となる。34の真の正約数は1,2,17であり、上記5剰余の集合はいずれの平行移動でも不変でない。よって**最小最終周期は34**。


- C++は異なる道の再帰式と `n=3..18` の全状態再帰を用いて独立に検算する。
