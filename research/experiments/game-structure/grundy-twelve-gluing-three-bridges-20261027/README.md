# Grundy値12・19頂点探索：既存8/4証人の一点接合と三本以下の橋の完全排除（2026-10-27）

## 結論と証拠の範囲

抽象二点禁止ゲーム（有限単純グラフ上の Node Kayles）について、既知の13頂点・Grundy値8の証人 `H8` と7頂点・Grundy値4の証人 `H4` を各一点で同一視して19頂点にし、**両成分の接合点以外の頂点間**に橋を0〜3本加える構成を調べた。

**有限完全列挙の結論：** 独立数 `α≥12` を保つこの構成族160,515件（ラベル付き構成、非同型類数ではない）のGrundy値は **最大10**。したがって、この構成法ではGrundy値12はもちろん11も実現しない。一般の19頂点グラフでの `g=12` の不存在は主張しない。既存の `19≤m(12)≤20` は更新されない。

## 数学的な全称補題：一点接合の独立数

グラフ `A,B` の頂点 `u,v` を同一視した一点接合 `J=A∨_{u=v}B` を考える。 `a_X^-(x)=α(X-x)`、`a_X^+(x)=1+α(X-N[x])` とすると

```
α(J)=max(a_A^-(u)+a_B^-(v), a_A^+(u)+a_B^+(v)-1).
```

証明：独立集合は接合点を含まないか、含むかの二通り。前者は両側で接合点を除く独立集合の直和、後者は両側で接合点を含む独立集合を選び、共有点を一回だけ数える。各場合の最大値を取ればよい。この補題は**任意の有限グラフ**で成立する。

橋の追加は独立数を増やせない。今回の二つの固定証人について、91通りの一点接合を直接列挙すると、`α=12` は接合点 `u∈{0,1,2,3,11}`（H8側）、`v∈{0,1,2}`（H4側）の15通りだけで、各接合には**12頂点の独立集合がちょうど一つ**ある。残り76通りは `α≤11`。さらに `g(G)≤α(G)`（既存の全称定理）から、`g=12` を狙うなら、この唯一の独立12集合の内部を結ぶ橋は追加できない。

15通りの接合のそれぞれで、両側固有の頂点間の橋候補は `12×6=72` 本。このうち唯一の独立12集合の両端を結ぶ `8×4=32` 本を除くと40本だけが残る。これらから三本以下を選ぶ構成が必要十分な検査範囲となる（この限定構成族について）。

## 有限完全列挙

```
橋の本数             0       1       2        3      合計
検査したラベル付き件数 15      600   11,700  148,200   160,515
```

全件のGrundy値0〜10の度数は順に

```
57950, 7418, 21777, 2836, 15964, 14781, 12925, 11904, 12562, 1806, 592
```

11以上は0。各値は占有していない頂点を選び閉近傍を削除するmex再帰で厳密に計算した。候補生成は40本の橋の全0〜3要素部分集合を漏れなく走査する。ラベルの違う構成が同型であっても重複除去しないため、度数は非同型グラフの度数ではない。

`verify_glued_12.cpp` は全91接合の独立12集合を直接列挙し、15接合・40橋・160,515件・上界10を検査する。独立した `verify_independent.py` は91接合の分類を別実装で再確認し、**0本・1本の全615件**を、残存集合再帰とは異なる「選択済み独立集合を増やす」再帰で再計算した。0〜1本の度数表は全件一致。**2〜3本のGrundy計算はC++単独の完全列挙であり、独立実装による全件照合は未実施**。

## 次の対象と限界

この結果は、**二つの固定証人の一点接合＋高々三本の橋**という自然な19頂点構成法を排除するだけで、`m(12)=19` を反証しない。次は別の8/4証人を使うか、四本以上の橋を許すか、19頂点で直接11を子に持つ構造を探索する。整数格子での実現・11×11空盤勝敗・実探索速度には結論を出さない。
