# 二点残余禁止グラフの頂点被覆数2：全辺数でGrundy数は3以下（2026-10-27）

## 定理（数学的全称証明）

任意の有限単純グラフ G の Node Kayles（頂点を選び、その頂点と隣接頂点を除去する通常プレイ）で、頂点被覆数 τ(G)≤2 なら

\[
\boxed{g(G)\le3}.
\]

孤立点の個数も、辺数も、頂点数も任意である。上界は鋭い。5頂点の道 P5 は g=3、また2辺の星 K_{1,2} と孤立点1個の直和も g=3 である。共円ゲームの局面に適用するには、**すべての包含極小残余禁止集合が二点集合**であり、その競合グラフが頂点被覆数2以下であることが必要。三点以上の残余禁止集合があれば適用不可。

## 任意サイズの閉形式

被覆頂点を x,y とする（被覆数が0または1なら適宜孤立頂点を追加して二頂点にできる）。その外の点は独立で、x のみに隣接する a 個、y のみに隣接する b 個、両方に隣接する c 個、どちらにも隣接しない f 個に分かれる。e=1 は xy が辺、e=0 は辺なしを表す。

S(t)=g(K_{1,t}) は t=0 または t が奇数なら1、正の偶数なら2である。孤立点を除いた核の初手の子のGrundy値集合 O は以下の値からなる（a,b,c が0なら対応する種類の手は存在しない）。

- x を選ぶ：e=1 なら b mod 2、e=0 なら S(b)。
- y を選ぶ：e=1 なら a mod 2、e=0 なら S(a)。
- a型を選ぶ（a>0）：S(b+c) xor ((a-1) mod 2)。
- b型を選ぶ（b>0）：S(a+c) xor ((b-1) mod 2)。
- c型を選ぶ（c>0）：(a+b+c-1) mod 2。

したがって任意の非負整数 a,b,c,f と e∈{0,1} について

\[
\boxed{g(G)=\operatorname{mex}(O)\ \operatorname{xor}\ (f\bmod2)}
\]

が厳密に成立する。入力の a,b,c,f の大きさに依存しない定数回の算術で計算できる。

## g≤3 の計算に依存しない証明

孤立点は xor 1 なので、核の値が0,1,2,3のいずれかなら全体も0,1,2,3のいずれかである。核の初手の子の値は上の式から最大3。mexが4以上になるには子の値として0,1,2,3がすべて現れる必要がある。

子の値3は a型か b型からしか生じない。対称性により a型から3が生じると仮定すると、**a は正の偶数、b+c は正の偶数**である。

- e=0 のとき、x,yの手はS(b),S(a)∈{1,2}。c型の手は、存在すれば (a+b+c-1) mod2=1。b型は、bが奇数なら S(a+c)≥1、bが正の偶数なら cも偶数で S(a+c) xor 1 = 2 xor 1 = 3。ゆえに**値0の子が存在しない**。
- e=1 のとき、x,y,c型の手の値は0または1。b型は、bが奇数ならcも奇数で S(a+c)=1、bが正の偶数ならcも偶数で S(a+c) xor 1=3。a型は仮定により3。ゆえに**値2の子が存在しない**。

いずれも子の値0,1,2,3は揃わず、mex≤3。これは有限列挙ではなく、任意の a,b,c,f に対する全称証明である。
