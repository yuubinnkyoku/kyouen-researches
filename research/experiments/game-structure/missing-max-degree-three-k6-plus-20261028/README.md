# 欠損最大次数3の鋭い全称境界：k≥6（2026-10-28）

## 結論

通常プレイのNode Kaylesを、クリーク `C={c_0,...,c_{k-1}}` と、クリークの1点または2点にのみ隣接する独立点からなる分割グラフで考える。私有葉数を `t_i≥0`、二点型の重複数を `r_ij≥0`、欠損グラフを `D={{i,j}:r_ij=0}` とする。独立側の孤立点は含めない（あればその個数の偶奇を最後にxorする）。

**全称定理：`k≥6` かつ `Δ(D)≤3` なら、任意の非負整数 `t_i,r_ij` に対して**

```text
u   = (sum_i t_i + sum_{i<j} r_ij) mod 2
z_i = (t_i + sum_{j≠i} r_ij) mod 2
g(G) = 1 xor u xor z_0    (全z_iが等しい)
g(G) = 2 + u              (z_iが混在)
```

**特に `g(G)≤3`。** 欠損数自体は無界でよく、例えば大きな3-正則欠損グラフも含む。従来の「欠損がK4の内部に収まる」定理を真に拡張する。**`k≥6` は鋭い**：既存のk=5、`D=K4⊔K1` の13頂点反例は `Δ(D)=3` で、真の値3、公式値2。

## 証明

### 偶奇縮約

既存の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同じ非空近傍の独立点の個数は `0/正の奇数/正の偶数` の3分類に厳密に縮約できる。従って `t_i∈{0,1,2}`、`r_ij>0` なら `r_ij∈{1,2}` の全代表で有限基底を証明できる。

### k=6の有限基底

`|E(D)|≤4` は[欠損4組定理](../four-missing-pairs-k6-plus-induction-20261028/README.md)で成立する。`|E(D)|=5` は[欠損5組のk=6完全分類](../five-missing-pairs-k7-plus-induction-20261028/README.md)で、唯一の例外は5本星（欠損最大次数5）なので今回の範囲では成立する。

残る `|E(D)|≥6` かつ `Δ(D)≤3` の6頂点単純グラフを同型を除いて全列挙すると、**33同型類**。各類の全 `3^6·2^(15-|E(D)|)` 代表を、予測公式を再帰の途中で使わない厳密mexで計算した。**計8,211,456構成、不一致0**。6頂点で欠損最大次数3なら欠損数は最大9なので、これで全てのk=6構成を覆う。

### k≥7の帰納法

親の独立点数の偶奇を `u` とする。クリーク頂点 `c_i` を選んだ子値は `u xor z_i`。

独立点を選び、その隣接クリーク集合 `B`（1点または2点）を削除すると、生存クリーク頂点の `z_i` は不変。残存クリークに接続する独立点の総数偶奇を `u'`、新たに孤立した独立点の偶奇を `δ` とすれば、`δ=u xor u' xor 1`。従って残存部分に公式を適用できるとき、この初手の子値は、生存 `z` が一様 `s` なら `u xor s`、混在なら `u xor 3`。

**子局面への公式の適用：**

- `k≥8` なら、独立点初手の後もクリーク点数は6以上、欠損最大次数は3以下のまま。帰納仮定が使える。
- `k=7` で私有葉を選べば残り6点で基底が使える。二点型を選べば残り5点である。[k=5の最大欠損次数3完全分類](../missing-k4-degree-three-20261028/README.md)で公式が破れる可能性は `D'=K4⊔K1` の場合だけ。その場合、残存K4の各頂点は既に欠損次数3を使い切っているため、消した2頂点との二点型は必ず両方存在する。よって残存K4の**4頂点全てに新しい私有葉**が生じる。同じk=5分類の「K4側の少なくとも2頂点に私有葉があれば公式成立」補題が使える。

**mexの決定：** 親の `z` が一様 `s` なら、全初手の子値が `u xor s` なので `g=1 xor u xor s`。混在ならクリーク初手だけで0と1の両方が現れる。さらに混在を保つ存在二点型を選べる：

- 少数派が1点なら多数派は `k-1≥6` 点。欠損最大次数3なので多数派内部に存在二点型があり、その2点を消しても混在が残る。
- 少数派が2点以上なら多数派は少なくとも4点。少数派の任意の頂点は多数派の4点全てを欠損にはできないため、存在する交差二点型があり、両群から1点ずつ消しても混在が残る。

この独立点初手の子値は `u xor 3`。他の子値は `{0,1,u xor 3}` に含まれるため、`mex{0,1,u xor 3}=2+u`。帰納法が閉じる。

## 独立検証と証拠の境界

`verify_k6.cpp` は15組の欠損有無を列挙し、6頂点の720置換による正準化で33同型類を自前生成する。各代表についてクリーク部分集合64個のGrundy値を小さい順に求め、根を公式と照合する。**8,211,456代表を完全検査**し、クラス数・総件数も固定値と照合する。

`verify_independent.py` は別の方法として、独立点を**個別の名前付き頂点**として構築し、閉近傍削除の直接再帰で33類×16構成＝**528構成**を検証した。これは全8,211,456件の独立再計算ではない。さらに調査時には `networkx.graph_atlas_g()` による独立した6頂点同型類の列挙でも33類・総8,211,456代表を確認した。
