# 二つの奇数中心・互いに素な偶数星：Grundy数 0/2/3/4 の全称分類（2026-10-28）

## 問題と既存成果との違い

通常プレイの Node Kayles を、クリークと独立集合からなる分割グラフで考える。独立点のクリーク側近傍は1点または2点のみ。

[奇数中心・偶数星型の単一中心定理](../odd-center-even-star-sharp-transition-20261028/README.md)は、枝が3本以上あるとGrundy数が2になることを証明している。**二つの中心を同じクリーク内に置いたとき、単一中心の値からは結果を予測できない。** 本稿は中心2個、互いに交わらない2つの星の全構成を、任意の正の偶数重複数と奇数私有葉数にわたって分類する。星を接続する辺とはクリークの辺であり、独立点による二点型は両中心間に置かない。

## 定理（全称証明）

非負整数 `p,q,m` を取り、クリークを次の頂点で構成する。

- 中心 `A,B` の2点。私有葉数はそれぞれ任意の**正の奇数** `a,b`。
- `A` 側の枝先 `x_1,...,x_p` と `B` 側の枝先 `y_1,...,y_q`。枝先の私有葉数は0。
- 補助頂点 `z_1,...,z_m`。各頂点には任意の**正の偶数**枚の私有葉。

二点型独立点は `{A,x_i}` と `{B,y_j}` にだけ置き、各型の重複数を任意の**正の偶数**とする。その他の二点型は存在しない。クリークの全頂点間には辺がある。

このグラフのGrundy数を `T(p,q,m)` とすると、`a,b` および各偶数重複数の具体値によらず、

$$
\boxed{
T(p,q,m)=
\begin{cases}
0,&p=q=m=0,\\
2,&\max(p,q)\le2\text{ かつ }p+q+m>0,\\
4,&\max(p,q)\ge3,\ \min(p,q)\le2,\\
3,&\min(p,q)\ge3.
\end{cases}}
$$

したがって **片方の星に3本以上の枝があり、もう片方が2本以下なら必ず `g=4`**。両方の星が3本以上になると `g=3` に戻る。補助頂点を任意個増やしてもこの境界は変わらない。

例えば `(p,q,m)=(3,1,0)`、`a=b=1`、各二点型2個なら16頂点で `g=4`。一方、`(3,3,0)` は22頂点で `g=3`。もっと小さい `(3,0,0)` は13頂点で `g=4`。

## 補題：単一中心の星

先行定理を `S(r,s)` と書き直す。中心に正の奇数枚の私有葉、`r` 個の私有葉なし枝先に正の偶数枚の二点型、`s` 個の補助頂点に正の偶数枚の私有葉を持つクリークの値は

$$
S(r,s)=
\begin{cases}
1,&r=s=0,\\
3,&r\le2,\ r+s\ge1,\\
2,&r\ge3.
\end{cases}
$$

これは [先行する全初手分類と帰納法](../odd-center-even-star-sharp-transition-20261028/README.md) で全称証明済み。重複数は頂点ごとに不均一でもよい。

## 厳密な全初手分類

孤立点が奇数個増えるとGrundy数が `⊕1` だけ変わる。全初手の子の値は次の通り。存在しない種類は除く。

| 初手 | 子のGrundy数 | 理由 |
|---|---|---|
| 中心 `A` または `B` | `1` | 全クリークが消え、他方の中心の奇数枚の私有葉だけが奇数個残る |
| 枝先 `x_i,y_j` または補助頂点 `z_l` | `0` | 全クリークが消え、二中心の奇数葉が計偶数個残る |
| `A` の私有葉 | `S(q,p+m)` | `A` が消え、A側の二点型は各枝先の正の偶数枚の私有葉になる。残る `a-1` 枚は偶数個の孤立点 |
| `B` の私有葉 | `S(p,q+m)` | 対称 |
| `{A,x_i}` 型独立点（`p>0`） | `S(q,p+m-1)` | `A,x_i` が消え、`a+(r_{Ai}-1)` 個の孤立点は偶数 |
| `{B,y_j}` 型独立点（`q>0`） | `S(p,q+m-1)` | 対称 |
| `z_l` の私有葉（`m>0`） | `1\oplus T(p,q,m-1)` | `z_l` が消え、残る奇数枚の葉は孤立点 |

枝先のクリーク頂点を選んだ場合、その枝先に隣接する二点型は消え、他の二点型は偶数個の孤立点として残る。したがって子の値は確かに0。すべての初手を上表が尽くす。

## 帰納法による全称証明

まず `m=0` を調べる。上表には最後の行がなく、`S` の閉形式を代入するだけで次の4場合に分かれる。

| 条件 | 子の値集合 | mex |
|---|---|---:|
| `p=q=0` | `{1}` | 0 |
| `p+q>0, max(p,q)≤2` | `{0,1,3}` | 2 |
| `max(p,q)≥3, min(p,q)≤2` | `{0,1,2,3}` | 4 |
| `min(p,q)≥3` | `{0,1,2}` | 3 |

次に `m≥1` とし、`m-1` の公式を帰納法の仮定とする。

- `p=q=0` なら `m=1` の子集合は `{0,1,3}`（追加の葉初手は `1⊕0=1`）、ゆえに2。以後、追加の葉初手は `1⊕2=3` となり2のまま。
- `p+q>0, max(p,q)≤2` なら単一星の子は1または3で、3は必ず現れる。追加の葉初手は `1⊕2=3`。子集合は `{0,1,3}`、ゆえに2。
- `max(p,q)≥3, min(p,q)≤2` なら二中心の私有葉初手だけで2と3が両方現れる。その他の単一星の子も2または3。追加の葉初手は `1⊕4=5`。子集合は `{0,1,2,3,5}`、ゆえに4。
- `min(p,q)≥3` なら単一星の子はすべて2。追加の葉初手も `1⊕3=2`。子集合は `{0,1,2}`、ゆえに3。

すべての `p,q,m` について帰納法が閉じる。これは**有限計算の外挿ではなく、全パラメータに対する数学的証明**である。

## 既存の統一候補との関係

以前の分割グラフ統一候補 `Φ` では、`p+q>0` のとき独立点総数の偶奇 `u=0`、中心の接続数偶奇 `z_A=z_B=1`、枝先と補助頂点は `z=0`。従って常に `Φ=2` を予測する。

今回、`max(p,q)≥3` の全構成は反例であり、真の値は3または4。**二つの奇数中心があると、片側の枝が3本に達しただけでGrundy数4が出現する。** ただし、抽象的な分割グラフでの結論であり、整数格子上で同じ残局を実現できるかは別問題。
