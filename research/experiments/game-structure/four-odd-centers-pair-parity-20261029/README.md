# 4奇数中心の二点型：11同型類によるGrundy数の全称分類（2026-10-29）

## 対象・結果

通常プレイ Node Kayles の抽象分割グラフ。クリークはちょうど4頂点 `0,1,2,3`、各頂点に任意の**正の奇数個**の私有葉を付ける。クリークの2頂点 `ij` にだけ隣接する独立点を `c_ij >= 0` 個置く。ほかの頂点はない。

**定理（有限完全列挙を用いた全称分類）**：`c_ij` が奇数である組だけを辺とする4頂点単純グラフ `P` を作ると、元のGrundy数は `P` の同型類のみで決まる。特に、正の偶数個の二点型は **0個と同じ値**を与える。値は次表の11種類に尽き、最大3である。

二点型の順番は `01,02,03,12,13,23`。代表はその順の0/1列で記す。行の「個数」は64個のラベル付き単純グラフにおける数である。

| 単純グラフの形 | 代表 | 個数 | Grundy |
|---|---|---:|---:|
| 空グラフ | 000000 | 1 | 0 |
| 1辺 | 000001 | 6 | 3 |
| 隣接2辺（長さ2の道） | 000011 | 12 | 2 |
| 独立2辺（マッチング） | 001100 | 3 | 1 |
| 三角形＋孤立頂点 | 000111 | 4 | 1 |
| 3本星 `K_{1,3}` | 001011 | 4 | 0 |
| 4頂点の道 `P_4` | 001101 | 12 | 3 |
| 三角形＋葉1枚 | 001111 | 12 | 2 |
| 4-cycle `C_4` | 011110 | 3 | 0 |
| `K_4` から1辺除去 | 011111 | 6 | 3 |
| `K_4` | 111111 | 1 | 1 |

特に `g=0` となるのは **空グラフ・3本星・4-cycle** の場合に限る。3中心の場合の「奇数辺数だけで決まる」法則は4中心では成立しない。例えば2辺でも、独立2辺なら1、隣接2辺なら2。

## 全称範囲への還元

**独立双子点の2個削除補題**：同じ開近傍を持ち互いに非隣接な独立点が `t>=3` 個あるとき、2個削除してもGrundy数は変わらない。全頂点数で帰納法を行う。双子点を選ぶ子では、残る双子点が孤立するため、対応する子局面の孤立点の個数が2だけ異なる。双子点に隣接する頂点を選ぶ子では型全体が消える。それ以外の子は帰納法を適用できる。各着手型の子Grundy集合が一致し、mexも一致する。

よって各私有葉数は1に、各二点型数は `0,1,2` のいずれかに還元できる（**0と2を補題だけで同一視してはならない**）。

残る `3^6=729` 個のラベル付き構成を、定義通りの閉近傍削除とmexで**有限完全列挙**した。各構成で、`c_ij=2` を0に置き換えた単純グラフの値と一致することを全件検査した。したがって全ての正の奇数私有葉数・任意の非負二点型重複数について、表が成立する。無限部分は双子補題による数学的帰納法、有限基底はプログラムによる完全列挙であり、手計算だけの証明とは区別する。

## 独立検証・再現

[verify.py](verify.py) は互いに異なる2方式を実装する。(1) **名前付き全頂点**の閉近傍ビット集合を削除する再帰、(2) **独立点の近傍型と個数**による再帰。どちらも上表を計算途中で参照しない。全729基底を両方式で照合し、偶数二点型の除去を全件確認した。さらに、4頂点の置換で同一視した `0/1/2` 基底66類と、単純グラフ11類を照合した。

2026-10-29の局所実行：

- 729/729基底一致、不一致0。Grundy分布は `g=0:108, g=1:81, g=2:240, g=3:300`。
- 11/11単純グラフ同型類一致（ラベル付き64個）。
- 私有葉数 `1,3,5` と二点型数 `0..5` の不均一な構成60件（頂点数17以下に制限）も2方式と閉形式が一致。
- 名前付き再帰の最大キャッシュ状態数65,536、型別再帰の累計状態数2,492。

実行：`python3 research/experiments/game-structure/four-odd-centers-pair-parity-20261029/verify.py`。

## 境界と次の問い

抽象分割グラフの定理であり、整数格子の共円・共線禁止ゲームでこれらの局面が実現するとは主張しない。星の枝先、補助クリーク頂点、私有葉が偶数または0の中心を加えた場合も対象外。

**次の課題**：5奇数中心で「正の偶数二点型は0と等価」が続くか。4中心の729基底では成立したが、一般のクリークサイズに対する全称定理ではない。
