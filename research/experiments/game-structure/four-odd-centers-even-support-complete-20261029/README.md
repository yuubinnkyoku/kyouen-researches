# 4中心・奇数私有葉の偶数近傍型：完全分類（2026-10-29）

## 対象と結論

抽象分割グラフの通常 Node Kayles を考える。中心集合 `C={A,B,C,D}` はクリークで、各中心に**正の奇数枚**の私有葉がある。独立側の残りの点は、中心集合内の2点型・3点型・4点型のいずれかに接続し、各型の重複数は任意の非負整数とする。孤立点は含めない（含める場合は個数の偶奇で `xor 1` する）。

**計算機援用の全称定理：**

1. 任意の2点型・3点型 `S` について、**その型の点を2枚追加しても** Grundy数は変わらない。ほかの2点型・3点型・4点型の重複数には一切制限を置かない。したがって、偶数個の2点型・3点型は0個へ完全に消去できる。
2. 4点型 `C` が**0枚**のグラフを `G0`、そこへ4点型を**2枚**加えたものを `G2` とする。このとき、`g(G0) != g(G2)` となる必要十分条件は、`G0` の**4中心すべての独立側次数が偶数**であること。各中心の私有葉数は奇数なので、これは「その中心を含む奇数重複の2点型・3点型の種類数が奇数」と同値である。
3. 上の変化条件が成立するとき、奇数重複の2点型・3点型の種類数を `t` とおけば、`g(G0)=(1+t) mod 2`、`g(G2)=3-g(G0)`。条件が不成立なら `g(G0)=g(G2)`。4点型が元から正の重複数を持つ場合、同じ型を2枚追加しても既存の正の偶奇縮約定理で常に不変である。

この主張は中心数4の**任意の非負重複数**について成立する。5中心以上、私有葉0枚または偶数枚、整数格子上での実現可能性については主張しない。

## 具体例

私有葉各1枚、奇数2点型 `AB,CD` 各1枚、その他の型なしなら `g(G0)=1`。4点型を2枚追加すると `g(G2)=2`。4中心の独立側次数はすべて2（偶数）なので、上の判定条件に一致する。

これに対して4中心のうち1つでも独立側次数が奇数なら、ほかの2点型・3点型に**偶数重複が何種類あっても**4点型2枚の追加はGrundy数を変えない。

## 全称性と有限証明の境界

既存の [K0336：同一linkの独立双子点の正の偶奇縮約](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、各私有葉の正の奇数枚を1枚、各非私有近傍型の個数を0・1・2のいずれかへ還元できる。**正の偶数2枚と0枚の同値性はK0336だけでは従わない**ため、別途完全検査した。

非私有近傍型は `C` の大きさ2以上の部分集合で `6+4+1=11` 種類。三値基底 `3^11=177,147` 個の全てについて、Grundy数を厳密な `mex` 再帰で求めた。各型の個数が0のとき2へ増やす全 `649,539` 比較を行った。

| 0枚→2枚にする型 | 比較数 | Grundy数が変化した数 |
|---|---:|---:|
| 2点型（6種類） | 354,294 | **0** |
| 3点型（4種類） | 236,196 | **0** |
| 4点型（1種類） | 59,049 | **3,564** |
| **合計** | **649,539** | **3,564** |

4点型の3,564変化は、上記「4中心の独立側次数がすべて偶数」という判定と**必要十分に一致**した。変化は `0→3` が1,744件、`1→2` が1,820件。偶数型をすべて0にした二値基底では、変化する2点型・3点型の奇数集合は64種類（`2^10` のうち64種類）で、4本の独立なGF(2)線形条件を満たす `2^6` 個に一致する。

三値基底全177,147構成のGrundy分布は `g=0,1,2,3` の順に `(7938,7128,80560,81521)`、`g≥4` は0だった。**これはこの4中心族の値域についての結果であり、一般の分割グラフの上界ではない。**

## 二方式の独立検証

[verify.cpp](verify.cpp) はC++17で次の異なる実装を含む。

- **型別再帰**：生存中心と非私有点の近傍署名別個数を使い、中心選択後の孤立点偶奇、および独立点選択後の署名射影と重複縮約を行う。
- **名前付き頂点の直接再帰**：全頂点・全辺を実際に生成し、閉近傍削除による通常の Node Kayles の `mex` を取る。孤立頂点は独立成分として `xor 1` で処理するが、型別署名射影・重複縮約は使わない。
