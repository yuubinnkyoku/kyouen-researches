# 同一近傍中心の鋭い確率界と均等配置の破れ（2026-10-30）

## 対象と全称定理

有限単純分割グラフの通常プレイ Node Kayles。一様合法着手とは、各局面の残存合法頂点から毎手一様に選んで閉近傍を削除する確率過程であり、最適戦略とは異なる。

独立集合 I は m>=1 点。中心はすべてクリークをなし、独立点 j だけに隣接する中心が t_j>=0 個（総数 L）、さらに**同一の非空近傍** A⊆I（|A|=d>=1）を持つ中心が c>=1 個ある。T=Σ_{j∈A}t_j とする。中心を一度も選ばずに終局する確率は、任意の m,d,c,t_j に対し

\[
\boxed{P_I=\frac{d+T}{d+T+c}\prod_{j\in I}\frac1{t_j+1}.}
\]

**証明。** 全頂点に独立一様な連続優先順位を割り当て、順に採用可能な頂点だけ採用する。これは逐次一様合法着手と同分布。中心を一つも採用しないための必要十分条件は、各 j とその t_j 個の次数1中心の群で j が最初に現れ、かつ A のいずれかの独立点が c 個の同一近傍中心より先に現れること。前者の確率は Q=∏_j 1/(t_j+1)。前者で条件付けると j の優先順位は w_j=t_j+1 個の独立一様順位の最小値と同分布で、群間は独立。後者の条件付き確率は A 内の W=Σ_{j∈A}w_j=d+T 個の仮想順位と c 個の中心順位のうち最小が前者に属する確率 W/(W+c)。積を取る。□

## 固定 m,d,c,L の真の最小値・最大値（全称証明）

s=an+r（0<=r<n）について B(n,s)=(a+1)^{n-r}(a+2)^r とする。B(0,0)=1、B(0,s>0) は不可能。実現可能な T の集合は、d=m なら {L}、d<m なら {0,...,L} とする。

\[
\boxed{P_{\min}=\min_{T\ {\rm feasible}}
\frac{d+T}{(d+T+c)B(d,T)B(m-d,L-T)},\qquad
P_{\max}=\frac{d+L}{(d+L+c)(L+1)}.}
\]

**両端はすべての許容パラメータで達成可能。** 最小値を与える配置は、最小化する T のそれぞれについて A 内・外の t_j を**別々に均等化**したもの（群内の差が高々1）。最大値は L>=1 なら A 内の一点へ L 個を集中させると達成する。

**証明。** T を固定すると第一因子は一定で、∏(t_j+1) は各群内で差が2以上ある二項を平滑化すると厳密に増える。よって固定 T の最小値は表示式で、実現可能。全 T の最小を取る。最大値は ∏(t_j+1)>=L+1 と T<=L、さらに x/(x+c) が c>=1 で厳密増加することから従い、A 内一点集中で等号。□

候補数は高々 L+1 であり、これは無限族に対する厳密な有限最適化式。「全独立点に常に均等配置すれば最小」という主張は一般には**誤り**。

## 相転移：m=3,d=2,L=5（全 c>=1 の数学的証明）

A={0,1} とする。T=0,1,2,3,4,5 に対する固定 T の最小値は順に

\[
\frac1{3(c+2)},\quad\frac3{10(c+3)},\quad
\frac1{4(c+4)},\quad\frac5{18(c+5)},\quad
\frac1{3(c+6)},\quad\frac7{12(c+7)}.
\]

c>=1 で T=0,1 は T=2 より大きく、T=4,5 は T=3 より大きい。残る二候補は

\[
\frac1{4(c+4)}\le\frac5{18(c+5)}
\iff c\ge5.
\]

従って c=1..4 では均等配置 t=(1,2,2)（A 内で1,2）が真の最小、c=5 では t=(1,1,3) と (1,2,2) が同値、**c>=6 では不均等配置 t=(1,1,3) が真の最小**。c=6 では前者 1/40、均等配置 5/198。これは有限実験による推測でなく、全整数 c>=1 に成立する代数的証明。
