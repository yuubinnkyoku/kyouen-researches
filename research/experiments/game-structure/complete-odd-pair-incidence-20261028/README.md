# 全二点型の奇数重複：不均一な私有葉でもGrundy数は3以下（2026-10-28）

## 定理（数学的全称証明）

有限単純グラフ上の通常プレイの二点禁止ゲーム（Node Kayles）を考える。クリーク `C={c_1,...,c_k}` を取り、**すべて**の二点組 `{c_i,c_j}` に対し、その二頂点だけに隣接する独立点を **任意の正の奇数個** `r_ij∈{1,3,5,...}` 置く。さらに `c_i` に `t_i≥0` 個の私有葉を付ける。独立側に辺はない。`r_ij` も `t_i` も不均一でよい。

`b=|{i:t_i は奇数}|` とする。`k≥3` なら、全グラフのGrundy値は次の閉形式で決まる。

\[
\boxed{g(G)=\begin{cases}
\mathbf 1[k\bmod4\in\{1,2\}]&b=0,\\
2+\bigl((b\bmod2)\operatorname{xor}(\lfloor k/2\rfloor\bmod2)\bigr)&0<b<k,\\
\mathbf 1[k\bmod4\in\{0,1\}]&b=k.
\end{cases}}
\]

`k=2` は `b=0,1,2` に対して順に `g=1,2,3`。`k=1` は `t_1=0` または奇数なら `g=1`、正の偶数なら `g=2`。`k=0` は空グラフで `g=0`。

**したがって全 `k` で `g≤3`、`k≥3` では `g` は `k mod 4` と奇数枚の私有葉を持つ頂点数 `b` だけで決まる。** 偶数枚の葉が0枚か正か、二点型独立点の奇数重複数が1か3以上かは値に影響しない。`k=3,b=2` などで `g=3` を達成するため上界は鋭い。

これは [二点型が1個ずつ、私有葉数が一様な先行定理](../complete-pair-incidence-uniform-leaves-20261028/README.md) を、**奇数重複・不均一葉**へ拡張する。一方、[正の偶数重複についての別定理](../complete-even-pair-incidence-20261028/README.md) とは異なる。偶奇が混在する場合や、二点型が欠ける場合については主張しない。

## すべての初手を尽くす再帰

私有葉数を `0 / 正の奇数 / 正の偶数` に分類し、そのクリーク頂点数をそれぞれ `(a,b,c)` とする（`a+b+c=k`）。`F(a,b,c)` をこの条件を満たす**任意の**グラフの値とする。以下の再帰と帰納法により、実際の `r_ij,t_i` に依存しないことを同時に証明する。

1. **クリーク頂点 `c_i` を選ぶ。** `ε_i=t_i mod 2` とすると、残存する孤立点の偶奇は `b−ε_i+binom(k−1,2) (mod 2)`。各残存二点組の重複数が奇数であることを使った。
2. **私有葉を選ぶ（`t_i>0`）。** `c_i` が消え、残る `t_i−1` 葉は孤立する。各 `c_j` の葉数は `t_j+r_ij` に変わり、`r_ij` が正の奇数なので葉の偶奇は反転し、葉数は必ず正になる。子の型は、`t_i` が奇数なら `(0,a+c,b−1)`、正の偶数なら `(0,a+c−1,b)`。孤立点の値を xor すると、子値は順に `F(0,a+c,b−1)`、`F(0,a+c−1,b) xor 1`。
3. **二点型独立点を選ぶ。** その二端点 `c_i,c_j` が消える。選んだ型の残り `r_ij−1` 個は偶数個の孤立点になり、各残存 `c_l` の葉数は `t_l+r_il+r_jl` に変わる。後者の加算は正の偶数なので、奇数葉の頂点数は変わらず、もとの葉数0も正の偶数になる。削除した端点のうち奇数葉の頂点数を `e∈{0,1,2}` とすると、子値は `F(0,b−e,k−2−b+e) xor (e mod 2)`。`e` が選べるのはそれぞれ `k−b≥2`、`b≥1 かつ k−b≥1`、`b≥2` の場合に限る。

三種類以外の合法手は存在しない。空局面は `F(0,0,0)=0`。上記の子値集合の mex を取ることが厳密な再帰である。右辺のクリーク頂点数は必ず減るので、`F` は帰納的に一意に定まり、実際の奇数重複数・葉数に依存しない。

## 閉形式の全称証明

基底 `k≤6` を上の再帰で評価する。`k=1` の正の偶数葉の例外を除き、`k=2,...,6` の全ての `(a,b,c)` に対して値は `a,c` に依存せず、`b=0,...,k` の順に次の表になる。これは各 `a+c=k−b` の全場合を含む有限の代数計算であり、付属の検証器は同じ計算を独立に再実行する。

| `k` | `b=0,1,...,k` の `F` |
|---:|---|
| 2 | `1,2,3` |
| 3 | `0,2,3,0` |
| 4 | `0,3,2,3,1` |
| 5 | `1,3,2,3,2,1` |
| 6 | `1,2,3,2,3,2,0` |

`k≥7` とし、より小さい `k` で閉形式が成立すると仮定する。上の三手型再帰に帰納仮定を代入すると、**全初手の子Grundy値の集合**は次の表になる（`0<b<k` の列は `b` の偶奇ごと）。

| `k mod 4` | `b=0` | `0<b<k`, `b` 奇数 | `0<b<k`, `b` 偶数 | `b=k` |
|---:|---|---|---|---|
| 0 | `{1}` | `{0,1,2}` | `{0,1,3}` | `{0}` |
| 1 | `{0}` | `{0,1,2}` | `{0,1,3}` | `{0}` |
| 2 | `{0}` | `{0,1,3}` | `{0,1,2}` | `{1}` |
| 3 | `{1}` | `{0,1,3}` | `{0,1,2}` | `{1}` |

表の等号は次のように確認できる。`b=0` ではクリーク初手の値は `binom(k−1,2) mod 2`、`b=k` では `binom(k,2) mod 2` で、葉・二点型の手も帰納仮定から同じ値になる。`0<b<k` では奇数葉の頂点と偶数葉の頂点をクリーク初手で選べるため、`0` と `1` が必ず現れる。`h=(b mod 2) xor (floor(k/2) mod 2)` とすると、その他の子値は帰納仮定への代入により `0,1,3−h` のいずれかに限られる。

残る `3−h` が**必ず**現れることも示せる。`b=1` なら偶数葉の二頂点間の二点型を選ぶと `F(k−2,1)=3−h`。`b=k−1` なら奇数葉を持つ頂点の葉を選ぶと `F(k−1,1)=3−h`。`2≤b≤k−2` なら奇数葉・偶数葉の一頂点ずつに接続する二点型を選ぶと、子値は `F(k−2,b−1) xor 1=3−h`。この三場合で混合範囲を尽くす。したがって表の全ての集合は必要十分である。

各集合の mex は定理の閉形式と一致する。`k` に関する数学的帰納法が閉じ、**全 `k`、全正の奇数 `r_ij`、全 `t_i≥0`** で成立する。

無限族の結論は前節の数学的帰納法に基づく。数値検査は誤りの発見・独立照合のためのもので、有限計算からの外挿ではない。
