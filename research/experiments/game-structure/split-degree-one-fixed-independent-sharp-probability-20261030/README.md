# 一様合法着手の中心非選択確率：次数1・独立点数固定の真の上下界（2026-10-30）

## 対象と新結果

有限単純分割グラフ G の頂点をクリーク C（中心 k 個）と独立集合 I（m≥1 個）に分ける。**各中心は I のちょうど1頂点に隣接する**と仮定する。独立点 v_j に隣接する中心数を t_j≥0 と書けば Σ_j t_j=k。Node Kayles（選んだ頂点とその隣接頂点を削除）で、毎手残存頂点から一様に選ぶ。

中心を一度も選ばずに終局する確率 P_I は、任意の m,k、任意の割当について

$$
\boxed{P_I=\prod_{j=1}^{m}\frac1{t_j+1}.}
$$

さらに k=am+r、0≤r<m とすると、**独立点数 m と中心数 k の両方を固定した真の上下界**は

$$
\boxed{\frac1{(a+1)^{m-r}(a+2)^r}\le P_I\le\frac1{k+1}.}
$$

下界は t_j が a または a+1（大きい方が r 個）のとき、かつそのときに限り達成する。上界はすべての中心が同一の独立点に隣接するとき、かつそのときに限り達成する（k≤1 は自明な例外で、すべての割当が両端に一致）。どちらも m,k の任意の値で実現できる。

例：m=3、k=7 なら均等な割当 (3,2,2) で P_I=1/36、全中心を一つの独立点に集中させた割当 (7,0,0) で P_I=1/8。**中心の次数列は両方とも (1,1,1,1,1,1,1)** である。したがって独立点数を固定した下界は、既存の次数だけによる下界 2^{-k} より厳密に改善する場合がある。

## 確率公式の数学的全称証明

各頂点に独立な連続一様乱数の優先順位を割り当て、小さい順に走査して、まだ残っていれば選ぶ。これは各時点で一様に合法頂点を選ぶ過程と同分布である。

中心を一度も選ばないための必要十分条件は、**各中心 c よりも、その唯一の独立点側の隣接頂点 f(c) が早い**ことである。十分性は、f(c) が先に選ばれると c が削除されることから明らか。必要性は、f(c) より早い c が別の中心によって削除される場合には、すでに中心が選ばれてしまっていることから従う。

各独立点 v_j とその t_j 個の中心からなる群は、頂点が互いに重ならない。群内で v_j が最初になる確率は 1/(t_j+1)。異なる群の相対順位は独立なので積公式が成立する。

## 真の上下界の数学的全称証明

P_I の最小化は積 D=Π_j(t_j+1) の最大化と等価。t_i≥t_j+2 なら中心1個の割当を i から j へ移すと、該当する積は

$$
(t_i+1)(t_j+1)\longrightarrow t_i(t_j+2)
$$

となり、その増分は t_i−t_j−1>0。したがって最大の D では t_j の差は高々1であり、そのとき D=(a+1)^{m-r}(a+2)^r。逆にその配置は実現可能である。

D の最小化については、t_i,t_j>0 の二群を一群にまとめると

$$
(t_i+1)(t_j+1)>t_i+t_j+1
$$

なので D が厳密に減る。したがって k>0 なら中心を一群に集中させた D=k+1 が最小。以上は任意の m,k に対する全称証明であり、有限列挙からの推測ではない。

## 決定論的な終局構造とGrundy数

この族では、独立点を選ぶ手はその点を1個削除し、中心を選ぶ手はその唯一の独立点側隣接頂点を1個削除する。**いずれの手でも残存独立点数がちょうど1減る。** 独立点が0個になれば、その独立点に隣接していた中心もすべて削除済みである。したがって任意の着手順序で終局手数は厳密に m。

到達可能な任意の残存局面 H で独立点数を ℓ とすると、すべての子局面は ℓ−1 個の独立点を持つ。帰納法と mex から

$$
\boxed{g(H)=\ell\bmod 2.}
$$

通常の二人対戦では m の偶奇だけで空盤勝者が決まる。r人循環対戦で最後の着手者が勝つ規則なら、戦略にかかわらず第 ((m−1) mod r)+1 番目のプレイヤーが勝つ。

さらに終局までの**合法な着手列の個数**は (k+1)m!。中心を一度も選ばない列は m! 個。特定の中心 c を選ぶ列は、c と I\\{f(c)} の m 頂点を任意に並べた m! 個である。k 個の中心について加える。この着手列数の一般公式自体は既存の分割グラフ定理の特殊化であり、今回の主な新規部分は **m を固定した確率の真の最小値と等号条件**である。着手列数が同じでも確率が異なる点に注意する。

## 独立検証（厳密有理数）

同梱 `verify.py` は標準ライブラリだけを使う。ラベル付き頂点の閉近傍削除による確率再帰、全頂点の優先順位順列の直接列挙、全到達局面の mex・終局長・着手列数再帰、および固定 (m,k) の全割当の上下界照合を**別々に**実装した。

- 確率公式：m=1..4、k=0..6 の **6,688** 割当で閉近傍再帰と一致。
- 優先順位の全順列：m+k≤7 の **276** 割当で一致。
- 全到達局面のGrundy数・終局長・着手列数：m=1..4、k=0..5 の **1,798** 割当、合計 **42,304** 到達局面で一致。
- 真の上下界：m=1..5、k=0..7 の **123,044** 割当、**40** 個の (m,k) 階級で両端を照合。不一致0。
