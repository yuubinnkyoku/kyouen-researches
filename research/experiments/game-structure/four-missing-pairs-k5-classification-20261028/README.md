# クリーク5点・欠損二点型ちょうど4組の完全分類（2026-10-28）

## 結論（有限完全列挙と明示的反例）

通常プレイの二点禁止ゲーム（Node Kayles）を、5頂点のクリーク `C={c0,...,c4}` と独立点からなる分割グラフで考える。独立点はクリークの1点（私有葉）または2点にのみ隣接する。二点型10組のうち**ちょうど4組が存在せず**、残る6組には各1個以上の独立点がある。私有葉数・存在する二点型の重複数は任意の非負整数（後者は正整数）。

以前の「欠損3組以下、k>=5」の統一公式
```
u = (sum_i t_i + sum_{i<j} r_ij) mod 2
z_i = (t_i + sum_{j!=i} r_ij) mod 2
F = 1 xor u xor z_0   (z_0=...=z_4)
F = 2+u               (それ以外)
```
は、**欠損4組の場合、欠損グラフが4本星でない限り、全ての重複数と私有葉数について成立する**。4本星の場合には成立しない構成がある（したがって全称拡張は偽）。欠損4組のどの形でも **g(G)<=3** が成立する。

### 最小点数の明示的反例

欠損組を `{01,02,03,04}` とし、残る `{12,13,14,23,24,34}` に各1点、私有葉0点とする。グラフはクリーク5点と独立点6点の**計11頂点**。

- `u=0`、`(z0,z1,z2,z3,z4)=(0,1,1,1,1)` なので旧公式は **2** を予測。
- 名前付き11頂点の閉近傍削除による厳密なmex再帰では **g(G)=3**。
- クリーク `c0` の子局面は0、`c1,...,c4` の子局面は1、独立点6個の子局面は全て2。ゆえに `mex{0,1,2}=3`。

欠損4組なら残る二点型6組が必ず非空なので、クリーク5点と合わせて頂点数は少なくとも11。したがって**この条件内での反例の頂点数11は最小**（一般の分割グラフ全体での最小性は主張しない）。

### 完全分類の計数

欠損4辺の単純グラフは5頂点上で6同型型。各型につき存在する6二点型を1（正奇数）または2（正偶数）、5つの私有葉型を0・1（正奇数）・2（正偶数）とする全 `2^6*3^5=15,552` 代表を厳密に列挙した。

| 欠損辺の代表 | ラベル付き軌道数 | 代表数 | 旧公式との不一致 |
|---|---:|---:|---:|
| 01,02,03,04（4本星） | 5 | 15,552 | **4,856** |
| 01,02,03,12 | 60 | 15,552 | 0 |
| 01,02,03,14 | 60 | 15,552 | 0 |
| 01,02,12,34 | 10 | 15,552 | 0 |
| 01,02,13,23 | 15 | 15,552 | 0 |
| 01,02,13,24 | 60 | 15,552 | 0 |
| **合計** | **210** | **93,312** | **4,856** |

4,856は**正規化代表の個数**であり、無限個の重複数の「割合」を意味しない。

## 証拠と論理的範囲

二点型の同一近傍を持つ独立点について、存在するかどうかと個数の偶奇だけがGrundy数に影響する。これは既存の偶奇縮約補題（`two-missing-pairs-arbitrary-multiplicities-20261028`）による。直接には、残存クリーク集合 `M` に隣接する独立点数の偶奇を `A[M]` とすると、クリーク初手 `i` の子値は `A[M] xor z_i`、署名 `S` の独立点初手は `g[M\\S] xor A[M] xor A[M\\S] xor 1` であり、後者の選択可能性にのみ個数が正かどうかが必要となる。この式は残存クリークの点数で厳密に帰納できる。

したがって各正の奇数重複を1、正の偶数重複を2、葉数を0/1/2に縮約した93,312件は**全ての元の無限個の重複数**を覆う。6型の網羅性は5!個の頂点置換で各軌道を生成し、210通りの4組欠損を重複なく被覆して確認する。

`verify.py` はクリーク部分集合のmex再帰で全93,312件を検査し、さらに**独立した名前付き頂点の閉近傍削除再帰**で6型の最小代表を再計算する。特に11頂点反例の全11初手の値を照合する。名前付き方式で93,312件全部を再計算したわけではない。

実行：
```sh
python3 research/experiments/game-structure/four-missing-pairs-k5-classification-20261028/verify.py
```

出力は `verification.txt`。有限基底の完全列挙と既存の数学的縮約を組み合わせた計算機援用の全称結論であり、**k>=6の欠損4組**、**欠損5組以上**、整数格子への実現、11×11空盤の勝敗には結論を及ぼさない。

次の実行可能な課題：k=6,7の欠損4組について有限基底を検証し、k>=8の「同じz値を持つ4頂点には少なくとも1つ存在する二点型がある」という帰納補題と接続する。k=5の4本星例外を無視してk=7を帰納させないこと。
