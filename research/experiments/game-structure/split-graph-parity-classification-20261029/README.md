# 分割グラフの全局面Grundy二値性：次数偶奇による必要十分条件（2026-10-29）

## 定理（数学的全称証明）

有限分割グラフ G のクリーク C と独立集合 I への分割を固定する。k=|C|、m=|I|、d(c)=|N(c)∩I| とし、通常プレイの Node Kayles を考える。

k=0 の場合は全局面Grundy値が0/1で、空局面は m mod 2。

k>0 の場合、**全合法局面のGrundy値が0/1だけになる必要十分条件**は次のどちらか。

1. 全ての d(c) が奇数。この場合、任意の合法集合 S に対して g(S)=(m-|S|) mod 2。
2. 全ての d(c) が偶数、かつ少なくとも一つの d(c)=0。この場合、任意の合法集合 S に対して g(S)=(m+1-|S|) mod 2。

それ以外ならGrundy値2以上の合法局面が必ず存在する（空局面の値が2以上とは限らない）。

## 証明：極大独立集合の全分類

C はクリークなので、任意の独立集合が含む中心は高々1個。中心 c を含む極大独立集合は M_c={c}∪(I\N(c)) に限り、これは実際に極大で、サイズは 1+m-d(c)。中心を含まない極大独立集合は I に限り、I が極大となる条件は全 d(c)>0。

全 d(c)>0 の場合、I と全 M_c のサイズ偶奇が一致することは、全 d(c) が奇数であることと同値。一つでも d(c)=0 なら I は極大でなく、全 M_c の偶奇一致は全 d(c) の偶奇一致、すなわち全 d(c) が偶数であることと同値。

既存の [K0305](../../../knowledge/items/K0305-binary-grundy-iff-maximal-parity.md) は、有限の下方閉・一点追加ゲームで全極大集合のサイズ偶奇一致と全局面Grundy二値性が同値で、共通終局偶奇 ε に対し g(S)=(ε-|S|) mod 2 と証明している。よって本定理は**計算機に依存しない全称証明**である。

## 系：奇数私有葉＋任意階数の偶数重複を一括消去

各中心に正の奇数枚の私有葉を付け、サイズ2以上の任意の中心部分集合 A を近傍とする独立点を、それぞれ任意の非負偶数枚だけ置く。近傍空の孤立点が a 枚あってもよい。全中心の独立側次数は奇数であり、|I|≡k+a (mod 2) だから、

g(空局面)=(k+a) mod 2、かつ全合法局面のGrundy値は0/1。

高次近傍型の偶数重複は、種類数・交差・階数に制限なく、すべて削除しても空局面Grundy値は不変。削除前後の全局面が一対一対応するとの主張ではない。奇数二点型が混在する8中心以上の偶奇消去は依然として未解決。

## 独立検証

verify.py はラベル付き分割グラフの全 C–I 辺配置を列挙し、(1) 全極大独立集合の偶奇、(2) 全合法集合の直接mex、(3) 次数条件を照合する。k,m≤4 と (3,5),(5,3) の **140,499構成**で不一致0。二値性成立13,815、不成立126,684、最大空局面Grundy値3。

verify_even_supports.py は名前付き頂点の閉近傍削除再帰（孤立点のみxorで処理）で、k≤4の全偶数高次近傍型0/2配置 **2,068構成**、不均一な私有葉1/3/5・高次重複2/4/6の固定乱数標本 **240構成**を照合し、不一致0。最大72頂点・単一構成最大13,434記憶状態。
