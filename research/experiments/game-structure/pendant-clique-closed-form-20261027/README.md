# 私有葉付きクリークのGrundy閉形式（2026-10-27）

## 対象と結論

抽象的な二点残余禁止ゲーム（Node Kayles）を扱う。グラフをクリーク C={c_1,...,c_k} と独立集合 I に分け、I の各点が C の**高々1点**にしか隣接しないとする。c_i だけに隣接する葉数を a_i≥0、どこにも隣接しない自由点数を f≥0 とする。k,a_i,f は無制限。

z=# {i:a_i=0}, o=# {i:a_i>0 かつ奇数}, e=# {i:a_i>0 かつ偶数} と置く。自由点を除いたGrundy値 F(z,o,e) は次の閉形式となる。

| 条件 | F |
|---|---:|
| z≥1, o=0 | 1 |
| z≥1, o≥1 奇数 | 2 |
| z≥1, o≥2 偶数 | 3 |
| z=0, e=0 | o mod 2 |
| z=0, e=1, o=0 | 2 |
| z=0, e≥2, o=0 | 1 |
| z=0, e≥1, o≥1 奇数 | 3 |
| z=0, e≥1, o≥2 偶数 | 2 |

したがって **g(G)=F(z,o,e) xor (f mod 2) ≤3**。頂点数とクリークの大きさに制限はない。k=2, (a_1,a_2)=(1,2) は5頂点で g=3 を達成するので鋭い。一般の分割グラフに対する既存上界より、この部分族では強い。

## 全称証明（有限列挙に依存しない）

自由点は独立成分なので xor (f mod 2) で分離できる。クリーク点 c_i を選ぶと全クリークが消え、残るのは他のクリーク点に付属した sum_{j≠i} a_j 個の孤立点で、子の値はその偶奇。a_i>0 の葉を選ぶと c_i とその葉が消え、残り a_i−1 個の葉が孤立点になる。他のクリーク点とその葉は元の形を保つ。

s=o mod 2 と書くと、子局面の値の集合 M は厳密に

- z>0 なら {s} を含む。
- o>0 なら {1−s, F(z,o−1,e)} を含む。
- e>0 なら {s, 1 xor F(z,o,e−1)} を含む。

これら以外の子の値はない。F(0,0,0)=0 とし、F(z,o,e)=mex(M) で z+o+e に関して帰納する。a_i の実数値は、葉を選んだ後の自由点数の偶奇にしか現れないため、この3種類への分類は全称的に正しい。

帰納段階のmexは次の通り。

1. z≥1：o=0 の子は {0} で F=1。o=1 は {0,1}（e>0 なら3も）で F=2。o≥2 偶数は {0,1,2} で F=3。o≥3 奇数は {0,1,3} で F=2。
2. z=0,e=0：o=0 は空グラフで0。o>0 は全子が (o−1) mod 2 なので F=o mod 2。
3. z=0,e>0,o=0：e=1 の子は {0,1} で F=2。e=2 の子は {0,3}、e≥3 の子は {0} で F=1。
4. z=0,e>0,o>0：o が奇数なら子は {0,1,2} で F=3。o が正の偶数なら {0,1,3} で F=2。

全場合で表と一致する。従って任意の有限 k,a_i,f に成立する**数学的全称定理**である。クリーク内部が完全であることと、独立側の各点がクリーク点高々1個にしか隣接しないことが必要であり、一般分割グラフへの拡張はできない。

## 独立検証

`verify.py` は閉形式を (1) z,o,e の独立mex再帰、(2) 隣接ビット集合から構築したグラフの閉近傍削除による完全再帰と照合する。前者は z,o,e=0..12 の2,197型、後者は k=0..5・各 a_i=0..3 の全1,365グラフに加えて、固定乱数40例（k≤6、a_i≤4、自由点0..1）を検査。**不一致0**。

```sh
python3 research/experiments/game-structure/pendant-clique-closed-form-20261027/verify.py
```
