# 分割グラフで初期Grundy数が1の場合の全勝ち初手（2026-10-31）

## 定理（無界・数学的全称証明）

通常プレイの Node Kayles を考える。有限単純グラフの分割 `V=C∪I` を固定し、`C` は `k≥1` 頂点の完全グラフ、`I` は `m` 頂点の独立集合とする。各 `c∈C` の独立側次数 `d(c)=|N(c)∩I|` を用いる。

初期局面のGrundy数が `g(G)=1` となるための必要十分条件は、既存の[空局面偶奇判定定理](../split-root-parity-iff-20261030/README.md)により、

- 全 `d(c)` が奇数で、`m` が奇数、または
- 全 `d(c)` が偶数で、`m` が偶数、かつ全中心に隣接する独立点が存在しない

のいずれかである。このとき**全ての勝ち初手を、mex再帰なしに厳密に分類できる**。

**奇数次数の場合**：`C∪I` の**全頂点が勝ち初手**（全初手の子Grundy数は0）。

**偶数次数の場合**：全中心 `c∈C` は勝ち初手。独立点 `x∈I` は、**異なる独立点 `y∈I\{x}` で `N(x)∪N(y)⊇C` を満たすものが存在しない場合、かつその場合に限り勝ち初手**である。

従って、偶数次数の場合の勝ち初手数は

```
k + |{x∈I : すべての y∈I\{x} について (N(x)∪N(y))∩C ≠ C}|
```

である。近傍の中心側ビット集合を `s(x)` とすると、各独立点の勝ち負けは `s(x)|s(y) == (1<<k)-1` という単純な対比較で決定する。

`k=0` の場合は独立点だけなので、`g=m mod 2`。したがって `g=1` なら全独立点が勝ち初手。

## 証明

中心 `c` を選ぶと、残るのは `m-d(c)` 個の孤立点であり、子のGrundy数は `(m-d(c)) mod 2`。上記の `g=1` のどちらの場合も、これは0。よって中心は全て勝ち初手。

独立点 `x` を選ぶと、`x` とその隣接中心集合 `S=N(x)∩C` が消える。残る中心は `T=C\S` であり、残る独立点は `I'=I\{x}` である。どの `c∈T` も元々 `x` と非隣接なので、**新しい独立側次数は元の `d(c)` のまま**である。孤立独立点も `I'` に含めてよい。

奇数次数の場合は `m-1` が偶数。もし `T` が非空なら、残余分割グラフの全中心次数は奇数であり、既存の空局面偶奇判定定理から子のGrundy数は `1 xor ((m-1) mod 2) xor 1 = 0`。もし `T` が空でも、子は偶数個の孤立点だけなので0。従って全独立点が勝ち初手。

偶数次数の場合も `m-1` は奇数。全域点 `y∈I'` が残余中心 `T` に対して**存在しない**なら、同定理から子のGrundy数は `1 xor 1 xor 0 = 0`。全域点が**存在する**なら、同定理の必要十分条件が破れるため子のGrundy数は2以上で、勝ち初手ではない。なお元のグラフには全域点が存在しないため `T` は空にならない。

この残余全域点の存在条件は、`T⊆N(y)`、すなわち `(N(x)∪N(y))∩C=C` と同値である。これで分類が完了する。

この定理は `g=1` の**全初手の勝敗**を決めるが、負け初手後のGrundy数の正確な値を決めるものではない。通常プレイ以外や任意の共円ゲーム残局への直接適用も主張しない。

## 最小限の非自明な例

`C={0,1,2}`、独立点の中心近傍をビット集合 `(3,5,6,0)` とする。各中心の独立側次数は2、`m=4`、全域点なしなので `g=1`。

中心3個と孤立独立点（署名0）は勝ち初手。一方、署名3,5,6の独立点は互いに二つずつで `C` を覆うため負け初手。個別頂点を展開した直接mex再帰による7初手の子値は

```
[0, 0, 0, 3, 3, 3, 0]
```

である。**根がg=1でも、全独立点が勝ち初手とは限らない**。

## 独立検証

[verify.py](verify.py) は個々の名前付き頂点に閉近傍削除を適用する直接mex再帰を使用し、上の分類式とは独立に子局面を計算する。以下の合計 **113,783構成**を照合した。

- `1≤k≤4, 0≤m≤4` の全ラベル付き `C-I` 辺配置。
- `k=5, 0≤m≤3` の全ラベル付き `C-I` 辺配置。
- `1≤k≤9, 0≤m≤14` の固定乱数5,000構成。

根が1となる **5,538構成**について、**勝ち初手の集合全体**を照合。不一致0。その他の根についても、既存の根0/1必要十分条件と直接mexが一致した。全称性の根拠は上の数学的証明であり、有限検査ではない。

```sh
python3 research/experiments/game-structure/split-root-one-winning-moves-20261031/verify.py
```
