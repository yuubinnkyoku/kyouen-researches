# 私有葉だけを持つ分割グラフの全局面Grundy閉公式（2026-10-30）

## 対象と定理（数学的全称証明）

通常プレイの二点禁止ゲーム（Node Kayles）を扱う。中心 `c_1,...,c_k` はクリークをなし、中心 `c_i` にだけ隣接する私有葉が `t_i>=0` 枚ある。さらに、全頂点と非隣接な孤立点が `a>=0` 個あってもよい。私有葉同士に辺はない。

`z=# {i:t_i=0}`、`o=# {i:t_i>0 かつ奇数}`、`e=# {i:t_i>0 かつ偶数}` とする。孤立点を除いたGrundy値 `F(z,o,e)` は次の**完全な閉公式**で与えられる。

| 条件 | F |
|---|---:|
| z>=1, o=0 | 1 |
| z>=1, oが奇数 | 2 |
| z>=1, oが正の偶数 | 3 |
| z=0, o=0, e=0 | 0 |
| z=0, o=0, e=1 | 2 |
| z=0, o=0, e>=2 | 1 |
| z=0, o>=1, e=0 | o mod 2 |
| z=0, o>=1, e>=1, oが奇数 | 3 |
| z=0, o>=1, e>=1, oが偶数 | 2 |

孤立点が `a` 個ある場合は **`g=F(z,o,e) xor (a mod 2)`**。したがって、この族の任意の局面で `0<=g<=3`、しかも四値とも実現する。中心数・葉の枚数が無制限でも、初期局面のGrundy値は `z,o,e` だけで決まる。これは単なる偶奇による勝敗分類ではなく、Grundy値2・3を含む強解決である。

例えば `(t_1,t_2)=(1,2)` の連結5頂点グラフは `z=0,o=e=1` より **`g=3`**。一方 `(1,1,1,1)` では `g=0`。偶数枚の私有葉が1中心でも混ざると、値は2または3に変わり得る。

## 全称証明

中心を選ぶと他の中心がすべて消え、残る葉は独立点になる。私有葉を選ぶと、その中心が消え、同じ中心の残りの葉は孤立点になる。孤立点は排他的論理和の規則で処理できる。

`p=o mod 2` とすると、中心だけの部分のGrundy再帰は厳密に

```text
F(0,0,0) = 0
F(z,o,e) = mex(
    {p            if z+e>0}          # 私有葉0枚または正の偶数枚の中心
  ∪ {p xor 1      if o>0}            # 奇数枚の中心
  ∪ {F(z,o-1,e)   if o>0}            # 奇数枚の私有葉
  ∪ {F(z,o,e-1) xor 1 if e>0}        # 正の偶数枚の私有葉
)
```

ここで `{... if 条件}` は条件を満たさなければ空集合である。中心選択後の孤立点数の偶奇は `p` または `p xor 1`、葉選択後は同中心の残葉がそれぞれ偶数枚または奇数枚になるため、この再帰に例外はない。中心を持たない空グラフが基底である。

上の表を `k=z+o+e` について帰納する。各場合の初手後の値集合は次の通り（`z=0,o=0,e>=2` だけ `e=2` と `e>=3` を分ける）。

| 条件 | 子の値集合 | mex |
|---|---|---:|
| z>=1,o=0 | {0} | 1 |
| z>=1,o奇数 | {0,1} または {0,1,3} | 2 |
| z>=1,o正の偶数 | {0,1,2} | 3 |
| z=0,o=0,e=0 | 空集合 | 0 |
| z=0,o=0,e=1 | {0,1} | 2 |
| z=0,o=0,e=2 | {0,3} | 1 |
| z=0,o=0,e>=3 | {0} | 1 |
| z=0,o>=1,e=0 | {(o+1) mod 2} | o mod 2 |
| z=0,o奇数,e>=1 | {0,1,2} | 3 |
| z=0,o正の偶数,e>=1 | {0,1,3} | 2 |

各行は再帰へ帰納仮定を代入するだけで検査できる。特に `z>=1,o=1,e=0` では子集合は `{0,1}`、`z>=1,o>=3` では `{0,1,3}` となる。これで表の全行と上界3が証明された。孤立点の寄与は通常プレイの非交和xor則による。

任意の合法な着手後も、残ったグラフは同じ「クリーク＋各中心の私有葉＋孤立点」の形を保つ。したがってこの公式は**初期局面だけでなく全ての到達局面**にそのまま適用できる。

## 既存研究との境界

- 既存の [分割グラフ次数偶奇による二値性](../split-graph-parity-classification-20261029/README.md) は全局面のGrundy値が0/1に限られる条件を扱う。本結果は私有葉だけという制約の下で、二値性が壊れた場合の**正確な2・3**まで計算する。
- [閾値グラフ六状態定理](../threshold-graph-six-state-20261027/README.md) と同じ上界3だが、今回のグラフ族は一般には閾値グラフではない（例 `t=(1,1)` は誘導P4を持つ）。
- 一般の分割グラフにはGrundy値7の既知証人がある。私有葉以外の二中心共有葉・高次数葉を許すと、この上界3は成立しない。
- 標準共円ゲームの残余禁止超辺が全て二点で、このグラフ構造になるときだけ利用できる。整数格子での出現・11×11への実測効果は未確認。
