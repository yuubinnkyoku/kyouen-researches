# 5中心・偶数三点型消去：他の偶数型を1種類まで許す完全な奇数型分類（2026-10-29）

## 結論（抽象分割グラフの通常 Node Kayles）

中心集合 `C={0,1,2,3,4}` はクリークで、各中心には任意の**正の奇数枚**の私有葉がある。その他の独立点は、中心の大きさ2以上の部分集合 `S` を近傍とする型ごとに任意個配置する。孤立点は除く（孤立点は独立成分として `xor 1` できる）。

任意の三点型 `T` を固定する。**`T` 以外の非私有型で、正の偶数枚を持つものが高々1種類**であり、それ以外の非私有型は0枚または正の奇数枚なら、

$
\boxed{g(G)=g(G+2T)}
$

が成り立つ。**奇数型の種類数には一切制限を設けない。** 非私有型は `2^5-1-5=26` 種類で、`T` 以外の25種類すべてを同時に許す。

`T` がもともと正の重複数を持つ場合は、[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により同じ型へ2枚追加してもGrundy数は変わらない。したがって `T=0` と `T=2` の比較だけで十分である。

既存の[奇数型全25種類・混在型8種類以下](../five-even-triple-odd-complete-mixed-eight-20261029/README.md)の定理を拡張する。今回の範囲は、**奇数型が24種類すべて存在し、さらに別の1種類が偶数**という、従来の「混在型8種類以下」の範囲外の構成を含む。偶数型が0種類の場合は既存結果で処理する。

## 全称性の根拠

[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) は同一linkの独立双子点について、**正の奇数枚を1枚、正の偶数枚を2枚**へGrundy数を保ったまま縮約できることを数学的に証明している。したがって、無限個の重複数を扱う本命題は次の有限基底に帰着する。

- 各私有葉は1枚。
- 固定した `T={0,1,2}` は0枚と2枚を比較する。
- 残り25型のうち、1種類 `E` は2枚、他の24型はそれぞれ0枚または1枚。

有限基底は `25 × 2^24 = 419,430,400` 構成。中心の `T` を保存する置換群 `S3 × S2`（12元）で `E` を8軌道にまとめ、各 `E` の安定化群で24ビットの奇数型集合を同型縮約する。**35,454,336代表を全件検査**した。各代表の軌道サイズを加算すると、元の419,430,400構成を過不足なく覆う。

すべての代表で `g(G)=g(G+2T)`、**不一致0件**。有限実験の支持だけではなく、**数学的縮約＋有限完全列挙**による計算機援用の全称証明である。コードの正しさを無条件に仮定する形式証明ではない。

## 厳密な再帰

生存中心集合を `R` とし、各近傍型の重複数を `a[S]` とする。非孤立独立点の個数の偶奇を

$
p(R)=\sum_{S:S\cap R\ne\varnothing}a[S]\pmod2
$

と置く。非孤立核のGrundy数を `h(R)`、`h(∅)=0` とすると、中心 `c∈R` の手の子は `p(R) xor p({c})`、独立型 `S` の手の子は

$
h(R\setminus S)\ \operatorname{xor}\bigl(p(R)\operatorname{xor}p(R\setminus S)\operatorname{xor}1\bigr).
$

両者の `mex` が `h(R)` である。中心の手では全中心が消え、残る独立点は孤立する。独立点の手では `S` の中心が消え、新たに孤立した独立点の偶奇を括弧内で補正する。

`T` に2枚加えてもすべての `p(R)` は不変であり、各 `R` で `T∩R` の手が追加されるだけである。[verify.cpp](verify.cpp) は `R=1..31` を小さい順に計算し、追加前後の `h` を別々に保持して根 `R=31` を比較する。支持型 `S` を `S∩R` でまとめて候補手を作るが、元の再帰と同値である。
