# 完全多部グラフのGrundy閉形式と分割グラフの値4証人（2026-10-27）

## 結論・範囲

抽象的な二点残余禁止ゲーム（有限単純グラフ上の Node Kayles）を扱う。グラフの頂点を一つ選ぶと、その頂点と隣接頂点が消える通常プレイである。整数格子上の幾何的実現は主張しない。

**数学的な全称定理：** 空でない完全多部グラフ \(G=K_{n_1,\ldots,n_k}\)（\(k\ge1\)、各 \(n_i\ge1\)）のGrundy値は

\[
g(G)=
\begin{cases}
0 & \text{すべての }n_i\text{ が偶数},\\
1 & \text{すべての }n_i\text{ が奇数},\\
2 & \text{奇数と偶数が混在する場合}.
\end{cases}
\]

空グラフの値は0。従って、頂点数・辺数・部数が無制限でも \(g\le2\) であり、上界は \(K_{1,2}=P_3\) で鋭い。完全多部グラフの有限個の非連結直和については、各成分の上記値を xor すればよい。

**境界を示す厳密な反例：** 「一方がクリーク、他方が独立集合」という分割グラフまで \(g\le3\) と拡張することはできない。12頂点・31辺の分割グラフで \(g=4\) を達成する明示例を得た。この例の最小性、分割グラフ全体の鋭い上界、標準整数格子での実現は未解決である。

## 全称証明（有限実験に依存しない）

完全多部グラフの第 \(i\) 部の頂点 \(v\) を選ぶと、他の部の全頂点と \(v\) 自身が消え、同じ部の残り \(n_i-1\) 個はすべて孤立点になる。孤立点 \(t\) 個のゲームは \(t\bmod2\) なので、初手後のGrundy値の集合は厳密に

\[
\left\{(n_i-1)\bmod2 : 1\le i\le k\right\}.
\]

この集合が \(\{1\}\)、\(\{0\}\)、\(\{0,1\}\) のいずれかであることから、mexは順に0、1、2となる。\(k=1\) の独立集合にも同じ式が適用される。空グラフは定義から0。直和の式は通常プレイのSprague–Grundyのxor則による。

## 分割グラフの明示証人

頂点 \(0,\ldots,5\) を完全グラフ \(K_6\) とし、\(6,\ldots,11\) を互いに非隣接とする。独立側の各頂点のクリーク側近傍を次のように定める。

| 頂点 | クリーク側の近傍 |
|---|---|
| 6 | {0,2,4,5} |
| 7 | {0,1,2} |
| 8 | {4} |
| 9 | {0,3} |
| 10 | {0,1,5} |
| 11 | {0,3,4} |

クリーク内部15辺と交差16辺の計31辺である。全12初手後のGrundy値は頂点順に

\[
(1,0,0,0,1,0,0,3,2,3,3,0)
\]

となる。集合はちょうど \(\{0,1,2,3\}\) なので \(g(G)=4\)。これは**一つの有限証人を完全再帰で検査した結果**であり、分割グラフ一般の上界を主張しない。

## 独立検証

- `verify.py`: 残存頂点の閉近傍削除再帰と、選択済み独立集合を増やす別状態再帰が証人の根・全12初手で一致。完全多部グラフの部数0〜4、部サイズ1〜4、総頂点数12以下の**306個のラベル付き部サイズ列**を二方式で全件照合。
- `verify_split_cpp.cpp`: Pythonとは独立のC++で全 \(2^{12}=4096\) 部分集合のGrundy値を下から計算。証人の値4と全12初手の値を一致検証。

## 適用上の注意

本定理は**残余禁止集合がすべて二点集合**で、そのグラフが完全多部グラフになっている局面にのみ適用できる。三点以上の極小残余禁止集合が一つでもある場合、単なる二点競合グラフで置き換えてはいけない。11×11の実際の探索における出現頻度や速度改善は未測定。
