# 二中心に共有される葉が任意個ある分割グラフのGrundy閉公式（2026-10-30）

## 対象・結論（数学的全称証明、有限場合分けは付属検証器で監査）

通常プレイの二点残余禁止ゲーム（Node Kayles）を考える。中心は完全グラフをなし、特別な相異なる中心 A,B にはそれぞれ `a,b>=0` 枚の私有葉が付く。A,B の両方に隣接し、他の中心には隣接しない**共有葉が `c>=1` 枚**ある。その他の中心には私有葉しかない。すべての葉は互いに非隣接。その他の中心のうち、私有葉0枚を `z` 個、正奇数枚を `o` 個、正偶数枚を `e` 個とする。

**定理**：このグラフのGrundy数は `a mod 2, b mod 2, c mod 2, [z>0], o` の「0・奇数・正偶数」の区分、および `[e>0]` だけで決まる。すべての非負整数 `a,b,z,o,e` と `c>=1` で `0<=g<=3`。孤立点が `h` 個あれば `g xor (h mod 2)` となる。中心数・私有葉数・共有葉数には上限がなく、任意の合法後続局面も閉公式または共有葉なしの既存公式で処理できる。

`c` が**正の奇数**の場合は既存の [共有葉1個の全称閉公式](../split-one-shared-leaf-closed-grundy-20261030/README.md)と完全に一致する（[独立双子点の正の偶奇縮約 K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)）。以下は新たに決定した **`c` が正の偶数** の完全表である。`E,O` は `a,b` の偶・奇（0も偶）、`o+奇` は正奇数、`o+偶` は正偶数を表す。

| z | a,b | e | o=0 | o+奇 | o+偶 |
|---|---|---|---:|---:|---:|
| 0 | E,E | 0 | 2 | 3 | 2 |
| 0 | E,E | 正 | 1 | 3 | 2 |
| 0 | E,O | 任意 | 3 | 2 | 3 |
| 0 | O,O | 0 | 0 | 1 | 0 |
| 0 | O,O | 正 | 2 | 3 | 2 |
| 正 | E,E | 任意 | 1 | 2 | 3 |
| 正 | E,O | 任意 | 2 | 3 | 2 |
| 正 | O,O | 任意 | 3 | 2 | 3 |

A,Bの交換で値は不変。例えば A,B に私有葉がなく他の中心もない場合、`c=1` は三角形で `g=1`、`c=2` は `g=2`。一方、`a=b=1` では `c=1` が `g=3`、`c=2` が **`g=0`**。共有葉を一つ増やすだけで先後の勝敗が反転し得る。

## 証明

まず K0336 の全称定理により、同じ二中心にだけ隣接する共有葉の正の奇数個は1個、正の偶数個は2個へGrundy数を変えずに縮約できる。`c=0` は別の族であり、正偶数個を0個と同一視してはならない。私有葉の重複も同じ理由で、0・1・2個の区分に縮約できる。

共有葉なしの私有葉公式を `F(z,o,e)` と書く（[既存の全称証明](../split-private-leaves-closed-grundy-20261030/README.md)）。`p=(a+b+c+o) mod 2` とする。以下の値の **mex** が厳密に `G_c(a,b,z,o,e)` である。角括弧の条件が不成立ならその子値は存在しない。

```text
(b+o) mod 2                                 # 中心Aを選択
(a+o) mod 2                                 # 中心Bを選択
F(z,o,e) xor ((a+b+c-1) mod 2)              # 共有葉を選択
p                       [z+e>0]            # その他の私有葉0枚/正偶数枚の中心
p xor 1                 [o>0]              # その他の私有葉正奇数枚の中心
F(z, o+((b+c) mod 2), e+1-((b+c) mod 2))
  xor ((a-1) mod 2)      [a>0]              # Aの私有葉
F(z, o+((a+c) mod 2), e+1-((a+c) mod 2))
  xor ((b-1) mod 2)      [b>0]              # Bの私有葉
G_c(a,b,z,o-1,e)        [o>0]              # その他の正奇数枚の私有葉
G_c(a,b,z,o,e-1) xor 1  [e>0]              # その他の正偶数枚の私有葉
```

中心を選ぶと他の中心とその中心の葉・共有葉が消え、残る葉は孤立する。共有葉を選ぶと A,B が消え、残る `c-1` 枚の共有葉と A,B の私有葉が孤立する。A の私有葉を選ぶと A が消え、共有葉は B の私有葉になる（Bの私有葉数は `b+c>0`）。その他の中心の私有葉を選ぶと、残葉の偶奇に従い孤立点の寄与が0または1となる。これらはすべての合法手を尽くす。

再帰に現れる `G_c` は `o+e` を必ず1減らすため、**`o+e` に関する帰納法**を使える。`c` が奇数の表は既存の証明で成立。`c` が偶数の場合、上表を帰納仮定として代入すると、全行で `mex(children)=表の値` となる。これは次の有限の場合分けで**無限個の整数を漏れなく代表できる**。

- `a,b=0,1,2,3`：私有葉の着手可否（0か正）と偶奇だけが必要。`a,b>=4` は正の偶奇の既存代表と同じ子値集合を持つ。
- `z=0,1`：0か正だけが必要。`z>=2` で新しい着手型は増えない。
- `o=0,1,2,3,4,5`：0・正奇数・正偶数と、`o-1` の遷移先を覆う。`o>=6` の遷移は `o=4,5` のいずれかと同じ分類になる。
- `e=0,1,2,3`：0・1・2以上と、`e-1` の遷移先を覆う。`e>=4` は `e=3` と同じ分類になる。特に F が `e=1` と `e>=2` を区別する例外を見落とさない。

この **`4×4×2×6×4=768` 個の帰納代表**（偶数 `c=2`）を付属の `verify.py` が各合法着手の値から直接 mex して表と比較する。奇数 `c=1` の768代表も回帰検査する。有限計算は**帰納法の有限場合分けの検算**であり、任意の頂点数を単に標本から外挿しているわけではない。最後に、閉近傍削除で残るグラフは共有葉の同じ族、共有葉なしの F 族、またはそれらと孤立点の非交和に限られるので、全後続局面にも適用できる。

## 既存研究との境界

- [共有葉1個の公式](../split-one-shared-leaf-closed-grundy-20261030/README.md)を任意の正個数へ拡張し、**偶数個の場合の値を新たに完全分類**した。単に `c=1` の数値を `c=2` に転用してはならない。
- [独立双子点の偶奇縮約 K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)を再証明したものではない。既存補題を用い、偶数代表に対する新たな閉公式を与えた。
- 共有葉が三中心以上に隣接する場合や、複数の異なる二中心対に共有葉がある場合は対象外。一般の分割グラフに `g<=3` を拡張してはならない。
- 抽象二点残余禁止ゲームの定理であり、整数格子の共円ゲーム残局としての実現可能性・11×11での出現頻度・探索速度改善は未確認。
