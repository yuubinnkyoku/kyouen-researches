# 交換可能類の計数ベクトル商：Grundy・極大配置・終局手順数

2026-10-20。対象は有限点集合の一点追加・通常プレイ。共円ゲームの残余禁止超グラフを含む抽象定理であり、11×11空盤の勝敗や実行速度改善は主張しない。

## 定理（全称数学的証明）

有限点集合 V を X_1 ⊔ ... ⊔ X_d に分割し、各 X_i 内の**任意の二点交換**が禁止集合族 F を保存するとする（単なる自己同型軌道では不十分）。k_i=|X_i| と置く。禁止辺 e の類別点数 profile を p(e)=(|e∩X_1|,...,|e∩X_d|)、局面 S の占有数ベクトルを a(S)=(|S∩X_1|,...,|S∩X_d|) とする。

1. a が安全 ⇔ どの禁止辺 profile p も成分ごとに p≤a とならない。
2. 安全な a の合法な後続ベクトルは、安全かつ a_i<k_i の成分を1増やした a+e_i に尽きる。
3. G(a)=mex{G(a+e_i): a+e_i が合法}（終端0）とすれば、元のラベル付き局面 S の通常Grundy値は G(a(S))。
4. 極大安全集合の石数別生成多項式は

   T(z)=Σ_{a:安全かつ極大} (∏_i binom(k_i,a_i)) z^{Σ_i a_i}。

5. 空局面から t 手で終局する、ラベル付き合法着手順の総数は t![z^t]T(z)。

商の全ベクトル数は高々 ∏_i(k_i+1)。禁止辺のprofile集合 P を前計算して素朴に判定すれば、O(∏(k_i+1) · d · (|P|d+1)) 時間でGrundyと終局分布を計算できる（類の発見にかかる時間は別）。実盤での速度改善は未測定。

## 証明

各類の全二点交換は類内の対称群を生成する。従って F は各類の任意の置換で不変であり、同一profileの禁止辺は全て存在する。よって S が禁止辺を含む条件は p≤a(S) の存在と同値。占有数が同じ任意の二局面はこの置換群で移り合い、合法手の類は増やす成分だけで決まる。有限ゲームの残り手数に関する帰納法とmexでGrundyが一致する。

類 i から a_i 点を選ぶ方法は binom(k_i,a_i) 通り。安全性と極大性はベクトルのみで決まるので重み付き和が終局多項式になる。安全集合は下方閉だから、t点の極大集合に到達する t! 個の順序はすべて合法であり、各着手列の終局集合は一意である。これで手順数公式も成立する。□

## 18点の厳密例

4類の大きさを (3,4,5,6) とし、隣り合う類の点間の全二点組を禁止する（P4の点群置換）。極大集合は類番号 (1,3), (1,4), (2,4) をそれぞれ丸ごと選ぶ3種類で、

    T(z)=z^8+z^9+z^10
    G(0,0,0,0)=0
    8!+9!+10!=4,032,000 通り

である。元の全占有状態 2^18=262,144 に対し商の全ベクトルは 4·5·6·7=840。
