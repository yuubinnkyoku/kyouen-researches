# 5奇数中心・全二点型：偶数重複消去と34同型類の完全分類（2026-10-29）

## 定理（有限完全列挙を用いた全称分類）

通常プレイ Node Kayles の抽象分割グラフを考える。クリークはちょうど5頂点 `0,1,2,3,4`。各クリーク頂点に**任意の正の奇数個**の私有葉（その頂点だけに隣接する独立点）を付ける。各2頂点組 `ij` に、両端のみに隣接する独立点を `c_ij >= 0` 個置く。他の頂点はない。

**結論**：Grundy数は、`c_ij` が奇数である組を辺とする5頂点単純グラフ `P` の同型類だけで決まる。正の偶数個の二点型は、0個と**同じGrundy値**を与える。可能な値は `0,1,2,3` に限られ、5中心のこの族では `g >= 4` は生じない。

`g=0` となるのは `P` が次の3種類の場合に限る。

1. 三角形と孤立頂点2個の直和 `K_3 ⊔ 2K_1`（ラベル付き10個）。
2. 5-cycle `C_5`（12個）。
3. `K_5` から三角形の3辺を除いたグラフ `K_2 ∨ 3K_1`（10個）。

`g=1` となるのは空グラフ、`C_4 ⊔ K_1`、その補グラフ、完全グラフ `K_5` の4同型類（ラベル付き計32個）。残る単純グラフは `g=2` または `g=3`。以下の表はそのすべてを区別する。

## 証明の論理構造と独立検査

1. **無限個から有限個への全称還元（数学的補題）**：同じ開近傍を持つ独立双子点を2個削除してもGrundy値は変わらない（既存の K0336）。よって私有葉の正の奇数枚は1枚に、各二点型の個数は0、1、2のいずれかに縮約できる。**2枚と0枚が同値であることはこの補題からは従わない**。
2. **有限完全列挙**：`verify_quotient.py` は全 `3^10 = 59,049` 個のラベル付き0/1/2基底を、クリークの生存集合と独立点の近傍型別個数で管理する厳密なmex再帰で計算した。各基底の値を、すべての2を0へ置き換えた基底の値と比較し、**59,049/59,049一致、不一致0**。これにより任意の重複数についての偶数消去を確定する。
3. **別方式による完全独立照合**：`verify_named.cpp` は実際に名前を付けた全頂点の閉近傍ビット集合を直接削除してmexを計算する。0/1/2基底を中心の置換で割った**792同型類すべて**について、元と2→0縮約後を直接比較した。全同型類で一致し、軌道サイズの合計は59,049。これは元の59,049個すべてを対称性を使って網羅する検証であり、単なる無作為標本ではない。孤立点成分はGrundy値の偶奇xorとして直接処理する。両方式は異なる状態表現と再帰実装を用いる。
4. **分類**：単純グラフ `2^10=1,024` 個を5頂点の全120置換で分類し、34同型類の値を表に示した。

0/1/2基底のGrundy値分布は `g=0:1,744, g=1:2,225, g=2:27,780, g=3:27,300`。2方式でこの分布まで一致した。型別再帰の共有キャッシュは71,175状態、名前付き直接再帰の1構成あたり最大メモ状態数は651（孤立点を除去してからmex）。

## 適用範囲と残る問い

**全称定理**であるのは「指定された抽象分割グラフ族」の範囲内であり、無限部分は既存の双子補題、有限部分は計算機援用の完全列挙に依存する。格子共円ゲームの実現可能局面だとは主張しない。枝先、偶数私有葉、0枚の私有葉、3点以上の近傍型は対象外。`k>=6` の全称偶数消去も未証明。

先行研究：[4中心の11同型類](../four-odd-centers-pair-parity-20261029/README.md)、[双子点縮約の知識正本](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)。

次の実行可能な課題は6中心の偶数消去について、まず0/1の中心間グラフを固定し1辺だけ2にする全 `15*2^14` 構成を厳密検査し、破れがなければ一般の0/1/2同型類に拡張すること。5中心の表だけから6中心一般の公式を外挿してはならない。
