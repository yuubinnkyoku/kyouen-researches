# 7奇数中心・高々3種の偶数二点型：完全分類（2026-10-29）

## 定理（数学的還元＋有限完全列挙）

通常プレイ Node Kayles の抽象分割グラフで、クリークはちょうど7頂点。各クリーク頂点に任意の正の奇数枚の私有葉を付け、各頂点対 ij に、両端だけに隣接する独立点を c_ij 個置く。他の辺・頂点はない。

**正の偶数 c_ij を持つ頂点対が高々3組**なら、Grundy数は c_ij が奇数である組を辺とする単純グラフ P の同型類だけで決まり、**0 ≤ g(G) ≤ 3**。正の偶数重複を0個へ消しても値は変わらない。各重複数そのものは任意の非負整数でよく、「3組」は重複数の合計ではなく頂点対の種類数を指す。

## 全称証明と独立検証

1. 既存の独立双子点の全称定理 [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、正の奇数私有葉は各1枚、正の奇数二点型は各1枚、正の偶数二点型は各2枚へ縮約できる。**K0336だけでは2枚→0枚は従わない**。
2. verify_named.cppは21辺マスク全2,097,152個を走査し、隣接交換6種で生成されるS7の軌道を完全列挙する。1,044軌道のサイズ合計が2,097,152であることを確認する。
3. 各代表Pの非辺から0〜3組を選び、それぞれに2枚の独立点を置いた構成を**全て**調べる。置換対称性により、対象のラベル付き構成は漏れなく覆われる。
4. verify_named.cppは実際の名前付き頂点の閉近傍削除によるmex再帰、verify_quotient.cppは隣接中心集合ごとの個数を用いる別のmex再帰で全構成を独立に計算した。

| 正の偶数二点型の種類数 | 代表×選択の完全検査数 | 両方式の不一致 |
| ---: | ---: | ---: |
| 0 | 1,044 | 0 |
| 1 | 10,962 | 0 |
| 2 | 56,318 | 0 |
| 3 | 187,891 | 0 |
| **合計** | **256,215** | **0** |

名前付き再帰の1構成あたり最大記憶状態数は127、型別再帰の共有記憶状態数は1,005,678。これは**数学的縮約と有限完全列挙による全称定理**であり、有限標本からの外挿ではない。列挙の健全性は添付コードとK0336の証明に依存する。

## 限界・次の課題

**7中心で4種類以上の正の偶数二点型**は未確定。三値基底全体3^21=10,460,353,203構成を調べたわけではない。8中心以上、偶数・0枚の私有葉、3点以上に接続する独立点、整数格子上の実現可能性についても結論はない。
