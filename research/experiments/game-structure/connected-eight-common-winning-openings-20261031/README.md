# 連結8頂点Node Kaylesで通常・misère共通勝ち初手を持つ全グラフ（2026-10-31）

## 結論（鋭い最小次数と完全分類）

有限単純無向グラフ G 上の Node Kayles を考える。手 x は閉近傍 N[x] を削除する。通常Grundy値 g は終端0、misère補助mex値 h は終端1とし、**両ルール共通の勝ち初手**とは (g(G-N[x]),h(G-N[x]))=(0,0) となる x をいう。

**定理1（連結の場合の最小頂点数）**：連結グラフで共通勝ち初手が存在するのは8頂点以上であり、この下限は鋭い。8頂点の連結グラフ G において x が共通勝ち初手である必要十分条件は次のとおり。

1. x は次数1の葉であり、唯一の隣接点を y とする。
2. 誘導部分グラフ G-{x,y} は C6 または P3 ⊔ P3 に同型。
3. C6 の場合、y は残余6頂点の少なくとも1点に隣接する。P3 ⊔ P3 の場合、y は各P3成分の少なくとも1点に隣接する。

3は G の連結性と同値であり、G が連結という仮定の下では1,2だけで十分である。

**定理2（個数と一意性）**：この条件を満たす連結8頂点グラフでは、共通勝ち初手は **必ずちょうど1個**。非同型グラフは **27種類**（C6 型12、P3⊔P3 型15）。ラベル付き8頂点グラフは **458,640個**（C6 型211,680、P3⊔P3 型246,960）。

```text
C6型:       8 * 7 * 60 * (2^6 - 1) = 211680
P3+P3型:    8 * 7 * 90 * (2^3 - 1)^2 = 246960
合計:                                      458640
```

## 数学的証明

**必要性**：x が共通勝ち初手なら、子局面 G-N[x] は (g,h)=(0,0)。既存 K0309 は合法点数5以下で h=τ(g)（τは0と1の交換）を証明しているから、子には少なくとも6頂点必要。従って |V(G)| ≥ 7+deg(x)。連結グラフの頂点数が2以上なら deg(x)≥1 なので |V(G)|≥8。8頂点で等号が成り立つには deg(x)=1、子はちょうど6頂点。既存の6頂点全グラフ完全列挙では (g,h)=(0,0) となるのは C6 と P3⊔P3 の2同型型のみ。連結性から y の残余成分への接続条件が従う。

**十分性**：上記のいずれかを構成すると G-N[x] は C6 または P3⊔P3 であり、どちらも (g,h)=(0,0)。よって x は両ルールの勝ち初手。8頂点の実現例は C6 に1頂点 y を接続し、その y に葉 x を1枚付ければよい。

**一意性**：C6 型では残余6頂点の次数は2以上、y の次数も2以上なので x だけが葉。P3⊔P3 型で別の共通勝ち初手 z があるとすれば、上の必要性により z も葉。z は x と異なり、y に隣接していない残余P3の端点でなければならない。z とその隣接中心 w を削除した残余6頂点で、同じP3の反対端点 u が y に隣接しなければ u は孤立する。y に隣接するなら y は x,u と他方のP3の少なくとも1点に隣接し次数3以上になる。どちらも C6（全次数2）および P3⊔P3（孤立点なし、最大次数2）ではない。矛盾。

**ラベル付き個数**：x のラベル8通り、y のラベル7通り。残余6ラベル上の C6 は 6!/12=60 通りで、y の非空近傍は63通り。P3⊔P3 は 6!/8=90 通りで、各3点成分への非空近傍は7×7=49通り。一意性により二重計数はない。

**非同型個数**：x が一意なので、同型写像は x とその唯一の隣接点 y をそれぞれ保つ。C6型の y-残余近傍は長さ6の非零二値ブレスレットに対応する。二面体群D6のBurnside計数は (84+72)/12=13 軌道、空集合を除いて12。P3型では各成分の非空近傍の自己同型軌道は5種類（中央のみ、片端のみ、両端、中央+片端、全点）。成分交換を許す順序なし二組は5×6/2=15種類。従って27。

**証拠の性格**：下限・構造分類・個数は既存の有限完全列挙結果（6頂点の分類）と数学的帰着による厳密結果。6頂点分類そのものを無界全称定理と読み替えない。8頂点を超える連結グラフの分類は主張しない。
