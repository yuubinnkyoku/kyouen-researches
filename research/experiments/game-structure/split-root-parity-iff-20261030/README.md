# 分割グラフの空局面Grundy数が0または1となる必要十分条件（2026-10-30）

## 定理（任意の有限分割グラフ・数学的全称証明）

通常プレイの Node Kayles を考える。有限グラフ G の分割 C∪I を固定し、C は k≥1 個の頂点からなるクリーク、I は m 個の頂点からなる独立集合とする。各中心 c∈C の I 側次数を d(c)=|N(c)∩I| とし、**全中心に隣接する独立点**を「全域点」と呼ぶ。

**空局面のGrundy数 g(G) が0または1である必要十分条件**は、

1. 全 d(c) の偶奇が一致し、その共通偶奇を d∈{0,1} とする。
2. d=1 であるか、または I に全域点が存在しない。

の両方が成り立つことである。その場合は完全な閉公式

```
g(G) = 1 xor (m mod 2) xor d
```

が成立する。いずれかの条件が破れる場合は **g(G)≥2** である。k=0 の場合は独立点のみなので g(G)=m mod 2。

この主張は**初期局面だけ**の必要十分条件であり、全到達局面が0/1になるという主張ではない。中心数、独立点数、近傍の大きさ、近傍型の重複に制限はない。

## 証明（二手先の偶奇による排除）

中心 c を初手で選ぶと、クリーク C はすべて消え、I のうち c に隣接しない m−d(c) 個だけが孤立点として残る。よって子のGrundy数は (m−d(c)) mod 2。

中心次数の偶奇が不一致なら、中心着手だけで子値0と1が両方現れる。したがって mex は2以上。

以下、全 d(c) の偶奇が共通値 d だとする。中心着手の子値はすべて b=(m mod 2) xor d であり、反対のビットを t=1 xor b とする。

独立点 x が全域点でなければ、x に隣接しない中心 c が少なくとも一つある。x を初手で選んだ後も c は残る。続いて c を選ぶと、元の I のうち c に隣接しない m−d(c) 個から、すでに選んだ x だけを除いた **m−d(c)−1 個の孤立点**が残る。二手後のGrundy数は t。従って「x を選んだ直後の局面」は t への合法着手を持ち、その局面自身のGrundy数は t にはなり得ない（mex の定義）。

一方、x が全域点なら、x を選ぶと C 全体が消え、m−1 個の孤立点が残る。したがって子値は (m−1) mod 2 = (m mod 2) xor 1。d=1 ならこれは b、d=0 なら t である。

よって d=1 または全域点なしの場合、中心着手により b は子値として存在し、すべての独立点着手では t が子値にならない。従って mex は厳密に t。d=0 かつ全域点がある場合、中心着手から b、全域点着手から t が得られ、子値0と1がそろうので mex≥2。以上で必要十分性を示した。

## 系と既存成果との差

**二点近傍型の多重集合**：独立点がすべて中心2点に隣接し、k≥3 なら全域点は存在しない。中心対の重複数に制限なく、中心ごとの接続本数の偶奇が全て等しければ g(G)=1 xor (m mod 2) xor d。特に、既存の「7中心・次数2・重複ありでg=5」という証人では、この次数偶奇の一致は成立しない。k=2 は全域点を含み得るため例外であり、同一対に2点を付けた4頂点グラフは g=2。

**全局面二値性との区別**：既存の [全局面二値性の必要十分条件](../split-graph-parity-classification-20261029/README.md) は全合法局面の値を0/1に制限する、より強い条件を扱う。本定理は空局面のみを分類するため、それより広い。例えば k=3、独立点の近傍が {0,1},{0,2},{1,2} の3個の場合、中心次数はすべて2（偶数）、全域点はなく、g(G)=0。しかし独立点を選んだ子は g=2 であり、全局面二値性は成立しない。

**全域点が必要条件を壊す例**：k=1 で同じ中心に接続する独立点2個（3頂点の星）は d=2、全域点あり、g=2。全域点を無視して閉公式を適用することはできない。

整数格子上の共円・共線禁止ゲーム残局としての実現可能性は未確認。一般の高階残余禁止集合に直接適用できるとは主張しない。

- k=1..4, m=0..4、および k=5, m=0..3 の全 C–I 接続 **108,783構成**を完全列挙。
- k=1..8、m=0..12 の固定乱数 **4,800構成**を追加検査。
- 全域点ありの反例2件と、初期局面0だが子局面2となる例1件を明示検査。

計 **113,586構成で不一致0**。全称性の根拠は上の数学的証明であり、検証した有限範囲からの外挿ではない。
