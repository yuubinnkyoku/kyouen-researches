# 二点次数・重複なしの分割グラフのGrundy完全列挙と、重複による跳躍（2026-10-30）

## 対象と新結果

通常プレイの二点残余禁止ゲーム（Node Kayles）。C={c0,...,c(k-1)} はクリーク、I は独立集合で、**各独立点はちょうど2個のクリーク点に隣接する**。その2点のビット和を署名とする。整数格子での実現可能性は仮定しない。

**定理A（k≤5、署名の重複あり）。** 同一署名の個数に上限を置かなくても g≤3。k≤4 は既存のクリーク上界。k=5 は独立双子点の正の偶奇圧縮 K0336 により、10種類の署名それぞれの個数を0,1,2に減らした **3^10=59,049全代表**を厳密に列挙し、最大3。これは有限完全列挙を用いた全称定理。

**定理B（k=6、署名の重複あり）。** g≤4。クリーク点を選んだ子は孤立点だけなのでg=0または1。独立点を選んだ子はクリークが4点に減り、既存のk≤4全称上界3を適用できる。従ってmex≤4。署名 [10,33,33,34,36,36,48,48] の14頂点グラフでg=4を達成し、**上界は鋭い**。上界の部分は数学的証明。

**定理C（k≤7、署名重複なし）。** どのクリーク点対にも独立点が高々1個なら **g≤3**。k=7 は2^21=2,097,152個の全ラベル付き単純対署名集合を完全列挙した。k≤6も全列挙。k≥4では署名 [3,5] がg=3を達成する。これは有限完全列挙を用いた全称定理であり、k≥8は含まない。

**定理D（k≥7、署名重複なし）。** g≤2k−9。これは紙上証明による無界の一般上界。独立点を選ぶとその近傍のクリーク点がちょうど2個消える。同じ2点を近傍に持つ別の独立点が存在しないため、残った独立点が孤立することはない。よって残るk−2点クリークの分割グラフに既存の「孤立点なし」上界2(k−2)−6を適用でき、独立点着手の子はg≤2k−10。クリーク点着手の子はg≤1なのでmex≤2k−9。k=7では定理Cの3の方が強い。

**新しい有限証人（k=7、重複あり）。** 署名 [5,5,12,12,20,20,34,66,68] の16頂点グラフは **g=5**。全独立点の次数は2であり、グラフは連結。独立点着手で残るクリークは5点なので、既存の孤立点あり上界5から子のg≤5、クリーク点着手の子はg≤1、ゆえに一般にg≤6。したがってk=7・次数ちょうど2・重複ありの真の最大値は **5以上6以下**。署名重複なしの最大3との落差は厳密である。

## 独立検証と証拠の境界

[verify_exhaustive.cpp](verify_exhaustive.cpp) はk=2,...,7の全重複なし署名集合を**省略なく**列挙する。二進Gray符号で対の有無を更新し、クリーク部分集合（最大128状態）上の厳密mexを評価する。度数表を検査する。

[verify_independent.py](verify_independent.py) は別実装のクリーク部分集合再帰でk≤6の全重複なし構成、k=5の重複あり全59,049代表を再計算する。k=2,...,7から選んだ150固定乱数標本では、**各頂点を展開した閉近傍削除再帰**と根・全初手を照合する。k=7の全2,097,152構成を名前付き頂点再帰で再計算したわけではない。

k=6・7の重複あり証人はクリーク部分集合再帰と名前付き頂点再帰で根・全初手が一致。子値集合はそれぞれ{0,1,2,3}、{0,1,2,3,4}。同じクリークを固定したまま独立点を少なくとも1個削る全255/511部分多重集合では、元のgに戻らない。これは**各証人内部での削除極小性**であって、全族での最小頂点数の証明ではない。

再現コマンド（repo rootから）：

    c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/split-simple-pair-signatures-20261030/verify_exhaustive.cpp -o /tmp/split_simple_pairs
    /tmp/split_simple_pairs
    python3 research/experiments/game-structure/split-simple-pair-signatures-20261030/verify_independent.py

全称性の根拠は、明示した有限完全列挙と[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)の全称圧縮定理、および既存のクリーク上界にある。標本検査だけで全称性を主張していない。整数格子上の共円・共線禁止ゲームの残局への実現可能性は未確認。
