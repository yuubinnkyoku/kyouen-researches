# 残余容量4以下の通常・misère完全局所分類と7点の共通勝ち手境界（2026-10-31）

## 結論（数学的全称定理）

任意の有限な遺伝的安全集合族を考え、現在の局面 S から安全に追加できる点の最大個数（残余容量）が4以下とする。通常のGrundy値 g は終端0、misère補助mex値 h は終端1。τ(0)=1、τ(1)=0、τ(j)=j (j≥2)。

各合法初手 x の子局面 T=S∪{x} は残余容量3以下。T に合法な手 y があるとき、

- A_T(y): T∪{y,z} が安全で、そこからさらに一手も安全に追加できないような z が存在する。
- B_T(y): T∪{y,z,w} が安全となる相異なる z,w が存在する。

と置く。いずれも T からの二手・三手の合法性だけで判定できる。各 y に対して

\[
c_T(y)=\begin{cases}
0 & \neg A_T(y),\\
1 & A_T(y)\land\neg B_T(y),\\
2 & A_T(y)\land B_T(y)
\end{cases}
\]

とし、U_T={c_T(y): y は T で合法} とする。

**定理1（深さ4の局所分類）**：T が終端なら (g(T),h(T))=(0,1)。非終端なら

\[
(g(T),h(T))=(\operatorname{mex} U_T,\operatorname{mex}\tau(U_T)).
\]

従って、初手の子局面は次の5種類に限られる。

| 種類 | (g(T),h(T)) | U_T |
|---|---|---|
| a | (0,1) | {1}, {1,2}、または終端 |
| b | (1,0) | {0}, {0,2} |
| c | (2,2) | {0,1} |
| d | (3,3) | {0,1,2} |
| e | (0,0) | {2} |

S の初手に現れる種類の集合を E⊆{a,b,c,d,e} とする。S が非終端なら、通常版で勝つ初手は **aまたはe**、misère版で勝つ初手は **bまたはe** である。従って **同じ初手が両ルールで勝つことと、種類eの初手が存在することは同値**。

**定理2（交換則の必要十分条件）**：非終端 S において

\[
\boxed{h(S)=\tau(g(S))
\iff
(a\in E\ \lor\ b\in E)
\land
(e\notin E\ \lor\ (a\in E\land b\in E)).}
\]

証明：定理1の5種類について通常・misèreそれぞれの子値集合のmexを取る。eがない場合、a,bがともにないと両mexは0で交換則が破れる。eがある場合、両子値集合に0が入り、a,bがともにある場合に限って両mexが2以上で一致する。a,bの一方だけなら両mexはそれぞれ1と2以上、どちらもなければ両mexは1となる。これで必要十分性が従う。終端 S では (g,h)=(0,1) なので交換則は成立する。□

定理1は既存の「残余容量3以下」定理を一手ずらして適用したものであり、深さ4以上の一般局面へ無条件に延長してはいない。根の値・全勝ち初手は二・三・四点の安全性照会だけで計算できる。残余容量4以下の**別途認証が必要**。

## 共通勝ち初手の鋭い7点境界

**定理3**：任意の有限遺伝的配置ゲームで、現在の合法点が6個以下なら、通常版とmisère版の両方で勝つ同一の初手は存在しない。合法点7個では実現できる。

証明：同一の勝ち初手 x が存在することは (g(S+x),h(S+x))=(0,0) と同値。合法点が6個以下なら子局面の合法点は5個以下であり、既存K0309の全称交換則 h=τ(g) に矛盾する。7点の実現例は後述の C6⊔K1。□

**定理4（単純グラフの7頂点での完全分類）**：Node Kayles（独立集合を安全集合とする）において、7頂点グラフの初期局面に両ルール共通の勝ち初手があるのは、グラフが

\[
\boxed{C_6\sqcup K_1\quad\text{または}\quad P_3\sqcup P_3\sqcup K_1}
\]

と同型である場合に限る。共通勝ち初手は孤立頂点ただ1個。ラベル付きでは前者420個、後者630個、合計 **1,050個**。

証明：7頂点で x の子に6合法点が残らなければ定理3の議論により (0,0) にはならない。従って x は孤立点。残る6頂点の全32,768ラベル付きグラフを通常・misèreの独立再帰で完全列挙すると、(g,h)=(0,0) となるのは C6 の60ラベルと P3⊔P3 の90ラベルのみ。孤立点のラベルを7通り選べるので420+630=1,050。独立のC++実装は7頂点の全2^21=2,097,152グラフを走査し、孤立点がある209,868個について残余の両値を直接計算し、同じ分類を確認する。□

両実現例は残余容量4で、根 (g,h)=(1,1)、孤立点を打った子が (0,0)。従って **通常とmisèreの両方で同じ初手が勝つ最小合法点数は7** であり、残余容量4で交換則の破れ (1,1) が起こる。
