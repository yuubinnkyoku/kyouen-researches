# 分割グラフ：任意個の特別中心に対する固定次数の真の確率極値（2026-10-30）

## 対象と全称定理

有限単純分割グラフの通常プレイ Node Kayles。独立点集合 \(I\) は \(m\ge1\) 点、中心はクリーク。独立点 \(j\) のみに隣接する次数1中心が \(t_j\ge0\) 個、総数 \(L=\sum_jt_j\)。これらとは別に \(k\ge0\) 個の区別された特別中心があり、特別中心 \(h\) の独立点側次数 \(d_h\)（\(0\le d_h\le m\)）を固定する。近傍の配置と \(t_j\) の分布は自由とする。各手で残存合法頂点を一様に選ぶ。\(P_I\) は終局まで**中心を一度も選ばない**確率であり、最適プレイの勝率ではない。

各独立点 \(j\) の**署名** \(b(j)\subseteq[k]\) を、その点に隣接する特別中心の集合とする。署名 \(b\) の独立点数を \(n_b\)、その群の次数1中心総数を \(s_b\) とする。実現可能性は

\[
n_b\ge0,\quad \sum_bn_b=m,\quad
\sum_{b:h\in b}n_b=d_h\ (\forall h),\qquad
s_b\ge0,\quad\sum_bs_b=L,\quad n_b=0\Longrightarrow s_b=0
\]

で必要十分。署名が空の点も許す。\(G=2^k\) 個の署名がある。

\[
U(S)=\sum_{b:b\cap S\ne\varnothing}(n_b+s_b),\qquad H(\varnothing)=1,
\]
\[
H(S)=\frac{\sum_{h\in S}H(S\setminus\{h\})}{|S|+U(S)}
\quad(S\ne\varnothing),\qquad
F(n,s)=\sum_{S\subseteq[k]}(-1)^{|S|}H(S).
\]

\(n\ge1,\ s=an+r,\ 0\le r<n\) に対して
\(B(n,s)=(a+1)^{n-r}(a+2)^r\)、また \(B(0,0)=1\) と定める。

**定理（固定 \(m,L,k,d_1,\ldots,d_k\) の真の最小・最大確率）。** 上の実現可能な整数組 \((n_b,s_b)\) 全体について

\[
\boxed{
P_{\min}=\min_{n,s}\frac{F(n,s)}{\prod_{b:n_b>0}B(n_b,s_b)},
\qquad
P_{\max}=\max_{n,s}\frac{F(n,s)}{\prod_{b:n_b>0}(s_b+1)}.
}
\]

**両端は必ず達成される。** 最小側では同一署名の独立点間で \(t_j\) をできるだけ均等にし、最大側では署名群ごとの次数1中心を一点に集中させる。署名群間の割当数 \(s_b\) と署名群の大きさ \(n_b\) は上式の有限最適化で決定する。

これは任意の固定 \(k\) に対する**厳密な極値計算方法**であり、単一の閉形式ではない。候補数は高々

\[
\binom{m+2^k-1}{2^k-1}\binom{L+2^k-1}{2^k-1}.
\]

各候補の計算は高々 \(O(4^k)\) 程度の有理数演算で実行できる。**固定 \(k\) なら頂点数 \(m+L\) に関して多項式個の候補**で真の極値が決まる。大整数の桁数・演算費用は別途であり、\(k\) に関して効率的とは主張しない。

## 証明

各頂点に独立な連続一様優先順位を与え、小さい順に、まだ削除されていない頂点だけを選ぶ。これは逐次一様合法着手と同分布である。各独立点 \(j\) が自身の \(t_j\) 個の次数1中心より先に現れる確率は \(1/(t_j+1)\)。この事象で条件付けると、その点の順位は \(t_j+1\) 個の独立一様順位の最小値と同分布になる。各 \(j\) の群は独立である。

したがって、次数1中心を一度も選ばない条件付き世界では、独立点 \(j\) を \(t_j+1\) 個の仮想点に置き換えて特別中心の「いずれかの近傍点が先に現れる」確率を計算できる。既証明の重み付き中心部分集合再帰（split-weighted-k-hub-subset-dp-20261030）から

\[
P_I=\frac{F(n,s)}{\prod_j(t_j+1)}.
\]

署名 \(b\) 内の総和 \(s_b\) を固定すると、特別中心の任意の近傍和集合の仮想点数は \(U(S)\) だけで決まり、\(F(n,s)\) は群内の \(t_j\) の分配に依存しない。非負整数 \(t_1+\cdots+t_n=s\) について、積 \(\prod_i(t_i+1)\) は二つの値の差が2以上なら平滑化により厳密に増加するため、均等分配で最大 \(B(n,s)\)。一方 \((a+1)(b+1)\ge a+b+1\) から一点集中で最小 \(s+1\)。\(F(n,s)\ge0\) は条件付き確率だから、群ごとにこれらを選ぶと同じ \((n,s)\) の真の下端・上端になる。

最後に、任意の実現可能な整数 \((n,s)\) は署名を持つ \(m\) 個の独立点を実際に作り、次数1中心を配分すれば実現できる。全候補で最小・最大を取ると表示式の両端が達成される。□

## 反例：近傍の重なりを減らすほど最小とは限らない

\(m=3,\ k=2,\ d_1=d_2=2,\ L=1\)。\(A=\{0,1\}\) とし、次数1中心の隣接先を自由に選ぶ。

- 重なり最小 \(|A\cap B|=1\)（\(B=\{0,2\}\)）では、3通りの配置をすべて調べた真の最小が **\(37/144\)**（次数1中心を1または2に付ける）。
- 重なり最大 \(|A\cap B|=2\)（\(B=A\)）では、真の最小が **\(1/4\)**（次数1中心を2に付ける）。

\[
\boxed{\frac14<\frac{37}{144}.}
\]

**重なりを増やした方が確率が下がる。** 既存の重み付き交差の単調性は \(\alpha,\beta,Q\) を固定したときの条件付き定理であり、今回は割当を最適化する際にそれらも変わるので矛盾しない。この階級の真の最大値は \(3/10\)（両中心の近傍を一致させ、次数1中心を共通近傍内に置く）。
