# 奇数中心・偶数星型のGrundy数：次数3での鋭い遷移（2026-10-28）

## 対象と既存成果との差

通常プレイの Node Kayles を、クリークと独立集合からなる分割グラフで考える。独立点はクリーク側の1頂点または2頂点にのみ隣接する。

[先行する3個の私有葉ゼロ頂点の無限反例族](../three-zero-private-unbounded-counterfamily-20261028/README.md)は、中心の私有葉1個、3本の二点型それぞれ2個、残りの頂点に私有葉2個という均一な構成で、Grundy数2を与えた。

今回の**新しい部分**は、星の枝数の鋭い境界と、任意の奇数・正の偶数重複数に対する閉形式である。既存の反例の再発見ではない。

## 定理（数学的全称証明）

整数 $p,m\ge0$ を選び、クリークを $c_0,c_1,\ldots,c_{p+m}$ とする。

- 中心 $c_0$ の私有葉数 $t_0=a$ は任意の**正の奇数**。
- $1\le i\le p$ では $t_i=0$、二点型 $\{c_0,c_i\}$ の独立点数 $r_{0i}=b_i$ は任意の**正の偶数**。
- $p+1\le j\le p+m$ では $t_j=d_j$ は任意の**正の偶数**。
- 上記以外の二点型は存在しない。

この分割グラフを $G(p,m;a,b,d)$ とすると、重複数の大きさや不均一性によらず

$$
\boxed{g(G)=
\begin{cases}
1,&p=m=0,\\
3,&p\le2,\ p+m\ge1,\\
2,&p\ge3.
\end{cases}}
$$

**境界 $p=3$ はこの族の中で鋭い。** $p=1,2$ では常に3だが、$p\ge3$ では常に2となる。$m$ をいくら増やしても変わらない。

従来の統一候補 $\Phi$ については、$p+m\ge1$ で $u=1$, $z_0=1$, $z_i=0$（$i>0$）なので $\Phi=3$。したがって $p\ge3$ の全構成は反例であり、偶数の二点型重複数を2から4,6,...へ変えても消えない。$k\ge3$ の範囲で $p\le2$ の構成は公式と一致する。

## 補題：各クリーク頂点に正の偶数枚の私有葉がある場合

$F(n)$ を、クリーク $K_n$ の各頂点に任意の正の偶数枚の私有葉があるグラフのGrundy数とする。値は枚数の選び方によらず

$$
F(0)=0,\qquad F(1)=2,\qquad F(n)=1\quad(n\ge2).
$$

証明：クリーク頂点を打つと偶数枚の独立点だけが残り、子の値は0。私有葉を打つとそのクリーク頂点が消え、残った私有葉は奇数枚の孤立点となる。よって子の値は $1\oplus F(n-1)$。$n=1$ から順に $\operatorname{mex}\{0,1\oplus F(n-1)\}$ を取れば上式が従う。枚数に依存しないため、不均一な偶数枚にも適用できる。

## 全初手分類と帰納法

$n=p+m$ と置く。$n\ge1$ の全初手は次の4（$m>0$ なら5）種類で尽きる。

| 初手 | 子のGrundy数 | 理由 |
|---|---|---|
| $c_0$ | $0$ | 残る独立点数は偶数 |
| $c_i$ ($i>0$) | $1$ | 中心の私有葉 $a$ が奇数、その他は偶数 |
| 中心の私有葉 | $F(n)$ | 中心が消え、各外側頂点には正の偶数枚の私有葉が残る。$a-1$ は偶数枚の孤立点 |
| 二点型 $\{c_0,c_i\}$ ($1\le i\le p$) | $F(n-1)$ | 中心と $c_i$ が消え、$a+(b_i-1)$ は偶数枚の孤立点 |
| 外側 $c_j$ の私有葉 ($j>p$) | $1\oplus g(G(p,m-1))$ | $d_j-1$ は奇数枚の孤立点 |

二点型を打った後、他の枝の二点型は残るクリーク頂点の私有葉になるため、上の $F(n-1)$ が正しい。ここが偶数重複を利用する箇所である。

$p\ge3$ なら $n\ge3$ で $F(n)=F(n-1)=1$。$m=0$ では子の値集合が $\{0,1\}$ だから $g=2$。$m>0$ では帰納法の仮定 $g(G(p,m-1))=2$ より子の値集合は $\{0,1,3\}$ であり、やはり $g=2$。

$p=2$ の $m=0$ では $F(2)=1,F(1)=2$、子の値集合は $\{0,1,2\}$ なので $g=3$。$m\ge1$ では私有葉を打つ手から $1\oplus3=2$ が現れ、他の手の値は0,1または2に限られるので帰納的に $g=3$。

$p=1$ の $m=0$ では $F(1)=2,F(0)=0$ で $g=3$。$m\ge1$ は同じ帰納法で $g=3$。

$p=0,m=0$ は奇数枚の葉を持つ星 $K_{1,a}$ で $g=1$。$p=0,m=1$ は $F(1)=2$ を使って子の値集合 $\{0,1,2\}$ となり $g=3$。$m\ge2$ でも外側の私有葉から $1\oplus3=2$ が現れるので $g=3$。以上で全称証明が完了する。
