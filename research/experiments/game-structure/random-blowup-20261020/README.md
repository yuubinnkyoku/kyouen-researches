# 二点禁止残局の独立類膨張：無作為終局分布の厳密な縮約

2026-10-20。対象は有限の二点禁止集合だけを持つ残局（競合グラフの独立集合を一石ずつ増やす通常プレイ）。勝敗最適戦略ではなく、各手で合法点を重みに比例して選ぶ確率過程である。11×11空盤勝敗や実残局での速度改善は主張しない。

## 全称定理：点数に依存しない類グラフの確率再帰

任意の有限単純グラフ `H` の頂点 `i=1,...,d` を、`k_i>=1` 個の互いに非隣接な点からなる類 `X_i` に置換し、`ij∈E(H)` なら `X_i` と `X_j` の間を完全結合する。得られる競合グラフを `G` とする。各点 `v` に任意の正の重み `w_v` を付け、毎手、合法な未占有点 `v` をその重みに比例して無作為に選ぶ。類内の重みは**等しくなくてもよい**。

`λ_i=Σ_{v∈X_i}w_v`、`N_H[i]` を類グラフでの閉近傍とする。`U⊆V(H)` に残る利用可能類から始めた終局類集合の確率分布 `F_U(I)` は、

```
F_empty(empty)=1
F_U(I)=sum_{i in U, i in I} [λ_i / sum_{j in U} λ_j]
                              F_{U\N_H[i]}(I\{i})    (U nonempty)
```

で正確に計算できる。到達可能な `U` は高々 `2^d`。指定した終局集合1個の確率または期待終局石数は `O(d 2^d)` 回の有理数演算で計算できる。石数分布全体は、`N=Σk_i` として多項式を保持すれば `O(Nd2^d)` 回の演算で求められる。終局類集合をすべて明示列挙する場合は、分布表の結合費用が追加される。初期類集合が空でない一般局面はこの式をそのまま適用できない場合があるため、**全類が未着手の初期局面**に限定する。

終局には選ばれた各類の `k_i` 点がすべて置かれ、他の類は0点となる。したがって終局の石数は `sum_{i∈I} k_i`。可能な `I` は `H` の極大独立集合にちょうど一致し、それぞれの終局配置は一意である。

### 証明

各点に独立な指数待ち時間 `Exp(w_v)` を一度だけ割り当て、時刻順に見て、着手時点で合法なら採用し、違法なら永久に棄却する。合法性は石の追加で失われることはあっても回復しない。指数分布の無記憶性により、現在合法な点の次の到着者は、その重みを合法点の重み総和で割った確率で選ばれる。ゆえにこの一括優先順位方式は毎手の重み付き合法点抽出と同分布である。

類 `i` の最初の到着時刻は、`k_i` 個の独立な `Exp(w_v)` の最小値なので `Exp(λ_i)`。異なる類の最初の到着時刻は独立。類の最初の点が採用されれば隣接類は以後すべて違法になり、採用類の残りの点はすべて最終的に採用される。従って採用される類集合は、`H` 上で独立な `Exp(λ_i)` 優先順位に従って貪欲に極大独立集合を作る操作と同じ。最初に採用される類が `i` である確率は `λ_i/Σ_{j∈U}λ_j`、その後の利用可能類は `U\N_H[i]`。再帰式が従う。□

**注意：** 一般の交換可能禁止超グラフではこの `2^d` 縮約は成り立たない。各類内に禁止辺がないこと、類間の二点禁止が完全結合か空かのいずれかであることが必要。重みが類内で異なる場合も `λ_i=Σ_{v∈X_i}w_v` によって成立する。

## 4類道型の閉公式と18点の厳密値

`H=P4`、類の順を `1-2-3-4`、率を `(a,b,c,d)`、`L=a+b+c+d` とすると、終局類集合は `{1,3}`, `{1,4}`, `{2,4}` だけで、

```
Pr({1,3}) = c/L + (a/L) * c/(c+d)
Pr({1,4}) = (a/L) * d/(c+d) + (d/L) * a/(a+b)
Pr({2,4}) = b/L + (d/L) * b/(a+b)
```

となる。各項は最初に選ばれる類で場合分けしたもの。

`k=(3,4,5,6)`、各類内で一定の重み `w=(1,2,3,4)` なら `λ=(3,8,15,24)` で、石数8,9,10の終局確率は順に `21/65`, `24/143`, `28/55`。期待終局石数は `6568/715`。同じ配置で `w=(1,1,1,1)` とすると既存の一様合法着手結果 `35/99`, `18/77`, `26/63` に戻る。
