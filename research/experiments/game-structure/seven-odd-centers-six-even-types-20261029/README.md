# 7奇数中心・高々6種類の偶数二点型（2026-10-29）

## 結論（数学的縮約＋有限完全列挙）

通常プレイ Node Kayles の抽象分割グラフ。クリークは7頂点、各中心に任意の正の奇数枚の私有葉を付ける。各中心対 ij に、その2中心にだけ隣接する独立点を任意の非負整数 c_ij 枚置く。他の辺・頂点はない。

**正の偶数 c_ij を持つ中心対が高々6組なら、Grundy数は奇数 c_ij の組だけを辺とする単純グラフ P の同型類で決まる。正の偶数重複をすべて0にしても変わらず、0 ≤ g ≤ 3。**

6組というのは偶数点の総枚数ではなく、重複が正の偶数である中心対の種類数。重複数そのものには上限を設けない。

## 根拠と計算範囲

[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、各正の奇数私有葉は1枚、奇数二点型は1枚、正の偶数二点型は2枚へ厳密に縮約できる。**2枚を0枚へ消せることはK0336からは従わない**ので、以下で別途完全列挙する。

7中心の奇数二点型グラフの全2^21=2,097,152ラベル付き構成を、隣接交換が生成するS7の軌道で1,044同型類に分ける。各代表Pの非辺から0〜6種類を選び、各2枚を置いた全構成を検査する。軌道サイズ総和が2,097,152なので、全ラベル付き構成を漏れなく覆う（軌道代表を固定したため重複検査はあり得る）。

| 正の偶数二点型の種類数 | 代表×選択の完全検査数 |
| ---: | ---: |
| 0 | 1,044 |
| 1 | 10,962 |
| 2 | 56,318 |
| 3 | 187,891 |
| 4 | **457,353** |
| 5 | **866,643** |
| 6 | **1,333,604** |
| 合計 | **2,913,815** |

0〜3種類は[先行研究](../seven-odd-centers-three-even-types-20261029/README.md)で独立な2方式の完全照合済み。今回、4〜6種類の**2,657,600構成すべて**を近傍型個数のmex再帰で完全検査し、不一致0。4種類の457,353構成については、名前付き頂点の閉近傍削除による別方式でも**全件照合し不一致0**。5種類・6種類については、各軌道代表で辞書順の最初・中央・最後の組合せを名前付き頂点方式で追加検査し、各3,033構成・2,930構成で不一致0。**5〜6種類の独立方式による全件照合は行っていない。**

基底の単純グラフ1,044同型類のGrundy値分布はg=0,1,2,3が順に27,27,495,495。0〜6種類の拡張はすべてこの基底値と一致した。

したがって主張は有限標本からの外挿ではなく、K0336による全称縮約と再現可能な有限完全列挙に基づく。ただし有限列挙の健全性は検証器実装に依存し、5〜6種類では独立な全件検証が未完了。

## 限界・次の課題

7中心で正の偶数二点型が7種類以上の場合は未確定。全三値基底3^21=10,460,353,203構成の完全分類はしていない。8中心以上、私有葉が偶数または0、3中心以上に隣接する独立点、整数格子上の実現可能性も対象外。11×11空盤勝敗には直接の結論を与えない。
