# 連結・独立側次数2以下の分割グラフでGrundy値6・7（2026-10-28）

## 新しい有限の厳密証人

二点残余禁止ゲーム（Node Kayles）を考える。グラフはクリーク C={c0,...,c(k-1)} と独立集合 I に分割し、独立点の近傍をクリーク点のビット集合で記す。例えば署名5は{c0,c2}。署名の重複は**異なる独立点**を表す。

- **Grundy 7**：k=7、署名 [3,3,5,9,9,20,20,32,36,36,48,65,65]。**20頂点・46辺**、連結、独立側次数1または2。
- **Grundy 6**：k=6、署名 [3,3,4,4,5,9,9,16,20,20,33,33]。**18頂点・36辺**、連結、独立側次数1または2。

全初手の子Grundy値を c0,...,c(k-1)、続いて署名の記載順に並べると：

- g=7 の証人：[0,1,0,1,0,1,1,2,2,2,2,2,3,3,6,4,4,5,2,2]。集合は{0,1,2,3,4,5,6}なのでmexは**7**。
- g=6 の証人：[1,0,1,0,1,0,3,3,5,5,3,3,3,4,2,2,3,3]。集合は{0,1,2,3,4,5}なのでmexは**6**。

したがって、以前の「独立側次数2の連結分割グラフで6以上を実現できるか」という問いには肯定的な答えが得られた。**この族に一様な上界があるか、これらの頂点数が最小かは未解決**。一般の共円格子残局として実現できるかも未確認。

## 検証と証拠水準

これは**明示グラフに対する有限の厳密な値**であって、族全体の最大値や最小頂点数の全称定理ではない。以下の互いに異なる計算で確認した。

1. verify.py の名前付き頂点・閉近傍削除による直接メモ化mex：20頂点例は11,408到達状態、18頂点例は5,590到達状態。全初手の値も確認。
2. 同じ verify.py の**クリーク部分集合のみの再帰**：独立点の活動数の偶奇と近傍署名を使う、既存の分割グラフ全称再帰を独立実装。2^7=128、2^6=64のクリーク部分集合を評価。
3. verify_cpp.cpp の**全誘導部分グラフの底からの動的計画法**：20頂点例の2^20=1,048,576状態、18頂点例の2^18=262,144状態を省略なく評価し、根と全初手を照合。

三方式は根・全初手について完全一致。verify.py は連結性と独立側次数条件も検査する。C++の全状態検査はグラフ上の二点禁止ゲームに関するもので、整数格子幾何の検査ではない。

## 適用範囲・引き継ぎ

標準の共円ゲームへ適用するには、ある安全局面の**全ての包含極小残余禁止集合が二点**であり、その競合グラフが本構造を持つことが必要。11×11の空盤勝敗には直接の結論を与えない。

次の課題は、次数2分割グラフでのg>=8の構成、一様上界の有無、18/20頂点証人の真の最小性、実際の幾何残局での出現検査。knowledge正本への昇格は、生成索引を再構築・検査できる環境で行う（生成ファイルは手編集しない）。
