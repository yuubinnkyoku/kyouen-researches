# 分割中心の任意群数・全中心型重複数に対するGrundy完全公式（2026-10-29）

## 定理（通常 Node Kayles、抽象分割グラフ）

中心クリーク \(C\) を空でない \(k\) 群 \(C_1,\ldots,C_k\) に分割し、\(|C_i|=a_i\ge1\)、\(n=\sum_i a_i\) とする。各中心には私有葉を1枚、各群 \(C_i\) にはその群の中心すべてに隣接する独立点を1枚付ける。さらに全中心に隣接する独立点を \(u\ge0\) 枚付ける。これらの独立点間には辺を張らない。得られるグラフを \(G(a_1,\ldots,a_k;u)\) とする。

\(e=(n+k)\bmod2\) とおくと、**任意の正整数 \(k,a_1,\ldots,a_k\)、任意の \(u\ge0\)** について

\[
\boxed{
g(G)=
\begin{cases}
1-e,& k=1,\ u\text{ が奇数},\\
2+e,& k=1,\ u\text{ が偶数（0を含む）},\\
2+e,& k\ge2,\ u>0\text{ が偶数},\\
1-e,& k\ge2,\ u=0\text{ または奇数}.
\end{cases}}
\]

特に \(k\ge2\) では全中心型を0枚から**正の偶数枚**へ増やすと、必ずGrundy数が \(0\leftrightarrow3\) または \(1\leftrightarrow2\) の形で変わる。一方、0枚から**奇数枚**への追加ではGrundy数は変わらない。群数も各群の大きさも無制限である。既存の二群定理を \(k\) 群および奇数全中心型へ拡張する。

[K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、私有葉の各重複数と群型の各重複数を任意の正の**奇数**へ変えても同じ式が成立する。全中心型は、0枚・正の奇数枚・正の偶数枚の三場合だけを調べれば十分である。\(k=1\) では群型と全中心型が同じ近傍だが、同一linkの偶奇圧縮を合わせて適用できる。

これは**抽象分割グラフ**のNode Kayles定理であり、整数格子上の共円ゲームの局面として実現できるとは主張しない。

## 数学的証明（計算機非依存）

K0336により全中心型の重複数 \(u\) は \(0,1,2\) のみを考えればよい。途中で中心が消えた群の私有葉・群型・全中心型は孤立点となる。孤立点1個のGrundy数は1なので、その寄与を xor で分離する。

生存中心数のベクトルを \(\boldsymbol a=(a_1,\ldots,a_k)\) とし、零成分を許す。非零成分の数を \(r\)、生存中心総数を \(N\) とする。非孤立核のGrundy数を \(h_u(\boldsymbol a)\)、\(h_u(\boldsymbol0)=0\) と定める。\(N>0\) なら非孤立独立点数の偶奇は

\[
p_u(\boldsymbol a)=(N+r+u)\bmod2,\qquad e(\boldsymbol a)=(N+r)\bmod2.
\]

**重要：** \(N=0\) では全独立点が孤立して核の外にあるため \(p_u(\boldsymbol0)=0\) とする。\(u\) が奇数の場合に \(p_u(\boldsymbol0)=1\) と誤って置くと、一群境界が間違う。

中心を選ぶと中心はすべて消え、選択した中心の私有葉1枚・群型1枚・全中心型 \(u\) 枚が取り除かれる。したがって子の値は常に \(e(\boldsymbol a)\)。

私有葉または群型を選んで生存中心数が \(\boldsymbol a'\) になったとき、子の値は

\[
h_u(\boldsymbol a')\ \operatorname{xor}\
\bigl(p_u(\boldsymbol a)\operatorname{xor}p_u(\boldsymbol a')\operatorname{xor}1\bigr).
\]

全中心型の手（\(u>0\)）の子の値は \(p_u(\boldsymbol a)\operatorname{xor}1\)。これらの mex が正確な再帰である。ここで \(\operatorname{xor}\) は整数のビットごとの排他的論理和であり、括弧内は0か1である。

### 境界：生存群が1個

生存中心数を \(N\ge1\)、\(e=(N+1)\bmod2\) とする。

- \(u=0,2\)：中心の手は \(e\)、群型の手は \(1-e\)（\(u=2\) の全中心型の手も同値）。\(N=1\) ではこの二値の mex が \(2\)。\(N\ge2\) では私有葉の手が帰納法から \(3-e\) を追加する。よって \(h_0=h_2=2+e\)。
- \(u=1\)：中心・群型・全中心型の手はすべて \(e\)。私有葉の手も \(N=1\) では同じ、\(N\ge2\) では帰納法から \(e\)。よって \(h_1=1-e\)。

### 帰納：生存群が2個以上

生存群数を \(r\ge2\)、\(e=(N+r)\bmod2\) とし、まず総中心数 \(N\) の小さい状態の式を仮定する。

- 中心の手は、どの \(u\) でも \(e\)。
- 私有葉の手：属する群に2中心以上残るなら \(N\) が1減り \(r\) は変わらず、偶奇補正は0。群に1中心しか残らなければ \(r\) も1減り、偶奇補正は1。境界と帰納仮定から、\(u=1\) では常に \(e\)、\(u=2\) では常に \(3-e\)。\(u=0\) では \(r=2\) で一中心群を消す場合だけ \(3-e\)、それ以外は \(e\)。
- 群型の手：群の大きさを \(a\) とすると、残りが非空なので \(e'=e\operatorname{xor}((a+1)\bmod2)\)、孤立点の偶奇補正は \(a\bmod2\)。帰納仮定から \(r\ge3\) では \(u=0,1\) の子は \(e\)、\(u=2\) の子は \(3-e\)。\(r=2\) では一群境界を用い、\(u=0,2\) の子は \(3-e\)、\(u=1\) の子は \(e\)。
- 全中心型の手：\(u=1\) では \(e\)、\(u=2\) では \(1-e\)。\(u=0\) にはない。

よって候補値の集合は正確に

\[
\begin{array}{c|ccc}
 &u=0&u=1&u=2\\
r=2&\{e,3-e\}&\{e\}&\{e,1-e,3-e\}\\
r\ge3&\{e\}&\{e\}&\{e,1-e,3-e\}.
\end{array}
\]

それぞれ mex を取ると \(h_0=h_1=1-e\)、\(h_2=2+e\)。一群境界と総中心数に関する強い帰納法で全状態について成立し、初期の \(r=k,N=n\) に代入して定理を得る。**有限実験に依存しない全称証明**である。

## 独立検証・再現

[verify.py](verify.py) は、(1) 中心・私有葉・群型・全中心型を別々の名前付き頂点として作り、ビット集合による閉近傍削除と mex で直接求める方式と、(2) 生存中心数ベクトルと孤立点の xor 補正による方式を**独立に**実装する。

- 名前付き頂点の直接再帰：総中心数 \(n\le7\) の全順序付き正整数分割、さらに \(n=8,u=0,2\) の全分割について、**637局面**で公式と一致。
- ベクトル再帰：\(n\le9,u=0,1,2\) の全順序付き分割、および長さ1〜6・各成分0〜3・総中心数9以下の境界を合わせて**11,928局面**で一致。
- 私有葉3枚・群型3枚・全中心型3/4枚を含む重複数変更を名前付き頂点で**12局面**検査。すべて一致。

実行：

    python3 research/experiments/game-structure/partitioned-centers-multigroup-universal-parity-20261029/verify.py

期待される出力：

    PASS named_vertex_roots=637, varied_multiplicity=12, quotient_states=11928

## 既存結果との関係・限界

- [二群の偶数全中心型反例](../partitioned-centers-even-universal-counterfamily-20261029/README.md)を、任意群数 \(k\ge2\) と奇数全中心型まで厳密化した。二群 \(k=2\) の旧式 \(g_0=1-(n\bmod2),g_2=2+(n\bmod2)\) は \(e=(n+2)\bmod2\) から復元する。
- 全中心型以外の任意の近傍型を追加してよいとは主張しない。五中心・三点型の一般的消去問題を解決したものではない。
