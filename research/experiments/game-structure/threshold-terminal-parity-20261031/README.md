# 閾値グラフの極大独立集合・終局長分布と通常/misère勝敗（2026-10-31）

## 範囲と既存成果との差分

閾値グラフを空グラフから「孤立点追加 I」「全既存点への支配点追加 D」で構築し、閉近傍削除型 Node Kayles（合法着手集合は独立集合）を考える。最初の操作は空グラフ上で I に正規化できる。空語も許す。

既存の [通常/misère 5状態計算](../threshold-misere-five-state-openings-20261031/README.md) は根のGrundy値と勝ち初手を与える。本結果は**極大独立集合（終局集合）の全分類・終局長別の全合法着手順序数・終局長の偶奇だけによる通常/misère勝敗の判定**を与える。r人対戦については全合法履歴の勝者別度数を数えるだけで、戦略的な必勝性を主張しない。

構築語を t_1,...,t_n とし、I の総数を N、D の位置 j より前の I の数を p_j とする。空語なら N=0。

## 定理1：終局集合の全分類

極大独立集合は、次のもの**ちょうどすべて**である。

1. すべての I 頂点からなる集合 A（空語なら空集合）。
2. 各 D 位置 j ごとの集合 B_j = {j} ∪ {i>j : t_i=I}。

A と各 B_j は相異なり、終局集合は正確に 1+#D 個。その石数は

[
|A|=N,qquad |B_j|=1+N-p_j.
]

**証明**：独立集合は D を高々1個含む。D_j を含めば、それ以前の全頂点とそれ以後の D は隣接して選べない。一方それ以後の I は全て D_j と非隣接で、極大なら全て含まなければならない。D を含まなければ、極大性により全 I を含む。最初の I はすべての後続 D に隣接するので A は極大（空語でも成立）。各 B_j は、j の閉近傍外の全頂点を含むため極大。□

## 定理2：全合法履歴の長さ分布

最後の一手までの合法着手順序を「完全履歴」と呼ぶ。任意の独立集合の全順列は合法なので、終局集合 S への完全履歴は |S|! 通り。したがって長さ k の完全履歴数は

$
\boxed{H_k=\mathbf 1_{N=k}N!+\sum_{j:t_j=D}\mathbf 1_{1+N-p_j=k}(1+N-p_j)!}.
$

全完全履歴数は N!+Σ_{j:D}(1+N-p_j)!。0!=1 とする。

r≥2人が巡回して最後の着手者だけを勝者とする場合、勝者番号 a∈{1,...,r} の完全履歴数は Σ_{k≥0:k≡a (mod r)}H_k（余り0はa=r）。これは**全合法履歴の度数**であり、各プレイヤーの合理的戦略や着手を一様選択した確率ではない。空語の長さ0は誰も着手していないため、勝者別集計から除く。

## 定理3：終局長の偶奇が通常/misèreの勝敗を決める

次の二条件は同値である。

- 終局集合の石数に偶数と奇数が両方存在する。
- p_j が偶数となる D 位置 j が存在する。

これらが偽なら、全終局長は N と同じ偶奇で、根の通常Grundy値とmisère補助mex値は (g,h)=(N mod 2,1-(N mod 2))。

これらが真なら、**両ルールとも初手番側が勝つ**。さらに最初の p_j 偶数の D 位置を j* とし、j* より後の I 個数を s とすると、

$
\boxed{(g,h)=(2+(s\bmod 2),\,2+(s\bmod 2))}.
$

したがって閾値グラフでは、終局長がすべて偶数なら通常版が後手勝ち・misère版が先手勝ち、すべて奇数ならその逆、偶奇混在なら**両ルールで先手勝ち**。これは「どの初手でも両方勝てる」という意味ではない（既存定理では勝ち初手集合は互いに素）。

**証明**：|B_j|−N=1−p_j より、A と B_j の長さの偶奇が異なるのは p_j 偶数のときに限る。前半の値は既存5状態遷移表から従う。実際、初期 E のあと最初の I で A 状態となり、偶数個の I の後は B、奇数個の I の後は A。偶数 p_j の D が現れるまでは D は A→A しか起こさず、状態は I 個数の偶奇で A/B を往復する。最初の該当 D で B→C（g=2）、以後は D が C/D 状態を保持し、I が C↔D を切り替える。ゆえに最終値は 2+(s mod2)。既存の分割グラフmisère交換則 h=τ(g) により h は g≥2 では等しく、g≤1 では 0/1 が交換される。これは任意長の構築語に対する全称証明である。□

## 独立検算

[verify.py](verify.py) は予測式を用いず、各構築語から隣接行列を作り、閉近傍削除の厳密mex再帰で (g,h) と全合法履歴の長さ別度数を算出する。また全 2^n 頂点集合を独立・支配条件で直接調べて極大独立集合の石数分布を求める。

正規化した0〜11頂点の**全2,048構築語**を完全検査し、(g,h)、終局集合数、終局長分布、完全履歴数、偶奇判定すべて不一致0。うち1,672語が偶奇混在だった。再現：`python3 research/experiments/game-structure/threshold-terminal-parity-20261031/verify.py`。

数学的全称性は上の証明と既存5状態・misère交換則に依存する。有限検算は独立した誤り検出であって無界定理の根拠そのものではない。実際の共円ゲーム残局に閾値グラフが現れる頻度、11×11探索の速度効果は未測定。knowledge正本への昇格と全体CIは未実施。
