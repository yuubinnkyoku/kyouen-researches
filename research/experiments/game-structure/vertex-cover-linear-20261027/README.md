# 二点残余禁止ゲーム：頂点被覆数に対する線形Grundy上界（2026-10-27）

## 結論（数学的な全称定理）

有限単純グラフ `G` 上で、手として頂点 `v` を選び、閉近傍 `N[v]` を削除する通常プレイ（Node Kayles）を考える。`τ(G)` を最小頂点被覆数、`g(G)` をGrundy値とする。

**任意の `τ(G)≥2` に対し、頂点数・辺数に依存せず**

\[
\boxed{g(G)\le 2\tau(G)-1}.
\]

さらに `τ(G)≥3` で孤立点がない場合は

\[
\boxed{g(G)\le 2\tau(G)-2}.
\]

特に `τ≤4` なら `g≤7`。`τ=4` で孤立点なしの上界6、一般の上界7はいずれも鋭い。`τ=2` の上界3、`τ=3` の上界5も既知の証人により鋭い。

これは既存の [被覆数2の全称定理](../vertex-cover-two-grundy-20261027/README.md) を基底とする**数学的帰納法の全称証明**であり、被覆数4以上について新たな完全列挙を必要としない。被覆数3の既存の計算機援用上界5も、同じ帰納法から（被覆数2の上界3を用いて）再証明できる。ただし既存の被覆数3の鋭い証人は別途必要である。

## 証明

**補題（被覆数の減少）。** 孤立点のない非空グラフ `H` とその頂点被覆 `C` を取り、`|C|=k` とする。どの合法手 `v` に対しても、`H-N[v]` は高々 `k-1` 個の頂点で被覆できる。

実際、`v∈C` なら `C\{v}` が残りの辺を被覆する。`v∉C` なら、孤立点がないため `v` は少なくとも一つの `C` 内の隣接点を持つ（`V(H)\C` は独立集合）。その隣接点は `N[v]` とともに消えるので、`C\N[v]` は残りの辺を被覆し、大きさは高々 `k-1` である。

**帰納法。** 被覆数 `τ≤2` なら既存の数学的全称定理から `g≤3`。`k≥3` とし、被覆数が `k-1` 以下の全グラフで `g≤2k-3` が成立すると仮定する。孤立点のない `τ=k` のグラフ `H` では、補題よりすべての子局面の被覆数は `k-1` 以下。従って各子のGrundy値は `0,...,2k-3` に含まれ、

\[
g(H)=\operatorname{mex}\{g(H-N[v]):v\in V(H)\}\le2k-2.
\]

一般の `G` から孤立点を除いた核を `H` とする。孤立点は一頂点ゲームの直和なので `g(G)=g(H)\mathbin{\mathrm{xor}}(f\bmod2)`。`2k-2` は偶数だから、`0≤g(H)≤2k-2` の範囲を0または1とxorしても高々 `2k-1`。これで帰納法が閉じる。`τ=2` の場合は既存の上界3を直接用いる。

`τ≤4` については、`τ≤2` で3以下、`τ=3` で5以下、`τ=4` で7以下なので全体で7以下。

## 最小頂点数の一般下界への帰結

既存の `g(G)≤α(G)`（`α` は独立数）と `|V|=α+τ` を使う。`g≥4` なら被覆数は少なくとも3であり、上の上界から

\[
\tau(G)\ge\left\lceil\frac{g(G)+1}{2}\right\rceil,
\qquad
\boxed{|V(G)|\ge g(G)+\left\lceil\frac{g(G)+1}{2}\right\rceil}.
\]

これは既存の `g=4,...,7` の最小頂点数7,8,10,11を一つの式で説明し、**未確定の `g=8` に必要な頂点数を従来の12以上から13以上へ改善する**。13頂点で実現できるかは未解決。

## 鋭さと独立検証

既存の [最小頂点数の証人](../grundy-minimum-vertices-seven-20261027/README.md) の10頂点・9辺グラフ

`(0,1),(0,2),(0,3),(1,4),(2,4),(3,5),(4,6),(7,8),(7,9)`

は孤立点なし、`τ=4`、`g=6`。孤立点10を一つ追加すると `τ=4` のまま `g=7`。上界は両方とも鋭い。証人は既存成果の再利用であり新発見ではない。

[verify.py](verify.py) は**証明とは独立した有限検査**として、6頂点以下の全33,868個のラベル付きグラフ、指定被覆3〜5頂点を持つ9・11・13頂点の乱数標本計1,800個、上記二つの鋭い証人を検査する。Grundy値は残存頂点再帰と占有独立集合再帰の二方式で照合し、独立数は部分集合全走査で求める。すべて一致した。

```sh
python3 research/experiments/game-structure/vertex-cover-linear-20261027/verify.py
```

**適用範囲：** 二点集合のみを包含極小残余禁止集合として持つ局面の抽象グラフに限る。三点以上の残余禁止集合、misère、多人数対戦にはそのまま適用できない。標準整数格子への証人埋め込みと11×11の探索時間短縮は未検証。乱数検査は全称証明の代わりではない。
