# 偶数三点型の消去：5中心・6中心の限定全称定理（2026-10-29）

## 結論と量化範囲

抽象分割グラフの通常 Node Kayles（独立集合への一点追加）を考える。中心集合 C は大きさ k のクリークで、各中心には **正の奇数枚**の私有葉がある。その他の独立点の近傍は C の部分集合（大きさ2以上）で、正の重複数はすべて奇数とする。ただし、指定された三点型 T には **偶数枚を別途追加**してよい。他の正の偶数近傍型は許さない。

正の奇数重複を持つ非私有近傍型の**種類数**を t とする。このとき、次の二つが成立する。

- k=5 かつ t≤7：T に任意の正の偶数枚を追加しても Grundy 数は不変。
- k=6 かつ t≤5：同じ結論が成立。

T が元から奇数重複で存在していてもよい。T はどの三中心でもよい。**k=5 の t≥8、k=6 の t≥6、k≥7、他の偶数近傍型が共存する場合については主張しない。** 特に中心数一般の偶数三点型消去定理ではない。整数格子上の共円残局としての実現可能性も未確認。

## 全称性の根拠：数学的縮約と有限完全列挙

既存の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同じ非空近傍を持つ独立双子点の**正の**重複数は奇数なら1枚、偶数なら2枚へ縮約しても Grundy 数が変わらない。したがって、各私有葉型と奇数非私有型を1枚、追加する偶数三点型を2枚にした有限基底を調べればよい。0枚と2枚の同値性は K0336 からは出ず、以下の完全列挙で別途検証する。

指定三点型は中心の置換で {0,1,2} に固定できる。残る中心置換の安定化群は k=5 で S3×S2（12元）、k=6 で S3×S3（36元）。サイズ2以上の全近傍型をビット集合で列挙し、奇数型集合を安定化群で最小の代表に正規化する。代表を**すべて**列挙して、追加前後の Grundy 数を厳密な mex 再帰で比較した。

| 中心数 k | 許容する奇数非私有型 t | 近傍型の総数 | 対称性削減前の全構成 | 完全検査した軌道代表 | 別方式の独立照合 |
|---:|---:|---:|---:|---:|---:|
| 5 | 0〜7 | 26 | 971,712 | **88,954** | 9,964 |
| 6 | 0〜5 | 57 | 4,613,030 | **157,754** | 6,342 |
| 合計 | ― | ― | 5,584,742 | **246,708** | **16,306** |

全代表で追加前後の値は一致し、独立照合も全件一致した。したがって**この明示的に限定した無限族については、有限基底の完全検査と K0336 の数学的縮約による全称証明**になっている。独立照合は全代表ではなく、規則を固定した部分集合である。

## 二つの検証方式

[verify.cpp](verify.cpp) は C++17 で、以下の異なる再帰を実装する。

1. **名前付き頂点の残存集合**：任意の頂点を選んでその閉近傍を消去し、残存部分グラフの mex を求める（全246,708代表）。
2. **独立葉の選択済み集合**：葉を追加するか、現在の葉と競合しない中心を選ぶ。中心を選ぶと他の中心は全滅し、残りの非隣接葉は孤立点なので Grundy 数はその個数の偶奇（16,306代表の追加前後）。

二方式は局面表現・漸化式・中心着手後の処理が異なる。両方式の照合は標本検査であり、有限基底の網羅性は第一方式の全軌道列挙に依存する。

再現（repo 直下から）：

```sh
c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/even-triple-support-bounded-orbits-20261029/verify.cpp -o /tmp/verify-even-triple
/tmp/verify-even-triple 5
/tmp/verify-even-triple 6
```

期待出力：

```text
k=5 all=971712 orbits=88954 independent=9964 mismatches=0
k=6 all=4613030 orbits=157754 independent=6342 mismatches=0
```

全軌道・独立照合の件数はプログラム内で assert している。
