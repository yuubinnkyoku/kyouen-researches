# 交換可能点群の一様合法着手：終局確率の厳密計算

2026-10-20。標準共円ゲームの残余禁止集合族を含む、任意の有限下方閉一点追加ゲームについての全称定理。既存の計数ベクトル商による Grundy 値・極大配置数・着手順数の計算を、**一様合法着手における終局分布**へ拡張する。通常の最善手戦略の勝率ではない。

## 命題

点集合を互いに素な `X_1,...,X_d` に分割し、各類内の**任意の置換**が禁止集合族を保存すると仮定する。類の大きさ `k_i`、現在の占有数 `a_i` とし、全禁止集合の類別占有数を profile `p` として保持する。

安全性は、全 profile `p` に対して `p <= a` が成り立たないことと同値。`a+e_i` が安全かつ `a_i<k_i` の場合だけ、類 `i` から合法手が存在する。そのときその類の未占有点 `k_i-a_i` 個は**すべて合法**である。

各着手で現在の合法な未占有点の中から一様に1点を選ぶ規則なら、

```
W(a) = sum_{i : a+e_i is safe} (k_i-a_i)
Pr(a -> a+e_i) = (k_i-a_i)/W(a)     (W(a)>0)
```

となる。`W(a)=0` は吸収終局状態である。初期安全ベクトル `a0` に質量1を置き、`sum(a)` の昇順で質量を伝播すれば、**全ての終局ベクトルの確率**が正確な有理数で得られる。終局石数の分布・期待値も直接求められる。

状態数は高々 `M=product_i(k_i+1)`、安全判定を事前計算すれば伝播は `O(dM)` 回の有理数演算で済む。安全判定の費用、類の発見、整数演算の桁数は含めない。初期状態を固定すれば、到達可能な部分だけを扱ってよい。

## 全称証明

各類の全置換不変性により、占有数ベクトルが等しい任意の2局面は自己同型で移り合う。特に未占有の類内点は全て等価である。したがって類 `i` への追加が合法なら、その類の未占有点はちょうど `k_i-a_i` 個すべて合法。ラベル付き合法点からの一様抽出を類別に合算した確率は上式に一致する。

着手ごとに `sum(a)` が1増えるため、占有数ベクトルの有向グラフは非巡回である。前向き確率伝播はラベル付き全履歴の確率を同じベクトルごとに足し合わせる操作と厳密に一致し、全質量は各非終局点で保存される。有限性により全質量が終局へ到達する。ゆえに吸収質量は各終局ベクトルの正確な確率である。□

**注意：** 単なる自己同型の軌道を交換可能類とみなすことはできない。また、終局配置の個数分布（均等な極大集合抽出）と、一様合法手の終局確率は一般に異なる。

## 18点の具体例

類サイズ `(3,4,5,6)`、隣接類間の全二点組を禁止する4頂点道型（既存の `count-vector-quotient-20261020` の例）では、極大配置は次の3個だけである。

| 終局占有数 | 石数 | 一様合法着手での確率 |
|---|---:|---:|
| `(3,0,5,0)` | 8 | `35/99` |
| `(3,0,0,6)` | 9 | `18/77` |
| `(0,4,0,6)` | 10 | `26/63` |

合計確率は1、終局石数の期待値は `6278/693 ≈ 9.05916`。各終局配置を一様に選んだ場合の平均9とは異なる。既存の全着手順数 `8!+9!+10!=4,032,000` からも、この確率は直接は導けない（各手の合法候補数による重みが必要）。
