# 欠損 K5 と任意の劣3次グラフの非交和：k≥7 でGrundy統一公式（2026-10-28）

## 新しい全称定理

通常プレイの Node Kayles を、クリーク C（頂点数 k）と、クリークの1点または2点にのみ隣接する独立点からなる分割グラフ G で考える。独立点の近傍型 i の重複数を t_i≥0、近傍型 {i,j} の重複数を r_ij≥0 とする。二点型が存在しない組からなる欠損グラフ D を定義する。

**k≥7 で、D が K5 と任意の最大次数3以下の単純グラフ H の非交和（D=K5 ⊔ H、|V(H)|=k−5、Δ(H)≤3）なら、任意の重複数に対して**

```text
u   = (sum_i t_i + sum_{i<j} r_ij) mod 2
z_i = (t_i + sum_{j≠i} r_ij) mod 2
g(G) = 1 xor u xor z_0    (全 z_i が同じ)
g(G) = 2 + u              (z_i が混在)
```

**特に g(G)≤3。** H の辺数には固定の上限がない。K5の外側の欠損配置は道・閉路・3正則グラフなど任意の劣3次グラフでよい。これは既存の「欠損が K5 のみ」の定理を真に拡張し、欠損最大次数4の無限族を与える。**k≥7 は鋭い。** k=6、D=K5⊔K1 には既存の16頂点反例（真のGrundy値3、公式値2）がある。\n\nただし **任意の Δ(D)≤4** を証明したわけではない。

独立側の孤立点がある場合は、その個数の偶奇を最終結果に xor する。

## 証明

### 使用する既知補題

1. [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md)：同一非空近傍を持つ独立点は 0 / 正の奇数 / 正の偶数に厳密縮約できる。
2. [欠損最大次数3、k≥6 の定理](../missing-max-degree-three-k6-plus-20261028/README.md)。
3. [k=5、欠損 K4⊔K1 の私有葉補題](../missing-k4-degree-three-20261028/README.md)：K4側の少なくとも2頂点が私有葉を持てば統一公式が成立。
4. [欠損 K5 の正葉補題](../missing-k5-clique-sharp-threshold-20261028/README.md)：k=5、D=K5 で5頂点すべてに私有葉がある場合、また k=6、D=K5⊔K1 でK5側の5頂点すべてに私有葉がある場合は公式成立。これらは偶奇縮約後の有限完全列挙で証明済み。

### 子局面の値

親の独立点総数の偶奇を u とする。クリーク点 i を選んだ子局面の値は u xor z_i。

独立点を選び、隣接するクリーク点集合 B（|B|=1 または2）を消す。残るクリーク点の z_i は変わらない。残る非孤立独立点の偶奇を u'、新たに孤立する独立点の偶奇を δ とすると δ=u xor u' xor 1。従って残存非孤立部分に統一公式を使える場合、**この独立点初手の子値**は、残存 z が一様 s なら u xor s、混在なら u xor 3 である。

### k=7 の基底（H は2頂点）

K5内の二点型は欠損なので、選択する独立点の B がK5側を2点含むことはない。

- B が K5 内の1点だけ：生存6点の欠損最大次数は3以下。既存定理を適用。
- B が K5 内の1点と外側1点：生存5点の欠損は K4⊔K1。消した外側点は生存K4の4頂点すべてと二点型を持つため、それらが私有葉となり既存のk=5私有葉補題を適用。
- B が外側1点だけ：生存6点の欠損は K5⊔K1。生存K5の全頂点に、消した外側点との二点型から私有葉ができるため既存のk=6正葉補題を適用。
- B が外側2点：生存5点の欠損は K5。全K5頂点に新しい私有葉ができるため既存のk=5正葉補題を適用。この二点型が欠損なら、そもそもその初手は存在しない。

したがって全ての独立点初手の子値に上記の式を適用できる。

### k=8 と帰納段階

k=8 で B が外側2点なら、生存6点の欠損は K5⊔K1 で、K5側は全頂点が正の私有葉を持つ。外側1点なら生存7点で k=7 の基底が使える。B がK5側を含めば欠損最大次数3以下で生存クリークは6点以上だから既存定理を適用。

k≥9 では、B がK5側を含めば生存クリーク6点以上かつ欠損最大次数3以下。B が外側のみなら生存クリークは少なくとも k−2≥7 点で、欠損は引き続き K5⊔H'（Δ(H')≤3）だから帰納仮定を適用。これで全子局面の式が得られる。

### mex の決定

全 z が一様 s なら、クリーク初手・独立点初手とも子値は u xor s。ゆえに mex は 1 xor u xor s。

z が混在なら、クリーク初手で0と1がともに現れる。さらに、**混在を保ったまま2点を消せる存在二点型**がある：

- 少数派が1点：多数派は6点以上。欠損 D の最大クリークは5点以下（K5とΔ(H)≤3の非交和）なので、多数派内部に存在二点型がある。
- 少数派が2点：多数派は5点以上。欠損最大次数は4なので、少数派の任意の頂点から多数派への存在二点型がある。
- 少数派が3点以上：両派とも3点以上。任意の存在二点型を消しても混在が残る。存在二点型はK5と外側の間に必ずある。

この初手の子値は u xor 3。子値は {0,1,u xor 3} に含まれ、三つとも実現する。従って mex{0,1,u xor 3}=2+u。帰納法が閉じる。
