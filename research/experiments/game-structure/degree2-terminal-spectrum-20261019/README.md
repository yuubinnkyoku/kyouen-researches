# 二点禁止残局・最大次数2の極大配置数と終局石数の完全公式

2026-10-19。**抽象的な二点禁止集合ゲーム**の全称定理。実際の整数格子上で任意の道・閉路が残余局面として実現できるとは主張しない。

## 定理

有限単純グラフ G の独立集合を一点ずつ増やすゲームを考える。合法手がない終局は極大独立集合に一致する。P_n を n 頂点の道（P_1 は孤立点、P_0 は空グラフ）、C_n を n>=3 の閉路とする。

A_G(k) を **ちょうど k 頂点の極大独立集合の個数**とする。範囲外の二項係数を0と定めると、

- n>=1 で **A_{P_n}(k) = binom(k+1, n-2k+1)**、A_{P_0}(0)=1。
- n>=3 で **A_{C_n}(k) = (n/k) binom(k, n-2k)**。

したがって P_n の終局石数は **ceil(n/3) から ceil(n/2) までの全整数**、C_n の終局石数は **ceil(n/3) から floor(n/2) までの全整数**である。

G が道 P_{n_i} と閉路 C_{m_j} の直和なら、極大独立集合の石数別母関数は各成分の多項式の積になる。従って **最大次数2以下の任意の有限単純グラフ**では、終局石数の集合は、各成分の最小終局石数の和から最大終局石数の和までの全整数となる。各石数の終局配置数も係数の畳み込みで正確に求まる。

## 証明

道の極大独立集合を 1<=x_1<...<x_k<=n とする。独立性と極大性は、両端の余白 x_1-1, n-x_k が各0または1、連続する選択頂点の差 x_{i+1}-x_i が2または3であることと同値。よって n=2k-1+e_0+e_k+Σ_{i=1}^{k-1}e_i（e_i∈{0,1}）。k+1個の変数から n-2k+1 個を1にする選択は binom(k+1,n-2k+1) 通りで、余白・間隔から集合を一意に復元できる。

閉路の極大独立集合では、選択したk頂点の循環間隔はすべて2または3。3の間隔が n-2k 個ある。始点を選択頂点として指定した表現は n binom(k,n-2k) 通りで、各集合はk回数えられるから (n/k)binom(k,n-2k) 通り。両公式の二項係数が正になる範囲が上記の閉区間である。

直和の極大独立集合は各成分の極大独立集合の直和に一致する。母関数の積と連続整数区間の和により一般の最大次数2グラフの主張を得る。□

## 系：全極大配置の石数が等しい場合の完全分類

最大次数2以下の G の全極大独立集合が同じ大きさになる必要十分条件は、**各連結成分が P_1, P_2, P_4, C_3, C_4, C_5, C_7 のいずれか**であること（空グラフも許す）。各成分の上記終局石数区間が一点となる場合を列挙すればよい。

この場合、共通終局石数を L とすると、任意の安全局面 S で残り手数が必ず L-|S| となる。終局からの帰納法で **g(S)=(L-|S|) mod 2** が成立し、全安全局面を偶奇で強解決できる。

頂点数が正の G で r>=2 人が交互に着手し最後の着手者を勝者とする場合、**実現可能な最後の着手者の種類数**は min(r,U-D+1) となる。D,U は全成分の最小・最大終局石数の和である。これは到達可能な終局列の主張であり、特定のプレイヤーが戦略的に終局を強制できることを意味しない。

上の全称結論は数学的証明によるもので、有限検算は補助的。標準共円ゲームへの適用は、**残余最小禁止集合が二点集合のみ**であり、対応グラフの最大次数が2以下の場合に限る。三点以上の残余禁止集合が残る局面には適用できない。終局長の区間はGrundy値の上下界を直接与えない。
