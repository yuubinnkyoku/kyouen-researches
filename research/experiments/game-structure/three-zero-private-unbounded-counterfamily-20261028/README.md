# 私有葉ゼロ3頂点の反例は任意に大きいクリークまで続く（2026-10-28）

## 定理：有限の安定化閾値は存在しない

通常プレイの Node Kayles を、クリーク $C=\{c_0,\ldots,c_{k-1}\}$ と独立集合 $I$ からなる分割グラフで考える。独立点のクリーク側近傍は1点または2点。$t_i$ は $c_i$ だけに隣接する独立点数、$r_{ij}$ は $c_i,c_j$ に隣接する独立点数とする。

**定理（数学的全称証明）：** 任意の整数 $k\ge4$ に対し、

$$
t=(1,0,0,0,\underbrace{2,\ldots,2}_{k-4}),\qquad
r_{01}=r_{02}=r_{03}=2,\quad r_{ij}=0\ \text{（それ以外）}
$$

とすると、すべてのクリーク頂点は独立側に隣接しているにもかかわらず、

$$\boxed{g(G_k)=2\qquad(k\ge4)}$$

となる。一方、以前検討した統一公式

$$
u=\left(\sum_i t_i+\sum_{i<j}r_{ij}\right)\bmod2,\qquad
z_i=\left(t_i+\sum_{j\ne i}r_{ij}\right)\bmod2,
$$

$$
\Phi(G)=\begin{cases}1\oplus u\oplus z_0&z_0=\cdots=z_{k-1},\\2+u&\text{otherwise}\end{cases}
$$

は $u=1$、$z=(1,0,\ldots,0)$ より、**全 $k\ge4$ で誤って $\Phi(G_k)=3$ と予測する**。

したがって「私有葉ゼロが高々3頂点で、全クリーク頂点が独立側に接続する」という条件だけでは、**どれほど $k$ を大きくしても統一公式は復活しない**。以前の「私有葉ゼロ高々2頂点かつ全頂点covered」の定理とは矛盾しない。

## 全称証明：二つの短い再帰

$F(n)$ を、クリーク $K_n$ の各頂点に私有葉がちょうど2個あるグラフのGrundy数とする。$F(0)=0$。$n\ge1$ でクリーク頂点を選ぶと独立点が偶数個残り、子の値は0。私有葉を選ぶと、他方の私有葉が孤立し、残りのクリークが $K_{n-1}$ になるので、子の値は $F(n-1)\oplus1$。従って

$$F(n)=\operatorname{mex}\{0,F(n-1)\oplus1\},$$

$$\boxed{F(0)=0,\quad F(1)=2,\quad F(n)=1\ (n\ge2)}.$$

次に、上記 $G_k$ で $m=k-4$ と置き、$H(m)=g(G_{m+4})$ とする。$n=m+3$ と置いて全初手を分類する。

| 初手 | 子のGrundy値 | 理由 |
|---|---:|---|
| $c_0$ | $0$ | 残る独立点は $2m$ 個 |
| $c_i$（$i\ne0$） | $1$ | 残る独立点数が奇数 |
| $c_0$ の唯一の私有葉 | $F(n)$ | $c_0$ が消え、残る各クリーク頂点に私有葉2個 |
| $\{c_0,c_i\}$ 型（$i=1,2,3$） | $F(n-1)$ | $c_0,c_i$ が消え、他の同型独立点と $c_0$ の私有葉が2個孤立し、xorは0 |
| $c_j$ の私有葉（$j\ge4$） | $H(m-1)\oplus1$ | $c_j$ が消え、もう一方の私有葉が孤立（$m\ge1$ のとき） |

$n\ge3$ なので $F(n)=F(n-1)=1$。$m=0$ なら子の値集合は $\{0,1\}$、よって $H(0)=2$。$m\ge1$ で $H(m-1)=2$ と仮定すると子の値集合は $\{0,1,3\}$ で、$H(m)=2$。帰納法で任意の $m\ge0$ について成立する。**計算結果からの外挿ではなく全称証明**である。

## 旧実験の「孤立クリーク頂点」補正は誤り

[前回の一次資料](../two-zero-private-leaves-covered-20261028/README.md) には「$t_i=0$ かつ全 $r_{ij}=0$ のクリーク頂点はグラフ全体で孤立している。削除してxorで補正できる」とあるが、**誤り**。その頂点は他のすべてのクリーク頂点に隣接する。独立側に隣接点がないことと、グラフで孤立していることは異なる。

明示的な反例：$r_{ij}=0$、$t=(1,1,1)$ の6頂点グラフは $g=1$。これに私有葉のないクリーク頂点2個を加え、$t=(1,1,1,0,0)$ とした8頂点グラフは **$g=2$**。旧補正なら $1\oplus(2\bmod2)=1$ と誤算する。

この訂正は「$k\ge3$、全クリーク頂点が独立側に隣接し、私有葉ゼロが高々2頂点」という**covered条件付き定理を否定しない**。否定されるのは、covered条件を外して「$k\ge5$ なら全構成に適用可能」とした追加の拡張だけ。旧実験を歴史資料として書き換えず、ここに明示的に訂正を残す。

`verify_named.py` は実際に名前付き頂点を生成し、全頂点について閉近傍を削除する直接mex再帰を実行する。上記の $F,H$ の短い再帰も別に評価する。両者は同じ再帰を流用していない。

```sh
python3 research/experiments/game-structure/three-zero-private-unbounded-counterfamily-20261028/verify_named.py
```

2026-10-28に $k=4,5,6,7,8,9,10$ の7構成（11〜29頂点）で直接mexがすべて $g=2$。最大 $k=10$ は970,868状態を直接評価した。covered条件のない補正反例も、6頂点・8頂点の名前付き再帰で独立確認した。

**証拠水準：** $g(G_k)=2$ は初手全分類と数学的帰納法による全称証明。$k\le10$ は追加の有限検算。抽象分割グラフの Node Kayles の結論であり、整数格子の共円ゲームでこの構成が実現できるという主張ではない。11×11空盤の勝敗を決定しない。
