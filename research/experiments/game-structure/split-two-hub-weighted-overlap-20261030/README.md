# 次数1中心群＋任意次数中心2個：一様合法着手の重み付き交差公式（2026-10-30）

## 対象

有限単純分割グラフの Node Kayles（合法頂点から一様に選び、閉近傍を削除）。独立集合 I={1,...,m}（m≥1）、中心集合はクリークとする。中心には、各 j∈I にのみ隣接する t_j≥0 個の次数1中心と、独立点側の非空近傍 A,B⊆I を持つ区別された中心 h_A,h_B がある。A=B も許す。求める P_I は、終局まで一度も中心を選ばない確率。

重み w_j=t_j+1 と
\[
\alpha=\sum_{j\in A}w_j,\quad
\beta=\sum_{j\in B}w_j,\quad
\gamma=\sum_{j\in A\cap B}w_j,\quad
\sigma=\alpha+\beta-\gamma,\quad
Q=\prod_{j=1}^{m}(t_j+1)^{-1}
\]
を定める。

## 定理1（全称証明：重み付き二中心公式）

任意の m、非負整数 t_j、非空 A,B に対して
\[
\boxed{P_I=Q\frac{\alpha\beta(\sigma+2)+\gamma}
{(\alpha+1)(\beta+1)(\sigma+2)}.}
\]

これは次数1中心がない t_j=0 の場合、既存の二中心交差公式そのものになる。中心数が k=2+Σt_j と大きくても、入力の長さ m だけで計算できる。

**証明。** 全頂点に独立な一様優先順位を与え、小さい順に未削除頂点を選択する。これは各段階で合法頂点を一様に選ぶ過程と同分布。独立点 j の順位を x_j に固定すると、次数1中心が一度も選ばれない条件付き確率は ∏_j(1-x_j)^{t_j}、さらに二つの中心が選ばれない条件付き確率は
\[
(1-\min_{j\in A}x_j)(1-\min_{j\in B}x_j).
\]
この積を積分する。前者の積分は Q。重み付き確率測度に移すと、Y_j=1-x_j は独立で密度 (t_j+1)y^{t_j} (0≤y≤1) を持ち、
\[
P_I=Q\,\mathbb E[M_A M_B],\qquad M_A=\max_{j\in A}Y_j,\quad M_B=\max_{j\in B}Y_j.
\]
各 Y_j の分布関数は y^{w_j}。従って 0≤u≤v≤1 では
\[
\Pr(M_A\le u,M_B\le v)=u^\alpha v^{\beta-\gamma},
\]
0≤v≤u≤1 では u^{\alpha-\gamma}v^\beta。積分すると
\[
\int_0^1\!\!\int_0^1 \Pr(M_A\le u,M_B\le v)\,du\,dv
=\frac{(\alpha+1)^{-1}+(\beta+1)^{-1}}{\sigma+2}.
\]
また E[M_A]=α/(α+1)、E[M_B]=β/(β+1)。二変量の尾積分公式から
\[
\mathbb E[M_A M_B]
=1-\frac1{\alpha+1}-\frac1{\beta+1}
+\frac{(\alpha+1)^{-1}+(\beta+1)^{-1}}{\sigma+2}.
\]
通分すると主張の式。□

## 定理2（固定重み和での単調性）

Q、α、β を固定し、許される構成間で重み付き共通近傍 γ を比較すると、P_I は γ の狭義増加関数である。実際
\[
\frac{P_I}{Q}
=\frac{\alpha\beta}{(\alpha+1)(\beta+1)}
+\frac{\gamma}{(\alpha+1)(\beta+1)(\alpha+\beta-\gamma+2)}.
\]
右辺第二項は γ≥0、γ≤min(α,β) の範囲で狭義増加。これは重み付き交差を固定するための条件付き主張であり、単に |A∩B| を増やす任意の操作について述べたものではない。□

## 定理3（各独立点に同数の次数1中心がある場合の鋭い界）

t_j=r≥0 を全 j で固定し、m、|A|=d、|B|=e（1≤d,e≤m）を固定する。h=|A∩B| とすると
\[
h_{\min}=\max(0,d+e-m),\qquad h_{\max}=\min(d,e).
\]
\[
F(h)=\frac1{(r+1)^m}\left[
\frac{(r+1)^2de}{((r+1)d+1)((r+1)e+1)}
+\frac{(r+1)h}{((r+1)d+1)((r+1)e+1)((r+1)(d+e-h)+2)}
\right].
\]
このとき
\[
\boxed{F(h_{\min})\le P_I\le F(h_{\max})}
\]
は **両端達成可能な真の最小・最大**。h が取り得る値は h_min,...,h_max の全整数であり、F は h に関して狭義増加だからである。r≥1 かつ 2≤d,e<m の場合も含み、既存の次数1中心だけの族や二中心だけの族を越える。

例：m=4、r=1、d=e=2 では h=0,1,2 に対して P_I=1/25, 13/320, 1/24。次数1中心が4個と中間次数中心が2個ある同一の次数列でも、近傍の重なりで確率が変わる。
