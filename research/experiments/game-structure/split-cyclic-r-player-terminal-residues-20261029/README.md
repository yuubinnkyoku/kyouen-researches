# 分割グラフの全終局長と巡回 r 人対戦の最終着手者（2026-10-29）

## 定理（数学的全称証明）

有限分割グラフ G のクリーク C と独立集合 I への分割を固定する。k=|C|、m=|I|、d(c)=|N(c)∩I| とする。通常の Node Kayles は頂点を選ぶと、その頂点と隣接頂点を以後選べなくなるゲームである。終局までの手数を L とする。

k≥1 なら、可能な終局手数の集合全体は厳密に

\[
\boxed{\mathcal T(G)=\{m+1-d(c):c\in C\}\ \cup\
\begin{cases}\{m\},&\min_{c\in C}d(c)>0,\\
\varnothing,&\text{それ以外}.\end{cases}}
\]

である。中心 c を含む極大独立集合は互いに異なり、中心を含まないものが存在するならそれも別の集合。従って極大独立集合の個数は k または k+1。長さ L の終局集合の個数は、d(c)=m+1-L となる中心数に、L=m かつ全 d(c)>0 のときだけ1を加えた値である。

最小終局手数は m+1-max d(c)、最大終局手数は全 d(c)>0 なら m、そうでなければ m+1。k=0 では唯一の終局長は m。

### 巡回 r 人対戦への帰結

r≥2 人が1,2,...,rの順で一手ずつ着手し、最後の着手者だけが勝つとする。空でない盤面では、終局長 L の最終着手者は 1+((L-1) mod r) 番目。従って上の終局長集合を r で割った剰余集合が、実際に到達できる最終着手者の集合を完全に与える。

k≥1 の場合、**全ての合法な進行で最終着手者が同じになる必要十分条件**は次のいずれか。

1. 全ての c∈C で d(c)≡1 (mod r)。この場合、全終局長は m (mod r)。
2. 全ての c∈C で d(c)≡0 (mod r)、かつ d(c)=0 の中心が少なくとも1個。この場合、全終局長は m+1 (mod r)。

k=0 の場合は全終局長 m で固定。盤面全体が空なら最終着手者は存在しない。r=2 では既存の[分割グラフの全局面Grundy二値性](../split-graph-parity-classification-20261029/README.md)の次数偶奇条件に一致する。r≥3 の結果は一般的な多人数最適戦略・均衡を計算するものではなく、全合法進行の終局到達可能性についての定理である。

## 証明

Node Kaylesで選んだ頂点集合は独立集合で、終局は極大独立集合に一致する。クリークCから選べる頂点は高々1個。中心 c を含む極大独立集合は

\[
M_c=\{c\}\cup(I\setminus N(c)),\qquad |M_c|=m+1-d(c)
\]

に限られ、実際に極大である。中心を含まない極大独立集合は I のみであり、I が極大となる条件は全 d(c)>0。これで終局集合の完全分類・度数・最大最小公式が従う。

全進行で最終着手者が固定されることは、全極大独立集合のサイズが同じ剰余類に属することと同値。全 d(c)>0 なら I も極大なので、各 m+1-d(c)≡m (mod r)、すなわち全 d(c)≡1 が必要十分。ある d(c)=0 なら I は極大でなく、各 m+1-d(c) が同じ剰余類に属するには全 d(c)≡0 が必要十分。有限実験を用いない両方向の証明である。

## r=3 の証人

C={0,1,2}。各中心に私有葉1枚、さらに {0,1} に隣接する独立点を3枚置く。m=6、独立側次数は (4,4,1)。すべて1 (mod 3) なので、合法な進行が3手で終わっても6手で終わっても必ず3番目のプレイヤーが最後に打つ。実際の終局長集合は {3,6}。同じ長さを強制する必要はない。

## 独立検証と適用範囲

[verify.py](verify.py) は、(A) 名前付き頂点の全部分集合から極大独立集合を直接判定する方式と、(B) 閉近傍削除による全合法手再帰から終局手数を列挙する方式で、終局長集合そのものを独立照合する。さらに r=2..6 の固定最終着手者条件を比較する。

クリーク k=0..4、独立側 m=0..4 の全交差辺配置、および (k,m)=(3,5),(5,3) の全配置、計 **140,499 ラベル付き分割グラフ**を完全列挙。二方式の終局長集合は全一致。r=2,3,4,5,6 で最終着手者が固定される構成数はそれぞれ **13,815、3,022、1,092、895、889**。判定不一致0。r=3の9頂点証人も独立確認した。
