# 中心が高々3個の任意の分割グラフのGrundy上界3（2026-10-30）

## 定理（無界個数を有限完全列挙へ帰着）

通常プレイの二点残余禁止ゲーム（Node Kayles）で、頂点集合がクリーク `C` と独立集合 `I` に分割でき、`|C|<=3` なら、**任意の合法局面のGrundy数は0,1,2,3のいずれか**である。独立点の個数、各中心への接続パターン、同一パターンの重複数に上限はない。上界3は鋭い（例えば二中心に私有葉が各1個、共有葉1個の例で `g=3`）。

これは前回の「一つの中心対にだけ共有葉がある」族と異なり、**3組すべての中心対に共有葉があり、さらに三中心共通葉と私有葉が任意に混在**しても成立する。

## 全称証明の構造

1. `C={0,...,k-1}`、`k<=3` と固定する。中心と隣接しない独立点（近傍空）は孤立点なので、個数の偶奇だけを `xor` で分離できる。これによりGrundy数の0/1、2/3は互いに入れ替わるだけで、上界3は保存される。
2. 残りの独立点を、中心への近傍 `A⊆C`（非空）ごとに分ける。同じ `A` の点は互いに隣接せず、残余禁止辺の全linkが等しい。既存の全称定理 [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、重複数は `0 / 正奇数代表1 / 正偶数代表2` へ **Grundy数を変えず** に縮約できる。
3. 非空近傍の種類は `2^k-1` 個なので、残りの状態は高々 `3^(2^k-1)` 通り。`k=0,1,2,3` の全代表数は `1+3+27+2187=2218`。
4. 付属の `verify.py` は各代表について、(i) 近傍の個数ベクトルだけで全着手を再帰計算する方式と、(ii) 各頂点を実際に展開して閉近傍を削除する**独立した方式**の二つでmexを求め、全2218代表の一致と上界3を確認する。これは「有限標本から無限を推測」ではなく、**K0336に基づいて無限の全対象を覆う有限場合分け**である。ただし形式証明支援系による機械検証ではなく、検証器の正しさは別途監査対象である。
5. 着手後もクリーク側は高々3点、独立側は依然独立なので、同じ結論がすべての後続局面に適用される。

中心を選ぶと残りの中心は全消滅し、その中心と非隣接の独立点だけが孤立点として残る。独立点を選ぶと、その点と隣接する中心だけが消滅し、残る独立点の中心近傍は残存中心との共通部分になる。この二種類が全着手を尽くす。

## 3組の中心対だけに共有葉がある場合の閉表

中心A,B,Cの各組AB,AC,BCに接続する葉の個数を `a,b,c` とし、それ以外の葉を置かない。各個数を `0,1,2` に縮約し、中心の置換により `a<=b<=c` に並べると、**すべての非負整数 `a,b,c` のGrundy数**は次の10通りに分類できる。

| 縮約後の(a,b,c) | g |
|---|---:|
| (0,0,0) | 1 |
| (0,0,1) | 2 |
| (0,0,2) | 1 |
| (0,1,1) | 2 |
| (0,1,2) | 3 |
| (0,2,2) | 1 |
| (1,1,1) | **0** |
| (1,1,2) | 2 |
| (1,2,2) | 3 |
| (2,2,2) | 1 |

例えば3組の共有葉が各1枚なら `g=0`、各2枚なら `g=1`。一つの中心対だけを扱う従来の閉公式からは直接読み取れない。
