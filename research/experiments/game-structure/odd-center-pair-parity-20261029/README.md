# 二つの奇数中心を結ぶ二点型の偶奇によるGrundy数の完全分類（2026-10-29）

## 対象と新しい結論

通常プレイの Node Kayles を、クリークと独立集合からなる分割グラフ上で考える。既存の[二中心・非接続の偶数星定理](../two-odd-centers-even-stars-20261028/README.md)に、**二中心 A,B の両方に隣接する独立点を `c` 個**追加する。クリークは A,B、A 側の `p` 個の枝先、B 側の `q` 個の枝先、`m` 個の補助頂点からなる。すべてのクリーク頂点同士は隣接する。

- A,B の私有葉数は任意の**正の奇数**。
- 各枝先の私有葉数は0。中心とその枝先の二点型独立点は各々任意の**正の偶数**個。
- 各補助頂点の私有葉数は任意の**正の偶数**。
- A,B 間の二点型独立点は `c>=0` 個。その他の二点型は存在しない。

`n=p+q+m` とし、元の非接続二中心のGrundy数を

$$
T(p,q,m)=\begin{cases}
0,&n=0,\\
2,&n>0,\ \max(p,q)\le2,\\
4,&\max(p,q)\ge3,\ \min(p,q)\le2,\\
3,&\min(p,q)\ge3
\end{cases}
$$

とする。**新しい全称定理**は次の通り。

$$
\boxed{g(G_{p,q,m,c})=\begin{cases}
T(p,q,m),&c\text{ が偶数},\\
3,&c\text{ が奇数かつ }n=0,\\
0,&c\text{ が奇数かつ }n>0.
\end{cases}}
$$

各私有葉数・二点型重複数が不均一でも成立する。とくに **A,B 間に奇数個の二点型を置くだけで、枝が1本でもある構成のGrundy数は常に0** となる。従来 `g=4` だった `(p,q,m)=(3,0,0)` も `c=1` なら `g=0` である。一方 `c=2` なら従来通り `g=4`。二点型の偶奇が勝敗を反転させる。

## 補題1：正の偶数私有葉付きクリーク

`F(s)` を `s` 個のクリーク頂点がそれぞれ任意の正の偶数枚の私有葉を持つ場合のGrundy数とする。既存の[一中心定理](../odd-center-even-star-sharp-transition-20261028/README.md)の補題より

$$F(0)=0,\qquad F(1)=2,\qquad F(s)=1\ (s\ge2).$$

証明はクリーク頂点を選んだ子が0、私有葉を選んだ子が `1 xor F(s-1)` となることによる帰納法。

## 補題2：偶数私有葉中心の星

`E(q,s)` を、中心の私有葉数が任意の**正の偶数**、枝先 `q` 個の二点型が各々正の偶数個、補助頂点 `s` 個の私有葉が各々正の偶数個である一中心の星とする。枝先自身には私有葉を付けない。すると

$$\boxed{E(q,s)=\begin{cases}2,&s=0,\ q\le1,\\1,&\text{それ以外} .\end{cases}}$$

証明：クリーク頂点を選ぶ子は常に0。中心私有葉を選ぶ子は `1 xor F(q+s)`、中心と枝先の二点型を選ぶ子は `1 xor F(q+s-1)`（枝先が存在するとき）、補助私有葉を選ぶ子は `1 xor E(q,s-1)`（`s>0`）。残りの中心私有葉は奇数個の孤立点となる。二点型を選ぶと中心の偶数枚の私有葉と、同型の残り奇数枚が合計奇数個の孤立点になる。

`s=0` のとき `q=0,1` の子集合はそれぞれ `{0,1}`, `{0,1,3}` でmexは2。`q>=2` では子集合は `{0}` または `{0,3}` でmexは1。`s>=1` では `q+s=1` の子集合が `{0,3}`、`q+s>=2` では帰納法の仮定により子の値は0か3だけなのでmexは1。よって全称的に **`E(q,s)>0`**。

## 全称証明：中心間の二点型が奇数

`c` が奇数なら全初手を次のように分類できる。A,B の奇数私有葉、各偶数重複数という条件だけを使い、実際の枚数には依存しない。

| 初手 | 子のGrundy数 |
|---|---|
| A または B のクリーク頂点 | `1` |
| 枝先または補助クリーク頂点 | `1` |
| A の私有葉 | `E(q,p+m)` |
| B の私有葉 | `E(p,q+m)` |
| A 側の二点型（`p>0`） | `E(q,p+m-1)` |
| B 側の二点型（`q>0`） | `E(p,q+m-1)` |
| A,B 間の二点型（`c>0`） | `F(n)` |
| 補助頂点の私有葉（`m>0`） | `1 xor g(G_{p,q,m-1,c})` |

中心間の二点型を選ぶとA,Bがともに消え、A,Bの奇数葉2組と残りの同型二点型 `c-1` 個が合計偶数個の孤立点になる。残る枝先・補助頂点はすべて正の偶数枚の私有葉を持つクリークになるため子は `F(n)`。Aの私有葉を選ぶとBには従来の奇数葉と `c` 個の新しい葉が付き、**正の偶数葉中心**になるため子は `E(q,p+m)`。他の行も閉近傍削除と孤立点のxorから従う。

`n=0` では可能な子の値が `{0,1,2}` なのでmexは3。`n>0` の場合、補題2より `E` 型の子はすべて非零、`F(n)` も非零、クリーク頂点を選んだ子は1。補助私有葉を選んだ子は `n-1=0` なら `1 xor 3=2`、`n-1>0` なら帰納法の仮定から `1 xor 0=1`。**すべての初手の子が非零**なのでmexは0。`n` に関する帰納法が閉じる。

## 全称証明：中心間の二点型が偶数

`c=0` の場合は既存の二中心定理。`c` が正の偶数の場合も、既存の初手の子の値は変わらない。A,B の私有葉・枝先の二点型を選んで片方の中心だけを消したとき、残る中心の私有葉数は奇数+偶数で奇数のまま。クリーク頂点を選んだ場合の孤立点の偶奇も従来と同じ。補助私有葉の再帰も `c` を固定して `m` に関する帰納法を使える。

新たに増えた **A,B 間の二点型を選ぶ手** の子は `1 xor F(n)` であり、`n=0` なら1、`n=1` なら3、`n>=2` なら0。`n=0` の1は既存の中心クリーク手に含まれる。`n=1` の3は既存の中心私有葉手（残る一中心星 `S(0,1)=3`）に含まれる。`n>=2` の0は枝先または補助クリーク頂点の手で既に現れる。したがって新しい手はmexを変えず、既存の `T(p,q,m)` が全 `c` 偶数について成立する。

## 独立検証

[verify_named.py](verify_named.py) はすべての独立点を名前付きの別頂点として構築し、全初手について閉近傍削除を再帰しmexを計算する。`F`, `E`, `T` の漸化式を**評価器には使わない**。

2026-10-29 に Python 3 で実行：均一62件、中心私有葉と二点型を不均一にした108件、補題2の独立検査9件、25頂点までの境界例11件、合計 **190件すべて一致**。最大217,536状態（`p=q=3,m=0,a=b=1,c=3`、25頂点）。この190件は有限標本の独立検算であり、無限の定理の根拠は上記の全称証明である。

```sh
python3 research/experiments/game-structure/odd-center-pair-parity-20261029/verify_named.py
```

## 範囲と未解決

抽象分割グラフの通常プレイNode Kaylesに対する定理である。整数格子上の共円・共線禁止ゲームでこの局面が実現できるとは主張しない。`c` が奇数のときの `g=0` は、中心数2に限る。中心数3以上の間に奇数二点型を張った場合の分類は未解決。全体CI、knowledge正本への昇格、生成物の再構築は未実施。
