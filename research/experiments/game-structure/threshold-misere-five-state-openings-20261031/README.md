# 閾値グラフの通常・misère最小5状態計算法と全勝ち初手（2026-10-31）

## 定理と新規性

閾値グラフは空グラフから、孤立頂点追加 I または全既存頂点に隣接する支配頂点追加 D を繰り返して得られる。頂点を選んで閉近傍を削除する Node Kayles を扱う。通常Grundy値 g は終端0、misère補助mex値 h は終端1とする。

既存の [通常6状態定理](../threshold-graph-six-state-20261027/README.md) は (g, 子のg値集合) を6状態で計算し、[分割グラフmisère交換則](../split-misere-swap-and-winning-openings-20261031/README.md) は任意の分割グラフで h=τ(g) を証明済み（τ(0)=1, τ(1)=0, τ(k)=k for k>=2）。閾値グラフは分割グラフなので交換則を使える。

**新規結果**：構築列から通常・misère両方の根値を求めるには、以下の**5状態が必要十分**である。また、全頂点の通常・misère勝ち初手を構築列から**O(n)時間**で完全分類できる。

| 状態 | (g,h) | Iの次状態 | Dの次状態 |
|---|---|---|---|
| E | (0,1) | A | A |
| A | (1,0) | B | A |
| B | (0,1) | A | C |
| C | (2,2) | D | C |
| D | (3,3) | C | D |

初期状態は E。任意の有限構築列に対して正しい。根の値だけなら時間O(n)・記憶O(1)。

### 5状態表の全称証明

既存通常6状態 E,A,B,C,D,F の遷移表で、CとFはどちらも通常値2であり、IではどちらもDへ、Dではそれぞれ自分自身へ遷移する。したがって値出力の観点ではCとFを同一視できる。残り4状態は変更せず、上の5状態表が得られる。通常6状態の閉包は任意長の構築列について帰納法で証明済みなので、5状態表も任意長で正しい。閾値グラフは分割グラフなので、既存の全称交換則 h=τ(g) により表のmisère値も正しい。有限検算からの外挿ではない。

**最小性**：E,A,B,C,Dは順に空列、I、II、IID、IIDIで到達できる。通常出力は0,1,0,2,3。EとB以外は出力だけで区別できる。EとBは末尾にDを追加するとそれぞれA（値1）とC（値2）になるため区別できる。よってこれら5状態はすべて異なる右文脈を持ち、通常値を出力する決定性有限状態機械には少なくとも5状態必要。これは構築列を左から読むモデルでの最小性であり、任意の入力形式での計算量下界ではない。

## 全勝ち初手の線形時間閉形式

構築列を t_1,...,t_n とし、p_j を t_j を処理する**直前**の5状態、b_j を j より後に出現する I の個数の偶奇（0または1）とする。頂点jを初手で選んだ子局面の通常値 a_j は

\[
\boxed{a_j=\begin{cases}
b_j & (t_j=D),\\
g(p_j)\mathbin{\mathrm{xor}} b_j & (t_j=I).
\end{cases}}
\]

**通常版の勝ち初手は a_j=0、misère版の勝ち初手は a_j=1 の頂点ちょうどすべて**である。a_j>=2なら両方で負け初手。両ルールの勝ち初手は重ならない。

**全称証明**：jがDなら、jは全先行頂点と全後続Dに隣接するので、閉近傍削除後に残るのは後続Iの孤立点だけ。通常値はb_j。jがIなら、jは先行頂点に隣接せず、後続Dにのみ隣接する。閉近傍削除後は先行部分グラフと後続I孤立点の直和である。通常Grundy値の直和xor則から g(p_j) xor b_j。どちらの子も閾値グラフなので h(child)=τ(a_j)。misèreの勝ち手は h(child)=0、すなわち a_j=1。通常の勝ち手は a_j=0。□

p_jは左から、b_jは右からそれぞれ一度走査すれば得られる。全n頂点の分類は時間O(n)・記憶O(n)（出力を保持する場合）。任意の隣接行列から構築列を認識する費用は含まない。
