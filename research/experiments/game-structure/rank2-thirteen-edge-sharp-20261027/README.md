**計算機援用の全称定理：** 有限一点追加・通常プレイの安全局面で、包含極小残余禁止集合がすべて二点集合であり、その本数が **13本以下** なら、自由点を任意個許しても **Grundy数は7以下**。10辺での既存証人により鋭い。12辺までの既存分類を、13辺の全一般グラフへ拡張した。

## 証明の帰着

二点残余禁止辺だけの継続ゲームは、競合グラフの独立集合を一点ずつ増やす Node Kayles と一致する。孤立点は独立な一手ゲームで、個数の偶奇だけが核のGrundy値とxorされる。

連結グラフは、1辺グラフから「既存の非隣接二頂点間に辺を追加」「既存頂点へ葉を追加」の二操作で全生成できる。逆向きには、閉路があれば非橋を除去し、木なら葉を除去する。次数・隣接次数・三角形数は**同型の必要条件としてだけ**使用し、候補の重複は全単射による厳密な同型判定で除去する。各連結代表に対して残存頂点再帰と占有済み独立集合再帰を照合する。

非連結の孤立点なしグラフは連結非同型類の多重集合に一意分解する。成分のGrundy値はxorで合成するため、個別連結型を逐次取り込む動的計画法で全度数を算出できる。さらに連結類を(辺数, Grundy値)でまとめた重複組合せ `C(c+k-1,k)` による**別方式の計数**でも一致した。これらは有限計算を全有限グラフへ帰着した**計算機援用証明**であり、標本実験を全称定理と取り違えていない。

## 独立検証の範囲

- 13辺までの全連結代表で二つのGrundy再帰が一致し、1〜12辺の既存度数表も再現した。
- NetworkXの **Graph Atlas** で、13辺・6頂点の連結2類と7頂点の連結95類を独立生成してGrundy値まで一致。
- NetworkXの非同型木生成器で、13辺・14頂点の木 **3,159類**を独立生成。Grundy度数 `(850,859,434,370,321,293,15,17)` まで一致。
- 非連結の13辺の度数は二種類の組合せ計数で一致。

**限界：** 8〜13頂点の連結13辺グラフについて、同型類の完全生成を別実装で独立照合したわけではない。13辺の全連結生成は数学的な完全生成帰着と厳密な同型判定に依存する。抽象二点禁止ゲームの結果であり、整数格子上での証人実現、三点以上の残余禁止集合への拡張、11×11の速度改善は未確認。
