# 6奇数中心・全二点型：偶数重複消去と156同型類（2026-10-29）

## 定理（数学的還元＋有限完全列挙）

通常プレイ Node Kayles の抽象分割グラフで、クリークはちょうど6頂点 `0,...,5`。各クリーク頂点には**任意の正の奇数個**の私有葉を置き、各頂点対 `ij` に、両端だけに隣接する独立点を任意の `c_ij >= 0` 個置く。他の頂点・辺はない。

**結論**：Grundy数は、`c_ij` が奇数である頂点対を辺とする単純グラフ `P` の同型類だけで決まる。**正の偶数個の二点型は0個と等価**である。全構成について

```
0 <= g(G) <= 3
```

が成立する。これは6中心のこの抽象分割グラフ族に限る全称定理であり、任意の分割グラフや格子共円ゲーム全体の上界ではない。

## 単純グラフの完全分類

15辺のビット順は `01,02,03,04,05,12,13,14,15,23,24,25,34,35,45`（右端でなく**最初の01が最下位ビット**）。ラベル付き単純グラフは `2^15=32768` 個、中心の置換による同型類は156個。

| Grundy | ラベル付き単純グラフ数 | 同型類数 |
|---:|---:|---:|
| 0 | 1,024 | 20 |
| 1 | 1,024 | 12 |
| 2 | 15,360 | 62 |
| 3 | 15,360 | 62 |

同型類の代表は各軌道で最小の整数ビットマスクとした。後手必勝の20代表は

```
0,31,102,121,510,655,656,758,957,1759,1880,4060,5871,5872,5905,6007,6655,7100,15870,32767
```

である。`g=1` の12代表は

```
35,60,239,639,684,691,926,1788,1915,4095,6142,7071
```

である。それ以外の同型類は `g=2` または `g=3`。付属検証器は各代表の軌道サイズを出力し、任意の15ビットマスクの値を厳密mex再帰で計算する。

## 全称証明の構造と検証範囲

1. **数学的還元**：既存の独立双子点の正の偶奇圧縮定理 [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、各正の奇数私有葉を1枚へ、各二点型重複を0/1/2へ縮約できる。**2枚を0枚へ消せることはK0336だけでは従わない**。
2. **有限完全列挙**：15組の二点型を0/1/2とした全 `3^15=14,348,907` 構成を6中心の置換群 `S_6` で割ると、**25,506軌道**になる。隣接交換5種類が `S_6` を生成するため、軌道の幅優先列挙は全構成を漏れなく覆う。軌道サイズの総和も14,348,907と一致した。
3. **型別個数の厳密mex**：`verify_quotient.cpp` は生存クリークと独立点の近傍型別個数で状態を表し、全25,506代表について `g(0/1/2)` と `g(2→0)` を比較した。不一致0。ラベル付き構成に換算して14,348,907/14,348,907で一致した。
4. **別方式の完全独立照合**：`verify_named.cpp` は実際に最大42個の**名前付き頂点**を構成し、各頂点の閉近傍を直接削除する別実装のmex再帰を使う。25,506軌道代表すべてで元と2→0縮約後を照合し、不一致0。孤立頂点の直和はxorの偶奇で除去する。名前付き再帰の一構成あたり最大記憶状態数は63。型別実装の共有記憶状態数は175,493。
5. **分類**：二値 `2^15` 構成を156同型類へ分類。両実装で、二値・三値の値の分布まで完全一致した。

三値全構成のGrundy値分布は `g=0:455625, g=1:443232, g=2:6721950, g=3:6728100`。独立検証は標本抽出ではなく、全軌道を覆う有限完全列挙である。無限個の私有葉・重複数への拡張はK0336の数学的証明を使うので、全称性は有限計算の外挿ではない。

## 限界・次の課題

対象は私有葉が正の奇数枚で、独立点の近傍がクリークの1点または2点に限られる抽象分割グラフ。私有葉0枚・偶数枚、3点以上の近傍型、星の枝先、整数格子上での実現可能性は対象外。**7中心以上で偶数二点型を消去できるかは未証明**。特に7中心の三値基底は `3^21` と大きいため、まず二値基底と少数の2型を足す境界の探索が実行可能。
