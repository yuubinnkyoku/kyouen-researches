# 欠損二点型がマッチングをなす分割グラフのGrundy閉形式（2026-10-28）

## 全称定理

通常プレイの二点禁止ゲーム（Node Kayles）で、クリーク \(C=\{c_0,\ldots,c_{k-1}\}\) と独立集合からなる分割グラフを考える。\(k\ge3\)。独立側の各頂点はクリークの1点または2点だけに隣接し、クリーク点 \(i\) の私有葉数を \(t_i\ge0\)、二点型 \(\{i,j\}\) の重複数を \(r_{ij}\ge0\) とする。

**欠損二点型の集合 \(D=\{\{i,j\}:r_{ij}=0\}\) がマッチング（どの2組も端点を共有しない）である**と仮定する。欠損数 \(|D|\le\lfloor k/2\rfloor\) は定数でなくてよく、存在する二点型の重複数と私有葉数も任意・不均一でよい。

\[
u=\left(\sum_i t_i+\sum_{i<j}r_{ij}\right)\bmod2,\qquad
z_i=\left(t_i+\sum_{j\ne i}r_{ij}\right)\bmod2.
\]

このとき

\[
\boxed{g(G)=
\begin{cases}
1\oplus u\oplus z_0 & z_0=\cdots=z_{k-1},\\
2+u & \text{それ以外}.
\end{cases}}
\]

特に **全ての \(k\ge3\)、全ての重複数で \(g(G)\le3\)**。値は \(O(k^2)\) で計算できる。独立側に孤立点が \(f\) 個ある場合は右辺と \(f\bmod2\) のxorを取る。

従来の「欠損が高々5組」の結果とは異なり、**欠損数が \(k\) とともに無制限に増える族**を覆う。例えば \(k=100\) で互いに素な50組が欠けても成立する。反面、欠損が6組でも端点を共有する一般の配置には、この定理を適用できない。

## 証明（数学的帰納法＋有限完全列挙）

### 1. 偶奇への縮約

既存の [K0336](../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同じ非空近傍を持つ独立点は正の奇数なら1個、正の偶数なら2個に減らしてもGrundy数が変わらない。従って \(t_i\in\{0,1,2\}\)、存在する \(r_{ij}\in\{1,2\}\) を調べれば、無限個の重複数を覆う。これは単なる標本化ではなく全称的な縮約である。

### 2. 全初手の子値

クリーク頂点 \(c_i\) を選ぶと、残りは孤立点だけとなり、その子値は \(u\oplus z_i\)。

独立点を選び、その隣接クリーク点集合を \(B\)（1点または2点）とする。残ったクリーク上の二点型と葉へ整理し直した偶奇を \(u',z'_i\)、別に孤立した点数の偶奇を \(\delta\) とすると

\[
z'_i=z_i\quad(i\notin B),\qquad \delta=u\oplus u'\oplus1.
\]

これは選んだ独立点1個を除き、元の独立点が「残るクリークに接続」または「孤立」のどちらかへ分配されることから従う。二点型の欠損集合は頂点削除による誘導部分集合となり、マッチング性を保つ。

残存クリークに帰納仮定が使えるとき、独立点初手の子値は

\[
g'\oplus\delta=
\begin{cases}
u\oplus s & \text{残った }z_i\text{ がすべて }s,\\
u\oplus3 & \text{残った }z_i\text{ に0と1が混在}.
\end{cases}
\]

### 3. 帰納段階 \(k\ge6\)

独立点初手で残るクリーク点は \(k-1\) または \(k-2\)、従って4点以上で、いずれも帰納仮定の対象となる。

親の \(z_i\) が全て \(s\) なら、クリーク初手も独立点初手も子値は \(u\oplus s\) だけ。mexは \(1\oplus u\oplus s\)。

親の \(z_i\) が混在するなら、クリーク初手だけで子値0と1の双方が現れる。鳩の巣原理で同じ \(z\) を持つ頂点が少なくとも3点ある。その3点の間の3二点組のうち、**マッチングで欠け得るのは高々1組**なので、存在する二点型を一つ選べる。その二点型の独立点を選んで2頂点を消しても、同じ \(z\) の頂点が1点以上、反対の \(z\) の頂点も1点以上残る。従って子値 \(u\oplus3\) が現れる。ほかの子値は0,1,\(u\oplus3\) 以外にならず、

\[
\operatorname{mex}\{0,1,u\oplus3\}=2+u.
\]

これで帰納段階が閉じる。

### 4. 有限基底 \(k=3,4,5\)

\(k=3\) の欠損0組・1組、\(k=4\) の欠損0〜2組、\(k=5\) の欠損0〜2組を、マッチングの同型代表ごとに全列挙した。各代表の全ての葉 \(0,1,2\) と存在二点型 \(1,2\) の組合せを検査している。任意のマッチングは頂点の置換でこの代表へ移るため、漏れはない。

| k | 欠損数 | 全代表構成 |
|---:|---:|---:|
| 3 | 0 / 1 | 216 / 108 |
| 4 | 0 / 1 / 2 | 5,184 / 2,592 / 1,296 |
| 5 | 0 / 1 / 2 | 248,832 / 124,416 / 62,208 |
| **計** | | **444,852** |

C++のクリーク部分集合再帰は全444,852構成で式と一致。さらにPythonの**名前付き全頂点の閉近傍削除**という別の再帰で \(k=3\) の324構成を完全照合し、\(k=4,5,6\) の固定乱数112構成を追加照合した。既存の [二組欠損定理](../two-missing-pairs-arbitrary-multiplicities-20261028/README.md) も \(k=4,5\) の基底を別方式で完全照合済みである。

\(k=6,\ldots,12\) では各欠損数について200構成、計7,400構成をC++で追加検査した。これは帰納証明の誤り検出用であり、無限族の根拠は上記の数学的帰納法である。

## 頂点数条件の鋭さ

\(k=2\) では、欠損が0組（従ってマッチング条件を満たす）でも公式は一般に成り立たない。クリーク \(K_2\) の二点型に独立点を2個付け、私有葉は0枚とする4頂点の例では、クリーク初手の子値が0、独立点初手の子値が1なので、真の値は \(\operatorname{mex}\{0,1\}=2\)。一方 \(u=z_0=z_1=0\) で公式は1を予測する。従って全称的な \(k\ge3\) の下限は鋭い。

## 適用範囲と残件

これは抽象的な二点禁止ゲームの全称定理であり、整数格子の共円ゲームとして任意の構成を実現できるとは主張しない。一般の欠損6組・\(k=8\) で同じ公式が成立するかは依然未解決である。欠損マッチングの条件を「最大欠損次数2」などへ緩められるかも未確定。knowledge正本への昇格は、生成物を直接編集せず、正式な構築・整合性検査ができる環境で行う。
