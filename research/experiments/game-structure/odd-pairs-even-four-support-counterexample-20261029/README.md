# 奇数二点型が混在すると偶数四点型の消去は失敗する（2026-10-29）

## 厳密な反例（抽象分割グラフの通常 Node Kayles）

クリーク C={A,B,C,D} を取り、独立側に各中心の私有葉を1枚ずつ、二点型 {A,B} と {C,D} を1枚ずつ置く。これを G0 とする。さらに四点型 {A,B,C,D} に接続する独立点を**2枚**加えたものを G2 とする。

**厳密な値は g(G0)=1、g(G2)=2。** 同じ近傍型の独立点を偶数枚追加しても、その型を0枚に消去できるとは限らない。奇数二点型2種類と偶数四点型1種類で既に破れる。先行の「7中心以下・二点型だけ」の偶数消去定理や「全ての高次型が偶数で全中心次数が奇数」の定理とは矛盾しない。

| 最初の手の種類 | G0の子Grundy | G2の子Grundy |
|---|---:|---:|
| 中心（4通り） | 0 | 0 |
| 私有葉（4通り） | 0 | 3 |
| 二点型（2通り） | 3 | 3 |
| 四点型（G2のみ、2通り） | ― | 1 |
| **mex** | **1** | **2** |

表の全子局面は独立な二方式で再帰計算した。したがってこれは単なる勝敗の違いではなく、**Grundy数そのものが1から2に変わる**反例である。

## 無限族への拡張（既存の全称補題＋有限基底）

各私有葉型と二点型 {A,B}, {C,D} を**任意の正の奇数**枚、四点型 {A,B,C,D} を**任意の正の偶数**枚に置き換えても、g=2 のまま。四点型を0枚にした場合は g=1 のまま。

理由：既存の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) は、同一非空linkの独立双子点の正の重複数を、奇数なら1、偶数なら2に縮約してもGrundy数が不変であることを全称証明している。各近傍型はここでの同一link classに該当する。縮約後は上記の10頂点・12頂点の有限基底そのものになる。**偶数2枚から0枚への縮約はK0336の射程外**であり、まさにその失敗を示した。

## 小中心数の完全検査と限定的な正の結果

中心数 k=2,3,4、各中心の私有葉は1枚、サイズ2以上の全近傍型をそれぞれ0枚か1枚だけ持つ全構成を列挙した。それぞれに指定した近傍型を2枚追加し、Grundy値が変わるかを調べた。

| 中心数 | 追加する偶数型の階数 | 完全検査数 | 不一致数 |
|---:|---:|---:|---:|
| 2 | 2 | 2 | 0 |
| 3 | 2 | 48 | 0 |
| 3 | 3 | 16 | 0 |
| 4 | 2 | 12,288 | 0 |
| 4 | 3 | 8,192 | 0 |
| 4 | 4 | 2,048 | **64** |

k=4 の階数4の反例に必要な奇数の非私有近傍型は最小**2種類**（上記の互いに素な二点型）。全検査は 2^(2^k-k-1) 個の0/1割当と、サイズ2以上の各追加対象を直積したもの。k=1 はサイズ2以上の型を持たない。

したがって、**中心数4以下・他に正の偶数近傍型が存在しない**という条件の下では、奇数非私有型を任意に持っていても、単一の偶数二点型または三点型を追加してもGrundy値は不変。K0336によって、既存の奇数重複を任意の正の奇数枚へ拡張できる。**複数種類の偶数型を同時追加した場合**や中心数5以上については、この完全検査からは結論できない。
