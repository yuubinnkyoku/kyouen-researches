# 次数1中心群＋任意個の中心：重み付き部分集合再帰（2026-10-30）

## 対象と全称定理

有限単純分割グラフの Node Kayles。一様合法着手は、残る合法頂点から毎手一様に1個選び、閉近傍を削除する。独立点集合を I={0,...,m−1}、中心は全て相互に隣接するクリークとする。各独立点 j だけに隣接する次数1中心が t_j≥0 個あり、それらとは別に k≥0 個の中心 h_0,...,h_{k−1} が、それぞれ任意の近傍 A_h⊆I を持つ（空集合・重複も許す）。

中心を **一度も選ばず** 終局する確率を P_I とする。w_j=t_j+1、Q=∏_{j∈I}1/w_j と置く。中心の部分集合 S⊆{0,...,k−1} について

\[
U_w(S)=\sum_{j\in\bigcup_{h\in S}A_h}w_j,\quad
H(\varnothing)=1,\quad
H(S)=\frac{\sum_{h\in S}H(S\setminus\{h\})}{|S|+U_w(S)}\quad(S\ne\varnothing).
\]

このとき、任意の m≥1、t_j、k、A_h に対して

\[
\boxed{P_I=Q\sum_{S\subseteq\{0,\ldots,k-1\}}(-1)^{|S|}H(S).}
\]

これは **全称証明済み** であり、有限実験に依存しない。k=0 では P_I=Q。空近傍の中心があれば P_I=0。全ての t_j=0 では既存の任意中心数の部分集合再帰に一致し、k=1,2 は既存の次数1中心＋1中心／2中心公式に一致する。

### 計算量と十分統計量

独立点 j に接続する特別中心のビット集合を B_j とする。F(B)=Σ_{j:B_j=B}w_j の部分集合和 Z(T)=Σ_{B⊆T}F(B) を高速ゼータ変換で求めると、全中心集合 C に対して

\[
U_w(S)=\sum_jw_j-Z(C\setminus S).
\]

これにより P_I は O(mk+k2^k) 回程度の整数・有理数演算で計算できる（大整数の桁数は別途）。次数1中心の総数 Σt_j は指数部に入らない。**Q と全 S の U_w(S) が一致する二構成は P_I が一致する。**

## 数学的証明

全頂点に独立な連続一様優先順位を割り当て、小さい順に、まだ削除されていない頂点だけを採用する。各段階の相対順位は一様なので、逐次一様合法着手と同分布である。

独立点 j の優先順位を X_j とし、そこだけに隣接する t_j 個の中心の順位を L_{j,a} とする。中心を全く採用しない事象は、(i) 全ての j,a で X_j<L_{j,a}、(ii) 各特別中心 h の順位より前に A_h 内の独立点が少なくとも一つある、の同時成立と同値である。実際、中心を採用しないなら全ての独立点が採用され、各中心は自身の独立点近傍の先行着手によって遮られる。逆向きも同様。

(i) の確率は独立な群ごとに 1/(t_j+1) なので Q。(i) で条件付けた X_j は群内の最小順位であり、**w_j 個の独立一様順位の最小値**と同分布になる。j ごとの条件付き分布は独立である。そこで各 j を w_j 個の仮想的な独立点に置き換え、各特別中心 h が A_h 内の全仮想点に隣接する補助分割グラフを考える。(ii) は、この補助グラフで特別中心を一つも採用しない事象と同じ確率になる。

補助グラフに既存の「任意中心数の分割グラフ・一様合法着手部分集合再帰」を適用する。中心部分集合 S の近傍和集合の大きさは、ちょうど U_w(S) である。包除原理により (ii) の条件付き確率は Σ_S(-1)^|S|H(S)。これに (i) の確率 Q を掛ければ公式を得る。補助グラフは確率計算のための抽象的置換であり、元の幾何的残局を主張するものではない。□

## 新しい3中心の具体例

m=3、(t_0,t_1,t_2)=(1,2,0)、A_0={0,1}、A_1={1,2}、A_2={0,2} とする。中心は合計6個（次数1中心3個＋特別中心3個）、独立点3個である。

\[
\boxed{P_I=281/3240.}
\]

これは k=3 かつ t_j>0 のため、既存の k=2 の重み付き閉形式にも、t_j=0 の k 中心公式にも直接は含まれない。
