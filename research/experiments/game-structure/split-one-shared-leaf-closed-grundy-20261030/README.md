# 一つの二中心共有葉を持つ分割グラフの全局面Grundy閉公式（2026-10-30）

## 定理（数学的全称証明）

通常プレイの二点禁止ゲーム（Node Kayles）を考える。中心はクリークで、相異なる二中心 A,B にそれぞれ a,b >= 0 枚の私有葉が付く。A と B の両方に隣接する独立点（共有葉）が **ちょうど一つ**ある。それ以外の中心には私有葉だけが付く。独立点同士に辺はない。

それ以外の中心を、私有葉0枚が z 個、正奇数枚が o 個、正偶数枚が e 個に分類する。a,b,z,o,e はすべて任意の非負整数。孤立点はまず除外する。

このグラフのGrundy値 G(a,b,z,o,e) は次の表で完全に決まる。偶・奇は a,b の偶奇を表す。o の「正偶数」は o>=2 の偶数、e+ は e>=1 の意味。

| z | a,b の偶奇 | o=0 | o が奇数 | o が正偶数 |
|---|---|---|---|---|
| 0 | 偶・偶 | e=0: **1**, e+: **3** | e=0: **0**, e+: **2** | e=0: **1**, e+: **3** |
| 0 | 偶・奇 | **2** | **3** | **2** |
| 0 | 奇・奇 | e=0: **3**, e+: **0** | **2** | **3** |
| >=1 | 偶・偶 | **2** | **3** | **2** |
| >=1 | 偶・奇 | **3** | **2** | **3** |
| >=1 | 奇・奇 | **0** | **3** | **2** |

偶・奇の行は A,B を交換しても同じ。偶数には0も含む。さらに孤立点が h 個あれば値は **G xor (h mod 2)**。従ってこの族の全ての合法な後続局面で **Grundy値は0,1,2,3のいずれか**。この上界は鋭い。

例：中心二個に私有葉が一枚ずつあると、共有葉なしではGrundy値0（既存の私有葉定理）、共有葉を一つ追加すると **3** になる。私有葉が正偶数枚の第三中心を一つ加えると **0** に戻る。

## 全称証明：全着手の分類

F(z,o,e) を共有葉なし・私有葉だけの既存閉公式（[前回の定理](../split-private-leaves-closed-grundy-20261030/README.md)）とする。F の値は以下で完全に定まる。

- z>=1: o=0 なら1、o奇数なら2、o正偶数なら3。
- z=0,o=0: e=0なら0、e=1なら2、e>=2なら1。
- z=0,o>=1,e=0: o mod 2。
- z=0,o>=1,e>=1: o奇数なら3、o偶数なら2。

p=(a+b+o) mod 2 と置く。中心の選択は他の中心をすべて削除する。A,Bの選択後はそれぞれ b+o、a+o 個（mod 2）の孤立点が残る。共有葉の選択後は両中心が消え、a+b 個の孤立点と F(z,o,e) が残る。

その他の中心を選ぶと共有葉は孤立する。私有葉0枚または正偶数枚の中心を選べる場合の子値は p xor 1、正奇数枚の中心を選べる場合は p となる。

A の私有葉を選ぶと A が消え、残り a-1 枚が孤立する。共有葉は B の新しい私有葉となる。よって子値は F(z, o+[bが偶数], e+[bが奇数]) xor ((a-1) mod 2)。B の私有葉の場合は a,b を交換する。これらの手はそれぞれ a>0、b>0 のときだけ存在する。

正奇数枚の私有葉を持つその他の中心で葉を選ぶと、その中心が消えて偶数枚の孤立葉が残る。子値は G(a,b,z,o-1,e)。正偶数枚の中心の葉を選ぶと奇数枚の孤立葉が残り、子値は G(a,b,z,o,e-1) xor 1。

従って子値の集合は正確に次のものからなる（条件不成立なら該当項を除く）。

    (b+o) mod 2
    (a+o) mod 2
    F(z,o,e) xor ((a+b) mod 2)
    p xor 1                                      [z+e>0]
    p                                            [o>0]
    F(z,o+[b even],e+[b odd]) xor ((a-1) mod 2) [a>0]
    F(z,o+[a even],e+[a odd]) xor ((b-1) mod 2) [b>0]
    G(a,b,z,o-1,e)                               [o>0]
    G(a,b,z,o,e-1) xor 1                         [e>0]

その mex が G(a,b,z,o,e) である。最後の二項だけが G を再帰参照し、必ず o+e が減るので、**o+e に関する帰納法**が成立する。o=e=0 の場合も上記の非再帰項だけで決まる。

表が全非負整数で成り立つことは、この再帰に F の既知の閉公式と表の帰納仮定を代入して確かめる。無限個の整数を個別に検査する必要はない。実際、a,b は「0・正奇数・正偶数」、z は「0・正」、o は「0・1・正偶数・3以上の奇数」、e は「0・1・2以上」に分ければ、各着手の存在と子値が完全に決まる。o>=4 では o-1 は正、e>=3 では e-1 は正なので、これらの範囲で新しい場合分けは発生しない。表の奇数 o>=1 の値は o=1 と o>=3 で一致し、e>=1 の値も e=1 と e>=2 で一致する。

上記の有限場合分けを手で追う代わりに、付属の verify.py の formula_children は**全種類の合法手**を列挙し、a,b=0..3、z=0..1、o=0..5、e=0..3 の **768代表**について、表の値が mex と一致することを整数演算だけで監査する。各代表を任意の同値類へ拡張できる理由は直前の分類による。これは有限盤での実験的な外挿ではなく、帰納証明の有限な代数的場合分けの検算である。

任意の合法な後続局面は、同じ「共有葉一つ＋私有葉」の形、または共有葉なしの F 形と孤立点の和になる。したがって表と F の公式で **全局面を強解決**する。独立点が残った後の孤立点は通常プレイの非交和 xor 則で処理する。

## 既存研究との境界・未実施

- 一般分割グラフにはGrundy値7の既知証人があり、上界3を一般化してはならない。
