# 通常・misère 補助mex交換則の最小連結反例と最小樹反例（2026-10-31）

## 厳密な有限分類

有限単純グラフの Node Kayles（選択点の閉近傍を削除）で、通常Grundy値を g（終端0）、misère補助mex値を h（終端1）とする。τ(0)=1, τ(1)=0, τ(j)=j（j≥2）とする。既存の [分割グラフ全称交換定理](../split-misere-swap-and-winning-openings-20261031/README.md) は h=τ(g) を保証するが、一般グラフでは成立しない。

**定理1（全グラフの最小反例）**：頂点数5以下のすべての有限単純グラフは h=τ(g) を満たす。6頂点で破れるラベル付きグラフは正確に150個、同型を除くと **2種類のみ**。一つは非連結な P_3⊔P_3（90個）、もう一つは **連結な C_6（60個）**。いずれも (g,h)=(0,0)。従って最小の連結反例は6頂点で、同型を除いて C_6 だけ。

**定理2（樹の最小反例）**：頂点数7以下のすべての樹は h=τ(g) を満たす。8頂点の樹は同型を除いて23種類あり、うち **3種類**だけが交換則に反する。ラベル付きでは45,360個で、(g,h)=(1,4) が25,200個、(g,h)=(4,1) が20,160個。したがって最小の**連結な弦グラフ**反例は8頂点以下であり、特に最小の樹反例は8頂点。

これは有限完全列挙による厳密な分類であり、任意頂点数の弦グラフの性質を主張するものではない。

## 直接計算できる証人

C_6 の任意の初手後は P_3 で、g(P_3)=h(P_3)=2。したがって g(C_6)=h(C_6)=mex{2}=0。一方 τ(g(C_6))=1 なので不一致。

8頂点の樹の一例は辺集合

$$E=\{01,02,03,14,15,26,27\}.$$

頂点0〜7の初手後の (g,h) は順に

$$(0,1),(3,3),(3,3),(0,0),(2,2),(2,2),(2,2),(2,2).$$

子の通常値集合は {0,2,3} なので g=1。misère値集合は {0,1,2,3} なので h=4。頂点3を選ぶと P_3⊔P_3 が残り、これが misère 値0の子を新たに生む。

## 二方式の独立検証

- [verify_labeled.cpp](verify_labeled.cpp) は n≤6 の **全ラベル付き単純グラフ**（最大 2^15=32,768 通り）を全列挙し、連結性と閉近傍削除の通常・misère二重mexを計算する。さらに n≤8 の **全ラベル付き樹**を Prüfer 符号で列挙（n=8 は 8^6=262,144 本）して厳密に計算する。
- [verify_independent.py](verify_independent.py) は名前付き頂点の集合削除による別の再帰で n≤6 の全グラフを照合し、樹については **葉を追加する帰納的生成と無根木の正準括弧表現**で非同型代表を直接生成する。n≤8 の非同型樹数は 1,1,1,2,3,6,11,23、n=8 の反例は3種類。C++のラベル付き数え上げとは異なる生成方式。

両方式とも結果が一致し、反例・境界に不一致0。n≤5 の全グラフ、n≤7 の全樹が安全であることは有限完全列挙による証明であり、標本調査ではない。

実行：

    c++ -O2 -std=c++17 -Wall -Wextra -Werror verify_labeled.cpp -o /tmp/verify_swap
    /tmp/verify_swap
    python3 verify_independent.py

これは抽象的な二点禁止グラフの結論であり、一般の共円ゲーム残余超辺が二点のみとは限らない。整数格子上での C_6 や8頂点樹の実現可能性は未確認。knowledge正本への昇格・全体CIは未実施。
