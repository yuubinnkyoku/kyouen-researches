# 二点禁止残局の道・閉路のGrundy周期と最大次数2の鋭い上界

2026-10-19。標準q=4の幾何盤の**一般的な**結論ではなく、残余禁止集合がすべて2点集合である抽象通常プレイへの定理。有限計算に依存する部分を明示し、無限への帰納証明を分離する。

## 定義と主結果

二点禁止集合を辺とする単純グラフGの頂点を一つずつ置く。隣接した二頂点を両方置くことは禁止する。置いた頂点vとその隣接頂点は以後の候補から消える。これはNode KaylesのGrundy再帰と同じ。

P_nをn頂点の道、C_nをn頂点の閉路（n≥3）とし、a_n=g(P_n)とする。

**定理1（厳密な最小周期と開始点）**：

- a_0=0, a_1=a_2=1、n≥3では

  a_n = mex( {a_(n-2)} ∪ {a_i xor a_(n-3-i) : 0≤i≤n-3} ).

- すべてのn≥52で a_(n+34)=a_n。34は最小の最終周期、52は周期34の最小開始点。
- すべてのnで0≤a_n≤9、値9はn≥85かつn≡17 (mod 34) のときに限り現れる。
- n≥52でa_n=0となるのは n mod34∈{4,8,20,24,28} のときに限る。

**定理2（最大次数2の全称的上界と最小達成頂点数）**：任意の有限単純グラフGについてΔ(G)≤2なら

  0≤g(G)≤15.

上界はP_68 ⊔ P_13 ⊔ P_3 ⊔ P_1（計85頂点）で達成され、g(G)=15となるグラフの頂点数は**少なくとも85**。

また n≥3で g(C_n)=1 if a_(n-3)=0 else 0。したがって閉路もn≥55で周期34となる。

## 定理1の証明

道の端点を選ぶと残りはP_(n-2)、内部点を選ぶと左右に長さi、n-3-iの道が残る。互いに辺のない成分のGrundy値はxorで合成されるので再帰式を得る。n=1,2は直接確かめられる。

**有限周期延長補題**。この再帰を満たす任意の非負整数列a_nについて、N≥1, p≥1とする。N≤n≤2N+p+1の全てでa_(n+p)=a_nなら、n≥Nの全てでa_(n+p)=a_n。

証明：n≥2N+p+2について強い帰納法を使う。nとn+pの端点手はそれぞれa_(n-2)、a_(n+p-2)を与え、n-2≥Nであるため帰納法により一致する。

nの内部手はa_i xor a_j (i+j=n-3) である。n-3≥2N+p-1なのでi,jの少なくとも一方がN以上。その成分の長さにpを足してn+pの内部手に写す。増やす前の長さはnより小さいので、帰納仮定からxorは変わらない。

逆にn+pの内部手ではi+j=n+p-3≥2N+2p-1。もし両方がN+p未満ならi+j≤2(N+p-1)=2N+2p-2となり矛盾。よって一方がN+p以上であり、そこからpを引くとnの内部手に写る。減らした長さはN以上かつn未満なので同じく帰納仮定が使える。したがって両者の子Grundy値集合は等しく、mexも等しい。□

N=52,p=34とすると帰納開始は140。`verify_path_period.py`は再帰式を整数で直接計算し、**52≤n≤139の88個の等式**をすべて検査する。必要なa_nはn≤173までで、出力にn=0..51と52..85の全値を保存した。補題からn≥52の無限周期性が従う。

周期34の直前の失敗はa_51=2, a_85=9なので開始点52が最小。34の真の約数1,2,17はいずれも周期ブロックで不一致を持つ。34周期を持つ無限列に別の最終周期pがあるなら、両周期の最大公約数も最終周期である（十分長い共通周期領域で剰余類を移動すればよい）。従って34が最小の最終周期。

n≤85の直接計算と周期性から最大9、9の出現位置、零となる剰余類を得る。

## 定理2の証明

最大次数2の有限単純グラフは、道（孤立点も含む）と閉路の互いに素な和である。C_nでは最初の手がどの頂点でもP_(n-3)だけを残すから、g(C_n)=mex{a_(n-3)}であり0または1。道は定理1から0..9のいずれか。従ってどの成分の値も4ビットで表せる。xorで合成した全体も0..15に収まる。

計算した値は a_68=8, a_13=4, a_3=2, a_1=1。よって4成分のxorは15、頂点数は68+13+3+1=85。

最小性について、周期性により道の各値の**最初の出現**は0..85の範囲に含まれ、0,1,2,3,4,5,7,8,9の最小必要頂点数はそれぞれ0,1,3,5,13,15,32,68,85である。6は道に現れない。閉路は0または1であり、値1には道P_1（1頂点）の方が安い。

各成分のGrundy値vを選ぶと、現在のxor状態xからx xor vへ移り、少なくとも上記の頂点数を要する。16個のxor状態を持つ重み付き有向グラフの最短路を求めれば、任意の成分数・頂点数を含む全ての可能性の下界が得られる。全状態0..15の最短距離は

  0,1,3,4,13,14,16,17,68,69,71,72,81,82,84,85。

特に15への最短距離は85。非負重みの最短路はDijkstra法で厳密に計算でき、独立C++実装ではBellman–Ford型の緩和で同じ16値を確認した。よって最小性が従う。□

## 独立検証と信頼境界

- `verify_path_period.py`: 道の分割再帰、周期延長補題の有限基底88件、n≤2000の余分な照合、n≤20の全残存頂点マスク再帰、16状態最短路、結果JSON。
- `verify_path_period_independent.cpp`: 頂点番号ごとに左右の残存長を直接計算（n≤2000）、道n≤19と閉路n≤16の全残存頂点マスク再帰、別の最短路算法。
- `path_period_results.json`: 再生成可能な有限証明基底・最小頂点数表。

無限周期は有限計算**だけ**から推測したのではなく、有限周期延長補題によって全称的に従う。幾何的な標準正方形盤の残余グラフとしてP_68等が実現可能であることは**主張しない**。11×11の残余グラフが二点禁止のみ・最大次数2である場合に限り、g≤15と道・閉路の定数時間評価を適用できる。
