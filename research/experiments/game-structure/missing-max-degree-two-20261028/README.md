# 欠損二点型の最大次数2でも成立するGrundy閉形式（2026-10-28）

## 全称定理

通常プレイの二点禁止ゲーム（Node Kayles）で、クリーク `C={c_0,...,c_{k-1}}` と独立集合からなる分割グラフを考える。独立側の頂点はクリークの1点または2点にのみ隣接する。私有葉数を `t_i>=0`、二点型の重複数を `r_ij>=0` とする。**欠損グラフ `D={{i,j}:r_ij=0}` の最大次数が2以下**と仮定する。欠損の総数に上限は設けない。

**任意の `k>=5` と全ての非負整数 `t_i,r_ij` について**、次の公式が成立する。

```text
u   = (sum_i t_i + sum_{i<j} r_ij) mod 2
z_i = (t_i + sum_{j!=i} r_ij) mod 2

g(G) = 1 xor u xor z_0    (z_i が全て等しい場合)
g(G) = 2 + u              (z_i が混在する場合)
```

特に **`g(G)<=3`**。孤立した独立点が別に `f` 個あれば右辺と `f mod 2` のxorを取る。欠損グラフは道や閉路の非交和でよく、欠損数は `k` とともに無制限に増やせる。前回の欠損マッチング（最大次数1）の定理を真に拡張する。

**`k>=5` は鋭い。** `k=4`、欠損組 `{01,02,12}`、存在する `{03,13,23}` の重複数が全て2、私有葉 `t=(0,0,0,1)` の11頂点構成では **真の `g=2`、公式の予測は3**。正規化した `k=4` の全51,516構成では、この反例のラベル替え4件だけが不一致だった。

## 証明

### 偶奇への全称縮約

既存の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同じ非空近傍を持つ独立点の個数は、0、正の奇数、正の偶数の3分類でGrundy数が不変。従って `t_i` は0/1/2、存在する `r_ij` は1/2だけを完全列挙すれば、重複数が無界の場合も覆う。有限基底は単なる標本ではない。

### 子局面の値

クリーク頂点 `c_i` を選ぶと、残る独立点は全て孤立し、そのGrundy値は `u xor z_i`。

独立点を選んで隣接クリーク頂点集合 `B`（1点または2点）を消すと、残存クリークの各頂点 `i` について **`z'_i=z_i`** が保たれる。残存クリークに接続する独立点の総数偶奇を `u'`、新たな孤立点の個数偶奇を `delta` とすれば、選択した1点を除く独立点を二分して `delta=u xor u' xor 1`。

残存クリークに公式が成立する場合、独立点初手の子値は、残存 `z` が一様 `s` なら `u xor s`、混在なら `u xor 3` となる。

### 帰納段階 `k>=7`

独立点初手の後のクリーク点数は `k-1` または `k-2` で、ともに5以上。欠損グラフは誘導部分グラフになるため最大次数2以下を保ち、帰納仮定が使える。

親の `z` が全て `s` なら、クリーク初手も独立点初手も子値は `u xor s` だけ。mexは `1 xor u xor s`。

親の `z` が混在するなら、クリーク初手だけで子値0と1が両方現れる。**混在を残す、存在する二点型**を一つ選べる。二つの `z` 値の人数を `a,b` とする。

- `min(a,b)=1`：多数派は `k-1>=6` 点。各点が欠損させる組は高々2本なので、多数派の内部に存在する二点型があり、それを選んでも両方の値が残る。
- `min(a,b)>=2`：多数派は少なくとも4点。少数派の任意の1点から多数派へは、欠損が高々2本なので、存在する二点型がある。両側から1点ずつ消しても両方の値が残る。

この二点型を選んだ子値は `u xor 3`。その他の初手の子値は `{0,1,u xor 3}` に含まれる。よって `mex{0,1,u xor 3}=2+u`。帰納法が閉じる。

### 有限基底 `k=5,6`

`k=5`：最大欠損次数2の単純グラフは同型を除いて11種類。各型の全ての葉数0/1/2、存在する二点型1/2を列挙し、**645,408構成**をmex再帰で完全検査。不一致なし。

`k=6`：欠損数4以下は[既存の全称定理](../four-missing-pairs-k6-plus-induction-20261028/README.md)、欠損5組は[既存の全分類](../five-missing-pairs-k7-plus-induction-20261028/README.md)で処理できる（唯一の例外である5本星は最大次数5なので対象外）。最大次数2なら欠損数は最大6。**欠損6組は2-正則**で、同型類は6閉路 `C6` と三角形2個 `2K3` だけ。それぞれ `3^6*2^9=373,248` 構成、計 **746,496構成**を完全検査。不一致なし。

これで `k>=5` の全称定理が成立する。`k=4` の全ラベル付き51,516構成も別に完全検査した。総計 **1,443,420構成**。

C++は各独立点型の**閉近傍を直接削除して残存型を再集約**する実装。Pythonは `u,z` からクリーク初手を評価し、独立点初手を別の再帰で処理する実装。どちらも予想公式を子に代入して再帰を省略することはなく、**全1,443,420構成について一致**した。出力を `verification.txt` に保存した。

これは抽象的な二点禁止ゲームの定理であり、任意の分割グラフが整数格子の共円ゲームの残余局面として実現できるとは主張しない。11×11の勝敗も未確定。knowledge正本への昇格には、生成物再構築・整合性検査が必要。
