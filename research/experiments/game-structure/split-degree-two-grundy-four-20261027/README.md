# 分割グラフの独立側次数2でGrundy値4：13頂点の一意な最小証人（2026-10-27）

## 結論と既存結果との差分

抽象的な二点禁止ゲーム（Node Kayles、頂点を選ぶと閉近傍を消す通常プレイ）を考える。分割グラフをクリーク C と独立集合 I に分け、I の各点の C 内次数を制限する。

**数学的な明示反例：** |C|=5、|I|=8、I の各点の次数が **高々2** である13頂点グラフに g(G)=4 のものが存在する。

既存の [私有葉付きクリークの全称定理](../pendant-clique-closed-form-20261027/README.md) は、独立側次数が高々1なら、クリークの大きさによらず g≤3 と証明している。**次数上限を1から2に緩めただけで上界3が破れる**ことを今回確定した。従来の分割グラフの g=4 証人は独立側に次数3の点を含んでいた。

また [クリーク5の既存完全列挙](../split-clique-four-five-20261027/README.md) により、非孤立独立点が7個以下なら g≤3。従って **クリーク5に限れば独立側8点・総13頂点は最小**である。今回さらに、独立側次数1〜2の条件で g=4 を実現する8点多重集合は、クリークの頂点名の置換を除いて**一種類だけ**と完全列挙で確定した。クリーク6以上を許す全分割グラフでの最小頂点数は主張しない。

## 13頂点・24辺の明示グラフ

C={c0,c1,c2,c3,c4} を5頂点クリークとし、I は以下の8頂点とする。

- a は c0 のみに隣接する。
- j=1,2,3 について x_j と y_j はそれぞれ c0,c_j のみに隣接する（計6点）。
- b は c4 のみに隣接する。

I の内部に辺はない。クリークの添字を下位ビットから数えた I の近傍ビット集合は (1,3,3,5,5,9,9,16)。クリーク内10辺、交差14辺、**合計24辺**。

## 全初手を分類する紙上証明

S(G)={g(G−N[v]):v∈V(G)}、g(G)=mex S(G) とする。独立な孤立点を1個加えるとGrundy値に xor 1 が作用する。

1. c0 を選ぶと b だけが残り、子は g=1。c4 を選ぶと a と6個の x_j,y_j が孤立して残り、g=1。c1,c2,c3 のいずれを選んでも6孤立点が残り、g=0。
2. a を選ぶと c0 が消え、クリーク c1,c2,c3,c4 に私有葉が (2,2,2,1) 個付く。既存の私有葉付きクリーク閉形式で、正の偶数葉3群・正の奇数葉1群だから g=3。
3. x_j または y_j を選ぶと c0,c_j が消える。a と同じ対のもう1点が孤立する（2個なので xor 効果は0）。残るクリーク3点の私有葉数は (2,2,1) で、同じ閉形式から g=3。
4. b を選ぶと c4 が消える。残る c0 は全頂点に隣接する支配頂点であり、これを除いたグラフは Q=P ⊔ K1。P は3頂点クリークの各点に私有葉を2枚ずつ付けたグラフ、K1 は a。P は g(P)=1 かつ S(P)={0}：クリーク点を選べば4孤立点で値0、葉を選べば1孤立点と「2頂点クリークに各2葉」のグラフが残り、1 xor 1=0。よって g(Q)=g(P) xor 1=0、S(Q)={g(P)}∪{s xor 1:s∈S(P)}={1}。支配頂点を戻すと S={0,1} となり g=2。

全初手後のGrundy値は頂点順 (c0,c1,c2,c3,c4,a,x1,y1,x2,y2,x3,y3,b) で

    (1, 0, 0, 0, 1, 3, 3, 3, 3, 3, 3, 3, 2)

したがって **g(G)=mex{0,1,2,3}=4**。これは全初手の値を数学的に分類した証明であり、有限標本からの外挿ではない。

## 8独立点の全分類（計算機援用の有限完全定理）

クリーク5点の非空部分集合のうちサイズ1または2は 5+10=15 種類。独立点8個の近傍を重複を許して選ぶ全多重集合は

$$\binom{15+8-1}{8}=\binom{22}{8}=319\,770$$

種類である。クリークの頂点名を固定し、独立点の並びだけを無視した**全対象の完全列挙**である。次数0の孤立点は後述のように別途排除する。

二つの独立した計算の度数表は完全一致した。

| Grundy値 | 0 | 1 | 2 | 3 | 4 | 5以上 |
|---|---:|---:|---:|---:|---:|---:|
| 多重集合数 | 9,240 | 11,055 | 197,015 | 102,440 | **20** | **0** |

g=4 の20多重集合はすべて交差辺14本、総辺数24本。**20個の集合は、今回の証人を S5 によりクリーク頂点名だけ置換した軌道と完全一致**する。よってクリーク5・独立側8点・独立側次数1〜2という条件では、g=4 証人は置換を除いて一種類しかない。

独立側に次数0の点を含む場合、非孤立独立点は7個以下となる。既存の完全列挙の上界3と孤立点の xor 1 分離から、この場合も g≤3。従って次数0を許した8点の分類でも新しい g=4 証人は増えない。

この**一意性は計算機援用の有限完全定理**であり、単一証人の紙上証明と区別する。整数格子への幾何的埋め込みは示していない。
