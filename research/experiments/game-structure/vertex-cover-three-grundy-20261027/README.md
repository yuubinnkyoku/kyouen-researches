# 二点残余禁止グラフ：頂点被覆数3ならGrundy数は高々4（2026-10-27）

## 定理と証拠の種類

**計算機援用の全称定理。** 任意の有限単純グラフ G における通常プレイの Node Kayles（一頂点を選び、その頂点と全隣接頂点を除くゲーム）について、頂点被覆数 τ(G)≤3 なら、頂点数・辺数に制限なく

\[
\boxed{g(G)\le4}.
\]

上界は鋭い。これは**全称的な数学的有限帰着 + 有限完全列挙 + 独立した再帰実装の照合**による結果であり、有限標本を無限命題へ外挿したものではない。頂点被覆数2以下の既知の鋭い上界3を拡張する。

共円ゲームの安全局面へ適用するには、**包含極小残余禁止集合がすべて二点集合**で、その競合グラフの頂点被覆数が3以下である必要がある。三点以上の残余禁止集合には適用できない。

## 全称的な有限帰着

G の頂点数が3未満なら直接 g≤1。3以上なら、被覆集合に頂点を補って3頂点 x,y,z を選ぶ。外側は独立集合であり、各外側頂点の近傍は {x,y,z} の8種類の部分集合のいずれかである。

- 空の近傍の頂点は孤立しており、g にその個数の偶奇を xor するだけである。
- 非空近傍 S は7種類。各種類の頂点は互いに非隣接で同じ全linkを持つ。既存の全称定理 [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、その個数は **0、1、2**（0、正の奇数、正の偶数）へGrundy値を変えずに圧縮できる。
- 被覆集合内の辺は3本の候補から任意に選べるので、2³=8種類。

よって孤立点を除いた任意の G は、最大17頂点の **8×3⁷=17,496個のラベル付き代表**のいずれかと同じGrundy値を持つ。これらの代表には同型重複があるが、全種類を含むため上界証明には問題ない。孤立点を戻しても、0〜4はxor 1で0〜4に収まる。

## 完全列挙

[verify_signatures.py](verify_signatures.py) は7種類の近傍署名ごとの個数を保持し、手の後に被覆集合が減ったとき、署名を射影・合算して正の偶奇数へ圧縮する。孤立点は独立成分として xor する。全17,496代表を再帰的mexで計算した。

[verify_subsets.py](verify_subsets.py) は各代表を**実際の個別頂点と隣接ビット列**から組み立て、各手で閉近傍を削除する独立した部分集合mexを実行する。署名射影による子局面生成は使わない。全17,496代表のGrundy値が点ごとに一致し、計6,706,678個の局所メモ化状態を訪れた（代表間の同型は共有しない）。さらに、各近傍種類を0〜4個含む256個の追加標本について、直接再帰と正の偶奇圧縮後の署名再帰が一致した。

孤立点を含まない17,496代表のGrundy値の度数は以下。これは**ラベル付き署名代表の度数**であり、非同型グラフ数ではない。

| Grundy値 | 代表数 |
|---:|---:|
| 0 | 3,735 |
| 1 | 3,264 |
| 2 | 3,695 |
| 3 | 4,603 |
| **4** | **2,199** |
| 5以上 | **0** |

被覆集合の内部辺が0〜2本の場合は最大4、3本すべてがある場合は最大3だった。したがって全代表の最大値は厳密に4。

## 鋭い7頂点証人

頂点集合 {0,1,2,3,4,5,6}、辺集合

\[
\{(0,3),(0,6),(1,4),(1,5),(1,6),(2,3),(2,4),(2,5),(2,6)\}
\]

のグラフでは、{0,1,2} が頂点被覆で、最小被覆数も3である。0〜6の順に各頂点を選んだ子局面のGrundy値は

\[
(0,2,0,1,3,3,1).
\]

したがって g(G)=mex{0,1,2,3}=4。個別頂点の独立再帰でも確認した。これは**抽象グラフの証人**であり、整数格子上の共円局面での実現を主張しない。
