# 分割グラフのクリーク4点上界と5点での鋭い破れ（2026-10-27）

## 結論

有限単純グラフ上の二点禁止ゲーム（Node Kayles）を扱う。頂点を選ぶとその閉近傍が消える通常プレイである。分割グラフの頂点をクリーク C と独立集合 I に分割し、c=|C| とする。

**計算機援用の全称定理：** c≤4 なら、独立集合の大きさに制限なく、孤立点を許しても **g(G)≤3**。上界は c=2、独立側の近傍署名 (2,3,3) で達成する。

**数学的帰納法と有限完全列挙による全称定理：** c≥5 で孤立点がなければ **g(G)≤2c−6**。孤立点を許す場合は **g(G)≤2c−5**。特に c=5 の鋭い上界は孤立点なしで4、孤立点込みで5。c≥6 での上界の鋭さは未確定。

**鋭い証人：** c=5、独立側の近傍署名 (2,8,11,11,12,14,24,26) で、13頂点・28辺の分割グラフが **g=4**。孤立点を一つ加えると **g=5**。

**有限完全結果：** c=5 で独立側の非孤立点が7個以下なら g≤3。従って c=5 の指定分割で g=4 に必要な非孤立独立点数の最小値は **8**。

これらは抽象二点禁止ゲームの結果であり、整数格子上の共円・共線禁止集合から実現できることは未確認。三点以上の極小残余禁止辺を含む局面には適用できない。

## 全称帰着と再帰

C の各頂点に番号を振り、独立点の C 内近傍を二進数署名 s∈{0,...,2^c−1} で表す。同じ署名の独立点は互いに非隣接で同じ link を持つ。既存の [K0336](../../../knowledge/items/K0336-independent-residual-twins-parity-compression.md) により、同じ署名の個数を **0、正の奇数なら1、正の偶数なら2** に圧縮してもGrundy値は不変。署名0は孤立点なので、その個数の偶奇に応じて xor 1 するだけである。

クリーク点 v を選ぶと、残るのは v に非隣接な独立点だけなので、子の値はその個数の偶奇。独立点の署名 s を選ぶと、C の s に属する頂点が消え、他の独立点の署名は残存 C へ射影される。選択した点を一個減らし、射影後の同一署名を合算・正の偶奇圧縮して再帰し、mexを取る。署名0を選ぶ場合も同じ c の点数が減るため再帰は停止する。

c=4 では非空署名15種類の個数がそれぞれ0/1/2なので、**3^15=14,348,907** 個のラベル付き代表をすべて計算すれば無界の |I| に対する結論が出る。g=0,1,2,3 の度数は

\[
(596322,\ 600696,\ 6574420,\ 6577469)
\]

で、g≥4 は0。c≤3 についても全署名型の再帰で最大3以下。署名0を戻しても xor 1 は集合 {0,1,2,3} を保つため、孤立点を含む c≤4 の全称上界が従う。

c≥5 では帰納法を使う。孤立点がなければ独立側のどの手もクリーク点を少なくとも一つ消し、クリーク側の手の子の値は0または1。c=5 の独立側の手の子は c≤4 なので g≤3、従って mex≤4。c≥6 では独立側の子は c'≤c−1 の分割グラフとなるが、**子局面には孤立点が新たに生じ得る**。従って孤立点込みの帰納的上界を使い、子の値は最大 2(c−1)−5=2c−7（c'≤4 なら3以下）。クリーク側の子は0/1なので mex≤2c−6。孤立点を戻すと xor 1 で最大1増え、2c−5となる。孤立点の発生を無視して c≥6 に g≤c−1 と主張することはできない。

## c=5、独立側7点以下の完全列挙

孤立点を除いた署名は1〜31の31種類。n個の署名多重集合は二項係数 C(30+n,n) 通り。n=0,...,7 の **12,620,256多重集合**を完全列挙し、すべて g≤3 だった。n=7 の10,295,472多重集合の g=0,1,2,3 の度数は

\[
(260100,\ 321759,\ 531360,\ 9182253).
\]

これは n≤7 の**有限完全列挙**であり、c=5、n無制限の上界4は前節の数学的帰納法による。

## 明示証人と独立検証

C={0,1,2,3,4} を完全グラフとし、独立側8点の C 内近傍をビット集合 (2,8,11,11,12,14,24,26) とする。例えば署名11は {0,1,3} に隣接する。クリーク内部10辺、交差18辺、合計28辺。

頂点0〜12の全初手後のGrundy値は

\[
(0,1,0,1,0,2,3,0,0,3,0,3,0).
\]

値集合が {0,1,2,3} なので mex=4。孤立点追加では xor 1 により5。

- verify_exhaustive.cpp：署名別残余再帰。c=4 の14,348,907代表、c=5・n≤7 の12,620,256多重集合を完全検査し、13頂点証人も確認。
- verify_independent.py：異なる状態表現の残存集合閉近傍削除再帰と、選択済み独立集合増加再帰を使い、証人の全初手、孤立点追加、固定乱数400標本を独立照合。**全代表の独立生成器による再列挙は未実施**。
