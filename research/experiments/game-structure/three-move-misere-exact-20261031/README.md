# 残り最大3手の任意の遺伝的配置ゲーム：通常・misèreの全勝ち手と交換則の例外（2026-10-31）

## 結論（任意の有限点集合に対する数学的全称定理）

任意の有限な遺伝的安全集合族（安全集合の部分集合も安全）において、現在の安全局面 S から **今後追加できる点の最大個数が3以下** であると仮定する。初手として合法な点集合を L とする。通常Grundy値 g は終端0、misère補助mex値 h は終端1、非終端はいずれも子のmexで定義する。τ は τ(0)=1, τ(1)=0, τ(j)=j (j≥2) とする。

各 x∈L について、次の二つの条件を定義する。

- A(x)：ある y∈L\{x} について S∪{x,y} は安全だが、**どの** z∈L\{x,y} を加えても安全でない。つまり x を含む「2手で終わる」極大な追加対が存在する。
- B(x)：相異なる y,z∈L\{x} について S∪{x,y,z} が安全。つまり x を含む「3手まで続く」追加三点組が存在する。

これらは **追加二点組と三点組の安全性だけ** から決まり、Grundy再帰を必要としない。

**定理1（全初手の厳密な勝敗判定）**：

- 通常版で x が勝ち初手であることと **¬A(x)** は同値。
- misère版で x が勝ち初手であることと **A(x)∧¬B(x)** は同値。

**定理2（全Grundy値と交換則の必要十分条件）**：

各初手 x の子局面の通常値 c(x) は

| A(x) | B(x) | c(x) |
|---|---|---:|
| 偽 | 偽 | 0 |
| 偽 | 真 | 0 |
| 真 | 偽 | 1 |
| 真 | 真 | 2 |

である。L≠∅ なら

$$
g(S)=\operatorname{mex}\{c(x):x\in L\},\qquad
h(S)=\operatorname{mex}\{\tau(c(x)):x\in L\}.
$$

L=∅ なら (g,h)=(0,1)。それ以外の場合、**交換則 h(S)=τ(g(S)) が破れる必要十分条件は、すべての x∈L について A(x)∧B(x) が成り立つこと**。このとき必ず

$$\boxed{(g(S),h(S))=(0,0)}$$

であり、通常版・misère版とも後手必勝である。その他の局面では交換則が成立する。特に残り最大2手なら必ず交換則が成立する。残り最大3手でも、どちらのルールの勝ち初手も、二点・三点の合法性から厳密に求められる。

## 証明

残り最大1手の局面は、終端 (g,h)=(0,1)、非終端 (1,0) のいずれか。

残り最大2手の非終端局面では、どの子も残り最大1手なので、子の (g,h) は (0,1) または (1,0)。子の通常値集合が {0}、{1}、{0,1} のいずれかに応じ、親の (g,h) はそれぞれ (1,0)、(0,1)、(2,2)。よって **残り最大2手の全局面で h=τ(g)、g≤2**。

残り最大3手の局面で x を選ぶと、残り最大2手になる。続く y を選んだ後は残り最大1手であり、さらに z が存在すればその局面の通常値は1、存在しなければ0。したがって x の子局面で通常値0の子が存在することと A(x)、通常値1の子が存在することと B(x) は同値。mexにより c(x) は上表のとおりで、misère補助値は τ(c(x))。

根の非終端では c(x)∈{0,1,2} である。空でない部分集合 U⊆{0,1,2} について直接mexを比較すると、mex(τ(U))=τ(mex(U)) が **U={2} のときだけ失敗**し、そのとき両mexは0となる。U={c(x):x∈L} と置けば定理2を得る。

## 鋭い6点反例（グラフに限らない）

L={0,1,2,3,4,5} とし、**全ての二点組を安全**、安全な三点組は **{0,1,2} と {3,4,5} だけ** とする。四点以上は全て禁止する。この族は遺伝的で、残余容量は3。

任意の x は、同じ三点組内の他の二点とともに安全な三点組を作るため B(x) が真。一方、反対側の三点組の任意の y と作る安全な二点組は、どの三点組にも延長できないため A(x) も真。よって **全6初手の子が通常値2、根は (g,h)=(0,0)**。二点の禁止が全くなくても交換則は破れる。

Node Kayles（禁止二点組だけ）の具体例としては既知の C₆ があり、全初手の子は P₃ で通常値2。既存の [6頂点最小反例分類](../misere-swap-sharp-connected-boundary-20261031/README.md) と整合する。既存の [合法点5個以下の交換則](../../../knowledge/items/K0309-misere-small-legal-set-exchange.md) により、**6合法点が最小**である。
