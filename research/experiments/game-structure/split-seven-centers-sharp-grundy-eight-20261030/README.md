# 七中心分割グラフのGrundy上界8・9の鋭さ（2026-10-30）

## 結論

有限単純分割グラフの通常プレイ Node Kayles を考え、クリーク側の頂点数を **ちょうど7** とする。

既存の [クリーク数に関する全称上界](../split-clique-four-five-20261027/README.md) により、独立側に孤立点がなければ `g(G)≤2·7−6=8`、孤立点を許せば `g(G)≤2·7−5=9`。**今回、両方の上界を達成する明示例を得た。**

- 孤立点なし：クリーク7点、独立点15点、計22頂点・47辺で **g=8**。
- 孤立点あり：上のグラフに孤立点1点を追加した23頂点グラフで **g=9**。孤立成分のGrundy数1との xor により `8 xor 1=9`。

従って **クリーク数7に対する既存の一般上界は、孤立点の有無の両方で鋭い**。クリーク数5・6での鋭さは既存の別証人による。本結果は7についての新たな達成例であり、クリーク数8以上の上界の鋭さを主張しない。

## 明示証人

`C={c0,...,c6}` を7点クリークとする。独立点のクリーク内近傍を、`ci` に対応する第 `i` ビットの整数で表す。15個の署名を重複込みで

```text
[3,3,4,4,5,9,9,16,33,33,64,64,68,80,84]
```

とする。全署名は非空で、最大次数は3（署名84）。クリーク内部21辺、交差26辺、合計47辺。クリークにより全グラフは連結である。

全初手後のGrundy値を、クリーク点 `c0,...,c6`、続いて上の独立点15個の順に並べると

```text
[0,1,0,1,0,1,0,2,2,4,4,2,2,2,6,2,2,7,7,4,5,3]
```

である。値集合は `{0,1,2,3,4,5,6,7}` に等しいため、mexは **8**。これは明示した有限グラフの厳密な値であり、上界8の全称性は既存の定理に依拠する。

## 独立検証と最小性の限定

- [verify.py](verify.py) は (A) クリークの128部分集合だけを用いる署名・偶奇再帰と、(B) 個々の22頂点の隣接ビット集合から閉近傍を削除する再帰を**独立に実装**し、根・全22初手後の値を照合する。孤立点を追加した23頂点例も後者で直接 `g=9` と検査する。
- [verify_all_subgraphs.cpp](verify_all_subgraphs.cpp) は上記二再帰を使わず、22頂点の **全 `2^22=4,194,304` 個の誘導部分グラフ**について、残存頂点集合の昇順動的計画法でmexを計算する。結果は `g=8` の誘導部分グラフが**元の全22頂点グラフだけ**、最大Grundy値も8だった。

従ってこの証人は、**真の誘導部分グラフのどれもGrundy値8を持たない**という意味で誘導部分グラフ極小である。ただし **全ての7中心分割グラフの中で22頂点が最小**とは主張しない。Grundy値は一般に頂点削除で単調でないので、単一頂点削除だけで極小性を結論してはいない。

```sh
python3 research/experiments/game-structure/split-seven-centers-sharp-grundy-eight-20261030/verify.py
c++ -std=c++17 -O3 -Wall -Wextra -pedantic research/experiments/game-structure/split-seven-centers-sharp-grundy-eight-20261030/verify_all_subgraphs.cpp -o /tmp/split_g8_all
/tmp/split_g8_all
```

2026-10-30実行結果：署名再帰と個別頂点再帰は根8・22子値で一致、孤立点付き根9、個別頂点再帰の記憶状態数は22頂点137,782、23頂点275,564。全誘導部分グラフ4,194,304個のうち `g=8` は1個。
