# 閾値グラフのGrundy数は最大3：六状態による全称閉形式（2026-10-27）

## 定理と範囲

有限単純グラフの二点禁止ゲーム（Node Kayles：一点を選び閉近傍を消す通常プレイ）を扱う。**閾値グラフ**とは、空グラフから「孤立頂点を追加する（I）」または「既存全頂点に隣接する支配頂点を追加する（D）」という操作を繰り返して得られるグラフである。

**数学的全称定理：** 任意の閾値グラフ G について `g(G)≤3`。さらに構築列を左から読むだけで、頂点数に線形な時間・定数記憶でGrundy値を**厳密に**計算できる六状態有限オートマトンが存在する。上界3は鋭く、構築列 `I I D I` の4頂点グラフ（3頂点道と孤立点）で達成する。**連結**の達成例は `I I D I D` の5頂点グラフ。

一般の分割グラフには `g=4` の既知反例があるため、この結果を分割グラフ全体へ拡張してはいけない。閾値グラフは分割グラフの真部分族である。

## 全称証明：子局面の値集合を状態とする

`S(G)={g(G-N[v]):v∈V(G)}` を全初手後のGrundy値集合、`g(G)=mex S(G)` とする。空グラフは `S=∅, g=0`。

独立な孤立頂点の追加を `I(G)=G⊔K_1`、全頂点に隣接する新頂点の追加を `D(G)=G∨K_1` とすると、**任意の有限グラフ**について以下の恒等式が成り立つ：

```text
g(I(G)) = g(G) xor 1
S(I(G)) = {g(G)} ∪ {x xor 1 : x∈S(G)}

S(D(G)) = {0} ∪ S(G)
g(D(G)) = mex({0} ∪ S(G))
```

最初の二式は孤立頂点を選ぶ手と旧頂点を選ぶ手を分け、独立成分のxor則を使う。後の二式は新しい支配頂点を選ぶと空局面となり、旧頂点を選ぶと新頂点が必ず消えることから従う。

次の六状態 `(g,S)` は両操作に関して**閉じている**。

| 状態 | g | S（子の値集合） | Iで移る先 | Dで移る先 |
|---|---:|---|---|---|
| E | 0 | ∅ | A | A |
| A | 1 | {0} | B | A |
| B | 0 | {1} | A | C |
| C | 2 | {0,1} | D | C |
| D | 3 | {0,1,2} | F | D |
| F | 2 | {0,1,3} | D | F |

各行の遷移は上の恒等式を代入するだけで個別に確認できる。空グラフ E から始め、任意の I/D 構築列についてこの表で帰納すれば、到達状態は常に六状態のいずれかである。よって `g∈{0,1,2,3}`。これは**有限列挙によらない全称証明**であり、表そのものが全長の正確なGrundy計算法になっている。

注意：`g=2` だけでは C と F を区別できない。値集合 `S` を記憶することが閉形式の要点である。また「D追加で常にGrundy不変」は誤りであり、B→C では0から2へ変わる。

## 独立検証

`verify.py` は構築列から隣接ビット集合を直接作り、(1) 残存頂点集合から閉近傍を削除する再帰、(2) 選択済み独立集合を増やす再帰、という異なる状態表現でGrundy値と全子局面値集合を求める。六状態表の結果と**各構築列で完全一致**するか調べる。

```sh
python3 research/experiments/game-structure/threshold-graph-six-state-20261027/verify.py
```

2026-10-27の実行結果：

```text
exhaustive_graphs= 8192
random_graphs= 160
state_counts= [1, 617, 377, 599, 3569, 3189]
max_grundy= 3
all checks passed
```

0〜13頂点について最初の操作を I に固定した全 `2^(n-1)` 構築列（合計8192列）を**有限完全検査**。14〜19頂点は固定乱数160列の**標本検査**。この実験は全称証明の必要条件ではなく、表・実装ミスの独立監査である。全閾値グラフの全構築列は帰納法で被覆される。

## 適用境界と残件

これは**抽象的な二点残余禁止グラフ**に対する結果。実際の共円ゲームの残余禁止集合がすべて二点で、対応グラフが閾値グラフなら、巨大な頂点集合でも厳密なGrundy値を構築列の長さに線形な時間で得られる。閾値グラフ認識と構築列生成の費用、11×11の局面での出現頻度・実測高速化は未確認。三点以上の極小残余禁止辺を含む局面には適用できない。整数格子での達成例の実現も主張しない。
