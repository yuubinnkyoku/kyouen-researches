# 一般マルチセット マージの境界Mex還元定理と対角帯・ストライプ構造の有限観測（2026-11-20）

- 対象: H(R;X;z)（κ=1 残余ゲーム・K0832 の定義と閉形式。生再帰セマンティクスは
  K1101 検証器から verbatim）

  MERGE(∀S) と、対角帯の明示的なビット条件群 BAND(∀S) が同値である。

  置き換えられた。BAND 自体は本項では有限証拠のみ（§4）で、まだ全称証明ではない。

## 1. 定義

- q_odd(k) = k（k 奇）または k−1（k 偶）。
- single_token(x,z,R): K0832 出版単一トークン閉形式。z ≥ x+1 場合は
  R ≤ q_odd(x) で (R 奇→2 / R 偶→0)、R > q_odd(x) で x mod 2。**z 非依存**。
- H(R;X;z): κ=1 残余ゲーム（生再帰: v>1 の縮小子は z を保ち和を 1 減らす、
  v==1 の除去子は和を 1 減らし z を 1 増やす、z ≥ 1 で 1⊕H(R−1,X,z−1) の
  up-down 子、値は mex; K1101 `H_canonical` verbatim）。

```
MERGE(S)  := 「sum X = S の全マルチセット X・全 z >= S+1・全 R >= 0 で
              H(R;X;z) = single_token(S,z,R)」
D_X(m)    := H(m;X;S)                      （対角帯: row z=S）
BAND(S)   := 「sum X = S の全 X について
   S 偶数:  (D_X(m) != 1 for all m)  and  (D_X(m) == 0 for all even m <= S-1)
   S 奇数:  (D_X(m) == 0  iff  (m even and m <= S-1))
            and (D_X(m) != 1 for all odd m <= S-2)」
```

単一トークン X={S} では D_X == single_token(S,S,·)（z==x 場合）であり、
その式はちょうど BAND を満たす（S 偶: e ∈ {0,2}・偶 R ≤ S−1 で 0、
S 奇: e==0 ⟺ 偶 R ≤ S−1）。よって BAND の量化は単一トークン含め全形状で意味を持つ。
MERGE の X={S} も自明。S=1 はマルチセットが {1} のみで両辺自明。

## 2. 記号的証明

### 2.1 補題 R1（遠行転送）

z ≥ S+2 の位置 (X,z) の子は 3 種:
(v−1 への) 縮小子: (sum S−1, z)、除去子: (sum S−1, z+1)、up-down 子: (sum S, z−1)。
いずれも merged region に留まる（z, z+1 ≥ S+2 = (S−1)+3 ≥ (S−1)+1、
z−1 ≥ S+1）。さらに z ≥ (S−1)+2 なので縮小子・除去子の値は
single_token(S−1, ·, R−1) の z ≥ x+1 場合で同一値
a'(R−1) = single_token(S−1, z, R−1) に等しい（z 非依存）。
単一トークン {S} の縮小子はまさに同じ位置 (S−1, z)。
よって「MERGE(S) の全 z ≥ S+1 がレベル R−1 で成立」＋「MERGE(S−1)」を仮定すると
両者の mex の入力が一致し、レベル R の z ≥ S+2 で H(R;X;z) = single_token(S,z,R)。■

### 2.2 補題 R2（崩壊）

境界 z=S+1 では、token 子（縮小: (S−1, S+1)、除去: (S−1, S+2)）は
z ≥ (S−1)+1 の merged region にあり、MERGE(S−1)（と z 非依存性）により
**全ての token 子が同一値 a(m) := single_token(S−1, S, m) に崩壊**する
（m = R−1; 縮小子 z=S+1、除去子 z=S+2 の差が z 非依存で消える。
X の重複トークンは mex で同一視される）。子集合は {a(m)} ∪ {1 ⊕ D_X(m)}:

```
H(R; X; S+1) = mex({ a(R-1), 1 ⊕ D_X(R-1) })            （境界分解）
single_token(S, S+1, R) = mex({ a(R-1), 1 ⊕ e(R-1) })   （単一トークン側）
```

ここで e(m) := single_token(S, S, m)。同じ分解を対角線そのものに適用すると
(MERGE(S−1) が z=S, S+1 の token 子を処理する):

```
D_X(m) = mex({ a(m-1), 1 ⊕ U1_X(m-1) })    （レベル1カスケード）
```

U1_X(m) := H(m; X; S−1)（レベル1ストライプ・row z=S−1）。■（C5・C13 で有限照合）

### 2.3 補題 R3（mex 事例補題）

D の値域の全事例（C10 で全数表照合・816点）:

| a | mex({a, 1⊕D}) | 依存ビット |
|---|---|---|
| 0 | D==0 → 2、D!=0 → 1 | D==0 のみ |
| 1 | D==1 → 2、D!=1 → 0 | D==1 のみ |
| 2 | D==1 → 1、D!=1 → 0 | D==1 のみ |

よって **mex({a,1⊕D}) == mex({a,1⊕e}) ⟺ [a==0 のとき (D==0 ⟺ e==0)] または
[a∈{1,2} のとき (D==1 ⟺ e==1)]**。■

### 2.4 還元定理

補題から直ちに a(m) と e(m) の帯構造が出る（single_token の z==x, z≥x+1 場合）:

- a(m) = single_token(S−1, S, m): S 偶 → 2（奇 m ≤ S−1）/ 0（偶 m ≤ S−1）/ 1（m ≥ S）。
  S 奇 → 2（奇 m ≤ S−2）/ 0（その他）。
- e(m) = single_token(S, S, m): S 偶 → 2（奇 m ≤ 2S−1）/ 0（その他）。
  S 奇 → 2（奇 m ≤ 2S−1）/ 0（偶 m ≤ S−1）/ 1（その他）。

**⟸（BAND(S) ⟹ MERGE(S)）**: MERGE(1..S−1) を外側帰納法の仮定とし、
レベル R について帰納する。境界 z=S+1（R ≥ 1, m=R−1）では R2 により
一致条件は R3 のビット条件に帰着し、BAND はそれを全位置で満たす:

- S 偶: a∈{1,2} の位置（奇 m ≤ S−1: e=2、m ≥ S: e∈{0,2}）はいずれも e≠1 なので
  条件は D≠1（BAND 第一節）。a==0 の位置（偶 m ≤ S−1）は e==0 なので条件は
  D==0（BAND 第二節）。
- S 奇: a==2 の位置（奇 m ≤ S−2, e==2）は D≠1（BAND 第二節）。a==0 の位置は
  (D==0 ⟺ e==0) ⟺ (D==0 ⟺ 偶 m ≤ S−1)（BAND 第一節）。

境界が全 R で一致し、遠行 R1 が z ≥ S+2 を帰納転送する。R=0 は自明。■

**⟹（MERGE(S) ⟹ BAND(S)）**: 境界一致は R3 のビット条件を全 m で与える。
節を集める:
- S 偶・D≠1: a==2 位置（奇 m ≤ S−1）と a==1 位置（m ≥ S）の条件から D≠1。
  a==0 位置（偶 m ≤ S−1）では D==0。全 m で D≠1。
- S 偶・偶 m ≤ S−1 で D==0: a==0 位置の条件そのもの。
- S 奇・iff 節: a==0 位置では (D==0 ⟺ e==0) が得られ、これは
  偶 m ≤ S−1 のとき D==0、それ以外（偶 m > S−1 と全奇 m > S−2）で D≠0 を与える。
  残る奇 m ≤ S−2（a==2 位置）では D≠0 が直接の条件に出ないが、
  レベル1カスケード D_X(m) = mex({a(m−1), 1⊕U1_X(m−1)}) において
  m−1 は偶 ≤ S−3 なので a(m−1)==0、よって mex は必ず ≥1、すなわち D≠0。
- S 奇・奇 m ≤ S−2 で D≠1: a==2 位置の条件そのもの。∎

**系**。全 S ≥ 1 で MERGE(S) ⟺ BAND(S)（各 S の証明は MERGE(<S) を前提する
二重帰納。S=1 は両辺自明）。特に **MERGE(∀S) ⟺ BAND(∀S)**。
一般マルチセットマージの全称化は、対角帯のビット条件群 BAND の全称証明に
**還元**された。BAND・レベルkストライプのカスケードは §4 の有限観測の対象で
まだ全称証明ではない。

## 4. 有限観測（全称主張ではない）

- **BAND は S ≤ 20 全分割（2,714 形状）・r ≤ 200（C7/C8）、2トークン部品≤40・
  r ≤ 200（C12）、深部 r ≤ 600（C13）で違反なし**。還元定理の意味は:
  これらの BAND 証拠がそのまま同範囲の MERGE の証拠になること（C4・C12・C13
  はマージ行の直接照合でも追認）。
- **レベル1・2カスケード**: R2 の対角分解を繰り返すと、D の条件は
  U1 = H(·;X;S−1) のビット条件（L1-A/L1-B: C9）、さらに U2 = H(·;X;S−2) の
  条件（Z2/N2: C11・C12・C13）へと下降する。各レベルの主張帯は
  レベル1は m ≤ S 程度、レベル2は m ≤ S−2 程度と約1ずつ縮小する。
- **偶S対角帯ゼロ法則（一方向形）**: 全偶 m および m ≥ 2S で D==0（C11）。
  奇 m < 2S での非自明な D≠0 構造は BAND(S偶) の第二節（偶 m ≤ S−1）
  の外側にあり、法則の双条件形は S 奇の場合と非対称。
- **帯表 B(k,S)**（C14・監査JSONに全 152 行）: レベル k (=S−z) のストライプで
  「全 X of sum S で H(r;X;S−k) == single_token(S,S−k,r)」が成立する r の
  前帯幅。k ≤ 2 はきれいな閉形式:
  **B(0,S) = S+2−(S mod 2)、B(1,S) = S+1−(S mod 2)、B(2,S) = S−(S mod 2)**。
  k ≥ 3 は概ね S−2·⌊(k+1)/2⌋ 程度まで縮小し（奇k: 2⌈(S−k+1)/2⌉ 型、
  偶数丸め構造）、最深部（z=0,1）で床 B=2 に着地する。第2帯の開始は
  低 k では B+2 前後、深い k では上方へずれる。これらは**観測**であり
  閉形式の全称主張ではない。

## 5. 信頼境界

- 還元定理・補題 R1/R2/R3 の全称性は §2 の記号的証明による。依存は
  K0832 の single_token 閉形式（出版済み・z==x と z≥x+1 の場合の式と
  z 非依存性）と K1101 の生再帰セマンティクス verbatim。Lean 形式化ではない。
- C1〜C3 はエンジン錨、C4〜C13 は有限ドメインのセンサスであり証明の
  代わりではない。C14 は帯抽出であり観測記録である。
- BAND・レベルkカスケード主張・帯表構造は**全称未証明**である。一般マルチセット
  マージの全称成立は BAND の全称証明（カスケードの upstairs 帰納）に還元されて
  いるが、それは次ラウンド以降のフロンティアである。
- S=z 行（対角線上）ではマージは失敗する（K1101 の鋭さ・C3 で固定）。
  本項の MERGE の量化は z ≥ S+1 に限り、S=z 行には一切触れない。

## 6. 次の一手

1. カスケードの一般レベル化: レベル k のストライプ主張（L_k のビット条件）
   と帯幅の縮小則（B(k,S) の閉形式）を導出し、k が S で打ち切られることを
   証明できれば BAND(∀S) ⟹ MERGE(∀S) が帰納的に閉じる（本項の還元定理と
   合わせて一般マージの全称証明になる）。
2. レベル3（L3）の明示的主張の導出と S≤20 センサスでの検証。
3. per-y 閉形式レーン（K1141/K1143 など）との交差: 2トークン形状 X=(x,y) に
  限れば、K1101 の境界整合から §2.4 の収集論法により当該形状の BAND 節が従う。
  y≥3 の出版閉形式が出れば、同じ経路で「形状別 BAND」の独立照合が可能になる。
