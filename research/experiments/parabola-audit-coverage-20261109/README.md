## 再現

repo rootで:

```sh
uv run --locked python research/experiments/parabola-audit-coverage-20261109/inventory.py --output research/experiments/parabola-audit-coverage-20261109/inventory.json
```

`inventory.json` に入力commit、各ファイルのSHA-256、被覆・未被覆の連続区間、
計画標本の未被覆dと13個の制御検査を保存した。区間の両端はともに包含する。
重複d、範囲外d、旧検査器hash、非UNSAT、検査失敗、空証明等の偽造レシートを拒否する。
完全被覆から1件を除く場合とUNKNOWNに変える場合も、完全と判定しないことを確認する。

## 範囲

これは保存された受理レシートの整合性・被覆検査であり、DRATの再生ではない。
ソルバ、検査器、CNF生成の新しい計算は起動しない。
各dのDRAT受理の一次記録と、今回その記録を集計した処理を区別する。
検査器の一般健全性や符号化の数学的正しさの証明ではない。
計画標本の完了を全dの監査完了へ拡張せず、標本から未検査dのUNSATを推定しない。

最新の命題・statusはSSOTのK0693/K0702/K0706/K0708を参照する。
この固定snapshotの後に監査が増えても、当時の入力・出力は書き換えず、
必要な時点の別snapshotを評価する。
