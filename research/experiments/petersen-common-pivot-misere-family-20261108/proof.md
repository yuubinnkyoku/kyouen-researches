# Petersen joinから作る通常・misère同時後手勝ちの無限族

## 定理

k≥1とする。Petersenグラフk個の完全joinをH_kとし、
合法pivot cと、H_kの各辺uvに対応する純三点禁止集合{c,u,v}を作る。
この通常／misère補助値は全kについて

\[
 \boxed{(g,h)=(0,0).}
\]

従って全残余辺が一つの未占有点を共有し、rank三以下というK0692の条件下でも、
通常版とmisère版の両方で後手勝ちになることがある。
合法点数は10k+1、三点辺数は50k²−35k。
K0683で標準q=4の指定有限整数点盤に実現でき、
占有anchor数50k²−35k、盤点数50k²−25k+1となる。
実現した盤の全禁止四点組は未占有cを共有する。
標準全正方形格子盤の空盤勝敗とは別の主張である。

## Petersenグラフの局所構造

PetersenグラフをKneser KG(5,2)で定義する。
頂点は五元集合の二要素部分集合10個、二頂点が交わらないときに辺で結ぶ。
一頂点a={1,2}の閉近傍を消すと、残る頂点は
{1,i},{2,i} (i=3,4,5)の六個。
残余の辺は{1,i}と{2,j}でi≠jのものだから、K_{3,3}から完全マッチングを
除いた六角形C6になる。対称性により全頂点で同じ。

完全join H_kでは一つの頂点へ着手すると他のk−1成分も全て消え、
自成分からC6だけが残る。従ってH_kの全Node-Kayles初手の子はC6。
C6のどの手も三点道P3を残し、P3は通常・補助値とも2なので、
C6は(g,h)=(0,0)、H_kは(g,h)=(1,1)である。

## 純三点pivot族の全初手

cへ先に着手すると、H_k上の二点禁止ゲームになり、子値は(1,1)。
外側点vへ先に着手すると、vの隣接点uについて二点辺{c,u}が生じる。
この子の外側残点数は10k−1で奇数。
さらにcへ着手した後のリンクゲームはC6で(g,h)=(0,0)。

通常版ではK0692の二点辺付き閉形式から、子のgは1。
misère版ではK0694の変換から、子のhは2+t(C6)で、少なくとも2。
よって初手の子の通常値は全て1、補助値はcへの手で1、他では2以上となる。
どちらも子値0がなく、根のmexはともに0。

実際にはC6からの子P3はh=2で、h=0/1制限ゲームではC6に手がないため、
t(C6)=0。全外側初手の補助値は厳密に2である。

## 辺数と幾何盤の大きさ

Petersen各成分の辺は15本、異なる二成分の間は10×10本なので

\[
 |E(H_k)|=15k+100\binom{k}{2}=50k^2-35k.
\]

合法点10k+1に、各三点辺につきK0683のanchorを一つ追加する。
全anchorを占有し、cとH_kの頂点を未占有にすれば指定した残余ゲームとなる。
禁止四点組は各{c,u,v,anchor_uv}だけであり、初期占有集合は安全。
従って全kの整数点盤実現と点数式が得られる。

## 独立検査

k=1..5について、全外側頂点の閉近傍削除が連結二正則六頂点グラフC6になることを
隣接集合から直接検査し、Node-Kaylesの通常・補助値が(1,1)、全子(0,0)と確認した。
k=1,2の純三点pivotゲーム全体は、別C++の占有subset DPで根値(0,0)を検査。
k=1はK0683の具体的26点整数座標へ移し、全四点組・全安全状態も検査した。
件数と座標は`output/audit.json`に保持する。
無限kの結論は上の局所構造と全初手の数学的証明による。

```sh
uv run --locked python research/experiments/petersen-common-pivot-misere-family-20261108/verify.py
```

hは直和のSprague–Grundy値ではない。最後の合法手が負ける比較ルールの補助値である。
初期局面以外の全局面勝敗の分類、最少点数、世界初性は主張しない。
