# 容量占有ゲームの全余裕・全次元Grundy一様上界3

2026-10-10。参照main: `ed75f33d9ccc1557df6143a59ec0994f46f28594`。既存K0352の「h≥4ではg≤3が未証明」を解消する新しい全称定理。K0356〜K0360の余裕0〜3公式とも整合する。

## 定理（数学的全称証明）

`1≤h<w`, `m≥1`, `0≤r<h*m` の抽象容量占有ゲームを考える。降順占有数 `m≥x_1≥...≥x_w≥0` で `x_1+...+x_h≤r` が安全条件。`sigma=r−sum_{i≤h}x_i` を容量余裕とする。全ての安全局面について

- `sigma` が偶数なら `g(x)∈{0,1}`。
- `sigma` が奇数なら `g(x)∈{0,1,2,3}`。

よって任意の `h,w,m,r`、任意の容量余裕で **`g(x)≤3`**。`hm≤r` の自明な無制約領域でも `g(x)` は残り着手数の偶奇であり同じ結論が成立する。`h≥2`・奇数 `n=w−h` では既存K0358の余裕1の構成が `g=3` を実現するので、定数3は最良。

さらに全局面のGrundy値を、上位h列の形だけに付ける有限の二値署名で正確に計算できる（以下）。

## 証明

上位h列の降順形を `u`、その最小値を `b`、下位列数を `n=w−h`、下位列の石数和を `s`、`R=n*b−s≥0` とする。上位列のどれかを増やす着手によって得られる相異なる上位形の集合を `U(u)` と書く。`sigma>0` なら `r<h*m` により `U(u)` は非空。上位着手 `u→v` では下位和は変わらず `R→R+n(b(v)−b(u))`、余裕は1減る。下位の `b` 未満の列への着手では `u` と余裕は不変で `R→R−1`。下位の値がちょうど `b` の列を増やす場合は、上位の値 `b` の列を増やす着手と同じ降順局面になる。従ってこの二種類で全合法手が尽きる。

`R=0` なら下位着手はない。`R>0` なら下位着手が必ず存在し、同じ上位形と `R−1` を持つ下位着手子は、帰納法により全て同じGrundy値を持つ。余裕 `sigma` に関する帰納と、各余裕内の `R` に関する帰納を使う。

**偶数余裕の署名** `theta_sigma(u)∈{0,1}` を定め、`g=(R+theta_sigma(u)) mod2` を示す。余裕0では上位着手ができず下位を全て `b` まで埋めるだけなので `theta_0=0`。

**奇数余裕の署名** は `single(a)` (`a∈{0,1}`) または `mixed` とする。`single(a)` なら `g=(R+a+1) mod2`、`mixed` なら `g=2+(R mod2)` と示す。

奇数余裕 `sigma` では、全上位子 `v∈U(u)` が偶数余裕である。各子のGrundy値は

`(R+alpha_v) mod2`, `alpha_v=(n*(b(v)−b(u))+theta_{sigma−1}(v)) mod2`。

`{alpha_v}` が一元集合 `{a}` なら、`R=0` のmexと、`R>0` での下位子値を使う帰納から `g=(R+a+1) mod2`。両値 `{0,1}` が現れるなら、上位子は毎回 `{0,1}` を与え、下位子の値は前の `R` での `2/3` なので `g=2+(R mod2)`。奇数余裕の署名はこれで決まる。

偶数余裕 `sigma≥2` では、全上位子 `v` は奇数余裕である。`mixed` 型の子は値2か3であり、mexの0/1には影響しない。`single(a_v)` 型の子は

`(R+beta_v) mod2`, `beta_v=(n*(b(v)−b(u))+a_v+1) mod2`

を持つ。**すべてのsingle型上位子の `beta_v` は同一**である。実際、異なる二つの上位子 `v_1,v_2` は、元の上位h列の異なる二箇所を増やすことで得られるので、両箇所を増やした共通の二手後上位形 `z` を持つ（可換菱形）。`sigma≥2` なので両順序とも合法。`v_i` が `single(a_i)` なら、その全上位子 `z` における偶数余裕署名は同じ `a_i` を作るため、

`beta_{v_i}=(n*(b(z)−b(u))+theta_{sigma−2}(z)+1) mod2`

であり、共通の `z` により二者は一致する。これは任意の二つのsingle型子に適用できる。

よって偶数余裕の上位子値集合に0/1は高々一方しか現れない。single型子が一つもなければ、`R=0` のmexは0、`R>0` の下位子が値 `(R−1) mod2` を持つので `g=R mod2`。single型子があり共通の `beta` を持てば、上位子の唯一の0/1値は `(R+beta) mod2`。`R=0` のmexはその反対、`R>0` の下位子も同じ唯一の0/1値を持つので、`g=(R+beta+1) mod2`。従って `theta_sigma(u)=0`（single型なし）または `beta+1 mod2`（single型あり）と定義でき、偶数余裕の帰納が閉じる。

この二重帰納は全ての余裕に適用でき、定理が証明された。□

## 検証と境界

`verify.py` は上記署名を直接構成する計算と、全w列の合法手を再帰的に列挙する独立mex計算を照合。`3≤w≤8,2≤h<w,1≤m≤6,1≤r<h*m` の **422,953安全局面**で一致。偶数余裕223,332件は全て0/1、奇数余裕199,621件は全て0〜3。`check_kernel.py` は別の既存K0352型の上位核を用い、`1≤h≤7,1≤m≤12,n=1`、三つのrで **337,625上位形**の偶数/奇数余裕上界を確認。どちらも有限検算であり、無界性の根拠は上の数学的証明。

標準2次元共円ゲームの一般盤にこの容量縮約を直接適用することはできない。K0352の幾何学的な一般位置平行列盤（例えばd次元版でq>2w）には移送可能。K0352が残した「h≥4のg≤3は未証明」は、この結果で解消する。
