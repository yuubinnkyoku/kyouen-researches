実験: vertical-fiber-two-token-y2-parametric-allz-proof-20261120

## 記号

O[a,b] は区間内の奇数、E[a,b] は偶数、I[a,∞) は a 以上の全整数、
O_z[a,b] は区間内で z と同じ偶奇の位置とする。2⌈x/2⌉+1 をラダー上端と呼ぶ。

## 定理（值2集合 T_z(x)、值1集合 P_z(x)）

H(R;(x,2);z)=2 ⟺ R∈T_z(x)、=1 ⟺ R∈P_z(x)、それ以外で 0（R=0 は常に 0）。

### 値2位置 T_z(x)（常に奇数位置＋高々1つの孤立pin）

z 奇数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-3 | O[1, 2⌈x/2⌉+1] |
| x=z-2 | O[1, z+2] |
| x∈{z-1, z, z+1} | O[1, z] |
| x=z+2 | O[1,z] ∪ {z+4} |
| x=z+3 | O[1,z] ∪ O[z+4, 2z+5]（掃引行） |
| x>=z+4 | O[1,z] ∪ {z+4} |

z 偶数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-3 | O[1, 2⌈x/2⌉+1] |
| x=z-2 | O[1, z+1] |
| x∈{z-1, z+1, z+2} | O[1, z-1] |
| x=z | O[1,z-1] ∪ {z+3}（前倒し孤立pin） |
| x=z+3 | O[1,z-1] ∪ O[z+5, 2z+5]（掃引行） |
| x>=z+4 | O[1,z-1] ∪ {z+5} |

z=0,1,2 でも例外行は発生しない（判定不能クラスは空になり、同じテンプレート
がそのまま適用される。z=0 では x>=z+4=4 行の pin は {5}、x=3 行は
O[1,-1]∪O[5,5]={5}）。

### 値1位置 P_z(x)

z 奇数のとき:

| 行クラス | P_z(x) |
|---|---|
| x 偶, x<=z-3 | ∅ |
| x 奇, x<=z-3 | I[x+3, ∞) |
| x∈{z-2, z} | {z+1,z+3} ∪ I[z+4, ∞) |
| x=z-1 | {z+1} |
| x=z+1 | {z+1,z+3} |
| x=z+2 | {z+1,z+3} ∪ I[z+5, ∞) |
| x=z+3 | {z+1,z+3} |
| x>=z+4 奇 | {z+1,z+3} ∪ O[z+6, x+z+3] ∪ I[x+z+4, ∞) |
| x>=z+4 偶 | {z+1,z+3} ∪ O[z+6, x+z+2]（有限） |

z 偶数のとき:

| 行クラス | P_z(x) |
|---|---|
| x 偶, x<=z-2 | ∅ |
| x 奇, x<=z-3 | I[x+3, ∞) |
| x∈{z-1, z+1} | {z+1,z+3} ∪ I[z+4, ∞) |
| x=z | {z+1} |
| x=z+2 | {z+1,z+3} |
| x>=z+3 奇 | {z+1,z+3} ∪ O_z[z+6, x+z+3] ∪ I[x+z+4, ∞) |
| x>=z+3 偶 | {z+1,z+3} ∪ O_z[z+6, x+z+2]（有限） |

中間帯の偶奇は常に z に追従する（O_z）。値1の無限帯 I[.., ∞) は tail 値が
1 になる奇数 x 行にだけ現れ、tail 主張（下記）と一致する。
T∩P=∅ は全点で成立（検証器が全照合点で assert）。

### tail

全 z>=0・x>=2 で R >= x+z+3 のとき H(R;(x,2);z) = (x+2) mod 2。

## 選択肢分解と x=2 での合流

R>=1 のとき、トークン減少は一方のトークンだけを 1 減らす操作で

- A = H(R-1; (x-1,2); z)（x>=3）
- B = H(R-1; (x,1); z)
- C = 1 ⊕ H(R-1; (x,2); z-1)（z>=1）

であり H(R;(x,2);z)=mex{A,B,C}（z=0 では C なし）。x=2 では
(2,2) の 2 つの減少手が同一の多重集合 (1,2)≡(2,1) 子に合流し
A≡B = H(R-1;(2,1);z)、すなわち K1023 の z 行 x=2 閉形式になる。
B は常に K1023 の全称閉形式 cand_y1(z,x,R-1)（z=0 は cand0）で評価する。

## 証明構成（K1023 と同型の機械化）

1. **選択肢分解の健全性**: A/B/C の列挙が素再帰と一致することを、raw エンジン
   （順序保持・降順正準化の二重再帰、出版済みセンサス機械と同一コード）の
   選択肢値集合との一致で錨止めする（検証 C3）。カーネルの B・x=2 の A も
   raw 照合で錨止め（C1b）。
2. **恒等式**: cand2 は上表そのものであり、恒等式
   cand2(z,x,R) = mex{A,B,C}（子は閉形式で評価）が R に関する帰納の本体。
   有限グリッド（C2: z=0..48・x=2..56・R<=x+z+40、C2b: z<=400、C12:
   z=0..120・x=2..120・R<=x+z+16 の全点、他）で直接照合する。
3. **型機械**: 型 = (x==2 ビット, z==0 ビット, z%2, x%2, R%2, 6差分族
   w0=x-z, w1=R-x, w2=R-z, w3=R-x-z, w4=R-2x, w5=R-2z の ±8 旧窓・±9 番兵
   クリップ)。自由座標 v0=x-z, v1=R-x, v3=R-x-z のボックス ±60 を掃引して
   実現型 11,090 個を完全列挙し、各型で (値, 子値列) の効果ベクトルが
   型内で一定（confluence）・証人で恒等式成立を機械検証する。ボックス外の
   型は新規型として現れないことを、v 空間シェル掃引 [61,64]∪[89,92]∪[117,120]
   （938,934 点）、境界多様体 z∈{0..5,29..31,59..61,299..301,999..1001,2999,3000}
   （394,085 点）、seed 付き遠方 probe 20万点（z,x<=3000, R<=9000）、
   深グリッド掃引 197万点で確認した（いずれも新規型 0・confluence 不一致 0）。
4. **出版切片の逐語アンカー**: 既出版の z=16（K1042 census）と z=17（K1044
   census）の candidate_T/candidate_P を機械に逐語転写し、cand2 と
   5,292 点ずつ全一致（C1d）。その他の z は census（下記）が z=0..80 の
   生二重再帰で直接照合する。

## 値の構造（既出版切片の記述の一般化）

- **値1基底点 {z+1,z+3}**: y=2 の値1基底点の y 点仮説 {z+1,z+3} は
  本定理により全 z>=0 で確定する（x=z-1 行と x=z 行では {z+1} のみに変形。
  これは z=12..21 の10連続観測（K1054）の全 z 拡張である）。
- **pin の偶奇分離**: 奇数 z では格子pin 2y+z が x=z+2 行に現れ、
  x=z-2 行の連続上端 2y+(d+z)/2 = z+2 とともに d+z≡2 (mod 4) 側に合流する。
  偶数 z では x=z-2 行上端 q_odd(2y+(d+z)/2)=z+1（孤立）、x=z 行前倒しpin
  2y+z-1=z+3、定常pin 2y+z+1=z+5 の3点が分離する（K1042/K1051/K1053 の
  記述の全 z 確定）。
- **掃引行** x=z+y+1=z+3: 帯は奇数 z で O[2y+z, x+y+z=2z+5]、偶数 z で
  O[2y+z+1, 2z+5]。
- **tail 境界 x+2y-1**: y=2 では x+z+3=x+2y-1 が tail 開始で、値は
  (x+2) mod 2（K0832 の一般 tail と整合）。
- **ラダー上端 2⌈x/2⌉+1**: x<=z-3 行の値2位置は z に依存しない。

## 信頼境界

- 全称性の根拠は、(i) 選択肢分解がゲーム定義そのものであること（raw錨）、
  (ii) 恒等式が正確な mex 再帰であること（有限完全グリッド＋型ごと照合）、
  (iii) 実現型空間が有限でボックス内に証人を持つこと（完全列挙＋シェル・
  多様体・遠方probe・深掃引の新規型ゼロ）、の3点であり、K1023 と同じ
  trust 境界に立つ。Lean 形式化ではなく、証人境界補題の証明テキストではなく
  機械掃引で裏付ける点も K1023 と同一基準である。
- 有限監査は転写・実装照合であり、それ自体が全称性の根拠ではない。
- H の定義（Theorem T・単一トークン閉形式）は K0832 に、B 子の評価は
  K1023 に依存する。K1023 が成立する限りで本項は成立する。
- 本項は y=2 のみを証明する。y=3 族（並走レーンが z=19,y=3 を宣言済み）
  、y>=3 のパラメトリック機械化、固定幅・q点版安定化長、11×11 は範囲外。
