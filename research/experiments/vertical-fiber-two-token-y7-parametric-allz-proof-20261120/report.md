## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数。q_odd(k) は k を奇数に切り下げた値（k 奇なら k、
k 偶なら k-1）。d = x - z、S = x + 7 と書く。y=7 は奇数 y で、S=x+7 の偶奇は
x と逆（x 奇なら S 偶・x 偶なら S 奇）。マージ行のラダー上端
q_odd(S) は x 奇なら x+6・x 偶なら x+7 になる（偶数 y の y=2,4,6 と逆の
寄り方で y=1,3,5 型に戻る）。値1の無限帯と tail も奇数 y 型で、
**x 偶の行**に出る（両 z 偶奇で共通・z にはよらない）。

## 選択肢分解と x=7 での合流

R>=1 のとき

- A = H(R-1; (x-1,7); z)（x>=8；x=7 では 2 つの減少手が同一多重集合
  (6,7)≡(7,6) 子に合流し A≡B = H(R-1;(6,7);z) = cand6(z,7,R-1)、
  すなわち K1127 の z 行 x=7 閉形式。H は多重集合にしか依存しない）
- B = H(R-1; (x,6); z) = cand6(z, x, R-1)（K1127 全称閉形式・逐語転写）
- C = 1 ⊕ H(R-1; (x,7); z-1)（z>=1）

であり H(R;(x,7);z)=mex{A,B,C}（z=0 では C なし）。

## 値の構造（y=2..7 の横断観察・一般称主張ではない）

- **値1基底点 y 点仮説の y=7 確定**: 基底点は y 個 {z+1, z+3, ..., z+2y-1}
  が y=1..7 の全称表で確定（y=7 は本項で 7 点 {z+1,..,z+13}・連続 7 例）。
  y>=8 は予想。
- **tail 開始族式 x+z+y+1 の y=2..7 確定**: 6 族連続の全称確定。tail 値
  (x+y) mod 2 も 6 族連続（y 奇で値1無限帯が偶数 x 行・y 偶で奇数 x 行。
  マージ行の値1無限帯も同じ S=x+y 偶奇に従い、y=7 では x 偶の行に出る）。
- **マージ行の境界 x<=z-y-1**: y=1..7 の 7 族で確定（y=7: x<=z-8）。
  マージ命題（K1101）は y=1..7 で全称確定。
- **掃引行 x=z+y+1 と帯 O[2y+z, 2z+2y+1]（奇z）/O[2y+z+1, 2z+2y+1]（偶z）**:
  y=2..7 共通の族式（y=7: O[z+14, 2z+15]/O[z+15, 2z+15]）。
- **中間帯（値1）**: O_z[2y+z+2, x+z+y]（y=7: O_z[z+16, x+z+7]）。
  族式は y=3..7 の 5 族連続。
- **定常 pin 2y+z（奇z）/2y+z+1（偶z）**: y=2..7 共通（y=7: {z+14}/{z+15}）。
- **前倒し pin の格子構造**: pin 行 x では (x-y)+z ≡ 2 (mod 4) が成り立ち、
  pin 値は格子公式 pin = 2y + ((x-y)+z)/2 で与えられる。y=7 では奇z の
  pin 行 d∈{-5,-1,3,7}（pin z+8, z+10, z+12, z+14）・偶z の pin 行
  d∈{-3,1,5}（pin z+9, z+11, z+13）。pin 行の d は d ≡ y (mod 4)（奇z）・
  d ≡ y+2 (mod 4)（偶z）に乗る（y=7 は奇z d≡3・偶z d≡1）。**格子公式は
  y=5,6,7 の 3 族で統一**（y<=6 知見の y=7 延長確認。一般証明は今後の課題）。
- **対角行 S=z（x=z-y）の連続上端の格子規則 r = z+y - [2(z-y)≡0 (mod 4)]**:
  y=7 の行（奇z 上端 z+6・偶z 上端 z+7）まで y=2..7 の全称表の全 z で一致
  （z-y の偶奇で上端が 1 つ下がる格子・y>=8 は予想）。
- **型機械の clip 窓**: 必要 clip 半径の族式候補 2y+2 が y=5:12, y=6:14,
