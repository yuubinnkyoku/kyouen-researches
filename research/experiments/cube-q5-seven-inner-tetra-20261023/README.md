# 7立方の内側正四面体4石N・中心追加後の5石P

点番号49x+7y+z。内側正四面体 `I={114,130,214,226}` はNで、171（中心）へ置くとP。
座標は `(2,2,2),(2,4,4),(4,2,4),(4,4,2)`。
五石Pの全証明169,941局面と、それにN根を加えた四石証明169,942局面を、別実装の
Bareiss検査器でそれぞれ独立検査した。全証明の最大石数は15。

| 根 | 勝敗 | 局面数 | 辺数 | 終端数 | 独立行列式数 |
| --- | --- | ---: | ---: | ---: | ---: |
| I∪{171} | P | 169941 | 219305 | 46050 | 113550903 |
| I | N | 169942 | 219306 | 46050 | 113550799 |

`../cube-q5-seven-tetra-20261023/` の大きさ2（座標1/5）の正四面体はPだったが、
大きさ1（座標2/4）はN。この違いは同じ7立方上で初期局面の勝敗が変わることを示す。
非終端四石を一律にPと見なすことはできない。

もう一つの独立N四石は `../cube-q5-seven-central-line-20261023/` の
`{24,169,171,173}`。157着手後の正規形五石 `{73,150,169,171,173}` はPである。
二つのP五石からは、その全四石親も残りの1点を置けばNとなる。
この1手の帰結と、全証明書を直接独立検査した根を分けて扱う。

五石の追加探索は333,352展開で閉じた。`five-p.cert.gz` は全証明書。
四石証明は同じ部分木に1行を加えるため、重複収録せず `derive_four.py` から生成する。
両者とも独立検査済み。これらから三石・二石・空盤の勝敗は決まらない。

```sh
gzip -dc research/experiments/cube-q5-seven-inner-tetra-20261023/five-p.cert.gz > /tmp/inner-five.cert
/tmp/q7-verify-incremental /tmp/inner-five.cert
python research/experiments/cube-q5-seven-inner-tetra-20261023/derive_four.py /tmp/inner-four.cert
/tmp/q7-verify-incremental /tmp/inner-four.cert
```
