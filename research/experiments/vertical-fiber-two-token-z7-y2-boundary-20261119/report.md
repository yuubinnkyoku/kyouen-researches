## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,2)（x≥2）における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる; x=2 を除く）: 子 = H(R−1;(x−1,2);7)。x=3 では子は (2,2) で同じ y=2 ファミリーに属する
- **B手**（トークン 2 を 1 へ減ずる）: 子 = H(R−1;(x,1);7)
- **C手**（z を 7→6 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,2);6)

x=2 では X=(2,2) で2本の減少手（各トークン 2→1）が同一の子 (1,2) に合流し、選択肢は {H(R−1;(1,2);7), 1⊕H(R−1;(2,2);6)} の2つにdedupされる。

子の値はそれぞれ既知の公式で閉じる: A子は y=2 ファミリーのスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K0977 の z=7・y=1 全称定理、C子は K0878 の z=6・y=2 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** 本証明で使う既証明の公式。r=R−1 と書く:

- B子（K0977）: c(x,r)=H(r;(x,1);7)。T₇⁽¹⁾ は x≥8・x≠9 で {1,3,5,7,9}、x=9 で O[1,17]。P₇⁽¹⁾(x) は x≥11奇数で {8}∪O[11,x+8]、x≥10偶数で {8}∪O[11,x+9]∪I[x+10,∞)。
- C子（K0878）: h(x,r)=H(r;(x,2);6)。T₆⁽²⁾ は x≥10 で {1,3,5,11}。P₆⁽²⁾(x) は x≥10偶数で {7,9}∪E[12,x+8]、x≥11奇数で {7,9}∪E[12,x+7]∪I[x+9,∞)。1⊕h は h∈{0,1,2} を {1,0,3} に写す。
- A子: 帰納仮定（スライス x−1 の主定理そのもの）。

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は z=6・y=2（K0878）の {1,3,5,11} に対し z=7 では **{1,3,5,7,11}**。zを6→7へ上げると 7 が加わる。一方 z=7・y=1（K0977）の {1,3,5,7,9} と比べると 9 と 11 が入れ替わっており、2番トークン y が 1→2 になると定常Tの最大元が +2 される。
- x=10 例外 T₁₀={1,3,5,7,11}∪O[13,19] の機構: A子スライス9の P₉={8,10}∪I[12,∞) は無限帯（x=9が奇数行でI帯を持つ）。r 偶数∈{10}∪E[12,18] では A=1（r∈P₉）かつ B=0（c(x=10,r) の偶数r∈E[10,18] は P₇⁽¹⁾(10)={8}∪O[11,19]∪I[20,∞) 外）で V に 0 と 1 が揃い値2が続く。r=8 では B=1 で V={1} となり帯の直前で切れ、r≥20 では B=1（I[20,∞)）で再び V={1} となり帯が止まる。ちょうど R=r+1∈{11}∪O[13,19] が T₁₀ の伸長分となる。x≥12 偶数では A子スライスが奇数となり P_A の無限帯は I[x+9,∞) に後退、B子の I[x+10,∞) とすれ違うため r 偶数で A=1∧B=0 となる領域が消え、この伸長が起きない。
- x=11 行の E[14,20]:12 署名の由来: A子はスライス10で、その特異T帯 O[13,19] により r 奇数∈O[13,19] で A=2 を供給する。V={A=2, B=1, C=1}={1,2} で mex は 0 と、定常奇数行の署名 1 と同じ値になる。y=2 特異帯は T の値に現れるだけでなく、1段上の行の署名にも痕跡を残す。
- 値1位置の構造は y=1（K0977）の {8}∪O[11,..] 型に対し y=2 では {8,10}∪O[13,..] 型と全体に +1 シフトし、低R域の値1位置が8に加えて10も持つ（トークン2→1の B手が R=10 子で P₇⁽¹⁾の8に届くため）。P の O 帯上端 x+9 は y=1 と同じく親のxで決まり、y に依存しない。
- x=3..9 の各行は R≤8 の高さのみ縮約域 + tail でしかなく、x∈{5,7,9} の I[10,∞)/I[12,∞) 全体値1型は y=1 の x∈{2,4,6} のときと同じ平坦化（残余手数が大きいと構造が偶奇のみになる）である。

## 適用範囲と限界

- 本定理は **z=7・y=2 の境界切片のみ**。z=7 の y=3 は未証明であり、K0976 の y≥4 有限予想と併せても z=7 全高さの統一は未解決。
- z≥8・y≥1 の全Grundy閉形式は未解決。
- 有限監査（V1..V9）は検証手段であり、定理の主張は上記 Step 1..5 の帰納構成による。監査は帯表の転写ミス・実装バグの検出を目的とする。
- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
