## 命題候補（observed・有限範囲で確定・全称は未証明）

すべての z>=0・x>=16・R>=0 に対して H(R;(x,16);z) = cand16(z,x,R)（候補・有限検証のみ）。cand16 は以下の z 偶奇別 T/P 集合表
（`cand16.py` が正本・Y=16・b_k = 奇 offset {1,3,...,2k-1}・offset o = R-z・d = x-z）。

### 値1集合 in_P16（probe 全点で mismatch 0・Tとの重複 0）

    k(d) = floor((d+50)/4) = floor((d+3y+2)/4)（= 8,9,9,10,10,11,11,12,12,13,13,14,14,15,15,16,16・偶数 y 族式 3 族目）・

    （**17 行掃引の初例**・y=12 の 13..27〔15行〕・y=14 の 15..29〔15行〕に続く偶数 y 族掃引 3 族目）。

    skew 行（d≡2 mod 4・8 行）では slot (d+48)/2 = 2k-1 が b_k 上端点（値1）と一致し th=2k。
    この th-1 スロット交替構造が T/P 重複 0 を実現する（y=12/14 と同型）。
  - base 行 d ∈ {-15,-13,...,15}（d 奇 16 行）: P = b_k(d) のみ。k = floor((d+49)/4) = floor((d+3y+1)/4)

    **偶y族の単一 band 則**（base/I 両型共通・y=15 奇y族の band_base/band_int 分離と対照）。
- 偶z 行別構造（d 奇 = x 奇行は I 型、d 偶 = x 偶行は base。base k は奇z と同一式 floor((d+49)/4)）:
  - d=-16（対角）: 値1なし（偶z 対角行は R<=z+15 の奇数列を値2で占有し z+16 以降は全て値0。

    pin はすべて偶z base 行（偶 d）側にあるため I 帯開始との衝突は存在しない（y=12/14 と同型）。
  - base 行 d ∈ {-14,-12,...,16}（d 偶 16 行）: P = b_k のみ。k = floor((d+49)/4)

### 初稿一発一致の記録（fitting 反復なし）

y=12 fit が初稿 240 点不一致を要したのと対照的に、y=16 は初稿から probe 74,741 点・box 外 spot 35,825 点・全回帰で修正 0 だった。
初稿は y=14 の**出版最終構造**（cand14・全称昇格済み）を seed とする Y+2 機械翻訳であり、
宣言で事前登録したとおりコード本体は Y 定数・関数名・y 固有コメント以外は正本 cand14 と同一構造
（Y 正規化差分比較で確認）。これにより
「直前の出版最終構造 seed による外挿が一発一致する」法則が **cand11→cand13・cand12→cand14・cand13→cand15・cand14→cand16 と
4 連続**（奇数 y 3 連・偶数 y 3 連）で成立し、y>=17 族の fit & 全称計画における 初稿リスクがほぼ消滅した。
y=12 で学習された族式（z-odd I 行 k=floor((d+3y+2)/4)・th 連続整数掃引・偶z I 行 k=floor((d+3y-1)/4)・
base 行 k=floor((d+3y+1)/4)・pin 格子統一式・pin mod 4 クラスの y (mod 4) 回転）は独立の第3偶数族で再確認された。

### マージ系（対角線下・y=16 の回帰）

y=16 では probe box 内にマージ行が存在しないため（x<=z-17 は z>=33 を要求）、
マージ命題（一般形 x<=z-(y+1)）の y=16 版は全面 box 外で検証した:
deep 行 (33,16)（z 奇）・(34,17)（z 偶）の生エンジン R<=130 全点照合と、

（z∈{33,40,47,54,64,77}・x=16..z-17・R<=x+z+33）がともに不一致 0。
マージ命題は y=1..15 全称確定に続き、y=16 で fitting レベル 16 族目として回帰した。
