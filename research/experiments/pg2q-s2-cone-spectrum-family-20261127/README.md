## 手法

K1359 と同一: 非共線3点 F を含む全アーク（PG(2,8): 8,450 / PG(2,11): 708,761 局面）を
visited-set DFS で完全列挙し mex DP、PGL(3,q) の非共線3点推移性により
`N_m(g) = N_3·T_m(g)/C(m,3)`。空盤の Grundy は k≤2 の一様鎖。

## 検証（`verify_pg2_general.py`・gate 6 + tamper 5・fail-closed）

- G1 盤: 二重構築一致・ライン形状・2直線交わり1点・GF の全分配律スイープ。
- G2 決定性: 3 走の canonical JSON sha256 同一。さらに**環境リセットを跨いだ
  再現**も確認（q=8/9/11 とも、最初の実行環境がタイムアウトで喪失した後の
  再構築で全数値 bit-exact 再現）。
- G3 推移性の運用検証: 異なる 3 つの F（PG(2,8): 錐 8,450×3 / PG(2,9): 31,681×3 /
  PG(2,11): 708,761×3）で T 表が完全一致。
- G4 アンカー: q=8 出版国勢調査（総数・極大個数・パリティ則 G=m mod 2）・
  q=9 出版 5 アンカー（K1359 と同じく PASS）・q=11 古典円錐曲線数 160,930 +
  軌道安定化群恒等式。
- G5 子/mex: 300 局面サンプルを別実装安全性判定で再計算し全一致。
- G6 整除性: 全 (m,g) セルで N_3·T ≡ 0 (mod C(m,3))。
- tamper T1..T5（総数/セル/盤/mex/完全アークの破壊）5/5 検出。

## 正直な開示

- q=11 は単一実装で総数の出版アンカーが存在しない。外部妥当性は
  (a) 円錐曲線の古典個数 160,930 との一致、(b) 3 軌道安定化群恒等式、
  (c) F 不変性、(d) q≤9 での較正・アンカー一致が担う。
  総数 5,989,752,243 自身は本計算の導出値（独立確認を次回課題とする）。
- 実行環境が q=11 検証バッテリー実行中に一度リセットした（300s cap 超過）。
  全成果は出版済み GitHub から再取得して bit-exact 再現したうえで検証を再実行。
- 8-アーク 645,248,835 の軌道分解（何軌道か）は未実施。
