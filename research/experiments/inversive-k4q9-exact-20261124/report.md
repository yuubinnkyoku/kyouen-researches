# 反転平面の s-弧上界: 第2乗数族による改善と 3-モーメント法の厳密最適性

実験ディレクトリ: `research/experiments/inversive-k4q9-exact-20261124/`（2026-11-24）

## 0. 要旨

K1291 は 3 本のモーメント等式と 3 次乗数
`P1_s(r) = −(r−(s−3))(r−(s−2))(r−s)` から
`K_s(q) ≤ (s−2)q`（`5 ≤ s ≤ q−1`, `q ≥ 9`）を証明した。
本実験は、同じ 3 モーメント等式に対して **別の 3 次乗数**

```
P2_s(r) = −(r−(s−4))(r−(s−3))(r−s)
```

を使うと `q ≥ 11`・`s ≥ 6` で **厳密に強い上界**が出ることを示す。

1. **定理 1（明示的上界）**: `5 ≤ s ≤ q−1`, `q ≥ 9` で
   `K_s(q) ≤ min( (s−2)q , n₂(s,q) )`。
   ここで `n₂(s,q) = max{n : Y_{P2}(n,q) ≥ 0}`、`Y_{P2}` は下の (1)。
2. **系 1（漸近）**: `limsup_{q→∞} K_s(q)/q ≤ s − 2 − d*(s)`。
   `d*(s) ∈ (0,1)` は `d³ − 4d² + (3s−8)d − (2s−8) = 0` の唯一の根で、
   `s → ∞` で `d*(s) → 2/3`。すなわち K1291 の漸近定数 `s−2` は
   **2/3 だけ改善**できる。
3. **方法の限界（有限範囲の厳密計算）**: 3-モーメント緩和の LP 最適値は、
   検査した格子（`q ∈ {9,11,13,16,17,19,25}`, `4 ≤ s ≤ 9`）で
   `min(P1 の上界, P2 の上界)` に一致した。したがって K1291 の定理 A
   （`s=4` の `2q+1`）はこの方法では **これ以上改善できない**。
   例外は `(q,s) = (19,9), (25,8), (25,9)` で、そこでは第 3 の乗数が
   さらに強い（表 3）。これは `min(P1,P2)` が常に LP 最適とは限らないことを
   正直に記録するものである。
4. **数値改善**: `K_9(25) ≤ 161`（旧 175）、`K_8(19) ≤ 105`（旧 114）、
   `K_7(19) ≤ 87`（旧 95）など（表 2）。

`s = 4` は K1291 の `2q+1` がすでに LP 最適で、本手法では改善しない。

## 1. 設定

`M(q)`: 位数 `q`（素数冪）の Miquelian 反転平面。点 `q²+1`、円 `q+1` 点、
円の総数 `q(q²+1)`、各点対はちょうど `q+1` 円に載り、各 3 点は一意な円に載る
（`3-(q²+1, q+1, 1)` 設計、`λ₂ = q+1`）。各点は `q(q+1)` 円に載る。

`s`-弧: すべての円 `C` に対し `|S ∩ C| ≤ s` を満たす点集合 `S`。
`K_s(q)` はその最大サイズ。`s = 3` が従来の「弧」（K1250–K1252）。

`s`-弧 `S`（`|S| = n`）に対し `t_r = #{C : |S∩C| = r}` とおくと
`t_r = 0 (r > s)`、`t_r ≥ 0` で、次の 4 本が成り立つ（K1274/K1291）:

```
(M1) Σ t_r            = q(q²+1)
(M2) Σ r t_r          = n q(q+1)
(M3) Σ C(r,2) t_r     = C(n,2)(q+1)
(M4) Σ C(r,3) t_r     = C(n,3)
```

`(M2)` の `q` 因子（各点が `q(q+1)` 円に載る）を落とすと後述の通り破綻する。

## 2. 主定理

**補題 1.** `P(r) = a₀ + a₁r + a₂C(r,2) + a₃C(r,3)` が整数 `r = 0..s` で
`P(r) ≥ 0` なら、`s`-弧 `S`（`|S| = n`）に対して

```
(1)  Y_P(n,q) := a₀ q(q²+1) + a₁ n q(q+1) + a₂ C(n,2)(q+1) + a₃ C(n,3)
              = Σ_r P(r) t_r  ≥  0.
```

証明: `Y_P = Σ_{r=0..s} P(r) t_r`（`(M1)`–`(M4)` の線形結合）で、
`P(r) ≥ 0`, `t_r ≥ 0` より非負。□

**補題 2.** `P2_s(r) = −(r−(s−4))(r−(s−3))(r−s)` は整数 `r = 0..s` で
`P2_s(r) ≥ 0`。モーメント基底では

```
(a₀, a₁, a₂, a₃) = ( s(s−3)(s−4),  −(3s²−17s+20),  6s−20,  −6 ).
```

証明: 根は `s−4 < s−3 < s`。`r ≤ s−5` で 3 因子すべて負（積が負、符号反転で正）、
`s−4` と `s−3` で 0、`r = s−2, s−1` では 2 因子が正・1 因子が負で積が負（よって正）、
`r = s` で 0。`s−4` と `s−3` が連続整数なので、その間の整数は存在しない。
展開は `r³ = 6C(r,3)+3r²−2r`, `r² = 2C(r,2)+r` による。□

**定理 1.** `5 ≤ s ≤ q−1`, `q ≥ 9` のとき

```
K_s(q) ≤ min( (s−2)q ,  n₂(s,q) ),    n₂(s,q) := max{ n ≤ q²+1 : Y_{P2}(n,q) ≥ 0 }.
```

証明: `Y_{P2}` は `n` の 3 次式で最高次係数 `−1`（`a₃C(n,3) = −n³+3n²−2n`）。
よって十分大きい `n` では `Y_{P2} < 0` となり、補題 1 に反する。
本実験では各 `(s,q)` について `Y_{P2}(n₂+1,q) < 0` と
`n > n₂+1` での単調減少（`n ≥ (3 + (q+1)(3s−10))/3` で `dY/dn < 0`）を
厳密整数で確認している。第 2 項 `(s−2)q` は K1291 の定理 B。□

## 3. 漸近系

`n = cq` を固定して `q → ∞` とすると

```
Y_{P2}(cq, q) / q³  →  f(c) := −c³ + (3s−10)c² − (3s²−17s+20)c + s(s−3)(s−4).
```

`c = s−2−d` を代入すると（3 次式なので展開は厳密）

```
f(s−2−d) = (8−2s) + (3s−8)d − 4d² + d³.
```

`h(d) = d³ − 4d² + (3s−8)d − (2s−8)` は `h(0) = −(2s−8) < 0`,
`h(1) = s−3 > 0`, `h'(d) = 3d²−8d+(3s−8) ≥ 3s−13 > 0`（`0 ≤ d ≤ 1`, `s ≥ 5`）
なので `(0,1)` に唯一の根 `d*(s)` をもつ。`f(0) > 0`, `f(c*) = 0`,
`c > s−2` では `f < 0` なので `f < 0` が `c ≥ c*(s) := s−2−d*(s)` で成り立つ。

**系 1.** 任意の `c > c*(s)` について、十分大きい `q` で `K_s(q) < cq`。
とくに `limsup K_s(q)/q ≤ s − 2 − d*(s)`。

数値: `d*(5) ≈ 0.35`, `d*(6) ≈ 0.43`, `d*(7) ≈ 0.49`, `d*(8) ≈ 0.54`,
`d*(9) ≈ 0.59`, であり `d*(s) → 2/3`（`d* ≈ (2s−8)/(3s−8)`）。
したがって K1291 の漸近定数 `s−2` は **最大 `2/3` 改善**される。
実測 `K_9(25) = 161`（`161/25 = 6.44`）は `c*(9) ≈ 6.41` と整合する。

## 5. 3-モーメント法の厳密最適性（表 3）

`moment_lp.py` は緩和 `{t ≥ 0 : (M1)–(M4)}` の実行可能性を
**有理数で厳密に**判定する（`A` は階数 4 なので Carathéodory により
4 列部分集合の列挙で十分）。`n` を上から下げて最初に実行可能になる `n` が
この方法の最適上界である。

| q | s | LP 最適 | `min(P1,P2)` | 一致 |
|---:|---:|---:|---:|:--:|
| 7,8,9,11,13,16,17,19,25 | 4 | `2q+1` | `2q+1` | ✓ |
| 9 | 5–8 | 27,36,45,54 | 同値 | ✓ |
| 11 | 5–8 | 33,43,53,64 | 同値 | ✓ |
| 13 | 5–8 | 39,49,61,73 | 同値 | ✓ |
| 16 | 5–8 | 46,59,74,89 | 同値 | ✓ |
| 17 | 5–9 | 49,63,78,94,111 | 同値 | ✓ |
| 19 | 5–8 | 54,70,87,105 | 同値 | ✓ |
| 19 | 9 | **122** | 123 | ✗（第 3 乗数が強い） |
| 25 | 5–7 | 70,91,113 | 同値 | ✓ |
| 25 | 8 | **135** | 137 | ✗ |
| 25 | 9 | **157** | 161 | ✗ |

読み方:

- `s = 4` では LP 最適値がちょうど `2q+1`（`q ≥ 7`）。K1291 の定理 A は
  **この方法の限界に到達している**。`K_4(7)=13`, `K_4(8)=14` との差
  （15,17 対 13,14）は、モーメントでは埋められない（整数性・幾何が必要）。
- `s ≥ 5` では `P1` が `q = 9` で最適、`P2` が `q ≥ 11` で最適という構造。
- `q ≥ 19`, `s ≥ 8` では `P1`/`P2` の外側に第 3 の乗数が存在する。
  `(25,9)` の LP 最適 157 は `161` より 4 小さい。この第 3 乗数の閉形式は未同定。

## 6. 検証

- **恒等式の実盤面照合**（`output/identity_checks.json`）: 貪欲に構成した実 `s`-弧
  （`q=9,11,13,16`; `s=3..9`）で `Σ_r P1(r) t_r = Y_{P1}` と
  `Σ_r P2(r) t_r = Y_{P2}` が厳密に一致（8 例すべて `true`）。
  これが (1) の実データ側の確認。
- **非負性**（`output/moment_p2.json`, `moment_p2_large.json`）:
  `P2_s(r) ≥ 0`（`r = 0..s`）を `s = 4..9` で全数確認。
- **上界の証明部分**（同）: 各 `(s,q)` で `Y_{P2}(n₂+1,q) < 0` を厳密整数で確認
  （例: `s=6,q=16` で `Y(59)=1122 ≥ 0`, `Y(60)=−168 < 0`）。
- **K1291 の再現**: 同じ計算で `P1` の上界が `(s−2)q` に一致（`s=5..9`）。
- **LP 最適性**: 表 3。`moment_certificate.py` は各 `(s,q)` について
  明示的な乗数（`Fraction` 係数）を出力し、`P ≥ 0` と `Y = −1` を
  独立に再検査する（`output/moment_certificates.json`, 全件 `certificate_ok`）。
- **盤面の独立構成**: `build_board.py` は出版済み `inversive_fast.build_circles`
  から円族を作り、`3-(q²+1,q+1,1)` の全パラメータ（点対重複 `q+1`、三重点重複 1）を
  再検査する。`q=9` の盤面は spectrum 実験の `board_q9.json` と
  **集合として完全一致**（738 円、点 82）。
- すべての算術は `int`/`Fraction`。浮動小数は使っていない。
- 本実験で **確立した** のは定理 1・系 1 と LP 最適値の格子（K1295/K1296）だけである。
  `K_4(9)` は確立していない（下節）。

## 7. `K_4(9)` の現状（本実験の副産物、未確定）

K1291 の上界 `K_4(9) ≤ 19` と K1275 の下界 `≥ 16` の間は未確定である。
本実験では以下を試した（**確定には至っていない**）。

- 反復貪欲＋強制挿入の局所探索（`local_search.py`）: `k = 16` は数秒で発見、
  `k = 17,18,19` は 90–300 秒の複数シードで到達できず（最良 16）。
- SAT（`sat_arc.py`、`cadical195`、円ごとの 5-部分集合禁止 + 基数 `≥ n` +
  3 点対称性破り）: `n = 17` は 3 回起動したが **判定に至らなかった**。
  (i) 自前 board に `∞,0,1` の添字が無く即時 `KeyError`（無効な試行）、
  (ii) 共有 board で長時間稼働、判定なしのまま手動停止（35 分程度）、
  (iii) 添字を追加して再実行、20 分超で判定なしのまま環境の再起動でプロセス消失。
  `pysat` の `interrupt()` による時間制限は本環境で効かず、`TIMEOUT` の
  記録も残せていない（`output/sat_q9_s4_n17_cadical.log` は空）。
  したがって UNSAT の証拠は無く、上限側の進展はゼロである。
- したがって `K_4(9) ∈ [16,19]` は据え置き。決定には
  円ごとの基数制約の compact 符号化・最大性制約・被覆 ILP のいずれかが必要。

## 8. 限界・未解決

- 定理 1 の `n₂` は明示的な閉形式ではない（`(s,q)` ごとの整数計算）。
  系 1 は漸近形で、`O(1)` の下端は与えない。
- `min(P1,P2)` は LP 最適と常に一致するわけではない（表 3 の 3 例外）。
  第 3 乗数の族と、`q ≥ 19` での最適値の公式は未解決。
- `s = 4` は改善しない（LP 最適が `2q+1`）。
- `2 ≤ s ≤ 4`、`q < 9`、`s = q` 行は対象外。非 Miquelian 盤（K1254）でも
  モーメント等式の係数 `λ₂` が変わるため別計算が要る。
- 漸近系は `q → ∞` の主張で、有限 `q` の最良上界は定理 1 の方が強い。

## 10. 正直記録（この回の落とし穴）

- モーメント等式 `(M2)` を最初 `n(q+1)` と書いてしまい、全 `(s,q)` で
  「実行不能」という誤った結果が出た。実 `s`-弧の `t_r` 分布で照合して発見
  （各点は `q(q+1)` 円に載るので `nq(q+1)` が正しい）。以後、恒等式の
  実盤面照合を検証手順に組み込んだ。
- LP の頂点計算で行列を転置して組み、`(q,s)=(9,16)` で矛盾（下界 16 が
  実行不能）が出て発覚。`solve_exact` の単体テストを追加して修正。
- 3 次式の Taylor 展開で `d³` の符号を落とし、`f(s−3) = s−3` と
  合わないことに気づいて修正（`f(s−2−d) = (8−2s) + (3s−8)d − 4d² + d³`）。
- 当初の penalty 型 SA は `k=16` すら 20 秒で届かず（penalty 6 で停滞）。
  反復貪欲＋強制挿入に置き換えたら即座に 16 に到達した。
- `sat_arc.py` は最初、自前 board に `special`（`∞,0,1` の添字）が無く
  `KeyError` で落ちた。`build_board.py` に追加して解消。
- 作業ツリーには他レーン由来の大量の削除が存在する。本実験のコミットは
  自分のパスのみを明示的に `git add` しており、削除には触れていない。
  知識チェックは他レーンの欠損のため全体では通らない。
