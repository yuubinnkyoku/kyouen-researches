# λ=0列盤の終局サイズ：盤の選び方を含む完全相図

2026-10-24。現在の結論の正本はK0536、全称証明は[proof.md](proof.md)。
相異なるw≥3本の鉛直列に、各列**ちょうどm≥2点**の候補を自由に選ぶ。
四点の `det[x²,x,y,1]=0` を禁止する通常プレイを扱う。

この盤の族のどれかでr石の極大安全集合を実現できる必要十分条件は

`r∈({3} if m≥3) ∪ {r:4≤r≤w, m≤(r−2)(r−3)(r+2)/6} ∪ {w+1}`。

これは**存在を盤全体に量化した**分類であり、一つの固定盤に全サイズが現れるという意味ではない。
各可能サイズを、各列ちょうどm個の整数高さで実現できる。
一列三石を除いた最小の終局サイズは、`h(m)=min{r≥4:B_r≥m}` として `min(w+1,h(m))`。
幅が十分ならmの三乗根のオーダーになる。

必要性は、一石列のみ／二石列一つの両方に対する補間数上界で証明する。
十分性は整数の明示構成で証明し、
`L=((r−2)!)², t=2L(w−1)²+(r−2)³+2` とする支配項評価により、
巨大な探索なしに補間高さを相異ならせる。中間サイズ構成の座標の二進長はO(r² log(rw))。

## 有限独立監査

[construct.py](construct.py)は幅3〜9、各列点数2,3,5,8,17,31の全可能サイズについて、
計147個の整数点盤・極大安全配置を具体化する。
各配置の全四点組の安全性と、全空候補の禁止三点組を、
3×3差分行列式と独立4×4置換展開・アフィン余因子で確認した。
非存在側は実数座標盤の有限探索で推測せず、数学的な補間数評価による。

既存の全局面有限検査データについても、実際の終局サイズが必要条件内にあることを照合した。
候補数が不等の場合はその最小値を下界に使い、三石については実際に三点列があるかを別扱いする。

```sh
uv run --locked python research/experiments/quadratic-zero-terminal-spectrum-20261024/construct.py
```

[results.json](results.json)には全構成の占有点・列候補集合・整数構成パラメータ・検査件数を保存。
全称性の根拠はproof.mdの必要性・明示的十分性であり、147個の有限例からの外挿ではない。

固定された標準格子では実現しないサイズもある。例としてw=6,m=6では
任意候補集合のどれかで3,5,6,7石が実現可能だが、標準6×6の全計算では3,6,7石だけが現れる。
全局面の勝敗・Grundy値をこの終局サイズ集合だけから決める主張でもない。
