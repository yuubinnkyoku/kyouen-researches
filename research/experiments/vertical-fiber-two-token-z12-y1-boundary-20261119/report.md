# z=12・y=1 2トークン境界切片の全Grundy分類（K1016・実験記録）

日付: 2026-11-19
対象: κ=1残余ゲーム H(R;(x,1);12)、全 x>=1・全 R>=0 の Grundy 値 0/1/2 の完全分類
方法: 有限センサス（census_z12_y1.py）→ 候補閉形式の導出 → A/B/C署名帯表による全称証明 → 独立検証器による大規模監査（verify_z12_y1.py）

## 命題

O[a,b] は区間内の奇数、E[a,b] は区間内の偶数、I[a,∞) は a 以上の全整数とする。
H(R;(x,1);12)=2 となる位置 T(x) は次のとおり。

| x | T(x) |
|---:|---|
| 1 | {1} |
| 2,3 | O[1,3] |
| 4,5 | O[1,5] |
| 6,7 | O[1,7] |
| 8,9 | O[1,9] |
| 10 | O[1,11] |
| 11 | O[1,13] |
| 12,13 | O[1,11] |
| 14 | O[1,11] ∪ O[15,27] |
| x>=15 | {1,3,5,7,9,11,15} |

H(R;(x,1);12)=1 となる位置 P(x) は次のとおり。

| x | P(x) |
|---:|---|
| 1,3,5,7,9,11 | ∅ |
| 2 | I[4,∞) |
| 4 | I[6,∞) |
| 6 | I[8,∞) |
| 8 | I[10,∞) |
| 10 | I[12,∞) |
| 12 | I[13,∞) |
| 13 | {13} |
| 14（偶） | {13} ∪ E[16,26] ∪ I[28,∞) |
| x>=16（偶） | {13} ∪ E[16,x+12] ∪ I[x+14,∞) |
| x>=15（奇） | {13} ∪ E[16,x+13] |

従って
H(R;(x,1);12) = 2 if R∈T(x), 1 if R∈P(x), 0 otherwise。

tail は
R >= x+14 ⟹ H(R;(x,1);12) = (x+1) mod 2
（K0832 の一般 tail R>=S+|X|+z−1 = x+1+2+12−1 = x+14 と一致）。
また κ=1 の高さのみ縮約から
R <= 13 ⟹ H(R;(x,1);12) = v_single(x+1,12,R)。

## 子と導出

R>=1 の子は
A = H(R−1;(x−1,1);12)  （x>=2・x外帰納）
B = H(R−1;(x,);13) = single_token(x,13,R−1)  （K0832 単一トークン全称公式）
C = 1 ⊕ H(R−1;(x,1);11) = 1 ⊕ K1012  （z=11,y=1 出版済み全称定理）
であり、x=1 では 2 本の除去手が同一の単一トークン子 (1;13) に合流する。

センサス（census_z12_y1.py・output/census.txt・2回実行byte-identical）は
K1012 子アンカー照合 x<=40・R<=x+48 の 0 不一致・単一トークンz=13アンカー照合 x<=60・R<90 の 0 不一致を含み、
x=1..26・R<=x+48 の T/P 行表と A/B/C 署名帯を機械出力した。
候補閉形式はこの表から導出し、x>=15/x>=14 の定常帯は x に関する線形パラメトリック形に読み替えた。

## 証明（A/B/C署名帯表）

各 x について R>=1 を互いに素な帯に分割し、各帯での A/B/C 子の Grundy 値集合を昇順数字列（署名）で表す。
帯は全 R>=1 を被覆する。署名と mex の対応は

| 署名 | 01 | 23 | 03 | 02 | 023 | 123 | 0 | 1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| mex | 2 | 0 | 1 | 1 | 1 | 0 | 1 | 0 |

である。行ごとの帯表は次のとおり（O/E は奇数/偶数だけを取る帯）。

| x | R帯: 子署名 |
|---:|---|
| 1 | 1:01, 2:23, R>=3:1 |
| 2 | 1,3:01, 2:23, 4:03, R>=5:0 |
| 3 | 1,3:01, 2,4:23, R>=5:1 |
| 4 | 1,3,5:01, 2,4:23, 6:03, R>=7:0 |
| 5 | O[1,5]:01, E[2,6]:23, R>=7:1 |
| 6 | O[1,7]:01, E[2,6]:23, 8:03, R>=9:0 |
| 7 | O[1,7]:01, E[2,8]:23, R>=9:1 |
| 8 | O[1,9]:01, E[2,8]:23, 10:03, R>=11:0 |
| 9 | O[1,9]:01, E[2,10]:23, R>=11:1 |
| 10 | O[1,11]:01, E[2,10]:23, 12:03, R>=13:0 |
| 11 | O[1,13]:01, E[2,12]:23, R>=14:1 |
| 12 | O[1,11]:01, E[2,12]:23, 13:0, 14:023, R>=15:0 |
| 13 | O[1,11]:01, E[2,12]:23, 13:0, E[14,26]:123, O[15,25]:1, R>=27:1 |
| 14 | O[1,11]:01, E[2,12]:23, 13:0, 14:123, O[15,27]:01, E[16,26]:0, R>=28:0 |
| 15 | O[1,11]:01, E[2,12]:23, 13:0, 14:123, 15:01, E[16,28]:02, O[17,27]:1, R>=29:1 |
| x>=16 偶 | O[1,11]:01, E[2,12]:23, 13:0, 14:123, 15:01, 16:02, O[17,x+13]:1, E[18,x+12]:0, R>=x+14:0 |
| x>=17 奇 | O[1,11]:01, E[2,12]:23, 13:0, 14:123, 15:01, 16:02, O[17,x+12]:1, E[18,x+13]:0, R>=x+14:1 |

各署名の mex を適用すると本文の T/P が得られる。K0832 Theorem T の偶奇上界
（奇数 R で親値<=2・偶数 R で親値<=1）にも一致する。
x=14 は掃引行（x=z+y+1）で値2位置が O[15,27]=O[pin,x+y+z] へ広がり、
x=13 は x=z+1 行で P={13} 有限、x=12 は x=z 行で P=I[13,∞) 、
x=11 は x=z−1 行でラダーが O[1,13] に伸びる（前倒し点 z+1=13 がこの行にのみ現れ、x=z 行で消滅）。
x>=15 で値2位置は {1,3,5,7,9,11,15} に定着する（pin=2y+z+[z偶]=15）。
値1の基底点は {13}={z+1} の 1 点（基底点 y 個仮説 {z+1,…,z+2y−1} の y=1 例）、
中間帯は E[16,..]（開始 z+2y+2=16、偶奇は z の偶奇追従で偶数帯）、
I[a,∞) 帯は x 偶数行のみ（tail 値 (x+1) mod 2 が 1 の行）。

全称性は x=1 の基底、既証明の子（K0832 単一トークン・K1012）、x>=2 の外帰納、
および上記全 R 署名帯表から従う。低 R（R<=13）は高さのみ縮約、高 R（R>=x+14）は
K0832 一般 tail から独立に得られる。

## 構造則（z=6..11 の7則の z=12 での貫徹・有限観察）

- 定常ピン pin=2y+z+[z偶]=15、定常値2位置はラダー O[1,z−1]={1,3,5,7,9,11} ∪ {pin}。
  偶数 z のラダー上限 z−1 は z=8（O[1,7]∪{11}）・z=10（O[1,9]∪{13}）に続き 3 例連続。
- 掃引行 x=z+y+1=14、掃引帯 O[pin, x+y+z]=O[15,27]。
- 値1基底点 {z+1}（y=1）、中間帯開始 z+2y+2=16（E帯・偶奇は z 追従）。
- I 帯は x≡y+1 (mod 2) の行（y=1 では x 偶数行）。tail R>=S+z+1=x+14 で H=(x+1) mod 2。
- 前倒し点 z+1=13 は x=z−1=11 行（d=10≡(10−z) mod 4）にのみ現れ、x=z 行で消滅。

z=7..11 で確定していた「前倒し格子・d=z+1 掃引行・d>=z+2 定常ピン・基底点 y 個・
帯開始 z+2y+2・帯偶奇 z 追従・tail R>=S+z+1」の 7 則は z=12,y=1 でも全て貫徹した。
z>=12 の族として最初の全称証明済み切片であり、偶数 z 族の一般則の 3 番目の確定データ点となる。

## 転写誤りの発見

最初の候補で P の奇数行を x=13 にも定常式 {13}∪E[16,x+13] を当てはめたところ、
検証器が V1/V4/V13 で計 6 点（x=13・R=16..26 偶数）の不一致を検出した。
x=13 は x=z+1 行で P={13} 有限が正しく、修正後全チェックが通過した。
V6 の x=14 での 6 点はこの誤りの A 子経由の波及であった。

## 輸送記録

最初のセンサス実行の tool 結果表示のみが奇数行の P を 2 点分だけ長く表示する破損を生じた
（実行自体の再現・独立プローブ・追試では全て別の結果となり、ファイル保存した出力は
2 回実行で byte-identical）。出版物は全てファイル実体の sha256 ピンと着地後の raw CDN
照合で検証する。

## 限界

本項は z=12・y=1 切片のみ。z=12 の y>=2、z>=13、全高さを統合する 2 トークン値2位置の
一般式、標準二次元盤の固定幅・q 点版安定化長は未解決。次の y=2 切片は
B=本項・C=1⊕K1013（z=11,y=2 出版済み）で着手可能である。
有限監査は転写・実装照合であり、全称性の根拠は外帰納と署名帯表である。
