# 有限列長を含む平行列版の二変数Grundy縮約

起点 main f76cb65cb5d6843e80a5359efa9c37473a80fbbd。K0340の三次元盤を
占有数ゲームへ縮約した後の問題を解く。K0341の奇数r長盤公式を
再発見せず、そこで残った短盤・全rを扱う。

## 定理: 奇数列の全局面を二変数表へ縮約

w≥3は奇数、m,rは非負整数。局面は
`0≤x_i≤m, x_i+x_j≤r (i≠j)`。一手で合法性を保って一座標を1増やす。
通常プレイのGrundyをgとする。

`0≤b≤a≤m, a+b≤r` で、次のDAG再帰を定義する。

```
F(a,b)=mex(P(a,b))
P(a,b) = { F(a+1,b) : a<m, a+b+1≤r }
       ∪ { F(a,b+1) xor 1 : b<a, a+b+1≤r }.
```

空集合のmexは0。この再帰はa+bが増えるので一意に定まる。選択肢は
高々二つであり、常に `F∈{0,1,2}`。

a,bをxの最大・二番目の占有数（重複を含む）とし、
`e=(Σx−a) mod2` と置く。このとき全有限長について

```
g(x)=F(a,b) xor e.
```

特に任意の奇数列数で全Grundyは0..3に収まる。表の大きさは
O(min(m,r)²)、初期計算後は最大二値と総和をO(w)で求めれば一局面を評価できる。
盤点の位置・列数に依存する大きいsubset DPは不要である。
偶数wはK0340の全長0/1公式を使う。

## 証明

最大の列を一つ指定し、残りw−1列の和の偶奇をeとする。aが重複しても
選び方でeは変わらない。合法手は次の三種に尽くされる。

1. 最大aの列を増やす: 二最大値は(a+1,b)、eは不変。
   必要十分条件は `a<m, a+b+1≤r`。
2. a>bのとき、二番目の値bを持つ列を増やす: 二最大値は(a,b+1)、eは反転。
   必要十分条件は `a+b+1≤r`。b<a≤mなので列端条件も満たす。
3. b未満の列を増やす: 二最大値は不変、eは反転。
   `x_i+1≤b` なので、列端と全ペア制約を自動的に満たす。

a=bで最大を増やす場合も他の最大がbとして残るので種1に入る。
種3が存在しないのは、指定した最大以外が全てbである場合に限る。
その個数w−1は偶数なので、その場合e=0。従って **e=1なら種3が必ずある**。
e=0の場合は種3の有無を判定する必要がない。

残り手数による帰納法を使う。全子で公式が成立するとする。
P=P(a,b), f=mex(P)と置けば、e=0で種1/2の後続値集合はP。
種3があれば後続値 `f xor1` が追加される。この追加はmex=fを変えない。
f=0なら追加値1、f=1なら追加値0は既にPにあり、f=2なら追加値3である。

e=1では種1/2の後続は `{p xor1:p∈P}`、必ずある種3の後続はf。
この集合のmexは `f xor1` である。

- f=0: Pは0を含まない。xor後は1を含まず、f=0を追加したのでmex=1。
- f=1: Pは0を含み1を含まない。xor後と追加f=1は0を含まないのでmex=0。
- f=2: Pの要素数≤2よりP={0,1}。xor後も{0,1}、追加f=2でmex=3。

全場合で主張が従う。終局を含めて同じ帰納が使える。

## 系: 全r・全mの空盤と真の安定化長

奇数w≥3の空盤Grundy値は

```
r=2k+1:  g(0)=min(m,k+1) mod2.
r偶数:   g(0)=m mod2（m<r）、0（m≥r）。
```

後半はK0345の全長閉式による。前半を二変数再帰で証明する。
m≤kなら全点が安全で手数wmが固定、w奇数なので値m mod2。
m≥k+1の場合、D_j=F(j,j), N_j=F(j+1,j), Q_j=F(j+2,j)と置く。
以下でQ_jはj≤k−1の場合だけ使う。

F(k+1,k)=0はペア容量が飽和した終局なのでD_k=1。
k=0ならこれでD_0=1を得る。
k≥1ではQ_{k−1}=F(k+1,k−1)のB手の値は1、A手は列端により
無いか、容量飽和終局の値0である。従ってQ_{k−1}∈{0,2}。
N_{k−1}=mex{Q_{k−1}, D_k xor1}=1、D_{k−1}=0。

下降帰納でD_j=(k+1−j) mod2, N_j=1−D_jを示す。
j≤k−2ではQ_jのB手が存在し、その値はN_{j+1} xor1=1−D_j。
F≤2だから、Q_jはこの値を取らず、Q_j∈{D_j,2}。
N_jにはA,B両手があり、後続値はQ_jとD_{j+1} xor1=D_jなので
N_j=1−D_j。さらにD_j=mex{N_j}で主張が閉じる。
従って空盤D_0=(k+1) mod2。

列長の定義域をm≥1とすると、r≥1の真の空盤勝敗・Grundy安定化長は
r奇数で(k+1)、r偶数でrである。境界より一つ短い盤は逆の偶奇値になる。
r=1は定義域の初めから安定する。
これは全局面の容量分離安定化長ではなく、**空盤勝敗の安定化長**である。

## 補題: 有限の一括減少回数を持つgapゲーム

偶数n≥2の非負gap yと非負budget zに対し、一手は正の座標一つを1減らすか、
`min y>0,z>0` のとき全座標を1減らしてzも1減らすものとする。
t=min y, E=Σy mod2と置くと、全Grundyは

```
z<t:   h(y,z)=(E+z) mod2.
z≥t:   h(y,z)=2(t mod2)+E.
```

z≥t領域は全ての子でも不変。t>0ならz>0で一括手が許されるので、K0341の
通常gapゲームの四場合mex証明をそのまま使える。

z<t領域では一括手は同じ領域に留まりE+zの偶奇を反転する（nは偶数）。
一座標手も、領域に留まる場合は偶奇を反転する。
領域から出るのは `z=t−1` かつ最小座標を減らす場合だけである。
この子は最小値z、和の偶奇E xor1を持ち、値は `2(z mod2)+(E xor1)`。
t奇数ならz偶数なので現在候補Eと逆偶奇、t偶数ならz奇数で現在候補(E xor1)+2。
いずれも現在候補0または1と等しくない。

候補1から値0の後続は必ずある。z>0なら一括手を使う。
z=0ならE=1で正のgapが存在する。その一座標手は、領域に留まれば値0。
t=1で境界に出ても、最小値0・和偶数なので値0である。
候補0には値0の後続がなく、候補1には値1の後続がなく値0がある。
Σy+nzによるmex帰納で補題が成立する。

## 三次元の短盤への移送

K0340の仮定（底面の三点共線なし、q>2w、r=q−1）の下で全実局面に適用できる。
支配列 `a>r/2` では、他列gap `y_i=r−a−x_i` と budget `z=m−a` が
上記補題のゲームになる。これが長盤の仮定m≥rを外した正しいgap式である。
単にm≥r用の閉公式を短盤へ代入することはできない。
例えばw=3,r=6,m=4の空盤はg=0、m=7の空盤もg=0だが、
同じ占有数(4,1,0)は短盤g=1、長盤g=3となる。

全Grundy≤3はこの明示的な三次元族の結果であり、標準二次元正方形盤の
Grundy無界性問題を解決しない。11×11空盤は引き続きUNKNOWN。
