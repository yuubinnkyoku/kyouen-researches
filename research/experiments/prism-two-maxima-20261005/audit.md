# 二列kernel・列端付きgap・偶数容量の独立数学監査

2026-10-05 (JST)。別担当による全称mex証明の独立監査。
検算した有限パラメータの一致を無界命題の根拠にしない。
以下は幾何を用いない占有数ゲームの証明であり、三次元盤への移送には
K0340の条件（底面に共線三点なし、q>2w）を別に必要とする。

## 1. 任意の容量・列端を持つ奇数列ゲームの二列kernel

奇数w≥3、整数r≥0,m≥1、安全な占有数0≤x_i≤m、全ペア和≤rを考える。
一手で一列を1増やす。a=max x、b=second max x（重複込み）、
e=(Σx−a) mod2とする。次の二変数再帰を定義する。

```
F(a,b) = mex P(a,b)
P(a,b) = { F(a+1,b)      : a<m, a+b+1≤r }
        ∪{ F(a,b+1) xor1 : b<a, a+b+1≤r }.
```

領域は0≤b≤a≤m、a+b≤r。座標和が増えるので再帰は有限。
選択肢は高々二つ、従って常にF≤2である。
**全称結論はg(x)=F(a,b) xor e。**

独立監査では、全合法手を次の三種類へ分類した。

* A: 最大列への追加。二列座標は(a+1,b)、eは保存される。
  最大列が複数でも、その一列を増やすと第二最大値は旧a=bになるので同じ式。
* B: a>bで値bの列への追加。二列座標は(a,b+1)、eは反転される。
  b+1=aで最大値が重複する境界も含む。
* C: 値b未満の列への追加。a,bは保存され、eは反転される。
  この手は常に合法。増加後の値はb以下なので列端と全ペア制約を満たす。

A,Bは二列再帰の条件と正確に同値であり、すべての手はこの分類に入る。
Cはe=0では存在する場合もしない場合もある。しかしe=1では必ず存在する。
最大列を一つ除いたw−1列は偶数個なので、それらがすべてbなら和は偶数。
e=1ならその中にb未満の列がある。

F=mex Pとして、e=0では後続値集合はPと、存在すれば{F xor1}の和集合。
F=0なら追加値1はmex0を変えない。F=1なら0はすでにPにあり、
F=2なら追加値3はmex2を変えない。
e=1では後続値集合は(P xor1)∪{F}である。

* F=0: Pに0がないのでP xor1に1がなく、追加値0がある。mex=1。
* F=1: Pに0があり1がないのでP xor1に1があり0がない。mex=0。
* F=2: Pに0,1があり、|P|≤2なのでP={0,1}。後続値は{0,1,2}、mex=3。

Pの値に3が含まれ得ることも以上の監査に支障がない。
終局を含めて占有総数の降順帰納が成立する。
これは局面同型を要求する証明ではなく、Grundy値を求める再帰の縮約である。

## 2. 偶数容量では全mのkernelも閉じる

rが偶数ならc=r−mとして、任意の列端m≥1で

```
F(a,b) = (a+m) mod2         if b<c,
         2 ((a−b) mod2)     if b≥c.
```

従って全安全局面で

```
g(x) = (Σx+m) mod2                          if b<r−m,
       2 ((a−b) mod2)+((Σx−a) mod2)          if b≥r−m.
```

短盤を長盤公式へ無条件に代入する誤りを、第一領域が正確に修正する。
特にm≥rならc≤0なので第二領域のみとなり、別担当の長盤公式を回収する。

二列再帰を直接検査する全称証明は次の通り。

**低第二最大値b<c。** A手は同じ領域にとどまり、候補Fの偶奇を反転する。
B手もb+1<cなら同じ候補Fを持つ子にxor1を付けるので値1−F。
境界b=c−1のB手では子が高領域に移り、その値は
2((a−c) mod2) xor1となる。rが偶数なのでc≡m mod2であり、
現在候補Fが0なら境界B値1、現在候補Fが1なら境界B値3。
いずれの手も候補自身を与えない。
F=1ならa=mではなくa<m。さらにb≤c−1なので
a+b+1≤(m−1)+(c−1)+1=r−1、従ってA手が合法で後続値0を与える。
よってmexは候補0または1。

**高第二最大値b≥c。** 両種の手はこの領域にとどまる。
候補F=0ならA,Bの後続値はそれぞれ2,3であり、mex0。
候補F=2ならa−bは奇数なのでa>bで、a+bは奇数≤r−1。
またa=mならb≥cよりa+b≥rとなって矛盾するためa<m。
A,Bは双方合法で後続値0,1を与える。mex2。
これで有限二列再帰への帰納が完了する。

この閉式はr=0も正しく扱うが、三次元ゲームへの移送条件はそれより強い。
幾何条件下の奇数q（偶数r）について、空盤はm<rならg=m mod2、
m≥rならg=0。その境界m=rでもmは偶数なので値が一致する。

## 3. 列端付きの偶数個gapゲーム

偶数n≥2の非負整数y_iと、非負整数zを状態とする。
合法手は正の一座標y_iを1減らすか、全y_i>0かつz>0のとき
全y_iとzを各1減らすこと。t=min y、E=Σy mod2とする。

```
h(y,z) = (Σy+z) mod2               if z<t,
         2 (t mod2)+(Σy mod2)      if z≥t.
```

**z≥t。** 一座標手も全座標手もこの不等式を保存する。
t>0ならz>0なので全座標手が常に存在し、通常gapゲームと同じmex証明が使える。
候補0には同値の後続がない。候補1はt=0なら正の座標を下げるか、
t>0ならtより大きい座標を下げて0へ移る（全同値なら偶数nからE=0）。
候補2は全座標手で0、最小座標手で1へ移る。
候補3は全座標手で1、最小座標手で0、tより大きい座標手で2へ移る。

**z<t。** 全座標手はstrict領域を保存し、Σy+zの偶奇を反転する。
一座標手も同領域に残れば偶奇を反転する。
他領域へ移る場合はz=t−1かつ最小座標を下げた場合だけ。
tが奇数なら後続のt−1は偶数で、後続候補は現在候補と逆の0/1。
tが偶数なら後続候補は2+現在候補となる。どちらも現在候補自身ではない。
現在候補1について、z>0なら全座標手で0へ行ける。
z=0ならΣyが奇数であり、正の座標を下げる手は同領域で0へ行くか、
t=1の境界で最小値0・和偶数となって0へ行く。
従ってmexは候補0または1。Σy+zでの帰納により全称式が成立する。

## 4. 有限独立検算の範囲

`independent_even_finite_audit.py` はソートした全占有数軌道の完全mexを使い、
奇数w=3,5,7,9、偶数r=2,...,20、全m=1,...,r+2で上の有限列端式を検査する。
幾何条件q>2wを満たさない小パラメータも、純粋な占有数定理の検算として含む。

## 5. 奇数容量の短盤も空盤の真の安定化長を閉じる

r=2k+1、m≥k+1とする。上の二列kernelについて

```
D_j=F(j,j)=(k+1−j) mod2                  (0≤j≤k),
N_j=F(j+1,j)=1−D_j                       (0≤j≤k−1),
Q_j=F(j+2,j)∈{D_j,2}                    (0≤j≤k−1).
```

最後の二式は添字のある場合にだけ主張する。
基底としてF(k+1,k)=0は、最大二値の和rなので終局である。
従ってD_k=mex{0}=1。
Q_{k−1}=F(k+1,k−1)にはB手の値F(k+1,k) xor1=1があり、
m=k+1ならA手がなくmex{1}=0。m≥k+2ならA手が値
F(k+2,k−1)=0を与え、mex{0,1}=2。
ゆえにQ_{k−1}∈{0,2}。N_{k−1}=mex{Q_{k−1},D_k xor1}=1、
D_{k−1}=mex{N_{k−1}}=0。

j≤k−2へ下降帰納する。目標偶奇をd_j=(k+1−j) mod2と書く。
Q_jのB手は必ず合法で、その値はN_{j+1} xor1=1−d_j。
F≤2なのでQ_jはこの値と異なり、Q_j∈{d_j,2}となる。
N_jのA,B手は双方合法で、値集合は{Q_j,D_{j+1} xor1}={Q_j,d_j}。
d_j=0ならmex{0,Q_j}=1、d_j=1ならmex{1,Q_j}=0。
従ってN_j=1−d_j、続いてD_j=mex{N_j}=d_jが従う。
k=0ではD_0=1の最初の基底だけで十分である。

空盤はe=0なのでD_0を使える。m≤kでは全点が安全で通常の自由追加ゲーム。
したがって奇数wの空盤は、全r,mについて

```
r odd 2k+1:   g(∅)=m mod2             if m≤k,
                       (k+1) mod2     if m≥k+1.
r even:       g(∅)=m mod2             if m<r,
                       0              if m≥r.
```

偶数容量の式は第2節から従う。r≥2で「これ以後ずっと同じ空盤勝敗」となる
**真の最小列長**は、奇数rなら(r+1)/2、偶数rならrである。
前者では直前m=kの勝敗が反対、後者では直前m=r−1が勝ちで以後は負け。
r=1では全m≥1で勝ち、最小列長1となる。
これは空盤勝敗の安定化であり、全極大サイズの均一化や全局面同型を主張しない。
