# 2×3×4 共面4点禁止版：misère の全安全局面分類（2026-11-09）

標準の安全着手だけを許す有限ゲームで、**最後の合法手を打った側が負ける** misère 版を調べた。合法手がない局面は手番側の勝ち（N局面）とする。これは通常プレイの Grundy 数とは別の再帰である。

同じ盤の整数外積による禁止四点組生成と安全手生成を `verify.py` から再利用し、`verify_misere.py` で全31,529安全局面を再帰分類した。空盤は N（先手勝ち）、全24初手の子局面は P（手番側負け）となる。従って **どの初手でも先手勝ち**。

| 石数 | P（手番側負け） | N（手番側勝ち） |
|---:|---:|---:|
| 0 | 0 | 1 |
| 1 | 24 | 0 |
| 2 | 0 | 276 |
| 3 | 1,952 | 72 |
| 4 | 8 | 8,492 |
| 5 | 13,872 | 1,184 |
| 6 | 0 | 5,648 |
| **計** | **15,856** | **15,673** |

検証：`python research/experiments/coplanar-234-20261109/verify_misere.py`（同じディレクトリの `verify.py` を読み込み、通常プレイの既存回帰も実行する）。

証拠水準：有限完全列挙。幾何生成器と着手生成器は既存の通常プレイ実験と共通なので、幾何条件まで独立した二実装の照合ではない。無限の2×3×mについては何も主張しない。
