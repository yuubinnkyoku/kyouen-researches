# 二次形式版：等方直線上の三石終局と安定化不能の無限族

2026-10-24。**証拠：全称代数証明＋独立有限完全列挙。** 標準共円ゲームではなく、`det[x²+λy²,x,y,1]=0` を禁止する4点版（退化も禁止）を扱う。盤は `D(w,m)={0,...,m-1}×{0,...,w-1}`、`w≥3, m≥4`、λは任意の実数。3石以下は常に安全。

## 定理：三石極大の必要十分条件

3点集合 `S` が極大安全配置（これ以上1石も置けない）となる必要十分条件は、3点がある整数直線上にあり、その方向ベクトル `(u,v)≠(0,0)` が

`u²+λv²=0`

を満たすことである。特に、**任意の `w≥3,m≥4` における三石極大配置の全個数** `N₃(w,m;λ)` は以下の通り。

- `λ=0`：`N₃=m*C(w,3)`（鉛直列から任意の3点）。
- `λ=−(a/b)²`、`a,b≥1` 互いに素：
  `N₃=2 Σ_{h=2}^{H} (h−1)(m−ah)(w−bh)`、`H=min(floor((m−1)/a),floor((w−1)/b))`。`H<2` なら和は0。
- その他の実数 `λ`：`N₃=0`。

`λ=−(a/b)²` で三石極大が存在するための必要十分条件は `m≥2a+1, w≥2b+1`。この場合、任意のより長い盤でも三石極大が残るため、満容量 `3w` への真の安定化長は **`M_{w,λ}=∞`**。`λ=0` についても `w≥3` で同じ結論（既存K0518）。

**三行に限ると**、`m≥4` で三石極大が存在するのは `λ=0` または `λ=−a²`（正整数aかつ `m≥2a+1`）の場合に限る。その個数はそれぞれ `m` と `2(m−2a)`。従って全ての正整数aに対し `M_{3,−a²}=∞`、さらに `m≥max(8,2a+1)` なら既存の `K(3,m;λ)=9` と合わせ `s=3<K=9` が成立する。これは `λ=0` だけでなく**非零の無限個の係数**における安定化不能を証明する。

## 全称証明

**(1) 三石極大なら持ち上げ後の3点が一次従属。** 各点を `L(x,y)=(x²+λy²,x,y,1)` に持ち上げる。固定した三石の行ベクトルの階数が3なら、四石目との4×4行列式は、ゼロでない

`P(x,y)=A(x²+λy²)+Bx+Cy+D`

となる。`A≠0` なら、どの水平行でも `x` の二次多項式である。w≥3なので三石のうち高々1石しかない行が存在し、m≥4ではその行に少なくとも3個の空点がある。二次式は全てを零にはできず、合法な第四石がある。`A=0,B≠0` なら同じ行で一次式の根は高々1個。`A=B=0` なら `P=Cy+D` は非零の一次式または定数であり、少なくとも一つの水平行で非零、その行には空点がある（m≥4）。いずれも極大性に反する。

逆に持ち上げ後の3点の階数が高々2なら、任意の第四点を加えても行列式は零。したがって三石は極大。

**(2) 持ち上げ後の階数2と等方直線。** 末尾の座標が1なので、持ち上げ後の3点が同一直線上にあるなら、元の3点も同一直線上にある。方向を `(u,v)`、三点の直線パラメータを相異なる `t₁,t₂,t₃` と書くと、`x²+λy²` の制限は

`Q(t)=Q₀+Lt+(u²+λv²)t²`。

3つの相異なる `t` でこの値が一次式に一致するための必要十分条件は `u²+λv²=0`。これで(1)の条件を分類できる。

**(3) 整数格子での方向と個数。** λ=0なら方向は鉛直。λ<0で等方整数方向が存在するのは、λが負の有理数平方 `−(a/b)²` のときだけ。既約な方向は `(±a,b)`（上下反転は同じ直線）。3点の両端はその方向に少なくとも2整数歩離れるので `m≥2a+1,w≥2b+1` が必要十分。両端の歩数差を `h≥2` と固定すると、間の第三点は `h−1` 通り、両端の配置は各方向につき `(m−ah)(w−bh)` 通り。二方向を合計して公式を得る。λ=0は各列の `C(w,3)` 通り。

## 有限独立検算と再現

```sh
python3 research/experiments/quadratic-pencil-isotropic-triples-20261024/verify.py > /tmp/isotropic-triples.json
```

`verify.py` は各盤の**全三点集合**を走査し、各三石について第四点を検査する（合法な第四点を発見した場合はそこで打ち切る）。整数にスケールした3×3差分行列式から極大性を独立判定する。別途、幾何的等方条件と上記の閉公式に一致することを検査する。三行4〜5列の20盤では、4×4行列式の24項置換展開を全第四点で追加照合する。三行4〜10列の70盤（λ∈{−16,−9,−4,−2,−1,0,1,2,−1/4,1/2}）と、幅4〜7の9盤、計79盤で一致した。結果は `results.json`。

有限検算は無界結論の根拠ではない。任意のλ・w・mに関する主張は上の代数証明による。**この定理は三石極大だけを分類する。** それ以外のλで4石以上の不足極大が存在するか、有限の真の安定化長がいくつかは未解決。11×11の標準λ=1に三石極大がないことは含意するが、11×11の勝敗や探索計算量の改善を主張しない。
