# 残容量が高さ計数以下なら一般多重集合が総和1トークンに縮約（κ=1）

- 日付: 2026-11-16
- 対象: K0832の抽象残余ゲーム \(H(R;X;z)\)、完了手の値 \(\kappa=1\)
- status: **全称証明済み**
- 主結果: \(R\le z+1\) なら、任意の有限正整数多重集合 \(X\) は総和 \(S=\sum X\) の単一トークンへ厳密に縮約される。さらに \(R\le2\) では \(z\) に条件を付けず成立する。
- 適用範囲: 純ファイバー残余ゲームのみ。標準二次元幾何ゲームの空盤勝敗は主張しない。

## 主定理

\[
S=\sum_{x\in X}x,\qquad v(s,z,r)=H(r;(s);z),\qquad v(0,z,r)=0
\]
と置く。\(X\) は正整数の有限多重集合（空でもよい）とする。

**定理（高さだけによる縮約）**
\[
\boxed{
R\le z+1\quad\Longrightarrow\quad H(R;X;z)=v(S,z,R).
}
\]

すなわち、\(z\ge R-1\) なら、トークンの個数・分割を忘れて総和 \(S\) だけを残せばよい。右辺の値はK0832で証明済みの単一トークン閉形式に \(x=S\) を代入すれば完全に決まる。

さらに
\[
\boxed{R\le2\quad\Longrightarrow\quad H(R;X;z)=v(S,z,R)\quad(\forall z\ge0).}
\]

後者は \(R=0,1,2\) の直接計算であり、前者の \(z\ge R-1\) より強い。

## 補題：単一トークン値の高さ安定性

\(v(s,z,r)=H(r;(s);z)\) とする。単一トークン閉形式から
\[
\boxed{z\ge r\quad\Longrightarrow\quad v(s,z,r)=v(s,z+1,r)}
\]
が全 \(s,r,z\) で成立する。

**証明。** \(r=0\) または \(s=0\) は両辺0。\(r\ge1,s\ge1\) とする。

- \(z\ge s+1\): \(z,z+1\) はともに単一トークン公式の \(z\ge s+1\) 枝に入り、値は \(z\) に依存しない。
- \(z=s\): \(z=s\) の特別枝と \(z=s+1\) の安定枝を比較する。奇数 \(r\le s\) では両方2、偶数 \(r<s\) では両方0、\(r=s\)（従って \(s\) 偶数）では両方 \(s\bmod2=0\)。
- \(1\le z\le s-2\): 両方とも中間枝または閾値枝にある。奇数 \(r\le z\) では両方2。偶数 \(r<z\) では両方0。残る \(r=z\) は \(z\) 偶数で、左辺は中間式 \((r+z)\bmod2=0\)、右辺は \(r\le q(z+1)\) の閾値枝で0。
- \(z=s-1\): \(z=s-1\) の枝と \(z=s\) の特別枝を比較する。奇数 \(r\le s-1\) では両方2。偶数 \(r\le s-1\) では両方0（境界 \(r=z\) の中間式も0）。

以上で全場合を尽くす。∎

## 主定理の証明

\(R\) に関する強帰納法を用いる。

### 基底・小さいR

\(R=0\) は定義から両辺0。

\(R=1\) では、\(X\ne\varnothing\) ならA/B手の子値0が少なくとも一つある。\(z=0\) なら選択肢値集合は \(\{0\}\)、\(z\ge1\) ならC手の値1も加わり \(\{0,1\}\)。従って値はそれぞれ1,2であり、\(X\) の分割によらない。空多重集合は常に0。

\(R=2\) では \(S=0,1\) は自明なので \(S\ge2\) とする。A/B手のうち少なくとも一つは存在する。子の多重集合の総和は \(S-1\ge1\) なので、R=1の計算から、
- \(z=0\): A子は1、B子は2。選択肢集合は \(\{1\}\) または \(\{1,2\}\) でmexは0。
- \(z=1\): A/B子は2、C子は \(1\oplus1=0\)。mexは1。
- \(z\ge2\): A/B子は2、C子は \(1\oplus2=3\)。mexは0。

いずれも単一トークン \(S\) の値と一致する。よって \(R\le2\) では任意の \(z\) で成立する。

### \(R\ge3,\ z\ge R-1\)

帰納仮説を \(R-1\) に適用する。親条件 \(z\ge R-1\) から、各子はすべて帰納領域に入る。

- A手の子: 総和 \(S-1\)、高さ \(z\)、残容量 \(R-1\)。\(z\ge R-2\)。
- B手の子: 総和 \(S-1\)、高さ \(z+1\)、残容量 \(R-1\)。同じく帰納領域。
- C手の子: 総和 \(S\)、高さ \(z-1\)、残容量 \(R-1\)。\(z-1\ge R-2\)。

従ってA手の子値は \(v(S-1,z,R-1)\)、B手の子値は \(v(S-1,z+1,R-1)\)、C手の子値は \(1\oplus v(S,z-1,R-1)\) である。

単一トークン安定性補題を \(r=R-1\) に適用すると
\[
v(S-1,z,R-1)=v(S-1,z+1,R-1).
\]
よって一般多重集合の全A/B手は、存在する限り同じ値を与える。\(S\ge2\) なら \(X\ne\varnothing\) であり、各トークンは1または2以上のどちらかなので、A/B手は少なくとも一つ存在する。単一トークン \((S)\) の唯一のA手も同じ値を与える。C手は両側で同じ値を与える。

したがって親の選択肢値集合が一致し、mexも一致する。\(S=1\) なら \(X=(1)\) そのもの、\(S=0\) なら空多重集合補題で終わる。∎

## 一様条件の鋭さ

\(R\le2\) では高さ条件が不要である。一方、各 \(R\ge3\) では \(z\ge R-1\) を一様に1だけ弱めることはできない。

- **Rが奇数**: \(X=(1^R)\)、\(z=R-2\)。全1族の証明済み2位置公式より \(H(R;X;z)=2\)。一方、総和 \(S=R\) の単一トークンは \(z=R-2\) の中間枝にあり、\(v(R,R-2,R)=(R+R-2)\bmod2=0\)。
- **Rが偶数（R≥4）**: \(X=(1^{R-1})\)、\(z=R-2\)。全1族の証明済み閉形式（z偶・k奇の枝）から \(H(R;X;z)=1\)。一方、単一トークン \(S=R-1\) は \(z=S-1\) の中間枝にあり、\(v(R-1,R-2,R)=(2R-2)\bmod2=0\)。

従って全 \(X\) に一様な低R縮約条件として、\(R\ge3\) での \(z\ge R-1\) は鋭い。これは個々の \(X\) について必要条件だという主張ではない。

## 既知tailとの接続

既存のtail補題
\[
R\ge S+|X|+z-1\quad\Longrightarrow\quad H(R;X;z)=S\bmod2
\]
と今回の低R縮約を合わせる。\(X\ne\varnothing\) を固定すると、一般多重集合として追加解析が必要な残容量は
\[
\boxed{z+2\le R\le S+|X|+z-2}
\]
に限られる。幅は
\[
S+|X|-3
\]
で、zに依存しない。従来の十分条件 \(z\ge S+R-1\) から得ていた帯より、下端が \(z-S+2\) から \(z+2\) へ上がる。特に2トークン族では未解決帯の幅は \(S-1\) まで縮む。

- 完了手の値が \(\kappa=1\) の残余ゲームに限る。
