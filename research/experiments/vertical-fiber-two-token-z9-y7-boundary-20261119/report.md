# 2トークン残余ゲーム z=9・y=7 の全Grundy分類（K0996）

- 日付: 2026-11-19
- 対象: H(R;(x,7);9)、全 x>=7・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0994（z=9,y=6）、K0995（z=8,y=7）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

全てのx>=7・R>=0で、H(R;(x,7);9)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailは

    R >= x+17  =>  H(R;(x,7);9) = (x+7) mod 2.

値2の定常位置は{1,3,5,7,9,23}。x=17だけはO[23,33]が一時的に加わる（掃引行）。z=9族の定常第6点はz+2yで、y=1..7では11,13,15,17,19,21,23が7点連続で成立する。x=8,12,16では第6点が19,21,23と4間隔で前倒しに現れ、x>=18で23に定着する。前倒し行はy=6ではx=7,11,15と奇数行だったが、y=7ではx=8,12,16と偶数行へ反転した（掃引行x=z+y+1がyの偶奇とともに動き、前倒し行も同じ向きで反転する）。値1の頭部E[10,22]={10,12,14,16,18,20,22}=z+1+2i (i=0..6)はz=9族のy=1..7各切片を貫く偶数帯で、中間帯は奇数帯O[25,x+16]/O[25,x+17]、tailが1になる側（y=7ではx偶数行）にI[x+18,∞)が付く。K0994ではI帯はx奇数行に付いたため、I帯の行がyの偶奇で交互する観察がz=9族でも1延長で確認され、z=8族のK0993(y=6,奇数行)→K0995(y=7,偶数行)の反転と同じ向きの2族目の延長となった。x=17の掃引帯は掃引位置x=z+y+1と掃引範囲O[z+2y,z+2y+10]の族公式どおり。tailの閾値R>=x+17はK0832の一般tail（R>=x+y+z+1でH=(x+y) mod 2）のy=7,z=9の場合に一致する。x=18はA子が掃引行x=17を横切る署名上の過渡行（偶数帯E[26,34]の署名12だけが定常と異なる）で、署名の定常はx>=19奇/x>=20偶から始まる。

## 証明

R=0は終局で値0。R>=1,x>=8の選択肢は

    A = H(R-1;(x-1,7);9)
    B = H(R-1;(x,6);9)
    C = 1 xor H(R-1;(x,7);8)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0994、CはK0995で評価できる。x=7では二つのトークン減少手が同じ(x,6)子（最大トークン7）に合流するため、A=B=K0994のx=7行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

各行はAに帰納仮説、BにK0994、CにK0995を代入した子値集合である。x>=19奇数行とx>=20偶数行では、帯端だけがxに依存し、署名は一定である。x=17は掃引行（掃引帯O[23,33]の署名01・mex 2が値2掃引帯を作る）、x=18はA子が掃引行x=17の掃引帯を横切る過渡行で、偶数帯E[26,34]（署名12・mex 0）の分割だけが定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+16を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+17ではK0832の高R tail定理を各子に適用できる。x偶数ならA=B=C=0で親値1、x奇数ならA=B=C=1で親値0となり、親tail (x+7) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=9,y=7切片のみを扱う。z=8のy>=8、z=9のy>=8、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=9族の定常第6点 z+2y の一般化（y=1..7の7点連続）、第6点の前倒し配置のy偶奇反転（y=6奇数行→y=7偶数行）、I帯のy偶奇交互は観察であり証明ではない。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
