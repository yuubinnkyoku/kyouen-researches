# 7行 q=4 の2石交換で 7×59 行欠損極大配置を構成

Date: 2026-11-15  
対象: 標準整数格子 7×m、共線4点・共円4点禁止（q=4）  
位置づけ: **7×59 の具体証人 + 指定した2-for-2近傍の完全列挙**。7×60 の不存在証明ではない。

## 新しい下界

既存の K0827 は 7×56 まで行欠損極大安全配置を持ち、M_{7,4} >= 57 だった。幅53の20石証人に対する2石交換を完全列挙したところ、7×57上で安全かつ行欠損極大となる配置が2個見つかった。その一つは幅59まで空列延伸できる。

\[
\boxed{60\le M_{7,4}\le1929}
\]

幅59の具体的な行欠損極大配置による下界であり、閾値の確定ではない。

## 構成

幅53の基礎配置から (28,2),(36,4) を除き、(56,2),(7,4) を追加する。石数20、行占有数は [3,3,3,3,3,3,2]。全座標は output/witness_7x59.json に保存した。

## 7×59 の厳密検証

Python検証器はC++列挙器と独立に、正規化した整数直線・円の方程式で検査する。浮動小数点は使わない。

- 最大共線点数3、最大共円点数3。
- 行0〜5は各3石の水平直線で全空点が遮断される。
- 行6の57空セル x=0..58 は全て直線または円で遮断される。
- (57,6) は直線 x-6y-21=0（証人 (21,0),(27,1),(39,3)）。
- (58,6) は円 3(x²+y²)-307x+611y+3940=0（証人 (18,1),(25,3),(35,5)）。
- (59,6) は未遮断。単純な空列延伸は幅60で止まる。

## 2-for-2近傍の完全列挙

候補は元の幅53証人から2石を除き、元の空セル2つを加える全ての置換で、最終行占有数が各行3以下のもの。20石・7行・容量3なので必ず [3,3,3,3,3,3,2] 型。

安全性は、追加点が0/1/2個の4点組に分けて判定する。0個は元の安全配置の部分集合。1個の場合は追加点ごとの危険な旧3点組、2個の場合は追加点対ごとの危険な旧2点組を事前列挙し、除去した2点を避けて残る危険組数を包除原理で O(1) 判定する。共線・共円判定は整数外積と4点行列式で行う。安全候補の極大性は欠損行の全空セルを候補20点の全3点組で直接検査する。

| 基礎配置 | 幅 | 行容量候補 | 安全候補 | 安全かつ行欠損極大 |
|---|---:|---:|---:|---:|
| 幅53の元証人 | 57 | 1,436,643 | 60,921 | **2** |
| 幅53の元証人 | 60 | 1,599,648 | 83,225 | 0 |
| 新しい幅59証人 | 60 | 1,599,648 | 110,748 | 0 |

7×57で得た2配置は両方とも独立Python検証器で再確認した。幅60の結果は指定した2つの近傍に限り、全盤面の不存在を意味しない。
