# 固定欠損の極大配置係数は固定パラメータ容易（2026-11-03）

## 定理（全称証明）

K0602・K0648 のグラフ星型共円構成について、任意の有限単純グラフ G=(V,E)、e=|E|≥1、禁止点数 q≥4、欠損 d≥0 を入力とする。n=|V|、r=q−3、N=1+n+re、s=N−e とする。

**s+d 石の極大安全配置の個数は f(d)(n+e) 回の有理数・整数演算で厳密に計算できる。** f は d のみの計算可能関数であり、d を固定しない場合も同じパラメータ依存のアルゴリズムが動く。従来の K0648 の O(f(d)n^d(n+e)) から、n の指数に d が現れない固定パラメータ容易（FPT）に改善する。ビット演算量をこの式で上界づける主張ではない。e=0 は唯一の全点終局で直接処理する。

## 証明

K0648 の記号を用いる。H は次数2以上の頂点、L は高次数頂点に隣接する葉数、h は K₂ 成分数、C=e−L−h。許容核 B⊆H は、各 v∈B が B 外に隣接点を持つ集合であり、d(B)=Σ_{v∈B}(deg(v)−1)−e_G(B)、a(B) は B に隣接する葉数とする。

K0648 により、空核を含めた中心付き終局の係数は、基底係数

A=(r+2)^h r^C (r+1)^L

に、許容核 B の重み

W(B)=r^{a(B)−|B|−d(B)}(r+1)^{−a(B)}

を掛けて足したものとなる。許容核 B を誘導連結成分 B₁,…,B_t に分解すると、成分間に辺がなく、d(B)=Σd(B_i)、a(B)=Σa(B_i)、W(B)=∏W(B_i) である。各非空成分の欠損は正整数。

**候補の個数と競合次数の上界。** 欠損 d 以下の連結許容核の全体を集合 U とする。K0648 より各候補は高々2d頂点で構成され、各頂点の次数は高々 d+1。連結集合を一頂点から順に拡張すれば、候補数 |U|≤f₀(d)n で列挙できる。途中の集合 B'⊆B（最終的に許容な B）では、追加頂点の B' 外次数が1以上なので、欠損は拡張に伴って減少しない。従って d を超えた枝を捨てても候補は失われない。

候補 B_i,B_j が頂点を共有するか、間に辺があるとき競合すると定め、競合グラフ J を作る。各候補は高々2d頂点、各頂点の元グラフ次数は高々 d+1 である。ある候補に競合する別候補は、その候補の頂点または隣接頂点を少なくとも一つ含む。元グラフの任意の頂点を含む候補数も f₁(d) 以下（その頂点を根とする連結集合の列挙上界）だから、J の最大次数 Δ(J)≤f₂(d)。逆引き索引を使えば J を f₃(d)(n+e) 回の演算で構成できる。

各候補 i∈U に、正の次数 d_i=d(B_i) と有理重み w_i=W(B_i) を付ける。重み付き独立集合多項式

Z_J(z)=Σ_{I⊆U : IはJの独立集合} ∏_{i∈I}(w_i z^{d_i})

の z^d 係数を求めれば、求める答えは

[u^{s+d}]P_{G,q}(u) = A[z^d]Z_J(z) + 1_{d=e−1}

となる。最後の項は中心を含まない唯一の終局である。

**対数の連結支持展開。** J の任意の誘導部分グラフ J[T] に対し F(T;z)=log Z_{J[T]}(z) を、定数項0の形式的冪級数として定義する。空集合なら F=0。非空 S⊆U に

c(S;z)=Σ_{T⊆S}(−1)^{|S|−|T|}F(T;z)

を定める。包除原理により log Z_J(z)=Σ_{S⊆U}c(S;z)。

S が J 上で非連結なら、S=A⊔B と分けて両者間に競合辺がない。任意の T⊆S について F(T)=F(T∩A)+F(T∩B) なので、包除和は相殺し c(S)=0。

また [z^j]c(S)=0（j<|S|）。実際、log Z の冪級数展開の各項は候補の重みを正次数で掛けたものなので、j 次以下の項に現れる相異なる候補は高々 j 個である。包除和で S のすべての候補が現れない項は相殺する。

従って log Z_J(z) の d 次以下は、**J 上の連結集合 S で |S|≤d のものだけ**を足せば求まる。J の最大次数が f₂(d) なので、これらの集合は高々 f₄(d)|U| 個であり、連結拡張で列挙できる。各 S の c(S) は高々2^d個の T を調べ、各 T の Z_{J[T]} を高々2^d個の独立集合から厳密に計算し、形式的対数を d 次で打ち切ればよい。従って全体で f₅(d)(n+e) 回の有理数演算で log Z_J mod z^{d+1} が得られる。

最後に Z_J=exp(log Z_J) を d 次まで復元する。係数 l_j=[z^j]log Z_J、p_0=1、p_k=[z^k]Z_J とおくと

k p_k = Σ_{j=1}^k j l_j p_{k−j}

により O(d²) 回で復元できる。A を掛け、中心なしの項を加えると所望の整数となる。以上により f(d)(n+e) 回の算術演算で計算できる。□

## 独立検証と境界

verify.py は、上記の連結支持・包除・形式的対数を用いる方式と、支配条件を満たす削除集合 X⊆V を全列挙し r^{e_G(V\X)} を直接加算する方式を独立に実装した。n≤5 の全ラベル付き単純グラフ（辺あり）および n=6,7,8 の決定的標本、q=4,5,6,8、d=0..3 の計13,047係数で一致、不一致0。さらに1000頂点の道（d=2）も大域的な頂点部分集合列挙なしに実行した。これらの有限検査は全称証明の代わりではない。

これは K0602 の構成族に限る。標準 n×n 全格子盤の s_n、K_n、11×11 の勝敗への直接の結論ではない。単位算術演算の FPT であり、q や出力整数のビット長を含めた厳密なビット計算量は別途評価が必要である。
