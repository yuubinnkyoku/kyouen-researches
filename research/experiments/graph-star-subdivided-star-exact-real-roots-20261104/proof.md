# 一辺細分星の実根数を厳密決定する二つの領域（2026-11-04）

## 前提
main の `research/experiments/graph-star-subdivided-star-root-count-20261104/proof.md` の多項式
```
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1},
k>=3, r=q-3>=1
```
を扱う。標準格子盤ではなく K0648 のグラフ星型構成である。

## 新定理 A（全称証明）
**偶数 k>=4、r>=2（q>=5）では、T は相異なる負の実根をちょうど1個持ち、それは単根である。** よって非実根は重複度込みで **ちょうど k 個**。

証明。x>0 とし、k が偶数なので
```
T(-x)=x^k(r+2-x)+(r+1)^k(r(r+1)-x).
```
r>=2 なら r(r+1)>=r+2。0<x<=r+2 では両項が非負で、同時には0にならない（r=2 でも x=r+2 のとき第二項は0だが第一項も0となる！）。
**境界例の修正:** r=2 では r(r+1)=6 > r+2=4 なので等号は生じない。実際 r(r+1)-(r+2)=r²-2>0。
従って 0<x<=r+2 で T(-x)>0。
x>r+2 では第一項の導関数 x^{k-1}[k(r+2)-(k+1)x]<0、第二項の導関数は -(r+1)^k<0。ゆえに T(-x) はこの区間で厳密減少し、r+2 で正、無限遠で負なので、ちょうど一つの単根を持つ。非負の u に根はない。証明終。

## 新定理 B（全称証明）
**奇数 k>=3、r=1（q=4）では、T は相異なる負の実根をちょうど2個持ち、いずれも単根である。** よって非実根は重複度込みで **ちょうど k-1 個**。

証明。奇数 k に対して
```
T(-x)=x^k(x-r-2)+(r+1)^k(r(r+1)-x).
```
r=1 では T(0)=2^{k+1}>0、T(-2)=-2^k<0、x→∞ で T(-x)→+∞。従って x∈(0,2) と x∈(2,∞) に少なくとも一つずつ相異なる正の零点がある。一方、降冪の符号列は +,-,-,+ で、デカルトの符号法則により重複度込みで高々2個。ゆえに両根は単根で、ほかに実根はない。証明終。

## 検証・境界
代数式は前記の T に u=-x を代入して独立に展開した。k=4,6,8・r=2,3 と k=3,5,7・r=1 の数値根の個数とも照合できるが、証明は数値計算に依存しない。偶数 k・r=1 および奇数 k・r>=2 の厳密分類はここでは主張しない。

既存のデカルト上界（偶数 k は実根高々3、奇数 k は高々2）を、上記二領域で等号を含めて厳密化した。
