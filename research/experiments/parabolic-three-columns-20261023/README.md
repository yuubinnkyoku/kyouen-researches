# 放物線型4点禁止ゲーム：三列の全長・全局面定理

2026-10-23。禁止条件は相異なる4点について
`det[[x²,x,y,1]] = 0`（二次形式係数 `λ=0`）。
退化配置も禁止する。**標準の共円ゲームではない。**

## 全称定理

相異なる実数 `x_0,x_1,x_2` 上の3本の鉛直列に、それぞれ相異なる実数の高さを
`a_0,a_1,a_2 >= 1` 個置く。高さの間隔は任意でよい。
`N=a_0+a_1+a_2`、`c_i(S)` を列ごとの占有数とする。

* 安全な4点集合は、占有数が `(2,1,1)` の順列であるものに**ちょうど**一致する。
  安全な5点集合は存在しない。
* `k<=3` の安全局面数は `C(N,k)`、4点安全局面数は
  `sum_i C(a_i,2) prod_{j!=i} a_j`。
* `N>=4` では最大安全石数 `K=4`。極大配置は安全4点集合と、
  同じ列に3点を持つ3点集合だけ。したがって
  `s=3` iff `max(a_i)>=3`、それ以外は `s=4`。
* `N>=4` の任意の安全局面 `S` のGrundy値は次の通り。

| 局面 | g(S) |
|---|---:|
| 空盤 | 0 |
| 1石 | 1 |
| 同じ列に2石、かつその列の容量が3以上 | 2 |
| その他の2石 | 0 |
| 同じ列に3石 | 0 |
| その他の3石 | 1 |
| 4石 | 0 |

`N=3` のときは3点すべて自由で `g(S)=(3-|S|) mod 2`。

特に通常の `3×m` 格子（3本の列それぞれにm点）では、
**空盤はm=1で先手勝ち、すべてのm>=2で後手勝ち**。
m>=3の極大配置は3石が `3*C(m,3)` 個、
4石が `3*C(m,2)*m²` 個。m>=3の全局面最大nimberは2。

## 証明

4点が1本または2本の列だけにある場合、`x²` はその2種類以下のx上で
`x` と定数の一次結合となり、行列式は0。
同じ列に3点がある場合、対応する3行は高々2次元を張るため、
第4行を加えても行列式は0。
したがって安全な4点の占有数は `(2,1,1)` に限られる。

逆に同列2点の高さをy,y'とすると、その2行を引き算した余因子展開から、
4点行列式は符号を除いて
`(y'-y)(x_1-x_0)(x_2-x_0)(x_2-x_1)`。
高さと列位置は相異なるので非零。4点の必要十分条件が得られる。
5点を置けば必ず、2列以下の4点または同列3点を含む4点ができる。

4点安全局面は終端。3点では同列3点だけが終端であり、
その他の占有数 `(2,1,0)` と `(1,1,1)` は、
`N>=4` のもとで `(2,1,1)` に拡張できるのでGrundy値1。
同列2点で列容量が3以上なら、Grundy値0の同列3点と
Grundy値1の `(2,1,0)` の両方へ進め、mexは2。
それ以外の2点からはGrundy値1の3点にしか進めずmexは0。
1点からは0の2点へ進めるが1の2点は存在せずmexは1。
空盤からは1の1点にしか進めずmexは0。
`N=3` は全点自由な3手ゲームなので偶奇式となる。□

## 独立検証

```sh
g++ -std=c++17 -O3 verify.cpp -o /tmp/verify-parabolic
/tmp/verify-parabolic 7
python3 verify_irregular.py
```

* `verify.cpp`: 4×4行列式の置換展開で禁止組を独立生成し、
  `m=1..7` の全 `2^(3m)` 部分集合から全安全局面のmexと極大分布を検査。
* `verify_irregular.py`: 別実装の再帰mexと整数行列式で、
  列位置・高さ間隔・列容量が不揃いな6盤の全安全局面を検査。

これらは**有限完全列挙による独立監査**であり、無界の結論の根拠は上記の数学的証明。
現行知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。
