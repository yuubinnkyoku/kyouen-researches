# 2トークン残余ゲーム z=7・y=1 境界切片の全Grundy分類（K0977）

- 日付: 2026-11-19
- 対象: 抽象残余ゲーム H(R;(x,y);z)（R手残余・トークン多重集合 X、通常値 z、周期基底 S）のうち、2トークン X=(x,1)・z=7・境界 y=1 のスライス。全 x≥1・全 R≥0。
- 状態: **全称定理（全x・全Rで証明済み）**
- 関連: K0832（残余ゲームHの再帰・Theorem T・単一トークン全z公式・tail定理・高さのみ縮約）、K0877（z=6・y=1境界切片の全Grundy分類）、K0976（z=7・y≥4の有限予想。y=1,2,3の基底切片を全称証明に必要として明示）

## 記法

- V₆(R) を x=1、一般に V_x(R) を位置 (R;(x,1);7) の選択肢（子のGrundy値）の集合と書く。
- O[a,b]={n: a≤n≤b, n奇}, E[a,b]={n: a≤n≤b, n偶}, I[a,∞)={n: n≥a}。
- 署名は子の値集合の昇順文字列: 01={0,1}, 23={2,3}, 03={0,3}, 02={0,2}, 13={1,3}, 12={1,2}, 023={0,2,3}, 123={1,2,3}, 0={0}, 1={1}。

## 主定理

**値2位置（H=2となるRの集合 T₇⁽¹⁾(x)）:**

残りは値0。R=0 は常に H=0。tail は **R≥x+9 ⟹ H=(x+1) mod 2** であり、K0832 の一般tail定理（2トークンでは R≥S+z+1=x+9）と整合する。

R≤8 の値は高さのみ縮約定理（K0832: H(R;X;z)=v(S,|X|... z, R)、ここでは H=v(x+1,7,R)）で全 x について一意に決まり、上表の R≤8 部分と一致する（値2がR∈{1,3,5,7}、値1がR=8、R∈{2,4,6}は値0）。x依存の構造は R=9 以降に現れる。

## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,1) における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,1);7)
- **B手**（値1のトークンを除去、通常値は z+1=8）: 子 = H(R−1;(x);8)（単一トークン）
- **C手**（z を 7→6 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,1);6)

x=1 では X=(1,1) で A手が存在せず、2本の除去手は同一の子 (1);8 に帰着する（B手とC手のみ）。

子の値はそれぞれ既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K0832 の単一トークン z=8 公式、C子は K0877 の z=6・y=1 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** 本証明で使う既証明の公式:

- 単一トークン v(x,8,r)（K0832）: x≤7 は z≥x+1 枠、x=8 は z=x 枠、x≥9 は 1≤z≤x−1 枠（m=7, L−1=x+8）。特に x≥9 では r≤7 の奇偶で {2,0}、8≤r≤x+7 で (r+8) mod 2、r≥x+8 で x mod 2。
- z=6・y=1（K0877）: x≥9 の定常値域 T₆={1,3,5,9}、P₆(x) は x 奇数で {7}∪E[10,x+7]、x 偶数で {7}∪E[10,x+6]∪I[x+8,∞)。C子の値は 1⊕h₆(x,r) で h₆∈{0,1,2} に対し {1,0,3} に写る。

**Step 3（署名帯表）.** V₆..V₁₀ は個別に、x≥11 は奇偶2行の定常形に落ちる。全 x≥1 で各行が R≥1 を矛盾なく被覆する。r=R−1 と書くと各帯は v(cand(x−1,r)), v_single(x,8,r), 1⊕h₆(x,r) の3値の代入で確定する（後述の機械監査 V3 が x≤2000・2,049,000点で照合）。

帯の現れ方の根拠（定常行の導出、x≥12 偶数行の全帯。r=R−1）:

- 奇数R∈{1,3,5,7}: r 偶数≤6 は T_A∪P_A 外で A=0、B子も r≤7 偶で0、C=1⊕h₆=1（r∉T₆∪P₆）。V={0,1}、値2。
- 偶数R∈{2,4,6}: r∈{1,3,5}⊂T_A で A=2、B子 r 奇≤7 で2、C=1⊕2=3。V={2,3}、値0。
- R=8: r=7∈T_A で A=2、B=2、C=1⊕1=0（7∈P₆）。V={0,2}、値1。
- R=9: A=1（r=8∈P_A(x−1奇)={8}∪O[11,x+7]）、B=(8+8)mod2=0、C=1（r=8∉T₆∪P₆）。V={0,1}、値2。
- R=10: A=2（r=9∈T_A）、B=(9+8)mod2=1、C=1⊕2=3。V={1,2,3}、値0。
- 奇数R∈O[11,x+9]（r 偶数∈E[10,x+8]）: A=0（P_A に偶数帯なし）、B=0（中間帯 (r+8)mod 2、r=x+8 では x mod 2=0）、C=0（r∈E[10,x+6]∪I[x+8,∞)⊆P₆）。V={0}、値1。
- 偶数R∈E[12,x+8]（r 奇数∈O[11,x+7]）: A=1（r∈O[11,x+7]=P_A の奇数帯）、B=1（中間帯 r 奇）、C=1（r 奇数≤x+7 は T₆∪P₆ 外）。V={1}、値0。
- R≥x+10（r≥x+9）: A=0（子のtail域）、B=x mod 2=0、C=0（r∈I[x+8,∞)⊆P₆）。V={0}、値1。

この導出は x≥12 の全偶数について一様に成り立つ（使っているのは子公式の帯境界が x の1次式であることのみ）。x≥11 奇数行も同様で、子側の境界 (x−1)+8=x+7 などが親側の x+8, x+9 に +1 リフトされて定常行が閉じる。x=1..10 の個別行は同じ代入をそのまま実行したものである。

**Step 4（mex評価と Theorem T）.** K0832 の Theorem T（1手進むと残余手数の偶奇が反転し、偶数R位置の子は全て偶数値、奇数R位置の子はrea奇数値を持つ）により、本ゲームの値は偶数Rで ⊆{0,1}、奇数Rで ⊆{0,1,2} に抑えられる。実際、上表の署名に mex を施すと次の一意対応で値が決まる:

| 署名 | {0,1} | {2,3} | {0,3} | {0,2} | {1} | {0} | {1,3} | {1,2} | {0,2,3} | {1,2,3} |
|---|---|---|---|---|---|---|---|---|---|---|
| 値 | 2 | 0 | 1 | 1 | 0 | 1 | 0 | 0 | 1 | 0 |

この規則を Step 3 の帯表に機械適用すると主定理の T₇⁽¹⁾/P₇⁽¹⁾ が正確に再構成される（例: x=9 の O[11,17]:01 → 値2 が T(9)=O[1,17] を与え、x≥12偶 の E[12,x+8]:1 → 値0 が P を除外する偶数帯を与え、x≥12偶 の R≥x+10:{0} → 値1 が P の I[x+10,∞) を与える）。

**Step 5（tail整合）.** 定常行の末帯で V は偶奇2値に退化し、R≥x+9 で H=(x+1) mod 2 となる。これは K0832 の一般tail定理の 2トークン・z=7 場合（R≥S+z+1=x+9、H=S mod 2=x+1 mod 2）と独立に一致する。 □

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は z=6（K0877）の {1,3,5,9} に対し z=7 では {1,3,5,7,9}。奇数R∈{1,3,5,7}では A=B=0・C=1 で V={0,1}、R=9では A=1（子スライスで 8∈P_A）・B=0・C=1 で V={0,1} となり mex=2 が揃う。
- x=9 例外 T₉=O[1,17] の機構: x=9 では A子がスライス x−1=8、その P₈={8}∪I[10,∞) は無限帯なので r=R−1 偶数≥10 で常に A=1。R 奇数∈O[11,17]（r∈E[10,16]⊆P₆(9) の偶数帯）では B=0・C=0 が揃い V={0,1} で値2が続き、r>16 では C が 1 に転じて値0に落ちる。x≥11 奇数では A子スライス x−1 が偶数≥10 となり P の値1帯が有限の O 帯へ替わるため、この延長が起きずTは {1,3,5,7,9} で止まる。
- 値1位置の低次構造は z=6 の {7}∪E[10,..] 型に対し z=7 では {8}∪O[11,..] 型と偶奇が反転する。C子の 1⊕ 反転が効いている。
- x=1..8 の各行は高さのみ縮約の値域そのもの（R≤8）+ R≥9 以降の tail にしかならず、P の「I[a,∞) 全体」型（x∈{2,4,6,8}）は、残余手数が十分大きいと偶奇構造が平坦化して値1に固定されることを示す。

## 適用範囲と限界

- 本定理は **z=7・y=1 の境界切片のみ**。z=7 の y=2,3 は未証明であり、K0976 の y≥4 有限予想と併せても z=7 全高さの統一は未解決。
- z≥8・y≥1 の全Grundy閉形式は未解決。
- 有限監査（V1..V9）は検証手段であり、定理の主張は上記 Step 1..5 の帰納構成による。監査は帯表の転写ミス・実装バグの検出を目的とする。
- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
