# 残余23行の被覆下界強化と8根ILPの縮約（2026-11-20）

## 発見

K1097の残余23行再解決は、旧記録では全safe8母集団の最大被覆4を使い、
\(\lceil 23/4\rceil=6\) を下界としていた。これは正しいが、REFUTED-D10を
50根除外した実際の候補pool P'''に対しては粗い。

K1097の正本と、safe8全120,474根を別実装で全数再検査したK1102の正本を
SHA-256で固定して照合した。残余23行に触れるproviderの被覆数分布は両者で一致する。

| 1根が覆う残余行数 | provider根数 |
|---:|---:|
| 1 | 40,065 |
| 2 | 4,857 |
| 3 | 297 |
| **合計** | **45,219** |

最大被覆は3行なので、23行を覆うには少なくとも
\(\lceil 23/3\rceil=8\) 根が必要となる。既存greedy計画は9根で全23行を
被覆しているため、候補根数の最小値は **8または9** に絞られた。
旧下界6は誤りではなく、今回のpoolに対する強い上界情報を使っていなかっただけである。

WIN16候補の内在被覆は残余23行と交差しない。したがって、WIN16を取り除く
scope2でもprovider分布は変わらず、同じ下界8が成り立つ。

## 8根被覆の形と縮約

8根で23行を覆う場合、単独で1行しか覆わないproviderは使えない。
また、2行providerを2根以上使うと最大22行しか覆えない。よって可能性は次の二つだけ。

1. 3行providerを8根選び、全24 membershipのうちちょうど1行だけが重複する。
2. 3行providerを7根、2行providerを1根選び、23行を重複なく覆う。

この条件から、8根被覆の判定に必要な候補は、45,219根をそのまま扱う必要がない。
1行provider 40,065根は除外できる。2行providerは23行から作れる部分集合が最大253通り、
3行providerは実在根が297本しかないため、被覆パターン変数は **最大550個**、
行制約は23本に縮められる。根単位の45,219候補から少なくとも82分の1の規模で
8根被覆の可否を調べられる。

## 次の課題

最大550パターンへ重複を除いて縮約し、8根被覆の可否を厳密に判定する。
不可能なら9根greedy計画がこの候補poolで最小だと確定できる。可能なら、その8根を
次のdepth-10候補選定に回せる。ただし候補被覆は証明書ではない。

**ゲームの勝敗・S6行の閉鎖は一切主張しない。標準11×11空盤、二石root
