# \(t=2,\ q=4\) 純ファイバーゲームの全局面Grundy分類

## 設定

有限集合 \(B\)、高さ集合 \(A\) を取り、\(w=|B|\ge2,\ m=|A|\ge2\) とする。底面跡制約は置かず、各ファイバー上で零多項式にならない \(z\) 次数2以下の多項式超曲面による4点共存を禁止する。

K0832の厳密占有縮約により、安全条件は
\[
C(c):=\sum_{b\in B}\min(c_b,2)\le3
\]
であり、着手は一成分を1増やす操作と一致する。

安全状態の正占有数の多重集合は、空 \(()\)、単独列 \((a)\)、二列 \((1,b)\)、三単独列 \((1,1,1)\) に限られる。二列なら少なくとも一方の占有数は1、三列なら全て1、四列は容量4で不安全である。

## 定理

Grundy値は占有数の多重集合だけで決まり、次で完全に与えられる。

| 占有数の形 | Grundy値 |
|---|---:|
| \(()\) | \((m+1)\bmod2\) |
| \((a)\), \(1\le a\le m\) | \((m-a+1)\bmod2\) |
| \((1,b)\), \(2\le b\le m\) | \((m-b)\bmod2\) |
| \((1,1)\), \(w=2\) | \((m+1)\bmod2\) |
| \((1,1)\), \(w\ge3\) | \(m\) 偶数なら1、奇数なら2 |
| \((1,1,1)\), \(w\ge3\) | 0 |

従って
\[
\boxed{\max G=
\begin{cases}
1&w=2,\\
1&w\ge3,\ m\text{ 偶数},\\
2&w\ge3,\ m\text{ 奇数}.
\end{cases}}
\]
特に \(w\ge3\) ではGrundy値2が現れる必要十分条件は \(m\) が奇数である。

## 証明

\(p_b=(m-b)\bmod2\) と置く。\((1,b)\) で \(b\ge2\) は容量3を使い切っているため、単独石を2にする手も新しい列を始める手も不合法である。\(b\) の列を進める鎖だけなので \(G(1,b)=p_b\)。

\((1,1,1)\) も容量3を使い切り、どの手も容量4になるため終局で \(G(1,1,1)=0\)。

\((1,1)\) からは \((1,2)\) へ移れる。さらに \(w\ge3\) なら \((1,1,1)\) へも移れる。従って
\[
G(1,1)=
\begin{cases}
\operatorname{mex}\{p_2\}&w=2,\\
\operatorname{mex}\{p_2,0\}&w\ge3.
\end{cases}
\]
\(p_2=(m-2)\bmod2\) を代入すると定理の値になる。

単独列について \(A_a=G(a)\) と置く。\(a\ge2\) では、同じ列を進める手と第二列を始める手だけがあり、後者の子は \((1,a)\) で値 \(p_a\)。終端 \(A_m=\operatorname{mex}\{0\}=1\)。後ろ向き帰納法により、\(2\le a<m\) では二つの子値がともに \(p_a\) なので
\[
A_a=\operatorname{mex}\{p_a,p_a\}=1-p_a=(m-a+1)\bmod2.
\]
\(a=1\) では子が \((2)\) と \((1,1)\)。上の式を代入すると、\(w=2\) と \(w\ge3\) のいずれでも \(A_1=m\bmod2\)。空局面の全ての子は同じ値なので \(G(())=(m+1)\bmod2\)。以上で全型を覆った。∎

## 最小のGrundy値2の局面

\[
w=3,\quad m=3,\quad c=(1,1,0)
\]
では合法な子は \((2,1,0)\) と \((1,1,1)\)。前者の値は1、後者は終局で0。従って
\[
G(1,1,0)=\operatorname{mex}\{0,1\}=2.
\]
\(w=2\) では第三列を開始できず、\(m\) 偶数でも上の分類から全値は0または1。よって \(w,m\ge2\) の範囲で最小の証人は \(3\times3\)。

## 有限監査

二つの独立表現で再帰mexを実行した。

1. ラベル付き占有ベクトルを直接列挙し、容量を保つ一成分増加を生成。
2. 正占有数を昇順に並べた多重集合で、既存列の増加と新列開始から遷移を独立生成。

範囲は \(2\le w\le12,\ 2\le m\le20\) の209パラメータ組。ラベル付き表現は144,001状態、多重集合表現は4,997状態。両方式とも閉形式との不一致0。

ラベル付き状態数は
\[
1+wm+\binom w2(2m-1)+\binom w3\quad(w\ge3),
\]
\(w=2\) では \(1+2m+(2m-1)=4m\)。多重集合状態数は \(1+2m+\mathbf1_{w\ge3}\)。検証器のSHA-256は監査JSONに記録した。

有限監査は再帰実装の照合であり、全称性は上記の型分類とmex帰納証明による。

## 適用範囲と限界

- 底面跡制約なし、\(t=2,q=4,w\ge2,m\ge2\)。
- K0832の各ファイバー上で零多項式にならない条件を維持する。
- \(w=1\)、\(m=1\)、底面跡制約ありにはこの表をそのまま適用しない。
- 抽象ファイバー多項式ゲームの定理であり、標準二次元の3×m・q=4幾何ゲームそのものの解決ではない。
