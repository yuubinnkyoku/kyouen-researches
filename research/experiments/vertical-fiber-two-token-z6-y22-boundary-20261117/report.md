# 2トークン残余ゲーム z=6, y=22 切片の全Grundy分類

## 定理

対象は H(R; (x,22); 6), x≥22, R≥0。Grundy値は常に 0,1,2 である。値2となる残容量は

T₂₂(x) = {1,3,5} ∪
- x=22: {47}
- x=26: {49}
- x=29: {51,53,55,57}
- x≥30: {51}
- その他: 追加なし

奇数・偶数の区間を O[a,b], E[a,b] と書き、上端 ∞ も許す。値1となる残容量は

P₂₂(x) =
- x=22: O[7,45]
- x=23: O[7,∞) ∪ E[48,∞)
- x=24: O[7,47]
- x=25: O[7,∞) ∪ E[50,∞)
- x=26: O[7,47]
- x=27: O[7,∞) ∪ E[50,∞)
- x=28: O[7,49]
- x≥29 が奇数: O[7,49] ∪ E[52,∞) ∪ O[x+30,∞)
- x≥30 が偶数: O[7,49] ∪ E[52,x+28]

値0の位置は T₂₂(x) と P₂₂(x) の補集合である。K0832の一般tail定理から

**R≥x+29 なら H(R;(x,22);6)=(x+22) mod 2**

も成り立つ。

## 再帰と依存

親の選択肢値を

- A = H(R−1; (x−1,22); 6)
- B = H(R−1; (x,21); 6)
- C = 1 xor H(R−1; (x,22); 5)

とする。

x=22ではAの子 (21,22) は降順正準化で (22,21) となり、Bの子と同一状態になるためK0914で評価できる。x≥23ではAを同じ y=22 切片のR強帰納仮説、BをK0914、CをK0873のz=5全Grundy公式で評価する。

K0832のTheorem Tにより、奇数Rの親では選択肢値が {0,1} に含まれ、偶数Rの親のGrundy値は高々1である。従って、

- 奇数Rでは署名 {0,1}, {0}, {1} のmexはそれぞれ 2,1,0。
- 偶数Rでは署名に0が含まれるときだけ親値が1となり、含まれなければ0。

## 選択肢署名表

各欄は {A,B,C} の値集合である。区間端点を含み、奇数R列では奇数だけ、偶数R列では偶数だけを読む。表は 1≤R≤x+28 を覆う。

| x | 奇数Rの署名 | 偶数Rの署名 |
|---:|---|---|
| 22 | 1..5:{0,1}; 7..45:{0}; 47:{0,1}; 49:{1} | 2..6:{2,3}; 8..50:{1} |
| 23 | 1..5:{0,1}; 7..51:{0} | 2..6:{2,3}; 8..46:{1}; 48:{0,2,3}; 50:{0} |
| 24 | 1..5:{0,1}; 7..47:{0}; 49..51:{1} | 2..6:{2,3}; 8..52:{1} |
| 25 | 1..5:{0,1}; 7..53:{0} | 2..6:{2,3}; 8..46:{1}; 48:{1,2}; 50..52:{0} |
| 26 | 1..5:{0,1}; 7..47:{0}; 49:{0,1}; 51..53:{1} | 2..6:{2,3}; 8..54:{1} |
| 27 | 1..5:{0,1}; 7..55:{0} | 2..6:{2,3}; 8..48:{1}; 50:{0,2,3}; 52..54:{0} |
| 28 | 1..5:{0,1}; 7..49:{0}; 51..55:{1} | 2..6:{2,3}; 8..48:{1}; 50..56:{1,2,3} |
| 29 | 1..5:{0,1}; 7..49:{0}; 51..57:{0,1} | 2..6:{2,3}; 8..48:{1}; 50:{1,2,3}; 52..56:{0} |

| x≥31 | 1..5:{0,1}; 7..49:{0}; 51:{0,1}; 53..Uo:{1} | 2..6:{2,3}; 8..48:{1}; 50:{1,2,3}; 52:{0,2}; 54..Ue:{0} |

最終行の端点は
- Uo=x+28 (x奇数)、x+27 (x偶数)
- Ue=x+27 (x奇数)、x+28 (x偶数)

である。x=29はA子が例外切片x=28を参照し、x=30もA子がx=29の例外を参照するため独立行にした。x≥31ではA子・B子・C子がそれぞれ定常式に入り、区間端点はxの一次式の偶奇比較で決まる。従って最終行は有限標本からの外挿ではない。

奇数親の{0,1}署名から値2位置が得られ、偶数親ではTheorem Tにより値2は生じない。値1位置は奇数親の{0}署名、偶数親で0を含む署名、およびtailを合わせると上のP₂₂(x)となる。表の範囲外R≥x+29は一般tail定理、R=0は終局値0で覆われる。よってRに関する強帰納が閉じ、全x≥22,R≥0で分類が成立する。

## 3族値2位置予想との一致

K0832の3族予想をz=6,y=22に特殊化し、d=x−22とする。

- 基本ラダーは {1,3,5}。
- 家族BのEXTは d=0,4 で、それぞれ47,49。
- 家族Aのランは d=7 で51,53,55,57。
- 家族Aの定常位置は d≥8 で51。

従って今回のT₂₂(x)と一致する。これはz=6,y=22特殊化の全称証明であり、3族予想全体の証明ではない。

## 適用範囲と限界

証明対象は抽象残余ゲームの固定切片z=6,y=22、全x≥22,R≥0。z=6,y≥23、z≥7の全Grundy分類、3族値2位置予想全体、標準二次元共円ゲームの固定幅・q点版の真の安定化長は未解決である。
