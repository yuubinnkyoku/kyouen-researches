# PG(2,9) 完全 7-アークの 6-部分集合の重複検査

## 目的

PG(2,9) の 6-キャップに関して「G=2 になるのは極大 7-拡大を持つ場合」という
経験則（K1333）を厳密化するため、**完全 7-アーク（極大 7-キャップ）2,021,760 個の
6-部分集合 14,152,320 個がすべて相異なるか**（= 2 つの完全 7-アークが 6 点を
共有しないか）を全数検査する。

## 方法

- `capcensus.c`（K1321 の独立検証で使われた全キャップ列挙器）を改変し、
  サイズ 7 で極大なキャップ（is_max）の 6-部分集合の 128-bit マスクを
  すべて `sixsub_masks.bin` に出力（`sixsub.c`）。
- `sortcount.c` でマスクをソートし、相異なる個数と重複数を数える。

## 実行

```
gcc -O2 -o sixsub.exe sixsub.c
gcc -O2 -o sortcount.exe sortcount.c
./sixsub.exe ../pg2q9-cap-game-20261125/output/board_pg2q9.txt --dump6sub sixsub_masks.bin
./sortcount.exe sixsub_masks.bin
```

- 期待: n = 14,152,320、distinct = 14,152,320、duplicates = 0 なら
  「各 6-キャップは高々 1 個の完全 7-アーク拡大を持つ」が厳密に成立し、
  **G=2 の 6-キャップ数 = 14,152,320（27.2%）** が确定する。

## 備考

- サイズ 7 の極大性は `is_max`（blocked == 全点）で判定。
- 全キャップ列挙は 128,917,712 個（国勢調査と一致）を走査する。
