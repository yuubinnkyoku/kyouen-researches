`audit.js` は `../n11-s9-n23-priority-20261027/prove.js` を実行し、選択した256個の9石局面の全10石子を二種類の整数幾何で終局まで再計算してから、固定証人・順序ハッシュ・逆伝播の整合性を確認する。n22の890類も上流で終局再計算される。未検証のWIN cache、df-pnの未完探索、pn/dn値は証拠に採用しない。8石の既知LOSS338類と衝突した場合は停止する。

`verify.py` はNetworkXで最小費用を求め、別の交互閉路・部分集合動的計画法で最適性を独立検査する。新しい証明で144辺未満の根集合が得られるかは、この検査結果で判定する。

```sh
python3 -m pip install 'networkx==3.4.2'
python3 research/experiments/n11-s5-post-n23-matching-20261027/verify.py --negative
```
