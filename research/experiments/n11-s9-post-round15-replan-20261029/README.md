# N11 round15後の証明限定・再計画

第15回の独立検証済み9石証明書と固定済み8石WIN伝播結果を入力として、固定14根計画の残る52本の未証明辺に関係する9石候補のみを選び直す。

`replan.js` は第9〜15回の証明書と過去の計画を照合し、10石LOSS証人から導いた9石LOSS親を再検査する。異なる回のWIN9/LOSS9衝突、WIN8/LOSS8衝突、証明書のハッシュ不一致を検出した場合は停止する。証明済み9石、LOSS親、未証明辺に接続しない候補を除外し、支配関係と被覆数に基づいて最大32局面を選ぶ。

この選択は**計算対象の計画**であり、勝敗証明ではない。候補数・被覆数は検証計算が成功するまで確定しない。第15回で証明済み8石WINは5,739類、固定14根計画の未証明辺は52本。

実行: `node research/experiments/n11-s9-post-round15-replan-20261029/replan.js`

空盤の勝敗は **UNKNOWN**。
