# 中心軸の3共線点を含む四石候補はN

点番号49x+7y+z。二石 `{169,173}` の未被覆第三手24に対し、第四手171（中心）を
置いた候補 `{24,169,171,173}` はNだった。勝ち手157 `(3,1,3)` を置いた後はP。
五石の正規形は `{73,150,169,171,173}`。

三共線点169・171・173を含むが、局面全体は安全である。全1,590,127局面の証明を
独立Bareiss検査し、2,021,853辺、454,101終端、1,087,416,615行列式を確認した。
五石P証人の全到達部分木も同じ検査に含まれる。最大石数は15。

第三手24をNと証明するには、Pとなる第四手が一つあればよいが、今回の171はその手に
ならない。四石Nだけから親の三石の勝敗は決まらず、三石・二石・空盤は未確定。
次は第四手318を用いた中心対称四石 `{24,169,173,318}` を別に探索する。

初期には未被覆5三石根のそれぞれへ171を加え、各10万展開したが全てUNKNOWN
（`probe.jsonl`）。その一つを絞って続け、100,000の初期probeの後に9,118,113展開を
加えて閉じた。残る4候補の勝敗は判定していない。

全証明は `stage-3.cert.gz`、独立検査は `stage-3-verified.json`。
巨大候補表全体を独立検査したという意味ではない。
