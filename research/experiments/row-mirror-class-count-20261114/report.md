# 行鏡像正準欠損クラス数の一般公式 — C(w) = 2^(w−1) + 2^(⌈w/2⌉−1) − 1（2026-11-14 高速レーン）

## 主張

行集合 {0, …, w−1} の空でない部分集合を、行鏡像 V: y ↦ w−1−y で割った orbit 数は

**C(w) = 2^(w−1) + 2^(⌈w/2⌉−1) − 1 = (2^w + 2^⌈w/2⌉ − 2) / 2**。

class-split 機械（sat3.js `--class=D`）の文脈では、これが「完全 sweep が走査すべき行鏡像正準
欠損クラス数」に等しい: D ≠ ∅ は欠損行集合（D 内の行は ≤ q−2 石・D 外の行は満容量 q−1 石）、
盤面鏡映 (x, y) ↦ (x, w−1−y) は格子の等長変換で直線・円を保ち、クラス D の配置をクラス
V(D) の配置に写す。よって SAT(D) ⟺ SAT(V(D)) であり、orbit ごとに代表 1 クラスの走査で
被覆は完全になる。

値: C(1)=1, C(2)=2, C(3)=5, C(4)=9, **C(5)=19**, **C(6)=35**, **C(7)=71**, **C(8)=135**,
C(9)=271, C(10)=527, C(11)=1055, C(12)=2079, C(13)=4159, C(14)=8255。

## 証明（Burnside）

G = {id, V} ≅ Z/2 が {0..w−1} の部分集合全体 X に作用する。V で固定される部分集合は、
各鏡像対 {i, w−1−i}（⌊w/2⌋ 個）と奇数 w の中央行 ⌊w/2⌋ の所属が対で等しいもの —
独立な二値選択は ⌊w/2⌋ + (w mod 2) = ⌈w/2⌉ 個なので |Fix(V)| = 2^⌈w/2⌉（空集合込み）。
|Fix(id)| = 2^w。X 上の orbit 数は Burnside で (2^w + 2^⌈w/2⌉)/2 = 2^(w−1) + 2^(⌈w/2⌉−1)。
空集合は固定された一元 orbit なので、空でない部分集合の orbit 数はそこから 1 を引いて
C(w) = 2^(w−1) + 2^(⌈w/2⌉−1) − 1。∎

## 機械との同一化（定義に基づく・solver の健全性は主張しない）

sat3.js `--class=D` は「D 内の行: ¬rowGe[y]（≤ q−2 石）・D 外の行: rowGe[y]（≥ q−1 石）」
を unit 節で付す。走査対象盤では m ≥ q なので各業は長さ m ≥ q の直線であり、safety は
行を q−1 石以下に cap する — よって D 外の行はちょうど q−1（満容量）、D は正確な欠損行集合
として一意に定まる。D = ∅（全行満容量）は「欠損」配置ではなく sweep 対象から除外される
（既存 sweep 項目と同一規約）。k × minpos 分解（K0816/K0821）はこのクラス分割のさらに
細かい直交分割であり、クラス数には影響しない。

## 交叉検証

- 総当たり orbit 列挙 w = 1..14（`scripts/orbit_count.js`・`output/counts.json`）:
  全 w で公式と一致。
- 既存の sweep 記録: w=5 → 19 クラス（K0816 5×20、K0821 5×21、five-row-q6-m22-class-split
  5×22）、w=6 → 35 クラス（K0818 6×19、K0819 6×20）。すべて C(5) = 19・C(6) = 35 と一致。
- 予測: 最初の 7 行 class-split は **C(7) = 71 正準クラス**、8 行は **135 クラス**を走査
  しなければ被覆が完全にならない（sweep 設計の検算に使える）。

## 範囲と限界

- 純粋な組合せ恒等式の全称証明（w ≥ 1）。census・符号化・solver の健全性は別項目
  （K0810・各 sweep 項目）の範囲。
- クラスは「どの行が満容量でないか」のみを区別し、欠損の深さ（欠損行は 0〜q−2 石を
  取り得る）は区別しない。
