# 一辺細分星 q=81〜90 の奇数次数実根切替（2026-11-06）

## 定理（各 q の全奇数 k≥3）

\(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}\)、\(r=q-3\) とする。

| q | 実根0個となる最大奇数 k | 相異なる負の単実根2個となる最小奇数 k |
|---|---:|---:|
| 81 | 969 | 971 |
| 82 | 985 | 987 |
| 83 | 999 | 1001 |
| 84 | 1013 | 1015 |
| 85 | 1027 | 1029 |

各行の非存在側は同じ k 範囲で任意の q'≥q にも成立する。

## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおくと、負の根は \(F(y)=r-y-(a-y)y^k=0\) と同値。\(u≥0\) では多項式の係数が正なので根はない。\(0<y≤1\) では \(F(y)≥r-y-(a-y)=r-a>0\)。\(y≥a\) では \(F(y)=r-y+(y-a)y^k>0\)：\(a≤y≤r\) は自明、\(y>r\) では \((y-a)y^k>(y-a)y>y-r\)（\(r≥78\)）である。よって根の候補は \(1<y<a\) のみ。

\(H(y)=(a-y)y^k\) の最大値は \(y_*=ka/(k+1)\) で達成される。\(k_-\) において \(H(y_*)<r-a\) を示せば \(F(y)>0\) が全 \(1<y<a\) で成り立つ。\(k_+\) において \(F(y_*)<0\) を示せば \(F(1)>0\), \(F(a)>0\) から異なる根が少なくとも2個ある。\(T(-x)\) の係数符号変化は2回なのでデカルトの符号法則から負の根は重複度込みで高々2個、従って両根は単根で全実根である。

\(1<y<a\) で k が増すと \(F(y)\) は減少するため、境界間に奇数 k がないことと合わせて全奇数次数に拡張できる。q の増加では r-y が増加し a-y が減少するため、非存在側は q'≥q にも拡張できる。

## 境界の厳密整数検証

\(A=k(r+2)\)、\(B=(k+1)(r+1)\) とすると \(y_*=A/B\)。非存在境界は十分条件

\[(r^2-2)(k+1)B^k>(r+2)A^k\]

を、存在境界は必要十分な判定

\[(rB-A)(r+1)(k+1)B^k<(r+2)A^kB\]

を検査する。以下のコードは全20境界を浮動小数点なしで検査し、2026-11-06 に全件成功した。

```python
bounds = [[81,971],[82,987],[83,1001],[84,1015],[85,1029],[86,1045],[87,1059],[88,1073],[89,1087],[90,1103]]
for q, kp in bounds:
    r = q - 3
    for k, existence in ((kp - 2, False), (kp, True)):
        A, B = k * (r + 2), (k + 1) * (r + 1)
        assert B < A
        if existence:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
        else:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
print("20 exact boundary inequalities passed")
```
