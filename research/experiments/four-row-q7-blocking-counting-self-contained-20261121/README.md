## 記号と定式化（K1177/K1182 と同一）

- 盤は 4×m 整数格子（w=4 行・m 列）。石は格子点上に置く。
- 安全 (safe): 石の 7 点組 (q=7) が同一円周上または同一直線上に存在しないこと
  （水平・垂直を含む直線と真円。以下「曲線」はこの両者）。
- 極大 (maximal): 安全かつどの空き格子点も追加できない（すべての空格子点 p で
  追加が禁止される = p を含む曲線上に既存の石が 6 点 (q−1) 以上ある）。
- 行容量: 水平線上に 7 点整列は禁止なので、安全配置の各行は高々 q−1 = 6 石。
- def-mode（行欠損）: ある行の石数 ≤ q−2 = 5 の極大安全配置。
- P(m) ⟺「4×m の全極大安全配置が満容量 24 石（全行 6）」⟺ def-mode UNSAT ∧
  capacity 配置の存在（被覆論・K1177/K1182 で確立）。
- M_{4,7} = min { m0 : P(m) が全 m ≥ m0 で成立 }。

## 主定理（自己完結ブロッキング計数上界）

**定理.** w=4・q=7 のとき、行欠損を伴う極大安全配置が存在するのは
m ≤ 86 のときに限る。したがって m ≥ 87 では全極大安全配置が満容量である。
（一般化: 点が 4 本の水平線上に載る任意の有限点配置でも同じ計数が成立する。
整数格子であることは使わない。）

**証明.** S を行欠損を伴う極大安全配置とし、石数 r ≤ q−2 = 5 の行を R と
する。R の空格子点は m − r 個ある。補題 L1（安全配置の行容量: 各行 ≤ 6 石。
水平線上の 7 点整列禁止による）より、R 上の水平線は 6 石に届かず、R の
空格子点 p を block できる水平線は存在しない。補題 L2（4×m 盤の非水平直線は
各水平行と高々 1 点で交わるため格子点 ≤ 4 点。p を含めて 7 点に届かない）より、
block 曲線は真円のみである。よって各空格子点 p に対し、p を通り石を 6 点以上
載せた円 C_i が存在する（blocker 円）。

割当: 各 p に blocker 円を 1 つ固定する。補題 L3（円と水平直線の交点 ≤ 2:
円方程式に行の y を代入すると x の 2 次方程式）より、円 C_i が R 内に載る
格子点は ≤ 2 点であり、そのうち割当空点 e_i ∈ {1, 2}・石 u_i ≥ 0 は
e_i + u_i ≤ 2 を満たす。blocker 円の定義より C_i 上の石数 s_i ≥ 6 なので、
R 外の石数は t_i = s_i − u_i ≥ 6 − (2 − e_i) = 4 + e_i、すなわち
- e_i = 1（type-1）: t_i ≥ 5, C(t_i,3) ≥ C(5,3) = 10
- e_i = 2（type-2）: t_i ≥ 6, C(t_i,3) ≥ C(6,3) = 20 = 10·2
のいずれでも **C(t_i,3) ≥ 10 e_i** が成り立つ。

補題 L4（相異なる 2 円の共有点 ≤ 2。3 共有点があれば同一円。円は 3 点で
一意に決まる非退化 2 次曲線）より、ブロッカー円が載せる R 外石の 3 点組
（円上の 3 点は非共線になる。実際、同一円上の 3 格子点が共線なら水平であり、
L3 の ≤ 2 と矛盾する）は相異なる円間で共有されない。ゆえに

Σ_i C(t_i, 3) ≤ C(N_out, 3)

ここで N_out ≤ 3(q−1) = 18 は R 以外の 3 行の石の総数（L1 の行容量）で
あるから C(18,3) = 816。以上より

10 (m − r) = Σ_i 10 e_i ≤ Σ_i C(t_i, 3) ≤ 816
⟹ m − r ≤ 81（整数）
⟹ m ≤ r + 81 ≤ 5 + 81 = 86。 ∎

（補足: 816/10 = 81.6 は type-1・type-2 の限界費用がちょうど等しい
（1点あたり 10 3つ組）ための緊い値で、実装上は全数値列挙
max { a + 2b : 10a + 20b ≤ 816 } = 81 として gate g05 で確認する。）

## 系: M_{4,7} = 13 の第二 certificate（K0318 非依存）

1. **機械掃引 [13,86]**: K1177 の q=7 def 全幅掃引 13..85（sat2.js CNF・
   pinned kissat 4.0.4・rc=20）と、K1182 closure の genfast3 m=86 掃引
   （conflicts 5930・2 回独立実行 bit-exact）。m=87, 88 の UNSAT 記録
   （5191 / 6072）はさらに先の支持証拠。
2. **計数上界 [87, ∞)**: 上の定理（数学的証明・K0318 も掃引にも依存しない）。
3. **下界**: m=12 に行欠損極大安全配置 (23 石・rows [6,6,5,6]・K1177 witness)
   が存在し P(12) は不成立。
4. **capacity 存在 m ≥ 13**: m=13, 16 の capacity SAT witness（24 石・全行6）
   と同一石集合の幅単調性（K1182 で確立・K0318 非依存）。

1 + 2 で P(m) は「P(12) 不成立かつ全 m ≥ 13 で def-UNSAT ∧ capacity 存在」
となり、K0318 の一般上界 U_{4,7}=81 を使わず **M_{4,7} = 13** が閉じる。
ゲーム帰結 g(S) = (24 − |S|) mod 2（空盤 second-player-win）の基盤も
K1182 と同一（K0024 の飽和形式）。

**誠実な相対位置の記載**: 計数上界の閾値は独立に見ると m ≥ 87 であり、
K0318 の解析上界 m ≥ 81 より 6 幅弱い（上界としての品質は K0318 が上）。
今回は既刊掃引が 86 まで（さらに 88 まで）埋まっているため certificate と
しては十分である。本証明の独立価値は、閉包が (i) 有限掃引、(ii) 自明で
ないが初等的な計数、の 2 部品のみで構成され、一般閾値定理 K0318 への
依存を除去した点にある。K1182 の status・数値は一切変更しない
（proved のまま・本実験は第二 certificate の追加のみ）。

## 一般化の備考 (w = 4)

同じ計数は q ≥ 5 でそのまま通り、
m ≤ (q−2) + floor( C(3(q−1), 3) / min(C(q−2,3), C(q−1,3)/2) )
- q=6: 費用/点 = C(4,3) = 4（type-1 が安い）・予算 C(15,3) = 455
  ⟹ m ≤ 4 + 113 = 117（K0318 の U_{4,6}=103 より弱い・参考値）
- q=7: 費用/点 = 10・予算 816 ⟹ m ≤ 5 + 81 = 86（上の主定理）
- q=8: 費用/点 = C(7,3)/2 = 17.5（type-2 が安い）・予算 C(21,3) = 1330
  ⟹ m ≤ 6 + 76 = 82（K0077 で M_{4,8}=11 は既に閉鎖済み・参考値）

閾値の緊さは q=7 のときに限って既刊掃引と噛み合う。q=6 は
M_{4,6} = 16 or ∈ [35,103] の現状では本計数では閉じない。

## 解釈規約

- 本実験は M_{4,7}=13 の値を一切変えない（K1182 status: proved は不変）。
  新規知識は K 項目（push 時に番号確定）として出版され、K1182 との relation

  conflicts 数・solved 数を勝敗として読まない。REFUTED-D10 は LOSS 証明ではない。
