## 手法 (scripts/count_f_n_17.mjs)

- D_n (系D): 原始方向 (a,b) 毎の最大線列挙、長さ t の線ごとに C(t,4)。
- C_n (系A): 差分行一次形式 (r1×r2)·r3 = 0 かつ (a,b,c) が2次元共線でない四点組。
  a,b,c 共線のトリプルは d が同線上なら共線四点組 (系Dで計数)、d が線外なら
  3共線点+線外点は円を共有し得ない (det≠0) ので除外して真円のみを計数。
- F_n (系B): 3×3差分行列式の余因子展開・スキップなし・総数のみ。系A+系Dと独立。
