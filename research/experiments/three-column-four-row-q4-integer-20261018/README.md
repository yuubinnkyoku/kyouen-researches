# 3列×4行・q=4：任意の正整数間隔に対する空盤勝敗の完全分類

2026-10-18。`main` 158b71ba を基準に独立して作成。対象は列座標 `0,a,a+b`、行座標 `0,d,2d,3d`、`a,b,d` は正整数。四点以上の共円・共線を禁じ、石を一つずつ置けなくなった人が負ける通常ルール。

## 定理（整数間隔、全称）

空盤の Grundy 値は常に 0 または 2 であり、

\[
 g(\varnothing)=2 \iff (a,b,d)=k(1,1,1),\ k(1,2,1),\ k(2,1,1)\quad(k\in\mathbb Z_{>0}).
\]

それ以外の正整数間隔では `g(empty)=0`（後手必勝）。先手必勝の三族で、勝てる初手はそれぞれ 6、4、4 通り。座標 `(列番号,行番号)` で記すと：

- `(1,1,1)`：各列の最下段または最上段、計6点。
- `(1,2,1)`：中央列・右列の最下段または最上段、計4点。
- `(2,1,1)`：左列・中央列の最下段または最上段、計4点。

この結論は有限の小さい間隔を調べただけの外挿ではない。以下の有限記号分類と全局面再帰により、全正整数に対して証明する。

## 証明

**1. 四点禁止集合の完全分類。** 4点が1列にある場合は3組の共線組。2列に2点ずつある場合は、それぞれの行番号の対の和が一致する場合に限り共円であり、合計24組。3+1列分布では3点が同一直線上にあり、残る点はその直線外なので禁止組ではない。3列に分布する4点は、ある列 `i` に2点（行番号 `r<s`）、他の列 `j<k` に各1点（行番号 `t,u`）を置いた288通りだけを調べればよい。

**2. 三列円の整数係数化。** `T=(t-r)(t-s)`、`U=(u-r)(u-s)` とする。円の一般式から縦の2点で縦一次係数を消去すると、残る二点が同じ円に乗る条件は

\[
 ab(a+b)=d^2(Aa+Bb)
\]

となる。2点を持つ列 `i=0,1,2` に対し、係数 `(A,B)` は順に `(T-U,T)`、`(-U,-T)`、`(U,U-T)`。288通りは37種類の係数にまとまり、正の間隔で成立しうるのは `A>0` または `B>0` の20種類だけ。残りの17種類は右辺が非正なので成立しない。

**3. 全ての同時成立パターンの有限化。** `t=a/b>0`、`v=b/d>0` と置くと、係数 `(A,B)` の円条件は

\[
 t(t+1)v^2=At+B.
\]

異なる2条件 `(A,B)`、`(C,D)` が同時に成立する場合、`A≠C` なら必ず

\[
 t=(D-B)/(A-C),\qquad v^2=(At+B)/(t(t+1)).
\]

`A=C` なら `B≠D` なので同時成立しない。したがって同時成立する係数集合は、20種類から2つ選んで上の有理数を計算し、`t>0,v²>0` を満たすものを抽出するだけで全て得られる。成立する係数が0種類、1種類の可能性も別途加える。重複除去後は**65種類**（0個:1、1個:20、2個:38、3個:6）。この集合は実現不能な単独条件を含んでもよい、厳密な上位集合である。

**4. 有限ゲームの完全再帰。** 65種類それぞれで27個の普遍禁止組に、成立する係数の三列禁止組を加える。全4096部分集合について、禁止4点組を含まない集合だけを安全局面とする。合法な1点追加の子の Grundy 値の `mex` を、石数の多い順に求める。`classify.py` がこの全列挙を標準ライブラリの整数演算だけで再現する。結果は `g(empty)=0` が58種類、`g(empty)=2` が7種類で、それ以外の値は現れない。

**5. 整数間隔に戻す。** 7種類の先手必勝パターンはすべて複数の係数が同時成立するため、上の式で `t` と `v²` が一意に決まる。該当する `(t,v²)` は

```
(1,1), (1/2,4), (2,1), (1/5,5), (5,1/5), (6,1/14), (1/6,18/7)
```

である。整数 `a,b,d` なら `v=b/d` は有理数なので、`v²` は有理数の平方でなければならない。後ろ4種類は分子・分母の既約平方判定で排除される。前3種類はそれぞれ `a:b:d=1:1:1`、`1:2:1`、`2:1:1`。初手の勝ち手の数と位置は同じ有限再帰から得られる。証明終。

## 独立検証と証拠の範囲

- `classify.py`：上の20係数と65種類を有理数で構成し、全4096局面を列挙。`signatures.json` は65種類の係数・安全局面数・Grundy値・勝てる初手数の出力。
- `independent.cpp`：係数分類を一切利用せず、12点から選ぶ495通りの四点の `4×4` 整数行列式で禁止組を生成。別実装の全安全局面再帰により、`1≤a,b,d≤16` の**4096盤すべて**で定理と一致。`independent.log` に結果を保存。
- この全称証明の信頼境界は、短い幾何的帰着と、公開した65種類の有限完全再帰である。C++の4096盤検証は独立支持であって、単独で無限個の盤を証明するものではない。

## 実行
