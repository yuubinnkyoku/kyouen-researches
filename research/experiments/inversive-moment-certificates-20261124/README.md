# モーメント多項式証明: K_4 ≤ 2q+1 と K_s ≤ (s−2)q（宣言・2026-11-24）

## 結果（本実験で証明する定理）

`M(q)` を位数 q の Miquelian 反転平面（点 `q²+1`、円 `q+1` 点、
3-(q²+1,q+1,1) 設計）とし、`K_s(q)` を「各円と高々 s 点で交わる集合」の
最大サイズ、`τ_1(q)` をブロッキング集合（全円と交わる集合）の最小サイズとする。

**定理 A（s=4）.** `q ≥ 6` で `K_4(q) ≤ 2q+1`。

**定理 B（一般 s）.** `5 ≤ s ≤ q−1` かつ `q ≥ 9` で `K_s(q) ≤ (s−2)q`。

**定理 C（ブロッキング）.** `q ≥ 9` で `τ_1(q) ≥ 2q`。
（Bruen–Rothschild 1985 の下界を、設計の 3 本のモーメント等式だけで再証明する。）

いずれも K1274 の設計上界 `K_s ≤ (s−2)(q+1)+2 = (s−2)q + s` を改善する:
定理 A は −3、定理 B は **加法的な s を完全に消す**。

## 証明の骨格（詳細は report.md）

`s`-弧 `S`（`|S|=n`）に対し `t_r` を「S とちょうど r 点で交わる円」の個数とする。
3-(q²+1,q+1,1) 設計のモーメント等式

```
Σ t_r = q(q²+1),      Σ r t_r = n q(q+1),
Σ C(r,2) t_r = C(n,2)(q+1),   Σ C(r,3) t_r = C(n,3)
```

が成り立つ。多項式 `P_s(r) = −(r−(s−3))(r−(s−2))(r−s)` は整数 `0 ≤ r ≤ s` で
非負であり、`P_s` を `{1, r, C(r,2), C(r,3)}` で展開した係数を
`(a0,a1,a2,a3) = (s(s−3)(s−2), −(s−3)(3s−4), 2(3s−8), −6)` とすると

```
0 ≤ Σ P_s(r) t_r = Y(n,q) := a0 q(q²+1) + a1 n q(q+1)
                            + a2 C(n,2)(q+1) + a3 C(n,3).
```

`n = (s−2)q+1` を代入すると `Y = −q·W(s,q)`、
`W(s,q) = q(s−1)(s−4) − s(s−2)(s−3) − 2`。`5 ≤ s ≤ q−1, q ≥ 9` で `W > 0`
なので矛盾、よって `K_s ≤ (s−2)q`。s=4 は `P_4 = −(r−1)(r−2)(r−4)` と
`n=2q+2` で `Y = −4(q²−5q−2) < 0`（q≥6）。

ブロッキングは `t_0 = 0` と `Q(r) = (r−1)(r−3)(r−4) ≥ 0`（r≥1）を使い、
`m = 2q−1` で `Σ Q(r)t_r = −2(q−8)(q−1) < 0`（q≥9）。

## 検証

`scripts/certificates.py` が Fraction の厳密算術で、
(i) `P_s(r) ≥ 0`（整数 r）、(ii) 係数展開、
(iii) 各 (q,s) で `Y < 0`、(iv) ブロッキングの `Y < 0`、
(v) `W > 0` を主張範囲で検査する。SAT は使わない。

さらに `independent/`（独立実装）が自前の多項式演算で
係数展開 196 件・P の非負性 20,090 点・定理A 195 件・定理B 19,104 件・
定理C 192 件・設計パラメータ 199 件を再検査し、failures 0。
実ボード上で `ΣP(r)t_r = Y` を 136 subset で直接確認。

  Kiss–Marcugini–Pambianco (2005) は q 大の構造定理（q≥4 拡張ではない）。

  定理A/Bの先行主張ではない。
