# モーメント多項式証明: 反転平面の s-弧上界の改善とブロッキング下界の初等証明

実験ディレクトリ: `research/experiments/inversive-moment-certificates-20261124/`（2026-11-24）

## 0. 要旨

`M(q)` を位数 q の Miquelian 反転平面（点 `q²+1`、円 `q+1` 点、
3-(q²+1,q+1,1) 設計）とする。

- `K_s(q)`: 各円と高々 `s` 点で交わる集合の最大サイズ（K1274 のスペクトル）。
- `τ_1(q)`: 全円と交わる集合（ブロッキング集合）の最小サイズ。

**定理 A.** `q ≥ 6` で `K_4(q) ≤ 2q+1`。

**定理 B.** `5 ≤ s ≤ q−1` かつ `q ≥ 9` で `K_s(q) ≤ (s−2)q`。

**定理 C.** `q ≥ 9` で `τ_1(q) ≥ 2q`。

いずれも **3 本のモーメント等式 + 3 次多項式の乗数**（Farkas 証明書）だけで
証明される。K1274 の設計上界 `K_s ≤ (s−2)(q+1)+2 = (s−2)q + s` に対し、

| s | 旧上界 | 新上界 | 改善 |
|---:|---:|---:|---:|
| 4 | `2q+4` | `2q+1`（q≥6） | 3 |
| 5 | `3q+5` | `3q`（q≥9） | 5 |
| 6 | `4q+6` | `4q`（q≥9） | 6 |
| s | `(s−2)q+s` | `(s−2)q` | **s** |

すなわち **加法的な `s` が完全に消える**（s=4 のみ 3 の改善）。
定理 C は Bruen–Rothschild (1985) の `τ_1 ≥ 2q`（q≥9）を
初等的なモーメント計算で再証明する。

## 1. モーメント等式

`s`-弧 `S`（`|S| = n`）とし、`t_r` を「`S` とちょうど `r` 点で交わる円」の個数
（`r = 0,1,...,q+1`）とする。`M(q)` は 3-(q²+1,q+1,1) 設計なので

```
(M1)  Σ_r t_r           = q(q²+1)          （円の総数）
(M2)  Σ_r r t_r         = n·q(q+1)         （各点は q(q+1) 円に載る）
(M3)  Σ_r C(r,2) t_r    = C(n,2)(q+1)      （各点対は q+1 円に載る）
(M4)  Σ_r C(r,3) t_r    = C(n,3)           （各 3 点は一意な円に載る）
```

`t_r ≥ 0`。任意の多項式 `P(r) = a0 + a1 r + a2 C(r,2) + a3 C(r,3)` に対し

```
Σ_r P(r) t_r = Y_P(n,q) := a0 q(q²+1) + a1 n q(q+1)
                            + a2 C(n,2)(q+1) + a3 C(n,3).
```

**鍵**: すべての可能な `r`（s-弧なら `r ≤ s`、ブロッキングなら `r ≥ 1`）で
`P(r) ≥ 0` なら `Y_P(n,q) ≥ 0` が必須。特定の `n` で `Y_P < 0` を示せば矛盾。

## 2. 定理 A（s=4）

`P_4(r) = −(r−1)(r−2)(r−4)`。整数 `r = 0,1,2,3,4` で
`P_4 = (8, 0, 0, 2, 0) ≥ 0`。`{1, r, C(r,2), C(r,3)}` 展開は

```
P_4(r) = 8 − 8r + 8C(r,2) − 6C(r,3)      （a0,a1,a2,a3) = (8,−8,8,−6)
```

`n = 2q+2` を代入すると

```
Y = 8q(q²+1) − 8(2q+2)q(q+1) + 8C(2q+2,2)(q+1) − 6C(2q+2,3)
  = −4(q² − 5q − 2).
```

`q ≥ 6` で `q²−5q−2 > 0` なので `Y < 0`、矛盾。よって `K_4(q) ≤ 2q+1`。□

（q=5 では `Y = 8 > 0` で証明できない。実際 `K_4(5) = 10 = 2q`。）

## 3. 定理 B（一般 s）

`4 ≤ s ≤ q−1` に対し

```
P_s(r) = −(r−(s−3))(r−(s−2))(r−s).
```

整数 `r ∈ [0,s]` で `P_s(r) ≥ 0`:
`r ≤ s−3` では 3 因子すべて ≤ 0 で積 ≤ 0、`r = s−3, s−2, s` で 0、
`r = s−1` では `(2)(1)(−1) < 0`。よって `−積 ≥ 0`。□

展開係数:

```
P_s(r) = a0 + a1 r + a2 C(r,2) + a3 C(r,3),
a0 = s(s−3)(s−2),  a1 = −(s−3)(3s−4),  a2 = 2(3s−8),  a3 = −6.
```

`n = (s−2)q + 1` を代入すると

```
Y = −q · W(s,q),     W(s,q) = q(s−1)(s−4) − s(s−2)(s−3) − 2.
```

**`W > 0` の確認**（主張範囲 `5 ≤ s ≤ q−1`, `q ≥ 9`）:

- `W` は `q` について傾き `(s−1)(s−4) > 0`（s≥5）の一次関数。
- `s = 5,6,7`: 最小の `q = 9` で `W(5,9)=4`, `W(6,9)=16`, `W(7,9)=32` 以上。よって `W>0`。
- `s ≥ 8`: 最小の `q = s+1` で
  `W(s,s+1) = (s+1)(s−1)(s−4) − s(s−2)(s−3) − 2 = s² − 7s + 2 > 0`
  （s=8 で 10、以降単調増加）。よって `W>0`。

したがって `Y < 0`、矛盾。`K_s(q) ≤ (s−2)q`。□

（`s = q` では `W = −2q−2 < 0` となり証明できない。実際 `s=q` は
全点集合に近い領域で、別のブロッキング上界 `K_q ≤ (q−1)²` が正しい。）

## 4. 定理 C（ブロッキング下界）

`X` をブロッキング集合、`m = |X|`、`t_r` を `|X∩C| = r` の円の個数とする。
ブロッキングなので **`t_0 = 0`**、`r ≥ 1`。

`Q(r) = (r−1)(r−3)(r−4)` は整数 `r ≥ 1` で非負
（r=1,3,4 で 0、r=2 で 2、r≥5 で正）。展開:

```
Q(r) = −12 + 12r − 10C(r,2) + 6C(r,3)      （a = (−12,12,−10,6)）
```

`m = 2q−1` を代入すると

```
Σ_r Q(r) t_r = −2(q−8)(q−1).
```

`q ≥ 9` で `−2(q−8)(q−1) < 0` だが、左辺は `Q(r) ≥ 0`, `t_r ≥ 0` の和なので
`≥ 0`。矛盾。よって `τ_1(q) ≥ 2q`。□

**鋭さ**: モーメント緩和は `q = 4..8` では `m = 2q−1` が実行可能で、
この方法では `2q` に届かない（線形計画の下限が `2q−1`）。
Bruen–Rothschild の `2q` は q≥9 の範囲で本証明と一致し、
q=4..8 の拡張（Kiss–Marcugini–Pambianco 2005）はモーメント外の議論を要する。

## 5. 帰結

- **`K_4`**: `q=6,7,8,9,11,13` で上界 `2q+1 = 13,15,17,19,23,27`。
  既知の厳密値 `K_4(4)=9`, `K_4(5)=10`, `K_4(7)=13`, `K_4(8)=14` と整合。
  **`K_4(9)` の上界は 22 → 19 に改善**（下界 16）。
- **一般 s**: `K_5(9) ≤ 27`（旧 32）、`K_6(9) ≤ 36`（旧 42）、
  `K_7(9) ≤ 45`（旧 52）、`K_8(9) ≤ 54`（旧 62）。
- **スペクトルの上包絡**:
  ```
  K_s(q) ≤ (s−2)q        (5 ≤ s ≤ q−1, q ≥ 9)
  K_q(q) ≤ (q−1)²        (定理 C; q ≥ 9)
  K_{q+1}(q) = q²+1
  ```
- 深い K1252 の `K_3 ≤ q` はこの枠組みの外（モーメント LP は `s=3` で `q+3`）。

## 8. 限界・未解決

- モーメント緩和は `s=4` で `2q+1`、実測 `K_4(7)=13`, `K_4(8)=14` との間に
  まだ 2〜3 の差がある。整数性・代数性を使う追加議論が必要。
- `s = q` の等号 `K_q = (q−1)²`（`τ_1 = 2q`）は q=4,5 のみ確認。
  SAT による `2q` ブロッキング集合の探索は q=7,8,9,11 で開始したが、
  今回は UNSAT を確定できず（CPU 約 5〜20 分で中断）。
- q < 9 の一般 s は定理 B の範囲外。LP 表による弱い上界のみ。
- SAT 較正: q=4,5 ではサイズ `2q` のブロッキング集合が SAT で見つかり、
  `τ_1(4)=8`, `τ_1(5)=10` を独立に再確認（`inversive-blocking-equality-20261124`）。
