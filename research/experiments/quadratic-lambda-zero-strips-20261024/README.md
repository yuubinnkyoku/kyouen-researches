# λ=0の列盤：最良一様閾値と全Grundy公式

2026-10-24。ローカルmain e4b1c5ef上での研究。リモート照合はDNSエラーで未完。
現在の知識の正本はK0533（任意列盤）とK0535（標準五列盤）。
数学的証明は[proof.md](proof.md)。規則は四点の `det[x²,x,y,1]=0` を禁じる通常プレイ。

## 数学的成果

相異なるw≥3本の任意の実数位置の鉛直列で、各列の有限候補集合が少なくとも

`M_w=max(3,1+(w−2)(w−3)(w+2)/6)`

点を持つなら、極大安全集合は一列三石かw+1石。全Grundy値は

- 偶数w：`(1−|S|) mod2`。
- 奇数w：一列二石なら2、一列三石なら0、その他は `|S| mod2`。

全局面でg≤2。候補高さが共通である必要も、等間隔や整数である必要もない。
三点の二次補間が目標列上で高々一点しか禁止しないことから、全称証明を得た。
さらに、各列M_w−1点では公式を破る整数座標盤をすべてのw≥3で構成できるため、
M_wはこの任意候補集合に対する一様閾値として最良。

標準五列盤 `{0,...,4}×{0,...,m−1}` だけに限れば、真の公式安定化高さは6。
m=6,7の有限完全検査とm≥8の全称定理、および5×5の明示五石終局を接続する計算機支援証明。

## 有限監査

18盤、延べ3,972,161安全局面を厳密検査。
全称定理の候補数条件内は延べ3,384,859局面で、全局面の公式との不一致は0。
標準・不等間隔・列ごとに異なる候補集合を含む。

二つの独立したC++アルゴリズムを使用。

1. [audit.cpp](audit.cpp)：禁止三点の補完を増分伝播し、全到達局面で再帰mexを計算。
2. [column_audit.cpp](column_audit.cpp)：列ごとの占有数パターンを列挙し、
   四点の禁止辺集合で安全性を直接判定。安全集合の所属だけを使う逆向きDPでmexを計算。

両方が各安全局面を閉公式と照合する。候補数条件内と標準5×6・5×7では両方とも不一致0。
全盤について安全層数・Grundy分布・終局サイズ分布・公式不一致数が一致。
20点以下の盤は既存Python全subset DPでも集計を再検査した。
四点の係数は置換展開とアフィン余因子の二方式の整数演算で照合。

条件外では、三列二点に公式不一致3、四列二点に40、5×5に216を検出した。
これらを全称定理の反例とは数えない。標準5×6・5×7は一般の十分点数8未満でも
公式が成立することを、それぞれ157,122・373,938局面で完全確認した。

[sharpness.py](sharpness.py)は一般閾値の最良性構成をw=4,...,10で具体化し、
すべての選択四点の安全性と全空候補への禁止証人を独立行列式で検査。
正整数tを避ける多項式構成はすべてt=2で成功したが、全wでt=2とは主張しない。
別途、標準5×5の明示五石終局について全20空点の禁止三点組も保存した。

## 再現

Python標準ライブラリとC++17コンパイラg++を使用。CXXでコンパイラを変更できる。
バイナリはOSの一時ディレクトリへ置き、repoには保存しない。

```sh
uv run --locked python research/experiments/quadratic-lambda-zero-strips-20261024/verify.py
uv run --locked python research/experiments/quadratic-lambda-zero-strips-20261024/sharpness.py
```

[results.json](results.json)は有限監査結果、[sharpness.json](sharpness.json)は整数反例と候補集合。
全称閾値の最良性は有限例だけから推論せず、proof.mdの全幅構成による。
標準λ=1の一般正方形盤や、他のλの長盤公式への主張ではない。
