# 2026-10-24 独立完全列挙の結果

対象は二層 `2×k×m` の4点共面禁止版。`3+2` の三石層を `x=0` に固定した数を示す。二方式は全数で一致。

| 断面 | 安全五石 | 極大五石 |
|---|---:|---:|
| 3×3 | 1,332 | 532 |
| 3×4 | 7,528 | 592 |
| 3×5 | 26,340 | 332 |
| 3×6 | 71,826 | 18 |
| 3×7 | 164,556 | 0 |
| 4×4 | 40,368 | 304 |
| 4×5 | 139,380 | 44 |
| 4×6 | 377,096 | 0 |
| 4×7 | 857,168 | 0 |

例（括弧内は `(y,z)`、先の三点が `x=0`、後の二点が `x=1`）：

- `3×6`: `A={(0,0),(1,1),(2,0)}`、`B={(1,1),(1,4)}`。五石極大の具体的証人。
- `4×5`: `A={(0,0),(0,2),(1,1)}`、`B={(0,2),(3,2)}`。五石極大の具体的証人。

二つの検証器はともに三角形の全 `C(km,3)` 通りと二石組の全 `C(km,2)` 通りを走査し、層を固定した安全な `3+2` 型を漏れなく調べる。Pythonは正規化方向・被覆ビット集合、C++は整数外積・候補点の直接走査を使用。各 `3+2` 配置は一度だけ数える。全層の五石極大配置総数は表の右列の2倍。

この結果だけから任意の盤長を主張しない。無界部分は `proof.md` の七直線補題および既存K0530に依存する。
