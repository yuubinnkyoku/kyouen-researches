# 2×k×m・4点共面禁止版：五石極大の完全分類（2026-10-24）

座標は `(x,y,z)`、`x∈{0,1}`、`0≤y<k`、`0≤z<m`。共線退化も含め四点共面を禁止する。以下 **k,m≥3**。

## 定理

**五石極大安全配置が存在することと `k+m≤9` は同値。** 従って既存K0530の全安全局面Grundy表が成立する必要十分条件は `k+m≥10`。固定した `k≥3` に対する真の開始長は `m=max(3,10-k)` である。

## 無界部分の証明

五石安全配置は二層に非共線三石 `A1,A2,A3` と二石 `B1,B2` を置いた `3+2` 型。三角形の三辺は相異なる方向で、`B1B2` はそれらと平行でない。二石層への追加点 `P` が違法になるのは、`P` が `B1B2` 上にあるか、`B1P` または `B2P` が三角形のいずれかの辺と平行な場合に限る。よって禁止候補は **七本の直線** に覆われ、水平線はそのうち高々二本。

`k≥3,m≥8` なら水平禁止線に含まれない行が存在する。その行の `m≥8` 個の点は、非水平な七本以下の直線では覆い切れない（各直線は高々一点）。従って合法な第六石がある。座標交換で `m≥3,k≥8` も同様。

`k,m≥5` の五石延長性は **既存K0530の全称定理** に依存する（そこで `5×5,5×6,6×6` の独立完全列挙も済んでいる）。残る短辺3・4、長辺7以下だけを次の独立二方式で全数検査する。

## 有限境界（完全列挙）

| k×m | 安全五石（3+2型、三石層固定） | 極大五石（同じく固定） |
|---|---:|---:|
| 3×3 | 1332 | 532 |
| 3×4 | 7528 | 592 |
| 3×5 | 26340 | 332 |
| 3×6 | 71826 | 18 |
| 3×7 | 164556 | **0** |
| 4×4 | 40368 | 304 |
| 4×5 | 139380 | 44 |
| 4×6 | 377096 | **0** |
| 4×7 | 857168 | **0** |

`verify.py` は最大公約数による方向正規化と整数ビット集合で七直線の被覆を計算する。`independent.cpp` は方向正規化・ビット集合なしで各候補点を整数外積により直接判定する。上表の全数が一致した。実際の五石極大配置数は三石層の選択で右列の二倍。正の各盤は明示的配置の存在、零の各盤は全数排除である。

これで `k+m≤9` の全盤に五石極大が存在し、`k+m≥10` は無界補題・既存K0530・境界零件数で覆われる。□

## Grundy表への必要十分性

既存K0530により `k,m≥3` で四石は必ず延長可能、共線三石だけが三石終局、六石は最大。五石が必ず六石へ延長できる場合、mex帰納法でK0530の全局面表が成立する。五石極大が一つでもあれば、その局面は通常 `g=0`、misère補助 `h=1` となり、表の五石値 `(1,0)` に反する。ゆえに上記条件は必要十分。空盤はこの条件下で `(g,h)=(0,1)`。条件外の空盤勝敗までは主張しない。

## 再現

```sh
python3 verify.py
g++ -std=c++17 -O2 -Wall -Wextra -pedantic independent.cpp -o /tmp/coplanar-narrow
/tmp/coplanar-narrow
```

有限列挙だけを無界の証明に外挿していない。全称部分は七直線の幾何と既存K0530に依存する。
