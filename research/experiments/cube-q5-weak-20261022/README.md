# 3次元5点禁止版の弱解決（2026-10-22）

開始main: `52c4d5e90c4b7f8d89d5d90581a73608de1c7cdd`。
対象は既存の `highdim-q5-cubes-20261016` と同じ、5点が共平面または共球面に
なる着手を禁止する通常プレイ。3次元の通常の円に5点が乗ることだけを禁止する
別ルールではない。現在の結論の正本はK0502。

## 全偶数辺長を扱う構成的証明

盤面を `P={0,...,n-1}³`、nを正の偶数とし、
`τ(x,y,z)=(n-1-x,y,z)` とする。τは盤の固定点なし鏡映である。
後手は常に相手の着手pにτ(p)を返す。

τ対称な安全局面Sからpが合法とする。τ(p)は未使用である。
応手が違法なら、S∪{p,τ(p)}内のある平面または球面Cに5点以上がある。

* Cがpを含まなければ、τ(C)は合法としたS∪{p}内に既に5点以上を含む。
* Cがpとτ(p)を含むなら、Cはτ不変。平面の場合、pとτ(p)を結ぶ方向が
  平面の方向空間に入るので、その法線は鏡映面に平行。球面の場合、二点への
  距離の等式から球心が鏡映面上にある。どちらもC=τ(C)となる。
  S∩Cは固定点なしの鏡像対で構成されるので偶数個。
  一方、pが合法で応手だけが違法なら `|S∩C|=3` で矛盾する。

したがって応手は常に合法で、各応手後に安全性と対称性が回復する。
有限盤なので後手が最後の合法手を打つ。これで4,6,8,...の全立方盤を
一括して弱解決する。同じ証明は少なくとも一辺が偶数の全直方格子に適用できる。
任意の安全なτ対称局面もP局面だが、非対称局面の強解決ではない。
これは既存の高次元鏡映証明を、明示的な戦略とsolution項目にしたものである。

## 戦略の実行

```sh
python3 research/experiments/cube-q5-weak-20261022/reflection.py 4 4 4 0 1 2
```

応手は `(3,1,2)`。関数は相手の合法着手と直前の安全性・対称性を前提とする。
奇数辺しかない盤はこの戦略の適用対象外である。

## 4×4×4の有限網羅検査

`audit_reflection.cpp` は各4点の持ち上げ差分3行から余因子法で法線を作り、
全635,376四点組の禁止追加点を前計算する。その後、x鏡映で不変な安全局面を
鏡像対の昇順追加で重複なく全列挙する。各局面の全合法手について、鏡像応手が
未使用かつ合法であることを検査する。64点maskの端を明示処理する。

結果 `reflection-4.json`: 禁止5点組714,936、対称安全局面529
（0石1、2石32、4石496）、応手検査2,048、対称終端496（すべて4石）。
`verify_reflection.py` は前計算表を読まず、5点の差分4×4行列式を24置換で
直接評価し、対称局面列挙・全合法手・応手を独立再検査する。
独立照合の対象は局面・合法応手・終局の各頻度で、禁止5点組総数そのものは対象外。

```sh
g++ -O3 -std=c++17 -Wall -Wextra -Werror research/experiments/cube-q5-weak-20261022/audit_reflection.cpp -o /tmp/audit-q5-reflection
/tmp/audit-q5-reflection 4 4 4
python3 research/experiments/cube-q5-weak-20261022/verify_reflection.py research/experiments/cube-q5-weak-20261022/reflection-4.json
```

4石終局には直接の説明もある。異なる二つの鏡像対は、平行な二弦を持ち
共通の垂直二等分線を持つため、同一平面内の円上にあるか、同一直線上にある。
円なら、任意の追加点はその円と同じ平面上にあるか、その円を含む球面上にある。
直線なら、任意の追加点とその直線を含む平面がある。いずれも5石目は違法。
よってこの3次元q=5戦略は全偶数n≥2で必ず4手終局になる。
