# 2トークン族の値2位置予想：広域格子監査

- 日付: 2026-11-16
- 対象: K0832 の残余ゲーム \(H(R;(x,y);z)\)、\(x\ge y\ge1,\ z,R\ge0\)
- 種別: **有限監査の拡張**。全称証明ではなく、K0832 の3族予想のstatusは変更しない。

## 何を確かめたか

K0832には、2トークン族の値2位置をラダー・家族B・家族Aで記述する予想がある。既存監査は全グリッド \(z\le16\)、広域の境界標的・標本 \(z\le40\) などを含む43,241照合だった。高さ方向の遷移をもう少し広く見るため、\(x,z\le60\) の全格子を直接再帰で走査した。

\(S=x+y,\ d=x-y\)、\(q_o(k)\) を \(k\) 以下の最大奇数、\(\delta_A(z)\) を \(z\) 以上の最小奇数、\(s_{\min}(d)\) を \(d+1\) 以上の最小奇数とする。既存予想は次の3族の和集合である。

- **ラダー**: 奇数 \(R\le q_o(\min(S,z))\)。
- **家族B**: \(d\equiv z\pmod2,\ d\le z\) とし \(y^*=(z-d)/2\) と置く。
  - \(y=y^*\ge1\) なら、奇数 \(\delta\) が
    \(s_{\min}(d)\le\delta\le2\lceil(z+d)/4\rceil-1\)
    を満たす各 \(R=2y+\delta\)。
  - \(z+d\equiv2\pmod4,\ y\ge y^*\) なら \(R=2y+(z+d)/2\)。
- **家族A**:
  - \(d=z+1\) なら、奇数 \(\delta\) が
    \(\delta_A(z)\le\delta\le2z+1\)
    を満たす各 \(R=2y+\delta\)。
  - \(d\ge z+2\) なら \(R=2y+\delta_A(z)\)。

監査対象は、各 \((x,y,z)\) について値2の候補が現れ得る全残容量 \(0\le R\le S+z\) である。既証明のtail定理により
\[
R\ge S+z+1\implies H(R;(x,y);z)=S\bmod2,
\]
なので、この外側に値2はない。

## 結果

| 再帰方式 | パラメータ範囲 | 比較数 | 不一致 |
|---|---|---:|---:|
| 降順整列する正準多重集合再帰 | \(x\le60,\ z\le60\) | 10,269,960 | 0 |
| トークン順を保ち整列しない再帰 | \(x\le60,\ z\le45\) | 7,113,210 | 0 |
| 2方式の全Grundy値を直接比較 | \(x\le20,\ z\le20\) | 141,120 | 0 |

- 正準再帰は各A手の後にトークンを降順整列する。
- 順序付き再帰はトークン位置を保持し、整列しない。
- 小さい共通範囲では両方式のGrundy値そのものを比較し、さらに予想式とも照合した。
- 検査は全て整数演算・決定的再帰であり、乱数標本ではない。

## 観察

今回の格子では反例は見つからなかった。特に \(z=6\) では、家族BのEXTが \(d=0,4\) に現れる層、PT角が \(d=2\) に現れる層、家族Aの \(d=7=z+1\) の4点ランが同じ再帰器で同時に再現された。これは既存の候補式と整合するが、個々の現象を新しい定理に昇格させるものではない。

## 限界

1. \(x,z\le60\) の有限格子であり、任意パラメータへの全称性は示していない。
2. 順序付きエンジンの全格子監査は \(z\le45\) まで。\(z=46..50\) の一括試行は完了しなかったため、その範囲を監査済みとは数えていない。
3. これは値2位置だけの検査で、値0・1を含む全Grundy分類ではない。
4. 既存の \(z=0,1,2,3,4\) 全称スライス証明は変更しない。\(z\ge5\) の全称証明は依然として未解決である。

したがって本記録は **有限監査済み予想への追加支持**にとどまる。K0832の命題statusや3族予想の量化範囲は変更しない。
