# 残余72行・36-root三手先D4重複censusの独立第二検証

## 範囲

K1075の残余72行を完全被覆する36本のfresh-safe 7石rootについて、既存の三手先幾何censusを独立実装で再検証した。探索probe、勝敗判定、証明書抽出、receipt foldは行っていない。

入力は次の2正本で、実行時にSHA-256をfail-closedで確認する。

- K1075候補供給正本: 49b6f85f6b51cfdd8a59c7797223da3d8797885d3c992ce67dc9dae629a883fa
- 先行三手先census正本: 94fdb0c6e3503f1e9d19aaaf345f4478157c5a44374f10642c52325f346c2023

## 独立実装

- Python 3.13標準ライブラリのみ。先行JavaScriptをimport・実行していない。
- 点を整数座標の放物面持ち上げ (x²+y², x, y) に写し、3次元外積と内積で4点行列式の零判定を行う。浮動小数点は使わない。
- D4の8変換は座標写像を直接列挙し、121-bit整数maskの最小値を正準代表とした。
- K1075の36 rootについて、安全性、D4正準形、D4像から1石除去したときの残余72行への所属を再導出。
- その後、合法な1・2・3手を全列挙し、各rootの10石D4類、root間の全221共有組、4 workerのstrided分割を再集計した。

## 解釈上の限界

これは幾何学的な重複censusであり、DFPNの節点数、実際の共有表命中率、同一深さ・同一証明境界の再利用可能性を測っていない。したがって、共有表の大規模実装やworker分割変更を正当化する結果ではない。

36-root depth-10 sweepは別の単一オーナーレーンに属するため、本実験では起動・変更していない。REFUTED-D10はLOSS証明ではない。標準11×11空盤、二石root、S2、class 1/2/4の勝敗は本実験では扱わず、UNKNOWNのまま。
