# 3×3×m・4点共面禁止版：全長の最大・最小極大と3立方の強解決

盤は B_m={(x,y,z):x,y∈{0,1,2},0≤z<m}。相異なる4点の det[x,y,z,1]=0 を禁止する（3点共線の退化も含む）。安全追加のみ合法とし、通常Grundy値 g と、終局を1とするmisère補助mex値 h を区別する。

## 全mの幾何学的証明

4石以上の安全配置に3点共線は存在しない。もし存在すれば任意の第4点と共面になる。各鉛直柱は高々2石であり、2石を含む柱は高々1本（2本の鉛直直線は同一平面上にある）。したがって安全石数は高々10。

二重柱の底面位置を p=(x,y) とする。底面3×3格子のpを通る水平・垂直の2直線は、それぞれp以外の2点を含み、互いに重ならない。二重柱の2石と、その直線上の他の2柱の各1石は必ず共面になる。したがって二重柱を持つ安全配置は両直線から各1柱以上を空ける必要があり、少なくとも2本の空柱が必要。占有柱は高々7本、石数は高々8。二重柱がなければ高々9。よって全mで K≤9、9石なら9本の柱にちょうど1石ずつである。

全mで s=3。3石未満なら常に追加できる。底面の一直線上の3石は任意の第4点と共面になるため極大である。

m≥5では各底面(x,y)に次の高さzを置くと9石安全（行がx、列がy）。

    0 0 1
    2 4 1
    3 1 0

この9点の126個の四点組の直接整数行列式はすべて非零（height_audit.py）。上界と合わせm≥5では K=9。

## m≤4の完全排除

m=1は全点共面なのでK=3。m=2は全2^18候補の安全集合6456個を独立に完全生成し最大石数6（368配置）。m=3は全2^27候補の安全集合72204個を完全生成し最大石数8（16配置）。m=4で9石があれば9柱各1石なので、全4^9=262144高さ割当だけを調べれば十分。126個の四点条件を検査し安全割当は0（独立C++枝刈りでも0）。m=3の8石安全配置の一例は (0,0,1),(0,1,1),(0,2,0),(1,1,0),(1,2,1),(1,2,2),(2,0,2),(2,1,0) であり、70個の四点組の行列式がすべて非零。この配置はm=4へそのまま埋め込める。ゆえに

    K(m) = 3 (m=1), 6 (m=2), 8 (m=3,4), 9 (m≥5)
    s(m) = 3 (m≥1)

## 3×3×3の全局面

Pythonは4×4行列式の24項展開で禁止組2918個を生成し、点番号が昇順となる追加だけで安全集合を各1回生成する。任意の安全集合は昇順に並べられるので完全列挙となる。全安全集合の階層を作り、各安全局面の全合法子を参照して逆順mexを計算。C++は3×3外積式で禁止組を独立生成し、空盤から全合法手を再帰探索してメモ化mexを計算。両者は安全局面数、極大分布、全局面のg/h分布まで一致。

| 石数 | 安全局面数 | 極大局面数 |
|---:|---:|---:|
| 0 | 1 | 0 |
| 1 | 27 | 0 |
| 2 | 351 | 0 |
| 3 | 2925 | 49 |
| 4 | 14632 | 0 |
| 5 | 34028 | 2644 |
| 6 | 19344 | 14616 |
| 7 | 880 | 752 |
| 8 | 16 | 16 |

空盤 g=2, h=1。通常版では中央(1,1,1)初手だけが敗着（子のg=0）、他26初手の子はg=1。misère版は全27初手の子がh=0で、どの初手も勝ち手。両版とも先手勝ち。全16最大配置は立方体の48対称操作で1軌道。3石極大はちょうど49本の3点共線であり、非共線3石ならその平面外に第4点を置ける。

## 再現

    python3 research/experiments/coplanar-3x3xm-q4-20261024/verify.py 1
    python3 research/experiments/coplanar-3x3xm-q4-20261024/verify.py 2
    python3 research/experiments/coplanar-3x3xm-q4-20261024/verify.py 3
    python3 research/experiments/coplanar-3x3xm-q4-20261024/height_audit.py
    g++ -std=c++17 -O2 research/experiments/coplanar-3x3xm-q4-20261024/independent.cpp -o /tmp/coplanar3
    for m in 1 2 3; do /tmp/coplanar3 "$m"; done
    g++ -std=c++17 -O2 research/experiments/coplanar-3x3xm-q4-20261024/search9.cpp -o /tmp/coplanar9
    for m in 3 4 5; do /tmp/coplanar9 "$m"; done

verify.pyはm≤3の全安全局面、height_audit.pyはm=3,4の9柱高さ割当を完全列挙する。search9.cppは高さを昇順に試し、四点共面で枝刈りし、最初の解があれば停止。m≥5の全局面Grundy値は未決定であり、最大値K=9から全局面の偶奇則を推論してはならない。共球・共面5点版とも異なる。
