# 2トークン残余ゲーム z=9・y=2 の全Grundy分類（K0988）

- 日付: 2026-11-19
- 対象: H(R;(x,2);9)、全 x>=2・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0985（z=9,y=1）、K0984（z=8,y=2）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

|---:|---|
| 2 | {1,3} |
| 3,4 | {1,3,5} |
| 5,6 | {1,3,5,7} |
| 7 | {1,3,5,7,9,11} |
| 8,9,10 | {1,3,5,7,9} |
| 11 | {1,3,5,7,9,13} |
| 12 | {1,3,5,7,9,13} ∪ O[15,23] |
| x>=13 | {1,3,5,7,9,13} |

| x | P_9^(2)(x) |
|---:|---|
| 2,4,6 | ∅ |
| 3 | I[6,∞) |
| 5 | I[8,∞) |
| 7 | {10} ∪ I[12,∞) |
| 8 | {10} |

| x>=13 odd | {10,12} ∪ O[15,x+12] ∪ I[x+13,∞) |
| x>=14 even | {10,12} ∪ O[15,x+11] |

全てのx>=2・R>=0で、H(R;(x,2);9)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailはK0832から

    R >= x+12  =>  H(R;(x,2);9) = (x+2) mod 2.

値2の定常位置は{1,3,5,7,9,13}。x=12だけは15,17,19,21,23が一時的に加わる。

## 証明

R=0は終局で値0。R>=1,x>=3の選択肢は

    A = H(R-1;(x-1,2);9)
    B = H(R-1;(x,1);9)
    C = 1 xor H(R-1;(x,2);8)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0985、CはK0984で評価できる。x=2では二つのトークン減少手が同じ(x,1)子に合流するため、A=B=K0985のx=2行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す（例: 023={0,2,3}）。mex対応は次の通り。

| mex | 2 | 0 | 1 | 1 | 0 | 0 | 1 | 0 | 1 | 0 |

各行はAに帰納仮説、BにK0985、CにK0984を代入した子値集合である。表の区間は互いに素で、各xについて1<=R<=x+11を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+12ではK0832の高R tail定理を各子に適用できる。x奇数ならA=B=C=0で親値1、x偶数ならA=B=C=1で親値0となり、親tail (x+2) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=9,y=2切片のみを扱う。z=9,y>=3、z=8のy>=5、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
