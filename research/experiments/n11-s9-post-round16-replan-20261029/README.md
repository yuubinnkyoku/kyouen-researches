# N11 第16回後の証明限定再計画

第16回の独立検証済み9石証明書と固定済み8石WIN伝播結果を用い、固定14根計画の残る49本の未証明辺に接続する9石候補だけを選び直す。

`replan.js` は第9〜16回の証明書・選択計画・8石伝播を再検査する。3×3および4×4整数幾何による第16回終局証明の独立再検査、SHA-256照合、10石LOSS証人からの9石LOSS親の再導出、回をまたぐWIN9/LOSS9矛盾とWIN8/LOSS8矛盾の検出を含む。既証明局面と残る49本に接続しない局面を除き、支配関係を利用して最大32局面を選ぶ。

結果の「潜在被覆」は証明ではない。実行・独立検証が完了するまで候補数や選択結果を確定値として扱わない。証明限定8石WINは5,763類、固定14根計画の未証明辺は49本。

node research/experiments/n11-s9-post-round16-replan-20261029/replan.js
