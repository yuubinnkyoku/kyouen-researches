# PG(2,5) s=3 の Grundy サイズ別完全分解

- 盤: PG(2,5)（31 点・31 直線、各 6 点）。s=3 ゲーム（各直線と高々 3 点）。
- `grundy_s_stats`（pg2q7 experiment）を `board_pg2q5.txt 3` で実行し、GSIZE 行を取得。
- 全 7,906,892 局面。サイズ別の和は SIZE 行、Grundy 別合計は GRUNDY 行と一致。

- 9: G0 666,500 + G1 620,000 + G2 930,000;
- 10: G0 248,000 + G1 483,600; 11: G0 65,100。

- 合計: G0 2,056,726 / G1 2,083,666 / G2 1,519,000 / G3 2,061,500 / **G4 186,000**
  （全 7,906,892、既存 GRUNDY 行と一致）。
- 最大 Grundy **4** はサイズ 7 のみ。極大サイズは 9,10,11（混在）で K1357/1358 と整合。
