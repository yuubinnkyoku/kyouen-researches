# 2026-11-16 — 2トークン残余ゲームの z=2 全Grundyスライス

## 命題

\(\kappa=1\) の残余ゲーム \(H(R;X;z)\) で、\(X=(x,y)\)、\(x\ge y\ge1\) とする。  
\(S=x+y\)、\(d=x-y\) と置く。

次の集合を定義する。

\[
T_2(x,y)=\{1\}\cup
\begin{cases}
\{S+1\},&d=0,\\
\{S,S+2\},&d=3,\\
\{2y+3\},&d\ge4,\\
\varnothing,&d=1,2.
\end{cases}
\]

奇数 \(R\ge3\) に対し、値1を取る集合を

\[
\mathcal O_2(x,y)=
\begin{cases}
\{3,5,\ldots,S-1\},&d=0,\\
\{3,5,7,\ldots\},&d=1,\\
\{3,5,\ldots,S-1\},&d=2,\\
\{3,5,\ldots,S-2\}\cup\{S+4,S+6,\ldots\},&d=3,\\
\{3,5,\ldots,2y+1\},&d\ge4\text{ 偶数},\\
\{3,5,\ldots,2y+1\}\cup\{S+4,S+6,\ldots\},&d\ge5\text{ 奇数}
\end{cases}
\]
とする。空になる区間は空集合と読む。

偶数 \(R\ge4\) に対して

\[
\mathcal E_2(x,y)=
\begin{cases}
\{S+1,S+3,\ldots\},&d\in\{1,3\},\\
\{2y+4,2y+6,\ldots\},&d\ge5\text{ 奇数},\\
\{2y+4,2y+6,\ldots,S+2\},&d\ge4\text{ 偶数},\\
\varnothing,&d\in\{0,2\}.
\end{cases}
\]

ここに現れる各列は偶数列である。

**定理.** 任意の \(x\ge y\ge1\)、任意の \(R\ge0\) について

\[
\boxed{
H(R;(x,y);2)=
\begin{cases}
0,&R=0,2,\\
2,&R\in T_2(x,y),\\
1,&R\in\mathcal O_2(x,y)\cup\mathcal E_2(x,y),\\
0,&\text{それ以外}.
\end{cases}}
\]

特に値2の位置は

\[
\boxed{
\{R:H(R;(x,y);2)=2\}=
\begin{cases}
\{1,S+1\},&d=0,\\
\{1\},&d=1,2,\\
\{1,S,S+2\},&d=3,\\
\{1,2y+3\},&d\ge4.
\end{cases}}
\]

従って、既存の2トークン値2位置予想の \(z=2\) スライスは全称証明された。

## 証明

残余ゲームの選択肢を \(A,B,C\) と呼ぶ。トークン \(t\ge2\) を \(t-1\) にする手がA、トークン1を除去して高さを1増やす手がB、高さを1減らしてGrundy値を反転する手がCである。親の選択肢Grundy値集合を \(\mathcal V_R\) と書く。

既証明の Theorem T より、全状態で \(H\le2\)、偶数 \(R\) では \(H\le1\)。したがって、

- \(R\) が奇数なら、子の残容量は偶数である。A/B子は0または1。C子も、既証明の \(z=1\) スライスと偶数残容量の上界から0または1である。従って \(\mathcal V_R\subseteq\{0,1\}\) であり、\(\mathcal V_R=\{0\}\), \(\{1\}\), \(\{0,1\}\) に応じてmexは1,0,2。
- \(R\ge4\) が偶数なら、親の値は高々1なので、\(H=1\) であることと \(0\in\mathcal V_R\) は同値。
- \(R=0,1,2\) は直接評価できる。特に \(R=1\) の選択肢集合は \(\{0,1\}\)、\(R=2\) は \(\{2,3\}\)。

残容量 \(R\) に関する強帰納法を行う。A子には帰納仮説、C子には既証明の \(z=1\) 閉形式を使う。\(y=1\) の境界ではB子が単一トークン \((x)\), 高さ3となるため、既証明の単一トークン閉形式を使う。\(x=y=1\) もこのB子で含まれる。

帰納仮説を代入したときの選択肢表は次の通り。奇数行では \(\mathcal V_R\) 自体を、偶数行では \(0\in\mathcal V_R\) の条件を記した。

**奇数 \(R\ge3\)**

| \(d\) | \(R\) の範囲 | \(\mathcal V_R\) |
|---:|---|---|
| 0 | \(R\le S-1\) | \(\{0\}\) |
| 0 | \(R=S+1\) | \(\{0,1\}\) |
| 0 | \(R\ge S+3\) | \(\{1\}\) |
| 1 | 全て | \(\{0\}\) |
| 2 | \(R\le S-1\) | \(\{0\}\) |
| 2 | \(R\ge S+1\) | \(\{1\}\) |
| 3 | \(R\le S-2\) | \(\{0\}\) |
| 3 | \(R\in\{S,S+2\}\) | \(\{0,1\}\) |
| 3 | \(R\ge S+4\) | \(\{0\}\) |
| \(d\ge4\) 偶数 | \(R\le2y+1\) | \(\{0\}\) |
| \(d\ge4\) 偶数 | \(R=2y+3\) | \(\{0,1\}\) |
| \(d\ge4\) 偶数 | \(R\ge2y+5\) | \(\{1\}\) |
| \(d\ge5\) 奇数 | \(R\le2y+1\) | \(\{0\}\) |
| \(d\ge5\) 奇数 | \(R=2y+3\) | \(\{0,1\}\) |
| \(d\ge5\) 奇数 | \(2y+5\le R\le S+2\) | \(\{1\}\) |
| \(d\ge5\) 奇数 | \(R\ge S+4\) | \(\{0\}\) |

**偶数 \(R\ge4\)**

| \(d\) | \(0\in\mathcal V_R\) となる条件 |
|---:|---|
| 0 または 2 | なし |
| 1 または 3 | \(R\ge S+1\) |
| \(d\ge4\) 偶数 | \(2y+4\le R\le S+2\) |
| \(d\ge5\) 奇数 | \(R\ge2y+4\) |

この表は、A子の \((x-1,y)\), \((x,y-1)\) を大きい順に整列して帰納式へ代入し、C子を \(z=1\) 公式で評価したもの。\(y=1\) の行ではB子に単一トークン \(z=3\) の公式を代入する。境界 \(x=y=1\) ではA子がなく、B/Cの二値だけで同じ表の \(d=0\) 行を得る。

奇数表から、\(\mathcal V_R=\{0,1\}\) となる位置が \(T_2\setminus\{1\}\)、\(\mathcal V_R=\{0\}\) となる位置が \(\mathcal O_2\)、\(\mathcal V_R=\{1\}\) となる残りの奇数位置である。偶数表から、\(0\in\mathcal V_R\) の位置が \(\mathcal E_2\)。よってmexは表示式に一致する。∎

## 構造上の意味

値2位置の形は、既存の三族予想の \(z=2\) をそのまま回収する。

- \(d=0\): 家族BのEXT位置 \(S+1=2y+1\)。\(y=1\) ではラダーの1と別に現れる。
- \(d=3=z+1\): 家族Aのランが \(S=2y+3\) と \(S+2=2y+5\) の2点になる。
- \(d\ge4=z+2\): 家族Aの定常位置 \(2y+3\) が1点だけ残る。
- \(d=1,2\): ラダーの \(R=1\) 以外はない。

例えば \(x=y=10\) では値2位置は \(\{1,21\}\)、\(x=13,y=10\) では \(\{1,23,25\}\)、\(x=15,y=10\) では \(\{1,23\}\)。差が3のときだけ家族Aの2点ランが残り、差が4以上では1点へ縮む。
