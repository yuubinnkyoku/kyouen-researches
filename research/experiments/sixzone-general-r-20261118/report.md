## 1. A-POS（a=0不在）の証明

**補題A-POS**: M≥3素数・main regime（κ∈[0,M−2]・(t,κ)≠(1,0)）で
σ_Z(M,K)=1ならば **a=v₂(N)≥1**。

証明: K0949定理PARITY（main regimeの値1ヒットKは全て偶数）よりKは偶数。
M+1は偶数なので K=(M+1)t+κ ≡ κ (mod 2) からκは偶数。
Y=K+1=(M+1)t+κ+1 は偶+偶+1で奇数。Mは奇素数なので
N=MY−1=奇·奇−1は偶数、すなわちa≥1。∎

（K=M+1特殊ケース・κ=M−1・κ=MはK0946 EXCL-2/EXCL-1で元々ヒット外。
M=2は本項のスコープ外。t=1のヒット（K0961で1,111件実在）にも適用され
a≥1が従う。）これでK0966が「a=0未証明（補題EXの(2^a−1)k₀が消滅）」と
していた隙間は、そもそもヒット側で起こらないことが確定した。
K0966・本項の全定理の仮定「a≥1」はA-POSで自動成立する。

## 2. 一般r定理群の証明

スコープ: 素数M≥5・main regime・t≥2・smoothヒット・r=kodd≥4・γ_r。
（t≥2でk₀ ≥ 2M−1 > Mであり窓は非退化。TWO-ZONE（K0961・t≥2）は
r非依存: Nの奇約数qは2^a·q ≤ M−1かq > k₀の一方のみ。）

### 補題GZ_r

q=p₂···p_{r−1}はNの奇約数でγ_rよりq ≥ M。窓空なのでq ∈ [M,k₀]は
不可能、ゆえ **q ≥ k₀+1**。∎

### 補題EX_r

各i∈{1..r}に対しmultiset相補積R_i := N/(2^a·p₁pᵢ)（整数）を定義する
（i=1はmult(p₁)≥2のとき2つのp₁位置を使用。mult(p₁)=1のときR₁は
非整数だがこの場合は下記の場合分けで処理する）。

(i) 2≤i≤r: R_i=(p₂···p_r)/pᵢ ≥ (p₂···p_r)/p_r = p₂···p_{r−1}
（pᵢ ≤ p_r）。
(ii) i=1・mult(p₁)≥2: R₁=p₂···p_r ≥ p₂···p_{r−1}。
いずれもγ_rより **R_i ≥ M**。

p₁pᵢ > k₀と仮定する（2≤i≤r、またはi=1かつmult(p₁)≥2）。このとき
R_i = (MY−1)/(2^a·p₁pᵢ) < MY/(2^a·k₀) = (M/2^a)·(Y/k₀)
= (M/2^a)·(1+(t+2)/k₀) 〔恒等式Y−k₀=t+2〕。
(M/2^a)(1+(t+2)/k₀) < M ⟺ t+2 < (2^a−1)·k₀ であり:
- a=1: (M−1)t+κ > 3（M≥5・t≥2で(4)·2=8 > 3）✓
- a≥2: (2^a−1)k₀ ≥ 3k₀ かつ 3k₀−(t+2)=(3M−1)t+3κ−5 ≥ 23 > 0 ✓

ゆえR_i < Mで矛盾。したがって **p₁pᵢ ≤ k₀**。
(iii) i=1・mult(p₁)=1: p₂ > p₁なので p₁² < p₁p₂ ≤ k₀（i=2の結果）。∎

### 定理SIX-ZONE_r

各i≥2: q=p₁pᵢはNの奇約数でEX_rよりq ≤ k₀。TWO-ZONEの二分法で
zone-2（q > k₀）が排除されているのでzone-1: **2^a·p₁pᵢ ≤ M−1**。
i=1: mult(p₁)≥2ならq=p₁²で同様。mult(p₁)=1なら
c·p₁ = 2^a·p₁² < 2^a·p₁p₂ ≤ M−1。ゆえ **c·pᵢ ≤ M−1 (∀i)**。∎

### 定理P2-LOWER_r / 系BAND_r

GZ_r: p₂p₃···p_{r−1} ≥ k₀+1。SIX-ZONE_r（i=3..r−1）: pⱼ ≤ B
（B=⌊(M−1)/c⌋）。よって **p₂·B^{r−3} ≥ k₀+1**（整数形）。
実数形ではp₂ > c^{r−3}k₀/(M−1)^{r−3}。さらにp₂ ≤ B（i=2）を
組み合わせると **k₀+1 = Mt+κ ≤ p₂·B^{r−3} ≤ B^{r−2}**。∎

### 定理Y-CAP_r

Y=(N+1)/M=(c·p₂···p_r+1)/M。SIX-ZONE_rよりp₂···p_r ≤ ((M−1)/c)^{r−1}
なので Y ≤ ((M−1)^{r−1}/c^{r−2}+1)/M。一方Y=(M+1)t+κ+1 > (M+1)t。
ゆえ **t·c^{r−2}·M·(M+1) < (M−1)^{r−1}+c^{r−2}**。κは
Y > (M+1)tの評価にしか現れないためκ=0行にも無条件。∎

r=4でSHARP-V（K0966）・r=5で t·c³M(M+1) < (M−1)⁴+c³
（c=6: t ≲ M²/216）。BAND_r（≈M^{r−3}/c^{r−2}）よりY-CAP_rが
因子(M−1)/(M+1)分だけ常に鋭い（r=4と同型）。

### γ₄ ⟺ SIX-ZONE₄（定理）

K0961 K4-CAP: t≥2のkodd=4ヒットは全てcase Aでp₂p₃の位置による
3分岐は排他。(β)は空、(α)はp₁p₄ ≥ Mゆえi=4でc·p₄=2^a·p₁p₄ ≥ 2M > M−1
でSIX-ZONE₄不成立、(γ)はSIX-ZONE₄成立（上記）。∎

r≥5での同値性（SIX-ZONE_r ⟹ γ_r）はOPENとする（§4のcensusは0例外）。
