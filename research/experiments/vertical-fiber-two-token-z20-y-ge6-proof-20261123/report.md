## 主定理

d=x-y、Y=2y、S=x+y と置く。O[a,b] は [a,b] 内の奇数、E[a,b] は偶数、I[a,∞) は全整数区間とする。
過渡25行とは 2y+d<=20 を満たす (y,d) 全体である（y>=6 では (6,0..8),(7,0..6),(8,0..4),(9,0..2),(10,0) の25行。
うち対角行 S=20 は (6,8),(7,6),(8,4),(9,2),(10,0) の5行、残る20行が S<20 の標準過渡行）。それ以外は S>=21 である。

Grundy値2の位置集合は

\[
T(x,y)=
\begin{cases}
O[1,S]\ \text{（S偶数なら O[1,S-1]）} &S<20,\\
O[1,Y+(d+20)/2]\ \text{（d≡2）、} O[1,Y+(d+20)/2-1]\ \text{（d≡0 mod 4）} &S=20,\\
O[1,19]\cup O[Y+21,S+20] &d=21,\\
O[1,19]\cup\{Y+21\} &d\ge22,\\
O[1,19]\cup\{Y+(d+20)/2\} &d\equiv2\pmod4,\ d\le18,\\
O[1,19] &\text{その他}.
\end{cases}
\]

S=20 の5対角行では値2ラダーが (6,8),(7,6),(8,4),(9,2),(10,0) の順に 25/27/27/29/29 まで伸びる
（ラダーが19を超える行）。S>=21 ではラダー上端は z-1=19（偶数z型、z=18のK1259と同じ）。

Grundy値1の位置集合は

\[
P(x,y)=
\begin{cases}
I[S+1,\infty) &S<20,\ S\text{ 奇数},\\
\varnothing &S\le20,\ S\text{ 偶数（S=20対角5行のPは全Rで空）},\\
O[21,Y+19]\cup E[Y+22,S+20] &d\ge22,\ d\text{ 偶数},\\
O[21,Y+19]\cup E[Y+22,S+19]\cup I[S+21,\infty) &d\ge23,\ d\text{ 奇数},\\
O[21,Y+19]\cup E[Y+22,S+21]\cup I[S+22,\infty) &d=21,\\
O[21,A_1]\cup I[A_1+2,\infty) &d\text{ 奇数},\ d\le19,\\
O[21,A_1] &d\text{ 偶数},\ d\le20,
\end{cases}
\]

ただし A_1 = Y+13+2⌊(d-8)/4⌋（d<=20。⌊·⌋ は負方向へのfloorを含む: d<=8 では
A_1=Y+9やY+11に下がる。d>=21 では使われずpin帯側の cap Y+19 が相当）。
A_1 は格子行 d≡2 (mod 4) では前倒し点 Y+(d+20)/2 のちょうど2下、
不活性偶行 d≡0 (mod 4) では前倒し点候補 Y+(d+20)/2（偶数、非出現）の1下になる
（z=18のA_1相対位置則と同じ）。
T(x,y) と P(x,y) を [1,S+20] に制限した集合は互いに素である
（署名帯表の一意被覆と深部散点検査で全称にわたり照合）。残りはGrundy値0であり、
全ての x>=y>=6、R>=0 に対して

\[
\boxed{H(R;(x,y);20)=
\begin{cases}
S\bmod2 &R\ge S+21,\\
2&R\in T(x,y),\\
1&R\in P(x,y),\\
0&\text{otherwise}
\end{cases}}
\]

が成立する。R=0 は終局値0である。R>=S+21=S+z+1 の tail が最優先で評価され、
P の無限区間は [1,S+20] でのみ有効である。

## 配置の意味

- **値1基底帯は奇数 O[21,A_1]**。z=18の O[19,·] の z+2 シフトで、下端節 z+1=21 は
  全z共通の「値1の下端節 z+1」そのもの。z=16/z=18と同じ偶数z型。
- **偶数z型の非編集継承**。z=19（奇数z）には d≡2 (mod 4) 偶行への U+1 一点追加が
  必要だったが、z=20 では不活性偶行 d≡0 (mod 4) に追加点は不要で、
  z=18 の構造が mod 4 位相回転（活性格子 d+z≡2 (mod 4) → d≡2）込みで
  そのまま継承される。census 364行・親box 28,830点・散点・クロージャ掃引で
  追加点は一切出現しない。
- **前倒し格子**: 全z規則 d+z≡2 (mod 4) は z=20 では d≡2 (mod 4)、
  r=Y+(d+20)/2（d=2,6,10,14,18 で r=Y+11,Y+13,Y+15,Y+17,Y+19、常に奇数R）。
  d≡0 (mod 4) の候補位置は偶数Rに落ち値1帯に吸収される。
  d=22 の候補 Y+21 は定常 pin と重合（z=18 の d=20 と同型）。
- **pin**: 定常 pin は Y+21=2y+z+1（偶数z型。z=17/z=19 の 2y+z と対照）。
  d>=22 の全行で T={O[1,19],Y+21}。
- **掃引行**: d=z+1=21 の行は掃引帯 O[Y+21,S+20]=O[pin,S+z]（下端がちょうど pin 位置。
  z=18 の O[S,S+18] と同型、z=19 の O[Y+19,S+19]=O[2y+z,S+z] と対照）。
- **pin帯の E**: d>=22 の E 帯は E[Y+22,S+20]（偶d）/E[Y+22,S+19]（奇d）で、
  d=22 (=z+2) は全帯 '02'、d>=23 は {Y+22} の '02' 点と [Y+24,·] の '0' 帯に署名分離。
  d=20 (=z) 行は値0の E 終帯 [Y+20,S+20] が '123' になる特異形（z=18 の d==18、
  z=16 の d==17 に対応）。
- **奇数d<=19行の P は単一ギャップ型**: O[21,A_1] の直後に A_1+1 の1点だけを抜いた
  I[A_1+2,∞) が続き（z=18 と同型の稠密tail）。
- **対角S=20の5行**: 拡張ラダー上端 Y+(d+20)/2-(0 if d≡2 else 1) は
  25/27/27/29/29=2y+(d+20)/2 の偶奇調整で、P が全 R で空（z=18 の S=18 対角と同型。
  z=19 の S=19 対角は P非空だったのと対照的）。上端の交差一致は
  25/27/27/29/29 の5実例目（z=18 では 23/25/25/27、z=19 では 25/25/27/27）。
- **署名の行別分布**: S=21 の4行（(6,9),(7,7),(8,5),(9,3)）と (10,1) は初期帯 [22,A_1+1] の
  コードが '1' でなく '12' になる例外クラスで、'023' 点を持つのは d%4==3
  （z=18 の d%4==1 からの位相回転）。S>21 の奇数行は d%4==3 が '023' 点 A_1+3、
  d%4==1 が '12' 点 A_1+1 の後 A_1+3 から '0'。
- **tail と低R**: R>=S+21=S+z+1 で値 S mod 2（tail開始族式 S+z+1 は全出版族共通）。
  低Rは R<=26=z+6 で単一トークン S=x+y に縮約し、境界は R=27 で鋭く破れる:
  witness (16,6)@R=27 は H=2 に対し単一トークン値 1。R<=z+6 は z=14,15,16,17,18,19 に続き
  7例連続（一般z版は未証明の観察）。witness行 (12,6)(z=18),(14,6)(z=19),(16,6)(z=20) は
  2刻みで y=6 行を維持、破壊高さ R=z+7 は全系共通。

## 証明骨子

y強帰納と各行内の d 外帰納による。y=6 の B子は K1126（y=5族全zパラメトリック証明の
z=20行。固定z y=5切片はK1126で不要化済み）、C子は 1⊕K1261（z=19,y>=6一様族）、
y>=7 の B子は y 帰納仮定、A子は d 外帰納仮定（d=0 は A==B 多重集合合流）とする。
1<=R<=S+20 の全域を過渡25行込みの偶奇別A/B/C署名帯表（TRANSIENT 25行の固定帯 +
S>=21 の7クラス・パラメトリック帯（掃引/pin/d=z特異/活性格子/不活性偶行/奇数2クラス））で
一意被覆し、各帯コードの子値集合から mex を機械計算する。R=0 は終局、R>=S+21 は
K0832 一般 tail。各 (y,d,R) で子の値集合と mex が帯コード・親閉形式の3者で一致する
ことを監査が機械照合する。
