# q∈{2,3} 完全退化 — 定理・独立機械監査（2026-11-15）

## 目的

固定幅 w×m 盤・禁止族 = 直線と円 の標準版で、q = 2, 3 の全領域
（全 w ≥ 1・全 m ≥ 1）を閉形式で決定する。repo の M_{w,q} 横断表
（K0795・results/fixed-width/mwq_stabilization.csv）は q ≥ 4 から
始まっており、q < 4 は未記録だった（検索確認: M_{w,3}・M_{w,2} の
記述なし。K0832 は多項式超曲面ファイバーゲームで別設定）。

## 定理（K0855・全称証明）

幾何的事実: 任意の2点は一直線上、任意の3点は一直線上または
同一円上（非共線なら一意の外接円）。よって q ∈ {2,3} では
全ての q 点部分集合が禁止曲線を含み、セル数 ≥ q−1 の盤面で:

1. safe(S) ⟺ |S| ≤ q−1
2. 極大 safe ⟺ |S| = q−1
3. w ≥ 2: 任意の (q−1) 石配置は行欠損（全行 ≥ q−1 石には
   w(q−1) 石が必要なのに |S| = q−1 < w(q−1)）かつ極大
   → 全幅 m ≥ 1 で witness 存在、witness 帯 = [1, ∞)、
   満容量安定化は決して起きず **M_{w,q} = ∞**
4. w = 1: 全極大が単一行 q−1 石 = 行容量 → m ≥ q−1 で安定、
   **M_{1,q} = q−1**
5. 全極大が同一サイズ → **g(S) = ((q−1) − |S|) mod 2**
   （通常対戦: q=2 先手1手勝ち・q=3 後手2手勝ち。
   完成勝利規則なら q=2 後手・q=3 先手）
6. q ≥ 4 が最初の非退化 q: safe 4 点集合の例
   (0,0), (1,0), (0,1), (2,2)（4共線なし・外接円
   中心 (1/2,1/2)・r²=1/2 に (2,2) は不乗）
7. 3点は2次元部分空間に収まる → 退化は d 次元でも持続

## 監査設計（scripts/q23_degeneracy_check.py・独立実装）

各盤面で全曲線 census を構築: ≥2 点を通る全直線（対から正規化
・重複除去）と ≥3 点を通る全円。円の構成は repo 既存 checker
（4x4 行列式・方程式系）と独立な**周心構成** — 3点の垂直二等分線
の交点を純 Fraction で解き、squared distance の等値で所属判定。

5検査:

- **A census 退化**: 全ての q 点部分集合が census 曲線上にある
  （= どの違反も census を逃れない。符号化の健全性）。
- **B 全部分列挙**: 盤面の全部分集合（2^n）について
  safe ⟺ |S| ≤ q−1・極大 ⟺ |S| = q−1 を照合。
- **C blocked**: 全 (q−1) 石配置・全空点が K0853 定義の blocked
  （c を通る census 曲線が ≥ q−1 石を含む）。
- **D 欠損構造**: w≥2 で全 (q−1) 石配置が行欠損（= その幅の
  全極大が witness）。w=1 で欠損極大 0 件。
- **E Grundy 完全逆算**: 安全 DAG 上で mex を全逆算し
  g = ((q−1)−|S|) mod 2 と照合。

## 解釈・接続

- 欠損 witness 探索（K0821型 class-split）は q=3 では自明 SAT:
  全幅で 2 石 witness。def-mode 符号化・デコーダの
  **正の制御族**（witness 2 石・復号検査は定数時間）。
- M 表の q<4 コーナーが閉じた。非自明な領域は q ≥ 4 から。
- K0853/K0854 の blocked・停止セル理論は q=3 でも成立するが
  停止セルは常に存在しない（全空点が必ず blocked のため
  R(S) = ∞・witness は全幅で帯延伸不要）— 自由列追加の
  自明な極限ケースとして理論の整合確認に使える。

## 限界

- 有限監査は実装・census 整合の確認であり、全称主張の根拠は
  数学的証明（本文の2行事実の展開）。
- 標準版（直線+円）限定。円のみ・多項式超曲面（K0832）等の
  変種には適用しない。
- d 次元は幾何的事実の持続のみ主張。
