# 5個の残余禁止集合でGrundy値7、5個の4点禁止集合で値6

2026-10-19。標準の「安全な着手だけを合法手とする」通常プレイを、有限超グラフ上の回避ゲームとして扱う。頂点は未着手の候補点、辺は全頂点が占有されると禁止になる包含極小集合。**以下の辺集合は抽象的な残余ゲームであり、整数格子への幾何実現は主張しない。**

## 厳密な存在結果

### 5辺、辺の大きさ2〜4、9頂点、空局面g=7

頂点集合 `{0,...,8}`、禁止集合を

```
{1,3,4}
{1,7}
{3,5,7,8}
{2,5,7}
{5,6}
```

とする。初手 `0,...,8` の子局面のGrundy値は順に

```
[6,1,2,5,4,3,2,0,4]
```

である。`{0,1,2,3,4,5,6}` をすべて含むので `mex=7`。全512部分集合を計算し、244局面が安全。頂点0はどの禁止集合にも属さない自由点であり、残る8頂点の空局面Grundy値6と自由点の値1の排他的論理和として7が生じる。

### 5辺すべて4点、12頂点、空局面g=6

頂点集合 `{0,...,11}`、禁止集合を

```
{1,3,4,8}
{3,5,9,10}
{0,1,9,11}
{0,2,7,8}
{6,7,9,11}
```

とする。初手 `0,...,11` の子局面のGrundy値は

```
[5,1,4,1,3,0,3,1,2,2,0,5]
```

であり、`mex=6`。全4096部分集合を計算し、3078局面が安全。5辺は互いに包含関係を持たない。各2辺の共通点数も高々2だが、この必要条件だけでは幾何実現を保証しない。

### 5辺、辺の大きさ2〜4、8頂点、空局面g=6

```
{1,4}, {2,5,7}, {0,1,5,6}, {6,7}, {1,3,6}
```

初手子の値は `[5,2,5,3,3,4,1,0]`、全256部分集合中122局面が安全。

## 全称的な帰結（数学的証明）

任意の `h>=5` に対して、辺数ちょうどh、辺サイズ2〜4の有限回避ゲームで空局面Grundy値7を実現できる。上記9頂点の5辺ゲームに、頂点が互いに素な3点禁止集合を `h-5` 個追加する。単独の3点禁止集合ゲームの空局面Grundy値は0（最大2手で終わる）なので、独立和のGrundy値の排他的論理和により元の7が保存される。

同様に、辺数6で4点辺のみの空局面Grundy値7を実現できる。上記12頂点の値6のゲームと、独立した4点禁止集合1個（Grundy値1）を直和すると `6 xor 1 = 7`。

これらは**存在下界**であって、5辺で7が最大であるという上界ではない。ランダム探索で8以上を見つけていないことは証明ではない。整数格子・標準正方形盤の残余局面としての実現も未証明。

## 検証・再現

```
python3 verify.py
python3 crosscheck.py
c++ -std=c++17 -O2 independent.cpp -o independent
./independent
```

`verify.py` は占有ビット集合を大きい順に処理する反復的なmex計算、`independent.cpp` は**未占有集合**から頂点を除去する再帰的なmex計算である。3例の全局面（512+4096+256=4864ビット集合）の安全判定とGrundy値が完全一致した。`result.json` はPythonによる全局面値のハッシュ、分布、初手値を保存する。計算器は標準ライブラリのみで動作する。

形式的には、すべての局面のGrundy値が再帰式 `g(S)=mex{g(S∪{v}) : S∪{v} が安全}` に一致することを、有限個の局面に対する帰納法で確かめている。独立C++照合は実装誤りへの追加監査であり、無限族の帰結には独立和の数学的議論を使用した。

## 研究上の位置づけ

4辺・辺サイズ2〜4の上界5（2026-10-19の未統合研究）に対し、5辺で7を達成できるため、4辺から5辺への上界拡張では値5は維持できない。4辺結果自体がmainに未統合であることに注意する。
