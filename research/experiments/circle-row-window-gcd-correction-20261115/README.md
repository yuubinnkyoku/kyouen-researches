# 円の行窓分母補題の訂正 — 最大公約数による正確な形

## 要旨

既存の K0831 は、二重行の任意の行間隔 δ について q | 4δ を証明している。この部分は正しい。

一方、そこから一般の w 行・d 二重行に対して
\[
q\mid 4\left\lceil\frac{w-1}{d-1}\right\rceil
\]
とした系は誤りである。短い行間隔 δ が上限値と等しいとは限らず、割り切りは上限値へ移せない。

正しい強い形は、二重行位置の差の最大公約数を使う。

## 訂正後の全称補題

二重行の位置を相異なる整数
\[
Y=\{y_1,\ldots,y_d\}
\]
とし、
\[
g=\gcd(y_2-y_1,\ldots,y_d-y_1)>0
\]
と置く。真円の中心を (α,β)、既約分数表示を 2β=p/q（q>0, gcd(p,q)=1）とする。

二重行 y_i の左右の整数点の差を u_i>0 とすれば、
\[
u_i^2-u_j^2=4(y_j-y_i)(y_i+y_j-2\beta).
\]
従って
\[
q(u_i^2-u_j^2)=4(y_j-y_i)\bigl(q(y_i+y_j)-p\bigr).
\]
gcd(q,q(y_i+y_j)-p)=1 なので、全ての i,j について
\[
q\mid4(y_j-y_i).
\]
特に i=1 とした差の最大公約数を取り、Bézout の等式を使うと
\[
\boxed{q\mid4g}.
\]

さらに、二重行は全て同じ剰余類 modulo g に属する。長さ w の連続整数行窓に含まれるその剰余類の点数は高々 floor((w-1)/g)+1 だから、
\[
d\le \left\lfloor\frac{w-1}{g}\right\rfloor+1,
\qquad
\boxed{g\le\left\lfloor\frac{w-1}{d-1}\right\rfloor}.
\]
従って
\[
\boxed{q\mid4g,\quad
g\le\left\lfloor\frac{w-1}{d-1}\right\rfloor,\quad
q\le4\left\lfloor\frac{w-1}{d-1}\right\rfloor}.
\]
より具体的には、q は
\[
\bigcup_{1\le h\le\lfloor(w-1)/(d-1)\rfloor}\operatorname{Div}(4h)
\]
のいずれかに属する。これは必要条件であり、十分条件とは主張しない。

## 旧系を否定する厳密な反例

次の円を考える。
\[
9(x+2)^2+(3y+14)^2=325,
\]
すなわち中心は (-2,-14/3)、従って
\[
2\beta=-28/3,\qquad q=3.
\]

円上の整数格子点はちょうど
\[
(-7,-8),(3,-8),(-8,-5),(4,-5),(-4,1),(0,1)
\]
の6点である。完全性は
\[
|3y+14|\le\sqrt{325}<19
\]
より -10≤y≤1 に限って整数平方を直接調べればよい。

二重行は Y={-8,-5,1}、行窓は -8,...,1 の w=10、d=3 である。
\[
g=\gcd(3,9)=3,\qquad
\left\lfloor\frac{9}{2}\right\rfloor=4,\qquad
\left\lceil\frac{9}{2}\right\rceil=5.
\]
従って正しい条件は q=3 | 4g=12 で満たされる一方、旧系の q | 4·5=20 は満たされない。

これは円そのものによる反例であり、単なる整数列の反例ではない。

## K0830 の7行帰結への影響

K0830 が使う場合は変わらない。

- w=7,d=5: g≤floor(6/4)=1 より g=1、従って q|4。
- w=7,d=4: g≤floor(6/3)=2、従って q|4g。g=1,2 のどちらでも q|8。

よって K0830 の q∈{1,2,4} および q∈{1,2,4,8} という7行専用の候補制限、ならびに同項目の円分類は影響を受けない。

## 検証

scripts/verify_counterexample.py は標準ライブラリのみを用い、円上の全整数点、中心分母、行位置の最大公約数、旧系の失敗、訂正後の割り切りを整数・有理数演算で再確認する。加えて7行窓の d=4,5 の全部分集合（35件・21件）で上記の g 上界と K0830 の帰結を検査する。

この有限検査は補題の証明の代わりではない。全称部分は上の Bézout と剰余類の個数による証明である。

## 変更範囲と限界

- K0831 の二重行対ごとの q|4δ は維持し、一般 w,d の誤った ceil 割り切り系だけを訂正する。
- K0830 の7行分類は維持するが、一般 w の説明を訂正する。
- これは分母に関する必要条件であり、円の存在条件や P(w) の完全分類を与えるものではない。
