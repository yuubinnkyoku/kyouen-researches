# 容量余裕2の完全Grundy閉公式と独立検証（2026-10-08）

## 状態・射程

K0352 の抽象容量ゲームを扱う。整数 `2<=h<w`, `m>=1`, `0<=x_w<=...<=x_1<=m`, `r<h*m`、安全性 `sum_{i=1}^h x_i<=r` を仮定する。本稿の定理は `sigma=r-sum_{i<=h}x_i=2` に適用する。幾何学上の K0352 の平行列盤への移送には `q=r+1>2w` 等が必要であり、標準2次元正方形盤への主張ではない。

```
n=w-h
b=x_h
R=n*b-sum_{i>h}x_i
c=#{i<=h:x_i=b}
delta=sum_{i<h}(m-x_i)
gamma=x_{h-1}-b   # only if c=1
eta=1 if (c=1 and (gamma=1 or delta=1)) else 0
```

**全称定理：**

```
g(x)=(R+((n mod 2)*eta)) mod 2.
```

したがって容量余裕2では、すべての有限パラメータ、すべての安全局面で **g(x) は0または1のみ**。奇数 `n` では `gamma=1` または `delta=1` の一意最小上位列構造だけが、単純な `R` の偶奇を反転する。偶数 `n` では K0352 の既存の全局面二値定理から `g(x)=R mod2` が従う。

## 無界・全称証明（奇数 n）

容量余裕2を保つ合法手は、上位 `h` 列の形を変えず、`b` 未満の下位列を1増やす手だけである。これは `R` を1減らし、`c,delta,gamma` を不変にする。したがって `R>0` では、余裕2の子はすべて帰納仮定により同じ Grundy 値 `(R-1+eta) mod2` を持ち、`R=0` なら余裕2の子はない。

残る合法手（高さ `b` 以上の列に打つ手）はすべて容量余裕1へ移り、K0358 の全称公式で値が厳密に決まる。以下 `p=R mod2` とし、`E_p` を**余裕1へ移る子の Grundy 値集合**とする（重複した列の着手は値集合にまとめる）。

| 上位 h 列の形 | E_p | eta |
|---|---|---|
| c>=3 | {1-p} | 0 |
| c=2 | {2+p}、上位 b より高い未満杯列があれば {1-p} を追加 | 0 |
| c=1, gamma=1, delta=1 | {p} | 1 |
| c=1, gamma=1, delta>=2 | {p,2+p} | 1 |
| c=1, gamma>=2, delta=0 | {1-p} | 0 |
| c=1, gamma>=2, delta=1 | {p,3-p} | 1 |
| c=1, gamma>=2, delta>=2 | {2+p,3-p} | 0 |

表の列挙が尽きる理由を詳述する。最小値 `b` の列へ着手する型と、`b` より高い上位列（`m` 未満）へ着手する型の二通りしかない。

- `c>=3` ではどちらの型も、着手後の上位最小値が重複する。余裕1の子は K0358 により `1-p`。
- `c=2` では `b` を上げると `b` が一意最小になり、次の高さ `b+1<m` が未満杯である（`b=m-1` なら `r>=h*m` となり仮定に矛盾）。よってその子は `2+p`。高い非満杯列に打つ場合は重複最小のままで `1-p`。
- `c=1, gamma=1` では `b` を上げると最小 `b+1` が重複する。境界の残り手数は `R+n` なので奇数 `n` に対してその余裕1子は `p`。高い列を増やしても他の非満杯上位列が残るとき（`delta>=2`）は `2+p`、唯一の非満杯上位列を満杯にした場合（`delta=1`）は `p`。
- `c=1, gamma>=2` では `b` を上げても新しい最小 `b+1` は一意で、上位の非満杯列が残れば余裕1子は `3-p`。すべて満杯（`delta=0`）なら `1-p`。高い非満杯列を増やす場合は、まだ高い非満杯列が残れば `2+p`（`delta>=2`）、最後の1枠を埋めれば `p`（`delta=1`）。

`gamma=1,delta=0` は非自明領域 `r<h*m` に矛盾するので起こらない。`c=2` の際の `b=m-1` も不可能である。ゆえに全場合分けは漏れない。

上の表に対して `R=0`（`p=0`）なら、`mex(E_0)=eta` が直接確かめられる。これは `g=(R+eta) mod2` の基底である。

`R>0` なら同じ最小形を保つ余裕2の子が少なくとも一つあり、その全子の Grundy は帰納仮定によって `(R-1+eta) mod2=1-((R+eta) mod2)` である。表の各 `E_p` にこの値を一つ加えて mex を取れば、全7場合で `(R+eta) mod2` が得られる。従って `R` に関する帰納法で無界の公式が成立する。□

**偶数 n**：K0352 より全到達終局サイズの偶奇が同じで、`g(x)=(r+n*A(x)-|x|) mod2`。容量余裕2では `|x|=(r-2)+sum_{i>h}x_i` なので、この値は `R mod2` となる。これで偶数 `n` も全称的に処理された。
