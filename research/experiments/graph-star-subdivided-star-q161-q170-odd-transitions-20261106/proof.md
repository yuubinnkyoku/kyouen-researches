## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおくと負根条件は \(F_k(y)=r-y-(a-y)y^k=0\)。\(r\ge158\) では \(y\le1\)、\(a\le y\le r\)、\(y>r\) に根がなく、候補は \(1<y<a\) のみ（\(y>r\) では \((y-a)y^k>y-r\)）。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大。

非存在境界 \(k_-\) では \(H_{k_-}(y_*)<r-a\) を検査し \(F_{k_-}>0\)。存在境界 \(k_+=k_-+2\) では \(1<y_*<a\) および \(H_{k_+}(y_*)>r-y_*\) を検査する。\(F_k(1)>0,F_k(a)>0\) より2根が存在。\(T_{k,r}(-x)\) の符号変化は2回なのでデカルトの符号法則からちょうど2つの相異なる単根。正根は全係数正で不存在。\(1<y<a\) では \(H_k(y)\) は k とともに厳密増加するため境界から全奇数次数へ拡張。

\(A=k(r+2), B=(k+1)(r+1)\) とすると \(y_*=A/B\)。非存在側は \((r^2-2)(k+1)B^k>(r+2)A^k\) （\(r-a=(r^2-2)/(r+1)\)）を、存在側は \((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\) を整数演算で確認した。先行q=151〜160と同じ解析枠組みであり、新規部分は20境界の検証。

```python
for q in range(161, 171):
    r = q - 3
    kp = 2193 + 16 * (q - 161)
    for k, exists in ((kp - 2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if exists:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
    print(q, "PASS")
```
