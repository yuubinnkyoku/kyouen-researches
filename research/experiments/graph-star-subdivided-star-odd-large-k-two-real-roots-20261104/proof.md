# 一辺細分星：奇数枝数・任意 q で十分大きい場合の実根数（2026-11-04）

## 対象と既存成果との差分

K0648 と `graph-star-subdivided-star-exact-real-roots-20261104/proof.md` の全終局長差多項式
```
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1},
r=q-3>=1
```
を扱う。既存証明は奇数 k・r=1 の実根2個を確定した。ここでは未分類だった **奇数 k・r>=2** について、明示的な十分条件で実根数を確定する。標準格子盤に対する定理ではない。

## 定理（全称的な十分条件）

整数 r>=2 と奇数 k>=3 に対し、
```
(1+1/(2(r+1)))^k > 2r^2-3
```
なら、T_{k,r} は相異なる負の実根をちょうど2個持ち、いずれも単根である。残りの k-1 個の根は非実根（重複度込み）。

特に各固定 r>=2 に対して、すべての十分大きい奇数 k で実根数は厳密に2となる。明示的には
```
k > log(2r^2-3)/log(1+1/(2(r+1)))
```
を満たす奇数 k で成立する。

## 証明

x>0 とおく。奇数 k では
```
P(x):=T_{k,r}(-x)=x^k(x-r-2)+(r+1)^k(r(r+1)-x).
```
P(0)=r(r+1)^{k+1}>0。x_0=r+3/2 とすると x_0-(r+2)=-1/2 および r(r+1)-x_0=r^2-3/2 より
```
P(x_0)=(r+1)^k[(r^2-3/2)-(1/2)(1+1/(2(r+1)))^k]<0
```
が仮定から従う。また x=r+2 では
```
P(r+2)=(r+1)^k(r^2-2)>0
```
（r>=2）。中間値の定理により (0,x_0) と (x_0,r+2) にそれぞれ異なる正の零点がある。

一方、P の非零係数の降冪符号列は +,-,-,+ で符号変化は2回。デカルトの符号法則から正の零点は重複度込み高々2個。よって見つかった2個がすべてであり、いずれも単根である。T の係数は非負、定数項は正なので非負実根は存在しない。証明終。

## 検算と境界

r=2 の十分条件は (7/6)^k>5 であり、例えば奇数 k>=11 で成立する（整数比較 7^11>5*6^11）。この検算は証明の必須部分ではない。

この条件は**十分条件**であり、これを満たさない k における実根数を主張しない。既存の奇数 k・r=1 定理とは量化範囲が異なる。根の数値近似や有限列挙を全称証明の代わりには用いていない。
