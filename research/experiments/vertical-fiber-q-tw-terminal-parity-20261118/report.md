# q=tw 純ファイバーゲームの全局面Grundy値 — 終局石数の一意性

報告日: 2026-11-18

## 設定

K0832の厳密占有縮約後の純ファイバーゲームを考える。幅を w=|B|≥1、高さを m=|A|≥1、ファイバー次数上限を t≥1 とし、底面跡制約は置かない。占有ベクトル c=(c_1,...,c_w) の安全条件と着手は

- Σ_i min(c_i,t) ≤ q−1
- 一成分を1増やし、安全条件を保つ

である。ここでは禁止点数を q=tw とする。

## 主定理

安全局面 c のGrundy値は、全ての t,w,m≥1 について

\[
G(c)=(N(t,w,m)-\sum_i c_i)\bmod 2,
\]

ただし

\[
N(t,w,m)=
\begin{cases}
wm,&m<t,\\
(w-1)m+t-1,&m\ge t.
\end{cases}
\]

従って全局面のGrundy値は0または1に限られる。これは最大値だけでなく、全安全局面の値を決める閉形式である。

## 証明

鍵は、終局の占有型が一つに決まることにある。

### m<t の場合

各成分は c_i≤m<t なので min(c_i,t)=c_i である。また

\[
\sum_i c_i\le wm\le w(t-1)\le tw-1.
\]

したがって全ての占有ベクトルが安全であり、空きがある限りその成分を増やせる。終局は c=(m,...,m) だけで、石数は N=wm。

### m≥t の場合

s を c_i≥t である成分数とする。安全容量は tw−1 である。

- s≤w−2 なら未飽和成分が少なくとも2個ある。容量和は高々
  st+(w−s)(t−1)=tw−(w−s)≤tw−2。
  よって容量に少なくとも1の余裕があり、未飽和成分を増やせる。終局ではない。
- s=w−1 なら未飽和成分はちょうど1個である。その値が t−1 より小さければ容量に1以上の余裕があり、その成分を増やせる。値が t−1 なら容量和は tw−1 で埋まるが、飽和成分のどれかが m 未満なら min(c_i,t) を変えずにその成分を増やせる。
- s=w は容量和が tw となり、安全条件に反する。

従って終局は、w−1成分が m、残る1成分が t−1 である置換に限る。逆にこの型からは、未飽和成分を増やすと容量違反になり、飽和成分は既に満杯なので着手できない。終局石数は常に N=(w−1)m+t−1 である。w=1やt=1もこの記述に含まれる。

### 終局石数からGrundy値へ

どの着手も石数をちょうど1増やす。上の分類により、任意の安全局面 c から終局までの全ての着手列は、長さ N−Σ_i c_i で終わる。

残り着手数 k に関する帰納法を使う。k=0なら終局でGrundy値0。k>0なら全ての子局面の残り着手数は k−1 なので、帰納法により子のGrundy値は全て (k−1) mod 2 で一致する。従って選択肢集合はその一値だけであり、その mex は k mod 2 である。よって主張が従う。∎

## 4×m・q=8 への具体化

t=2、w=4、q=8 では

- m=1: 全4ファイバーが満杯になるまで進み、N=4。
- m≥2: 終局型は (m,m,m,1) の置換だけで、N=3m+1。

従って

\[
G(c)=
\begin{cases}
(4-\sum_i c_i)\bmod2,&m=1,\\
(3m+1-\sum_i c_i)\bmod2,&m\ge2.
\end{cases}
\]

4×m・q=8 の全安全局面が0/1に分類された。mの安定化を待つ必要はない。

またK0832の既存q=7分類では、w=4,m=3の局面 c=(3,2,1,0) がGrundy値3を持つ。したがって幅4では、q=7からq=8へ禁止点数を1増やした境界で最大値が3から1へ落ちる。この差は、q=twが単なる上界ではなく、終局構造が切り替わる境界であることを示す。

## 独立有限監査

検証器は、次の二方式で状態と遷移を別々に生成した。

1. ラベル付き占有ベクトルを列挙し、各座標を増やす全合法手から直接再帰mexを計算。
2. 正の占有数を降順に並べた多重集合を列挙し、同値成分をまとめた正準遷移から再帰mexを計算。

対象は t=1..5,w=1..5,m=1..7 の175組に、t=2,w=4,m=8..30 の23組を加えた198組。

| 監査量 | 結果 |
|---|---:|
| ラベル付き状態 | 2,029,831 |
| 正準多重集合状態 | 98,335 |
| 閉形式との不一致 | 0 |
| 二方式間の不一致 | 0 |
| 値0の状態 | 1,014,963 |
| 値1の状態 | 1,014,868 |

4×m・q=8 のm=1..30だけでは、ラベル付き1,733,520状態、正準多重集合87,295状態を検査した。不一致は両方式とも0。

検証器を独立に2回起動し、監査JSONはバイト単位で一致した。検証器SHA-256は d555047ba0d56f4240a2528a0a710eb9580a72b3793c84cd9502ca0c5f119a24、監査JSON SHA-256は 91dcd8c589478ded575810a7ed527af02f2dff7ee3261f0d250ae308f85344b5。

この有限監査は実装照合であり、全称性の根拠ではない。全称性は終局型の完全分類と、固定終局長からGrundy値を導く帰納証明による。

## 適用範囲

- 底面跡制約なしの抽象純ファイバーゲーム。
- K0832の全多項式族に対する厳密占有縮約を適用した後のゲーム。
- 底面跡制約を併用する場合、固定底面次数・既約性を課す部分族、標準二次元共円ゲームの固定幅安定化長には、そのまま適用しない。
- q=tw の全称分類であり、q<tw の全局面分類を主張しない。

## 次の境界

q=tw−1 では終局型が複数現れ得る。既存の全t最大値定理は最大値を決めるが、全局面の閉形式は別問題として残る。
