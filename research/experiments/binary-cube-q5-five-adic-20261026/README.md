# 5点超平面切片の5進差分・最小周期・4本の零点枝（2026-10-26）

## 対象と結論

`E_{d,5}` は二値超立方体 `{0,1}^d` と実アフィン超平面の交点がちょうど5頂点になる**異なる頂点集合**の数（K0561）。`d>=5` とする。

**全称定理：** 任意の整数 `t>=0` と `d>=max(5,t+1)` に対して

$$
\boxed{E_{d+4\cdot5^t,5}-E_{d,5}\equiv 2^d5^t\pmod{5^{t+1}}.}
$$

右辺の5進付値はちょうど `t` なので、差の付値も**正確に `t`**。従って任意の `t>=1` に対し、`E_{d,5} mod 5^t` の**最小の最終周期は `4\cdot5^t`**。

さらに、`d>=max(5,t)` で `5^t | E_{d,5}` となる次元は、法 `4\cdot5^t` で**ちょうど4剰余類**に属する。それぞれの零点枝は `t` を1増やすと、5個の候補のうちただ1個に持ち上がる。

| 可除条件 | 最小最終周期 | 0となる剰余類（昇順） |
| --- | ---: | --- |
| `5 | E` | 20 | 1, 2, 3, 4 |
| `25 | E` | 100 | 2, 3, 4, 61 |
| `125 | E` | 500 | 3, 4, 202, 261 |
| `625 | E` | 2500 | 3, 4, 202, 1761 |
| `3125 | E` | 12500 | 2504, 6761, 10003, 10202 |

表の `t=1..5` は `d>=5` に対して成立する。一般の `t` では上記の `d>=max(5,t)` を用いる。

## 全称証明

K0561で証明済みの**全次元厳密指数公式**は

$$
120E_{d,5}=\sum_a c_a a^d\quad(d\ge5)
$$

であり、`(a,c_a)` は

```
(32,1), (24,-30), (20,140), (18,135), (16,-1215),
(14,2205), (12,-1977), (10,780), (8,250),
(6,-495), (4,255), (2,-49).
```

`P=4\cdot5^t` とおく。5と互いに素な底 `a` について、`a^4\equiv1 (mod 5)` と二項定理から

$$
a^P-1\equiv5^{t+1}\frac{a^4-1}{5}\pmod{5^{t+2}}.
$$

`5|a` の底は `a=10,20` だけで、どちらも `5|c_a`。よって `d>=t+1` ではその差分寄与は `5^{t+2}` の倍数。残る底でも `5|c_a` の項は消える。結局、法 `5^{t+2}` で寄与するのは `a=32,12,2` の3項だけである。

$$
\frac{32^4-1}{5}\equiv0,\quad
\frac{12^4-1}{5}\equiv2,\quad
\frac{2^4-1}{5}\equiv3\pmod5.
$$

3底はいずれも `2 mod 5` なので、

$$
\frac{120(E_{d+P,5}-E_{d,5})}{5^{t+1}}
\equiv2^d(1\cdot0-1977\cdot2-49\cdot3)
\equiv4\cdot2^d\pmod5.
$$

`120=5\cdot24`、`24^{-1}\equiv4 (mod 5)` より、主張した差分合同式が得られる。

特に `E_{d+P,5}\equiv E_{d,5} (mod 5^t)`。法5の20剰余類を公式で完全計算すると、`E_{d,5} mod5` は `d=0,1,...,19 (mod20)` の順に

```
4,0,0,0,0,2,4,3,1,4,3,1,2,1,2,4,3,3,1,2
```

となる。周期20の真の約数は10または4の約数で、例えば `d=5` と `d=15,9` の値が異なるため、最小周期は20。任意の `t>=2` で最小周期は `4\cdot5^t` の約数で、かつ20の倍数でなければならない。真の約数なら `4\cdot5^{t-1}` を割るが、差分定理からこの移動は法 `5^t` の周期ではない。ゆえに最小性が従う。

`t=1` の零点は `1,2,3,4 (mod20)`。零点 `r (mod 4\cdot5^t)` の次段階候補 `r+j(4\cdot5^t)`（`j=0,...,4`）について、差分定理を繰り返せば

$$
E_{d+j(4\cdot5^t),5}\equiv E_{d,5}+j\,2^d5^t\pmod{5^{t+1}}
$$

が十分大きい `d\equiv r` で成立する。`2^d` は5進単元なので、5候補のうちちょうど1個が次の5冪で割り切れる。これを帰納して4本の枝が全 `t` で存在し、他には存在しないことが示された。

## 独立照合と限界

`verify.py` は (1) 分母120をそのまま割る合同算法、(2) 分母の5だけを割り24を逆元で処理する算法、(3) 指数係数を二項反転して復元した座標型係数と第二種Stirling数による有限次元の整数計算、を照合する。差分は `t=0..12` の各60次元、4枝は `t<=12`、表の5段階は一周期の全剰余類を検査する。

**無界次元への主張は上の数学的証明に依存する。** 検査器は数値回帰であり、新たな超平面切片の幾何学的完全列挙ではない。3方式はいずれもK0561の同一の全称指数公式に依存するため、幾何学的に独立した再証明ではない。5進零点4枝の閉形式、および全次元の共円ゲームの勝敗は主張しない。
