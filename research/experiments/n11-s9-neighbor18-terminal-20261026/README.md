## 局所証明

既知の9石WIN 12根の一石交換近傍4,055類を生成し、合法10石子数の小さい候補から150類を試験した。WIN候補23件のうち3件は従来の証明限定統合集合152根と重複し、さらに2件は別途すでに終局証明済みの単独根（K0560・K0562）だった。**残る18根が新規証明対象**である。候補選別は証明の根拠には使用しない。

- 9石18根：全合法10石子 **355辺、相異なる348類**。
- 348類の10石局面は、すべて手番側WIN。したがって18個の9石根は手番側LOSS、**元先手WIN**。
- 一石戻して得られる8石WIN証人親：**151対称類**。それぞれ少なくとも1個の合法9石WIN子を持つ。
- 終局探索の状態数：**39,670**（二実装の合計ではなく、各実装それぞれの値）。
- 凍結8石LOSS 294類との衝突：**0件**。

状態数は探索順依存の回帰指紋であり、勝敗・残り手数ではない。
151類の8石親について、研究全体の証明限定集合との重複および7石への純増被覆は**未集計**。新規7石全子被覆は主張しない。

## 証明の信頼境界

固定入力は `s9-roots.keys`（D4正準・昇順・18行）。`verify.py` が全合法10石子と全8石親を盤面から再生成し、SHA-256、完全性、合法着手、対称性、安全性を検査する。既存の独立した3×3差分行列式実装と4×4 Bareiss整数行列式実装で、**348個すべての10石局面を保存済み勝敗表に頼らず終局まで再帰**する。両実装の勝敗・合法手・探索状態数を葉ごとに照合する。欠落・異物を拒否する負の試験を含む。
