# 垂直ファイバー容量の境界層におけるGrundy値

## 主張

底面跡制約を持たない純粋なファイバー多項式ルールを考える。有限底面 \(B\)、\(|B|=w\)、高さ集合 \(A\)、\(|A|=m\)、ファイバー次数上限 \(t\ge1\)、禁止点数 \(q\) とする。占有ベクトルを \(c=(c_b)_{b\in B}\) とし、

\[
C(c)=\sum_{b\in B}\min(c_b,t)
\]

と置く。安全局面は \(C(c)\le q-1\) である（K0832）。

**境界層 \(C(c)=q-1\) 上の全局面は、その層の中だけに子を持つ。** そして、そのGrundy値は

\[
\boxed{
G(c)=\bigoplus_{\substack{b\in B\\c_b\ge t}}
\bigl((m-c_b)\bmod 2\bigr)
}
\]

で与えられる。ここで \(\oplus\) は排他的論理和である。

つまり、境界層では「すでに \(t\) 個以上置かれたファイバー」だけが動ける。各ファイバーの残りマス数の偶奇を排他的論理和すればよい。

## 証明

\(C(c)=q-1\) とする。ファイバー \(b\) に石を1個追加したとき、

- \(c_b<t\) なら \(C\) は1増え、\(q\) になるため不合法。
- \(c_b\ge t\) なら \(\min(c_b,t)\) は変わらず、\(C=q-1\) のままなので、\(c_b<m\) である限り合法。

従って合法手は、ちょうど \(c_b\ge t\) かつ \(c_b<m\) のファイバーを1つ選び、その占有数を1増やす操作である。手を打っても \(C=q-1\) は保たれ、飽和済みファイバーが未飽和へ戻ることもない。

よって境界層のゲームは、各 \(b\) について長さ \(m-c_b\) の一方向の鎖を独立に1手ずつ進めるゲームの直和である。長さ \(h\) の鎖のGrundy値は、唯一の子が長さ \(h-1\) の鎖であることから帰納的に \(h\bmod2\)。直和のGrundy値は各成分の排他的論理和なので、主張の式を得る。∎

## 底面跡制約もある場合

K0832のように、さらに各 \(T\in\mathcal T\) の柱 \(T\times A\) に対して

\[
\sum_{b\in T}c_b\le q-1
\]

を課していても、次の十分条件の下では同じ式が成立する。

\[
\boxed{
\sum_{b\in T}c_b+
\sum_{\substack{b\in T\\c_b\ge t}}(m-c_b)
\le q-1
\quad(\forall T\in\mathcal T).
}
\]

左辺は、現在の局面から飽和済みファイバーを全て満杯にしたときの各跡の占有数である。この最終値が全跡で容量以下なら、その途中のどの順序で飽和済みファイバーを進めても跡容量を超えない。未飽和ファイバーへの手は多項式容量条件により禁止されるため、合法手集合は引き続き独立な鎖の直和と一致する。

**注意:** この十分条件を満たさない一般の底面跡制約付き局面に、上のGrundy公式を適用してはならない。跡容量が飽和済みファイバー間の手を結び付ける可能性がある。

## 有限完全監査

独立な再帰計算で、次の全パラメータを検査した。

- \(|B|=w=1,\ldots,4\)
- 高さ数 \(m=1,\ldots,4\)
- 次数上限 \(t=1,\ldots,4\)
- 各組で可能な全 \(q\)
- 各境界占有ベクトル \(C(c)=q-1\)

合計 **64パラメータ組・5,080境界状態**。全状態で再帰mex値と上式が一致した。

これは有限範囲の完全監査であり、全称性の根拠は上の鎖分解証明である。

## 限界

- 定理はK0832の「各ファイバーで次数 \(t\) の多項式が非零」という純ファイバー多項式規則の境界層についてのもの。
- 底面跡制約がある場合は、上記の全飽和条件を別途確認する必要がある。
- \(C(c)<q-1\) の内部層では、未飽和ファイバーを進める手も存在するため、この単純な排他的論理和公式は主張しない。
- 固定底面次数や既約性制約を持つ多項式族への一般化も主張しない。
