## 主定理

\(O[a,b]\) は区間内の奇数、\(q_o(n)\) は \(n\) 以下最大の奇数とする。値2の位置集合を \(T_x\)、値1の位置集合を \(P_x\)、値0はそれ以外。

高残容量のtailは K0832 の一般定理から
\[
R\ge x+24=S+z+1\ \Longrightarrow\ H(R;(x,4);19)=(x+4)\bmod 2 .
\]

## 構造の読み

- 値2: 通常ラダー O[1,19]=O[1,z]（奇数z型）。**対角行 x=15（S=x+4=19=z）は上端23**（交差式 2y+q_o(z−y)=8+15、8切片目の一致）。**前倒し点は x=19（単点25）と x=23（単点27）**で、d=x−y∈{15,19} は y=3 の前倒し点（x=18・x=22、d=15・19）と同じ d 値（d+z≡2 mod 4 の格子式 2y+(d+z)/2。d の活性値が y によらない新観察。d=15 は z−4、d=19 は z）。**掃引行 x=24=z+y+1 は O[27,47]=O[2y+z,S+z]**、**定常pin 27=2y+z は x>=25=z+y+2**（x=23 の前倒し点は x=z+y 行のpinそのもの）。
- 値1: **基底点 {20,22,24,26}**（z+1..z+2y−1=[20,26] の偶数点、ちょうど y=4 点。z=19 族で y=2（K1052 {20,22}）・y=3（K1098 {20,22,24}）と縦に完成し、**y点仮説 {z+1,…,z+2y−1}（z奇は偶点）が同一zで y=2,3,4 の3連続で確認**）。途中行は [20,∞) から零点 odd {21,23(,25,27)} を除いた形。中間帯 O[29,q_o(x+23)] と奇数行tail I[x+24,∞) は x>=25 で接続。
- **「高さのみ」領域 x<=14（S=x+4<=18<z）**: 全行が全 R で単一トークン値 v(x+4,19,R) に完全一致（K1078 の x<=14、K1098 の x<=15 と合わせ S<z 候補命題の3実例）。x=15..22 の最大初期一致区間は行別 24,23,24,25,24,25,26,27。**x>=23（=z+y）で R<=26=pin−1 が一様成立し、R=27=2y+z（pin）で親2・単一0の鋭い反例**（一般形 R<=pin−1 の4実例目。低R一様の開始行が x=z+y であることも y=3（x>=22=z+y）と一致）。
- tail 開始 R=x+24=S+z+1・値 S mod 2 は K1083（z=18,y=4: x+23）、K1098（z=19,y=3: x+23=S+z+1）と同じ S+z+1 形。

## 全称証明

R=0 は終局で値0。R>=x+24 は K0832 一般tail。残る 1<=R<=x+23 について、
- B は K1098（z=19,y=3 切片定理）
- C は 1⊕K1083（z=18,y=4 切片定理）
- x>=5 のAはx外帰納、x=4 では二つのトークン減少手が多重集合 (3,4) に合流して A=B=K1098 の x=4 行

であり、各 x の行で子値集合の署名が帯表どおり一定であることを機械照合する。
帯表は静的22行（x=4..25）＋x>=26 のアフィン帯で、各偶奇行で R=1..x+23 を刻み2で敷き詰め、上端は q_o/q_e(x+23) で tail に接続する。
有限監査は証明そのものではなく、再帰実装・子アンカー・帯表転写・mex恒等式の独立照合である。
