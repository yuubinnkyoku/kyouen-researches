# 標準11×11：4個の既証明8石LOSSを統合し、7石LOSSを29類拡張

**11×11空盤の勝敗はUNKNOWN。**

## 証明の出所

`n11-four-s8-joint-terminal52-20261023/` の4個の8石LOSS根は、
52個の10石LOSS葉で103個の9石義務をすべて覆う、既存の独立終局証明である。
今回、この4根が直前の**証明書由来40個の8石LOSS根**の集合に含まれていないことを確認した。
52葉を別実装のJavaScript（3×3整数行列式、保存済み勝敗表を参照しない終局再帰）でも
再計算した。**52葉すべてLOSS、状態数合計12,280**で保存記録と一致し、
103義務の全被覆も再生成した。元のC++4×4・Python3×3による
1,017候補の独立終局分類と52葉の最小性は、元実験の証拠に依存する。

8石が元先手固定LOSSなら、その石を1個取り除いた合法な7石親も、
8石LOSS応手を1つ持つ奇数AND局面なのでLOSSとなる。
この逆向き伝播には凍結勝敗表や未完探索のpn/dnを使用しない。
