## 手法（K1085実験と独立な再導入）

- Stage B: universe82（72行×空き2石の generation witness 471,960 events →
  D4 canon dedup 380,098根・unsafe8 は整数4×4行列式（D-memo 3点式）で
  259,624根・safe8 120,474根）と coverage/demand を本機械が再導入し、
  K1085出版集計（coverage hist {1:82,602, 2:33,104, 3:4,718, 4:50}・
  per-row demand min 1,714/max 2,944/sum 163,164・
  coverage crosscheck 39,255根の全C(8,6)=28部分集合再導入）と全点一致した上で、
  **greedy 23根計画（根順序・各根の主張被覆行の両方）を完全再現**した
  （lex-smallest max-gain 規則はK1085と同じ定義を独立実装）。
- Stage C: K1086 verdict join（7 WIN8/16 REFUTED・両順序 uncapped）と
  greedy計画の72行分割（WIN 7根が主張23行 + REFUTED 16根が主張49行）を検証。
- Stage D: pool P = safe8 − REFUTED16根（120,458根）上で残余49行の
  demand・greedy set cover・情報論的下界 ceil(49/4)=13・二部最大マッチング
  （Kuhn 追加分岐・決定的順序）・WIN8 7根の内在被覆（intrinsic coverage:
  全C(8,6)=28削除再導入）を計算した。

## 結果（16/16 gate PASS・3実行byte-identical）

- **残余49行は除外後 pool でも全行需要あり**: demand on P は合計 109,719・
  min 1,713・max 2,943（safe8 全域imin 1,714/2,944 からの低下は各行高々1）。
  stranded 行 0（16 REFUTED根が特定行の唯一の供給源になっているケースは皆無）。
- **greedy 再解決: 16根が残余49行を leftover 0 で完全被覆**
  （gains hist {4:3, 3:11, 2:2}）。情報論的下界 ceil(49/4)=13 に対し3根超過。
- **二部最大マッチング 49**: 49行全部に互いに異なる被覆根が存在
  （每行1根の witness も構成可能）。greedy 16根はその圧縮表現。
- **WIN8-D10 candidate 7根の内在被覆は主張23行と一致**（residual49への
  巻き込みなし）。将来の WIN8 receipt fold が残余49行を追加閉鎖する
  幾何学的余剰はなく、需要構造は WIN8 fold 前後で不変
  （scope1 = scope2 の両 greedy が同一の16根を返すことで機械保証）。
- **新計画の全体像: 7 WIN8根（23行）+ 16代替根（49行）= 23根で72行を被覆**
  （最元のgreedy計画と同数の23根）。代替16根は未掃引であり、
  depth-10掃引には両AND順序32 probes が必要（K1086の平均392K nodes/probeを
  当てるなら概算13M nodes。観察に基づく外挿であり保証しない）。
