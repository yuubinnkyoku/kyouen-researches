# 任意の途中局面からの極大盤面と全合法対局順序の厳密計数（2026-10-08）

## 適用範囲

K0352の抽象容量ゲームで整数 `2<=h<w`, `m>=1`, `1<=r<h*m`。ラベル付き `w` 本の列にそれぞれ `m` 個の区別可能な位置があり、現在の石の集合 `P` は各列で `x_i` 個占有、降順の占有数は `x_1>=...>=x_w`。安全性は上位 `h` 列の合計が `r` 以下であることとする。現在の実際の占有位置 `P` は固定する。

これは一般位置平行列盤の `q>2w` 条件等を満たすときの幾何版に移送できる。一般の2次元正方形盤への適用は主張しない。

## 全称定理：途中局面条件付き極大盤面数の母関数

到達可能な極大盤面の共通最小占有数を `t` とし、`s=r-h*t` と置く。各列 `i` の局所多項式を

```
P_i(t;u,z) =
    sum_{k=max(0,x_i-t)}^{m-t}
      binom(m-x_i,t+k-x_i) * u^(1 if k>0 else 0) * z^k
```

と定義する。和の下限が上限より大きければゼロ多項式とする。すると、`P` を含み、閾値 `t` を持つ**実際の極大安全盤面**の個数は

```
N_t(P)=sum_{j=0}^{h-1} [u^j z^(r-h*t)] product_{i=1}^{w} P_i(t;u,z).
```

ここで `[u^j z^s]` は該当係数。K0352により `t` の範囲は厳密に

```
A=max(x_h,0,r-(h-1)*m) <= t <=
B=max{t<=m:sum_{i<=h}max(x_i,t)<=r}
```

であり、それ以外の閾値には到達できない。`A<=t<=B` なら `N_t(P)>0`。

**証明：** 極大局面で全列の占有数は `t` 以上、`t` より多い列は高々 `h-1` 本、そこからの超過分の総和は `r-h*t`（K0352の極大条件）。ある列の終局占有数 `t+k` は `k>=max(0,x_i-t)`, `k<=m-t` と同値で現在盤面を含み、残り `m-x_i` 個の位置から `t+k-x_i` 個の石を追加する方法は `binom(m-x_i,t+k-x_i)` 通り。変数 `z` が超過和、`u` が超過列数を数えるので、全列の積の該当係数が必要十分に対象盤面を一度ずつ数える。□

**占有数ベクトルのみ数える場合：** 局所係数 `binom(...)` を一律1にすれば、現在占有数を含むラベル付き終局占有数ベクトルの総数が同じ係数抽出で求まる。これは物理的な盤面数とは違う。

## 全称定理：全合法対局手順の長さ別正確な個数

閾値 `t` の終局石数は `T_t=r+(w-h)t`、現在石数は `|P|=sum_i x_i`、残りの着手数は `ell_t=T_t-|P|` である。

**終局までゲームを打ち切る異なる合法着手列（1手ごとに位置を区別）の長さ `ell_t` の個数は**

```
H_t(P)=ell_t! * N_t(P).
```

**証明：** 固定された終局盤面 `Q` を一つ選び、追加する `Q\P` の `ell_t` 個の位置を任意の順に着手する。安全集合族は包含について下方閉なので、`Q` のどんな部分集合も合法な途中局面である。従って `ell_t!` 通りの着手順序すべてが合法で終局 `Q` に達する。異なる `Q` の着手列は最後の石集合が異なるから交わらない。□

任意の `s>=2` 人巡回版で、現在手番を `P_0` とすると、最終手の担当者が `P_j` になる**合法な全プレイ経路の本数**も

```
sum_{t=A}^B 1{ell_t>=1 and (ell_t-1)%s==j} * ell_t! * N_t(P)
```

と厳密に求められる。`ell_t=0` は今すでに終局であり「今後の最後の着手者」は定義しない。これは経路数の分布であり、各人の戦略的勝率や均衡を意味しない。全合法完全経路を等確率で選ぶ特殊な確率モデルなら、上の本数を総経路数で割ればその分布となる。逐次合法手を等確率で選ぶモデルとは一般に異なる。

**空盤からの K0354 の回収：** `x_i=0` と置くと `P_i=binom(m,t)+sum_{k=1}^{m-t}binom(m,t+k)u z^k` なので、`u^j` 係数が `binom(w,j)binom(m,t)^(w-j)(sum_{k>=1}binom(m,t+k)z^k)^j` となり、K0354の `N_b` に一致する。K0354は全体の極大盤面数を与えるが、本結果は各途中盤面からの条件付き数と着手列数を与える。

## 独立有限完全列挙

[check_terminal_paths.py](check_terminal_paths.py) は、（A）上記の二変数母関数の動的計算と、（B）全ての**物理的に異なる合法な次の石位置**を `m-x_i` で重み付けした全合法着手のメモ化再帰を、別々に実装する。後者は降順対称性を使用せずラベル付き列状態を保持する。

`3<=w<=6, 2<=h<w, 1<=m<=4, 1<=r<h*m` の全安全降順初期占有数に対し、終局までの全経路数を長さごとに照合した。

```
PASS positions= 8774 terminal-spectrum entries= 14390
by_width= {3: 164, 4: 748, 5: 2268, 6: 5594}
total_paths= 454320785617981222619262
```

不一致0。全称性の根拠は上の組合せ証明であり、この有限完全列挙は独立監査である。

**例：** `w=3,h=2,m=3,r=3,x=(0,0,0)` では極大盤面数は終局石数3に対し3通り、終局石数4に対し81通り。合法な全対局手順はそれぞれ `3!×3=18` 通りと `4!×81=1944` 通りになる。
