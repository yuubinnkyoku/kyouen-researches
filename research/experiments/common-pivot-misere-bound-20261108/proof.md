# 共通pivotのmisère変換：二値部分ゲームが高い補助mexを作る

## 値の意味

通常Grundyをg、終局で1、非終局で子値のmexとする補助値をhとする。
h=0であることと、最後の合法手を打つ側が負けるmisère版で手番側負けであることは同値。
hは直和に対するSprague–Grundy不変量ではなく、xorで合成しない。

以下は通常版K0692の上界をmisère版へ移す証明ではない。
最初の単純な移植は独立検査で失敗し、正しい変換には別のゲーム値が必要になった。

## 定理：二点辺のある共通pivot族の厳密変換

全極小禁止辺が一点cを含み、二点辺{c,z}が少なくとも一つあるとする。
rankは任意。c以外に現在合法な点がr個あり、p=r mod 2とする。
cへ着手した後のゲームをLと書く。

h(L)が0または1である局面だけを残し、その間の合法手だけを許す別の有限通常ゲームを
考え、そのGrundyをt(L)とする。元のhが2以上の子への手はこの別ゲームでは捨てる。
tはこの制限ゲームの終局で0、非終局で子のtのmexである。
親子でhが等しくなることはないので、残る手は必ずh=0とh=1の間を移る。

現在のmisère補助値Qは

\[
 \boxed{
 Q=
 \begin{cases}
 2+t(L)&p=0,\ h(L)=1,\\
 1&p=0,\ h(L)\ne1,\\
 2+t(L)&p=1,\ h(L)=0,\\
 0&p=1,\ h(L)\ne0.
 \end{cases}}
\]

rankや点数を制限しない数学的な恒等式である。
tが現れる行ではh(L)∈{0,1}なのでtは定義されている。

## 証明

zへ着手するとcが不合法となり、以後のr−1点は全て自由となる。
自由点r−1個の補助値はr mod 2=pなので、選択肢にpが必ず存在する。
cを合法に保つ外側の手はLの合法手L→L'と一対一に対応し、
二点辺{c,z}はその後も残る。pは反転する。
従ってrに関する帰納が可能である。

p=0では、子のp=1の値は0か2以上であり、1にはならない。
h(L)≠1なら選択肢に1がなく、0が必ずあるのでQ=1。
h(L)=1なら、cへの手が1、zへの手が0を与える。
L'のhが0なら帰納仮定で子値は2+t(L')、hが2以上なら子値0。
従ってmexは2+mex{t(L'):h(L')=0}=2+t(L)。
Lが元の終局である場合も、h(L)=1,t(L)=0で、選択肢{0,1}のmex=2となる。

p=1では、子のp=0の値は1か2以上であり、0にはならない。
h(L)≠0なら選択肢に0がなくQ=0。
h(L)=0なら、cへの手が0、zへの手が1を与え、
h(L')=1の子値が2+t(L')、h(L')≥2の子値が1となるため、同じく2+t(L)。

## 自由点を二個加える補題

任意の有限不偏ゲームGについて、自由な一点取りを二個加えてもhは変わらない。
h_j=h(G+j個の自由点)とする。h_1は選択肢にh_0を含むのでh_1≠h_0。
Gが非終局なら、全ての真の子について帰納仮定h_2(child)=h_0(child)を使うと
h_2=mex({h_0(child)}∪{h_1})=h_0。
Gが終局なら(h_0,h_1,h_2)=(1,0,1)で直接成立する。
従って自由点数は0/1へ圧縮できるが、h_1=h_0 xor1とは限らない。

## 純三点で二点辺のない初期局面

三点辺{c,u,v}のリンクグラフHを作り、孤立点を自由点として分離する。
Hの非孤立頂点数をmとする。
Hの通常のNode-Kayles後続H−N[v]をL_vとすると、外側点vへの手の後には
二点辺があり、上のQ式が使える。

自由点なしの根値q_0は、cへの手のh(H)と、
各vについてp=(m−1) mod2で評価したQ(L_v)のmex。
自由点一個の根値q_1は、h(H+自由点)、q_0、
各vについてp=m mod2で評価したQ(L_v+自由点)のmex。
任意個の自由点は上の二点補題でこの二通りに帰着する。
空のHでは全点自由の偶奇式を直接使う。
この厳密計算法はHのhおよび制限ゲームtを計算する必要があり、
一般の計算量を改善したという主張ではない。

## 通常上界3との分離

純三点族

```
7,13,49,97,515,517,521,529,545,577,641,769
```

は全辺が頂点0を共有する。合法点十個では(g,h)=(1,4)、
同じ辺族へ自由点一個を加えた十一点では(g,h)=(0,5)。
K0692のg≤3をhへ移すことはできない。
十一点と十二点の二点辺付き別例でも(g,h)=(0,4),(1,5)を得た。
これらの点数最小性や、hの全称有界性・非有界性は確定しない。

## 十五点h6・十六点h7への拡張

十四頂点グラフの有界な辺変更探索から、h=0/1制限ゲーム値t=5の例を得た。
その全16384誘導部分グラフを調べ、次の十二頂点・十八辺リンク核へ縮めた。

```
3,65,6,66,130,68,132,24,40,528,96,160,2080,320,2112,640,1152,2176
```

このリンクゲームは通常g=6、補助h=1、制限ゲームt=4。
合法pivot cと、リンクの十二点、cを不合法にする外側二点を用意する。
各リンク辺へcを加えた三点辺と、二点辺二本を禁止する。
合法点十五個・二十辺となり、外側点数r=14は偶数なので式から(g,h)=(0,6)。
自由点を一つ加えるとリンクの補助値が0、制限ゲーム値が5、rは奇数となり、
(g,h)=(1,7)を得る。両方とも別C++全占有subsetで根値を検査した。
この誘導部分グラフ内での縮小は、全グラフ・全残余族での最小性ではない。

K0683から占有anchor22点、総点数37/38の整数点盤へ移せる。
この二例では具体座標の全四点組を別途走査しておらず、
幾何実現の根拠はK0683の構成的全称定理である。
データと別検査は`output/induced_high_audit.json`と`audit_induced.py`に保存する。

## 独立監査と幾何

外側0..6点の全41658共通pivot・rank三以下の族と追加四証人を、
Node-Kayles上のh/t再帰による式と、全占有subsetを直接判定する別C++で比較した。
全41662根・3284481安全状態で通常値と補助値の両方が一致した。
小型範囲では、pivotのラベルを0に固定した通常／misère交換則の例外が150族あり、
全て七点で(g,h)=(2,1)。そのリンクグラフはC6が60族、P3二個の直和が90族で、
この二同型型に限る。六点以下のrank三共通pivot族には例外がなく、
この条件下での交換則破れの最少合法点数は七と確定する。

純三点h4/h5をK0683で整数座標盤へ移し、22点・23点の盤について
計16170個の四点組の行列式と1839安全状態の補助値を検査した。
全禁止四点組が未占有の合法pivotを共有し、指定した十二個だけである。
これは指定有限整数点盤であり、全正方形格子盤の主張ではない。
