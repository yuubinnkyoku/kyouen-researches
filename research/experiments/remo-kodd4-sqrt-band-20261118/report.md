## 1. バンドの完全性（なぜこの掃引でkodd=4・t≥2が全て見つかるか）

K0961 K4-CAP（出版・全称証明）: kodd=4・t≥2のsmoothヒットは
(a) K4-Aにより全てcase A（p₃p₄ ≥ M）、(b) T7交叉対二分法により
β枝（p₂p₃<M∧p₁p₄<M）は空、(c) よって各ヒットはα（p₂p₃<M≤p₁p₄）か
γ（p₂p₃≥M）のいずれかで、

- α: t < ((M−1)^{3/2}/2^{3a/2}+1)/M < √M/2^a + 1/M ≤ √M/2 + 1/M < √M
  （a≥1はK0949 PARITY）→ α行は決して予想(i)に違反しない;
- γ: sharp上界 t·2^{2a}·p₁² ≤ M−2（κ≥1）・t·2^{2a}·p₁ ≤ M−2（κ=0）。
  a≥1・p₁≥3から **κ≥1 ⟹ t ≤ (M−2)/36**、**κ=0 ⟹ t ≤ (M−2)/12**
  （Mは奇素数なので(M−2)/36・(M−2)/12は非整数・floorを取ってよい）。

ゆえに掃引バンド

- part 1: t ∈ [2, ⌊(M−2)/36⌋]・全κ（候補は素数Yのみ・[Y ok]分類）,
- part 2: t ∈ (⌊(M−2)/36⌋, ⌊(M−2)/12⌋]・κ=0のみ（Y=(M+1)t+1）

は **kodd=4・t≥2・M∈(2000,10000]のsmoothヒットの全体を含む**
（Y=M²はt=M−1 > (M−2)/12なので帯外・(t,κ)≠(1,0)とlive範囲はそのまま）。
予想(i)の違反帯 t ≥ ⌈√M⌉ はこの中に完全に含まれる
（⌈√M⌉ ≤ ⌊(M−2)/36⌋はM≥1300近傍で成立・bounds.pyが926素数全件でassert）。
kodd=5に対してはT₅(M) ≤ ⌊(M−2)/36⌋（同assert）なのでpart 1はK0963掃引
バンドの上位互換（開始点t=2を含む）。
