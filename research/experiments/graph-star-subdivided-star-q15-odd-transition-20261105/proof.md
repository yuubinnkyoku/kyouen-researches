# 一辺細分星 q=15 の奇数次数実根切替（2026-11-05）

## 結論（全称解析＋有理数区間証明）

一辺細分星の終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
について、r=q-3=12、奇数 k≥3 とする。

- q=15、奇数 3≤k≤107 では実根0個。
- q=15、奇数 k≥109 では相異なる負の単実根がちょうど2個。
- 任意の整数 q≥15、奇数 3≤k≤107 では実根0個。

## 証明

u=-(r+1)y と置く。奇数 k の場合、正の u に根はなく、負の u の根候補は 1<y<a=1+1/(r+1) に限られる。この区間で零点条件は
\[
F_{k,r}(y)=r-y-(a-y)y^k=0
\]
となる（区間外の符号は先行一般証明を参照）。

r=12、a=14/13。固定 y>1 では (a-y)y^k は k に関して増加するので、k=107 で F>0 を証明すれば、それ以下の全奇数 k に及ぶ。

H(y)=(a-y)y^{107} は [1,a] で唯一の極大点 y_*=107a/108 を持つ。区間 [1,a] を100等分し、各区間 [l,h] に対して z=min(max(y_*,l),h) とすれば H(y)≤H(z)。付属の有理数検証コードで100区間すべてについて
\[
H(z)<12-h\le 12-y
\]
が成立する。ゆえに k≤107 に実根はない。

k=109 では有理数 y=763/715=109a/110 に対し 1<y<a かつ F_{109,12}(y)<0 が厳密整数演算で成立する。k≥109 の奇数でも同じ y で負値を保つ。一方 F(1)>0、F(a)>0 なので中間値定理で少なくとも2個の負実根がある。T_{k,r}(-x) の符号変化は2回なのでデカルトの符号法則により重複度込みで高々2個。よって相異なる単根がちょうど2個。

さらに r≥12 では候補区間が (1,14/13) に含まれ、固定 y>1 で ∂F/∂r=1+y^k/(r+1)^2>0。したがって q≥15、奇数 k≤107 でも根はない。

## 再現（Python 3、浮動小数点なし）

```python
from fractions import Fraction as Q

r, k = 12, 107
a = Q(14, 13)
star = a * k / (k + 1)
for i in range(100):
    l = 1 + (a - 1) * Q(i, 100)
    h = 1 + (a - 1) * Q(i + 1, 100)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = Q(763, 715)
assert 1 < y < a
assert r - y - (a - y) * y**109 < 0
```

**証拠区分:** 解析的全称証明と100個の厳密有理数区間不等式。一般 q の接触二重根不存在は未証明。格子盤の勝敗を主張しない。
