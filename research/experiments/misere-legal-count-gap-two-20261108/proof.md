# 合法点数の二段差はmisère補助mexにも成立する

gは通常Grundy、hは終局1のmisère補助mexとする。
任意rankの有限禁止集合一点追加ゲームで、現在合法点数μ≥5なら

\[
 \boxed{g\le\mu-2,\qquad h\le\mu-2.}
\]

gの定理はK0690。hについてはK0309の五合法点以下での交換則と、
K0690の五点以下の全表から、μ=0..5の最適上界が1,0,1,2,3,3と分かる。
μ≥6では子の合法点数m≤μ−1。
m≥5なら帰納仮定で子h≤m−2≤μ−3、m≤4でも子h≤3≤μ−3。
非終局のhは通常どおり子のmexなので、h≤μ−2。
終局h=1という例外は有限基底に含めており、帰納で取り落とさない。

## 最少合法点数

任意rankでh=0..7を達成する最少点数は

\[
 1,0,3,4,6,7,8,9.
\]

h0は自由一点、h1は空点集合。h2は三点道の二点禁止ゲーム、h3はその自由点付き。
h4/h5はK0686の六点純三点g4とその自由点付きで達成し、
h6/h7はK0691の八点純三点g6とその自由点付きで達成する。
各達成例のh自体を残余族再帰と別C++生subsetで計算し、通常gだけから推測していない。
点数下界は上のh上界と小さい基底から従う。

純三点禁止族に限ると、最少点数は

\[
 1,0,6,7,6,7,8,9.
\]

五点以下ではK0686の通常二値性とK0309の交換則からhも0/1だけ。
六点のh3は、K0686の通常g3不存在と、K0309の六点交換則破れが
(g,h)=(0,0)だけという完全分類で排除できる。
他の高値の下界は一般上界だけで足り、具体的純三点例が全て達成する。

## 有限監査

0..5点の全rank clutter7021族と、二組の最少点数達成例を調べる。
主h計算は一手ごとの残余縮約・一点辺による不合法点除去と再ラベル再帰。
別C++は元の個別占有subsetを直接判定してg/hの両方を下から計算する。
全件数・ヒストグラム・比較安全状態数・全達成例は`output/audit.json`に保持する。

```sh
uv run --locked python research/experiments/misere-legal-count-gap-two-20261108/verify.py
```

大きいμの全称性は有限基底からの帰納証明による。hは直和のxor不変量ではない。
最少点数は任意の指定残余禁止集合についてであり、標準全正方形盤での最少盤幅ではない。
