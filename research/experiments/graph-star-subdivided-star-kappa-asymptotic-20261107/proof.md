# 一辺細分星の奇数次数切替閾値の漸近展開（2026-11-07）

## 結論

K0677 の切替次数 `κ(r)`（一辺細分星の終局長差多項式 `T_{k,r}` が奇数 `k` で初めて実根をもつ次数）について

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + o(r)      (r → ∞).
```

さらに評価を精密化すると

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + r (ln ln r + 1 + ln 2)/(2 ln r)
       + O(r (ln ln r)^2 / (ln r)^2).
```

特に `κ(r)/(r ln r) → 2` であり、K0677 の `Θ(r log r)` 評価を先頭3項と誤差の次数まで確定する。
標準格子盤の勝敗・最大安全サイズ・Grundy 値への主張ではない。

## 記号と判定条件

`a = 1 + 1/(r+1)`、`y_* = k a/(k+1)`、`H(y) = (a-y)y^k`、`F(y) = r - y - H(y)`、
`M(k) = max_{1<y<a} H(y) = a^{k+1} k^k/(k+1)^{k+1}`。実根の存在は K0677 により次の2つの十分条件で判定できる。

- `M(k) > r - y_*`（すなわち `F(y_*) < 0`）なら相異なる負の実根がちょうど 2 個。
- `M(k) < r - a` なら `F > 0` が `(1,a)` 全体で成り立ち実根なし。

（`r - y_* ≥ r - a` なので両条件は両立しない。）

## 補題1（両側対数評価）

`r >= 4`、`k >= 3` について

```
(k+1)/(r+1) - (k+1)/(2(r+1)^2) - ln(k+1) - 1  <  ln M(k)  <  (k+1)/(r+1) - ln(k+1) - 1 + 1/(2k).
```

**証明** `ln M(k) = (k+1) ln a + k ln k - (k+1) ln(k+1) = (k+1) ln a - ln(k+1) - k ln(1 + 1/k)`。
`0 < t <= 1` で `t - t^2/2 < ln(1+t) < t` だから

```
(k+1)(1/(r+1) - 1/(2(r+1)^2)) < (k+1) ln a < (k+1)/(r+1),
1 - 1/(2k) < k ln(1 + 1/k) < 1.
```

組み合わせて両側評価を得る。□

## 補題2（Φ の漸近）

`Φ(k) := (k+1)/(r+1) - ln(k+1) - 1 - ln r` とおく。固定した実数 `c` に対し
`k = 2 r ln r + r ln ln r + c r + O(1)` とすると（`r → ∞`）

```
Φ(k) = c - (1 + ln 2) + o(1).
```

**証明** `(k+1)/(r+1) = (k/r)(1 - 1/(r+1)) + 1/(r+1) = 2 ln r + ln ln r + c + O(ln r / r)`。
また `ln(k+1) = ln r + ln(2 ln r + ln ln r + c + o(1)) = ln r + ln ln r + ln 2 + o(1)`。
差をとれば `Φ(k) = c - 1 - ln 2 + o(1)`。□

## 定理

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + o(r).
```

**証明** `c > 1 + ln 2` を固定し `k_c = 2 r ln r + r ln ln r + c r`（奇数に丸める。丸めは `O(1)`）とおく。
補題2 より `Φ(k_c) → c - (1+ln2) > 0`。補題1 の下界と `y_* < a <= 4/3` より

```
ln M(k_c) >= Φ(k_c) + ln r - (k_c+1)/(2(r+1)^2) > ln r - y_*/(r - y_*) = ln(r - y_*)
```

が十分大きい `r` で成り立つ（補正項は `O(ln r / r)` で消える）。よって `M(k_c) > r - y_*`、実根が 2 個現れ、
`κ(r) <= k_c + O(1)`。すなわち任意の `c > 1 + ln 2` に対して、十分大きい `r` で

```
κ(r) <= 2 r ln r + r ln ln r + c r.
```

同様に `c < 1 + ln 2` では `Φ(k_c) → c - (1+ln2) < 0` で、補題1 の上界と `a/r` の補正から

```
ln M(k_c) <= Φ(k_c) + ln r + 1/(2k_c) < ln r - a/r <= ln(r - a)
```

が十分大きい `r` で成り立つ。よって根は現れず `κ(r) > k_c`、すなわち `κ(r) >= 2 r ln r + r ln ln r + c r`。
`c` は `1 + ln 2` の両側で任意だから定理を得る。□

## 三項漸近

**補題3（`M` の展開）** `Ψ(k) := (k+1)/(r+1) - ln(k+1) - 1 - ln r` とおくと

```
ln M(k) = Ψ(k) + ln r + e1 + e2,
e1 := (k+1)(ln a - 1/(r+1)) ∈ ( -(k+1)/(2(r+1)^2),  -(k+1)/(2(r+1)^2) + (k+1)/(3(r+1)^3) ),
e2 := 1 - k ln(1 + 1/k)     ∈ ( 0,  1/(2k) ).
```

**補題4（閾値の位置）** `F` の最小点は `y_c = y_* + O(a^{-k})`（指数的に小さい）で、
閾値では `min F = 0` すなわち `ln M(κ) = ln(r - y_*) + O(a^{-k})`。補題3 と
`ln(1 - y_*/r) ∈ (-y_*/(r - y_*), -y_*/r)` より

```
Ψ(κ) = (κ+1)/(2(r+1)^2) + O(1/κ + 1/r) = (ln r + O(ln ln r))/r.
```

**定理2（三項漸近）**

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + r (ln ln r + 1 + ln 2)/(2 ln r)
       + O(r (ln ln r)^2 / (ln r)^2).
```

**証明** `T := k/r = 2 ln r + ln ln r + μ` とおく（`k = rT`）。`T/(r+1) = O(ln r / r)`、`1/(rT) = O(1/(r ln r))` に注意すると

```
Ψ = T - T/(r+1) + 1/(r+1) - ln r - ln T - 1 - ln r
  = μ - ln 2 - 1 - x + x^2/2 - (2 ln r + ln ln r + μ)/(r+1) + O(1/(r ln r)),
x := (ln ln r + μ)/(2 ln r).
```

補題4 の右辺 `(ln r + O(ln ln r))/r` と等置して

```
μ = 1 + ln 2 + x + O(ln r / r + x^2).
```

さらに `x = (ln ln r + 1 + ln 2 + x + O(...))/(2 ln r)` だから
`x = (ln ln r + 1 + ln 2)/(2 ln r) + O(ln ln r / (ln r)^2)`。
よって `μ = 1 + ln 2 + (ln ln r + 1 + ln 2)/(2 ln r) + O((ln ln r)^2/(ln r)^2)` で、
`κ = r(2 ln r + ln ln r + μ) + O(1)` に代入して定理を得る。□

## 系

```
κ(r) = r (2 ln r + ln ln r + 1 + ln 2) + r (ln ln r + 1 + ln 2)/(2 ln r) + O(r (ln ln r)^2/(ln r)^2),
κ(r)/(r ln r) → 2.
```

数値的には残差 `δ(r) = κ(r) - (2r ln r + r ln ln r + (1+\ln 2)r)` は
`r (\ln\ln r + 1 + \ln 2)/(2 \ln r)` に近づき、相対誤差は `O(\ln\ln r/\ln r)` で消える（下記の表）。

## 数値検証

- 厳密表（K0677）`r = 2..1000` に加え、`κ(3000) = 60,057`、`κ(10000) = 225,393`、`κ(30000) = 744,937` を
  新たに厳密証明（`M` 上界・根証明の両方）。
- 比 `κ(r)/(r ln r)`: `r=4: 5.23`、`9: 3.89`、`24: 3.21`、`100: 2.81`、`998: 2.565`、`3000: 2.500`、`10000: 2.447`、
  `30000: 2.409` と 2 へ近づく。
- 三項公式の照合（`pred3 = 2r ln r + r ln ln r + (1+\ln 2)r + r(\ln\ln r+1+\ln 2)/(2\ln r)`）:

  | r | κ(r) 厳密 | pred3 | 誤差 | 誤差/r(\ln\ln r)^2/(\ln r)^2 | 残差/三項項 |
  |---:|---:|---:|---:|---:|---:|
  | 1000 | 17,715 | 17,703.7 | +11.3 | 0.144 | 1.043 |
  | 3000 | 60,057 | 60,065.3 | -8.3 | -0.041 | 0.988 |
  | 10000 | 225,393 | 225,466.0 | -73.0 | -0.126 | 0.966 |
  | 30000 | 744,937 | 745,180.2 | -243.2 | -0.158 | 0.959 |

  `残差/三項項`（`δ(r) / [r(\ln\ln r+1+\ln 2)/(2\ln r)]`）は 1 に近づき、三項の係数と符号が正しいことを示す。
  誤差は `O(r(\ln\ln r)^2/(\ln r)^2)` の定数倍に収まる。
- 残差 `δ(r) = κ(r) - (2r ln r + r ln ln r + (1+\ln 2) r)` の比 `δ(r)/r`:
  `r=4: 2.458`、`9: 1.681`、`24: 1.003`、`100: 0.519`、`998: 0.273`、`1000: 0.274`、`3000: 0.233`、`10000: 0.205`、
  `30000: 0.187`。全体として減少する（`κ` が離散的に増えるため局所的な揺れはある）。
- `r = 3000, 10000, 30000` で `k = floor(2r ln r + r ln ln r + 1.2 r)`（奇数丸め）の根なしと、
  `k = floor(2r ln r + r ln ln r + 2.5 r)` の2根を厳密証明。閾値が `1.2 r` と `2.5 r` の間にあることの確認。
- 補題1・補題3の両側評価を50桁 `decimal` で20点検査（`ln M` が両側評価の内側にあること。数値監査であり証明ではない）。

## 限界

- 誤差 `O(r(\ln\ln r)^2/(\ln r)^2)` の定数は明示していない（数値では `r >= 1000` で 0.16 未満）。
- 判定条件は `M(k)` の上界・下界による十分条件であり、`r - a < M(k) < r - y_*` の狭間は本稿の議論では使わない
  （K0677 の接触二重根不存在により実際には切替は1回である）。
- 標準格子盤・ゲームの勝敗への主張ではない。
