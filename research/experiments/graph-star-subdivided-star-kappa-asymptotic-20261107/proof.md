# 一辺細分星の奇数次数切替閾値の二項漸近律（2026-11-07）

## 結論

K0677 の切替次数 `κ(r)`（一辺細分星の終局長差多項式 `T_{k,r}` が奇数 `k` で初めて実根をもつ次数）について

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + o(r)      (r → ∞).
```

特に `κ(r)/(r ln r) → 2` であり、K0677 の `Θ(r log r)` 評価を先頭2項まで確定する。

標準格子盤の勝敗・最大安全サイズ・Grundy 値への主張ではない。

## 記号と判定条件

`a = 1 + 1/(r+1)`、`y_* = k a/(k+1)`、`H(y) = (a-y)y^k`、`F(y) = r - y - H(y)`、
`M(k) = max_{1<y<a} H(y) = a^{k+1} k^k/(k+1)^{k+1}`。実根の存在は K0677 により次の2つの十分条件で判定できる。

- `M(k) > r - y_*`（すなわち `F(y_*) < 0`）なら相異なる負の実根がちょうど 2 個。
- `M(k) < r - a` なら `F > 0` が `(1,a)` 全体で成り立ち実根なし。

（`r - y_* ≥ r - a` なので両条件は両立しない。）

## 補題1（両側対数評価）

`r >= 4`、`k >= 3` について

```
(k+1)/(r+1) - (k+1)/(2(r+1)^2) - ln(k+1) - 1  <  ln M(k)  <  (k+1)/(r+1) - ln(k+1) - 1 + 1/(2k).
```

**証明** `ln M(k) = (k+1) ln a + k ln k - (k+1) ln(k+1) = (k+1) ln a - ln(k+1) - k ln(1 + 1/k)`。
`0 < t <= 1` で `t - t^2/2 < ln(1+t) < t` だから

```
(k+1)(1/(r+1) - 1/(2(r+1)^2)) < (k+1) ln a < (k+1)/(r+1),
1 - 1/(2k) < k ln(1 + 1/k) < 1.
```

組み合わせて両側評価を得る。□

## 補題2（Φ の漸近）

`Φ(k) := (k+1)/(r+1) - ln(k+1) - 1 - ln r` とおく。固定した実数 `c` に対し
`k = 2 r ln r + r ln ln r + c r + O(1)` とすると（`r → ∞`）

```
Φ(k) = c - (1 + ln 2) + o(1).
```

**証明** `(k+1)/(r+1) = (k/r)(1 - 1/(r+1)) + 1/(r+1) = 2 ln r + ln ln r + c + O(ln r / r)`。
また `ln(k+1) = ln r + ln(2 ln r + ln ln r + c + o(1)) = ln r + ln ln r + ln 2 + o(1)`。
差をとれば `Φ(k) = c - 1 - ln 2 + o(1)`。□

## 定理

```
κ(r) = 2 r ln r + r ln ln r + (1 + ln 2) r + o(r).
```

**証明** `c > 1 + ln 2` を固定し `k_c = 2 r ln r + r ln ln r + c r`（奇数に丸める。丸めは `O(1)`）とおく。
補題2 より `Φ(k_c) → c - (1+ln2) > 0`。補題1 の下界と `y_* < a <= 4/3` より

```
ln M(k_c) >= Φ(k_c) + ln r - (k_c+1)/(2(r+1)^2) > ln r - y_*/(r - y_*) = ln(r - y_*)
```

が十分大きい `r` で成り立つ（補正項は `O(ln r / r)` で消える）。よって `M(k_c) > r - y_*`、実根が 2 個現れ、
`κ(r) <= k_c + O(1)`。すなわち任意の `c > 1 + ln 2` に対して、十分大きい `r` で

```
κ(r) <= 2 r ln r + r ln ln r + c r.
```

同様に `c < 1 + ln 2` では `Φ(k_c) → c - (1+ln2) < 0` で、補題1 の上界と `a/r` の補正から

```
ln M(k_c) <= Φ(k_c) + ln r + 1/(2k_c) < ln r - a/r <= ln(r - a)
```

が十分大きい `r` で成り立つ。よって根は現れず `κ(r) > k_c`、すなわち `κ(r) >= 2 r ln r + r ln ln r + c r`。
`c` は `1 + ln 2` の両側で任意だから定理を得る。□

## 系

```
κ(r) = r (2 ln r + ln ln r + 1 + ln 2) + o(r),      κ(r)/(r ln r) → 2.
```

数値的には残差 `δ(r) = κ(r) - (2r ln r + r ln ln r + (1+\ln 2)r)` は `r ln(1 + (\ln\ln r + O(1))/(2\ln r))` 程度、
すなわち `o(r)` で減衰する（下記の表）。

## 数値検証

- 厳密表（K0677）`r = 2..1000` に加え、`κ(3000) = 60,057`、`κ(10000) = 225,393` を新たに厳密証明（`M` 上界・根証明の両方）。
- 比 `κ(r)/(r ln r)`: `r=4: 5.23`、`9: 3.89`、`24: 3.21`、`100: 2.81`、`997: 2.565`、`3000: 2.500`、`10000: 2.447` と
  2 へ単調に近づく。
- 残差 `δ(r) = κ(r) - (2r ln r + r ln ln r + (1+\ln 2) r)` の比 `δ(r)/r`:
  `r=4: 2.458`、`9: 1.681`、`24: 1.003`、`100: 0.519`、`997: 0.275`、`1000: 0.274`、`3000: 0.233`、`10000: 0.205`。
  全体として減少する（`κ` が離散的に増えるため局所的な揺れはある）。補題2の補正
  `ln(1 + (ln ln r + O(1))/(2 ln r))` は `r=10^4` で `0.202` を与え、観測値 `0.205` と整合する。
- `r = 3000, 10000` で `k = floor(2r ln r + r ln ln r + 1.2 r)`（奇数丸め）の根なしと、
  `k = floor(2r ln r + r ln ln r + 2.5 r)` の2根を厳密証明。閾値が `1.2 r` と `2.5 r` の間にあることの確認。
- 補題1の両側評価を50桁 `decimal` で20点検査（`ln M` が両側評価の内側にあること。数値監査であり証明ではない）。

## 限界

- `o(r)` 項の明示評価は未証明（数値的には `r ln ln r/(2 ln r)` 程度と整合）。
- 判定条件は `M(k)` の上界・下界による十分条件であり、`r - a < M(k) < r - y_*` の狭間は本稿の議論では使わない
  （K0677 の接触二重根不存在により実際には切替は1回である）。
- 標準格子盤・ゲームの勝敗への主張ではない。
