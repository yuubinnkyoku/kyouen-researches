# (7,6) 7×30 の m=29 witness surgery 完全監査

2026-11-15。対象は seven-row-q5-q8-sat-frontier-20261115 の7×29・34石証人である。7×30に同じ34石を置くと、未遮断セルは T=(29,3) だけになる。q=6なので、空セルを塞ぐには、その点を通る直線または円に5石が必要である。

**結論:** この証人から石を高々2個除き、高々2個加え、最終石数を34以下に保つ全てのT修復候補を、互いに素な6種類に分類して完全列挙した。候補は **1,781,021通り**、安全なものは **126,730通り**、安全かつ極大なものは **0通り**だった。これは証人の局所手術近傍に関する有限完全結果であり、7×30全体の不存在や M_{7,6}=30 を意味しない。

## seed と T の幾何

seedは34点、行占有数 [5,5,5,4,5,5,5]。独立した有理数計算で、seedが定める5,273本の異なる直線・円を再構成した。

| seed上の点数 | 曲線数 |
|---:|---:|
| 3 | 5,108 |
| 4 | 129 |
| 5 | 36 |

最大曲線点数は5。5点曲線による被覆を直接調べると、7×29の空セルは全て遮断され、7×30では T=(29,3) だけが未遮断となる。

Tとseedの2点から決まる曲線の点数分布は、2点曲線531本、3点曲線8本、4点曲線1本。唯一の4点曲線は水平直線 y=3。3点T曲線上にある空セル対は4組だが、3組はTを含み、Tを含まない唯一の対は ((1,3),(5,5)) である。

5点でTを塞ぐ曲線は、追加石が高々2個なので、seed石を少なくとも3個含まなければならない。seed石2個以下のT曲線は修復に使えない。

## 完全場合分け

最終石数34以下・除去2個以下・追加2個以下の範囲で、Tを占有するか、5石曲線で塞ぐ全候補を次の6種類に分けた。各行の候補は重複しない。3点T曲線の唯一の対 ((1,3),(5,5)) について、除去2点がともに y≠3 の435通りはgap-Aに既に含まれるため、独立枠には残り126通りだけを置いた。

| 種類 | 操作 | 候補 | 安全 | 安全かつ極大 |
|---|---|---:|---:|---:|
| T-occupancy | Tと別の空セルを追加、seed石2個を除去 | 98,175 | 18,342 | 0 |
| one-swap | y=3上の空セルを1個追加、seed石1個を除去 | 884 | 154 | 0 |
| two-remove-one-add | y=3上の空セルを1個追加、seed石2個を除去 | 14,586 | 4,306 | 0 |
| three-stone-T-curve-extra | ((1,3),(5,5)) を追加、y=3上のseed石を少なくとも1個除去 | 126 | 5 | 0 |
| four-stone-line-gap-A | y=3上（T以外）とy≠3上から1点ずつ追加、y≠3のseed石2個を除去 | 1,631,250 | 101,439 | 0 |
| four-stone-line-gap-B | y=3上（T以外）から2点追加、y=3上1石とy≠3上1石を除去 | 36,000 | 2,484 | 0 |
| **合計** |  | **1,781,021** | **126,730** | **0** |

旧部分記録の case-b=561 は、gap-Aに含まれる435通りと、今回の独立枠126通りに分かれる。したがって旧4ケース114,206と新しい二つの線型ケース1,667,250を単純加算した値から、重複435通りを除いた1,781,021が重複なしの総数である。

### 場合分けの完全性

- Tを追加する場合はT-occupancy、one-swap、two-remove-one-addに入る。
- Tを追加しない場合、追加が1点なら、その点は唯一の4点T曲線 y=3 上になければならない。
- 追加が2点で4点直線 y=3 を使う場合、直線上1点＋直線外1点を追加して除去2点が直線外（gap-A）、または直線上2点を追加して直線上1石と直線外1石を除去（gap-B）となる。
- 3点T曲線を使う場合、Tを含まない空セル対は ((1,3),(5,5)) だけである。除去2点がともに直線外ならgap-Aに含まれ、少なくとも1点が直線上ならthree-stone-T-curve-extraに入る。
- seed石2点以下のT曲線は2追加しても4点以下なので、Tを塞げない。

これで、指定した編集数・最終石数の範囲におけるT修復候補を尽くす。

## 検査方法

Python検証器 scripts/verify_surgery.py は円の外心・半径を fractions.Fraction で表し、先行TypeScript実装の整数係数正規化とは別方式で曲線を構成する。5,273曲線の点マスクを作り、各候補について安全性と全210セルの極大性を検査する。

安全性は、追加が2点以下なら6点曲線にseed石が少なくとも4点必要なことから、seed三つ組で定まる曲線のうち4点以上のものだけで完全に判定できる。極大性は、追加が2点以下なら5点の遮断曲線にseed石が少なくとも3点必要なことから、3点以上の全seed曲線を各セルで検査すれば完全である。

C++交差検査 scripts/crosscheck_gap_cases.cpp は整数係数の正規化直線・円と64-bit石マスクで実装し、今回欠けていたgap-A/gap-Bの合計1,667,250候補を別方式で再検査した。Pythonと一致した。

再現コマンド:

python3 research/experiments/seven-row-q6-m30-surgery-completion-20261115/scripts/verify_surgery.py

g++ -O3 -std=c++17 -Wall -Wextra -Werror -pedantic research/experiments/seven-row-q6-m30-surgery-completion-20261115/scripts/crosscheck_gap_cases.cpp -o /tmp/crosscheck_gap_cases

/tmp/crosscheck_gap_cases

Python検証器を連続2回実行した output/audit.json はSHA-256が同一（35c4a0010e6a5ee3be937c1ac36744408bcbbf451543c6a27928f7f44e569863）。C++のgap-A/B出力もPythonの候補数・安全数・極大数と一致した。
