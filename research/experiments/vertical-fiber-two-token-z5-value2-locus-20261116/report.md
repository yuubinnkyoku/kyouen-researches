# 2トークン残余ゲームの高さ \(z=5\)：Grundy値2位置の有限抽出

- 日付: 2026-11-16
- 対象: K0832 の \(\kappa=1\) 残余ゲーム \(H(R;X;z)\)、\(X=(x,y)\)、\(x\ge y\ge1\)、\(z=5\)
- status: **有限監査済み予想**。全称性は未証明。本記録は全Grundy値の分類ではなく、値2を取る残容量の候補集合だけを扱う。

## 観測された閉形式候補

\(d=x-y\) と置く。有限抽出から得た値2位置集合の候補は

\[
T_5(x,y)=\{R\ge0:H(R;(x,y);5)=2\}
\]

について

\[
\boxed{
T_5(x,y)=
\begin{cases}
\{1\},&d=0,\ y=1,\\
\{1,3\},&d=0,\ y=2,\\
\{1,3,5\},&d=0,\ y\ge3,\\[2pt]
\{1,3\},&d=1,\ y=1,\\
\{1,3,5,2y+3\},&d=1,\ y\ge2,\\[2pt]
\{1,3\},&d=2,\ y=1,\\
\{1,3,5\},&d=2,\ y\ge2,\\[2pt]
\{1,3,5\},&d\in\{3,4\},\\
\{1,3,5,2y+5\},&d=5,\\
\{1,3,5,2y+5,2y+7,2y+9,2y+11\},&d=6,\\
\{1,3,5,2y+5\},&d\ge7.
\end{cases}
}
\]

既証明の Theorem T により、任意の状態で \(H\le2\)。また既知の tail 定理
\[
R\ge S+|X|+z-1=S+6,\qquad S=x+y
\]
から \(H(R;(x,y);5)=S\bmod2\) である。したがって値2の候補は必ず \(R\le S+5\) に含まれる。今回の有限格子はこの全候補域を覆い、さらに \(S+8\) まで tail との接続も監査した。

## 観測の読み方

- \(d=0,2,3,4\) では、基本ラダー \(\{1,3,5\}\) が残る。ただし \(y\) が小さい端点では短くなる。
- \(d=1\) と \(d=5\) では、ラダーに加えてそれぞれ \(2y+3\)、\(2y+5\) が1点現れる。
- \(d=6=z+1\) では、\(2y+5\) から \(2y+11\) までの4点ランが現れる。
- \(d\ge7=z+2\) では、そのランは先頭の1点 \(2y+5\) に縮む。

特に \(d=6\) の4点ランは、既知の \(z=3,d=4\) の3点ラン、\(z=4,d=5\) の3点ランから点数が1増えている。単純な「高さを1増やすと全てのランが1点伸びる」という規則ではなく、\(d=z+1\) の境界だけが特別に動いているように見える。

## 証明状況と限界

この監査は有限範囲 \(x\le100\) の完全照合であり、任意の \(x,y\) に対する全称証明ではない。固定seed散点も全称性を補わない。今回の結果をK0832の定理へ昇格させない。

z=5 の全Grundy値（0/1/2）の分類も未完成である。値2位置だけでも、全称化には z=4 スライスの候補をまず全称証明へ昇格させ、その後に \(R\) 強帰納の選択肢表を \(d\) の各領域で閉じる必要がある。

## 次の実行可能な課題

1. z=4候補のA/B/C選択肢表を \(d=0,1,2,3,4,\ge5\) に分けて全称化する。
2. z=5 の \(d=6\) 4点ランが \(d=z+1\) に固有か、より大きい高さでも \(z-1\) 点ランになるかを検査する。
3. z=5 の値1位置を別途抽出し、値2位置だけの候補から全Grundy分類へ進める。

現段階で確定したのは有限格子上の観測と二方式の再現性だけである。
