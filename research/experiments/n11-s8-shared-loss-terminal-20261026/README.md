## 発見

証明済み8石WINから見た7石局面の未被覆候補を抽出したところ、2個の7石親に共通する8石候補 `000000100010a0011000000001004000` が現れた。8石WINを予想して終局を調べたが、実際は**8石LOSS**だった。

この8石根の全合法9石子はD4対称類で27個。各9石子について、元先手が手番となる10石局面の**LOSS**証人を1個ずつ選択した。証人は延べ27個、相異なる24個。全24個を既存cacheなしで終局まで解き、3×3整数行列式と独立の4×4 Bareiss法で結果が一致した。よって9石の手番である後手には、必ず元先手を負け局面へ移す応手が存在する。8石根は元先手LOSS。

8石根の一石除去から7石LOSS親8類、さらに一石除去から6石WIN親28類（従来証明との純増27類）を導出した。6石WINは各親に合法な7石LOSS子が存在することを確認している。
