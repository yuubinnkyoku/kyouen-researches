# 3トークン過渡帯の値2位置 — 対角線と c ≤ −(2k+1) スライスの有限分類（κ=1）

実験日: 2026-11-16（JST）。対象は K0832 の残余ゲーム H(R;X;z)（κ=1）で、2トークン閉形式予想の「家族B（過渡位置）」に対応する帯を3トークン族で体系的に掃引した初回の実験である。

## 問題の設定

3トークン族 X=(x,y,w)（x≥y≥w≥1）、z≥0、S=x+y+w とする。2トークン族では値2位置の帯構造（ラダー・家族B・家族A）が予想済みで、家族Bは過渡帯（x<R<S+z+2）に現れる。3トークン族では過渡帯の完全な形は未知であり、今回は帯内の R=2x+c のうち奇数 c=−(2k+1)（k≥0）のスライスを、j := x−(y+w+z)（≥0、2x_max=S+z+j すなわち e=j の座標）に沿って掃引した。

帯条件は R>x、R>z+1、R<S+z+2。最後の条件は j<2k+3 を含意し、各 k で j の取り得る範囲は有限になる（k=0 では j≤2）。ラダー帯 R≤z+1 は証明済みの高さのみ縮約で閉じているため除外した。

## 主結果

### 予想U（k≥1 スライスの統一形・双方向有限監査）

**命題U.** k≥1、j≥0、x=y+w+z+j、R=2x−(2k+1)、帯条件内のとき
H(R;(x,y,w);z)=2 ⟺
- (j=0 ∧ w=1): z ≥ 2k、または
- (それ以外): 2(k+1−j−w) ≤ z ≤ 2(k+1−j−w)+1（下端が負なら不成立）。

OK 位置は y に依存しない。k=1,2,3 の全グリッド（y≤13、w≤6、z≤15、j≤7）20,052ケースで予想の陽性・陰性の両面が完全一致（不一致0）。k=1 では (j,w)=(0,1)→z≥2、(0,2)→z∈{0,1}、(1,1)→z∈{0,1} の3族、k=2 では (0,1)→z≥4、(0,2)→z∈{2,3}、(0,3)→z∈{0,1}、(1,1)→z∈{2,3}、(1,2)→z∈{0,1}、(2,1)→z∈{0,1} の6族となり、k の増加とともに (j,w) 平面の下三角に周期2の「z 区間」が並ぶ。

### 予想A/B/C（k=0・R=2x−1 の特異スライス）

**命題A.** j=0（x=y+w+z）なら帯内で常に H(2x−1;(x,y,w);z)=2。y,w,z に依存しない。
**命題B.** j=2（x=y+w+z+2）なら帯内で常に値2。
**命題C.** j=1 のとき値2となるのは z=0 のみで、z≥1 では帯内の全位置が値2でない。j≥3 は帯条件を満たす位置が存在しない（R≥S+z+1 となり tail 側）。

5,658ケースの双方向照合と、j=1・z≥1 の陰性面 1,183ケースで不一致0。k=0 は統一形 U に当てはまらない（w がいくつでも j=0 が全OK になる、j=2 の全OK は k≥1 の式が予測しない）特異ケースである。構造的な説明候補として、k=0 では R+1=2x がちょうど最大トークンの 2 倍であり cap_{R+1} が X を変えないのに対し、k≥1 では R+1=2x−2k<x で最大トークンが cap されることが挙げられる（未証明）。

### 対角線 OK 表（2x_max=S+z、R=2x_max−1、m=|X|）

X=(x_max,)∪rest、x_max=sum(rest)+z と置く。m=1 は単一トークン閉形式の z=x 特別枝そのもの（証明済み）。m≥2 について抽出した OK 条件（rest は昇順）:

| m | OK 条件 | 照合ケース数 |
|---|---|---|
| 2 | z=1 | 69 |
| 3 | 常に成立（rest 任意） | 280+2760 |
| 4 | (z=0 ∧ (rest[:2]≠(1,1) ∨ rest=(1,1,1))) ∨ (z=1 ∧ rest[:2]=(1,1)) | 840 |
| 5 | rest[:3]=(1,1,1)（z 任意） | 2100 |
| 6 | (z=1 ∧ rest[:4]=(1,1,1,1)) ∨ (z=0 ∧ rest[:2]=(1,1) ∧ ((rest[:3]=(1,1,1) ∧ rest[3]=2) ∨ (rest[2]=2 ∧ rest[3]=2))) | 2520 |
| 7 | rest[:5]=(1,1,1,1,1)（z 任意） | 840 |
| 8 | (rest=(1^7) ∧ z∈{0,1}) ∨ (z=1 ∧ rest[:6]=(1^6)) ∨ (z=0 ∧ ((rest[:5]=(1^5) ∧ rest[5]=2) ∨ (rest[:4]=(1^4) ∧ rest[4]=2 ∧ rest[5]=2))) | 252 |

m 奇数では「rest の先頭 m−2 個がすべて1」の族が全 z で OK し、m 偶数では z∈{0,1} の2層構造（z=1 層は先頭 m−2 個が1、z=0 層は先頭 m−3 個が1のあと 2 が並ぶ族）が現れる。ただし m=4 の z=0 層だけは例外で、「先頭2個が (1,1) でない」限り自由である。抽出トークン上限は m≤5 で 7、m=6 で 6、m=7 で 4、m=8 で 3 であり、表はこの範囲内の完全抽出（全称主張ではない）。

### 初期観察の反例

「m 奇数なら対角線 OK が常に成立する」という初期観察（m=1,3 で支持）は、m=5 で OK が rest=(a,1,1,1) 族（先頭3個が1）に限られることが完全抽出で確定したため反例となった。m=5 の帯内グリッドの大多数は値2でない。この訂正により、m 依存の OK 条件は表の通り有限族として記述し直した。

## 既知結果との整合

- 予想A の位置 R=2x−1 は天井予想の位置族 p_0=2w+δ_A(z)、p_1=2y+δ_A(z+1) より大きく（R=2(y+w+z)−1≥2y+δ_A(z+1)、δ_A≤z+2）、cap ブリッジ帯 [max(z+2,y), x−1] の外側であり、既存のいずれの族とも重複しない新しい帯である。
- 予想A/B/C の位置はすべて奇数 R で Theorem T（奇数 R で H≤2）と整合する。
- 単一トークン閉形式（z=x 特別枝で R=2x−1 が値2）は m=1 行として回収される。
- 高さのみ縮約（R≤z+1）と tail 定理（R≥S+|X|+z−1）で閉じる帯は本次の過渡帯の外側であり、本結果は中間帯の知見を増やす。

## 限界と次課題

- 予想U・A/B/C・OK表はいずれも有限監査による予想・観察であり、全称証明ではない。証明戦略として、A手 x→x−1 がスライス族 F_j(x):=H(2x−2k−1;(x,y,w);z) の間を結ぶ連立漸化式（F_{k,j} の子は F_{k,j} の x 方向隣接と cap によるレベル再帰）を与えること、R 前進帰納で帯内の値プロファイル（0/1 の周期構造）を固定することが挙げられる。全1族の機械支援帰納証明（3,803シグネチャ類）と同じ方法論が適用できる可能性がある。
- 対角線 OK 表の m≥9 への外挿、m 偶数 z=0 層の一般形（m=4 の例外性の説明）、m 奇数の「先頭 m−2 個が1」族と B 手（1 を除去して z+1）による m−2 への帰着関係は未解決。
- k≥4 のスライス、c が偶数の位置（R と 2x の偶奇が異なる場合、Theorem T の偶数 R 側）は今回未掃引である。
