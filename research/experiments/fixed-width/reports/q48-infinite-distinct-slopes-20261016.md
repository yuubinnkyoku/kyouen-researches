# 4行8点円：相異なる既約傾きが無限に存在する

2026-10-16。基準 `main=db2a6b9b5291c4038b65e98fa838088881b17c0d`。対象は標準整数格子の四連続行 `y=0,1,2,3` に各2点を持つ非局所8点円。**証拠区分：全称的な整数論証明**。末尾の検算は有限監査。

## 定理

四行8点円に現れる相異なる既約傾き `A/B` は**無限個**存在する。実際、すべての `n>=0` について正の互いに素な整数 `C_n,B_n` を明示的に構成でき、

```
37*C_n² - 325*B_n² = 8,
A_n/B_n = 3*C_n/B_n,
3*sqrt(325/37) < A_(n+1)/B_(n+1) < A_n/B_n <= 9,
lim_(n->infinity) A_n/B_n = 3*sqrt(325/37) = 8.891234675... .
```

各傾きには**実際の整数8点円**が存在する。さらに任意の整数 `N>=1` に対して、これらの中には

```
A_n ≡ 9 (mod N), B_n ≡ 1 (mod N)
```

を同時に満たす**相異なる傾きが無限個**ある。その部分列の8点円を左端0へ正規化した全座標も、初項 `(35,51,63,73)` の円と法 `N` で一致する。従って、**どんな固定有限法の合同篩も、この傾き9の合同類に実現傾きが無限にあることを排除できない**。

ここで「傾き」は K0432 の `s/v=A/B` に従う。異なる円型が無限個あるという K0431 より強く、**傾き自体が無限種類**という結論である。

## 構成

次の明示的な整数を固定する。

```
U = 1859131879201,
V = 16953823416,
U² - 12025*V² = 1.
```

`(C_0,B_0)=(3,1)` から

```
C_(n+1) = U*C_n + 325*V*B_n,
B_(n+1) = 37*V*C_n + U*B_n
```

と定める。各世代で弦長を

```
(a,b,c,d) = (18C-19B, 19C-6B, 19C+6B, 18C+19B)
```

とし、四行それぞれの横座標を `(d-a)/2,(d+a)/2` などと置く。

K0432の正規形では、各世代で `A=3C, g=3, L=6, M=19` と固定でき、`P=9C²−B², Q=C²−B²` に対して `Q M²−P L²=37C²−325B²=8` が成立する。したがって固定傾きのPell延長とは逆に、**Pell解の固定したL,Mから傾きA/Bを変化させる**構成になっている。

## 全称証明

1. **ノルム保存・既約性。** `37C_0²−325B_0²=8`。再帰行列 `T=[[U,325V],[37V,U]]` は行列式 `U²−12025V²=1` を持ち、二次形式 `37C²−325B²` を保存する。`T` と `T^{-1}` は整数行列なので `gcd(C_n,B_n)=1` が保たれる。`U` は奇数、`V` は偶数だから両変数は常に奇数。また `U≡1, V≡0 (mod 3)` より `C_n≡0, B_n≡1 (mod 3)`。従って `A_n=3C_n` と `B_n` は互いに素で、K0432 の `g=gcd(A_n,3)=3` である。

2. **正値・単調性。** `t=sqrt(325/37)` とする。`C_0/B_0=3>t>2`。比の写像は `f(r)=(Ur+325V)/(37Vr+U)`。`f(t)=t`、導関数は `1/(37Vr+U)²>0`、さらに `f(r)-r=V(325−37r²)/(37Vr+U)<0`（`r>t`）。よって `t<C_(n+1)/B_(n+1)<C_n/B_n<=3`。正整数の再帰なので各変数は増大し、比は `t` に収束する（極限は `f` の正の固定点）。

3. **奇数弦長と真の共円性。** `2B<C<=3B` から `0<a<b<c<d` が従う。具体的に `a=18C−19B>0`、`b−a=C+13B>0`、`c−b=12B>0`、`d−c=13B−C>0`。`C,B` は奇数なので弦長4個は奇数。直接展開で

   ```
   a²−2b²+c² = b²−2c²+d² = 325B²−37C² = −8.
   ```

   従って `S=d`、`D=(d²−a²)/4`、`E=(a²−b²)/4−1` と置くと、整数係数円 `x²+y²−Sx+Ey+D=0` は各行 `y=i` にちょうど整数根 `x=(S±d_i)/2` を持つ。8点は相異なり、全横座標は0以上d以下。これは実在する非局所8点円である。さらに `(d+a)/2=18C`、`(c−b)/2=6B` だから、K0432の傾きは `A/B=3C/B` に等しい。比が真に減少するので全て相異なる。

4. **任意の合同類での無限性。** `T` は任意の `2N` を法とする有限群 `GL₂(Z/(2N)Z)` の元なので、ある `h>=1` について `T^h≡I (mod 2N)`。全 `k>=0` で `(C_(kh),B_(kh))≡(3,1) (mod 2N)`。従って `A_(kh)≡9, B_(kh)≡1 (mod N)`。弦長は `C,B` の整数線形結合なので初項と法 `2N` で一致し、`(d±d_i)/2` は法 `N` で一致する。比は単調減少なのでこの部分列も相異なる。□

## 限界・接続

新定理は相異なる実現傾きの**無限性**と一つの明示的な集積点を確定するが、傾きの計数関数 `R(H)` の正確な増加次数や、次の未発見傾きの最小盤長は決めない。K0431・K0432の「固定傾きの無限Pell延長」とは異なる方向の無限性である。任意の法での無限同余傾きは、固定合同類の列挙を有限分類と取り違えないための注意点となる。
