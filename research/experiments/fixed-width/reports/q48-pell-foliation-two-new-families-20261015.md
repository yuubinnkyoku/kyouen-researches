# 四行8点円の一般Pell分解と、既知の新型から生じる二つの無限族

日付: 2026-10-15。対象は標準4行 `y=0,1,2,3` を各2整数点ずつ通る円。**全称代数定理＋二つの具体的無限族の全称構成**であり、全円型の分類ではない。

## 結論

厳密増加する正の奇数弦長 `a<b<c<d` が四行8点円を与えるなら、既約正整数 `A,B` と正整数 `L,M`、`g=gcd(A,3)` が一意に存在し、

```
a = A L - (3B/g) M
b = (A/g) M - B L
c = (A/g) M + B L
d = A L + (3B/g) M
A > 3B, gcd(A,B)=1,
P = A²-B² > 0,  Q = (A²-9B²)/g² > 0,
Q M² - P L² = 8.
```

この正規形は弦長の二階差分条件を完全に表す。逆に右辺の4数が正の奇数なら、同じ二階差分を満たすため四行8点円を作る。上下反転型は弦長の順序を逆転させる。

特に、`D=P Q` が非平方数で一つ解 `(L,M)` があれば、任意の正のPell単元 `U²-DV²=1` に対して

```
L' = U L + Q V M
M' = U M + P V L
```

は再び解となる。下記の二つの既知新型はこの条件を満たし、**互いに異なる二つの新しい無限Pell族**を生む。

| 最初の弦長 `(a,b,c,d)` | `(A,B)` | `(P,Q)` | `(L,M)` | `D=PQ` |
|---|---|---|---|---:|
| `(445465,715719,908883,1067653)` | `(47,6)` | `(2173,1885)` | `(16097,17283)` | 4096105 |
| `(98119,1096275,1547259,1893727)` | `(53,12)` | `(2665,1513)` | `(18791,24939)` | 4032145 |

前者は最小1,067,654列、後者は最小1,893,728列で出現する。いずれも旧 `u²-10v²=1` 族の傾き `(A,B)=(9,1)` と異なり、同族の単なる後続項ではない。

## 全称証明

四行の弦長二階差分条件は

```
a² - 2b² + c² = -8,
b² - 2c² + d² = -8.
```

これらを引くと `d²-a²=3(c²-b²)`。全弦長が奇数なので

```
s=(d+a)/2, t=(d-a)/2, u=(c+b)/2, v=(c-b)/2
```

は正整数で、`st=3uv`。`s/v=A/B` を既約分数で表すと、`s=A L, v=B L`、さらに `g=gcd(A,3)` として `t=(3B/g)M, u=(A/g)M` が整数解の全形である。これを `a=s-t,b=u-v,c=u+v,d=s+t` に代入すると表記の4式を得る。

最初の二階差分は

```
(A²-B²)L² + ((9B²-A²)/g²)M² = -8.
```

一方 `s>v` は `d+a>c-b` から自明なので `A>B`。`B<A<=3B` なら上式の左辺は非負で矛盾する。従って `A>3B`、`P,Q>0`、`Q M²-P L²=8` が必要。逆向きは同じ展開を逆にたどるだけである。

Pell漸化式の不変性は直接展開して

```
Q(M')² - P(L')² = (U²-PQV²)(QM²-PL²) = 8
```

で従う。`D` 非平方数ならPell方程式には `U>1,V>0` の整数解が存在する。従って `(L',M')` を繰り返せば `L` は真に増加し、互いに異なる無限個の弦長型を得る。

**具体的な二族の正値・単調性・奇偶性。** 両族は `A` 奇数、`B` 偶数、`g=1`、初期 `L,M` 奇数、`P,Q,D` 奇数かつ `D≡1 (mod 4)`。任意のPell単元について `V` は偶数、`U` は奇数なので、漸化式は `L,M` の奇数性を保ち、4弦長は奇数のまま。さらに

```
(M/L)² = P/Q + 8/(Q L²),
```

ゆえに `L` の増加に伴い `M/L` は真に減少し、常に `M/L>sqrt(P/Q)>1`。初期4弦長は厳密増加・正であり、

```
a/L = A - 3B(M/L),
b-a = (A+3B)M-(A+B)L > 0,
c-b = 2BL > 0,
d-c = (A-B)L-(A-3B)M
```

の各式から、全後続項でも `0<a<b<c<d` が保たれる。最後の式では `A>3B` を使う。よってPell後続項は全て実際の8点円である。

**円への復元。** 各行 `y=i` に `x=(d±d_i)/2` を置く。奇数弦長のため全点整数で、`0<=x<=d`、上下各行2点。円方程式

```
x²+y²-d x + C y + E = 0,
C=(a²-b²)/4-1, E=(d²-a²)/4
```

の各行への代入は二階差分条件により0。従って最小列数は厳密に `d+1`。任意の円は各行高々2点しか持てないので、この8点が四行内の円上全格子点である。

## 限界・未解決

- `D=PQ` が平方数となる既約傾き `(A,B)` が存在しうるか、あるいは全非局所円が無限Pell族を生むかは**未証明**。一般正規形から無条件に全円の無限延長を結論しない。
- 第0世代の二新型が200万1列までの円型完全列挙で見つかっていることと、全世代が実在することは別の主張。後者は上記の数学的帰納証明に基づく。
- 二族が既存の `u²-10v²=1` 族と異なることは、各弦長から一意に復元される傾き `A/B` の相違による。
- 11×11の長時間root探索には依存しない。
