# 接線型5点円の定数項 B=4 の厳密簡約と高精度独立照合（2026-11-13）

対象：`research/experiments/fixed-width/reports/q35-tangent-log-periodic-constant-term-20261113.md` の定数項。既存の全称式の**代数的厳密化**であり、新たな幾何学的分類の証明ではない。

`λ=3+2√2, C=4+3√2, D=4−3√2` と置く。既存報告の
`B=2C/(λ−1)−2D/(1−λ^(−1))` は厳密に **4** である。

実際、`C+D=8`, `CD=−2`, `λ+λ^(−1)=6`, `Cλ^(−1)=−D` を用いると
`B=2(C−λD)/(λ−1)`。ここで `C−λD=2(λ−1)` だから `B=4`。

したがって既存定理は、全ての整数 `m≥9` について

```
T₅(m)=2m log_λ(m/C)+mH({log_λ(m/C)})+4
       + 2D λ^(−N)/(1−λ^(−1)),
N=floor(log_λ(m/C))+1,
H(t)=2(1−t)−2λ^(1−t)/(λ−1).
```

となる。最後の項は厳密に負であり、`O(1/m)` である。

## 別経路の数値照合

整数漸化式 `a₀=8,a₁=48,a_(j+2)=6a_(j+1)−a_j` から `T₅(m)=2Σ_(a_j<m)(m−a_j)` を直接算出。Python の Decimal 70桁精度で `m=9,10,48,49,280,281,100000` を照合した。定数項は `3.999999999999999999999999999999999999999999999999999999999999999999996`、各点の残差は最大 `10^(-63)` 程度（高精度丸め誤差）だった。有限数値照合は上の恒等式の証明の代用ではない。

## 注意

`N` の算出に浮動小数点を用いると閾値付近で丸めによる誤判定があり得る。実装上の正本は整数漸化式による `a_j<m` の判定とする。総円数 `F₅(m)` の漸近式を主張しない。
