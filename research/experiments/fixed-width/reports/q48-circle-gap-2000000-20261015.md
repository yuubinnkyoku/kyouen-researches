# 4×m・q=8：2000001列までの8点円の有限完全分類

2026-10-15。GitHub main `c1d0044e6f06dc2791e157ba208fdf7624b653a2` を確認し、K0317の1000001列までの有限分類を拡張した。**全盤長の定理ではない。**

## 結論

四連続整数行 y=0,1,2,3 に各2点を持つ8点円の水平弦長型は、1<=m<=2000001 の範囲で、局所型 `(1,3,3,1)`、以下の増加型5種類、および各増加型の上下反転の **11型** に限る。

| 増加型 `(d0,d1,d2,d3)` | 初出盤長 |
|---|---:|
| (35,51,63,73) | 74 |
| (1331,1935,2391,2773) | 2774 |
| (50543,73479,90795,105301) | 105302 |
| **(445465,715719,908883,1067653)** | **1067654** |
| **(98119,1096275,1547259,1893727)** | **1893728** |

下の2型は、従来の100万弦長までの分類に存在しない新型であり、これまで列挙されていたPell列とも異なる。特に1000002〜1067653列に新型はない。

`[x]_+ = max(0,x)` とすると、全整数 1<=m<=2000001 に対して8点円の本数は厳密に

```
C8(m) = [m-3]_+ + 2[m-73]_+ + 2[m-2773]_+
       + 2[m-105301]_+ + 2[m-1067653]_+ + 2[m-1893727]_+.
```

特に `C8(2000001)=15860954`。同じ範囲の禁止8点集合数は `4*binom(m,8)+C8(m)`、安全な8石集合数は `binom(4*m,8)-4*binom(m,8)-C8(m)`。

## 全列挙への数学的還元

各行の水平弦長 d_i は正整数で、円の弦長平方の二階差分が -8 であることから

```
d0² - 2d1² + d2² = -8,
d1² - 2d2² + d3² = -8.
```

mod 4 から d_i はすべて同偶奇。全て偶数なら d_i=2e_i として二階差分は -2。mod 2 で e0,e2 は同偶奇、e1,e3 も同偶奇。mod 4 でこの2組は逆偶奇になる。奇数組の平方は mod 8 で1、偶数組の平方は mod 8 で0または4なので、奇数組を含む方の二階差分は mod 8 で2となり、-2≡6に矛盾。したがって **d_i はすべて奇数**。

円の縦中心 b について `d1²-d0²=8b-4` であり、奇数平方の差が8の倍数なので b は半整数。b=1/2,5/2 のときは隣接する弦長が等しく、他の隣接平方差8から正の奇数弦長 `(3,1)` が強制され、最も外側の弦長平方が負になる。b=3/2 なら `(d0,d1,d2,d3)=(1,3,3,1)` のみ。その他の半整数 b は4行の外側にあり、弦長は厳密増加または厳密減少。従って局所型と **厳密増加の奇数4つ組** を調べ、上下反転で全型を復元すればよい。

逆にこれら二階差分を満たす奇数4つ組から、`S=max(d_i)`, `C=(S²-d0²)/4`, `B=(d0²-d1²)/4-1` として円 `x²+y²-Sx+By+C=0` を構成できる。各行の2交点は整数。幅 D=max(d_i) の型は m 列盤に `[m-D]_+` 本だけ水平移動して現れる。

## 二つの独立した有限完全列挙

`census_ab.cpp` は `(d0,d1)=(a,b)` を列挙し、`d2²=2b²-a²-8`, `d3²=3b²-2a²-24` の平方数性を法4032の必要条件と整数平方根で検査。B=2000000で **3,536,966,397** 候補を確認し、増加型5件を出力（14.38秒）。

`census_ac.cpp` は独立の `(d0,d2)=(a,c)` 列挙から、`d1²=(a²+c²+8)/2`, `d3²=(3c²-a²-24)/2` を法2016の必要条件と整数平方根で検査。B=2000000で **3,160,924,246** 候補を確認し、増加型5件を出力（13.35秒）。**全型一覧が完全一致**。B=1000000でも既存分類の増加型3件と一致。

`check_geometry.py` は別方式で11型の整数座標を復元し、各8点の全70通りの4点共円行列式を直接整数計算した。**計770件すべて0**、横幅も各型の最大弦長と一致した。

両列挙の剰余枝刈りは平方数の必要条件しか用いないため解を落とさない。浮動小数点sqrtは初期値のみで、整数積で補正した完全平方判定を使う。B=2000000で二乗は64bit符号付き整数の範囲内。増加奇数の全候補を走査しており、ここまでの有限分類は完全。

## 再現

```
g++ -O3 -std=c++17 census_ab.cpp -o ab
g++ -O3 -std=c++17 census_ac.cpp -o ac
./ab 2000000 > ab_2m.txt
./ac 2000000 > ac_2m.txt
diff -u ab_2m.txt ac_2m.txt
python check_geometry.py
```
