# 整数円の二重点行257〜384本：二つの明示円による128個の構成下界

2026-10-09。最新mainのK0369は `T(63)=16` までを正式に記録している。未統合の先行研究ZIPにある `97〜256` の構成とは別に、**257〜384の128個の構成下界**を新しく与える。先行の上界証明を仮定しない独立の存在証明である。

## 定義・結論

`T(w)` は、連続した整数水平行 `0≤y<w` において、一本の実円が**相異なる整数格子点2個**を持つ行の最大数。横座標は全整数を許す。`research/experiments/fixed-width/output/double_rows_257_384.csv` に、全ての `257≤k≤384` に対して `T(width)≥k` を証明する円の整数係数と幅を収録する。

代表値：

| k | width | 証人円 `x²+y²+x+Cy+D=0` |
|---:|---:|---|
| 257 | 77,086 | C=−79,485, D=−432,306 |
| 288 | 79,486 | C=−79,485, D=−432,306 |
| 289 | 137,005 | C=−160,493, D=−1,624,350 |
| 300 | 142,477 | C=−160,493, D=−1,624,350 |
| 320 | 149,743 | C=−160,493, D=−1,624,350 |
| 350 | 157,296 | C=−160,493, D=−1,624,350 |
| 384 | 160,494 | C=−160,493, D=−1,624,350 |

この表の `width` は**採用した二つのノルムの範囲内**で最短の幅であり、すべての円に対する最小幅の証明ではない。

## 構成の全称的な正当化（128件の有限存在証明）

二つの正整数

- `N1=6,319,594,450 = 2·5²·13²·17·29·37·41`
- `N2=25,764,500,450 = 2·5²·13·17·29·37·41·53`

を用いる。いずれも `N≡2 (mod 4)` なので `u²+v²=N` の整数解では `u,v` は奇数。`u≠0` である解の異なる `v` の個数はそれぞれ288と384である。

任意の奇数 `v` に対して `u²+v²=N`、`u≠0` なら、`C=v_0`、`D=(1+C²−N)/4` と置いた円

`x²+y²+x+Cy+D=0`

の `y=(v−C)/2` 行に、整数 `x=(-1±u)/2` の**相異なる2点**が存在する。`N≡2 mod4` かつ `C` が奇数なので `D` は整数である。CSVは `v` の昇順列のうち `k` 個を収める最短区間 `[v_0,v_{k−1}]` を二つの `N` で比較し、`width=(v_{k−1}−v_0)/2+1` と `C=v_0` を記録した。これにより128個の下界が証明される。

Gaussian整数の因数分解による生成器は、`p≡1 (mod4)` の各素因数 `p=a²+b²` に対して `(a+bi)^j(a−bi)^(e−j)` の全 `0≤j≤e` を掛け合わせ、座標交換・符号反転を加える。`2=(1+i)(1−i)` も同様に処理する。有限集合の構成であり、円係数全体の探索ではない。

## 独立検証・限界

`construct_double_rows_257_384.py` がGaussian整数の積からCSVを作成する。別実装の `verify_double_rows_257_384.py` は `u=1,...,⌊√N⌋` を直接走査し、`N−u²` の整数平方根を判定して**全vを独立に列挙**する。さらに128件の証人すべてについて、`y=0,...,width−1` の判別式の整数平方根・二つの整数根・円方程式への代入を直接検査し、指定した二つのノルム間の最短区間も照合する。

```sh
python research/experiments/fixed-width/scripts/construct_double_rows_257_384.py
python research/experiments/fixed-width/scripts/verify_double_rows_257_384.py
```

出力：128/128件PASS、ノルム別の二重点行288/384本、全幅で直接整数検証PASS。全て**明示構成下界**であり、`T(w)` の全円に対する上界・厳密値は主張しない。先行する64〜336の条件付き厳密値や未統合の97〜256下界とは論理的に独立である。
