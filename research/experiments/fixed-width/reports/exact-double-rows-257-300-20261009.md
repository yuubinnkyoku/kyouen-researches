# 標準整数円の二重点行数：257〜300行の厳密値

2026-10-09。新規の44幅について、数学的な必要条件の有限完全排除を二つの実装で検査し、整数円の明示構成を独立検証した。

## 定理と先行依存

連続する整数水平行 `y=0,...,w-1` のうち、一本の実円が異なる整数格子点2個を持つ行の最大数を `T(w)` とする。横座標は全整数。

**先行の計算機援用証明 `T(256)=32` を基底として**、

```
T(w)=32  (257<=w<=300).
```

従って33本の二重点行を実現するための最小幅は少なくとも301である。この下限は `T(256)=32` の先行証明に依存する。先行証明のZIP `kyouen-fast-exact-T64-256-20261009.zip`（SHA256: `9cdfe1abcc2e3c230596a29f60efc3b189160668fa03a5ed8bf8a4a50a5646ac`）は現時点のmainに未統合であり、knowledge昇格時には同時に統合する。

## 下界（整数点の直接検証）

円

```
x²+y²+x−235y−6=0
```

の `0<=y<300` における二重点行は次の32本だけである。

```
0,1,3,4,10,15,22,25,45,49,60,70,87,91,102,115,
120,133,144,148,165,175,186,190,210,213,220,225,231,232,234,235
```

`verify_double_rows_257_300_witness.py` は横座標 `-120<=x<120` を直接走査し、全300行で円への整数代入を行う。円の中心は `(-1/2,235/2)`、半径二乗は `6+1/4+(235/2)^2=13812.5`、従って上記x範囲は全整数解を含む。これにより各幅257〜300で32行の下界が成立する。

## 全称上界の帰着

任意の `w` で `T(w−1)<=T(w)<=T(w−1)+1`。`T(w−1)=32` が証明済みとし、33本の二重点行を持つ円を仮定する。両端 `y=0,w−1` はともに二重点行でなければならない（片端を除いた幅 `w−1` でも33本残ってしまうため）。

円の式を `x²+y²+Bx+Cy+D=0` とすると、行0の二整数根の和・積から `B,D∈Z`。二重点行の行番号差の最大公約数を `g` とすると `gC∈Z` で、`g|(w−1)` かつ `1<=g<=floor((w−1)/32)`。該当行を `y=gk`、`a=gC∈Z` と書けば、整数根 `x` は

```
(2x+B)²=B²−4D−4g²k²−4ak
```

を満たす。任意の奇数法 `p` で `gcd(g,p)=1` のとき、ある `c,n mod p` について各該当行の `k` は

```
n−(2gk+c)² ∈ QR(p)    （QRは0を含む平方剰余）
```

を満たす必要がある。`c=a/g`, `n=B²−4D+(a/g)² mod p` とすれば導ける。法ごとに `(c,n)` を独立に選ぶのは制約を緩めるため、これを排除できれば全実円を排除できる。

`verify_double_rows_257_320.cpp` は各 `g` と各法 `p` に対して全 `p²` 組の `(c,n)` を列挙し、両端を含み33行以上を許すマスクを保持する。次の法を加えるたび共通部分を取り、33行未満を捨てる。全 `w=257,...,300` の可能な `g` で最終候補数0を検査した。法は `9,11,7,49,19,23,31,43,47,37,41,53`、`g` と非互いに素なものは飛ばす。円係数の有限範囲探索ではない。

## 独立検査

C++20の二方式は `(c,n)` ごとの全行直接検査（`-DDIRECT_RESIDUES`）と、行別の平方剰余を転置して作る方式（標準ビルド）。257〜280行と281〜300行をそれぞれ完全実行し、**計537段階の `CASE` 行、44幅の `EXACT` 行、2本の `PASS` 行が全てバイト単位で一致**した。下界は別言語Pythonによる整数座標の直接走査で確認した。

```
g++ -O3 -std=c++20 research/experiments/fixed-width/scripts/verify_double_rows_257_320.cpp -o /tmp/rows_a
g++ -O3 -std=c++20 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_double_rows_257_320.cpp -o /tmp/rows_b
for pair in '257 280' '281 300'; do
  set -- $pair
  /tmp/rows_a "$1" "$2" > /tmp/a.txt
  /tmp/rows_b "$1" "$2" > /tmp/b.txt
  cmp /tmp/a.txt /tmp/b.txt || exit 1
done
python research/experiments/fixed-width/scripts/verify_double_rows_257_300_witness.py
```

**重要**：分割実行の開始幅の直前の `T(w−1)=32` を仮定する。前区間と先行の64〜256行の完全検証を接続しない限り、ログだけで独立の全称証明とはならない。有限完全列挙に依存する計算機援用証明であり、Lean等の形式証明ではない。

## ゲームへの帰結

300行における円の整数点は高々 `300+T(300)=332`、非水平直線は高々300。従って標準整数格子の300×m・q点版で `q>=333` なら全ての `m>=1`、全安全局面 `S` に対し

```
g(S)=(300 min(m,q−1)−|S|) mod 2,
M_(300,q)=q−1.
```

q<=332の必要性や、任意間隔の平行行への一般化は主張しない。
