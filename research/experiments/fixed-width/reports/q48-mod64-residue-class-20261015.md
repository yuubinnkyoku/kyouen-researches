# 4×m・q=8 非局所円の奇数分母傾き：法64の4合同類

2026-10-15。証拠区分：全称数学的証明と、別方式の有限算術検算。

## 命題

4連続整数行に各2格子点を持つ非局所8点円の弦長を上下反転で `0<a<b<c<d` とし、`s=(a+d)/2`, `v=(c-b)/2` の既約比を `A/B=s/v`（`A,B>0`, `gcd(A,B)=1`）とする。**Bが奇数なら**、必ず

```
A/B ≡ 9, 23, 41, 55 (mod 64),
```

ここで左辺は `A * B^(-1) mod 64` を表す。従って `A²−B²≡16 (mod64)`、`A²−9B²≡8 (mod64)`。これらは必要条件であり、十分条件ではない。B偶数には適用しない。

## 証明

既存K0431/K0432の正規形を用い、`g=gcd(A,3)`, `P=A²−B²`, `Q=(A²−9B²)/g²` とすると正整数 `L,M` が存在して `QM²−PL²=8`。また `A>3B`。

**素因数補題。** `r≡3 (mod4)` の素数は `P,Q` を割らない。`r>=7` で `r|P` なら既約性から `r∤B` であり `Q≡−8B²/g² (mod r)`、ノルム式から `−(BM/g)²≡1 (mod r)` となって矛盾。`r|Q` でも `P≡8B²` から `−(BL)²≡1 (mod r)` と矛盾。`r=3` では `3∤A,3∤B` の場合 `M²≡2 (mod3)`、`3|A,3∤B,9∤A` の場合 `L²≡2 (mod3)` となって矛盾。残る `3|B` または `9|A` では `3∤PQ`。補題が従う。

B奇数のときAが偶数なら `P≡3 (mod4)` であり、Pは必ず `3 (mod4)` の素因数を持つため不可能。よってA,Bとも奇数。`P=8p`, `Q=8q` と書く。`P−g²Q=8B²`、`g²≡1 (mod8)` から `p≡q+1 (mod8)`。ノルム式は `qM²−pL²=1`。

法8の平方剰余 `0,1,4` を用いる。q奇数ならp偶数でM奇数、L偶数が必要となり `q≡1 (mod8)`。q偶数ならp奇数でL奇数、M偶数が必要となり `p≡7 (mod8)`、従って `q≡6 (mod8)`。後者では `q≡2 (mod4)` かつ `q/2≡3 (mod4)` なのでQは `3 (mod4)` の素因数を持ち、補題に反する。従って `q≡1`, `p≡2 (mod8)`。

つまり `A²−B²=P≡16 (mod64)`。Bが奇数で可逆なので `(A B^(-1))²≡17 (mod64)`。この平方根は正確に `9,23,41,55 (mod64)` の4つ（全32奇数剰余の直接計算、または平方合同式の標準分類）。証明終。

## 独立監査と解釈

別実装 `q48_mod64_residue_class_independent_20261015.py` は、法64の奇数B剰余32種について4つの根を直接確認する。また、素因数条件・法3条件・既知の厳密な傾き下界を通る `A≤1000,B≤200` の既約候補735組について、平方剰余集合を使って `QM²−PL²≡8 (mod64)` の可解性を検査した。B奇数99組中、39組は可解、60組は不可解で、合同類判定と全件一致。既知5弦長型にも矛盾なし。

例えば `A/B=63/5` は `63*5^(-1)≡51 (mod64)` で4合同類のいずれにも属さず、円を生成できない。これは有限範囲で「見つからない」という主張ではなく、全称必要条件による排除である。

この4合同類への制限は **B奇数の既約傾きだけ**を対象とし、実現可能傾きの十分判定、全円型数、ゲーム勝敗には拡張しない。有限監査の一致は証明の代替ではない。
