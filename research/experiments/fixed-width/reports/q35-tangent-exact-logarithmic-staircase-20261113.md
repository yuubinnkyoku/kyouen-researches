# 3×m・q=5：接線型5点円数の閉形式と離散差分（2026-11-13）

**証拠水準：既存の全称分類を前提とする全称的な代数的帰結。** 既報の漸近主項を、任意の盤幅で計算できる閉形式と差分の完全記述へ強化する。一般の5点円総数については主張しない。

## 定理

`a_{-1}=0, a_0=8, a_{j+1}=6a_j-a_{j-1}`（`j≥0`）とする。これは既報の弦幅列 `8,48,280,1632,...` と一致する。整数 `m≥1` に対して `N=N(m)=#{j≥0:a_j<m}` と置く。このとき接線型のちょうど5点円数は

```
T_5(m) = 2Nm - (a_N-a_{N-1}-8)/2.
```

特に `N=0` でも右辺は0であり、境界 `m=a_j` においても成立する。前進差分は

```
T_5(m+1)-T_5(m)=2 #{j≥0:a_j≤m},
T_5(m+1)-2T_5(m)+T_5(m-1)=2 * 1_{m=a_j}  (m≥2).
```

したがって `T_5` は整数上の凸関数であり、**傾きが変化する盤幅は厳密に `8,48,280,1632,...` のみ**。傾きはその都度2ずつ増える。これは有限観測でなく、全ての盤幅についての定理である。

## 証明

既報の完全分類により `T_5(m)=2Σ_{j≥0}(m-a_j)_+`。正の寄与を持つのは `j=0,...,N-1` だから `T_5(m)=2Nm-2S_N`、`S_N=Σ_{j=0}^{N-1}a_j`。

漸化式 `a_{j+1}-6a_j+a_{j-1}=0` を `j=0,...,N-1` で足し合わせると、または直接帰納法により

```
4S_N=a_N-a_{N-1}-8
```

を得る（`N=0` では `a_0-a_{-1}-8=0`）。これを代入すれば閉形式。各 `(m-a_j)_+` の前進差分は `m≥a_j` のとき1、それ以外0なので差分式も従う。

## 独立検算（純整数演算）

```python
a=[8,48]
while a[-1]<100000:
    a.append(6*a[-1]-a[-2])
def direct(m):
    return 2*sum(max(0,m-x) for x in a)
def closed(m):
    n=sum(x<m for x in a)
    prev=0 if n==0 else a[n-1]
    return 2*n*m-(a[n]-prev-8)//2
for m in range(1,100001):
    assert direct(m)==closed(m)
for x in a[:-1]:
    if 2<=x<100000:
        assert direct(x+1)-2*direct(x)+direct(x-1)==2
```

検算は有限範囲の独立した算術検査であり、全称性は上記の恒等式による。

## 意味と限界

既報の `T_5(m)=(2/log(3+2√2))m log m+O(m)` は大域的な漸近主項である。今回の式はその誤差を含む**全ての整数盤幅の値を、閾値を挟む二つの弦幅と項数だけで決める**。特に非接線型の円を除外しているため、全5点円数 `F_5(m)` の差分や増大次数については何も確定しない。
