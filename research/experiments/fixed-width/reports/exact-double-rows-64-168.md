# 連続整数行の二重点円：64〜168行の厳密値（2026-10-08）

## 定義と結果

横座標をすべての整数とし、連続する `w` 本の水平整数行 `y=0,...,w-1` のうち、一本の実円が異なる整数格子点をちょうど2個通る行数の最大値を `T(w)` とする。円の中心・半径は自由であり、`w` ごとに異なってよい。

**定理（全幅厳密）**

| 幅 `w` | `T(w)` |
|---|---:|
| 64〜82 | 16 |
| 83〜86 | 17 |
| 87〜93 | 18 |
| 94〜95 | 19 |
| 96〜99 | 20 |
| 100 | 21 |
| 101〜104 | 22 |
| 105 | 23 |
| 106〜168 | 24 |

これにより既知の44〜63行の厳密値（K0369）を168行まで延長する。以下の証明は**任意の実円に対する数学的帰着**と**有限個の合同必要条件の完全排除**を組み合わせる。単なる有限半径・有限中心の円探索ではない。

## 上界の数学的帰着

円を `x²+y²+Bx+Cy+D=0` と書く。二重点行 `y` では二つの整数根 `x1,x2` があり、Vietaから `B=-(x1+x2)` は整数、`y²+Cy+D=x1*x2` は整数である。二重点行の集合を `Y`、相異なる行番号差のgcdを `g` とすると、`gC` は整数で、上の整数積の式から `gD` も整数となる。従って `g` と互いに素な任意の法 `p` で `C,D` と

`N=B²+C²-4D`

の剰余 `c,n` が定義される。整数根の判別式は正の平方数なので、すべての `y∈Y` は

`n-(2y+c)²` が `mod p` の平方剰余（0を含む）

を満たす。これを満たす行のビット集合を `A_{p,c,n}` とし、`0<=c,n<p` の全組を列挙する。異なる法の許容集合の共通部分に `k` 行が残らなければ、`k` 本の二重点行を持つ円は存在しない。共通部分の候補集合は包含関係で支配される小集合を捨てても完全性が保たれる。検証器は判別式からの平方剰余検査と、平方根から許容 `n` を逆算する方法を**各 `(p,c,n)` で照合**する。

### 基底 `w=64`

17本の二重点行があると仮定すると、`16g<=63` より `g<=3`。`g=3` なら64行中の一つの `mod 3` 剰余類（高々22行）に17行が入る。法19では、この22行に同じ剰余が現れる重複は高々3個だから、少なくとも14種類の `mod 19` 行剰余が必要。しかし `19≡3 (mod 4)` では、任意の `c,n` に対して `n-(2y+c)²` が平方剰余になる `y mod 19` は高々 `(19+3)/2=11` 種類（有限体の二平方和の計数）。矛盾する。

`g=1,2` なら法 `9,11,19,23,7,49` はいずれも `g` と互いに素であり、検証器による全マスク共通部分は空になる。よって `T(64)<=16`。

### 65〜168行への帰納法

`T(w-1)=t` が確定したとする。長さ `w` の窓で `t+1` 行を通る円があれば、**最初と最後の行は必ず二重点**である。片方が違えば `w-1` 行の窓に `t+1` 行が入ってしまうからである。このとき `g | (w-1)` かつ `tg<=w-1`。本証明の全幅で `g<=6`。

- `g∈{1,2,4,5}` は `9,7,49,11,19,23,31,43` とすべて互いに素。両端行を含む合同許容マスクだけを残し、`t+1` 行の共通部分を全件排除する。
- `g∈{3,6}` は `w≡1 (mod 3)` の場合にしか両端を含められない。その場合は `y≡0 (mod 3)` に制限し、`11,19,23,31,43,47,59,67,71,79,83` の合同マスクで全件排除する。

前の幅から下界が1増えた幅では、一般的な `T(w)<=T(w-1)+1`（追加された一行が二重点行数を高々1増やす）だけで上界が一致する。下界が増えない幅は、上の両端帰納と有限合同排除で上界を示す。C++検証器は **64〜168の全105幅**について、この二つの場合を分け、全マスクを二方式で検査し、最後の法と結果を保存する。帰納段階の合同排除の最終法は最大43であり、64行の基底のみ49を用いる。

## 下界：一本の円から24行

64〜82行では `x²+y²+x−47y=0` が次の16行に整数点を2個ずつ持つ。

`0,2,3,5,9,12,14,23,24,33,35,38,42,44,45,47`

83行以降の証人は、**一つの円**

`x²+y²+x−105y−6=0`

から得られる。この円の判別式は `11050−(2y−105)²` であり、整数の二根を持つ行 `y=0,...,105` は正確に次の24行である。

`0,1,5,6,9,12,19,23,28,30,42,50,55,63,75,77,82,86,93,96,99,100,104,105`

縦方向に整数 `s` だけ平行移動し、これらの行のうち `s<=y<s+w` に入るものを `0..w-1` に移せば、整数係数の円 `x²+y²+x+(2s−105)y+(s²−105s−6)=0` を得る。24行の有限集合上で `s` を全探索した下界が冒頭の表に一致する。全証人について判別式の正平方性、整数根の相異性、円方程式への直接代入を検証器が確認する。

特に `w=83` で17行、`w=87` で18行、`w=94` で19行、`w=96` で20行、`w=100` で21行、`w=101` で22行、`w=105` で23行、`w=106` で24行を達成する。168行まで25行は不可能。

## 帰結・限界

任意の `w=168a+b` (`0<=b<168`) について窓を分割すると `T(w)<=24a+T(b)`。以前の有限窓分割上界 `16/63` や `16/82` より小さい係数 `24/168=1/7` が得られる（K0370の漸近的な劣線形上界とは別）。固定幅q点版の独立行帰着（K0072）により、`q>w+T(w)` なら全長・全安全局面で容量型の強解決が成立し、特に `w=168,q>=193` で成立する。

`T(169)` は未確定であり、本証明は24行上界をそれ以降に拡張しない。整数水平行・円の二重点数を扱う結果であり、任意実数間隔の平行線や有限横幅での達成性を主張しない。
