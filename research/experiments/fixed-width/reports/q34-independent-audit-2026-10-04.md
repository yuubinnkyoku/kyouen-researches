## 使用した独立手法

repo の判定は整数 lifted 行列式 `det[x^2+y^2,x,y,1]`（Python は
`kyouen_core.det4`、C++ は4点小行列式）である。監査側では同じ規則を
**別アルゴリズム**で3種類実装し、全4点組で一致を要求した。

- A. 有理数 `Fraction` による円方程式 `x^2+y^2+Dx+Ey+F=0` の当てはめ。
  定数項を含む **4元** 連立方程式であり、repo の原点移動3×3とは別系統。
- B. 単項式行列 `(1,x,y,x^2+y^2)` の `4x4` に対する **有理数上の**
  ガウス消去法による rank 判定。三角形探索が無く、退化は構造的に扱える。
- C. 同じ rank 判定を **有限体 F_1000003** 上で行う。第三の算術モデル。
- 二項係数は `math.comb` / パスカルの三角形 / 乗算式の3実装で交差確認。

浮動小数点はどの判定にも使っていない。q点版でも circle と line を
rank≤3 として統一し、hyperplane と取り違えていない。

## 一致した項目

### 1. 三つの8石証人はすべて安全かつ極大（一致）

| 証人 | 出所 | 石数 | 禁止4点組 | 判定不一致 | 極大 |
|---:|---|---:|---:|---:|:---:|
| y0{1,17} y1{7,10,13} y2{9,10,12} | q34-exact-threshold | 8 | 0 | 0 | 是 |
| y0{4,7,18} y1{3,4} y2{4,10,13} | q34-exact-threshold | 8 | 0 | 0 | 是 |
| y0{4,15,18} y1{18,19} y2{9,12,18} | q34-stabilization-lower-bound | 8 | 0 | 0 | 是 |

各証人の61空点は全て追加不能だった。**新しい証人は既存資料の証人の
反射とも一致しない**が、これは問題ではなく、同一の命題 M₃,₄≥24 の
別の証人である。

### 2. 3×23 盤全体の判定（一致）

69点の $\binom{69}{4}=864{,}501$ 四点組について3判定が完全一致し、
不一致0件。禁止四点組数は **33,819** で、既存JSONの値と一致した。

### 3. 固定幅十分長 T_w（一致）

`3, 9, 69, 237, 567, 1,113` が `min(A,B)` と閉形式
`3+2{C(3w−2,3)−(w−1)}` の両方と一致。w=3 の 69 も再計算した。

### 4. q=4,w=3,m=6 の完全列挙行（一致）

独立部分集合DPで、最大安全サイズ **8**、極大サイズ分布
**5:4, 6:648, 7:964, 8:108**、空盤 Grundy **1**、偶奇式は全安全局面で
**成り立たない** — 既存表の行と完全一致した。

### 5. 容量9は到達可能（一致）

4点同一直線が禁止なので各行は高々3石、総数は高々9石。
実際 interlace した9石集合が安全で存在するため、**真の容量は9**。

### 6. q点版固定幅補題 §2 の場合分け（一致、反例なし）

対象行の石数 `a ≤ q−2` という補題の仮定を厳密に守って走査した。
q=4,5、w=2,3 の小盤で **全安全集合を全列挙**し、

- b≥2 の (q−1)-subset で **新しい** 空点が塞がれる例: **0件**
- 一つの b=1 subset が塞ぐ新しい点: 高々 **1個**（主張どおり）
- 一つの b=0 subset が塞ぐ新しい点: 高々 **2個**（主張どおり）

`a ≤ q−2` の仮定を外すと `b≥2` の主張は **`q=5,w=2` で実際に反例になる**
（例: 対象行 y=0 に a=3 点、Q={(0,0),(1,0),(2,0),(0,1)}、新点 p=(3,0)）。
このため報告書の `a≤q−2` は本質的な境界条件であり、落とすと定理が壊れる。

## 不一致：K0068 が確定値を否定していた（1件、修正済み）

**検出内容。** 2026-10-04 の commit `bdbcb42` が K0068 に
「幅3・q=4の現在の鋭い区間」節を追加し、

- $\boxed{24\le M_{3,4}\le69}$
- 「m≥24 の不足極大集合の不存在はまだ証明していないため、M₃,₄=24とは主張しない」

と記載した。しかし同じ main 上の K0302 は `M_{3,4}=24` を **proved** として
保持し、K0303 も `q34-exact-threshold.md` を根拠に全長分類を主張している。
`q34-exact-threshold.md` 自体は §2 で m≥69 の再証明、§5 で m=24..68 の
有限完全排除を持ち、`M_{3,4}=24` を閉じている。

つまり K0068 の新節だけが、**既に正本として確定している値を一段弱め**、
かつ「証明していない」と明示的に否定していた。K0068 の本文が一般定理で
与えるのは **十分長** `T_w` であり、**真の安定化長ではない**。
この二つの量を同一視した記述が不一致の原因である。

**判定。** K0068 の新節は誤り。q34-exact-threshold.md 側の m=24..68
完全排除が既存であり、こちらが監査可能な具体的根拠を持つ。

**修正内容（最小差分）。** K0068 の該当節を「幅3・q=4の下界証人」と改題し、
「本項の一般定理は十分長さ69しか与えない。幅3の真の値は[K0302]として
別に確定済み」と明記した上で、主張を `M_{3,4}\ge24` のみに限定した。
K0302 へ `depends_on` 関係を追加した。K0302 の値も削除していない。
一般定理の上界69は幅3については真の値ではない旨を明記した。

**未検証として残す部分。** 監査したのは証人の安全性・極大性、T_w の値、
小盤の完全列挙行、補題の反例探索までである。m=24..68 の有限排除
（`q34_support_exclusion.cpp`）と m=23 短終局的全 census（8個）自体は
本監査で再実行していない。従って M₃,₄=24 の**上界側**は既存の
`q34-exact-threshold.md` と K0302 の主張として引用するものであり、
本監査が新たに証明したものではない。この区別を明記する。
