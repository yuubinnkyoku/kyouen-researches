# 四行8点円：未出現の法27型は任意の法で局所可解

2026-10-15。対象は標準整数行 `y=0,1,2,3` にそれぞれ異なる2格子点を持つ円の**水平弦長の必要条件**。無界な整数円の存在は主張しない。

## 定理（無界、数学的証明）

任意の正整数 `M` に対し、正の**奇数** `d0<d1<d2<d3` が存在し、

```
d0² - 2*d1² + d2² = -8  (mod M)
d1² - 2*d2² + d3² = -8  (mod M)
(d0²,d1²,d2²,d3²) = (19,0,0,19)  (mod 27)
```

を同時に満たす。従って法27の第四型 `(19,0,0,19)` は、**いかなる固定した有限法の平方剰余篩でも**、上記の二つの弦長方程式および奇数性・厳密単調性だけを根拠として排除できない。

この定理は「この型の本物の整数8点円が存在する」という意味ではない。合同解は整数の厳密な等式の解とは限らない。特に、法27第四型の真の整数円での実現可能性は未解決のままである。

## 証明

四行の弦長は円方程式の各行の二根の差であり、平方の二階差分が `-8` なので上記二式を満たす。

3進整数において `73≡1 (mod 3)` であり、`x²−73` の根 `x≡1 (mod 3)` は導関数 `2x` が3で割れない。Henselの補題により、**すべての** `k>=1` に対して整合的な根 `t_k²≡73 (mod 3^k)` が存在する（数字を一桁ずつ持ち上げてもよい）。

3冪法では弦長の候補を `(t_k,9,9,t_k)` と置く。二つの弦長方程式の左辺と右辺の差は、いずれも `t_k²−73` に等しくなる。特に法27では `73≡19`、`9²≡0` なので、要求する第四型を得る。

一方、3と互いに素な任意の法 `n` では `(1,3,3,1)` が**厳密に**二式を満たす。`L=lcm(M,54)=3^k*n`（`gcd(n,3)=1`, `k>=3`）として、各座標について中国剰余定理で3冪法の候補と法 `n` の候補を貼り合わせる。得られる4整数は二式を法 `L` で満たし、第四型を法27で満たす。`2|L` かつ法2では `(1,3,3,1)` に一致するため全て奇数である。

最後に、各座標に順に `L,2L,3L,4L` を加える。剰余は不変で、代表元を `1..L` に取っておけば4数は正で厳密増加する。これで全 `M` に対する主張が成立する。□

### 円方程式側でも排除できない範囲

任意の法 `N` に対して上の構成を `M=4N` で行い、得た奇数弦長に共通の整数根和 `S=d3` を与える。`C=(S²-d0²)/4`, `B=(d0²-d1²)/4−1` は整数であり、各行 `y=i` の2整数 `x=(S±d_i)/2` は

```
x²+y²-S*x+B*y+C ≡ 0  (mod N)
```

を満たす。よって円の整数係数表示を法 `N` で直接代入する篩でも、**有限法だけでは**第四型を排除できない。ここでも円方程式が整数として厳密に成立するとは主張しない。

## 限界と次の課題

法27第四型の実在を決めるには、合同式だけではなく、整数としての**同時平方条件**や不等式以外の大域的制約が必要である。既知のPell族は第四型を出さないが、それだけで他の族の不存在は証明できない。法4032・12096などの篩は実行速度を改善し得るものの、第四型の不可能性を全称証明する道具にはならない。
