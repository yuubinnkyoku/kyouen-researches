# 3×m・q=5：接線型5点円の完全分類（2026-11-13）

**証拠水準：整数論の全称証明。** 先行 `q35-tangent-pell-superlinear-five-circles-20261113.md` の下界を、接線型全体の厳密な個数式に強化する。ここで接線型とは、三行のうち一方の外側の行にちょうど1格子点、残る二行に各2格子点を持ち、外側の一行が円に接する型をいう。

## 定理

`(a_0,b_0)=(8,6)`、`(a_{j+1},b_{j+1})=(3a_j+4b_j,2a_j+3b_j)` とする。3×m整数盤における接線型のちょうど5点円の総数 `T_5(m)` は、全ての整数 `m≥1` で

```
T_5(m) = 2 Σ_{j≥0} max(0,m-a_j).
```

従って `T_5(m)=Θ(m log m)` である。この等式は接線型に限る。一般の5点円総数 `F_5(m)` の上界を主張しない。

## 全解の分類

先行の整数論的必要十分条件で接線型は `k=0`、すなわち正の整数 `a,b` が `a²+8=2b²` と同じ偶奇を満たす場合に限る。合同式から `a` は偶数。もし `a=2u` で `u` が奇数なら `b²=2u²+4≡6 (mod 8)` となり不可能。従って `a` は4の倍数、`b` も偶数である。

`a=0` の退化解は `b=2` のみ。正の解は `b≥6` であり、`a/b = sqrt(2-8/b²)` は `4/3≤a/b<3/2` を満たす（等号は `(8,6)`）。逆変換

```
(a',b')=(3a-4b, 3b-2a)
```

は非負整数対を与え、`0≤a'<a`、`b'>0`、`a'²+8=2b'²` を満たす。実際 `a'<a` は `a<2b` に等価である。逆変換で `a'=0` に到達するまで下降でき、終点は `(0,2)` に限る。逆向きに戻すと `(0,2)→(8,6)→(48,34)→…` の唯一の正解軌道が得られる。

各解の弦幅は `a>b` で、先行の接線型計数により、幅mで上下反転込み `2 max(0,m-a)` 本の相異なる円を生む。弦幅aは軌道上で狭義増加するので重複しない。これで式が成立する。

## 増大次数と独立検算

`a_{j+1}>3a_j` かつ `a_{j+1}<7a_j` より、`a_j` は指数的に増大する。幅mで寄与する項数は `Θ(log m)`、各項は高々 `2m` なので `T_5(m)=O(m log m)`。一方、`a_j≤m/2` である `Θ(log m)` 項は各々少なくともmを寄与する。従って `T_5(m)=Ω(m log m)`。

独立検算の短い整数列挙：

```python
sol=[]
for a in range(1,2000):
    for b in range(1,a+1):
        if a*a+8==2*b*b:
            sol.append((a,b))
a,b=8,6
orbit=[]
while a<2000:
    orbit.append((a,b))
    a,b=3*a+4*b,2*a+3*b
assert sol==orbit, (sol,orbit)
```

これは有限範囲の検算であり、全称性は下降法で保証する。
