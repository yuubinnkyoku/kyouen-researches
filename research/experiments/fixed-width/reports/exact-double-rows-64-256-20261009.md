# 標準整数格子円の二重点行 T(w)：212〜256行の厳密値

2026-10-09。K0369 の T(63)=16 を基底とする帰納的な全称上界と明示的な整数円の下界を組み合わせる。64〜211行の未統合先行計算を同一検証器で引き継ぎ、**新規212〜256行の45幅**を確定する。

## 定理

連続する整数水平行 `y=0,...,w-1` に対し、同一の実円が異なる整数点2個ずつを持つ行数の最大値を `T(w)` とする。横座標は全整数。

| w | T(w) |
|---|---:|
| 212〜213 | 25 |
| 214〜220 | 26 |
| 221〜225 | 27 |
| 226〜231 | 28 |
| 232 | 29 |
| 233〜234 | 30 |
| 235 | 31 |
| 236〜256 | 32 |

従って25,26,...,32本の最初の達成幅はそれぞれ211,214,221,226,232,233,235,236。最初の211は先行の64〜211計算による。**33本を初めて実現する幅は未確定**であり、ここから `T(257)` 以降の値を推測しない。

## 下界：4本の明示円

```
x²+y²+x−47y=0
x²+y²+x−105y−6=0
x²+y²+x−95y−506=0
x²+y²+x−235y−6=0
```

各円 `x²+y²+x+cy+d=0` で、行 `y` の判別式 `1−4(y²+cy+d)` が**正の奇数平方**であることと、2整数根の方程式への直接代入を整数平方根で完全検査した。最後の円の `0<=y<=255` の二重点行は

```
0,1,3,4,10,15,22,25,45,49,60,70,87,91,102,115,
120,133,144,148,165,175,186,190,210,213,220,225,231,232,234,235
```

であり32本。4円の行数最大値が上表の各下界に一致することを Python で45幅すべて独立検査した。

## 全称上界：端点・gcd・平方剰余による有限完全排除

単調性 `T(w−1)<=T(w)<=T(w−1)+1` は明白。`T(w−1)=t` が証明済みで、下界が t のままのとき `t+1=K` 本を持つ円を仮定すると、最下端 `y=0` と最上端 `y=w−1` はともに二重点行でなければならない。片端を外した `w−1` 行で K 本が残るなら帰納仮定に反するためである。

円を `x²+y²+Bx+Cy+D=0` と書く。行0の二つの整数根の和・積から `B,D` は整数。二重点行の番号差のgcdを `g` とすると `gC=a` は整数で、`g|(w−1)`、`1<=g<=floor((w−1)/(K−1))`。行 `y=gk` の整数根 `x` は

```
(2x+B)² = B²−4D−4g²k²−4ak
```

を満たす。任意の奇数法 `p` で `gcd(p,g)=1` なら、ある `c,n (mod p)` に対し各二重点行の `k` は

```
n−(2gk+c)² ∈ QR(p)  （0を含む平方剰余）
```

を満たす必要がある。`c=a/g`, `n=B²−4D+c² (mod p)` とすればよい。各法ごとに `c,n` を**独立に**選ぶのは実際の円の制約を緩めるので、排除できれば全実円に対して有効である。

検証器は各 `g` と法 `p` で `p²` 通りの `(c,n)` を列挙し、両端を含み少なくとも K 個の行を許すマスクを作る。法を追加するたびにマスクの共通部分を取り、K 行未満を捨てる。全ての `g` で候補が空になれば `T(w)<=t`。下界が t+1 に増えた幅は単調性だけで確定。`T(63)=16` を K0369 から開始して64〜256行へ帰納する。

使用法は `9,11,7,49,19,23,31,37,41,43,47,53`（幅で順序変更）。`g` と互いに素でない法は使わない。整数円の係数や半径を有限範囲に限定していない。

## 検証記録と信頼境界

C++20の2方式：通常版は行ごとの平方剰余を転置してマスク生成、`-DDIRECT_RESIDUES` 版は `(c,n)` ごとに直接全行を判定。新規212〜256行では **38幅の上界排除・7幅の下界増加**、合計 **430段階の CASE 行**を含む全出力がバイト単位で一致した。4分割の各末尾は `PASS`。別実装のPython整数平方根検証器が下界45幅と両根を照合した。

```
g++ -O3 -std=c++20 research/experiments/fixed-width/scripts/verify_double_rows_64_256.cpp -o /tmp/rows_a
g++ -O3 -std=c++20 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_double_rows_64_256.cpp -o /tmp/rows_b
# 新規幅を区間に分ける場合、各区間直前の T(w−1) の厳密値が必要。
for pair in '212 220' '221 228' '229 235' '236 256'; do
  set -- $pair
  /tmp/rows_a "$1" "$2" > /tmp/a.txt
  /tmp/rows_b "$1" "$2" > /tmp/b.txt
  cmp /tmp/a.txt /tmp/b.txt || exit 1
done
python research/experiments/fixed-width/scripts/verify_double_rows_212_256_witnesses.py
```

**重要：** 212行の帰納基底 `T(211)=25` は2026-10-09の未統合先行成果に依存する。先行の `64〜211` 検証器・報告・ログは別添の先行ZIPにある。新規検証器自体は `64 256` の全範囲を検査できるが、今回の連続一括再実行は197行付近で時間制限により中断した。既存の64〜211独立照合記録と新規212〜256照合を接続するのが現時点の検証根拠である。**本研究は形式証明ではなく、数学的必要条件＋有限完全列挙の計算機援用証明**である。

## ゲームへの帰結

標準整数格子の幅 `w` の円は高々 `w+T(w)` 個の整数点を持つ（水平行は高々2点、非二重点行は高々1点）。非水平直線は高々 `w` 点。従って `w=256` で `q>=289` なら全 `m>=1`・全安全局面で独立行容量ゲームとなり

```
g(S)=(256 min(m,q−1)−|S|) mod 2,
M_(256,q)=q−1.
```

これらは標準整数座標・q点版についての結論。`q<=288` の最小閾値や任意間隔の平行線については主張しない。
