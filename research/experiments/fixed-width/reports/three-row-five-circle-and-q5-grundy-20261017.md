# 不等間隔三列・三行盤：5点円の完全分類とq=5全局面Grundy（2026-10-17）

**証拠水準：** 円の分類は任意の正整数に対する全称証明。ゲームのGrundy表は有限状態（最大82個の個数状態）を再帰式で完全計算した厳密な強解決であり、独立9-bit全局面計算でも照合した。対象は3列×3行の有限異方格子のみで、一般の盤長の閾値を意味しない。

## 定理：3行の5点円

任意の正整数 `a,b,d` に対し

\[
B(a,b,d)=\{(x,dj):x\in\{0,a,a+b\},\ j\in\{0,1,2\}\}
\]

とする。5点以上を通る円の本数 \(N_5\) は

\[
\boxed{N_5=\mathbf1_{a(a+b)=d^2}+\mathbf1_{b(a+b)=d^2}+2\mathbf1_{ab=2d^2}.}
\]

3条件は互いに排他的なので \(N_5\in\{0,1,2\}\)。どの円も盤上ちょうど5点を通り、6点円は存在しない。特に無限三列格子での5点円の初出行数 \(H_5\) が3であることと、右辺が正であることは同値である（1〜2行に5点円は存在しない）。

### 証明

円は各縦列と高々2点で交わる。5点円があるなら三列の占有数は2,2,1。2点を持つ二列で、交点の縦座標の和は同一の円の縦中心の2倍に等しい。3行の異なる2行組 `(0,1),(0,2),(1,2)` の和はそれぞれ1,2,3なので、二列の行組は一致する。

二点を持つ列のx座標を `u<v`、その行組を `r<s` とすれば、円はただ一つで、方程式は

\[
 x^2+y^2-(u+v)x-d(r+s)y+uv+d^2rs=0.
\]

第三列の座標を `z`、その行番号を `t` とすると、その点が円上にある必要十分条件は

\[
 (z-u)(z-v)+d^2(t-r)(t-s)=0.\tag{1}
\]

`t` が `r,s` のいずれかなら、式(1)は `z=u` または `z=v` を要求するので不可能。したがって `(r,s,t)` は `(0,1,2),(0,2,1),(1,2,0)` の3通りに限られる。

- `(0,1,2)` または `(1,2,0)` なら \((z-u)(z-v)=-2d^2<0\)。第三列は二列の間にある必要があるので `u=0,z=a,v=a+b`、かつ `ab=2d²`。各行組から1本ずつ、計2本。
- `(0,2,1)` なら \((z-u)(z-v)=d^2>0\)。第三列は二列の外側にあり、`(u,v,z)=(0,a,a+b)` なら `b(a+b)=d²`、`(u,v,z)=(a,a+b,0)` なら `a(a+b)=d²`。各条件につき1本。

`ab=2d²` なら `a(a+b)>ab`、`b(a+b)>ab` なので残り2条件は成立しない。また `a(a+b)=b(a+b)=d²` なら `a=b`、`2a²=d²` となり正整数では不可能。これで排他性を示した。

6点円なら三列とも2点を持ち、上の行組一致により同じ二つの水平行に各3点がある。しかし円と水平直線の交点は高々2点。矛盾。2行以下で5点円がないことも同じ水平行の交点上界から従う。□

## 系：3列×3行、q=5の全安全局面を強解決

完全指摘・通常プレイで、5点以上が同一直線または同一円に乗る着手を敗着とする。盤上の直線は高々3点なので、禁止集合は上の5点円のみ。

- \(N_5=0\)：全9点が自由で、全安全局面で \(g(S)=(9-|S|)\bmod2\)。空盤Grundyは1。
- \(N_5=1\)：禁止5点組が一つで、全極大安全集合が8点。全安全局面で \(g(S)=(8-|S|)\bmod2\)。空盤Grundyは0。
- \(N_5=2\)：二つの禁止5点組はちょうど2点を共有し、和集合は8点。空盤Grundyは1。Grundy値は0,1,2,3のいずれも現れ、全安全局面の数は482。極大安全集合の大きさは7または8である。

最後の場合、共有2点の占有数を `i`、各禁止集合に固有な3点の占有数を `u,v`、残る1点の占有数を `f` とする。安全条件は `i<2` または `u,v<3`。各類内の点は完全に対称なので \(g(S)=G(i,u,v,f)\) であり、次の有限再帰で**全局面の厳密なGrundy値**を与える：

\[
G(i,u,v,f)=\operatorname{mex}\{G(i',u',v',f'):\text{安全条件を保って一成分だけ1増加}\}.
\]

終端のmexは0。さらに独立した1点のゲームとの直和なので

\[
G(i,u,v,f)=G(i,u,v,1)\mathbin{\mathrm{xor}}(1-f).
\]

`f=1` の値を行 `u=0,1,2,3`、列 `v=0,1,2,3` で示す。`-` は禁止状態。

`i=0`:

```
0 3 1 0
3 2 0 1
1 0 1 0
0 1 0 1
```

`i=1`:

```
1 0 2 1
0 1 3 0
2 3 2 1
1 0 1 0
```

`i=2`:

```
0 1 0 -
1 0 1 -
0 1 0 -
- - - -
```

表は上記のmex再帰を石数の降順に計算した厳密な有限証明である。空盤は `G(0,0,0,0)=0 xor 1=1`。共有点が2点とも置かれた場合は、二つの固有3点組から各2点までしか置けず、`i=2` の表は残り手数の偶奇に一致する。

**検算・再現：** `research/experiments/fixed-width/scripts/three_row_five_circle_classification_20261017.py` は `1<=a,b,d<=16` の4096盤について、全非共線三点組から円を整数行列式で列挙し、予測された全円の方程式と盤上支持点集合を照合する。内訳は `N5=0:4048`, `N5=1:24`, `N5=2:24`。別途、代表3盤で安全局面を9-bit集合として独立に全列挙（512/496/482局面）し、すべてのGrundy値を上記の式・表と照合する。標本検算は全称証明の代用ではない。

**既存結果との区別：** 標準3×mの全長q=5分類（K0071, K0303）、標準3水平行の共円4点組分類（K0408）とは対象が異なる。今回の三列は一般の非等間隔整数座標、縦間隔も任意の正整数である。初出行数を固定した無界6点円族の以前の作業にも `a(a+b)=d²` の特殊例が現れるが、3行における**全5点円の本数と全局面Grundy**は今回の別の結論である。

## 追補：全安全局面のnimber分布と極大配置の個数（2026-10-17）

上の再帰表は各同値類の値を与えるだけでなく、同値類に属する実際の局面数を二項係数で重み付けすることで全局面のGrundy分布を決定する。二つの禁止円がある場合、状態 `(i,u,v,f)` の重みは

\[\binom{2}{i}\binom{3}{u}\binom{3}{v}\binom{1}{f}.\]

安全条件 `i<2 or (u<3 and v<3)` の下でこれを上記の `G(i,u,v,f)` ごとに加算すると、次の**有限状態完全計算による厳密な分布**が得られる。

| 5点円の本数 | g=0 | g=1 | g=2 | g=3 | 極大安全集合の石数と個数 |
|---:|---:|---:|---:|---:|---|
| 0 | 256 | 256 | 0 | 0 | 9石:1個 |
| 1 | 248 | 248 | 0 | 0 | 8石:5個 |
| 2 | 160 | 160 | 81 | 81 | 7石:9個、8石:2個 |

極大安全集合の個数には別の組合せ証明がある。禁止円が一つなら、その5点からちょうど1点を除いた5配置が極大である。禁止円が二つなら、二つの5点組は共通2点・各固有3点・自由1点に分かれる。極大集合は、共通2点のうち1点だけを欠く8石配置が2個、または共通2点を両方含み、各固有3点から1点ずつを欠く7石配置が3×3=9個。ほかに極大配置はない。

**独立照合：** 9点集合の全512部分集合について、禁止円をビット集合で判定してmexを直接計算し、各値の個数と極大配置数を集計した。一方、上記の重み付き縮約再帰でも各値の個数を計算した。両方式の結果は全3分類で一致した。実装と実行結果は同梱の検証器・出力を参照。
