# 4行8点円の非分解素数障害と傾きの定量的疎性

2026-10-16。基準 main `c1790f67dbac039244852702d7b5504cceb97704`。証拠区分：数学的全称証明。有限監査は別途。

## 定理

K0432のPell正規形に従い、非局所8点円の既約傾きを `A/B`、`g=gcd(A,3)` とおく。`A>3B>0`、`gcd(A,B)=1` であり、正整数 `L,M` について

```
P=A²-B², Q=(A²-9B²)/g², QM²-PL²=8.
```

(1) **どの素数 `p≡3 (mod 4)` も `PQ` を割らない。** 従って `A-B`, `A+B`, `(A-3B)/g`, `(A+3B)/g` の四つはすべて二平方和であり、`3|B` または `9|A` が必要。

(2) `1≤A,B≤H` に属する実現可能な既約傾きの種類数 `R(H)` は

```
R(H)=O(H²/log H).
```

円数 `C8(m)` に関する上界ではない。

## 全称証明

`p≥7`, `p≡3(mod4)` とする。`p|P` なら既約性から `p∤B` で、`Q≡−8B²/g²(mod p)`。ノルム式を法pで見れば `−(BM/g)²≡1(mod p)` となる。`p|Q` なら `p∤B`, `P≡8B²(mod p)` なので `−(BL)²≡1(mod p)`。いずれも −1 が平方非剰余であることに矛盾する。

`p=3` は別扱いする。`3∤A,3∤B` なら `P≡0,Q≡1(mod3)` より `M²≡2(mod3)` となり不可能。`3|A,9∤A` なら `P≡2,Q≡0(mod3)` より `L²≡2(mod3)` となり不可能。残る `3|B` では `P≡Q≡1(mod3)`、`9|A` では `P≡Q≡2(mod3)`。従って `3∤PQ` である。

`P=(A-B)(A+B)`、`Q=((A-3B)/g)((A+3B)/g)` の四因子は正整数であり、どれも3(mod4)の素因数を持たない。Fermatの二平方和定理により各因子は二平方和。

`S(X)=#{1≤n≤X:n=x²+y², x,y∈Z}` とおく。Landau–Ramanujan定理より `S(X)=O(X/√log X)`。写像 `(A,B)↦(A-B,A+B)` は単射で、両成分が1..2Hの二平方和なので `R(H)≤S(2H)²=O(H²/log H)`。□
