# 3×m・q=5：接線型5点円数の漸近主項（2026-11-13）

**証拠水準：全称証明（既存の接線型完全分類を前提）。** 先行 `q35-tangent-complete-pell-classification-20261113.md` の厳密計数式を漸近的に精密化する。一般の5点円総数についての上界ではない。

## 定理

`λ=3+2√2` とする。接線型のちょうど5点円数は、整数 `m→∞` に対し

```
T_5(m) = (2 / log(3+2√2)) m log m + O(m)
```

を満たす（logは自然対数）。従って `T_5(m)/(m log m) → 2/log(3+2√2)`。

## 証明

既存の完全分類により `T_5(m)=2Σ_{j≥0}(m-a_j)_+`、`(a_0,b_0)=(8,6)`、`(a_{j+1},b_{j+1})=(3a_j+4b_j,2a_j+3b_j)`。この線形変換の固有値は `λ=3+2√2` と `λ^{-1}=3-2√2` であり、初期条件から

```
a_j = √2(λ^{j+1}-λ^{-(j+1)}).
```

よって `a_j=√2 λ^{j+1}(1+O(λ^{-2j-2}))`。正の寄与を持つ項数 `N(m)=#{j≥0:a_j<m}` は `N(m)=log(m)/log(λ)+O(1)`。また `a_j` は幾何級数と同じ増大率なので `Σ_{a_j<m}a_j=O(m)`。従って

```
T_5(m)=2mN(m)-2Σ_{a_j<m}a_j
      =2m log(m)/log(λ)+O(m).
```

`a_j=m` の境界は寄与0なので、項数の取り方による差は高々1であり誤差項に吸収される。

## 再現用の整数計算

```python
import math
lam=3+2*math.sqrt(2)
for m in (100,1000,10000,100000,1000000):
    a,b=8,6
    exact=0
    while a<m:
        exact+=2*(m-a)
        a,b=3*a+4*b,2*a+3*b
    leading=2*m*math.log(m)/math.log(lam)
    print(m,exact,round((exact-leading)/m,5))
```

出力：

```
100 288 -2.34499
1000 5328 -2.50949
10000 77040 -2.74598
100000 1066160 -2.40088
1000000 13219904 -2.45507
```

数値は有限の整合性検査に過ぎず、主張の全称性は上記の固有値による証明から従う。

## 境界

この主項は接線型のみの厳密な主項であり、非接線型を加えた `F_5(m)` の漸近定数・増大次数は依然として未解決である。
