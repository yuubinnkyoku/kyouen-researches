# 異方格子の三列6点円：存在の完全判定とq=6全長強解決（2026-10-17）

**証拠区分：無限格子の存在必要十分条件、Grundy公式、真の安定化長、鋭い一様上界は数学的全称証明。** 独立検算は有限格子216件に限る。既存の `K0073`（二点弦の一般判定）、`K0070`（通常格子の3行q=6で M=9）、および前回の未統合資料 `three-column-six-point-height-20261017.md` と区別する。

## 対象と結論

水平格子間隔 `h`、垂直格子間隔 `d` を**正整数**とし、

`G(h,d,m) = {(ih,jd): i=0,1,2; j=0,...,m-1}`

を考える。`m` を無制限にした三列帯を `G(h,d,∞)` と書く。

**定理A（六点円の存在の完全判定）**：`G(h,d,∞)` に6点を通る円が存在するための必要十分条件は

`d | h`

である。従って `d ∤ h` なら、**どの有限長mでも**一本の円が通る格子点は高々5点である。逆に `h=ad` (`a>=1`) なら、既に `m=3a+1` で6点円がある。

**定理B（全長のゲーム解）**：`d ∤ h` の三列帯で、完全指摘q点版の `q>=6` では、円による禁止q点組も、列をまたぐ直線による禁止q点組も存在しない。よって全安全局面 `S` は、各列の占有数が `q-1` 以下という条件のみで特徴づけられ、任意の `m>=1` について

`g(S) = (3 min(m,q-1) - |S|) mod 2`

が成り立つ。全極大集合は `3 min(m,q-1)` 点を持ち、真の満容量安定化長は `M_{3,q}(h,d)=q-1`。特に `q=6` で `M=5`。標準等間隔格子 `h=d` の既知値 `M_{3,6}=9` を誤って置換しないこと。

**定理C（存在側の鋭い一様高さ上界）**：`d|h`、`a=h/d` とすると、6点円が初めて出現する行数 `H(a)` は

`2a+2 <= H(a) <= 3a+1`。

両端の下界と上界の係数は鋭い。上界の係数3は `a=5` の `H(5)=16` により一様な `C*a+1` 形では改善できない。`a` が偶数なら、より強く `H(a) <= 5a/2+1` であり、この係数 `5/2` も `a=2` の `H(2)=6` により鋭い。`H(5)=16` および `H(2)=6` の下界証明は前回の三列弦差式資料に記録済み（前回資料はこの時点でmain未反映）。

## 定理Aの証明

6点円は各列でちょうど2点を持つ。列 `i` の2点の行番号を `l_i<u_i`、その和を `s_i=l_i+u_i`、差を `D_i=u_i-l_i>0` とする。円の中心の縦座標を `b` とすれば、上下弦の中点は常に `b` なので `s_0=s_1=s_2=2b/d`。特に `D_0,D_1,D_2` は全て同じ偶奇である。

各列の縦半弦長は `d D_i/2`。円方程式から、列位置 `x=0,h,2h` での縦半弦長の平方は `x` の二次式で、二階差分は `-2h²`。したがって

`d² (D_0² - 2D_1² + D_2²) = -8h²`. (1)

`g=gcd(h,d)`, `h=ga`, `d=gb`, `gcd(a,b)=1` と置くと、

`b² (D_0² - 2D_1² + D_2²) = -8a²`。

ゆえに `b²|8` なので `b=1` または `b=2`。後者なら `a` は奇数で、

`D_0² - 2D_1² + D_2² = -2a²`. (2)

しかし全 `D_i` が偶数なら左辺は4の倍数、右辺は `2 (mod 4)`。全 `D_i` が奇数なら左辺は `0 (mod 8)`（奇数平方は常に `1 (mod 8)`）、右辺は `6 (mod 8)`。いずれも矛盾する。従って `b=1`、すなわち `d|h` は必要。

逆に `h=ad` なら、行番号で

- 列0：`a,2a`
- 列1：`0,3a`
- 列2：`0,3a`

を選ぶ。全列の行番号和は `3a`、差は `(a,3a,3a)` で、(1) は `d²(a²-2(3a)²+(3a)²)=-8h²` を満たす。等しい行番号和と二階差分条件は円の存在に十分（中心と半径を逆算できる）なので、6点円を得る。必要な行番号は `0..3a`、よって `m=3a+1`。実際に円を明示すれば `(x-3h/2)²+(y-3h/2)²=5h²/2` であり、六点 `(0,h),(0,2h),(h,0),(h,3h),(2h,0),(2h,3h)` を通る。□

## 定理Bの証明

一つの円と一つの垂直直線の交点は高々2点であるから、3列の格子に含まれる円上点は高々6点。`d∤h` では定理Aより高々5点。非垂直直線は各列と高々1点ずつ交わるので高々3点。`q>=6` の禁止集合は垂直列に `q` 点置く場合に限られる。

したがって各列は `min(m,q-1)` 点まで自由に占有でき、ある安全局面からのどの合法手も残りの容量 `R=3min(m,q-1)-|S|` をちょうど1減らす。`R=0` で終局、帰納的に `g(S)=R mod 2`。`m<q-1` では全極大サイズが `3m<3(q-1)`、`m>=q-1` では `3(q-1)` なので真の開始長は `q-1`。□

## 定理Cの証明

任意の6点円の弦差式は `2D_1²=D_0²+D_2²+8a²>=8a²+2`。従って `D_1>=2a+1`、`m>=D_1+1>=2a+2`。上界 `3a+1` は定理Aの明示構成から従う。

`a=2k` が偶数なら、弦差式を満たす `(D_0,D_1,D_2)=(3k,5k,3k)`、共通和 `5k` を選べば `m=5k+1` で構成できる。`H(2)=6` は下界から、`H(5)=16` は `D_1=11..14` で必要な同奇偶二平方和を全て排除し、`(5,15,15)` が存在することから従う（この小さい整数範囲は以下の独立検証器でも照合できる）。□
