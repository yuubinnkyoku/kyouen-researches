# 4-row q=8: exact 8-point circle count for m <= 2774

On the board {0,...,m-1} x {0,1,2,3}, every 8-point circle meets each row in two points. Let d0,d1,d2,d3 be the positive horizontal chord lengths. They have the same parity and satisfy

    d0*d0 - 2*d1*d1 + d2*d2 = -8
    d1*d1 - 2*d2*d2 + d3*d3 = -8.

Conversely, such a tuple gives a circle on a board of minimum width 1+max(d0,d1,d2,d3), by taking common root sum equal to the maximum chord length.

Exhaustive exact integer-square tests for all d0,d1 <= 2773 produce only:
(1,3,3,1), (35,51,63,73), (73,63,51,35),
(1331,1935,2391,2773), (2773,2391,1935,1331).

Hence for every 1 <= m <= 2774 the number of distinct 8-point circles is

    C(m) = max(0,m-3) + 2*max(0,m-73) + 2*[m==2774].

All forbidden 8-sets: 4*binom(m,8)+C(m), because nonhorizontal lines contain at most four board points. This extends K0317: no new circle type appears between widths 74 and 2773, while the second Pell-family example first fits at width 2774.

The finite enumeration is a complete bounded proof, not an unbounded classification. The Python and independent C++ checkers enumerate opposite pairs of chord variables; the Python product-based checker additionally reconstructs all circles for m=1..74.
