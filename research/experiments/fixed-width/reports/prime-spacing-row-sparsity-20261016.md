# 異方格子の素数間隔による共円行の疎性（2026-10-16）

区分：**全称的な数学的証明**。後述の有限盤監査は独立した支持資料であり、全称性の根拠ではない。

## 定理（奇素数による二段階の行剰余制限）

水平間隔 `h`、垂直間隔 `d` を正整数とし、連続 `w` 行の格子

`{(x0+h*j, y0+d*i): j∈Z, i=0,...,w-1}`

を考える。奇素数 `p` について `v_p(h)>v_p(d)` とする。円が少なくとも一行で異なる2格子点を通る場合、円が格子点を持つ行番号の集合 `I` は、次のいずれかを満たす。

1. `I` は法 `p` の一つの剰余類に含まれる。
2. `I` は法 `p^2` の高々二つの剰余類に含まれる（それらは法 `p` で相異なる）。

よって、`w=p*a+r` (`0≤r<p`)、`w=p^2*b+s` (`0≤s<p^2`) と書くと、二重点行を持つ円の占有行数は

`|I|≤max(ceil(w/p), 2*b+min(2,s))`。

特に **`w≥4` なら任意の円上の格子点数は高々 `w`** である。円が全行で高々1点しか持たない場合も同じ上界を満たす。

**ゲームへの帰結：** `w≥4, q≥w+1` では、任意の盤長 `m≥1`、任意の安全局面 `S` に対して

`g(S)=(w*min(m,q-1)-|S|) mod 2`、`M_(w,q)=q-1`。

つまり水平間隔に、垂直間隔より高い指数で含まれる**奇素因子が一つでもあれば**、標準格子では難しい `q=w+1` の全長強解決が成立する。たとえば `(h,d,w,q)=(3,1,5,6)`、`(5,1,7,8)`、`(7,2,12,13)` はすべて該当する。

## 全称証明

平行移動で `x0=y0=0` としてよい。円がある行の異なる2点 `(h*j1,d*i0)`, `(h*j2,d*i0)` を通るなら、円の中心の横座標 `X` は `2X=h*(j1+j2)`。よって整数 `c=2X/h` が存在する。

占有行が一行だけなら第1の場合で終了する。二行以上ある場合は非共線な整数格子3点が存在するので、円の中心と係数は有理数である。円の方程式を展開すると、円上の任意の格子点 `(h*j,d*i)` は

`d^2*i^2 + U*i + V = -h^2*(j^2-c*j)`

を満たす（`U,V` は円に依存する有理数）。`p` 進体で両辺を `d^2` で割り、`a=U/d^2,b=V/d^2` とおく。`v_p(h)>v_p(d)` より、占有行の全てで

`f(i)=i^2+a*i+b ∈ p^2 Z_p`。

占有行が法 `p` の一つの剰余類に収まれば第1の場合。そうでなければ、法 `p` で異なる二つの占有行 `u,v` を選ぶ。`f(u),f(v)∈p^2 Z_p` なので、差を取って

`(u-v)*(u+v+a) ∈ p^2 Z_p`。

`u-v` は `p` 進単元だから `a∈Z_p`。さらに `f(u)∈p^2 Z_p` から `b∈Z_p`。従って `f` は `Z_p` 上のモニック二次多項式で、法 `p` に異なる根 `u,v` を持つ。根が二つ相異なるので、どちらも単根である。各単根は法 `p^2` へただ一つ持ち上がる（`f(r+p*t)≡f(r)+p*t*f'(r) mod p^2` かつ `f'(r)≠0 mod p`）。よって全占有行は法 `p^2` の高々二つの剰余類に含まれる。第2の場合が成立する。

長さ `w` の連続整数区間で、一つの法 `p` 剰余類に属する行は高々 `ceil(w/p)` 本、二つの法 `p^2` 剰余類に属する行は高々 `2*floor(w/p^2)+min(2,w mod p^2)` 本。水平線と円の交点は高々2なので、点数上界はこれらの2倍と `w` の最大値である。

`p≥3,w≥4` なら `2ceil(w/p)≤w`。また `w=p^2*b+s` に対し、`b=0` なら `w=s≥4` より `2min(2,s)≤w`、`b≥1` なら

`4b+2min(2,s)≤9b+s≤p^2*b+s=w`。

従ってどの円も高々 `w` 点。非水平直線も各行と高々1点で交わるため `q≥w+1` では行間の禁止 `q` 点集合が存在しない。水平行だけの容量 `min(m,q-1)` の独立和になり、残り手数の偶奇からGrundy公式が従う。`m=q-2` では満容量 `w(q-1)` に達しないため、真の安定化長は `q-1`。□

## 独立有限監査

`research/experiments/fixed-width/scripts/verify_prime_spacing_20261016.py` は整数係数の円方程式を非共線3点から直接生成し、同じ円上の点をビット集合にまとめる。法 `p` / 法 `p^2` の二分法と、点数 `≤w` を検査する。`p=3,5,7,11` を含む **計56有限盤** で矛盾なし。最大の監査例は `(h,d,w,m,p)=(7,3,12,14,7)` で円622,304種類、最大共円点数5（上界12）。

円を3点から生成するので、2点以下の円は列挙されないが、今回の上界は4以上であり検証上問題ない。有限監査は全長の証明ではない。

`anisotropic-mod9-all-widths-20261016.md` は `v_3(d)≤v_3(h)` を扱うが、そのうち **`v_3(d)<v_3(h)` を大幅に強化**した。等号の場合の法9上界は引き続き有効であり、本定理からは従わない。標準格子 `h=d=1` の既存値も変更しない。

`v_p(h)≤v_p(d)` が全ての奇素数で成立する異方格子については、この証明は適用できない。`P≤w` が各幅で鋭いか（実際に `w` 点円を構成できるか）も一般には未確定。
