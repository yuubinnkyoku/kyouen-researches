# mod 23・31 による格子円二重点行の半密度定理

K0072 の Vieta 帰着を mod 23 と mod 31 に同時に適用し、N mod 713、巡回始点、区間長を完全列挙した。

結論：標準整数格子の連続 w 行で一本の円が2格子点を持つ行数 t は、w>=27 なら t<=ceil(w/2)。したがって円上の盤内格子点数 P は P<=w+ceil(w/2)。

有限補題は、713行一周期の許容数が最大221、全区間長 L=27..713 で許容数が ceil(L/2) 以下、L=26 では最大14>13、L=27 では最大14=ceil(27/2)。

w=713k+r とする。k=0 は有限補題。k>=1,r>=27 なら t<=221k+ceil(r/2)<=ceil(w/2)。r<27 なら t<=221k+r<=ceil(w/2)。よって全 w>=27 に延長される。

系：w>=27 かつ q>w+ceil(w/2) なら行間 q 点共円・非水平 q 点共線は存在せず、全 m>=1 で g(S)=(w min(m,q-1)-|S|) mod 2、M_{w,q}=q-1。

証拠境界：713周期部分は有限完全列挙、無限幅への延長は数学的証明。w=26 の14個は合同必要条件の反例であって実円の存在証明ではない。
