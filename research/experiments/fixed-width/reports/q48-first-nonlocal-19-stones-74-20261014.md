# 4×74・q=8：最初の非局所円による19石安全配置数の厳密補正

2026-10-14。対象は横74列・縦4行、禁止条件は同一直線または円上に8点が揃うこと。これは**有限盤の完全計数**であり、一般の無界盤長に対する多項式主張ではない。基準は main `8d65bcced13a02c587a33f3c855756bc55c32e70`。K0317の円型分類、および既存の4×m・q=8安定化定理とは矛盾しない。

## 新しい厳密値

```text
a_19(4×74;q=8) = 295248500387707036716621378756
```

局所円 `(1,3,3,1)` の平行移動71個だけを採用した場合は

```text
a_19(local only) = 295248500428508218666508077236
```

したがって、幅74で初めて現れる非局所円2個による厳密な減少量は

```text
Δa_19 = -40801181949886698480
```

## 円型の完全性

4行で8点以上を通る非退化円は各行をちょうど2点通る。各行の二点の横方向の距離を正整数 `d_0,...,d_3` とすると、共通の二点座標和から全て同じ偶奇を持ち、円の二次方程式から

```text
d_0² - 2d_1² + d_2² = -8
d_1² - 2d_2² + d_3² = -8
```

を満たす。逆に、この条件と正の弦長、共通の整数座標和は円を定める。幅74で `1≤d_i≤73` の全整数組を完全列挙すると、円型は `(1,3,3,1)`、`(35,51,63,73)`、`(73,63,51,35)` のみ。前者の平行移動が71個、後者が各1個である。後者の円方程式はそれぞれ

```text
x²+y²-73x-345y+1026=0
x²+y²-73x+339y=0
```

であり、盤内で各8点のみを通ることも直接代入で確認した。二つの非局所円は互いに交わらない。各非局所円は局所円12個とちょうど1点で交わり、残り59個とは交わらない。従って新規の円対は1点共有24対、共有なし119対（非局所円同士の1対を含む）となる。

## 包除原理による補正

任意の異なる二つの直線・円の交点数は高々2なので、四つの禁止図形を同時に完成するには `4·8-6·2=20` 石以上が必要。19石では包除原理が三次で厳密に打ち切れる。

`B(n,r)=binom(n,r)`（範囲外は0）、`N=296` とする。新しい円の単独禁止寄与は `-2B(288,11)`。各円は各水平行に2点を持つので、新しい円と水平行の二重禁止寄与は

```text
+8R,  R=Σ_{a=6}^{72} B(72,a) B(216,11-a).
```

新しい円対の二重禁止寄与は

```text
+119B(280,3)+24B(281,4).
```

三重禁止では、二つの水平行と一つの円は少なくとも20点を要し、三つの円も20点以上を要する。後者は、局所円同士が最大2点共有し、非局所円と局所円が最大1点共有することから従う。水平行1本と円2本の三重禁止の新規分だけが残る。1点共有の円対24対について、共有点のない他の3行では円の合併が4点を占めるため、追加4点を行から選ぶ `B(70,4)` 通りが生じる。共有点のある行では5点以上の追加が必要で、19石には収まらない。三次補正は `-72B(70,4)`。

従って厳密に

```text
Δa_19 = -2B(288,11) + 8R
       + 119B(280,3) + 24B(281,4)
       - 72B(70,4)
       = -40801181949886698480.
```

局所円だけの場合の19石配置数は、4行の単独・二重禁止、局所円の交差2点対138組、水平行と局所円2本の三重禁止を同様に包除して計算した。コードは局所円だけと全73円を別々に計数し、差分も独立した閉式で照合する。

## 検証と境界

`research/experiments/fixed-width/scripts/q48_nonlocal_74_audit.py` は標準ライブラリだけで、整数平方根による弦長全列挙、非局所円の整数方程式の直接照合、全円対・三円組に基づく三次包除、独立差分公式の照合を実施する。幅8・9・10の既存19石数も回帰検査する。検査はすべて一致した。弦長全列挙は**幅74に関して完全**だが、幅75以降の円型・交差統計を証明したものではない。Grundy値や極大配置数の主張も含まない。
