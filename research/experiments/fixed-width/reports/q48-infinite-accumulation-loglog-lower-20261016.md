# 4行8点円：実現傾きの無限個の集積点と `log H log log H` 下界

2026-10-16。基準 `main`：`db2a6b9b5291c4038b65e98fa838088881b17c0d`。

**証拠区分：数学的全称証明。** 末尾の840件の行列式検査は独立した有限監査であり、無限性の証明ではない。

## 定理

四連続整数行の各行を2点ずつ通る非局所8点円の、K0432の意味での実現可能な既約正傾きを `A/B` とする。`1<=A,B<=H` を満たす相異なる傾き数を `R(H)` と書く。

1. 実現可能な傾き集合の集積点は**無限個**存在する。具体的に、相異なる無理数 `alpha_n` (`n>=0`) が集積点で、`alpha_n` は厳密増加して `47/6` に収束する。従って `47/6` は集積点集合の集積点でもある。
2. `D=4096105` の正Pell単元

   ```
   u0 = 2623690785907841834392601869396094258501902861264863636874872064001
   v0 = 1296364440273750313833394026099398390407297776771462878763466560
   u0²-D*v0²=1
   Lambda=u0+v0*sqrt(D)>1
   ```

   を使うと、明示的に

   ```
   liminf_(H->infinity) R(H)/(log H * log log H)
       >= 1/(4 log Lambda) = 0.001627303864... > 0.
   ```

   したがって `R(H)=Omega(log H log log H)`。既存の三族から得られる `Omega(log H)` を真に改善する。上界や正確な漸近は未解決。

## 1. 固定傾きの無限Pell列

`A=47,B=6` とし、`P=A²-B²=2173`, `Q=A²-9B²=1885`, `D=PQ=4096105` とする。既知の8点円

```
(L0,M0)=(16097,17283),
(a,b,c,d)=(445465,715719,908883,1067653)
```

は `Q M0²-P L0²=8` を満たす。上の `u0,v0` は直接代入でノルム1を満たし、`u0` は奇数、`v0` は偶数である。整数行列

```
T0=[[u0,Q*v0],[P*v0,u0]]
(L_n,M_n)=T0^n(L0,M0)
```

は行列式1でノルム8と各成分の奇偶を保存する。`L_n,M_n` は正の奇数で厳密増加し、`L_n=Theta(Lambda^n)`。また

```
(M_n/L_n)² = P/Q + 8/(Q L_n²),
1 < M_n/L_n <= M0/L0 < 4/3.
```

以下

```
U_n=M_n²-L_n²,
V_n=9M_n²-L_n²
```

と置く。両者は正の8の倍数であり、恒等的に

```
U_n A²-V_n B²=8,
U_n=8*(B² L_n²+1)/Q.
```

従って `U_n` は厳密増加し `Theta(Lambda^(2n))`、かつ `U_(n+1)>2 U_n`。最後の不等式は `L_(n+1)>=2 L_n` と `B² L_n²>=36` から従う。

## 2. 各nでの双対Pell列

`U=U_n,V=V_n` を固定し、`x=U A²-4`, `y=AB=282` とする。`x≡4 (mod 8)` なので

```
u=x²/8-1,
v=x*y/8
```

は正整数である。`UA²-VB²=8` を展開すると `x²-UV y²=16` であり、従って `u²-UV v²=1`。さらに `u≡1 (mod 6)`, `Uv≡Vv≡0 (mod 6)`：法2は `8|U,V`, `x≡4(mod8)` から、法3は `3|B`, `3∤A`, `UA²≡8≡2(mod3)`, `x≡1(mod3)`, `3|v` から従う。

従って

```
T_n=[[u,V*v],[U*v,u]],
(A_(n,k),B_(n,k))=T_n^k(47,6)   (k>=0)
```

は全kで正整数、`gcd=1`, `A` 奇数、`B` 偶数、`3∤A` を保存する。`B_(n,k)` は厳密増加し、

```
r_(n,k)²=(A_(n,k)/B_(n,k))²
        =V/U+8/(U B_(n,k)²)
```

なので `r_(n,k)` は `47/6` から厳密減少し

```
alpha_n=sqrt(V_n/U_n)
```

に収束する。`UV` が平方なら `alpha_n` は有理数で `UA²-VB²=8` の正整数解から `U,V` の共通平方自由部分を取り出せるが、`U,V` はともに8の倍数、`B` は偶数であり、ノルム8の因数分解から矛盾する。実際 `U=p r²,V=p s²` と置くと `p(rA-sB)(rA+sB)=8`。正の同偶奇因数対で `sB>0` となる可能性は `p=1,(rA-sB,rA+sB)=(2,4)` だけで、`sB=1` は `B=6` に矛盾する。`p=2,(2,2)` は `sB=0` なので除外される。ゆえに `alpha_n` は無理数である（この無理性は無限集積点の個数を示すには必須ではない）。

実際の8点円であることも確認する。各kの弦長を

```
a=A_(n,k)*L_n-3*B_(n,k)*M_n
b=A_(n,k)*M_n-B_(n,k)*L_n
c=A_(n,k)*M_n+B_(n,k)*L_n
d=A_(n,k)*L_n+3*B_(n,k)*M_n
```

とする。`z=M_n/L_n` は `1<z<4/3` なので

```
L_n² V_n > 9 M_n² U_n
<=> 9 z^4-18 z²+1<0.
```

この多項式は `[1,4/3]` 上で負（`z>1` で増加、`z=4/3` でも `-23/9`）だから、`a>0` は極限傾きでも成り立つ。`b-a=(M-L)A+(3M-L)B>0`, `c-b=2BL>0`。`d-c=(L-M)A+(3M-L)B` を `B` で割った値は傾き `A/B` が減ると増えるため、`k=0` の正値から全kで正。全弦長は奇数、平方の二階差分はともに `-8`。各行yの二点を `((d±chord_y)/2,y)` とすれば整数座標で同一円上にある（円方程式は検証器に明記）。従って `alpha_n` は実現傾きの集積点である。

## 3. 集積点が無限個であること、傾き族の重複排除

恒等式 `U_n A²-V_n B²=8` から

```
alpha_n² = (A/B)²-8/(B² U_n).
```

`U_n` が厳密増加して無限大に発散するので、`alpha_n` は相異なり、厳密増加して `47/6` に収束する。

さらに、異なるnの双対列は**k>=1なら完全に分離**できる。`B_(n,1)>=2B` は `u>=2` から従う。そこで

```
r_(n,1)²-alpha_n²=8/(U_n B_(n,1)²) <= 2/(B² U_n),
alpha_(n+1)²-alpha_n²
  =8/B²*(1/U_n-1/U_(n+1)) > 4/(B² U_n).
```

よって

```
alpha_n < r_(n,k) <= r_(n,1) < alpha_(n+1)   (k>=1).
```

区間 `(alpha_n,alpha_(n+1))` はnごとに互いに交わらない。従って**異なるn,k>=1は必ず異なる実現傾き**を与える。

## 4. 定量的下界

`lambda_n=u_n+v_n sqrt(U_n V_n)>1` を双対変換の正固有値とする。第1節より `L_n=Theta(Lambda^n)`、従って `U_n,V_n,x_n=Theta(Lambda^(2n))`。第2節の公式から

```
log lambda_n = 4n log Lambda + O(1)   (n->infinity).
```

対角相似変換 `diag(sqrt(U_n),sqrt(V_n))` により `T_n` は対称行列 `[[u,v sqrt(UV)],[v sqrt(UV),u]]` になる。従って

```
sqrt(U)*A_(n,k)+sqrt(V)*B_(n,k)
  =lambda_n^k*(sqrt(U)*A+sqrt(V)*B).
```

`V/U< (A/B)²`、`U<V` なので、全n,kについて

```
A_(n,k) <= 2A*lambda_n^k = 94*lambda_n^k,
B_(n,k) <= (A+B)*lambda_n^k = 53*lambda_n^k.
```

`H>94` とし、`N=floor(log(H/94)/(8 log Lambda))`。十分大きなHでは全 `1<=n<=N` について `log lambda_n<log(H/94)`。各nで `1<=k<=floor(log(H/94)/log lambda_n)` は `A_(n,k),B_(n,k)<=H` を満たし、第3節により全て相異なる。よって

```
R(H) >= sum_(n=1)^N floor(log(H/94)/log lambda_n)
     >= log(H/94) * sum_(n=1)^N 1/log lambda_n - N.
```

`log lambda_n=4n log Lambda+O(1)` より

```
sum_(n=1)^N 1/log lambda_n
    = (log N)/(4 log Lambda)+O(1).
```

`N=Theta(log H)` だから

```
R(H) >= (log H log log H)/(4 log Lambda)-O(log H).
```

これは第1節の明示的下界を証明する。□
