# 非原始二重点行34〜96本の厳密構成上界（2026-10-10）

## 定義・結論

連続する幅 `w` の整数水平行の中から、同じ実円がそれぞれ異なる二つの整数格子点を持つ `k` 行を選び、その行番号差の最大公約数が2以上になるような最小幅を `F(k)` とする。横座標は無制限。

**34≤k≤96 の全63個の k に対して、新しい厳密な構成上界 `F(k)≤W_k` を与えた。** 各 `W_k` は同梱TSVに記録する。これらは円の明示的な構成であり、最小幅 `F(k)` の確定ではない。`F(33)` の既存の範囲 `561≤F(33)≤743` も変更しない。

| k の範囲 | 実現円 `x²+y²=N` | W_k（区間両端） |
|---|---:|---:|
| 34〜36 | 143650 | 755〜759 |
| 37〜48 | 320450 | 981〜1131 |
| 49〜64 | 1602250 | 2171〜2531 |
| 65〜72 | 4165850 | 3943〜4083 |
| 73〜80 | 8011250 | 5523〜5655 |
| 81〜96 | 11856650 | 6469〜6887 |

例えば `x²+y²=11856650` では、`-3443≤y≤3443` の奇数行のうち96本で `11856650−y²` が正の整数平方となる。両端行の差は6886で、選択行差のgcdは2。従って `F(96)≤6887`。同様に `F(34)≤755`, `F(48)≤1131`, `F(64)≤2531`, `F(80)≤5655`。

## 証明と独立検証

TSVの各行は `(k, W_k, N, y_min, y_max, y_1,...,y_k)`。Python検証器は各 `y_i` で `isqrt(N−y_i²)^2=N−y_i²` かつ `N−y_i²>0` を厳密な整数演算で確認し、点 `(±isqrt(N−y_i²), y_i)` の二点が相異なること、`k` 行が相異なること、行差gcdが厳密に2であること、幅が `W_k` であることを検査する。

C++探索器は半径二乗 `N≤30,000,000` の整数中心円 `x²+y²=N` と、`(2x+1)²+4y²=N'`（`N'≤120,000,000`）という横方向半整数中心円を有限走査し、同じ偶奇の行から `k` 個連続に取る候補を列挙する。探索対象をこの二族に制限しており、**一般の実円や任意半径を完全探索したという主張ではない**。実際に採用された63件の証人はすべて整数中心円6個から生じた。

独立したPython整数平方根走査で六円の全二重点行を生成し、各kについて窓の最小幅を再計算。C++の63件の `k, W_k, N, y_min, y_max, 全y` が完全一致した。両実装の探索の独立性は限定的だが、**構成の正当性はPythonの整数演算のみでも検証できる**。

## 再現

```sh
c++ -std=c++20 -O3 research/experiments/fixed-width/scripts/search_nonprimitive_34_96.cpp -o /tmp/search_f34_96
/tmp/search_f34_96 30000000 > /tmp/search_f34_96.tsv
python research/experiments/fixed-width/scripts/verify_nonprimitive_34_96.py > /tmp/verify_f34_96.tsv
```

C++の出力は `# candidates` 行の後に `(k, W, type, N, min, max, y-list)` が続く。type=0なら `x²+y²=N`、type=1なら `(2x+1)²+4y²=N`。Pythonの出力は `(k,W,N,min,max,y-list)`。証人がtype=0なので対応欄は完全一致する。

本結果は既存の未統合 `F(2)..F(33)` に依存しない。次の課題は `F(33)` の幅561〜742を無制限円について排除または証人発見すること、`k≥97` に対する構成改善である。
