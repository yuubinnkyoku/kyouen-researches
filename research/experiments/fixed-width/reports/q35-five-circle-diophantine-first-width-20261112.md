# 3×m のちょうど5点円：弦幅の整数方程式と初出幅（2026-11-12）

**証拠水準：全称的な必要十分条件と整数論的な初出幅公式。** 既存の `q35-width14-chord-independent-audit-20261112.md` の有限列挙を一般化する。ここでは盤の横座標を 0,...,m−1、縦座標を 0,1,2 とする。円そのものの全格子点数を数え、五点部分集合の個数とは区別する。

## 定理

ちょうど5点を含む円は、上・中段に各2点で下段に1点、または中・下段に各2点で上段に1点のどちらかである（中央段だけ1点の型は既存の `q35-middle-singleton-first-width.md` で排除済み）。

上・中段の水平弦の長さを正整数 `a,b`、共通の横中点を `c` とし、下段との交点を `c±k/2` とする。整数格子点を持つ条件は

```
a ≡ b ≡ k (mod 2),  k≥0,  a²+k²+8=2b².
```

このとき次の二種類だけがちょうど5点円を作る。

* **接線型**：`k=0`。下段の交点は重根なので、下段の整数点は1個。最小横幅（列数）は `m₀=max(a,b)+1`。
* **片側切断型**：`k>max(a,b)=W`。下段の2つの整数交点のうち片方だけが盤内にある場合に限り5点円。最小横幅は `m₀=(W+k)/2+1`。

`0<k≤W` なら、下段の整数交点は両方とも既存の弦の横範囲に入るため、必ず6点円となる。

より強く、特定の正整数弦幅対 `(a,b)` と `k` について、幅 `m` の盤にある **ちょうど5点円の個数**（上下反転を含む）は、接線型なら `2 max(0,m-W)`、片側切断型なら

```
4 min(max(0,m-(W+k)/2), (k-W)/2)
```

である。条件を満たさない組の寄与は0。異なる `(a,b,k)` は異なる円を表すので、全ての整数解について和を取れば任意の `m` の5点円数が得られる。和は `W≤m−1` および `(W+k)/2≤m−1` の有限範囲に限ればよい。

## 証明

円の各行における半弦長二乗を `H(y)=R²-(y-y₀)²` とすると二階差分は −2 である。`4H(0)=a²`, `4H(1)=b²`, `4H(2)=k²` より `k²=2b²-a²-8`。両弦の整数端点は同じ中点 `c` を持つため `a≡b (mod 2)`。下段の整数交点の存在は `k≡a (mod 2)` と同値である。

`k=0` では1交点、`k>0` では左右対称な2交点。弦の端点は `c±W/2` なので `k≤W` なら2交点とも盤内。逆に `k>W` なら、片方だけを収める最小整数列区間は長さ `(W+k)/2`、従って最小列数はそれに1を加えたもの。区間の左端を `u` として右側の交点を採用すると `0≤u≤m−1−(W+k)/2`。反対側の交点が盤外である条件は `u<(k-W)/2`。よって右側を採る配置数は `min(max(0,m−(W+k)/2),(k-W)/2)`。左右反転で2倍、上下反転でさらに2倍。接線型は `m-W` 通りの平行移動と上下反転の2倍。全ての逆方向も同じ方程式で円を復元できるため必要十分である。

## m=14 の新型と独立検算

`(a,b,k)=(3,11,15)` は `9+225+8=2·121` を満たし、`W=11`、最小列数 `(11+15)/2+1=14`、片側切断の余裕 `(15−11)/2=2`。したがって幅14での寄与は `4 min(14−13,2)=4`。これは既存の独立列挙が見つけた新型4円を、無界に有効な式から説明する。

同様に `(a,b,k)=(3,7,9)` は初出幅9、寄与は幅9以上で4本一定。`(8,6,0)` は接線型で初出幅9、幅m≥9に `2(m−8)` 本。従って幅9〜13の5点円数は `2(m−8)+4=2m−12`、幅14ではこれに新型4本を加えて20本となり、既存の厳密列挙と一致する。

## 検証用独立コード

```python
from math import isqrt

def five_circle_count(m):
    ans=0
    for a in range(1,m):
        for b in range(1,m):
            if (a-b)%2: continue
            z=2*b*b-a*a-8
            if z<0: continue
            k=isqrt(z)
            if k*k!=z or (k-a)%2: continue
            W=max(a,b)
            if k==0: ans+=2*(m-W)
            elif k>W:
                L=(W+k)//2
                ans+=4*min(max(0,m-L),(k-W)//2)
    return ans

assert [five_circle_count(m) for m in (9,10,11,12,13,14,15)] == [6,8,10,12,14,20,26]
```

本結果はちょうど5点円に関する一般公式であり、6点円の個数や q=5 のGrundyを直接決定するものではない。
