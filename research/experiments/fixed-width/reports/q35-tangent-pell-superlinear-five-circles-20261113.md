# 3×m・q=5：接線型Pell族から5点円数の超線形成長（2026-11-13）

**証拠水準：全称的な構成証明。** 既存の `q35-five-circle-diophantine-first-width-20261112.md` の接線型計数式を用いる。ゲームのGrundy値・勝敗に関する主張ではない。

## 定理

3×mの格子点をちょうど5個通る相異なる円の個数を `F_5(m)` とする。このとき

```
F_5(m) = Ω(m log m),   特に F_5(m)/m → ∞.
```

さらに、整数列 `(a_0,b_0)=(8,6)`, `(a_{j+1},b_{j+1})=(3a_j+4b_j,2a_j+3b_j)` と置くと、任意の `m≥1` で

```
F_5(m) ≥ 2 Σ_{j≥0} max(0,m-a_j).
```

和は有限個の非零項しか持たない。

## 証明

`a_0²+8=2b_0²` であり、更新は `a²−2b²` を保存する（`(3a+4b)²−2(2a+3b)²=a²−2b²`）。各項は正の偶数で、`a_j>b_j` が保存される（差は `a'+(-b')=a+ b>0`）。したがって `a_j²+8=2b_j²` と `a_j≡b_j≡0 (mod 2)` を満たす。

既存の一般定理で `k=0` とすると、上・中段の水平弦幅が `a_j,b_j`、下段が接線となる円は幅mの盤でちょうど `2 max(0,m-a_j)` 個ある。上・下反転も含めて数え、`a_j` は狭義増加なので族同士で円は重複しない。よって表示した下界が成り立つ。

また `a_j>b_j>0` より `a_{j+1}=3a_j+4b_j<7a_j`。従って `a_j≤8·7^j`。任意の `j≤⌊log_7(m/16)⌋` で `a_j≤m/2` となり、その項の寄与は `2(m-a_j)≥m`。よって `m≥16` で

```
F_5(m) ≥ m (⌊log_7(m/16)⌋+1).
```

これが `Ω(m log m)` と `F_5(m)/m→∞` を与える。上界 `O(m log m)` は示していない。

## 既存成果との差分

先行報告の弦幅1・3・9・15の片側切断型Pell族は、基準線形項からの乖離が無界になることを示した。本結果は **接線型だけで円数が超線形** となることを示す。接線型の別の種解があるか、正確な増大次数は未分類。
