# 非原始二重点行の最小幅 F(k)：2〜32本（9本を除く）

2026-10-10。一本の実円が相異なる整数格子点を2個ずつ持つ水平行から **k本を選び**、選択した行番号差の最大公約数を `g` とする。横座標は任意の整数。`g≥2` を実現できる最小の連続整数行幅を `F(k)` と定義する（k≥2）。

**9本だけは未確定**で、完全合同排除から `F(9)≥41`、`x²+y²=650` の構成から `F(9)≤43` が成立する。幅41・42では局所平方剰余の全法検査後も候補マスクが残り、無限円係数に対する上界証明にはなっていない。

## 無限個の円に対する上界の帰着

`F(k)-1` 本の連続整数行の中に条件を満たすk本が存在すると仮定する。最小行を `y=0` に平行移動する。`g≥2` とすると行は `y=gi`（`i` 整数、`0≤i≤floor((F(k)-2)/g)`）にあり、最小行 `i=0` が選ばれる。`(k-1)g≤F(k)-2` より `2≤g≤floor((F(k)-2)/(k-1))`。**最大行が窓の右端にあるとは仮定しない。**

円を `x²+y²+Bx+Cy+D=0` と表す。`y=0` に相異なる二つの整数根があるので、Vietaの公式から `B,D` は整数。各 `y=gi` の整数根の積より `giC` は整数である。選択された `i` の最大公約数は1なので、Bézoutにより `a=gC` は整数。

`p` を `gcd(p,g)=1` を満たす奇数法（素数でなくてもよい）とし、`c≡a/g (mod p)`, `n≡B²−4D+c² (mod p)` とする。二整数根の差の平方は

`(2x+B)² ≡ n−(2gi+c)² (mod p)`

なので、選択された全 `i` で右辺は0を含む平方剰余集合 `QR(p)` に属する。法ごとに `c,n` を独立に選ぶのは条件を**緩める**操作であり、真の円の可能性を削らない。

検証器は各法 `p∈(9,11,7,49,19,31,23,43,47,37,41,53,59)` に対し全 `p²` 組の `(c,n)` を列挙し、`i=0` を含みk行以上を許すビットマスクを作る。現在残るマスクと共通部分を取り、k行未満を捨てる。全30件・各gで空集合になった。円係数・半径を有限に制限した探索ではない。

## 明示的な下界構成

各行に記した整数円 `x²+y²=N` の整数点を、`x=1,...,floor(sqrt(N))` の整数平方根で全列挙する。`x>0` なら `x` と `−x` が同じ水平行の相異なる二整数点を与える。得られたy座標からk本の最短連続区間を選び、行番号差のgcdが**厳密に2**であることを確認した。平行移動により区間を `0≤y<F(k)` へ移せる。

証人は N=2,10,50,130,650,2210,11050,55250 の8円だけで全30値を達成する。特に `k=25..32` は `N=55250`、`k=17..24` は `N=11050` の同じ円からそれぞれ構成される。

## 再現と信頼境界

```sh
python research/experiments/fixed-width/scripts/check_nonprimitive_rows_2_32.py
python research/experiments/fixed-width/scripts/run_nonprimitive_rows_2_32.py
```

後者はC++を2通り（平方剰余マスクの転置生成・`(c,n)`直接生成）にコンパイルし、30件の上界と9本の幅40排除について**出力全行を照合**する。結果の件数・最大中間状態数・SHA-256は `output/nonprimitive_rows_2_32_audit.csv` に記録する。二つのC++方式はマスク交差処理を共有するため、完全独立な形式証明器ではない。Pythonによる下界検証は独立の整数平方根列挙である。

数学的帰着と有限完全排除を組み合わせた全称証明であり、有限半径探索の結果ではない。未解決の `F(9)`、未統合の `T(64..336)`、および標準盤 `K_n,s_n` への含意を過大主張しない。
