# 等間隔三行の6点円：初出付近の幅に対する厳密計数（2026-10-22）

**証拠水準：** 全整数 h,m に対する下記範囲内の数学的証明。有限計算は独立検算。対象は V(h,m)={0,...,m−1}×{0,h,2h} の6点円の本数 C_h(m)。円は各行と高々2点で交わるので、6点円は必ず各行2点ずつを通る。

## 定理

整数 h≥1、0≤k≤⌊√8 h⌋−2h、m=2h+k+1 とする。r₂(n) は整数解 u²+v²=n の符号と順序を区別した個数、d_j(n) は n の正の約数で j mod 4 に合同なものの個数とする。ε(n)=1 は n=2a²（a≥1 整数）のとき、その他は0。

\[
\boxed{C_h(2h+k+1)=\sum_{\ell=1}^k(k+1-\ell)\rho(\ell(4h+\ell)),\qquad
\rho(n)=r_2(n)/4-\varepsilon(n)=d_1(n)-d_3(n)-\varepsilon(n).}
\]

特に k≥2 でこの範囲内なら、幅に関する二階差分は
\[
C_h(2h+k+1)-2C_h(2h+k)+C_h(2h+k-1)=\rho(k(4h+k))\ge0.
\]
k=1 でも C_h(2h)=0 を用いれば同じ式が成立する。k=1 は既存 K0492 の C_h(2h+2)=r₂(4h+1)/4 を回収する。

## 全称証明

各行の水平弦長を d₀,d₁,d₂≥1 とする。円方程式の x の一次係数が共通なので、三弦の横座標中点は等しく、弦長は同じ偶奇である。行ごとの二交点の積の二階差から
\[
d_0^2+d_2^2=2d_1^2-8h^2. \tag{1}
\]
よって d₁≥2h+1。d₁=2h+ℓ とし u=(d₀+d₂)/2、v=(d₀−d₂)/2 と置けば、
\[
u^2+v^2=\ell(4h+\ell),\qquad u>|v|,\ u>0. \tag{2}
\]
逆に (2) の整数解から d₀=u+v,d₂=u−v を作ると正で、d₁ と偶奇が一致する。ℓ が奇数なら右辺は奇数で u,v は異偶奇、ℓ が偶数なら右辺は4の倍数で u,v はともに偶数だからである。

(2) の解数は r₂(n)/4 だが、n=2a² なら対角線 |u|=|v| 上の4解は弦長0を生むため除外する。従って形状数は ρ(n)。古典的な二平方和公式 r₂(n)=4(d₁(n)−d₃(n)) で約数表示を得る。

幅の条件より d₁≤m−1≤√8 h。式(1)から d₀²+d₂²≤d₁²、特に d₀,d₂<d₁。従って最長弦は中央行の d₁ であり、同じ三弦を盤内で水平移動できる方法はちょうど m−d₁=k+1−ℓ 通り。ℓ=1,...,k で和を取れば公式が成立する。二階差分は公式の差を取ればよく、ρ は実際の形状数なので非負。□

## 注意・独立検証

**対角線補正は不可欠。** h=7,ℓ=4 では n=128=8²+8² だが、ρ(128)=0。補正なしでは無効な0長弦を数えてしまう。

**十分区間外へ外挿してはならない。** h=3,m=12 では真の円数は20だが、上の重みを区間外へ延長した式は22を返す。区間外では最大弦長が中央行に限られない。
