# 五本の等間隔整数行：間隔が3の倍数でなければ9点円は存在しない

日付: 2026-10-16。基準 main: `1238bfaedc71e1a0d2f08f9cd85f5b3243adeb8d`。

## 定理（全称数学的証明）

整数 `t,d,m` が `d>=1,m>=1,3∤d` を満たすとし、格子盤

`D(t,d,m)={(x,t+i*d):x=0,...,m-1; i=0,...,4}`

で同一直線・同一円上の9点を禁止する通常プレイを考える。このとき**任意の** `t,d,m` と安全局面 `S` について

```
g(S) = (5*min(m,8)-|S|) mod 2,
M_{t,d,5,9} = 8.
```

すなわち各水平行に高々8点という条件だけが安全性を決める。特に `m>=8` の空盤は後手勝ち。`M` は「全ての極大安全配置が各行8点を持つ状態へ安定する最小の横幅」とする。

### 証明

もし円が五行すべてに少なくとも一つの整数点を持ち、いずれか一行で異なる2整数点を持つなら、円を

`x²+y²+Bx+Cy+D=0`

と書いたとき二根の和から `B∈Z`。従って他の行でも整数根が1個あれば他方も整数根である（接点は重根）。各行の二根の差を整数 `a_i` と置くと、判別式により

`a_i² = B² - 4((t+id)²+C(t+id)+D)`

だから

`a_{i+2}² - 2a_{i+1}² + a_i² = -8d²`。

`3∤d` なので `d²` は法9で可逆な平方剰余。`u_i=d^{-2}a_i² mod 9` とすれば各 `u_i` は法9の平方剰余集合 `Q={0,1,4,7}` に属し、

`u_{i+2} - 2u_{i+1} + u_i ≡ -8 (mod 9)`。

`u_0,u_1∈Q` の全16組を調べると、最初の4項が `Q` に属するのは `(1,0,0,1)` の場合だけ。その5項目は `3 mod 9` で非平方。矛盾。よってそのような円はない。

円は各水平行と高々2点で交わる。9点円があれば5行すべてに点を持ち、少なくとも4行で二点を持つので上の不可能性に反する。非水平直線も五行に高々5点。したがって9点禁止は同一水平行の9点だけで、各行容量8の独立ゲームとなる。全終局石数は `5*min(m,8)`、Grundy値は残り手数の偶奇。`m=7` では40点の極大配置を作れず、`m=8` から各行8点を置けるので、閾値8は鋭い。□

### さらに強い補題：どの整数間隔でも無限水平格子上に「ちょうど9点の円」はない

間隔 `d` が3の倍数であっても、5行をすべて通り、うち1行だけに整数点が1個（接点）という円は存在しない。**ここで各行は x∈Z 全体であり、有限横幅での点数ではない。**

**証明。** この場合の整数二根差 `a_i` のうち接点行では `a_j=0`。`3|d` なら二階差分を法3で見ると `a_i²` は `{0,1}` 内の長さ5の等差数列となる。法3で非定数の3項等差数列は `{0,1,2}` をすべて通るため、**全項が同じ剰余**でなければならない。接点で `a_j=0` なので全 `a_i²≡0 (mod 3)`、従って全 `a_i` は3の倍数。`a_i/3` と `d/3` は同じ二階差分方程式を満たし、接点の差0も保つ。`v₃(d)` 回この議論を繰り返すと、3の倍数でない行間隔に帰着し、先の法9障害に矛盾する。□

円と5行の交点数は最大10点である。**ちょうど9点**なら分布は `(2,2,2,2,1)` の並べ替えとなり、1点行は接点なので上の補題に反する。従って**任意の整数間隔 `d≥1` で、円が五行の無限水平格子 `x∈Z` 上に持つ整数点数は9にならない**。9点以上があるとすれば、必ず各行2点の**10点円**である。ただし有限の横幅で切り取ると、10点円のうち9点だけが盤内に残る可能性があるため、3の倍数間隔の有限盤にこの結論を直接適用してはならない。

さらに `3|d` の10点円が存在すると仮定すると、5行の整数二根差 `a_i` は全て同じ3進付値 `v₃(a_i)=e` を持ち、必ず `e<v₃(d)` である。実際、法3の平方剰余等差数列は「全部0」または「全部1」しかなく、前者なら全差を3で割り、後者なら付値0で停止する。`e≥v₃(d)` なら割り切った時点で3と互いに素な間隔に到達して矛盾する。これは**必要条件**であり、10点円の存在を証明したものではない。

## 独立検証と限界

付属の `verify_spaced_five_rows.py` は (1) 正規化した法9の16初期組と直接の法9平方差分を独立照合し、(2) 等間隔 `d=1,2,3,4,5,6,7,8,9,12` の有限盤で三点行列式による円の完全列挙を実行する。3の倍数でない間隔は8点以下、3の倍数の間隔は9点ちょうどの円がないことを照合する。計算結果は同梱の出力を参照。全称定理の根拠は有限盤の列挙ではなく法9の全剰余証明。

`3|d` の**10点円**の存在・不存在、任意間隔の五行、標準盤の6行以上への一般化は本定理では決めない。K0072の標準連続行の法9分離と、未統合の5行q9証明を**等間隔の非3倍数へ拡張**する結果である。
