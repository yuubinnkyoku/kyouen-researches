# 標準整数円の二重点行数 T(w)：64〜190行の厳密値

2026-10-09。数学的帰納法＋必要合同条件の有限完全排除。新規範囲は148〜190行（43幅）。

## 結論

連続する整数水平行 y=0,...,w-1 に対し、一本の実円が異なる整数格子点を2点ずつ持つ行の最大本数を T(w) とする。x座標は全整数を許す。

| 幅 w | 厳密値 T(w) |
|---|---:|
| 64〜82 | 16 |
| 83〜86 | 17 |
| 87〜93 | 18 |
| 94〜95 | 19 |
| 96〜99 | 20 |
| 100 | 21 |
| 101〜104 | 22 |
| 105 | 23 |
| **106〜190** | **24** |

外部の帰納基底は既存正本 K0369 の T(63)=16 だけ。64〜147行の先行成果（main未統合）を本検証器で再現し、148〜190行まで厳密値を延長した。特に T(190)=24 である。191行以降と最初に25本が実現する幅は未確定。

## 下界

次の3円について、各行の二根判別式が正の奇数平方数であることと、二つの整数根の円への直接代入を検証した。

- x²+y²+x−47y=0
- x²+y²+x−105y−6=0
- x²+y²+x−95y−506=0

3円から得られる下界が直前の幅より1増えるのは w=83,87,94,96,100,101,105,106。2番目の円は y=0,...,105 の24本に整数点を2点ずつ持つため、全 w≥106 で T(w)≥24。

## 全称上界

単調性 T(w−1)≤T(w)≤T(w−1)+1 は任意の円について明らか。T(w−1)=t を仮定し、幅 w で t+1 本の二重点行を持つ円を仮定する。両端 y=0,w−1 のどちらかが二重点行でなければ、残る w−1 行で t+1 本を実現して帰納仮定に反する。よって両端必須。

円 x²+y²+Bx+Cy+D=0 の行0の整数根の和・積より B,D∈Z。各二重点行 i の整数根の積から i²+Ci+D∈Z なので、行番号差の最大公約数 g に対し gC∈Z。両端必須と t+1 本の行から

    g | (w−1),     1 ≤ g ≤ floor((w−1)/t).

行番号を i=gk、a=gC∈Z、u=2x+B とすれば

    u² = B²−4D−4g²k²−4ak.

任意の奇数法 p で gcd(g,p)=1 なら、ある c,n (mod p) について

    n−(2gk+c)² が平方剰余（0を含む）

が必要。実際、c=a/g、n=B²−4D+a²/g² と法 p で定めれば上式は u² に一致する。法ごとの c,n を独立に選ばせるのは緩和であり、すべての実円を含む必要条件を保存する。

各 g と各法 p に対し、p² 通りの c,n の全組を走査して k=0,...,(w−1)/g の許容マスクを構成。両端必須かつ t+1 本以上のマスクのみを保持し、法を追加するたび共通部分を取る。すべての g で残存マスクが0となれば矛盾、T(w)≤t が全称的に従う。下界が t+1 に増える幅では単調性だけで上界が確定する。これを T(63)=16 から帰納した。

この列挙は円の半径・中心・係数を有限範囲に制限したものではない。

## 再現と独立検証

`research/experiments/fixed-width/scripts/verify_double_rows_64_190.cpp` は C++20 の整数ビット集合による有限完全排除器。法は 9,11,7,49,19,23,31,37,41,43,47,53 の部分集合で、幅ごとに計算効率のため順序を変更する。g と非互いに素な法は使用しない。

同一ソースに二種類の独立したマスク生成法を実装した。通常版は「行・許容 n を転置して蓄積」、`-DDIRECT_RESIDUES` 版は「c,n ごとに全行を直接判定」。両方式の全出力がバイト単位で一致した。

    g++ -O3 -std=c++20 research/experiments/fixed-width/scripts/verify_double_rows_64_190.cpp -o /tmp/rows_a
    g++ -O3 -std=c++20 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_double_rows_64_190.cpp -o /tmp/rows_b
    for range in '64 95' '96 128' '129 147' '148 170' '171 175' '176 180' '181 185' '186 190'; do
      set -- $range
      /tmp/rows_a "$1" "$2" > /tmp/a.txt
      /tmp/rows_b "$1" "$2" > /tmp/b.txt
      cmp /tmp/a.txt /tmp/b.txt
      tail -1 /tmp/a.txt
    done

8区間の全実行で末尾 `PASS a..b`、不一致0。監査ログは `audit/transposed-*.txt`, `audit/direct-*.txt` に保存。さらに171〜177行の73段階はPython第三実装で一致した。先行64〜128行の別Python/C++実装も同じ厳密値を返す。

この検証器は最大190行に対して192ビットの固定配列を用いる。幅191以上に拡張するときはビット幅・法選択・性能を再評価すること。分割実行は各区間の直前幅までの帰納結論を前提とするため、**全区間を順に成功させること**が必要。

## ゲームへの帰結

一本の円が190行に持つ整数格子点は高々190+24=214個、非水平直線は高々190個。従って標準190×m・q点版で q≥215 なら、任意の m≥1・任意の安全局面 S に対して

    g(S) = (190 min(m,q−1) − |S|) mod 2,
    M_(190,q) = q−1.

各行の q−1 個までの独立な容量ゲームへ帰着するため、後者の安定化長は十分条件でなく厳密な最小値である。q=214 以下で行独立が破れるという逆方向の主張は含まない。
