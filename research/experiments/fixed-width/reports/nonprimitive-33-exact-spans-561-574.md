# 非原始二重点行33本：最小幅候補561〜574の厳密排除

2026-10-10。対象は全実円、整数格子の連続水平行、横座標無制限。二重点行とは、同じ円が相異なる2個の整数格子点を持つ水平行をいう。選択した33行の行番号差の最大公約数を `g>=2` とする。

## 新しい結果と先行成果との境界

**新しい全称結果**：幅 `W=561,...,574` のどの値も、33本の二重点行を持ち、選択行の最小・最大行差がちょうど `W-1`、かつその行差の gcd が2以上、という円は存在しない。各幅の合同必要条件を完全排除した計算機援用証明である。

先行する未統合の `F(33)>=561`（幅560以下の排除）と接続すれば、`F(33)>=575`。先行の幅743の明示円と合わせて、**条件付きで** `575<=F(33)<=743`。本実験は幅560以下を再検査していないため、これを単独で `F(33)>=575` の無条件証明と呼ばない。

## 端点を使う帰着

幅Wの実現があるなら、選択した最小行を0に平行移動したとき最大行はW−1である。選択行差の gcd g は W−1 を割り、`2<=g<=floor((W-1)/32)`。よって `y=gi`、`0<=i<=h-1`、`h=(W-1)/g+1` と書け、**両端 i=0,h−1 が必須**。幅の上限だけでなく、最小幅の各候補を調べることにより探索対象が大きく減る。

円 `x²+y²+Bx+Cy+D=0` が選択行で2整数点を持つとき、`y=0` のVietaから `B,D` は整数、`gcd(i)=1` から `a=gC` は整数。gと互いに素な法pに対し、ある剰余 `c,n` が存在して、全選択iで `n−(2gi+c)²` は0を含む平方剰余 `QR(p)` となる。法ごとに `c,n` を自由に選ぶ緩和は真の円を排除しない。

各gについて、法 `9,11,7,49,19,31,23,43,47,37,41,53,59` のうち `gcd(g,p)=1` を順に用いる。全 `p²` 組の `(c,n)` で得られる許容iマスクと現存マスクを交差させ、33行未満またはどちらかの端点を欠くものを捨てる。最後に全gで候補が空になる。gが条件を満たさない幅（例：W=564,570,572）は法検査すら不要である。

## 実行・独立性

`research/experiments/fixed-width/scripts/verify_nonprimitive_33_exact_span.cpp` は幅640までのビットマスクを扱う。`-DDIRECT_RESIDUES` は平方剰余マスクの構築を異なるループ順・手法に切り替える。両方式でW=561..574の全ログがバイト単位で一致し、全幅がPASSとなった。これは**合同必要条件の完全列挙**の独立二方式照合であって、形式証明器による完全独立検証ではない。

```sh
c++ -std=c++20 -O3 research/experiments/fixed-width/scripts/verify_nonprimitive_33_exact_span.cpp -o /tmp/f33-exact-a
c++ -std=c++20 -O3 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_nonprimitive_33_exact_span.cpp -o /tmp/f33-exact-b
for w in $(seq 561 574); do
  /tmp/f33-exact-a "$w" 33 > "/tmp/f33-a-$w.log"
  /tmp/f33-exact-b "$w" 33 > "/tmp/f33-b-$w.log"
  diff -u "/tmp/f33-a-$w.log" "/tmp/f33-b-$w.log"
done
```
