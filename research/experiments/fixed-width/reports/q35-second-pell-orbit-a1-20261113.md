# 3×m のちょうど5点円：弦幅1の独立Pell族（2026-11-13）

**証拠水準：全称証明。** 既存の `q35-five-circle-diophantine-first-width-20261112.md` の必要十分条件を利用する。先行する `q35-five-circle-pell-unbounded-excess-20261113.md` の `a=3` 族とは弦幅が異なる。

## 定理

`F_5(m)` を3×m整数盤でちょうど5点を通る円の本数とする。`(b_0,k_0)=(15,21)` および
`(b_{j+1},k_{j+1})=(3b_j+2k_j,4b_j+3k_j)` と置き、
`N_j=(b_j+k_j)/2+1` とする。先行する `a=3` 族の初出幅を `M_j` とすれば、全 `m≥9` について

```
F_5(m) ≥ 2(m−8) + 4 #{j≥0:M_j≤m} + 4 #{j≥0:N_j≤m}.
```

特に新族は `m=19` で初めて4本を寄与し、その後 `N_j=19,107,620,3609,...` で各4本が新たに現れる。

## 証明

三行の二点弦幅を `a=1,b=b_j`、残り一行の二交点の距離を `k=k_j` とする。整数円の条件は `a²+k²+8=2b²` と三者同偶奇である。初項は `1+21²+8=2·15²` を満たす。漸化式は `k²−2b²=−9` を保存し、正の奇数性と `k>b>a` を保存する。よってすべての項が先行の片側切断型の必要十分条件を満たす。

この型の最小盤幅は `(b+k)/2+1`。長い弦の左右端と残り行の片方の交点を盤に収める位置は2通りあり、上下反転でさらに2通り、合計4本である。反転で一致しないのは `k>b` のため。異なる `j` では `b_j` が厳密増加し、先行 `a=3` 族とは短い弦幅 `a` が異なるため、相互に円は重複しない。先行接線型の `2(m−8)` 本とも行別の弦数が異なり重複しない。以上を加算して主張を得る。

## 初出例と独立な整数検算

`m=19` では次の5点が同一円上にある：

```
(7,0),(8,0),(0,1),(15,1),(18,2).
```

円の方程式は `x²+y²−15x−(223/2)y+56=0` ではなく、正しくは下記の整数係数式を用いる。上段の中心は `x=15/2`、上段の半弦幅は `1/2`、中央段は `15/2`、下段の2交点は `−3,18`。三行の二次関数 `r_y²=R²−(y−v)²` により `r_0²=1/4,r_1²=225/4,r_2²=441/4` である。二階差分は `−2` となるべきだが、これらは `1/4−2(225/4)+441/4=−2` を満たす。したがって円は
```
4x²+4y²−60x−224y+224=0
```
であり、盤内の整数解は上記5点のみ（各水平行との交点を直接確認）。

再現用の厳密整数検査：

```python
b,k=15,21
for j in range(4):
    assert 1+k*k+8==2*b*b and k>b>1 and b%2==k%2==1
    print(j,b,k,(b+k)//2+1)
    b,k=3*b+2*k,4*b+3*k
points=[(7,0),(8,0),(0,1),(15,1),(18,2)]
def eq(x,y): return 4*x*x+4*y*y-60*x-224*y+224
assert all(eq(*p)==0 for p in points)
assert {(x,y) for x in range(19) for y in range(3) if eq(x,y)==0}==set(points)
```

## 限界

新しいのは `a=3` とは異なる `a=1` の無限族と、両族を同時に数える明示下界である。これは全5点円の漸近的な正確な本数やゲーム勝敗を決めない。研究規約に従うknowledge昇格・生成索引更新・全回帰検査は別途必要。
