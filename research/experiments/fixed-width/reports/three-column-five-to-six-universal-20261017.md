# 三列格子の「5点円なら別の6点円」全称定理（2026-10-17）

## 結論と量化範囲

正整数 `a,b,d` に対し、無限三列格子

`G(a,b;d) = {(x,dj) : x in {0,a,a+b}, j in Z}`

を考える。**5点以上の格子点を通る円が一つでもあれば、6点の格子点を通る円が無限個存在する。** 従って一本の円が通る最大格子点数 `P(a,b;d)` は **4または6** であり、5にはならない。後者の円は元の5点円と同じとは限らない。

これは `d` が素数冪であるという仮定を使わない。`d² gcd(a,b) | ab(a+b)` が6点円の存在に十分かどうかは、一般の合成数 `d` についてこの定理だけでは決まらない。

## 証明

1. 一本の円が格子点5個を通るとき、三列の点数分布は `2,2,1` である（6個なら結論済み）。二点を含む列の二点の縦座標和は、円中心の縦座標の2倍であり、両列で同じ `dT`（整数 `T`）である。残りの列の一点 `(x,dj)` を円中心の高さで反射すると `(x,d(T-j))` となり、これも格子点である。反射点が異なれば同じ円に6点ある。反射点が一致する場合は接線であり、円中心の高さは `dj` なので、縦方向に平行移動して中心を0にできる。この場合、各列の交点の高さは `±d t_i`（`t_i` は整数）で、ちょうど一つの `t_i=0`、他の二つは非零である。

2. `c=a+b` とし、整数三つ組 `t=(t_0,t_1,t_2)` に対して

   `Q(t)=b t_0² - c t_1² + a t_2²`

   と定義する。各列の二点 `(0,±dt_0),(a,±dt_1),(c,±dt_2)` が同一円上にあるための必要十分条件は

   `d² Q(t) = -abc`

   である。これは円の方程式 `x²+y²+Ux+W=0` に三列を代入して `U,W` を消去すれば得られる。`t_i=0` の場合はその列の接点一個を意味する。

3. 対称双線形形式を `⟨u,v⟩=b u_0v_0-c u_1v_1+a u_2v_2` とする。`e=(1,1,1)`, `f=(a,0,-b)` について

   `Q(e)=0`, `⟨e,f⟩=0`, `Q(f)=abc`。

   `L=⟨t,e⟩`, `N=⟨t,f⟩` と置き、任意の整数 `n` に対して

   `t(n)=t+2n L f-(2n N+2n²abc L)e`

   と定める。展開すると `Q(t(n))=Q(t)` が**恒等的に**成立し、`t(n)` は整数三つ組である。

4. `Q(t)=-abc/d²<0` なので `L,N` が同時に0になることはない。実際、両方0なら `t` は `e,f` の直交補空間にあり、その空間は `e` の張る一次元空間だから `Q(t)=0` となり矛盾する。`L≠0` なら `t(n)` の各成分は共通の非零二次係数 `-2abcL` を持つ二次多項式、`L=0` なら `N≠0` で各成分は非零一次係数 `-2N` を持つ一次多項式である。従って三成分が0になる整数 `n` は合計高々6個であり、`n=1,...,7` のどれかで**全成分非零**になる。これを2の必要十分条件に戻せば、各列二点ずつ計6点を通る円を得る。

5. `|n|` を無限大にすると `|t_0(n)|` は無限大になるので、得られる6点円は無限個互いに異なる。

二列に同じ二つの高さを選べば必ず長方形の4点円ができ、どの円も三列から最大6点しか取れない。以上から `P(a,b;d)∈{4,6}`。

## 明示例

`a=b=d=1` では `x²+y²-10x=0` は `(0,0),(1,±3),(2,±4)` の5点を通る。接線列を `t=(0,3,4)` として上記の変換に `n=1` を代入すると `t(1)=(12,19,24)` となる。円 `x²+y²-218x-144=0` は `(0,±12),(1,±19),(2,±24)` の6点を通る。

## 独立検算と限界

`research/experiments/fixed-width/scripts/three_column_five_to_six_verify.py` は、変換の二次形式不変性1260例を整数演算で検査し、`1≤a,b≤8`, `1≤d≤6` の範囲で見つけた94個の接線5点円それぞれから6点円を構成した。別実装の三点円決定（有理数での連立一次方程式）で、得られた六点すべてが同一円上にあることを検証した。94例の最初の成功は `n≤2` だったが、**一般に保証するのは `n≤7`** である。

有限検算は全称証明とは独立した実装監査である。既存の素数冪間隔の必要十分条件を合成数全般に拡張したとは主張しない。通常の `3×m, q=5` の真の安定化長に関する K0071 とも別の、無限異方格子の幾何命題である。
