# 四行8点円は、局所型を除いて必ず無限Pell族へ延長できる

2026-10-15。基準：`main` `e0156f283f1cbe500c43bd9845e562ee0acfb464`。**数学的全称証明**。有限監査は独立の支持資料であり、証明の代替ではない。

## 定理（非局所8点円の無限延長）

標準整数格子の四連続行 `y=0,1,2,3` の各行を異なる整数格子点2個ずつで通る任意の円を考える。弦長が `(1,3,3,1)` である局所型を除けば、その円と同じ既約傾き `A/B`（以下で定義）を持つ、互いに異なる8点円が無限に存在する。弦長・最小必要盤長は無限に増加する。

これは「既知の数族が無限」という K0317 の既存主張を強める。**任意の非局所円が無限族に属する**。すべての族を有限個に分類したという主張ではない。

## 1. 正規形（既存の2026-10-15の統合前報告からの代数的帰着）

円の4本の正の水平弦長はすべて奇数であり、二階差分

```
a² - 2b² + c² = -8,   b² - 2c² + d² = -8
```

を満たす。局所型以外では上下反転により `0<a<b<c<d` としてよい。`s=(d+a)/2, t=(d-a)/2, u=(c+b)/2, v=(c-b)/2` と置くと `st=3uv`。`s/v=A/B` を既約正整数比にすれば、`g=gcd(A,3)` と正整数 `L,M` が一意に存在し

```
a = A L - (3B/g) M,
b = (A/g) M - B L,
c = (A/g) M + B L,
d = A L + (3B/g) M,
P = A²-B²,  Q = (A²-9B²)/g²,
Q M² - P L² = 8.
```

`A>3B>=3` で `P,Q` は正整数。特に `A>=3B+1` より

```
P=A²-B² >= 8B²+6B+1 >= 15.
```

逆に、この形の4数が正の奇数で厳密増加し、ノルム方程式を満たせば二階差分がともに `-8` となり、四行8点円を構成する。

## 2. 新補題：ノルム8の正整数解では判別式が平方にならない

**補題（一般形）**。正整数 `P,Q,L,M` が `QM²-PL²=8` を満たし、`P>=2` なら `PQ` は完全平方数ではない。さらに `PQ` が平方になる正整数解は、

```
(P,Q,L,M)=(1,1,1,3) または (1,9,1,1)
```

の二つに限られる。

**証明**。`PQ` が平方数なら、同一の平方因子を除いた共通の平方自由整数 `p` と正整数 `r,s` があり、`P=p r²`, `Q=p s²` と書ける。ノルム式は

```
p(sM-rL)(sM+rL)=8.
```

従って `p` は8の平方自由な正約数で `p=1` または `p=2`。`x=sM-rL>0`, `y=sM+rL>x` は同じ偶奇の正整数で `xy=8/p`。

- `p=1` では `xy=8` の同偶奇かつ `x<y` の組は `(x,y)=(2,4)` のみ。ゆえに `sM=3`, `rL=1`、特に `r=L=1`, `P=1`。`sM=3` から `(s,M)=(1,3),(3,1)` のみ。
- `p=2` では `xy=4` の同偶奇かつ `x<y` の組は存在しない（`(2,2)` は `rL=0` となる）。

よって補題が従う。四行8点円では `P>=15` なので、**`D=PQ` は例外なく非平方数**。□

## 3. すべての非局所円から無限個を構成

`D=PQ` は正の非平方整数だから、通常のPell方程式 `U₀²-D V₀²=1` に `U₀>1,V₀>0` の整数解がある。その解を二乗して

```
U=U₀²+D V₀² = 2U₀²-1 (奇数),
V=2U₀ V₀ (偶数),
U²-D V²=1.
```

とする。初期の `(L,M)` から

```
L' = U L + Q V M,
M' = U M + P V L
```

を繰り返すと、直接展開で `Q(M')²-P(L')²=8`。係数は整数で `L',M'>0`、`L'>L`。`U` が奇数、`V` が偶数なので `L,M` の偶奇はそれぞれ保存され、4弦長の奇数性も保存される。

残るのは正値・厳密増加性。`z=M/L` と置くとノルム式から

```
z² = P/Q + 8/(Q L²).
```

従って反復で `z` は真に減少し、下限 `z₀=sqrt(P/Q)` より大きい。`a/L=A-(3B/g)z` は増加するので初期 `a>0` を保存。`(d-c)/L=(A-B)-((A-3B)/g)z` も増加するので初期 `d>c` を保存。`c-b=2BL>0` は自明。

一見問題になるのは `b-a` で、これは `z` とともに減少する。しかし

```
(b-a)/L = ((A+3B)/g)z-(A+B)
          > ((A+3B)/g)sqrt(P/Q)-(A+B) > 0.
```

最後の不等式は `P=A²-B²`, `g²Q=A²-9B²` を代入し、正の両辺を二乗すれば

```
(A-B)(A+3B) > (A+B)(A-3B)
```

すなわち `4AB>0` と同値。ゆえにすべての反復で `0<a'<b'<c'<d'`。

各反復の4弦長は奇数で、二階差分は `-8`。最大弦長を `d` として行 `y=i` に `( (d±d_i)/2, i )` を置けば8個の異なる整数点が同一円上にある。`d=A L+(3B/g)M` は反復ごとに増大して無限大に発散するので、得られる円は無限個で互いに異なる。元の円が厳密減少型なら上下反転して同じ構成を行い、最後に反転し直す。□
