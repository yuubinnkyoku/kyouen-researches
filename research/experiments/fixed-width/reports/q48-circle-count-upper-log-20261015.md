# 4行8点円数の上界を O(m² log m) に改善

2026-10-15。対象は標準整数格子の4連続行（y=0,1,2,3）・m列の盤に各行2点ずつを持つ8点円。水平移動で異なる8点集合は別々に数える。**証拠：無界の数学的証明**。有限監査は独立に扱う。

## 定理

8点円の総数 C8(m) は全ての整数 m≥1 で

```
C8(m) ≤ 162 m (m+1) (1+floor(log2(m+1)))
```

を満たす。特に C8(m)=O(m² log m)。従来の未統合の粗い上界 O(m²(log m)³) を対数2因子だけ改善する。真の増加次数は未解決。

## 証明

円と4本の水平線との交点の二根和は同じ整数 S。正の水平弦長を a,b,c,d とすれば、弦長平方は行番号の二次式（最高次係数 −4）なので

```
a²−2b²+c²=−8,   b²−2c²+d²=−8.
```

全弦長は S と同じ偶奇。偶数なら a=2a', b=2b', c=2c', d=2d' とおく。第一式を4で割り法8で見ると、平方剰余 0,1,4 から b' は奇数、a',c' は偶数でなければならない。第二式は d'²≡5 (mod 8) を要求して矛盾する。従って a,b,c,d は全て奇数であり b≥3。

第一式から a²+c²=2(b−2)(b+2)。奇数 b では gcd(b−2,b+2)=1。
r₂(n)=#{(x,y)∈Z²:x²+y²=n} とする。二平方和表示公式 r₂(n)=4Σ_{e|n}χ₄(e) により f(n)=r₂(n)/4 は乗法的で、奇数 n には f(2n)=f(n)。従って

```
r₂(2(b²−4)) = r₂(b−2) r₂(b+2)/4.
```

b,a,c が決まれば第二式から d>0 は高々1個。最大弦長 <m の型数 T(m) は

```
T(m) ≤ (1/4) Σ_{3≤b<m, b odd} r₂(b−2)r₂(b+2)
     ≤ (1/4) Σ_{1≤n≤m+1} r₂(n)².
```

最後は Cauchy–Schwarz。不変な二根和 S から各型の横移動は高々 m 通りなので C8(m)≤m T(m)。

二乗平均 M₂(X)=Σ_{n≤X}r₂(n)² を評価する。これは非零ガウス整数 z,w∈Z[i] で N(z)=N(w)≤X を満たす順序対の数である。Z[i] はユークリッド整域。g=gcd(z,w)、z=gα、w=gβ と書けば gcd(α,β)=1、N(α)=N(β)。αは β·conj(β) を割るから互いに素性より α|conj(β)。ノルムが等しいため conj(β)=uα（u∈{±1,±i}）。よって全対数は g,α,u の数で上から抑えられる。

Y≥1 の円盤内の非零ガウス整数は高々 (2√Y+1)²≤9Y 個なので

```
M₂(X) ≤ 36 X Σ_{0<N(g)≤X} 1/N(g).
```

各殻 2^j≤N(g)<2^(j+1) の点数は高々 9·2^(j+1)、各点の逆ノルムは 2^(−j) 以下。殻ごとの寄与は高々18で、j=0,...,floor(log₂ X) を足せば

```
M₂(X) ≤ 648 X (1+floor(log₂ X)).
```

X=m+1 として C8(m)≤mM₂(m+1)/4 を代入し定理を得る。□
