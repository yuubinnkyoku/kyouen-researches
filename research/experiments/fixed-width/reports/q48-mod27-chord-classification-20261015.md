# 4行8点円の法27弦長分類と300万までの有限監査

作成: 2026-10-15。標準4行 `y=0,1,2,3`、各行で相異なる整数横座標2点を通る円を対象とする。これは全盤長の**必要合同条件**と、有限範囲の**完全列挙**を区別した報告である。

## 定理（無界・数学的証明）

各行の正の水平弦長を `d0,d1,d2,d3` とすると、**すべての**そのような円について

```
(d0²,d1²,d2²,d3²) mod 27 ∈ {
  (1,9,9,1), (10,9,0,10), (10,0,9,10), (19,0,0,19)
}.
```

特に `d0²≡d3² (mod 27)`、中央2弦長はともに3の倍数であり、中央2弦長がともに9の倍数なら必ず `(19,0,0,19)` 型となる。上の4型がいずれも実際の整数円に現れるとは主張しない。

### 証明

円を `x²+y²+Bx+Cy+D=0` と書く。各行の二つの整数根の和・積から `B,C,D` は整数であり、

```
d_i² = N-(C+2i)²,   N=B²+C²-4D.
```

既証明の法9剛性より `(d0²,d1²,d2²,d3²)≡(1,0,0,1) (mod 9)`、かつ `C≡6 (mod 9)` である（`q48-four-row-mod9-rigidity-20261015.md`）。差の式

```
d3²-d0² = -12(C+3)
```

は右辺が108の倍数であるから、`d0²≡d3² (mod 27)`。平方剰余を法27で調べると、法9で1の平方剰余は `1,10,19`、法9で0の平方剰余は `0,9` だけである。そこで

```
d0²≡d3²≡1+9α,  d1²≡9β,  d2²≡9γ  (mod 27)
α∈{0,1,2}, β,γ∈{0,1}.
```

4行の弦長平方の二階差分は厳密に `-8`。したがって

```
d0²-2d1²+d2² = -8
α-2β+γ ≡ 2 (mod 3).
```

`(β,γ)=(1,1),(1,0),(0,1),(0,0)` に対して `α=0,1,1,2` が一意に決まり、表示した4型を得る。盤長に関する仮定はない。□

## 独立監査

`q48_mod27_chord_audit_20261015.py` は上の証明とは別に、(1) 円の `C,N` の全 `27²=729` 剰余組、(2) `d0,d1` の全 `27²=729` 剰余組を別々に完全列挙し、いずれも同じ4型となることを検証する。さらに小さい弦長上限73,150,300では、合同篩を使わない全整数対探索で既知の3型を復元する。

## 追加の有限完全列挙（無界定理ではない）

`q48_mod27_circle_census_20261015.cpp` は `M=12096=2^6·3^3·7` の平方剰余篩で `1≤d0,d1≤B` を漏れなく列挙し、残りの `d2,d3` が正の整数平方根で `≤B` かを厳密に判定する。実測値:

```
B=1,000,000: 7型、篩候補 2,519,531,872、所要 3.76秒（篩準備除く）
B=2,000,000: 11型、篩候補 10,078,148,652、所要 15.05秒
B=3,000,000: 11型、篩候補 22,675,723,356、所要 35.10秒
```

従って、**弦長最大3,000,000以下の型は既知11型だけ**であり、対応する全8点円は盤長 `m≤3,000,001` で新型を持たない。列数上限は「円の横幅 `max(d_i)` +1」による。この結論は有限完全列挙であり、全盤長には延長しない。

独立した `(d1,d2)` 対列挙器 `q48_bc_independent_20261015.cpp` は `B=2,500,000` まで11型で一致した。`B=3,000,000` の結果は現時点で単独完全列挙に依存する。元の `M=4032` 篩との `B=1,000,000` での結果一致も確認した。

既存 `M=4032` 篩との100万上限の同一環境比較では、`M=4032` の走査時間5.82秒に対し `M=12096` は3.76秒（約1.55倍）。前処理はそれぞれ0.02秒と0.16秒。これは**特定機材の計測値**であり、一般の速度保証ではない。法11を後段に追加すると候補は減るが、この環境では剰余計算の費用でかえって遅くなった。

### 残る問い

法27の第4型 `(19,0,0,19)` は少なくとも300万の弦長まで現れなかったが、全称的に不可能か、さらに大きい弦長で初出するかは未確定。既知の Pell 族 `(19+6√10)^n` は `n mod 3` に応じて残る3型を周期的に通り、第4型は出さない（Pell再帰の法27周期から従う）。別の円族が必要となる可能性がある。
