# 3×m・q=5：中央行が1点の五点円の最小幅

## 結論（整数論による全称帰着＋有限小表）

標準格子 `{0,...,m-1}×{0,1,2}` で、下段と上段に各2点、中央段に1点を含む円が存在する最小の `m` は **25** である。これは5点以上の円の一部の型についての幾何学的主張であり、ゲームの安定化長を変更しない。

## 証明

上下段の2点は同じ円上にあるため、両弦の横方向の中点は円中心の横座標 `c` に一致する。弦の横幅を `a,b`（正整数）、中央段の点の横座標を `c+t` とする。各段で円との交点の横方向の半弦長の二乗は、縦座標について二次式 `R²-(y-y₀)²` なので

`t² = (a²+b²)/8 + 1`, すなわち `8t²=a²+b²+8`。

上下の弦端は整数なので `a,b` は同じ偶奇であり、`2c` は整数。両方奇数なら `a²+b²+8≡2 (mod 8)` だが `t` は半整数であり、`8t²≡2 (mod 8)` も可能である。そこで奇数の場合は `t=k+1/2` と書くと `8t²=8k(k+1)+2`。これを等式に代入すると `a²+b²=8k(k+1)-6` となるが左辺は `2 (mod 8)`、右辺は `2 (mod 8)` で矛盾しない。**奇数弦も除外せず**、以下の有限完全検査で扱う。

幅 `m≤24` なら `1≤a,b≤23`。中央点も整数であることは `t` と `c` の小数部分が一致することと同値。したがって `a,b` 同偶奇、`8t²=a²+b²+8`、`t=(2z-a)/2`（整数 `z`）を全探索すれば十分である。さらに配置を平行移動して全点が幅 `m` に収まる必要がある。以下の独立した整数列挙は、`a,b≤23` について解がないことを確認する。

```python
from math import isqrt
def witnesses(max_gap):
    out = []
    for a in range(1, max_gap + 1):
        for b in range(1, max_gap + 1):
            if (a-b) % 2: continue
            # t=(2z-a)/2; 2z-a has same parity as a
            n = a*a+b*b+8
            if n % 2: continue
            k2 = n//2  # (2t)^2 = (a²+b²+8)/2
            k = isqrt(k2)
            if k*k != k2 or (k-a)%2: continue
            for s in (-1,1):
                # all coordinates doubled, with c=0
                xs = (-a,a,-b,b,s*k)
                span = (max(xs)-min(xs))//2+1
                if (max(xs)-min(xs))%2: raise AssertionError
                out.append((span,a,b,s*k,xs))
    return sorted(out)
assert not [w for w in witnesses(23) if w[0] <= 24]
print(witnesses(24)[:4])
```

実際の証人は上下の弦が `(8,16)` と `(0,24)`、中央の点が `(21,1)`。五点 `(8,0),(16,0),(21,1),(0,2),(24,2)` は同一円上にある。円中心は `(12,37)` ではなく、上下の半弦長二乗が16と144なので `y₀=33`、円の式は `(x-12)²+(y-33)²=1105`。中央点について `9²+32²=1105`、下段 `4²+33²=1105`、上段 `12²+31²=1105`。

## 証拠区分と限界

式の導出は全称的。最小性は `a,b≤23` の整数完全列挙による有限証明であり、上の短い検証器で再現可能。五点円の全種類・総数・Grundy値については何も主張しない。
