# 3×m の円：中央行だけ1点の「ちょうど5点円」は存在しない

## 定理（全称証明）

整数格子 `D(3,m)` の円が、上段と下段に各2点、中央段に少なくとも1点を持つなら、**中央段には必ず2点ある**。したがって行別点数 `(2,1,2)` の「ちょうど5点円」は、どの `m` にも存在しない。

注意：5点を選んだ組として `(2,1,2)` が共円になることはある。しかしその円には盤内に第6点もある。この定理は「円上の全格子点数がちょうど5」の分類であり、5点禁止組の不在を意味しない。

## 証明

上下段の2点はそれぞれ円の水平弦であり、共通の中点の横座標を `c`、弦幅を正整数 `a,b` とする。中央段の円との交点は `c±t` である。半弦長の二乗は縦座標 `y` に関して二次式 `R²-(y-y₀)²` だから

`t²=(a²+b²)/8+1`。

上下の整数端点から `a,b` は同じ偶奇であり、`2c` は整数である。中央段に整数点 `c+t` があれば、その反射点 `c-t=2c-(c+t)` も整数。

両弦幅が異なるとき、同じ偶奇の正整数なので、`max(a,b)²-min(a,b)²≥3²-1²=8`。従って

`t²=(a²+b²+8)/8≤max(a,b)²/4`。

ゆえに両方の中央交点は、長い方の弦の両端の間にある。長い方の弦の両端が盤内なら、中央の反射点も必ず盤内である。

両弦幅が等しい `a=b` の場合、`(2t)²=a²+4`。ここで `2t` は整数（`2c` と `c+t` が整数）なので、正整数 `a` に対して `(2t-a)(2t+a)=4`。両因子は同じ偶奇の正整数であるが、積4を満たす組 `(2,2)` は `a=0`、組 `(1,4)` は偶奇が異なる。矛盾。したがってこの場合、中央段に整数交点はない。

以上から、中央に1点あれば別の整数交点も盤内にあり、しかも `t>0` なので相異なる。証明終。

## 境界例と独立検算

最小の例 `m=4` では `(1,0),(2,0),(0,2),(3,2)` と中央段 `(0,1),(3,1)` が同一円上にある。円の式は `(x-3/2)²+(y-3/2)²=5/2`。中央の片方だけを選んだ五点組は確かに共円だが、円全体は6点を含む。

検算には各 `a,b=1,...,200` を走査し、`(2t)²=(a²+b²+8)/2` が整数平方である場合に `2t≤max(a,b)` を照合する。上の証明は任意の正整数 `a,b` に有効なので、この有限検算に依存しない。

```python
from math import isqrt
for a in range(1,201):
    for b in range(1,201):
        if (a-b)%2: continue
        n=a*a+b*b+8
        if n%2: continue
        k2=n//2
        k=isqrt(k2)
        if k*k==k2 and (k-a)%2==0:
            assert a!=b and k<=max(a,b)
print("OK")
```

## 研究上の位置付け

全称的な幾何補題。3×m・q=5 の円由来の禁止組生成では、上下段2点ずつを含む円の中央段整数交点を必ず対で扱える。円上の全点がちょうど5点の場合の行型は `(2,2,1)` または `(1,2,2)` に限られる（各行の円との交点数は高々2）。
