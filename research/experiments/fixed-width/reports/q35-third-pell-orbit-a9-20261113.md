# 3×m のちょうど5点円：弦幅9の第三のPell族（2026-11-13）

**証拠水準：全称証明＋整数による独立検算。** 既存の `q35-five-circle-diophantine-first-width-20261112.md` の必要十分条件を用いる。既知の弦幅3・1の二族と重複しない。

## 定理

`F_5(m)` を3×m整数盤のちょうど5点円の本数とする。`(b_0,k_0)=(15,19)`、
`(b_{j+1},k_{j+1})=(3b_j+2k_j,4b_j+3k_j)`、
`T_j=(b_j+k_j)/2+1` とする。既知の弦幅3・1の初出幅列をそれぞれ `M_j,N_j` とすると、すべての `m≥9` について

```
F_5(m) ≥ 2(m−8) + 4 #{j≥0:M_j≤m} + 4 #{j≥0:N_j≤m} + 4 #{j≥0:T_j≤m}.
```

第三族の初出幅は `18,101,584,3399,19806,...` であり、各初出時に少なくとも4本が追加される。

## 証明

二点弦幅を上段 `a=9`、中央段 `b=b_j` とし、下段の二交点の距離を `k=k_j` とする。初項は
`9²+19²+8=2·15²`、すなわち `k²−2b²=−89` を満たす。更新行列は `k²−2b²` を保存し、正の奇数性および `k>b>9` を保存する。したがって全項は既存の片側切断型の必要十分条件を満たす。

`W=b` なので最小盤幅は `T_j=(b_j+k_j)/2+1`。その幅で右交点だけを収める配置と左交点だけを収める配置が各1本、上下反転で計4本である。各 `j` で `b_j` は厳密増加し、他の二族とは上段の弦幅 `a=9,3,1` が異なる。接線型とも異なるので、全て重複なく下界に加算できる。

## 独立検算

最初の円は `m=18` の5点
`(3,0),(12,0),(0,1),(15,1),(17,2)` を通る。円の方程式は
`4x²+4y²−60x−148y+144=0` で、下段のもう一方の交点 `(-2,2)` は盤外にある。

```python
b,k=15,19
for expected in [18,101,584,3399,19806]:
    assert 9*9+k*k+8==2*b*b
    assert b%2==k%2==1 and k>b>9
    assert (b+k)//2+1==expected
    b,k=3*b+2*k,4*b+3*k
pts={(3,0),(12,0),(0,1),(15,1),(17,2)}
def eq(x,y): return 4*x*x+4*y*y-60*x-148*y+144
assert {(x,y) for x in range(18) for y in range(3) if eq(x,y)==0}==pts
```

## 限界

これは第三の明示的無限部分族による下界改善であり、全円数の正確な公式やゲームの勝敗を決定するものではない。一般の整数解をすべて分類したわけでもない。
