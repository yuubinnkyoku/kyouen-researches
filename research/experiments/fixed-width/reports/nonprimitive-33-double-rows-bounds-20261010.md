# 非原始二重点行33本の初出幅：厳密下界561と構成上界743

2026-10-10。一本の実円が整数格子点を2個ずつ持つ水平行から33本を選び、その行番号差の最大公約数が2以上となる最小連続行幅を `F(33)` とする。横座標には上限を設けない。

## 結論と証拠区分

\[
\boxed{561\le F(33)\le743}.
\]

**下界は全実円を対象とする合同必要条件の有限完全排除による計算機援用証明**、上界は**明示円の厳密な整数点構成**である。`F(33)=743` は主張しない。先行する未統合の `F(2)..F(32)` や `T(64)..T(336)` の結果に依存しない。

## 下界：560行以下では不可能

選択された最小行を `y=0` に平行移動し、選択行番号差の最大公約数を `g≥2` とする。選択行は `y=gi` で、`i=0` を含み、全て `0≤i≤floor(559/g)` を満たす。`g≤floor(559/32)=17`。最大行が窓の右端にあるとは仮定しない。

円を `x²+y²+Bx+Cy+D=0` とする。`y=0` 上の二つの相異なる整数根から、Vieta により `B,D∈Z`。各選択行 `y=gi` の二つの整数根の積から `giC∈Z` である。選択された `i` の gcd は1なので、Bézout により `a=gC∈Z`。

`gcd(p,g)=1` の奇数法 `p` で `c≡a/g (mod p)`、`n≡B²−4D+c² (mod p)` と置くと、選択行の水平弦長の判別式から

\[
\boxed{n-(2gi+c)^2\in QR(p)}
\]

が必要。`QR(p)` は0を含む平方剰余集合。法ごとに `c,n` を独立に選ぶのは真の必要条件を**緩める**ので、真の円を誤排除しない。

各 `g=2,...,17` に対して、`p=(9,11,7,49,19,31,23,43,47,37,41,53,59)` のうち `gcd(p,g)=1` のものを順に使う。全 `p²` 組の `(c,n)` から許容 `i` のビットマスクを作り、現存マスクと共通部分を取り、33行未満を捨てる。全16通りの `g` で候補が空になった（**計44段階**）。したがって、無限にある円係数を有限に切り詰めることなく、560行以下での実現を排除できた。

検証器：`research/experiments/fixed-width/scripts/verify_nonprimitive_33_rows_560.cpp`。平方剰余マスクを「`c` ごとに `n` 全体へ転置生成」する方法と、`-DDIRECT_RESIDUES` による「`(c,n)` 直接生成」の**二つのC++実行が44段階すべて一致**した。ログ：`research/experiments/fixed-width/output/nonprimitive_33_rows_560_audit.log`、SHA-256 `1d8fc32eb2f804c338be076edd807454d86d7459332fc88b3c6a094492f12a0f`。マスク交差の実装は共通であり、完全独立な形式証明器ではない。

## 上界：幅743の円

\[
\boxed{x^2+y^2=143650}
\]

は、`-379≤y≤363` の33本の水平行で二つの相異なる整数点を持つ。行番号は

```
-379 -377 -375 -363 -351 -333 -325 -305 -269 -267 -225
-195 -181 -143 -109 -55 -39 -3 3 39 55 109 143
181 195 225 267 269 305 325 333 351 363
```

各 `y` で `143650−y²` は正の整数平方、したがって `(±sqrt(143650−y²),y)` が異なる整数点である。最小・最大行の差は742、連続行幅は743、選択行番号差の gcd は2。全 `y` を整数平方根で走査し直接代入した独立 Python 検査：`scripts/check_nonprimitive_33_rows_743.py`（この実験ディレクトリからの相対パス）。

## 再現

repo rootから：

```sh
c++ -std=c++20 -O3 research/experiments/fixed-width/scripts/verify_nonprimitive_33_rows_560.cpp -o /tmp/f33a
c++ -std=c++20 -O3 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_nonprimitive_33_rows_560.cpp -o /tmp/f33b
/tmp/f33a 560 33 > /tmp/f33a.log
/tmp/f33b 560 33 > /tmp/f33b.log
diff -u /tmp/f33a.log /tmp/f33b.log
python research/experiments/fixed-width/scripts/check_nonprimitive_33_rows_743.py
```

検証範囲外：`561≤w≤742` の完全排除、`F(33)` の厳密値、任意 `k` への最適性。実装の容量は `W≤640` に限る。短時間〜中時間で扱う範囲を超える上界探索は本件の根拠にしない。
