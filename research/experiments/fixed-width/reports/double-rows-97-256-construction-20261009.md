# 整数円の二重点行：97〜256本の短区間構成下界（2026-10-09）

**証拠区分：明示的な整数円による数学的下界と、4ノルム内での有限完全列挙。** 全ての円についての最適幅ではない。

連続する `w` 本の整数水平行で、一本の実円が整数格子点を2個ずつ持つ行の最大本数を `T(w)` とする。`output/double_rows_97_256.csv` の各行 `(k,w,N,Ylo,Yhi,C,D)` に対して **T(w) >= k** が成立する。対象は `k=97,...,256` の160件。

## 構成

4つのノルム `N` はすべて `N ≡ 2 (mod 4)` である。

| N | 素因数分解 | 二重点行の総数 | 全行を含む幅 |
| ---: | --- | ---: | ---: |
| 59283250 | 2·5³·13·17·29·37 | 128 | 7700 |
| 296416250 | 2·5⁴·13·17·29·37 | 160 | 17216 |
| 770682250 | 2·5³·13²·17·29·37 | 192 | 27756 |
| 2430613250 | 2·5³·13·17·29·37·41 | 256 | 49302 |

各CSV行で円 `x²+y²+x−Cy+D=0` を取る。`C=−Ylo`、`D=(1+C²−N)/4` は整数。`X=2x+1`, `Y=2y−C` と置くと円の方程式は `X²+Y²=N` と同値。`Ylo <= Y <= Yhi` に含まれる奇数 `Y` のうち `N−Y²` が正の奇数平方となるものはちょうど `k` 個ある。各 `Y` に対し `x=(±sqrt(N−Y²)−1)/2`, `y=(Y−Ylo)/2` の異なる整数点2個があり、`0<=y<w` に収まる。

二平方和表現数公式（既存 K0059）より、各円の二重点行総数は表の128,160,192,256。CSVの各 `k` では、整数平方根による全Y列挙から、**上記4つの円の中で**k行を含む最短の連続区間を選んだ。

代表的な下界：

| k | w | 円の方程式 |
| ---: | ---: | --- |
| 97 | 6606 | `x²+y²+x−7699y−2162=0` |
| 128 | 7700 | `x²+y²+x−7699y−2162=0` |
| 160 | 17216 | `x²+y²+x−17215y−15006=0` |
| 192 | 27756 | `x²+y²+x−27755y−85556=0` |
| 256 | 49302 | `x²+y²+x−49301y−6162=0` |

## 独立検証

`construct_double_rows_97_256.py` はY座標を全走査し、CSVを再生成し、各k組の2整数点を元の円に直接代入する。`verify_double_rows_97_256.cpp` は独立にX座標を全走査してYを復元し、160行すべての4ノルム内での最短区間と直接代入を照合する。いずれも整数平方根の結果を整数演算で検査している。

```sh
python research/experiments/fixed-width/scripts/construct_double_rows_97_256.py
g++ -O2 -std=c++17 research/experiments/fixed-width/scripts/verify_double_rows_97_256.cpp -o /tmp/verify_double_rows_97_256
/tmp/verify_double_rows_97_256 research/experiments/fixed-width/output/double_rows_97_256.csv
```

**限界：** 160件は明示的な構成下界であり、各幅での厳密最大値でも最小達成幅でもない。Nを4つに限定している。mainへの反映とknowledge正本への昇格はこの成果物単体では未実施。
