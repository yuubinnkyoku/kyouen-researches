# 4行8点円：Pell基本単元は奇数弦長を保存する（有限判定上界の改善）

2026-10-15。基準：`main` `e0156f283f1cbe500c43bd9845e562ee0acfb464`。証拠水準：**数学的全称証明**。付属の独立有限監査は証明の代用ではない。

## 問題

既存の未統合報告 `q48-slope-reduction-congruence-20261015.md` は、傾きごとのPell解の存在判定に**平方した**基本単元を使う。そのため有限探索範囲は `L <= floor(sqrt(8Q) * 2U0 V0)` となる。奇数弦長を保存するには平方が本当に必要だろうか。

**必要ない。** ノルム8の制約自体が基本単元の奇偶保存を保証する。

## 定理（基本単元による鋭い有限帰着）

四連続行を各2整数点ずつ通る非局所8点円の既約傾き `A/B` を考え、`A,B>0, gcd(A,B)=1, A>3B`, `g=gcd(A,3)` とおく。正規形は

```
P=A²-B², Q=(A²-9B²)/g²,
QM²-PL²=8,
a=AL-(3B/g)M, b=(A/g)M-BL,
c=(A/g)M+BL, d=AL+(3B/g)M.
```

`P,Q>0`, `PQ` は非平方である。実際 `A>3B` より `P>=15`。仮に `PQ` が平方なら `P=pr²,Q=ps²`（`p` は共通の平方自由部分）と書け、`p(sM-rL)(sM+rL)=8`。正の同偶奇因数対を全て調べると `p=1,(sM-rL,sM+rL)=(2,4)` だけであり `rL=1`、従って `P=1` となり矛盾する。`U0,V0>0` を `U0²-PQV0²=1` の最小正単元とする。

**(i)** 任意の正整数ノルム8解 `(L,M)` で、基本単元変換

```
T0(L,M)=(U0 L+Q V0 M, U0 M+P V0 L)
```

は `L,M` の偶奇を**それぞれ**保存する。従って弦長 `a,b,c,d` の奇偶も保存する。

**(ii)** 任意の正整数ノルム8解は `T0` の正方向反復により得られる、次の有限区間内の正整数解に帰着する。

```
1 <= L <= floor(sqrt(8Q) V0).
```

平方単元を使った従来の境界から、上界を**厳密に `2U0` 倍縮小**できる。

**(iii)** 傾きの必要条件 `A/B>sqrt(9+6sqrt(2))` を満たす場合、上記有限区間内にノルム8の正整数解が存在し、その `a,b` がともに奇数となることが、当該傾きに属する非局所8点円が存在するための**必要十分条件**である。有限区間内で `a>0` 等を要求する必要はない。

傾きの必要条件は `a=AL-(3B/g)M>0` と `M/L>sqrt(P/Q)` を組み合わせて

```
(A/B)^4 - 18(A/B)^2 + 9 > 0
```

を得ることで導かれる。`A/B>3` なので大きい方の根を選ぶ。

## 証明

まず `g` は奇数であるから `P≡Q (mod 2)`。ノルム式を法2で見る。

- `P,Q` がともに偶数なら、Pell等式から `U0` は奇数。従って `T0` の非対角成分は偶数、対角成分は奇数であり、`(L,M)` の偶奇はそのまま保存される。
- `P,Q` がともに奇数なら、ノルム8から `M≡L (mod 2)`。また `U0²-PQV0²=1` から `U0,V0` は異なる偶奇。`T0 (mod 2)` は恒等行列または成分交換行列となる。`L≡M` のため、どちらでも**各成分**の偶奇が保存される。

これで(i)。ノルム保存は行列式1と直接展開で従う。

(ii) では `z=M/L` とすると `z²=P/Q+8/(QL²)`。もし `L²>8Q V0²` なら

```
Q² V0² z² = PQ V0² + 8Q V0²/L² < PQ V0²+1 = U0².
```

従って逆変換の `L'=U0 L-QV0 M` は正。さらに `z>sqrt(P/Q)` と `U0>sqrt(PQ)V0` より `M'=U0 M-PV0 L` も正。しかも

```
0 < L'/L = U0-QV0 z < U0-sqrt(PQ)V0 < 1.
```

ノルム・奇偶を保ったまま正整数 `L` が真に減少するため、有限回で上記区間に達する。これで(ii)。平方単元では `V=2U0V0` なので探索境界の比は厳密に `2U0`。

(iii) の必要性は元の8点円を逆変換することで従う。十分性は、有限区間の正整数解を `T0` で反復することから従う。`L` は増大し、`z=M/L` は `sqrt(P/Q)` に単調減少する。傾き下界から `a/L=A-(3B/g)z` はやがて正となる。他の差は

```
(b-a)/L=((A+3B)/g)z-(A+B)>0,
(c-b)/L=2B>0,
(d-c)/L=(A-B)-((A-3B)/g)z>0
```

（後二つの平方根比較は正の両辺の平方を取れば `4AB>0` に帰着する）。従って十分後の反復では `0<a<b<c<d`。奇数性は(i)で保存される。二階差分がともに `-8` なので、横中心を `d/2` とした4行8整数点が共円になる。以上。
