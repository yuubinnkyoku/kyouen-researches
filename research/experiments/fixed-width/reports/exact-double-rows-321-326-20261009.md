# 円の二重点行数：321〜326行の条件付き厳密値（2026-10-09）

## 結果と信頼境界

整数行 `y=0,...,w-1` を横切る実円が、各行に相異なる整数格子点を2個持つ行の最大数を `T(w)` とする。先行する未統合の `T(320)=32` の計算機援用証明を前提として、

\[
\boxed{T(w)=32\quad(321\le w\le326)}.
\]

従って33本の二重点行を実現する幅は327以上。ただしmainの正式knowledgeはK0369の63行までであり、64〜320行の先行証明を統合・監査するまでは条件付き結果である。有限係数範囲だけの探索結果ではない。

## 全実円に対する有限帰着

`T(w-1)=32` なら、幅wで33本の二重点行を持つ円は両端 `y=0,w-1` に二重点行を持たねばならない。円を `x²+y²+Bx+Cy+D=0` とするとVietaから `B,D∈Z`。二重点行の番号差の最大公約数をgとすれば、`g|(w-1)`, `32g≤w-1`, `gC∈Z` で、行は `y=gk` に限られる。

任意の法 `p` で `gcd(p,g)=1` のとき、`N=B²+C²-4D` として整数平方剰余条件 `d_i²+(2gi+C)²=N (mod p)` が必要。各 `p` について独立の `(C,N) mod p` を許した全マスクを作る。両端を含み33以上の行が残る交差マスクだけを保持し、全gを排除すれば上界が証明される。この緩和は全実円に対して必要条件であり、係数を有限探索したものではない。

検証器 `verify_double_rows_321_326.cpp` は長さ6の64ビット集合（384行まで対応）で、法9,11,7,49,19,23,31等を使用する。幅321〜326の各々で、全ての許容gについて候補交差集合が空になった。幅ごとの標準出力は `output/double-rows-321-326/` に置く。

## 構成下界

円 `x²+y²+x−235y−6=0` は、各幅321〜326で次の32行に整数格子点を2個ずつ持つ：

```text
0,1,3,4,10,15,22,25,45,49,60,70,87,91,102,115,
120,133,144,148,165,175,186,190,210,213,220,225,231,232,234,235
```

判別式 `1−4(y²−235y−6)` の正の奇数平方性と両整数根をPythonの整数平方根で独立検査した。

## 独立照合と再現

C++の平方剰余マスク生成を行ごとの蓄積方式と `(c,n)` 直接方式で変えたところ、**321〜326の全81 CASE行と6 EXACT行が完全一致**した。交差探索部分は共有しており、独立形式化は未完了。各幅を別プロセスで実行すると長時間のメモリ断片化を避けられる。

```sh
g++ -O3 -std=c++20 research/experiments/fixed-width/scripts/verify_double_rows_321_326.cpp -o /tmp/double_rows_a
g++ -O3 -std=c++20 -DDIRECT_RESIDUES research/experiments/fixed-width/scripts/verify_double_rows_321_326.cpp -o /tmp/double_rows_b
for w in $(seq 321 326); do
  /tmp/double_rows_a "$w" "$w" > "/tmp/a-$w.txt"
  /tmp/double_rows_b "$w" "$w" > "/tmp/b-$w.txt"
  cmp "/tmp/a-$w.txt" "/tmp/b-$w.txt" || exit 1
done
python research/experiments/fixed-width/scripts/verify_double_rows_321_326_witness.py
```

## ゲームへの条件付き帰結

幅326の円上の格子点は高々 `326+32=358` 個なので、先行基底を含めて採用できれば、`326×m` の `q≥359` について全長・全安全局面で `g(S)=(326 min(m,q−1)−|S|) mod 2`、真の満容量安定化長 `M_{326,q}=q−1`。

次の未確定幅は327。なお幅327の最初の合同探索は中間集合が大きく、時間制限内に完走していない。327の結果を本稿から推論しない。
