# 等間隔二重点行の素数分離：行間隔と円判別式の強制整除

日付: 2026-10-21。基準main: `9295ee55bb3272295bd3d1aad5d2edc98b3a4883`。

**証拠区分:** 以下の主定理は数学的全称証明。法9と小素数の表は有限体の完全列挙を補題として使用する。整数円の存在は主張しない。

## 定理

整数 `r>=5,d>=1,t` に対し、同じ実円が等間隔行 `y=t+jd` (`j=0,...,r-1`) の各行に相異なる整数横座標2点ずつを持つとする。弦長（横座標差）を `a_j>=1` とし、

```text
A = a_0^2,
L = a_1^2 - a_0^2 + 4d^2,
H = L^2 + 16d^2 A > 0
```

と置く。全 `j` で `a_j^2=A+Lj-4d^2 j^2`。

1. `p<=r, p≡1 (mod4)` の素数はすべて `H` を割る。`p∤d` なら `j=0,...,p-1` の弦長で `p|a_j` はちょうど一回で、その位置は `j≡L/(8d^2) (modp)`。`p|d` なら `p^2|H`。
2. `7<=p<=r, p≡3 (mod4)` の素数はすべて `d` を割る。さらに全 `j` で `v_p(a_j)=v_p(a_0)<v_p(d)`、かつ `p^2|H`。
3. `r>=5` なら `3|d`、全 `j` で `v_3(a_j)=v_3(a_0)<v_3(d)`、かつ `9|H`。

特に `r>=7` で

```text
P_-(r) = product{p<=r: p≡3 mod4},
P_+(r) = product{p<=r: p≡1 mod4}
P_-(r) | d,        P_+(r) * P_-(r)^2 | H.
```

算術級数の素数定理を使えば、`r→∞` に沿って存在する場合、`log d >= (1/2+o(1))r`, `log H >= (3/2+o(1))r`。したがって `r <= (2+o(1))log d`。

### 小素数によるさらに強い必要条件

`p∤d` のとき、`p=7,11,19,23,31` に対して許容される連続二重点行の最大長は順に `5,6,9,8,10`。平方剰余の全初期組と独立な中心・半径の全組を照合した。

## 全称証明

円方程式を `x²+y²+Bx+Cy+D=0` とする。行 `y=t+jd` の二根の差の平方は `B²-4((t+jd)²+C(t+jd)+D)`。二次係数は `-4d²` なので、最初の二つの整数値から `a_j²=A+Lj-4d²j²`。係数 `B,C,D` の整数性は不要。

奇素数 `p∤d` に対し、`z_j=(a_j/(2d))²=V-(j-u)² (modp)` と書ける。ただし `u=L/(8d²)`, `V=H/(64d⁴)`。二次指標 `χ` (`χ(0)=0`) について `V≠0` なら

```text
sum_{j mod p} χ(V-(j-u)^2) = -χ(-1).
```

実際 `sum χ(j²−V)=-1` は `X²−Y²=V` の解が `p−1` 組であることから従う。

`r>=p` なら全 `p` 剰余で `z_j` は平方剰余または0。`p≡1 mod4` では上の和は `-1` で不可能だから `V=0`、つまり `p|H`。その場合 `z_j=-(j-u)²` なので、ちょうど一行だけ `p|a_j`。`p≡3 mod4, p>=7` では `V≠0` なら和は1だが、零点は高々2個だから平方剰余の和は `>=p−2>1`。`V=0` でも `-(j-u)²` は `p−1` 個の非平方を持つ。ゆえに `p∤d` は不可能。

一方 `p|d, p<=r` なら `a_j²≡A+Lj (modp)`。もし `p∤L` なら全剰余を走って非平方を含むので矛盾。従って `p|L`、よって `p²|H`。`p≡3 mod4,p>=7` で `p|a_0` なら全 `a_j` も `p` で割り切れる。`(a_j,d)` を同時に `p` で割った新しい二次式でも同じ議論が使える。もし `v_p(a_0)>=v_p(d)` なら、最後に `p∤d` の禁止形へ達する。従って `v_p(a_0)<v_p(d)`。ちょうど `v_p(a_0)` 回縮小した形では `a_0` は単元、`d` は非単元であり、全 `a_j²≡a_0²≠0 (modp)`。よって全弦長の付値が一致する。

`p=3,r>=5` では、`3∤d` の場合の `A,L mod9` 全81組と `d mod9` の6単元を検査すると、`j=0,...,4` の `A+Lj−4d²j²` が全て平方剰余となる組は0。よって `3|d`。上記と同じ縮小論法で付値の主張を得る。`p≡1 mod4` で `p|d` の場合は `p²|H` が既に示された。これらから積の整除性が従う。算術級数の素数定理より各合同類の素数の対数和は `(1/2+o(1))r` であり、漸近評価が従う。□

小素数表は `z_{j+2}=2z_{j+1}−z_j−2 (modp)` の平方剰余初期2項を全列挙し、独立に `V−(j-u)²` の全 `p²` 組を列挙して一致させた。有限の合同補題の証明であり、整数円の探索ではない。
