# 4×m・q=8：1000001列までの8点円の有限完全分類

2026-10-15。4行整数格子盤（y=0,1,2,3）における8点円の水平弦長型を、最大弦長1000000まで**有限完全列挙**した。無限の全円型分類ではない。

## 結論

各行の弦長を `(d0,d1,d2,d3)` とする。`1<=m<=1000001` に現れる型は次の7種類だけである。

| 弦長型 | 最初の列数 |
|---|---:|
| (1,3,3,1) | 4 |
| (35,51,63,73), (73,63,51,35) | 74 |
| (1331,1935,2391,2773), (2773,2391,1935,1331) | 2774 |
| (50543,73479,90795,105301), (105301,90795,73479,50543) | 105302 |

したがって、**105302列の次に新型が現れることは1000001列までない**。従来の2774列までの完全分類、およびPell構成から得られていた105302列の存在例を拡張した。

`[x]_+=max(0,x)` として、上記区間の8点円の総数は厳密に

```text
C8(m) = [m-3]_+ + 2[m-73]_+ + 2[m-2773]_+ + 2[m-105301]_+.
```

`C8(1000001)=6783710`。8点を含む直線は4本の水平行だけなので、禁止8点集合の総数は `4*binom(m,8)+C8(m)`、安全な8石配置数は `binom(4*m,8)-4*binom(m,8)-C8(m)` となる。

## 完全性の数学的還元

円の方程式を `x²+y²-Sx+By+C=0` とする。4行にそれぞれ2格子点を持つ円は、各行の交点が `x=(S±d_i)/2` と書ける。したがって `d_i` は全て正整数・同じ偶奇で、

```text
d0² - 2d1² + d2² = -8,
d1² - 2d2² + d3² = -8.
```

逆に、これらを満たす4つ組から `S=max(d_i)`, `C=(S²-d0²)/4`, `B=(d0²-d1²)/4-1` と置けば、各行に2整数点を持つ円ができる。共通偶奇のためx座標も整数になる。弦長最大値 `D` の型は、m列盤で正確に `[m-D]_+` 個の水平平行移動を持つ。8点円は4行の各行高々2点だから、これ以外の盤上点は円上にない。

ゆえに `1<=d_i<=1000000` の整数解を完全列挙すれば円型分類が完成する。

## 二つの独立した完全列挙

1. `scripts/q48_circle_census_mod4032_20261015.cpp` は `(d0,d1)=(a,b)` を走査し、`d2²=2b²-a²-8`, `d3²=3b²-2a²-24` を検査。法4032の平方剰余という**必要条件だけ**で候補を枝刈り。1000000までの剰余候補3,779,297,808組、正かつ範囲内1,230,997,127組、解7型。実行約16秒。
2. `scripts/q48_circle_census_ac_mod2016_20261015.cpp` は別の `(d0,d2)=(a,c)` を走査し、`d1²=(a²+c²+8)/2`, `d3²=(3c²-a²-24)/2` を検査。法2016の平方剰余必要条件で枝刈り。剰余候補2,078,609,034組、正かつ範囲内1,229,491,948組、解7型。実行約15秒。

**両方式の全出力が一致した。** 平方剰余による枝刈りは平方数を除外しない。浮動小数点平方根は初期値のみで、整数積による完全平方判定を必ず実施。最大二乗値10¹²は符号付き64bitの範囲内。さらにB=10000で、枝刈りなしの二つの独立した旧列挙方式とも一致した。B=200000では従来の7型の有限分類と一致した。

## 再現

```sh
g++ -O3 -std=c++17 research/experiments/fixed-width/scripts/q48_circle_census_mod4032_20261015.cpp -o /tmp/q48_ab
g++ -O3 -std=c++17 research/experiments/fixed-width/scripts/q48_circle_census_ac_mod2016_20261015.cpp -o /tmp/q48_ac
/tmp/q48_ab 1000000 > /tmp/q48_ab.txt
/tmp/q48_ac 1000000 > /tmp/q48_ac.txt
diff -u /tmp/q48_ab.txt /tmp/q48_ac.txt
```

記録：`output/q48_circle_census_1000000_20261015.json`。11×11巨大探索は実施していない。

**境界**：1000002列以降の不存在は未確認。円数公式をそれ以降に延長しない。19石配置数やGrundy値の決定も主張しない。
