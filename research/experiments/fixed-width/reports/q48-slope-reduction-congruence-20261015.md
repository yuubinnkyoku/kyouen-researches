# 四行8点円：傾きの厳密な隙間、各傾きの有限判定、合同類を保つ無限延長

作成: 2026-10-15。基準 main: `e0156f283f1cbe500c43bd9845e562ee0acfb464`。

**証拠区分**：以下の定理1–3は整数・代数による**全称証明**。末尾の Python/C++ 計算は独立した**有限監査**であり、全称証明の代替ではない。

## 設定と正規形

標準格子の4連続行 `y=0,1,2,3` に各2個の異なる整数点を持つ円を考える。各行の水平弦長 `a,b,c,d` は正の奇数で、

```
a² - 2b² + c² = -8,     b² - 2c² + d² = -8.                (1)
```

奇数性も (1) だけから従う。法4で4個の平方剰余（0または1）の二階差分が0であるため、弦長の偶奇は4個とも一致する。もし全て偶数なら `a=2a',...,d=2d'` と割って二階差分はともに `-2` となる。しかし法8の平方剰余 `{0,1,4}` から作れる4項列には、二階差分がともに `6 (mod 8)` となるものがない（3^4=81通りの直接分類でも確認できる）。よって全て奇数。

局所型 `(1,3,3,1)` 以外は上下反転して `0<a<b<c<d` とできる。実際 `b²-a²=8k` とすると (1) から続く差は `8(k-1),8(k-2)`。`k<=-1` なら厳密減少、`k>=3` なら厳密増加。`k=0` では `a=b, a²-c²=8` より `(a,c)=(3,1)` だが `d²<0`。`k=1` では `(a,b,c,d)=(1,3,3,1)`。`k=2` では `c=d, c²-b²=8` より `(b,c)=(1,3)` だが `a²<0`。これで尽くされる。

`s=(d+a)/2, t=(d-a)/2, u=(c+b)/2, v=(c-b)/2` とすると、(1) の差から `st=3uv`。既約比 `s/v=A/B`、`g=gcd(A,3)` とすると正整数 `L,M` を用いて

```
a= A L -(3B/g) M,    b=(A/g) M-B L,
c=(A/g) M+B L,      d=A L+(3B/g) M,
P=A²-B²,             Q=(A²-9B²)/g²,
Q M²-P L²=8.                                              (2)
```

となる。`A,B` は互いに素、`A>3B>0`、`P>=15`。逆に (2) の正整数解で4弦長が正の奇数かつ厳密増加なら、(1) を満たし、水平中心 `d/2` の8整数点が共円となる。

`PQ` は必ず非平方である。実際、もし `P=p r²,Q=p s²`（p は平方自由）なら `p(sM-rL)(sM+rL)=8`。同偶奇の正の因数対を調べると `p=1,(sM-rL,sM+rL)=(2,4)` のみで、`rL=1`、すなわち `P=1`。`P>=15` と矛盾する。

## 定理1：実現可能な傾きには厳密な隙間がある

任意の非局所8点円の既約傾き `A/B` は

```
A/B > sqrt(9+6 sqrt(2)) = 4.1815405503... .               (3)
```

**証明**。`a>0` と (2) から `A L>(3B/g)M`。一方、`Q M²-P L²=8` より `M/L>sqrt(P/Q)`。従って

```
A²(A²-9B²)>9B²(A²-B²),
(A/B)^4-18(A/B)^2+9>0.
```

`A/B>3` なので大きい方の根を選ぶと (3)。□

(3) だけでは存在は言えない。例えば `A/B=5/1` は (3) を満たすが、(2) は `2M²-3L²=1` となり、mod 3 で `M²≡2` を要求するため解がない。

## 定理2：各既約傾きの実現可能性は有限の整数検査に帰着する

`A,B` を互いに素な正整数、`A>3B` とし (2) の `P,Q` を計算する。次の判定は**必要十分**であり、有限手順である。

1. (3) を満たさなければ不可能。
2. `D=PQ` が平方数なら不可能（上の因数分解補題）。
3. 非平方の場合、`u²-Dv²=1` の正の整数解を連分数で1組求め、二乗して `U=u²+Dv²`（奇数）、`V=2uv`（偶数）とする。
4. **有限区間** `1<=L<=floor(sqrt(8Q) V)` で `QM²-PL²=8` を満たす正整数 `M` を探索し、(2) の `a,b` が奇数となる解が1つでもあれば実現可能。なければ不可能。

**有限性と完全性の証明**。ノルムを保つ整数行列

```
T = [ U   QV ]      T^{-1}=[ U  -QV ]
    [ PV  U  ]             [ -PV U  ]
```

は行列式1で、`U` が奇数、`V` が偶数なので `L,M` の偶奇を保つ。任意の正整数解について `z=M/L>sqrt(P/Q)`。もし `L²>8QV²` なら

```
z²=P/Q+8/(QL²)<P/Q+1/(Q²V²)=U²/(Q²V²),
```

従って `L'=UL-QVM>0`。また `M'=UM-PVL>0` は `z>sqrt(P/Q)>PV/U` から従う。さらに `0<L'<L`（`U-QVz<U-sqrt(D)V<1`）。ゆえに逆変換を繰り返すと必ず有限区間の正整数解に至る。したがって候補漏れはない。

逆に有限区間に奇偶条件を満たす正整数解があれば、`T` を反復する。`L` は単調増加して無限大となり、`z=M/L` は `sqrt(P/Q)` に近づく。弦長の差を `L` で割った極限は

```
a/L -> A-(3B/g)sqrt(P/Q) > 0                   ((3) に同値),
(b-a)/L -> ((A+3B)/g)sqrt(P/Q)-(A+B)>0,
(c-b)/L = 2B>0,
(d-c)/L -> (A-B)-((A-3B)/g)sqrt(P/Q)>0.
```

最後の二つの平方根不等式はそれぞれ

```
(A+3B)² P-(A+B)²(A²-9B²)=4AB(A+B)(A+3B)>0,
(A-B)²(A²-9B²)-(A-3B)²P=4AB(A-B)(A-3B)>0
```

で確かめられる。従って十分先の反復はすべて正・厳密増加で、`L,M` の偶奇が保存されるため4弦長は奇数。よって8点円が実在する。□

この判定は数学的には有限だが、`V` が非常に大きくなることがある。全傾きの有限リスト化や実用上の高速判定を主張するものではない。

## 定理3：各非局所円の座標合同類には無限個の円がある

任意の非局所8点円と任意の法 `N>=1` を固定する。各行の2点を左端が0になるように平行移動して表すと、**全8点の座標を法Nで保存する、互いに異なる8点円が無限個存在する**。元の円が下向き弦長なら上下反転してから構成し、最後に戻せばよい。

**証明**。定理2の `T` は `GL_2(Z/(2N)Z)` に属するので有限位数 `h>=1` を持ち、`T^h≡I (mod 2N)`。初期 `(L,M)` に `T^{kh}` を適用すると、4弦長は初期値と法 `2N` で一致する。全ての反復は元の円から出発するため正・厳密増加性を保ち、水平弦長 `d` は無限に増える。左端0に正規化した8点の横座標は `(d±a)/2`, `(d±b)/2`, ... だから、法Nで全て元の座標と一致する。□

**帰結**：例えば法27の第四型が整数円として1つでも実現すれば、同じ第四型の整数円が無限に存在する。これは第四型の実在を証明したものではない。有限個の法による「その剰余型は有限個だけ」という結論は非局所円に対して成立しない。

## 定理4：固定した実現傾きの円型数は対数的に増える

既約傾き `A/B` を固定し、これを持つ非局所8点円が1つ以上存在するとする。上下反転を同一視して厳密増加向きに正規化し、最大水平弦長 `d<=X` を持つ異なる弦長型の数を `F_{A/B}(X)` とすると、定理2の `U,V` および `λ=U+sqrt(PQ)V>1` に対し、**ある正整数 `κ` が存在して**

```
F_{A/B}(X) = (κ/log λ) log X + O_{A,B}(1)   (X→∞).
```

特に `F_{A/B}(X)=Θ_{A,B}(log X)`。固定傾きに属する円型の、全弦長上限に対する密度は0である。

**証明**。定理2の逆変換は、正整数ノルム解を正のまま真に小さい `L` へ移すか、正整数領域を出るかのいずれか。従ってすべての正整数解は、逆変換が正でなくなる**有限個の原始種**のいずれかを正方向反復したものに一意に属する。原始種は定理2の有限区間内にあり、`T` の可逆性から異なる原始種の正方向軌道は交わらない。`T` は偶奇を保つので、奇数弦長を生む原始種だけを残す。定理1の傾き下界を満たすため、その各軌道は有限個の例外を除き実際の8点円になる。

`T` の固有値は `λ` と `λ^{-1}`。正の原始種から始める軌道の最大弦長は `d_n=C λ^n+C' λ^{-n}`（`C>0`、定数は種に依存）なので、`d_n<=X` となる項数は `(log X)/(log λ)+O(1)`。原始種のうち奇偶条件を満たすものの個数を `κ` として加算すれば結論。少なくとも一つの実現円があるので `κ>=1`。□

この定理は**傾きを固定した場合**の円型数である。全傾きを合わせた `4×m` の8点円型総数に `O(log m)` を主張するものではない。
