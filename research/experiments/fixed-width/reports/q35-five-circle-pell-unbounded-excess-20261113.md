# 3×m のちょうど5点円：Pell型無限族による線形基準からの無界超過（2026-11-13）

**証拠水準：全称証明（既存の5点円個数公式に基づく系）。** 先行資料 `q35-five-circle-diophantine-first-width-20261112.md` の必要十分条件を使用する。ここで `F_5(m)` は3×m盤に含まれる、ちょうど5個の格子点を通る相異なる円の個数である。

## 定理

`F_5(m)-2(m-8)` は `m→∞` で無限大へ発散する。特に、幅9〜13で成立する `F_5(m)=2m-12` は、単に幅14で例外を持つだけでなく、超過分が無界に増える。

## 証明

先行公式の接線型 `(a,b,k)=(8,6,0)` は任意の `m≥9` に `2(m-8)` 個寄与する。

片側切断型の無限族として `a=3` を固定し、正整数列 `(b_j,k_j)` を

```
(b_0,k_0)=(11,15)
b_(j+1)=3b_j+2k_j
k_(j+1)=4b_j+3k_j
```

で定める。初項は `3²+15²+8=2·11²` を満たす。行列 `[[3,2],[4,3]]` は二次形式 `k²−2b²` を保存するため、帰納的に

```
k_j²−2b_j²=−17
3²+k_j²+8=2b_j²
```

となる。初項が奇数であり、漸化式も奇数性を保存するので `3≡b_j≡k_j (mod 2)`。また `k_j>b_j≥3` は初項で成立し、差の漸化式からも保たれる。従って先行公式の片側切断型に該当する。

その初出幅は `M_j=(b_j+k_j)/2+1` であり、`m≥M_j` では各族が少なくとも4円寄与する。列 `b_j,k_j` は厳密単調増加するため `M_j` も増加し無限大に発散する。異なる `j` は異なる弦幅 `b_j` を持ち、同じ円を二重計数しない。よって

```
F_5(m) ≥ 2(m−8) + 4·#{j≥0 : M_j≤m}  (m≥9).
```

右辺の超過項は `m→∞` で無限大に発散する。証明終。

## 数値的な独立検算

最初の `(b,k,M)` は `(11,15,14)`, `(63,89,77)`, `(367,519,444)`, `(2139,3025,2583)`。次のコードは漸化式・整数条件・最小幅の整合性を整数演算のみで検査する（証明は有限検査に依存しない）。

```python
b,k=11,15
expected=[(11,15,14),(63,89,77),(367,519,444),(2139,3025,2583)]
for B,K,M in expected:
    assert (b,k,(b+k)//2+1)==(B,K,M)
    assert 9+k*k+8==2*b*b and k>b and b%2==k%2==1
    b,k=3*b+2*k,4*b+3*k
print("OK")
```

## 意味と限界

これは**ちょうど5点円の本数**に関する無界性であり、6点円を含む総円数、禁止五点組数、勝敗・Grundyの漸近式ではない。先行の全称個数公式から導かれる独立した無限族の系であり、同じ命題の再証明ではない。さらに `M_j` は指数的に増えるため、この族だけで得られる超過は少なくとも対数的である。他の整数解の寄与は非負なので下界は壊れない。
