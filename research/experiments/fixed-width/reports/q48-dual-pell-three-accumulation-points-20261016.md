# 4行8点円：二つの双対Pell族、三つの異なる傾き集積点、対数的種類数下界

日付：2026-10-16。基準 main `db2a6b9b5291c4038b65e98fa838088881b17c0d`。対象は4連続整数行の各行に2整数点を持つ非局所8点円。**証拠区分：全称数学的証明**。検証器の有限検算とは区別する。

## 定理

K0432の既約傾き A/B に対し、実現可能な傾きの集合は少なくとも **3個の相異なる集積点**を持つ。具体的には

1. `9/1` から始まる既知の族：`3 sqrt(325/37)`。
2. `47/6` から始まる新しい双対Pell族：`sqrt(2429205392/39588680)`。
3. `53/12` から始まる新しい双対Pell族：`sqrt(5244481808/268852040)`。

いずれも初期傾きから厳密に減少し、実際の整数8点円を各項に持つ。三つの傾き区間は互いに交わらない。特に、

```
R(H) = #{既約実現傾き A/B : 1<=A,B<=H}
```

とおくと、以下の明示定数 `c>0` に対し

```
liminf_{H->infinity} R(H)/log(H) >= c,
c = 1/log(lambda_0) + 1/log(lambda_1) + 1/log(lambda_2)
  = 0.07371302838...  (参考近似)
```

が成立する。ここで log は自然対数、`lambda_i=u_i+v_i sqrt(D_i)`、次節の `(u_i,v_i,D_i)` を用いる。上界との一致や真の漸近を主張しない。

## 固定(L,M)・可変傾きの双対Pell構成

K0432の正規形で `g=gcd(A,3)=1` の場合、弦長は

```
a=A L-3B M, b=A M-B L, c=A M+B L, d=A L+3B M.
```

`Q M²-P L²=8` を展開して

```
U A² - V B² = 8,
U=M²-L², V=9M²-L².
```

となる。`M>L>0`、`A,B>0` の整数解が一つあり、`A` が奇数、`B` が偶数、`3∤A`、`gcd(A,B)=1`、`L,M` が奇数、かつ

```
L² V > 9 M² U
```

とする。正の整数 `u,v` が `u²-U V v²=1` を満たし、行列

```
T=[[u,Vv],[Uv,u]]
```

が `I (mod 6)` と合同なら、`(A_n,B_n)=T^n(A,B)` は全nで実現可能な相異なる既約傾きを与える。

**証明**：`det(T)=1`、`T` は整数可逆で二次形式を保存するので、ノルム8・既約性・偶奇・`3∤A_n` が保存される。`r_n=A_n/B_n` とすると

```
r_(n+1)-r_n = v (V-U r_n²)/(Uv r_n+u) < 0,
r_n > sqrt(V/U),
lim r_n=sqrt(V/U).
```

ノルム8から `r_n²=V/U+8/(U B_n²)` であり、`B_n` は正に増大するので極限が従う。さらに `a_n/B_n=L r_n-3M > L sqrt(V/U)-3M>0`。`b_n-a_n=A_n(M-L)+B_n(3M-L)>0`、`c_n-b_n=2B_n L>0`、`(d_n-c_n)/B_n=(L-M)r_n+(3M-L)` は n とともに増加するため、初項で正なら以後も正。4弦長は奇数、二階差分はともに -8。各行の横座標を `(d_n±a_n)/2`, `(d_n±b_n)/2`, `(d_n±c_n)/2`, `(d_n±d_n)/2` と置くと、整数係数円

```
x²+y²-d_n*x+((a_n²-b_n²)/4-1)*y+(d_n²-a_n²)/4=0
```

に8点が乗る。よって全項が実現可能である。□

## 第三の集積点と定量的下界

既知の初期弦長 `(35,51,63,73)` について、`(C_0,B_0)=(3,1)`、`A_n=3C_n` とし

```
T0=[[1859131879201,325*16953823416],
    [37*16953823416,1859131879201]],
37C_n²-325B_n²=8.
```

`det(T0)=1`, `T0≡I(mod6)`。弦長 `(18C-19B,19C-6B,19C+6B,18C+19B)` は常に正の奇数で厳密増加し、同じ二階差分を満たす。傾き `3C_n/B_n` は `9` から `3sqrt(325/37)` へ厳密に減少する（先行する未統合証明の独立再記述）。

三族の区間はそれぞれ `(3sqrt(325/37),9]`、`(sqrt(V1/U1),47/6]`、`(sqrt(V2/U2),53/12]` であり、`3sqrt(325/37)>47/6`、`sqrt(V1/U1)>53/12` から交わらない。

各族の整数行列の正固有値を `lambda_i=u_i+v_i sqrt(D_i)>1` とすれば、正初期ベクトルの各座標は `Theta(lambda_i^n)`。したがって `1<=A_n,B_n<=H` の項数は `log(H)/log(lambda_i)+O(1)`。三族は重複しないため、合算して定理の下界が得られる。ここで `D0=12025`、`D1=U1V1`、`D2=U2V2`。
