# 三列異方格子：5点円の初出は3行、6点円の初出は無界となる無限族（2026-10-17）

**全称証明。** 正整数 `t >= 2` に対し、三列の座標を `x = 0, 1, t²`、縦格子間隔を `d=t` とする。盤 `G_t(m)={(x,tj): x∈{0,1,t²}, 0<=j<m}` で、少なくとも `q` 点を通る**円**が初めて現れる行数を `H_q(t)` と定める（直線は含めない）。

> **定理** `H_5(t)=3`、`H_6(t)=2t+1`。さらに `m=2t+1` の6点円はちょうど1本である。

従って `H_6-H_5=2t-2` と `H_6/H_5=(2t+1)/3` はどちらも無界。とくに、**H5だけを引数とする有限値の普遍的上界 f(H5) では H6 を抑えられない**。以前の `ab=d²k(k+1)` 族では H5も大きくなったが、ここでは H5を3に固定したまま差を増やせる。

## 明示構成

5点円は

```
(x-(t²+1)/2)² + (y-t)² = ((t²+1)/2)²
```

で、格子点 `(0,t)`, `(1,0)`, `(1,2t)`, `(t²,0)`, `(t²,2t)` を通る。3行に収まる。一方、2行以下では各列が最大2点であり、5点円には二列の上下両端（4点）が必要になる。その4点を通る円は、各水平行との交点のx座標がその二列に尽きるため、第三列の5点目を通れない。よって `H5=3`。

6点円は

```
(x-1/2)² + (y-t²)² = t⁴+1/4
```

で、 `(0,0),(0,2t²),(1,0),(1,2t²),(t²,t²-t),(t²,t²+t)` を通る。行番号は `0,2t,t-1,t+1` なので `H6<=2t+1`。

## 6点円の下界（全称）

三列の各列に2点ある6点円を任意に取る。列 `x=0,1,t²` での二点の**行番号差**を `D0,D1,D2` とする。これらは正整数で、同じ円の縦中心について各列の二根の和が等しいため、**三つとも同じ偶奇**を持つ。

一般の列 `0,a,a+b`、縦間隔 `d` の弦長恒等式

```
d²[b D0²-(a+b) D1²+a D2²] = -4ab(a+b)
```

に `a=1,b=t²-1,d=t` を代入すると

```
                  t² Z = D2²-D0²-4,
                  Z = D1²-D0²-4.                 (★)
```

仮に `m<=2t` なら、`1<=Di<=2t-1`。`t>=2` より

```
             -4t² < D2²-D0²-4 < 4t²,
```

従って整数 `Z` は `-3<=Z<=3`。`D0,D1` が奇数なら平方は法8でともに1なので `Z≡4 (mod 8)` となり不可能。偶数なら `Z≡0 (mod 4)` なので `Z=0`。しかしこれは `D1²-D0²=4` を意味し、`D1=2u,D0=2v` と置けば `u²-v²=1`。正整数 `u,v` では `(u-v)(u+v)=1` は不可能。矛盾。

ゆえに `m>=2t+1`、明示構成と合わせて **`H6=2t+1`**。□

## 初出6点円の一意性（全称）

`m=2t+1` では `1<=Di<=2t`。式(★)の右辺は `-4t²-3` 以上、`4t²-5` 以下なので、`t>=2` から整数 `Z` は `-4<=Z<=3`。同じ偶奇論法で `Z` は `-4` または `0` に限られ、`0` は先ほどの平方差で不可能。従って `Z=-4`、すなわち `D1=D0` であり、式(★)は

```
                  D0²-D2²=4t²-4.
```

`1<=D2` と `D0<=2t` から `D0=2t, D2=2` が強制され、`D1=2t`。行番号 `0..2t` に長さ `2t` の弦を置く方法は両端 `0,2t` しかない。三列の縦中心は共通なので、第三列の弦は `t-1,t+1` に限られる。これで上記の6点円が**唯一**となる。□
