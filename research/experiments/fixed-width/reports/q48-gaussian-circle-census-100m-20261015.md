# 4×m・q=8：ガウス整数による完全列挙（最大弦長1億）と新しい既約傾き

作成：2026-10-15。確認したmain：`fea4c4b3c74458fd6cd2e43673af8b86e80b5d54`（実験出力を追加する前）。

**証拠の区分**：弦長列挙法の完全性と新傾きの無限延長は数学的証明。最大弦長1億の分類は**有限完全計算（単一の新方式）**。独立の弦長対列挙との全範囲照合は100万までであり、1億までの二重完全列挙は未実施。

## 1. 結論

標準の連続する4整数行 `y=0,1,2,3` をそれぞれ相異なる整数2点ずつ通る円を考え、各行の2点の横座標差を `d0,d1,d2,d3>0` とする。最大弦長 `max(d0,d1,d2,d3)≤100000000` を満たす弦長列は、**ちょうど15種類**だった。

局所型 `(1,3,3,1)` のほか、増加列は以下の7種類と、それぞれの上下反転である。

| 増加弦長列 | 最大弦長D | 備考 |
|---|---:|---|
| `(35,51,63,73)` | 73 | 既知Pell族 |
| `(1331,1935,2391,2773)` | 2773 | 同族 |
| `(50543,73479,90795,105301)` | 105301 | 同族 |
| `(445465,715719,908883,1067653)` | 1067653 | 既知別傾き |
| `(98119,1096275,1547259,1893727)` | 1893727 | 既知別傾き |
| `(1919303,2790267,3447819,3998665)` | 3998665 | 最初のPell族の次世代 |
| **`(5371183,43796547,61704339,75476575)`** | **75476575** | **新しい第4の既約傾き** |

この有限範囲で出現する既約傾きは `9/1`, `47/6`, `53/12`, **`181273/40152`** の4種類だけ。最後の値は「全無限範囲で4番目に小さい傾き」という意味ではない。

`[x]_+=max(x,0)` とおく。4行盤に全8点が含まれる円の個数 `C8(m)` は、**全ての `1≤m≤100000001`** について

```
C8(m)=[m-3]_+ + 2 Σ_{D∈{73,2773,105301,1067653,1893727,3998665,75476575}} [m-D]_+ .
```

特に `C8(100000001)=1334910478`。4行にそれぞれ2点ずつという円型だけを数える（他の点数分布の禁則は含まない）。

## 2. 列挙法が完全である理由（無界の数学的証明）

円の各行における横座標二根の和を `S`、積を `p_i` とすると、全行で和 `S` は共通であり、`p_{i+2}-2p_{i+1}+p_i=2` である（K0073）。`d_i²=S²-4p_i` から

```
d0²-2d1²+d2² = -8,
d1²-2d2²+d3² = -8.
```

逆に、**正の奇数** `d0,d1,d2,d3` がこの二式を満たせば、`S=max(d_i)` として各行の点を `((S-d_i)/2,i),((S+d_i)/2,i)` に取ると、整数格子上の8点が同一円に載る。二根和と積の二階差分が必要十分だからである。横幅は厳密に `S` となる。

弦長の偶奇は `d_i≡S (mod 2)` で全行同じ。もし全て偶数なら `e_i=d_i/2` は整数で

```
e0²-2e1²+e2² = -2,
e1²-2e2²+e3² = -2.
```

法4から `e0,e2` は同じ偶奇、`e1,e3` はその反対の偶奇となる。`e0,e2` が奇数なら第一式の左辺は法8で2、偶数なら第二式の左辺は法8で2となり、いずれも右辺の `-2≡6 (mod 8)` に矛盾。よって全弦長は奇数。

`a=d0,b=d1,c=d2,d=d3` と書くと、第一式は

```
a²+c²=2(b²-4)=2(b-2)(b+2).
```

`b=1` は右辺が負なので不可能。全ての `b≥3` の奇数について、`b-2,b+2` を素因数分解する。`3 (mod 4)` の素数が右辺に奇数指数で現れれば二平方和表示は不可能。そうでなければ、ガウス整数環 `Z[i]` の一意分解により、**全ての** `a²+c²=2(b²-4)` の整数解は次の積から、単元 `±1,±i` の作用を除いて生成できる。

- 2 の因子は `1+i`。
- `p≡3 (mod 4)` の指数 `2e` は実数因子 `p^e`。
- `p≡1 (mod 4)` の指数 `e` は `p=α²+β²` として、`(α+iβ)^k(α-iβ)^(e-k)` (`k=0,...,e`) の全選択。

各積の実部・虚部の絶対値とその交換から、正の順序付き `(a,c)` を全て得る。最後に

```
d²=3b²-2a²-24
```

が正の奇数平方であるか、`a,b,c,d≤B` かを厳密な整数平方根で判定する。この手順には「増加型しかない」という既存定理は不要で、反転型・局所型も自動で拾う。従って**任意の上限Bに対して**、素因数分解とガウス整数生成が正しければ列挙は完全である。`p≡1 (mod4)` の二平方和表示は平方根 `-1 (mod p)` とCornacchiaの算法で構成し、`α²+β²=p` を整数で再確認する。

実装は `scripts/q48_gaussian_circle_census_20261015.cpp`。B=100000000の実行では奇数bが49,999,999個、そのうち素因数障害を通過したbが2,824,070個、生成した順序付き候補が100,003,980個、重複除去後の弦長列が15個だった。実行環境で約13秒（参考値、性能保証ではない）。

## 3. 新しい傾きの厳密な存在証明

新型 `(a,b,c,d)=(5371183,43796547,61704339,75476575)` は二つの二階差分式を整数として満たす。`S=75476575` で復元した8点は次の通り。

```
y=0: x=35052696, 40423879
y=1: x=15840014, 59636561
y=2: x= 6886118, 68590457
y=3: x=       0, 75476575
```

全点が次の円に載る。

```
x²+y²-75476575x-472321980575931y+1416965941727784=0.
```

`A/B=((a+d)/2)/((c-b)/2)` を既約化すると `A/B=181273/40152`。K0431のPell正規形では `g=gcd(A,3)=1, L=223, M=291` であり、

```
P=A²-B²=31247717425,
Q=A²-9B²=18350252593,
Q M² - P L² = 8.
```

これによりK0431の非局所型の無限延長定理が適用され、**同じ傾きの相異なる整数8点円が無限に存在**する。新しい無限族の存在は有限列挙結果だけに依存しない（明示的な整数証人と既存全称定理に依存する）。

さらに、この型の中央弦 `b=43796547` に対して

```
b-2=5·13·673793,   b+2=43796549,
5=1²+2², 13=2²+3², 673793=212²+793²,
43796549=607²+6590²,
(1+i)(1+2i)(2+3i)(212-793i)(607-6590i)
   =61704339+5371183i.
```

という因数分解証明書があり、平方和生成経路も直接確認できる。

## 4. 独立監査と限界

付属の独立Python監査は15種類すべてを整数座標へ復元し、各8点から選ぶ70組ずつ、計1050組の4点円行列式が厳密に0となることを確認した。新しい傾き、Pellノルム、上記ガウス整数恒等式も検査した。別方式の法4032剰余篩付き `(d0,d1)` 完全列挙と**最大弦長100万まで**照合し、既知の7種類と一致した。

**注意**：最大弦長1億までの「他にない」は新しいガウス整数列挙器の1回の完全走査に依存する。独立した別算法による1億全走査はまだない。一般の全弦長の種類数、1億を超える最初の新型、全円数の漸近次数は未確定。新傾きの無限延長は別途全称証明済み。
