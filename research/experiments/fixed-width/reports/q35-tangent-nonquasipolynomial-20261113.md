# 3×m・q=5：接線型円数は最終的にも準多項式にならない（2026-11-13）

**証拠水準：既存の完全分類からの全称的な数学的帰結。** 既存の接線型分類・二階差分公式を再利用する。全5点円数 F_5 についての主張ではない。

## 命題

接線型のちょうど5点円数 `T_5(m)` は、どの整数周期 `p≥1` に対しても、十分大きい整数 `m` 上で各剰余類ごとに多項式で与えられる（最終準多項式）ことはない。

特に `T_5(m)` は最終的に単一の多項式にはならない。接線型計数の母関数は
```
sum_{m>=0} T_5(m) z^m
 = (2/(1-z)^2) sum_{j>=0} z^(a_j+1)
```
という形式的冪級数である。ただし `a_0=8, a_1=48, a_{j+1}=6a_j-a_{j-1}`。

## 証明

先行研究で証明済みの完全分類より
```
T_5(m) = 2 sum_{j>=0} max(0,m-a_j).
```
よって中心二階差分 `D(m)=T_5(m+1)-2T_5(m)+T_5(m-1)` は `m=a_j` で2、それ以外で0となる。

仮に `T_5` が周期 `p` の最終準多項式なら、`D` も同じ周期の最終準多項式である（各剰余類の多項式をずらして差分を取ればよい）。しかし `D(m)` は全ての整数 `m` で0または2なので、各剰余類の多項式は無限個の点で有界であり定数でなければならない。したがって `D` は最終的に周期 `p` の周期列となる。

一方、`a_j` は無限に増え、`a_{j+1}-a_j` は無限大へ発散する（漸化式と初期値から単調増加し、差も増加する）。ゆえに `D` は値2を無限回取りながら、その出現間隔が無界である。非零値を無限回取る最終周期列にはそのような性質はない。矛盾。

母関数の式は `m>a` に対する `sum_{m>=0}(m-a)_+ z^m=z^(a+1)/(1-z)^2` を各 `a_j` について加えるだけで従う。各係数には有限個の項しか寄与しないので形式的冪級数として正当。

## 境界と次の課題

これは接線型部分列の非準多項式性であり、非接線型を加えた全円数 `F_5(m)` の非準多項式性を意味しない。非接線型の二階差分が接線型の跳躍を相殺する可能性は、この証明では排除していない。
