# グラフ星型整数共円構成の多項式ビット長化と幾何入力の #P 完全性

2026-11-02。最新 main（開始時 df34855e1bdd8afec9467f9d622d1c8d5037c5b6）、AGENTS.md、knowledge/README.md、generated/summary.md、K0602、K0635 を確認。K0602 の「有限個の代数条件を避ける」存在証明を、明示的な多項式時間・多項式ビット長の算法に置き換える。これは K0635 が明示的に未証明としていた整数座標入力への計数困難性を解消する。

## 定理 A（明示構成）

頂点集合 [t]、辺集合 E≠∅ を持つ任意の有限単純グラフ G と整数 q≥4 に対し、N=1+t+(q−3)|E| 個の相異なる整数平面点を決定的に構成でき、共円・共線の禁止 q 点組は各辺 ab に対応する {O,V_a,V_b,P_ab,1,...,P_ab,q−3} のみである。算法は N に関して多項式時間、各整数座標のビット長は O(N log(N+1)) である。特に固定 q=4 ではグラフ入力長に関して多項式時間・多項式ビット長である。

**芯点を固定する。** O=(0,0)、V_i=(i,i²) (1≤i≤t)。放物線上の異なる3点は非共線である。任意の円 x²+y²+Ax+By+C=0 と放物線の交点の x 座標は
\[
 x^4+(B+1)x^2+Ax+C=0
\]
を満たす。4個の異なる非負根が存在すると、その和は正であるが、三次項がないため根の和は0で矛盾する。よって芯点の4点は共円でない。

各辺 a<b に割り当てる円は整数係数の
\[
 \Gamma_{ab}:\quad x^2+y^2+A_{ab}x+B_{ab}y=0,\quad
 A_{ab}=ab(a+b),\quad B_{ab}=-(1+a^2+ab+b^2).
\]
これは O,V_a,V_b を通り、他の芯点を含まない。異なる辺の円は異なる（同じ円なら芯点4点が共円になる）。係数の絶対値は O(t³)。

**有界整数傾きで私有点を選ぶ。** 各辺に q−3 点を順に追加する。整数 s≥1 の直線 y=sx と Γ_ab の O 以外の交点を
\[
 p_{ab}(s)=\left(-\frac{A_{ab}+B_{ab}s}{1+s^2},
 -\frac{s(A_{ab}+B_{ab}s)}{1+s^2}\right)
\]
とする。A+Bs=0 の場合は O になるため棄却する。それ以外では s の異なる候補は異なる点である。

既存点数は N 未満。候補点について以下をすべて避ける。

1. 既存点との一致（高々 N 個の傾き）。
2. 別の割当円 Γ_cd 上にあること（各円との交点高々2、合計高々 2|E| 個）。
3. 既存2点と共線になること（各直線との交点高々2、合計高々 2 binom(N,2) 個）。
4. 既存3点が定める円のうち Γ_ab とは異なる円上にあること（各円との交点高々2、合計高々 2 binom(N,3) 個）。

なお、既存3点は非共線なので円が一意に定まる。既存3点がすべて Γ_ab 上なら4点目が同じ円にあることは意図した共円性として許す。候補が O になる傾きも高々1個である。従って
\[
 M=2\binom N3+2\binom N2+N+2|E|+3
\]
として s=1,2,...,M を順に試せば、必ず採用可能な候補がある。全判定は有理数の行列式・円方程式の厳密な整数演算で実行できる。

帰納的に、3点共線はなく、意図した割当円以外の4点共円もない。各 Γ_ab には対応する O,V_a,V_b と q−3 私有点だけが載る。他の私有点は条件2で除外し、他の芯点は放物線の性質で除外した。従って q 点以上の共円集合は各 Γ_ab のちょうど q 点のみで、禁止 q 点組は指定通り。

**整数化と計算量。** N≥t,|E| かつ M=O(N³) なので、各有理点の分子・分母は N の多項式で抑えられ、ビット長 O(log(N+1))。私有点ごとの分母 1+s² をすべて掛けた正整数 D で全点を一様に拡大する。私有点数は (q−3)|E|<N なので log₂ D=O(N log(N+1))。整数化後の座標も O(N log(N+1)) ビット。傾き候補数 O(N³)、各候補の検査条件数 O(N³)、追加点数 O(N) だから、全体は多項式時間である。整数相似拡大は共線・共円関係を保存する。

## 定理 B（明示整数幾何入力の #P 完全性）

入力として、相異なる整数平面点の明示リストを与え、4点が共線または共円になることを禁止する共円ゲームの極大安全配置総数を数える問題は、**多項式時間チューリング還元の意味で #P 完全**である。さらに、3点共線がない入力に制限しても #P 困難である。

**#P 所属。** 4点の共線・共円は整数行列式で判定でき、入力点数の4乗個の組を列挙して安全性と全未選択点への追加不能性を検査できる。非決定的に点部分集合を一意に選ぶことで、受理経路数が極大配置数になる。

**#P 困難。** K0635 の #VertexCover からの単一照会還元で、元の n 頂点 m 辺グラフから多項式サイズの分割グラフ H を構成する。K0602 による H のグラフ星型4点禁止超辺の極大配置数 T(H)=1+d(H) と、K0635 の
\[
 \#VC(G')=\left\lfloor\frac{T(H)-2}{2^{(n'+1)m'}}\right\rfloor
\]
（G' は孤立頂点除去後、n',m' はその頂点数・辺数）を使う。定理 A を q=4 に適用すれば、H の星型禁止超辺を**多項式時間・多項式ビット長の整数座標**で実現できる。ゆえに整数座標入力の極大配置数を1回問い合わせ、上の整数除算と孤立頂点の 2 冪補正を行うだけで #VertexCover を計数できる。構成した点集合には3点共線もない。

#P 完全という語は上記のチューリング還元の意味に限定する。標準 n×n 全格子盤の計数困難性、空盤勝敗・Grundy 数の困難性、q≥5 の計数困難性は本証明の対象外。
