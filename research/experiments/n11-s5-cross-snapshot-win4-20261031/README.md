# 11×11：凍結S5と旧計算結果のWIN5証人統合

`manifest.json` は、2026-10-12凍結S5厳密判定cache（5,851類）に含まれない、保存済みの別系統S5計算結果のWIN5 **2類**から得られる、S4 WIN証人 **6類**を記録する。証拠源をGit blob SHAで固定し、D4・4×4整数行列式・勝敗極性・親子合法性・重複・矛盾を `verify.js` で再計算する。

```sh
node research/experiments/n11-s5-cross-snapshot-win4-20261031/verify.js
```

凍結cache単独のWIN5 159類が被覆するS4 WINは549類。2件のWIN5を統合すると161類からS4 WIN **555類**となり、差分6類のうち中央60を含むのは4類。これらは未解決19初手軌道のうち5軌道（16、3、14、49、1）に接続する。逆に、別途追加されたLOSS5 30類が改善するS4親112類との重複は0で、直近のLOSS4候補110類をさらに削減したわけではない。

**重要**：S5のWINは保存済み厳密探索のラベルを利用したもので、今回終局まで独立再計算していない。新規の局面勝敗確定ではなく、異なる既存cacheの統合による、凍結比較集合に対する証人被覆の増分である。二石rootの新規閉鎖は0。空盤は **UNKNOWN**。
