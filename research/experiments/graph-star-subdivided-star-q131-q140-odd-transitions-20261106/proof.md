## 解析的証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) と置くと、負根は \(F_k(y)=r-y-(a-y)y^k=0\) に対応する。
\(0<y\le1\) では \(F_k(y)\ge r-a>0\)、\(a\le y\le r\) では正、\(y>r\) では \((y-a)y^k>(y-a)y>y-r\) より正。従って根候補は \(1<y<a\) に限られる。

\(H_k(y)=(a-y)y^k\) の最大点は \(y_*=ka/(k+1)\) である。
境界 \(k_-\) で \(H_{k_-}(y_*)<r-a\) なら \(F_{k_-}>0\)。
境界 \(k_+=k_-+2\) で \(F_{k_+}(y_*)<0\) なら、\(F(1),F(a)>0\) と連続性により少なくとも二根。
\(T_{k,r}(-x)\) の非零係数の符号変化は2回なのでデカルトの符号法則でちょうど二根、重複度はともに1。正根は全係数正のため存在しない。
\(1<y<a\) で \(y^k\) は \(k\) とともに厳密増加するので境界から全奇数 \(k\ge3\) に拡張できる。

## 境界の厳密整数検査

\(A=k(r+2)\)、\(B=(k+1)(r+1)\) と置く。非存在側は十分条件
\((r^2-2)(k+1)B^k>(r+2)A^k\) を、存在側は
\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\) を用いる。
整数のみで比較し浮動小数点誤差はない。

```python
bounds = [[131,1721],[132,1737],[133,1753],[134,1769],[135,1783],[136,1799],[137,1815],[138,1831],[139,1847],[140,1861]]
for q, kp in bounds:
    r = q - 3
    for k, yes in ((kp-2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if yes:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
print("20 exact inequalities passed")
```
