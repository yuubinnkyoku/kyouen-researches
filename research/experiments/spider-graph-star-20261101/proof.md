# 細分星型共円構成：終局母関数と q=4/5 の相転移

2026-11-01。K0602 の整数幾何実現と極大配置の削除集合公式を前提とする。無界命題は以下の全称証明に基づき、有限列挙は独立した検査である。

## 定義・定理

S_d は中心 c、中間頂点 m_i、葉 l_i (1<=i<=d) と辺 c--m_i--l_i からなる木。d>=1、q>=4、r=q-3、N=2+2(r+1)d、s=N-2d。K0602 の N 点整数共円実現の極大安全配置の石数別母関数を P_{d,r}(u) とする。

\[
\boxed{P_{d,r}(u)=u^s(r(r+1)+u)^d+((r+2)^d-1)u^{s+d-1}+u^{s+2d-1}.}
\]

総数は (r²+r+1)^d+(r+2)^d。d>=3 なら実現する終局石数は s,...,s+d と s+2d-1 の d+2 種類で、欠番は s+d+1,...,s+2d-2 の d-2 種類。

## 全称証明

K0602 により、共通点 O を除く極大配置はちょうど1個（N-1石）。O を含む極大配置は、グラフの削除頂点集合 X の各頂点が残存隣接点を持つ場合に限られ、重みは r^{e(V\setminus X)}u^{N-|X|-e(V\setminus X)} である。

中心 c を残す場合、各枝の (m_i,l_i) は (残す,残す)、(残す,削除)、(削除,残す) の3通りだけ。両方削除すると葉が支配されない。各枝の重みは順に r²u^{-2}, ru^{-2}, u^{-1}。枝は独立なので、中心残存寄与は

\[
u^N((r²+r)u^{-2}+u^{-1})^d=u^{N-2d}(r(r+1)+u)^d.
\]

中心 c を削除する場合も各枝は (残す,残す)、(残す,削除)、(削除,残す) の3通りで、重みは順に ru^{-1},u^{-1},u^{-1}。ただし中心が支配されるには少なくとも1本の枝の中間頂点 m_i が残る必要がある。全枝が (削除,残す) となる1通りを除外し、中心自身の削除 u^{-1} を掛けると

\[
u^N u^{-1}(((r+2)u^{-1})^d-u^{-d})=((r+2)^d-1)u^{N-d-1}.
\]

O を除く1配置を加えて母関数が得られる。u=1 で総数を得る。第一項の全 d+1 次数の係数は正、第二項の指数はその範囲内、第三項の指数は s+2d-1。d>=3 の終局長集合と欠番も従う。

## 一様極大配置の分布

A=r²+r+1、B=r+2、p=1/A とする。第一項の重みの総和は A^d であり、その内部では H-s が厳密に Bin(d,p) に従う。残りの総重みは B^d なので

\[
d_{TV}(\mathcal L(H-s),\mathrm{Bin}(d,p))\le B^d/(A^d+B^d).
\]

r>=2 (q>=5) なら A-B=r²-1>0、右辺は指数的に0。二項分布の中心極限定理から

\[
(H-s-dp)/\sqrt{dp(1-p)}\Longrightarrow N(0,1).
\]

r=1 (q=4) なら A=B=3。第一項の重みは 3^d、第二項は 3^d-1、第三項は1で総重みは 2\cdot3^d。第一項の条件付き分布は Bin(d,1/3)、第二項は H=s+d-1、第三項は H=s+2d-1 で重み 1/(2\cdot3^d)。大数の法則から

\[
(H-s)/d\Longrightarrow\tfrac12\delta_{1/3}+\tfrac12\delta_1.
\]

2つの峰が距離 O(d) だけ離れた正の質量を持つため、全体を単一の \sqrt d 規模の非退化正規分布として中心化することはできない。

## 独立検査と限界

verify.py は閉形式を使わず (1) 頂点削除集合を直接全列挙し、支配条件・残存辺の重みを計算する28条件、(2) q点禁止超辺を直接生成して全点部分集合の安全性・極大性を判定する9条件・計1,608,000局面を照合し、不一致0。標準の全格子盤や無作為着手順の分布、11×11の勝敗は対象外。K0611の星と比較すると、全辺を一回細分した木は q>=5 で正規極限を持つ一方、q=4 では二峰混合となる。
