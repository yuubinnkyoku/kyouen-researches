# z=13・y>=6 一様2トークン全Grundy分類（K1061）証明報告

2026-11-19/20。高速レーン。対象は κ=1 残余ゲーム H(R;(x,y);13) の2トークン族、
全ての x>=y>=6・全ての R>=0。記法: S=x+y、Y=2y、d=x−y。O[a,b] / E[a,b] は
それぞれ奇数・偶数の閉区間。

## 定理（全称）

基底 K0832 の A/B/C 再帰・Theorem T・一般 tail を用い、次が成り立つ:

  - R=0: 値 0（終局）。
  - tail R>=S+14: 値 S mod 2。
  - 帯域 1<=R<=S+13 は下の閉形式で完全分類され、値は 0/1/2。

値2（T）:
  - ラダー O[1,13]（奇数）。
  - 格子点: d+z≡2 (mod 4)、d<=z のとき R=Y+(d+z)/2。z=13 では d∈{1,5,9,13}、
    点 R=Y+7,Y+9,Y+11,Y+13。
  - 掃引列 d=14: O[Y+13, S+13]。
  - pin: d>=15 で R=Y+13。
  - 縮退セル:
      (y,d)=(6,0): ラダーは O[1,11] で止まる。
      (y,d)=(6,1): 連続ラダー O[1,19]=O[1,Y+7]。

値1（P、帯域内）:
  - 偶 d<=12: E[14, Y+4+2⌈(d+2)/4⌉]。
  - d=14       : E[14, Y+12]。
  - 偶 d>=16   : E[14, Y+12] ∪ O[Y+15, S+13]。
  - 奇 d<=13   : E[14, S+13] ∪ O[Y+7+2⌈d/4⌉, S+12]。
  - 奇 d>=15   : E[14, Y+12] ∪ O[Y+15, S+12]。
  - 縮退セル (y,d)=(6,0): 値1なし。
  （(6,1) の P は奇 d=1 標準クラスと同一。）

低残容量 R<=19 は高さのみの縮約で単一トークン H(R;(S;);13) に一致する
（y=6..19・d=0..15 で 5,472 点のエンジン照合、最初の失敗は (6,2), R=20）。

## 子分解と全称証明

値の再帰は K0832 の A/B/C 分解に従う: 各手は
  - 2つのトークンのいずれかを 1 減らす（子 A=H(R−1;(x−1,y);13)、B=H(R−1;(x,y−1);13)）、
  - または第三の手 z 減少 C=1⊕H(R−1;(x,y);12)。
ただし x=y では A と B は同一多重集合子に合流する。

全称性は二段帰納による:
  1. y=6 行の x 外帰納。x=6（d=0）の子は B=K1045(6,·) と C=1⊕K1056(6,6,·) のみで
     両者は出版済み全称定理。x 各ステップで A は同一 y=6 行の x−1 列（帰納仮定）、
     B=K1045(x,·)、C=1⊕K1056(x,6,·)。ゆえに y=6 全行が determinate。
  2. y>=7 は y に関する強帰納: B=同一 x の y−1 行（帰納仮定、ただし y−1=6 はステップ
     1 で確定済み）、A は同行 x−1 列、C=1⊕K1056(x,y,·)。
  3. 各 (y,d) 列の全 R∈[1,S+13] は bands.py の A/B/C 署名帯表で丁度1回ずつ被覆
     され（coverage smoke 573,319 行・bad=0）、mex(署名) が閉形式値を与える。
     R=0 は終局、R>=S+14 は K0832 一般 tail。
署名帯表は値閉形式を一切呼ばない独立 artifact であり、band_derive.py の
閉形式子集合 {B,A,C} と全点で一致する（V1）。ゆえに「子3つがそれぞれ出版済み
定理または帰納仮定で閉じる」ことと「署名帯表の mex が閉形式値に一致する」こと
から全称分類が従う。
