# 残余禁止辺が4本以下のrank-4ゲーム: Grundy上界5と達成型の完全分類

- 日付: 2026-10-19
- 確認したmain: `bb59f5e5bd3193baa03ba2553a9afe24aacf23f2`
- 対象: 通常プレイの一点追加・完全指摘。残余禁止辺は包含極小で、サイズ2〜4。元の幾何配置を仮定しない抽象禁止集合ゲーム。
- 証拠水準: 有限完全列挙に基づく全称的な**計算機援用証明**。9点・11点の達成例は独立した占有集合再帰でも直接検証。

## 定理

現在合法な点集合上の包含極小残余禁止辺が高々4本で、各辺の大きさが2〜4なら、Grundy値は **5以下**。

孤立点（どの残余禁止辺にも属さない点）を除いた核で、Grundy値が5となる場合は、辺と頂点の改名を除いて**ちょうど2種類**。一方は9頂点で辺サイズが (2,3,3,4)、もう一方は11頂点で4辺すべてサイズ4。特に4本の禁止4点集合だけでもg=5を実現する。幾何学的な共円・共線配置として実現できるという主張は**しない**。

孤立点がf個なら、その独立成分のGrundy値はf mod 2であり、全体の値は核の値とのxor。0〜5はxor 1で集合として不変なので、上界5は孤立点を含めても成立する。ただし孤立点がある場合、g=5の達成型が上記2種類に限られるわけではない。

## 達成例

9頂点を0〜8とすると、4辺を

```
{0,2}
{1,2,8}
{3,4,8}
{5,6,7,8}
```

と置く。空局面から0〜8の各点に置いたときの子Grundy値は、順に

```
1, 2, 0, 0, 0, 4, 4, 4, 3
```

なので、mex{0,1,2,3,4}=5。これは4辺・rank4でg=5を達成する最少頂点数（孤立点を除いた場合）。

4辺すべてサイズ4の11頂点達成例は

```
{0,6,9,10}
{1,2,5,6}
{3,4,5,6}
{7,8,9,10}
```

で、11個の子Grundy値は `4,0,0,0,0,2,1,3,3,0,0`。こちらもmexは5。

## 完全性の有限帰着

h本の禁止辺（1≤h≤4）を番号0,...,h-1で区別する。孤立点を除く任意の頂点vは、どの辺に属するかという空でない集合T(v)⊆{0,...,h-1}を持つ。種類は2^h-1個で、各種類の頂点数c_Tは非負整数。各辺の大きさは2〜4だから

\[
2\le\sum_{T\ni i}c_T\le4\quad (0\le i<h).
\]

包含極小性は、異なるi,jに対し「iに属しjに属さない頂点が少なくとも一つある」という条件と同値。これで**全ての**該当超グラフを、辺の番号付きで漏れなく列挙できる。辺が同じ種類に属する頂点は交換可能で、残余数ベクトルcだけで次の手が決まる。c_T>0の点を一つ置くとc_Tを1減らす。ただし、その手でいずれかの辺の残数が0になるなら不合法。残数の総和が減るので、mex再帰は停止し、全局面のGrundy値を厳密に与える。

h=4の場合、辺サイズの上限4だけで制限した非負整数ベクトルは**92,550**個。辺サイズ2以上と包含極小性を課すと**37,592**個。各ベクトルについて、上記の有限mex再帰で計算した結果は次のとおり。

| g | 0 | 1 | 2 | 3 | 4 | 5 | 6以上 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 4辺・サイズ2〜4 | 13,508 | 13,427 | 5,111 | 5,270 | 240 | 36 | **0** |
| 4辺すべてサイズ4 | 1,269 | 1,294 | 429 | 602 | 36 | 12 | **0** |

3辺では562種類で最大3（既存の3辺分類と一致）。2辺では23種類で最大3、1辺では3種類で最大1。禁止辺0本では孤立点の偶奇のみ。したがって4辺以下でg≤5。

4辺のg=5の36個の番号付きベクトルを、4!通りの辺の改名で正規化すると、**9頂点の軌道24個**と**11頂点の軌道12個**の2軌道のみ。よって上記の2種類で尽くされる。これは抽象禁止集合に関する分類であり、幾何実現性を含まない。

## 独立検証と再現

- `enumerate.py`: 辺への所属種類ごとの残数でmexを再帰計算。h=1,2,3,4を列挙し、g=5の辺改名軌道を検査。最小達成例は別の全占有subset再帰で再検算。
- `independent.cpp`: Pythonの残数mexを使わず、各ベクトルを実際の頂点と4個のbitmask辺に展開し、全2^n占有集合を降順に評価する独立C++検査。37,592個すべてで一致。辺改名による軌道も別実装で2個と確認。
- `results.json`: Pythonが出力した集計と明示的な達成例。

実行例:

```sh
python3 enumerate.py
g++ -O3 -std=c++17 -Wall -Wextra -pedantic independent.cpp -o independent
./independent
```

PythonとC++でh=4の37,592個すべての分布、サイズ4に限った分布、g=5の2軌道・24/12の分割が一致。C++は実行時に全結果をassert相当の条件で照合して非ゼロ終了する。

## 適用範囲と残件

この上界は、標準の4点禁止共円ゲームで、現在の合法点上の包含極小残余禁止辺が4本以下の**あらゆる安全局面**に適用できる。全禁止辺は元の4点禁止組の残余なのでサイズは高々4、合法点だけを残せば1点辺は存在しない。孤立点のxorを考慮してもg≤5。

残余辺が4本でg=5の抽象型が、実際の整数格子上の安全局面で実現できるかは未解決。11×11の探索時間が短縮するという性能主張も行わない。
