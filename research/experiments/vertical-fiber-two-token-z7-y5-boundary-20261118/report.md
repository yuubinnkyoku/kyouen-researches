# 2トークン残余ゲーム \\(z=7,\\ y=5\\) の全Grundy分類

- 日付: 2026-11-18
- 対象: 抽象残余ゲーム \\(H(R;(x,y);z)\\)、\\(x\\ge y\\ge1\\)、固定 \\(z=7,y=5\\)、全 \\(x\\ge5,R\\ge0\\)
- 状態: **全称定理**。全称性は \\(R\\) に関する強帰納法と、全 \\(x\\ge5\\)・全 \\(1\\le R\\le x+12\\) を覆うA/B/C選択肢署名表、および既証明tail定理（K0832高R縮約 \\(R\\ge S+|X|+z-1\\)）による。
- 依存: K0832のTheorem T・単一トークン閉形式・高さだけの縮約・高R tail、K0980の \\(z=7,y=4\\) 切片、K0884の \\(z=6,y=5\\) 切片。

\\[

## 証明

### 1. A/B/C再帰

\\(R=0\\) は終局で値0。\\(R\\ge1,x\\ge6\\) では選択肢値集合は
\\[
V_x(R)=\\left\\{
H(R-1;(x-1,5);7),\\
H(R-1;(x,4);7),\\
1\\oplus H(R-1;(x,5);6)
\\right\\}.
\\]
順にA手（トークン \\(x\\to x-1\\)）・B手（トークン \\(5\\to4\\)）・C手（\\(z:7\\to6\\)）である。A子は \\(R\\) に関する強帰納仮説、B子はK0980、C子はK0884で評価される。

\\(x=5\\) では2個のトークンがともに5であり、どちらを減らしても同じ \\((5,4)\\) 子になる。従って
\\[
V_5(R)=\\left\\{
H(R-1;(5,4);7),\\
1\\oplus H(R-1;(5,5);6)
\\right\\},
\\]
であり、第一子はK0980だけで評価できる。

### 2. mexを決める原理

K0832のTheorem Tより、全残余値は2以下であり、偶数残容量の親の値は1以下である。

- 親 \\(R\\) が奇数なら子の残容量は偶数。A/B/C子はいずれも0または1である。従って \\(V_x(R)\\subseteq\\{0,1\\}\\)。署名 \\(01=\\{0,1\\}\\)、\\(0=\\{0\\}\\)、\\(1=\\{1\\}\\) のmexはそれぞれ2、1、0。
- 親 \\(R\\) が偶数なら親値は高々1。従って \\(0\\in V_x(R)\\) なら値1、\\(0\\notin V_x(R)\\) なら値0。

### 構造の観察

- 特異伸長はy=1: \\(x=9\\)、y=2: \\(x=10\\)、y=3: \\(x=11\\)、y=4: \\(x=12\\)、y=5: \\(x=13\\) と1ずつシフトし、\\(x=y+8\\)。区間は \\(O[17,25]=O[17,x+12]\\)（y=4では \\(O[17,x+11]\\)）とtail境界の1つ手前まで伸びる。
- 単発の値2追加点は \\(x=y+3\\) と \\(x=y+7\\) に現れ、値は \\(2y+5\\) と \\(2y+7\\)（y=5では \\(x=8\\) の15と \\(x=12\\) の17）。定常値2位置は \\(\\{1,3,5,7,2y+7\\}\\)。
- 値1位置の構造も \\(y\\) とともに規則的に拡張される: 低域は偶数 \\(\\{8,\\ldots,2y+6\\}\\)、過渡 \\(I\\) 開始は \\(2y+5\\) と \\(2y+7\\)、定常奇数段の \\(O\\) 帯は下端 \\(2y+9\\)、上端偶数 \\(x+(2y+3)\\)・奇数 \\(x+(2y+2)\\)。y=6以降のK0976候補式と整合する。
- 本項の直接再帰はK0976のy=5行の二方式有限照合に第三の独立エンジンを追加するものであり、かつ \\(y=5\\) 行を全称で確定する。
