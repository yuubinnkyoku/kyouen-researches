## 一点追加障害の強化

前回の提供辺は非自明な四点だけを含み、二つの完全対からなる四点を省いていた。
候補u∉Sで2539−u∈Sなら、q={6,2533,u,2539−u}も禁止四点である。
固定点{6,2533}とuを保つ安全集合は2539−uを必ず失う。
従って前回の三点以下のhitting障害族へ、単点障害{2539−u}を加える。

1255候補にこの四点を追加した。全1281候補の障害は6514+1255=7769四点となり、
全てを独立generic整数4×4行列式検査で0と実確認した。
既存bounded hitting探索と、探索コードをimportしない独立証明木checkerを使い、
**116点を五点以下の削除では使えないと排除した。以前の60点を全て含み、新規56点が加わる。**
負証明木はpacking248・branch99 node。残る1165点には、この強化された必要障害族だけをhitする削除証人がある。
それは安全な改善証人でも、他の全幾何条件を回避する証人でもない。
提供辺の完全性は負結果の前提にしない。

Sからの削除集合Dは、追加点uの各禁止四点から固定点とuを除いた障害をhitしなければならない。
完全対の四点から単点障害が得られる点だけが今回の強化であり、木の帰納健全性は以前の凍結論証を使う。

## 空対26点から少なくとも一点を追加する必要条件

Sで両側とも空の13対からなる26点集合Eは次の通り。

```

1342 1367 1512 1518 1547 1623 1847 1892 1927 2270 2277 2433 2479
```

改善TについてA=T∖S、D=S∖Tと置く。|T|>|S|なので|A|>|D|。
u∈A∖Eの鏡像2539−uはS内にあり、保持する完全対{6,2533}と二つ目の完全対を作れないためDに属する。
u↦2539−uは単射なので|A∖E|≤|D|<|A|。従って**TはEの少なくとも一点を追加しなければならない**。
116除外点とEは交わらず、この必要条件によって未知部分を26個の点仮定へ分けられる。

親の保持側CNF（51570変数144546節、SHA-256 `64496e29f631e4f4090c103e571490f7959a30558462d9b4992ec668633f561b`）に対し、
正point変数26個のORを一行RUPとして直接検査した。
固定DRAT-trimの-f -Uでs DERIVATIONを受理し、証明とreceiptを`gate-output/`へ保存した。
これは空節ではなく、親全体のUNSATを主張しない。DERIVATIONの終了値1とUNSATの終了値0を区別する。
