# 欠損2許容核の完全分類（2026-11-04、全称証明）

K0648 の有限単純グラフ G、q≥4、許容核 B と欠損 d(B) を用いる。次数2頂点集合を D、次数3頂点集合を T とする。

## 定理

欠損2の許容核 B は、以下のいずれかに一意に分類される。

1. **連結核**： (a) 次数3の単点、(b) 次数2と次数3を結ぶ辺、(c) 次数3の中央頂点と次数2の両端からなる誘導3頂点道（両端は非隣接）。
2. **非連結核**：欠損1の連結許容核を2つ、互いに頂点を共有せず、かつ両核間に辺がないように選んだ和集合。欠損1の連結許容核は次数2の単点または次数2同士の辺である。

この分類は必要十分であり、各核は重複して数えられない。特に非連結核は「単点＋単点」だけでなく「単点＋辺」「辺＋辺」も含む。

記号 A={ {v}:v∈D } ∪ { {v,w}:vw∈E(G[D]) } を欠損1連結核の集合とし、A の2要素 I,J が **両者の間に辺を持たず、交わらない** とき I∼J と書く。次数列 (2,2,3) の三角形の個数を τ とする。欠損2の許容核数は

\[
\boxed{
|T|+|E_G(D,T)|+
\sum_{v\in T}\binom{|N(v)\cap D|}{2}-\tau+
\#\{\{I,J\}\subset A:I\sim J\}.
}
\]

重み付き係数は K0648 の W(B)=(r+2)^h r^{C+a(B)-|B|-2}(r+1)^{L-a(B)}（r=q−3）を用いて、[u²]F(u)=Σ_{B:d(B)=2}W(B)。中心なし配置 u^{N−1} は別項であり、N−1=s+2（すなわち e=3）のときだけ P の s+2 係数に1を加える。

## 証明

B の誘導連結成分 Q について、外向き辺数 b(Q) と巡回数 β(Q) を用いると d(Q)=b(Q)−1+β(Q)。許容条件から b(Q)≥|Q|、かつ d(Q)≥1。したがって d(B)=2 なら (i) 欠損2の連結成分1つ、または (ii) 欠損1の連結成分2つに限られる。

(i) では b(Q)+β(Q)=3、従って |Q|≤3。|Q|=1 なら deg=3。|Q|=2 なら隣接辺の両端の次数和が5、すなわち (2,3)。|Q|=3 なら b≥3 より β=0、b=3。誘導3頂点道で各頂点の外向き次数がちょうど1だから、中央は次数3、両端は次数2。逆に列挙した各形は許容条件を満たし d=2。三角形の (2,2,3) は両端が核外隣接点を持たないので除外する。

(ii) では各成分が欠損1である。欠損1連結核は K0648 に基づく既証明の単点Dまたは辺DD。2つの核が非隣接で頂点を共有しないことが、誘導連結成分として残る必要十分条件である。各成分の外向き隣接点は、相手核に接続していないため失われない。よって和集合も許容核で欠損2。逆も成分分解の一意性から従う。□
