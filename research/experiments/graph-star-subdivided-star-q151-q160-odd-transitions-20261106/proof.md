## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおくと、負根の条件は \(F_k(y)=r-y-(a-y)y^k=0\) となる。\(r\ge148\) では \(y\le1\)、\(a\le y\le r\)、\(y>r\) に根はなく、可能性があるのは \(1<y<a\) のみである。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大となる。

非存在境界 \(k_-\) では \(H_{k_-}(y_*)<r-a\) を確認し、\(F_{k_-}>0\) を得る。存在境界 \(k_+=k_-+2\) では \(1<y_*<a\) と \(F_{k_+}(y_*)<0\) を確認する。両端で \(F>0\) なので2根が存在する。\(T_{k,r}(-x)\) の符号変化は2回であり、デカルトの符号法則からちょうど2個の相異なる単根である。正根は係数が全て正なのでない。\(1<y<a\) において \(y^k\) は k とともに厳密増加するため、各境界から全奇数 k へ拡張される。

\(A=k(r+2), B=(k+1)(r+1)\) として、非存在側は \((r^2-2)(k+1)B^k>(r+2)A^k\)、存在側は \((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\) を整数演算で検査した。これは先行 q=141〜150 の証明と同じ解析枠組みであり、新規部分は20境界の厳密検証である。

```python
bounds = [[151,2035],[152,2051],[153,2067],[154,2081],[155,2097],[156,2113],[157,2129],[158,2145],[159,2161],[160,2177]]
for q, kp in bounds:
    r = q - 3
    for k, exists in ((kp - 2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if exists:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
    print(q, "pass")
```
