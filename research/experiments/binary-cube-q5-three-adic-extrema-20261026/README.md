# 5点二値超立方体切片：3進付値の巨大有限区間最大値（2026-10-26）

対象は K0561 の `E_{d,5}`（`{0,1}^d` の5頂点をちょうど含む超平面切片数）。**平面共円ゲームの勝敗ではない**。

## 厳密結果

`v_3` を3進付値とする。既証明の K0567・定理11と有限の厳密な合同計算を合わせて、以下を得た。

| 次元の範囲 | `max v_3(E_{d,5})` | 最大を取る全次元 |
|---|---:|---|
| `5 <= d <= 10^5` | **13** | `55246, 79149` |
| `5 <= d <= 10^6` | **14** | `920111` |
| `5 <= d <= 10^12` | **26** | `134093761688, 970208334687` |
| `5 <= d <= 10^18` | **41** | **`863338084376830994`** |

特に、

$$
\boxed{\max_{5\le d\le10^{18}}v_3(E_{d,5})=41}
$$

であり、達成する次元は一つだけである。これは `10^18` 個の次元を直接列挙した主張ではない。

## 証明

K0567・定理11は、任意の `t>=2` で `P_t=2*3^(t-1)`、`D_t=max(5,t+2)` と置くと、`d>=D_t` に対し

$$
3^t\mid E_{d,5}\quad\Longleftrightarrow\quad
d\bmod P_t\in R_t
$$

を証明している。ここで `R_t` は4個の剰余類からなり、`R_2={2,3,4,5}`。各 `r in R_t` は `r,r+P_t,r+2P_t` のうち**ただ一つ**を `R_(t+1)` に持つ。この一意持ち上げは無界の全称定理であり、今回の計算からの外挿ではない。

K0561の全次元指数公式を2の冪で割った

$$
120\,E_{d,5}/2^d =
16^d-30\cdot12^d+140\cdot10^d+135\cdot9^d
-1215\cdot8^d+2205\cdot7^d-1977\cdot6^d
+780\cdot5^d+250\cdot4^d-495\cdot3^d
+255\cdot2^d-49
$$

から、各段階の3候補を法 `3^(t+1)` で厳密判定した。分母120を扱うため、(1) 分子を `120*3^t` で剰余計算して120で整数除算する方法、(2) 分子を `3^(t+1)` で計算して3で割り、40の逆元を掛ける方法を照合した。**同一のK0561係数を共有する算術的二方式**であり、係数自体を独立に再証明したものではない。

最終段階の剰余類は以下の通り。

| `t` | `P_t` | `R_t` |
|---:|---:|---|
| 38 | 900567811781994726 | 598841409424707995, 607800646991213230, 800015958976071945, 863338084376830994 |
| 39 | 2701703435345984178 | 800015958976071945, 863338084376830994, 2399977032988697447, 2408936270555202682 |
| 40 | 8105110306037952534 | 863338084376830994, 2399977032988697447, 5110639705901186860, 6203422829668040301 |
| 41 | 24315330918113857602 | **863338084376830994**, 2399977032988697447, 14308533135705992835, 21320860317977091928 |
| 42 | 72945992754341572806 | 2399977032988697447, 14308533135705992835, 45636191236090949530, 49493999920604546198 |

`P_41 > 10^18` なので、`R_41` のうち区間に入るのは `863338084376830994` のみ。`R_42` の4剰余はすべて `10^18` より大きく、`P_42 > 10^18` なので区間内には一つもない。これで最大が41と確定する。

**小さい次元の例外処理が必要。** 定理11の周期は `d>=D_t` からの最終周期である。`t=42` では `D_42=44` なので、`5<=d<=43` の40個について、指数公式を通常の整数で直接評価し `3^42` で割り切れないことを確認した。`t=41` の例外も同時に検査した。他の区間の `t+1` に対しても `5<=d<D_(t+1)` を個別に検査している。これにより最終周期を開始前へ誤用していない。

同じ手法で、`10^5` では `R_13` に2点・`R_14` に0点、`10^6` では `R_14` に1点・`R_15` に0点、`10^12` では `R_26` に2点・`R_27` に0点となる。上表の達成次元は全て `D_t` 以降にある。
