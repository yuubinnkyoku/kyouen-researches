# 3枝REMO決定性のサイズ境界（枝サイズ≤12）×r=9

2026-11-17。K0906が定理J（sv/det は r ≥ max(M,2) で不変）の機械アンカー
として残した「cap≤12の未走査列」4本（r=9,10,13,14）のうち第1本目。
K0893（cap≤10・r=9）が「枝サイズ11,12×r=9は未走査」と残したサイズ
セルを埋め、定理I系譜のr=9列をcap≤12全域で確定する。

領域はK0875/K0876/K0893と同一の正準形で枝サイズだけ拡大:
47,595プロファイル（cap≤11: 28,065の上位互換・Burnside
261749/7805/203→47,595 orbits・1,365キー・cap-set包含
15,863⊂28,065⊂47,595は順序保存埋め込み K0882）。

スイープは独立2プロセスで実行し（添字0..24,447と23,798..47,594、

マージして単一列とした。実行環境のリセットを1回挟んだが、
両セグメントが保全され、再マージで packed 列
（sha256 02e771cd…・975,488 bytes・レコード [i, sv_mask, fl_mask,
states]・atoms は i の純関数なので劣化なし）が byte 再現した。

## 主張

**定理I9（cap≤12拡張・mixed 34キーちょうど・サイズ不変）**:
決定性が(sizes,γ)に坍縮しない（mixed）キーは、cap≤10で確定した
K0893の7族34個と**完全同一**。サイズ11/12を含む650新キー
（11枝363・12枝364・31,732プロファイル）のうち mixed は**0**:

- 新キー内訳: 一様決定45 / 一様非決定605 / mixed 0。
- 34キーの per-key 分割計数・決定側生存者（一様P_5）・
  34チェーンプロファイル全決定は K0893 と完全同一。
  cap≤10サブセンサス 98/583/34 も K0893 出版値と同一。

すなわち **K0893のr=9境界はサイズ拡張に対して閉じている**
（有限完全列挙による確定・定理E′経由で該当プロファイルを実現する
すべての盤に適用）。

**新45決定キーの構造（有限観察）**: 新キーの一様決定45個は
(1,1,11)|0, (1,11,11)|0, (10,10,12)×γ0..9, (10,12,12)×γ0..9,
(11,11,11)×γ0..10, (12,12,12)×γ0..11 ちょうど。第1敗者剰余類は
{1,2},{1,3},{2},{3} のみ（11≡2, 12≡3 mod 9）。605一様非決定
キーのうち167は可能生存者集合==チェーン生存者の和集合（観察）。

**定理J cap≤12 r=9アンカー（K0906全称定理の機械アンカー）**:
M = max C_i ≤ 8 の全キーで r=9 の det/sv は r=8 列（K0881出版）
と完全一致（0不一致）、M ≤ 7 では fl も一致。r8→r9 の det 差分
876 はすべて M=9 プロファイル、うち一様決定キーは (9,9,9)×γ0..8
（Δ=0族）ちょうど。sv-mask差分 38,070（M≤8: 0）。

**Δ=0（定理D r=9列）**: 一様サイズ1,512プロファイル（うち784は
11/12枝を含む）はすべて定理Dのr=9生存者で決定。定理D再帰は
K0859出版表（84エントリ・C=1..12・r=2..8）に一致。

**G′ r=9**: 一様決定143キーすべての決定プロファイルが
チェーン生存者を持ち、不一致0（45新キーを含む）。

**ECHO r=2..9**: 34 mixedキーのr=2..9決定性履歴（K0893 ECHO表の
r=9拡張）をピン留め。サイズ拡張はエコー/休眠/復活構造を一切
変えない: (6,6,8),(6,8,8)はr=8,9で・(8,8,9),(8,9,9)はr=3,4,5,9で・
6/9三族はr=9初覚醒。

**補題FL（K0864全称・冗長アンカー）**: 全47,595プロファイルで
第1敗者 == {C_i mod 9}・違反0。

センサス: 1,365キー = 一様決定143 / 一様非決定1,188 / mixed 34。
max_states 2,331,310（i=31964・(12,12,12)|γ=3）・状態総数
3,889,246,676。

## 限界

- 枝サイズ≥13・r≥10は本項の範囲外（K0906の残るアンカー列）。
- 定理Jは全称定理（K0906）であり、本項のr=9列はその cap≤12
  機械アンカーであって証明ではない。
- 順位決定性は本項で扱わない（検証器も順位フィールドを再導出
  しない）。
- 新キー構造・ECHO・チェーン和集合一致はすべて有限観察であり、
  一般則・全称定理へは昇格しない。
- 11×11空盤・クラスフロンティアは本項と無関係でUNKNOWNのまま。
