# 森グラフ型共円ゲームの三状態計数と星の二点終局分布（2026-11-01）

## 定理（任意の森、全称証明）

K0602 の整数点実現を、少なくとも1辺を持つ任意の有限単純森 \(G=(V,E)\) に適用する。孤立頂点も許す。\(t=|V|,\ e=|E|,\ q\ge4,\ r=q-3,\ N=1+t+re\) とする。極大安全配置の石数別多項式を \(P_G(u)\) とする。

各連結成分を任意の根で根付き木とする。頂点 \(v\) の部分木について、K0602 の「削除するグラフ頂点集合」\(X\) の重みを

\[
u^{-|X|}(r/u)^{e(V\setminus X)}
\]

とする。ただし根頂点 \(v\) の親との辺は重みに含めない。次の3種類の状態を区別する。

- \(A_v\): \(v\notin X\)（残す）。部分木の削除頂点は全て残存隣接点を持つ。
- \(B_v\): \(v\in X\) かつ部分木内に残存隣接点がある。全削除頂点の条件を満たす。
- \(C_v\): \(v\in X\) かつ部分木内に残存隣接点がない。\(v\) 以外の削除頂点は条件を満たし、\(v\) だけは親が残る場合に限り救済できる。

子の集合を \(\operatorname{ch}(v)\) とすると、空積を1として

\[
\boxed{
A_v=\prod_{w\in\operatorname{ch}(v)}
\left(\frac r u A_w+B_w+C_w\right),
}
\]

\[
\boxed{
B_v=\frac1u\left[
\prod_{w\in\operatorname{ch}(v)}(A_w+B_w)
-\prod_{w\in\operatorname{ch}(v)}B_w
\right],\qquad
C_v=\frac1u\prod_{w\in\operatorname{ch}(v)}B_w.
}
\]

葉の初期値は \(A_v=1,\ B_v=0,\ C_v=u^{-1}\)。森の各成分の根を \(v_1,\ldots,v_c\) とすれば

\[
\boxed{
P_G(u)=u^{N-1}+u^N\prod_{i=1}^{c}(A_{v_i}+B_{v_i}).
}
\]

右辺は見かけ上Laurent多項式を含むが、最終結果は非負整数係数の通常の多項式になる。この再帰は任意の頂点数、任意の次数、任意の \(q\ge4\) で正確である。各部分木について有限個の係数表を畳み込むだけなので、出力の係数のビット長を考慮しても多項式時間で計算できる。特に全 \(2^t\) 個の削除集合を列挙する必要はない。

### 証明

K0602 より、中心点 \(O\) を含まない極大配置は石数 \(N-1\) の1個だけ。\(O\) を含む極大配置は、削除グラフ頂点集合 \(X\) の各頂点が残存隣接点を持つ場合に限り生じ、\(r^{e(V\setminus X)}\) 通り、石数 \(N-|X|-e(V\setminus X)\) である。

部分木の根 \(v\) を残す場合、子 \(w\) を残すと辺 \(vw\) は両端残存であり、重み \(r/u\) を掛ける。子を削除する場合、\(w\) が未充足状態 \(C_w\) でも残存親 \(v\) によって条件を満たせる。これが \(A_v\) の積を与える。

\(v\) を削除する場合、子の未充足状態 \(C_w\) は救済できないため、各子は \(A_w\) または \(B_w\) である。少なくとも一つの子が \(A_w\) なら \(v\) も充足され \(B_v\)、一つもなければ \(v\) だけ未充足で \(C_v\) になる。頂点 \(v\) 自身を削除する重み \(u^{-1}\) を掛ければ上記の差と積を得る。根には救済する親がないので \(C\) を除き、異なる連結成分は独立に積を取る。最後に \(u^N\) を掛けて石数へ戻し、\(O\) 不在の1配置を加える。これで全称公式を証明した。□

## 星 \(K_{1,d}\) の閉形式と正規極限の反例

\(d\ge1\) とし、中心頂点に \(d\) 個の葉を接続した星を取る。\(t=d+1,\ e=d,\ N=2+(r+1)d\)。

削除集合 \(X\) について、中心を残す場合は各葉を独立に削除・残存できる。残す葉の本数を \(j\) とすれば、その辺 \(j\) 本の補助点選択は \(r^j\) 通り、終局石数は常に \(N-d\)。合計 \((r+1)^d\) 通りである。中心を削除する場合、削除した葉は残存隣接点を持てないため全葉を残すしかなく、石数 \(N-1\) の1通り。さらに \(O\) 不在の1通りが同じ石数 \(N-1\) に加わる。

従って

\[
\boxed{P_{K_{1,d}}(u)=(r+1)^d u^{N-d}+2u^{N-1}.}
\]

\(d=1\) では両指数が一致し、係数は \(r+3\) になる。\(d\ge2\) では終局石数は **ちょうど2種類**で、間の \(d-2\) 種類の整数石数は実現しない。極大配置を一様に選ぶと

\[
\Pr(H=N-d)=\frac{(r+1)^d}{(r+1)^d+2},\qquad
\Pr(H=N-1)=\frac{2}{(r+1)^d+2}.
\]

固定 \(q\ge4\)、\(d\to\infty\) では最短極大配置への集中が指数的に進む。これは K0609 の道グラフや K0610 の完全グラフ花束で成立する非退化な正規極限が、**連結な木全般には拡張できない**ことを示す反例である。実際、平均で中心化し標準偏差で規格化しても正規分布には収束しない。最短値の質量が1に収束し、残る質量が無限遠へ逃げるため、規格化分布は弱収束で点質量 \(\delta_0\) に近づく。

## 独立検証と限界

verify.py では Prüfer 符号から生成した全ラベル付き木 \(n=2,\ldots,7\)、各 \(r=1,2,3\) の **54,744条件**を、三状態再帰と全削除集合の直接判定で照合する。さらに24条件、計79,856個の点部分集合について、禁止超辺を直接作って安全性・極大性を全列挙する。星の閉形式48条件と孤立頂点を含む森3条件も照合する。いずれも厳密整数計算であり、全称証明の代替ではない。

これは K0602 の自由な整数点配置における極大安全集合の数え上げである。標準の全格子盤、無作為な着手列、最適戦略の終局分布や11×11空盤の勝敗は扱わない。
