Read-only planning/audit computation for the 19 unresolved first-move trajectories
(K0415/K0417) against the current chain-native merged exact-S5 cache. No solver
search is performed here, no unknown verdict is asserted, and no coverage/closure
claim is made by this experiment: every remaining S5 stays UNKNOWN. The standard
11x11 empty board and all 19 central-reply two-stone roots stay UNKNOWN.

## Method

`scripts/refresh_19root_frontier.py` (stdlib only):

1. Parse the merged cache fail-closed (6-field schema, canonical+safe 5-stone keys,
   no quarantined key, duplicates must agree).
2. Map cache rows and update8's 23 receipt verdicts into the frozen graph's S5
   index space; WIN/LOSS conflicts abort.
3. Refresh each of the 34,949 S4 classes from its frozen `s4_cost` (unknown
   children at graph build). Any cost child with a known WIN excludes the class;
   a class with zero unknown cost children is a *free* candidate ONLY after the
   independent Board regenerates the class's full canonical S5 child boundary and
   every child is an exact LOSS in the merged cache (fail-closed: no reliance on
   the stale graph-time cache instance).
4. Recompute per-root third-move coverage (baseline root {27,60} must still
   reproduce the published 119/119 free coverage, and it does), per-root greedy
   requirement unions, and a plain-joint greedy union over the deduplicated
   2,139 non-free groups (scheduling quantities only, not claimed optimal).
5. Refresh the frozen update8 joint plan: per-group remaining requirement,
   selection invalidation (WIN hits), and the per-root remaining sums.
6. Emit a closure worklist: for every non-free group the option class with the
   fewest still-unknown children; classes ranked by remaining count
   (`output/closure-classes.csv`); the full per-key probe order is reproducible
   with `output/probe-worklist.csv` (regenerated byte-identically by the script;
   not published as a repo file to keep the tree lean).

  34,504 classes still have unknown children; 390 baseline-excluded classes are
