# 二値五次元立方体・共六点禁止版の強解決の独立再検証

2026-10-30、main `05e2a1a6` を基準に作業。
[K0546](../../knowledge/items/K0546-five-cube-hyperplane-strong-and-general-lower-bound.md)の
五次元ゲーム強解決を、独立な実装で全局面から再計算した。

## 手法(v5、rank-check DFS)

ゲームの禁止は「6点の実アフィン共超平面（退化含む）」、つまり
安全 ⟺ **全6点部分集合が増広独立**。4点・5点の依存は合法なので、
包含極小な禁止集合は依存6点組そのものであり、circuit削減は不能である
（この点を誤った初版実装は安全局面1,085,113と誤値を出した）。

- DFSで頂点を昇順に追加して全安全集合を列挙。追加時、新しく完成する
  6点組（追加頂点を含む $C(k,5)$ 個）だけを増広行列
  （行 $(1,x)$、$6\times6$）のrankで判定。
  rankは $p=2^{61}-1$ 上の消去で、Hadamard限界 $6^3<p$ により整数rankと同値。
- Grundy・misèreはpopcount降順DP。**子は「未使用頂点のうち安全な全て」**
  （DFSの経路制約で子を記録すると誤る：初版v4はこれで空盤g=7という誤値）。
  終局（子なし）のGrundy=0、misèreの終局はN側。

実行時間57秒（WSL、1コア）。

## 教訓

1. **石追加ゲームの包含極小禁止集合は「禁止サイズの依存集合そのもの」**。
   依存(禁止サイズ未満)の集合が合法な限り、circuit化はできない。
   K0568で使ったK_6のcircuit削減CNF（19,484,942節）は同じ誤りを含むため、
   そのCNFでのUNSAT結果はK_6の上界証明として無効である。
   K_6の上界には依存7点組全部（255,036,992節、生6.9GB）のCNFが必要。
2. 全局面列挙型のゲームソルバでは、**子関係を経路制約で代用してはならない**。
   子は「未使用頂点のうち着手可能な全て」から再計算する。
