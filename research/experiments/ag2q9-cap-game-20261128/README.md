# AG(2,9) s=2 キャップ・ゲームの完全 Grundy スペクトル

## 目的

AG(2,9)（81 点、90 直線）の s=2 キャップ・ゲームのサイズ別 Grundy 分布を、
錐＋枠二重数え上げ法（K1353）で厳密に求める。

## 方法

- `scripts/build_ag2q9.py`: GF(9)=GF(3)[i]/(i^2+1) 上で AG(2,9) 盤を構築
  （垂直 9 直線 + 傾き×切片 81 直線 = 90 直線、各 9 点）。
- `scripts/cone_ag2q9.py`: 3-キャップ F = ビット {0,9,1}（親盤の添字で (0,0),(i,0),(0,i)）の錐
  （F を含む全キャップ、21,353 局面）で完全 DP。AGL(2,9) は三角形に推移的なので、
  どの 3-キャップでも同じ分布になる（検証で別の三角形 {0,27,3}, {0,30,55} も同一分布を確認）。AGL(2,9) は三角形に推移的なので
  `N_m(g) = N_3 · T_m(g) / C(m,3)`（K1353）。k=0,1,2 は mex 連鎖。

| 0 | 1 | G0: 1 |
| 1 | 81 | G1: 81 |

| 6 | 26,290,656 | G0: 12,216,096 / G1: 77,760 / G2: 13,996,800 |

| 8 | 3,411,720 | G0: 3,353,400 / G1: 58,320 |
| 9 | 239,760 | G0: 6,480 / G1: 233,280 |

- 全 63,277,282 局面: G0 19,276,705 / G1 29,537,217 / G2 13,996,800 / **G3 466,560**。
- **最大 Grundy は 3**（5-キャップの 466,560 個）。
- 錐は 21,353 局面のみ（全列挙 6,327 万局面を 0.03% に圧縮）。

## 再現

```
python scripts/build_ag2q9.py

```
