# REMO tail smooth-factor reduction — K0952

K0950 の HIT-ARITH は値1判定を「Yの素数性」と「N=MY−1の約数窓」に分けた。残っていた約数窓は、まだ一つの条件のままだった。ところが、窓の外にある小さな因子を全部まとめると、条件そのものが有限個の素数対へ分解する。

## 1. 記法と主定理

Mを素数、0≤κ≤M−2、t≥max(M,3) とし、

\[
K=(M+1)t+\kappa,\quad
Y=K+1=(M+1)t+\kappa+1,\quad
k_0=Mt+\kappa-1,
\]
\[
N=MY-1,\quad
C=\gcd(M+1,\kappa+2),
\]
\[
Q(t)=\frac{N}{C}
=\frac{M(M+1)}{C}t+\frac{M(\kappa+1)-1}{C}.
\]

Cは整数で、C≤M−1。実際、C≤κ+2≤M かつ M∤M+1 である。また

\[
\gcd\!\left(\frac{M(M+1)}C,\frac{M(\kappa+1)-1}C\right)=1.
\]

これは
\[
\gcd(M(M+1),M(\kappa+1)-1)
=\gcd(M+1,\kappa+2)=C
\]
から従う。CはK0950フォローアップのP-FACTORが与える強制小因子を、素数冪までまとめたものでもある。

**定理 K0952（全称）**:

\[
\boxed{
\sigma_Z(M,K)=1
\iff
Y\text{ が素数であり、ある整数 }e\ge1\text{ が存在して }
Ce<M,\ e\mid Q(t),\ Q(t)/e\text{ が素数}
}
\]

適用範囲は上記のM,κ,t。これはK0950 HIT-ARITHの約数窓を、有限個の素数対条件へ完全に展開した式である。eの候補は

\[
1\le e\le \left\lfloor\frac{M-1}{C}\right\rfloor
\]

なので、固定したM,κについて有限個しかない。

## 2. 証明

まずt≥Mより

\[
k_0=Mt+\kappa-1\ge M^2-1\ge M(M-1).
\]

また

\[
k_0^2-N
\ge M^2t(t-1)-M(3t+1)+2>0
\]

である。左辺はκについて単調増加し、κ=0での下界を取った。t≥3では右辺は正である。

さらにY=M²となるのはt=M−1, κ=0だけなので、この範囲ではY=M²例外は起こらない。K0950のHIT-ARITHにより、

\[
\sigma_Z(M,K)=1
\iff
Y\text{ が素数かつ }N\text{ が}[M,k_0]\text{ 内に約数を持たない}.
\]

NのM未満の素因子を全て集めた最大のM-smooth因子を

\[
D=\prod_{p<M}p^{v_p(N)},\qquad P=N/D
\]

とする。C|NでC<Mだから、Cの素因子は全てDに入り、C|Dである。

約数窓に約数がないならD<Mでなければならない。そうでなければ、Dの素因子を順に掛け、初めてM以上になる積dを取る。直前の積はM未満、最後の素因子はM−1以下なので

\[
M\le d<M(M-1)\le k_0,
\]

かつd|Nとなり矛盾する。

次にPは素数である。Pが合成なら全素因子がM以上であり、その最小素因子pは

\[
M\le p\le\sqrt P\le\sqrt N\le k_0
\]

を満たしてNの窓内約数となる。P≤k₀でもP自身が窓内約数になる。したがってPは素数かつP>k₀。

ここでe=D/Cと置けば、e|Q、Ce=D<M、Q/e=Pは素数となる。

逆にe|Q、Ce<M、Q/e=Pが素数ならN=CePである。さらに

\[
N-Ce\,k_0
=M(M+1-Ce)t+(M-Ce)\kappa+M+Ce-1>0
\]

だからP=N/(Ce)>k₀。Ce<Mなので、Nの約数はCeの約数（全てM未満）かPを含む約数（全てk₀超過）に限られ、[M,k₀]に入らない。よってHIT-ARITHからσ_Z=1。∎

## 3. 有限個の素数対への展開

\[
A=\frac{M(M+1)}C,\quad B=\frac{M(\kappa+1)-1}C
\]
とすればQ(t)=At+Bで、gcd(A,B)=1である。e|Q(t)ならgcd(e,A)=1なので、tは法eでただ一つの剰余類に入る。各eについてt=t_e+enと書けば、

\[
Y_e(n)=(M+1)en+(M+1)t_e+\kappa+1,
\]
\[
P_e(n)=An+\frac{At_e+B}{e}
\]

という二つの一次式の同時素数性に帰着する。したがって固定M,κの値1軌跡は有限個の素数対族の和である。

M=2,3のlive κはどちらもκ=0のみで、このクラスでは許されるeが1だけとなり、K0950のPAIR-2/PAIR-3が尾部でそのまま回復する。M=5,κ=0ではC=2でe=1,2の二枝が残る。実際、t=32ではY=193、N=964=4·241、Q=482=2·241、e=2であり、Q自体は素数でないのに値1となる。したがって「Qが素数であること」だけへの短絡は誤りで、e>1の枝が必要である。

## 4. P-KILL-TIGHTへの条件付き帰結

live候補をgcd(κ+1,M+1)=1で定義する。このときe=1枝の一次式

\[
L_1(t)=(M+1)t+\kappa+1,\qquad L_2(t)=At+B
\]

は素数対として局所的に許容される。

gcd(a₁,b₁)=gcd(a₂,b₂)=1で、二式は
\[
a_1b_2-a_2b_1=-\frac{M+1}{C}\ne0
\]
より比例しない。p≥3では各式の零剰余は高々1つずつなので、2個の零剰余が全剰余を覆うことはない。p=2ではMが奇数ならlive条件からκは偶数となりL₁は常に奇数、M=2ならκ=0でL₂=6t+1が常に奇数である。よって全素数pで共通の固定約数はなく、特異級数は正である。

したがって二一次式版のHardy–Littlewood予想を仮定すれば、各live κについてe=1枝だけで無限個の値1局面が得られる。これはP-KILL-TIGHTの**条件付き証明**であり、無条件の無限存在証明ではない。
