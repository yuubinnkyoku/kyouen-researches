# z=15・y=2 2トークン境界切片の全Grundy分類（K1032）

- 日付: 2026-11-19
- 対象: κ=1残余ゲーム \\(H(R;(x,2);15)\\)、全 \\(x\\ge2\\)・全 \\(R\\ge0\\)
- 状態: **全称定理**
- 依存: K0832、K1020（B子）、K1028（C子）

## 命題

\\(O[a,b]\\) は区間内の奇数、\\(I[a,\\infty)\\) は \\(a\\) 以上の全整数とする。

Grundy値2の位置集合 \\(T(x)\\):

|---:|---|
| 2 | \\(\\{1,3\\}\\) |
| 3, 4 | \\(O[1,5]\\) |
| 5, 6 | \\(O[1,7]\\) |
| 7, 8 | \\(O[1,9]\\) |
| 9, 10 | \\(O[1,11]\\) |
| 11, 12 | \\(O[1,13]\\) |
| 13 | \\(O[1,17]\\)（h=z孤立上端・上端17） |
| 14, 15, 16 | \\(O[1,15]\\) |
| 17 | \\(O[1,15]\\cup\\{19\\}\\)（前倒しpin） |
| 18 | \\(O[1,15]\\cup O[19,35]\\)（掃引行） |
| \\(x\\ge19\\) | \\(O[1,15]\\cup\\{19\\}\\) |

Grundy値1の位置集合 \\(P(x)\\):

| x | \\(P(x)\\) |
|---:|---|
| 偶数 \\(x\\le12\\) | \\(\\varnothing\\) |
| 奇数 3, 5, 7, 9, 11 | \\(I[x+3,\\infty)\\) |
| 13, 15 | \\(\\{16\\}\\cup I[18,\\infty)\\) |
| 14 | \\(\\{16\\}\\) |
| 16 | \\(\\{16,18\\}\\) |
| 17 | \\(\\{16,18\\}\\cup I[20,\\infty)\\) |
| 18 | \\(\\{16,18\\}\\) |
| 奇数 \\(x\\ge19\\) | \\(\\{16,18\\}\\cup O[21,x+16]\\cup I[x+18,\\infty)\\) |
| 偶数 \\(x\\ge20\\) | \\(\\{16,18\\}\\cup O[21,x+17]\\) |

従って
\\[
H(R;(x,2);15)=
\\begin{cases}
2,&R\\in T(x),\\
1,&R\\in P(x),\\
0,&\\text{otherwise}.
\\end{cases}
\\]

一般tailはK0832から
\\[
\\boxed{R\\ge x+18\\implies H(R;(x,2);15)=(x+2)\\bmod2.}
\\]
また高さのみ縮約から
\\[
R\\le16\\implies H(R;(x,2);15)=v_{\\rm single}(x+2,15,R).
\\]

## 構造の注記

- **pin=19=2y+z**（奇数zラダー \\(O[1,z]\\cup\\{z+2y\\}\\)）。掃引行は \\(x=z+y+1=18\\)、
  掃引行上の値2帯は \\(O[1,z]\\cup O[\\text{pin},x+y+z]=O[1,15]\\cup O[19,35]\\)。
  前倒しpin行は \\(x=z+y=17\\) で \\(O[1,15]\\cup\\{19\\}\\)
  （\\(d=x-y=15\\) 格子点・点値 \\(2y+(d+z)/2=4+15=19=2y+z\\) がpinに一致・\\(d+z=30\\equiv2\\pmod4\\)）。
- **h=z行 \\(x=z-y=13\\) の孤立上端17**: \\(2y+(d+z)/2=4+13\\)（\\(d=11=x-y\\)・\\(d+z=26\\equiv2\\pmod4\\)）。
  奇数z型h=z行孤立上端は K1025 の z=13・x=11 上端15（\\(d=9\\)・\\(d+z=22\\equiv2\\)）に続く2例目で、
  y=2横断では偶数z型（K1028 の x=12 上端15・K1030 の x=11 上端17）と対をなす。
- **値1基底点 \\(\\{16,18\\}=\\{z+1,z+3\\}\\)**: y点仮説2点型の3例目
  （K1019 の {13,15}、K1025 の {14,16} に続き、奇数zでは2例目）。
- **値1中間帯は \\(z+2y+2=21\\) 開始の奇帯**: 帯の偶奇はzに追従し（奇数z→奇数位置）、
  奇数行は \\(O[21,x+16]\\cup I[x+18,\\infty)\\)、偶数行は有限 \\(O[21,x+17]\\)。
  無限I帯は奇数x行のみで、tail \\(R\\ge x+18\\) の値 \\((x+2)\\bmod2\\) が1になる行と一致する
  （「I帯はtail値1の行にだけ現れる」一般則のy=2奇数z型確認）。
- 移行行: x=17（偶帯署名「023」群）、x=18掃引行（奇帯署名「01」・偶帯「1」交互）、
  x=19移行行（偶帯署名「12」）、x≥20偶数/x≥21奇数で定常化
  （帯構造は行偶奇完全共通・帯上端のみ \\(x+17\\)/\\(x+16\\) 入替）。

## 証明

子分解は
\\[
A=H(R-1;(x-1,2);15),\\quad
B=H(R-1;(x,1);15),\\quad
C=1\\oplus H(R-1;(x,2);14).
\\]
BはK1020、Cは1⊕K1028。x=2では二つのトークン減少手が同じ多重集合
\\((1,2)\\equiv(2,1)\\) に合流して単一の子値となり、K1020のx'=2行を帰納基底として使う。
x≥3ではAをx外帰納で閉じる。全 \\(R\\ge1\\) は検証器内の完全A/B/C署名帯表
（静的行 \\(x=2..19\\)・定常閉形式 \\(x\\ge20\\)・各行が \\(R=1..x+17\\) を互いに素に被覆）と
mex対応表で被覆し、\\(R\\ge x+18\\) はK0832一般tail、\\(R\\le16\\) はK0832高さのみ縮約で閉じる。
