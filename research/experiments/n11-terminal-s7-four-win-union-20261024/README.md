# 標準11×11：既存4個の7石WIN終局証明を7石被覆へ統合

2026-10-24。q=4・完全指摘・通常プレイ、元先手固定視点。
**標準11×11空盤の勝敗はUNKNOWN。二石rootの新規閉鎖はない。**

## 動機と追加した証拠

前段の `n11-terminal-s7-direct-s8-union-20261024/audit.js` は、独立終局証明済み
9石WIN 120根から導出した8石WIN 961類と、別の8石直接証明74根を統合し、
8石WIN **1,025類**、7石→8石の証明済み着手辺 **8,202本**を得た。

しかし、`n11-s7-four-win-terminal-20261020/s7_win_four_min_certificate.json`
に既にある **4個の7石WIN根**の完全な8石子159類（延べ165手）は未統合だった。
この既存証明書は159個の8石WINに合法9石WIN証人を付け、
129個の相異なる9石WINの全10石子2,670件を、独立したC++とPythonの
終局探索で確認したもの（詳細は元の実験README）。

今回、その159個の8石WINを被覆集合へ合成した。既存1,025類との重複9類を除き、
**150類を追加**した。新たな10石終局探索を行ったものではない。

## 構造検証

`audit.js` は従来の監査器を固定基準として継承し、さらに以下を再生成・照合する。

- 4個の7石根の全合法8石子（42、39、41、43類、合計159類・延べ165類）
- 159個の8石WINの合法9石証人、および相異なる129個の9石WIN
- 129個の9石WINの全合法10石子と、2,670個の相異なる10石葉
- 2,670葉のD4正準性・整数幾何による安全性・合法手数
- 8石WIN/LOSS衝突、7石の全子被覆、元の1,025類の監査結果

入力の7石子欠落、8石→9石証人改変、9石境界欠落、10石葉欠落の
**4種類の改変拒否試験**に成功した。旧監査器の改変拒否4種も継承する。
