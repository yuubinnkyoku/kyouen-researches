# 幅8格子における円の格子点数: P(8) = 12、可能サイズは {7, 8, 10, 12}、9以上はすべて偶数

## 主張

**定理.** 8行の連続整数格子（8×m、任意の m ≥ 1）上の円の格子点数は高々 12。
可能な点数は 7, 8, 10, 12 のみで、**9 以上の奇数サイズ（9, 11, 13）と 14 は全 m で存在しない**。
12点円は 8×8 で実在（witness）。よって P(8) = 12。

**接点補題（w=8 版）.** 盤内に接点行を持つ円の二重行は高々 3。よって**サイズ ≥ 9 の円は
すべて接点なし（s = 0）で、点数は偶数**。サイズ 7 は (d,s) = (3,1) 型（接点必須）。

**系（q ≥ 13 の行分離）.** 幅8・q ≥ 13 では円 ≤ 12 < q、非水平直線 ≤ 8 < q により
行を跨ぐ禁止 q 点集合なし。全 m ≥ 1・全安全局面 S で

g(S) = (8·min(m, q−1) − |S|) mod 2,　M_{8,q} = q−1。

新規に確定するのは **q = 13, 14, 15, 16**（q ≥ 17 は K0025 の q > 2w と重複整合）。

## witness

(x − 7/2)² + (y − 7/2)² = 25/2、すなわち (2x−7)² + (2y−7)² = 50。
8×8 で 12 点: 行 0: {3,4}、行 1: {1,6}、行 3: {0,7}、行 4: {0,7}、行 6: {1,6}、行 7: {3,4}、
行 2, 5 空（6二重行・接点なし）。列 0..7 に収まるため m ≥ 8 の全 8×m に乗る。
K0764 の witness と同一円（7行版では10点・8行版では12点）。

## 証明（K0763/K0764 機械の w=8 拡張）

**d ≤ 6**: 8連続行に7二重行あれば連続ペアがあり Vieta 還着（D, M ∈ ℤ）が効く。
mod9 剰余分類（9³ 通り）で 8 連続行中 disc ∈ QR(9) の行は最悪 6（M=1, D=1, k=2）。

**素数オフセット補題（t = p ≡ 3 mod 4 の孤立性）**: 接点ありのとき二重行のオフセット
t は t(g−t) = s² を満たす。t = p（素数）が二重行なら p(g−p) = s² から p | s、
g − p = pz²、すなわち **g ≡ 0 (mod p)**。他の二重行 t'（1 ≤ t' ≤ p−1）では
t'(g−t') ≡ −t'² (mod p) が平方数（QR）である必要があるが、これは (s/t')² ≡ −1 (mod p)、
すなわち −1 ∈ QR(p)、p ≡ 1 (mod 4) を要求する。**p = 7 ≡ 3 (mod 4) なので t = 7 は
他の全ての二重行オフセットと非両立**（機械検証: |g| ≤ 10⁶ で t=7 の共存 0 件）。

**接点補題（w=8）**: 4つ以上の二重行が必要なとき f | t（K0763 と同一の導出）より
- f = 1: t ∈ {1..7} から 4つ。t = 7 は孤立（上の補題）→ t ∈ {1..6} から 4つだが、
  これは K0764 の w=7 排除（ペア (1,3),(2,3),(3,4),(3,5),(1,4),(5,6)）で全滅。
- f = 2: 同符号で {2,4,6} の3つのみ。
- f ≥ 3: 倍数は高々4つだが混合符号（f=3: {±3,±6}）で符号論に反するか2つ以下。
よって接点ありなら二重行 ≤ 3、P ≤ 2·3 + 2 = 8。

**残るプロファイル**: サイズ ≥ 9 は s = 0 で P = 2d ≤ 12（d ≤ 6）。
13 = d=6+s=1 ✗（接点補題）、14 = d=7 ✗（mod9 worst 6）/ d=6+s=2 ✗
（2接点 |g| ≤ 7 の間の二重行は g=7 で 0 個・g=6 で {3} の1個のみ）。

**等号**: witness（d=6, s=0, P=12）。

## P(w) の数据列と接続

- **P(6) = 8, P(7) = 10, P(8) = 12**（K0763, K0764, 本項目）。いずれも
  「サイズ ≥ 9 は偶数のみ・接点補題で奇数サイズ全滅・最大値は 2·(mod9上界の二重行数)」
  という共通構造。P(w) = w + 2 が w = 6,7,8 で成立。
- K0025 の自明上界は P ≤ 2w（本項目は w=8 で 16 → 12 に改良）。
  K0072 の w ≥ 15 では P ≤ w + ⌈w/2⌉。**w = 9..14 の P(w) 正確値は open**。
- w = 9 では t ∈ {1..8} が加わる。t = 7 は孤立のまま（素数 7 ≡ 3 mod 4）、
  t = 8 は (2,8): 2e²−8z² 型（e²−4z²、実質 t=4 と同型）など新ペアが要解析。

## 機械検証（scripts/width8_circle_bound.ts → output/width8_circle_bound.json）

1. witness 12点の直接列挙（6二重行・行プロファイル一致）。
2. mod9 分類: 8連続行 worst 6。
3. f=1: |g| ≤ 10⁶ で最大 3、t=7 共存 0 件（素数補題の有限検証）。
4. f=2: 最大 2。
5. 2接点: g=7 → 0 二重行、g=6 → {3} のみ。
6. census: 8×8 = 86（8:81, 10:4, 12:1・12点円は witness のみ）、
   8×11 = 213（7:30, 8:169, 10:10, 12:4）。サイズ集合 {7,8,10,12} で
   9・11・13・14 は 0。7点円は列幅が大きい円（例: 半径5円が列 ±5 を使う）のため
   m=8 では現れず m=11 で出現する事実とも整合。

## スコープと限界

- 標準整数格子（連続8行）の定理。任意間隔平行行・w ≠ 8 には主張しない。
- 幅8の q ≤ 12 ゲーム（occupancy プログラム）は本項目では解いていない。
  ただし危険円が 7/8/10/12 点のみで全 m で保証されたため census 方式の完全性は確定。
  幅8では非水平8点直線も危険曲線。
