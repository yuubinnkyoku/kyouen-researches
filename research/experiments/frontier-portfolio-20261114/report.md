# 前線未決着インスタンスへの順列シャッフル kissat ポートフォリオと (5,7) 5×19 前線の決着確認（2026-11-14）

K0815 第2弾後の全未決着インスタンス（6×30 q=5・6×23 q=6・6×21 q=7・5×22 q=6・
6×19 q=8・5×19/5×20 q=7・6×12 q=8 cap=36）を、DIMACS 変数順列シャッフルによる
kissat 4.0.4 ポートフォリオ（1回260〜280秒・単発予算）で攻撃した。
全 run 未決着（timeout・非不在）。そのうえで、**5×19 q=7 cap=29 のSATインスタンスは
K0738–K0759 の occupancy 完全列挙によってすでに UNSAT が確定していることを確認し、
(5,7) の下界前線を m=19 で閉じた**。これが本実験の主成果である。

## 主成果: (5,7) の 5×19 SAT インスタンスは列挙で解決済み

- K0759 の Corollary: 5×19 の全occupancy クラス（単一行〜5行欠損・K0738–K0759、
  各クラス全 8,378 鏡映代表・witness 0・leaves 0・二重実行一致）により、
  **5×19 に行欠損の極大安全配置は存在しない**（全極大が30石）。
- K0332 の下界証人（5×18・29石・occupancy (5,6,6,6,6)）を sat.js の census 不使用
  独立検証器で再検証し safe+maximal PASS。同じ石を 5×19 に置くと (18,0) が非極大
  （欠損行の新列セルが ≥6 石の非行曲線でブロックされない）で、列挙結果と整合する。
- よって「欠損極大が存在しない最小の m」は 19。K0810/K0811/K0815 が timeout・
  抵抗記録として扱ってきた 5×19 q=7 cap=29 の grind は、列挙による既証明と重複する。
  **(5,7) の下界 19 は最終確定**であり、以後の witness 探索は m≥20 だけを対象にする
  （5×20 q=7 cap=29 が次の前線）。
- ただし M_{5,7} を真の安定化長（全 m≥M で満容量）として読む場合は 19..158 が不変。
  20≤m≤157 の持続性は未解決のままである。また列挙は「共有runnerの正確性まで」の
  machine-verified であり（K0759 自身の記述）、数論的証明ではない。
  SATソルバによる独立交叉確認（5×19 cap=29 の UNSAT 決着）は今後の課題。

## 手法と制御

- 符号化: K0810 の encode()/toDimacs を verbatim 使用。拡張版（全体石数 counter ≤ cap
  ＋「上半分のいずれかの行が ≤ q−2 石」の行対称性条項）は dump2.js と同一構成。
  さらに本実験では **欠損行を特定の行に固定するユニット節版**（dump3.js）を追加した
  （行対称性で deficient 行は上半分 {0,..,⌈w/2⌉−1} に置けるため、行ごとの部分問題分割は健全）。
- 順列シャッフル: permute.js が xorshift で変数番号の全置換・節順・リテラル順を
  シャッフルした DIMACS を生成（意味は同値で探索多様化）。SAT 時は unpermute.js で
  元の変数番号に戻して witness を抽出する。
- 制御: 2×8 q=4 cap=5 は順列経由で SAT・witness 抽出・検証 PASS
  （stones [[0,0],[4,0],[2,1],[3,1],[4,1]]・safe+maximal）。2×9 q=4 cap=5 は UNSAT。
  いずれも公表値（K0796・K0069）と一致。
- kissat 4.0.4 は公式 linux-amd64 リリースバイナリ。1コマンド ≤300 秒の実行環境制約のため
  各 run 260〜280 秒で打ち切り。

観察:

- 単発予算では K0815 の単発記録（838k〜5.54M conflicts）を順列シャッフルでも超えられず、
  決着には至らない。変数順列は難度を変えない（conflict 数は同オーダーでばらつく）。
- 欠損行固定（ユニット節）も 6×30（733k）・5×20（4.68M）ともに難度を崩さなかった。
- 6行盤の decisions/conflict は 9〜12 と高く、sequential counter 由来の長い決定列が
  難度の主因と推定される。符号化改良（counter の局所化・対称性破り強化）が
  次の攻撃候補。
- 5×19 q=7 cap=29 は列挙で決着済みのため本ポートフォリオの対象外とした。
