## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,3)（x≥3）における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,3);10)
- **B手**（トークン 3 を 2 へ減ずる）: 子 = H(R−1;(x,2);10) = K1004
- **C手**（z を 10→9 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,3);9) = K0989

x=3 では X=(3,3) で A手とB手は同一の子 (2,3);10 = K1004 の x=3 行に合流する（A=B）。子の値はすべて既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**）、B子は K1004 の z=10・y=2 全称定理、C子は K0989 の z=9・y=3 全称定理。よって各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** A=cand(x−1,r)、B=z10_y2(x,r)、C=1⊕z9_y3(x,r)（r=R−1）。定常行で使う子の帯:

- 偶数R=18（r=17）: A=2（**奇数行 x−1 のピン 17∈T_A**）、B=0（r奇∉E_B）、C=0（17∈O[17,x+13] → h₉=1）。V={0,2}、値1。**A子のピンが偶数帯の孤立点 18 を作る**（K1004 の R=16:02 と同型だが、ここでは A子由来で孤立点は 1 個）。

この導出は全偶数 x≥16 に一様に成り立つ（使うのは子公式の帯境界が x の1次式であることのみ）。奇数行 x≥17 では B子・C子の帯の向きが入れ替わり（B・C の I 帯が消え A の I 帯が現れる）、末帯 R≥x+14 は V={1}（A=1・B=1・C=1）に反転して値0=tail、E帯は [18,x+13] まで延長される。**掃引行は x=z+y+1=14**: A子は x=13、B子は K1004 の x=14 移行行（E_B[16,26] の署名02全幅）、C子は K0989 の x=14 行（K0989 側の y=3 掃引帯 O₉[17,27]）で、奇数 R∈O[17,27] で A=0・B=1・C=1 の V={0,1}（値2）・偶数 R∈[18,26] で V={0}（値1）が並び、**掃引帯 O[17,27]=O[pin,x+y+z]** が生じる（pin=17=2y+z+[z偶]、終端 x+y+z=27）。**移行行 x=15** では A子が掃引行 x=14 を横切り、偶帯 E[18,28] 全体で A=2（掃引帯 O_A[17,27] の r 奇）が持続して署名 02 が続く（K1004 の x=14 移行行と同型）。x≤13 の個別行は同じ代入の直接実行である。x=7（高さ h=x+y=10=z）は値2点が {11,13} の**2点前倒し**（y=1・y=2 の h=z 行は1点 R=z+1 だけだった新形、11=z+1 に加えて 13 も値2）。x=11 は前倒し生存点（x=y+8、点 15=2y+9）。

**Step 4（mex評価と Theorem T）.** K0832 の Theorem T により、奇数Rの親の値は mex{0,1}=2, mex{0}=1, mex{1}=0 に限り、偶数Rの親の値は高々1である。署名→値の一意対応:

**Step 5（tail整合）.** 定常行の末帯で V は単値に退化し、R≥x+14 で H=(x+3) mod 2 となる。これは K0832 の一般tail定理の 2トークン・z=10・y=3 場合（R≥S+|X|+z−1=x+14、H=S mod 2=(x+3) mod 2）と独立に一致する。□

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は **{1,3,5,7,9,17}**。ピン 17=2y+z+[z偶]=2·3+10+1。値1基底点は **{11,13,15}={z+1,z+3,z+5} の3点**で、基底点y個仮説 {z+1,…,z+2y−1} を y=3 でも満たす。帯開始は z+2y+2=18（E帯、z偶奇追従）。**7則は y=3 でも貫徹**: 基底点y個 ✓、帯開始 z+2y+2=18 ✓、帯偶奇 z追従（E）✓、掃引行 x=z+y+1=14 ✓、掃引帯 O[pin,x+y+z]=O[17,27] ✓、前倒し生存点 x=y+8=11・点 2y+9=15 ✓、tail R≥x+y+z−…=x+14・H=(x+y) mod 2 ✓。
- **I 帯の行は x 偶数行**（y=1 と同じ向き、y=2 とは反転）。tail 値 (x+y) mod 2 が 1 になる行に I 帯が現れる規則は y=1,2,3 で機械的に整合する。
- h=z 行（x=7）の追加点は {11,13} の2点。y=1 では x=9 の1点 R=11、y=2 では x=8 の1点 R=11 だったので、y=3 は「z+1 に加えて z+3 まで前倒しする」初例。h=z 行の追加点個数の一般則（y個？）は y=4 で検証する価値がある。
- x=9 と x=11、x=10 と x=12 の構造対応、x=8 の I[14,∞) と x=10,12 の I[15,∞) は K1004 の x=9,11 と x=10,12 の対応と同型に現れる（A子=x−1 行の穴を B・C が埋める）。

## 適用範囲と限界

- 本定理は **z=10・y=3 の境界切片のみ**。z=10 の y=4..5 は未証明（y=4 は A=x外帰納・B子=本項・C子=1⊕K0990(z=9,y=4) の三子が本出版で揃い着手可能、y=5 は C子=1⊕K0992）。y≥6 は K1002 の一様式候補のまま（有限センサスのみ）。
- R≤11 の列は高さのみ縮約で並走レーン出版の z=10 低残余帯と完全一致し、本項が中間帯 12≤R≤x+13 を閉じたため y=3 の全R分類が完成（K1002 の未証明帯は y=3 について消滅）。
- 有限監査は検証手段であり、定理の主張は上記 Step 1..5 の帰納構成による。監査は帯表の転写ミス・実装バグの検出を目的とする。
- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
