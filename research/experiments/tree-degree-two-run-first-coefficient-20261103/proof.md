# 木型の最短直上係数：修正版（2026-11-03）

**重要：初版 ec11782f の「任意長の次数2連続区間が許容核」という主張は誤り。** 許容核は各頂点が核の外に隣接点を持たなければならない。次数2の道の内部頂点を3個連続して取ると、中央頂点の隣接点は両方とも核内にあり不許容となる。

## 正しい全称公式

有限木 T の辺数 e>=2、q>=4、r=q-3。K0648に従い、L は葉の数、C=e-L、s=N-e とする。次数2頂点の極大連続区間を R_i、長さを ℓ_i とする。

各 R_i の**長さ1または2の連続部分区間** I について、a(I) は I に隣接する葉の数とする。このとき

```
[u]F(u) = Σ_i Σ_{I⊆R_i, I connected, 1≤|I|≤2}
          r^(C+a(I)-|I|-1) (r+1)^(L-a(I)).
```

許容核の個数は厳密に

```
Σ_i (ℓ_i + max(ℓ_i-1,0)) = Σ_i (2ℓ_i-1).
```

## 証明

K0648の許容核 B の誘導連結成分 D は木であり、欠損は d(D)=1+Σ_{v∈D}(deg_T(v)-2)≥1。d(B)=1 なら B は連結で、全頂点の次数が2。従って B は次数2の道の連続部分区間である。許容核条件（各 v∈B に B 外の隣接点が存在）から、|B|≥3 は不可能。逆に長さ1または2の次数2区間は各頂点に核外の隣接点を持つので許容される。K0648の重みを代入して公式を得る。

## 初版への具体的反例と独立監査

5頂点道 P5 の次数2区間は長さ3。初版は6核と数えたが、正しくは単点3個と隣接2点組2個の計5核。q=4 (r=1) では初版の係数13に対し正しい係数は12。

独立監査では Prüfer 列から生成したラベル付き木（頂点数3〜7）と r=1,2,3,4 の **72,988条件**で、K0648の全許容核を直接列挙する方式と修正版の長さ1・2区間方式が一致した。これは有限検証であり、全称結論の根拠は上の証明である。

この修正は K0648 自体の公式を変更しない。標準格子盤への適用は主張しない。
