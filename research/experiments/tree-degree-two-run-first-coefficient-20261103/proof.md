# 木型の最短直上係数：次数2の連続区間公式（2026-11-03）

**証拠区分：K0648からの全称的な演繹。** 新しい有限計算の外挿ではない。

K0602の構成で、有限木 T の辺数 e>=2、q>=4、r=q-3 とする。K0648の記号に従い、L を次数2以上の頂点に接続する葉の数、C=e-L とする（木の e>=2 では孤立辺成分なし）。最短終局長 s=N-e とし、中心付き終局長母関数を F(u)=sum_B w(B)u^{d(B)} とする。

**命題。** T の次数2頂点だけからなる極大連結区間（道）を R_1,...,R_t とする。各 R_i の非空連続部分区間 I を全て走らせ、a(I) を I に隣接する葉の数とすると

```
[u]F(u) = Σ_i Σ_{∅≠I⊆R_i, I connected} r^(C+a(I)-|I|-1) (r+1)^(L-a(I)).
```

指数は K0648 により非負整数である。特に、次数2頂点がなければ係数は0、存在すれば正である。各 R_i の長さを ℓ_i とすると寄与する許容核の個数は Σ_i ℓ_i(ℓ_i+1)/2 であり、**この核の個数は q に依存しない**。係数そのものは重み付きなので q に依存する。

**証明。** 木の許容核 B に対し、誘導部分グラフ T[B] の連結成分を B_1,...,B_c とする。各成分は木であり、K0648の欠損式から

d(B_j)=Σ_{v∈B_j}(deg_T(v)-1)-(|B_j|-1)
      =1+Σ_{v∈B_j}(deg_T(v)-2)>=1.

したがって d(B)=1 なら c=1 かつ全頂点の次数が2である。逆に、次数2の連続区間 I は（有限木で e>=2 なら）両端に区間外の隣接頂点を持つため許容核で、d(I)=1 である。K0648の重みを各 I に代入して公式を得る。各長さ ℓ の道に非空連続区間は ℓ(ℓ+1)/2 個ある。

**注意。** この公式は最初の非定数係数だけを与える。次数2を含む枝分かれ木の終局長多項式が非実根を持つという未解決予想を証明するものではない。実根性の判定には2次以上の係数とNewton不等式などが必要である。標準格子盤には適用しない。
