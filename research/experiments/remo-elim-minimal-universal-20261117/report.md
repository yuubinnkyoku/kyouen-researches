# 定理Wと系MPV: 敵者全列の最小周期 = Q(r) の全称証明（K0924）

2026-11-17・高速レーン・depends_on: K0919, K0922, K0859

## 要旨

K0859定理Dの計数再帰 E(C,r)（Δ=0一様盤・r人・終端サイズC）の
敗者全列 elim(C,r) = (l_1, …, l_{r−1}) について:

1. **定理W（全称・証明つき）**: すべての r ≥ 2 と d ≥ 1 に対して
   **elim(1+d, r) = elim(1, r) ⟺ Q(r) | d**（Q(r) = lcm(1..r)）。
   K0922で有限観察（r ≤ 16）だった witness C=1（全真約数がC=1で
   棄却される）の全称化。
2. **系MPV（全称・証明つき）**: **敗者全列のC方向最小周期は
   すべての r ≥ 2 でちょうど Q(r)**。K0922定理MPのうち敗者全列
   （elim列）分を r ≤ 16 の機械結果から全称定理へ昇格。
3. **機械検証**: witness C=1のelim列棄却を **r = 40 まで直接拡張**
   （r=2..40のQ(r)全真約数293,573個・一致0・各dは評価2回の
   直接比較で済み窓走査不要）し、定理Wのカスケード予測（最初の
   発散フェーズ）を118,486件で検証（不一致0）。

## 記号と前提

- E(C,r): 計数再帰。各フェーズで k = |active|、s = Σ counts[active]、
  ell = C − s、turn から始まるサイクリック配分、敗者 =
  active[(turn+ell) % k]、敗者の石は没収され除外、
  turn = li % len(active)。
- Q(r) = lcm(1..r)。
- K0919定理PER: Q(r) は E(·,r) の周期（全称・全Cで全列一致）。
- K0919素数冪補題: **lcm({r} ∪ {k(k+1) : k = 2..r−1}) = Q(r)**。
- K0922補題DIV（列形式）: 任意の列 f(C) = elim(C,r) について周期
  集合は gcd で閉じる（Bezout・上向き適用で添字 ≥ 1 を保存する
  議論は列関数にそのまま働く）。Per_elim(r) = m_e(r)·Z_{>0} で
  m_e(r) | Q(r)。

## 補題B1（E(1,r)の剛構造）

elim(1,r) = (1, 2, …, r−1)、生存者 sv(1,r) = 0。かつすべての
フェーズ h ≥ 2 で ell = 0・turn = 1・敗者 = active[1] = プレイヤーh。

証明: フェーズ1でell=1、P0に1石、敗者 = active[1] = P1（0石）。
以後アクティブなのは P0（1石）と P_h（0石）だけで s = 1・ell = 0。
敗者 = active[(1+0) % k] = active[1] = プレイヤーh（h ≥ 2では
active = [0, h, h+1, …]）。敗者は常に0石なので s = 1 は不変。∎

## 定理Wの証明

A = E(1+d, r)、B = E(1, r) をフェーズごとに比較する。フェーズh
（1 ≤ h ≤ r−1）で k_h = r−h+1・e_h = r−h+2 = k_h + 1 とおく。

**主張**: フェーズ1..h−1の敗者が両ゲームで一致するならば
（h ≥ 2）、アクティブ全プレイヤーの石数差は一様オフセット
**D_h = d / e_h**（整数）であり、ell差 **X_h := ell_A − ell_B = D_h**、
そして「フェーズhの敗者が一致する ⟺ k_h·e_h = (r−h+2)(r−h+1) | d」。

- **基底（フェーズ1）**: 第1敗者は A: active[(1+d) % r]、
  B: active[1]。一致 ⟺ (1+d) ≡ 1 (mod r) ⟺ r | d。r | d のとき
  1+d = r·(d/r) + 1 なので配分差は全プレイヤーで d/r 一様
  （P0は(q+1)−1、他はq−0、q = d/r）。敗者P1は両ゲームで除外され
  D_2 = d/r = d/e_2。
- **帰納ステップ（h ≥ 2）**: 一様オフセット D_h = d/e_h のもとで
  s_A − s_B = D_h·k_h。補題B1より s_B = 1・ell_B = 0 なので
  X_h = ell_A = (1+d) − s_A = d − D_h·k_h = D_h·(e_h − k_h) = D_h。
  敗者は A: active[(1+X_h) % k_h]、B: active[1] で、一致 ⟺
  k_h | X_h = D_h ⟺ k_h·e_h | d。一致する場合、Aは X_h = k_h·c_h
  個の石（c_h = d/(k_h·e_h)）をサイクリックに均等配分
  （各アクティブプレイヤーちょうど c_h 個）、Bは0個。よって
  残存プレイヤーのオフセットは一様に
  D_h + c_h = d/e_h + d/(k_h·e_h) = d·(k_h+1)/(k_h·e_h) = d/k_h = d/e_{h+1}。
  敗者P_hは両ゲームで除外され一様性は保存される。turnは
  「敗者一致 → 同一アクティブリスト上で同一プレイヤー → 同一
  除去位置 → 同一turn」で両ゲーム一致。

**⟹方向の完成**: 全 r−1 フェーズの敗者が一致するには
r | d かつ k(k+1) | d（k = 2..r−1）がすべて必要。K0919の
lcm恒等式より **Q(r) | d**。∎

**⟸方向**: K0919定理PERにより Q(r) | d なら E(1+d) = E(1)
（全Cで周期）。∎

### 帰納の副産物（発散位置の構造）

elim(1+d) と elim(1) の最初の発散フェーズは正確に予測できる:
r ∤ d ならフェーズ1、r | d なら「最小の h ≥ 2 で
(r−h+2)(r−h+1) ∤ d となる h」。真約数 d の「深さ」は約数条件の
最初の破れで決まる（機械検証M3/M3bの根拠）。

## 系MPVの証明

elim列の周期集合は gcd 閉包（K0922補題DIVの列形式）なので
Per_elim(r) = m_e(r)·Z_{>0} かつ m_e(r) | Q(r)（定理PERより
Q(r) はelim列の周期）。m_e(r) < Q(r) と仮定する。このとき
m_e(r) は Q(r) の真約数かつ elim 列の周期なので
elim(1+m_e) = elim(1) が成り立つが、定理Wより Q(r) ∤ m_e なら
elim(1+m_e) ≠ elim(1)。矛盾。ゆえに **m_e(r) = Q(r)**、すべての
r ≥ 2 で成立。∎

## 限界・免責

- **Δ=0一様盤・敗者全列限定**。非一様盤には一切言及しない。
- **生存者全列の最小周期は K0922 の機械結果（r ≤ 16）のまま**。
  全称性はOPEN。C=1は生存者列の棄却witnessにならないdが存在
  （M6・sv(1+d)=0）。生存者列の全称最小性には別のwitness族が
  必要で、r ≥ 17の生存者列最小性も窓走査が必要なまま未到達。
- P(C) = 1 ⟺ 素数予想（K0922）は本項で変わらず予想のまま。
- 11×11空盤・クラスフロンティアは無関係でUNKNOWNのまま。
- 定理W・系MPVの証明は本reportの記述による（形式的証明
  （Lean等）には未展開・M3/M3b/M4は証明の各ステップの数値的
  整合性の独立機械確認であり形式的検証ではない）。
