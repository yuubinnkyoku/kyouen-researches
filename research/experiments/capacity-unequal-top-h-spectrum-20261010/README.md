# 異容量・上位 h 列ゲームの極大配置・終局石数（全称証明）

**対象**：抽象容量ゲーム。整数 `w>=1, 1<=h<=w, r>=0`、列容量 `c_1>=...>=c_w>=0`。占有数 `0<=x_i<=c_i` の最大 `h` 成分の和が `r` 以下なら安全。1手は1列の占有数を1増やすこと。標準2次元共円ゲーム全体への適用は主張しない。

## 定理1：全極大配置・終局石数

`sum_{i=1}^h c_i<=r` なら、極大配置は `x=c` のみで終局石数は `sum_i c_i`。

そうでなければ、次を定義する（`h=1` の空和は0）。

```
L = max(0, r - sum_{i=1}^{h-1} c_i)
U = min(c_h, floor(r/h))
T(b) = r-h*b + sum_{i=1}^w min(c_i,b)
```

`L<=U` であり、**極大配置の全て**は、整数 `L<=b<=U` に対して次の形に一意に分類される。

```
x_i = min(c_i,b) + d_i,
0 <= d_i <= max(c_i-b,0),
#{i:d_i>0} <= h-1,
sum_i d_i = r-h*b.
```

ここで `b` は `x` の第 `h` 大成分である。全終局石数の集合は厳密に

```
{T(b): L<=b<=U}
```

である。`b` が異なっても `T(b)` は同じ値になり得る。

**差分と欠番**：

```
T(b+1)-T(b) = #{i:c_i>=b+1}-h >=0   (L<=b<U).
```

差分は `b` に関して単調非増加。したがって終局石数に欠番がある必要十分条件は

```
L<U and #{i:c_i>=L+1}>=h+2.
```

`w>=h+2` なら後半は `c_{h+2}>=L+1` と同値である。欠番がなければ `T(L),...,T(U)` の値の集合は `T(L)` から `T(U)` までの全整数となる。

## 定理2：占有ベクトル数、物理的石集合数、着手順序数

`b` を固定し `s=r-h*b` とする。`[y^{<h}z^s]` は `sum_{j=0}^{h-1}[y^j z^s]` を表す。

ラベル付き極大**占有ベクトル**数は

```
A_b = [y^{<h}z^s] prod_{i:c_i>b}
      (1 + y*sum_{d=1}^{c_i-b} z^d).
```

列 `i` に区別可能な `c_i` 個の位置があるとき、極大**石集合**数は

```
N_b = [y^{<h}z^s] prod_{i:c_i>b}
      (binom(c_i,b) + y*sum_{d=1}^{c_i-b} binom(c_i,b+d)*z^d).
```

容量 `c_i<=b` の列は全占有なので係数1。石数 `t` ごとの個数は `T(b)=t` を満たす全 `b` の係数を合計する。空盤から `t` 石終局へ至る合法な物理的着手順序の総数は

```
t! * sum_{b:T(b)=t} N_b.
```

## 定理3：二値Grundy・多人巡回対戦の完全判定

`D_b=#{i:c_i>=b+1}-h` (`L<=b<U`) と置く。

K0305の一般定理から、**全安全局面のGrundy値が0/1のみ**である必要十分条件は、全ての `D_b` が偶数であること（差分が空なら成立）。この場合、`epsilon=T(L) mod 2` として

```
g(x) = (epsilon - sum_i x_i) mod 2.
```

K0339の一般定理から、`Delta=gcd(D_L,...,D_{U-1})`（差分がない、または全て0なら `Delta=0`）とすると、`R>=2` 人巡回で最初に合法手を失う敗者が全合法対局で同じである必要十分条件は `R|Delta`（`Delta=0` なら全 `R`）。最適戦略や均衡の分類ではない。

## 数学的全称証明

容量全体 `c` が安全なら、全列を満杯にした配置だけが極大。そうでなければ `f_h(x)<r` の安全局面は必ず未満杯列を持ち、そこへの1手は `f_h` を高々1しか増やさないので合法である。よって極大なら `f_h(x)=r`。

`b` を第 `h` 大成分とする。未満杯かつ `x_i<b` の列に着手しても上位 `h` 成分和は変わらないため、極大性に反する。逆に `x_i>=b` の列への着手は必ず上位 `h` 成分和を1増やす。従って極大の必要十分条件は `f_h(x)=r` かつ `x_i<b` の全列が満杯であること。これは定理1の `x_i=min(c_i,b)+d_i` の形と同値であり、正の `d_i` を持つ列は高々 `h-1` 本である（`h` 本なら第 `h` 大成分が `b` を超える）。

`b<=c_h` と `hb<=r` は必要。また上位 `h-1` 列が担える余剰は最大 `sum_{i<h}(c_i-b)` だから、`r<=sum_{i<h}c_i+b`、すなわち `b>=L` が必要。逆にこれらの条件が成立すれば、上位 `h-1` 容量列に `b` を基底として置き、余剰 `r-hb` をそれらに整数で配分できる（0から容量までの区間の和は穴のない整数区間）。残り列を `min(c_i,b)` にすれば極大である。したがって可能な `b` はちょうど `[L,U]` の全整数。

石数公式は基底占有数 `sum_i min(c_i,b)` と余剰 `r-hb` の和である。差分は `min(c_i,b+1)-min(c_i,b)=[c_i>=b+1]` から従う。`b+1<=U<=c_h` より差分は非負で、`b` の増加に伴い非増加。最初の差分が2以上ならそこに欠番があり、最初の差分が1以下なら全差分が0か1なので欠番はない。母関数は余剰のある列数を `y`、余剰石数を `z` で数えたもの。物理的石集合については各列の選択数を二項係数で重み付けする。安全集合は下方閉なので、固定した終局石集合に対する全 `t!` 個の追加順序は合法。最後の二系は既存のK0305/K0339から従う。□

## 追加定理4（2026-10-10）：終局石数の欠番の**正確な個数**

定理1の全容量が安全でない場合の `L,U,T(b)` を用いる。終局長の最小値 `T(L)` と最大値 `T(U)` の間に存在しない整数の個数を `H`、相異なる終局長の個数を `Q`、最大と最小の差を `R` とする。このとき全整数パラメータについて

```
H = sum_{i=h+2}^w max(0,min(c_i,U)-L)
Q = 1+max(0,min(c_{h+1},U)-L)   (h<w)
Q = 1                           (h=w)
R = sum_{i=h+1}^w max(0,min(c_i,U)-L)
R = H+Q-1
```

が成り立つ。空和は0とする。全容量が安全なら `H=0,Q=1,R=0`。

**全称証明**：`b=L,...,U-1` に対して `D_b=T(b+1)-T(b)=#{i:c_i>=b+1}-h`。`b+1<=U<=c_h` より `D_b>=0`。`D_b>0` のときに限り異なる終局長が1つ増え、その条件は `b+1<=c_{h+1}` と同値である。`D_b>0` のとき隣接する異なる終局長の間にある欠番の個数は `D_b-1=#{i>=h+2:c_i>=b+1}`、`D_b=0` のときは双方0である。従って全欠番数は `sum_{b=L}^{U-1} #{i>=h+2:c_i>=b+1}`。列 i ごとに和の順序を交換すると H の式。Q と R も同じ和の順序交換で得る。□

これにより先行する欠番**存在**の必要十分条件 `L<U and c_{h+2}>L` を定量化した。たとえば `c=(5,4,3,2,1),h=2,r=5` では H=3、終局長 `{5,8,10}` の欠番 `{6,7,9}` を正確に与える。`h=3,r=7` では H=1、欠番は `{8}`。
