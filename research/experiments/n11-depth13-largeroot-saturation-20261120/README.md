# n11 大型4根のdepth-13飽和確認（K1082台帳上位4根、depths 10-13、2026-11-20）

## 目的

軽量2根の第3差分（b231035d25）でD12→D13倍率1.0000（フロンティア飽和）を確認した一方、
**飽和深度の大型rootへの外挿は未知**だった（K1081の明示済み限界）。K1082台帳上位4根
（大型root標本と同じ4根）をdepth 10/11/12/13で自己完結的に再測定し、飽和の有無と
depth非単調性を測った。コスト測定のみであり、判定変更・行の閉鎖・掃引は行わない。
単一オーナー宣言ノート
（`research/log/2026-11-20-n11-depth13-largeroot-saturation-single-owner-note.md`・commit fed52e3f）の下で実施。

## 対象とプロトコル

- 対象: K1082台帳 by_root sum_nodes上位4根（rank1 bit20・rank2 bit12・rank3 bit2・rank4 bit18。
  大型root標本1cdbe215daと同一選択）。
- runner v17固定コピー（git blob `c132cc6425eee3feaeef1d697dd74f968cfedb59`）・cap 30M・
  timeout 280s・両AND順序・pilot_d6制御必須・逐次・**depth 10/11/12/13を自己完結的に再測定**
  （**計32 probe**。宣言ノートに「計16 probe」と書いたのは誤記で、実施内容自体は宣言通り
  4深度×両順序×4根の自己完結フル再測定。ここに訂正記録する）。
- D10/D11は大型root標本正本（SHA-256 c9927a23…）、D10はK1082台帳per-probe値とも
  node一致をfail-closed gateで要求。

- **D12→D13倍率は全8 probeで1.0000（node数完全同一）**。軽量2根（b231035d25）と合わせ、
  depth-13まで測った全6根12ケースはすべてD12→D13で飽和（うち4ケースはD11→D12で先行飽和。
  rank1 ac1・rank2 ac0の飽和はD11→D12だった）。
- **depth非単調性を初観測**: rank1 ac0はD11→D12でnode数が減少（0.9805・−2.0%）。rank2 ac0
  （0.9974）・rank4 ac1（0.9955）も減少。探索のdepth延長はmemo効果とカットの変化でnode数を
  **増加も減少も**させうる。node数は依然として(root, depth, ordering)ごとに決定的である。
- rank3 ac0のD11→D12は **+11.8%** で、D10→D11バンド（1.0004〜1.0666）を超える最初の観測。
  累積D13/D10の観測範囲は **1.0024〜1.1424**（最大はrank3 ac0）。
- 供給判断への含意（提案のみ・実行はしない）: 6根12ケースの観測では、depth延長3手分の累積
  コストは+0.2%〜+14.2%に収まり、depth 13で全ケースが飽和。39根掃引のdepth-13版の総コストは
  169.6M×1.1424 ≈ **194M nodes** を観測上限バンドとして見積もれる。ただし非単調性により
  個別rootの増減方向は事前保証されない。

## 解釈規約

node数はcap内で決定的（機種非依存の費用単位）。capped/timeoutはいかなる方向の証拠にもならない
（本実験でcapped 0）。depth-12/13のloss=falseはREFUTED-D12/D13分類でも行の閉鎖でもない。
D11→D12のnode減少は同エンジンのmemo化挙動の観察であってゲームの値に関する証拠ではない。
REFUTED-D10はLOSS証明ではない。**標準11×11空盤・二石root {49,60}/{59,60}・S2 {59,60}・
class 1/2/4 はすべて UNKNOWN のまま。**
