# 一辺細分星 q=24〜30 の奇数次数実根切替（2026-11-05）

## 定理（解析的全称証明と厳密有理数証明書）

一辺細分星の終局長差多項式
`T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}`
について、整数 `r=q-3`、奇数 `k>=3` とする。

| q | 実根0個（奇数k） | 相異なる負の単実根がちょうど2個（奇数k） |
|---|---|---|
| 24 | 3<=k<=209 | k>=211 |
| 25 | 3<=k<=219 | k>=221 |
| 26 | 3<=k<=231 | k>=233 |
| 27 | 3<=k<=243 | k>=245 |
| 28 | 3<=k<=255 | k>=257 |
| 29 | 3<=k<=267 | k>=269 |
| 30 | 3<=k<=281 | k>=283 |

各行の実根非存在は、その q 以上の任意の整数 q にも拡張される（ただし対応する k 範囲のみ）。

## 証明

`a=(r+2)/(r+1)`、`u=-(r+1)y` とおく。正の u では T の全係数が正なので根はない。負の u に関する既存の符号解析から、実根の候補は `1<y<a` に限られる。その区間で根の方程式は
`F_{k,r}(y)=r-y-(a-y)y^k=0`。
`H_k(y)=(a-y)y^k` は `[1,a]` で `y_k=ka/(k+1)` に最大値を持つ（表の境界次数では `1<y_k<a`）。

各行の `k_-=k_+-2` について `H_{k_-}(y_{k_-})<r-a` を厳密な整数比で検証した。ゆえに全区間で `F_{k_-,r}>0`。固定 `y>1` で `y^k` は k とともに増加するため、奇数 `3<=k<=k_-` に根はない。

一方 `F_{k_+,r}(y_{k_+})<0` を厳密に検証した。端点では `F(1)=r-1-1/(r+1)>0`、`F(a)=r-a>0` だから中間値定理で区間内に2個の異なる根がある。奇数 k について `T_{k,r}(-x)` の非零係数の符号変化は2回なので、デカルトの符号法則により負根は重複度込み高々2個。従ってこの2根は単根であり、他に実根はない。固定 `y_{k_+}>1` で k を増やすと F は減少するので、すべての奇数 `k>=k_+` でも成立する。

さらに `F_{k,r}(y)` は固定 `y>1` で r に関して狭義増加（`∂F/∂r=1+y^k/(r+1)^2>0`）。r が増すと `(1,a)` は縮む。ゆえに非存在側は全 q 以上に拡張される。

## 再現（Python 3、浮動小数点不使用）

```python
from fractions import Fraction as Q

bounds = [(24, 211), (25, 221), (26, 233),
          (27, 245), (28, 257), (29, 269), (30, 283)]
for q, kp in bounds:
    r, km = q - 3, kp - 2
    a = Q(r + 2, r + 1)
    ym, yp = a * km / (km + 1), a * kp / (kp + 1)
    assert 1 < ym < a and 1 < yp < a
    assert (a - ym) * ym**km < r - a
    assert r - yp - (a - yp) * yp**kp < 0
```

全14不等式を Python の `fractions.Fraction` で検算済み。非存在側は区間全体の解析的最大値を使い、存在側は厳密な有理数の負値証人を使う。数値実験から無限範囲を外挿したものではない。
