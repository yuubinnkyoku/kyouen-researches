## 全称証明
\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおく。負根は \(F(y)=r-y-(a-y)y^k=0\) に対応する。\(0<y\le1\) では \(F(y)\ge r-a>0\)。\(a\le y\le r\) では明らかに正、\(y>r\) では \((y-a)y^k>(y-a)y>y-r\) より正。よって候補は \(1<y<a\) のみ。

\(H(y)=(a-y)y^k\) の最大点は \(y_*=ka/(k+1)\)。非存在境界 \(k_-=k_+-2\) で \(H(y_*)<r-a\) を確認すれば、全 \(y\) で \(F(y)>0\)。存在境界 \(k_+\) で \(F(y_*)<0\) なら \(F(1),F(a)>0\) なので少なくとも2個の負根を持つ。\(T(-x)\) の符号変化は2回なのでデカルトの符号法則から正確に2個の相異なる単根であり、正根は正係数性からない。

\(1<y<a\) では \(k\) の増加に対して \(F(y)\) は厳密減少する。従って両境界の確認で全奇数 \(k\) に結論が及ぶ。これは境界の有限検査を用いた全称証明であり、有限個の \(k\) のみの観測ではない。

## 整数演算による境界検査
\(A=k(r+2),B=(k+1)(r+1)\) とする。非存在側の十分条件は \((r^2-2)(k+1)B^k>(r+2)A^k\)。存在側の条件は \((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)。以下のPythonコードを実行し、20件すべて成功した。浮動小数点演算は用いない。

```python
bounds = [[111,1415],[112,1431],[113,1445],[114,1461],[115,1477],[116,1491],[117,1507],[118,1521],[119,1537],[120,1553]]
for q, kp in bounds:
    r = q - 3
    for k, exists in ((kp-2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if exists:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
        else:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
print("20 exact inequalities passed")
```
