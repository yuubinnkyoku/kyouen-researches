# 2トークン残余ゲーム z=8・y=6 の全Grundy分類（K0993）

- 日付: 2026-11-19
- 対象: H(R;(x,6);8)、全 x>=6・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0991（z=8,y=5）、K0982（z=7,y=6）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

| x | T_8^(6)(x) |
|---:|---|
| 6,7,9,10,11,13,14 | {1,3,5,7} |
| 8 | {1,3,5,7,17} |
| 12 | {1,3,5,7,19} |
| 15 | {1,3,5,7} ∪ O[21,29] |
| x>=16 | {1,3,5,7,21} |

| x | P_8^(6)(x) |
|---:|---|
| 6,8 | O[9,15] |
| 7 | O[9,17] ∪ I[18,∞) |
| 9 | O[9,17] ∪ I[18,∞) |
| 10,12 | O[9,17] |
| 14 | O[9,19] |
| 11 | O[9,17] ∪ I[19,∞) |
| 13 | O[9,19] ∪ I[20,∞) |
| x>=15 odd | O[9,19] ∪ E[22,x+15] ∪ I[x+16,∞) |
| x>=16 even | O[9,19] ∪ E[22,x+14] |

全てのx>=6・R>=0で、H(R;(x,6);8)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailは

    R >= x+15  =>  H(R;(x,6);8) = (x+6) mod 2.

値2の定常位置は{1,3,5,7,21}。x=15だけはO[21,29]が一時的に加わる（掃引行）。z=8族の定常第5点は2y+9で、y=1..6では11,13,15,17,19,21が6点連続で成立する。x=8,12では第5点が17,19と前倒しで現れ、x>=16で21に定着する。値1の頭部O[9,19]={9,11,13,15,17,19}=z+1+2i (i=0..5)はz=8族のy=1..6各切片を貫く奇数帯で、中間帯は偶数帯E[22,x+15]/E[22,x+14]、tailが1になる側（y=6ではx奇数行）にI[x+16,∞)が付く。y=4ではI帯は奇数行・y=5では偶数行・y=6では再び奇数行で、I帯の行がyの偶奇で交互する観察が2延長で確認された。x=15の掃引帯は掃引位置x=z+y+1と掃引範囲O[2y+9,2y+17]の族公式どおり。x=16は値としては偶数定常式に合致するが署名帯は過渡行（A子が掃引行x=15を横切る）で、署名の定常はx>=17奇・x>=18偶から始まる。

## 証明

R=0は終局で値0。R>=1,x>=7の選択肢は

    A = H(R-1;(x-1,6);8)
    B = H(R-1;(x,5);8)
    C = 1 xor H(R-1;(x,6);7)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0991、CはK0982で評価できる。x=6では二つのトークン減少手が同じ(x,5)子（最大トークン6）に合流するため、A=B=K0991のx=6行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

各行はAに帰納仮説、BにK0991、CにK0982を代入した子値集合である。x>=17奇数行とx>=18偶数行では、帯端だけがxに依存し、署名は一定である。x=15は掃引行、x=16はA子が掃引行x=15を横切る過渡行で、x=16の偶数帯E[22,30]（署名02・mex 1）と奇数帯O[23,29]（署名1・mex 0）の分割だけが定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+14を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+15ではK0832の高R tail定理を各子に適用できる。x奇数ならA=B=C=0で親値1、x偶数ならA=B=C=1で親値0となり、親tail (x+6) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=8,y=6切片のみを扱う。z=8のy>=7、z=9のy>=6、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=8族の定常第5点 2y+9 の一般化（y=1..6の6点連続）と第5点の前倒し配置（y=6でx=8,12）、I帯のy偶奇交互は観察であり証明ではない。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
