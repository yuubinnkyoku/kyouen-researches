# 三行二次形式ゲーム：無理数係数の真の安定化長は15

2026-10-23。現在の知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。標準共円ゲームではなく、退化も含む行列式零の変種。

盤面は \(D(3,m)=\{0,\ldots,m-1\}\times\{0,1,2\}\)。相異なる4点に対し

\[\det[x_i^2+\lambda y_i^2,\ x_i,\ y_i,\ 1]_{i=1}^4=0\]

なら禁止する。\(\lambda\) は固定された**任意の無理数**とする。整数格子の各四点組の行列式は整数係数の \(A+B\lambda\) なので、無理数では \(A=B=0\) のとき、かつそのときだけ禁止となる。

## 無界の新定理（数学的証明）

すべての無理数 \(\lambda\) について、三行盤の**真の満容量安定化長**は

\[\boxed{M_{3,\mathrm{irrational}\ \lambda}=15}.\]

つまり全 \(m\ge15\)・全安全局面 \(S\) で、極大安全集合はすべて9石、

\[\boxed{K(3,m;\lambda)=s(3,m;\lambda)=9,\qquad g(S)=(9-|S|)\bmod2}.\]

空盤は先手勝ち。\(m=14\) には8石の極大安全集合があるため15は鋭い。任意の固定 \(m\) では、無理数の代わりに有限個の例外有理数を除いた実数 \(\lambda\) でも同じ結論が成立する。ただし例外集合は \(m\) に依存する。

### 禁止四点組の全称分類

三行整数格子で \(A=B=0\) となる四点組は、次の二種類に限る。

1. 同じ水平行にある4点。
2. 異なる二つの水平行から2点ずつ選び、それぞれの横座標を \(a,b\)、\(c,d\) としたとき \(a+b=c+d\) となる4点。

証明：4点が非共線なら \([x,y,1]\) の列階数は3。\(B=0\) なら \(y^2=ux+vy+w\) が4点上で成立する。三つの異なる高さが現れるなら同じ高さの相異なる二点が存在するため \(u=0\)。すると三つの異なる \(y\) で \(y^2=vy+w\) が成立して矛盾。従って高々二行を使う。\(A=0\) かつ非共線なら、一行に3点あると \(x^2=px+qy+r\) が3個の異なる \(x\) で成立して矛盾するので、二行から2点ずつ。各行で二次式の二根の和が同じ係数 \(p\) になることから \(a+b=c+d\)。逆向きは \(y^2\) が二行上で \(y\) の一次式、\(x^2\) が各行上で共通傾き \(a+b\) の \(x\) の一次式になることから従う。三行格子で4点共線なら水平行だけ。

したがって禁止四点組数は、\(r_m(t)=\#\{0\le a<b<m:a+b=t\}\) とおけば

\[F_m=3\binom m4+3\sum_t r_m(t)^2\]

\[\boxed{F_m=3\binom m4+\frac{2m^3-3m^2+4m-3(m\bmod2)}4}.\]

例えば \(m=7,14,15\) でそれぞれ \(246,4242,5628\) 組。

### 15以上で必ず9石まで伸ばせる理由

各行に4点置くと禁止されるので、どの行も石数は3以下。ある行に \(k\le2\) 点あるとする。他の二行が作る二点和は合計高々 \(2\binom32=6\) 個。新しい横座標 \(x\) が禁止されるのは、既存の同じ行の横座標 \(a\) と他行の二点和 \(t\) が \(a+x=t\) を満たすときだけ。よって禁止候補は高々 \(6k\) 個、占有済みの \(k\) 個を合わせても \(7k\le14\) 個。\(m\ge15\) なら必ず追加可能。全極大配置は各行3点、合計9点。終局までの残り手数が常に \(9-|S|\) であるため、mexの帰納法でGrundy公式が従う。

### 14での鋭い反例

\(y=0:\{1,8\},\ y=1:\{3,5,7\},\ y=2:\{5,6,8\}\)。各行の二点和集合は順に \(\{9\},\{8,10,12\},\{11,13,14\}\) で、互いに交わらないので安全。後二行は3石で満杯。最初の行の未占有12列は、既存の \(1\) または \(8\) と他行の二点和を作るためすべて禁止。従って8石で極大。

## 独立監査・有限完全列挙

- `independent_determinants.py` は4×4置換行列式で \(A,B\) を計算し、\(m=3,4,5,6,7,8,14,15\) の全四点組について上記分類と個数公式を照合。さらに14列の8石証人の安全性・全空き点の禁止性を行列式から直接検査。
- `exhaustive_maximal.cpp` は二点和のビット集合で、行ごとの石数が2または3である全安全配置を \(m=14,15\) で完全列挙し、全追加候補を検査。行置換を同一視した石数型 \((2,2,2),(2,2,3),(2,3,3)\) を網羅する。14列では固定された不足行の8石極大配置24件（行置換込み72件）、15列では不足極大配置0件。

再現：

```sh
python3 independent_determinants.py
g++ -std=c++17 -O3 exhaustive_maximal.cpp -o /tmp/exhaustive_maximal
/tmp/exhaustive_maximal
```

有限計算は分類・証人の**独立検算**。\(m\ge15\) の無界の結論は上の計数証明による。\(m=14\) の単一反例は行列式でも独立検査済み。有限例外有理数でのゲームの振る舞いは本定理の対象外。

出力（C++）：

```text
m=14 safe_deficient_candidates=7829706 deficient_maximal=24 witness={1,8} {3,5,7} {5,6,8}
m=15 safe_deficient_candidates=14430504 deficient_maximal=0 witness=none
```

この無界結果は既存の3×5〜3×7の全実数有限分類と重複しない。標準共円ゲーム \(\lambda=1\) の \(M_{3,4}=24\) とも区別する。
