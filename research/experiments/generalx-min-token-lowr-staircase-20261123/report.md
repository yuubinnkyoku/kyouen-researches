# 一般X低Rミントークン階段定理（min-token staircase）: H(R;X;z) = v(ΣX;z;R) for R <= z+min(X)

実験: generalx-min-token-lowr-staircase-20261123（2026-11-23、単一オーナー宣言 commit 35cbad4f 配下・publish-then-execute）
作成名: Vibe 高速レーン（定時自律実行）

## 命題（定理・全称）

空でない任意の有限多重集合 X（トークンは正整数、アリティ自由）、任意の z>=0、
任意の 0<=R<=z+min(X) に対して

    H(R;X;z) = v(ΣX, z, R)

が成立する。ここで v(x,z,R):=H(R;(x);z) は単一トークン残余ゲームの値
（K0832出版の閉形式）である。

**この定理の全称性は本報告書の構造的帰納法による。** 機械監査は証明そのものでは
なく、エンジン・アンカー・限界ケースの独立照合である（AGENTS.md規定の区別）。

## 記法・定義域

残余ゲーム H(R;X;z) は K0832/K1138系の検証器と同一の再帰で定義する:
- H(0;X;z)=0。
- 各手は残容量を1消費し、子は R-1 で評価する:
  - A手: トークン a>1 を a-1 に減らす（z不変）。
  - B手: トークン a=1 を除去する（z -> z+1）。
  - C手: z>0 のとき選択肢値 1 XOR H(R-1;X;z-1) を追加する。
- H(R;X;z) = mex(子の値の集合)（重複子は集合で潰れる）。

## 補題E（空残余）

H(R;∅;z)=0（任意の R,z>=0）。
証明: Rについての帰納。R=0 は定義。R>=1 のとき選択肢は高々
{1 XOR H(R-1;∅;z-1)}={1}（z>0）または ∅（z=0）で、いずれも mex は 0。∎

## 補題Z（単一トークン残余のz-shift不変性・本証明の唯一の解析的成分）

全ての x>=1, z>=1, 0<=n<=z に対して

    v(x,z+1,n) = v(x,z,n).

証明: nについての強帰納（x,zは全称）。
n=0: 両辺とも H(0;·)=0。
n>=1: 両辺を展開する。
v(x,z+1,n) の選択肢: デクリメント（x>=2 なら v(x-1,z+1,n-1)、x=1 なら除去で
空残余 z+2 の値 0（補題E））と C手 1 XOR v(x,z,n-1)（z+1>0 で常に合法）。
v(x,z,n) の選択肢: デクリメント（x>=2 なら v(x-1,z,n-1)、x=1 なら除去で
空残余 z+1 の値 0）と C手 1 XOR v(x,z-1,n-1)（z>=1 で合法）。
子を組にして比較する:
- デクリメント対: 帰納法 Z(x-1,z,n-1)（条件 n-1<=z は n<=z から成立）により
  v(x-1,z+1,n-1)=v(x-1,z,n-1)。x=1 の場合は両辺とも補題Eの値 0。
- C対: 帰納法 Z(x,z-1,n-1)（条件 n-1<=z-1 は n<=z と同値）により
  v(x,z,n-1)=v(x,z-1,n-1)。z=1 のときは n<=1 から n=1 のみで、
  n-1=0 で両者とも v(·,·,0)=0。
よって選択肢集合は完全に一致し、mex も等しい。∎

## 定理の証明（min(X)>=2 リフト + min(X)=1 基底）

主張を R についての強帰納で証明する（各帰納段階で X, z は全称）。
R=0 は終局で両辺 0。以下 R>=1、m:=min(X)>=1、S:=ΣX とし、R<=z+m を仮定する。
単一トークン側 (S,z,R) の選択肢は、S>=2 のとき
{v(S-1,z,R-1)} ∪ ({1 XOR v(S,z-1,R-1)} | z>0)、
X={x} が単一トークンのときは主張は恒等式として成立。

### 場合1: m>=2（アリティ自由リフト）

X に 1トークンは存在せず、B手はない。
- A手の子: 各トークン a_i を a_i-1 にする子 X_i の和は S-1、min(X_i)>=m-1。
  帰納法の適用条件 R-1 <= z+min(X_i) は R-1<=z+m-1<=z+min(X_i) で成立し、
  全てのA子の値は v(S-1,z,R-1) に一致する。
- C手の子 (R-1, z-1): 条件 R-1<=z-1+m は R<=z+m と同値で、
  値は 1 XOR v(S,z-1,R-1)。
LHSの選択肢集合 = {v(S-1,z,R-1)} ∪ ({1 XOR v(S,z-1,R-1)} | z>0)
= 単一トークン側の選択肢集合（S>=m>=2）。mex は等しい。∎(場合1)

### 場合2: m=1（補題ZがB子値をA子値に一致させる）

X = {1}^t ∪ Y（t>=1、Y はトークン>=2 の多重集合・空も可）とする。
R<=z+1 に注意。
- A手の子（Y 非空の時）: min >= 1 で R-1<=z<=z+min(child)、値は
  v(S-1,z,R-1) =: A。
- B手の子: X から 1 を1個除去した X' を (R-1, z+1) で評価。
  min(X')>=1 で R-1<=z+1+min(X')、値は b := v(S-1,z+1,R-1)。
  n:=R-1<=z だから **補題Zにより b = v(S-1,z,n) = A**。
  （z=0 のときは R<=1 で n=0、両者とも 0。S>=2 は |X|>=2 または恒等式ケースで
  確保され、補題Zの適用には S-1>=1 が必要十分。）
- C手の子 (R-1,z-1): 条件 R-1<=z は R<=z+1 と同値、値は
  1 XOR v(S,z-1,R-1) =: c。
LHSの選択肢集合 = {A} ∪ ({c} | z>0)（B子は値Aの重複、全1多重集合 {1}^t, t>=2
でも A手不在で {b}∪{c} = {A}∪{c}）。
単一トークン側（S>=2）の選択肢集合も {v(S-1,z,R-1)} ∪ ({1 XOR v(S,z-1,R-1)} | z>0)
= {A}∪({c})。mex は等しい。∎(場合2)

両場合を合わせて定理は成立する。∎

** remark: 証明はK0832単一トークン閉形式を一切使わない（補題Zも含めて純構造的帰納
であり、閉形式は機械監査のアンカーとしてのみ使用する）。**

## 系

1. **2トークン窓**: x>=y>=1, R<=z+y で H(R;(x,y);z)=v(x+y,z,R)。窓は行の
   minトークン y とともに1ずつ上る（階段構造）。
2. **z切片族の低R観察の全z昇格**: K1259 が未解決として列挙した
   「R<=z+6 低R縮約の全z一般証明」は本定理の y>=6 の場合として閉じる
   （y>=6 => z+y >= z+6）。K1259/K1261/K1262/K1263レーンが「一般z版は未証明の観察」
   と7例連続で区別していた z=14..20 の R<=z+6 一致、および published y=22機の
   C1d低Rチェック（z=15..17）はすべて本定理の帰結となる。
3. **K0832 一般X低R縮約の拡張**: K0832出版の「R<=z+1 なら一般多重集合Xが総和Sの
   単一トークンへ縮約」は本定理の R<=z+1<=z+min(X) の部分ケース。本定理は窓を
   z+min(X) まで真に拡張する（min(X)>=2 で厳密な強化）。
   K0832 の「R<=2 は全zで成立」条款は本定理と直交し、併用すれば
   縮約保証領域は R <= max(z+min(X), 2) に拡大される。
4. **未証明領域の被覆**: 2トークン y>=23, z>=20 の未開拓域も窓 R<=z+y は
   全称保証される（証明はzにもyにも上限を置かない）。

## 鋭さ（有限観測として区別）

- min=1 一様の鋭さ: X=(2,1), z=1, R=3=z+min+1 で H=2 vs v(3,1,3)=0（分離）。
  K0832 の「R>=3 では z>=R-1 が一様条件として鋭い」と整合する反例側。
- 2トークン行ごとの鋭さ witness（R=z+y+1 で分離・audit C5で再現）:
  (2,1)@z=1・{1}^3@z=1（いずれも親2 vs 単一0）、(2,2)@z=2（親2 vs 1）、
  (4,3)@z=5（2 vs 0）、(4,4)@z=6（2 vs 1）、(6,5)@z=9（2 vs 0）、
  (6,6)@z=10（2 vs 1）。
- **出版 z 切片 witness との精密一致**: K1087 (12,6)@z=17,R=24=親0 vs 単一1、
  K1259 (12,6)@z=18,R=25=親0 vs 単一2（z==x==18対角のz==x閉形式枝）、
  K1261 (14,6)@z=19,R=26=親0 vs 単一1、K1262 (16,6)@z=20,R=27=親2 vs 単一1。
  4例すべて R=z+min+1 ちょうどで破壊しており、窓 z+min の行ごとの鋭さの
  独立傍証である（破壊高さ R=z+7 がy=6行で全z共通という K1259-K1262 の
  横断観察の説明にもなっている）。
- 境界+1 census（C4、y=1..8, d=0..24, z=0..26 の掃引）: 窓内 R=z+y では
  5,400点全点一致、境界+1では 370点の分離（y毎 180/37/32/31/26/25/20/19）。
  y>=9・より深い領域の分離構造は本項では掃引しない。

## 位置づけ・効能

- K0832「一般R<=z+1縮約」の窓を z+min(X) に拡張する最初の全称定理。
  証明技術はK0832の閉形式帯表解析ではなく、選択肢集合の完全一致による
  純構造帰納（FR-X（K1254）の「k>=1層は選択肢集合完全一致で無条件」という
  觀察と同型の技術を低R方向に独立に構成したもの）。
- 今後の z 切片・y 族検証機の lowR チェックは族固有の系でなく本定理を引用して
  構成できる（y>=6 一様族機の R<=z+6 チェック、K1263 z=21 機の低R帯など）。
  FR-X/GX-M レーンの F±X 前沿条件のうち境界行 R'<=σ の低R側とも整合
  （本定理は min(X)>=σ-R' 型の下限保証を与える）。
