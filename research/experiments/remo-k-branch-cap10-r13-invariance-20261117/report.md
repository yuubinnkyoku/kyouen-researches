# 3枝REMO決定性のr=13不動列と定理J（枝サイズ≤10）

2026-11-17。K0898（r=12境界）が「r≥13は未走査」と残した列の埋め。
K0862/K0864/K0866/K0893/K0895/K0897/K0898と同一のcap≤10領域
（正準形15,863プロファイル・715キー・Burnside 15863）をr=13で完全
スイープし、r=13列がr=12列と**全ラベルで一致**することを確定する。
あわせて一般則を**定理J（予想）**として定式化する。自己完結検証器
`verify_remo_k_branch_cap10_r13_invariance.py`（stdlibのみ・決定的）が
13機械チェック全合格・二重実行byte同一（sha256 8557f6a200441380baf16506452c1d01862bfc9d3bd92f774fddb008bb0a36d4）。

## 主張

**r=13列（有限・完全スイープ）**: 決定性が(sizes,γ)に坍縮しない
（mixed）キーはr=9..12の4列と**同一の7族34個**で、新規キー0個・
坍縮0個（5列連続同一）:

- (6,6,8),(6,8,8)×γ=0..4（10キー）
- (8,8,9),(8,9,9)×γ=0..5（12キー）
- (6,6,9),(6,8,9),(6,9,9)×γ=0..3（12キー）

34キーすべてで決定側生存者は一様P_5（=チェーン値・定理G′ r=13
拡張・不一致0）。非決定側可能生存者集合・per-key分割計数も34キー
すべてでr=12出版表と完全同一。センサスは一様決定98・一様非決定583・
mixed 34（r=9..13でキー数不変）。max_states 741,630（r=12の666,030
より増大・状態数はr単調でないが増加傾向）。Δ=0プロファイル728個は
定理Dのr=13列（検証器内verbatim再帰・K0859表の外挿列）に全一致。
補題FL違反0（K0864全称証明のr=13冗長アンカー）。

**STASIS5（5列分類不動点＋3列全ラベル不動点）**: K0898出版のr=12
packed記録・K0897出版のr=11 packed記録とr=13記録が**全15,863プロ
ファイルでdeterminedフラグ・生存者mask・第1敗者maskの3つ全て完全
一致（0/0/0差分・両比較）**。全ラベル不動点はr=11↔r=12（K0898）に
続きr=12↔r=13でも成立し、**3列連続（r=11,12,13）の全ラベル不動点**。
K0895 r=10・K0893 r=9記録を含めると**5連続列（r=9..13）で決定性
分類が完全不変**（有限観察）。ラベル収束の様相（段階的収束）:
detフラグはr=9→固定・生存者maskはr=10→固定・第1敗者maskはr=11→
固定、以降不動。

**ARITH（補題FL wraparoundの列間交差検証・新種の算術チェック）**:
r=13は最大枝サイズ10を超えるため第1敗者ラベルは非wrapの{C_i}その
もの。よって補題FL（fl={C_i mod r}・K0864全称証明）は次を予測する:
r=13記録とr=10記録の第1敗者ラベル差集合は**maxC=10プロファイル
集合と正確に一致**し（7,328件）、r=13とr=9では**maxC≥9集合**
（11,533件）。両者とも3つのcommitted列にわたる**集合等式として
成立**（検証器C12・全15,863プロファイルで双方向包含を検査）。
生存者ラベルはr=10とは全プロファイルで一致（差0）し、r=9とは
**同一のmaxC=10集合（7,328件）でちょうど差を持つ**（集合等式・
検証器C12の3本目）。これにより「r=10→11で7,328件動いた第1敗者
ラベル」の動きが剰余算術で完全説明され、生存者ラベルのr=9→10
収束も同じ7,328プロファイルに局在することが確定する。

**定理J（予想・未証明）**: k枝プロファイル（枝サイズC_1..C_k・
M=max C_i）に対し、(i) 生存者集合svと決定性フラグdetは**すべての
r ≥ Mで一定**、(ii) 第1敗者集合はfl={C_i mod r}（補題FL・K0864
全称証明済み）ゆえ**r > Mで一定**。cap≤10領域ではM ≤ 10 < 13なので、
r=13列は予想の帰結「r=13列=r=12列（全ラベル）」を満たす最初の独立
検証列であり、r=14/17の層化サンプル496判定×2（live L5）も予測
（committed r=13ラベル一致+fl={C_i mod rr}）を全数一致で満たす。
**予想が正しければcap≤10領域のrレーンは閉じる**: r ≥ 13の全列は
r=12列（=r=11=r=13列）と全ラベル等しい。r ≥ 14のスイープは不要に
なる。ただし本項はこの閉包を**条件付き**でしか主張しない（定理Jは
未証明）。

**補題C1（カスケード停止・本項で証明付きの新規補題）**: すべての
石がstar[Y]内にある局面を考える（star[i]=枝iを含む原子集合・
C_i=star[i]の総容量・単一原子は枝iのみの原子）。単一原子は空でない
（C_i ≥ 1+共有石）ので、star[Y]内の局面で他の枝j ≠ Yが飽和する
ことはない: star[j]上の石は共有原子j∩Yにしか載らず、その総容量は
C_j−単一_j ≤ C_j−1だから。よってstar[Y]内のプレイで飽和トリガーに
なり得るのは枝Yのみであり、Yの飽和（総石数=C_Y・包含）は「石を
持たない敗者の連鎖（0石敗者を順に飛ばす）」の後、**必ず石を持つ
敗者P_0で停止する**（盤上のC_Y ≥ 1個の石はすべて現役プレイヤーの
もので、少なくとも1人は石を持つ）。P_0の石（y ≥ 1個・すべて
star[Y]内）が除かれた後、どの枝も飽和しておらず通常プレイに戻る。
この補題は盤上の所有権構造と無関係にカスケードの有限性を保証する
（証明: 上の容量不等式・検証器の状態遷移規則から直接）。

**証明スケッチ（未完成・定理Jの方向付け）**: 敗者は「その時点の
累積置石数Tのr剰余」（置石数Tのプレイヤー=T mod rが消滅対象=手番
者）。第一飽和はT=C_Y ≤ Mでr ≥ Mならwrapなし・敗者index=C_Yは
r非依存。補題C1により各飽和イベントは有限カスケード+1人の石持ち
敗者で構成され、盤面はstar[Y]内に留まる限り枝Yの再飽和のみが
トリガー。プレイライン分解（playline decomposition: star[Y]内の
再飽和サイクルと共有原子を経由した他枝への脱出は、すべて単一
原子の空容量によって律速される）と「脱出後も同型の議論」を帰納
的に重ねると、イベント木の抽象構造（どの枝がどの順で飽和し、
どの順でプレイヤーが石を失うかの所有権抜き骨格）はr非依存で、
r依存性は敗者indexのT mod r算術のみに局在する、という形の議論が
組み立てられる。ここまではスケッチであり、(a)脱出後の包含条件の
帰納段階、(b)所有権と敗者indexの相互作用、(c)sv/detへの集約、の
3点が未完成。**定理Jは予想として扱い、証明済みとはしない。**

**FATE56（族の運命・r=3..10出版失敗キー56個のr=13列）**:
r=9..12でmixedだった34キーは**全てr=13でもmixed存続**（5列連続）。
22キーは一様非決定のまま（チェーンverdict・チェーン生存者ラベルも
r=11/r=12と不変）で**4列連続の無事象列**。

**剰余レンズ（r=13の新算術列）**: 715キーの剰余類計数は単一55・
二重330・三重330でr=10/r=11/r=12と完全同一（本項が初計数・純算術・
r=13>最大枝サイズ10でwraparound無し・一般にr>最大枝サイズなら
分割不変は純算術の帰結）。mixedキーの剰余対は{6,8},{6,9},{8,9}と
3剰余{6,8,9}（(6,8,9)×γ=0..3）で「非坍縮⇒2剰余」初反例は5列目も
存続。

**SG（過大主張防止の機械ガード）**: 状態数はr不変でない: r=13の
max_states 741,630 ≠ r=12の666,030（両方committed記録から再導出
して検証器C13でpin）。本項の列不変性は**ラベルのみ**（detフラグ・
生存者mask・第1敗者mask）を対象とし、状態数・順位・消滅順序の
r不変性は主張しない（消滅順序はrで変わる・J-3）。生存者集合への
r非依存性は予想の一部（定理J(i)）であり、検証されたのは
r=9..13の5列+スポットr=14/17である。

## エンジン

`mask_engine_fast_r13.js`はK0898出版エンジンのbyte同一コピー
（sha256 c2b5c2767f446c9ff5bac511d2a9044597976f64295f23d847a53305b287b03b
・CLI引数でr指定）。r=13スイープは15,863レコードを566.9秒で
生成。packed出版blobは326,564 bytes（sha256 b0ec4f58ac0f4e91185ad252924920738d5e6e8d47a75e61477cf3d915bb7dca）。

検証器のPython mask twinは本項で**メモリ効率化**された: K0898版の
メモ状態（tuple-of-tuples+frozenset・約1.7KiB/状態）はr=13の最重
サンプルプロファイル（約742k状態）で1GiB監査環境を超過するため、
状態をflat bytes（counts[m*r+p]）+整数bitmaskに再符号化した
（走査・状態空間・len(memo)=states計数・verdict完全同一・L1/L2で
毎実行live再検証）。これは検証器の実装差分であり数学的内容は
変わらない。

## 限界

- **定理Jは未証明の予想**。rレーン閉包（r ≥ 13の全列=r=12列）は
  定理Jに条件付き。無条件に確定したのはr=13列（完全スイープ）・
  r=9..12列（committed）・r=14/17層化サンプル（L5・各496判定）。
- 枝サイズ11,12×r=9..13は未走査（K0881のcap≤12拡張はr=7,8まで）。
  定理Jはもし証明されればこれらにも全称適用されるが、アンカー列は
  ない。
- 順位決定性は本項で扱わない。消滅順序はr不変でない（SG参照）。
- STASIS5/ARITH/FATE/分割計数不変性は有限観察のまま。
- 11×11空盤・二石root・クラスフロンティアは本項と無関係でUNKNOWN
  のまま。
