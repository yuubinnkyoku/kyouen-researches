2026-10-27。標準q=4、完全指摘、通常プレイ。**11×11空盤の勝敗はUNKNOWN**。

既存のn22（22子890類）とn23（23子256類）の固定証明書を終局まで再実行し、証明限定8石WIN5,120類から再開した。n23選択時に未証明の8石親に接続していた23子9石候補は445類あり、256類はn23で検証済み。残る189類を再評価すると、32類は既に未証明の保存14根8石子に接続しなくなっており、**現在も未証明親に接続する157類**だけを選択した。候補選択順序をSHA-256で固定した。

選択157類の全合法10石子を3×3整数差分行列式と独立した4×4整数Bareiss法で終局まで再計算した。**9石WIN23類・LOSS134類**。WINには全23子がWINであること、LOSSには少なくとも1子がLOSSであることを確認した。相異なる10石葉3,454類、各幾何の終局探索状態数487,390。既知8石LOSS338類との衝突0。
