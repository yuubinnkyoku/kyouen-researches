# 安全な子局面のD4同値と親の着手軌道がずれる例外の完全分類

2026-10-13。標準四点共円・共線禁止、任意の正方形盤についての全称証明。
K0421の四石以上の定理を、四石未満の必要十分分類と正確な補正公式で完成させる。
勝敗・Grundy数・11×11空盤の解決を主張するものではない。

## 記号と結論

盤の中心を `c`、中心まわりの90度回転を `r` とする。
`n` が偶数なら `c` は盤の点ではない。点 `a≠c` の回転軌道は

`O(a)={a,r(a),r²(a),r³(a)}`

である。「一般位置点」とは、中心を通る水平・垂直・二対角線の四つの鏡映軸の
どれにも載らない点を意味する。中心相対座標 `(x,y)` では

`x≠0, y≠0, x≠y, x≠−y`

が必要十分であり、そのD4軌道は八点からなる。

安全な親 `S` の合法手集合を `L(S)`、親の安定化群を `H=Stab_D4(S)` とし、
`A(S)` を `H` による合法手軌道数、`C(S)` を子 `S∪{p}` のD4同値類数とする。

**完全分類定理。** `C(S)<A(S)` が成立する必要十分条件は、一般位置点 `a` と
`Z∈{∅,{c}}` を用いて、次のいずれかに書けることである。
中心一点の選択は盤に中心が存在する場合だけ許す。

1. `S=Z∪{a}`。
2. `S=Z∪{a,r(a)}`。

全ての例外で `H={id}`、`A(S)−C(S)=1` である。
余分に同値になる合法手対は、第一型で `{r(a),r³(a)}`、第二型で
`{r²(a),r³(a)}` に正確に限られる。
第二型の表示で回転方向を逆にしても同じ集合族になる。

従って、全ての安全な親について正確な公式

\[
C(S)=\frac{1}{|H|}\sum_{h\in H}|\operatorname{Fix}_{L(S)}(h)|
      -\mathbf 1_{\{S\text{ は上記例外}\}}
\]

が成立する。四石条件を外したBurnside公式への補正は、例外指示関数一つだけである。

## 必要性

親の異なる着手軌道に属する合法手 `p≠q` があり、
`g(S∪{p})=S∪{q}` と仮定する。もし `g(p)=q` なら `g(S)=S` となり、
同じ親着手軌道になってしまう。従って `g(p)∈S` である。

位数二の `g` では `p=g²(p)∈g(S)⊂S∪{q}` となり矛盾する。
恒等変換でも子は相異なるため不可能。よって `g=r` または `r⁻¹` に限られる。
必要なら回転方向を交換して `g=r` としてよい。

`g(p)∈S` と `q∉S` より

`r(S)=(S\{r(p)})∪{q}`、従って `|S△r(S)|=2`。

中心は回転で固定される。各非中心四点軌道は共円なので、安全な `S` は
その四点全てを占有できない。空でない部分軌道は `S△r(S)` に少なくとも二点を
寄与するから、非中心占有点はちょうど一つの四点軌道 `O` に限られる。
その占有部分 `T=S∩O` は回転周期上で連続する点からなる。
二点の場合、対向二点なら対称差が四点になるため、隣接二点に限られる。

`r(p)∈S` と `q∈r(S)\S` はともに `O` 内にある。従って相異なる `p,q` は
`O\S` 内にある。未占有点が一つしかない三点占有は不可能である。
よって `T` は一点または隣接二点で、`S=T` または `S=T∪{c}`。

ここまでで必要な形が得られた。鏡映軸上の点から生じる形が本当の例外ではない
ことを次に示す。

## 鏡映軸上なら親の着手軌道に既に含まれる

`a` が鏡映軸上なら、`a` を固定する鏡映 `f∈D4` が存在し、`fr=r⁻¹f` を満たす。

第一型 `S=Z∪{a}` では `f` が親を保ち、`r(a)` と `r³(a)` を交換する。
従ってこの手対は同じ親着手軌道である。

第二型 `S=Z∪{a,r(a)}` では鏡映 `rf` が `a` と `r(a)` を交換して親を保ち、
同時に `r²(a)` と `r³(a)` を交換する。やはり同じ親着手軌道である。
必要性の議論で余分な同値を生じ得る手対はこれらだけなので、軸上の形は例外にならない。

## 一般位置なら必要な同値が存在し、補正は正確に一つ

一般位置点 `a` を固定するD4変換は恒等変換だけである。
第一型の親は、中心を任意に加えても安定化群が自明となる。

第二型で親を保つ変換 `h` を考える。`h(a)=a` なら `h=id`。
`h(a)=r(a)` なら `r⁻¹h` が一般位置点 `a` を固定するため `h=r` となるが、
`r` は `r(a)` を `r²(a)` に移すので親を保たない。従って第二型も安定化群が自明である。

第一型では

`r(S∪{r³(a)})=S∪{r(a)}`。

第二型では

`r(S∪{r³(a)})=S∪{r²(a)}`。

いずれも安定化群が自明なので二手は異なる親着手軌道である。
第一型の子と中心を含まない第二型の子は高々三点だから全て合法。
中心を含む第二型の子は中心と `O` の三点である。`O` の三点は非共線であり、
その唯一の円は中心 `c` を中心とする非零半径の円なので `c` を含まない。
従ってこの四点も共円・共線ではなく合法である。

必要性の議論を固定した `S` へ適用すると、四分回転と逆回転が生じさせる余分な
手対は上述の同じ一組に限られる。他のD4変換は親着手軌道内の同値しか生じさせない。
よって正準子の同値類は正確に一組だけ合併し、`A(S)−C(S)=1`。証明完了。

## 任意nの例外数

`t=⌊n/2⌋` とする。一般位置点の絶対座標は、奇数盤なら `1,…,t`、
偶数盤なら `1/2,3/2,…,t−1/2` から異なる二つを取る。
絶対座標の順序を無視すれば `binom(t,2)` 通りで、各々の符号と交換で八点となる。
従って一般位置点数は

\[
G(n)=8\binom t2=4t(t-1)=
\begin{cases}
(n-1)(n-3)&n\text{ 奇数},\\
n(n-2)&n\text{ 偶数}.
\end{cases}
\]

第一型の中心なし親は `G(n)` 個、中心あり親も中心が存在すれば `G(n)` 個。
第二型の中心なし親は各四点軌道の四つの隣接対だから `G(n)` 個であり、
中心あり親も中心が存在すれば `G(n)` 個である。これらの型は互いに重ならない。

| 親の石数 | 奇数nの例外親数 | 偶数nの例外親数 |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| 1 | G(n) | G(n) |
| 2 | 2G(n) | G(n) |
| 3 | G(n) | 0 |
| 4以上 | 0 | 0 |
| 合計 | 4G(n) | 2G(n) |

各例外親の安定化群は自明なので、D4同値類数は表の値を八で割った値である。
従って各型の親D4類数は `binom(t,2)`。奇数盤では四型、偶数盤では二型ある。
11×11では `t=5, G(11)=80` なので、サイズ1・2・3にそれぞれ80・160・80親、
D4類として10・20・10類、合計320親／40類である。

さらに次が直ちに従う。

- `n≤3` では全ての安全親で `C(S)=A(S)`。
- 偶数盤では全ての三石以上の安全親で `C(S)=A(S)`。
- 奇数盤でも中心を占有しない三石以上の安全親では `C(S)=A(S)`。
- 三石例外が存在するのは奇数 `n≥5` に正確に限られる。
- 任意の例外で `C(S)=|L(S)|−1`。第一型と中心なし第二型では
  `|L(S)|=n²−|S|` も成立する。

## 適用範囲

証明は共線禁止を必要としない。中心を共有するD4不変な任意の有限平面点集合 `V`
におけるcircle-only q=4でも同じ必要十分分類と補正公式が成立する。
一般位置点数を `G`、中心が `V` にあるかを `χ∈{0,1}` とすれば、例外親数は
サイズ1・2・3で `G, (1+χ)G, χG`、合計 `2(1+χ)G` となる。
`V` のD4不変性により一般位置軌道は必ず八点なので `G/8` は整数である。
q>4やline-onlyへの延長は主張しない。

分類不一致は全盤でゼロ。全例外の安定化群が自明で補正が一つであること、
