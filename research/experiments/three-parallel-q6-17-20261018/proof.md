# 三平行線・6点禁止ゲーム：一様十分候補数17

2026-10-18。**証拠種別：全称数学的証明＋整数上の有限完全列挙（独立したPython/C++検証）。**
対象は3本の相異なる平行直線、それぞれに任意の実数位置の相異なる候補点が17個以上ある盤。等間隔・整数座標を仮定しない。標準等間隔盤の真の値 `M_{3,6}=9`（K0070）とは別の一様問題。

## 定理

共線または共円の6石を禁止する完全指摘・通常プレイでは、任意の極大安全配置は各直線5石、合計15石である。任意の安全局面 `S` について

\[
\boxed{g(S)=(15-|S|)\bmod 2}.
\]

**17は十分条件であり、真の最小一様候補数と主張しない。** 従前の19候補十分を改善する。

## 1. 四円同時通過の組合せ必要条件

補題1：二本の相異なる平行直線 `L_B,L_C` 上に各5点以下を置く。第三直線上の点 `P`（`P` は `L_B,L_C` 上にない）を通り、各 `L_B,L_C` 上の指定点をちょうど2点ずつ通る**相異なる4円**があるなら、その4円のどの2円も、`L_B ∪ L_C` 上の指定点を**ちょうど1点**共有する。

証明：4円の各々は各直線に2点ずつ接続するので、各直線には計8個の円・点接続がある。5点以下に8接続を配分したとき、同一点を共有する円の対の個数（重複度 `d` に対する `C(d,2)` の和）は、凸性により少なくとも3（次数列 `2,2,2,1,1` で最小）。一方、2円が `P` のほかに異なる2点を共有すれば3点を通る円の一意性から同じ円になり、相異なるという仮定に反する。よって各円対は二直線を合わせても高々1点しか共有できない。全6円対に対して両直線の共有円対は合計6以上だから、すべての円対がちょうど1点共有する。□

これにより、円を「B線の弦（2点添字集合）、C線の弦」として列挙したとき、四円同時通過の候補は、4個の円の全6対について

`|B_i ∩ B_j| + |C_i ∩ C_j| = 1`

を満たすものに限定される。この条件は円の半径・直線間隔に依存しない。

## 2. 5点弦和energyの14以上を分類

各線の石の縦座標集合を `B,C` とし、`r_B(s)=#{i<j:b_i+b_j=s}`、`H(B)=Σ_s r_B(s)^2`、`E(B,C)=Σ_s r_B(s)r_C(s)` とする。同和弦の対だけが二線に2点ずつ通る円を作る。5点集合では `H∈{10,12,14,16}`、16は5項等差数列に限る。異なる二弦が同和なら4つの端点はすべて異なり、5点集合の衝突数は高々3で、3なら等差数列になる。従って `H=10+2c`、`c≤3`。

Cauchy–Schwarzから、`E≥14` なら両者の `H` は14以上。`E=15` は不可能であり、`E≤14` または `E=16`（この場合は `B=C` が同じ5項等差数列）。以下で `E=14` を三分類する。

**(14,14)：** `E=14` ならCauchy–Schwarz等号で `r_B=r_C`。5点集合の無順序二点和の多重集合から元の5点集合は一意復元できる。実際 `p_k=Σ b_i^k`、`q_k=Σ_{i<j}(b_i+b_j)^k` とすると、

`q_k=(5-2^{k-1})p_k+(1/2)Σ_{j=1}^{k-1}binom(k,j)p_j p_{k-j}`。

`k=1,...,5` の係数はすべて非零で、`p_1,...,p_5` を復元し、Newton恒等式で5根を復元する。よって `B=C`。

**(14,16) または (16,14)：** `H(B)=14,H(C)=16,E=14` なら `Σ_s(r_B-r_C)^2=2`。両方の二点和は合計10個だから、10個中9個の和が重複度込みで共通する。平行移動・正の拡大で `C={0,1,2,3,4}` と置くと、Cの二点和は1〜7の整数。Bの10本の弦のうち少なくとも9本の和が整数なので、Bの5点は全て整数、または全て半整数である。昇順 `b1<...<b5` とすると、二番目に小さい和 `b1+b3≥1`、二番目に大きい和 `b3+b5≤7`。従って `1/2<b3<7/2`、`-5/2<b1<b5<13/2`。候補は整数9個から5個選ぶ126通り、半整数8個から5個選ぶ56通りの計182通りに完全帰着する。整数演算の全列挙で `H(B)=14,E(B,C)=14` となるのは

`B={-1,1,2,3,4}` または `B={0,1,2,3,5}`

の2種類だけ。両者は上下反転で同値。B/Cの交換も同値としてよい。

**(16,16)：** B,Cは5項等差数列。二点和の台は7項等差数列、重複度は `1,1,2,2,2,1,1`。公差が異なる二台の共通点は高々4点（5点共有すると公差比の既約分子分母がともに1となる）。そのうち両者で重複度2となる点は高々2個（3個あれば中央3連続点が一致し公差も一致する）なので `E≤2·4+2·2=12`。よって `E=14` なら公差は同じ。台のずれが公差1単位なら内積14、ずれ0なら16、ずれ2以上なら12以下。従って `E=14` の正規形は

`B={0,2,4,6,8}, C={1,3,5,7,9}`。

この議論は `E=15` の不可能性も与える。`H` の一方が14なら `E≤14`、双方16なら上の台の議論で16または14以下。

## 3. E=14,16では任意の第三線上の点を通る候補円は高々3本

**(14,14)：** `B=C`、`H=14` なので10個の同じ弦を両線で使う対角円と、2組の同和異弦対からできる4個の非対角円がある。対角円2個は二線で同じ弦を使うため、共有点数が0または2となり、補題1に反する。非対角円のうち同じ衝突対を左右交換した2個は二線のどちらでも弦が互いに素で、共有点数0となる。したがって補題1を満たす集合は対角円1個以下と非対角円各衝突対から1個以下、合計最大3個。

**(14,16)：** 上の2正規形の各14円について、4円組 `C(14,4)=1001` 通りを補題1の条件で検査すると、該当する組はどちらも0。`verify.py` と独立した `audit_independent.cpp` が同じ結果を得る。全実数配置は上の182候補への厳密な帰着により尽くされている。

**(16,16) で E=14：** 上の正規形で14円の四円組1001通りを補題1で絞ると、2組だけが残る。それぞれの4円を `(s,δ,p)`（二線の弦和、弦積の差、B線弦積）で記すと

```
(4,3,0), (8,3,12), (10,-7,16), (12,3,32)
(8,7,0), (6,-3,8), (10,-3,24), (14,-3,48)
```

二線を `x=0,x=d`、第三線上の点を `P=(du,y)` とすると、その円をPが通る必要十分条件は

`d²u(u−1)+y²−s*y+δ*u+p=0`。

四円の式から最初の式を引いた3本の一次式（未知数 `y,u`）の拡大係数行列式は、上の2組でそれぞれ `-320,+320`。非零なので共通解なし。よって四円同時通過は不可能。

**E=16：** `B=C` が5項等差数列。対角円は高々1個、非対角円は3衝突対の各交換組から高々1個ずつでなければ補題1に反する。四円なら対角円1個＋各衝突対から非対角円1個となる。衝突対の2弦は4点を分割するから、対角弦は共有点数をちょうど1にするため、その衝突対に含まれない5番目の点を端点として含む必要がある。しかし等差数列の3衝突対で除外される点は相異なる3点で、対角弦の端点2個ではすべて含められない。矛盾。なお正規形 `B=C={0,2,4,6,8}` の16円全四円組も独立検査済み。

従って `E=14` または `E=16` なら、第三直線上の任意の点を通る該当円は高々3本。これは有限標本からの推測ではなく、全称帰着と有限整数検査による結論。□

## 4. E=13も第三線上の一点に四円同時通過しない

`E(B,C)=13` なら `13²≤H(B)H(C)` より、`(H(B),H(C))` は順序を除き `(12,16),(14,14),(14,16),(16,16)` のいずれか。最後の `(16,16)` は第2節の等差数列の台の議論から `E=13` が不可能。

**(12,16),(14,16)：** `H(C)=16` として `C={0,1,2,3,4}` に正規化する。`E=13` なら `Σ_s(r_B-r_C)²=H(B)+16-26` は、H(B)=12のとき2、14のとき4。どちらも、Bの二点和10個のうち少なくとも8個がCの二点和（1〜7の整数）に重複度込みで一致する。5点の10本の弦のうち8本以上の和が整数なら、整数和を持つ辺だけからなるグラフ `K5` から高々2辺を除いたグラフには三角形があり、各残余頂点もその三角形と接続するので、Bの全点は整数または全点が半整数。

昇順 `b1<...<b5` の第三小和・第三大和を使うと `b2+b3≥1`、`b1+b4≥1`、`b3+b4≤7`、`b2+b5≤7`。従って `1/2<b3<7/2`、`-11/2<b1`、`b5<19/2`。整数15個 `{-5,...,9}` から5個選ぶ3003通り、半整数14個 `{-9/2,...,17/2}` から5個選ぶ2002通り、合計**5005通り**を整数に2倍して完全列挙できる。`H(B)=12,E=13` は0件。`H(B)=14,E=13` は8件で、正規化してBを2倍した座標は

```
(-2,0,2,6,8)   (-2,0,4,6,8)
(0,2,4,8,10)   (0,2,6,8,10)
(-1,1,3,5,9)   (-1,1,3,7,9)
(-1,1,5,7,9)   (-1,3,5,7,9)
```

これら8件の13円から四円組を補題1で検査すると、**適合四円組はすべて0**。

**(14,14)：** `Σ_s(r_B-r_C)²=2` より、二点和10個のうち9個が重複度込みで一致する。`H(B)=14` は5点の同和異弦衝突がちょうど2組の場合。5つの四点組の衝突方程式を調べ、上下反転・平行移動・正の拡大で、Bの隣接差を次の**3つの一変数族**へ帰着できる（`t>0`、第1・第2族の`t=1`はH=16となるため除外）：

```
F0: (1,t,1,1)
F1: (1,t,1,t)
F2: (1,t,1,1+t)
```

Bの8種類の二点和を `Σ_B` とする。Cの10弦のうち少なくとも9弦の和が `Σ_B` に入るので、Cの5頂点のうち3頂点を選んでその三角形の全3辺を「一致する和」にでき、さらに三角形の1頂点を、残る2頂点との両辺も一致するよう選べる（`K5` から高々1辺除いたグラフ）。その頂点をc1、三角形の他の頂点をc2,c3、残りをc4,c5と書けば、

```
2c1 = s12+s13-s23
2c2 = s12+s23-s13
2c3 = s13+s23-s12
2c4 = 2s14 - 2c1
2c5 = 2s15 - 2c1
```

で、5つの `sij` はすべて `Σ_B` の8種類から選ばれる。したがって**連続実数の探索を有限の8^5個以下の記号候補へ帰着**できる。

Bの各座標を `A+Bt`（整数係数）とみなし、Cの倍座標 `2ci` も整数係数一次式として扱う。`t` を未定元とした記号的な一致判定では、各族につき安全な必要条件で枝刈りした**544個の異なるC候補**が残り、`E≥13` は `C=B,E=14` の1件だけで、`E=13` は0件。

記号的に異なる和が特殊な実数 `t` で一致する可能性も尽くす。Bの二点和の係数は定数項0〜6、t係数0〜4。上式からCの倍座標の係数は定数項−12〜18、t係数−8〜12。よってCの倍二点和とBの倍二点和の差は `A+Bt` で `|A|≤36, |B|≤24`。記号的に異なる両和が一致する `t>0` は、必ず既約分数 `t=p/q`、`1≤p≤36,1≤q≤24` に含まれる。これ以外の実数tでは記号的な判定がそのまま正しい。

この全既約分数について上記の8^5構成を整数演算で完全検査した。5点の相異性と必要な一致数で安全に枝刈りした候補は合計**6,173,662件**、`H(B)=H(C)=14,E=13` を満たすラベル付き生成例は60件で、重複除去後の正規形は**1件だけ**：

```
B={0,1,2,3,5}, C={-1,1,2,3,4}  (F2, t=1)
```

この13円の四円組は、補題1を満たすものが0件。`verify_e13.py` と独立した `audit_e13_independent.cpp` が、記号候補544件×3族、全有理数候補6,173,662件、AP候補5005件の全件数・結論まで一致する。これで任意の実数B,Cについて `E=13` なら四円同時通過は不可能と確定する。□

## 5. 17候補での極大性とGrundy値

6石共線が禁止されるので各線高々5石。極大安全配置で不足線に `a≤4` 石があると仮定し、他の2線の石集合をB,Cとする。不足線に追加して6石共円となる円は、不足線の既存石1個と他の2線から各2石を通る必要がある。円の候補数は高々 `E(B,C)`。既存石を通る各円は不足線上で、もう1点だけを塞ぎうる。

他線のどちらかが4石以下なら、既存の弦和上界またはCauchy–Schwarzで `E≤⌊√(8·16)⌋=11`、利用不能点は `a+E≤15`。両線5石で `E≤12` なら利用不能点は `a+E≤16`。`E=13,14,16` なら第3・4節により既存石の各々を通る円は高々3本だから、利用不能点は `a+3a≤16`。`E=15` は存在しない。

どの場合も不足線上の利用不能候補点は**高々16個**。候補点が17個以上なら必ず追加でき、極大性に反する。したがってすべての極大安全配置は15石。全継続の残り手数が `15-|S|` に固定されるので、通常プレイのGrundy値はその偶奇。□
