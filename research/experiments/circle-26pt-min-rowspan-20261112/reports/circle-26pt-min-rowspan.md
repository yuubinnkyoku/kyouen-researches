## 0. 定式化（3実現族）

格子点を持つ円は、適切な (A,B) と奇・1mod4-smooth R′ で次の3族に帰着する
（素因数分解 p ≡ 1 (mod 4) ⇔ p = a²+b² とガウス整数の標準理論による）。

| 族 | 円 | 中心 | 行オフセット | 幅 |
|---|---|---|---|---|
| E | (2x−A)²+(2y−B)² = 2R′ | (奇/2, 奇/2) | ±c/2, c ∈ {X+Y, |X−Y|}（奇） | (c_max−c_min)/2+1 |
| O | (2x−A)²+(2y−B)² = R′ | (奇/2, 整数) | ±Y_even/2 | span+1 |
| Z | (2x−A)²+(2y−B)² = 4R′ | 整数 | ±X, ±Y | span+1 |

ここで (X,Y) は R′ のガウスペア g = ∏(a_j+ib_j)^{k_j}(a_j−ib_j)^{e_j−k_j}
の (|Re g|, |Im g|)。E では X,Y は逆パリティなので c は常に奇、
行 (B±c)/2 は整数。各ペアは X²+Y²=R′ を機械検証（違反 0）。

**t スケーリング補題**: R′ = t²·r（t は 3mod4 素因数の平方根部分、r は 1mod4-smooth）
のとき R′ のペア集合は r のペアの t 倍であり、行オフセット集合もちょうど t 倍。
よって **W(t²r) = t·(W(r)−1)+1 ≥ W(r)**（t ≥ 1）。最小円は常に t=1、
すなわち 1mod4-smooth に現れる。以下の掃引は t=1 に限定してよい。

## 3. 完備性証明（新規・本稿の核心）

**設定**: E族。窓幅 W₀ の中心窓に 13 個の相異なる符号付き c が入る。
窓は 0 を含み c スパン C := 2(W₀−1) なので |c| ≤ C。

各 c はあるペアの s(g)=X+Y または d(g)=|X−Y|（s²+d²=2R′、s,d 奇）。

**(i) s 型**: s ≤ C → R′ = X²+Y² ≤ (X+Y)² ≤ C²。

**(ii) 同一ペア両型（小ペア）**: s,d ≤ C → 2R′ = s²+d² ≤ 2C² → R′ ≤ C²。

**(iii) d 型のみ・2相異な d**: d₁ ≠ d₂ ≤ C なる2ペアに対し
  (s₁−s₂)(s₁+s₂) = s₁²−s₂² = d₂²−d₁² = (d₂−d₁)(d₂+d₁)。
  s 奇で s₁ ≠ s₂ → |s₁−s₂| ≥ 2、また d 奇で d₁ ≥ 1, d₂ ≤ C−1（C 偶）から
  s₁+s₂ ≤ (C−1)²−1) / 2 … 正確には |d₂²−d₁²| ≤ (C−1)²−1 = C²−2C より
  **s₁+s₂ ≤ C(C−2)/2**。一方 sᵢ = √(2R′−dᵢ²) ≥ √(2R′−C²) なので
  2√(2R′−C²) ≤ C(C−2)/2 ∴ **R′ ≤ C²((C−2)²+16)/32**。

13 個の符号付き c は ≥7 個の相異なる正の d/s を含み、s 型も小ペアも無ければ
≥7 個の相異なる d、特に 2 相異な d が存在する。よって **W₀ 窓 ⇒
R′ ≤ B_E(W₀) := max(C², ⌊C²((C−2)²+16)/32⌋)**（C = 2(W₀−1)）。
W₀=43 なら R′ ≤ 1,486,170。掃引 11.3M ≫ この限界で σ₁₃=43・1105一意は全称。

**Z族**: 行は ±X, ±Y（X ≥ √(R′/2)）。R′ > 2C′²（C′=W₀−1）なら X > C′ で
窓内は Y 型のみ → 2相異な Y₁,Y₂ ≤ C′ → (X₁−X₂)(X₁+X₂) = Y₂²−Y₁² ≤ C′²、
Xᵢ ≥ √(R′−C′²) → **R′ ≤ C′⁴/4+C′²**。R′ ≤ 2C′² は掃引入る。
B_Z(58) = 2,642,249 ≪ 11.3M で σ₁₃^center(Z)=58・1105一意も全称。

**O族**: 同型（Y 偶、C″=2(W₀−1)）で R′ ≤ C″⁴/4+C″²。B_O(149)=1.92e9 のため
今回の掃引では全称化されない（将来課題）。

証明は機械によらない純数学（ (iii) の不等式は検算容易）で、掃引は
「B 以内の全ての R′ を調べた」ことを機械保証する（下記制御）。

## 4. 制御・独立検証

1. **ペア検証**: 全掃引（890,637円・約190万ペア）で X²+Y²=R′ 違反 0。
2. **素朴幾何クロスチェック**: R′ ≤ 20,000 の D≥7 全118円で、3族の行オフセット
   集合が整数点の直接全列挙（u²+v²=2R′/R′/4R′ 型）と完全一致（不一致 0）。
3. **計数制御**: D≥8, R′ ≤ 11,296,324 の円数 149,490 — 旧セッションの
   制御値と完全一致。D=7 は 5⁶, 13⁶, 17⁶ のみ（=c7−c8=3、理論通り）。
4. **bestK 制御**: E/Z/O 全表が旧セッションの制御値と完全一致。
5. **1105 幾何**: (2x−105)²+(2y−105)²=2210 は32点16行（行29..76）、
   行34..76（幅43）にちょうど13二重行。幅42の中心窓は最大12行。
6. **枝刈りの正しさ**: D≥7 到達可能性の指数下界 Fmin（同一素数の冪も許す）
   による DFS 打ち切り。誤った m 表（異素数のみ想定）は 5·q²·r 型・25·q² 型を
   見逃すことが判明し修正済み（旧チャンクの c8=17,230≠149,490 で発覚）。
