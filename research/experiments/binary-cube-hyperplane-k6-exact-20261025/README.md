# 二値六次元立方体・共七点禁止版のK_6上界（未確定）

2026-10-25に開始、2026-10-30に上界証明の取り消しを記録した。
[K0553](../../knowledge/items/K0553-binary-hypercube-growing-excess-witnesses.md)が
$K_6\ge9$ の9点証人を与えている。本実験は上界 $K_6\le9$ を狙うが、
2026-10-30現在、**上界は未確定**である。
[項目K0568](../../knowledge/items/K0568-binary-cube-k6-exact-upper-bound.md)は
scope-unclear、経緯は
[log 2026-10-30](../../log/2026-10-30-d5-verification-and-circuit-cnf-error.md)と
[検証K0591](../../knowledge/items/K0591-binary-cube-d5-strong-solution-verification.md)
を参照。

## 対象ゲーム

$V_6=\{0,1\}^6$ の64頂点上で、相異なる7点が一つの実アフィン超平面に
載ること（退化を含む）を禁止する。安全 = 任意の7点部分集合がアフィン独立。

## 依存7点組の全列挙（有効）

`build_k6_cnf.cpp`：全 $\binom{64}{7}=621{,}216{,}192$ 個の
7点部分集合について、増広行列（行 $(1,x)$ の $7\times7$）の階数を
$p=2^{61}-1$ 上で計算する。Hadamard限界より $7\times7$ の0/1行列の
任意の小行列式の絶対値は $7^{7/2}=907<p$ なので、
整数での特異性と $\bmod p$ での特異性は同値。
`--count` モードでは全判定を独立な第二算法（$\bmod 1000000007$、
別の消去法）でも再計算し、621M件すべて一致した。

依存点組数（二算法照合済み）：

| サイズ | 全部分集合数 | 依存数 |
|---:|---:|---:|
| 4 | 635,376 | 4,816 |
| 5 | 7,624,512 | 311,360 |
| 6 | 74,974,368 | 10,663,520 |
| 7 | 621,216,192 | 255,036,992 |

## 上界（未確定）

1. **完全版CNF（正しい符号化）**：依存7点組全部を禁止節とするCNF。
   4,160変数・255,045,246節（生6.9GB）。
   CaDiCaL 1.7.4（メモリ19GB環境）はメモリ不足で未完。
   **UNSATは確定していない。**

2. **circuit削減CNF（無効）**：包含極小依存集合（circuit）だけを禁止節とする
   削減は、石追加ゲームでは不能である。禁止サイズ未満の依存集合はゲームで
   合法なので、包含極小禁止集合は「禁止サイズの依存集合そのもの」であり、
   circuit化すると依存6点組を含む依存7点組が禁止漏れになる
   （[K0591](../../knowledge/items/K0591-binary-cube-d5-strong-solution-verification.md)
   の教訓1）。このCNF（4,160変数・19,484,942節）でのkissat 4.0.4実行は
   8h10mでSIGTERM終了し、UNSAT判定は得られていない。
   `certificates/k6_k10_fix0.drat` は未完の部分証明で、証明として無価値である。

3. **対称性削減 `fix0`**：頂点0を含む10点集合に制限する版。
   超立方体の頂点推移性（アフィン群が頂点に推移的）により、
   10点一般位置集合が存在すれば頂点0を含むものが存在するので健全。
   ただし適用先が無効なcircuit節集合だったため証明には使えない。

## 下界側の確認

9点証人は
[binary-cube-hyperplane-large-d-20261025](../binary-cube-hyperplane-large-d-20261025/frontier.txt)
の d=6 m=9 レコード。同実験の `verify_exact.py`（整数Bareiss・全286小行列式）
と `verify_mod.cpp`（mod $2^{61}-1$）の両方で完全検証済み。ここでは再検査しない。
`audit_frontier9.py` により、この9点証人が64頂点すべてを禁止する
（極大配置である）ことも独立確認済み。

## K=9 SAT制御（完了）

`certificates/k6_k9.cnf`（exactly-9、circuit節集合版、4,160変数・19,484,942節）を
kissat 4.0.4で解き **s SATISFIABLE** を確認した（23秒、exit 10）。
割当のx変数から取り出した9点集合 {11, 22, 28, 37, 42, 49, 57, 58, 63} が
`verify_k9_witness.py` で全 $\binom{9}{7}=36$ 個の7点小行列式非零
（|det| 1〜9）と検証済み。

これは「circuit節集合の下で9点一般位置集合が存在する」ことの制御にすぎず、
circuit削減の健全性を裏付けるものではない（削減自体が不能である）。

## 現在の状態と次の一手

- 下界 $K_6\ge9$ は確定。上界 $K_6\le9$ は未確定。
- 正しい上界証明には完全版CNF（255,036,992節）のUNSATが必要。
  選択肢：メモリの許す環境での kissat/CaDiCaL 実行、座標順列対称性の活用、
  超平面cardinality制約付きの別エンコーディング、組合せ論的証明。
- 逆方向（10点一般位置集合の存在）の探索も未完了。

## 再現

```sh
g++ -std=c++17 -O2 -Wall -Wextra -o /tmp/k6cnf build_k6_cnf.cpp
/tmp/k6cnf --count                      # 約25分、二算法照合つき列挙数

# circuit削減版は証明に使えない（無効な削減）。監査目的でのみ残す：
g++ -std=c++17 -O2 -Wall -Wextra -o /tmp/k6circ build_k6_circuits.cpp
/tmp/k6circ --count                     # circuit数の確認（無効な削減の記録用）

# 9点証人の幾何学的再検証：
python verify_k9_witness.py certificates/k6_k9_witness.txt
```

CNFの生ファイル（完全版約6.9GB、circuit版約560MB）は再現時にのみ必要なので
リポジトリには入れない。`certificates/` はローカルに残る未完・無効Attemptの
成果物であり、証明書としては無価値である。

## 証拠の意味と限界

- 下界9点は二検証器で完全検証済み。9点証人の極大性（単一証人）は上界の根拠にならない。
- 依存7点組の全列挙（二算法完全一致）は有効で、完全版CNFの節集合の正しさの根拠。
- 上界は未証明。circuit削減CNFの UNSAT はそもそも取得されていない上、
  符号化自体が不能である。
- $d\neq6$ の上界、Grundy値、misère版は対象外。
