# 6点純三点辺・六本以下の全型についての34周期証明（2026-11-07）

## 背景と範囲

K0684は「任意の固定rank3残余核に長道を付けたGrundy列は最終的に34周期」という
核サイズ無界の予想。`rooted-core-larger-periods-20261107` は6点の純三点辺が高々3本の
全1351件（根付き100型）と追加67件を全長認証した。

本実験はそれを **6点の純三点辺が高々6本の全列挙** へ拡張する。6点の三点集合は20種類
あり、その高々6本を選ぶ全入力は

```
sum_{k=0}^{6} C(20,k) = 1+20+190+1140+4845+15504+38760 = 60460
```

件。根付き同型（根0を固定する S5）で畳むと **732型**。根を残す着手で到達する閉状態は
すべて5点以下に落ち（K0682の全長証明済み表を再利用）、新規に解く6点状態はちょうど732件。
これは「6点・純三点辺・六本以下」という有限族の **完全列挙** であり、無作為抽出ではない。

結果（`output/audit.json`）：`jointly_certified=true`、共同開始571・必要値1211、
prefix上のGrundy最大27、独立subset mex検査5124条件・安全状態1345310で一致。

## 方法

`rooted-core-tail-periodicity-20261107/engine.py` の正確な再帰をそのまま使う。

1. 5点以下の全513型はK0682の証明済み表 `output/audit.json` を既知部分問題として再利用
   （0..1069は保存整数値、それ以後は500からの周期34で延長。全長証明済み値の利用であり
   有限prefixの外挿ではない）。
2. 新規732状態を核の小さい順・長さの二重帰納で `limit=1400` まで生成。
3. K0682の有限窓定理：`start = max(500, 各状態の最終周期破綻+1)`、`needed = 2*start+69`。
   `needed <= limit` かつ窓 `start..2*start+35` で自分自身と周期34が一致すれば、
   その族と全到達状態は **全長でstart以降34周期**。本族の実測は `start=571`・`needed=1211`。
4. 独立検証：全732型・長さ0..6について、再帰を使わず原始禁止族からの占有subset mex
   （`direct()`）を計算し、再帰値と一致することを確認（732×7=5124検査）。

## 限界

- これは有限族の完全な定理であり、K0684の核サイズ無界の全称証明ではない。
- 「純三点辺」のみ。二点辺を含む一般clutterや7点以上の核は含まない。
- 固定seed統計ではなく、決定的に再現する全列挙として扱う。
