# 有限族の全長周期証明（6点・純三点辺・六本以下）

核の意味・正確な再帰・有限窓定理はK0682と同じ。ここでの新規主張は次の有限族に限る。

## 命題（有限・完全）

6頂点上の三点集合20種類のうち高々6本からなる全てのclutter（純三点辺、根付き）と
指定根に対し、根に長さLの二点禁止道を付けた通常Grundy列 f_C(L) は

```
f_C(L+34) = f_C(L)  for all L >= 571
```

を満たす。根付き同型で732型、 raw入力60460件を全て被覆する。
開始571はこの族全体の共同上界であり、個々の核の最小開始ではない（最悪状態の最終周期破綻は570）。

## 証明の構造

1. **既知部分問題**：5点以下の全513型はK0682で全長証明済み。その保存整数値を
   0..1069はそのまま、それ以後は500からの周期34で延長して使う。これは証明済み値の
   利用であり、観測prefixの外挿ではない。
2. **新規状態の閉包**：732型の根を残す着手で到達する状態を `closure()` で列挙すると
   1177状態。うち5点以下445状態は既知表に一致し、新規は6点732状態のみ。
3. **二重帰納**：核の頂点数の小さい順・長さの昇順で正確な再帰を計算。各手の
   （根着手・根禁止・根残し核内手・道_split）を `engine.play` の残余更新で分離。
4. **有限窓認証**：各状態の最終周期破綻 `last_period_failure(seq,34)` から
   `start = max(500, max+1)`、`needed = 2*start+69`。実測は `start=571`・`needed=1211` で
   `needed <= 1400` を満たし、窓 `start..2*start+35`（571..1177）について道列と全状態列の
   周期34一致をassertで確認。K0682の有限窓定理により、この族と全到達状態は全長で571以降34周期。
5. **独立基底検証**：全732型・長さ0..6で、再帰を使わない原始subset mex `direct()` と
   再帰値の一致をassert（5124検査・安全状態の総数はaudit.jsonに記録）。

## 監査範囲と限界

- `output/audit.json` の `jointly_certified=true`、`joint_start_candidate`、
  `values_needed_through`、`direct_subset_checks` が有限証明の機械可読証拠。
- 一般核（二点辺混在・7点以上・無界サイズ）への拡張は証明しない。K0684は予想のまま。
- 数値 `maximum_grundy_in_prefix` はこの族のprefix上界であり、核によらない一様上界ではない。
