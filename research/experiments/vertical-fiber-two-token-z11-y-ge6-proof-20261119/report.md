# z=11・y>=6 一様 2トークン全Grundy分類の全称証明

実験: `vertical-fiber-two-token-z11-y-ge6-proof-20261119`
対象: κ=1 残余ゲーム `H(R;(x,y);11)`、2トークン族、固定高さ z=11、全 `x>=y>=6`、全 `R>=0`。
記号: `S=x+y`, `Y=2y`, `d=x-y`。帯域 `1<=R<=S+11`、その外は `R=0` で値 0、`R>=S+12` で一般 tail `S mod 2`（K0832）。

## 1. 命題（値の閉形式）

全 `x>=y>=6`, `R>=0` について `H(R;(x,y);11) in {0,1,2}` は次で完全分類される。

**値2 (T)**
- 基本ラダー: 奇数 `R in {1,3,...,11}`
- 前倒し格子点: `d=3: R=Y+7`, `d=7: R=Y+9`, `d=11: R=Y+11`（`d+z = 14,18,22 ≡ 2 (mod 4)`、格子値 `Y+(d+z)/2`）
- 掃引帯: `d=12`: 奇数 `R in [Y+11, S+11]`
- 定常 pin: `d>=13`: `R=Y+11`（=`2y+z`）

**値1 (P)**（帯域内）
- `d` 偶 `0<=d<=10`: 偶数 `R in [12, Y+4+2*ceil(d/4)]`
- `d=12`: 偶数 `R in [12, Y+10]`
- `d` 偶 `>=14`: 偶数 `R in [12, Y+10]` ∪ 奇数 `R in [Y+13, S+11]`
- `d` 奇 `1<=d<=11`: 偶数 `R in [12, S+11]` ∪ 奇数 `R in [Y+7+2*floor((d+1)/4), S+10]`
- `d` 奇 `>=13`: 偶数 `R in [12, Y+10]` ∪ 奇数 `R in [Y+13, S+10]`

残りは値 0。実装は `candidate.py`（`v11`）、アンカー転写は `z10_uniform`（K1002）と `k1037.py`（K1037）。

## 2. 子分解と前提

各 `(x,y),R>=1` の子は（r=R-1）
- `B = H(r;(x,y-1);11)`（y=6 行では K1037 = `(x,5)` 切片、y>=7 では帰納仮定）
- `A = H(r;(x-1,y);11)`（x>y のみ、行内 x 外帰納。`d=0` では A=B が同一子 `(y,5)`/`(y,y-1)` に合流）
- `C = 1 xor H(r;(x,y);10)`（K1002 一様式、proved。z=10 の値 2 は xor 後 3 になる）

値 = mex({A,B,C} 値集合)。K0832 の Theorem T（奇数 R の親の値<=2、偶数 R の親の値<=1）と一般 tail（`R>=S+12` で `S mod 2`）を使う。

前提となる既出版成果: K0832（A/B/C 再帰・Theorem T・一般 tail）、K1037（z=11, y=5 切片、全 x）、K1002（z=10 一様式、`x>=y>=6`、proved 昇格済み; その構成要素 K1008/K1009/K1010/K1011）。

## 3. 署名帯表（正本アーティファクト）

`bands.py` が正本。各 `(y,d)` クラスの帯 (lo, hi, sig) が帯域 `1<=R<=S+11` を各 parity で一意被覆し、sig は子値集合の昇順数字列で値は `mex(sig)`。要点:

- 全クラス共通: 奇 `O[1,11]:01`（ラダー、値2）、偶 `E[2,10]:23`（反ラダー、値0）、`12:02`（h=z+1 行の不動点、値1）。
- 偶 d 段階形 `d in {2,6}`/`{4,8}`: 値1偶帯 `[14,cap±2]` + `cap:02` 単点（cap=Y+4+2⌈d/4⌉）、その先単点 `cap+2:123`/帯 `:1`。
- `d=10`: `[14,Y+8]:0, Y+10:02, [Y+12,S+10]:1`（staged d≡2 形の cap=Y+10 版、`123` 単点なし）。
- `d>=12` 偶: `[14,Y+8]:0, Y+10:02, Y+12:123, [Y+14,S+10]:1`。
- 奇 d `<=9`: 偶側は `[14,S+11]:0`（値は全て 1: P 偶全域）。
- `d=11`: `[14,Y+8]:0, Y+10:02, [Y+12,S+11]:023`（"023" は A 子列 d=10 による値0混入と C 子の z=10 掃引行 d=11 による 3）。
- `d=13`: `[14,Y+8]:0, Y+10:02, Y+12:123, [Y+14,S+11]:12`（"12" 末尾は A 子列 d=12 掃引帯の影: A=2 が偶側全域に現れる）。
- 奇 d `>=15`: 同型で末尾 `:1`（A 子の pin が単点に戻るため）。
- 奇 d 奇数側: `t=min(Y+7+2⌊(d+1)/4⌋, Y+13)`、pin は `d≡3 (mod 4)`（d=3,7）または `d>=11`: pin あり `O[13,t-4]:1, (t-2):01, O[t,S+10]:0`、なし `O[13,t-2]:1, O[t,S+10]:0`。
- 偶 d 奇数側: `d<=10: O[13,S+11]:1`、`d=12: O[13,Y+9]:1` + 掃引 `O[Y+11,S+11]:01`、`d>=14: O[13,Y+9]:1, (Y+11):01, O[Y+13,S+11]:0`。
- 縮退セル `(y,d)=(6,0)`: `[12,16]:02, 18:13, [20,22]:1`（B 子が K1037 の h=z 行 x=6 で、その奇ラダー `O[1,15]` の値2が偶行 14,16 に混入）。この 1 セルを除き全表は (y,d) のクラス式で一様。

## 4. 証明の構造（二段帰納）

**Step 1（y=6 基底行）**: B 子は K1037（`(x,5)` 行）。K1037 の x>=18 定常行は「値2={1,3,...,11,21}、値1={12,14,16,18,20}∪O[23,x+17]、tail x+17」と一様に確定しており、これは本表の `d>=12` クラス（`Y+11=21` pin、`E[12,Y+10]={12,...,22}`、`O[Y+13,S+11]`）と原文一致する。`d=1..11`（x=7..17）は K1037 に列挙された 12 個の有限遷移セルに対応し、各セルの帯域 R の mex を K1037 の行ごとの値表から直接計算すると本表の該当クラス式に一致する（監査 V7 はエンジン照合 1,100 点・不一致 0、V1 グリッドは y=6 全 d=0..40 で表=子署名）。`d=0`（x=y=6）は A=B 合流の 1 セルで、子は `(6,5)`:11（K1037 の h=z 行）と `1 xor (6,6):10`（K1002）のみ。C 子は全域 K1002（proved）。

**Step 2（y>=7 の行）**: B 子は行 y-1 の帰納仮定（同 d クラス式の y->y-1 代入）、A 子は行内 x 外帰納（d-1 クラス式）、C 子は K1002（クラス表 z10_T/z10_P、転写 `z10_uniform`）。各 (y,d) クラスで、3つの子の値域区間の和集合演算が帯表の sig を復元する。導出は記号 y・クラス d について一様（下の代表例）。帯域全体で表の mex を取った値が閉形式 `v11` と一致し、Theorem T の上界（奇<=2, 偶<=1）を破らないため、mex 構成に抜けはなく、K0832 一般 tail が `R>=S+12` を閉じる。有限監査（§6）は証明の代わりではなく、独立実装に対する照合である。

**代表導出**: R 偶 `>=Y+14`・`d=13`（末尾 "12"）: r=R-1 奇。A=(x-1,y) は d-1=12 掃引列で `O[Y+11, S+10]` に値2を持ち、r<=S+10 の間 A=2。B=(x,y-1) は行 y-1 の d=13 クラスで奇 r ∈ [Y+11, S+8] に値1、C は z=10・d=13 で奇 r に値 0 を与えるため `1 xor 0 = 1`。子値集合 {1,2}="12"、mex 0。`d>=15` では A の d-1>=14 偶列は単点 pin `Y+11` に退き、代わりに `O[Y+13, S+10]` の値1が現れるため子は {1}="1"。`d=0` 合流セル・段階 cap 形・奇 d 格子 pin（`d=3` で t-2=Y+7、`d=7` で Y+9、`d=11` で Y+11=pin へ合流）・`d=11` の "023"（A 列 d=10 の staged 形と C 列 z=10・d=11 掃引の 1 xor 2=3）も同一手続きで導出される。前倒し格子 `d+z≡2 (mod 4)`・`d<=z`・格子値 `Y+(d+z)/2` は d=3,7,11 の 3 点で z=11 に埋まり、`d=z` の格子値が定常 pin `Y+z` に一致する。

## 5. 構造注記（奇数 z 族の比較・観察的）

z=11 は K1011（z=10, y>=9 一様）と異なり、**基底アンカー切片（y=5, K1037）が直上の y=6 から一様族に入るため y>=6 で直ちに一様化**する（z=10 では y=6,7,8 の 3 切片 K1008..K1010 を挟んだ）。値1基底点（定常行の不変偶点集合）`{z+1, z+3, ..., z+2y-1} = {12,14,...,22}`（y=6）は y 点仮説の第 7 例。奇数 z 実例（z=9: K1001, z=13: K1045, z=15: K1049）で共通する構造: ラダー `O[1,z]`、前倒し格子 `d=z-8+4k` 上の `Y+(d+z)/2`（ただし格子値<=pin）、pin `Y+z`、掃引行 `d=z+1` 帯 `O[pin, S+z]`、定常 `d>=z+2` の `{pin}`。d=13 の "12" 末尾帯は「掃引行の A 子影が d=z+2 に 1 だけ残る」現象で、K1049（z=15）の「移行行」と同型。これらの統一式は未証明であり本項の主張外。

## 7. 限界・主張の範囲

- 本項の全称性は二段帰納とクラスパラメトリック署名帯表による。有限監査は独立実装照合であり、証明の代わりではない（K1011 と同じ区別）。
- 表の被帯域 `1<=R<=S+11` 外は K0832 の一般 tail による。本項は tail の再証明を行わない。
- z=11 の y=6 基底行の d=1..11 は有限セル解析（K1037 行表の直接 mex 計算）で、d>=12 は K1037 の x>=18 定常行の原形引用による。K1037 自体は proved である。
- z>=12 の一般化・奇数 z 族の統一格子式・y 点仮説の一般証明・h=z 孤立上端の d+z mod 4 規則は未解決のまま。11x11 本盤への直接転送ではない。
