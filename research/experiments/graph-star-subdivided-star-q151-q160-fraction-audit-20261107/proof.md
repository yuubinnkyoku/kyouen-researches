## 再現コード

```python
from fractions import Fraction

bounds = [(151,2035),(152,2051),(153,2067),(154,2081),
          (155,2097),(156,2113),(157,2129),(158,2145),
          (159,2161),(160,2177)]
for q, k_plus in bounds:
    r = q - 3
    a = Fraction(r + 2, r + 1)
    for k, should_be_negative in ((k_plus - 2, False), (k_plus, True)):
        y = Fraction(k, k + 1) * a
        assert 1 < y < a
        f = r - y - (a - y) * y**k
        assert (f < 0) == should_be_negative
    print(q, "PASS")
```

実行環境: Python 3、標準ライブラリのみ。実行結果: 151〜160の全10行PASS。
