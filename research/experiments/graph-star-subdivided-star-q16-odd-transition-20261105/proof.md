# 一辺細分星 q=16 の奇数次数実根切替（2026-11-05）

## 定理（解析的全称証明と有限個の厳密有理数不等式）

一辺細分星の終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
において、r=q-3=13、奇数 k≥3 とする。

- q=16 では奇数 3≤k≤117 に実根はない。
- q=16 では奇数 k≥119 に相異なる負の単実根がちょうど2個ある。
- 任意の整数 q≥16、奇数 3≤k≤117 に実根はない。

## 証明

奇数 k について u=-(r+1)y と置くと、正の u に根はなく、負の実根の候補は 1<y<a=1+1/(r+1) に限られる。零点条件は
\[
F_{k,r}(y)=r-y-(a-y)y^k=0
\]
である（候補区間外の符号については先行一般証明）。

r=13、a=15/14 とする。固定 y>1 では (a-y)y^k が k とともに増加する。従って k=117 で F>0 を示せば、それ以下の全奇数 k でも F>0。

H(y)=(a-y)y^{117} は [1,a] 上で一意の最大点 y_*=117a/118 を持つ。区間 [1,a] を50等分し、各 [l,h] で z=min(max(y_*,l),h) とすれば H(y)≤H(z) である。付属の検査コードにより50区間すべてで
\[
H(z)<13-h\le13-y
\]
が厳密に成立する。よって k≤117 で根はない。

k=119 では y=119a/120=119/112 において F_{119,13}(y)<0 が厳密に成立する。k≥119 の奇数でも同じ y で負値を保つ。一方 F(1)>0、F(a)>0 であるため少なくとも二つの負実根がある。T_{k,r}(-x) の符号変化は2回なので、デカルトの符号法則より重複度込みで高々2根。従って二つとも相異なる単根。

さらに r≥13 では候補区間 (1,1+1/(r+1)) は (1,15/14) に含まれ、固定 y>1 における F_{k,r}(y) は r に関して厳密増加する（偏導関数 1+y^k/(r+1)^2>0）。従って q≥16、k≤117 にも非存在が及ぶ。

## 再現（Python 3、浮動小数点不使用）

```python
from fractions import Fraction as Q

r, k = 13, 117
a = Q(15, 14)
star = a * k / (k + 1)
for i in range(50):
    l = 1 + (a - 1) * Q(i, 50)
    h = 1 + (a - 1) * Q(i + 1, 50)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = Q(119, 112)
assert 1 < y < a
assert r - y - (a - y) * y**119 < 0
```

**証拠区分:** 全称解析と50区間の有理数厳密不等式。一般 q における接触二重根不存在、格子盤の勝敗は主張しない。
