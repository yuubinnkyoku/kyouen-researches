# 核＋道の末尾シフト構造（K0697）

## 背景

K0684 は任意の固定残余核 C に長さ L の道を付けた Grundy f_C(L) が最終的に周期 34
になると予想する。裸の道（path 上の Node-Kayles）の Grundy 列 p も最終周期 34 である。
もし全ての C で f_C(L)=p_{L+s(C)}（核に依存するシフト）が成り立つなら、周期 34 は
p から直ちに継承され、K0684 の簡単な構造証明になる。本実験はこの「普遍シフト仮説」を、
全長認証済みの二族について決定論的に検証する。

## 対象と方法

入力（いずれも K0682 の有限窓定理で全長認証済み）:
- **六点純三点辺** 10688 型: `rooted-core-six-pure-triple-full-20261108/output/audit.json`
  （prefix 0..1343）。末尾窓 L=900..1300、末尾ブロック f[1000:1034]。
- **五点以下 rank≤3** 513 型: `rooted-core-tail-periodicity-20261107/output/audit.json`
  （prefix 0..1069）。末尾窓 L=600..1000、末尾ブロック f[700:734]。

裸の道 p は `engine.path_values`。各型を s=-10..80 で f_C(L)=p_{L+s} と走査し、
窓内完全一致を純シフトと判定する。末尾ブロックの異なり数・最小周期、純シフト型の
核 Grundy ordinary(C)・辺数・根の所属との相関、シフト＋定数 xor（⊕c）も集計する。

## 結果

六点純三点辺:
- 純シフト **3445 型（32%）**。offset s=1:429、2:2891、3:52、7:73。
- 末尾ブロック **1825 種**、うち p のシフトは **4 種**。残り 7243 型は新しい周期 34 列。

五点以下:
- 純シフト **134 型（26%）**。offset s=1:39、2:52、3:10、4:12、5:18、6:1、7:2。
- 末尾ブロック **134 種**、うち p のシフトは **7 種**。残り 379 型は新しい周期 34 列。

両族共通:
- 全型（10688＋513）の末尾最小周期は **34**（周期 1・2・17 への退化は零）。
- xor 緩和は新規型を生まない（全て c=0）。

核 Grundy 相関は族依存: 六点純三点辺の純シフトは g0∈{1,2} に限るが、五点以下では
g0=0（s=4）・g0=3（s=5）にも純シフトが現れる。よって「g0≤2 が必要」は普遍ではない。

## 解釈

両族とも大多数の核は p のシフトではない新しい周期 34 末尾を作る。よって K0684 の
普遍周期 34 は「核が道をシフトするだけ」では説明できず、再帰自体の頑健な性質として
理解すべきである。これは普遍シフト証明戦略を排除する有限計算であり、K0684 の証明・反証ではない。

## 再現

```sh
uv run --locked python research/experiments/core-path-shift-structure-20261108/analyze.py
```

`output/shift_probe.json`・`per_type.json`（六点）と `output/shift_probe_le5.json`・
`per_type_le5.json`（五点以下）を生成する。認証済み prefix に依存するため、
姉妹実験と K0682 の audit.json が先に存在する必要がある。

## 限界

対象は六点純三点辺核と五点以下核に限る。二点辺混在の六点核
（rooted-core-six-mixed-full-20261108）や 7 点以上の核の末尾構造は別途。
末尾窓・シフト範囲は有限であり、認証済みの全長周期性は K0682 の有限窓定理が保証する。
この走査は構造の記述であって周期性の再証明ではない。
