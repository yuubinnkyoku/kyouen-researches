# 核＋道の末尾シフト構造（K0697）

## 背景

K0684 は任意の固定残余核 C に長さ L の道を付けた Grundy f_C(L) が最終的に周期 34
になると予想する。裸の道（path 上の Node-Kayles）の Grundy 列 p も最終周期 34 である。
もし全ての C で f_C(L)=p_{L+s(C)}（核に依存するシフト）が成り立つなら、周期 34 は
p から直ちに継承され、K0684 の簡単な構造証明になる。本実験はこの「普遍シフト仮説」を、
全長認証済みの六点純三点辺核 10688 型について決定論的に検証する。

## 対象と方法

入力: `rooted-core-six-pure-triple-full-20261108/output/audit.json` の全 10688 型
（prefix 0..1343、K0682 の有限窓定理で全長認証済み）。裸の道 p は `engine.path_values`。

末尾窓 L=900..1300（401 点）で f_C(L)=p_{L+s} を s=-10..80 で全走査し、
完全一致（401/401）を純シフトと判定する。さらに末尾ブロック f_C(1000..1033) の
異なるブロック数、純シフト型の核 Grundy ordinary(C)・辺数・根の所属との相関を集計する。
シフト＋定数 xor（f_C(L)=p_{L+s}⊕c）も各 best shift で検査する。

## 結果

- 純シフトは **3445 型（32%）** のみ。offset 別: s=1:429、s=2:2891、s=3:52、s=7:73。
  最大クラス 2891 型は同一末尾ブロック（p の 2 シフト）を共有。
- 周期 34 末尾ブロックは全体で **1825 種**。うち p のシフトは **4 種** だけ。
- 残り 7243 型はどのシフトとも高々約半数しか一致せず、真に新しい周期 34 列。
- xor 緩和は新規型を生まない（全て c=0、純シフトと同一の 3445 型）。
- 純シフトの核 Grundy は **1 または 2 に限る**（必要条件）。s=3↔g0=2、s=1,2,7↔g0=1。
  g0=0 の 2018 型・g0=4 の 30 型は純シフト零。十分条件ではない
  （g0=1 の 8457 型中 3393、g0=2 の 183 型中 52 のみ）。

## 解釈

大多数の核は p のシフトではない新しい周期 34 末尾を作る。よって K0684 の普遍周期 34
は「核が道をシフトするだけ」では説明できず、再帰自体の頑健な性質として理解すべきである。
これは普遍シフト証明戦略を排除する有限計算であり、K0684 の証明・反証ではない。

## 再現

```sh
uv run --locked python research/experiments/core-path-shift-structure-20261108/analyze.py
```

`output/shift_probe.json`（集計）と `output/per_type.json`（全 10688 型の判定）を生成する。
認証済み prefix に依存するため、姉妹実験の audit.json が先に存在する必要がある。

## 限界

対象は六点純三点辺核に限る。二点辺混在核（rooted-core-six-mixed-full-20261108）や
7 点以上の核の末尾構造は別途。末尾窓・シフト範囲は有限であり、認証済みの全長周期性は
K0682 の有限窓定理が保証するため、この走査は構造の記述であって周期性の再証明ではない。
