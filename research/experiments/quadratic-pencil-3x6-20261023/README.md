# 3×6 二次形式係数版：全実数 λ の厳密分類（2026-10-23）

盤は `(x,y)∈{0,…,5}×{0,1,2}`、安全でない4点組は
`det[x²+λy²,x,y,1]=0` を満たすものとする。退化も含める。

## 有限帰着の証明

4点 `P0,…,P3` に対し、第1行を残り3行から引いて展開すると
`det = A+Bλ`（`A,B∈ℤ`）。`B≠0` のとき禁止性が変化する値は
`−A/B∈ℚ` だけであり、`B=0` のときは禁止性は全実数で一定。
全 `C(18,4)=3060` 組を整数演算で調べると相異なる例外値は53個。
従って例外53型とそれ以外の一般型の計54型が全実数を尽くす。
この帰着は数学的に全称で、54型の勝敗は有限完全列挙による。

## 結果

`results.tsv` は54型すべての空盤Grundy値、全安全局面数、
禁止四点組数、勝ち初手（点番号 `3x+y`）を保存する。
極大石数別個数・安全局面の石数別個数は検証器の完全出力から再生成できる。

空盤 `g=0`（後手必勝）になるのは、一般型（53個の例外値以外の**全実数**）と
`λ∈{−20,−15,−13,−12,−13/2,−1/2,5/2,7,31/2}` のみ。
`g=2` は
`{−16,−23/2,−11,−17/2,−9/2,15/2,17/2,27/2,14,15,17,19}`。
残る32個の例外値は `g=1`。最大安全石数は λ=0 のみ7、それ以外の53型で8。
54型合計で1,192,642安全局面を検査した。

```sh

{ head -n1 /tmp/q36-full.tsv; tail -n+2 /tmp/q36-full.tsv | cut -f1-5; } > /tmp/q36-compact.tsv

```

C++は3×3差分行列式・下からの全部分集合計算と、独立の
4×4置換行列式・上からの合法手再帰を**全54型で**照合する。
Python監査も独立に4×4行列式と再帰を実装し、全型の
空盤値・安全局面数・勝ち初手・禁止組数を照合した。
両者一致。3×5の既存32型も再現した。
