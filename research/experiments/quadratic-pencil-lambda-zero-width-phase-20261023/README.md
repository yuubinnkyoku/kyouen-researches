# 放物線型（λ=0）二次形式4点禁止ゲーム：幅3で満容量安定化が消滅する

2026-10-23。正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。
標準の共円・共線禁止ではなく、格子
D(w,m)={(x,y):0≤x<m,0≤y<w} の相異なる4点について
det[x²,x,y,1]=0 を禁止する変種を扱う。
全極大配置が3w石となる真の開始長を M_w とし、存在しなければ M_w=∞ と記す。

## 定理（全称数学的証明）

すべての整数 w,m≥1 に対して：

1. w=1 の真の満容量安定化長は **M_1=3**。
2. w=2 の真の満容量安定化長は **M_2=9**。
   m≥9 の全安全局面 S で g(S)=(6−|S|) mod 2。
3. **w≥3 なら全 m≥1 で最小極大石数 s(w,m;0)=3**。
   従って **M_w=∞**（満容量3wへの安定化は一切起きない）。
   特に三行盤では既存の K(3,m;0)=9（m≥8）と同時に
   s(3,m;0)=3 が成り立ち、最大と最小極大の差は常に6である。

この定理は、有限実験からの外挿ではない。

## 証明

**基本恒等式。** 横座標が a,b の高々2種類である4点に対して、
各点で x²=(a+b)x−ab が成立する（a=b でも成立）。
したがって行列 [x²,x,y,1] の第一列は第二列と第四列の線形結合となり、
行列式は0である。横座標が1種類の場合も同様。

**w≥3。** 同一縦列 x=0 に三石 (0,0),(0,1),(0,2) を置く。
三石以下では禁止四点組がないので安全である。
どの未占有点 (x,y) を加えても横座標は高々 {0,x} の2種類であり、
上の恒等式から禁止四点組が完成する。よって三石で極大。
一方、盤上に少なくとも三点あるので、0〜2石の安全集合は
任意の未占有点を追加でき、極大になれない。従って s=3。
3w≥9>3 なので、どんな m でも全極大3w石とはならない。
m≥3 では (0,0),(0,1),(1,0),(2,0) が安全な四石
（行列式の絶対値2）であり、極大三石と最大容量の違いも明白になる。

**w=1。** 四石が同じ水平行にあれば禁止である。
m≥3 ではどの三石も極大で、全極大は三石。
m=2 では満容量3に届かないため M_1=3。

**w=2。** y∈{0,1} では y²=y なので、任意の実数λに対して
det[x²+λy²,x,y,1]=det[x²,x,y,1]。
四点が禁止される必要十分条件は、(i)同一行の四点、
または(ii)各行二点ずつで両行の横座標二点和が一致すること。
一行に三点＋他行一点の四点は常に安全である。

安全局面の各行は高々三石。ある行に k≤2 石、他行に高々三石がある場合、
その行へ新しい石 (x,y) を追加して初めて禁止四点組を作るなら、
他行の二点和 t と同じ行の既存点 a について x=t−a が必要。
禁止される未占有横座標は高々 k*C(3,2)≤6 個で、
既占有点を含めても高々 k+k*C(3,2)≤8 列。
m≥9 では必ず合法な追加点があるため、全極大は各行三石、計六石。
終局までの手数が全局面で6−|S|に固定されるのでmex帰納で
g(S)=(6−|S|) mod2。

鋭さは m=8 の五石配置

    y=0: {0,2}
    y=1: {1,2,5}

で示す。上行の二点和は2、下行の二点和は3,6,7で一致せず安全。
下行は三石で満杯。上行の未占有六列は
{3−0,3−2,6−0,6−2,7−0,7−2}={1,3,4,5,6,7}
に等しく、すべて禁止。従って五石極大が存在し M_2≥9。
上界と合わせ M_2=9。□
