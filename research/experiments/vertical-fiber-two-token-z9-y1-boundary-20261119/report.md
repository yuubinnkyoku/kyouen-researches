- 日付: 2026-11-19
- 対象: 抽象残余ゲーム H(R;(x,y);z)（R手残余・トークン多重集合 X、通常値 z、周期基底 S）のうち、2トークン X=(x,1)・z=9・境界 y=1 のスライス。全 x≥1・全 R≥0。

## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,1) における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,1);9)
- **B手**（値1のトークンを除去、通常値は z+1=10）: 子 = H(R−1;(x);10)（単一トークン）
- **C手**（z を 9→8 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,1);8)

x=1 では X=(1,1) で A手が存在せず、2本の除去手は同一の子 (1);10 に帰着する（B手とC手のみ）。

子の値はそれぞれ既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**で既に証明済みと見なす）、B子は K0832 の単一トークン z=10 公式、C子は K0983 の z=8・y=1 全称定理。よって R に関する帰納は不要で、各 x ごとに R の帯分割を機械的に書き下すだけでよい。

**Step 2（子の公式）.** 本証明で使う既証明の公式:

- 単一トークン v(x,10,r)（K0832）: x≤9 は z≥x+1 枠、x=10 は z=x 枠（r 奇≤2x−1=19 で2・r 偶≤9 で0・それ以外 x mod 2）、x≥11 は 1≤z≤x−1 枠（m=qod(10)=9, x+z−1=x+9）。特に x≥11 では r≤9 の奇偶で {2,0}、9<r<x+10 で (r+10) mod 2、r≥x+10 で x mod 2。
- z=8・y=1（K0983）: 値域は T₈(x)={1,3,5,7}（x∈{2..9}は個別、x=10は{1,3,5,7}∪O[11,19]、x≥11は{1,3,5,7,11}）、P₈(x) は x≥11 奇数で {9}∪E[12,x+9]、x≥12 偶数で {9}∪E[12,x+8]∪I[x+10,∞)、x≤10は個別。C子の値は 1⊕h₈(x,r) で h₈∈{0,1,2} に対し {1,0,3} に写る。

- R≥x+11（r≥x+10）: A=0（子スライス x−1（奇数）の P は O[13,x+9] に限り有限、r≥x+10 で外）、B=x mod 2=0（r≥x+10=x+z でtail）、C=0（r=x+10 は E[12,x+8] の外だが K0983 偶数xの P₈ は I[x+10,∞) を含み r≥x+10 で h₈=1）。V={0}、値1。

この導出は x≥14 の全偶数について一様に成り立つ（使っているのは子公式の帯境界が x の1次式であることのみ）。x≥13 奇数行では A子スライス x−1 が偶数になり P_A={10}∪O[13,x+10]∪I[x+11,∞)（無限I帯つき）となるため、奇数帯は R∈O[13,x+10] まで V={0}（A=0・B=0・C=0）で値1、偶数帯は R∈E[14,x+9] で V={1}（A=1・B=1・C=1）で値0、末帯 R≥x+11 は V={1}（A=1・B=1・C=1）で値0に反転する。x=1..12 の個別行は同じ代入をそのまま実行したものである。

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は z=6（K0877）の {1,3,5,9}、z=7（K0977）の {1,3,5,7,9}、z=8（K0983）の {1,3,5,7,11} に対し z=9 では **{1,3,5,7,9,11}**。ラダー {1,3,…,qod(z)} は z=9 で初めて5点すべてを含み（qod(9)=9）、追加位置は 11。第5点系列は z=6→9, z=7→9, z=8→11, z=9→11 と2つずつペアをなす。z=8 の「9を飛ばして11」が対ではない点は残る未特徴化。
- 値1位置の基本構造は z=6 の {7}∪E[10,..]、z=7 の {8}∪O[11,..]、z=8 の {9}∪E[12,..] に対し z=9 では **{10}∪O[13,..]** で、基底点 z+1・帯開始 z+4・偶奇が z 毎に反転する。tail開始はいずれも **x+z+2**（R≥x+11）で K0832 一般tailと一致。
- x=10（=z+1）の平坦P帯 {10,12}∪I[13,∞) の機構: A子はスライス x−1=9 の P={10} が有限で、B子 v_single(10,10,·) は z==x 枠（r 奇≤2x−1=19 で2、r 偶≤9 で0、r≥12 偶で x mod 2=0）、C子の P₈(10)={9}∪E[12,18]∪I[20,∞)。この結果 R≥13 の全Rで V が {0}（r 偶≥12）または {0,2,3}（r 奇∈O[13,19]）に落ち、いずれも mex=1。値1が無限帯に一様に広がる「冪ゼロ平坦化」は z≤8 に現れたどの例外（z=7のx=9無限P帯、z=8のx=10掃引）とも異なる発生機構。
- x=11（=z+2）の掃引 T₁₁=…∪O[13,21] の機構: A子はスライス x−1=10 の無限平坦P帯 I[13,∞) により r≥12 で常に A=1、B子の中間帯 9<r<21 が r 偶で0、C子の P₈(11)={9}∪E[12,20] が r 偶で1（→C=0）。r∈E[12,20] で V={0,1} が揃い値2が続く。r≥22 で B子がtailに移って B=1・C=1 となり V={1} に反転して掃引が終わる。掃引帯の開始13は A子平坦帯の開始と一致し、終端21=2x−1 は B子中間帯の終端と一致する。z=8 では掃引が x=z+2=10、帯 O[11,19]、開始 z+3=11。z=9 では x=z+2=11、帯 O[13,21]、開始 z+4=13 と、掃引開始が値1帯の開始 (z+4) 側に揃う。
- x=12 では署名が R∈E[14,22] で {1} から {1,2} に変わるが値は不変（A子がスライス x−1=11 の掃引帯 O[13,21] 内で 2 を供給、mex{1,2}=0）。z=8 の x=11 と同じく「子の例外は署名に1スライス写像するが値に影響しない」ことを示す。
- x=8 は T₉(8)={1,3,5,7,9} と z==x−1 枠（高さのみ縮約 v_single(9,9,·) の R 奇≤17→2）そのもので、P=I[10,∞)（冪の無限平坦化、z=8 の x=8 の I[9,∞) に対応）。x=9 は P={10} のみ。

## 適用範囲と限界

- 本定理は **z=9・y=1 の境界切片のみ**。z=9 の y≥2 は未証明。z≥10・y≥1 の全Grundy閉形式も未解決。

- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
