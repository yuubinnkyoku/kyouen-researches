# p=2207：剰余放物線の等号 A(p)=(p+3)/2 を達成する証人が存在しない（2026-11-08）

## 主張（監査待ちの計算結果）

`Q_p = {(t, t² mod p) : 0 <= t < p}` の安全集合（共円・共線四点を含まない）の最大を `A(p)` とすると、
**p = 2207 では `A(2207) <= 1104 < (2207+3)/2 = 1105`** である。
すなわち K0097 の上界 `A(p) <= (p+3)/2` は p=2207 で達成されず、
「全奇素数で等号が成立する」という K0101 の問いには **反例候補** が見つかった。

根拠は K0334 の証明済みの等価（等号 ⟺ ある `d` について signed NAE3/4＋原点節 CNF が充足可能）である。
本実験は **d = 1..h（h=1103）の全 1103 個**についてその CNF が UNSAT であることを確認した。

**信頼境界**: UNSAT はソルバ（CaDiCaL）の主張であり、DRAT 証明の保存・検査はまだ行っていない。
本記録は「計算結果（要監査）」として扱うこと。

## 構造（なぜ d の走査で十分か）

サイズ `h+2` の集合 `S ⊆ Q_p` を考える。対 `{i, p-i}`（i=1..h）が二つとも `S` に入ると
同高さ二弦の等脚台形で共円になるため、完全対は高々一つ。`0` の有無を `x`、完全対を2点含む対を
一つとすると `|S| = x + 2 + (#一側のみの対) <= x + 2 + (h-1)` で、等号 `|S|=h+2` は
`x=1` かつ「ちょうど一つの完全対 `{d,p-d}` と各他の対の一側」に限る。
したがって等号の存在は `d` ごとの CNF 充足可能性と同値（K0334）。

## 方法

1. `forbidden_edges.cpp`（`Q_p` の禁止四点を整数行列式で厳密列挙、Vandermonde 条件で絞る）で辺集合を作る。
2. `parabola_half_bound.py` の `clauses_for_pair(p, edges, d)` で signed NAE3/4＋原点節 CNF を作る
   （二完全対の台形辺は構造的に消去済み）。
3. d ごとに CNF を解く。UNSAT が期待値。SAT ならモデルから `{0,d,p-d} ∪ 各対の一側` を構成し、
   独立検証器（generic 4×4 Leibniz）で検査する。

## 証拠

- **全 d の判定**: `output/p2207_d_verdicts.json` に d=1..1103 の各判定と出所を保存。
  - d=289..1103: CaDiCaL（WSL, 30 秒制限つき）のログ（2 件はタイムアウト）。
  - d=1..288: マルチプロセス版（`scan_mp.py`, 衝突予算 200k, unknown 0）で全件 UNSAT。
  - タイムアウトした 4 個（289, 297, 312, 324）は `build_inventory.py` が衝突予算 2000 万で再確認。
  - 結果: **UNSAT 1103 / SAT 0 / 不明 0**。
- **別ソルバ一致**: d ∈ {1, 289, 550, 1103} を Glucose4 と Minisat22（衝突予算 2000 万）でも解き、全て UNSAT。
- **実装の全数照合（縮小）**: `validate_reduction.py` が p = 5, 7, 11, 13, 17, 19, 23 について
  Q_p の全安全集合（サイズ `(p+3)/2`）を DFS で列挙し、完全対 d の集合を求め、
  CNF の SAT/UNSAT（全 d）と比較。**7 素数すべてで完全一致**
  （p=23: 安全集合 8,064 個、brute_d = cnf_d = {1,...,11}）。`output/reduction_validation.json`。
- 既存 63 素数の証人（2003..2477）は同じ実装で SAT 側も動作することを示している
  （`parabola-equality-extension-2143-2500-20261107`、独立検証済み）。

## 限界と次の監査

- **UNSAT の DRAT 証明は未取得・未検査**。cadical は DRAT を出力できるので、
  証明生成と検査（例: drat-trim 相当）が次の監査段階である。現時点の主張は「3 ソルバ一致の計算結果」。
- `A(2207)` の正確な値（1104 か、それ未満か）は未確定。サイズ `h+1` の集合は
  「0 と各対一側（完全対なし）」または「0 なしで一完全対と他各対一側」の形なので、別の SAT 問題で決まる。
- p=2207 以外の反例素数は未探索（2209..2477 は証人あり、2500 以上は未走査）。
- 監査が通れば K0101 の全称的主張は p=2207 で反証される。
