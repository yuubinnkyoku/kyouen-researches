# 三葉三点制約を持つ箒木の全長Grundy分類

## 1. ゲーム族と命題

L≥0 とする。木 B_L は中心 c、三葉 a,b,d、中心から出る長さ L の道
c−v₁−…−v_L からなる（L=0 なら道はない）。頂点数 L+4。
禁止二点組は木の全辺、追加の禁止三点組は {a,b,d} だけ。
空集合から一点ずつ追加し、禁止集合を完成させない通常プレイを考える。

追加三点辺ありのGrundyを b_L、二点辺だけの近似を h_L、
n頂点の道のGrundyを p_n とする。以下は全 L への証明であって、1500項の外挿ではない。

**定理。** b_L は L=311 から周期34、最小の最終周期は34、
周期34が成立し始める最小位置は311。二点近似は h_L=p_{L+2}。
従って有限prefix L=0..310 と34剰余類の表で全長の値が決まる。

L≥311 において、三点辺が値を変えないのは L≡5,12 (mod34) だけ。
勝敗を変えるのは L≡2,6,13,18,22,26,32 (mod34) だけ。
値変更の長さの自然密度は16/17、勝敗反転は7/34。

この木と三点辺の残余ゲームは、[geometry.md](geometry.md) により
標準q=4の有限整数点盤の指定安全局面として全 L で実現できる。
標準の全正方形格子盤への実現は主張しない。

## 2. 正確な二つの漸化式

道では p₀=0,p₁=1。n≥2 の端点手は p_{n−2}、内部手は
分離した二つの道のxorとなるので

\[
 p_n=\operatorname{mex}\left(\{p_{n-2}\}\cup
 \{p_i\mathbin\oplus p_{n-3-i}:0\le i\le n-3\}\right).
\]

n=2では後半は空集合とする。
道の最終周期34自体は既知である
（[Guignard–Sopena, Compound Node-Kayles on Paths, §3.1](https://arxiv.org/html/0806.3033v2#S3.SS1)）。
今回の証明書でも開始添字52を含めて別途再証明し、それを文献から仮定する必要はない。

三葉は二点辺だけなら全linkが等しい独立双子であり、K0336 により3点を1点へ減らせる。
残るグラフは L+2 頂点の道なので h_L=p_{L+2}。
三点辺がある場合にこの双子圧縮を適用することはできない。

b₀=2,b₁=1 は全選択肢のmexで直接確認できる。
L≥2では次の全手を分類する。

| 着手 | 子の値 | 理由 |
|---|---|---|
| 三葉のどれか | 1⊕p_L | 中心が禁止され、残る二葉は二点禁止で一手分。道は独立 |
| 中心 c | p_{L−1} | 三葉とv₁が禁止される |
| v₁ | p_{L−2} | 中心とv₂が禁止される。孤立三葉は三点禁止で必ず二手、値0 |
| v_L | b_{L−2} | 末端二点が除かれる |
| v_j, 2≤j≤L−1 | b_{j−2}⊕p_{L−j−1} | 中心側の箒と末端側の道が分離 |

よって

\[
 \boxed{b_L=\operatorname{mex}\left(
 \{1\oplus p_L,p_{L-1},p_{L-2},b_{L-2}\}\cup
 \{b_i\oplus p_{L-3-i}:0\le i\le L-3\}\right).}
\]

どの子も全残余禁止集合から導いた。三点辺を最初から無視した再帰ではない。

## 3. 有限窓から無限周期を保証する補題

上記二漸化式を満たす列 p,b について、N≥2,T≥1 とする。
全 N≤n≤2N+T+1 で
p_{n+T}=p_n かつ b_{n+T}=b_n を確認できれば、両等式は全 n≥N に成立する。
必要なのは添字2N+2T+1までの有限値だけである。

**証明。** 比較添字 n≥2N+T+2 について強い帰納法を行う。
まず p、次に b の等式を示す。

両漸化式の畳み込み部分では、添字対 (i,j) は i+j=n−3 または n+T−3。
前者では少なくとも一方が N 以上なので、その添字へTを足せる。
後者では少なくとも一方が N+T 以上なので、その添字からTを引ける。
実際、後者で両方 N+T−1 以下なら和は2N+2T−2以下で、
n+T−3≥2N+2T−1に矛盾する。
帰納仮定により変更した成分値は同じであり、他方は変更しない。
従って新旧の畳み込みで得られる値の集合は双方向に包含し合い一致する。
混合 b_i⊕p_j でも、変更する側の列が違うだけで全く同じ議論になる。

端点項 p_{n−2},b_{n−2},p_{n−1} は先行する比較添字の帰納仮定で一致する。
b の1⊕p_nは、その段階で証明済みのpの等式を使う。
選択肢値の集合が一致するためmexも一致する。□

pだけの漸化式でも同じ補題が成り立つ。
これは選択肢集合の一致を証明する有限窓であり、長い標本の周期検出とは異なる。

## 4. 整数による有限証明書

`verify_period.py` は上の漸化式から全整数値を生成し、次を全件確認する。

* p：N=52,T=34、比較添字52..139、必要な値0..173。
* pとbの同時周期：N=311,T=34、比較添字311..657、必要な値0..691。
* b₃₁₀=8≠14=b₃₄₄。従って周期34の開始を311より早められない。
* p₅₁=2≠9=p₈₅。
* bの34項ブロックの循環シフト1..33は全て元と異なる。
  従って34より小さい最終周期は存在しない。

値の生成・有限比較と第3節の全称帰納法を組み合わせた**計算支援証明**である。
有限計算だけを無限命題の根拠にはしない。証明書の全prefixはJSONに保存する。

別実装では L=0..18 の原始禁止二点・三点組から占有subsetの全安全mexを求め、
b_L と h_L の38条件・全287525状態を検査した。
さらに二点版は閉近傍を削除するNode-Kaylesの第三の定式化19条件とも一致した。
この直接列挙では道への分解も双子圧縮も周期表も使わない。

## 6. 三点辺の効き方を有限半径だけで判定することはできない

任意の整数R≥0を固定する。十分大きいtに対して
L₁=34t+5,L₂=34t+13 を取り、両方をmax(R,311)より大きくする。
三点辺の三頂点をマークした B_{L₁},B_{L₂} を比較する。

* 三点間距離は全て2、Steiner木は同じK1,3。
* 中心から半径R以内のマーク付き誘導球は同型。
* 追加の長枝の長さは両方奇数で、全頂点数の偶奇も同じ。
* L₁では b=h=1 で三点辺は根のGrundy値を変えない。
* L₂では b=0,h=5 で三点辺が勝敗を反転する。

従って、木の三点辺の効果を、三点間距離・Steiner木・任意の固定半径の近傍と
長枝の偶奇だけから正しく判定する規則は存在しない。
ここで半径は競合グラフの距離であり、平面座標のEuclid距離ではない。
木全体を入力する分類や、長さのmod34情報を用いる規則を否定してはいない。
K0193の任意の大きな木に対する一般分類は依然未解決である。
