# 標準11×11：独立終局証明済み9石2根の7石被覆への統合

標準 q=4・完全指摘・通常プレイ。勝敗は元先手固定視点。
**空盤の勝敗は UNKNOWN。二石rootの新規閉鎖は確認されていない。**

## 証明の連鎖

- 原証明：`../n11-s9-two-neighbor-20261025/`。9石WIN 2根、全合法10石子延べ59辺・58対称類の終局WINを、別実装の3×3・4×4整数幾何で検証する。
- 各9石WIN根から一手を戻すと、8石WINの合法証人を持つ17対称類が得られる。
- `audit.js` は原証明の3入力のSHA-256、対称性・安全性、AND境界59辺/58類、8石親17類の完全一致、親から根への合法着手を再確認する。さらに別のJavaScript整数幾何実装で58葉を終局まで再帰する。
- 先行証明限定集合（9石WIN 138根、8石WIN 1,574類、7石親6,424類、確保済み7石→8石合法着手12,594辺）と集合和をとり、重複除去後の純増と7石の未被覆子を計算する。
- 独立証明済み8石LOSS 76類、凍結8石LOSS 294類との矛盾を検査する。凍結表は衝突検査にのみ用い、WIN証明の根拠にはしない。

再現（リポジトリ直下）：

```sh
python3 research/experiments/n11-s9-two-neighbor-20261025/verify.py --negative
node research/experiments/n11-s9-two-neighbor-s7-union-20261025/audit.js --negative
```

`audit.js` は、9石根の欠落、10石子の欠落・重複、8石親の欠落・重複を拒否する負の試験も含む。証明書の完全性と勝敗の再計算は別の検査であり、未完の探索状態数を勝敗や残り手数に読み替えない。

この統合監査は新しい二石rootの勝敗を主張しない。7石の新たな全子被覆が実際に成立するかどうかは、監査器の `newlyClosedS7` を確認すること。
