# 一辺細分星 q=13 の奇数次数実根切替（2026-11-05）

## 結論（解析的全称証明＋有理数有限検査）

一辺細分星の終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
で q=13、r=q-3=10、奇数 k≥3 とする。

- 3≤k≤87 では実根0個。
- k≥89 では相異なる負の単実根がちょうど2個。
- 任意の整数 q≥13、奇数 3≤k≤87 では実根0個。

## 証明

先行する一般閾値の証明により、奇数 k、r≥2 では実根の候補は u=-(r+1)y とした
\[
F_{k,r}(y)=r-y-\left(1+\frac1{r+1}-y\right)y^k
\]
の区間 1<y<1+1/(r+1) に限られ、u≥0 には根がない。

r=10、a=12/11 とおく。区間内の各 y>1 で (a-y)y^k は k に関して単調増加するため、k=87 で F>0 を示せば全奇数 k≤87 に及ぶ。

関数 H(y)=(a-y)y^87 は y_*=87a/88 を境に増加から減少に転じる。区間 [1,a] を100等分し、各小区間 [l,h] について z=min(max(y_*,l),h) と置けば H(y)≤H(z) である。下記の厳密有理数検査は100区間すべてで
\[
H(z)<10-h\le 10-y
\]
を確認する。したがって F_{87,10}(y)>0 が全区間で成立する。これは数値標本による推測ではなく、連続区間全体の厳密な上界証明である。

一方、k=89、y=1079/1000∈(1,a) で F_{89,10}(y)<0 が下記の整数演算で成立する。k≥89 の奇数では同じ点で負値を保つ。F(1)>0、F(a)>0 と中間値の定理により2個の相異なる負の根が存在する。T(-x) の係数符号変化は2回なのでデカルトの符号法則からそれ以外の実根はなく、両根は単根である。

さらに固定 y>1 で F_{k,r}(y) は r に関して厳密増加し、r≥10 の候補区間は (1,12/11) に含まれる。よって q≥13、奇数 k≤87 にも実根不存在が及ぶ。

## 再現検査（Python 3、浮動小数点なし）

```python
from fractions import Fraction as Q

r, k = 10, 87
a = Q(12, 11)
star = a * k / (k + 1)
for i in range(100):
    l = 1 + (a - 1) * Q(i, 100)
    h = 1 + (a - 1) * Q(i + 1, 100)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = Q(1079, 1000)
assert 1 < y < a
assert r - y - (a - y) * y**89 < 0
```

**証拠区分:** 全称的解析証明と100個の厳密有理数区間不等式。一般 q の接触二重根不存在は未解決。格子盤勝敗に関する主張ではない。
