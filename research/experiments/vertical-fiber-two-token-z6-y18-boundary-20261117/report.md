# 2トークン残余ゲーム \(z=6,\ y=18\) 切片の全Grundy分類

## 定理

\[
H(R;(x,18);6),\qquad x\ge18,\ R\ge0
\]
のGrundy値は常に \(0,1,2\) であり、値2となる残容量は

\[
\boxed{
T_{18}(x)=\{1,3,5\}\cup
\begin{cases}
\{39\}&x=18,\\
\{41\}&x=22,\\
\{43,45,47,49\}&x=25,\\
\{43\}&x\ge26,\\
\varnothing&\text{その他}.
\end{cases}}
\]

である。

\(O[a,b]\) を区間内の奇数、\(E[a,b]\) を区間内の偶数、\(O[a,\infty)\), \(E[a,\infty)\) を対応する無限列とする。値1の位置は

\[
P_{18}(x)=
\begin{cases}
O[7,37],&x=18,\\
O[7,\infty)\cup E[40,\infty),&x=19,\\
O[7,39],&x=20,\\
O[7,\infty)\cup E[42,\infty),&x\in\{21,23\},\\
O[7,39],&x=22,\\
O[7,41],&x=24,\\
O[7,41]\cup E[44,\infty)\cup O[x+26,\infty),
  &x\ge25\text{ 奇数},\\
O[7,41]\cup E[44,x+24],
  &x\ge26\text{ 偶数}.
\end{cases}
\]

値0の位置は上記の値1・値2の位置以外である。また一般tail定理から

\[
\boxed{
R\ge x+25\implies H(R;(x,18);6)=(x+18)\bmod2
}
\]

を得る。

## 再帰と依存

親の選択肢を

\[
\begin{aligned}
A&=H(R-1;(x-1,18);6),\\
B&=H(R-1;(x,17);6),\\
C&=1\oplus H(R-1;(x,18);5)
\end{aligned}
\]

とする。\(x=18\) ではA/Bの子はトークンを降順正準化すると同じ \((18,17)\) であり、K0908で評価できる。\(x\ge19\) ではAは同じ \(y=18\) 切片のR強帰納仮説、BはK0908、CはK0873の \(z=5\) 全Grundy公式で評価できる。

K0832のTheorem Tにより、奇数Rの親の選択肢値は \(\{0,1\}\) に含まれ、偶数Rの親のGrundy値は高々1である。従って奇数親は選択肢署名からmexを直接決定でき、偶数親は署名に0が含まれるかどうかで値が決まる。

## 選択肢署名表

以下は親の残容量Rに対するA/B/Cの値集合である。区間は両端を含み、奇数R表では奇数だけ、偶数R表では偶数だけを読む。R=1から \(x+24\) までを覆う。

| x | 奇数Rの署名 | 偶数Rの署名 |
|---:|---|---|
| 18 | 1..5:{0,1}; 7..37:{0}; 39:{0,1}; 41..43:{1} | 2..6:{2,3}; 8..42:{1} |
| 19 | 1..5:{0,1}; 7..43:{0} | 2..6:{2,3}; 8..38:{1}; 40:{0,2,3}; 42..44:{0} |
| 20 | 1..5:{0,1}; 7..39:{0}; 41..45:{1} | 2..6:{2,3}; 8..44:{1} |
| 21 | 1..5:{0,1}; 7..45:{0} | 2..6:{2,3}; 8..38:{1}; 40:{1,2}; 42..46:{0} |
| 22 | 1..5:{0,1}; 7..39:{0}; 41:{0,1}; 43..47:{1} | 2..6:{2,3}; 8..46:{1} |
| 23 | 1..5:{0,1}; 7..47:{0} | 2..6:{2,3}; 8..40:{1}; 42:{0,2,3}; 44..48:{0} |
| 24 | 1..5:{0,1}; 7..41:{0}; 43..49:{1} | 2..6:{2,3}; 8..40:{1}; 42..48:{1,2,3} |
| 25 | 1..5:{0,1}; 7..41:{0}; 43..49:{0,1} | 2..6:{2,3}; 8..40:{1}; 42:{1,2,3}; 44..50:{0} |
| 26 | 1..5:{0,1}; 7..41:{0}; 43:{0,1}; 45..49:{1} | 2..6:{2,3}; 8..40:{1}; 42:{1,2,3}; 44..50:{0,2} |
| x≥27 | 1..5:{0,1}; 7..41:{0}; 43:{0,1}; 45..u_o:{1} | 2..6:{2,3}; 8..40:{1}; 42:{1,2,3}; 44:{0,2}; 46..u_e:{0} |

ここで \(u_o=x+23\)（x偶数）、\(u_o=x+24\)（x奇数）、\(u_e=x+24\)（x偶数）、\(u_e=x+23\)（x奇数）である。

奇数親の署名が \(\{0,1\}\) となる位置から、基本ラダー \(\{1,3,5\}\) に加え、x=18の39、x=22の41、x=25の43,45,47,49、x≥26の43だけが値2となる。偶数親ではTheorem Tにより値2は生じない。値1位置は奇数親で署名が \(\{0\}\)、偶数親で署名が0を含む場合を取り出せば上記の \(P_{18}(x)\) になる。

x=18のA/B合流、x=19..25の過渡域、x=26の境界署名を個別に扱った。x≥27ではA子も定常域に入り、偶奇別の署名表がそのまま保たれる。表はK0908とK0873の閉形式を再帰へ代入した場合分けであり、有限範囲からの外挿ではない。

すべての \(1\le R\le x+24\) は署名表で尽くされ、\(R\ge x+25\) は一般tail定理で覆われる。R=0は終端値0である。よってR強帰納が閉じ、表示した全Grundy分類が全 \(x\ge18,R\ge0\) で成立する。∎

## 3族値2位置予想との一致

K0832の3族予想を \(z=6,y=18\) に特殊化し、\(d=x-18\) とする。

- 基本ラダーは \(\{1,3,5\}\)。
- 家族BのEXTは \(d=0,4\) で、それぞれ39,41。
- 家族Aのランは \(d=7\) で43,45,47,49。
- 家族Aの定常位置は \(d\ge8\) で43。

これは証明した \(T_{18}(x)\) と一致する。ただし、固定切片の一致であり、3族予想全体の証明ではない。

## 適用範囲と限界

証明対象は抽象残余ゲームの固定切片 \(z=6,y=18\)、全 \(x\ge18,R\ge0\)。\(z=6,y\ge19\)、\(z\ge7\) の全Grundy分類、3族値2位置予想全体、標準二次元共円ゲームの固定幅・q点版の真の安定化長は未解決である。
