# 四つの4点禁止集合だけでGrundy値5を実現する整数格子配置

2026-10-19。標準の「同一直線または同一円に4点で禁止」、一手一点追加、通常プレイ。**盤面は次の11点からなる有限部分集合**であり、全ての格子点を含む正方形盤の空盤とは異なる。

## 厳密な存在結果

次の点 `p_i=(x,y)` を使用する。

| i | x | y |
|--:|--:|--:|
|0|12|8|
|1|-8|0|
|2|2|0|
|3|-2|0|
|4|3|5|
|5|0|4|
|6|0|-4|
|7|24|-16|
|8|12|-4|
|9|24|-4|
|10|12|-16|

この11点に含まれる禁止4点組は、**ちょうど**次の4つである。

```
E0={0,6,9,10}  circle: (x-12)^2+(y+4)^2=144
E1={1,2,5,6}   circle: (x+3)^2+y^2=25
E2={3,4,5,6}   circle: (x-3)^2+y^2=25
E3={7,8,9,10}  circle: (x-18)^2+(y+10)^2=72
```

禁止4点組を含まない集合は1635個。全2048部分集合を石数の降順に計算すると、空盤のGrundy値は**5**。空盤からの11手の子の値は点番号順に

```
[4,0,0,0,0,2,1,3,3,0,0]
```

であり、0,1,2,3,4の全てが現れるのでmex=5。全安全局面の値別件数は
`g=0:585, 1:586, 2:224, 3:230, 4:9, 5:1`。

これは抽象4辺rank4ゲームの値5達成例（先行の高速レーン検算）を、**具体的な整数格子点**で実現した存在証明である。実際の標準 `n×n` 盤で、ある局面の残余禁止集合がこの4辺だけになるとは主張しない。

## 証明の完結性と独立検証

1. `verify.py` は4点の全330組について整数の4×4持ち上げ行列式を計算する。行列式0は共線または共円と同値（重複点はない）。ゼロになる組は上記4つのみ。全2048部分集合で安全性とGrundyのmex再帰を厳密計算する。
2. `independent.cpp` は行列式を使わず、全ての点対から直線、非共線三点から有理係数の円を生成し、それぞれに乗る点集合から禁止4点組を再構成する。独立の全状態mex計算で1635個、根5、全値分布と子の値を照合する。座標と判定は整数のみで、浮動小数点を使わない。

```
python3 research/experiments/fastlane-four-edge-geometry-20261019/verify.py
c++ -std=c++17 -O2 -Wall -Wextra -Werror research/experiments/fastlane-four-edge-geometry-20261019/independent.cpp -o /tmp/kyouen-4edge-geo
/tmp/kyouen-4edge-geo
```

`output.json` に独立照合済みの期待値を保存した。結論は**具体例の有限完全列挙**による厳密な存在結果であり、任意の整数格子盤の一般的なGrundy上界や、4辺の任意の幾何的実現可能性の証明ではない。
