## 独立した検査式

`r=q-3`, `a=(r+2)/(r+1)`, `y*=ka/(k+1)` とおき、`H=(a-y*) y*^k` を Python 標準ライブラリ `Fraction` で直接計算する。各 `k_-` で `1<y*<a` と `H<r-a`、各 `k_+=k_-+2` で `1<y*<a` と `H>r-y*` を検査する。先行記録の `A,B` 整数不等式をコードには転記せず、分数式そのものを評価する。

```python
from fractions import Fraction

rows = [
    (181,2511), (182,2529), (183,2545), (184,2561),
    (185,2577), (186,2593), (187,2609), (188,2625),
    (189,2641), (190,2659),
]
for q, km in rows:
    r = q - 3
    a = Fraction(r + 2, r + 1)
    for k in (km, km + 2):
        y = Fraction(k, k + 1) * a
        assert 1 < y < a
        h = (a - y) * y ** k
        if k == km:
            assert h < r - a, (q, k, "no-root")
        else:
            assert h > r - y, (q, k, "two-root")
    print(q, "PASS")
```

実行結果: `181 PASS` から `190 PASS` まで10行すべてPASS。Python任意精度整数を分子・分母に用い、丸め誤差はない。
