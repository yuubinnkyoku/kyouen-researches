# n11-residual58-fold16-k1113-geometry-preflight-20261120

K1113 の8石root 00000000010000889002000080100000 を、K1114 の fold15 完了後に fold16 として適用する前の幾何監査。

## 結果

fold14 の残余58行を基準に、K1113 と K1114 の各8石rootについて、S6被覆集合を二方式で独立再導出した。

- 方法A: rootの8石から6石を選ぶ C(8,6)=28 部分集合をD4正準化
- 方法B: 8個のD4像それぞれから2石を除く 8×C(8,2)=224 操作をD4正準化

両方式は両rootで完全一致し、それぞれ28行を得た。rootのD4正準性と70個の四点組の安全性も整数演算で再確認した。

| root | 28行のうちfold14残余58行にある行 | K1097/K1086主張行 | 余分なopen hit |
|---|---:|---:|---:|
| K1113 8890020 | 4 | 4 | 0 |
| K1114 120000038 | 3 | 3 | 0 |

さらに、K1113とK1114の28行集合は互いに素だった。K1114のfold15単一オーナー宣言が予告する3行だけを閉じる場合、K1113の4主張行はすべて残る。

## 解釈と制限

これは被覆幾何の事前監査であり、receipt foldではない。K1114のfold15は別の単一オーナーが担当しているため、重複実行していない。K1113のfold16はfold15の完了・公開後に、実際の新しいfrontierとreceipt chainを再取得してから着手する。

WIN8-D10証明書が証明するのは各8石rootのゲーム木だけである。S6行の閉鎖はfrontierの簿記であり、その行自体の勝敗を意味しない。標準11×11空盤・二石root {49,60} / {59,60}・S2 {59,60}・class 1/2/4 は依然 UNKNOWN。
