# 円の格子状交差による終局長母関数（2026-11-01）

## 定理（無界の整数平面構成）

任意の整数 m,n≥2 に対し、N=(m+1)(n+1) 個の相異なる整数点を選び、共円または共線の禁止4点集合がちょうど mn 個で、その所属構造が次の形になるようにできる。

- 点は O、R_i (1≤i≤m)、C_j (1≤j≤n)、P_ij (1≤i≤m,1≤j≤n) のみ。
- 禁止集合は正確に E_ij={O,R_i,C_j,P_ij}（mn本）。

この盤の極大安全集合の石数別母関数は

\[
\boxed{P_{m,n}(u)=u^{N-1}+u^{N-m}+u^{N-n}
+\sum_{a=0}^{m-1}\sum_{b=0}^{n-1}
\binom ma\binom nb\,u^{N-a-b-(m-a)(n-b)}}.
\]

これはすべての m,n に対する**数学的全称定理**である。m=2,n=3 では

\[
\boxed{P_{2,3}(u)=u^6+3u^7+17u^8+u^9+u^{10}+u^{11}},
\]

従って**6本の共円禁止4点集合だけで、6,7,8,9,10,11石という連続した6種類すべての終局長**が整数平面上に現れる。

## 終局長の数え上げの証明

安全集合の補集合 T は、禁止集合族の包含極小横断集合と同値。O∈T の場合、極小性から T={O} に限られる。

O∉T とし、T に入れた行点の添字集合を A、列点の添字集合を B とする。A に属さない行かつ B に属さない列の辺 E_ij は、専用点 P_ij を選ぶほかない。反対に、それ以外の P_ij は選ぶと冗長である。従って T は A,B によって一意に定まり、

\[
|T|=|A|+|B|+(m-|A|)(n-|B|).
\]

|A|<m, |B|<n なら、選んだ各行点には B 外の列が、各列点には A 外の行が私有証人辺を与え、T は極小である。|A|=m の場合は B=∅ に限り極小、|B|=n の場合は A=∅ に限り極小。よって T={O}、A=[m],B=∅、A=∅,B=[n]、および |A|<m,|B|<n がすべてである。最後の型の選択数は C(m,a)C(n,b)。|S|=N-|T| に変換すると表示した多項式が得られる。

## 幾何的実現の証明

相異なる有理点 O,R_1,...,R_m,C_1,...,C_n を一般位置で選ぶ。任意の3点 O,R_i,C_j は非共線で、定める有理円 Γ_ij は相異なり、ほかの芯点はどの Γ_ij にも載らず、芯点の意図しない4点共円・共線も起きないようにする。これらは有限個の真の代数的等式を避ける条件なので、有理点を逐次選ぶことで満たせる。

各 Γ_ij は有理点 O を持つ有理円だから、無限個の有理点を持つ。P_ij を順に選ぶとき、既に選んだ任意の3点と意図しない共円・共線4点組を作る候補、ほかの Γ_kl に載る候補、既存点との重複を除く。候補を排除する円・直線は Γ_ij 自身ではない（Γ_ij 上の既存点は O,R_i,C_j の3点だけに保っている）。異なる円・直線との交点は高々2点なので、有限個の除外後も有理点が残る。これにより禁止4点集合はちょうど E_ij となる。全有理座標を共通分母倍すれば整数点配置を得る。共円・共線性はこの拡大で保存される。

## 12点の明示証人（q=4、m=2、n=3）

点番号0〜11の順に

    0 O    = (  0,   0)
    1 R1   = (  8,  -4)
    2 R2   = (  2,  -6)
    3 C1   = ( -4,   4)
    4 C2   = (  6,  -2)
    5 C3   = ( -2,   2)
    6 P11  = ( -8,  24)

    9 P21  = (  2,  -8)
    10 P22 = ( -1,  -2)
    11 P23 = (-14, -14)

全 C(12,4)=495 組について、行列の行 (x,y,x²+y²,1) の行列式が0になるかを整数演算で判定すると、該当する組は正確に

    (0,1,3,6), (0,1,4,7), (0,1,5,8),
    (0,2,3,9), (0,2,4,10), (0,2,5,11)

の6組だけ。ここでは4点共線も同じ行列式0に含まれる。全 2^12=4096 部分集合を独立に調べると、安全局面は3117、極大安全集合は石数6,7,8,9,10,11についてそれぞれ 1,3,17,1,1,1 個。verify.py は同じ判定を一般 2×2,2×3,2×4,3×3 の抽象盤でも点別全列挙して上記母関数と照合する。

## 適用範囲と未解決点

幾何構成の存在は全称証明、12点の具体座標と4種の小盤の係数は有限完全列挙。これは任意の整数点集合を選ぶ版であり、標準11×11全121点盤の勝敗は主張しない。m,n の増大に伴う最小座標範囲、固定された11×11への埋め込み可能性、さらに任意本数 r における幾何的終局長集合の全分類は未解決。
