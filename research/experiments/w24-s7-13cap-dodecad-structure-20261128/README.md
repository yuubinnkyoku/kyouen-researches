# W_24 s=7 — 極大 13-キャップ × ドデカッド構造の全数検証

## 目的

K1347（極大 13-キャップの 11-部分集合 66/12 分割）が 3 個のサンプルでしか検証されていなかったのを、
**全 30,912 個の極大 13-キャップに対する全数検証**に強化する。あわせて

- 「各極大 13-キャップはドデカッド（Golay 重み 12 語）を**ちょうど 1 個**含む」の全数確認、
- 各ドデカッドを含む 13-キャップの個数（12）、インシデンス恒等式、
- 66/12 分割の全数確認と非 d11 11-部分集合 2,040,192 個の重複ゼロ確認、
- 非ドデカッド 11-キャップ 2,040,192 個すべての Grundy 値（G=2）と極大拡大プロファイル（{12:6, 13:1}）の**全数** DP 検証、

を行う。

## 方法

- ボード: `research/experiments/design-kyouen-witt-20261125/output/board_w24.txt`
  （24 点、759 オクタッド、s=7 ルール「各オクタッド ≤7 点」）。
- **stage1**（`gen_structure.c`、単一プロセス、1.4 秒）:
  1. 759 オクタッドの F2 張から Golay コードを再構成（基底 12、span 4,096）。
     重み分布 {0:1, 8:759, 12:2,576, 16:759, 24:1} を確認。重み 12 語 = ドデカッド 2,576 個。
  2. ドデカッドの 11-部分集合（d11）30,912 個を生成、ソートして互いに相異なることを確認。
  3. C(24,13) = 2,496,144 個の 13-点集合を**全走査**し、どのオクタッドも含まない
     （＝すべてのオクタッドとの交差が ≤7、＝s=7 ゲームの安全 13-局面）集合を列挙 → 30,912 個。
  4. 各 13-cap について全 11 個の外部点の追加可能性を検査し**終端（極大）**であることを全数確認（非極大 0 個）。
  5. 各 13-cap × 全 2,576 ドデカッドの包含を全数検査（30,912×2,576 ≈ 8,000 万包含判定）:
     cap あたりちょうど 1、dodecad あたりちょうど 12。
  6. 各 13-cap の C(13,11)=78 個の 11-部分集合を全数検査: d11 への二分探索で 12 個 / 非 d11 66 個に分割。
     d11 の 12 個がすべて「含まれた唯一のドデカッド」の部分集合であることを確認。
     非 d11 を全収集（2,040,192 個）しソートして重複ゼロを確認。
- **stage2**（`grundy_fullcheck.c`、4 並列プロセス、約 42 秒）:
  2,040,192 個の非 d11 11-マスクすべてについて、1 段展開 DP で Grundy を計算。
  安全 13-集合がすべて終端であることを stage1 が全数確認済みなので、
  12-マスクの子の G は 0（終端＝極大 12-cap）か 1（13-cap 拡大あり）に限られ、
  G(11-マスク) = mex{子の G} は正確に計算できる（メモ化不要の正確 DP）。
  あわせて極大 12-拡大の個数と 13-cap 親の個数（補集合の 78 ペアで cap ビット集合を検査）を数える。
  part 0 ではさらに d11 30,912 個（期待 G=0・13-cap 親 12）とドデカッド 2,576 個（期待 G=1）を全数検査。
- **独立クロスチェック**（`check_golay.py`、Python 標準ライブラリのみ、2.5 秒）:
  Golay span・重み分布・dodecad・d11 を Python で独立再導出して C 出力と照合。
  30,912 cap すべての安全性（オクタッド非包含）と昇順ソートを再検査。
  極大性サンプル 102 個、インシデンス+分割サンプル 608 cap を再計算。
  nond11_masks.bin の長さ・厳密昇順・d11 との非交・sha256 を検査。
- **マージ**（`merge_results.py`）: `output/structure_summary.json` に統合、`all_pass: true`。

恒等式:

- 2,576 × 12 = 30,912 = 極大 13-cap 数（dodecad–cap インシデンス、全数）。
- 30,912 × 66 = 2,040,192 = サイズ 11 の G=2 総数（K1342）と集合一致（全数 DP で各マスクの G を直接確認）。
- 30,912 × 12 = 370,944 = d11 側の 13-cap インシデンス総数（各 d11 は 13-cap をちょうど 12 個持つ、全数）。

## 「高々 1 個」の純粋証明（計算と独立）

Golay コードは線形で最小重み 8。相異なる 2 つのドデカッド D1, D2 が同じ 13-cap C に含まれると
|D1∩D2| ≥ 12+12−13 = 11。D1+D2 は符号語で重み 24−2|D1∩D2| ≤ 2、D1≠D2 ゆえ非零。
これは最小重み 8 に矛盾。ゆえどの 13-cap もドデカッドを**高々 1 個**含む。
（「ちょうど 1 個」の ≥1 側と個数 30,912 は本実験の全数列挙が与える。なお
「各ドデカッドは 12 個の 13-cap に含まれる」側は純粋に従う: 符号語の交差は偶数なので
各オクタッドはドデカッドと ≤6 点で交わり、12 個の単一追加 D∪{p} はすべて安全 13-cap、
13-cap ⊇ D は必ずこの形。）

## 副次所見（K1348 の k=12 行の訂正候補）

s=7 ではドデカッド自身（サイズ 12）は**子を 12 個持つ（すべて安全な 13-cap＝終端）ため終端ではなく、
G = mex{0} = 1**。K1348 の表の k=12 行「0（極大・終端）」は s=6 の挙動の混在と考えられ、
s=7 では不正確。K1342 の「サイズ 12 の G=0 1,020,096 は極大 12-キャップ（ドデカッド 2,576 を含む）」
の括弧書きも同様に、ドデカッドは G=1（非極大 373,520 側）に入る。
本実験は 2,576 個すべてで G=1 を直接確認した（`structure_summary.json` の `dodecads_grundy_s7`）。

## 限界

- 「各オクタッドはドデカッドと偶数点で交わる」等の符号理論的事実は再計算で確認しているが、
  Golay コードの一意性（同型を除く）までは扱わない。
- Grundy DP は 1 段展開で、安全 13-集合の終端性（stage1 全数）に依存する。この依存は
  stage1 が閉じているので循環検証ではない。
- K1348/K1342 の k=12 関連の記述訂正は本実験では行わない（関係 K 項目の管理者に委ねる）。
