# w=8 strip 分類 — ≥9点円配置の全称列挙と census の帯全域閉包（2026-11-15）

## 目的・位置づけ

(8,9)/(8,10) レーンの禁止曲線 census を m ≤ 984 の帯全域で全称化するため、
K0830（7行版）の弦上界付き完備列挙機械を w=8 に移植し、8行 strip（8行×無限幅）
内で ≥10 点を持つ円配置を弦上界 UMAX=2100 まで完備に列挙・分類した。
census-structure（q10/q9 census）の「予測（未証明）」を全称成立に格上げする。

## 記法

- 盤面 8×m（rows 0..7, columns 0..m−1）。円は (2x−u)² + (2y−2b)² = R（u 奇数）。
- strip 点数: rows 0..7 内の円の格子点数（各行 ≤2点・常に偶数・≤16）。
- 配置（config）: (R, v₀ = 2b, 行別倍化半弦 c_y = 2t_y)。鏡映: v₀ → 14−v₀。
- k2 = 複点行数（盤内で2点）、k1 = 単点行数（盤内で1点）。
- 盤内点数 n(u,m) = Σ_y（[c_y ≤ u ≤ 2m−2+c_y] + [−c_y ≤ u ≤ 2m−2−c_y]）（u 奇数）。

## 主定理（Theorem A）

**m ≤ 984 の 8×m 盤で ≥9 盤内点を持つ円は、census 9族 F1–F9 の配置メンバーに限る。**

K0830 例外円 R=2353705250（弦 {5,623,763,985,1079}・5複点行）は盤内9点に m ≥ 986、
10点には m ≥ 1080 を要する（K0830 7行結果と一致）。よって帯内（m ≤ 984）では
≥9 盤内点円は例外を含まない。≥9 盤内点 → ≥10 strip 点（偶数）なので、
≥10 strip 点配置の完備列挙（L3）が主定理を与える。

## 系（curves 計量の帯全域全称化）

1. **curves9(m) = 9m−97（m ∈ [23,984] 全幅・全976幅を数値完備検証・0失敗）**
2. **curves10(m) = 9m−105（m ∈ [23,940] 全幅。(8,10) の応用上限 U_{8,10}=940。
   モデル検証は m ≤ 984 でも成立）**
3. **ちょうど9点円**: F8/F9 幾何の端部メンバー u ∈ {19,21,2m−23,2m−21} のみ
   （m ≥ 23 で常に8個・m=22 で4個・m ≤ 21 で0個・全幅で集合として厳密検証）。
   q=9 符号化への追加 CNF は O(1)。
4. **≥11点円は F1 のみ（全 m ≤ 984・m−7 個）** → (8,11)/(8,12) の行2,5 強制満杯が
   帯全域で全称化（sampled m ≤ 100 主張の全帯昇格）。

## 補題

### L0（v₀ 整数性）
d ≥ 5 → v₀ ∈ ℤ。骨子: 8行中5行に鳩の巣原理で連続複点行対があり v₀ ∈ ¼ℤ
（v₀ = g/4）。g 奇数なら (8y−g)² mod16 の偶奇分離で複点行が同一偶奇に制限され
d ≤ 4。g ≡ 2 (mod 4) なら弦差 ≡ 2Δ (mod 4) が完全平方差の mod4 値と矛盾して
d ≤ 4。よって d ≥ 5 → g ≡ 0 (mod 4)、つまり v₀ = 2b ∈ ℤ。整数 Z 列挙は d ≥ 5 を
逃さない。一般 w: 連続複点行対の存在は d > ⌈w/2⌉ で保証。

### L1（k2 ≥ 3）
K0765 接点補題（複点行どうしの弦は盤内で交差しない → 接点なし）と mod9 剰余論法
（d ≤ 6）から 2k2+k1 ≥ 9 ∧ k2+k1 ≤ 6 → **k2 ≥ 3**。よって「1複点行+7単点行」型の
9点円は m ≤ 984 で原理的に不可能 → **chord-pair census は q=9 でも m ≤ 984 で完全**
（q9-census.md の L2-prime リスクが m > 984 に退避）。

### L2（弦上界）
遠方ケース: 複点行弦の二次成長評価 B ≤ ((m−1)²−16)/16 → 任意の窓行弦
c*² ≤ 4.5(m−1)² + 308 → m ≤ 984 で **c* ≤ 2085 < 2100 = UMAX**。
近方ケース: c*² ≤ (m−1)² + 392。よって UMAX=2100 の列挙は m ≤ 984 の
≥9 盤内点円を逃さない。

### L3（完備列挙・13構成）
半レンジ Z ∈ [−1102502,−2]（鏡映 v₀ → 14−v₀ で半減）+ 対称対 A′ + 鏡映閉包。
4チャンク実行: SPF sieve 1,102,503・Case A 1,101,450 ペア・A′ 2,100。
**結果: 13構成 = census F1–F9 と完全一致する9構成 + K0830 例外円の8行窓版**
（v₀ ∈ {48515,48517} + 鏡像 {−48501,−48503}・5複点行・弦 {5,623,763,985,1079}）。
チャンク別集計は output/stripsearch-w8-umax2100.json に記録。

### L4（族配置解析）
9族の盤内点数 n(u,m)（上記公式）の帯全域解析:
- 左端部（m ≥ 44）: m 非依存の有限計算（≥10 端部は F1@{u=5} のみ・ちょうど9は
  F8/F9@{19,21} のみ）。
- 内部: 全行収容で 9m−113 個（≥10点）。
- 右端部: 左端部の鏡像。
→ 系1–4。**本ラウンドで m ∈ [9,984] 全976幅を数値完備検証（0失敗）**
（scripts/family_placement.ts・output/family-placement-m22-984.json）。

## スコープ・誠実性の区別

- **全称定理**: Theorem A と系1–4（いずれも m ≤ 984 に限る）。L1–L2 の補題証明と
  L3 の完備列挙（弦 ≤ 2100）に基づく。
- **機械検査（完全列挙）**: L3 の13構成・L4 の全976幅・弦平方算術検証。
- **記録値**: L3 の集計（SPF/pairsTested/チャンク別）は 2026-11-15 の 4チャンク
  実行の記録。scripts/stripsearch_w8.ts は compaction 後の参照再構成であり、
  定数・ケース構造は実行時のもの、集計値は output JSON の記録を正とする。
- **範囲外**: m > 984（U_{8,9}=984 の外）での族閉包（超平坦円の除去など）は
  今後の数学的課題（K0817/P(w) 型）。
