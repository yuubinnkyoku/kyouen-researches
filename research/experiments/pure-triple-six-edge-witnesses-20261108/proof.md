# Grundy 6・7を実現する純三点辺の最少本数

## 定理

自由点を許す純三点禁止集合ゲームで、g=6およびg=7を実現する
三点辺の最少本数はともに **6**。

下界はK0687の全称定理「三点辺が五本以下ならg≤5」から従う。
上界のg=6は、九点上の六辺mask

```
49,37,262,56,448,52
```

で達成する。頂点0を最下位bitとした集合であり、重複辺はない。
初手後のGrundy値は頂点0..8の順で

```
1,5,0,2,4,3,5,5,1
```

なので根値はmex{0,1,2,3,4,5}=6。
自由点を一つ追加するとxor1により、十点・六辺でg=7を得る。
K0683により両方とも標準q=4の指定有限整数点盤に実現できる。

## 探索と独立検査

K0687の五辺核のうちg≥4の全七型に、新しい三点辺を一つ追加した。
既存点と1..3個で交わる追加を全て試し、入力重複を除くと831族となった。
C++個別占有subset DPは332043安全状態を調べ、最大観測値6。
値6の族は七入力あった。保存した一つは別のPython原始subset再帰でも
根値と全九初手値を確認した。

この831族は六辺族全体の完全列挙ではない。
「六辺以下ではg≤7」などの上界を証明する計算ではなく、
上記の存在証拠とK0687による五辺以下の排除で、最少辺数だけを確定する。

後続の八点合成で辺mask `22,38,41,49,88,146` のg=6を得た。
全初手値は `5,1,3,4,2,0,5,0`、自由点追加で九点g=7となる。
K0690からg=6では8点以上、g=7では9点以上が必要なので、
最少合法点数も8,9と確定する。後続資料は
`../pure-triple-grundy-synthesis-20261108/output/witness_audit.json`に保存し、
このディレクトリの九点一次発見はそのまま保持する。

