# 一辺細分星 q=51〜60 の奇数次数実根切替（2026-11-06）

## 結論（全称証明、境界は厳密整数計算）

\(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}\), \(r=q-3\), 奇数 \(k\ge3\) に対し、以下の各行で \(3\le k\le k_+-2\) は実根なし、\(k\ge k_+\) は相異なる負の単実根がちょうど2個。

| q | k_+ | 非存在の最大奇数 k |
|---|---:|---:|
| 51 | 553 | 551 |
| 52 | 567 | 565 |
| 53 | 579 | 577 |
| 54 | 593 | 591 |
| 55 | 607 | 605 |
| 56 | 621 | 619 |
| 57 | 633 | 631 |
| 58 | 647 | 645 |
| 59 | 661 | 659 |
| 60 | 675 | 673 |

各非存在結論は同じ k 範囲で任意の q'≥q にも成立する。

## 証明

\(u=-(r+1)y\), \(a=(r+2)/(r+1)\) とおく。正の u に根はなく、負の根は \(1<y<a\) に限られる。根方程式は \(F(y)=r-y-(a-y)y^k=0\)。\(H(y)=(a-y)y^k\) の区間内最大値は \(y_*=ka/(k+1)\) での値。各 \(k_-=k_+-2\) に対し **\(H(y_*)<r-a\)** を下記の厳密整数不等式で検証する。従って全 \(1<y<a\) で \(F(y)\ge r-a-H(y_*)>0\)。小さい奇数 k では \(y>1\) より H が減少するため非存在は全 \(k\le k_-\) に及ぶ。rを増すと \(r-y\) は増加し a は減少するため q'≥q にも及ぶ。

\(k_+\) では \(F(y_*)<0\) を検証する。\(F(1)>0\), \(F(a)>0\) なので2つの異なる根が存在する。\(T(-x)\) の符号変化は2回なのでデカルトの符号法則により負の実根は重複度込み高々2つ、従って両者は単根で、他の実根はない。kを増すと \(y>1\) でFが減少するので同じ試験点により全奇数 \(k\ge k_+\) に拡張できる。

**重要:** 非存在側では単に \(F(y_*)>0\) を確認するだけでは不十分。\(r-y\) もyに依存するためである。本証明はより強い \(H(y_*)<r-a\) を確認する。

## 独立再現可能な整数検算

\(A=k(r+2), B=(k+1)(r+1)\) とおく。非存在側の不等式は
\((r^2-2)(k+1)B^k>(r+2)A^k\)。
存在側の \(F(y_*)<0\) は
\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)。
以下は浮動小数点を使用しない。

```python
bounds = [(51,553),(52,567),(53,579),(54,593),(55,607),
          (56,621),(57,633),(58,647),(59,661),(60,675)]
for q, kp in bounds:
    r = q-3
    km = kp-2
    A, B = km*(r+2), (km+1)*(r+1)
    assert B < A and A*(r+1) < (r+2)*B
    assert (r*r-2)*(km+1)*B**km > (r+2)*A**km
    A, B = kp*(r+2), (kp+1)*(r+1)
    assert B < A and A*(r+1) < (r+2)*B
    assert (r*B-A)*(r+1)*(kp+1)*B**kp < (r+2)*A**kp*B
print("20 exact inequalities passed")
```
