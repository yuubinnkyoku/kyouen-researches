# (8,11)/(8,12) 帯の初報告 — SA witness 下界と12点族構造補題（2026-11-15 高速レーン）

## 概要

w=8 の固定幅安定化長のうち M_{8,11} と M_{8,12} は、これまでどの既証明帯にも覆われていなかった
（分離帯は q>=13 から K0765/K0767、K0025 は q>2w=16、K0072 は q=16/15 のみ）。
本実験は K0811 の SA機を増分更新方式（曲線石数カウンタ・点遮蔽カウンタ・石スタック・固定反復予算）に
改修して移植し、両帯を掃引した。8枚の row-deficient witness を発見し、すべて census 不使用・
整数演算のみの独立検証で safe + maximal を確認した。あわせて弦対census（完全列挙）により、
q in {11,12} の検証盤面では禁止円が単一の12点パラメータ族のみであることを確認し、
「行2・5は任意の極大安全配置で満杯」という構造補題を得た。

## 構造補題（検証盤面について証明済み・全 m への解析的拡張は未完）

q in {11,12} のとき、検証したすべての盤面（8x11..8x26 の全m、8x30/40/45/50/60/80/100）で
完全弦対censusの禁止円は **m-7 個の12点円族のみ**:

- 中心 (u, 7/2)、方程式 (2x-2u)^2 + (2y-7)^2 = 50、u は半整数で 7/2, 9/2, ..., m-9/2（ちょうど m-7 個）
- 各円は12点: 行0・7 で x = u±1/2、行1・6 で x = u±5/2、行3・4 で x = u±7/2
- **行2・5 を通らない**（これらの行では (2y-7)^2=9、残り 50-9=41 が平方数でないため）

帰結: 行2・5上の空点は行自身でしか block され得ないため、任意の極大安全配置で行2・5は
強制的に満容量 min(m, q-1) 石になる（検証した各盤面について証明済み）。
実際、8枚の witness すべてで行2・5は満杯（欠損は行 {0,1,3,4,6,7} に集中）。
また w=8 では非水平直線は高々8点しか持たず q-1 >= 10 に届かないため、
block に有効な曲線は行とこの12点族円のみである。

census 完全性の制御:

- 8x11 q11 / 8x16 q11 / 8x14 q12 で全3点組ブルートフォース列挙と弦対censusがキー完全一致
- (8,10) レーンの公開曲線数（m=26/31/42/100 で 129/174/273/795）と一致（前日セッションの較正）

## 機械と手法

scripts/sa_machine_incremental.js（実行は 2026-11-15 Vibe TS サンドボックス・node 実行は再現用）。

- **census**: genfast3 弦対法の移植（行 + >=q 点の円）。
- **SA**: K0811 方式の増分更新版。状態は常に極大安全配置。move = 石を r 個（<=30%）乱数除去 →
  再極大化（自由点から sampleK=24 の貪欲 + 微小ノイズ）。Metropolis（T0=2.5, alpha=0.99985,
  TMin=0.02 で再加熱）、30万 iter 停滞でベストへ再シード。乱数は LCG で決定論的（seed 再現可能）。
  予算は反復数（15000〜30000）。
- **独立検証** scripts/verify_census_free.js: census 不使用・整数演算のみ。
  safety = 行 <= q-1、非水平線 <= q-1（実際は <=8）、全3点組円の石数 <= q-1。
  maximality = 全空点が「行 q-1 石」または「空点を通る円（石対+空点で列挙）が q-1 石」で block。

## 抵抗の記録（不在証明ではない）

- (8,11): m=16..18 は seeds {1,2,3} x 15000 iter、m=19..26 は seed1 x 15000、m=45 は seed1 x 30000 で
  すべて best = 80（満容量）から崩せず。ヒューリスティックな非発見の記録であり、witness の不在は主張しない
  （K0811 で確立したとおり、貪欲・SAT・SA の非発見と実際の不在は一致しない前例がある）。
- (8,12): m=15 は seeds {1,2,3} x 15000 で best = 88（満容量）。

## レジューム

1. (8,11) m=16..45・(8,12) m=15..45 の SA 強化（シード多様化・長時間予算）。witness が見つかれば
   下界がさらに伸びる。SAT（kissat def-mode）での直接攻撃も有力 — 12点族censusは曲線数 m+1 しかなく、
   符号化は (8,10) より軽い。行2・5固定子（構造補題）で変数を削減できる。
2. 12点族の全 m 解析証明: 円と水平線の交点は高々2点/行なので >=q=11 点の円は >=6 行を占有する。
   8行盤での多格子点円の分類（mod 論法・Melchior 型会計）で族のみであることの証明を狙う。
   成功すれば「行2・5強制満杯」が全 m で証明され、(8,11)/(8,12) の SAT 符号化が大きく削減される。
3. K項目への昇格は bash 環境復帰後（build.py による generated 再生成が必要なため本日は見送り・log に記録）。
