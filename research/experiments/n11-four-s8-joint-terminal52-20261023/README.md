# 標準11×11：4個の8石LOSSを同時に証明する最小52葉証明

2026-10-23。通常版・完全指摘・元先手固定視点。**空盤の勝敗はUNKNOWN**。

## 新しい成果

独立終局証明のある4個の8石LOSS根を、10石LOSS証明葉**52個**で一括して証明する。これまで別々に使った27＋13＋14＝54葉には1件の重複があり、相異なる証明葉は53個だった。新しい集合は**52個（相異なる葉数で1件削減）**。52葉という下界は、整数線形計画器を信用しなくても検査できる有理数双対証明書で保証される。対象は**この4根・10石LOSS葉形式の証明**に限る。

4根の9石合法子は延べ106、重複を除いて103義務。その義務から到達する相異なる10石局面を**全1,017件**列挙した。C++の4×4整数行列式とPythonの3×3整数行列式を用いた二つの直接終局探索が、1,017件すべてについて勝敗・合法手数・再帰状態数で一致した。結果は元先手WIN780・LOSS237。個別探索状態数の総和は**205,690**（共有表ではない）。未完探索・旧cacheを終局判定に用いていない。

52葉の選択は4根の全103義務を覆い、各9石局面には10石LOSS子が少なくとも一つある。したがって奇数9石ANDはLOSS、偶数8石ORは全子LOSSでLOSS。

## 52葉が最小である理由

`dual-weights.tsv`は103義務のうち79個に、重みを半単位で割り当てる（25個に2、54個に1、合計104半単位＝52）。**全237個の10石LOSS候補**について、それが覆う義務の重みの合計は高々2半単位＝1。WIN780件は正しい証明葉に使えない。1,017候補はすべて列挙・分類済みなので、52個未満のLOSS葉で103義務を覆うことは不可能。検証器はこの不等式を整数演算だけで全件確認する。

## 以前の53葉との比較

`prior53.keys`は27葉＋13葉＋14葉の重複除去和集合。52葉と53葉はともに全義務を覆う。終局葉を**個別**に解く場合の状態数合計は53葉が12,327、52葉が12,280（47状態減）。これは共有探索表や実行時間の削減率ではない。

52葉のうち個別状態数合計12,280の集合はSciPy/HiGHSの0-1整数計画でも最適と判定されたが、その**副次的費用最適性**には独立した双対証明書は付けていない。52という**葉数の最小性**だけが上記の独立検査可能な下界である。`optimize.py`は任意の再探索用で、証明検証には不要。

## 既存証拠との照合

6件の既存実験にある相異なる10石判定925件と照合し、今回の1,017候補との共通730件でWIN/LOSS矛盾は0。共通集合外の287件はWIN211・LOSS76。これは**当該925件に対する増分**であり、研究全体の全cacheに対する新規件数ではない。`prior925.tsv`はこの限定的な照合対象を凍結したもので、今回の独立終局証明の前提には使用しない。
