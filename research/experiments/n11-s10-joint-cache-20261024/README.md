初版の `verify_joint.cpp` は逆順（mode 1）の分岐で734個のWIN葉だけを処理し、52個のLOSS葉を処理していなかった。このため、逆順の期待値55,289状態を照合する前に48,794状態で不一致となり、初版の逆順検証は**実行不能**だった。また、`reproduce.sh` が呼び出す `verify_joint.py` が未登録で、全体の再現手順も完走できなかった。
