- 状態: 全称定理。有限監査だけによる外挿ではない。

## 選定理由

最新mainのAGENTS.md、research/knowledge/README.md、K0832、K0873、K0885を確認した。z=6の全Grundy切片はy=1..6まで証明済みで、y>=7が未解決だった。K0886はREMOの別項目として既に使われているため、新しい項目番号はK0887とした。

y=7ではA/B/C再帰のB子にK0885、C子にK0873を使える。x=7だけA/Bが同一の(7,6)子に合流する。従って、R強帰納と有限個の過渡xを明示した署名表で閉じられる。

## 定理

E[a,b]を区間内の偶数、O[a,b]を奇数、I[a,infty)をa以上の全整数とする。

値2位置は
- x=7: {1,3,5,17}
- x=11: {1,3,5,19}
- x=14: {1,3,5,21,23,25,27}
- x>=15: {1,3,5,21}
- x in {8,9,10,12,13}: {1,3,5}

値1位置は
- x=7: O[7,15]
- x=8: O[7,17] union I[18,infty)
- x=9: O[7,17]
- x=10: O[7,17] union I[19,infty)
- x=11: O[7,17]
- x=12: O[7,19] union I[20,infty)
- x=13: O[7,19]
- x>=14 even: O[7,19] union E[22,x+12] union I[x+14,infty)
- x>=15 odd: O[7,19] union E[22,x+13]

従ってHは値2位置で2、値1位置で1、それ以外で0。

## 証明

R=0は終局。R>=1,x>7の選択肢は
- A = H(R-1;(x-1,7);6)
- B = H(R-1;(x,6);6)
- C = 1 xor H(R-1;(x,7);5)

x=7ではA/Bが同じ(7,6)子に合流する。AはR強帰納仮説、BはK0885、CはK0873で評価できる。

K0832のTheorem Tにより、奇数Rの親では選択肢が{0,1}に限られ、偶数Rの親の値は高々1。奇数親の署名01/0/1に対するmexは2/1/0、偶数親は署名に0があるときだけ値1となる。

一般tail定理
    R >= S+|X|+z-1 => H(R;X;z)=S mod 2
にS=x+7, |X|=2, z=6を代入すると
    R >= x+14 => H(R;(x,7);6)=(x+7) mod 2.
署名表とtailが全Rを覆い、R強帰納が閉じる。QED.

## 3族値2位置予想との一致

K0832の3族予想をz=6,y=7に特殊化すると、基本ラダー{1,3,5}に加え、d=x-7=0で17、d=4で19、d=7で21,23,25,27、d>=8で21となる。これは全称分類と一致する。ただし、3族予想全体の証明ではない。
