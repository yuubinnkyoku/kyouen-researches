# 11×11二石局面 {27,60} の既知LOSS被覆の最小性（2026-10-17）

標準11×11・完全指摘・通常プレイ。空盤勝敗は **UNKNOWN**。

既存の [K0414](../../knowledge/items/K0414-n11-reply27-root-loss.md) に記録された二石局面 {27,60} の119合法第三手に対し、既知の四石LOSSクラス32件だけで被覆する場合、**32件すべてが不可欠**であることを独立整数幾何で確認した。

## 検査結果

- 合法な第三手：119件。合法な有向第三手→第四手：13,742辺。
- その四石D4正準クラス：3,384件。
- 既存証明で使用する四石LOSSクラス：32件。
- 被覆済み第三手：119/119件。
- **既知32クラスの中で、他の31クラスでは覆えない第三手を各クラスが少なくとも1件持つ。**
- 第三手の既知LOSSクラス次数：1が114件、2が2件、3が2件、13が1件。
- よって、この32クラスに制限した集合被覆の最小値は32。既存の32クラス解は厳密最適。

入力の32クラスは `input/known-s4-loss-classes.txt` に128-bit maskの32桁16進数で保存した。抽出元は `research/experiments/n11-s4-boundary-direct-20261012/output/root-60-27-loss-proof.json`（Git blob SHA-1 `b52b6e2829f960e93393eac8fb930d415c37ac33`）。抽出時は64-bit整数の精度を失わないよう文字列として扱った。

独立検査では、11×11整数格子上の四点の行列式零判定、D4の8変換、第三手・第四手の全合法辺を再生成した。32件それぞれを一つずつ除いた33件未満の集合では、そのクラスだけで被覆できていた第三手が少なくとも一つ未被覆になる。32削除試験と重複混入試験はすべて拒否した。

## 信頼範囲

これは**既知32件の四石LOSSクラスに制限した最小性**である。未確定の別の四石クラスが後にLOSSと判明すれば、より少数のクラスで被覆できる可能性がある。既知クラスのLOSS判定はsolver-trustedのままで、今回の計算は終局までの独立勝敗証明を新たに与えるものではない。空盤勝敗はUNKNOWN。
