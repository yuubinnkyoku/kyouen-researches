## 設定

pinned composite_core.py の定義をそのまま使う:

- E(P;α,β): k=α+β人、ptrフレーム円 [P]^α+[P+1]^β、pot P。
  フェーズ: q,r=divmod(pot,k)。framesに(k,r)を記録し、
  r<α なら (pot,α,β)←(pot+q, α−r−1, β+r)、 else
  (pot,α,β)←(pot+q+1, β+2α−r−1, r−α)。k←k−1。
  σ_E = 後方から (r+1+σ) mod k。
- Z(M,K): K人全員M持ち・pot M。q,r=divmod(M,K)。
  σ_Z = (r+1+σ_E(M+q, K−1−r, r)) mod K。

K>M のとき q=0・r=M なので Zの第1フェーズのfold寄与は c=M+1 で、
E入口は E(M; K−M−1, M)。

## 補題 RUN-UNIV（全称・紙上）

M ≥ 1, K > M とする。α₀ = K−M−1 ≥ 0, k₀ = K−1,
s = ⌊α₀/(M+1)⌋, κ = α₀ mod (M+1)（= K mod (M+1)）。

(i) α₀ ≥ M+1 のとき、E(M;α₀,M) の最初の s フェーズは各々
    q=0・r=M<α（type-A）で、各フェーズ (α,β)←(α−M−1, β+M)・k←k−1・
    pot M 不変。
(ii) run中常に k ≥ k_t+1 ≥ M+2 > M（s ≤ α₀−1 ゆえ）。すなわちrunは
     k=pによる打ち切りを受けず、q=0レジームがrun全体で保たれる。
(iii) run終了時の状態は E(M; κ, M(s+1))、k_t = κ+M(s+1) = K−1−s。
(iv) α₀ = 0（K=M+1）のとき s=0・κ=0 で tail は E(M;0,M) 自身。

証明: (i) i<s の間 αᵢ = α₀−i(M+1) ≥ M+1 > M = r でtype-A条件が
保たれる。α ≥ M+1 ≥ 2 のとき s = ⌊α₀/(M+1)⌋ ≤ α₀/(M+1) ≤ α₀−1。
(ii) run中のkの最小値は k_t+1 = K−s ≥ K−α₀+1 = M+2。割り算レジーム
q ≥ 1 に入らない。(iii)(iv) はαの減算の直接計算。∎

## 補題 NO-WRAP-RECOVERY（後方チェーン・全称・紙上）

定理ONE-CHAR-GENERALの証明の中核。runレベル [k_t+1, K−1] とZレベルKは
全てfold寄与 c=M+1。前向きfold: σ_ℓ = (σ_{ℓ−1}+c) mod ℓ。
silent（σ_{ℓ−1}+c < ℓ）と wrap（σ_ℓ = σ_{ℓ−1}+c−ℓ; 単一wrapは
ℓ ≥ M+2 > c と σ_{ℓ−1} ≤ ℓ−2 から保証）の後方分解で

**σ_{k_t} = σ_{K−1} − c·s + Σ_{j∈W} j**、
W = [k_t+1, K−1] 内のwrapレベル集合。

σ_{k_t} ≤ k_t−1（tailの生存者位置の範囲）が常に成り立つので、
W ≠ ∅ なら σ_{k_t} ≥ (σ_{K−1}−cs) + (k_t+1)。値1の場合
σ_{K−1}−cs = κ+1 ≤ M なので σ_{k_t} ≥ κ+1+k_t+1 > k_t−1（κ ≥ 0）
で矛盾する。ゆえ **値1はwrapを持たない**。∎

## 定理 ONE-CHAR-GENERAL（全称・紙上）

**M ≥ 2, K > M に対し σ_Z(M,K) = 1 ⟺ σ_E(M; κ, M(s+1)) = κ+1**、
κ = K mod (M+1), s = ⌊(K−M−1)/(M+1)⌋。

証明: (⇒) σ_Z = (M+1+σ_{K−1}) mod K = 1 と σ_{K−1} ∈ [0,K−2] から
σ_{K−1} = K−M（一意; M ≥ 2 で K−M ≤ K−2）。NO-WRAP-RECOVERYで
W=∅、σ_{k_t} = K−M−(M+1)s = κ+1。
(⇐) σ_tail = κ+1 のとき silent chain v_ℓ = κ+1+(M+1)(ℓ−k_t) は
v_ℓ−ℓ = Mℓ−(M+1)k_t+κ+1 がℓで増加し ℓ=K−1 で 1−M ≤ 0 だから
wrapせず、レベルKで v_K = (v_{K−1}+M+1) mod K = (K+1) mod K = 1。∎

M=3 では κ=0・s+1=u と置き直すと K0945 ONE-CHAR
（σ_Z(3,K)=1 ⟺ σ_E(3;K mod 4, 3⌊K/4⌋)=K mod 4+1）と同一の式になる。
K0945の証明はM=3固有の積分性の場合分けだったが、後方チェーン引数は
Mによらず同じ形で働く。

## 系 EXCL-2（κ=M−1 除外・全称・紙上）− A2-NEVERの一般化

**M ≥ 2, K > M, K ≡ M−1 (mod M+1) なら σ_Z(M,K) ≠ 1**。

証明: ONE-CHARより σ_tail = M が必要。tail E(M; M−1, M(s+1)) は
k_t = M(s+2)−1 ≥ 2M−1 > M なので第1フェーズは q=0・r=M ≥ α=M−1 の
bump。σ_tail = (M+1+I) mod k_t（I は継続ゲームの生存者位置、
I ∈ [0, k_t−2]）。= M ⟺ I ≡ −1 (mod k_t) だが解は I = k_t−1 ∉ 範囲。∎

M=3 でK ≡ 2 (mod 4) が除外される K0945 A2-NEVER はこの系のM=3の場合。

## 系 EXCL-1（κ=M 除外・帰着）と U0-NEVER

**M ≥ 2, K > M, K ≡ M (mod M+1) なら σ_Z(M,K) ≠ 1 ⟺
σ_E(M+1; Mt−1, 0) ≠ 0 ∀t ≥ 2**（t = s+2）。

証明: ONE-CHARより σ_tail = M+1 が必要。tail E(M; M, M(s+1)) の
第1フェーズは r=M ≥ α=M のbumpで、σ_tail = (M+1+I) mod k_t
（k_t = M(s+2)）。= M+1 ⟺ I ≡ 0 (mod k_t) ⟺ I = 0。bump後状態は
E(M+1; M(s+2)−1, 0)（β₁ = 0 の均一game）。∎

帰着先 **U0-NEVER**（未証明・機械検証）: σ_E(M+1; Mt−1, 0) ≠ 0。

## 系 M1-EMPTY（全称・紙上）

**σ_Z(1,K) ≠ 1 ∀K ≥ 2**。証明: 値1は σ_{K−1} = K−1 を要求するが
σ_{K−1} ∈ [0,K−2]。∎（M=1の軌跡は完全に空。機械: K≤10⁵ で0ヒット）

## 補題 DEG（退化閉形式・紙上）

- **σ_Z(M,2) = 1 ⟺ M 偶数**。M偶数: r=0, q=M/2, σ_E(M+q;1,0)=0
  （k=1）より (1+0) mod 2 = 1。M奇数: r=1, σ_E(M+q;0,1)=0 より
  (2+0) mod 2 = 0。
- **σ_Z(M,3) = 1 ⟺ M ≡ 2 (mod 3)**。M=3t+2: r=2, P=M+q=(4M−2)/3=4t+2
  偶、σ_E(P;0,2) = 1−(P mod 2) = 1、(3+1) mod 3 = 1。M≡0: P=4s 偶で
  σ_E(P;2,0)=1、(1+1) mod 3 = 2。M≡1: P=4s+1 奇で σ_E(P;1,1)=0、
  (2+0) mod 3 = 2。
- **σ_Z(M,M−1) ≠ 1 (M ≥ 3)**: q=1, r=1、σ_Z = (2+σ_E(M+1;M−3,1)) mod (M−1)
  で σ_E ∈ [0,M−3]、値1は σ_E ≡ −1 ≡ M−2 (mod M−1) を要求するが
  範囲外。

機械（K ≤ M・M ≤ 40）: 退化ヒットは K=2（M偶数）・K=3（M≡2 mod 3）で
完全説明される場合が大半で、他は K∈{4,6,7,8,10,12,13,24} など散発

## 応用: 合成NのV/U値への必要条件（K0941 THM-B経由）

K0941 THM-B の死後状態（V: breaking死 → Z(w+1, n−t)）で
σ_Z(w+1, n−t) = 1 が問われる場面:

- **証明済み必要条件（全称）**: n−t > w+1 なら
  **n−t ≢ w, w+1 (mod w+2)**（EXCL-2: κ=w、EXCL-1: κ=w+1 に該当。
  M=w+1, K=n−t, M+1=w+2）。
- **M1相当**: w+1=1 は w=0 で非発生。
- **予想（PRIME-M経由）**: w+1 合成 かつ n−t > w+1 なら
  σ_Z(w+1, n−t) ≠ 1、すなわち死後frame位置1は合成NのV値に現れない
  （機械検証の必要条件。全称主張ではない）。
- n−t ≤ w+1（t ≈ n−w−1 の近傍）は退化レジームでDEG補題族が適用される
  （例: n−t = w+1 ⟺ κ=0; n−t = w ⟺ K=M−1 で値1不可能・証明済み）。
