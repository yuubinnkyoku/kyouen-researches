## プロトコル

- 入力4正本をSHA-256 pin（K1085 `5fdd342d…`・K1086 `3045e152…`・
  K1089 `808fbda1…`・K1091 `edd7ac84…`）でfail-closed読み出し。
- universe82（残余72行×空き2石のgeneration witness→canonical dedup 380,098根）・
  unsafe8（整数4×4行列式）・safe8 pool 120,474根・coverage・per-row demand・
  greedy 23根計画（根順序・主張被覆行とも）を本実験機械内で独立再導入
  （coverage crosscheck 39,255根）。
- 残余49行宇宙はK1085+K1086から再導入、K1089代替16根の主張をcanonical化して
  49行exactly-once分割を再検証（K1090と同一構造）した上で残余40行を定義し、
  さらにK1091代替15根の主張被覆をcanonical化（D4 orbit最小hex）して
  「40行exactly-once分割・generation-witness被覆包含・WIN8-3根の主張10行と
  REFUTED-12根の主張30行のdisjoint union==40」を検証した。
- 除外: REFUTED-D10 41根（K1086の16根+K1089の13根+K1091の12根）。
  pool P″ = safe8 − 41 = **120,433根**。
- 残余30行 = K1091 REFUTED-12根の主張被覆行（canonical化）。
- 内在被覆: 累計13 WIN8-D10候補根（K1086の7根+K1089の3根+K1091の3根）の
  C(8,6)=28部分集合のcanonical再導入によるintrinsic coverage。
