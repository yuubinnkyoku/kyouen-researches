# 標準11×11：9石19根の証明限定8石・7石被覆統合（2026-10-26）

**11×11空盤の勝敗はUNKNOWN。二石rootの新規閉鎖は主張しない。**

## 証拠と信頼境界

原証明は `../n11-s9-neighbor19-terminal-20261026/`。9石19根の全合法10石子319辺、相異なる314類が、保存済み勝敗表を使わない二種類の整数幾何・終局minimaxでWINと検証済み。逆向きの8石WIN証人親は164対称類。

`audit.js` は原証明の根・葉・親のSHA-256と合法境界を別のJavaScript整数幾何で再生成し、既存の証明限定9石WIN 170根、8石WIN 1,824類に重複なく統合する。**この境界監査だけで終局勝敗を再証明するものではない**。必ず原証明の `verify.py --negative` と組み合わせる。

凍結8石LOSS 294類・独立証明済み8石LOSS 76類との衝突を、既存8石WINも含めて拒否する。凍結表は勝敗の根拠に使わない。

8石WINの新規類を逆向きに7石へ投影し、前向きの全合法着手列挙で被覆増分・未被覆子数を再計算する。逆向きの対称類着手辺集合との一致も確認する。旧集合は証明済み8石WIN 1,824類、被覆7石親7,270類、確保済み7石→8石着手14,594辺（対称類辺14,592）で固定する。

## 再現

リポジトリ直下で：

```sh
python3 research/experiments/n11-s9-neighbor19-terminal-20261026/verify.py --negative
node research/experiments/n11-s9-neighbor19-s7-union-20261026/audit.js --negative
```

監査器は機械可読JSONで純増8石WIN、影響7石親、確保済み着手辺、最少未被覆子数、新規全子被覆の有無を出力する。負の試験は証明境界の根・葉・親の欠落・重複を拒否する。通常CIに登録した。

この局所的な被覆の拡大を7石・二石root・空盤の勝敗決着と混同しない。
