# K0867 — r=8の4/10族非坍縮予想を有限完全検査で反証

2026-11-16。K0866の最後に残された軽量課題、r=8での
`(4,4,10),(4,10,10) × γ=0..2` という2点外挿を検査した。

## 結果

予想は成立しなかった。

| 枝サイズ | γ | 正準プロファイル数 | 決定プロファイル | 全プロファイルの可能生存者 |
|---|---:|---:|---:|---|
| (4,4,10) | 0 | 20 | 0 | {3,7} |
| (4,4,10) | 1 | 10 | 0 | {3,7} |
| (4,4,10) | 2 | 4 | 0 | {3,7} |
| (4,4,10) | 3 | 1 | 0 | {3,7} |
| (4,10,10) | 0 | 51 | 0 | {3,7} |
| (4,10,10) | 1 | 32 | 0 | {3,7} |
| (4,10,10) | 2 | 15 | 0 | {3,7} |
| (4,10,10) | 3 | 7 | 0 | {3,7} |

対象は合計140プロファイル。γ=0..2の6キーは、全プロファイルが非決定であるだけでなく、
各キーの共通核だけを持つ鎖プロファイルも同じ可能生存者集合 {3,7} を持つ。
したがって、K0866が予想した「鎖は決定側だが一部プロファイルが非決定」という
非坍縮は起きない。γ=3も同じ一様非決定状態だった。

## 完全性と独立照合

3枝の7原子を、3つの単独原子・3つの二枝専用原子・三枝共通原子に分ける。
枝サイズ ((C_1,C_2,C_3)) と共通核 (gamma) を固定すると、
二枝専用原子 (a_{12},a_{13},a_{23}) を選べば単独原子は

[
s_1=C_1-gamma-a_{12}-a_{13},quad
s_2=C_2-gamma-a_{12}-a_{23},quad
s_3=C_3-gamma-a_{13}-a_{23}
]

に一意に定まる。条件 (s_ige1) を満たす全組を列挙し、枝の置換 (S_3) で正準化した。
この列挙は対象キーの全プロファイルを覆う。

ゲーム値は二方式で照合した。

1. K0866の領域ゲーム再帰（元検証器のGit blob SHAを固定）。
2. 終局順序を保持せず、生存者集合をビット集合で返す独立再帰。

140プロファイルと8鎖プロファイルの全てで可能生存者集合が一致した。
r=8のプロファイル再帰は各エンジン合計1,465,293状態、鎖は各4,767状態、
単一プロファイルの最大は57,739状態。予算打切りは0。

さらにr=7の既知陽性対照を再計算した。K0866の分割
((4,4,9)): 16/20, 7/10, 2/4、
((4,9,9)): 39/45, 22/28, 7/13
を再現し、γ=3の鎖は両族とも非決定だった。これにより、単に全てを非決定と返す実装ではないことも確認した。

## 結論の範囲

これは有限完全な**対象族の反証**である。r=8・枝サイズ上限10の全715キーを走査したものではない。
従って「r=8に非坍縮キーが存在しない」とは主張しない。今回否定したのは、
K0866から外挿された二つの4/10族だけである。

領域ゲームが実盤面のREMOを正確に表すことはK0861の定理E′に依存する。
r=8でのセル単位全探索は行っていない。11×11空盤の値にも影響しない。
