## 直接被覆恒等式ゲート（λ=5..9、DFS完全不使用）

covered_λ := 禁止四点組を少なくとも1つ含むλ点部分集合の個数 と定義すると、Z_n(λ) = C(N,λ) − covered_λ が定義レベルで成立する。covered_λ をヒストグラムDFS機構と無関係に直接計数し、出版 Z_n(λ) を独立検証する:

- **Z_7(5) = C(49,5) − covered5 = 1,906,884 − 273,836 = 1,633,048** — `scripts/z4z5_identity.mjs`（quartet+余剰1セルの直接集合構成）。n=3..6 も全一致 (56 / 2,360 / 37,272 / 301,952)。
- **Z_7(6..8)**: covered6/7/8 = 5,187,216 / 56,211,944 / 394,050,338 → Z_7(6..8) = 8,796,600 / 29,688,640 / 56,927,728 — `scripts/z678_identity.mjs`（λ点集合を組合せ数体系 colex 順位でビットセットに直接刻印し popcount。ランク式の全単射性は小N全列挙の単体検証、popcount表にも検証付き）。n=3..6 も含め15/15点全一致（`output/z678_identity.jsonl`）。
- **Z_7(9) = C(49,9) − covered9 = 2,054,455,634 − 1,999,282,310 = 55,173,324** — `scripts/z9_identity.mjs`（同一方式、quartetレンジ4シャード実行 + ビットセットファイル永続化。監査モードで永続ビットセットから最終行を再導出）。n=3..6 も全一致 (0 / 0 / 100 / 438,952)（`output/z9_identity.jsonl`, `output/z9_n7_shard_log.jsonl`）。
- まとめ: **λ=0..9 の10係数すべてが、3実装DFSとは独立な直接被覆計数で出版値と一致**。残る λ=10..14 は3実装交叉+総数アンカーで支えられる（λ=10 の直接被覆は covered10 刻印サイクル約51.9Gで次回候補）。

## 方式と独立検証（3実装 × 分散統合 × 総数アンカー）

1. **系統1（cov増分法）**: `scripts/safehist_n7.mjs` — dfs_py.py `--safehist` と同一セマンティクス（安全接頭辞木を昇順セルDFSで全走査し cov/stInF を増分管理）。**n7 全走行2回が byte 同一**（`output/hist_n7_run{1,2}.jsonl`, sha 同一）。さらに **初手セルによる7分割シャードを並走**し union が全走行と係数単位で完全一致（`output/unite_check_n7.json`, `output/shards/`）。シャードは「各安全集合の最小セルが一意」により全体を恰好に分割する。
2. **系統3（マスク法）**: `scripts/safehist_mask.mjs` — cov/stInF 機構を使わない第三実装（現在の石集合を明示ビットマスクで持ち、セルが置けない ⟺ それを含む禁止四点組の「他3点」マスクのいずれかが現マスクに含まれる、をその場で判定）。n=3..6 較正 + **n7 完全走行で系統1と全15係数一致**（`output/mask_hist_n7.jsonl`）。
3. **系統2（Python複製実装）**: `scripts/dfs_py.py --safehist` — K1228 出版機材のsolete化を避けるため本実験で浅く複製した同一セマンティクスの独立実装。**n=3..6 の33係数が K1228 出版スペクトルと全桁一致**（`output/py_safehist_n{3..6}.json`）。n7 は本環境での CPython 実行時間制約（推定〜1時間）により完全走行を見送り、**n7 の値は系統1×2走行+シャードunion+系統3完全走行+総数アンカーで確定**とする（過大主張なし: Python による n7 直算は行っていない）。
4. **n3..n6 較正**: 系統1・系統3・系統2の3実装とも K1228 出版の Z_3..Z_6 全33係数に一致（総数 298/5,811/151,394/5,081,289 = K0004 出版値）。`output/hist_n{3..6}.jsonl`, `output/mask_hist_n{3..6}.jsonl`。

決定性: 全出力ファイルは乱数・時刻を含まない逐次テキストで、再実行は byte 同一（cmp 検証済み）。
