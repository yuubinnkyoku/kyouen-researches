# 標準11×11：終局LOSS葉12件から9石LOSSを拡張

2026-10-24。標準q=4、完全指摘、通常プレイ、**元先手固定視点**。
標準11×11空盤の勝敗は **UNKNOWN**。

独立終局証明済みの9石WIN根113件が生む10石WIN葉2,074件を再利用し、
10石葉から一手戻した9石候補16,711件を調査した。
既知の9石WIN根を除いた候補を被覆数順に並べ、上位1,500件について
合法な10石子の不足数を調べると、不足8件以下の候補は12件だった。
その12件では、未分類の10石子の中にそれぞれ少なくとも1件の**LOSS**があり、
9石AND節点は12件ともLOSSと確定する。

12件の10石LOSS証人は `s10-loss12.keys` に、9石根との対応は
`s9-loss12-witness.tsv` に固定した。C++の4×4整数行列式による終局再帰と、
Pythonの独立3×3整数幾何・部分集合終局再帰の双方で12葉すべてLOSS、
合法手数不一致0。C++の個別探索状態数合計338。

| 項目 | 結果 |
| --- | ---: |
| 今回終局証明した10石LOSS葉 | 12 |
| 9石LOSS証人付き根 | 12（既存427葉由来との重複1） |
| 既存427葉と合算した10石LOSS葉 | 439 |

| 被覆対象の8石候補 | 17,338 → **17,798**（+460） |
| 被覆が増えた8石候補 | **490** |

| 新たに閉じた8石LOSS | 0 |
| 既知113個の9石WINとの矛盾 | 0 |

最も不足が少ない変化先8石候補は
`00000010001000001a00001020100000`（17子中11子をLOSS被覆、残り6）。
ただし**既に9石WIN子を持つ8石WIN局面**なので、8石LOSS証明候補には
採用できない。`audit.py` はこの既知WINの排除も確認する。

## 再現

リポジトリ直下で実行：

```sh
bash research/experiments/n11-s9-loss12-frontier-20261024/reproduce.sh
```

既存の独立C++終局検証器を再コンパイルし、12葉を再計算して固定表と照合。
Pythonの別幾何・終局再帰で再検査し、改変した勝敗行を拒否する。
`audit.py` は既存385+39+12=427葉の**既存証明を前提**に、
12葉追加後の9石LOSS逆向き閉包、8石被覆、既知WINとの無矛盾を再計算する。
過去のcacheの勝敗を新証明の前提にはしない。

12葉の独立終局証明と、過去427葉の証明を前提とする逆向き被覆の監査は
**別の検証境界**である。新たな8石LOSS、二石root、空盤勝敗は確定していない。
