# p2539: 残る18点gateの全153組と二つの非鏡像相互制約（2026-11-11）

採用時の正本はK0734。同じ1258点seed S（SHA-256 `454f0e293fd846aa6616dd45500dbaf9b325834408ec7f69234852e3e35e22fb`）と、
原点・完全対{6,2533}を保持し、Sから高々五点を失う安全集合Tを対象とする。
前回の124点除外・18点gateを変えず、gate内の二点同時追加を調べた。
**153組中7組を独立排除し、146組には提供障害族だけをhitする削除証人を得た。**
後者は安全な改善証人ではない。SAT探索や同じUNKNOWN仮定の再実行は行っていない。

## 障害族と独立検査

各組P={u,v}に対し、保存済み38868禁止四点のうち、S外の点が空でなくPに含まれる四点qを集める。
鏡像組u+v=2539には実四点{6,2533,u,v}も加える。
固定点F={0,6,2533}とすると、P⊆TならD=S∖Tは各q∖(P∪F)をhitしなければならない。
高々五点でhitできない負証明を、凍結済みhitting探索で生成し、探索をimportしない検査器で再構成・検査した。

`verify.py`は全153組の欠落・重複、seed・辺・前回qualification・source hash、各組の障害族と証明を照合する。
負7組は空障害5個・六つの互いに素な障害packing2個で受理した。分岐木は不要だった。
全組の族が用いる実四点の和集合45個を、generic整数4×4行列式検査で受理した。
辺cacheの完全性は仮定せず、必要障害だけから排除する。

排除組は次の通り。

五つの鏡像組は、保持する完全対の他に完全対を作るため禁止される。
非鏡像の{1027,1197}と{1927,2433}が今回の新しい相互制約。

## 二つの六障害packing

各行の四点が禁止四点であり、右欄のS内の点を少なくとも一つ削除する必要がある。
各組の六行の右欄は互いに素なので、必要削除数は少なくとも六点となる。

この二つのpackingの四点には固定点0,6,2533が現れず、右欄はq∖Pそのものである。
従って非鏡像二組の排除は、原点・元の完全対の保持を仮定しなくても、高々五点の種点削除だけから成立する。
元の18点gateのうち一つだけを含む候補は排除しない。五点削除改善の全体非存在や全体最大性は主張しない。
18個の既存point仮定はUNKNOWN、1258≤A(2539)≤1271のまま。

## 回帰と再現

実証明書の8改変を拒否し、小型hitting族495例を総当たりと照合した。
最初の回帰では、鏡像組の本当に空の障害を「偽の空障害」として選んでいたため受理された。
負制御を非鏡像packingの非空障害へ修正して全制御が成功した。検査器側の変更はなかった。

repo rootから既存出力を上書きしない新しいpathで実行する。

```powershell
$exp='research/experiments/parabola-p2539-gate-pair-obstructions-20261111'
uv run --locked python "$exp/produce.py" --output "$exp/output-fresh"
uv run --locked python "$exp/verify.py" --certificate "$exp/output/certificate.json" --output "$exp/audit-fresh"
uv run --locked python "$exp/regression.py" --output "$exp/regression-fresh.json"
```

次の候補はgate18点と他の追加候補点との同時追加障害を評価し、18点全てと両立しない点を正gateと結合して除外すること。
今回の146削除証人を安全集合として採用しない。
