# 容量ゲームの途中局面：到達可能終局閾値の下限訂正（2026-10-08）

## 経緯と反例

K0352 の途中局面向け公式 `b<=t<=B(x)` には、各列の上限 `m` に起因する下限 `r-(h-1)m` が漏れていた。反例は `(w,h,m,r,x)=(3,2,2,3,(0,0,0))`。旧公式は `t=0` を許すが、上位2列の和を3にするには最小列の高さが少なくとも1なので不可能。正しい終局閾値は `{1}` のみ。

## 無界の数学的訂正

`b=x_h`, `A(x)=max(b,0,r-(h-1)m)`, `F_x(t)=sum_{i<=h}max(x_i,t)`, `B(x)=max{t∈{0,...,m}:F_x(t)<=r}` とする。到達可能な全終局閾値は正確に `A(x),...,B(x)`。終局サイズは `r+(w-h)t` である。

閾値 `t` の極大配置は上位 `h` 列の和が `r`、最小列が `t`、下位が全て `t`。実現には `t>=b`, `F_x(t)<=r`, `r<=(h-1)m+t` が必要十分で、満たす場合は最小列を `t` に、他の上位列を `max(x_i,t)` 以上 `m` 以下で和 `r-t` に、下位列を `t` に増やして構成できる。単調な増加経路は全て合法となる。

## 全後続局面の二値Grundy条件

`n=w-h` が偶数、あるいは `A(x)=B(x)` のとき、かつそのときに限り、局面 `x` 以降の全局面は `g∈{0,1}` を満たす。式は `g(x)=(r+n*A(x)-|x|) mod 2`。この領域では全合法手でGrundy値が反転する。

逆に `n` が奇数かつ `B(x)>A(x)` なら、到達可能な終局サイズが奇数差 `n` の隣接二値を持つので、K0305 の逆向きにより必ずどこかの後続局面で `g>=2`。

終局一意の局所判定は `A(x)+1` を `F_x` に代入する。特に `b>=L=max(0,r-(h-1)m)` なら容量余裕 `sigma=r-sum_{i<=h}x_i` と最小値重複度 `c` に対し `sigma<c` と同値。一方 `b<L` では `r=hm-1` または `x_{h-1}=m` と同値になる。`sigma<c` を全域で必要十分とする以前のメモは撤回される。

## 奇数余剰列での非二値性：容量余裕1への明示的到達（2026-10-08）

K0352 の修正後の下限 `A(x)` と上限 `B(x)` を用いる。非自明な容量ゲーム `hm>r` で、`n=w-h` が奇数かつ `B(x)>A(x)` とする。このとき、**下位 `n` 列に一度も着手せず、上位 `h` 列へのちょうど `sigma-1` 手で容量余裕1の局面 `y` に到達でき、`g(y)` は必ず2または3**である。`sigma=r-sum_{i<=h}x_i`。

構成は `a=A(x)` とし、`i<h` について `y_i=max(x_i,a+1)`、`y_h=a`、`i>h` について `y_i=x_i` から開始する。その後、最初の `h-1` 列だけを増やして上位和を `r-1` にする。これは `F_x(a+1)<=r` と `r-1-a<(h-1)m` により必ず可能。完成後は `a=y_h<y_{h-1}<m` で余裕1なので K0358 を適用でき、

```
g(y) = 2 + ((n*a - sum_{i>h}x_i) mod 2).
```

上位和だけが `sigma-1` 増えたため、経路長は正確に `sigma-1`。安全配置族の下方閉性により、構成した `y` までの任意の単調増加順序が合法である。逆に `n` が偶数か `B=A` なら、K0352 によりどの子孫にも `g>=2` はない。よって、これは **後続に非二値Grundy局面が存在するための必要十分条件に、明示的な浅い証人を与える全称証明**である。

[check_slack_one_witness.py](check_slack_one_witness.py) は閉公式を使わずに、すべての着手を辿る別の mex 再帰で上記 `y` の Grundy 値を評価する。`3<=w<=8`, `2<=h<w`, `2<=m<=7`, `1<=r<hm` の全安全降順状態を対象に、該当する **491,084局面**すべてで予測と一致した（`g=2`: 309,454、`g=3`: 181,630、不一致0）。有限完全列挙は独立検証であり、無界の結論は上の構成と K0358 による。


## 容量余裕1にある非二値証人の閾値・Grundy値の完全分類（2026-10-08）

K0352 の修正された到達閾値を `A=A(x)`, `B=B(x)`、`sigma=r-sum_{i<=h}x_i>0`、`n=w-h` は奇数とする。`x` から下位 `n` 列を動かさず、上位 `h` 列だけに正確に `sigma-1` 手を使って到達する容量余裕1の局面 `y` のうち、`y_h=t<y_{h-1}<m` を満たす（K0358 の両境界型を持つ）ものを全て考える。

**定理（無界・全称）**：そのような `y` に現れる閾値の集合は厳密に `{A,...,B-1}` である（`A=B` なら空）。各閾値 `t` の証人は、全て

```
g(y) = 2 + ((n*t - sum_{i>h}x_i) mod 2)
```

を持つ。従って `B=A+1` なら値2または3の片方だけ、`B>=A+2` なら2と3が**同じ手数**で両方実現する。

**十分性。** `A<=t<B` なら `F_x(t+1)<=r`。上位 `h-1` 列を `max(x_i,t+1)`、第 `h` 列を `t`、下位列を元のままにする。上位和は `F_x(t+1)-1<=r-1`。また `t>=r-(h-1)m` なので、上位 `h-1` 列のみをさらに増やし、その総和を `r-1-t<(h-1)m` にできる。このとき `t=y_h<y_{h-1}<m` となり、K0358 により上式の Grundy 値を持つ。元の `x` を含み、下方閉性から到達経路はすべて合法で、長さはちょうど `sigma-1`。

**必要性。** この条件を満たす証人の `t=y_h` には、まず `t>=x_h`。上位 `h-1` 列のうち少なくとも一本が `m` 未満なので `r-1<=((h-1)m-1)+t`、よって `t>=r-(h-1)m`、すなわち `t>=A`。一方 `i<h` は `y_i>=max(x_i,t+1)` で、上位和が `r-1` なので `F_x(t+1)<=r`、したがって `t<=B-1`。奇数 `n` では閾値が1増えるたびに値2/3が反転する。□

**独立有限完全列挙。** [check_capacity_witness_spectrum.py](check_capacity_witness_spectrum.py) は K0358 の公式を使わない全合法手 mex 再帰と、構成公式に依存しない証人全列挙で調べる。`3<=w<=7,2<=h<w,2<=m<=5,1<=r<hm` の奇数 `n` の全安全降順局面（`sigma>0`）について：

```
PASS {'positions': 34785, 'interval_width_0': 9597,
      'witnesses': 83639, 'interval_width_1': 12978,
      'interval_width_2': 8370, 'interval_width_3': 3840}
EXAMPLES {'single': (3,2,2,2,(0,0,0),[2],0,1),
          'both': (3,2,4,4,(0,0,0),[2,3],0,2)}
```

`interval_width_3` は `B-A>=3` の意味。計算との不一致は0件。無界の定理の根拠は上記の数学的証明と K0358 であり、有限列挙は独立検証である。
