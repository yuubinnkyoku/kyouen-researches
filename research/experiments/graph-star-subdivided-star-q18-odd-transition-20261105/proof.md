# 一辺細分星 q=18 の奇数次数実根切替（2026-11-05）

## 定理（解析的全称証明＋厳密有理数不等式）

\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
について r=q-3=15、奇数 k≥3 とする。

1. q=18 では奇数 3≤k≤139 に実根はない。
2. q=18 では奇数 k≥141 に相異なる負の単実根がちょうど2個ある。
3. 任意の整数 q≥18、奇数 3≤k≤139 に実根はない。

## 証明

先行する q=17 の証明と同じ変数変換 u=-(r+1)y により、負の実根は 1<y<a=1+1/(r+1) に限られ、その零点条件は
\[
F_{k,r}(y)=r-y-(a-y)y^k=0
\]
となる。正の u に根はない。

r=15、a=17/16 とする。固定 y∈(1,a) で (a-y)y^k は k に関して単調増加する。k=139 で F>0 を示せば全奇数 k≤139 でも成立する。

H(y)=(a-y)y^{139} は [1,a] で一意の最大点 y_*=139a/140 を持つ。区間 [1,a] を50等分し、各 [l,h] で z=min(max(y_*,l),h) とすると H(y)≤H(z)。以下の厳密検査により全50区間で H(z)<15-h≤15-y を確認する。したがって k≤139 に実根はない。

k=141 では y=141a/142 を選び F_{141,15}(y)<0 を厳密に確認する。k を増すと F は減少するので全奇数 k≥141 にも負値が存在する。F(1)>0、F(a)>0 より少なくとも2実根がある。T_{k,r}(-x) の係数の符号変化は2回なので、デカルトの符号法則より重複度込みで高々2根。従って相異なる負の単実根がちょうど2個ある。

r≥15 では候補区間が (1,17/16) に含まれ、固定 y>1 で F_{k,r} は r に関して厳密増加する（偏導関数 1+y^k/(r+1)^2>0）。よって q≥18、奇数 k≤139 にも非存在が及ぶ。

## 再現（Python 3、浮動小数点不使用）

```python
from fractions import Fraction as Q

r, k = 15, 139
a = Q(17, 16)
star = a * k / (k + 1)
for i in range(50):
    l = 1 + (a - 1) * Q(i, 50)
    h = 1 + (a - 1) * Q(i + 1, 50)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = a * 141 / 142
assert 1 < y < a
assert r - y - (a - y) * y**141 < 0
```

**証拠区分:** 全称解析と50区間の有理数厳密不等式。一般 q の接触二重根不存在や格子盤の勝敗は主張しない。
