## 対象と探索

条件付き14個の7石証人計画は全合法7→8石着手548本のうち282本が既存の独立終局証明で確保され、未証明266本（相異なる266類）。これは7石WINを証明したことではない。

`survey.js` は、この266類を起点に9石候補6,123類を列挙し、未証明8石親を2類以上持ち、合法10石子が21類の候補138類だけを調査した。保存済みWIN/LOSSを終局の代用品にせず、3×3整数行列式による10石以降の完全再帰で判定した。

成功した短時間実験 [40442901028](https://github.com/yuubinnkyoku/kyouen-researches/actions/runs/40442901028) の測定値：

9類の根と各根の終局探索状態数を `certificate.tsv` に保存した。全合法9→10石辺は189本。証明書には子局面の勝敗表を保存せず、検証時に盤面から再列挙する。

## 独立検証

`verify.js` は証明書の9根について、3×3差分行列式と独立4×4 Bareiss法の両方で全合法10石子を再列挙し、全189辺を終局まで再計算する。二つの実装の勝敗・合法手数・探索状態数の一致、8→9石の合法な逆伝播、既知LOSSとの衝突なし、証明書改変拒否6件を確認する。

```sh
node research/experiments/n11-s9-targeted-gap266-20261027/survey.js
node research/experiments/n11-s9-targeted-gap266-20261027/verify.js --negative
```

独立検証に成功した場合、保存14根の未証明辺は266→250本、証明済み辺は282→298本となる。**250は固定14根の残数であり、再最適化による厳密最小値ではない。** 7石・5石・二石rootの新規閉鎖はなく、空盤UNKNOWN。
