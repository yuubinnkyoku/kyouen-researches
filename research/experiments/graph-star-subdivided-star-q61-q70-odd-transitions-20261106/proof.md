# 一辺細分星 q=61〜70 の奇数次数実根切替（2026-11-06）

## 結論（全称証明、境界は厳密整数計算）

\(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}\), \(r=q-3\), 奇数 \(k\ge3\) とする。以下の各 \(q\) について、\(3\le k\le k_-\) では実根なし、奇数 \(k\ge k_+\) では相異なる負の単実根がちょうど2個。

| q | 根なしの最大奇数 k_- | 2単実根の最小奇数 k_+ |
|---|---:|---:|
| 61 | 687 | 689 |
| 62 | 701 | 703 |
| 63 | 715 | 717 |
| 64 | 729 | 731 |
| 65 | 743 | 745 |
| 66 | 757 | 759 |
| 67 | 771 | 773 |
| 68 | 785 | 787 |
| 69 | 799 | 801 |
| 70 | 813 | 815 |

さらに、各行の非存在側は任意の \(q'\ge q\) にも成立する。

## 全称部分の証明

\(u=-(r+1)y\), \(a=(r+2)/(r+1)\) とする。正の \(u\) では全係数が正で根はない。負の実根は \(1<y<a\) に限られ、根方程式は
\[
F(y)=r-y-(a-y)y^k=0.
\]
実際 \(y\le1\) では \(r-y> a-y\ge(a-y)y^k\) （\(r\ge58\)）、\(y\ge a\) では \(r-y+(y-a)y^k>0\) が成り立つ（\(y\le r\) は自明、\(y>r\) では \((y-a)y^k>y-r\)）。

\(H(y)=(a-y)y^k\) は \(1<y<a\) で \(y_*=ka/(k+1)\) に最大値を持つ。各 \(k_-\) に対して厳密不等式 \(H(y_*)<r-a\) を下記で検証した。よって \(F(y)>0\)。小さい奇数 \(k\) では \(y>1\) 上の \(y^k\) が小さくなるため非存在は全 \(k\le k_-\) に及ぶ。\(q\) を増すと \(r-y\) が増し \(a\) が減るので、非存在側は任意の \(q'\ge q\) にも及ぶ。

各 \(k_+\) では厳密不等式 \(F(y_*)<0\) を検証した。\(F(1)>0\), \(F(a)>0\) より区間内に相異なる2実根が存在する。\(T(-x)\) の非零係数の符号変化は2回であるため、デカルトの符号法則より負の実根は重複度込み高々2個。したがって2根は単根で、他に実根はない。\(y>1\) で \(k\) を増やすと \(F(y)\) が減るので、同じ試験点で全奇数 \(k\ge k_+\) に拡張できる。

## 厳密整数検証（浮動小数点不使用）

\(A=k(r+2), B=(k+1)(r+1)\) とおく。非存在側 \(H(y_*)<r-a\) は
\[
(r^2-2)(k+1)B^k>(r+2)A^k
\]
と同値。存在側 \(F(y_*)<0\) は
\[
(rB-A)(r+1)(k+1)B^k<(r+2)A^kB
\]
と同値。次の独立実行可能なコードで20件すべてを整数比較し、成功を確認した。

```python
bounds = [(q, 689 + 14*(q-61)) for q in range(61, 71)]
for q, kp in bounds:
    r, km = q-3, kp-2
    A, B = km*(r+2), (km+1)*(r+1)
    assert B < A and A*(r+1) < (r+2)*B
    assert (r*r-2)*(km+1)*B**km > (r+2)*A**km
    A, B = kp*(r+2), (kp+1)*(r+1)
    assert B < A and A*(r+1) < (r+2)*B
    assert (r*B-A)*(r+1)*(kp+1)*B**kp < (r+2)*A**kp*B
print("20 exact inequalities passed")
```
