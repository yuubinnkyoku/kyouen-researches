# グラフ星型共円ゲームの葉・高次数核による全終局長公式（2026-11-03）

## 定理（全称数学的証明）

K0602 の整数共円・共線禁止 q 点構成を、少なくとも一辺を持つ任意有限単純グラフ G=(V,E) に適用する。孤立頂点も許す。e=|E|≥1、r=q−3≥1、N=1+|V|+re、最短極大石数 s=N−e とする。

L は「次数1で、隣接頂点の次数が2以上」の頂点数、h は孤立辺 K₂ の連結成分数、C=e−L−h とする。H={v∈V:deg(v)≥2} とおく。

B⊆H に対して、各 v∈B が V\B に隣接頂点を持つものだけを **許容核** と呼び、

- a(B)=∑_{v∈B} |{w∈N(v):deg(w)=1}|（B に隣接する葉の個数）
- d(B)=∑_{v∈B}(deg(v)−1)−e_G(B)

を定める。空核は許容され、a(∅)=d(∅)=0 とする。

**定理A（全終局長の局所核公式）**：極大安全配置の石数別母関数は

\[
\boxed{
P_{G,q}(u)=u^{N-1}
+u^s(r+2)^h
\sum_{B\subseteq H\text{ 許容核}}
r^{C+a(B)-|B|-d(B)}(r+1)^{L-a(B)}u^{d(B)}.
}
\]

表示した r の指数はすべて非負整数である。特に s+d 石の極大配置数は

\[
\boxed{
[u^{s+d}]P_{G,q}(u)=
\mathbf1_{d=e-1}
+(r+2)^h\!\sum_{B\text{ 許容核}:d(B)=d}
r^{C+a(B)-|B|-d}(r+1)^{L-a(B)}.
}
\]

**定理B（固定欠損の小核）**：許容核 B に対し |B|≤2d(B)。したがって、固定 d の係数は頂点数 n のグラフに対して高々 O(n^{2d}) 個の候補核を調べ、各候補を O(n+e) 時間で検査すれば厳密に計算できる。これは整数演算回数の粗い上界 O(n^{2d}(n+e)) であり、全分布を同時にこの時間で計算できるとは主張しない。

**定理C（最短直上の欠番判定）**：e≥3 なら **s+1 石の極大安全配置が存在することと、G に次数2の頂点が存在することは同値**。e=2 なら中心 O を含まない唯一の極大配置が s+1 石を実現する。e=1 なら s=N−1 が最長でもあるため s+1 石配置は存在しない。これらはすべての q≥4 に成立する。

## 証明

K0602 の極大配置分類で、中心 O を含む極大配置は、削除頂点集合 X⊆V が各頂点 v∈X に V\X 内の隣接点を持つとき、ちょうど r^{e_G(V\X)} 通りで、石数 N−|X|−e_G(V\X) である。X と V\X の交差辺数を δ(X) と書くと、最短からの差は

\[
d=e−|X|−e_G(V\X)
=e_G(X)+\sum_{v\in X}(\deg_{V\setminus X}(v)−1)\ge0.
\]

X に含まれる次数1の頂点は、その唯一の隣接点を X に含められない。したがって X の次数1頂点 Y は互いに独立で、次数2以上の頂点 B=X∩H にも隣接しない。孤立頂点は X に入れない。

逆に、許容核 B を任意に選び、B に隣接しない次数1頂点から独立な Y を選べば、X=B∪Y は必ず上の条件を満たす。B の各頂点は、葉の削除を許さないため、V\B に隣接点があることと V\X に隣接点があることが同値である。ゆえにこれが削除集合の重複のない分類になる。

この X について e_G(X)=e_G(B)、Y の各頂点は V\X にちょうど一つ隣接するので

\[
d=e_G(B)+\sum_{v\in B}(\deg_{V\setminus B}(v)−1)
=\sum_{v\in B}(\deg(v)−1)−e_G(B)=d(B).
\]

B に隣接しない非孤立辺の葉は L−a(B) 個あり、各々「残す重み1、削除する重み1/r」を持つ。孤立辺 K₂ ごとに両端を残すか片方を削除する三通りがあり、重み和は 1+2/r となる。したがって B 固定の重みの総和は

\[
r^{e-|B|-d(B)}(1+1/r)^{L-a(B)}(1+2/r)^h
=r^{C+a(B)-|B|-d(B)}(r+1)^{L-a(B)}(r+2)^h.
\]

すべての許された葉を削除し、各孤立辺で片端を削除しても安全な極大配置が得られるので、最右辺の r の指数はその配置の残存誘導辺数であり非負である。中心を含まない唯一の極大配置 u^{N−1} を足すと定理A。

B 内の孤立頂点（G[B] で次数0）は元の G で次数≥2なので、各々 \deg_{V\setminus B}(v)−1≥1。B 内で非孤立の頂点は高々2e_G(B) 個である。ゆえに

\[
|B|\le 2e_G(B)+\sum_{v\in B}(\deg_{V\setminus B}(v)−1)\le 2d(B).
\]

定理Bが従う。

d(B)=1 なら |B|≤2。|B|=1 では B={v}、d(B)=deg(v)−1=1 より deg(v)=2。|B|=2 で非隣接なら d(B)≥2、隣接なら d(B)=deg(u)+deg(v)−3=1 より両者次数2。逆に任意の次数2頂点 v は {v} が許容核で d=1 となる。中心なしの項は s+(e−1) に位置するので、e≥3 では s+1 に寄与しない。e=2,1 も上の通り。定理Cが従う。□

## 直上係数の具体的閉形式

a_v を v に隣接する次数1頂点数とする。e≥2 のとき

\[
\begin{aligned}
[u^{s+1}]P_{G,q}(u)
={}&\mathbf1_{e=2}+(r+2)^h\biggl[
\sum_{\deg(v)=2}r^{C+a_v-2}(r+1)^{L-a_v}\\
&+\sum_{uv\in E,\deg(u)=\deg(v)=2}
r^{C+a_u+a_v-3}(r+1)^{L-a_u-a_v}\biggr].
\end{aligned}
\]

例：三角形 K₃ では 3r+3、星 K_{1,3} では0、4頂点道 P₄ では 2r+3、孤立辺2本の和では1。すべての q≥4 で成立する。
