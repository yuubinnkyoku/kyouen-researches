# 三行二次形式版：69列以降の極大配置は3石か9石に限る

2026-10-24。知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。これは標準の共円ゲームではなく、退化も含めた \(\det[x^2+\lambda y^2,x,y,1]=0\) を禁止する通常プレイ。盤は \(D(3,m)=\{0,\dots,m-1\}\times\{0,1,2\}\)、\(\lambda\in\mathbb R\)。

**証拠区分：全称数学的証明。** 末尾の有限計算は独立監査であり、無界主張を計算から外挿していない。

## 定理（全係数に共通の二極化）

任意の実数 \(\lambda\)、任意の \(m\ge69\) に対して、極大安全配置の石数は **3または9** に限られる。4〜8石の極大配置は存在しない。

3石極大の存在は既存の等方直線定理で完全に分類されている。三行では \(\lambda=0\) または \(\lambda=-a^2\)（正整数 \(a\) かつ \(m\ge2a+1\)）の場合だけである。既存の \(K(3,m;\lambda)=9\)（全実数 \(\lambda\)、\(m\ge8\)）と合わせて、

- \(\lambda\notin\{0,-1,-4,-9,\ldots\}\) なら、**すべての \(m\ge69\)** で \(K=s=9\)、全安全局面 \(S\) の \(g(S)=(9-|S|)\bmod2\)。したがって \(M_{3,\lambda}\le69\)。
- \(\lambda=0\) または \(\lambda=-a^2\)（\(a\ge1\) 整数）なら、3石極大が任意に長い盤に残り、\(M_{3,\lambda}=\infty\)。特に \(m\ge\max(69,2a+1)\) では極大サイズはちょうど \(\{3,9\}\)（\(\lambda=0\) では \(m\ge69\)）。

従って **三行版の真の満容量安定化長が有限であるための必要十分条件** は
\[
\boxed{\lambda\notin\{0,-a^2:a\in\mathbb Z_{>0}\}.}
\]
有限な場合の *正確な* \(M_{3,\lambda}\) を69と主張するものではない。既知の一般型は15、標準 \(\lambda=1\) は24。

## 全称証明：不足行を塞ぐ列は高々68

どの水平行でも4点が禁止なので、安全集合 \(S\) の各行の石数は高々3。 \(|S|\le8\) なら、石数 \(k\le2\) の行 \(r\) がある。他の二行の石は合わせて高々6。

まず \(|S|\ge4\) なら、\(S\) 内の任意の3石の持ち上げベクトル
\[
L(x,y)=(x^2+\lambda y^2,x,y,1)
\]
は階数3である。もし階数が2以下なら、その3石と任意の第四石の行列式が0となり、\(S\) は安全でなくなる。

そのような3石 \(T\subset S\) が、行 \(r\) 上の新点 \((x,r)\) を禁止する条件は
\[
P_T(x)=\det[L(t_1);L(t_2);L(t_3);L(x,r)]=0
\]
である。これは \(x\) の次数高々2の多項式。しかも **恒等的には0でない**。仮に \(P_T\equiv0\) なら、持ち上げ三点の張る3次元超平面を定義する非零一次形式が、行 \(r\) のすべての点で0となる。この一次形式を \(A(x^2+\lambda y^2)+Bx+Cy+D\) と書けば、\(A=B=0\)、\(Cr+D=0\) なので、三点 \(T\) は全て \(y=r\) にある。しかし行 \(r\) の石は高々2で矛盾する。

行 \(r\) に既にある石を「新しく塞がれる列」と数えない。 \(T\) に行 \(r\) の石が \(j\) 個含まれると、それらの横座標は \(P_T\) の相異なる根なので、**新たに塞げる列は高々 \(2-j\) 個**。

- \(j=0\): 他行6石からの三つ組は高々 \(\binom63=20\)。うち各他行の3石だけからなる高々2組は \(P_T(x)\) が非零定数となり、行 \(r\) に根を持たない。上界は \(2(20-2)=36\)（両他行が3石の場合に最大）。一方が3石未満なら三つ組総数自体が高々 \(\binom53=10\) なので、この上界を超えない。
- \(j=1\): 高々 \(k\binom62\) 組で、それぞれ新たな根は高々1個。
- \(j=2\): 新たな根は0個。

従って行 \(r\) の既占有列も含めた使用不能列数は
\[
k+36+k\binom62\le 2+36+30=68.
\]
\(m\ge69\) なら行 \(r\) に必ず合法な追加点がある。 \(|S|=3\) でも持ち上げ階数3なら同じ議論を適用できる（石数上界はむしろ小さい）。階数2の三石のみが極大候補であり、その必要十分条件と係数分類は既存の等方直線定理による。 \(|S|\le2\) は \(m\ge69\) で明らかに延長可能。よって極大サイズは3か9だけ。□

\(\lambda\notin\{0,-a^2\}\) では三行格子に等方三石がないので、全極大配置が9石。全安全局面から任意の合法手を進めれば必ず9石に達するため、石数の降順帰納で上記Grundy式を得る。

## 独立した有限監査

外部依存なし。整数4×4行列式を24項の置換展開で直接計算する。

```sh
python3 research/experiments/quadratic-pencil-row-extension-20261024/verify.py
```

係数 \(-4,-1,-1/4,0,1/3,1/2,1,3/2,2\) と三行6列盤の全三点組について、階数3の場合の行上の二次多項式・非恒等零・既存点の根を **21,438件** 照合した。さらに69列盤の8係数・固定乱数種の計160安全局面（4〜8石）で実際に合法追加点を検出した。実行出力と照合済み。これらは **有限監査** であり、無界の結論は上の計数証明に依存する。

## 限界

69は単純な三点組の合併上界から得た**十分長さ**であり、真の最小閾値ではない可能性が高い。各半整数係数の正確な \(M_{3,\lambda}\)、短い盤の4〜8石極大の構造は未解決。11×11標準盤の勝敗には直接言及しない。
