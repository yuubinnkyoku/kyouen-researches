## 発見と証拠

元の証明書：research/experiments/n11-s8-targeted-closure-20261015/s8-loss-terminal.cert

対象8石LOSS根：00000000000040001000044400830000

10石LOSS葉で全子を被覆できる。保存済み勝敗を使わず二つの実装で
17葉を終局まで再計算した。

  **4×4整数行列式、Bareiss消去**、独立した合法手と終局再帰。

  既存のgap6独立検証器の**3×3整数行列式**と終局再帰を再利用。
- 17葉すべて元先手LOSS。両実装の合法手数・各葉の再帰状態数が一致。
  個別状態数合計 **12,241**。31/31義務を被覆。
- 4種類の証明書改変（葉の欠落、重複、盤面寸法、根の改変）を拒否。

## 再現

リポジトリ直下でPython 3.10以上、Node.js 22以上。外部依存は不要。

    python3 research/experiments/n11-s8-targeted-closure-20261015/verify_terminal_independent.py --negative
    node research/experiments/n11-terminal-s7-targeted-loss-union-20261024/audit.js
    NEGATIVE=1 node research/experiments/n11-terminal-s7-targeted-loss-union-20261024/audit.js

終局再計算を行う。旧gap6の580葉の終局勝敗は今回再計算せず、
以前の独立再計算結果を信頼境界として継承する。

Pythonの17葉は独立環境で実行して全件LOSS・状態数12,241を確認。
