# 11×11：8石候補の反対極性を13個の9石子で監査

2026-10-24。標準q=4、完全指摘、通常プレイ、元先手固定視点。
**11×11空盤の勝敗はUNKNOWN。**

既存439個の終局LOSS葉（385+39+12+12、重複除去）から導出した
9石LOSS 4,273件で、8石候補17,798件を逆向きに調べた。
既知の9石WIN 113根から導出した8石WIN 904件を除外すると、
38件の既知8石LOSS根以外で最小不足数は13だった。
その候補 `00000000041000001000501000102000` は
15個の合法9石子のうち2件がLOSS被覆済み、残り13件が未分類だった。

ところが、その13件を終局まで分類すると、**WIN 7件、LOSS 6件**。
したがって対象8石局面は、9石WIN子を持つ**WIN**であり、
8石LOSS候補ではない。この8石自体は凍結8石WIN 13,501件に既に含まれるが、今回は**終局までの独立証明**を新たに与えた。未被覆数をLOSS判定に読み替えてはならない。

## 終局証明と追加被覆

- 7個の9石WIN根について全合法10石子79辺、相異なる**63個の10石WIN葉**を再帰計算した。7根すべてWIN。
- 6個の9石LOSS根について、相異なる**5個の10石LOSS葉**を合法な証人として再帰計算した（1葉は2根で共用）。6根すべてLOSS。
- 計68個の10石葉を独立したC++の4×4整数行列式とPythonの3×3整数行列式・部分集合再帰で照合し、勝敗と合法手数の不一致0。局所再現でC++訪問状態数合計3,152、Python3,122。**状態数は探索順・対称性処理が異なるため同一値を要求しない**。
- 7個の9石WINのうち5個は凍結9石WIN 1,611件に含まれる。凍結集合との差分は**2個**。7根の全57個の8石WIN親のうち43件は凍結8石WIN 13,501件と重複し、既存113個の終局証明根由来904親とは重複0。比較集合との差分は**14個の8石WIN**。
- 新しい14個の8石WINは63個の7石親に**112本の独立終局証明由来の合法辺**を与える。これら63親のうち41件は従来の8石WIN比較集合からは到達しなかった。
- 5個の10石LOSS葉は既存439葉と重複0。逆向きに9石LOSSを**4,273→4,319件（+46）**、8石LOSS候補を**17,798→17,978件（+180）**に拡張。197候補の8石→9石LOSS被覆が**414辺**増加した。新たな8石LOSS全子閉包は0。
- 新しい9石WINと9石LOSSの衝突0、凍結8石LOSS294件と新8石WINの衝突0。いずれも明示した比較集合に対する値であり、全探索履歴との差分ではない。

## 独立再現

リポジトリ直下で：

```sh
bash research/experiments/n11-s8-frontier-13way-20261024/reproduce.sh
```

重複除去した68葉を出力する。既存の独立C++検証器を再コンパイルして
68葉を終局まで探索し、Pythonの別幾何・部分集合再帰で勝敗と合法手数を照合する。
既存の439葉は逆向き被覆の出所として使い、その勝敗の独立再計算は
**既存の各証明実験を前提**とする。凍結cacheは比較・矛盾監査にのみ使用する。
不完全な葉一覧と反転したC++勝敗行を拒否する負例試験も含む。
