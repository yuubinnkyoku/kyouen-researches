# K0824のq=2w境界は一様には延長できない

日付: 2026-11-15

## 全次元での反例

r=d−1≥1 とし、底面を標準単体

\[
B=\{0,e_1,\ldots,e_r\}\subset\mathbb Z^r
\]

とする。w=|B|=r+1、m=2、q=2w=2r+2 と置く。盤は

\[
X_2=B\times\{0,1\}\subset\mathbb Z^{r+1}
\]

であり、配置 S=X_2 は q 点を持つ。

B の r+1 点はアフィン独立である。従って底面の任意のアフィン超平面 H は B の高々 r 点しか含まない。各列の占有数は c_b=2 だから、全ての超平面跡 T=B∩H について

\[
\sum_{b\in T}c_b=2|T|\le2r=q-2\le q-1.
\]

つまりK0824の占有数条件だけなら S は安全と判定される。

ところが S の全点は、通常球面

\[
\boxed{
\sum_{j=1}^{r}(x_j-\tfrac12)^2
 +(z-\tfrac12)^2=\frac{r+1}{4}
}
\]

上にある。各座標は0または1なので各平方項が1/4となり、左辺は常に(r+1)/4である。S は q=2r+2 個の相異なる点からなるため、禁止配置そのものである。

従って、q=2w では超平面跡の占有数条件は安全性を特徴付けない。反例は全ての d≥2 に存在する。

## 帰結

K0824の q>2w は、任意の有限底面に対する一様な十分条件として、等号境界まで鋭い。q=2wを含む主張への単純な拡張は不可能である。

ただし、これは個別の底面に対して q>2w が必要条件という意味ではない。標準整数行では合同式などの追加構造を利用でき、K0072が q=2w の一部を扱う。今回の反例は、そのような特別構造を持たない任意底面一般に関するものである。

## 独立検証

`verify_boundary.py` は標準ライブラリだけで次を検査する。

1. B の拡大座標行列 [b,1] の有理数階数が r+1 である。
2. B×{0,1} の点数が q=2(r+1) で、重複がない。
3. 各点で整数化した球面方程式
   \[
   \sum_{j=1}^{r}(2x_j-1)^2+(2z-1)^2=r+1
   \]
   が成立する。
4. 超平面跡の最大サイズ r から、占有数和が q−1 以下となる。

r=1..12 は有限実行検査の対象である。無限次元での結論は、アフィン独立性と球面方程式による上の証明から従う。
