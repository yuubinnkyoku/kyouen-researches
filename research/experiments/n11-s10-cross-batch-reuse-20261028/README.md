## 証拠と再現

- `reuse.js` は第22・23子群、第24子群と短子群、第2〜7回の凍結証明書を再構築する。各証人の順序・ハッシュ・WIN/LOSS数を照合し、10石葉のWIN/LOSS衝突を即時拒否する。
- 10石から石を1個取り除いた全9石親を正準化し、既知LOSS10子が実際に合法子であることを3×3差分行列式と独立4×4整数幾何の双方で再検査した。WIN9候補については全子一致が必須。
- `report.json` は集計の固定値、`derived-loss9.json` は383類の9石鍵・LOSS10証人鍵・元証明書の参照を保存する。次回はこの383類を再探索しない。
- `plan_next.js` は既調査32類と383類を除外し、包含関係による削減と決定的な貪欲選択・1対1交換を実行する。`plan.json` は次回の候補順序とSHA-256を固定する。50類は**潜在被覆**であり、WIN8や勝敗証明ではない。

```sh
node research/experiments/n11-s10-cross-batch-reuse-20261028/reuse.js
node research/experiments/n11-s10-cross-batch-reuse-20261028/plan_next.js
```
