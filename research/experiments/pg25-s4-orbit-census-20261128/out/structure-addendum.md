# 追記: 高対称軌道の幾何学的特徴付け (2026-11-28・同日第2commit)

本体census (13軌道) に続く構造解析。すべて PG(2,5) での有限全数計算・PGL(3,5) (372,000)
作用下的な主張であり、一般 q への外挿はしない。ただし構成自体は一般 q で定義可能で、
個数の一致は群計算 (位数/stabilizer) と独立組合せ計算の両方で確認した。

## 1. orbit16-2 (3,100個・安定化群 120) = 「conic ∪ その内部点」

**主張**: size-16 の 3,100 軌道は、ちょうど各非退化 conic (楕円・6点oval) に対して
「conic の 6 点 ∪ その内部点 10 点 (接線を 1 本も含まない点)」として得られる。
3,100 = PG(2,5) の conic 総数 = 372,000/120 (conic の stabilizer ≅ PGL(2,5)・位数 120)。

**検証** (すべて機械確認):
- 構成例 (conic y²=xz): S = conic∪internal は 16 点・4-safe・極大 safe。
  直線プロファイル {1:6, 3:10, 4:15} (接線 6 本が 1 点、conic の 0-secant 10 本が 3 点、
  secant 15 本が 4 点) = orbit16-2 の hist [0,6,0,10,15] と一致。
  size-16 の 6 軌道の中でこの hist は orbit16-2 に一意 → 構成例は orbit16-2 に属する。
- stab(S) = stab(conic) (集合として等しい・位数 120)。群 BFS 372,000 全要素から
  conic の stabilizer を直接計数 → 120・conic 軌道サイズ 3100。
- 構成の対偶: S から conic と internal は回復可能 (internal = S 内の「接線を含まない点」)。

## 2. orbit16-5 (3,875個・安定化群 96) = 「三角形の辺に全く乗らない点」

**主張**: size-16 の 3,875 軌道は、ちょうど各三角形 T (非共線 3 点) に対して
「T の 3 辺 (sideline) 上にない点すべて (16 点)」として得られる。
3,875 = PG(2,5) の三角形総数 (C(31,3) − 31·C(6,3) = 4,495 − 620 = 3,875)
= 372,000/96 (三角形の stabilizer 位数 6(q−1)²/gcd 補正なしで 96・機械計数)。

**構成の直接証明** (任意の三角形で成立・組合せ論的):
- 辺 3 本は S と交差 0。辺でない直線 L は各辺と 1 点で交わる。T の頂点を通る
  辺でない直線は頂点が 2 辺の交点として二重計上されるため L∩(辺の合併) は
  2 点 → |L∩S| = 4 (頂点あたり 4 本 × 3 = 12 本)。それ以外は 3 点 (16 本)。
  プロファイル {0:3, 3:16, 4:12} = orbit16-5 の hist [3,0,0,16,12] (6 軌道中一意)。
- 極大性: 辺上の点 p を追加すると、p と対頂点を結ぶ直線 (辺でない・頂点を通る)
  が 4 点を含むため 5 点になり違反。4-safe も同プロファイルから自明。

**検証**: rep の 0-secant 3 本がその頂点三角形の辺と完全一致、S が辺外点集合と
完全一致、stab(S) = stab(T) (位数 96)、三角形総数の独立計数 3,875。

## 3. size-13 軌道 (15,500個・安定化群 24) と 4-arc (frame)

**観察 (機械確認・構成の完全記述は未取得)**:
- rep の stabilizer (24) の点軌道構造: 3 + 6 + 12 + 4 + 6。3-orbit は三角形
  (frame の対角三角形か)、4-orbit は 4-arc (frame)。
- stab(S) = stab(4-arc) (集合として一致)。
- **PG(2,5) の 4-arc 総数の独立計数 = 15,500 = 軌道サイズと一致**
  (C(31,4) − 「共線 3 点組を含む 4 集合」31·C(6,3)·25 − 31·C(6,4) = 15,500)。
- S13 = (3-orbit) ∪ (4-orbit) ∪ (6-orbit) の合併。6-orbit の幾何学的意味は未特定。
- orbit15-4 (15,500個・stab 24) の stabilizer は点軌道 1+3+3+12+12 (不動点あり)
  で frame stabilizer とは別型の S4 部分群。こちらは 4-arc 対応ではなく
  「不動点 + 2つの三角形軌道」構造。15,500 = #4-arcs との一致は偶然の可能性も
  含め未解釈のまま記録する。

## 帰結

orbit16-2 と orbit16-5 の 2 軌道 (6,975 集合) は古典的対象 (conic・三角形) で
完全に特徴付けられた。size-13 軌道は frame (4-arc) との stab 同一性と個数一致が
確認されたが、frame からの S の明示構成は次回課題 (対角三角形 + 6-orbit の特定)。
