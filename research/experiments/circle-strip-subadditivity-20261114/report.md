# 円の連続行窓点数 P(w) の劣加法性と漸近密度上界

## 定義

P(w) は、標準整数格子の真円が連続する w 本の整数水平行に含む格子点数の最大値とする。横方向の幅 m は制限しない。P(0)=0 と定める。

## 定理（全称）

全ての a,b≥0 について P(a+b)≤P(a)+P(b)。従って P(w) は非負の劣加法列であり、Fekete の補題から

λ = lim_{w→∞} P(w)/w = inf_{k≥1} P(k)/k

が存在する。K0804 の全称結果 P(82)=32 を使うと 0≤λ≤32/82=16/41≈0.390244。

## 証明

真円と固定した水平整数直線との交点は高々2点なので P(w)≤2w。従って P(w) は各 w で有限である。

任意の真円 C と連続する a+b 本の整数行の窓 I を取る。I を互いに素な先頭 a 行 I_a と残り b 行 I_b に分割すれば、

|C∩I| = |C∩I_a| + |C∩I_b| ≤ P(a)+P(b)。

C と I は任意なので最大値を取って劣加法性を得る。a=0 または b=0 は P(0)=0 から自明である。

Fekete の補題を適用し、極限 λ の存在と下限表示を得る。K0804 の P(82)=32 を代入すれば λ≤16/41。

## 全幅に対する明示的上界

w=82k+r（k≥0、0≤r<82）とする。劣加法性と各行2点上界から

P(w)≤kP(82)+P(r)≤32k+2r
≤(16/41)w+5346/41<(16/41)w+131。

よって単に極限上界だけでなく、全 w に対する明示的な線形上界も得られる。

## 追加の厳密値 P(83)=34

K0791 の円

(2x−105)²+(2y−105)²=11050

を取る。整数点のうち y=0..82 にあるものは、行

{0,1,5,6,9,12,19,23,28,30,42,50,55,63,75,77,82}

に各2点ずつ、合計34点である。従って P(83)≥34。

一方、全称劣加法性と既知の P(82)=32、P(1)=2 から

P(83)≤P(82)+P(1)=32+2=34。

よって

**P(83)=34**

が全称的に確定する。上界は円の探索ではなく行窓分割だけから従い、下界は上記の明示円が与える。

## 有限表の独立照合

pw_circle_point_max.csv の w=2..83 の82行、全行 proved-exact、P(82)=32、P(83)=34 を確認した。P(1)=2 と P(0)=0 を補い、a+b≤83 の3,570組全てで劣加法不等式を検査し、違反0件。既知範囲 w≤83 での最小比率 P(w)/w は引き続き w=82 の16/41である。

追加の検証器は、上記の円の奇数座標解を整数演算で直接列挙し、0..82行の34点・17二重行を再確認する。この有限検査は明示 witness と表の整合性を確認するものであり、全称上界は劣加法性の証明に依存する。

## 未解決の境界

λ の正確な値は不明で、λ=16/41 は主張しない。λ=0 も排除していない。P(84) 以降の正確な値も未確定である。P(83)=34 は λ の上界を改善せず、既存の M_{w,q} の真の安定化長を新たに確定する結果でもない。
