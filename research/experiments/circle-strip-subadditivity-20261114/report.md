# 円の連続行窓点数 P(w) の劣加法性と漸近密度上界

## 定義

P(w) は、標準整数格子の真円が連続する w 本の整数水平行に含む格子点数の最大値とする。横方向の幅 m は制限しない。P(0)=0 と定める。

## 定理（全称）

全ての a,b≥0 について P(a+b)≤P(a)+P(b)。従って P(w) は非負の劣加法列であり、Fekete の補題から

λ = lim_{w→∞} P(w)/w = inf_{k≥1} P(k)/k

が存在する。K0804 の全称結果 P(82)=32 を使うと 0≤λ≤32/82=16/41≈0.390244。

## 証明

真円と固定した水平整数直線との交点は高々2点なので P(w)≤2w。従って P(w) は各 w で有限である。

任意の真円 C と連続する a+b 本の整数行の窓 I を取る。I を互いに素な先頭 a 行 I_a と残り b 行 I_b に分割すれば、
|C∩I| = |C∩I_a| + |C∩I_b| ≤ P(a)+P(b)。
C と I は任意なので最大値を取って劣加法性を得る。a=0 または b=0 は P(0)=0 から自明である。

Fekete の補題を適用し、極限 λ の存在と下限表示を得る。K0804 の P(82)=32 を代入すれば λ≤16/41。

## 全幅に対する明示的上界

w=82k+r（k≥0、0≤r<82）とする。劣加法性と各行2点上界から
P(w)≤kP(82)+P(r)≤32k+2r
≤(16/41)w+5346/41<(16/41)w+131。

よって単に極限上界だけでなく、全 w に対する明示的な線形上界も得られる。

## 有限表の独立照合

pw_circle_point_max.csv の w=2..82 の81行、全行 proved-exact、P(82)=32 を確認した。P(1)=2 と P(0)=0 を補い、a+b≤82 の3,486組全てで劣加法不等式を検査し、違反0件。既知範囲 w≤82 での最小比率 P(w)/w は w=82 の16/41だった。

この有限照合は表の整合性検査に限られる。全称劣加法性は有限計算ではなく、上記の行窓分割による証明である。

## 未解決の境界

λ の正確な値は不明で、λ=16/41 は主張しない。λ=0 も排除していない。また P(w)=32 が w>82 で続くとも主張しない。既存の M_{w,q} の真の安定化長を新たに確定する結果でもない。
