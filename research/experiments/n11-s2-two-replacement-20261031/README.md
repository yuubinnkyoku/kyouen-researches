# 11×11二石root {60,27}：2個追加・3個除去による31クラス被覆の全列挙

## 目的と範囲

既存の二石LOSS証明は、119第三手を32個の既知LOSS4クラスで覆う。32クラスはいずれも固有の第三手を持つため、そのまま間引くことはできない。2026-10-17の既存研究では、**1個の未知S4クラスを追加して既知2個を除去**する31クラス案を全列挙し、4案中3案が既知WIN、残る1案には94個の未判定S5子があると確定している。

本実験は重複を避け、**2個の新しいS4クラスを追加し、既知3個を除去**する31クラス案を全列挙した。これは証明費用を下げる候補を選ぶための構造監査であり、新しいLOSS4や二石rootの勝敗を証明するものではない。

## 結果（2026-10-31）

| 指標 | 値 |
|---|---:|
| 全合法S4正準クラス | 3,384 |
| 既知LOSS4 | 32 |
| 追加候補（既知32以外） | 3,352 |
| 幾何学的に成立する2追加・3除去案 | **548** |
| 548案に現れる相異なる追加候補 | 313 |
| 313候補のうち保存済みWIN5子があるS4 | 97 |
| WIN5子が見つからないS4候補 | 216 |
| 2候補ともWIN5子が見つからない31クラス案 | **174** |
| 174案の最少・相異なる未判定S5子 | **185** |

最も未判定子が少ない案は、新規S4
`00000000000000009100000000000400` と
`00000000000000001200000018000000`
を使い、既知S4
`00000000000000009100000000000001`、
`00000000000000009200000000000001`、
`00000000000000101000000018000000`
を外す。新規2クラスの未判定S5子は94件と91件、共有0件で計185件。**一クラス置換案の94件より多い**。したがって、少なくともこの固定した既知32クラスから1〜2クラスを追加して31クラスへ縮約する方法では、現存する二つのS5 cacheに対する未判定依存数は1クラス置換の方が小さい。

未判定子数は探索費用や終局証明書サイズを表さない。2クラス追加で既知3クラスを外せれば、既知側の終局依存が減る可能性もあるため、総費用最小性は主張しない。新規クラスの勝敗もすべてUNKNOWNのまま扱う。

## 再現

```sh
node research/experiments/n11-s2-two-replacement-20261031/verify.js
```

固定Git blob 3件をSHA-1で照合し、64-bit整数を丸めずに解析する。3×3差分行列式、D4対称性、119第三手の被覆、既知32クラスの固有第三手、全3,384合法S4クラス、全2追加候補対（3,352個からの5,616,276組）、3除去の被覆を再計算する。S5子は幾何から再生成し、二系統のexact cacheを矛盾検査つきで統合する。WIN5子が1個でもあれば候補S4はLOSSになれないため除外し、残りの相異なる未判定S5子を数える。

証明の信頼境界：WIN5/LOSS5は保存された厳密探索のラベルであり、今回終局まで独立再探索していない。未知のS5はWINにもLOSSにも置き換えない。標準11×11空盤の勝敗は **UNKNOWN**。
