# 5x21 q=7 class-split: independent record and coverage audit

Date: 2026-11-15.

This audit checks the published run records and the completeness bookkeeping. It does not
re-run Kissat and does not replace a DRAT/LRAT proof certificate.

## Raw-log reconciliation

The 52 entries in `output/records.jsonl` were compared with the 52 raw Kissat logs committed
in the two raw-log batches. Every entry agrees on:

- final status (SAT / UNSAT),
- conflict count,
- process time (within the JSON record's two-decimal precision).

Result: **52/52 exact matches; 0 missing logs; 0 mismatches**.

The 51 m=21 entries are all UNSAT: 17 direct deficiency classes, 32 exact-count/minpos
subinstances for classes {0} and {1}, and 2 column-reflection lex cross-checks. The sole m=18
entry is the SAT positive control. The m=21 conflict total independently recomputes to
28,617,104.

## Independent coverage checks

There are 31 non-empty subsets of five rows. Quotienting by row reflection
\(y\mapsto4-y\) gives exactly 19 classes. The 17 direct classes are precisely all classes
except {0} and {1}; those two are covered by the split records.

For each of {0} and {1}, the records contain exactly one instance for each deficient-row
occupancy \(k=0,1,2,3,4\), followed by one instance for each recorded minpos
\(p=0,1,\ldots,10\) when \(k=5\). Thus the published 16-way split per class is complete.

A sharper elementary bound shows that two of those eleven minpos cases are empty. If
\[
0\le x_1<x_2<\cdots<x_k\le m-1,
\qquad p=\min(x_1,m-1-x_k),
\]
then
\[
x_k\ge x_1+k-1\ge p+k-1,
\qquad x_k\le m-1-p,
\]
so
\[
\boxed{p\le\left\lfloor\frac{m-k}{2}\right\rfloor}.
\]
For \((m,k)=(21,5)\), this gives \(p\le8\). The independent enumeration of all
\(\binom{21}{5}=20,349\) five-column subsets also finds no case with \(p>8\).
Consequently, the recorded p=9 and p=10 subinstances for each of {0} and {1} are vacuous
UNSAT cases. They are harmless, but future sweeps can omit them.

## Sharpening the threshold disjunction

Let \(M=M_{5,7}\) be the least threshold such that every width \(m\ge M\) has no
row-deficient maximal safe configuration. A 29-stone witness at width 18 gives \(M\ge19\).
The machine result gives no such configuration at widths 19, 20, and 21.

If \(M\le22\), then all widths \(m\ge M\) are witness-free by definition, and the already
checked widths among 19, 20, 21 fill the finite gap down to 19. Hence every width \(m\ge19\)
is witness-free and the least threshold is \(M=19\). Otherwise \(M\ge23\). Therefore the
stronger logical alternative is
\[
\boxed{M_{5,7}=19\quad\text{or}\quad M_{5,7}\ge23.}
\]
This is a deduction from the definition of the least eventual threshold and the consecutive
witness-free band; it is not an additional solver result. The general upper bound 158 is
unchanged, and widths \(m\ge22\) remain unresolved by this audit.

## Reproducibility and trust boundary

Run from this directory with:

```sh
node scripts/audit_records.js
```

The script checks raw-log/JSONL agreement, all 19 row-reflection classes, the exact k/minpos
record partition, the lex cross-checks, the positive control, aggregate conflicts, and the
sharper minpos bound.

This remains finite machine evidence. In particular, this audit does **not** independently
validate the geometric census, prove the CNF encoding correct for every assignment, or check
UNSAT proof traces (no DRAT/LRAT certificates are part of these records). The status remains
`computed`, not a number-theoretic proof.
