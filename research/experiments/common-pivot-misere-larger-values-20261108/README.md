# 共通pivotのmisère補助値をさらに大きくする有界探索

K0694の変換で使うリンクグラフの0/1制限ゲーム値tを、辺変更で大きくする。
入力は既知の十四頂点・t5グラフ、目的はt6以上。
不発見は上界や不存在を意味しない。

`search.cpp`はC++17でコンパイルし、頂点数、試行上限、目標t、入力ファイルを渡す。
入力の先頭は元頂点数と辺数、以降は二点辺mask。新しい頂点は孤立点として追加する。
seedは20261108。出力の候補は別Pythonと全占有subsetで再検査するまで知識へ昇格させない。

十六点リンクでt6を得て、十九合法点h8・二十合法点h9を別C++でも確認した。
[証明と無界性の同値帰着](proof.md)、[独立検査](verify.py)、[検査結果](output/audit.json)。
無界性そのものはK0696で予想として記録し、有限達成と区別する。
