## 証明・依存関係

先行 q=171〜180 の解析的補題を用いる。\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とすると負根条件は \(F_k(y)=r-y-(a-y)y^k=0\)。根候補は \(1<y<a\) に限られ、\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大になる。

非存在境界 \(k_-\) で \(H_{k_-}(y_*)<r-a\)、存在境界 \(k_+=k_-+2\) で \(H_{k_+}(y_*)>r-y_*\) を確認する。後者は \(F_k(1),F_k(a)>0\) と中間値の定理により少なくとも2根を与え、デカルトの符号法則によりちょうど2単根となる。正根は存在しない。\(1<y<a\) で \(H_k(y)\) が k に関して厳密増加するため、奇数次数の境界の外側にも拡張できる。

\(A=k(r+2),B=(k+1)(r+1)\) とおき、非存在側は
\((r^2-2)(k+1)B^k>(r+2)A^k\)、
存在側は
\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)
を確認する。\(B<A\) も同時に検査する。

## 再現用の厳密整数検証

```python
rows = [
    (181,2511),(182,2529),(183,2545),(184,2561),(185,2577),
    (186,2593),(187,2609),(188,2625),(189,2641),(190,2659),
]
for q, km in rows:
    r = q - 3
    for k in (km, km + 2):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if k == km:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
        else:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
    print(q, "PASS")
```
