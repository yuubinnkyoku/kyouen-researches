# p2539: 正18点gateによる97点の被覆排除（2026-11-11）

採用時の正本はK0734。同じ1258点seed S（SHA-256 `454f0e293fd846aa6616dd45500dbaf9b325834408ec7f69234852e3e35e22fb`）の五点削除改善を対象とする。
前回の必要条件は、原点・完全対{6,2533}を保持し、124点を避け、空対から残る18点Eの少なくとも一点を追加すること。
**新たに97点を独立排除し、総除外を221点へ強化した。Eは同じ18点のまま。**
SAT探索や既存のUNKNOWN仮定の再実行は行わず、保存済み幾何辺と有限hitting証明を使った。

## 20502個の新しい二点仮定

S外1281点のうち、既除外124点とEの18点を除く1139点をuとし、vをEの18点全てに動かした。
E内153組は前回済みなので再実行せず、新しい20502組だけを処理した。
各{u,v}について、S外の点が空でなく{u,v}に含まれる提供禁止四点qと、
保持する完全対から得られる四点{6,2533,u,2539−u}（鏡像がS内の場合）を集める。
P={u,v}⊆T、F={0,6,2533}⊆Tなら、D=S∖Tは各q∖(P∪F)をhitする必要がある。

凍結済みhitting探索は96903 callsで全組を完了し、5010組を排除、15492組には必要障害族だけの削除証人を得た。
後者は安全集合でもSATモデルでもない。
新規97点は全18組が排除された点であり、他の1042点には少なくとも一つの未排除gate組が残る。

## 正gateによる被覆論証

改善Tは既存の必要条件よりT∩E≠∅を満たす。
uが新規97点の一つでu∈Tなら、あるv∈T∩Eを選べる。
この{u,v}の障害族は高々五点ではhitできない独立負証明を持つため、D=S∖Tの存在に反する。
従ってu∉T。この論証はTの点数に依存せず、大きな改善Tにもそのまま成立する。
被覆の18仮定は互いに排他的である必要はないが、一つも欠けてはならない。

## 独立監査と限界

`verify.py`は探索をimportせず、凍結された独立single-family実装と、別に構成した二点外部辺のindexで各族を再構成する。
全1139点と各18gateの欠落・重複、seed・辺・前回qualification・source hashを照合する。
5010負証明はpacking7439・branch2056 nodeを独立受理し、15492削除証人も各族に対して確認した。
全族が参照する4891四点をgeneric整数4×4行列式で実検査した。辺cacheの完全性には依存しない。
実証明書の8改変（point欠落、gate被覆欠落・重複、偽の空障害、空の削除証人、除外点欠落、誤gate、誤予算）を拒否した。
既存hitting探索・検査器の小型495例総当たり回帰は前回experimentへsource hashで接続する。

正18点gateは以前の独立監査・数学的接続を引き継ぐ。新しい97負point単位節のnative RUP導出は作っていない。
親CNFや五点削除近傍全体のUNSAT、安全な1259点改善証人、A(2539)=1258を主張しない。
以前の18個のpoint仮定はUNKNOWN、全体範囲1258≤A(2539)≤1271も不変。

圧縮証明書のraw SHAと圧縮SHAは`output/manifest.json`へ保存した。新しい出力pathを使い、既存証拠を上書きしない。
