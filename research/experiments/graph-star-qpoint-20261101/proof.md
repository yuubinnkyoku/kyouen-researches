# 任意 q≥4 のグラフ星型整数共円構成と最短極大配置（2026-11-01）

## 定理

整数 q≥4 と辺を少なくとも一つ持つ有限単純グラフ G=(V,E) を任意に取る。t=|V|、e=|E|、r=q−3、N=1+t+re。整数平面上の相異なる N 点 O、頂点点 V_v、各辺 ab の r 個の私有点 P_ab,j を配置して、共円・共線の禁止 q 点組を正確に

    H_ab={O,V_a,V_b,P_ab,1,...,P_ab,r}  (ab∈E)

だけにできる。

X⊆V の誘導辺数を e(X)、D(G)={X⊆V: 各 v∈X が V\X に隣接点を持つ}（空集合も含む）とする。全安全局面・極大安全局面の石数別母関数は

\[
 A_{G,q}(u)=(1+u)^{N-1}
 +u\sum_{X\subseteq V}u^{|X|}
 \bigl((1+u)^r-u^r\bigr)^{e(X)}(1+u)^{r(e-e(X))},
\]

\[
 P_{G,q}(u)=u^{N-1}+\sum_{X\in D(G)}r^{e(V\setminus X)}
 u^{N-|X|-e(V\setminus X)}.
\]

最短極大石数と最大安全石数はグラフの辺のつなぎ方に依存せず

\[
 \boxed{s=N-e=1+t+(q-4)e,\qquad K=N-1.}
\]

次数1の頂点のうち次数2以上の頂点に隣接する数を ℓ、両端次数1の孤立辺成分の数を h とすると、最短極大配置数は

\[
 \boxed{M_{\min}=r^{e-\ell-h}(r+1)^\ell(r+2)^h+\mathbf1_{e=1}.}
\]

孤立頂点（次数0）は ℓ に含めない。e−ℓ−h≥0。q=4 なら s=t+1、M_min=2^ℓ 3^h+1_{e=1}。q≥5 の完全グラフ K_t 族では t→∞ において s/N→(q−4)/(q−3) となる。

## 幾何実現の全称証明

K0601と同じく、O と頂点点 V_v を有理座標で一般位置に選び、各辺 ab に O,V_a,V_b を通る互いに異なる有理円 Γ_ab を割り当てる。各 Γ_ab は他の芯点を含まず、芯点の意図しない共円四点組・共線三点組もないようにする。これは有限個の真の代数的等式を避けることで達成できる。

各 Γ_ab に私有有理点を r 個ずつ順に追加する。Γ_ab は有理点 O を含むので無限個の有理点を持つ。候補点は、既存点との一致、他の割当円との交点、既存二点との共線、既存三点との意図しない共円を避ける。最後の条件では、既存三点がすでに Γ_ab 上にある場合だけ許す。それ以外の三点の円は Γ_ab と異なり、交点は有限個。各追加段階で除外候補は有限個だから選択できる。

完成後、共円四点組は必ずいずれかの割当円 Γ_ab 上にあり、共線三点組はない。相異なる円の交点は高々二点であり、各 Γ_ab に載る点はちょうど O,V_a,V_b とその r 私有点で合計 q 点。したがって禁止 q 点組は H_ab のみ。全有理座標の分母を一括して払う相似変換で整数化できる。

## 母関数と極値の全称証明

O がない集合は他の N−1 点を自由に選べる。O があり、選んだ頂点点が X のとき、両端点が X にある辺の r 私有点は全部を同時には選べない。各辺の因子はそれぞれ (1+u)^r−u^r または (1+u)^r となり A の式が従う。

極大安全集合の補集合 T は禁止辺族の包含極小横断集合である。O∈T なら T={O}。O∉T なら、T に入る頂点点を X とする。X に端点を持たない各辺から私有点をちょうど一つ T に入れ、X に端点を持つ辺の私有点は入れないことが極小性から必要。各 v∈X が必要なのは v が X 外に隣接点を持つ場合に限る。したがって X∈D(G)、私有点の選択数は r^{e(V\X)}、|T|=|X|+e(V\X) で P の式が従う。

X と V\X の間の辺数を δ(X) とすると、X∈D(G) なら δ(X)≥|X|。ゆえに

\[
 |X|+e(V\setminus X)=e+|X|-\delta(X)-e(X)\le e.
\]

X=∅ で等号成立なので s=N−e。等号成立には e(X)=0 と δ(X)=|X| が必要十分で、これは X が次数1の頂点からなる独立集合であることと同値。葉の独立集合を重み r^{e−|X|} で数えると、ℓ 個の非葉に隣接する葉が因子 (1+1/r)、h 個の孤立辺が因子 (1+2/r) を与え、

\[
 r^e(1+1/r)^\ell(1+2/r)^h
 =r^{e-\ell-h}(r+1)^\ell(r+2)^h.
\]

T={O} が最短に加わるのは e=1 の場合だけ。T={O} は常に K=N−1 を達成し、全点集合は安全でない。これで全称証明が完了する。

\]
