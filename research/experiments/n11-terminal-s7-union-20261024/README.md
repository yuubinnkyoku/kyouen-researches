## 独立証明済み局面の集合統合

既存の7群（29、27、2、10、7、20、7根）とK0528の18根を読み、
9石WIN **120根**を重複なしで統合した。9石はAND節点なので、各実験で
全合法10石子のWINが独立検証されていることを前提とする。
この120根を一手戻すと、D4正準化した8石WINは**961類**、
さらに一手戻すと7石候補は**3,337類**となる。

別に、既存の独立終局証明に由来する8石LOSS 35根とK0528の3根を
統合した**38類**を一手戻すと、7石LOSSは**268類**。
これらのうち上記3,337候補と重なる**15類**は、すでにLOSS証人を持つため
「全8石子WINで7石WINを証明する」候補から除外した。
8石WIN 961類と8石LOSS 38類の衝突は**0**。

7石3,337類の合法8石子を整数3×3行列式で全生成し、
961類との共通部分を再計算した。結果は次のとおり。

| 対象 | 合法子総数 | 証明済み8石WINで被覆 |
| --- | ---: | ---: |
| 着手位置を区別した辺 | 209,225 | **7,690** |
| D4正準化した親子類の辺 | 209,205 | **7,688** |

いずれも「3,337候補に属する7石親」だけを集計した値で、
全7石局面に対する被覆率ではない。今回の全子被覆による新規7石WINは**0**。

## 対称性を含めた次の候補

未被覆を着手位置で数えると最小は22だが、**対称類で数えると18**まで減る。
7石 `00000010001000009200001000100000` は鏡映対称性を持ち、
合法な着手位置40に対して相異なる8石子は20類のみ。
そのうち証明済み8石WINは2類で、**未確定18類**が残る。
この7石は上記38個の8石LOSS根からはLOSS証人を持たない。
ただし別系統の証明まで含めた全研究資産に対する未分類性は主張しない。

対称性を利用しない場合の最小不足22は
`00000010001000001800001020100000`（28手、被覆6手）。
以前の候補 `00000000100000021081000020000020` は
36手中33手がWIN被覆済みで不足3手だが、すでに8石LOSS子を持つ
**7石LOSS確定局面**なので、新規7石WINの候補にしてはならない。

D4正準化・整数行列式・合法子生成・親子類の重複除去を自前で実行する。

集合数・被覆数・最小不足数の退行を検査する。
入力の重複・欠落を拒否する負例試験も実施した。
