# 容量ゲーム：高さ増大時の終局分布は「完成対局一様」と「逐次合法手一様」で異なる（2026-10-08）

## 定理の範囲と用語

K0352の抽象容量ゲーム：ラベル付き列数 `w>h>=2`、上位 `h` 列占有数の和 `<=r`、`r>=1` は固定。各列に `m` 個の区別可能な着手点があり、一度置いた点には再着手しない。初期の安全石集合 `P` は固定し、その列別石数を `x=(x_1,...,x_w)` とする。高さ `m` を `m>=r` の整数で増加させる。元の石の位置は全ての高さで存在するとする。

`n=w-h`、`|P|=sum_i x_i` とし、K0352の到達終局閾値区間を `A=x_h<=t<=B` とする。ここで `m>=r` なので下限 `max(0,r-(h-1)m)=0`、上限 `B=max{t:sum_{i<=h}max(x_i,t)<=r}` も `m` に依存しない。閾値 `t` の終局石数は `T_t=r+n*t`、追加着手数は `ell_t=T_t-|P|` である。

以下の2種類の確率モデルを厳密に区別する。

- **完成対局一様**：現在局面から終局までの有限な合法着手列（物理的な点の違いと順序を区別）の集合から、それぞれ同じ確率で1列を選ぶ。途中着手は一般には等確率ではない。
- **逐次合法点一様**：現在の局面で合法な空き点を毎手一様に選び、終局まで繰り返す。完成対局全体の上で一様分布にはならない。

## 定理1：長さ別完成対局数は高さの多項式

閾値 `t` の終局で、各列の占有数が `y=(y_1,...,y_w)` となるラベル付きベクトル全体を `F_t(P)` とする。条件は `y_i>=x_i`、`top_h(y)=r`、`y_h^{sorted}=...=y_w^{sorted}=t`（最小値が `t` かつ上位 `h` 和が容量境界）、`0<=y_i<=r` である。 `m>=r` ならこの集合は高さと無関係で、K0352により区間内では空でない。

実際の終局盤面数と、完成した着手列数は K0361から

```
N_t(m) = sum_{y in F_t(P)} product_i binom(m-x_i, y_i-x_i),
H_t(m) = ell_t! * N_t(m).
```

各二項係数は整数 `m` の多項式（`m>=r` の範囲で上式と一致）。したがって **`N_t(m)` は正の最高次係数を持つ、厳密に次数 `ell_t` の多項式**で、最高次係数は

```
Lambda_t(P) = sum_{y in F_t(P)} product_i 1/(y_i-x_i)! > 0.
N_t(m) = Lambda_t(P) * m^ell_t + O(m^(ell_t-1)).
H_t(m) = ell_t! * Lambda_t(P) * m^ell_t + O(m^(ell_t-1)).
```

ここでは `m` に依らない有限集合 `F_t(P)` を使うため、漸近係数も有限和で正確に計算できる。

## 定理2：完成対局一様モデルは最長終局に集中する

`B>A` で複数の終局長が実現するとする。最大終局長は `ell_B`、次は `ell_{B-1}=ell_B-n` であり、`n=w-h>=1`。上の最高次係数の比較から

```
Pr_complete(t=B) = 1 - C(P)*m^(-n) + O(m^(-n-1)),
C(P) = (ell_(B-1)! * Lambda_(B-1)) /
       (ell_B! * Lambda_B) > 0.
```

特に最長終局以外の確率は `Theta(m^(-n))`。これは有限実験からの外挿ではなく、異なる終局閾値ごとの多項式の次数差が常に正確に `n` であることによる全称結論。`B=A` の場合は最長終局が初めから唯一の長さなので確率1。

## 定理3：逐次合法点一様モデルでは全到達終局長の極限確率が正

任意の後続局面 `z` において、現在の列占有数 `z_i` の列にある合法な空き点は `m-z_i` 個。`m>=r` のもとで次の着手に使えるラベル付き列集合 `L(z)` は高さに依存しない（全安全列の占有数は `<=r`）。従って、列 `i∈L(z)` が次に選ばれる確率は

```
Pr_m(i|z) = (m-z_i) / sum_{j in L(z)}(m-z_j)
          -> 1/|L(z)|  (m -> infinity).
```

どの完全着手列も長さが `<=r+n*floor(r/h)` の有限上界を持つので、分布全体もこの遷移確率の有限積・有限和として極限を持つ。極限では**各合法列を一様に選ぶ**有限ゲームの分布に一致する。

K0352により、区間内の各閾値には少なくとも一つ合法な完成着手列がある。その経路の極限確率は有限個の正の `1/|L(z)|` の積で厳密に正だから

```
Pr_sequential,limit(t) > 0   for every A<=t<=B.
```

`B>A` なら、完成対局一様モデルは最長終局へ集中する一方、逐次合法点一様では最長以外の総確率も正に残る。**2つの確率モデルは一般に一致しない。**

**巡回 s 人版**（`s>=2`）：今が非終局で最後の着手者を `P_(ell_t-1 mod s)` とすると、完成対局一様モデルは `P_(ell_B-1 mod s)` に収束集中する。他方、`s` が `n` を割り切らず、`B>A` なら、隣接終局長の最後の手番が異なり、逐次一様モデルの極限でも少なくとも二人の最終着手確率が厳密に正となる。ただし「最後の着手者」は最適戦略による勝者・均衡とは異なる。

## 完全に計算できる最小例

`w=3,h=2,r=3,P=empty,m>=3`。到達する終局サイズは3と4。

```
N_0(m)=3*binom(m,3)
N_1(m)=3*binom(m,2)*m^2
H_0(m)=3!*N_0(m), H_1(m)=4!*N_1(m)
Pr_complete(T=3)=(m-2)/(12*m^2+m-2) ~ 1/(12*m)
Pr_sequential(T=3)=(m-1)*(m-2)/((3*m-1)*(3*m-2)) -> 1/9
Pr_sequential(T=4) -> 8/9
```

後者の短い終局には、最初に選んだ列へ3手続けて着手することが必要十分である。2人版では短い終局の最後の着手者は先手、長い終局は後手。完成対局一様では後手へ集中し、逐次一様では先手・後手の極限確率はそれぞれ1/9・8/9。**この例の q=4,w=3 は q>2w を満たさないので抽象容量ゲームの例であり、幾何盤への直接の例ではない。** 幾何盤への全称移送は `q=r+1>2w` などのK0352条件を満たすパラメータに限る。

## 独立有限検証と限界

[check_height_bias.py](check_height_bias.py) はK0361の母関数実装を使わず、ラベル付き全終局占有数ベクトルを独立列挙して `N_t(m)` を直接和で作る。有限差分で次数 `ell_t` を検査し、`ell_t!` で割った最高次係数を別計算の `Lambda_t` と照合する。さらに合法列ごとの正確な遷移確率を `fractions.Fraction` で再帰評価し、無限高さの一様列極限でも全到達終局長の確率が正となることを検査する。

`3<=w<=5,` `2<=h<w,` `1<=r<=5` の**354局面・505終局閾値**について多項式の次数・最高次係数と確率正規化を全照合し反例0。例の `m=3,5,10,100` では逐次確率の閉式も独立再帰と全一致。有限検証は実装監査であり、無界な数学的結論は上の全称証明に基づく。

研究上の限界：これは固定 `w,h,r` で `m` を増やす確率分布。固定幅・q点版の勝敗安定化長、一般の11×11標準共円ゲームの勝敗、各プレイヤーの最適戦略を決める定理ではない。
