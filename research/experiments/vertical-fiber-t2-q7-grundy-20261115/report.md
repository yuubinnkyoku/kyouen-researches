# t=2・q=7 純ファイバーゲームのGrundy上限と最大値

## 設定と定理

有限非空集合 B、有限集合 A を取り、w=|B|≥1、m=|A|≥2 とする。底面跡制約は置かない。K0832の厳密占有縮約により、安全条件は Σ_b min(c_b,2)≤6、合法手は一成分を1増やしてこの不等式を保つ操作である。

全安全局面のGrundy値の最大値は
- 1（mが偶数、またはw≤3）
- 3（mが奇数かつw≥4）

である。Grundy値3の最小の幅・高さは w=4,m=3、証人は c=(3,2,1,0)。

さらに、底面跡制約のない t=2 純ファイバーゲームでは、禁止点数 q を任意にしても、m偶数なら全安全局面でG≤1、m奇数なら全安全局面でG≤3。

## 任意qの上界の証明

安全容量を一般の C=q−1 とする。占有数 c に対し、s=#{b:c_b≥2}、ℓ=#{b:c_b=1}、e=w−s−ℓ、R=C−2s−ℓ と置く。安全性からR≥0。

各 c_b≥2 のファイバーは、占有数 c_b から m まで進める長さ m−c_b の独立な鎖であり、そのGrundy値は (m−c_b) mod 2。従って飽和ファイバー部分の値は

    x = XOR_{c_b≥2} ((m−c_b) mod 2) ∈ {0,1}.

残る空・単独石ファイバーの部分を H_p(e,ℓ,R) とする。単独石ファイバーを2石に進めると、残容量を1消費し、長さm−2の鎖を残す。その値は p=(m−2) mod 2=m mod 2。空ファイバーを1石にする手も残容量を1消費するが、鎖はまだ生じない。

空ファイバー同士、単独石ファイバー同士は置換対称なので、各種類から生じる子のGrundy値はそれぞれ一種類だけである。従って

    H_p(e,ℓ,R) =
      mex({
        H_p(e−1,ℓ+1,R−1)       if e>0,
        p XOR H_p(e,ℓ−1,R−1)   if ℓ>0
      })

ただしR=0またはe+ℓ=0ならH_p=0。飽和鎖と残余ゲームは独立な和なのでG(c)=x XOR H_p(e,ℓ,R)。

mが偶数ならp=0。残余ゲームの各手は残容量Rと残り資源操作数2e+ℓをそれぞれ1ずつ減らす。空ファイバーは2操作、単独石ファイバーは1操作を残すため、どのプレイもちょうどmin(R,2e+ℓ)手で終わる。よってH_0=min(R,2e+ℓ) mod 2∈{0,1}、従ってG≤1。

mが奇数ならp=1。残余ゲームの合法手は「空ファイバー開始」「単独石ファイバー飽和」の高々2種類。同じ種類からの子は同じGrundy値を持つため、mexの対象は高々2個の異なる整数でH_1≤2。x≤1よりG≤3。以上で任意qの上界を得る。∎

## q=7の最大値の達成

w≤3かつm奇数なら、終局で容量6を使い切るには全ファイバーが満杯でなければならない。従って全終局の石数はwmで固定され、G=(wm−|S|) mod 2∈{0,1}。全ファイバー満杯から一つだけm−1石にした局面は、長さ1の鎖一本なので値1を達成する。

m偶数では一般上界からG≤1。c=(m−1,0,…,0) を取る。m≥4なら飽和鎖の値は1、H_0=min(4,2(w−1)) mod 2=0。m=2なら飽和鎖はなく、H_0=min(5,2w−1) mod 2=1。いずれもG=1。

m奇数かつw≥4ではc=(m,m−1,1,0,…,0)を取る。s=2、ℓ=1、e=w−3≥1、R=1、飽和鎖の値x=1。空ファイバー開始の子の残余値は0、単独石ファイバー飽和の子の値は1なのでH_1(e,1,1)=mex{0,1}=2。従ってG=1 XOR 2=3。上界と一致する。w=4,m=3で最小証人c=(3,2,1,0)。∎

## 独立した有限監査

遷移生成の異なる二方式を実装した。
1. ラベル付き占有ベクトルを直接列挙し、各座標を増やす全合法手から再帰mexを計算。
2. 正占有数を降順に並べた多重集合を独立に列挙し、異なる占有数の増加と新列開始だけから遷移を生成。

範囲は1≤w≤10、2≤m≤12の110組。

| 監査量 | 結果 |
|---|---:|
| ラベル付き状態の延べ数 | 3,809,674 |
| 占有多重集合状態の延べ数 | 18,117 |
| ラベル付き方式のGrundy値分布 | 0: 1,774,979 / 1: 1,748,855 / 2: 144,960 / 3: 140,880 |
| 多重集合方式のGrundy値分布 | 0: 8,784 / 1: 8,023 / 2: 745 / 3: 565 |
| 構造式との不一致 | 0 |

全110組で最大値の幅・高さ分類も一致した。検証器SHA-256は 4aaa2b0aaed3d3b0680f11f40c142404e867a0f9cf2622b69e778a1380c965c3。有限監査は再帰実装の照合であり、全称性は残余ゲームへの分離と上記の証明による。

## 適用範囲と限界

- 全称定理の対象は底面跡制約なし・t=2の純ファイバーゲーム。
- q=7の正確な最大値は全てのw≥1,m≥2に対するもの。
- 一般のqについて証明したのはGrundy値の上界であり、全局面の閉形式分類ではない。
- 底面跡制約あり、底面係数次数の制限あり、既約性制約ありの部分族にはそのまま適用しない。
- 標準二次元の3×m・q=7幾何ゲームの解決を意味しない。
