## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数。q_odd(k) は k を奇数に切り下げた値（k 奇なら k、
k 偶なら k-1）。q_odd(x+4) はマージ行のラダー上端である（S=x+4 の偶奇は x と
同じなので、実際には E[2, x+4]/ すなわち x 偶なら 2⌈(x+4)/2⌉-1 = x+4・
x 奇なら x+3）。

## 定理（値2集合 T_z(x)、値1集合 P_z(x)）

H(R;(x,4);z)=2 ⟺ R∈T_z(x)、=1 ⟺ R∈P_z(x)、それ以外で 0（R=0 は常に 0）。

### 値2位置 T_z(x)（常に奇数位置＋高々1つの孤立pin／掃引帯）

z 奇数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-5 | O[1, q_odd(x+4)]（単一トークン値そのもの） |
| x=z-4 | O[1, z+4]（対角行 S=z の連続上端） |
| x∈{z-3, z-2, z-1, z+1, z+2, z+3} | O[1, z] |
| x=z | O[1, z] ∪ {z+6}（前倒し孤立pin） |
| x=z+4 | O[1,z] ∪ {z+8} |
| x=z+5 | O[1,z] ∪ O[z+8, 2z+9]（掃引行） |
| x>=z+6 | O[1,z] ∪ {z+8} |

z 偶数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-5 | O[1, q_odd(x+4)] |
| x=z-4 | O[1, z+3]（対角行 S=z、連続上端） |
| x∈{z-3, z-1, z, z+1, z+3, z+4} | O[1, z-1] |
| x=z-2 | O[1, z-1] ∪ {z+5}（前倒し孤立pin） |
| x=z+2 | O[1, z-1] ∪ {z+7}（前倒し孤立pin） |
| x=z+5 | O[1,z-1] ∪ O[z+9, 2z+9]（掃引行） |

そのまま適用される。例: z=0 では x>=z+6=6 行の pin は {9}、掃引行 x=5 の
帯は O[9,9]={9}、x=4 行（対角行かつ z-4 行）は O[1,3]、マージ行 x<=-5 は空）。
奇数 z の掃引帯 O[z+8, 2z+9] は孤立 pin {z+8}（=定常 pin 2y+z）と
帯本体 O[z+10, 2z+9]（下端 2y+z+2）の和に等しい（z=9・x=14 では
{17}∪O[19,27]）。これは単一オーナー宣言ノートの予備観察
「奇数zの掃引帯下端が 2y+z+2」の全 z 版である。

### tail

全 z>=0・x>=4 で R >= x+z+5 のとき H(R;(x,4);z) = (x+4) mod 2。
すなわち奇数 x 行は tail で 1、偶数 x 行は tail で 0（y=4 では値1無限帯が
奇数 x 行に反転し、y=2・y=3 と逆になる。tail 値式 (x+y) mod 2 が
y の偶数性で切り替わるため）。tail 開始 x+z+5 = x+z+y+1 は y=2・3 と
同じ族式（下記「横断観察」）。

## マージ系（対角線下・y=4 の全称昇格）

x<=z-5（すなわち S=x+4 <= z-1 < z）の全行で

  H(R;(x,4);z) = single_token(x+4, z, R)  （K0832 出版単一トークン閉形式）

が全 R>=0 で成り立つ。明示的には値2位置は O[1, q_odd(x+4)]、値1位置は
x 偶 のみ I[x+5, ∞)、行全体が z 非依存になる。K1101 が y∈{1,2} で全称証明し
y>=3 を有限センサス観察（2トークン y=1..40・z<=40・348,270点・不一致0）に
とどめていたマージ命題の y=4 版が、本定理の閉形式から直ちに従う
（single_token の z>=S+1 場合とマージ行の T/P が一致する。S=x+4 の偶奇が
x と同じなので、S 奇（x 奇）の行が値1無限帯 I[q_odd(S)+1,∞)
= I[x+5,∞) を持ち、S 偶（x 偶）の行は値1なし（tail「奇数 x 行は tail
で 1」と整合する）。監査機械は全グリッド・probe 点でこの系を直接照合した
（総 1,991,409 点・不一致 0）。

## 選択肢分解と x=4 での合流

R>=1 のとき

- A = H(R-1; (x-1,4); z)（x>=5；x=4 では 2 つの減少手が同一多重集合
  (3,4)≡(4,3) 子に合流し A≡B = H(R-1;(3,4);z) = cand3(z,4,R-1)、
  すなわち K1104 の z 行 x=4 閉形式。H は多重集合にしか依存しない）
- B = H(R-1; (x,3); z) = cand3(z, x, R-1)（K1104 全称閉形式）
- C = 1 ⊕ H(R-1; (x,4); z-1)（z>=1）

であり H(R;(x,4);z)=mex{A,B,C}（z=0 では C なし）。

## 値の構造（y=2..4 の横断観察・一般称主張ではない）

- **値1基底点 y 点仮説の y=4 確定**: 基底点は y 個 {z+1, z+3, ..., z+2y-1}
  が y=1..4 の全称表で確定（y=4 は本項。y=2 は K1099・y=3 は K1104）。
  全称確定は y<=4。y>=5 は予想。
- **tail 開始式 x+z+y+1 の確定（y=2..4）**: y=2 の x+z+3・y=3 の x+z+4・
  y=4 の x+z+5 が族式 x+z+y+1 で統一される（3族連続の全称確定）。
  K1104 が「y=4 の全称表が決め手」とした未解決のうち y=2..4 帯は決着。
  tail 値 (x+y) mod 2 も 3 族連続（y 偶で値1無限帯が奇数 x 行に反転）。
- **pin の偶奇分離（y=3→y=4 の変化）**: 奇数 z の前倒し pin 2y+z-2 は
  行 x=z-1（y=3）から行 x=z（y=4）へ移動（位置式 x=z+y-4 が
  y=3・y=4 で一致）。偶数 z の y=4 は前倒し pin が 2 つ（{z+5} が x=z-2 行・
  {z+7} が x=z+2 行）に増え、y=3（{z+5} の x=z+1 行のみ）と構造が変わる。
  定常 pin は奇数 z 2y+z・偶数 z 2y+z+1 で y=2..4 共通。
- **掃引行 x=z+y+1 と帯 O[2y+z, 2z+2y+1]（奇z）/O[2y+z+1, 2z+2y+1]（偶z）**:
  y=2..4 共通の族式。y=4 では帯下端の偶奇依存が消える（奇z でも
  2y+z に孤立 pin が乗る形で帯本体は 2y+z+2 から）。
- **中間帯（値1）**: 本項では O_z[2y+z+2, x+z+y] = O_z[z+10, x+z+4]。
  ひとつ上の式 x+z+y は y=3（x+z+3）とも一致し、族式の候補。
- **対角行 S=z（x=z-4）**: 奇数 z 上端 O[1, 2y+z-4]=O[1,z+4]（y=3 の
  横断式 2y+z-4 の直接延長）・偶数 z 上端 z+2y-5=z+3…は y=3 の
  z+2y-3=z+3 と同じ位置式偶 z 2y+z-5（y=3: z+3 は 2y+z-3 とも読める。
  偶 z: y=3 上端 z+3 = 2y+z-3・y=4 上端 z+3 = 2y+z-5 で、偶 z 対角上端は
  z+定数で y 非依存の初の反例）。対角行の値1は z 偶奇によらず常に空。
  （K1100 が z=19 で観測した交差式 2y+q_o(z-y)=8+15=23 の位置。
  本項の奇 z 表では x=z-4 上端 z+4 で、d=x-y=z-8 の格子式
  r=2y+(d+z)/2 は z=19 では 2y+(15)/2→端数ケースは d+z≡2 mod 4 の
  要件を満たさず適用外。格子規則は z=19 の実例のまま一般証明ではない。）

## 信頼境界

- 全称性の根拠は、(i) 選択肢分解がゲーム定義そのものであること（raw錨）、
  (ii) 恒等式が正確な mex 再帰であること（有限完全グリッド＋型ごと照合）、
  (iii) 実現型空間が有限でボックス内に証人を持つこと（完全列挙＋シェル・
  多様体・遠方probe・深掃引の新規型ゼロ）、の 3 点であり、K1023/K1099/K1104
  と同じ trust 境界に立つ。Lean 形式化ではない。
- 有限監査は転写・実装照合であり、それ自体が全称性の根拠ではない。
- H の定義（Theorem T・単一トークン閉形式）は K0832 に、B 子の評価は
  K1104（さらに K1099・K1023）に依存する。それらが成立する限りで本項は
  成立する。
- 本項は y=4 のみを証明する。y>=5 族・3トークン以上・基底点 y 点仮説の
