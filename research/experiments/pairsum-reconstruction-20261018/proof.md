# 無順序二点和による点集合復元：2の冪がちょうど例外

2026-10-18。**証拠種別：全称数学的証明。** 有限列挙は独立の監査に過ぎない。

## 定理（実数・整数）

`n≥2` とし、重複を許す実数 `n` 個の多重集合 `X` から、`i<j` の `n(n−1)/2` 個の和 `x_i+x_j` を重複度込みで集めた多重集合を `P(X)` と書く。

1. `n` が2の冪でなければ、`P(X)` は `X` を一意に決める（全称）。
2. `n=2^h (h≥1)` なら、`P(X)=P(Y)` かつ `X≠Y` となる、互いに異なる整数からなる `n` 点集合 `X,Y` が存在する（任意の `h`）。

従って、`n≥2` での写像 `X↦P(X)` の全域単射性は「`n` が2の冪でない」と同値。これは古典的な二点和復元問題の結果を、この研究の同和弦energyの記法で記したものであり、数学史上の新発見とは主張しない。

## 1. 2の冪以外での全称一意性

`p_k=Σ_i x_i^k`、`p_0=n`、`Q_k=Σ_{i<j}(x_i+x_j)^k` とする。二項定理から

```
2Q_k = Σ_{j=0}^k C(k,j)p_j p_{k−j} − 2^k p_k
     = (2n−2^k)p_k + Σ_{j=1}^{k−1} C(k,j)p_j p_{k−j}.
```

`Q_k` は `P(X)` から直接計算できる。`n` が2の冪でなければ、`k=1,...,n` のすべてで `2n−2^k≠0`。ゆえに上式で `p_1,p_2,...,p_n` を順に一意復元できる。Newtonの恒等式により `p_1,...,p_n` から `∏_i(T−x_i)` の全係数が定まり、その根の多重集合 `X` も一意に定まる。□

## 2. 2の冪での無限族の明示構成

初期値を `A_1={0,3}`、`B_1={1,2}` とする。両者は異なる2点集合で `P(A_1)=P(B_1)={3}`。

一般に `A,B` は互いに異なる同じ大きさ `m` の有限整数集合で `P(A)=P(B)` とする。両集合の要素を同時に平行移動して非負とし、`t>max(A∪B)` を取る。

```
A' = A ∪ (B+t)
B' = B ∪ (A+t)
```

とおく。低い区間と高い区間が重ならないため、`A',B'` は各 `2m` 個の相異なる整数を含み、低い区間に現れる `A≠B` から `A'≠B'`。

`P(A')` を三種類の組に分けると、

```
P(A') = P(A) ⊎ (P(B)+2t) ⊎ (A+B+t)
P(B') = P(B) ⊎ (P(A)+2t) ⊎ (B+A+t)
```

となる（`⊎` は多重集合和、`A+B` は全 `a+b` を重複度込みで列挙）。仮定 `P(A)=P(B)` と交換法則 `A+B=B+A` により `P(A')=P(B')`。従って `m=2,4,8,...` と再帰すれば任意の2の冪について反例が得られる。□

最小例（`n=4`）：`A={0,3,15,16}`、`B={1,2,14,17}`。さらに4点の場合、総和 `T` が偶数なら `x↦T/2−x` という補集合変換でも同じ二点和多重集合を与える。これは `i,j` と残りの2点 `k,l` の組が `T−(x_i+x_j)=x_k+x_l` を満たすためである。

## 3. 共円ゲームへの直接の帰結

同一直線上の石集合 `X` について `r_X(s)=#{i<j:x_i+x_j=s}` と置く。同和弦の自己energyと交差energyを

```
H(X)=Σ_s r_X(s)^2,  E(X,Y)=Σ_s r_X(s)r_Y(s)
```

とする。`H(X)+H(Y)−2E(X,Y)=Σ_s(r_X(s)−r_Y(s))²` だから、`H(X)=H(Y)=E(X,Y)` なら `r_X=r_Y`。そのとき `|X|=|Y|=n` が2の冪でなければ `X=Y`。逆に `n` が2の冪なら、**異なる整数集合であっても全ての相手集合 `Z` に対して `E(X,Z)=E(Y,Z)` となる**例が存在する。

特に3平行線・6点禁止で使う5石弦の同和多重集合は石集合を一意に決めるが、4石弦（5点禁止版）や8石弦ではその論法は使えない。**energyの一致は円の幾何的同一性を意味しない**（弦積などが異なる）。

```

```

限界：`n` が2の冪のとき全ての `X` に曖昧性があるとは主張しない。整数座標格子での「共円配置としての」実現性や、3平行線の真の安定化閾値はこの定理からは直接決まらない。
