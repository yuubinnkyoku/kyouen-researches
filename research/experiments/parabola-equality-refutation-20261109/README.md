# 全奇素数での剰余放物線等号予想の反証

現在の結論は [K0101](../../knowledge/items/K0101-prime-parabola-equality-open.md)。
本実験は、既にコミットされたp=2647の完全監査を読み、全称命題に対する論理的帰結を確認する。
SAT探索やDRAT検査は再実行していない。

## 反証の論理

`Q_p = {(t,t² mod p): 0<=t<p}` の最大安全サイズを `A(p)` とする。
元の主張は「全奇素数pで `A(p)=(p+3)/2`」。K0097の一般上界とK0334の等価により、
等号集合は原点・一完全対 `{d,p-d}`・他対の一側という形を取り、あるdのCNFのSATと同値である。

奇素数2647ではh=1323。K0706の全d=1..1323のUNSAT証明が修正版検証器で受理されているので、
`A(2647)<=1324<1325=(2647+3)/2`。よって元の全称命題は偽である。
p=2207の監査完了や他のすべての素数の分類を待つ必要はない。
この帰結は `A(2647)=1324` を意味しない。

## 受理記録の確認

入力はコミット `b52faa12b77ff8bae9cf5343b20f3561917381a6` に保存された監査記録と検証器ソース。
作業中の他処理の未コミット変更は使わない。
`verify_receipts.py` は全1323 dの一意な被覆、全件のUNSAT・正常終了・VERIFIED、
検証器ソースSHA-256と入力記録のSHA-256を確認する。
欠落・重複・範囲外d・素数違い・ソース違い・未検証・異常終了・出力違い・UNKNOWN・空証明の
10個の改変をすべて拒否する。

```powershell
uv run --locked python research/experiments/parabola-equality-refutation-20261109/verify_receipts.py
```

結果は `receipt_coverage.json`。証明総行数8,038,838行、1件10〜52,650行、検査0.2〜79.3秒。
受理記録のSHA-256は `bc838b7273d1115803f98847b06ab392b6e3573f70c3b69cb76f85b1023908bd`。

## 信頼境界

本実験の確認は受理記録の整合性検査であり、個々のDRAT証明の再検査ではない。
幾何からCNFへの等価はK0334、計算の実行記録はK0706に依存する。
修正版検証器にも実装とコンパイラへの依存があり、一般的な健全性の形式証明は行っていない。
K0707で不具合が見つかった旧検証器の受理記録は、今回の反証の根拠に使わない。
