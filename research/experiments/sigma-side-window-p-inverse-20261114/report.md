# 側窓σ(n)=min{w:P(w)≥n} の全称決定 — n≤34（2026-11-14・高速レーン・K0823）

## 背景

- K0785（中心窓bestK・E/Z/O族）・K0791（11050円witness・レジューム2「σ₁₇の直接決定」・
  R′≤10⁸で34点最小幅83）・K0817（P(83)=34・P(1)=2・劣加法性）。
- 本実験の観察: **位置自由の窓**について σ(n) := min{w: ある円が w 連続整数行に n 点を持つ}
  は、P(w) の定義（全円・全窓位置の最大）より **σ(n) = min{w: P(w) ≥ n}** が恒等的に成り立つ。
  P表（w=2..83・全行 proved-exact）が既に完備しているため、**n=2..34 の σ(n) は追加計算なしで
  全称確定**する。中心窓版（窓が円の行中心を含む・全実現族）も n=26..34 で同値。

直接計数。P は非減少（w行窓⊆w+1行窓）なので min は well-defined。

## 中心窓版（n=26..34）

σ^center(n) ≥ σ(n) は自明（中心窓⊆全窓）。witness 窓は中心行を含む:
2210円 52.5∈[34,76]・11050円 52.5∈[0,82]・650円 12.5∈[0,25]。
K0785 の E族中心窓 bestK(K=13..17) = 43,44,46,48,83 とも完全一致。
よって **σ^center(n) = σ(n)（n=26..34・全実現族）**。K0785 の族別値（Z族58等）は
族別の量としてそのまま。n<26 では主張しない（小幅 witness 窓は中心を含まない
場合がある。例: 10円の w=3 窓 {−1,0,1} に中心行 1.5 は含まれない）。
