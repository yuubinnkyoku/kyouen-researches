# σ_Z(3,K) の fold 分解と値1位置の特徴付け（ONE-CHAR）・K≡2 (mod 4) 非存在（A2-NEVER）・run-bump 高速算

date: 2026-11-18
status: 本文中の補題・定理はすべて紙上全称証明。機械的証拠は sigmaz3_verify.py /
audit_build.py（監査 output/sigmaz3_audit.json）+ deep_census.py（深いセンサス・
2回実行 byte-identical）。

## 0. 設定と依存

K0941 定理C・定理D（pinned・composite_core.py byte同一 sha256 3990d67f…）の
σ再帰を前提にする:

- σ_E(P;α,β): k=α+β人・holdings [P]^α+[P+1]^β・pot P。各フェーズ
  q,r=divmod(P,k): r<α → (P+q; α−r−1, β+r)、r≥α → (P+q+1; β+2α−r−1, r−α)。
  生存者の入口フレーム位置は逆向き再帰 σ_旧=(r+1+σ_新) mod k（基底 k=1 で σ=0）。
- σ_Z(M,K): K人全員保持M・pot M。1フェーズ後 E(M+q; K−1−r, r) で
  σ_Z(M,K)=(r+1+σ_E(M+q, K−1−r, r)) mod K。

K0941の残課題として「σ_Z(3,K)（K偶数・K≤4,000）の値1位置 4,8,12,28,40,52,72,…
は単純な倍数構造に乗らない」が挙げられていた。本項はこれを閉じる:
**値1位置は tail ゲーム E(3; a, 3u) の生存者位置がちょうど a+1 であることと同値**
（ONE-CHAR・全称）であり、K≡2 (mod 4) は全称的に値1を取らない（A2-NEVER）。
さらに E-game の phase 構造を run-bump セグメントに束ねることで σ_Z(3,K) が
O(√K) 時間・O(1) 追加メモリで計算できる（FAST・検証済み）。

以下 K≥4 とし、u=⌊K/4⌋・a=K mod 4（K=4u+a）と書く。

## 1. 補題 RUN-3（pot-3 run と tail の分離）

**主張.** σ_Z(3,K) の E ゲーム入口状態 E(3; K−4, 3)（k₁=K−1人）のフェーズ列は
接頭辞として「run」s=⌊(K−4)/4⌋=u−1 フェーズを持ち、各 run フェーズは
q=0・r=3（k>3 は常に成立: k=α+β≥α≥4>3）で α←α−4・β←β+3・k←k−1・pot 3 不変。
run 終了時の状態は **E(3; a, 3u)**（k=3u+a）であり、それ以降を tail と呼ぶ。
run の各フェーズは fold では定数寄与 c=r+1=4 を持つ。

**証明.** 分岐条件は r=3<α ⟺ α≥4。α は初期値 K−4 から各 run フェーズでちょうど
4 減る。したがって run フェーズ数は
s=#{i≥0 : K−4−4i≥4}=⌊(K−4)/4⌋=u−1、終了時 α=K−4−4s=a∈{0,1,2,3}<4、
β=3+3s=3u、k=(K−1)−s=3u+a。∎

系として fold のレベル並びが確定する: tail E(3;a,3u) の内部 fold
（レベル 2..3u+a、値 σ_tail∈[0,3u+a−1]）を下から畳んだ後、
run+Z のレベル **K−s=3u+a+1, 3u+a+2, …, K の各レベルで
sig=(sig+4) mod level** を昇順に適用したものが σ_Z(3,K) である。

## 2. 定理 FOLD（三分法と明示式 Φ_K）

**主張.** D=σ_tail+4u（「巻き戻し無し値」）とおくと

- D≤K−1 のとき: どのレベルでも bite せず **σ_Z(3,K)=D**。
- K≤D≤K+2 のとき: レベル K でちょうど1回 bite し **σ_Z(3,K)=D−K**。
- D≥K+3 のとき: 最初の bite はレベル L₀=⌈(4K−D)/3⌉（<K）で値
  v₀=D+3L₀−4K∈[0,2]。以降、値 v のレベル L から次の bite はレベル
  m=⌈(4L−v)/3⌉、その値 v←v+4(m−1−L)+4−m∈[0,2]、と幾何級数的に続き
  （レベル比≈4/3・bite回数 O(log K)）、最終的に
  **σ_Z(3,K)=v+4(K−L)**。

**証明.** レベル ℓ への入力は位置（ℓ−1 人のフレーム内）で [0,ℓ−2]、
bite（mod が作用する）⟺ 入力+4≥ℓ ⟺ 入力≥ℓ−4。bite 出力=入力+4−ℓ∈[0,2]。
静寂鎖では v_ℓ=D+4(ℓ−K) であり、レベル ℓ が bite する条件は
D+3ℓ≥4K。これが ℓ≤K で一度も成り立たないのが D≤K−1、
はじめて ℓ=K で成り立つのが K≤D≤K+2（⌈(4K−D)/3⌉=K ⟺ K≤D≤K+2）、
ℓ₀<K から始まるのが D≥K+3。bite 後の値 v∈[0,2] からの静寂鎖
v_ℓ=v+4(ℓ−L) が次に bite する条件は v+4(m−1−L)+4≥m ⟺ 3m≥4L−v。
∎（fold4 として sigmaz3_core.py に実装し、K≤4,000 で pinned σ_Z と
0 不一致・予備的に K≤20,000 でも 0 不一致。）

## 3. 定理 ONE-CHAR（値1位置の特徴付け・全称）

**主張.** すべての K≥4 に対し

**σ_Z(3,K)=1 ⟺ σ_E(3; K mod 4, 3⌊K/4⌋)=K mod 4+1。**

**証明.** 最終レベル K の fold は v_K=(v_{K−1}+4) mod K・v_{K−1}∈[0,K−2] だから
v_K=1 ⟺ v_{K−1}=K−3（v_{K−1}+4∈{1,K+1} のうち 1 は不可能・K+2<2K+1）。
K∈{4,5} は s=0（fold レベルは K のみ）で v_{K−1}=σ_tail であり、
σ_tail=K−3=a+1 とONE-CHARは直接同じ。K≥6 とする。v_{K−1}=K−3≥3>2 だから
レベル K−1 は bite していない（bite 出力は ≤2）。よって v_{K−1} は
(i) 全面静寂: v_{K−1}=D−4 ⟺ D=K+1 ⟺ σ_tail=a+1、または
(ii) 最後の bite がレベル ℓ_m≤K−2 にあり、その後静寂:
v_{K−1}=v_m+4(K−1−ℓ_m)、v_m∈[0,2]。
(ii)のとき K−3=v_m+4(K−1−ℓ_m) ⟺ 4ℓ_m=3K−1+v_m が必要で、
4|3K−1+v_m となる v_m は K mod 4 ごとに
a=0: v_m=1, ℓ_m=3u / a=1: v_m=2, ℓ_m=3u+1 / a=2: 解なし / a=3: v_m=0, ℓ_m=3u+2。
ところが fold レベルは K−s=3u+a+1 以上しか存在しないので
ℓ_m∈{3u,3u+1,3u+2} はいずれも fold レンジ未満で**不可能**
（a=2 は解自体が無い）。ゆえに値1 ⟺ (i) ⟺ σ_tail=a+1。∎

これにより K0941 の観察「値1位置 4,8,12,28,40,52,72,…」は
**{4u : σ_E(3;0,3u)=1}** に正確に特徴付けられる（観察91個≤4,000は監査で
91↔91 双方向一致・K≤10^5 では1,146個すべて K≡0 mod 4・deep_census.json）。

## 4. 定理 A2-NEVER（K≡2 (mod 4) は全称的に値1を取らない）

**主張.** K=4u+2≥6 に対し σ_Z(3,K)≠1。（K=2 は値0。）

**証明.** ONE-CHARより σ_tail=3 を示せばよい。tail E(3;2,3u) は k=3u+2≥5>3
なので第1フェーズは q=0・r=3≥α=2 で bump:
σ_tail=(4+I) mod (3u+2)、I=σ_E(4; 3u−3, 1)∈[0,3u]（内部 k′=3u+1）。
4+I∈[4,3u+4] であり σ_tail=3 には 4+I∈{3, 3u+5} が必要だが、
前者は <4・後者は >3u+4 でともに不可能。∎

K0941の「K偶数」備考はこれで半分定理化され、残るのは a∈{1,3}（K 奇数）の
場合であるが、これらは u≤50,000 で反例ゼロ（経験的事実・主張はしない）。

## 5. FAST（run-bump セグメント化と定数 c fold の一括処理）

E-game の phase 構造（pot P<k の間）:

- α≥P+1 の間は **run**: t=⌊α/(P+1)⌋ フェーズが一括可能
  （各フェーズ r=P・α←α−(P+1)・β←β+P・k←k−1・pot 不変）。
- α≤P で **bump**: 1フェーズで pot←P+1・α←β+2α−P−1・β←P−α。
- P≥k で endgame: q≥1・r=P mod k がフェーズごとに変わる（個別処理）。

fold 側も run の寄与 c=P+1 が定数なので、レベル区間 [m₀,m₁] の
sig=(sig+c) mod level の昇順列を bite 解析で一括できる
（最初の bite は j₀=⌈(m−v−c)/(c−1)⌉ オフセット。bite 1回あたり O(1)・
run あたりの bite 数は O(1)）。セグメント数は経験的に O(√k)
（u=3,000: runs+bumps=339・endgame 188 フェーズ・maxPot≈6u・
u=10⁵ の tail が 1.1ms）。**σ_Z(3,K) 全体が O(√K) 時間・O(1) 追加メモリ**
（tail O(√K) + fold O(log K)）。

**検証（FASTEQ・全0不一致）**: tail 族 u≤800×a∈0..3・一般 E 状態
P∈2..10・k≤150 の全 α（103,257状態）・σ_Z fast（M∈{2,3,5,9}・K≤100）・
σ_Z3 対 pinned K≤1,500。予備的に一般 E 500k 状態・fold K≤20,000 も 0 不一致。

## 7. 観察（全称主張しない）

- σ_E(3;0,3u)=1 は真のアトラクタ（u≤3,000 で 205 回・2番手の値6は15回）。
  U の完全な特徴付け（閉形式・漸化式）は未解決。
- 再帰構造: ONE-CHAR条件 σ_tail=a+1 は第1フェーズ bump をほどくと
  a=0 ⟺ σ_E(4;3u−4,3)=3u−3、a=1 ⟺ σ_E(4;3u−2,2)=3u−1（内部最大位置）、
  a=3 ⟺ σ_Z(4,3u+2)=0 と書き直せ、同じ fold 構造が pot 4,5,… へ
  連分数様に再帰する。U の冪減衰はこの深い再帰の反映と解釈できる
  （証明は今後課題）。
- K0941 備考の「K偶数」は「K≡0 (mod 4)」に強化される
  （K≤4×10^5 まで機械確認・a=2 は全称証明・a∈{1,3} は u≤50,000 で反例ゼロ）。
