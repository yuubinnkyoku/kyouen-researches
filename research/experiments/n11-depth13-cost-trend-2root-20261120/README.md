# n11 depth-13第3差分コスト測定（最軽量2根、depths 10-13、2026-11-20）

## 目的

depth-11倍率系列（K1081・バンド1.0004〜1.0666）とdepth-12第2差分（D11→D12倍率
1.0000〜1.0802・非複利）に続き、**1手延長あたりの乗数が3手連続でどう振る舞うか**
（D12→D13・第3差分）を最軽量2根で測った。コスト測定のみであり、判定変更・行の閉鎖・
掃引は行わない。単一オーナー宣言ノート
（`research/log/2026-11-20-n11-depth13-cost-trend-single-owner-note.md`・commit da4b167811）の下で実施。

## 対象とプロトコル

- 対象: depth-12トレンドと同じ最軽量2根（K1069 REFUTED-D10 idx0
  `00000000000000003800000008001220`（bit 5）・idx12 `00000000000000801202000000880100`（bit 8））。
- runner v17固定コピー（git blob `c132cc6425eee3feaeef1d697dd74f968cfedb59`）・cap 30M・
  timeout 280s・両AND順序・pilot_d6制御必須・逐次・**depth 10/11/12/13を自己完結的に再測定**
  （計16 probe）。D10/D11/D12はd12trend正本（SHA-256 10082aef…）とのnode一致を
  fail-closed gateで要求（決定論の三重測定合意）。

## 結果（16/16完走・capped 0・error 0・gate 7/7 PASS）

| label | ordering | D10 | D11 | D12 | D13 | r11/10 | r12/11 | r13/12 | r13/10 |

| idx0 | andclose0 | 815,057 | 837,946 | 905,121 | **905,121** | 1.0281 | 1.0802 | **1.0000** | 1.1105 |

- **D12→D13の倍率は全4 probeで1.0000（node数完全同一）**。idx0根もidx12根と同じく
  フロンティア飽和に到達し、**depth 13以降の追加depthはこれらの根では追加nodeを生まない**。
- D13/D10 の最大は1.1105であり、D12/D10と同一（飽和後は変わらない）。逐次深化の乗数は
  複利にならず、rootごとに1.0へ収束する。
- D10/D11/D12再測定はd12trend正本の12値全てと厳密一致（決定論の三重測定合意）。

## 再現性

- 正本 `output/depth13-cost-trend-2root-20261120.json`（SHA-256
  `573171e004b8b9d4e29590d9cc12be4ecbc144d1ae3a7b5aa0ca2893c6341c01`）は生probe記録
  `output/probe-records-d13trend.jsonl`（16行）からassembleのみで生成され、別cwd・別プロセスで
  byte-identical（2回確認）。
- 再現: repoからK1069正本（22953ae1…）とd12trend正本（10082aef…）をraw取得し、
  `python3 scripts/depth13_cost_trend_20261120.py assemble <k1069.json> <d12trend.json>`。

## 解釈規約

node数はcap内で決定的（機種非依存の費用単位）。capped/timeoutはいかなる方向の証拠にもならない
（本実験でcapped 0）。depth-13のloss=falseはREFUTED-D13分類でも行の閉鎖でもない。
REFUTED-D10はLOSS証明ではない。**標準11×11空盤・二石root {49,60}/{59,60}・S2 {59,60}・
class 1/2/4 はすべて UNKNOWN のまま。**
