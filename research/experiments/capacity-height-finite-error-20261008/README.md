# 高さ有限での逐次合法点一様分布：明示誤差上界と一次漸近補正（2026-10-08）

## 適用条件

K0362 と同じ抽象容量ゲーム。列数 \`w>h>=2\`、容量上限 \`r>=1\`、固定安全初期盤面 \`P\` の列占有数 \`x=(x_1,...,x_w)\` とする。高さ \`m>r\` は全列共通で、点の位置を区別する。通常プレイで毎回 **現在の合法な空き点をすべて等確率** に選ぶ。無限高さ極限では **現在合法な列を等確率** に選ぶ。後者を \`P_infty\`、前者を \`P_m\` と書く。盤面の \`r\` と \`w,h,x\` は \`m\` を増やすとき固定する。K0352の一般位置・\`q=r+1>2w\` を満たすとき幾何学的平行列盤に移送可能。標準の二次元正方形盤にはそのまま適用しない。

\`n=w-h\` として、K0352の終局石数分類から全後続局面での残り最大着手数は高々

\`\`\`
L = r + n*floor(r/h) - sum(x_i).
\`\`\`

初期盤面がすでに終局なら \`L\` はこの公式では0以上でも、両モデルとも同じ1点分布なので誤差0。

## 定理1：有限高さの明示的な全変動距離上界

\`m>r\` について、全ての初期安全状態で

\`\`\`
d_TV(P_m, P_infty) <= min(1, L*r/(4*(m-r))).
\`\`\`

これは**無界の全称不等式**である。個々の終局閾値の確率についても差の絶対値は右辺以下である。

**証明。** 任意の非終局状態 \`z\` における合法列の集合を \`J(z)\`、その大きさを \`k\`、占有数平均を \`zbar=(sum_{i∈J} z_i)/k\` とする。各列は現在 \`z_i\` 点占有、\`m-z_i\` 個の空き点へ合法に打てるので、有限高さの合法列選択確率と極限確率は

\`\`\`
p_i(m) = (m-z_i)/(k*(m-zbar)),
q_i=1/k,
p_i(m)-q_i=(zbar-z_i)/(k*(m-zbar)).
\`\`\`

上位 \`h\` 列の和が \`r\` 以下という条件から、**全ての占有数**は \`0<=z_i<=r\` である。有限集合 \`{z_i:i∈J}\` の平均絶対偏差は標準偏差以下、また区間 \`[0,r]\` にある変数の分散は \`<=r²/4\`（平均からの偏差の平方に \`(z-0)(r-z)>=0\` を使う初等不等式）なので

\`\`\`
(1/k)*sum_{i∈J}|z_i-zbar| <= r/2.
\`\`\`

従って1手の列分布の全変動距離は

\`\`\`
d_TV(p(m),q)
  =sum_{i∈J}|z_i-zbar|/(2*k*(m-zbar))
  <=r/(4*(m-r)).
\`\`\`

二つのモデルで同じ列を選べる限り状態を一致させる最大結合を各手で用いる。最初に異なる列を選ぶまで各手の乖離確率は上の一様上界以下で、対局は高々 \`L\` 手で必ず終わる。和集合評価により終局分布の全変動距離は \`L\` 倍以下、また全変動距離は1以下。□

## 定理2：全終局閾値の一次補正係数を有理数で厳密計算

\`F_t(z)\` を「合法な列を毎手等確率で選ぶ」極限モデルで、状態 \`z\` から終局閾値 \`t\` に至る確率とする。非終局の \`z\` における次の列の集合を \`J(z)\`、\`k=|J(z)|\`、\`zbar=(sum_{i∈J} z_i)/k\` とし、次の後ろ向き再帰で \`D_t(z)\` を定める。

\`\`\`
terminal z: F_t(z) = [minimum terminal occupancy of z == t], D_t(z)=0

nonterminal z:
F_t(z) = (1/k)*sum_{i∈J(z)}F_t(z+e_i)

D_t(z) = (1/k)*sum_{i∈J(z)}D_t(z+e_i)
       + (1/k)*sum_{i∈J(z)}(zbar-z_i)*F_t(z+e_i)
\`\`\`

すると全ての初期盤面 \`x\` と終局閾値 \`t\` について

\`\`\`
P_m(t) = F_t(x) + D_t(x)/m + O(m^-2)  (m→∞).
\`\`\`

\`F_t,D_t\` はいずれも**有限状態・有理数**だけの再帰で厳密評価できる。\`sum_t F_t(z)=1\`, \`sum_t D_t(z)=0\`。

**証明。** 上の1手確率の恒等式から一様に（現在の固定有限ゲーム木の各状態で）

\`\`\`
p_i(m) = 1/k + (zbar-z_i)/(k*m) + O(m^-2).
\`\`\`

終局状態を基底として、残り可能手数の帰納法で、有限高さの終局確率の一次係数を比較すれば表示した \`F_t,D_t\` の再帰を得る。ゲーム木は有限なので \`O(m^-2)\` の誤差も有限和と積で閉じる。列ごとに \`sum_i(zbar-z_i)=0\` なので \`sum_t D_t=0\` も帰納的に成立する。□

同じ \`D_t\` は、極限一様列モデルの全終局列選択列 \`π\` に対し

\`\`\`
D_t(x) = sum_{π ending at t} (
             product_{steps j in π} 1/k_j
          ) * sum_{steps j in π} (zbar_j-z_(chosen_column,j))
\`\`\`

という明示的な有限和でも表される。よって補正の符号は一律ではなく、選択した列の占有数が平均より大きいか小さいかに依存する。

## 1/mの収束速度は一般には改善できない

最小例 \`w=3,h=2,r=3,x=(0,0,0)\`、\`m>=3\` の短い終局（3石）確率は K0362 より厳密に

\`\`\`
P_m(short) = (m-1)*(m-2)/((3*m-1)*(3*m-2))
           = 1/9 - 2/(9*m) + O(m^-2).
\`\`\`

したがって \`D_short=-2/9\`、長い終局は \`D_long=+2/9\`。ゆえに **全局面について一般の誤差 \`O(m^-2)\` を期待することはできず**、上の \`O(m^-1)\` 上界の次数は一般に最適である。ただし数値定数 \`L*r/4\` の最適性までは主張しない。

## 再現検証：独立した後ろ向き・前向き計算

[check_finite_height.py](check_finite_height.py) は以下を別々に実装する。

1. 後ろ向きメモ化再帰による厳密有理数の \`F_t,D_t\`。
2. 着手数層を進める**前向き**確率・一次重み伝播による別実装の \`F_t,D_t\`。
3. 有限 \`m=r+1,r+2,2r+1,5r+1\` について、前向きの実際の合法点数 \`m-z_i\` による厳密有理数終局分布と、上記の全変動距離上界を比較。

\`3<=w<=5\`, \`2<=h<w\`, \`1<=r<=5\` の全安全降順初期状態：354局面・505終局閾値、1,416件の有限高さ比較すべて一致／上界成立。不一致0。\`D\` が非零となる局面は130件。小例では \`F=(1/9,8/9)\`、\`D=(-2/9,2/9)\` を厳密に回収した。

実行方法：

\`\`\`sh
python3 research/experiments/capacity-height-finite-error-20261008/check_finite_height.py
\`\`\`

K0362は高さ無限の定性的な乖離、今回の結果は**具体的な有限高さ誤差上界と全閾値一次係数の計算法**。一般の標準正方形盤の勝敗・最適戦略・11×11 root証明とは無関係。
