## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数、q_odd(k) は k を奇数に切り下げた値。d = x - z、
S = x + 10 と書く。y=10 は偶数 y で S=x+10 の偶奇は x と一致（y=2,4,6,8 と
同じ型）。値1の無限帯と tail は偶数 y 型で **x 奇の行**に出る
（y=9 の逆・y=2,4,6,8 と同じ寄り方）。

## 命題骨子（正本は検証器内 in_T10/in_P10 = K1141 出版 cand10.py の逐語）

H(R;(x,10);z)=2 ⟺ R∈T_z(x)、=1 ⟺ R∈P_z(x)、それ以外で 0（R=0 は常に 0）。

値2 T_z(x)（常に奇数位置＋高々1つの孤立pin／掃引帯）・d=x-z:

| 行クラス | T_z(x) |
|---|---|
| x<=z-11（マージ行） | O[1, q_odd(x+10)] |
| d=-10（対角行） | O[1, z+10]（奇z）/ O[1, z+9]（偶z）＝ cap z+y-[2(z-y)≡0 mod 4] |
| 奇z・d∈{-6,-2,2,6,10} | O[1,z] ∪ {z+(d+30)/2}（前倒しpin格子行・pin z+12..z+20） |
| 奇z・d=11（掃引行 x=z+11） | O[1,z] ∪ O_z[z+20, x+z+10] |
| 奇z・d>=12 | O[1,z] ∪ {z+20}（定常pin 2y+z） |
| 偶z・d∈{-8,-4,0,4,8} | O[1,z-1] ∪ {z+(d+30)/2}（pin z+11..z+19） |
| 偶z・d=11（掃引行） | O[1,z-1] ∪ O_z[z+21, x+z+10] |
| 偶z・d>=12 | O[1,z-1] ∪ {z+21}（定常pin 2y+z+1） |
| その他 | O[1,z]（奇z）/ O[1,z-1]（偶z）（ラダー） |

値1 P_z(x): マージ行は x 奇のみ I[x+11, ∞)。合流行 d>=12 は
base ∪ band ∪ tail（base10={z+1,z+3,...,z+19} の10点・
band=O_z[z+22, x+z+10]（下端 z+2y+2）・tail=x 奇の I[x+z+11, ∞)）。
d=-10..10 は th(d) のジグザグ表（基底点數が 5..10 に1列ごとに階段状。
奇z は偶数dの行・偶z は奇数dの行が interval）
＋行ごとの無限帯 I[z+c]（族構造: 無限帯下端は行列の格子で
z+12/z+14/z+16/z+18/z+20 と1行おきに上昇・最終pin行 d=10〔奇z〕は
bk10 ∪ {z+21} ∪ I[z+22]〔^z+21=2y+z+1=pin(z+20) の1つ上の追加値1点〕）。
偶zの対角行 d=-10 は値1なし（値2上端 z+9 のみ）。
掃引行 d=11 は base10 のみ。全文は検証器 in_P10 が正本。

tail: 全 z>=0・x>=10 で R>=x+z+11 のとき H(R;(x,10);z) = (x+10) mod 2
（x 奇行が値1・tail 開始 x+z+11 = x+z+y+1 は族式どおり）。

マージ系: x<=z-11（S=x+10 < z-1）の全行で
H(R;(x,10);z) = single_token(x+10, z, R)（K0832 出版単一トークン閉形式）。

## 選択肢分解と x=10 での合流

R>=1 のとき

- A = H(R-1;(x-1,10);z)（x>=11。x=10 では 2 つの減少手が同一多重集合
  (9,10)≡(10,9) 子に合流し A≡B = H(R-1;(9,10);z) = cand9(z,10,R-1)、
  すなわち K1138 の z 行 x=10 閉形式）
- B = H(R-1;(x,9);z) = cand9(z, x, R-1)（K1138 全称閉形式・逐語転写。
  **B 子に cand9 を使う初の族**。y=9 までは B 子は cand8 だった）
- C = 1 ⊕ H(R-1;(x,10);z-1)（z>=1 の z 外帰納・cand10）

であり H(R;(x,10);z)=mex{A,B,C}（z=0 では C なし）。

## 値の構造（y=2..10 の横断観察・一般称主張ではない）

part1 の時点では P10 は命題（昇格前）であり、以下は「cand10 が正しければ」の
条件付きの族観察。part2 昇格後に全称確定する。

- **基底点 y 点仮説の y=10 候補**: {z+1, z+3, ..., z+19} の 10 点。
  y=1..9 で全称確定・y=10 は K1141 fit と本機で観測一貫（昇格で第10例）。
- **tail 開始族式 x+z+y+1**（y=10: x+z+11）: y=2..10 の 9 族連続候補。
  tail 値 (x+y) mod 2 も 9 族連続（y 偶は x 奇行が値1無限帯）。
- **マージ行の境界 x<=z-y-1**（y=10: x<=z-11）: 10 族候補。
- **掃引行 x=z+y+1 と掃引帯**: 奇z O_z[2y+z, x+z+y]（y=10: O_z[z+20, x+z+10]）・
  偶z O_z[2y+z+1, x+z+y]（y=10: O_z[z+21, x+z+10]）。
- **値1中間帯 O_z[z+2y+2, x+z+y]**（y=10: O_z[z+22, x+z+10]）: 下端 z+2y+2。
- **定常 pin 2y+z（奇z）/ 2y+z+1（偶z）**: y=10 で {z+20}/{z+21}。
- **前倒し pin 格子 pin=z+(d+3y)/2**: 格子条件 (x-y)+z≡2 (mod 4)（奇zは
  d≡y mod 4 → y=10 で d∈{-6,-2,2,6,10}・偶zは d≡y+2 mod 4 →
  d∈{-8,-4,0,4,8}。両偶奇とも pin 行 5 行・格子公式は y=5..10 の 6 族で統一）。
- **最終 pin 行の追加値1点 2y+z+1**: 奇 z の pin 行 d=y の z+2y+1
  （y=10: d=10 行の z+21。pin z+20 の1つ上）。y=6,8,9 に続き4例目
  （y=10 で初めて偶数 y の例。y=5,7 では未観測）。
- **対角行格子規則 cap = z+y-[2(z-y)≡0 mod 4]**: y=10 の行（奇z 上端 z+10・
  偶z 上端 z+9）まで y=2..10 の全称表の全 z で構造一貫。偶 z 対角 d=-y の
  値1空集合も y=8,9,10 の 3 族連続。
- **型機械 clip 窓 2y+2**: y=5..10 の 6 族連続 tight（y=10 で clip 21 反例
  4,736 件を確認・初違反 (z=60,x=84,R=84)）。
