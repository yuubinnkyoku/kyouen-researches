# 一辺細分星 q=41〜50 の奇数次数実根切替（2026-11-06）

## 結論（数学的証明）

多項式 \(T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}\)、\(r=q-3\)、奇数 \(k\ge3\) について：

| q | 実根なし | 相異なる負の単実根がちょうど2個 |
|---|---|---|
| 41 | 3≤k≤419 | k≥421 |
| 42 | 3≤k≤431 | k≥433 |
| 43 | 3≤k≤445 | k≥447 |
| 44 | 3≤k≤457 | k≥459 |
| 45 | 3≤k≤471 | k≥473 |
| 46 | 3≤k≤485 | k≥487 |
| 47 | 3≤k≤497 | k≥499 |
| 48 | 3≤k≤511 | k≥513 |
| 49 | 3≤k≤523 | k≥525 |
| 50 | 3≤k≤537 | k≥539 |

さらに各行の非存在結論は同じ k の範囲で任意の q'≥q に成立する。

## 全称証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおく。正の u に根はない。負の根があり得るのは \(1<y<a\) のみで、根方程式は \(F(y)=r-y-(a-y)y^k=0\)。\(H(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大値をとる。各行の境界 \(k_-=k_+-2\) で \(H(y_*)<r-a\) を厳密な整数演算で確認したので、全区間で F>0。kを小さくすると y>1 で F は増加するから k≤k_- の全奇数次数で根なし。qを増すと r-y は増加し a は減少するため、非存在は q'≥q にも及ぶ。

一方 k_+ で \(F(y_*)<0\) を厳密に確認した。F(1)>0 および F(a)>0 なので相異なる根が2つある。\(T(-x)\) の係数の符号変化は2回なのでデカルトの符号法則より負の根は重複度込み高々2個。したがって2根は単根で、他の実根はない。kを増すと同じ y>1 で F は減少するので k≥k_+ の全奇数次数で結論が成立。

## 独立再現可能な整数検査

以下のコードは各境界の20個の厳密不等式を検証する。\(A=k(r+2),B=(k+1)(r+1)\) とすれば \(y_*=A/B\) であり、\(F(y_*)\) の符号は \((rB-A)(r+1)(k+1)B^k-(r+2)A^kB\) の符号と一致する。

```python
bounds = [[41,421],[42,433],[43,447],[44,459],[45,473],[46,487],[47,499],[48,513],[49,525],[50,539]]
for q, kp in bounds:
    r = q - 3
    def numerator(k):
        A = k * (r + 2)
        B = (k + 1) * (r + 1)
        assert B < A < (r + 2) * B // (r + 1) + 1
        return (r*B-A)*(r+1)*(k+1)*B**k - (r+2)*A**k*B
    assert numerator(kp-2) > 0, q
    assert numerator(kp) < 0, q
print("20 exact boundary inequalities passed")
```
