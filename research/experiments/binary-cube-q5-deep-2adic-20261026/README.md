# 5点切片の高精度2進零点と有限区間の付値最大値

2026-10-26。K0567定理7（全称証明済み）の零点持ち上げを法 2^60 まで具体化し、巨大な有限区間の最大2進付値を厳密に決定する。新たな無界次元の閉形式を主張するものではない。

## 対象と結論

K0561の全次元厳密公式による整数 B_d=E_{d,5}/2^d（d>=5）を使う。K0567定理7により、十分大きなdで B_d≡0 (mod 2^t) となる剰余類は、法 2^(t+1) でちょうど二つ。今回の計算で、次の剰余類を確定した。

| t | 法 2^(t+1) の二つの零点剰余類 |
|---:|---|
| 18 | 14828, 398995 |
| 19 | 398995, 539116 |
| 40 | 569366821356, 1763551090323 |
| 41 | 1763551090323, 2768390076908 |
| 59 | 16256943456130707, 642416626174015980 |
| 60 | 1169178448062977683, 1795338130780862956 |

この表とK0567の全称周期・零点定理から、**有限区間について厳密に**次が成立する。

| 対象の次元 d | max (v2(E_{d,5})-d) | 最大値を取る全次元 |
|---|---:|---|
| 5 <= d <= 100000 | 18 | 14828 |
| 5 <= d <= 10^12 | 40 | 569366821356 |
| 5 <= d <= 10^18 | 59 | 16256943456130707, 642416626174015980 |

特に 5<=d<=10^18 での余分な2因子の最大数は59であり、**ちょうど2次元**で達成する。

## 厳密性の根拠

K0567定理7は、すべての t>=1 と d>=t+4 について、B_d mod 2^t の最終周期が 2^(t+1) であり、零点剰余類が二つだけであることを数学的に証明している。零点 r mod 2^(t+1) の次段候補は r と r+2^(t+1) mod 2^(t+2)。定理7の正確な差の付値により、次段では**必ず片方だけ**が零点になる。評価する代表元は d>=t+5 に取る。

K0561の厳密公式を P(d)=120 B_d と書き、P(d) を法 2^(t+3) で評価する。P(d) は8の倍数なので、8で割った後に15の逆元を掛ければ B_d mod 2^t が正確に得られる。計算は全て整数の剰余演算であり、巨大な 16^d などを展開しない。

別算法では K0561の原点固定Stirling公式を使う。P(d)=sum_k h_k k! S(d,k) で、非零の h_{5,k} (k=5..16) は順に

81, 466, 1825, 4320, 6375, 6168, 4008, 1790, 560, 120, 16, 1。

恒等式 j^d=sum_k C(j,k) k! S(d,k) より、h_k=sum_{j>=k} c_j C(j,k) と独立に係数変換を検算し、全射数を包除原理で評価する。直接指数式とStirling・包除式は全持ち上げ段階で一致した。ただし**両方式ともK0561の同じ既証明公式を出発点とする算術的独立照合**であり、元の公式の独立な幾何学的証明ではない。

各有限区間の最大値の証明では、上表の t における零点剰余類を区間と交差させ、t+1 における零点剰余類が区間内にないことを確認する。最終周期の適用範囲より小さい次元も、B_d の厳密剰余で個別に排除した。例えば 10^18 の場合、t=59 は d>=63、t=60 は d>=64 に適用できる。d=5..63 の不足部分は全件検算しており、全称定理の開始位置を無視していない。
