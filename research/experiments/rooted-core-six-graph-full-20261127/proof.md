# 有限族の全長周期証明（6頂点・純二点辺clutter全体 = グラフ核全型）

核の意味・正確な再帰・有限窓定理は K0682 と同じ。ここでの新規主張は次の有限族に限る。

## 命題（有限・完全）

6頂点 {0..5} 上の辺がすべて2点であるclutter全体（根0固定の根付き単純グラフ、
以下「グラフ核」）の各型 C と指定根に対し、根に長さ L の二点禁止道を付けた
通常Grundy列 f_C(L) は

```
f_C(L+34) = f_C(L)  for all L >= 500
```

を満たす。raw入力は15個の点対の任意部分集合 2^15 = 32768 件（二点辺同士は
包含を持たないため全件がclutter）。根付き同型は544型（Burnside軌道数と
canonical列挙の二重導出で一致）。閉包663状態 = 新規544（初期型そのもの）+
既知119（≤5点・K0682認証済み表に一致）。開始500はこの族と全残留状態の共同上界
（最悪状態の最終周期破綻は499）であり、個々の核の最小開始ではない。

## 証明の構造

1. **既知部分問題**: 5点以下の全513型はK0682で全長証明済み。その保存整数値を
   0..1069はそのまま、それ以後は500からの周期34ブロックで延長して使う。
   証明済み値の利用であり観測prefixの外挿ではない。
   グラフ核の閉包における既知状態は119個で、すべてK0682表に一致する
   （グラフ核の根を残す着手は核の点数を必ず減らすため、閉包は6点と≤5点に分かれ、
   中間の新しい状態は生じない）。
2. **二重帰納**: 新規544状態の残余更新は pinned engine `play` に従い、長さの
   昇順で正確な再帰を計算（`solve_graph.py`）。
3. **有限窓認証**: 各新規状態の最終周期破綻から `start = max(500, max+1)`、
   `needed = 2*start+69`。実測は `start=500`・`needed=1069` で、窓
   `500..1035`（=2*500+35）について道列 p と全544状態列の周期34一致を確認。
   K0682の有限窓定理により、この族と全到達状態は全長で500以降34周期
   (`jointly_certified=true`)。
4. **最小周期の確認**: 窓500..1069上で、全544型の周期は 1 にも 2 にも 17 にも
   短縮されない（機械検査）。よって各型の最小最終周期はちょうど34。
5. **独立基底検証**: (a) 独立第二実装 `verify_independent.py`（engine不使用・
   K0682表不使用の全再帰）が全閉包663状態・全544レコードを0..1069で再計算し
   全一致。(b) 原始第三実装 `verify_direct.py` が層化標本76状態×L=0..8の
   684比較をラベル付き局面の直接ゲーム木で全一致。
6. **同型検証**: 型数544をBurnside軌道数計算で独立導出し（`verify_enum.py` E2）、
   軌道安定化子の総和 Σ120/|Aut| = 32768 がraw件数と一致（E3）することで、
   選抜表と全ラベル入力の対応を群論的に確認。
7. **外部交差照合**: 出版済み7点純三点辺≤5本監査の閉包に現れた純二点辺状態
   102個（全103個のうち n=6 のもの）が、本公式 audit と全 prefix で完全一致。

## 監査範囲と限界

- `output/audit.json`（sha256 は MANIFEST 参照）の `jointly_certified=true`、
  `joint_start_candidate=500`、`values_needed_through=1069` が有限証明の
  機械可読証拠。544レコードそれぞれが prefix_start と全prefixを保存する。
- 7点以上のグラフ核、6点での三点辺混在の全体、無界サイズへの拡張は証明しない。
  K0684（一般固定核の全称34周期）は予想のまま。
- 辺数ヒストグラムの対称性・Grundy最大22（一意達成状態 (6,[3,5,6,10,12,18,20,34])
  L=159）・開始分布（71値・最小46・最頻値50）はすべて有限観測である。
- 標準二次元盤の固定幅・q点版への直接の移送はしない（K0683の移送は
  残余辺サイズ2・3の仮定に依存し、グラフ核の残余辺はサイズ2のみで
  同様にq=3版の有限整数点盤に移送可能だが、本項目では主張しない）。
