## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、d=x-yとする。全x>=y>=9・R>=0について、H(R;(x,y);8)はRがT(x,y)に属すれば2、P(x,y)に属すれば1、それ以外は0である。高R tailは

    R >= x+y+9  =>  H(R;(x,y);8) = (x+y) mod 2.

値2位置T(x,y)は次の通り。

## 構造注記

- **定常第6点**: 値2の第6点はd>=10で2y+9=z+2y+1に定着する。前倒し局面はd=2の一点2y+5とd=6の一点2y+7の2点のみ。d=9が掃引行（x=z+y+1=y+9、掃引帯O[2y+9,2y+17]）、d=10はA子が掃引帯を横切る過渡行で、偶数"02"帯がE[2y+10,2y+18]（=E[2y+10,X]）に広がり、d>=11では一点2y+10に縮む。z=9族の定常第6点はz+2y（K0998）であり、z方向のシフトz+2y→z+2y+1は観察として記録する。
- **値1頭部のd構造**: 奇数帯の上端h(d)は偶数dではh=2y+3+2*floor(d/4)（d=0,2→2y+3、d=4,6→2y+5、d>=8→2y+7収束）、奇数d<=7ではh=2y+d+8まで伸び、下端2y+6（d≡1 mod 4）/2y+8（d≡3 mod 4）で上端を共有する偶数帯を伴う。d>=9では頭部はO[9,2y+7]に縮み、代わりに偶数帯がE[2y+10,x+y+8]まで伸びてtailに接続する（x+y奇数のときtailの1が連なる、x+y偶数のときPはx+y+8で終わる）。
- **K0999との完全一致**: K0999のy=9署名帯表・閉形式は本式のy=9特殊化と完全一致する（x=9..300・R<=x+35の55,626点再生監査・不一致0）。
- **下位切片の再現**: 同一式はy=8のK0996（x=8..300・55,377点）、y=7のK0995（x=7..300・54,243点）とも有限全域で正確に一致し、y=5,6ではエンジン直接照合（y<=x<=30・1,746点）で一致する。逸脱が始まるのはy<=4の小さいx域のみである。よってz=8の2トークン族は、y=1..4境界切片（K0983・K0984・K0986・K0987）、y=5..8切片（K0991・K0993・K0995・K0996）、y=9境界切片（K0999）、そして本項の一様閉形式の併せ技で**全y>=1で全称分類済み**となる。

## 証明

R=0は終局で値0。x>yかつR>=1の選択肢は

    A = H(R-1;(x-1,y);8)
    B = H(R-1;(x,y-1);8)
    C = 1 xor H(R-1;(x,y);7)

で、d=0では二つのトークン減少手が同じ子へ合流しA=Bである。帰納は二段構えである。(i) **基底行y=9**: B子はK0996のy=8行閉形式、C子は1 xor K0976（z=7・全y>=4一様式、ここではy>=9で適用可）、A子は同一行内のx外帰納仮説であり、d=0でA=Bが合流するためx=yが出発点になる。(ii) **帰納段y>=10**: B子は同一式のy-1行（y強帰納仮説）、A子は同行内のx外帰納仮説、C子はやはりK0976で評価する。いずれの行でも子の値が閉形式で確定する。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

R>=x+y+9ではK0832の一般tail定理を三子へ適用できる。tail署名の監査どおりA=B=C=(x+y+1) mod 2となり、親値はmex{(x+y+1) mod 2}、すなわちx+y偶数で0・奇数で1=(x+y) mod 2であって、tail式に一致する。よって帰納は閉じ、全x>=y>=9・全R>=0が証明された。

## 限界

本項は抽象残余ゲームのz=8・y>=9一様切片である。y<=4の逸脱スライスは本式の適用外であり、ぞれぞれの切片証明（K0983・K0984・K0986・K0987）が全称性を担う。y=5..8の行は本式と有限域で一致するが、全称性は各切片証明（K0991・K0993・K0995・K0996）による。z=9のy>=9、z>=10の全Grundy分類、全高さを統合する2トークン値2位置の一般式、標準二次元盤の固定幅・q点版の真の安定化長は未解決。第6点の高さ方向シフト（z=8族のz+2y+1とz=9族のz+2y）とd=10過渡"02"帯幅の高さ方向一般化は観察であり証明ではない。標準二次元盤へ直接転送する結果ではない。
