# 5点超平面切片の素数法周期：1億未満の有限完全調査

2026-10-26。最新mainのK0567・AGENTS.md・knowledge/README.md・未解決一覧を確認したうえで、既存の1000万未満の調査を重複させず1億未満へ拡張した。**標準の平面共円ゲームの勝敗ではなく、二値超立方体の5点超平面切片数**についての結果。

## 既証明定理からの帰結

K0567の全称定理により、素数p>32、t>=1、A={2,3,5,7}について

```
L_p = lcm(ord_p(a) for a in A)
h_p = min(v_p(a^L_p - 1) for a in A)
L_{p,t} = L_p * p^max(0,t-h_p)
```

が E_{d,5} mod p^t の最小周期（全d>=5）を与える。この周期定理自体は**既存の数学的証明**であり、今回の新規主張ではない。

**補題（全p>32）**：h_p>=2 であることと、4底すべてが `a^(p-1) ≡ 1 (mod p^2)` を満たすことは同値。

証明：I=(p-1)/L_p はpと互いに素で、各a^L_p≡1 (mod p)。h_p>=2なら各a^L_p≡1 (mod p^2)だから、I乗して各a^(p-1)≡1。逆にa^(p-1)=(a^L_p)^I≡1 (mod p^2)なら、a^L_pは法p^2の主単元群（位数p）に属し、Iとpが互いに素なのでa^L_p≡1。□

よって4底の同時Wieferich条件を調べれば、各素数の高冪法周期の指数が1ずつ増えるかを決定できる。

## 有限完全調査（32<p<100,000,000）

| 項目 | 厳密な値 |
| --- | ---: |
| 調査した素数 | 5,761,444 |
| L_p < p-1 の素数 | 394,985 |
| L_p = p-1 の素数 | 5,366,459 |
| 最大短縮倍率 (p-1)/L_p | **42** |
| 最大倍率を取る唯一の素数 | **37,059,289** |
| h_p>=2 の素数 | **0** |
| 底2で a^(p-1)≡1 (mod p^2) の素数 | 1093, 3511 |

したがって、この**有限範囲内の全素数**について、任意のt>=1で

```
L_{p,t} = L_p * p^(t-1)
```

が成立する。これが無制限の全素数に成立するとは主張しない。

最大倍率の証人はp=37,059,289、L_p=882,364。p-1=42*882,364、各底の位数は順に
`ord_p(2)=220591, ord_p(3)=882364, ord_p(5)=882364, ord_p(7)=31513`。
従って4位数の最小公倍数は882,364。素数性・位数は別途SymPyの`isprime/n_order/factorint`でも照合した。底2の例外1093・3511では、底3の`3^(p-1) mod p^2`がそれぞれ341017・24578であり、どちらも1でない。

短縮倍率25以上の素数（p:倍率）は次の9個のみ。

## 再現・独立検証

```sh
g++ -O3 -std=c++17 census.cpp -o census
./census 100000000 > output.txt

g++ -O3 -std=c++17 independent.cpp -o independent
./independent 90000000 > independent_90m.txt
./independent 100000000 90000000 > independent_90_100m.txt
```

第一方式は通常のエラトステネスの篩、p-1の試し割り、**4底の共通周期を直接短縮**する。第二方式は奇数だけの篩、最小素因子表、**4底の位数を別々に計算して最小公倍数を取る**。後者は範囲を90,000,000で分割して実行した。両方式で全5,761,444素数の件数、短周期件数、**倍率別度数表の全項目が完全一致**した。第二方式も底2のWieferich候補を独立に検出し、1093・3511のみと確認した。

第一方式は各素数で `h_p>=2` の直接検査と4底のFermat指数での同時Wieferich検査が一致することをassertする。第二方式は底2のWieferich候補に対し残る3底がすべて同時にWieferichにはならないことをassertする。すべて64-bit範囲内（p^2<10^16）の整数剰余演算で、積は128-bit整数を用いて厳密に求める。倍精度浮動小数点は用いない。

`output.txt`・`independent_90m.txt`・`independent_90_100m.txt`を固定した監査資料とする。今回の無界部分は既存K0567の周期定理と上の初等補題であり、**1億未満という素数範囲の完全性は二方式の有限完全列挙**による。独立の幾何学的切片再列挙ではない。

未解決：1億以上に4底同時Wieferich素数が存在するか、短縮倍率が42を超える最初の素数はいくつか。
