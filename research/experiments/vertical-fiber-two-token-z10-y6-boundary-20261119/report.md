## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,6)（x≥6）における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,6);10)
- **B手**（トークン 6 を 5 へ減ずる）: 子 = H(R−1;(x,5);10) = K1007
- **C手**（z を 10→9 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,6);9) = K0994

x=6 では X=(6,6) で A手とB手は同一の子 (6,5);10 = K1007 の x=6 行に合流する（A=B）。子の値はすべて既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**）、B子は K1007、C子は K0994。y=6 では h=x+y≥12>10 で h=z 行はスライス内に現れない（X=(3,6) は正準化でx≥yに反するため h=z 相当の多重集合 {4,6} は H(R;(6,4);10)=K1006 側に正準化される）。

**Step 2（子の公式）.** A=cand(x−1,r)、B=z10_y5(x,r)、C=1⊕z9_y6(x,r)（r=R−1）。定常行で使う子の帯:

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は **{1,3,5,7,9,23}**。ピン 23=2y+z+[z偶]=2·6+10+1。値1基底点は **{11,13,15,17,19,21} の6点**で、基底点y個仮説 {z+1,…,z+2y−1} を y=6 でも満たす。帯開始は z+2y+2=24（E帯）。**7則は y=6 でも貫徹**: 基底点y個（6個）✓、帯開始 z+2y+2=24 ✓、帯偶奇 z追従（E）✓、掃引行 x=z+y+1=17 ✓、掃引帯 O[pin,x+y+z]=O[23,33] ✓、前倒し生存点 x=y+8=14・点 2y+9=21 ✓、tail R≥x+17・H=(x+y) mod 2 ✓。
- **I 帯の行は x 奇数行**（y=6 で x≡y+1 (mod 2)。I 帯は tail 値 (x+y) mod 2 が 1 の行に現れる規則の y=6 検証で、y=1..6 で一貫）。
- **h=z 行は y=6 では存在しない**（x+y≥12>10）。y=5 の h=z 行（x=5）で見えた3点前倒し {11,13,15} のうち d=0 格子点 15=2y+5 のみが y=6 の対角線 x=6 に点 17=2y+5 として引き継がれ、11・13 の2点（K1002候補のy=5例外点）は消滅する。h=z 行の追加点個数 ceil(y/2) 仮説の y=6 検証は z≥12 の剰余族で実施する。
- **点 2y+7 の現れる行は d=4 で安定**（y=4: x=8、y=5: x=9、y=6: x=10 の3例連続）。
- **K1002 一様候補との整合（新監査）**: 本項の全称式と K1002 の y≥6 一様候補を y=6 スライス上で機械照合した（`agree_k1002_y6.py`、下記監査）結果、**不一致は 0 点**である（グリッド 2,042,880 点・tail 24,975 点・高さのみ 5,445 点の総 2,073,300 照合）。y=6 は K1002 の主張域 y≥6 の第1行であり、**候補のリーディング行が全称定理になった**。グリッド外（x>2000）の一致は、各 d 区分で本項の行式と候補式が同一の集合式（区分内で x の一次式の端点が係数まで一致）に帰着することによる。y=5 監査の対角線2点例外は h=z 行起因であり、h=z行が構造的に現れない y≥6 ではこの種の例外は発生しない。
