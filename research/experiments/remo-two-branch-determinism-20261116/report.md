## 定義

**2枝合成族**: 極大安全集合が A, B の2個で |A|=C1 < C2=|B|、γ=|A∩B| < C1。
安全集合 = A または B の部分集合（K0859 の {6,9} 反例の一般化）。
領域分割: core = A∩B（γ点）・A-only（C1−γ点）・B-only（C2−γ点）。

**REMO 規則（K0859 と同一）**: プレイヤー 0..r−1 が巡回し、合法手 = 安全を保つ
空点への着手。極大安全位置で着手番のプレイヤーが敗者となり、**その所有石を
すべて**盤から除去、巡回順の次の残存者が着手。除去後も位置が極大なら次の
残存者も連鎖的に排除し、1人残った時点で終了（生存者＝唯一の勝者）。

本項を通じて C1 ≥ r（第1終端で敗者が必ず ≥1 個の石を所有するため）。
r=3 では連鎖排除は起こらない（第2排除で終了）。

## 定理E（領域計数帰約・全称）

対称群 G = Sym(core) × Sym(A-only) × Sym(B-only) は配置空間に作用し、
REMO のゲームグラフ（合法手・終端判定・所有権機構）は G 同変である。
よって REMO の全成果（敗者列・生存者）は (S, own) の G 軌道のみで決まる。
軌道は「プレイヤー別 core 石数 (c_i)_i・プレイヤー別排他石数 (e_i)_i・
枝ロック branch ∈ {F, A, B}・手番・残存集合」で完全に決まる。

*証明.* 合法手は S∪{c} ⊆ A または ⊆ B ⟺ (branch=F なら c ∈ core ∪ A-only ∪ B-only、
branch=A なら c ∈ A、branch=B なら c ∈ B)。終端は S ∈ {A, B}、いずれも領域分割と
石数のみで決まる。敗者の石の除去はその領域別石数を減算し、残存排他石数が
正なら枝ロック維持、そうでなければ F に戻る。巡回・残存集合は明らかに
軌道不変量。よって状態遷移系は領域計数状態で閉じ、成果は軌道で一定。□

**領域計数ゲーム**（全 r で決定的・有限状態）: 状態 = (core, excl, branch, 手番, 残存)。
遷移: F: core 追加（F 維持）／A-only 追加（→A）／B-only 追加（→B）;
A: core または A-only 追加; B: core または B-only 追加。終端:
(branch=A ∧ 総数=C1) ∨ (branch=B ∧ 総数=C2)。排除: 敗者の (core, excl) を
ゼロ化、excl 総和 >0 ならロック維持・そうでなければ F。

帰結: **REMO の生存者決定性は (C1, C2, γ, r) のみで決まり、合成族の
細胞配置に非依存**。機械検証: 細胞レベル全対局木（所有権込み・メモ化DFS）と
領域計数ゲームが重なりグリッド68族+K0859アンカー (6,9,3) で r=3,4 とも完全一致。

## 定理F（r=3 閉形式・全称）

先手は WLOG で P_0（族はプレイヤー対称・巡回ラベル替え）。

**Phase 1**: 終端 X ∈ {A, B} は両方到達可能、長さ L1 = C_X。
第1敗者 λ = L1 mod 3（K0339）。敗者の所有石数 o = (L1−λ)/3（巡回着手の計数）。
dip 位置 S' = X ∖ (敗者の o 石)。敗者の o 石は X 内の任意の o 点集合として
実現可能（X の部分集合はすべて安全・任意の順序で埋まる）。よって:

- **free dip**（S' ⊆ core）の実現可能性 ⟺ o ≥ C_X − γ（敗者が X-only 全点を所有）。
- **locked dip**（S' に X-only が残る）は常に実現可能（o ≤ C_X − 1）。

**Phase 2**（残存2人、回転 [λ+1, λ+2]・開始 λ+1）:
locked X なら終端は X に固定され長さ ℓ₂ = C_X − s'（s' = L1 − o）。
free dip なら両終端が到達可能で ℓ₂ = L₂ − s'（L₂ ∈ {C1, C2}）。
このとき

> **敗者₂ = (λ + 1 + (ℓ₂ mod 2)) mod 3、生存者 = (−λ − 敗者₂) mod 3。**

（2人の回転なので ℓ₂ の偶奇のみが効く。）

**決定性 ⟺ 全ての実現可能パス (L1, dip型, L2) で生存者が一致。**

*証明.* Phase 1 の終端到達可能性は core→枝の埋め順で自明。dip 実現可能性は
上の計数。Phase 2 の長さは自由dipでない限り枝ロックで固定、自由dipでは
「残り core を埋めてから枝を埋める」戦略で両終端が到達可能。回転の計数は
K0339 と同じ。連鎖排除は r=3 では起こらない（第2排除後に1人）。□

**系（ロック体制の判定式）** 両 dip が locked（γ < C1−o1 かつ γ < C2−o2）のとき
決定性 ⟺ f(λ1,o1) = f(λ2,o2)、ただし f(λ, o) = (−λ − (λ+1+(o mod 2)) mod 3) mod 3。
特に **3 | Δ のとき: 決定性 ⟺ Δ/3 が偶**（λ1=λ2、o2−o1=Δ/3）。

機械検証: r=3 グリッド197族で領域計数ゲームと閉形式が完全一致、
ロック体制143族で上の判定式どおり（2チェック）。

## 系: r|Δ は生存者決定性にとって必要でも十分でもない（無限族・全称）

f の直接計算（free パスを含む全実現可能パス）で、次が **全ての γ ∈ 0..C1−1** に対して成り立つ:

- **(6u, 9u), u ≥ 1**: 決定性 ⟺ u 偶。u 偶なら生存者は常に P_2
  （o1=2u・o2=3u とも偶）。u 奇なら {P_1, P_2}（A枝パスが P_2・B枝パスが P_1）。
  Δ = 3u なので常に r | Δ。u 奇は「r|Δ なのに非決定的」の無限族
  （u=1 が K0859 の {6,9}）、u 偶は「r|Δ で決定的」の無限族。
- **(6u, 12u), u ≥ 1**: 常に決定的・生存者 P_2（o1=2u・o2=4u とも偶、
  Δ = 6u ≡ 0 mod 3）。
- **(3t+2, 3t+4), t ≥ 1**: 決定性 ⟺ t 奇。t 奇なら生存者は常に P_0
  （4種のパスすべて: locked-A で排除順 (P_2,P_1)、locked-B で (P_1,P_2)、
  free-A では ℓ₂ ∈ {t, t+2} が同偶奇、free-B では ℓ₂ ∈ {t−1, t+1} が同偶奇で
  いずれも同じ生存者）。t 偶なら {P_1, P_2}。Δ = 2 なので常に r ∤ Δ。
  t 奇は「r∤Δ でも決定的」の無限族、t 偶は「r∤Δ で非決定的」の無限族。

よって4象限（r|Δ×決定/非決定、r∤Δ×決定/非決定）すべてが無限族で非空で
ある。K0339 の「第1敗者固定 ⟺ r|Δ」（K0859 により全順位には昇格しない）と
生存者決定性は独立な概念である。**CASC の決定性⟺r|Δ（K0859 定理C(iii)）と
対照的に、REMO の生存者決定性を r|Δ で特徴づけることはできない。**

機械検証: (6,9)(12,18)(18,27)(6,12)(12,24)(5,7)(8,10)(11,13)(14,16) の全γ
（計95γ）および (3,6) 全γ で分予想と完全一致。

## 系: 生存者決定的だが順位非決定的な族

- **(5,7, γ)（t=1 族）**: 全対局で生存者は P_0 だが排除順は
  (P_2, P_1) と (P_1, P_2) のちょうど2通り（互いに逆順）。
- r=3 グリッド: 決定的52族のうち34族が順位非決定的。完全順位決定的な18族は
  Δ=6 系（(3,9)(4,10)(5,11)(6,12) など・ロック体制で o1, o2 が同偶奇のとき）。
- r=4/5/6 グリッドでは決定的族は**すべて**順位非決定的（47/47・12/12・6/6）。
  決定的な例: r=4 で (4,6) 全γ・生存者 P_3、r=5 で (6,10)・P_4、
  r=6 で (6,10)・P_5。

これは「第1敗者の非決定性がそのまま生存者の非決定性に伝播する」という
単純な描像の反例でもある: 生存者は排除順の**組合せ**として決まり、
順位が分かれても生存者が一致しうる。

## γ 依存性

閉形式では、各パスの生存者は (λ1, λ2, o1 mod 2, o2 mod 2) のみで決まり、
γ は free dip の**実現可能性の閾値**としてのみ作用する。よって決定性の
γ 依存性は「free パスの追加が生存者集合を変えるか」に還元される。
r=3 グリッドの39個の (C1,C2) ペアのうち γ 依存は (3,8)（γ=2 で非決定化）
と (8,9)（γ∈{6,7} で非決定化）の2つのみ。上の3無限族では γ 非依存。
一般の γ 非依存性は主張しない。
