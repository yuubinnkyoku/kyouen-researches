# 二次形式4点禁止版：全幅の安定化相図と長盤Grundy値

2026-10-24。現行知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。標準の円・直線禁止ではなく、退化も含めた
`det[x²+λy²,x,y,1]=0` を禁止する通常プレイである。
盤は `D(w,m)={0,...,m-1}×{0,...,w-1}`、`w,m≥1`、`λ∈R`。

**証拠区分：全称的な数学的証明。** 有限検査は独立監査であって、無界結論を有限実験から外挿していない。

## 定理：任意幅の有限／無限安定化を完全分類

`T_w=3+2{C(3w−2,3)−(w−1)}` とおく。二項係数は上が下より小さいとき0とする。
これは既存の標準共円ゲーム [K0068](../../knowledge/items/K0068-standard-fixed-width-parity-threshold.md) と**数値的に同じ上界**だが、ここでは任意の実数λの二次形式版を扱う。

全ての `w≥1, λ∈R, m≥T_w` に対し、極大安全集合の石数は **3または3w** のみ。
3石極大が存在する必要十分条件は

1. `λ=0, w≥3`、または
2. `λ=−(a/b)², gcd(a,b)=1, a,b≥1, w≥2b+1, m≥2a+1`。

よって真の満容量安定化長（存在しないとき∞）の**全幅・全実数相図**は

```text
M_{w,λ}=∞  iff  [λ=0 and w≥3]
                  or [λ=−(a/b)², gcd(a,b)=1, a,b≥1, w≥2b+1].
それ以外は M_{w,λ}≤T_w<∞。
M_{1,λ}=3, M_{2,λ}=9 （全λ）。
```

有限の場合の `T_w` は十分長さであり、一般に真の最小値ではない。
三行の既存の厳密値（一般型15、λ=1は24）と矛盾しない。

## 定理：長盤の全安全局面Grundy値

`C=3w` とする。**全てのλ、m≥T_w** において次の式が成立する。

- `|S|≥4`：`g(S)=(C−|S|) mod 2`。
- `|S|=3`：持ち上げ階数が2なら `g(S)=0`、階数3なら `g(S)=(C−3) mod 2`。
- `|S|=2`：wが奇数なら `g(S)=1`。wが偶数なら、Sを含む等方三石配置が盤内に存在するとき `g(S)=2`、存在しないとき `g(S)=0`。
- `|S|=1`：`g(S)=(C−1) mod 2`。
- `S=∅`：`g(∅)=C mod 2=w mod 2`。

特に **空盤の勝敗は係数λによらず、奇数幅で先手勝ち・偶数幅で後手勝ち**。
奇数幅では三石極大が存在しても、**全安全局面**で `g(S)=(C−|S|) mod 2` が成立する。
偶数幅では等方三石が存在すると二石局面にGrundy値2が生じるが、空盤勝敗は変わらない。

## 全称証明

### 1. 不足行の追加候補の被覆数

各行の4石は常に禁止なので、安全集合の各行は高々3石。
`|S|<3w` なら石数 `k≤2` の不足行 `r` がある。
`|S|≥4` のとき、S内の任意の三石は持ち上げベクトル
`L(x,y)=(x²+λy²,x,y,1)` の階数3を持つ。階数2なら任意の第四石との行列式が0になり安全性に反する。

三石 `U⊂S` が行rの候補 `(x,r)` を塞ぐ条件は
`P_U(x)=det[L(u1);L(u2);L(u3);L(x,r)]=0`。
`P_U` は次数高々2で、かつ恒等零ではない。
恒等零なら、三石の張る超平面を `A(x²+λy²)+Bx+Cy+D=0` と書いたとき
`A=B=0, Cr+D=0`。従って三石すべてが行r上にあり、k≤2に矛盾する。

Uが行rの既存石をj個含めば、それらは既知の相異なる根であり、新たに塞げる列は高々 `2−j`。
他行の石は高々 `n=3(w−1)` 個。行rに石を含まない三石組で、全て同じ他行にあるものは、行rでのPが非零定数となり根を持たない。
従ってj=0の混合三石組数は高々 `C(n,3)−(w−1)`。
j=1の組数は高々 `k C(n,2)`、j=2は新しい根を持たない。
占有済みを含めた使用不能列は

```text
≤ k + 2[C(n,3)−(w−1)] + k C(n,2)
≤ 2 + 2[C(n,3)−(w−1)] + 2 C(n,2)
= T_w−1.
```

よってm≥T_wでは、階数3の三石からなる安全局面は必ず延長できる。
石数0〜2は明らかに延長できる。階数2の三石だけは第四石を一切置けない。
従って極大サイズは3か3wのみ。四石以上からの任意の合法な進行は必ず3w石で終わる。

### 2. 三石極大の幾何学的分類

三石の持ち上げ階数が2となる必要十分条件は、元の三点が一直線上にあり、
その方向 `(u,v)` について `u²+λv²=0` となること。
これは既存の [等方三石定理](../quadratic-pencil-isotropic-triples-20261024/README.md) の全称証明。
λ=0なら鉛直三石、λ<0なら負の有理数平方だけが整数等方方向を持つ。
既約方向は `(±a,b)` で、三石を置くには縦幅 `2b+1` と横長 `2a+1` が必要十分。
いったん三石極大が存在すれば、横に盤を延長しても極大性は残る。
これでMが無限となる条件の必要十分性が従う。

### 3. mex帰納

四石以上の安全局面からの全終局は同じ石数Cなので、降順帰納で
`g(S)=(C−|S|) mod 2`。
三石は階数2なら終局0、階数3なら全子が同じ偶奇値なので `(C−3) mod2`。

w奇数なら三石の二種類の値はいずれも0。
二石は必ず合法な第三石を置けるため値1、一石は0、空盤は1。
w偶数なら三石は階数2で0・階数3で1。
任意の二石には階数3となる第三石が存在する（同じ行の二石なら別行の点、
異なる行の二石なら片方の行の別の横座標）。従って二石の値は
等方三石への延長があれば `mex{0,1}=2`、なければ `mex{1}=0`。
任意の一石から同じ行の別の点へ進めば、その二石は等方三石に含まれない
（水平方向は `u²+λ·0²>0`）。よって一石の子に値0があり、
その他の二石の値は0か2だけなので一石の値は1。
空盤の子は全て1なので値0。w=1は三石容量の自明な偶奇計算。□

## 独立した有限監査

`verify.py` は三石ごとに**全第四点を直接3×3差分行列式で判定**し、
等方直線による幾何学的分類と閉公式の個数を照合する。
w=3,4,5、m=4,5,6、λ∈{−4,−1,−1/4,−2,0,1/2,1,3/2} の72盤、
計101,720個の三石組が全て一致。詳細は `results.json`。
さらに `verify_2x9.py` は幅2・9列の全11,130安全局面を再帰mexで完全列挙し、356禁止四点組、空盤g=0、全局面容量偶奇式との一致を確認した（この幅ではλの値に依存しない）。
有限検算は無界証明の代用ではない。

## 留保

ここでのMは「全極大が3w石になる開始長」であり、空盤勝敗の安定化長とは異なる。
標準の共円ゲームはλ=1という特別な場合。11×11の巨大探索には踏み込まない。
