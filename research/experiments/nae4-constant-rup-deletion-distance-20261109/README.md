# 連結・有界次数のsigned NAE4と定数長RUP証明

現在の命題は [K0710](../../knowledge/items/K0710-nae4-constant-rup-unbounded-deletion-distance.md)。
K0709の単位節を使う例に対し、全節の長さ4、全符号反転で閉じたCNFでも同様の非決定性を示す。
剰余放物線からの幾何的実現は主張しない。

## 距離の定義

δ_CNF(F)はFをSATにするために削除する最少CNF節数。
δ_NAE(F)は対応するsigned NAE4制約を削除する最少制約数で、相反する節の対を1制約と数える。
後者の1削除はCNF節2個の削除に相当するが、両距離を同じ単位では数えない。

一般に、制約を削除してSATにする最少数は、全割当のうち違反制約数を最小にした値に等しい。
割当が違反する制約を全て除けば上界が得られ、削除後の充足割当は残存制約を全て満たすので逆の不等式も従う。
今回、節Cと全符号反転した節C'の対は一つのNAE制約を表す。
各割当で違反するCNF節は対ごとに0個か1個なので、違反CNF節数と違反NAE制約数は一致する。

## 任意のm,kの構成（1<=k<=m）

変数を4個ずつのmブロックB_iに分ける。各ブロックの変数を順にa,b,c,dと書く。

1. 先頭kブロックには、各ブロックの4変数について全16通りの符号の4リテラル節を置く。
2. 残りの各ブロックでは全16節から全正節と全負節を除く。
   直前ブロックの最初の変数をtとし、
   `(t ∨ ¬a ∨ ¬b ∨ ¬c)` とその全符号反転の対を加える。
3. 第2ブロック以降の全てについて、直前ブロックの最後の変数をsとし、
   `(s ∨ ¬a ∨ ¬b ∨ ¬d)` とその全符号反転の対を加える。

変数数4m、節数18m-2、全リテラル出現数72m-8、NAE制約数9m-1で、これらは固定mではkに依存しない。
各節は異なる4変数を含み、重複節・同語反復節・単位節はない。全変数が出現する。
全符号反転で閉じているのでsigned NAE4のCNF展開として読める。
各ブロック内の局所節で4変数は連結し、手順3の対で隣接ブロックが全て接続する。
従って変数・節の二部接続グラフも連結である。
自ブロックの局所節と手順2の自ブロック分で、各変数の出現数は高々16。
残る寄与は、aなら次ブロックの手順2と自ブロックの手順3、dなら自ブロックと次ブロックの手順3、
bなら自ブロックの手順3だけで、cにはない。各補対の寄与は2なので追加は高々4回である。
CNF節への出現数は高々20、NAE制約次数は高々10であり、この上限はm,kに依存しない。

## 削除距離の証明

先頭kブロックの全16節の集合は、それぞれ4変数の全割当を禁止するUNSAT核である。
これらの核の節集合もNAE制約集合も互いに重ならないので、SAT化には少なくとも各核から1個、合計k個を削除する必要がある。

逆に各核から全正節を一つずつ削除し、全変数を偽にすれば、残りの全節を満たせる。
残りのブロックの14節は全て負リテラルを含む。追加した混合節は負の局所変数で、
その反転節は負の前ブロック変数でそれぞれ満たされる。従ってδ_CNF=k。
NAE制約を単位にする場合は各核から全正・全負の対を一つずつ除けば同じ割当が使え、δ_NAE=k。

## 共通の15行RUP証明

最初のブロックだけを使う。初期の全16節から、4番目の変数で解消した全8通りの3リテラル節を加える。
次に全4通りの2リテラル節、2通りの単位節、最後に空節を加える。合計8+4+2+1=15行。
各追加節の否定を仮定すると、既にある2節が次の変数の相反する値を単位伝播で強制するためRUPである。
これ以外のブロックは証明に使わない。同じ15行が全m,kで使え、最短証明だとは主張しない。

固定mでも同じ入力寸法と共通証明のままで両削除距離は1..mを取る。
m=kを任意に大きくすれば、15行の証明を保ったまま両距離は無界となる。

## 有限検査と限界

```powershell
uv run --locked python research/experiments/nae4-constant-rup-deletion-distance-20261109/verify.py --tmp D:/tmp
```

m=1..3の全6例で、全12,816割当を列挙し、違反CNF節数と違反NAE制約数の逐点一致、
最小値k、入力寸法、補対閉包、連結性、出現数20以下を検査した。
修正版検証器をソースからビルドし、全例で同じ15行証明をRUPのみで受理した。
入出力hashと結果は `results.json` に保存する。全称命題の証明は上の構成と上下界であり、有限例の外挿ではない。

初回の全体共有変数を用いた16m節の試作は `prototype_global_link_verify.py` と
`prototype_global_link_results.json` に当時のコード・結果を保持する。現在の主張は上の連結・有界次数版である。

この族が剰余放物線Q_pの幾何制約として実現できるとは確認していない。
