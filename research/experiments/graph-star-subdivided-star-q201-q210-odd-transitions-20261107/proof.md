## 厳密証明

先行するq=191〜200の解析補題を使用する。\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) と変数変換すると、負根は \(F_k(y)=r-y-(a-y)y^k=0\) に対応し、候補は \(1<y<a\) に限られる。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大。\(1<y<a\) で \(H_k(y)\) はkに対して厳密増加する。

下側境界\(k_-\)で \(H_{k_-}(y_*)<r-a\)、上側境界\(k_+=k_-+2\)で \(H_{k_+}(y_*)>r-y_*\) を示す。後者は\(F_k(1),F_k(a)>0\)と合わせて二根の存在を示し、デカルトの符号法則でちょうど二つの相異なる単根となる。正根はない。境界の間に奇数次数はなく、単調性により全奇数kに拡張できる。

\(A=k(r+2), B=(k+1)(r+1)\)とおき、各境界で\(B<A\)および以下を任意精度整数演算で確認した。

- 非存在：\((r^2-2)(k+1)B^k>(r+2)A^k\)
- 存在：\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)

## 再現コード（Python 3、整数演算のみ）

```python
rows = [[201,2837],[202,2855],[203,2871],[204,2887],[205,2903],[206,2919],[207,2937],[208,2953],[209,2969],[210,2985]]
for q, km in rows:
    r = q - 3
    for k in (km, km + 2):
        A, B = k * (r + 2), (k + 1) * (r + 1)
        assert B < A, (q, k)
        if k == km:
            assert (r*r - 2)*(k + 1)*pow(B, k) > (r + 2)*pow(A, k), (q, k)
        else:
            assert (r*B - A)*(r + 1)*(k + 1)*pow(B, k) < (r + 2)*pow(A, k)*B, (q, k)
    print(q, 'PASS')
```
