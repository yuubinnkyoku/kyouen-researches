# 一辺細分星 q=31〜40 の奇数次数実根切替（2026-11-06）

## 定理
`T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}`、`r=q-3`、奇数 `k>=3` について：

| q | 実根なし | 相異なる負の単実根ちょうど2個 |
|---|---|---|
| 31 | 3<=k<=293 | k>=295 |
| 32 | 3<=k<=305 | k>=307 |
| 33 | 3<=k<=317 | k>=319 |
| 34 | 3<=k<=329 | k>=331 |
| 35 | 3<=k<=343 | k>=345 |
| 36 | 3<=k<=355 | k>=357 |
| 37 | 3<=k<=367 | k>=369 |
| 38 | 3<=k<=381 | k>=383 |
| 39 | 3<=k<=393 | k>=395 |
| 40 | 3<=k<=405 | k>=407 |

## 証明
`a=(r+2)/(r+1)`、`u=-(r+1)y`。正のuに根はない。負の根候補は `1<y<a` に限られ、根方程式は `F(y)=r-y-(a-y)y^k=0`。関数 `H(y)=(a-y)y^k` は `y_k=ka/(k+1)` で最大。各表の `k_-=k_+-2` において `H(y_{k_-})<r-a` を厳密検証したので全区間で `F>0`。固定 `y>1` でkを下げればFは増加するため全奇数 `k<=k_-` で根はない。

一方各 `k_+` で `F(y_{k_+})<0` を厳密検証した。両端のFは正であるため2根存在。奇数kの `T(-x)` は符号変化が2回なのでデカルトの符号法則から重複度込み高々2根、したがって相異なる単根ちょうど2個。kを増せば同じ点のFは減少するため全奇数 `k>=k_+` で成立。rを増すとFは増加し候補区間が縮小するため非存在は全 `q'>=q` に拡張される。

## 再現コード（Python 3、整数演算のみ）
```python
bounds = [[31,295],[32,307],[33,319],[34,331],[35,345],[36,357],[37,369],[38,383],[39,395],[40,407]]
for q, kp in bounds:
    r = q - 3
    def evaluate(k):
        A, B = k*(r+2), (k+1)*(r+1)
        assert A > B and A*(r+1) < B*(r+2)
        h = (r+2)*A**k
        d = (r+1)*(k+1)*B**k
        return A, B, h, d
    A,B,h,d = evaluate(kp-2)
    assert h*(r+1) < (r*(r+1)-(r+2))*d
    A,B,h,d = evaluate(kp)
    assert h*B > (r*B-A)*d
```
