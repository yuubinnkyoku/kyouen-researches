# 2トークン残余ゲーム z=9・y=6 の全Grundy分類（K0994）

- 日付: 2026-11-19
- 対象: H(R;(x,6);9)、全 x>=6・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0992（z=9,y=5）、K0993（z=8,y=6）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

| 15 | {1,3,5,7,9,21} |

| x>=17 | {1,3,5,7,9,21} |

| x | P_9^(6)(x) |

| 6 | E[10,16] |
| 7 | E[10,18] ∪ I[19,∞) |

| 10 | E[10,18] |

| x>=17 odd | E[10,20] ∪ O[23,x+16] ∪ I[x+17,∞) |
| x>=18 even | E[10,20] ∪ O[23,x+15] |

全てのx>=6・R>=0で、H(R;(x,6);9)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailは

    R >= x+16  =>  H(R;(x,6);9) = (x+6) mod 2.

値2の定常位置は{1,3,5,7,9,21}。x=16だけはO[21,31]が一時的に加わる（掃引行）。z=9族の定常第6点はz+2yで、y=1..6では11,13,15,17,19,21が6点連続で成立する。x=7,11,15では第6点が17,19,21と4間隔で前倒しに現れ、x>=17で21に定着する。値1の頭部E[10,20]={10,12,14,16,18,20}=z+1+2i (i=0..5)はz=9族のy=1..6各切片を貫く偶数帯で、中間帯は奇数帯O[23,x+16]/O[23,x+15]、tailが1になる側（y=6ではx奇数行）にI[x+17,∞)が付く。K0992ではI帯はx偶数行に付いたため、I帯の行がyの偶奇で交互する観察がz=9族でも1延長で確認された。x=16の掃引帯は掃引位置x=z+y+1と掃引範囲O[z+2y,z+2y+10]の族公式どおり。tailの閾値R>=x+16はK0832の一般tail（R>=x+y+z+1でH=(x+y) mod 2）のy=6,z=9の場合に一致する。x=16は掃引行、x=17はA子が掃引行x=16を横切る署名上の過渡行（偶数帯E[24,32]の署名12だけが定常と異なる）で、署名の定常はx>=19奇/x>=18偶から始まる。

## 証明

R=0は終局で値0。R>=1,x>=7の選択肢は

    A = H(R-1;(x-1,6);9)
    B = H(R-1;(x,5);9)
    C = 1 xor H(R-1;(x,6);8)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0992、CはK0993で評価できる。x=6では二つのトークン減少手が同じ(x,5)子（最大トークン6）に合流するため、A=B=K0992のx=6行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

各行はAに帰納仮説、BにK0992、CにK0993を代入した子値集合である。x>=19奇数行とx>=18偶数行では、帯端だけがxに依存し、署名は一定である。x=16は掃引行、x=17はA子が掃引行x=16の掃引帯O[21,31]（署名01・mex 2）を横切る過渡行で、偶数帯E[24,x+15]（署名12・mex 0）の分割だけが定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+15を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+16ではK0832の高R tail定理を各子に適用できる。x奇数ならA=B=C=0で親値1、x偶数ならA=B=C=1で親値0となり、親tail (x+6) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=9,y=6切片のみを扱う。z=8のy>=7、z=9のy>=7、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=9族の定常第6点 z+2y の一般化（y=1..6の6点連続）、第6点の前倒し配置（y=6でx=7,11,15）、I帯のy偶奇交互は観察であり証明ではない。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
