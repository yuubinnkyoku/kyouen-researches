# 一辺細分星：k=9, q=5 の全実根不存在（2026-11-04）

## 定理

K0648 の全終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1},\qquad r=q-3
\]
について、**k=9, q=5 (r=2) では全実数 u に対して T_{9,2}(u)>0**。従って10根はすべて非実根（重複度込み）。標準格子盤ではなくグラフ型構成についての定理。

## 証明

u>=0 は係数の正性より明らか。u=-x (x>0) と置くと
\[
P(x)=T_{9,2}(-x)=x^9(x-4)+3^9(6-x).
\]
4<=x<=6 では両項非負で同時に0とならない。x>6 では x>3 かつ x-4>x-6>0 より x^9(x-4)>3^9(x-6)。よって P(x)>0。

0<x<4 では P(x)=3^9(6-x)-x^9(4-x)。f(x)=x^9(4-x) は x=18/5=3.6 で最大となり
\[
M=\max_{0\le x\le4}f(x)=\frac{4^{10}9^9}{10^{10}}.
\]
以下の有理数の厳密比較が成り立つ：
\[
M<\frac94 3^9,\qquad
\frac{(15/4)^9}{4}<2\cdot3^9.
\]
実際、両辺に正の分母を掛ければ整数の大小比較だけで検証できる。

* 0<x<=7/2: 6-x>=5/2>9/4 だから 3^9(6-x)>M>=f(x)。
* 7/2<=x<=15/4: 6-x>=9/4 だから同様に 3^9(6-x)>M>=f(x)。
* 15/4<=x<4: f は x>=18/5 で厳密減少するため f(x)<=f(15/4)=(15/4)^9/4<2*3^9<3^9(6-x)。

したがってすべての x>0 で P(x)>0、証明終。

## 証拠と限界

この証明は有理数の厳密な不等式と微分による全称証明であり、浮動小数点の根探索に依存しない。k=9, q=5 のみに適用し、他の q や奇数 k へは外挿しない。既存の k=3,5,7 の証明で使った粗い一様評価が k=9 で失敗することと矛盾しない。

検算例（Python の整数演算）：
```python
from fractions import Fraction
M = Fraction(4**10 * 9**9, 10**10)
assert M < Fraction(9, 4) * 3**9
assert Fraction(15, 4)**9 / 4 < 2 * 3**9
```
