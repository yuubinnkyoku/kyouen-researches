# 2トークン残余ゲーム z=8・y=5 の全Grundy分類（K0991）

- 日付: 2026-11-19
- 対象: H(R;(x,5);8)、全 x>=5・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0987（z=8,y=4）、K0981（z=7,y=5）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

| x | T_8^(5)(x) |
|---:|---|
| 5,6,8,9,10,12,13 | {1,3,5,7} |
| 7 | {1,3,5,7,15} |
| 11 | {1,3,5,7,17} |
| 14 | {1,3,5,7} ∪ O[19,27] |
| x>=15 | {1,3,5,7,19} |

| x | P_8^(5)(x) |
|---:|---|
| 5,7 | O[9,13] |
| 6 | O[9,13] ∪ I[15,∞) |
| 8 | O[9,15] ∪ I[16,∞) |
| 9,11 | O[9,15] |
| 10,12 | O[9,15] ∪ I[17,∞) |
| 13 | O[9,17] |
| 14 | O[9,17] ∪ E[20,28] ∪ I[29,∞) |
| x>=15 odd | O[9,17] ∪ E[20,x+13] |
| x>=16 even | O[9,17] ∪ E[20,x+14] ∪ I[x+15,∞) |

全てのx>=5・R>=0で、H(R;(x,5);8)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailは

    R >= x+14  =>  H(R;(x,5);8) = (x+5) mod 2.

値2の定常位置は{1,3,5,7,19}。x=14だけはO[19,27]が一時的に加わる。z=8族の定常値2位置はy=1..5が「{1,3,5,7}∪{2y+9}」（11,13,15,17,19）を5点連続で満たす（z+2y+1型）。値1の頭部O[9,17]={9,11,13,15,17}=z+2i+1 (i=0..y-1)でy=1..5の各切片を貫く。x=14の掃引帯はz=8族の掃引位置x=z+y+1（y=1..5でx=10..14）と掃引範囲O[2y+9,2y+17]に一致する。値1帯E[20,x+13]/E[20,x+14]はtailが1になる側（y=5ではx偶数行）にI[x+15,∞)が付く点で族共通の構造のまま、O帯ではなくE帯（z=8族は偶数帯・z=9族は奇数帯）である。x=15はA子が掃引行x=14を横切る過渡行で、定常は偶数x>=16・奇数x>=17から始まる。

## 証明

R=0は終局で値0。R>=1,x>=6の選択肢は

    A = H(R-1;(x-1,5);8)
    B = H(R-1;(x,4);8)
    C = 1 xor H(R-1;(x,5);7)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0987、CはK0981で評価できる。x=5では二つのトークン減少手が同じ(x,4)子（最大トークン5）に合流するため、A=B=K0987のx=5行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す。mex対応は次の通り。

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| mex | 2 | 0 | 1 | 0 | 1 | 0 | 0 | 1 |

各行はAに帰納仮説、BにK0987、CにK0981を代入した子値集合である。x>=16偶数行とx>=17奇数行では、帯端だけがxに依存し、署名は一定である。これはAがx-1行の閉形式、B・Cがx行の閉形式で、21<=R<=x+13の全域で帯ごとに子値が定数となる（例: 偶数X行のE[22,x+12]でA=(x-1)奇数行のE内、B=z=8,y=4の偶数行even(r,18,x+12)/I外、C=1 xor z=7,y=5の偶数行O[19,x+13]内・I[x+14,∞)内の子値一定性）ことによる。x=15はA子が掃引行x=14を横切る過渡行で、帯端・署名が定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+13を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+14ではK0832の高R tail定理を各子に適用できる。x偶数ならA=B=C=0で親値1、x奇数ならA=B=C=1で親値0となり、親tail (x+5) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=8,y=5切片のみを扱う。z=8,y>=6、z=9のy>=5、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=8族の定常第5点 2y+9 の一般化（y=1..5の5点連続）も観察であり証明ではない。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
