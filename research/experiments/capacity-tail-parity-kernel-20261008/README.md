# 任意容量余裕の上位h列・下位偶奇Grundy核（2026-10-08）

## 対象と定理

抽象容量ゲームを考える。整数1<=h<w, m>=1, r>=0、降順占有数m>=x_1>=...>=x_w>=0、sum(x_1,...,x_h)<=r。1手は一列を1増やして安全性を保つ。n=w-h、u=(x_1,...,x_h)、b=u_h、s=sum(x_{h+1},...,x_w)とする。

U(u)を上位h成分のうちm未満の一つを1増やして降順にした合法な形の集合とする。上位和がrに達しているならUは空。p=(n*b) mod2として、上位和が大きい形から

    F(u)=mex({F(v) xor p : v in U(u)}) xor p

を再帰定義する。すると任意の安全局面について厳密に

    g(x)=F(u) xor (s mod2)

である。従って下位n列の個別占有形は不要で、その合計偶奇だけがGrundy値に影響する。Fがnに依存するのはその偶奇だけ。余剰列2本の追加では上位形と下位石数偶奇が同じなら値が変わらない。

## 商ゲームの厳密性

下位の各占有数は0..bなので0<=s<=N=n*b。上位列への着手は(u,s)から(v,s)へ移る。下位列のうちb未満を増やすと(u,s+1)へ移る。この種の手が存在することとs<Nは同値。下位列のちょうどbを増やすと、上位のb列と入れ替わるので、商では上位b列への着手と同じ(v,s)になる。したがって商状態の全子集合は正確に

    {(v,s):v in U(u)} union ({(u,s+1)} if s<N else empty)

である。物理的な着手点数や終局盤面数を保存する主張ではない。全手で石数が1増えるため、終局からの帰納で同じ(u,s)は同じGrundy値を持つ。

## mexの交換補題と全称帰納

tau(z)=z xor1とし、Aを有限集合、a=mex(A)とする。このとき

    mex(tau(A) union {a})=tau(a)
    mex(A union {tau(a)})=a

が成り立つ。前者はa=2tならAが0..2t-1を含み2tを欠くため、tau(A)が0..2t-1を含み2t+1を欠くことから従う。a=2t+1ならAが0..2tを含み2t+1を欠き、tau(A)は0..2t-1を含み2tを欠く。後者はmexの定義から直ちに従う。

上位和の大きい形vでg(v,s)=F(v) xor(s mod2)を帰納仮定とする。E={F(v):v in U(u)}、N=nb、p=N mod2、A={z xor p:z in E}、a=mex(A)と置く。s=Nでは下位手がなくg(u,N)=a。sをN-1から0へ下げる帰納で

    g(u,s)=a xor((N-s) mod2)

を示す。N-sが奇数なら上位子値はtau(A)、下位子値はaなのでmexはtau(a)。偶数なら上位子値はA、下位子値はtau(a)なのでmexはa。ゆえにg(u,0)=a xor p=F(u)であり、一般のsでもg(u,s)=F(u) xor(s mod2)。上位和最大の基底もEが空の場合として含まれる。□

## 一様上界と計算量

U(u)の異なる子は高々h個なので、a=mex(A)<=h。0..hにxor1を作用させた最大値はhが奇数ならh、偶数ならh+1。従って**全局面でg<=h（h奇数）、g<=h+1（h偶数）**。特に**h=3、すなわちK0352の一般位置4次元平行列版では容量余裕4以上も含めg<=3**を無界に証明した。一般h>=4のg<=3は未証明。

上位降順形は高々binom(m+h,h)個。各形の上位子は高々h個なので、固定hではmの多項式時間で全局面のGrundy値を厳密評価でき、wに指数的に依存しない。K0352の幾何条件q=r+1>2w、底面一般位置のとき平行列ゲームへ適用できるが、標準二次元11×11には適用できない。
