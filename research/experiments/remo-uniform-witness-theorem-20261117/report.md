# 生存者列最小周期r=2..32（小witness棄却）と定理Wの全C強化・h*算術

実験: `remo-uniform-witness-theorem-20261117`（2026-11-17）
対応項目: K0925

## 命題

K0859定理Dの計数再帰 E(C,r)（Δ=0一様盤・終端サイズC・r人・
K0919定理PERの対象と同一の再帰）について:

**定理W+（全称・全C・証明つき・K0924定理Wの強化）**: すべての
r ≥ 2, C ≥ 1, d ≥ 1 について

> elim(E(C+d, r)) = elim(E(C, r)) ⟺ Q(r) | d

であり、Q(r) ∤ d のとき elim列の差は**すべての C ≥ 1** で同じ
位置 h*(d,r) で生じる。K0924定理Wは C=1 固定版。本項は同じ
均一オフセット帰納の**帰納ステップが C を参照しない**ことを
明示して全C版を与える（よってelim列ではすべてのC ≥ 1が
witness であり、「witness C=1」は一般Cの中の一点にすぎない）。

**系1（全称・K0924系MPVと一致・独立再導出）**: elim列のC方向
最小周期はすべての r ≥ 2 でちゕど Q(r)、周期は Q(r) の倍数全体。
ペア列（elim, 生存者）の最小周期も全rでちょうど Q(r)。K0924
系MPVの相互検証になる。

**定理S32（機械・r=2..32・生存者列の拡張）**: 生存者列のC方向
最小周期は r = 2..32 の全rで**ちょうど Q(r)** である。K0922定理
MPの生存者列分（r ≤ 16）を r ≤ 32 に拡張し、K0924が「r ≥ 17 の
生存者列最小性は窓走査が必要で未到達」と残した部分を、
**小witness棄却への手法転換**によって解決する:

- K0922補題DIV（全称）により生存者列の周期集合は最小周期 m(r)
  の倍数全体で m(r) | Q(r)。よって**各真約数 d を1つの
  witness C で棄却すれば十分**で、[1, Q(r)] の完全走査は不要。
- 実際には witness は小さい: Q(r) の全真約数72,397個
  （Q(32) ≈ 1.44e14 の18,431個を含む）がすべて witness
  C ≤ 150 で棄却される（観測最大 28 = r=29・フォールバック窓
  [151,1500] は不使用）。

**h* の算術（d=Q/p）**: Q(r)/p（p 素数・Q/p が真約数）に対して
k(k+1) | Q は常に成立する（k ≤ r−1）ため、d=Q/p で条件 M_h
（k_h(k_h+1) | d）が失敗するのは v_p(k_h(k_h+1)) = v_p(Q) の
とき、かつそのときに限る。フェーズ順は k の降順なので最初の
失敗は最大の k で起きる:

> h*(Q/p) = 1（v_p(r) = v_p(Q) のとき・M_1 失敗）、それ以外は
> r+1 − max{k ≤ r−1 : v_p(k(k+1)) = v_p(Q)}

（r = 2..24 の全 (p, r) で機械確認・W6・不一致0）。

### 証明（定理W+・メモ）

フェーズ h（1 ≤ h ≤ r−1）は生徒数 k_h = r+1−h で進行し、配りは
「手持ち ℓ_h 個を順番に1個ずつラウンドロビン配布（li =
(τ_h + ℓ_h) mod k_h 番目が敗者・手持ちゼロ化）」。run A =
E(C,r)、run B = E(C+d,r) とし、K0919 の条件列 M_1: r|d、
M_h: k_h(k_h+1)|d（2 ≤ h ≤ r−1・lcm はちょうど Q(r)・K0919
素数冪補題）の最初の失敗を h* とする（存在 ⟺ Q(r) ∤ d）。

**補題W（均一オフセット帰納・K0924と同一の帰納）**: M_1..M_{h−1}
が成立している限り両runはフェーズ 1..h−1 をフェーズロック
（同一の生徒リスト・手番・敗者・手持ち差一様）で通過し、
フェーズ h 開始時点で手持ち差 D_1 = 0, D_h = d/(k_h+1)、
ℓ差 X_1 = d, X_h = d/(k_h+1) が成り立つ。

- 基底（h=1）: 両run手持ち全0・手番0。ℓ差 d。M_1 不成立なら
  li 差 = d mod r ≠ 0 で敗者が異なる（h*=1）。成立なら配布差
  は各生徒ちょうど d/r（D_2 = d/r = d/(k_2+1)）。
- 帰納段（h ≥ 2）: D_h = d/(k_h+1) が一様整数（k_h+1 = k_{h−1}
  で M_{h−1} より整数性）。ℓ差 X_h = d − k_h·D_h = d/(k_h+1)。
  M_h 不成立（h=h*）なら k_h ∤ X_h で li^B − li^A ≡ X_h ≢ 0
  (mod k_h) となり敗者が異なる（elim列の最初の差）。成立なら
  配布差は各生徒ちょうど X_h/k_h で li・敗者は同一のまま
  D_{h+1} = d/k_h = d/(k_{h+1}+1) に更新される。
- **ℓ ≥ 0**: フェーズ h+1 の手持ち ℓ_{h+1} は直前の敗者の受領
  石数に等しい（配布後の全手持ち総和は常に C）ゆえ再帰は健全。
- **C 非依存（本項の追加観察）**: 基底・帰納段のどの式も C を
  参照しない（ℓ^A ≥ 0 であれば任意の C で同一の議論）。
  よって差はすべての C ≥ 1 で生じ、位置も h* に一致する。∎

**系1の導出**: 定理W+より「T が elim列の周期 ⟺ Q(r) | T」。
ペア列は elim列より細かいので同様。

**定理S32の導出**: 生存者列の周期集合に K0922 補題DIV（Bezout
によるgcd閉包・列汎用）を適用すると最小周期 m(r) は Q(r) の
約数。各真約数 d に witness C ≤ 150 が存在すれば m(r) ≠ d、
d は任意の真約数だから m(r) = Q(r)（r = 2..32 で機械検証・W5）。

## 限界

- Δ=0一様盤（定理D域）限定。非一様盤には一切言及しない。
- 定理S32は r ≤ 32 の機械確定。生存者側の全称は OPEN
  （「witness が常に有界（観測では C ≤ r−1）」が示せれば
  補題DIVにより全称最小性が閉じる・有界witness予想として
  記録するのみで証明しない）。
- 定理W+の elim 全称は K0924 と同一の主張の独立到達であり、
  二重証明としての付加価値のほか、全Cステートメントの初出。
- 生存者列では C=1 が witness にならない真約数が多数ある
  （r=32 で18,431個中9,146個・監査JSON記録）。
- 11×11空盤・クラスフロンティアは本項と無関係でUNKNOWNのまま。
