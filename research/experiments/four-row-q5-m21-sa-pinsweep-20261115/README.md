## 定式化 (k3 バケット)

- 15石の安全極大配置の行 profile は必ず [3,4,4,4] (鳩の巣: 各行の安全石数は <=4)。
- class {0} k=3: 行0がちょうど3石。p0: x1=0 ((0,0) が石) / p1: x1=1 ((0,0) 空・(1,0) 石)。
- U := 行0の空セルのうち blocked でないものの個数。極大 <=> U=0。
  行0は3石なので行満杯では遮断されず、blocked(e) <=> e を通る count-4 円が存在。
- safeSwap(a,e): 石 a を除去し同行の空セル e に追加 (profile 保存)。
  安全性: e を通る円 g のうち a が g 上に無く石数4のものが存在しないこと
  (a が g 上の円は除去で3に落ちるため自動的に安全)。
- 判定は増分維持 (add/rm で円石数 3<->4 の境界でのみ cnt4[] を更新)。

## 構造的観察 (ヒューリスティック)

- p1 の U=1 は端点 ((0,0)/(20,0)) に集中し、内部セルは常に何らかの円で遮断済み。
- 円17ピン下の p1 では未遮断セルは常に (0,0) — 端点の遮断が最後の障害。
- p0 のピン付き U=1 は孤立局所最適で、未遮断セルは内部セル ((2,0)/(1,0))。
- seed の (20,0) 遮断には「(20,0) 通過円上の石数が最大2」という構造的隙間があり、
  単スワップ修復が原理的に不可能 (run 3)。多様体孤立 (サイズ1) と合わせて、
  p1 seed 近傍の U=1 の谷は深く狭い。

## カバレッジの注意

ピン掃引は「(20,0) が空きセルで blocker 円 g∋(20,0) の4石をピン」する
サブケースのみをカバーする。「(20,0) が石」のサブケースは自由SAのみで
触れている (厳密な被覆は class-split の sat4.js x2 分割が担う)。

## 次段階提案: blocker 円ケース分割 (kissat・厳密・完全分解)

SA の観察 (難所が (20,0) の遮断構造に集中) を厳密に変換する完全分解。
バケット c0k3p1 (c0k3p0 も同様) を:

- **A: cell (20,0) が石** — unit 1 本のインスタンス、と
- **B: cell (20,0) が空** — 極大性より何らかの count-4 円 g∋(20,0) が存在する。
  (g, S) (S は g から (20,0) を除いた点集合の4元部分集合; p0 かつ g∋(0,0) の場合は
  (0,0) 固定石を含めて3元部分集合) で完全場合分解。
  **p1 83 / p0 86 インスタンス** (静的フィルタ: 行0ピン <=2、p1 は (0,0) 禁止)。
  sat4.js 方式の unit pin で符号化可能。

に分解する (計 p1 84 / p0 87 インスタンス)。全 UNSAT ⟹ バケット全体が UNSAT。
被覆の完全性: U=0 の配置で (20,0) が空なら blocker 円 g の4石が確定し、
その (g, S) ケースに厳密に対応する (g 上の石数は安全性よりちょうど4)。
各インスタンスは unit ~8 本と強く束縛され、軽い決着が期待できる。
ピン掃引 SA が全ケース bestU>=1 (大半 >=2) だったことは、各ケースが早く
UNSAT に落ちることと整合する示唆 (証拠ではない)。
本分解は x2 分割 (第2石位置) と直交し、併用も可能。他の難バケット
(k2/k1・他クラス) にも同じ手法が一般化できる。
