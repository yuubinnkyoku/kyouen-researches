## 主定理

d=x-y、Y=2y、S=x+y と置く。O[a,b] は [a,b] 内の奇数、E[a,b] は偶数、I[a,∞) は全整数区間とする。過渡16行とは 2y+d<=18 を満たす (y,d) 全体である（y>=6 の行では (6,0..6),(7,0..4),(8,0..2),(9,0) の16行、S=18 の4行 (6,6),(7,4),(8,2),(9,0) を含む）。S=19 の4対角行は (6,7),(7,5),(8,3),(9,1) である。それ以外は S>=20 である。

Grundy値2の位置集合は

\[
T(x,y)=
\begin{cases}
O[1,S]\ \text{（S偶数なら O[1,S-1]）} &S<19,\\
O[1,\mathrm{top}] &S=19,\\
O[1,19] &S\ge20,\ d\le18,\ \text{活性行以外},\\
O[1,19]\cup\{Y+(d+19)/2\} &S\ge20,\ d\equiv3\pmod4,\ d\le19,\\
O[1,19]\cup O[Y+19,S+19] &S\ge20,\ d=20,\\
O[1,19]\cup\{Y+19\} &S\ge20,\ d\ge21,
\end{cases}
\]

ただし対角行 S=19 では top=Y+(d+19)/2（d≡3 mod 4）または
top=Y+(d+19)/2-1（d≡1 mod 4）である（4行の値2上端は 25/25/27/27=2y+q_o(z-y)、
交差10実例目の一致）。d≡3 (mod 4)、d<=19 が活性格子行で、格子点 r=Y+(d+19)/2
（常に奇数R）は全z規則 d+z≡2 (mod 4) の z=19 実現（d=3,7,11,15,19）。
**d=19=d=z 行では格子点 Y+(19+19)/2=Y+19=2y+z が pin 位置そのものに一致する**
（z=17 の d=17 行と同型の重合）。

Grundy値1の位置集合は

\[
P(x,y)=
\begin{cases}
I[S+1,\infty) &S<19,\ S\text{ 奇数},\\
\varnothing &S\le18,\ S\text{ 偶数（S=18の4行を含む）},\\
E[20,Y+18]\cup O[Y+21,S+19]\cup I[S+20,\infty) &d\ge21\ (S\text{ 奇数のみ最後の項}),\\
E[20,Y+18] &d=20,\\
E[20,\mathrm{rt}-1]\cup I[\mathrm{rt}+1,\infty) &d\text{ 奇数},\ d\equiv3\pmod4,\ d\le19,\\
E[20,U]\cup\{U+1\} &d\equiv2\pmod4,\ d\le18,\\
E[20,U] &d\equiv0\pmod4,\ d\le18,
\end{cases}
\]

ただし rt=Y+(d+19)/2、U=Y+9+2⌊d/4⌋（偶数）である。不活性奇数行
（d≡1 mod 4、d<=17）では rt が偶数に落ち、P の高域は I[rt,∞) に
2点だけ空洞（rt-1, rt は E 終端と重なるが P 陌地の1点 rt-1... 正確には
E[20,rt-2]∪I[rt,∞)）を除いて稠密である（z=18 と同じ単一ギャップ型）。

**d≡2 (mod 4) 行の一点追加 U+1**（奇数R、値1）が、z=17 型の単純
z+2シフトに対する唯一の構造修正である（z=17 では d≡1 mod 4 の不活性行は
E 終端 U で止まる）。この1点は probe fit が最初の41点不一致から特定した。
T(x,y) と P(x,y) を [1,S+19] に制限した集合は互いに素である
（署名帯表の一意被覆と深部散点検査で全称にわたり照合）。残りはGrundy値0であり、
全ての x>=y>=6、R>=0 に対して

\[
\boxed{H(R;(x,y);19)=
\begin{cases}
S\bmod2 &R\ge S+20,\\
2&R\in T(x,y),\\
1&R\in P(x,y),\\
0&\text{otherwise}
\end{cases}}
\]

が成立する。R=0 は終局値0である。R>=S+20=S+z+1 の tail が最優先で評価され、
P の無限区間は [1,S+19] でのみ有効である。

## 配置の意味

- **値2ラダー O[1,19]=O[1,z]**（奇数z型、z=17と同じ）。「S<19 では偶ラダー
  O[1,S-1]、奇ラダー O[1,S]」の過渡規則も z=17 と同一構造。
- **活性格子**: 点 r=2y+(d+z)/2 が d+z≡2 (mod 4) で活性化する全z規則の
  z=19 では d≡3 (mod 4)（d=3,7,11,15,19、r=Y+(d+19)/2、常に奇数R）。
  d≡1 (mod 4) の候補位置は偶数Rに落ち活性化しない（z=18 の鏡像関係）。
- **pin**: 定常 pin は Y+19=2y+z（奇数z型、z=17 と同じ 2y+z。偶数z=16,18 は
  2y+z+1）。d>=21 の全行で T={Y+19}。
- **掃引行**: d=z+1=20 の行は掃引帯 O[Y+19,S+19]=O[2y+z,S+z]（z=17 の
  O[2y+z,S+z] と同型、z=16/z=18 の 2y+z+1 型と対照的）。掃引帯の下端は
  ちょうど pin 位置に一致する。
- **値1基底帯 E[20,·]**（偶点系）。z=17 の E[18,·]=E[z+1,·]、z=18 の（反転した）
  O[19,·]=O[z+1,·] と同じく下端節は z+1=20 で不変。
- **d≡2 mod 4 行の U+1 追加点**: U=Y+9+2⌊d/4⌋ の直下の奇数点 U+1 が値1。
  z=17→z=19 のシフトで唯一の新規構造。帯表上は d≡2 行の署名が '02' 点と
  なり、d=0 行では同じ位置のコードが '13'、d>=4 の d≡0 行では '123' で
  出現する。
- **過渡16行**: S<19 では P は I[S+1,∞)（S奇数）か ∅（S偶数）だけに退化し、
  T は O[1,S]/O[1,S-1] の対ラダー。しきい値 2y+d<=18 は z=18 の
  2y+d<=18=z と初めて一致（z=17 の 2y+d<=17、z=18 の 2y+d<=18 と同じ
  「2y+d<=z」構造）。
- **対角行 S=19**: 4行 (6,7),(7,5),(8,3),(9,1) は T 上端が 25/25/27/27=
  2y+q_o(z-y) に達する（y=1..5 切片で交差検証済みの式の10実例目）。
- **tail と低R**: R>=S+20=S+z+1 で値 S mod 2（tail開始族式 S+z+1 は全出版族
  と同じ）。低Rは R<=25=z+6 で単一トークン S=x+y に縮約し、境界は R=26 で
  鋭く破れる: witness (14,6)@R=26 は H=0 に対し単一トークン値 1。
  R<=z+6 は z=14..19 で6例連続（一般z版は未証明の観察）。
  witness行 (14,6) は z=17/z=18 の (12,6) と同じ「y=6・ピン近傍」行、
  破壊高さ R=z+7 は全系で同型。

## 証明骨子

y強帰納と各行内の d 外帰納による。y=6 の B子は K1260（z=19,y=5出版切片）、
C子は 1⊕K1259（z=18,y>=6一様族）、y>=7 の B子は y 帰納仮定、A子は d 外帰納仮定
（d=0 は A==B 多重集合合流）。1<=R<=S+19 の全域を過渡16行込みの偶奇別
A/B/C署名帯表（TRANSIENT 16行の固定辞書 + S=19対角式 + S>=20 の7クラス・
パラメトリック帯: d=20掃引、d>=21 pin、d=19特異、奇数d活性/不活性、
偶数d≡0/≡2、S=20特異）で一意被覆し、各帯コードの子値集合から mex を
機械計算する。R=0 は終局、R>=S+20 は K0832 一般 tail。各 (y,d,R) で
子の値集合と mex が帯コード・親閉形式の3者で一致することを監査が機械照合する。
