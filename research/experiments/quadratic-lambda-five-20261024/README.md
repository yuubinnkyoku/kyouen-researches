# 二次形式λ版5×5：全実数の全安全局面分類

2026-10-24、ローカルmain e4b1c5ef上での研究。リモート照合はDNSエラーで未完。
現在の結論の正本はK0534。規則は相異なる四点の
`det[x²+λy²,x,y,1]=0` を禁止する通常プレイ。

## 全実数パラメータの結論

5×5盤で空盤Grundy値が0となるのは、厳密に次の13個。

`{−4,−3,−2,−3/2,−2/3,−1/2,−1/3,−1/4,0,1/2,2/3,3/2,2}`

λが3または1/3なら空盤値3。それ以外の全実数λは空盤値1。
正・負・0・無理数のすべてを含む。

全12,650四点組の係数を完全列挙し、恒等的に禁止となる共通284辺と、
167個の有理例外を得た。例外外は離れた区間も含め同一ゲームなので、
共通族と各例外の168族で全実数を網羅できる。
全称帰着の証明は[先行実験のproof.md](../quadratic-lambda-20261024/proof.md)。

全168族、延べ**89,789,920安全局面**の全Grundy値を二方式で照合した。
同じ占有集合が複数の族に現れた分も延べ件数に含む。
全局面で現れる最大Grundy値は7。

## 初手の分類

点番号は `i=5*y+x`。共通族を含む148族は全25初手が勝ち手。
後手必勝の13族には勝ち初手がない。

全初手の子Grundy値そのものもresults.jsonに保存した。
λ=1は既存の標準5×5の空盤・初手・安全局面数151,394を再現する。

## 独立検査の構成

1. Pythonで4×4行列式の置換展開とアフィン余因子による係数計算を照合し、
   有理数の全例外集合と禁止辺を構成する。
2. [census.cpp](census.cpp)は別の整数3×3行列式から禁止辺を再構築し、
   全辺の完全一致を確認する。全到達局面の探索では三点補完を増分伝播する。
3. [audit.cpp](audit.cpp)は元の禁止辺から全2²⁵部分集合の安全性を帰納判定し、
   降順の全subset DPで全安全局面のGrundy値を計算する。
4. それぞれのGrundy配列を一時ファイルへ書き、**全局面をバイト単位で完全比較**する。
   未安全集合の255を含む長さ2²⁵の配列そのものを比較し、ハッシュ一致だけでは済ませない。
   加えて安全層数・Grundy分布・終局サイズ分布・全初手値も一致させる。
5. 先行2×2〜4×4の51族についても、禁止辺・全分布・全初手値をC++方式で再現する。

一時配列はOSの一時ディレクトリに固定2ファイル、合計64MiBだけ保持し、
成功時に削除する。バイナリもrepo外へ置く。

```sh
uv run --locked python research/experiments/quadratic-lambda-five-20261024/run.py
```

Python標準ライブラリとC++17コンパイラg++を使う。CXXでコンパイラを指定できる。
[results.json](results.json)は共通辺、各族の追加辺、全分布、全初手値、完全比較の成否を含む。
JSONは作業ドライブ容量を節約するため空白を圧縮して保存している。

## 採用範囲

結果は5×5の有限全数計算と全実数への数学的帰着による。
6×6以上や、非退化楕円・双曲線だけを禁止する別ルールは未分類。
標準4×4の「λ=1のみ後手勝ち」という結果を他の辺長へ一般化してはならない。
λ=0の十分に縦長い盤には別の一般定理K0533・K0511がある。
