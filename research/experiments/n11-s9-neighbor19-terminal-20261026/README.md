## 対象と探索

直前の独立証明済み9石18根を一石交換して得た正準候補5,836類から、合法10石子の対称類数が少ない順に148類を試験した。20類で全合法10石子が手番側WINとなり、既存の証明限定9石WIN 170根と照合して重複1類を除いた**19根**を固定した。候補選別と途中打切りは証明根拠に用いない。

- 9石19根：全合法10石子319辺（各根で対称類化した子の延べ数）、相異なる10石子**314類**。
- 314類すべてを保存済み勝敗表なしで終局まで解き、**手番側WIN**を検証した。従って9石19根は手番側LOSS、**元先手WIN**。
- 9石根を一石戻して得られる8石WIN証人親は**164対称類**。各親は少なくとも1つの合法9石WIN子を持つ。
- 独立3×3差分行列式・4×4 Bareiss整数行列式の勝敗、合法着手集合、葉ごとの探索状態数が一致。状態数合計は**各実装25,435**。
- 凍結8石LOSS 294類との衝突は0件。凍結8石WIN 13,501類および凍結9石WIN 1,611類との重複も0件（凍結表は勝敗証明に使わない）。

19根は既存の証明限定9石WIN 170根と重複しない。**164個の8石親が既存の証明限定8石WIN 1,824類に対して何類純増か、7石の被覆増分はいずれも未集計。** 新たな7石全子証明は主張しない。
