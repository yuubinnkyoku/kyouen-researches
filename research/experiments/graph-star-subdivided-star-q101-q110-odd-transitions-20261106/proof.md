## 定理

## 証明

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) と置けば負根は \(F(y)=r-y-(a-y)y^k=0\) に対応する。

\(0<y\le1\) では \(F(y)\ge r-y-(a-y)=r-a>0\)。\(y\ge a\) では \(F(y)=r-y+(y-a)y^k>0\)：\(a\le y\le r\) は自明、\(y>r\) は \((y-a)y^k>(y-a)y>y-r\) による。根候補は \(1<y<a\) に限る。

\(H(y)=(a-y)y^k\) の最大点は \(y_*=ka/(k+1)\)。境界 \(k_-=k_+-2\) において \(H(y_*)<r-a\) なら \(F>0\) で実根なし。境界 \(k_+\) において \(F(y_*)<0\) なら \(F(1),F(a)>0\) より負根が少なくとも2個。\(T(-x)\) の符号変化は2回なので、デカルトの符号法則からそれらは相異なる単根で他の負根はない。正根は正係数性からない。

\(1<y<a\) で \(k\) が増すほど \(F(y)\) は厳密に減少する。したがって2境界の検証だけで各qの全奇数kを覆う。

## 厳密な整数検証

\(A=k(r+2), B=(k+1)(r+1)\) とする。非存在境界での十分条件 \(H(y_*)<r-a\) は

\((r^2-2)(k+1)B^k>(r+2)A^k\)。

存在境界の条件 \(F(y_*)<0\) は

\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)。

以下の20件の整数不等式を独立したPython整数計算で確認した。浮動小数点は使わない。

```python
bounds = [[101,1265],[102,1281],[103,1295],[104,1311],[105,1325],[106,1341],[107,1355],[108,1371],[109,1385],[110,1401]]
for q, kp in bounds:
    r = q - 3
    for k, existence in ((kp - 2, False), (kp, True)):
        A, B = k * (r + 2), (k + 1) * (r + 1)
        assert B < A
        if existence:
            assert (r*B-A)*(r+1)*(k+1)*pow(B,k) < (r+2)*pow(A,k)*B
        else:
            assert (r*r-2)*(k+1)*pow(B,k) > (r+2)*pow(A,k)
print("20 exact inequalities passed")
```
