# 交換可能な残余点群の極大配置多項式：全称定理と独立検査

2026-10-20。対象：任意の有限点集合上の、禁止集合を一つも完成させない一点追加ゲーム（通常プレイ）。本稿の対象は**終局の配置数・石数分布**であり、Grundy値の計算ではない。K0344の交換可能class縮約はGrundyを保存するが、終局配置数を保存するとは限らない。

## 定理

点集合を `V=X ⊔ Y`、`|X|=k≥1`、`|Y|=h` とする。空集合を含まない任意の禁止集合族 `F` は、`X` の任意の置換で不変とする（`X` は完全交換可能class）。`F` は包含極小化していなくてもよい。

各禁止集合 `e` に対し `s=|e∩X|` と `A=e∩Y` を記録する。交換可能性により、ある `(s,A)` が現れれば、`X` の任意の `s` 点を `A` と併せた集合がすべて禁止集合となる。この組の集合を `O` とする。

`T⊆Y` に対し

`c(T) = min({k} ∪ {s−1 : (s,A)∈O, A⊆T})`

と定義する。`c(T)=-1` は `T` 自体が禁止集合を完成させることを意味する。`c(T)` は `T` に関して単調非増加である。

ちょうど `j` 点からなる極大安全集合の個数を `a_j` とすると、**終局配置多項式**は

`P_F(z) = Σ_j a_j z^j = Σ_{T⊆Y : c(T)≥0, ∀y∈Y\T c(T∪{y})<c(T)} binom(k,c(T)) z^{|T|+c(T)}`。

したがって、交換可能classの具体的な `2^k` 個の部分集合を一度も列挙せずに、`O(2^h(|O|+h))` 回程度の整数演算（組合せ数の前計算を除く）で正確な終局配置数・石数分布を得る。特に総極大配置数は `P_F(1)` である。`P_F` の次数集合から終局石数の可能値、最小・最大値、石数差の最大公約数を求められる。最後の量には既存K0339の多人数版敗者固定判定が適用できる。

## 証明

外側の占有集合を `T` と固定する。禁止集合のうち外側部分 `A` が `T` に含まれるものだけが、`X` の占有数を制限する。`s` 個の `X` 点を含む禁止集合の軌道があれば、`X` の占有数 `t` は `t≤s−1` であることが必要十分である。`s=0` の場合は `T` 自体が違法となる。よって `T` と `X` の任意の `t` 点を合わせた集合が安全であることと `0≤t≤c(T)` は同値。

極大安全集合なら、`X` にさらに一点を加えられないので、必ず `t=c(T)` となる。逆に `t=c(T)` なら `X` の追加手は不可能である。残る `y∈Y\T` の追加手は、占有済みの `X` 点集合を保ったまま `T∪{y}` にできる場合に限って合法である。交換可能性によって、これは `c(T∪{y})≥c(T)` と同値。したがって極大条件は、すべての未占有 `y` について厳密不等式 `c(T∪{y})<c(T)` が成立すること。各 `T` で `X` の `c(T)` 点の選択は `binom(k,c(T))` 通りで、すべて同じ石数 `|T|+c(T)`。異なる `T` の配置は重複しない。総和式が従う。□

## 鋭い注意点と具体例

`k=4, Y={y}` とし、禁止集合を `X` の全3点組、および `{x,y}` (`x∈X`) とする。軌道は `(3,∅)` と `(1,{y})`。`c(∅)=2`, `c({y})=0` なので

`P_F(z)=z+6z²`。

実際、終局は `{y}` と、`X` から二点選んだ6通りである。K0344の内部容量縮約で `X` を2点にするとGrundy値は保存されるが、極大配置多項式は `z+z²` に変わる。したがって**Grundy保存縮約を終局配置の計数に流用してはならない**。本定理の二項係数は、縮約で失われる多重度を明示する。

## 検証と適用境界

- `verify_terminal_polynomial.py`: 全 `k=3,h=2` の `2^15=32768` 軌道族、全 `k=2,h=2` の `2^11=2048` 軌道族、追加3200乱択族（`k=4..6,h=2..3`）。計38016件で直接全配置列挙と上式が一致。
- `verify_terminal_polynomial.cpp`: Pythonとは別に、`k=3,h=2` の32768族を直接全配置列挙し、上式と一致。
- いずれも空禁止集合を含まない一般の対称禁止族を対象とし、冗長な禁止集合や一点禁止も許す。有限検査は実装監査であり、無限全称性の根拠は上記の証明。

**実際の11×11の残余禁止族**では、まず全包含極小辺からK0344の完全交換可能classを検出する必要がある。残余点全体を `X⊔Y` に分けて `h` が小さいときのみ、本定理の `2^h` 計算が有効。小さい `h` の出現頻度、共有solverの高速化、Grundyへの直接応用は未検証。`X` が単なる自己同型軌道であって全置換不変でない場合は本定理を適用できない。
