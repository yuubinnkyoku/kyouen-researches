# 全rank rでclass r点上限は誘導点削除kernelとして最良

`exchangeable-kernel.md` のrank4反例を全rank r≥2へ一般化する。
この節は通常Grundyに関する。misère版での最良性は主張しない。

## 一つの証人族

d≥1とし、Xをn点、外部をa,b,cとする。禁止辺は完全軌道

```
(d,{b}), (d−1,{a,c}), (0,{b,c})
```

すなわち各Xのd点+b、各Xの(d−1)点+a+c、および{b,c}である。
n<tの軌道は空で、その辺は存在しない。この族はclutterで、rankは高々d+1。
内部辺はなくXは交換可能。rootの通常GrundyをF(n,d)とする。

以下の全称公式が成立する。

```
F(n,1) = 2             n=0
         0             n≥1奇数
         3             n≥2偶数

F(n,2) = 0             n=0
         3             n=1
         1             n≥2偶数
         2             n≥3奇数

F(n,d) = n mod 2       d≥3, n≤d−2
         3−(d mod 2)   d≥3, n=d−1
         3−(n mod 2)   d≥3, n≥d.
```

## 補助ゲーム

H(n,l)をXの各l点+aだけを禁止するゲームとする。
l=0ではaが違法なのでH(n,0)=n mod2。
l=1ではn=0なら孤立aの1、n≥1なら奇数nで1、偶数nで2（三葉starの一般式）。
l≥2ではn<lなら全点が自由で(n+1)mod2、n≥lならH(n,l)=l mod2。
最後の式は

```
H(n,l)=mex{ (l−1)mod2, H(n−1,l−1) }      n≥l
```

から従う。l=2は右のstar値が1または2で左値も1なのでmexは0、
l≥3では両子の値が(l−1)mod2となり、mexはl mod2。

G(n,d)を外部b,c、軌道(d,{b}),(d−1,{c}),(0,{b,c})のゲームとする。
d=1ではcが違法でG(n,1)=H(n,1)。d≥2について

```
G(n,d)=1−(n mod2)      n≤d−2
        2+(d mod2)      n=d−1
        2+(n mod2)      n≥d.
```

低い領域では二点辺{b,c}とn孤立点だけである。残りの式は、b手・c手が
それぞれXを容量min(n,d−1)、min(n,d−2)まで制限し、X手がG(n−1,d−1)へ
移る再帰

```
G(n,d)=mex{ min(n,d−1)mod2, min(n,d−2)mod2, G(n−1,d−1) }
```

から得る（n=0ではXの子を省く）。n≥d−1では最初の二値が0,1なので、
最後の値2/3が交代する。d=2の境界G(1,2)=2とtail G(n,2)=2+n mod2を
starの式で直接確認し、dについて帰納すれば上の公式となる。

## Fの公式の証明

d=1は二点グラフだけなので直接計算できる。a手がH(n,1)、b手が1、
c手がn mod2、X手が二点辺{a,c}とn−1孤立点のxorでn mod2となる。
n=0のX手を省くとF(0,1)=2、n≥1では奇数0・偶数3。

d≥2ではa手がG(n,d)、b手がX容量min(n,d−1)と孤立a、c手がH(n,d−1)、
X手がF(n−1,d−1)である。従って

```
F(n,d)=mex{ G(n,d), (min(n,d−1)+1)mod2,
            H(n,d−1), F(n−1,d−1) }
```

（n=0ではX手を省く）。d=2ではGの式、Hのstar式、F(n−1,1)から
F(0,2)=0、F(1,2)=3、n≥2では偶数1・奇数2を得る。

d≥3、n≤d−2なら二つの混合辺軌道が空で、{b,c}と孤立aおよびn個のXが
残り、F=n mod2。n≥d−1ではb手とc手が0,1を与える。
境界n=d−1はa手が2+d mod2、X手も帰納法で同じ値なので、mexは3−d mod2。
d=3のtailはd=2の公式を代入すると3−n mod2となる。
d≥4のtailではa手とX手がいずれも2+n mod2となり、そのmexは3−n mod2。
これで全n,dについて公式を証明した。

## 上限の最良性

r≥4でd=r−1、Xをn=r=d+1点とする。F(d+1,d)=2+d mod2。
Xをd点以下へ誘導削除すると、0..d−2点では値0/1、d−1とd点では
3−d mod2であり、どれも元と異なる。rank rのXを常にr−1点以下へ
誘導削除してGrundyを保存する強化は成立しない。

r=3ではX3点でF(3,2)=2、0/1/2点の値0/3/1は全て異なる。
r=2ではX2点でF(2,1)=3、0/1点の値2/0は全て異なる。
従って全rank r≥2でclass r点上限は最良である。

これは外部a,b,cを保持する誘導点削除方式に関する最良性であり、
別のゲームへの置換や外部も変更する圧縮のサイズ下界ではない。
`verify_sharpness.py` が商count-subset mexでr=2..64を検査し、r=2..7では
別の全占有subset DPとも照合する。有限検算は上の全称再帰証明の代わりではない。
