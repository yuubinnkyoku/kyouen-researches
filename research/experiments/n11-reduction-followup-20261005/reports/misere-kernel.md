# 同じ交換可能class kernelはmisère補助mexとP/Nも保存する

`exchangeable-kernel.md` の通常プレイ定理の独立した追加スコープ。
misèreは最後の合法手を打った人が負ける二人・交互・有限impartialゲームとする。
9×9・11×11空盤の新しいmisère勝敗は求めていない。

## 補助mex

有限ゲームGについて補助値hを次で定義する。

```
h(G)=1                        Gが終端の場合
h(G)=mex{h(G'): G'はGの子}     非終端の場合
```

このhはGrundy数と区別する。通常の分離成分xorをhに適用してはいけない。
終端は手番側が勝つN、非終端ではh=0がP、h>0がNとなることはゲーム木帰納で従う。
他の任意ゲームとの直和のhを、部品hだけから計算できるという主張ではない。

## 補題: 孤立点を二つ加えてもhは変わらない

孤立点一つのゲームを*と書く。任意有限impartial Gとk≥0について
`h(G+(k+2)*)=h(G+k*)` が成立する。

Gのゲーム木高さに関して帰納する。Gが終端ならk個の孤立点だけなので
h列は1,0,1,0,…であり成立する。

Gが非終端の場合、各子G'で帰納法により孤立点数に関するh列は周期2である。
`A={h(G')}`, `B={h(G'+*)}` として、a=h(G), b=h(G+*)を置く。

```
a = mex A
b = mex (B ∪ {a})             ⇒ b≠a
h(G+2*) = mex (A ∪ {b}) = a.
```

最後の等式はaがAの最小欠損値であり、b≠aを一つ追加してもその欠損を
埋めないことによる。以後同じ子の周期と直前の孤立点手によってa,bが交代する。
孤立点が偶数個ならゼロ個に、奇数個なら一つに置き換えてhが一致する。

## 交換可能classの圧縮への適用

内部容量があるclassは、通常プレイproofの(i,T)商DAGが終端を含めて同型。
従って終端h=1、非終端mexでも一致する。

内部辺がなく混合深さdを持つclassは、通常プレイproofと同じ
(外部点数,d)の辞書式帰納を使う。d=0だけを上の孤立点周期補題へ置き換える。
X手はdを減らし、外部手は外部点数を減らすか内部容量へ移る。
したがって対応する全ての子hが一致する。
d≥1では比較するX点数がどちらもd以上なので両ゲームは非終端であり、
mexの一致が従う。全Xが禁止された場合や容量0の子も同じ終端規則で扱える。

結局、通常プレイのGrundy数を保存した同じ容量・深さ付き偶奇・孤立偶奇の
kernelは、このmisère補助mex hも、従ってmisèreのP/Nも保存する。
rank4でclass高々4点へ減らせる上限も変わらない。
rank4の4点必要反例は通常Grundyに関する反例であり、misère版上限の
最良性はこの証明から推定しない。
