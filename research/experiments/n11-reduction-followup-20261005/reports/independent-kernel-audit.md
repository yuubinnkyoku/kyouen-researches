# 交換可能class kernelの独立数学監査

2026-10-05 (JST)。`exchangeable-kernel.md` の容量補題、混合深さの偶奇安定化、
rank上限、最良性を独立に検討した。以下は残余更新やsingleton除去に依存しない
別定式化を使う。11×11空盤はUNKNOWNのままである。

## 軌道を占有数と外部subsetだけで表す

X内の全二点交換が自己同型なら、辺は完全軌道(t,B)に分かれる。
具体的なX点を選んだ数をs、外部Wの選択subsetをTとすれば、禁止条件は

```
ある軌道(t,B)で s≥t かつ B⊆T。
```

これは辺を含むことと正確に同値である。Grundy計算では、同じ軌道のX手が
複数あることは選択肢集合を変えないため、商局面(s,T)だけで十分。
この定式化は非極小辺も許す。現在違法な外部点を残して、合法手判定で
除外してよいため、cleanupの実装差は証明に入らない。

## 内部容量補題の監査

内部軌道(h,∅)の最小hに対し、すべての安全局面はs≤h−1。
k≥h−1のX点数をh−1へ誘導削除する。t>h−1の辺軌道は消えるが、
それらは元でもs≤h−1では禁止を起こせない。t≤h−1の軌道はすべて残る。
従って両側で同じ(s,T)が安全で、外部各手も同じ条件で合法。
X手はs<h−1なら両側で存在し、s=h−1なら元では内部禁止、縮約側では
物理点数によって不可能となる。商DAGは同型で、Grundyと終局手数集合を保存する。
元の証明の包含極小性を使う議論も正しいが、この監査ではそれを必要としない。

## 混合深さの偶奇安定化の監査

内部軌道なし、d=max tとする。同じ軌道族でk,k'≥d、k≡k' mod2を比較する。
辞書式(|W|,d)で帰納する。d=0ではXは孤立点集合なので
外部ゲームとの直和からg=g(W) xor(k mod2)で成立する。

Xを一つ選ぶと、t≥1の軌道は(t−1,B)となり、t=0の軌道は不変。
旧(t,B)の禁止は新(t−1,B)の禁止に包含されて不要である。
Bは非空のままなので内部軌道は生じず、新深さd'≤d−1。
両側は点数k−1,k'−1で、同じ偶奇かつともにd'以上。帰納法が適用される。
違法な外部点が生じても残したまま合法性で除けばよく、|W|が増えることはない。

外部点vを選ぶ手は、t=0の軌道のみで一手目の合法性が決まるため、k,k'で
同時に合法または違法である。合法な場合、vを含むBをB\{v}へ変換し、
外部点数は減る。内部軌道が生じないなら新深さd'≤dで帰納法が使える。
内部軌道(h,∅)が生じるならh≤d、従って容量h−1≤d−1であり、
両側のk,k'≥dに上の容量補題を適用して同じ商ゲームへ移せる。
h=1なら容量0となり、Xは全て違法となる場合も含む。

したがって各対応手の子Grundyが同じで、子値集合とmexも同じ。
各singletonの禁止・包含極小化を途中で実行する原実装は、同じ商ゲームから
到達不能点・冗長条件を取り除く操作なので定理を変えない。
任意の削除対象X点の選び方も完全置換対称性から結果に影響しない。

## rank上限とsharpness

rank≤Rなら内部容量は≤R−1。内部なしならB≠∅からd≤R−1、
同じ偶奇のdまたはd+1点に残すので≤R。各削除でGrundyを保存するため、
再検出したclassにも繰り返し適用できる。

rank4の証人X4、外部a,b,c、軌道(3,{b}),(2,{a,c}),(0,{b,c})は
clutter条件を満たす。Xの誘導点数0,1,2,3,4に対してGrundyは0,1,2,2,3。
元の4点を3点以下へ誘導削除する強化はすべて失敗する。
外部も変更する圧縮や別ゲームへ置換する方法を否定する反例ではない。

`scripts/independent_count_audit.py` はこの(s,T)商DAGを直接mex計算する。
全122+5097交換不変clutterの既存入力生成器を再利用し、値計算は残余辺更新、
双子core、module_coreのいずれも使わない。さらに深さ・rankを広げた
決定的なrandom軌道族を検査する。これは有限実装監査であり、全称性の根拠は
上記帰納法である。

## 最後の合法手が負けるmisèreへの追加監査

補助整数hを、終局で1、非終局で子hのmexと定義する。
misèreの終局はNであり、非終局のP/N再帰からPであることはh=0と同値。
このhをGrundyのxor加法則へ用いてはいけない。

任意の有限impartial game Gに、通常の一点自由追加ゲーム*を二つ直和しても
h(G+2*)=h(G)である。Gが終局の基底は、孤立点数0,1,2のhが1,0,1。
Gが非終局なら、各子Hについてh(H+2*)=h(H)を帰納仮定とする。
A={h(H)}、B={h(H+*)}、h0=h(G)、h1=h(G+*)と置くと

```
h0=mex A,
h1=mex(B∪{h0})≠h0,
h(G+2*)=mex(A∪{h1})=h0.
```

最後の等号は、Aがh0未満の全値を含みh0を含まず、h1≠h0だからである。
この孤立偶奇補題を上記(|W|,d)帰納のd=0基底へ用いる。
内部容量の商DAGは終局も一致し、その他の子対応も通常プレイの場合と同じ。
従ってkernelは補助hの値、特にmisèreのP/Nを保存する。
終局手数、一般misèreゲームのxor則、単なる通常Grundy一致からのmisère推論は
主張していない。有限count verifierも同じ全入力で補助hを別に検査する。
