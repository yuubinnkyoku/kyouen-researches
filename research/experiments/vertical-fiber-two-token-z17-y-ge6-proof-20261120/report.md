# 2トークン残余ゲーム z=17・y>=6 一様全Grundy分類

- 日付: 2026-11-20
- 対象: κ=1残余ゲーム H(R;(x,y);17)、x>=y>=6、R>=0
- 状態: **全称証明済み**
- 依存: K0832（残余ゲームの再帰・単一トークン式・一般tail）、K1080（z=17,y=5）、K1077（z=16,y>=6）

## 主定理

d=x-y、Y=2y、S=x+y と置く。O[a,b] は [a,b] 内の奇数、E[a,b] は偶数、I[a,∞) は全整数区間とする。過渡12行とは 2y+d<=17 を満たす (y,d) 全体である（S=17 の3行 (6,5),(7,3),(8,1) を含む）。それ以外は S>=18 である。

Grundy値2の位置集合は

\[
T(x,y)=
\begin{cases}
O[1,S]\ \text{（S偶数なら O[1,S-1]）} &S<17,\\
O[1,Y+(d+17)/2]\ \text{（d≡1）、}\ O[1,Y+(d+17)/2-1]\ \text{（d≡3）} &S=17,\\
O[1,17]\cup O[Y+17,S+17] &S\ge18,\ d=18,\\
O[1,17]\cup\{Y+17\} &S\ge18,\ d\ge19,\\
O[1,17]\cup\{Y+(d+17)/2\} &S\ge18,\ d\equiv1\pmod4,\ d\le17,\\
O[1,17] &\text{その他}.
\end{cases}
\]

d=17 では (d+17)/2=17 なので格子式は pin 位置 Y+17 を与え、d>=19 の行と一致する。
S=17 の3行では (6,5),(7,3) が上端23、(8,1) が上端25 に達する（ラダーが17を超えて伸びる唯一の行）。

Grundy値1の位置集合は

\[
P(x,y)=
\begin{cases}
I[S+1,\infty) &S<17,\ S\text{ 奇数},\\
\varnothing &S<17,\ S\text{ 偶数},\\
E[18,Y+16]\cup O[Y+19,S+17]\cup I[S+18,\infty) &d\ge19,\\
E[18,Y+16] &d=18,\\
E[18,rt-1]\cup I[rt+1,\infty) &d\text{ 奇数},\ d\equiv1\pmod4,\ d\le17,\\
E[18,rt-2]\cup I[rt,\infty) &d\text{ 奇数},\ d\equiv3\pmod4,\\
E[18,Y+8+2\lfloor d/4\rfloor] &d\text{ 偶数},\ d\le16,
\end{cases}
\]

ただし rt=Y+(d+17)/2 と置く。S=17 の3行は d 奇数の行に、S>=18 の判定と同じ式で含まれる。
T(x,y) と P(x,y) を [1,S+17] に制限した集合は互いに素である（深部散点検査で全称にわたり照合）。残りはGrundy値0であり、全ての x>=y>=6、R>=0 に対して

\[
\boxed{H(R;(x,y);17)=
\begin{cases}
S\bmod2 &R\ge S+18,\\
2&R\in T(x,y),\\
1&R\in P(x,y),\\
0&\text{otherwise}
\end{cases}}
\]

が成立する。R=0 は終局値0である。R>=S+18 の tail が最優先で評価され、上の P の無限区間は [1,S+17] でのみ有効である。

## 配置の意味

- 値2のラダーは一般行で O[1,17]=O[1,z] で上端は z。奇数 z（K1065, z=15 の O[1,z]）と同じ規則であり、偶数 z（K1077, z=16 は O[1,z-1]）と対照的である。
- 格子点（前倒し点）は d+z≡2 (mod 4) の行 d∈{1,5,9,13} に出現し、位置は r=Y+(d+z)/2=Y+9,Y+11,Y+13,Y+15。偶数 z=16 では d∈{2,6,10,14} の同じ r に現れ、r の位置集合は偶奇で変わらない。
- 格子式を d=17 まで延長すると (d+17)/2=17 であり、ちょうど掃引帯の下端 Y+17=2y+z に一致する。奇数 z では pin は 2y+z（z=16 では 2y+z+1）で、d=17 と d>=19 の両クラスに現れる。
- 掃引行は d=z+1=18 で、値2の掃引帯は O[Y+17,S+17]=O[2y+z,S+z]。
- 値1のラダー（基底帯）は 18=z+1 から始まり、d=18 でちょうど
  \[
  E[18,Y+16]=\{18,20,\ldots,2y+16\}=\{z+1,z+2,\ldots,2y+z-1\}
  \]
  の y 点になる（z=16 では奇ラダー O[17,Y+15]=\{z+1,\ldots,2y+z-1\} の y 点。オフセットの式は共通）。d>=19 でもこの基底帯が残り、さらに奇ラダー O[Y+19,S+17] が上に乗る。
- 値2は常に奇数Rに現れ、値1の帯は偶数Rの O[18,...] または奇数Rの O[Y+19,...] から始まる。d>=19 の行では偶奇両方のRに値1が出る。
- 過渡セルは (6,0),(6,1),(6,2),(6,3),(6,4),(6,5),(7,0),(7,1),(7,2),(7,3),(8,0),(8,1) の12行で、z=16 の過渡セルと同一の (y,d) 集合である（2y+d<=17 というしきい値が z に依らないため）。このうち S 偶数の (6,0),(6,2),(6,4),(7,0),(7,2),(8,0) の6行では値1が一度も出現しない。
- tail は R>=S+18=S+z+1 で S mod 2。K0832 の一般tail R>=S+|X|+z-1（|X|=2）の等号ケースに一致する。

## 全称証明

二段の帰納を用いる。

1. y=6 を基底行とし、各yについてd=x-yの増加に関する外帰納、y全体にわたる強帰納を行う。
2. y=6 のB子はK1080（z=17,y=5）の全称定理で閉じる。y>=7 のB子はy強帰納仮定で閉じる。
3. d>0 のA子は同じyのd-1行で閉じる。d=0 では A と B が同じ多重集合 (y,y-1) なので B の評価で足りる。
4. C子はK1077（z=16,y>=6）の全称定理で閉じる。
5. したがって全ての子値集合は上表の署名帯に一致し、表のmexが主定理のT/P式を与える。

R=0 は終局。中間領域 1<=R<=S+17 は上表が全域を被覆する。高残容量 R>=S+18 はK0832の一般tail

\[
R\ge S+|X|+z-1\quad\Longrightarrow\quad H(R;X;z)=S\bmod2
\]

に |X|=2, z=17 を代入して閉じる。よって帰納は全x,y,Rで閉じる。

## 低R単一トークン縮約の強化

閉形式をK0832の単一トークン式と比較すると、このz=17・y>=6族では

\[
R\le23\quad\Longrightarrow\quad H(R;(x,y);17)=H(R;(S);17)
\]

が成立する。K0832の一般条件 R<=z+1=18 より5段広い、族固有の系である。24では一様に延長できず、例えば

\[
H(24;(12,6);17)=0,\qquad H(24;(18);17)=1
\]

であり、(11,6)@25、(13,6)@25、(15,6)@25、(10,7)@25 など複数の行でも破れる。z=14（K1062）では R<=20、z=15（K1065）では R<=21、z=16（K1077）では R<=22 であり、境界 R<=z+6 が4例連続して観測されている。ただし本項の係は z=17 に限って全称的に成り立ち、一般z版 R<=z+6 は未証明の観察（予想）として区別する。この低R系はT/P閉形式からの帰結であり、全称証明の帰納を閉じるための前提ではない。
