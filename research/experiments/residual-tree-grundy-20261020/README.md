# 二点禁止残局：木でGrundy値4を実現する最小頂点数

2026-10-20。対象は**抽象的な二点禁止残局**（有限単純グラフの独立集合を一点ずつ構成する通常プレイ）。整数格子の共円残局としての実現可能性は主張しない。

## 結論（有限完全列挙による計算機援用証明）

- 木の空局面でGrundy値4を実現する最小頂点数は **8**。
- 8頂点の非同型木23種のうち値4を持つのは**ちょうど1種**。ほかの22種は値0または1。
- 8頂点のラベル付き木262144個のうち、値4は**20160個**（自己同型数2なので8!/2）。
- 達成木の辺：`(0,1),(0,2),(1,4),(1,7),(2,3),(4,5),(4,6)`。初手の子のGrundy値は頂点0..7の順に `[2,1,3,1,3,2,2,0]`。よってmexは4。

## 証明の有限性・網羅性

Prüfer符号はn≥2のラベル付きn頂点木と長さn−2の `0..n−1` の列との全単射。C++は全 `n^(n−2)` 符号を列挙する。n=1は一頂点木を直接扱う。各木の閉近傍N[v]を構成し、

`g(G)=mex {g(G−N[v]) : v∈V(G)}`, `g(∅)=0`

を頂点部分集合のビットマスクについて昇順で厳密計算する。再帰の全遷移で残りのマスクは真に小さいため計算は完結し、値は数学的定義と一致する。

PythonはPrüfer符号も閉近傍削除も使わず、NetworkXの非同型木生成と、占有済み独立集合への合法一点追加で別にmexを計算する。各非同型木のラベル付き個数は `n!/|Aut(G)|` から求め、C++の分布と完全一致した。独立検証は実装上の取り違えの検出であり、有限範囲を超える一般定理ではない。
