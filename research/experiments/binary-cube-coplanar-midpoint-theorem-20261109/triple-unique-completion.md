# 二値立方体の共面四点：三点の一意補完と三重線形性

## 結論（全次元の数学的証明）

任意の `d >= 2` に対し、相異なる三頂点 `a,b,c ∈ {0,1}^d` を含む共面四頂点集合は**高々一つ**である。存在する場合の第四頂点は座標ごとの排他的論理和 `e = a xor b xor c` に限られる。

三点が補完可能であるための必要十分条件は、各座標で三点のビットが一致しないとき、少数派のビットを持つ頂点の種類が三頂点のうち高々二種類であること。すなわち、ある一頂点が全座標を通じて一度も少数派にならないこと。

したがって共面四点禁止版の禁止集合は、任意の三頂点を共有しない **3-線形な4一様超グラフ**をなす。補完可能な三点集合の総数は

```
T(d) = 4 F(d) = (6^d - 2*4^d + 2^d)/2.
```

## 証明

既証明の二値立方体共面四点＝非退化平行四辺形の定理を使う。平行四辺形の四頂点は `x, x xor U, x xor V, x xor U xor V` と表せる。ここで `U,V` は互いに素な非空の座標支持集合である。四頂点の座標ごとの xor は0なので、三頂点が与えられたら第四頂点は必ず `a xor b xor c` となり一意。

三頂点 `a,b,c` が補完可能なら、平行四辺形の四隅のうち三つを占めるので、三点のうち一つを基点として残り二点への変化座標集合は互いに素になる。この基点はどの非定数座標でも少数派にならない。逆に少数派にならない頂点を基点に選べば、他の二頂点への変化支持は互いに素で、残りの頂点 `a xor b xor c` が平行四辺形を完成する。相異なる三点なので二つの支持は非空。

各共面四点組はちょうど四つの三点部分集合を持ち、各三点は高々一つの共面四点組に属する。よって補完可能三点の総数は `4F(d)`。既証明の `F(d)` の公式を代入して得る。□

## 独立有限検算

`d=2,3,4,5` の全四点組を、3通りの対角分割における整数座標和の一致で直接判定し、各四点組の三点部分集合を辞書に登録した。三点が複数の共面四点組に現れないことと、補完可能三点の総数が順に `4,48,400,2880` であることを確認した。

これは全称証明とは独立の有限検算である。一般の共円ゲームの共円四点組にこの一意補完性は成り立たない（同じ三点を通る円は一意だが、その円上の格子点は複数あり得る）。

## 探索への応用

安全集合 `S` の検査では、各三点 `a,b,c ∈ S` に対して上記の少数派条件を判定し、補完可能な場合だけ `a xor b xor c ∈ S` を調べればよい。禁止四点組全体を保持する必要はない。これは二値立方体の共面四点禁止版に限る。通常プレイのGrundy値や勝敗を決めるものではない。
