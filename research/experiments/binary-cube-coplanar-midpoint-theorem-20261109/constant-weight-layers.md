# 二値立方体の等重み層に含まれる共面四点の厳密計数

## 定理（全次元）

`d >= 1`, `0 <= k <= d` とし、`L(d,k)={x in {0,1}^d: |x|=k}` とする。相異なる四頂点が同一の実アフィン平面上にある四点集合の数は

```
F(d,k) = (1/8) * sum_{u,v >= 2, u,v even, u+v <= d}
  multinomial(d;u,v,d-u-v) * binom(u,u/2) * binom(v,v/2)
  * binom(d-u-v, k-(u+v)/2).
```

二項係数は下添字が範囲外なら0と定義する。特に `k=0,1,d-1,d` では `F(d,k)=0`、`F(d,2)=F(d,d-2)=3*binom(d,4)`。また `F(d,k)=F(d,d-k)`。

## 証明

既証明の二値立方体共面四点＝平行四辺形の特徴付けを使う。任意の共面四点は、互いに素な非空支持集合 `U,V` と基点 `x` により

```
{x, x xor U, x xor V, x xor (U union V)}
```

と表せる。全四点が重み `k` であるためには、`U` 内の `x` の1と0の個数が等しく、同様に `V` 内でも等しくなければならない。従って `u=|U|,v=|V|` はともに正の偶数で、各々少なくとも2。

順序付きの互いに素な `U,V` の選び方は多項係数、`x` の `U,V` 内のビットはそれぞれ `binom(u,u/2),binom(v,v/2)` 通り。残りの座標ではちょうど `k-(u+v)/2` 個の1を選ぶ。各四点集合は基点4通りと `U,V` の交換2通りで計8回数えられるため、8で割る。

`k=2` では `u=v=2` しか寄与せず、`F(d,2)=3 binom(d,4)`。重みの反転対称性より `d-2` も同じ。重み0,1および補集合側は `u+v>=4` に反するので0。□

## 独立有限検算

`d=2,...,7` の各重み層の全四点部分集合について、三通りの頂点対分割の整数座標和一致を直接判定し、上記計数式と一致した。各 `k=0,...,d` の値は以下。

```
d=2: 0,0,0
d=3: 0,0,0,0
d=4: 0,0,3,0,0
d=5: 0,0,15,15,0,0
d=6: 0,0,45,135,45,0,0
d=7: 0,0,105,630,630,105,0,0
```

検算は有限完全列挙であり、上記全称証明とは別の確認である。

## 探索上の帰結

等重み層だけを盤面とする共面四点禁止版では、重み1とd-1の層には禁止四点組が一つもない。重み2の層では、頂点を完全グラフ `K_d` の辺とみなすと、禁止四点組は四頂点から作る四角形の辺集合にちょうど対応する（各4頂点につき3通り）。従って重み2の探索は `K_d` の四角形禁止辺集合問題に帰着できる。

通常の共円四点禁止ゲームや全立方体上の勝敗についての結論ではない。
