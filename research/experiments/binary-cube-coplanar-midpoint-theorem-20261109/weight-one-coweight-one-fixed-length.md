# 二値立方体の重み1・重み(d−1)層の共面四点禁止ゲーム（2026-11-10）

## 定理（全称証明）

整数 d>=3 とし、V={e_i, 1-e_i : 1<=i<=d} を {0,1}^d の二つの等重み層の和集合とする。相異なる四頂点が共面であることと、相異なる i,j に対して四頂点が {e_i,1-e_i,e_j,1-e_j} であることは同値である。したがって禁止四点組の総数は C(d,2)。

この頂点集合に限定した「四点共面なら違法」のゲームでは、**すべての極大安全配置の大きさが d+1** である。最大安全石数も最小極大石数も d+1。通常プレイの空盤は d が偶数なら先手勝ち、奇数なら後手勝ち。misère は逆になる。

## 証明

前提として、二値立方体の共面四頂点が平行四辺形であること（同じ実験ディレクトリの proof.md）を用いる。各頂点を L_i=e_i, H_i=1-e_i と書く。d>=3 では L 層と H 層は交わらない。

座標和の全成分和（通常の重みの和）は L+L で2、L+H で d、H+H で2d−2。d>=3 でこの三数は相異なる。したがって等しい二頂点和は同じ組み合わせの層同士でしか起こらない。

L_i+L_j は支持集合 {i,j} で決まり、相異なる二頂点対なら一意。H_i+H_j も 2·1−e_i−e_j なので一意。交差対は L_i+H_j=1+e_i−e_j であり、i≠j なら +1 の座標 i と −1 の座標 j から一意に復元できる。i=j のときだけ全て 1 に等しく、異なる二つの交差対 {L_i,H_i},{L_j,H_j} が同じ中点を持つ。以上から禁止四点組はちょうど二つの完全な対頂点対の和集合である。

安全集合には完全な対頂点対が高々一つしかない。極大安全集合が完全な対を一つも含まなければ、未選択の点を少なくとも一つ追加しても安全なので極大でない。完全な対をちょうど一つ含む場合、他の対からは高々一つ選べる。どれかの対から一つも選んでいなければ追加可能なので、極大なら残り d−1 対からちょうど一つずつ選ぶ。石数は 2+(d−1)=d+1。逆にそのような集合はどの未選択点を追加しても完全な対が二つとなるため極大。

合法手がなくなるまで必ず d+1 手かかるので、通常プレイは d+1 が奇数（d 偶数）なら先手勝ち。misère は逆。

極大配置の総数は d·2^(d−1) である（完全な対を選び、残りから一つずつ選択）。

## 独立有限検算

共面四点を既存の平行四辺形定理に頼らず、各座標の和の一致で直接検査した。d=4,5,6,7,8 の禁止四点組数はそれぞれ 6,10,15,21,28 であり C(d,2) に一致した。下の再現コードは全四点組を直接検査し、d=3..8 の禁止集合が予想集合と完全一致することを確認する。これは定理の代用ではない。

```python
from itertools import combinations

for d in range(3, 9):
    vertices = [1 << i for i in range(d)] + [
        ((1 << d) - 1) ^ (1 << i) for i in range(d)
    ]
    actual = set()
    for quad in combinations(range(2*d), 4):
        for a,b,c,e in ((0,1,2,3),(0,2,1,3),(0,3,1,2)):
            if all(
                ((vertices[quad[a]] >> k) & 1) +
                ((vertices[quad[b]] >> k) & 1) ==
                ((vertices[quad[c]] >> k) & 1) +
                ((vertices[quad[e]] >> k) & 1)
                for k in range(d)
            ):
                actual.add(quad)
                break
    expected = {
        tuple(sorted((i,j,d+i,d+j)))
        for i,j in combinations(range(d), 2)
    }
    assert actual == expected, (d, actual ^ expected)
    print(d, len(actual))
```

## 範囲と接続

全次元 d>=3 の証明済み結果。ただし**二値立方体の二つの等重み層だけを使う変種**であり、全頂点を使う共面四点禁止ゲームの勝敗ではない。固定手数の構造は、一般の極大安全配置の解析で比較対象となる。独立した形式証明は未実施。
