# 偶数次元の重み2層 C4 極大構成を1石改善（2026-11-10）

## 定理（全称証明）

任意の整数 k≥1 に対し、n=2k+4 頂点、3k+3=(3n−6)/2 辺の C4-saturated 単純グラフが存在する。したがって二値立方体の重み2層の最小極大石数について、偶数 n≥6 で

\[
s_n^{(2)}\le (3n-6)/2.
\]

従来の風車＋中心葉の (3n−4)/2 辺構成より **1石少ない**。最適性は主張しない。正方形盤の s_n とは異なる。

## 構成

中心 c と、互いに素な k 組 {a_i,b_i} を置き、各 i に三角形 c-a_i-b_i-c を張る。さらに3枚の葉 x,y,z をそれぞれ c,a_1,b_1 に接続する。頂点数 1+2k+3=2k+4、辺数 3k+3。

C4 が存在しないことは、葉が閉路に含まれず、三角形の和が中心 c のみで交わることから明らか。

## 全欠辺に対する長さ3の道（極大性の証明）

C4 のない単純グラフに欠辺 uv を加えると C4 が生じることと、元のグラフに u,v を結ぶ長さ3の単純道があることは同値。

1. **葉同士**：3枚の葉の支持点 c,a_1,b_1 は三角形を作る。葉 p,q に対し p–support(p)–support(q)–q が長さ3の道。
2. **葉と基礎風車の頂点**：葉 p の支持点を v∈{c,a_1,b_1} とする。基礎風車の任意の頂点 w≠v について、v と w が非隣接なら v–c–w（v≠c）または対応する別の2辺道が存在する。隣接する場合も、v=c なら w の三角形の相方 t を経由する c–t–w、v=a_1 または b_1 で w=c または相方なら同じ三角形の残りの頂点を経由する2辺道が存在する。したがって **任意の w≠v に対し v から w への長さ2の単純道が存在する**。葉 p を先頭につけて長さ3の道を得る（p と w が非隣接の場合を含む）。
3. **基礎風車の欠辺**：異なる三角形に属する周辺頂点 u,w だけが非隣接。u の相方 u' を用いて u–u'–c–w が長さ3の道。

すべての欠辺を尽くしたので極大性が従う。

## 独立検算（Python 3、標準ライブラリのみ）

元の長さ3の道による証明と独立に、4頂点上の3種類の閉路を直接検査する。

```python
from itertools import combinations

def has_c4(n, E):
    for a,b,c,d in combinations(range(n),4):
        for t in ((a,b,c,d),(a,b,d,c),(a,c,b,d)):
            if all(frozenset((t[i],t[(i+1)%4])) in E for i in range(4)):
                return True
    return False

for k in range(1,9):
    n = 2*k+4
    E = set()
    for i in range(k):
        a,b = 2*i+1,2*i+2
        E.update(map(frozenset, ((0,a),(0,b),(a,b))))
    for v,u in ((2*k+1,0),(2*k+2,1),(2*k+3,2)):
        E.add(frozenset((v,u)))
    assert len(E)==3*k+3 and not has_c4(n,E)
    for e in combinations(range(n),2):
        f=frozenset(e)
        if f not in E:
            assert has_c4(n,E|{f}), (k,e)
    print(n,len(E),"OK")
```

実行済み結果（2026-11-10）：6/6、8/9、10/12、12/15、14/18、16/21、18/24、20/27（頂点数/辺数）、全例 OK。

## 帰結と限界

奇数 n≥5 の既存構成 s_n^(2)≤(3n−5)/2 と合わせ、全 n≥5 で s_n^(2)≤⌊(3n−5)/2⌋ が得られる。偶数 n では (3n−6)/2 に一致する。これは **構成的上界のみ** であり、一般の下界・最適性は未証明。特に n=8 の9辺構成が従来の10辺上界を更新する。

検証は n=6,8,…,20 に限定され、全称性は上記の数学的証明に依存する。
