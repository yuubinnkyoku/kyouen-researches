# 奇数次元の重み2層 C4 極大配置を1石改善する構成（2026-11-10）

## 定理（全称証明）

任意の整数 (k\ge1) に対し、(n=2k+3) 頂点で (3k+2=(3n-5)/2) 辺を持つ C4-saturated 単純グラフが存在する。したがって二値立方体の重み2層における最小極大石数は、奇数 (n\ge5) に対して
[
s_n^{(2)}\le (3n-5)/2.
]
従来の中心風車構成による奇数次元上界 (3(n-1)/2) より1小さい。最適性は主張しない。

## 構成

頂点 (c) を中心とし、互いに素な (k) 組 (\{a_i,b_i\}) を用意する。各 (i) について三角形 (c a_i b_i c) を置く。さらに頂点 (x,y) を追加し、辺 (x a_1) と (y c) のみを加える。

辺数は (3k+2)。三角形同士は中心だけを共有し、追加頂点は葉なので C4 は存在しない。

## 極大性の証明

任意の欠辺を追加すると C4 ができることを、追加前の長さ3の単純道で確認する。

1. 異なる三角形成分の周辺頂点 (u\in\{a_i,b_i\},v\in\{a_j,b_j\})（(i\ne j)）について、(u-u'-c-v) が長さ3の道（(u') は (u) の相方）。
2. (y) と任意の周辺頂点 (u) について、(y-c-u'-u)。
3. (x) と中心 (c) について、(x-a_1-b_1-c)。
4. (x) と (a_1) 以外の周辺頂点 (u) について、(x-a_1-c-u)。ただし (u=b_1) の場合も4頂点は異なる。
5. (x) と (y) について、(x-a_1-c-y)。

以上で全欠辺を尽くす。各道に欠辺を加えると C4 が成立するので、構成は C4-saturated。

## 有限検算と適用範囲

(k=1,2,3,4) の構成を、禁止 C4 の全4頂点組検査と、全欠辺追加後の C4 検査で独立確認できる。全称性の根拠は上の証明であり、有限検算ではない。

(n=7) では8辺となり、既知の最小極大値8に一致する。(n=9) では11辺の極大配置を与える。これは一般の正方形盤の (s_n) ではなく、**二値立方体の重み2層**に限定した結果である。
