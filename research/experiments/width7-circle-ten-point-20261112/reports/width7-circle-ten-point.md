# 幅7格子における円の格子点数: P(7) = 10、可能サイズは {7, 8, 10} のみ

## 主張

**定理.** 7行の連続整数格子（7×m、任意の m ≥ 1、行 y = 0..6）上の円の格子点数は高々 10。
可能な点数は 7, 8, 10 のみで、**9 と 11, 12 は全 m で存在しない**。
10点円は m ≥ 8 で実在（下の witness。7×13 で 12 本・7×16 で 18 本・7×19 で 24 本）。
特に P(7) = 10。

**10点円の構造.** P = 2d + s（d = 二重行、s = 接点行）で 10 = (d,s) ∈ {(5,0), (4,2)} だが
(4,2) は排除されるので、**幅7の10点円はすべて 5二重行 + 2空行**（接点なし）のプロファイルを持つ。
witness も行 2, 5 が空で一致。

**系（q ≥ 11 の行分離）.** 幅7・q ≥ 11 では円 ≤ 10 < q 点、非水平直線 ≤ 7 < q 点により
行を跨ぐ禁止 q 点集合が存在せず、K0072 と同様に全 m ≥ 1・全安全局面 S で

g(S) = (7·min(m, q−1) − |S|) mod 2,　M_{7,q} = q−1。

新規に確定するのは q = 11, 12（q ≥ 13 は K0025 の q > 2w と重複整合）。
q = 7..10 は 7点円・8点円・10点円・7点非水平直線が実在するため対象外。

## witness

(x − 7/2)² + (y − 7/2)² = 25/2、すなわち (2x−7)² + (2y−7)² = 50。
行0: x ∈ {3,4}、行1: {1,6}、行3: {0,7}、行4: {0,7}、行6: {1,6}、行2,5: 空の10点。
列 0..7 に収まるため m ≥ 8 の全 7×m に translate して乗る。
dy = ±1/2, ±5/2, ±7/2 で dx = ±7/2, ±5/2, ±1/2（r² = 25/2 = 6.25 + 6.25 = 12.25 + 0.25）。
なお同一円は8行版（行 0..7）では12点を持つ（(3,7),(4,7) が加わる）→ **P(8) ≥ 12** の由来。

## 証明

K0763 の枠組み（判別式 disc(y) = M − 4y² − 4Dy、二重行/接点行、P = 2d + s、s ≤ 2）をそのまま使う。

**d ≤ 5**: mod9 剰余分類（(M,D,k) 全 9³ 通り）で 7 連続行中 disc ∈ QR(9) の行は最悪 5 行。
連続二重行ペア → Vieta還着（D, M ∈ ℤ）が有効。

**11点（d=5, s=1）の排除**: 接点 → C 偶 → disc(y)/4 = t(y₀+y+D) = s²、t = y₀−y ∈ [−6,6]。
D = e/f 既約 → f | t（h = 2fy₀+e、gcd(h,f)=1）。5つの相異なる非零 t → f ∈ {1, 2}
（f ≥ 3 の倍数は [−6,6] に4つ以下）。
- f = 2: 同符号（符号論）で {2,4,6} の3つのみ < 5。
- f = 1: t ∈ {1..6} から 5つ。t = 3 は t ∈ {1,2,4,5} と mod 3 で非両立
  （w=6 と同じ 4 式。t = 6 との両立 (3,6): w²−2z²=1 Pell、g = 30, 870, 29406, … は残るが
  5-集合は t=3 を含めば {1,2,4,5} のどれかを必ず含む）。t=3 を含まない 5-集合は
  {1,2,4,5,6} で、これは (1,4) を含み a² − u² = 3 → g = 5 を強制するが、
  その g で t=2 は 2·3 = 6（非平方）・t=6 は負。矛盾。

**9点（d=4, s=1）の排除**: f = 2 は同符号で {2,4,6} < 4。f = 1 で t ∈ {1..6} から 4つ。
非両立ペア: (1,3),(2,3),(3,4),(3,5)〔mod 3〕、(1,4)〔g=5 強制〕、**(5,6)**〔5v²−6z²=1 →
2v² ≡ 1 → v² ≡ 2 (mod 3)〕。6値から4つ選ぶ全 15 通りはすべてこれらのペアを含む
（t=3 を含むものは 1,2,4,5 と衝突、含まないものは {1,2,4,5,6} から選び (1,4) か (5,6) を避けられない）。

**12点（d=5, s=2 / d=6）の排除**: d = 6 は mod9 で ✗。2接点は t = 0, t = g で共に盤内、
|g| ≤ 6、二重行は t ∈ (0, g)（符号論より接点の間）→ g = ±5: {1,4} の2つ、g = ±6: {3} の1つ
のみで 5 二重行に届かない（機械検証 two_tangent）。

**等号**: witness（5二重行、s=0、P=10）。

## 幅6との対比（K0763 との関係）

- P(6) = 8（サイズ {7,8}）に対し P(7) = 10（サイズ {7,8,10}）。**9点円は w=6, w=7 ともに不存在**
  （接点補題は共通）。10点は w=7 から登場し、それは「5二重行が接点なしで並ぶ」形のみ。
- 排除の核は共通の mod 3 恒等式群だが、w=7 では t = 6 が新たに加わり (3,6) の Pell 両立が
  発生する。それでも 5-集合の被覆論で落ちる。**w=8 では t ∈ ±7 がさらに加わり
  (3,6) 型の両立が 9点・11点・13点に効く可能性がある**（未解析。P(8) ≥ 12 は既知）。
- P(w) の小w値: P(6)=8, P(7)=10, P(8) ≥ 12。K0072 の w ≥ 15 での P ≤ w + ⌈w/2⌉ と接続する
  中間帯のデータ点として、P(w) の正確な決定は w = 8..14 が open。

## 機械検証（scripts/width7_circle_bound.ts → output/width7_circle_bound.json）

1. witness 10点の直接列挙（行プロファイル一致）。
2. f=1 接点条件: |g| ≤ 10⁶ で最大 3（9点・11点の排除と整合）。t=3 の共存は 8 件で
   すべて {3,6}/{−3,−6}（Pell の 4 解 + 鏡映と厳密一致）。t=5 と t=6 の共存は 0 件。
3. f=2: 最大 2。
4. 2接点: g = ±5 → {1,4}、g = ±6 → {3} のみ。
5. mod9 分類: 7連続行 worst 5。
6. census: 7×13 = 201（7:28, 8:161, 10:12）、7×16 = 321（7:48, 8:255, 10:18）、
   7×19 = 457（7:76, 8:357, 10:24）。サイズ集合は全て {7,8,10} で 9・11・12 は 0。

## スコープと限界

- 標準整数格子（連続7行）の定理。任意間隔平行行・w ≠ 7 には主張しない。
- 幅7の q=7 ゲーム自体（M_{7,7}・occupancy プログラム）は本項目では解いていない。
  ただし危険円が 7/8/10 点のみで 9 点がないことが全 m で確定したため、
  幅7 census 方式の完全性は K0760 と同様に保証される。加えて幅7では**非水平 7 点直線**
  （傾き ±1 等）が初めて危険曲線になる点が w ≤ 6 と質的に異なる。
