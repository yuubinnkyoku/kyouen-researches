# g0 会計の拡張法による有効範囲決定 — w ≤ 84（高速レーン 2026-11-13）

## 定理（証明済み・有限完全検査）

convention B の g0 会計（非標準形 e = q/g0 の classMax < 17 要求）を、
法リストを BASE18（K0788 の18法）から拡張法リスト（EXTRA: 49, 121, 53..83, 32, 64, 81, 125, 169 /
BIG: 343, 89..139, 128, 243, 289）まで拡大すると:

1. **会計は w = 65..84 の全幅で有効**。基底18法のみの場合の有効範囲は w ≤ 78。
2. **w = 85..87 では会計不成立**: g3 形（類サイズ 29）が全法で classMax = 17。
   最良法でも witness (a,u) = (0,1) mod 31 が17点類部分集合を生存させる。
3. **g4 形は壁ではない**（K0794 帰結の訂正）: classMax は 5..9 しかない。
   g0=4 は偶数なので u' = q は奇 → 偶数法で u奇制限が正当であり、
   係数 4·4² = 64 と合わせて自明に切れる。
4. **g2 形は m = 32/64（u奇制限付き）で大幅強化**: 類サイズ 43（w=85）まで classMax = 10。

## 意味論と限界（重要）

- この結果は「level 17 全滅 ⟹ d+s ≤ 16 ⟹ P(w) ≤ 32」論法の**非標準形側の前提**が
  w ≤ 84 で正当化されることを意味する。**P(65)..P(84) の値は決定していない**。
  標準形側（16法 bit-set DFS）の実行コストは w=64 で 33.2M ノード・×1.3/w で成長するため、
  個別幅の分類は長期レーン対象。
- K0785 の P(83) ≥ 34（level 17 が w=83 で生存）と合わせ、会計有効範囲は
  復活点の下界 83 をちょうどカバーする。w=85..87 で会計が切れることは
  P(85..87) の決定には影響しない（P(85)..P(87) ∈ [32, 2⌈w/2⌉−4] のまま）。
- classMax の計算は全 (a,u) 対の全数走査（直接法）と増分 sweep（類サイズ s を
  1..sMax で一括）の2実装で一致を確認（g2_m16_s32 = 8/8・g3_m49_s28 = 16/16）。

## 制御

- BASE18 直接法で K0788/K0792/K0794 の既知値を完全再現:
  w36: g2=6, g3=8 / w42: 7, 10 / w48: 7, 11 / w64: 8, 13。
- sweep ≡ direct（2点）。
- g3 size 29 の失敗は反対側の witness 明示で確認（誤殺でなく真の生存）。
