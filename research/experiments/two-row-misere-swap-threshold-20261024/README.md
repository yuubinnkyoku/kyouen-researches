# 2×m の通常／misère Grundy値交換則：真の開始長7

2026-10-24。通常mex値をg、終局を1とするmisère補助mex値をh、τ(0)=1、τ(1)=0、τ(k)=k (k≥2)とする。

**定理（全称証明＋有限完全列挙）**：標準2×m・q=4と、二次形式版 det[x²+λy²,x,y,1]=0（全実数λ）のどちらでも、全安全局面について h(S)=τ(g(S)) がすべての m≥7 で成立する。m=6では成立しない。従って真の開始長は **7**。全極大が6石になる開始長9とは異なる。

## 無限長への証明

二行ではy²=yなので、行列式の第一列からλ倍の第三列を引けばλは消える。標準q=4の禁止四点組は同一行4点、または二行から2点ずつで両行のx座標の和が一致する四点であり、二次形式版の禁止集合と一致する（非水平直線上に4点は載らない）。

既存[K0069](../../knowledge/items/K0069-two-row-all-lengths-strong-solution.md)の全称証明によりm≥9では全極大が6石。よってg=(6−|S|) mod 2、h=(7−|S|) mod 2で交換則が成立する。m=7,8は下記の全安全局面完全列挙で不一致0。m=6のS={(0,0)}は(g,h)=(3,0)なので最小性も証明された。m=1..4でも交換則は偶然成立するが、m=5,6で破れるため開始長ではない。

- `verify.py` は二点和による禁止集合と空盤からの再帰で通常・misère値を計算。
- `independent.cpp` はλ=1の整数行列式で禁止集合を独立生成し、全ビット集合を大きい順に走査して通常・misère値を別々に計算。
- 二方式でm=1..9の局面数、不一致数、空盤値が完全一致。`independent-results.txt` に実測出力を保存。

実行：`python3 research/experiments/two-row-misere-swap-threshold-20261024/verify.py` および `g++ -std=c++17 -O2 research/experiments/two-row-misere-swap-threshold-20261024/independent.cpp -o /tmp/kyouen_misere && /tmp/kyouen_misere`。
