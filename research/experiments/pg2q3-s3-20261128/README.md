# PG(2,3) s=3 の完全 Grundy スペクトル（錐法）

- 盤: PG(2,3)（13 点・13 直線、各 4 点）。s=3（各直線と高々 3 点）。
- 3-キャップは 2 軌道（三角形 234・一直線 52）。両方の錐（260 / 214 局面）で完全 DP。
- 二重数え上げ: `234·T_m(g) + 52·U_m(g) = C(m,3)·N_m(g)`。
- k=0,1,2 は mex 連鎖。
