# 一辺細分星：k=3、q≥5 では実根が存在しない（2026-11-04）

## 対象と位置づけ

既存の全終局長差多項式
```
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}
r=q-3≥1
```
について、奇数 k≥3、r≥2 の小さい k の分類は未完了だった。ここでは **k=3、全整数 r≥2** を決定する。グラフ型構成の多項式であり標準格子盤の結果ではない。

## 定理（全称証明）

任意の整数 r≥2 に対し、四次式
```
T_{3,r}(u)=u^4+(r+2)u^3+(r+1)^3 u+r(r+1)^4
```
は実根を持たない。したがって4根すべてが非実根（重複度込み）。

## 証明

u≥0 では全係数が非負で定数項が正なので T>0。x=-u>0 と置き、
```
P(x)=T_{3,r}(-x)=x^3(x-r-2)+(r+1)^3(r(r+1)-x).
```
とする。a=r+2、b=r(r+1) と書く。r≥2 では b>a。

**0<x<a**：P(x)=(r+1)^3(b-x)-x^3(a-x)。
第一項は
```
(r+1)^3(b-x) ≥ (r+1)^3(b-a) = (r+1)^3(r²-2).
```
一方、関数 x³(a-x) の x∈[0,a] における最大値は 27a⁴/256（x=3a/4）。さらに r≥2 より
```
(r+1)/(r+2) ≥ 3/4,
r²-2 ≥ (r+2)/2
```
（後者の差は (r-2)(2r+3)/2≥0）。したがって
```
(r+1)^3(r²-2)
 ≥ (27/64)(r+2)^3 · (r+2)/2
 = 27a⁴/128
 > 27a⁴/256 ≥ x³(a-x).
```
よって P(x)>0。

**a≤x≤b**：x³(x-a)≥0、(r+1)³(b-x)≥0。両者は同時に0にならないため P(x)>0。

**x>b**：x³>(r+1)³ かつ x-a>x-b>0。よって
```
x³(x-a)>(r+1)³(x-b),
```
したがって P(x)>0。

全ての x>0 で P(x)>0 となり、実根はない。証明終。

## 検証境界

本結果は有限数値探索ではなく r≥2 に対する全称不等式の証明。既存の k=3,r=1 の2実根定理と合わせ、k=3 について全整数 q≥4 の実根数を分類した（q=4 は2個、q≥5 は0個）。奇数 k≥5 の小さい k と r≥2 は引き続き未分類。
