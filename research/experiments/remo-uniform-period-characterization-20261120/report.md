# 一様盤REMO計数再帰・全記録Eの周期の完全特徴付け（必要性方向の全称証明）— K0919 OPENの解決（item K1154）

巡回配分・敗者石除去）。Q(r) := lcm(1,2,…,r)。

## 定理PNE（全称・必要性方向を含む完全特徴付け）

**すべての r ≥ 2 とすべての T ≥ 1 に対し**:

> T が E(·,r) の周期（すべての C ≥ 1 で E(C+T,r) = E(C,r)） ⟺ Q(r) | T。

**系1（最小周期・全r）**: E(·,r) の最小周期は**すべての r ≥ 2 でちょうど Q(r)**。
周期はちょうど Q(r) の正の倍数。**K0919の明示的OPEN「r ≥ 10の最小性と必要性方向
（周期は必ずQ(r)の倍数）」を閉じる。**

**系2（強形・単一witness）**: Q(r) ∤ T なら**すべての C ≥ 1 で E(C+T,r) ≠ E(C,r)**、
かつ敗者列の第1〜h*−1項は一致し**第h*項でちょうど最初の不一致**が起きる
（h* = h*(T,r) は T と r のみで決まり C 非依存）。とくに **C = 1 が
E側の万能witness**（棄却に探索窓が不要）。

## 証明

十分性（Q|T ⟹ 周期）は K0919 定理PER（既刊・全称証明）。ここでは必要性方向を示す。

**セットアップ。** 2つの盤 C と C+T を並走させる。フェーズh（活性者数
k_h = r, r−1, …, 2、h = 1..r−1）開始時の状態:

- σ_h（in-sync）: 順序つき活性リスト・turnポインタが両盤で同一で、
  すべての活性者の石数差が共通の値 D_h（δ一様）。
- Σ_h := 活性者の石数の総和は両盤で丁度 k_h·D_h 異なるので、フェーズhの配分石数は
  ell と ell + X_h（X_h := T − k_h·D_h）。
- σ_1 は自明（D_1 = 0、X_1 = T）。

**補題INS（保存・K0919帰納法と同一内容）。** σ_h かつ k_h | X_h なら:
剰余パターン t が同一（配分の貧富パターンが同じ位置に載る）、活性者ごとの受領差が
ちょうど X_h/k_h、敗者オフセット li が同一（ell ≡ ell+X_h mod k_h）、よって**同一ラベル**が
除去され、除去後のturnも同一、offsets D_{h+1} = D_h + X_h/k_h = **T/k_h** で一様。
閉形式: 閉じた接頭辞上で D_h = T/k_{h−1}（h ≥ 2）、X_h = T − k_h·T/k_{h−1} = **T/k_{h−1}**
（h ≥ 2、X_1 = T）。

**補題MIS（逸脱）。** σ_h かつ k_h ∤ X_h なら: li′ − li ≡ X_h mod k_h ≠ 0 なので
敗者オフセットが異なり、活性リストが同一ゆえ**除去されるラベルが異なる**。

**保存条件の列。** 補題INSを全フェーズに適用する条件は
M_1: k_1 = r | T、M_h: k_h | X_h（h ≥ 2、接頭辞上は X_h = T/k_{h−1} なので
同値に k_{h−1}·k_h | T）。K0919補題Qにより、M_1..M_{r−1} の成立はちょうど Q(r) | T
と同値（本検証器のV0も機械アンカー）。

**必要性方向。** Q(r) ∤ T とし、h* := 条件列 M_1..M_{r−1} の**最初の破れの番号**
（σ接頭辞は必要で、h* は (T,r) のみの関数）。
補題INSをフェーズ1〜h*−1に適用すると σ_{h*}（D_{h*} = T/k_{h*−1}・X_{h*} = T/k_{h*−1}）、
補題MISがフェーズh*に適用され、**第h*除去ラベルが不一致**。
この議論は C に一切依存しない ⇒ すべての C ≥ 1 で E(C+T) ≠ E(C)。
第1〜h*−1項は一致（INSが同一ラベル除去を保証）、よって最初の不一致は丁度第h*項。
対偶: 周期は必ず Q(r) の倍数。定理PERの十分性と合わせて特徴付け・最小周期 = Q(r)
がすべての r ≥ 2 で確定する。∎

## 生存者側との厳密な分離

- 本定理の対象は**全記録 E（敗者全列＋生存者）**。生存者列 S(·,r) の必要性
  （K1145後も全称は未証明の**有界witness予想**）は本結果で**閉じない**:
  フェーズh*の除去ラベル不一致は生存者不一致を含意しない（h*以降は
  ラベルの異なる同サイズ部分ゲームの比較になり、構造は保存されない）。
- V4の掃引は生存者側最小性に言及しない。本項の機械最小性アンカーは
  E側（DIV引数: K0922）。
- K1145の等Qブロックwitnessストリーム同一性（生存者側・観察）は、
  V6の E側ブロック非不変性により「E側から自動的には説明がつかない」ことが
  機械的に明示された。両観察の説明は次課題。
