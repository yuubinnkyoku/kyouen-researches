## 記法

- Vₓ(R) を位置 (R;(x,4);10) の選択肢（子のGrundy値）の集合と書く。
- O[a,b]={n: a≤n≤b, n奇}, E[a,b]={n: a≤n≤b, n偶}, I[a,∞)={n: n≥a}。

## 証明

**Step 1（再帰と外帰納の設計）.** R=0 は H=0。X=(x,4)（x≥4）における合法手は次の3種で、子はいずれも残り R−1 手:

- **A手**（トークン x を x−1 へ減ずる）: 子 = H(R−1;(x−1,4);10)
- **B手**（トークン 4 を 3 へ減ずる）: 子 = H(R−1;(x,3);10) = K1005
- **C手**（z を 10→9 へ減ずる、値は 1⊕子の値）: 子 = H(R−1;(x,4);9) = K0990

x=4 では X=(4,4) で A手とB手は同一の子 (3,4);10 = K1005 の x=4 行に合流する（A=B）。子の値はすべて既知の公式で閉じる: A子はスライス x−1 の値（**x に関する外帰納**）、B子は K1005、C子は K0990。

**Step 2（子の公式）.** A=cand(x−1,r)、B=z10_y3(x,r)、C=1⊕z9_y4(x,r)（r=R−1）。定常行で使う子の帯:

- A（x−1 奇数 ≥17 行）: T_A={1,3,5,7,9,19}、P_A={11,13,15,17}∪E[20,x+14]∪I[x+15,∞)。A（x−1 偶数 ≥18 行）: P_A={11,13,15,17}∪E[20,x+13]（有限）。A（x−1=15 の掃引行）: T_A に O[19,29] を追加。

帯の現れ方の根拠（定常偶数行 x≥18、r=R−1）:

- 奇数R∈{11,13,15,17}（r∈{10,12,14,16}⊆P₉）: A=0・B=0（いずれの T/P 頭部にも入らない）・C=0（h₉=1 → 1⊕1）。V={0}、値1。**この基底点組 {11,13,15,17}={z+1,z+3,z+5,z+7} が P の頭部**。

- 奇数R=19（r=18）: A=0（E_A 前）・B=1（18∈E_B[18,·] 頭）・C=1。V={0,1}、値2。**この点 19 が定常ピン**。
- 偶数R=20（r=19）: A=2（**奇数行 x−1 のピン 19∈T_A**）・B=0・C=0（19∈O₉ → h₉=1）。V={0,2}、値1。**A子のピンが中間帯の孤立開始点 20 を作る**。
- 奇数R∈[21,x+13]（r偶∈[20,x+12]）: A=1（E_A[20,x+14]）・B=1（E_B[18,x+12]）・C=1（r偶 → h₉=0）。V={1}、値0。
- 偶数R∈[22,x+14]（r奇∈[21,x+13]）: A=0・B=0・C=0（r奇∈O₉[19,x+13] → h₉=1）。V={0}、値1。
- R≥x+15: A=0・B=0・C=0一定（偶行は3子とも有限帯外、h₉(r)=0）で V={1}、値0=tail（H=(x+4) mod 2、x偶）。

この導出は全偶数 x≥18 に一様に成り立つ。奇数行 x≥17 では B・C の帯の向きが入れ替わり、末帯 R≥x+15 は V={0} に反転して値1=tail、E帯は [20,x+15] まで延長され I[x+16,∞) と接続する。**掃引行は x=z+y+1=15**: A子は x=14 行（平坦）、B子は K1005 の x=15 移行行（偶帯 E_B[18,28] 全幅で署名02）、C子は K0990 の x=15 行（P₉ が奇帯 O₉[19,29]∪I[30,∞) を持つ）で、奇数 R∈O[19,29] で A=0・B=1・C=1 の V={0,1}（値2）・偶数 R∈[20,28] で V={0}（値1）が並び、**掃引帯 O[19,29]=O[pin,x+y+z]** が生じる（pin=19=2y+z+[z偶]、終端 x+y+z=29）。**移行行 x=16** では A子が掃引行 x=15 の O_A[19,29] を横切り、偶帯 E[20,30] 全体で署名 02 が続くが**値表は偶行定常と完全に同一**（署名のみの差異、K1004/K1005 の移行行は帯端の延伸もあったが y=4 では現れない）。x≤14 の個別行は同じ代入の直接実行である。x=6（高さ h=x+y=10=z）は値2点が {11,13} の2点前倒し（y=3 と同じく2点）、x=12 は前倒し生存点（x=y+8、点 2y+9=17）、x=8 は点 15=2y+7 の追加行（d=4）である。

**Step 4（mex評価と Theorem T）.** K0832 の Theorem T により、奇数Rの親の値は mex{0,1}=2, mex{0}=1, mex{1}=0 に限り、偶数Rの親の値は高々1である。署名→値の一意対応:

この規則を Step 3 の帯表に機械適用すると主定理の T₁₀⁽⁴⁾/P₁₀⁽⁴⁾ が正確に再構成される。

**Step 5（tail整合）.** 定常行の末帯で V は単値に退化し、R≥x+15 で H=(x+4) mod 2 となる。これは K0832 の一般tail定理の 2トークン・z=10・y=4 場合（R≥S+|X|+z−1=x+15、H=S mod 2）と独立に一致する。□

## 構造的な観察（補足メモ、証明不要）

- 定常値2位置は **{1,3,5,7,9,19}**。ピン 19=2y+z+[z偶]=2·4+10+1。値1基底点は **{11,13,15,17} の4点**で、基底点y個仮説 {z+1,…,z+2y−1} を y=4 でも満たす。帯開始は z+2y+2=20（E帯）。**7則は y=4 でも貫徹**: 基底点y個 ✓、帯開始 z+2y+2=20 ✓、帯偶奇 z追従（E）✓、掃引行 x=z+y+1=15 ✓、掃引帯 O[pin,x+y+z]=O[19,29] ✓、前倒し生存点 x=y+8=12・点 2y+9=17 ✓、tail R≥x+15・H=(x+y) mod 2 ✓。
- **I 帯の行は x 奇数行**（y=2 と同じ向き、y=1,3 と反転）。tail 値 (x+y) mod 2 が 1 になる行に I 帯が現れる規則は y=1..4 で一貫。
- **h=z 行（x=6）の追加点は {11,13} の2点**で y=3（x=7 の {11,13}）と同じく2点。h=z 行の追加点個数は y=1:1点・y=2:1点・y=3:2点・y=4:2点。一方 **点 2y+7 の現れる行は移動する**: y=3 では h=z 行 x=7 に現れた 2y+7=13 が、y=4 では h=z 行 x=6 には現れず d=4 行 x=8 に 15=2y+7 として現れる。低行の追加点 (-1, 2y+7) 格子の y 依存は y=5 で検証する価値がある。
- x=7 と x=9、x=11 と x=13 の構造対応（C子=K0990 行の穴を A・B が埋める）はこれまでの切片と同型。x=5 は y=3 の x=3..7 と同様の冪ゼロ平坦化系の低行（P=I[10,∞)）。

## 適用範囲と限界

- 本定理は **z=10・y=4 の境界切片のみ**。z=10 の y=5 は未証明（A=x外帰納・B子=本項・C子=1⊕K0992(z=9,y=5) の三子が本出版で揃い着手可能）。y≥6 は K1002 の一様式候補のまま（有限センサスのみ）。y=5 を閉じれば y=6 行の三子（B子=y=5切片・C子=1⊕K1001）が揃い、K1002 の y強帰納証明に着手できる。
- R≤11 の列は高さのみ縮約で並走レーン出版の z=10 低残余帯と完全一致し、本項が中間帯 12≤R≤x+14 を閉じたため y=4 の全R分類が完成。
- 有限監査は検証手段であり、定理の主張は上記 Step 1..5 の帰納構成による。
- 固定幅・標準二次元盤面（11×11 等）への転写は本項では行わない。残余ゲームの抽象定理である。
