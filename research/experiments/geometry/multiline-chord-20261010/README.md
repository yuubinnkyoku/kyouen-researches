# 全行対の2+2共円四点組を同時最大化する整数列配置（2026-10-10）

**分類：全称数学的証明。** 有限完全列挙と行列式検証は独立監査。`K0342` と `research/experiments/unequal-row-sharp-chord-energy-20261010/README.md` の二行鋭い上界を、**任意の複数行・指定した列幅の中で同時達成できる**形へ強化する。

## 定理（任意の占有数列、元の m 列の中で鋭い）

整数 `m>=1`、相異なる実数の水平行 `y_1,...,y_w`、各行の占有数 `0<=r_i<=m` を与える。各行で整数横座標 `A_i subset {0,...,m-1}` を `|A_i|=r_i` 個選ぶ。`Q_22` は異なる2行から2点ずつ選んだ共円四点組の総数とする。

\[
\boxed{\max_{|A_i|=r_i} Q_{22}=\sum_{1\le i<j\le w}U(r_i,r_j),\qquad
U(r,t)=\sum_{a=0}^{\lfloor r/2\rfloor-1}\sum_{b=0}^{\lfloor t/2\rfloor-1}
\min(2r-4a-3,2t-4b-3).}
\]

より一般に、各行対に非負実数の重み `lambda_ij` を与えても、最大値は `sum lambda_ij U(r_i,r_j)` である。**一つの配置が全行対について同時に等号を達成する**。行間距離は任意の相異なる実数でよい。

特に従来の二行の等号構成が必要とした約 `2 max(r_i)` 列の余地は不要で、指定された `m` 列だけで達成できる。

## 明示的な同時等号構成

行ごとに次の整数集合を選ぶ。`r=0,1` は任意（例えば `A_0=empty`, `A_1={0}`）。

- `3<=r<=m`: `a=floor((m-r)/2)`, `A_r={a,a+1,...,a+r-1}`（中央寄せの連続区間）。
- `r=2`: `s=m-1`（`m` 偶数）または `s=m-2`（`m` 奇数）、`A_2={0,s}`。`r=2` があり得る `m>=2` では `s>=1`。

同じ占有数の行には同じ集合を使う。`m=1` では二点行がなく、主張は自明。

## 証明

高さの異なる二行から選んだ `(x_1,y_i),(x_2,y_i),(u_1,y_j),(u_2,y_j)` は、`x_1+x_2=u_1+u_2` のとき、かつそのときに限り共円である。円の中心の横座標が各行の二点の中点に等しいことから従う。四点は同一直線上にはない。

既証明の二行鋭い上界 `P(A_i,A_j)<=U(r_i,r_j)` を全行対で足せば、主張する上界を得る。以下で同時等号を示す。

連続区間 `A_r`（`r>=3`）の異なる二点の和を、外周鎖 `k=0,...,floor(r/2)-1` に分解する。各鎖は、長さ `L_k(r)=2r-4k-3` の連続整数区間の和をそれぞれ一度ずつ持つ。全鎖の中心は

\[
 c_r=2\lfloor(m-r)/2\rfloor+r-1=m-1-((m-r)\bmod2).
\]

よって `c_r` は `m-1` か `m-2` のいずれか。同じ偶奇の `r,t` なら中心が一致し、異なる偶奇なら中心が1だけずれる。一方、`L_k(r)` は全て奇数であり、`r,t` の偶奇が異なると任意の `L_k(r),L_l(t)` は相異なる（長さの差は少なくとも2）。したがって両鎖の整数区間は、一方が他方を完全に含み、交差の大きさは正確に `min(L_k(r),L_l(t))` である。全鎖対を合計すると `P(A_r,A_t)=U(r,t)`。

`r=2` では二点和はただ一つの `s`。`t>=3` の各外周鎖の中心 `c_t` は `s` と同じか1だけ異なる。`t` 偶数なら `c_t=s`（最短鎖の長さは1）、`t` 奇数なら `|c_t-s|<=1`（最短鎖の長さは3）。従って **すべての鎖が `s` を含み**、`P(A_2,A_t)=floor(t/2)=U(2,t)`。`r=t=2` も両行で同じ和 `s` を持つため `P=1=U(2,2)`。`r<=1` の寄与は0。

全行対で同時に等号が成り立ち、非負重みの場合も同様。□

## 検証

## 適用範囲と注意

この定理は「2点ずつを取る行対型の共円**四点組数**」の最大化である。3行以上にまたがる `2+1+1` 型などの共円四点組は数えていない。また同じ円が3行以上に2点ずつを持つ場合でも、**四点部分集合**は行対ごとに別なので二重計数にはならない。指定占有数が3を超える行は標準q=4ゲームではそもそも安全でないため、構成がゲームの合法局面であるとは主張しない。

既存の二行鋭い上界を、行数・占有数・横幅の制約の下で**同時に鋭い**と示す新しい量化である。標準11×11の全共円四点組やGrundy値はこれだけでは決まらない。
