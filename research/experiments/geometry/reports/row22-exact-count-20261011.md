# 2+2行型の共円四点組：任意の行集合に対する厳密計数（2026-10-11）

## 既存結果との境界

標準盤の共円・共線四点組の総数は K0057 に既知であり、二行上の共円条件「各行の二点の横座標和が等しい」も B214 などで既知である。本記録の追加点は、**任意の行ごとの有限点集合に対する厳密な計数恒等式**、連続区間の場合の**閉じた三次準多項式**、および **11×11 の共円四点組の行占有型による完全な内訳**である。勝敗や Grundy 値についての新しい主張はしない。

## 全称定理

有限な相異なる水平線 y の各行に横座標集合 X_y⊂ℝ を置く。p_y(s)=#{(a,b):a,b∈X_y, a<b, a+b=s} とすると、ちょうど二行を使い各行二点ずつ含む（非退化）共円四点組数は

\[
\boxed{C_{22}=\sum_{y<z}\sum_s p_y(s)p_z(s).}
\]

ここで内側の和は実際に出現する有限個の和 s について取る。整数格子に限らず実数座標でも成立する。

特に X_y={0,1,…,m−1} を h 行に共通して使う標準 m×h 盤では

\[
\boxed{C_{22}(m,h)=\binom h2\,E(m),\quad
E(m)=\frac{2m^3-3m^2+4m-3(m\bmod2)}{12}.}
\]

m,h≥1 のすべての整数に成立する。m が偶数なら E(m)=m(2m²−3m+4)/12、奇数なら E(m)=(m−1)(2m²−m+3)/12。

## 証明

水平線 y=u と y=v（u≠v）上の二点 (a,u),(b,u) および (c,v),(d,v) を考え、a<b,c<d とする。円の中心 (ξ,η) の横座標は、同一水平線上の二交点の中点なので ξ=(a+b)/2=(c+d)/2 である。逆に a+b=c+d なら ξ をこの値とし、四点の円中心からの距離が等しくなるよう η を解く一次方程式の係数は 2(v−u)≠0 だから、ただ一つの η と正の半径が存在する。二行にそれぞれ異なる二点があるため四点は共線ではない。したがって行対ごとに同和の二点組を数えればよく、最初の公式が従う。

連続区間 X={0,…,m−1} では、和 s を持つ相異なる二点組の数は

\[
p(s)=\left\lfloor\frac{\min(s,2m-2-s)+1}{2}\right\rfloor
\quad(1\le s\le 2m-3).
\]

よって E(m)=∑_s p(s)²=2∑_{s=1}^{m−2}⌊(s+1)/2⌋²+⌊m/2⌋²。m=2t なら 4∑_{j=1}^{t−1}j²+t²=(4t³−3t²+2t)/3、m=2t+1 なら 4∑_{j=1}^{t−1}j²+3t²=(4t³+3t²+2t)/3。平方和公式を代入して閉形式を得る。m=1 も直接0で一致する。

## 11×11 の行占有型の完全な内訳（有限完全列挙）

整数の四点行列式（円）と外積（直線）による直接列挙の結果は以下。**この節の数値は有限完全列挙であり、上記の全称証明と区別する。**

| 行占有型 | 共円四点組数 |
|---|---:|
| 2+2（2行） | 10,725 |
| 2+1+1（3行） | 39,557 |
| 1+1+1+1（4行） | 34,960 |
| 合計 | 85,242 |

共線四点組は 10,428、全禁止四点組は 95,670。全円数と全禁止数は K0057 の既知値と一致する。2+2型は閉公式 C(11,2)E(11)=55×195=10,725 により**列挙に依存せず**確定する。一方、2+1+1・1+1+1+1型の個別数値は本記録では11×11に対する完全列挙であり、任意寸法への閉公式は主張しない。

## 適用と限界

二行二点型の全列挙を整数和のヒストグラムに置き換えられる。固定幅の禁則生成器や11×11の全禁止四点組生成器に対し、円の2+2成分の独立検算として使用できる。新規 K 項目への昇格時には knowledge の生成物を `uv run --locked python tools/knowledge/build.py` で再構築し、AGENTS.md の検査一式を通す必要がある。
