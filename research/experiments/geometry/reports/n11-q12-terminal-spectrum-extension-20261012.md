# 11×11・q=12：極大安全配置の全石数スペクトル（2026-10-12）

## 確定結果（有限完全列挙＋明示的証人）

標準11×11格子で共円・共線12点組を禁止した通常プレイについて、包含極大安全配置の石数は**ちょうど103から114までの全12整数**である。これはq=4の標準ゲームのs₁₁やK₁₁、あるいはq=12の空盤勝敗を確定するものではない。

既存の[両端値の証明](n11-q12-terminal-extremes-20261012.md)と[検証器](../scripts/verify_n11_q12_terminal_extremes_20261012.py)が次を確定している。

1. 12点以上を含む禁止曲線は、各12点の円21本だけ（12点の直線・13点以上の円はない）。半整数中心441個の整数距離列挙と全三点組287,980通りからの円方程式生成が一致する。
2. 盤点が21円に属する次数は最大3であり、補集合としての横断集合は7点以上必要。
3. 極大安全集合の補集合は包含極小横断集合。包含極小横断集合の各点は自分だけが遮る「私有円」を持つ。19点以上の包含極小横断集合なら、19本の私有円を選べて、各円にはこの19本中の他の円に属さない点が必要。しかし21本から19本を選ぶ210通りの全候補でこの必要条件が成立しないため、18点以下。
4. 7点・18点の包含極小横断集合の具体的証人がある。

**残った問題は8〜17点の包含極小横断集合がそれぞれ存在するか**だった。[新しい検証器](../scripts/verify_n11_q12_terminal_spectrum_extension_20261012.py)は、その10サイズすべてについて座標付きの具体的証人を保持する。

各証人Tに対し、21本の禁止円Eについて次を全件検査する。

- すべてのEでE∩T≠∅（横断集合）。
- すべてのp∈Tで、あるEについてE∩T={p}（包含極小性）。
- 座標は盤内で相異なり、|T|は宣言したサイズと一致する。

この判定は独立した整数ビット演算で行い、円支持集合は既存の二方式完全列挙器から受け取る。既存の7・18点証人と合わせて|T|=7,8,...,18をすべて実現するため、補集合の石数121−|T|は114,113,...,103をすべて実現する。両端の排除も済んでいるので、これが完全な石数スペクトルである。

## 再現

```sh
python research/experiments/geometry/scripts/verify_n11_q12_terminal_spectrum_extension_20261012.py
```

Python標準ライブラリのみを使用する。既存検証器の二方式の円生成、点次数、210候補排除と両端証人を先に実行し、続けて新しい10証人を独立のビット集合判定で照合する。実行時間は一般的な計算機で数秒以内。

**証拠水準**：極大安全集合と極小横断集合の双対性、私有円の必要条件は任意の有限超グラフに対する全称的な数学的証明。一方、21円の確定、210候補の排除、12種類の達成証人は11×11・q=12に限る有限完全列挙と直接検証である。空盤Grundy値や勝敗は依然として未解決。
