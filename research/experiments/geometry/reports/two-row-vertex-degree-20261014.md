# 2行盤の禁止四点組：各点の次数の全長公式（2026-10-14）

## 結論（数学的全称証明）

盤面 `P_m={0,...,m-1}×{0,1}`、通常の共円・共線4点禁止規則を考える。各点 `(x,y)` を含む禁止四点組の数 `d_m(x)` は行 `y` に依存せず、全ての整数 `m≥1, 0≤x<m` で

```
d_m(x) = binom(m-1,3) + binom(m,2)
       - floor(x^2/4) - floor((m-1-x)^2/4)
       - min(x,m-1-x).
```

ここで `binom(n,3)=0` (n<3)。最初の項は同一行の共線四点組、残りは両行に二点ずつ置く共円四点組である。二行の縦座標は任意の相異なる実数に変更しても同じ式が成立する。

**最大次数点の位置**も全長で確定する。m≤4 では全列が同次数。m≥5 では

- m≡1 (mod 4)：中央 `c=(m-1)/2` の両隣 `c-1,c+1` だけが最大。
- m≡3 (mod 4)：`(m-5)/2,...,(m+3)/2` の連続5列が最大。
- m偶数：`(m-4)/2,...,(m+2)/2` の連続4列が最大。

特に `m=4t+1 (t≥1)` では、中央列は隣接列より**ちょうど1だけ次数が小さい**：

```
d_(4t+1)(2t-1) = d_(4t+1)(2t+1) = d_(4t+1)(2t) + 1.
```

「中央列が最も多くの禁則に属する」という自然な予想への無限反例族である。

## 証明

4点が禁止になる行分布は、同一行4点（共線）または各行2点（真円）に限られる。3+1型は直線にも真円にも載らない。異なる二行の二本の水平弦が同じ円に載る必要十分条件は、それぞれの横座標和が等しいことである（円心の横座標が共通の弦中点）。

固定点 `(x,0)` と相方 `(z,0)` (`z≠x`) に対し、反対行の unordered pair `u<v` が `u+v=x+z` を満たす場合がちょうど1個の円四点組を与える。

`P_m(s)=#{0≤u<v<m:u+v=s}` と置く。 `0≤s≤m-1` では `P_m(s)=floor((s+1)/2)`、また `P_m(s)=P_m(2m-2-s)`。全 `binom(m,2)` 組のうち、`z=u+v-x<0` となる `u+v<x` の組は

```
sum_(s=0)^(x-1) P_m(s) = floor(x^2/4).
```

同様に `z≥m` となる組は対称性により `floor((m-1-x)^2/4)` 個。残る `z=x` の不適格な組（`u+v=2x`）は `min(x,m-1-x)` 個。以上を差し引き、同一行の `binom(m-1,3)` を加えると次数公式を得る。

最大点の分類は、`f(n)=floor(n²/4)` の差 `f(n+1)-f(n)=floor((n+1)/2)` を用いる。中心より左側で、中心を横切らない隣接列について

```
d_m(x+1)-d_m(x)
  = floor((m-1-x)/2)-floor((x+1)/2)-1.
```

中心を横切る偶数 m の二列間は差0。左側の差は中心に近づくほど非増加で、中心付近の値を m mod 4 ごとに代入すると上記の2点・4点・5点の最大点集合が得られる。右半分は `d_m(x)=d_m(m-1-x)` による。m≤4は直接式に代入する。

## 独立検証（有限完全列挙）

`../scripts/verify_two_row_vertex_degrees_20261014.py` は、(1) 4点の円判定を整数3×3行列式で直接行う全組列挙、(2) 行ごとの点対和の列挙、(3) 上記閉公式を独立に照合する。m=1..16 の全点で一致。さらに禁止四点組総数は既知 K0393 の

```
2*binom(m,4)+(2*m^3-3*m^2+4*m-3*(m mod 2))/12
```

と一致し、各禁止四点組を行ごとに2回数える `sum_x d_m(x)=2F(m)` も成立した。
