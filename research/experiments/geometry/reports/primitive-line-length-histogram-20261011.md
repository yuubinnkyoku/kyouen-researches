# 任意次元直方整数格子の極大直線長分布を O(dN+N log N) で厳密計算する（2026-10-11）

## 結果と既存成果との差分

整数直方格子 `B=∏_{i=1}^d {0,...,n_i-1}`（`d≥1`, `n_i≥1`）、`N=max n_i` を考える。`E_k` は、格子点を **ちょうど k 個** 含む異なる極大直線の本数（`k≥2`）とする。「極大」は点集合としての直線全体であり、単なる k 点組とは区別する。

`t=1,...,N-1` として

```
a_i(t) = floor((n_i-1)/t)
B_i(t) = (2*a_i(t)+1)*n_i - t*a_i(t)*(a_i(t)+1)
F(t) = product_i B_i(t) - product_i n_i
P_k = (1/2) * sum_{a=1}^{floor((N-1)/(k-1))} mu(a)*F(a*(k-1))  (2<=k<=N)
P_{N+1}=P_{N+2}=0
E_k = P_k - 2*P_{k+1} + P_{k+2}
```

**定理**：上式は任意の次元・辺長で厳密に成立し、全 `E_2,...,E_N` を `O(dN+N log N)` 回の整数算術演算で求められる（巨大整数のビット計算量は別）。`N=1` のとき直線は0本。これは既存の原始方向別の `A_k(v)-2A_{k+1}(v)+A_{k+2}(v)` 公式から方向ベクトル列挙を取り除き、全長の分布を一括して求める強化である。既存の高q閉公式と任意qの点組計数とは、求める統計量が異なる。

## 全称証明

原始整数方向 `v∈Z^d\{0}`（座標の最大公約数1）を向き `v` と `-v` の対として扱う。その方向の格子上の連続 `k` 点窓の本数は `∏_i (n_i-(k-1)|v_i|)_+`。極大直線が `l≥k` 点を含むとき、窓はちょうど `l-k+1` 個である。従って全方向で足した窓数を `P_k` とすれば

`P_k = Σ_{l≥k} (l-k+1) E_l`。

一方、整数方向 `u≠0` の重み `∏_i (n_i-t|u_i|)_+` を全て足すと、座標ごとの積に分離し、

`Σ_{u≠0} ∏_i (n_i-t|u_i|)_+ = ∏_i [n_i+2Σ_{j≥1}(n_i-tj)_+] -∏_i n_i = F(t)`。

有限和 `Σ_{j=1}^{floor((n_i-1)/t)} (n_i-tj)` を評価すると上記 `B_i(t)` になる。原始性 `gcd(u_1,...,u_d)=1` を Möbius 反転で選別し、向きの2重計数を2で割ると、`t=k-1` に対し

`P_k = (1/2) Σ_{a≥1} μ(a) F(a(k-1))`。

`a(k-1)>N-1` なら `F=0` なので有限和である。最初の窓数恒等式を2階差分すると `E_k=P_k-2P_{k+1}+P_{k+2}` が従う。全計算は整数のみで、`P_k` の分子は常に偶数。`F(t)` は `N-1` 個を各 `O(d)` で計算でき、`P_k` の合計項数は `Σ_{s=1}^{N-1} floor((N-1)/s)=O(N log N)`。証明終。

## 点組計数との接続

異なる共線 `q` 点組数は、極大直線長分布から `H_q=Σ_{k≥q} E_k binom(k,q)` と復元できる（`q≥2`）。これは全称恒等式であり、`q` 点組を直接列挙したものではない。`q=2` では `H_2=binom(∏n_i,2)` も回収する。

## 独立検証の範囲

`verify_primitive_line_histogram_20261011.py` は、公式側では Möbius 篩・約数和・2階差分を使用する。一方、独立実装は全格子点対から原始方向を求め、直線上の最初の格子点をキーとして同じ直線をまとめ、長さを数える。1〜4次元の204直方格子で全 `E_k` が完全一致した。さらに格子点数12以下の170条件で、`q` 点部分集合を直接列挙し、全ての2×2小行列式が0かを調べる第三方式と `H_q` が一致した。これらは有限実装監査であり、無限範囲の根拠は上の証明である。

| 格子 | 極大直線の総数 | 長さ別本数 `k:E_k` |
|---|---:|---|
| 3×3×3 | 253 | 2:204, 3:49 |
| 2×3×4 | 214 | 2:192, 3:16, 4:6 |
| 4×4×4 | 1,492 | 2:1,344, 3:72, 4:76 |
| 11×11 | 3,296 | 2:2,668, 3:396, 4:124, 5:40, 6:28, 7:4, 8:4, 9:4, 10:4, 11:24 |

11×11 の `H_4=10,428`, `H_5=13,116`, `H_8=4,180`、100×100 の `H_4=1,391,895,282` と一致。後者は証明済み公式による値であり直接列挙ではない。
