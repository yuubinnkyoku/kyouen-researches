# 多軸包囲箱型による安全配置数の復元と生成関数

2026-10-14。対象は任意次元の格子上の、平行移動で不変な非空有限配置族。標準共円ゲーム・q点版の安全なk石配置（k≥1）に適用できる。数学的証明と有限検算を区別する。

## 定理（全称証明）

d≥1、k≥1を固定する。合法性が整数平行移動で不変なk点集合S⊂Z^dの族を考える。辺長m_iの直方体B(m)=∏{0,...,m_i−1}に収まる合法集合の数をA_k(m)とし、どれかm_i≤0ならA_k(m)=0とする。

各Sの座標最小値を0に平行移動して正規化する。正規化した集合の各軸の最大値（座標差）s=(s_1,...,s_d)が指定値となる型の個数をc_k(s)とする。回転・鏡映では同一視しない。

任意のm_i≥0で
```
A_k(m) = Σ_{s≥0} c_k(s) ∏_i max(0,m_i−s_i).
```
従って各軸の中心二階差分D_i² f(m)=f(m+e_i)−2f(m)+f(m−e_i)は非負であり、全軸について
```
(∏_i D_i²) A_k(s) = c_k(s) ≥ 0.
```
部分軸だけに二階差分を施しても非負。二次元では前進混合差分が
```
Δ_xΔ_y A_k(m,n) = Σ_{0≤s≤m, 0≤t≤n} c_k(s,t) ≥ 0
```
となる。境界s_i=0でも負の辺長のA=0という規約で成立する。

さらに多変数形式的冪級数について、z^s=∏z_i^{s_i}として
```
Σ_{m≥0} A_k(m) z^m
  = [ (∏_i z_i) Σ_{s≥0} c_k(s) z^s ] / ∏_i(1−z_i)².
```
すなわち左辺に∏(1−z_i)²を掛け、各変数でz_iを1次だけ戻した係数は非負整数であり、包囲箱型を直接数える。

## 証明

非空配置の各座標最小値は一意であり、正規化型と整数平行移動ベクトルの組は元の配置と一対一に対応する。幅s_iの型を辺長m_iの盤に置く第i座標の移動は0,...,m_i−1−s_iの(m_i−s_i)_+通りで、各軸独立である。これが第一式。

h_s(m)=(m−s)_+ とし、m<0では0とする。D²h_s(m)=[m=s]、Δh_s(m)=[m≥s]（m,s≥0）。これを各因子に施すと差分式が従う。Σ_{m≥0}h_s(m)z^m=z^{s+1}/(1−z)²を各軸で掛け合わせると生成関数式も従う。□

## 独立の有限監査

`../scripts/verify_box_shapes_20261014.py` は整数行列式による4点禁止判定と、別実装の三点円心・共線判定を全5×5盤の4点組12,650通りで照合する。次に、1..5×1..5の盤とk=1..5について、全k点集合の直接列挙と、各包囲箱の全辺に触れる正規化集合の独立列挙を比較する。

108条件で総数再構成、45条件で二軸二階差分の復元が一致。例: A_4(3,3)=112、c_4(2,2)=64、A_5(5,5)=37,272。これは有限検査であり、上記の全称証明とは別。

## 適用限界

k=0の空配置には最小座標がないので含めない。盤面に依存する「極大」配置数、最大配置数、Grundy値の凸性は帰結しない。離散二階差分の非負性から連続Hessianの半正定値性も主張しない。既存の一軸禁止組数の凸性を、合法な途中局面の全軸差分・生成関数へ拡張したもの。11×11のroot証明は実施しない。
