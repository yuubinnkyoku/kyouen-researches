# 90度回転対称点集合の q 点共円・共線組の法4計数（2026-10-11）

## 範囲と結論（全称証明）

有限点集合 P⊂R² は中心 O の90度回転 R に不変とし、q≥4 とする。C_q(P) を q 個の相異なる点が一つの真円上にある部分集合の個数、H_q(P) を q 個が一直線上にある部分集合の個数とする。両者は排他的。

O 以外の点 p と -p が P にあるので、各対蹠点対を一度ずつ数える。a_s を O からの距離の二乗 s にある対蹠点対数、b_L を O を通る直線 L 上の対蹠点対数とする。δ=1_{O∈P}。さらに c_s=a_s/2 は同じ半径の4点回転軌道数である。二項係数は k>n のとき0とする。

**定理：**

- q=2k 偶数なら C_q(P)≡Σ_s binom(a_s,k) (mod 4), H_q(P)≡Σ_L binom(b_L,k) (mod 4)。
- q=2k+1 奇数なら C_q(P)≡0 (mod 4), H_q(P)≡δΣ_L binom(b_L,k) (mod 4)。
- 任意の q≥4 で H_q(P)≡0 (mod 2)。また C_q(P)≡0 (mod 2) unless 4|q。q=4k なら C_q(P)≡Σ_s binom(c_s,k) (mod 2)。

特に 4∤q なら、共円・共線を合わせた禁止 q 点組数は偶数である。q=4 の場合は既存の四点版を含むが、ここでは任意 q の新しい一般化を与える。

## 証明

有限集合 X に R が作用すると、その軌道の長さは1,2,4。従って |X|≡|Fix(R²)| (mod 4) である（固定されない軌道は4個ずつ、R²固定軌道は1または2個）。また |X|≡|Fix(R)| (mod 2)。これを X=共円 q 点組の集合、共線 q 点組の集合に適用する。

R² は O を中心とする半回転。R² 不変な点組は、偶数 q なら k 個の対蹠点対の合併、奇数 q なら O と k 個の対蹠点対の合併である。異なる対蹠点対 ±u,±v を含む真円は、中心が O で半径が |u|=|v| でなければならない。実際、円の中心 z は |u-z|²=|-u-z|² より z·u=0、同様に z·v=0。u,v が非平行なら z=0。u,v が平行なら四点は共線であり真円上にない。O と ±u は一つの真円に同時に乗れない（中心 z に対し |z|²=|u-z|²=|-u-z|² は |u|²=0 を強制する）。したがって真円の R² 不変 q 点組は、q 偶数なら同半径の k 対、q 奇数なら存在しない。

直線の R² 不変 q 点組は、すべて同じ O 通過直線上の k 対（奇数なら O も含む）であり、q≥4 ならその直線は一意。これで法4公式を得る。

R 不変な非中心点は必ず4点軌道を丸ごと含む。4点軌道は中心 O の真円上にあるので、q≥4 の R 不変共円点組は、中心を含まず q=4k で、同半径の k 個の4点軌道の合併に限る。R 不変な q≥4 の共線点組はない。これで法2公式も得る。証明終。

## 有限の独立検算（全称証明とは区別）

`scripts/quarter_turn_q_verify.py` は整数行列式と共線判定を用い、対称性を仮定しない直接 q 部分集合列挙から実測値を求め、軌道公式と照合する。5×5 全盤の q=4..8 と、中心の有無を含む回転対称部分集合および鏡映対称性を持たない集合を含め、計554条件を照合。不一致なし。

中心を原点に移した5×5盤では、q=8 の真円組はちょうど5個、共線組は0個。8点を通る真円は `x²+y²=5` と `x²+y²±x±y=2` の計5個（符号独立）。従って q=8 禁止組数は奇数であり、4|q の例外が実際に必要である。

q=4..8 の 5×5 全盤の共円組数は順に 762,360,152,40,5、共線組数は 64,12,0,0,0。計算値は整数行列式による有限完全列挙であり、全称定理の証明とは別の根拠。

## 制限・後続

q 点の円・直線禁止組の**個数の合同式**であって、ゲームの勝敗・極大配置・Grundy数を直接決めるものではない。一般の非回転対称盤には適用できない。固定幅長方形でも90度対称性がない場合は使えないが、正方形盤の q 点禁止組生成の独立検算条件になる。

`research/knowledge/items/` への昇格時は生成物を `uv run --locked python tools/knowledge/build.py` で再生成し、規約に従い全検査を行う。今回の実験記録を現行知識の正本として二重管理しない。
