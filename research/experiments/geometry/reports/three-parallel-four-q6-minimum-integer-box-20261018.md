# 3本の整数水平行・各4点・6点円3本の最小包囲格子は7×4

2026-10-18。対象は、整数格子の相異なる3本の水平行を選び、各行に相異なる4個の整数点を置いた12点集合。**通常の長方形全点盤ではない**。非退化な実円で6点を通るものの本数を数える。包囲格子の幅・高さは `W=max(x)-min(x)+1`, `H=max(y)-min(y)+1`、面積は `WH` とする。

## 定理（有限完全列挙と明示構成）

**6点円が3本存在する配置の最小包囲格子面積は28。** これを達成する幅と高さは `W=7,H=4` のみであり、平行移動で `0≤x≤6,0≤y≤3` と正規化すると配置はちょうど4個、すべて左右・上下反射で移り合う。

一つの達成配置：

| y | 4個のx座標 |
|---:|---|
| 0 | 0,3,4,5 |
| 1 | 0,2,5,6 |
| 3 | 2,3,4,6 |

この12点にある6点円は正確に以下の3本：

```
x²+y²−8x−4y+15=0
x²+y²−7x−3y+12=0
x²+y²−5x−y=0
```

**3本の完全性は手計算で証明できる。** 円は各水平行と高々2点で交わるため、6点円は各行からちょうど2点を含む。円の方程式 `x²+y²+Ax+By+C=0` の二根の和はどの行でも `−A` で共通。上記3行の相異なる2点の和の共通部分は `{5,7,8}` で、それぞれ各行でただ一組の点対に対応する。従って6点円は高々3本。列挙した3本が実際にそれぞれ6点を通ることは直接代入で確認できる。

## 面積28未満の完全排除

各行に4点必要なので `W≥4`、3行必要なので `H≥3`。`WH<28` なら、次の4個の長方形のいずれかに収まる：

- `H=3` なら `W≤9` → `9×3`。
- `H=4` なら `W≤6` → `6×4`。
- `H=5` なら `W≤5` → `5×5`。
- `H=6` なら `W≤4` → `4×7`。

`H≥7` は面積が28以上。面積28で `W≥4,H≥3` を満たす形は `7×4` と `4×7` だけ。

固定した `W,H` に対し、行の選択 `C(H,3)` 通り、各行の4点選択 `C(W,4)^3` 通りをすべて検査した。下表の `c_j` は**6点円がちょうどj本**の配置数。座標の平行移動・反射による同型除去は行っていない。

| W×H | 全配置 | c0 | c1 | c2 | c3 |
|---|---:|---:|---:|---:|---:|
| 9×3 | 2,000,376 | 1,890,350 | 108,920 | 1,106 | 0 |
| 6×4 | 13,500 | 8,696 | 4,424 | 380 | 0 |
| 5×5 | 1,250 | 650 | 498 | 102 | 0 |
| 4×7 | 35 | 22 | 8 | 5 | 0 |
| 7×4 | 171,500 | 138,776 | 31,452 | 1,268 | **4** |

この表は座標を上記の有限格子に制限した**完全列挙**である。任意の整数座標への適用は、包囲格子の幅・高さでの正規化と、上記の4長方形への包含から従う。任意の実数座標や傾いた平行線については主張しない。

## 二方式の独立照合

`../scripts/three_parallel_four_q6_minbox_primary.cpp` は、各行の二点和 `s` と積 `p` を使う。6点円の必要十分条件は、3行で二点和が等しく、`(y_i,p_i-y_i²)` が一直線上にあること。これは円方程式の根の和と積から直ちに導かれる。

`../scripts/three_parallel_four_q6_minbox_independent.cpp` は、全格子上の2+2+2点組を先に生成し、整数の4点共円行列式が0になるものを列挙。その6点集合が各12点配置に含まれるかを直接判定する。**二点和・積の判定を使用しない**。

両方式の出力を文字単位で比較し、全5長方形で完全一致した。結果は `../output/three_parallel_four_q6_minbox_counts.txt`。全体で2,186,661配置を検査（重複を含む包含長方形での数え上げ）。

```sh
g++ -std=c++17 -O3 research/experiments/geometry/scripts/three_parallel_four_q6_minbox_primary.cpp -o /tmp/q6minbox_a
/tmp/q6minbox_a > /tmp/q6minbox_a.txt
g++ -std=c++17 -O3 research/experiments/geometry/scripts/three_parallel_four_q6_minbox_independent.cpp -o /tmp/q6minbox_b
/tmp/q6minbox_b > /tmp/q6minbox_b.txt
cmp /tmp/q6minbox_a.txt /tmp/q6minbox_b.txt
python3 research/experiments/geometry/scripts/three_parallel_four_q6_minbox_witness.py
```

## ゲームの参考値と限界

上の7×4達成例を**12候補点のq=6通常プレイ**として完全計算すると、安全局面3915、空盤Grundy値0、極大配置は9石が8個・10石が24個。全安全局面のGrundy値分布は `g=0:1865,1:1837,2:90,3:123`。`../scripts/three_parallel_four_q6_minbox_witness.py` は有理数係数の円を3点から独立に復元し、全4096部分集合を再帰計算する。円3本の存在・完全性は上記の手計算でも証明済みだが、**ゲーム数値はこの特定の12点に対する有限完全列挙**である。
