# 等間隔三行の中央弦型 2+1+1：有限幅の厳密計数・最小横幅・4の合同式

2026-10-11。対象は整数格子の水平三行 `y=-h,0,h`（`h≥1`）、中央行の2点、上下行の各1点。**数学的全称証明**と独立4×4整数行列式による**有限監査**を区別する。

## 全称定理

中央行の2点を `(0,0),(d,0)`（`d≥1`）、上下行の点を `(u,-h),(v,h)` とする。`a=u+v-d`, `b=u-v` と置くと、共円条件は

```
a²+b² = d²-4h²,
u=(d+a+b)/2, v=(d+a-b)/2.
```

この対応は、整数完成 `(u,v)` と整数表現 `(a,b)` の全単射である。`d<2h` なら表現はない。

**横方向の最小包含幅。** 上の四点の横座標の最大値と最小値の差 `S` は

```
S(d,a,b) = d + e(d,a,b),
e(d,a,b) = max(0, (|a|+|b|-d)/2).
```

分子は必ず偶数。従って、固定弦長 `d` を含む四点をどこかの幅 `m` の整数列窓 `{0,...,m-1}` に収める必要十分条件は `m≥S+1` である。共円完成が少なくとも一つあるとき、その弦長の**真の最小盤幅**は

```
m_min(h,d) = 1+d+ min_{a²+b²=d²-4h²} e(d,a,b).
```

**有限幅での正確な個数。** `C_h(m;d)` を、上記三行の幅 `m` 窓において中央行の弦長が `d` である2+1+1型共円四点組の個数とする。上側と下側の点は区別し、中央行の2点は昇順に取る。このとき

```
C_h(m;d) = Σ_{a²+b²=d²-4h²} max(0,m-d-e(d,a,b))
C_h(m) = Σ_{d=1}^{m-1} C_h(m;d).
```

この和は各四点組を一度だけ数える。任意の `h,m` で厳密であり、有限幅の全四点組を走査する必要はない。和を実際に計算するときは `a` を `-⌊√(d²-4h²)⌋..⌊√(d²-4h²)⌋` で走査し、残りが平方数かだけを判定できる。

**弦への包含の必要十分条件。** 完成点が両方とも `0≤u,v≤d` にあることと `|ab|≤2h²` は同値。両方とも厳密に内側 `0<u,v<d` にあることと `|ab|<2h²` は同値。これは前段の包含上界より細かい、各表現ごとの完全判定である。

**4を法とする合同式。** 任意の `h≥1,m≥1` について

```
C_h(m;d) ≡ 0 (mod 4)     (d>2h),
C_h(m;2h) = max(0,m-2h),
C_h(m) ≡ max(0,m-2h) (mod 4).
```

`d<2h` では `C_h(m;d)=0`。特に標準3行盤 (`h=1`) の中央弦型2+1+1四点組の総数は、`m≥3` なら必ず `m-2 (mod 4)` に等しい。これは独立した計数実装の整合性検査に使える。

## 証明

中央弦を通る円を `x²+y²-dx+Ey=0` と書き、上下の点を代入して `E` を消去すると `u(d-u)+v(d-v)=2h²`。平方完成して `a²+b²=d²-4h²`。逆に `a²+b²≡a+b≡d²≡d (mod2)` より `u,v` は整数となり、元の円条件を満たす。

`N=d²-4h²≥0` なら `|a|,|b|<d`。`u,v` の最大・最小は `(d+a+|b|)/2`, `(d+a-|b|)/2` なので、横方向の超過は

```
S-d = max(0,(a+|b|-d)/2) + max(0,(|b|-d-a)/2).
```

`|b|<d` のため両項が同時に正になることはない。和は `max(0,(|a|+|b|-d)/2)` に一致する。表現式と `d` の偶奇が一致するためこの値は整数。固定形状の横幅が `S` なら幅 `m` に収める平行移動は `max(0,m-S)` 通りであり、計数公式が従う。

`S=d` と `|a|+|b|≤d` は同値。両完成点が厳密に内側なら `|a|+|b|<d`。これらを二乗し、`a²+b²=d²-4h²` を代入すると、`|ab|≤2h²` と `|ab|<2h²` がそれぞれ得られる。

`d>2h` のとき `N>0`。整数表現 `(a,b)` の符号変更と座標交換で得られる軌道は4または8個（`a=0` または `|a|=|b|` の場合のみ4）。各軌道の `|a|+|b|` は一定なので、窓内の平行移動数も同じ。従って各軌道の寄与は4の倍数。`d=2h` の唯一の表現は `(0,0)` で、`u=v=h`、横幅は `2h`、移動数は `max(0,m-2h)`。全てを足して合同式を得る。□

## 独立監査と数値

`../scripts/audit_central_211_finite_width.py` は、表現数側と独立に4×4の整数行列式（24置換の定義）で全四点候補を判定する。`1≤h≤5,2≤m≤12` の55条件について、弦長ごとの個数まで完全一致。全条件で直接検出した共円四点組は延べ1,225個。さらに `1≤h≤16,1≤d≤300` の4,800条件、17,564整数表現で横幅・包含条件と整数行列式を検証し、不一致なし。

標準3行盤の中央弦型個数 `C_1(m)` は `m=4,6,8,10,12` で順に `10,28,50,92,134`。幅11では `C_h(11)` は `h=1..5` で `113,95,57,23,1`。従って**11×11の等間隔三行の中央弦型**だけを数えた厳密な部分和は、中央行の位置の重み `11-2h` を用いて

```
9*113 + 7*95 + 5*57 + 3*23 + 1*1 = 2037.
```

これは11×11の**全禁止四点組数ではない**。非等間隔三行、外側行に弦がある型、2+2型、4行型、共線型は含まない。禁止四点組の分類・生成の部分検算には使用できる。

## 残件

同じ有限幅の厳密計数を、非等間隔三行や外側行に弦があるPell型に拡張できるか。`m_min(h,d)` の二平方和表現の最小 `|a|+|b|` を素因数分解から高速に得られるかも未解決。上記の式は全称的だが、実際の生成器に組み込んだ速度改善は未測定。
