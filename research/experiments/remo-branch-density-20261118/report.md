## 記法

Mは素数、0≤κ≤M−2。live: gcd(κ+1, M+1)=1。
K=(M+1)t+κ, Y=K+1=(M+1)t+κ+1, N=MY−1, C=gcd(M+1, κ+2),
Q=N/C=At+B, A=M(M+1)/C, B=(M(κ+1)−1)/C, gcd(A,B)=1（K0952）。

枝集合 E(M,κ) = {e : 1≤e≤⌊(M−1)/C⌋, gcd(e,A)=1}。
各 e∈E に対し t_e=(−B·A^{-1}) mod e（e=1ではt_e=0）とおくと、
枝ペアは一次形式の対

- Y_e(n) = (M+1)e·n + c1, c1=(M+1)t_e+κ+1（= Y(t_e+en)）
- P_e(n) = A·n + c2, c2=(At_e+B)/e（= Q(t_e+en)/e）

（A t_e + B ≡ 0 (mod e) なので c2 は整数）。t_e+en（n≥0）は丁度 e|Q(t) を満たす t の集合。

**恒等式（KEY）**: 全 n≥0 に対し M·Y_e(n) − 1 = C·e·P_e(n)。M·Y(t)=M(M+1)t+M(κ+1)=C(At+B)=C·Q(t) から直ちに従う。

TAIL-CLEAN 補題: Y=M² は t=M−1（κ=0）でのみ起き、t0=max(M,3)>M−1（M≥2）なのでテール t≥t0 には現れない。よってテールでは K0952 の枝分解とengineのヒット判定は完全に一致する（§BRANCH-EXACTで機械検証）。

## 定理

### ALL-ADM（全称・無条件）

**定理1** M素数・κ live・e∈E(M,κ) に対し、枝ペア (Y_e, P_e) は全ての素数 q で局所許容である。すなわち ν_e(q) = #{n mod q : q|Y_e(n) または q|P_e(n)} < q が全素数 q で成り立つ。

証明: 閉包障害は次のいずれかのみの場合に起きる。
(1) q|a1=(M+1)e ∧ q|c1（Y_e(n)≡0 ∀n）
(2) q|a2=A ∧ q|c2（P_e(n)≡0 ∀n）
(3) q∤a1a2 かつ両形式がmod qで根を持ち、根が相異なる（このとき q≤2 が必要）。

(1): q|M+1 なら c1≡κ+1 (mod q) で、live条件から q∤κ+1。q|e なら恒等式より M·Y_e(n)−1 ≡ 0 (mod q)、つまり Ce·P_e(n) ≡ −1 (mod q)。q|e のとき左辺は常に ≡0 なので −1≡0、矛盾。よって q|a1 では c1≢0。

(2): gcd(e,A)=1 から q|A ∧ q|e は排斥される。よって q|A では q∤e であり、c2·e=At_e+B ≡ B (mod q) より c2 ≡ B e^{-1} (mod q)。gcd(A,B)=1（K0952）から q|A ∧ q|B は不可能、よって c2≢0。

(3): q≥3 なら ν_e(q)≤2<q なので問題なし。q=2: まず両形式はmod qで根を共有しない（共通根 n があれば恒等式で MY_e(n)≡1 (mod q) と q|Y_e(n) が両立せず 0≡1）。M=2 のとき P_e(n)=(M·Y_e(n)−1)/(Ce)=(2Y_e(n)−1)/(Ce) は常に奇（2Y−1が奇）なので P 側に偶数根は存在せず ν_2≤1。M 奇のとき live ⟹ κ 偶 ⟹ 2|C かつ 2|(M+1)=a1、c1≡κ+1 (mod 2)≡1 なので Y 側根なし。よって ν(2)=0 または P 側根1つのいずれかで、2被覆は起きない。∎

帰結（K0952の強化）: live クラスの全ての枝 e∈E が局所許容になった。e=1 のみで十分だった無限性議論（BH+許容性）に変更はないが、全枝がBH期待値に寄与し得るようになった。

### SS-STRUCT（全称・無条件）

**定理2** M素数・κ live・e∈E に対し、ν_e(q) の値は次で完全に決まる（q=2,3 はコード nu_case と同一の例外処理を含む）。

- ν_e(q)=0 ⟺ q|M+1 ∧ v_q(C) < v_q(M+1)
- ν_e(q)=1 ⟺ [q|M] ∨ [q|e ∧ q∤M+1] ∨ [q|M+1 ∧ v_q(C) = v_q(M+1)]
- ν_e(q)=2 ⟺ その他（q∤e·M·(M+1)、または該当しない組合せ）

さらに、e=1 の特異級数を G(M,C) とおくと

  SS_e = G(M,C) · Π_{q|e, q∤M(M+1)} (q−1)/(q−2)

であり、G を含め ν 分類は κ を C=gcd(M+1,κ+2) のみを経由して決まる。

証明: q∤e·M·(M+1) のとき両形式の係数は q で可逆で、根は常に相異なる（共通根は恒等式で排除、定理1と同じ議論）ので ν=2。
q|e ∧ q∤M+1: c1≢0（定理1で示済み）で Y 側根なし、P 側は根1つ（q∤A: gcd(e,A)=1）なので ν=1。
q|M+1 ∧ v_q(C)<v_q(M+1): v_q(A)=v_q(M+1)−v_q(C)≥1 なので P 側は係数が q で落ち c2 ≡ B e^{-1} ≢0（gcd(A,B)=1）で根なし。Y 側は c1≡κ+1≢0（live）で根なし。ν=0。
q|M+1 ∧ v_q(C)=v_q(M+1): v_q(A)=0 なので P 側根1つ、Y 側根なし。ν=1。
q|M: C|M+1 と gcd(M,M+1)=1 から q∤C。c2·e ≡ At_e+B ≡ B ≡ (M(κ+1)−1)C^{-1} ≡ −C^{-1} (mod q) ≢0 なので P 側根なし、Y 側（q∤M+1 なら可逆、q|M+1 は上と同じ扱い）根1つ。ν=1。
q=2: M=2 なら P_e 常奇で ν=1（Y 側根1つ、P 側0）。M 奇なら上の分類に 2|M+1 を代入し、v_2(C)≥1（κ偶）から ν(2)=0 または 1。コード nu_case の分岐と一致。
SS_e への影響: ν=0 の q は因子 q²/(q−1)²、ν=1 は q/(q−1)、ν=2 は q(q−2)/(q−1)²。e を e で割る素数 q∤M(M+1) の効果は ν=2→1 のみで、因子比は (q/(q−1)) / (q(q−2)/(q−1)²) = (q−1)/(q−2)。q|M では ν が元々1なので変化なし。∎

**系（DENSITY-CLASSIFY）** 枝ごとのHL密度 SS_e（と積分形状）は κ を C のみ経由で決まる。よってBH条件付きでは、live クラス (M,κ) のテールでのヒット密度は C=gcd(M+1,κ+2) のみの関数である。

### U_M-DENSITY（BH条件付き）

**命題3** κ=0 クラスの小テールヒット（t<t0, engine 事実、§U_M-ANCHORS の +1 補正）を s とおくと、BH予測は

  U_M(N) = s + Σ_{e∈E(M,0)} SS_e · ∫_0^{(N−t_e)/e} dn / (ln Y_e(n) · ln P_e(n))

積分は 1/e を掛けない。t に換算した積分 ∫_{t_e}^{N} dt/(ln Y(t) ln Q(t)) の上限は (N−t_e)、Jacobi行列 dt=e·dn による e と、剰余類 t≡t_e (mod e) の密度 1/e が相殺する。K0950 で M=3 に固定していた密度閉形式を一般 M に拡張した形で、K0950 の「一般MのU_M密度OPEN」をBH条件付きで解決する。

### STARVATION再解釈

- 出版 sparse 69クラス（K≤2e5 で cnt≤2、K0946/0950 で指摘）は**全て** bh_pred_at_2e5=0。理由: min M=991 > 200 = 2e5/(M+1) 上限より大きく、census 窓のテール T=⌊2e5/(M+1)⌋ が t0=M を割り込めない。つまり sparse tail は「テール密度が低い」のではなく「窓が pre-tail に達していない」現象。p−2 型濃縮（48/69=69.6%, P-FACTOR: p|MY−1 が全 Y に強制される）と single-branch 13/69・median C/M=0.077 は pre-tail 偤の記述として保存される。
- per-κ 再集計（素数M≤100・live 385クラス・K≤2e5・engine事実）: Spearman(count, BH予測)=0.9825、log-log傾斜0.9664。BH条件付き密度がクラス間のヒット数のほぼ全分散を説明する。
- (M,C)群（n≥3・総ヒット≥12）44群中35群で var/mean ∈ [0.25,3]（Poisson 95%帯）。DENSITY-CLASSIFY が予測する「(M,C)群内は交換可能」観察と整合（帰納的ではあるが、群内クラスの分散がポアソン的であることは枝密度のκ非依存の自然な帰結として説明可能）。

### FIRSTHIT: 出版則 F(M)~1.767·M^1.5088 は pre-tail 現象

- **PRE-TAIL-FIRSTHIT（機械事実）**: live 1,546クラス（素数M≤199・K≤1e7・tier3素数表）中 1,545 の初回ヒット t_first がテールシーム t0=max(M,3) 未満。唯一の例外 (M,κ)=(43,20) は t=43=t0 ちょうど（シーム上=枝レジーム内）。max t_first/t0 = 0.923。よって出版 FIRSTHIT-GROWTH（F~1.767·M^1.5088, R²=0.8991）は丸ごと pre-tail 現象であり、枝レジームの密度からは導かれない。
- **反例（pre-tail は別レジームの実証）**: (M,t)=(3,2): engine は σ_Z=1（ヒット）だが Y=9 は合成。枝分解は σ_Z=1 ⟹ Y 素数 を要求するので、pre-tail では枝構造が σ_Z を記述しない。
- **TAIL-FIRSTHIT-PRED（BH条件付き）**: 枝レジームのみの積分でBH期待値が1に達する時点 t̂（二分探索・nodes=48・iter=14）は全1,546クラスで有限。median t̂/t0=1.07（q10=1.04, q90=1.16）。小Mでは t̂≫t0（M=2: 36.7, M=3: 27.3, M=5: 2.60）、M≥100 では t̂/t0 ∈ [1.04, 1.11]。
- per-M 回帰: F̂(M)=max_κ K̂ は 12.77·M^1.4814（R²=0.9125）で観測 1.767·M^1.5088 と指数が一致するが、これは crossover の産物: 大Mでは F̂≈(1.10–1.33)·M² で観測より 2.5–22倍大きい（M=199: F̂=46,699 vs F=5,518）。クラス単位の順位相関 Spearman(ln K_first, ln K̂)=0.5249（Pearson 0.6139）はM依存の反映にすぎず、**within-M** の Spearman 平均は 0.095（M≥50: 0.137）で、テール密度は pre-tail 初回ヒットの順序を予測しない（きれいな否定結果）。
