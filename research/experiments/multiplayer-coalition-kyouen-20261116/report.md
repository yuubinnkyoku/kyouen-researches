## 位置づけ

K0339（2026-10-05）は r人巡回配置ゲームの全称 mod r 定理（敗者が戦略に依存しないことと
r | Δ の同値性、Δ=極大サイズ差のgcd）を証明し、K0024/K0025 の一様レジームへの系を与えた。
ただし本文で「r人対戦の利害や連合を含む戦略的分類、敗者を取り除いて継続する規則、
r人版のnimber定義は対象外であり未解決として残る」と明示していた。

本実験はその残課題のうち**連合を含む戦略的分類**と**最終着手者（勝者候補）の特定**を開く。
新しい全称定理は主張しない範囲も明確に区別する:

1. **全称（証明）**: 連合ゲームの決定性、r=2 帰着、凍結系（K0339の系として）、
   Win⟹Surv、Win⟹可能最終着手者。すべて本文で証明し、かつ列挙全位置で機械検証した。
2. **導出（算術）**: K0339の剰余公式を、K0339が instantiate しなかった全ての既証明一様
   レジーム（K0855/K0072/K0302 5件/K0331/K0484/K0813/K0763/K0820/K0843 等）へ一斉適用した
   敗者・最終着手者表。各行の C の出典は引用のみで、新しい幾何は含まない。
3. **有限計算**: 40小盤（w×m, q=4,5、面積≤18）の全安全局面について
   可能敗者・可能最終着手者・連合 Surv/Win を完全計算した。全称への昇格はしない。

## 規則・定義

盤は D(w,m)={0..m−1}×{0..w−1} の整数格子、q点版完全指摘（K0001）。安全判定は
[x²+y²,x,y,1] 整数行列式のランク（≤3 ⟺ 共円または共線）、浮動小数点不使用。
プレイヤー 0..r−1 が巡回し、合法手 = 安全を保つ空点への着手。

- **敗者規則（K0339と同一）**: 最初に合法手を失ったプレイヤーを唯一の敗者として終了。
- **最終着手者**: 終局で最後に着手したプレイヤー。「最終着手者＝唯一の勝者」という
  規約は一つの選択肢であり、本実験は規約に依存しない「可能最終着手者集合」と
  強制可能性のみを報告する。順位・報酬・敗者除外後の継続は主張しない。
- **可能敗者集合** Λ(S,a;r) = { (a+ℓ) mod r : ℓ∈ℓ(S) }。
  ℓ(S) = { |M|−|S| : M は S を含む極大安全集合 }。下方閉性により S を含む全極大集合は
  到達可能（K0339証明と同じ到達可能性論）なのでこれは全対局の厳密な集合。
- **連合ゲーム**: プレイヤー j 一人 vs 他 r−1 人の連合。連合は全員が j の不利益になる
  よう完全に協調する（最悪仮定）。j は単独で戦う。
  - **Surv_j(S,a)**: j が「敗者でない」ことを強制できる（j の手番は OR、連合の手番は AND、
    終端では着手者＝敗者）。
  - **Win_j(S,a)**: j が最終着手者であることを強制できる（終端では (a−1) mod r が最終着手者）。

## 全称部分（証明）

**補題D（決定性）。** 任意の (S,a,r,j) について Surv_j(S,a) が偽 ⟺ 連合が「j を敗者にする」
合同戦略を持つ。Win_j についても同値。
*証明.* 有限完全情報ゼロサムゲームの標準的な後退帰納決定性。状態は (S, 手番)、
選択は有限、引き分けなし。□

 Surv_j=偽 のことを「j は連合によって標的化できる」と呼ぶ。敗者規則のもとでは
これは「他 r−1 人が協調すれば j の如何なるプレイでも j が最初に詰む」という強い主張である。

**補題L1（r=2 帰着）。** r=2 では Surv_0(S,a) = Win_0(S,a) = 古典通常プレイの手番側勝利
（= Grundy値 ≠ 0）。
*証明.* r=2 では「自分が詰む前に相手を詰ませる」ことと「自分が最終着手者になる」ことは
同一事象。AND/OR 帰納は古典 win/loss 帰納そのものである。□
（検証器は全40盤で Surv=Win かつ Grundy mex DP との一致を機械照合した。）

**系F（凍結、K0339の系）。** S を含む全極大安全集合の石数が一様に C+|S|（Δ(S)=0、
特に全確定レジームの任意の局面）のとき、任意の r≥2・任意のプレイで
敗者 = (a + C − |S|) mod r、最終着手者 = (a + C − |S| − 1) mod r であり（K0339本文の式）、
連合は無力: Surv_j = [j ≠ 敗者]、Win_j = [j = 最終着手者]。
*証明.* 全対局が同じ長さ C−|S| で終わるので OR/AND が崩壊する。K0339の定理4（全局面版）の
直系。□
（検証器は列挙した全盤面・全位置・全 r∈{2,3,4} で |ℓ(S)|=1 の位置の Surv/Win 配列が
この予測と一致することを機械検証した — 例えば 3×3 の一様5石終局では r=3 の敗者は
5 mod 3 = 2 に固定される。）

**補題L3。** r≥2 で Win_j(S,a) ⟹ Surv_j(S,a)。
*証明.* j が最終着手者である限り、次に詰むのは (j+1) mod r ≠ j。強制戦略の存在は
連合の如何なる応答に対してもこの性質を保つ。□

**補題L4。** Win_j(S,a) ⟹ j ∈ 可能最終着手者集合。
*証明.* 強制戦略の実行列自体が合法対局列であり、その終局の最終着手者は j。□

注: 逆は成り立たない（4×4・3人では全員が可能最終着手者だが誰も Win を強制できない）。
また Surv_j と可能敗者集合の間には含意がない（j の悪手を含む全対局は j の最善を
仮定しない）。この区別が「可能 ≠ 強制」の主内容である。

### 主要な発見（いずれも有限計算の帰結）

1. **単独強制勝利（非一様盤のルート）**: 2×4（=4×2 回転同形）の3人戦では
   **P_1 が連合2人を相手に単独で最終着手を強制できる**（Win=[0,1,0]、ℓ={4,5} のうち
   5石終局を必ず実現できる）。2×8（=8×2）では3人戦で P_2、4人戦で P_1 が単独強制勝利。
   それ以外の非一様盤のルートでは誰も単独強制勝利できない。
   一方、**途中局面には単独強制勝利位置が豊富に存在する**（例: 4×4 の3人戦で
   5,811位置中4,776位置）。ルートで強制勝利が存在するかは盤ごとに変わる。
2. **可能 ≠ 強制**: 2×4 の3人戦で可能敗者は {1,2} の両方だが、連合が敗北を強制できるのは
   P_2 のみ（Surv=[1,1,0]）。P_1 は可能敗者でありながら連合にも追い詰められない。
3. **連合の選択的標的化**: 4×4 の3人戦では全員が可能敗者（{0,1,2}）かつ誰も単独強制勝利
   できないが、連合が敗北を強制できるのは P_0 と P_2 のみで P_1 は標的化できない。
   3×5 q=5・4×4 q=5 の3人戦では P_0, P_1 が標的化可能で P_2 は不可。
   3×5・3×6 q=4 の3人戦では**全員が標的化可能**（Surv=[0,0,0]）で、かつ誰も単独強制勝利
   できない — 「連合完全支配」のルート。
4. **カオス位置の計数**: ℓ(S) の分散が r 以上ある盤では全 r 人が可能敗者になる位置
   （|Λ|=r）が存在する。例: 3×5 q=5 では r=3 で 6,472 位置、r=4 で 585 位置。
   3×6 q=4 では r=3 で 3,449 位置、r=4 で 69 位置。4×4 q=4 は ℓ が3値なので r=4 では
   カオス位置は1つも存在しない。
5. **凍結系の全位置機械検証**: Δ=0 の位置（一様レジーム相当、列挙盤の多数）は
   全位置・全 r で系Fの予測と DP が厳密一致した。
6. **幾何エンジンは既刊値を完全再現**: 安全集合数 2×2:15, 3×3:298, 4×4:5,811（K0004）、
   極大サイズ分布・Δ・可能敗者 r=2..8（1..4 正方形盤、K0339 の JSON と完全一致）、
   2×m q=4 m=6,7,8 の空盤後手勝ち（K0069）、3×m q=5 の空盤先手勝ちが m∈{1,3} のみ
   （K0071）、(2,4)/(2,5)/(2,6) q=5 の全極大8石・個数 C(m,4)²（K0025 の実幾何検証）。
   回転対 (w,m)↔(m,w) 13組が全不変量で一致。

### 新しい有限データ（副産物）

2×m q=4 の極大サイズ分布 m=1..8（m=3: {4:12} 一様, m=4: {4:8,5:16}, m=5: {5:72,6:6},
m=6: {5:108,6:64}, m=7: {5:60,6:320}, m=8: {5:16,6:1058}）と安全集合数の全列、

## 検証構造

- **2独立エンジン**: A は (q−1) 点部分集合の円/直線方程式の増分管理（着手ごとに
  C(|S|,q−2) 個の新述語を追加）、B は禁止 q 点集合のビットマスク全列挙から
  直接 children を導出。位置集合・children の完全一致を全盤で確認。
- **DPの独立照合**: r=2 の Surv/Win が Grundy mex DP（別アルゴリズム）と全40盤で一致。
  凍結規則の全位置一致。L3・L4 の全位置成立。
- **外部アンカー**: K0004/K0011-K0014/K0339/K0069/K0071/K0025 の既刊数値 354件を
  検証器内にハードコードし全件一致。回転対13組。
- **決定性**: 乱数・時刻不使用、辞書順ソート固定、`json.dump(sort_keys=True, indent=1)`。
  再実行で `output/audit.json` はバイト同一（確認済み）。CI は
  `git diff --exit-code` で再現を強制する。

## 限界・主張しないこと

- 有限センサスは列挙40盤のみの帰結であり、非一様盤一般についての全称主張ではない
  （例:「ルート強制勝利は (2,4)型と (2,8)型に限る」ような主張はしない）。
- 順位・報酬規約、敗者を除外して継続する規則、r人版 nimber、Grundy 拡張は主張しない
  （K0339と同様に未解決のまま）。
- 確定レジーム表の各行の C は引用した既刊定理による。本実験は新しい幾何閾値を証明しない。
- 11×11 空盤・二石root {49,60}/{59,60}・S2 {59,60}・class1/class2/class4 は本実験と無関係に
  UNKNOWN/IN FLIGHT のまま。
