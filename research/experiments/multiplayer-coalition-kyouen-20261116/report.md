## 位置づけ

K0339（2026-10-05）は r人巡回配置ゲームの全称 mod r 定理（敗者が戦略に依存しないことと
r | Δ の同値性、Δ=極大サイズ差のgcd）を証明し、K0024/K0025 の一様レジームへの系を与えた。
ただし本文で「r人対戦の利害や連合を含む戦略的分類、敗者を取り除いて継続する規則、
r人版のnimber定義は対象外であり未解決として残る」と明示していた。

本実験はその残課題のうち**連合を含む戦略的分類**と**最終着手者（勝者候補）の特定**を開く。
新しい全称定理は主張しない範囲も明確に区別する:

1. **全称（証明）**: 連合ゲームの決定性、r=2 帰着、凍結系（K0339の系として）、
   Win⟹Surv、Win⟹可能最終着手者。すべて本文で証明し、かつ列挙全位置で機械検証した。
2. **導出（算術）**: K0339の剰余公式を、K0339が instantiate しなかった全ての既証明一様
   レジーム（K0855/K0072/K0302 5件/K0331/K0484/K0813/K0763/K0820/K0843 等）へ一斉適用した
   敗者・最終着手者表。各行の C の出典は引用のみで、新しい幾何は含まない。
3. **有限計算**: 40小盤（w×m, q=4,5、面積≤18）の全安全局面について
   可能敗者・可能最終着手者・連合 Surv/Win を完全計算した。全称への昇格はしない。

## 規則・定義

盤は D(w,m)={0..m−1}×{0..w−1} の整数格子、q点版完全指摘（K0001）。安全判定は
[x²+y²,x,y,1] 整数行列式のランク（≤3 ⟺ 共円または共線）、浮動小数点不使用。
プレイヤー 0..r−1 が巡回し、合法手 = 安全を保つ空点への着手。

- **敗者規則（K0339と同一）**: 最初に合法手を失ったプレイヤーを唯一の敗者として終了。
- **最終着手者**: 終局で最後に着手したプレイヤー。「最終着手者＝唯一の勝者」という
  規約は一つの選択肢であり、本実験は規約に依存しない「可能最終着手者集合」と
  強制可能性のみを報告する。順位・報酬・敗者除外後の継続は主張しない。
- **可能敗者集合** Λ(S,a;r) = { (a+ℓ) mod r : ℓ∈ℓ(S) }。
  ℓ(S) = { |M|−|S| : M は S を含む極大安全集合 }。下方閉性により S を含む全極大集合は
  到達可能（K0339証明と同じ到達可能性論）なのでこれは全対局の厳密な集合。
- **連合ゲーム**: プレイヤー j 一人 vs 他 r−1 人の連合。連合は全員が j の不利益になる
  よう完全に協調する（最悪仮定）。j は単独で戦う。
  - **Surv_j(S,a)**: j が「敗者でない」ことを強制できる（j の手番は OR、連合の手番は AND、
    終端では着手者＝敗者）。
  - **Win_j(S,a)**: j が最終着手者であることを強制できる（終端では (a−1) mod r が最終着手者）。

## 全称部分（証明）

**補題D（決定性）。** 任意の (S,a,r,j) について Surv_j(S,a) が偽 ⟺ 連合が「j を敗者にする」
合同戦略を持つ。Win_j についても同値。
*証明.* 有限完全情報ゼロサムゲームの標準的な後退帰納決定性。状態は (S, 手番)、
選択は有限、引き分けなし。□

 Surv_j=偽 のことを「j は連合によって標的化できる」と呼ぶ。敗者規則のもとでは
これは「他 r−1 人が協調すれば j の如何なるプレイでも j が最初に詰む」という強い主張である。

**補題L1（r=2 帰着）。** r=2 では Surv_0(S,a) = Win_0(S,a) = 古典通常プレイの手番側勝利
（= Grundy値 ≠ 0）。
*証明.* r=2 では「自分が詰む前に相手を詰ませる」ことと「自分が最終着手者になる」ことは
同一事象。AND/OR 帰納は古典 win/loss 帰納そのものである。□
（検証器は全40盤で Surv=Win かつ Grundy mex DP との一致を機械照合した。）

**系F（凍結、K0339の系）。** S を含む全極大安全集合の石数が一様に C+|S|（Δ(S)=0、
特に全確定レジームの任意の局面）のとき、任意の r≥2・任意のプレイで
敗者 = (a + C − |S|) mod r、最終着手者 = (a + C − |S| − 1) mod r であり（K0339本文の式）、
連合は無力: Surv_j = [j ≠ 敗者]、Win_j = [j = 最終着手者]。
*証明.* 全対局が同じ長さ C−|S| で終わるので OR/AND が崩壊する。K0339の定理4（全局面版）の
直系。□
（検証器は列挙した全盤面・全位置・全 r∈{2,3,4} で |ℓ(S)|=1 の位置の Surv/Win 配列が
この予測と一致することを機械検証した — 例えば 3×3 の一様5石終局では r=3 の敗者は
5 mod 3 = 2 に固定される。）

**補題L3。** r≥2 で Win_j(S,a) ⟹ Surv_j(S,a)。
*証明.* j が最終着手者である限り、次に詰むのは (j+1) mod r ≠ j。強制戦略の存在は
連合の如何なる応答に対してもこの性質を保つ。□

**補題L4。** Win_j(S,a) ⟹ j ∈ 可能最終着手者集合。
*証明.* 強制戦略の実行列自体が合法対局列であり、その終局の最終着手者は j。□

注: 逆は成り立たない（4×4・3人では全員が可能最終着手者だが誰も Win を強制できない）。
また Surv_j と可能敗者集合の間には含意がない（j の悪手を含む全対局は j の最善を
仮定しない）。この区別が「可能 ≠ 強制」の主内容である。

### 主要な発見（いずれも有限計算の帰結）

1. **単独強制勝利（非一様盤のルート）**: 2×4（=4×2 回転同形）の3人戦では
   **P_1 が連合2人を相手に単独で最終着手を強制できる**（Win=[0,1,0]、ℓ={4,5} のうち
   5石終局を必ず実現できる）。2×8（=8×2）では3人戦で P_2、4人戦で P_1 が単独強制勝利。
   それ以外の非一様盤のルートでは誰も単独強制勝利できない。
   一方、**途中局面には単独強制勝利位置が豊富に存在する**（例: 4×4 の3人戦で
   5,811位置中4,776位置）。ルートで強制勝利が存在するかは盤ごとに変わる。
2. **可能 ≠ 強制**: 2×4 の3人戦で可能敗者は {1,2} の両方だが、連合が敗北を強制できるのは
   P_2 のみ（Surv=[1,1,0]）。P_1 は可能敗者でありながら連合にも追い詰められない。
3. **連合の選択的標的化**: 4×4 の3人戦では全員が可能敗者（{0,1,2}）かつ誰も単独強制勝利
   できないが、連合が敗北を強制できるのは P_0 と P_2 のみで P_1 は標的化できない。
   3×5 q=5・4×4 q=5 の3人戦では P_0, P_1 が標的化可能で P_2 は不可。
   3×5・3×6 q=4 の3人戦では**全員が標的化可能**（Surv=[0,0,0]）で、かつ誰も単独強制勝利
   できない — 「連合完全支配」のルート。
4. **カオス位置の計数**: ℓ(S) の分散が r 以上ある盤では全 r 人が可能敗者になる位置
   （|Λ|=r）が存在する。例: 3×5 q=5 では r=3 で 6,472 位置、r=4 で 585 位置。
   3×6 q=4 では r=3 で 3,449 位置、r=4 で 69 位置。4×4 q=4 は ℓ が3値なので r=4 では
   カオス位置は1つも存在しない。
5. **凍結系の全位置機械検証**: Δ=0 の位置（一様レジーム相当、列挙盤の多数）は
   全位置・全 r で系Fの予測と DP が厳密一致した。
6. **幾何エンジンは既刊値を完全再現**: 安全集合数 2×2:15, 3×3:298, 4×4:5,811（K0004）、
   極大サイズ分布・Δ・可能敗者 r=2..8（1..4 正方形盤、K0339 の JSON と完全一致）、
   2×m q=4 m=6,7,8 の空盤後手勝ち（K0069）、3×m q=5 の空盤先手勝ちが m∈{1,3} のみ
   （K0071）、(2,4)/(2,5)/(2,6) q=5 の全極大8石・個数 C(m,4)²（K0025 の実幾何検証）。
   回転対 (w,m)↔(m,w) 13組が全不変量で一致。

## 2×m q=4 族のルート連合特徴付け（m=1..12・r=2..8・全 r ≥ 9 は含めて全称）

  （=可能敗者集合 {0,2} 全体）、m=8: {0}。
- **可能敗者は誰もが標的化可能なわけではない**（r=3 の m=4,5,8）が、
  r≥4 では可能敗者から強制勝利者を除けば常に全員標的化可能。

**一様盤 (m=1,2,3 と m≥9) のルート**: 凍結予測どおり（敗者=C mod r・最終着手者=(C−1) mod r、
連合無力）であることを r=2..8 全てで機械検証（C∈{2,3,4} と C=6）。

**全称系（証明・導出のみ、計算不要）**: K0069 は 2×m q=4 の m≥9 で全極大がちょうど6石
（ゆえに全安全局面で Δ=0）を証明済み。凍結崩壊（本項の系3）と合わせて、
**2×m q=4・m≥9 では任意のプレイヤー数 r ≥ 2 に対してルートは凍結**: 可能敗者・
標的化可能者は {6 mod r}、単独強制勝利者は {(6−1) mod r} で、いかなる連合も結果を
変えられない。これは2つの既証明結果から演繹される全称命題であり、m=9..12 の
センサスはその有限照合である。

**族の完全特徴付けのまとめ（r≥3 の非自明部分）**: 2×m q=4 族全体で、ルートの
単独強制勝利は (4,3,P_1)、(8,3,P_2)、(8,4,P_1) の3箇所ちょうど
（m≤8 は有限計算・m≥9 は全称系で排除）。r≥5 では族全体で単独強制勝利は存在せず、
非一様盤では可能敗者から強制勝利者を除いた全員が連合に標的化可能。

（限界: m≤8 の非一様部分のうち r=3..6 は有限計算であり、「2×8 型が最後の非一様強制勝利盤」
などの非一様盤一般への外挿はしない。r≥7 は次節の短プレイ定理で全称決定される。）

## 高r完了: 短プレイ定理による r≥7 の族全体決定（2026-11-16 第2拡張）

**定理A（短プレイ標的化）。** 位置 S（手番 P_0）の到達可能プレイ長集合を Λ(S) とし、
max Λ(S) < r とする。このとき標的化可能集合（連合が敗北を強制できる j の集合）は
可能敗者集合 { L mod r : L∈Λ(S) } に一致する。
*証明.* (⊆) j が標的化可能ならある合同戦略の実プレイが j の敗北で終わるので j は可能敗者。
(⊇) j ≡ L (mod r)、L∈Λ とし、長さ L を実現する合法プレイ π を取る。L < r より π の着手者は
P_0..P_{L−1} と互いに異なり、敗者となる P_j = P_L は π に一度も現れない。よって π の全着手は
連合（P_j 以外の全員）の着手であり、π を実行すれば対局はちょうど L 手で終局し、
手番は P_j に回るので j が敗れる。□ （下方位相性は不要。π は定義から S から合法。）

**定理B（短プレイ単独勝利）。** 同仮定の下（さらに安全位置がすべてルートから到達可能 —
禁止集合ゲームでは安全集合の下方位相性から成立）、P_j が最終着手者を単独強制できるのは、
j = min Λ − 1 であり、かつ min Λ − 1 石の全安全位置が1手で極大（終端）に達する場合に限る。
特にルートの単独強制勝利集合は r > max Λ のすべての r で同一（r 非依存）である。
*証明.* (⇒) j の強制プレイは長さ L、最終着手者添字は L−1 ≡ j (mod r)、L < r より L = j+1、
特に j+1 ∈ Λ。min Λ ≤ j なら、ターン 1..j の着手者 P_0..P_{j−1} はすべて連合側なので、
連合は最小極大（石数 min Λ ≤ j）を実現するプレイを先に打ち切り、j の手番が来る前に
最終着手者 P_{minΛ−1} ≠ P_j で終局させられる。よって j+1 = min Λ、すなわち j = minΛ−1。
さらに、minΛ−1 = j 石の安全位置 X で1手で極大に達さないものが存在すれば、連合は
下方位相性により X を j 手で実現し（着手順序は任意）、P_j の着手後も対局が続く。
以後の長さは L ≥ j+2、L ≤ maxΛ < r なので最終着手者添字は L−1 ≥ j+1 ≠ j となり
j は最終着手者になれない。したがって全 j 石安全位置が1手で極大に達する必要がある。
(⇐) 仮定の下、対局は minΛ = j+1 手より早く終われず、連合がターン 1..j で到達する
j 石安全位置はいずれも1手で極大に達するので、P_j は自分の唯一の手番（ターン j+1）で
終局させ、すべての自戦略整合プレイが長さ j+1 で P_j を最終着手者とする。□

**系（族の全 r≥2 特徴付けの完成）。** 2×m q=4 はすべての m で max ℓ(∅) ≤ 6 である
（m=1,2,3: C=2,3,4、m=4: Λ={4,5}、m=5..8: Λ={5,6}、m≥9: Λ={6} — m≥9 は K0069）。
よって **r ≥ 7 では族全体が短プレイ体制**であり、定理A・Bより:

- **標的化可能集合 = Λ mod r**（全 m≥1・全 r≥7）。r=7..16 の全 (m,r) で DP と一致
  （一様盤では {C mod r}、非一様盤では m=4: {4,5}・m=5..8: {5,6}）。
- **単独強制勝利**: 一様盤では定理Bの述語が常に真（任意の (C−1) 石安全位置は
  一様性より極大まであと1手）で P_{(C−1) mod r} — 凍結系と厳密一致。
  非一様盤 m=4..8 では述語が偽: 反例位置を audit に記録した（例: 2×4 の3石安全位置
  {(0,0),(0,1),(3,0)}、2×5 の4石安全位置 {(0,0),(1,0),(1,1),(2,0)}、
  2×6..2×8 の4石安全位置 {(0,0),(0,1),(1,0),(2,0)} — いずれもどの1手でも極大に達しない）。
  よって **m=4..8 のルート単独強制勝利は全 r≥7 で空**
  （定理Bによる全称帰結。r=7..16 の DP が有限照合、r=7,8 は既発表と一致）。
- **r≥4 則「標的化可能＝可能敗者∖単独強制勝利者」**は r≥7 では定理A+B から全称的に従う
  （勝者 j0 = minΛ−1 < minΛ は決して可能敗者でない）。r=4..6 は有限計算のまま。

以上により **2×m q=4 族（全 m≥1）のルート連合特徴付けは全プレイヤー数 r≥2 で完成**:
一様盤（m=1,2,3 と m≥9）は全 r で凍結（系F＋K0069）、非一様盤 m=4..8 は r=2 が古典、
r=3..6 が有限表（`output/audit.json`）、r≥7 が定理A・B。残る有限依存は
(m,r) ∈ {4..8}×{3..6} の15組のみで、いずれも完全計算済み。

検証構造（本拡張）: r=2..8 は既発表 audit と168照合（win・targ 各12盤×7r）で完全一致。
定理Bの述語は連合 DP と独立に位置グラフ上で直接評価し、r=7..16 の全 (m,r) で DP の
単独勝利集合と一致。Win⊆可能最終着手者・標的化⊆可能敗者は r=2..16 全件で機械検証。

## 敗者除外後の継続規則（2026-11-16 第4拡張）

K0339は規則を「最初に合法手を失った一人を敗者として終了」に固定し、「敗者を取り除いて
継続する規則」を明示的に未解決として残した。以下の2つの自然な継続規則を定式化する
（いずれも最初の排除までは K0339 と厳密に同一）:

- **CASC（カスケード）**: 詰んだプレイヤーを排除し盤面は変更しない。巡回順の次の
  残存者が着手を試みる。
- **REMO（石除去）**: 詰んだプレイヤーを排除し、**その所有石を盤から取り除いて**継続する
  （着手者=所有者として所有権を追跡する）。

**定理C（カスケード順位・全称）** 任意の有限下方閉配置ゲーム・任意の r≥2・任意の対局:
終端が極大安全位置 M（|M|=L）なら、CASC の排除順は P_{L mod r}, P_{(L+1) mod r}, …
（巡回順に連続）と完全に決まり、生存者（唯一の勝者）は **P_{(L−1) mod r}＝最終着手者**。
*証明* 終端位置は極大なので着手者は全員詰む。排除は着手不能者の巡回連続であり、
生存者は巡回順で敗者の一つ前＝最後の着手者。□

帰結: (i) 可能生存者集合＝可能最終着手者集合 {(a+ℓ−1) mod r}、連合 Win_j は
「j が単独生存を強制できる」ことと一致し、K0858 の表はそのまま勝者表になる。
(ii) 「最終着手者＝勝者」は規約ではなく CASC の帰結。(iii) 全順位の戦略非依存性は
L mod r の一意性、すなわち **r | Δ と同値**（K0339 の条件が敗者から全順位へ昇格）。

**定理D（一様盤の石除去完全決定性・全称）** 全極大安全集合が同サイズ C（Δ=0）なら、
REMO の全敗者列・生存者は (C, r) のみで決まり（幾何・戦略に非依存）、次の明示再帰で
計算できる: 各フェーズは盤を現在サイズから C まで満たす（フェーズ長 ℓ=C−s は強制、
一様性によりサイズ C の安全位置は常に極大で C 未満は常に拡張可能）、着手者は巡回順、
詰むのは (開始+ℓ) mod k、排除後にその石数だけ盤が減る。所有権は個数のみで再帰閉鎮。
2×m q=4 の一様盤（m=1,2,3,9..12 → C=2,3,4,6）は表の該当行を読むだけ。
*証明* 上記の通り、全ての量（盤サイズ・巡回順・手番・各プレイヤーの石数）が
履歴を通じてこの計数再帰の状態のみに依存し、幾何情報は入らない。帰納。□

**反例（r | Δ でも REMO は決定的でない）** 極大集合のサイズが {6,9}（Δ=3）の合成下方閉族
（A=6点、B=A∩部3点+別6点）で r=3: 第1敗者は常に P_0（K0339、3|3）だが、
6点集合で終わる対局の生存者は P_2、9点集合で終わる対局の生存者は P_1 で、
**生存者が戦略依存**。同じ族の CASC は決定的（生存者 P_2）。よって定理Dの Δ=0 仮定は
本質的であり、「第1敗者が固定でも順位は決まらない」。なお Δ=1 の実盤では r≥2 は常に
r ∤ Δ なのでそもそも第1敗者から非決定的（機械確認済み）。

**CASC と REMO は r≥3 で実際に異なる**: 例えば 2×3 q=4（C=4）r=3 では
CASC の生存者は P_0（最終着手者）、REMO の生存者は P_2。

検証構造（本拡張）: `verify_elimination_continuation.py`（自己完結・機械チェック336件・
全件合格・2回実行バイト同一）。REMO は所有権を追跡した全対局木の完全列挙
（メモ化DFS）による独立計算で、定理Dの計数再帰予測と 2×2/2×3/3×2/2×4/3×3・
r=2..6 で完全一致（一様盤は全て単一結果）。CASC は順位構造・可能敗者/可能最終着手者
との一致・決定性⟺r|Δ を9盤×r=2..6 で機械確認（Δ は既発表 audit の値を使用）。
合成反例は r=2,3 で全対局列挙により確認。r=2 では REMO≡CASC（機械確認済み）。
