# 三行二次形式係数版：全長を通じた例外係数の完全分類

2026-10-23。知識の正本は [K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。この実験は、既存の「無理数係数の真の安定化長15」を有理数の大部分へ拡張する**数学的な全称証明**と、その独立有限検算である。標準共円ゲーム（λ=1）とは別の変種。

## 定理（全mを通じた例外集合）

`D(3,m)={(x,y):0<=x<m, y∈{0,1,2}}`、`m>=2`。相異なる4点について
`det[x²+λy²,x,y,1]=A+Bλ` とする。一般型とは `A=B=0` で禁止される4点組だけからなる規則をいう。

**任意の実数 λ について、すべての m で一般型と同じ禁止4点組を持つことと、λ∉(1/2)Z は同値。**

さらに、λ=k/2（k∈Z）なら、`m>=|k|+2` で一般型にはない禁止4点組が必ず現れる。つまり「有限盤ごとに異なる例外有理数」を全盤長で合併すると、**ちょうど半整数全体**になる。一般型以外の追加禁止4点組の存在は、空盤勝敗が必ず異なるという意味ではない。

### 証明

四点が三つの高さ0,1,2を使い、かつ4点が相異なるなら、同じ高さに二点ある。その高さを `r`、二点の横座標を相異なる整数 `a,b` とし、残りの高さの横座標を `c,d` とする。

`B=det[y²,x,y,1]` は、三行すべてが現れる場合に `±2(a-b)` であり、従って0でない。二行以下なら、`y²` はその二行上で `y,1` の一次結合だから `B=0` である。

三行すべてを使う場合、4×4行列式を同じ高さの二行の差で展開すると、`A/(a-b)` も整数となる。より具体的に、点の順を `(a,r),(b,r),(c,s),(d,t)` とすれば、r=0,1,2について `A/(a-b)` は次の整数式（符号は点の並びに依存）で表される：

- r=0, s=1, t=2：`-ab+2(a+b)c-(a+b)d-2c²+d²`
- r=1, s=0, t=2：`-2ab+(a+b)(c+d)-c²-d²`
- r=2, s=0, t=1：`-ab-(a+b)c+2(a+b)d+c²-2d²`

ゆえに `B≠0` の四点が追加で禁止されるなら `λ=-A/B∈(1/2)Z`。これは全mに一様な必要条件。

逆に k≥0 なら
`(0,0),(k+1,0),(0,1),(1,2)`、
k<0 なら
`(0,0),(1-k,0),(1,1),(1,2)`
を選ぶ。いずれも `m>=|k|+2` で盤内にあり、直接行列式を計算すると `-A/B=k/2` かつ `B≠0`。したがって半整数はすべて、十分長い盤で本当に例外になる。□

### 既存の無理数係数定理への系

既存の [無理数係数・三行全長定理](../quadratic-pencil-generic-3xm-20261023/README.md) の証明は `A=B=0` という禁止族のみに依存する。よって **λ∉(1/2)Z の任意の実数**（有理数1/3なども含む）について、

```text
M_{3,λ}=15
m>=15: K=s=9, g(S)=(9-|S|) mod 2 for every safe S
m=14: 8-stone maximal witness exists
```

がそのまま成立する。ここでMは「以後のすべての長さで全極大配置が9石となる」真の最小開始長。

**λ∈(1/2)Z については、この系から安定化長・勝敗を推論しない。** 例外となる禁止組が存在しても、それだけでは別の終局構造を決定できない。

## 独立有限検算

`verify.py` は4×4置換展開によって `A,B` を計算し、m=2..8の**全四点組**で以下を検査する。

- `A=B=0` と一般型の「同一水平行4点／二行二点ずつで横座標和一致」の同値。
- `B≠0` の全例外値が分母1または2の有理数であること。
- 各盤長で `k=-(m-2),...,m-2` に対応する半整数が実際に現れること。
- `k=-20,...,20` の明示的な四点証人の直接行列式確認。

```sh
python3 research/experiments/quadratic-pencil-half-integer-universality-20261023/verify.py
```

実測した例外係数数はm=2..8で順に **1, 7, 17, 31, 53, 73, 110**。既存のm=3..7の有限完全分類に現れた例外係数数とも一致する。有限検算は証明の独立監査であり、無界性の根拠は上記の整数因子分解と明示的証人である。
