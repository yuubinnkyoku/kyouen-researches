# WIN8証明書からS6親行への二手応答被覆（4行・2026-11-20）

**K1096の証明書1本に加えて148本の追加証明が必要、という149根の幾何学的最小計画であり、S6行の閉鎖ではない。** K1096の8石root証明書が4つの6石親行を含むことは正しい。しかし「親行がrootのD4像から2石を除いた部分集合である」だけでは、その親行の勝敗は決まらない。

## 対象と上流正本

- `00000000000000003800000008001100`
- `00000000000000003800000008002080`

K1097の16 WIN8-D10候補のうち、この4行の二手応答候補集合に入るのは2根だけだった。

1. `00000000000000003800000008003180` — K1096で証明書・三重検証済み。
2. `0000000800000000380000000810000a` — K1095のWIN8-D10候補。K1097で親行 `...08001080` へのintrinsic余剰被覆が確認されたが、証明書は未抽出。

また、K1097の既知REFUTED-D10 50根のうち、4行の安全な8石拡張集合に入る根は `00000008000000003800000008100006` の1根だけだったため除外した。REFUTED-D10はLOSS証明ではない。

## なぜ「2石除去」だけでは親行を閉じられないか

8石root証明書は、そのrootで手番側が負けることを証明する。6石親行Pで先手Aが合法手xを打ち、後手Bがyを返してrootのD4像へ入れれば、rootで手番となるAが負ける。したがってPをこの方法でP局面と示すには、**Pからのすべての合法な初手x**について、何らかの証明済み8石root像へ入る返しyが必要になる。

K1096 rootのD4像に各親行を含めると、各行について該当像はちょうど1つ、欠けている点の組は1組だけだった。よって、この証明書が返せる初手は各行2手だけである。

| 親行 | 合法初手数 | K1096 rootで返せる初手 | 未被覆 |
|---|---:|---:|---:|
| `...08001080` | 79 | 2（bit 8, 13） | 77 |
| `...08001100` | 82 | 2（bit 7, 13） | 80 |
| `...08002080` | 69 | 2（bit 8, 12） | 67 |
| `...08002100` | 74 | 2（bit 7, 12） | 72 |

合法手集合は、4点行列式の24項整数展開と、3点からの余因子・軌跡判定という独立した2方式で全点一致した。欠けた2点のどちらを先に置いても、残る1点は合法である。ただし、それは各行の合法初手のうち2手を処理しただけであり、親行を閉じない。

## K1096だけを証明済み根とする最小計画（K1103独立第二検証）

4行の合法初手義務は合計304個。K1096 rootは8個を覆う。K1095 rootは2個を覆うが、WIN8-D10候補であって証明書ではないため、証明済み固定根には数えない。K1095の2義務も追加証明が必要な側へ移すと、残りは296義務になる。

K1097の既知REFUTED-D10根を除いた安全8石D4軌道は9,489根。K1096を除く9,488候補は、296義務に対して**すべてちょうど2個ずつ**を覆う。したがって追加根の下界は ceil(296/2)=148 本。

既存計画の147追加根にK1095候補rootを加えた148本は、296義務を重複なくちょうど一度ずつ覆う。下界と構成が一致するため、この4行・この二手応答方式に限れば、K1096を含む149根が最小である。

- 固定済み証明根: K1096の1本（既存三重検証済み）
- 追加で証明が必要な根: 148本
  - K1095のWIN8-D10候補: 1本（証明書未抽出）
  - safe8候補のみ: 147本（verdict・証明書なし）

元のplan JSONではK1095 rootが fixed_roots 配列に置かれているが、同ファイル内でも WIN8-D10-candidate-certificate-not-yet-extracted と明記されている。本項ではこのrootを証明済み根として扱わず、追加候補の1本として再分類した。総根数は変わらないが、証明状態と必要な作業本数が正確になる。

## 解釈上の制限

- K1096以外の148本は安全8石の**候補**であり、K1095はWIN8-D10候補、他147本はverdictなし。いずれも証明書ではない。
- K1095 root `...0810000a` は148追加根の1本として数える。WIN8-D10候補にとどまり、証明書抽出・独立検証が必要。
- K1096と148追加根すべてが独立検証済みWIN8証明書になり、応答戦略をfoldして初めて4行を閉じられる。この計画だけではS6行を1行も閉じない。
- これは4行に対する特定の二手応答方式の最小数であり、別の証明方法や深さを延ばした証明の下界ではない。147本を一括probeする作業は開始していない。
- 標準11×11空盤、二石root `{49,60}`・`{59,60}`、S2 `{59,60}`、class 1/2/4はすべてUNKNOWNのまま。
