従来の184個の10石LOSS葉は固定し、全606種類の11石LOSS同型類を候補として、これらを証明する過程で生じた2,672種類の残余ゲームと、既存ゲーム間の合法な応手遷移を再列挙した。混合整数計画では、184個の葉を必須、672個の10石WIN排除義務を被覆必須、LOSS節点は全合法子、WIN節点は少なくとも1個のLOSS子という条件で、使用する残余ゲーム節点数を最小化した。

HiGHSは**この固定候補集合の範囲で**1,877節点の最適性を報告（下界も1,877）。この最適性は整数計画器から独立した数学的証明ではない。また606同型類以外の証人、2,672種類以外の残余ゲーム、別の184葉の選択、異なる証明方式に対する大域最適性を意味しない。

## 独立検証

- `verify_joint_dag_optimized.py` はPython標準ライブラリのみで、1,877節点・5,097辺の厳密な残余ゲーム遷移、全LOSSの全合法子、WINの実際のLOSS子、根の整数幾何との同型写像、352個の11石証人による672義務の完全被覆、18個の8石LOSS根と184葉の最小性下界を再検証する。最適化器や保存済み勝敗表を信用しない。
- `verify_direct_roots.py` は別の盤面直接終局再帰で、184個の10石LOSSと193個の11石LOSS代表を全件再計算する。**377/377 LOSS、合計21,483メモ化状態**を確認。
- `mutation_tests_optimized.py` はLOSS辺欠落、勝敗反転、偽同型写像、証人削除を拒否する4負例を検査する。
