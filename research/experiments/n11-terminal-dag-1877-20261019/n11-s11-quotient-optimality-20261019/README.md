# 11×11：11石証人の終局ゲーム同型商による検証費用削減と厳密最小性

2026-10-19。標準 q=4、完全指摘、通常プレイ。**空盤勝敗は UNKNOWN**。新しい二石根は閉じていない。

## 確定した改善

既存の18個の8石LOSS根・387個の9石証明義務・184個の10石LOSS葉・672個の10石WIN排除義務は変更しない。従来は342個の異なる11石LOSS証人をそれぞれ終局まで計算し、メモ化状態数の加算費用が7,779だった。

各11石局面の合法な追加点を頂点、禁止される追加点集合（最小の2〜4点超辺）を制約とする有限ゲームを作る。**禁止超辺集合が頂点置換で一致するなら、残りのゲーム木も同型で勝敗が一致する。** この同型を、実際の点の番号に依存しない形で証明書にした。したがって、一つの代表局面を終局まで解けば、同型な他の証人は幾何学的な置換検査だけで済む。

## 5,805状態の厳密な下界

672個の10石義務の合法11石子はD4正準化後4,522局面で、終局勝敗はLOSS 982・WIN 3,540。全982個のLOSS候補の禁止超辺集合を同型類に分類すると **606類**になる。

- 全982候補の各類への所属を、実際の頂点置換を収めた証明書で検査する。
- 606代表が互いに非同型であることを、全代表に共通する厳密な色細分と、残った6頂点の1組に対する全置換列挙で検査する。
- 各類の費用は、その類に属する982候補のうち、保存済み終局再帰のメモ化状態数が最小の代表の費用とする。
- 672義務に非負の有理数双対重みを与える。各類が覆う義務の重み和は、その類の費用以下。**双対重みの合計は 11,609/2 = 5,804.5**。
- 類を選択する費用は整数なので、必要な費用は少なくとも **5,805**。実際に189類・349盤面で5,805を達成する。

したがって、**全982個の合法LOSS候補を対象とし、同型な残余ゲームを一度だけ終局再帰計算するという費用定義の下で、5,805は大域最小**。整数計画器の最適性報告は検証に不要。これは任意の実装・任意の証明形式に対する計算量下界ではない。また、従来の「盤面ごとに加算する費用」の最小値7,779と矛盾しない。
