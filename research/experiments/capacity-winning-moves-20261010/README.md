# 容量占有ゲーム：全容量余裕の勝ち手の完全分類

2026-10-10。基準 main: `ed75f33d9ccc1557df6143a59ec0994f46f28594`。

## 定理（全称数学的証明）

抽象容量ゲームを `1≤h<w, m≥1, 0≤r<hm` とする。降順占有数 `x=(x_1,...,x_w)`、`sum_{i≤h}x_i≤r` が安全条件。`n=w−h`、`b=x_h`、`R=nb−sum_{i>h}x_i`、`sigma=r−sum_{i≤h}x_i`。`x_i<b` の列への着手を **下位着手**、それ以外の合法着手を **上位着手** と呼ぶ。上位着手では上位h列の和が必ず1増え、下位着手では不変でRが1減る。

**(A) 下位着手の全称勝ち手判定：** 下位着手が存在する局面では、**その全てが Grundy 0 へ移ることと、親局面の Grundy 値がちょうど1であることは同値**である。親が2または3なら、下位着手の子はそれぞれ3または2である。親が0なら下位着手の子は1である。

**(B) 全合法手の分類：** 前回の全容量余裕署名定理（同梱の `capacity-all-slack-20261010/README.md`）の記号を使う。上位h列の降順形を `u`、上位着手で生じる相異なる形を `v∈U(u)` とする。偶数余裕の署名 `theta(v)∈{0,1}`、奇数余裕の署名 `single(a)` または `mixed` は同梱の全称証明で再帰的に定義されている。次の分類は物理的な**各列への着手**を対象とする。

1. `g(x)=0` なら勝ち手はない。
2. `g(x)=1` かつ `sigma` が奇数なら、**全ての合法手が勝ち手**。
3. `g(x)=1` かつ `sigma` が偶数なら、**全下位着手**と、行き先の上位形 `v` が `single` 署名である **全上位着手** が勝ち手。`mixed` 型の上位着手は勝ち手でない（余裕0では上位着手がない）。
4. `g(x)∈{2,3}` なら `sigma` は奇数で親の署名は `mixed`。下位着手に勝ち手はなく、上位着手の行き先 `v` が Grundy 0 となる必要十分条件は

   `((n*(v_h−b)+theta(v)) mod 2) = (R mod 2)`。

   この場合、**少なくとも一つの上位着手が勝ち手で、少なくとも一つが勝ち手でない**。

**(C) 盤上の実際の勝ち手点数：** 列iに `x_i` 個の石があるとき、区別可能な空き点は `m−x_i` 個である。各列への着手を上の分類で勝ち手と判定し、勝ち手の列iについて `m−x_i` を合計すれば、**勝ち手となる盤上の点の厳密な総数**が得られる。抽象ゲームの列着手数と実際の点着手数を混同しない。

## 証明

全容量余裕署名定理（同梱の `capacity-all-slack-20261010/README.md`）では、`R` が1減る下位着手について次の全称公式を証明した。

- 偶数余裕：`g(x)=(R+theta(u)) mod2`。
- 奇数余裕の `single(a)`：`g(x)=(R+a+1) mod2`。
- 奇数余裕の `mixed`：`g(x)=2+(R mod2)`。

下位着手は `u` と署名を変えず `R` を1減らす。前二者では親と子が0/1を反転する。後者では親と子が2/3を反転する。これで(A)が従う。

奇数余裕の上位子は偶数余裕なので、上位着手で `u→v` となる子の値は

`g(child)=(R+n*(v_h−b)+theta(v)) mod2`。

親の署名が `single(a)` なら全上位子の `n*(v_h−b)+theta(v)` の偶奇は同じ `a` であり、親が1なら上位子は全て0。下位子も(A)から0。親の署名が `mixed` なら上位子のこの偶奇は0と1の**両方**を実現し、上の等式がちょうど0となる型のみが勝ち手。`mixed` 親の値は2/3なので下位子は(A)から勝ち手でない。

偶数余裕が2以上の場合、上位子は奇数余裕。`mixed` 型上位子は2/3なので勝ち手でない。`single` 型上位子の値は `(R+beta) mod2` であり、**可換菱形補題**により全ての `single` 上位子の `beta` は一致する。少なくとも一つ `single` 子がある場合、親の値は `(R+beta+1) mod2` だから、親が1のとき全 `single` 上位子が0。`single` 子がない場合は親の値が `R mod2` であり、上位に勝ち手はない。下位子については(A)。余裕0では上位着手自体が不可能。これで(B)が尽きる。各列の未占有点は同じ子占有数を作るため、(C)も従う。□

## 独立検証

`check_winning_moves.py`：`3≤w≤8,2≤h<w,1≤m≤6,1≤r<hm` の安全な**降順**局面422,953件で、署名からの全列勝ち手分類と、全列を直接再帰した mex を照合。物理的な合法列着手2,628,542件のうち勝ち手1,208,834件、勝ち手となる盤上の点数の総和4,347,448件で不一致なし。

`check_lower_ordered.py`：署名を**一切使用せず**、ラベル付きの**非整列**全列に対して直接mexを計算。`3≤w≤6,2≤h<w,1≤m≤4,1≤r<hm` の安全局面388,006件、下位着手420,945件で(A)に不一致なし。2方式の実装と検査範囲が異なる。いずれも有限検証であり、無界の結論の根拠は上記数学的証明である。

幾何学的な盤への適用はK0352の一般位置平行列盤（`d≥3,q>2w`）など、**安全性が上位h列容量制約に一致する盤**に限る。標準の2次元共円盤全体には主張しない。
