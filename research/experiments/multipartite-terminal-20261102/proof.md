# 完全多部グラフ型 q 点共円ゲームの終局長母関数：部数無制限の多項式時間計数

2026-11-02。K0602 の任意グラフの整数平面実現・極大配置の削除集合公式を使用する。K0604 は完全二部グラフ、K0622 は小頂点被覆、K0623 は有界木幅を扱う。ここでは**部数が無制限の完全多部グラフ**を扱う。完全多部グラフの Node Kayles / Grundy 値に関する K0437 とはゲームの禁止超辺が異なる。

## 定理

任意の整数 k>=2、正整数 n_1,...,n_k、q>=4 を取り、G=K_{n_1,...,n_k}、n=Σ_i n_i、e=Σ_{i<j}n_i n_j、r=q−3、N=1+n+re とする。K0602 による整数平面 q 点共円・共線禁止盤の全極大配置の石数別母関数 P_G(u) は次の**有限閉式**で与えられる。

\[
\boxed{
P_G(u)=u^{N-1}+\sum_{j=1}^{k}u^{N-n+n_j}
+\sum_{\substack{0\le a_i\le n_i\\|\{i:a_i>0\}|\ge2}}
\left(\prod_i\binom{n_i}{a_i}\right)
 r^{E(a)}u^{N-n+A(a)-E(a)},
}
\]

ここで A(a)=Σ_i a_i、Q(a)=Σ_i a_i²、E(a)=Σ_{i<j}a_i a_j=(A(a)²−Q(a))/2。部数 k が増大しても、P_G(u) の全係数は **O(n⁴) 回の整数加算・乗算と冪の前計算**（多項式ビット長）で求められる。係数・指数を二進整数で保持した疎多項式として出力すれば、q の二進桁数についても多項式時間である。K0602 の一般グラフに対する多項式時間計数は主張しない。

### 証明1：許容残存集合の分類

K0602 の削除集合公式において、元グラフの残存頂点集合を R=V\X とする。各削除頂点は R に隣接する頂点を少なくとも1個持つ必要十分条件がある。完全多部グラフでは異なる部の頂点だけが隣接する。

各部 i の残存数を a_i とすると、R が**2部以上**にまたがる場合、削除頂点がどの部にあっても別の部の残存頂点がある。したがって無条件で許容される。

R が**ちょうど1部 j** にある場合、部 j 内の削除頂点には残存隣接点がないため、a_j=n_j が必要十分である。このとき残存辺は0本で、各 j につきちょうど1つの残存集合があり、重みは u^{N-(n-n_j)}。

R が空なら、非空グラフの全頂点が削除され、どの削除頂点にも残存隣接点がないので不許容。

2部以上に残存点を持つ場合、部 i の残存点の選び方は binom(n_i,a_i) 通り、残存辺数は E(a)、削除頂点数は n−A(a)。K0602 の極大配置の個数 r^{E(a)} と石数 N−(n−A(a))−E(a) を代入すると上の総和を得る。中心を含まない唯一の極大配置 u^{N−1} を加える。□

### 証明2：部数無制限の多項式時間算法

部を順に処理し、整数係数の表

\[
D_i(A,Q,s),\quad s\in\{0,1,2\}
\]

を保持する。A は処理済み部の残存点数、Q は残存点数の二乗和、s は残存点がある部の数を2で打ち切った値。初期値 D_0(0,0,0)=1。大きさ b の次の部について、各 0<=a<=b に対し

\[
D_{i+1}(A+a,Q+a^2,\min(2,s+\mathbf1_{a>0}))
\mathrel{+}=D_i(A,Q,s)\binom ba.
\]

処理終了後、s=2 の状態について E=(A²−Q)/2 を求め、係数 D_k(A,Q,2) r^E を指数 N−n+A−E に加える。さらに上の単一部の k 項と中心なしの1項を加える。

0<=A<=n、0<=Q<=Σ n_i²<=n²、s は3値なので表の大きさは O(n³)。部 i の選択肢は n_i+1 個で、Σ_i(n_i+1)=n+k<=2n。従って表の更新は O(n⁴) 回の整数演算。E は 0..e の整数であり、r^E は反復乗算で前計算できる。全係数は高々 2^n r^e+k+1、従ってビット長 O(n+e log(r+1))=O(n² log(q+1))。指数は高々 N で二進表示に O(log N) ビットを要するだけ。これで部数が n に比例しても多項式時間が成立する。□

## 系：q=4 の極大配置総数

r=1 と置くと全重みは1。全残存集合 2^n 個から、残存0部の1個と、残存1部だが部全体ではない Σ_i(2^{n_i}−2) 個を除く。中心を含まない1個を足すから、

\[
\boxed{P_G(1)=2^n-\sum_i2^{n_i}+2k.}
\]

k=2 では K0604 の 2^{a+b}−2^a−2^b+4 と一致する。全 n_i=1 なら K0602 の完全グラフの P_G(1)=2^n に一致する。一般の q に対しても閉式の k=2 は K0604、全 n_i=1 は K0602 の完全グラフ式に一致する。

## 非有界木幅・非有界頂点被覆の例

G_m=K_{m,m,m} は k=3 で m を増やすと頂点被覆数 2m、木幅 2m（完全多部グラフの木幅公式）でともに無界。K0622 と K0623 の固定パラメータ指数による保証だけでは m の多項式時間を得られないが、今回の算法は O(n⁴) の整数演算で計算できる。一般に k 自体が n とともに増大しても同様。
