# W_24 s=7 とドデカッド層のサンプル検証

## 目的

W_24 s=7 の Grundy 2/0 層がドデカッド（Golay 重み 12 語、2,576 個）の
9-/11-部分集合と一致するという仮説（K1346）のサンプル検証。

## 方法

- 759 オクタッドの F2 張から Golay コード（重み分布 {0:1, 8:759, 12:2576, 16:759, 24:1}）を再計算。
- ドデカッドの 9-部分集合 566,720 個、11-部分集合 30,912 個を列挙。
- 各カテゴリ 5 個をランダムに取り、完全 DP で Grundy を計算。

## 結果

| カテゴリ | サンプル数 | Grundy |
|---|---:|---|
| ドデカッド 9-部分集合 | 5 | すべて 2 |
| 非ドデカッド 9-キャップ | 5 | すべて 1 |
| ドデカッド 11-部分集合 | 5 | すべて 0 |
| 非ドデカッド 11-キャップ | 5 | すべて 2 |

- 個数: 566,720 = 2,576×C(12,9)（サイズ 9 の G=2 総数）、
  30,912 = 2,576×C(12,11)（サイズ 11 の G=0 総数）。

## 全数検証（fullcheck.c）

- 全 566,720 個の 9-部分集合を完全 DP で計算 → **すべて G=2**（他の値なし）。
- 全 30,912 個の 11-部分集合 → **すべて G=0**。
- 個数が K1342 の G=2（566,720）・G=0（30,912）と一致するので集合レベルで完全一致。

## 再現

`gcc -O2 -o fullcheck.exe fullcheck.c && ./fullcheck.exe ../../design-kyouen-witt-20261125/output/board_w24.txt`
