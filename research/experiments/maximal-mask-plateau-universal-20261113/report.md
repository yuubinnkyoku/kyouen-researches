# maximal mask 3,300 プラトーの全称化 — 全幅 w ∈ [99, 198)（proved・全称）

## 背景

maximal-mask-saturation-20261113 では w=62..132 の exhaustive-enumeration で
「maximal mask 数は w=66..132 の全測定点でちょうど 3,300・unique は w≥99 で 3,630 固定」
という有限確定事実を得たが、w>132 は「99 周期構造から w<198 まで維持が予想されるが
予想の域を出ない」だった。本実験はこの予想を**全称定理**に昇格させる。

## 定理（L=17・標準形掃引 harness と同一の窓マスク生成・全称）

**任意の幅 w（99 ≤ w < 198）に対し、窓マスク掃引の unique = 3,630・
maximal = 3,300 がちょうど成り立つ。**

## 証明

窓マスクは T(x,y) = {i < w : m9[x][i mod 9] ∧ m11[y][i mod 11]}（x∈[0,81)・y∈[0,121)・
m9/m11 は level 17 掃引 harness の (a,u) 全列挙マスク）で生成される。

1. **周期性**: cond(i) = m9[x][i mod 9] ∧ m11[y][i mod 11] は i について 99 周期
   （99 ≡ 0 mod 9・99 ≡ 0 mod 11）。全 (x,y)∈81×121・i<99 で機械確認
   （`periodicity99: true`）。
2. **パターンへの単射と順序同型**: w ≥ 99 のとき T(w) ∩ [0,99) = P
   （パターン集合）なので、相違なるパターンは相違なる T(w) を与える（単射）。
   さらに T1(w) ⊆ T2(w) ⟺ P1 ⊆ P2:
   （⇐）P1 ⊆ P2 が点ごとなら周期性から全 i < w で cond1 ≤ cond2。
   （⇒）T1(w) ⊆ T2(w) を [0,99) に制限。
   よって mask の包含半順序は w によらずパターンの点順序と同型。
3. **CRT**: |P| = c9·c11（c9 = |m9[x]|・c11 = |m11[y]|）。[0,99) では各
   (i mod 9, i mod 11) 対がちょうど 1 回現れるため。全 81×121 対で機械確認
   （不一致 0）。
4. **popcount ギャップ**: c9 ∈ {0,3,5,6}（81 マスクの完全列挙）・
   c11 ∈ {1,6,7}（121 マスク）→ |P| ∈ {0,3,5,6,18,21,30,35,36,42}。
   相違パターン 3,994 個のヒストグラムで [7,17] に空き（`gap7to17Empty: true`）。
5. **フィルタ同値**: 99 ≤ w < 198 で r = w−99 < 99 とすると
   |T(w)| = |P| + |P∩[0,r)| ≤ 2|P|。
   |P| ≥ 18 → |T(w)| ≥ 18 ≥ 17（通過）。|P| ≤ 6 → |T(w)| ≤ 12 < 17（不通過）。
   よって |T| ≥ 17 フィルタの通過集合は「|P| ≥ 18 のパターン」で
   w=99 と完全に一致する。
6. **結論**: 2・5 より mask poset は w=99 の poset と同型（フィルタ集合も同一）。
   w=99 の exhaustive 計算で unique=3,630・maximal=3,300 だから、
   全 w ∈ [99,198) で unique=3,630・maximal=3,300。∎

## 制御（機械的独立確認）

- 周期性・CRT・popcount ギャップの 3 検査 PASS（script 同梱・output 参照）。
- 同型論の再現として、w=99（制御・公表値と完全一致）と w∈[133,198) の代表点
  133/140/150/160/170/180/190/197 を直接 exhaustive 計算し、全て 3,630/3,300。
- **否定的制御（定理の限定が真であることの実証）**: k≥2 周期ではフィルタ同値が
  壊れる。w=296 では |P|=6 の小パターンが |T|=18 ≥ 17 に届いて新規参入する
  （`boundaryProbe_w296_smallPatternEnters: true`）。
  よって「全 w ≥ 99」への拡大は誤りで、定理は真に w ∈ [99,198) に限定される。

## 帰結（11×11 キャンペーンへの接続）

- level 17 掃引の mask ワークロード数は **w=66..197 の全範囲で一定 3,300**
  （66..98 は saturation 実験の有限測定・99..197 は本定理）。
  コスト増（~×1.35/w）は per-mask ノード加重のみ。
- 11×11 レーン（w ≤ 121）の掃引 harness ワークロードサイズは全域で一定。
- w ≥ 198 帯では小パターンの参入で unique が再増加する可能性があり、
  maximal 3,300 の維持は別問題（小パターンが c9=6 × c11∈{6,7} の
  点順序上位パターンの真部分集合なら非maximal のまま trivially 維持されるが、
  これは未検証のまま残す）。

## 限定

- L=17 に限る。他の L では |P| のフィルタ域とギャップの位置関係が変わる
  （未検証）。
- 標準整数格子の level 17 掃引 harness の窓マスク生成（mod 9×11・(a,u) 全列挙）
  に限る。
