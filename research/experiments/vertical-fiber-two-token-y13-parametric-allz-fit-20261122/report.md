## y=10/y=11/y=12 出版表との横断判定（有限範囲・全称ではない）

- **pin 格子統一式（本 fit の主眼・新規の横断式）**: pin offset o_pin = (d+3y)/2 ∈ [y+1, 2y]・o_pin ≡ z+1 (mod 2)。
  この単一式は y=10/y=11/y=12 の出版 pin 行集合（d 基準の mod 4 則と行範囲）をすべて正確に再現し、
  y=13 では 奇z 7 行・偶z 6 行を与える。pin 行数の族式も従属する（偶y: 両偶奇 y/2 行・奇y: 奇z (y+1)/2 行・偶z (y-1)/2 行）。
- **「pin スロット = th-1」型: y=11/y=12/y=13 の 3 族連続で確定**（K1152 が「y=13 fit での追完が横断型の判定材料」と
  指名した問いへの回答・fit レベル）。偶z 側は pin が base 行上端 2k-1 の +2 位置（2k+1）に載る slot 則が
  y=11/y=12/y=13 の 3 族で同一。
- tail 開始式 x+z+y+1: y=13 で一致（x+z+14・y=2..13 の 12 族連続の予想を支持）
- tail 値 (x+y) mod 2・値1無限帯の x 偶奇: y=13 は奇数 y 型（x 偶の行）で y=9/y=11 と同型
  （y 偶奇が行型を決める観察 13 族連続・y=13 は fit レベル）
- マージ命題 x<=z-(y+1): y=13 で一致（x<=z-14・probe 690 点＋回帰 17,277 比較）
- 基底点 y 点仮説 {z+1,..,z+2y-1}: y=13 で 13 点が一致（y=1..13 連続の 13 例目・fit レベル）
- 対角行上端格子規則 cap = z+y-[z≡y (mod 2)]: y=13 で全 probe z 一致（奇z z+12／偶z z+13）
- 定常 pin 2y+z／2y+z+1: y=13 で一致（z+26/z+27）
- 偶z 対角行の値1全欠如: y=8..12 に続き **6 族連続**（fit レベル）
- 最終 pin 行 d=y の I[2y+z+1) 型（奇z d=13: b13 ∪ I[z+27)・pin z+26 skip）: y=6/8/9/10/11/12 に続き **7 族連続候補**（fit レベル）
- band 下端 2y+2 = 28: 定常・掃引帯の偶 offset band 下端として出現（y=10: 22・y=11: 24・y=12: 26・y=13: 28）
- base 行 k(d)=floor((d+3y+1)/4): y=10/11/12/13 の **4 族で全 base 行**（z 偶奇・行型反転込み）同一族式。
  y=13 では奇z I 帯行も同式（y=11 と同じく奇z 全行単一式・飽和は d=12 でちょうど k=13 に到達し cap 不要）
- 偶z I 帯行 k(d)=floor((d+3y-1)/4): y=11/12/13 の **3 族で同一族式**（y=10 は floor((d+3y+3)/4) で異なる）
- 奇z I 帯行 th: y=11 は 2k+1・y=13 も 2k+1（y=10 は 2k・y=12 は ceil((d+3y+1)/2) の連続整数掃引）。
  **y 偶奇が th 則を決める観察**（偶y: y=10 は 2k・y=12 は連続掃引・奇y: 2k+1 の 3 番目の例）
- 初稿一発一致（y=11 も同様・y=12 は 240 点修正・y=10 は手順外）: 奇数 y 族はテンプレート外挿が
  過剰修正なく Y+2 に伸びるという工芸的観察
