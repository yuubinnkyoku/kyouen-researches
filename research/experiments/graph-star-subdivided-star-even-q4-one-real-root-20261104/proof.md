# 一辺細分星：偶数 k・q=4 の実根数の完全決定（2026-11-04）

## 位置づけ
`graph-star-subdivided-star-exact-real-roots-20261104/proof.md` では偶数 k>=4・r>=2 の実根がちょうど1個であることが証明済みで、r=1 (q=4) は未分類だった。ここでこの残りを全称証明する。対象は K0648 由来のグラフ型構成であり、標準格子盤ではない。

## 定理（全称証明）
任意の偶数整数 k>=4 に対し、
```
T_{k,1}(u)=u^{k+1}+3u^k+2^k u+2^{k+1}
```
は負の実根をちょうど1個持ち、その根は単根である。残りの k 個の根は非実根（重複度込み）。

したがって既存の r>=2 の証明と合わせ、**全偶数 k>=4・全整数 r=q-3>=1** で T_{k,r} の実根はちょうど1個となる。

## 証明
x>0 とおく。k が偶数なので
```
P(x)=T_{k,1}(-x)=x^k(3-x)+2^k(2-x).
```
0<x<=2 では両項が非負で第一項が正なので P(x)>0。

2<x<3 では
```
P'(x)=x^{k-1}(3k-(k+1)x)-2^k.
```
P''(x)=k x^{k-2}(3(k-1)-(k+1)x).
```
k>=4 の場合 P'' は区間 (2,3) で符号を高々一度しか変えないが、この事実は不要である。代わりに、P(x)=0 を
```
(x/2)^k=(x-2)/(3-x)
```
と書き、根の個数を単調性だけで判定する方法にも注意が必要である（両辺とも増加する）。

確実な方法は x>=2 における一次因子との比較である。x=2 で P(2)=2^k>0、x=3 で P(3)=-2^k<0。一方、2<x<3 の正の根について
```
P(x)=0 \iff k\log(x/2)+\log(3-x)-\log(x-2)=0.
```
この関数の二階微分だけでは直接単調性が得られないため、次の導関数の形を使う：
```
P'(x)=x^{k-1}(3k-(k+1)x)-2^k.
```
x>=3k/(k+1) では P'<0。2<x<3k/(k+1) では
```
P(x)=x^k(3-x)-2^k(x-2),
```
第一項は x=3k/(k+1) まで増加するが、正値を保つとは限らない。そこで直接、x<=3k/(k+1) なら
```
x^k(3-x) >= 2^k(3-2)=2^k
```
が成り立つ：x^k(3-x) は [2,3k/(k+1)] で増加し、左端で2^k。さらに x-2<1 より P(x)>0。

したがって P は (2,3k/(k+1)] で正、[3k/(k+1),3] で厳密減少し、端点の符号が正・負だから (3k/(k+1),3) にただ1個の単根を持つ。x>=3 では両項が非正で第二項が負だから P<0。正の u では T の全係数が正で根がない。証明終。

## 独立検算
SymPy の `count_roots(P,0,oo)` と `count_roots(P,2,3)` により k=4,6,8,10,20 の各例でともに1個を確認。これは有限標本検算であり全称証明の代替ではない。

## 境界
奇数 k・r>=2 の小さい k の実根数は未分類のまま。本証明は偶数 k に限定する。
