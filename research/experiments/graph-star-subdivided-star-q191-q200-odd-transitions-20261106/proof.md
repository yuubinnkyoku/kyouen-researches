## 証明・依存関係

q=181〜190の先行証明の解析補題を用いる。\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とすると、負根の条件は \(F_k(y)=r-y-(a-y)y^k=0\) であり、候補は \(1<y<a\) に限られる。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大となる。

非存在境界 \(k_-\) で \(H_{k_-}(y_*)<r-a\) を確認し、存在境界 \(k_+=k_-+2\) で \(H_{k_+}(y_*)>r-y_*\) を確認する。後者と \(F_k(1),F_k(a)>0\) から2根が存在し、デカルトの符号法則からちょうど2つの単根となる。正根はない。\(1<y<a\) で \(H_k(y)\) はkに関して厳密増加するため、全奇数次数へ拡張できる。

\(A=k(r+2), B=(k+1)(r+1)\) とおき、\(B<A\) とともに次の整数不等式を検証した。

- 非存在：\((r^2-2)(k+1)B^k>(r+2)A^k\)
- 存在：\((rB-A)(r+1)(k+1)B^k<(r+2)A^k B\)

## 再現コード（JavaScript BigInt、厳密整数演算）

```js
const rows = [
  [191,2675],[192,2691],[193,2707],[194,2723],[195,2739],
  [196,2755],[197,2773],[198,2789],[199,2805],[200,2821],
];
for (const [q, km] of rows) {
  const r = BigInt(q-3);
  for (const k of [km, km+2]) {
    const K = BigInt(k), A = K*(r+2n), B = (K+1n)*(r+1n);
    if (!(B < A)) throw Error("interval " + q);
    if (k === km) {
      if (!((r*r-2n)*(K+1n)*B**K > (r+2n)*A**K)) throw Error("absence " + q);
    } else {
      if (!((r*B-A)*(r+1n)*(K+1n)*B**K < (r+2n)*A**K*B)) throw Error("existence " + q);
    }
  }
  console.log(q, "PASS");
}
```
