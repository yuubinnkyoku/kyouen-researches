# 3×7 二次形式係数版：全実数 λ の厳密分類（2026-10-23）

盤は `(x,y)∈{0,…,6}×{0,1,2}`、禁止四点組は
`det[x²+λy²,x,y,1]=0`（退化を含む）で定義する。
**通常の円のみを禁止する規則とは異なる**。現在の知識の正本は
[K0518](../../knowledge/items/K0518-quadratic-form-small-board-parameter-classification.md)。

## 有限帰着の数学的証明

相異なる四点に対する行列式は整数 `A,B` を用いて `A+Bλ` と書ける。
`B=0` の組の禁止性は全実数で一定、`B≠0` の組は有理数
`−A/B` でのみ禁止性が変わる。全 `C(21,4)=5985` 組を
整数演算で調べると相異なる例外係数は **73個**。
従って一般型（それら73値以外の**すべての実数**）と例外73型の
合計74型を完全列挙すれば、無理数も含めて全実数を分類できる。
有限帰着は全称的な数学的証明、各型の値は有限完全列挙である。

## 空盤の完全分類

```text
g(∅)=2: λ∈{-9,-8,-5/2,-3/2,1}
g(∅)=1: λ∈{-7,-6,-4,-3,-2,-1,0,2,3,5}
g(∅)=0: それ以外のすべての実数
```

従って **後手必勝は15個の有理数例外値を除く全実数**で成立する。
標準の共円ゲーム `λ=1` は `g(∅)=2`、勝ち初手は
点番号 `3x+y` で `{1,4,6,7,8,10,12,13,14,16,19}`（11点）。

全74型で最大安全石数は `λ=0` のみ8、それ以外は9。
最小極大安全石数は係数によって3〜7で変化する。
一般型では `g(∅)=0`、安全局面85,784、禁止四点組246、
極大局面の石数別個数は7石894・8石4,866・9石414。

## 独立検証と再現

`classify.cpp` は二つの異なる方式で全74型の全安全局面を比較する。

1. 3×3差分行列式による `A,B` と、全部分集合の下からの mex 動的計画。
2. 独立した4×4置換行列式による禁止組生成と、合法手を逐次判定する上からの再帰。

両方式で、空盤値・全安全局面数・禁止組数・勝ち初手・安全局面の
石数別分布・極大局面の石数別分布・Grundy分布がすべて一致した。
**74型合計5,378,055安全局面**をそれぞれ二方式で検査した。
一般型の代表値 `1000003` は例外集合に含まれないことも検査する。

```sh
g++ -O3 -std=c++17 classify.cpp -o /tmp/quad_3x7
/tmp/quad_3x7 7 > /tmp/quad_3x7.tsv
```

`results.csv` は全74型の空盤値、安全局面数、禁止組数、
勝ち初手数、最大安全石数、最小極大石数を保存する。
詳細な石数別分布と勝ち初手の点番号は上記コマンドで再生成できる。
全出力TSVのSHA-256:
`3576fad046a93633ae38162ff54b110c440bd19d15c94f6471760dc21640c7e4`。

**限界**：3×7固定盤についての厳密分類であり、3×mの全長定理ではない。
