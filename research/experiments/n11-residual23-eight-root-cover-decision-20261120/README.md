# 残余23行の8根被覆厳密判定: UNSAT、P‴上の最小被覆数は9（2026-11-20）

単一オーナー宣言: [research/log/2026-11-20-n11-residual23-eight-root-cover-decision-single-owner-note.md](../../../research/log/2026-11-20-n11-residual23-eight-root-cover-decision-single-owner-note.md)（commit `cb31752551`・先行出版）

## 判定

問い: REFUTED-D10 50根を除外した候補pool P‴（120,424根）から8根を選び、
残余23行をすべて被覆できるか。

判定: **不可能（UNSAT）**。P‴上の23行被覆の最小根数は **9**。
下界強化監査の interval \([8,9]\) は \([9,9]\) へ崩壊した。
上界はgreedy 9根計画（K1097・K1102で同一選定）が既に到達しているため、
9は最小確定である。greedy 9根の代替掃引計画（両AND順序18 probes）は
**候補根数においてP‴上で最小**になっている。

## 数え上げ証明書（手計算検証可能）

3行はP‴上に3行providerを1本も持たない:

- `00000000000000003800000008002010`
- `0000000000000000380000000a080000`
- `00000000020000801202000000100000`

これらの行に触れるproviderは2行以下しか被覆できない（3行被覆なら3行providerになるため）。
8根のうちこの3行に触れる根をk本とすると、

1. 3行を2行以下で被覆するには \(k \ge \lceil 3/2 \rceil = 2\) 本必要。
2. k本は残余23行の被覆枠 \(2k\) のうち3枠をこの3行に使うので、
   残る \(23-3=20\) 行の被覆は \(2k - 3 + 3(8-k) = 21 - k\) 枠が上限。
   \(k=2\) で最大19 < 20 で、\(k\) が増えるほどさらに悪化する。

よって **k ≥ 2 かつ \(21-k \ge 20\)（k ≤ 1）の両立は不可能**であり、
8根被覆は算術的に排除される。判定機はこれを
`eight-impossible-counting-certificate` ゲート
（\(k_{min}=2 > k_{max}=3\cdot 8-23=1\)）として固定した。

## 探索による機械的確認

数え上げ証明書に加えて、ILP縮約で予告された2形の完全探索も行った。

- Shape B（7 triple + 1 pair、重複なしの23行exact分割）:
  2行provider 4,857根は重複を除くと **100個のpair pattern**（監査上界は253）。
  各patternの補集合21行を3行providerは **60 pattern** から離散exactly coverで構成しようと試みた。
- Shape A（8 triple、ちょうど1行重複）: 重複行dを挟む2 tripleの対は
  全dについて **351組**（\(t_1 \cap t_2 = \{d\}\)）。残る18行を6 disjoint tripleで構成しようと試みた。

どちらも不成立、探索は極めて浅い（exact cover呼び出し451回・メモ211エントリ）。
これは数え上げ証明書の3行が、すべての18/21行残り去掉で即座に候補枯渇させるためである。

独立第二実装（新規幾何・メモなし・行選択と候補順が逆順の別探索コード）も
同じ列挙空間（pair pattern 100・d-対351）でUNSATを再現した。
出力JSONの当該統計は3回実行（同一cwd 2回+別cwd/別HOME 1回）でバイト同一。

## 解釈規約

本判定は候補root計画の被覆簿記であり、証明書ではない。証明書抽出・receipt foldは
本計算に含まれない。行は1行も閉じていない。REFUTED-D10はLOSS証明ではなく、
nodes数・solved数を勝敗として読まない。
監査下界8は任意の宇宙で有効なまま（本結果はP‴に特有）。

**標準11×11空盤・二石root {49,60}/{59,60}・S2 {59,60}・class 1/2/4はすべてUNKNOWNのまま。**
