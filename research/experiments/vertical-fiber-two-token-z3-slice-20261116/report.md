# 2トークン残余ゲームの高さ \(z=3\) スライス：全Grundy値の閉形式

- 日付: 2026-11-16
- 対象: K0832 の \(\kappa=1\) 残余ゲーム \(H(R;X;z)\)、\(X=(x,y)\)、\(x\ge y\ge1\)、\(z=3\)
- status: **全称定理**。全称性の根拠は \(R\) に関する強帰納法。有限監査は独立な再帰照合であり、証明の代用ではない。
- 位置づけ: 既証明の \(z=0,1,2\) に続く第4の完全スライス。2トークン族の全 \(z\) 予想について、未証明領域を \(z\ge4\) に縮める。

## 主定理

\[
S=x+y,\qquad d=x-y
\]
と置く。

値2の位置集合を
\[
T_3(x,y)=
\begin{cases}
\{1\},&(x,y)=(1,1),\\
\{1,3,S\},&d=3,\\
\{1,3,2y+3,2y+5,2y+7\},&d=4,\\
\{1,3,2y+3\},&d\ge5,\\
\{1,3\},&d\in\{0,1,2\}\text{ かつ }(x,y)\ne(1,1).
\end{cases}
\]

値1の位置集合を \(P_3=P_{\rm low}\cup P_{\rm high}\) とする。ただし
\[
P_{\rm low}=\{R\in2\mathbb Z:4\le R\le\min(S,2y+2)\}
\]
であり、
\[
P_{\rm high}=
\begin{cases}
\{R:R\ge S+1\},&d\in\{1,3\},\\
\{R:R\text{ は奇数},\ R\ge2y+5\}\cup\{R:R\ge S+4\},
 &d\ge5\text{ が奇数},\\
\{R:R\text{ は奇数},\ 2y+5\le R\le S+3\},
 &d\ge6\text{ が偶数},\\
\varnothing,&d\in\{0,2,4\}.
\end{cases}
\]

**定理.** 任意の \(x\ge y\ge1\)、\(R\ge0\) について
\[
\boxed{
H(R;(x,y);3)=
\begin{cases}
2,&R\in T_3(x,y),\\
1,&R\in P_3(x,y),\\
0,&\text{それ以外}.
\end{cases}}
\]

対角線 \((1,1)\) を除けば値2位置は奇数だけに現れる。特に \(d=4\) では \(2y+3,2y+5,2y+7\) の3点が並ぶ。これは \(z=0,1,2\) にはなかった形である。

### 具体例

| \((x,y)\) | 値2となる \(R\) | 値1となる \(R\) |
|---|---|---|
| (10,10) | 1, 3 | 偶数 4〜20 |
| (13,10) | 1, 3, 23 | 偶数 4〜22、および24以上 |
| (14,10) | 1, 3, 23, 25, 27 | 偶数 4〜22 |
| (15,10) | 1, 3, 23 | 偶数 4〜22、奇数25以上、および29以上 |
| (16,10) | 1, 3, 23 | 偶数 4〜22、奇数25〜29 |

\(d=5\) では奇数列が伸び、\(d=6\) では \(S+3\) で止まる。

## 再帰と既知定理

- A手: \(t\ge2\) のトークンを \(t-1\) にする。
- B手: トークン1を取り除き、\(z\) を1増やす。
- C手: \(z\ge1\) のとき \(z\) を1減らし、子のGrundy値を1と XOR する。

各手で \(R\) は1減り、親の値は子の値集合の mex である。既証明の Theorem T（K0832）より
\[
H(R;X;z)\le2,\qquad R\text{ が偶数なら }H(R;X;z)\le1.
\]

## 証明

\(R\) に関する強帰納法を用い、右辺を \(F_3(x,y,R)\) と書く。A子には帰納仮説 \(F_3\)、C子には既証明の \(z=2\) 全Grundy閉形式を使う。\(y=1\) のB子は単一トークン \((x)\)・高さ \(z=4\) なので、既証明の単一トークン閉形式を使う。\(x=y=1\) でもB手の後にはもう一つのトークン1が残り、B子は空状態ではない。

### 小さい残容量

直接代入した選択肢値集合 \(\mathcal V_R\) は
\[
\begin{array}{c|c|c}
R&\mathcal V_R&H(R;(x,y);3)\\ \hline
0&\text{着手なし}&0\\
1&\{0,1\}&2\\
2&\{2,3\}&0\\
3&\{1\}\ ((x,y)=(1,1)),\ \{0,1\}\ (\text{それ以外})&
0\ ((1,1)),\ 2\ (\text{それ以外})\\
4&\{1,3\}\ ((x,y)=(1,1)),\ \{0,2\}\ (\text{それ以外})&
0\ ((1,1)),\ 1\ (\text{それ以外})
\end{array}
\]

### 奇数 \(R\ge5\)

子の残容量 \(R-1\) は偶数なので、Theorem T により全ての子の値は0または1。従って \(\mathcal V_R\subseteq\{0,1\}\) であり、集合が \(\{0,1\},\{0\},\{1\}\) のとき親の mex はそれぞれ2,1,0となる。

A/B/C子の閉形式を代入した選択肢表は次の通り。

| \(d\) | 奇数 \(R\ge5\) の範囲 | \(\mathcal V_R\) |
|---:|---|---|
| 0 | 全て | \(\{1\}\) |
| 1 | \(R\le S\) / \(R\ge S+2\) | \(\{1\}\) / \(\{0\}\) |
| 2 | 全て | \(\{1\}\) |
| 3 | \(R\le S-2\) / \(R=S\) / \(R\ge S+2\) | \(\{1\}\) / \(\{0,1\}\) / \(\{0\}\) |
| 4 | \(R\le2y+1\) / \(R\in\{2y+3,2y+5,2y+7\}\) / \(R\ge2y+9\) | \(\{1\}\) / \(\{0,1\}\) / \(\{1\}\) |
| \(d\ge5\) 奇数 | \(R\le2y+1\) / \(R=2y+3\) / \(R\ge2y+5\) | \(\{1\}\) / \(\{0,1\}\) / \(\{0\}\) |
| \(d\ge6\) 偶数 | \(R\le2y+1\) / \(R=2y+3\) / \(2y+5\le R\le S+3\) / \(R\ge S+5\) | \(\{1\}\) / \(\{0,1\}\) / \(\{0\}\) / \(\{1\}\) |

\(\{0,1\}\) の行が \(T_3\setminus\{1\}\)、\(\{0\}\) の行が奇数側の \(P_3\)、\(\{1\}\) の行が値0の位置を与える。\(R=3\) の対角線最小例外は小さい残容量の表で処理済みである。

### 偶数 \(R\ge6\)

親自身が Theorem T により高々1なので、
\[
H(R;(x,y);3)=1\iff 0\in\mathcal V_R.
\]
同じ代入から得られる判定表は次の通り。

| \(d\) | \(0\in\mathcal V_R\) となる条件（偶数 \(R\ge6\)） |
|---:|---|
| 0 | \(R\le S\) |
| 1 | 常に成立 |
| 2 | \(R\le S\) |
| 3 | 常に成立 |
| 4 | \(R\le2y+2\) |
| \(d\ge5\) 奇数 | \(R\le2y+2\) または \(R\ge S+4\) |
| \(d\ge6\) 偶数 | \(R\le2y+2\) |

\(R=2,4\) は直接処理済み。偶数側の表を奇数側の表と合わせると、値1の位置はちょうど \(P_{\rm low}\cup P_{\rm high}\) となる。全ての \(R\) で候補式が再帰の mex に一致したので、強帰納法により定理が成立する。∎

## 限界と次の課題

- 証明対象は抽象残余ゲーム \(H(R;X;z)\) の2トークン族 \(X=(x,y)\)、高さ \(z=3\) のみ。
- \(z\ge4\) の2トークン全Grundy閉形式、および全高さをまとめた3族の値2位置予想は未証明。
- 標準二次元の共円ゲームの勝敗、固定幅安定化長、3トークン族の全分類は主張しない。
- 次の候補は \(z=4\)。今回の \(d=4\) の3点ランが、次の高さで延長・分裂・消滅のどれになるかを先に調べる。
