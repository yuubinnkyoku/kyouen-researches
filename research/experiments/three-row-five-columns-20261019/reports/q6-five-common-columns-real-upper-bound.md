# 3本の水平行・共通5列・6点円の完全計数式と最大4本定理

検証基準: `main` `9abcfcb2115bb189b87d36c529920e5939e879aa`（2026-10-19 JST時点）。

## 定理（全称、実数座標）

相異なる実数 `x0<x1<x2<x3<x4` と正実数 `a,b` に対し、15点

`P={(xi,0),(xi,a),(xi,a+b) : i=0,...,4}`

を考える。**相異なる6点を通る円の本数**を `C(P)` とする（円上に余分な点がある場合も円は1本と数える）。このとき

1. `C(P) <= 4`。
2. `C(P)=4` であるための必要十分条件は、ある `d>0` に対し `xi=x0+i*d` かつ `a=b=d` であること。
3. `a != b` なら `C(P)<=3`。`x0,...,x4` が等差数列でなければ `C(P)<=3`。
4. 次の有限式で **任意の実数座標の `C(P)` を正確に計算**できる。

各和 `s` について、`xi+xj=s (i<j)` を満たす対を集める。2対存在する `s` のみを考え、それらの積 `xi*xj` の差の絶対値を `D_s>0` とする。このとき

`C(P) = sum_{s:2 pairs} ( [D_s=a*b] + [D_s=a*(a+b)] + [D_s=b*(a+b)] )`。

`[条件]` は条件が真なら1、偽なら0。複数条件が一致する場合は重複して数える（別々の円になる）。

この定理は、各行の横座標が**同じ5点集合**であることを仮定する。行ごとに異なる横座標を許す一般化には適用しない。

## 証明

**(1) 円の水平断面。** 円は水平線と高々2点で交わるため、15点中の6点を通る円は3行の各行からちょうど2点ずつ通る。円の方程式を `x²+y²-Sx+By+C=0` と書くと、同じ行上の2つの `x` 座標は、和が `S`、積が `P(y)=y²+By+C` である。したがって各行で選ばれた点対の和は同じ `S`。

**(2) 1つの和で可能な円。** 5個の相異なる横座標に対し、同じ和をもつ点対は互いに素である。よって高々2対。1対だけなら3行で積がすべて同じになるが、3つの異なる `y` に対し `y²+By+C` が同じ値になることはない。2対の場合、その積を `L<H`、`D=H-L` とする。各行の積 `P0,P1,P2` は `L` または `H`。二次式の二階差分より

`(P2-P1)/b - (P1-P0)/a = a+b > 0`。

可能な8種類の `(P0,P1,P2)` のうち、この等式を満たしうるのは `(H,L,H)`（`D=ab`）、`(H,L,L)`（`D=a(a+b)`）、`(L,L,H)`（`D=b(a+b)`）だけ。これらは各々一意の円を実際に定める。計数式が従う。`a != b` なら3つの正数 `ab,a(a+b),b(a+b)` は互いに異なるので、1つの和から高々1本。`a=b=t` なら2本が生じるのは `D=2t²`、1本が生じるのは `D=t²` の場合だけ。

**(3) 重複する和の個数。** `gi=x(i+1)-xi>0 (i=0,1,2,3)` とする。4つの昇順の数の2点和一致は、外側2数の和と内側2数の和が等しい場合に限る。5点のうち省く点の番号 `j` で、対応する条件を `Rj` と書くと

- `R0: g3=g1`
- `R1: g3=g0+g1`
- `R2: g3=g0`
- `R3: g2+g3=g0`
- `R4: g2=g0`

である。`R1,R2,R3` は互いに両立せず、`R0,R1` および `R4,R3` も両立しない。よって重複和は高々3個。3個あるときは `R0,R2,R4` の組だけで、`g0=g1=g2=g3=d`、すなわち5点は等差数列。

**(4) 等差数列でない場合。** 重複和は高々2個である。さらに2個ある場合、**その2つの積差 `D` は相異なる**。実際、両立可能な組と、`p,q>0` を用いたギャップ・積差は以下の全5通り。

| 条件の組 | `(g0,g1,g2,g3)` | 対応する積差 |
|---|---|---|
| `R0,R4` | `(p,q,p,q)` | `q(p+q)`, `p(p+q)` |
| `R0,R2` | `(p,p,q,p)` | `p(p+q)`, `p(2p+q)` |
| `R0,R3` | `(p+q,p,q,p)` | `p(p+q)`, `(p+q)(2p+q)` |
| `R4,R1` | `(p,q,p,p+q)` | `p(p+q)`, `(p+q)(2p+q)` |
| `R4,R2` | `(p,q,p,p)` | `p(p+q)`, `p(2p+q)` |

1行目の積差が等しいのは `p=q`、すなわち等差数列のときだけ。残り4行は正の `p,q` に対し厳密に異なる。`a!=b` なら各重複和から高々1本、`a=b` なら積差が異なるので2本生じる和は高々1個。したがって非等差の場合 `C<=3`。

**(5) 等差数列の場合。** 共通差を `d>0` とすると、3つの重複和の積差は順に `2d²,3d²,2d²`。`a!=b` なら各重複和から高々1本なので `C<=3`。`a=b=t` なら各和から2本生じる条件は `D=2t²`、1本生じる条件は `D=t²`。`2d²` と `3d²` は異なり、比は `2:3` であるため、両方が同時に `{t²,2t²}` に入ることはない。よって最大は外側2和から各2本の合計4本であり、これは `2d²=2t²`、すなわち `t=d` のときに限る。実際この場合は4本存在する。証明終。

## 具体例

- 4本（上界達成）: `x=(0,1,2,3,4), (y0,y1,y2)=(0,1,2)`。和3・5に対応する各2本。
- 3本（行間隔非等間隔）: `x=(0,1,2,3,4), (y0,y1,y2)=(0,1,3)`。和3・4・5に各1本。
- 3本（横座標非等差、実数行間隔）: `x=(0,1,3,4,6), (y0,y1,y2)=(0,sqrt(3),2sqrt(3))`。重複和4・7の積差は3・6で、後者から2本、前者から1本。

## 独立検証と範囲

`verify_three_rows_five_columns.py` は和・積差の計数式で検査する。`verify_three_rows_five_columns.cpp` はその計数式を使わず、全ての「各行から2点」の組合せに対し、3点から決まる円の整数係数方程式に残り3点を代入して判定する。

両方式とも、横座標を `{0,...,10}` の5点部分集合（462通り）、行間隔 `a,b` をそれぞれ1〜7の整数（49通り）とする合計 **22,638配置**を検査した。出現本数別配置数は `0:20439, 1:1848, 2:321, 3:20, 4:10` で完全一致。4本の10配置はすべて定理の等差条件を満たす。

検証範囲は有限整数座標だが、**定理の根拠は上記の任意実数に対する証明**である。行ごとに横座標を独立に変える場合は依然として未解決。
