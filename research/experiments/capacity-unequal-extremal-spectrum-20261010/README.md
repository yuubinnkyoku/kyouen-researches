# 異容量・上位 h 列ゲーム：終局石数の幅・欠番数・種類数の鋭い一様上界

2026-10-10。**全称数学的証明**。`verify.py` の有限完全列挙は独立監査であり、無限個の容量を網羅した証明ではない。

## 対象と結論

`w>=1`, `1<=h<=w`, `r>=0`, `M>=0` は整数。ラベル付き `w` 列の容量 `0<=c_i<=M` は不均一でよい。占有数 `0<=x_i<=c_i` に対して、大きい順に並べた上位 `h` 成分の和が `r` 以下なら安全。合法手は一列の占有数を1増やすこと。`E(c)` を、空局面から到達できる全極大配置の**石数の集合**とする（空からの到達可能性は安全性の下方閉性による）。

```
Delta = max(0, min(M, floor(r/h)) - max(0, r-(h-1)*M))
n = w-h
```

容量 `c` を全ての `0<=c_i<=M` に動かしたとき、次の最大値は**それぞれ厳密に**

```
max_c (max E(c)-min E(c))                     = n * Delta
max_c (max E(c)-min E(c)+1-|E(c)|)           = max(0,n-1) * Delta
max_c |E(c)|                                  = 1 + (Delta if n>0 else 0)
```

となる。左辺第2式は、最小終局石数から最大終局石数までの**欠番の個数**。3つの上界は**同一の容量ベクトル `c=(M,...,M)` で同時に達成**される。`h=1`, `h=w`, `r>=h*M`, `M=0` などの退化場合も含む。

均一容量 `c=(M,...,M)` に対し、`h*M>r` なら

```
L0=max(0,r-(h-1)*M),  U0=min(M,floor(r/h))
E(c)={r+(w-h)*b : L0<=b<=U0, b integer}.
```

`h*M<=r` なら `E(c)={w*M}`。これにより上の等号が全て成立する。

**容量上限を設けない場合の系**：`2<=h<w`、`k=floor(r/h)` なら

```
max_c span = (w-h)*k
max_c holes = (w-h-1)*k
max_c number_of_sizes = k+1.
```

例えば `c=(r+1,k,...,k)` が3つの最大値を同時達成する。`h=1` または `h=w` の場合は終局石数が常に一種類だけである。

## 全称証明

容量を降順に並べて `c_1>=...>=c_w` としてよい。`sum_{i=1}^h c_i<=r` なら全容量占有だけが極大で、石数は一意である。

それ以外では極大配置 `x` の上位 `h` 占有数の和はちょうど `r`。もし `r` 未満なら、満杯でない列を一つ増やしても安全であり、極大性に反する。`b` を `x` の第 `h` 大成分とする。`x_i<b` の列は、まだ空きがあれば1増やしても上位和は変わらないので、必ず満杯である。従って各列は `min(c_i,b)` 以上占有され、`b` を超える列は高々 `h-1` 本である。余剰を `d_i=max(x_i-b,0)` とすれば

```
x_i=min(c_i,b)+d_i,
0<=d_i<=max(c_i-b,0), #{i:d_i>0}<=h-1,
sum_i d_i=r-h*b.
```

逆にこの形の局面は上位和が `r` であり、`b` より少ない占有の列は全て満杯、残りの列への追加は上位和を増やすため極大である。存在する `b` の範囲は厳密に

```
L=max(0,r-sum_{i=1}^{h-1}c_i) <= b <= U=min(c_h,floor(r/h)).
```

必要性は上位 `h-1` 列の容量と上位和から従う。十分性は `c_1,...,c_{h-1}>=b` および `sum_{i<h}(c_i-b)>=r-h*b` から、余剰を先頭 `h-1` 列へ貪欲に配ればよい。したがって、各 `b` の極大石数は

```
T(b)=r-h*b+sum_{i=1}^w min(c_i,b),
E(c)={T(b):L<=b<=U}.
```

隣接差は `D_b=T(b+1)-T(b)=#{i:c_i>=b+1}-h`。`b<U` なら `c_h>=b+1` なので `0<=D_b<=w-h=n`。容量上限 `M` から `L>=L0`, `U<=U0` であり、`U-L<=Delta`。よって

```
span(E)=sum_{b=L}^{U-1}D_b <= n*Delta,
holes(E)=sum_{b=L}^{U-1}max(0,D_b-1) <= max(0,n-1)*Delta,
|E|<=1+(U-L) <=1+Delta.
```

`n=0` の場合は全ての `D_b=0` なので `|E|=1`。`n>0` なら `|E|<=1+Delta`。

`c_i=M` を全列で選べば `L=L0`, `U=U0` かつ全 `b<U` で `D_b=n` となるため、各不等式が等号になる。`h*M<=r` の場合は全容量ベクトルが安全なので全ての幅と欠番は0、種類数1であり、定義した `Delta=0` と一致する。以上で証明が完了する。□

**無上限系の達成**：`2<=h<w` で `k=floor(r/h)` とし `c=(r+1,k,...,k)` を選ぶ。`L=0`, `U=k`, `D_b=w-h` が全 `b<k` で成り立つ。一般上界では `Delta<=floor(r/h)=k` として `M` を十分大きく取ればよい。□

## 独立有限監査

`verify.py` は上記 `T(b)` を一切使用せず、全占有ベクトルを直接列挙し、安全性と各列への追加可能性から極大石数集合を求める。`w=1..5`, `M=0..4`, `h=1..w`, `r=0..h*M+2` の全575組で、全ての非減少容量ベクトル22,246件を検査した。各組で均一容量が3最大値を同時達成し、その他の容量がいずれも超えないことを照合した。独立検証は有限範囲のみに関する事実であり、上の全称性は証明に基づく。

実行：`python research/experiments/capacity-unequal-extremal-spectrum-20261010/verify.py`。
