を**ラベル閉包法**で全称証明する。K0902の証明スケッチが残していた

## 主張

以下、計数ゲームはK0859のREMO規則・K0861定理E′の軌道簡約ゲーム
（k枝・原子は枝部分集合のマスクで添字づけ・枝iのstarは枝iを含む
原子群・枝容量 C_i = star内総容量）、**正準領域**とはすべての単一
原子が非空（e_j = atoms[2^{j−1}−1] ≥ 1）で C_i ≥ 1 のことであり、
committed列（K0893/K0895/K0897/K0898/K0902のcap≤10・15,863
プロファイル）はすべて正準である。M = max C_i。

**定理J（本項で証明・正準領域）**: k ≥ 1任意・r ≥ 2人のとき、

- **(i)** 生存者集合 sv と決定性フラグ det は、すべての
  r ≥ max(M,2) で**一定**。
- **(ii)** 第1敗者集合は fl(r) = {C_i mod r}（補題FL・K0864と同じ
  値をL4で根において直接再導出）。ゆえに r > M では C_i < r なので
  fl は**一定値 {C_i}**。
- **(iii)** 可能生存者ラベルはすべて ≤ M−1（σ ≤ M−1）。

**定理J-広域版（C_i ≥ 1のみ・単一原子は空を許す）**: (i) と (iii)
は修正なしで成立する（証明L1〜L4は単一原子の非空性を一切使わ
ない）。(ii) は次の精緻化形になる:

- **(ii′)** fl(r) = {c mod r : c ∈ E}。ここに **E = 第1飽和可能な
  枝容量の集合**（空盤からあるプレイが第1イベントで飽和させる枝
  容量の全体。盤面のみで決まる r 非依存の集合で E ⊆ {C_i}、
  正準領域では E = {C_i}）。ゆえに r > M でも fl = E で一定。

(ii) の {C_i mod r} 形は広い領域では**偽**であることに注意:
反例 atoms = (0,0,0,0,1,1,0)（k=3・sizes (1,1,2)・e_1 = e_2 = e_3 =
0）では、合法な初手は s13 か s23 のみで、どちらも置いた瞬間に
枝1または枝2（容量1）が飽和して深さ1のイベントになる。枝3
（C_3 = 2）は決して第1飽和枝になれないので E = {1} ⊊ {1,1,2} で
fl ≠ {C_i mod r}。検証器J9の特別電池がこの証人を自動検出した

ステップは excl_Y（枝Y専用原子）への初手を用い、e_Y ≥ 1 が必要
であるのと同じ境界である。K0864・K0902の主張はcommitted列と
同じ正準領域の内部なので影響を受けない。

定理E′（K0861）により、プロファイルを実現するすべての実盤に
そのまま転写される。証明はkに一切依存しない。

**系1（cap≤10 rレーンの無条件閉包）**: K0902が「定理Jが正しけれ

## 定義と記号

K0859/K0861系の計数ゲームの記法に従う。k枝に対し原子は枝部分集合
のマスク m ∈ {1, ..., 2^k−1} で添字づけられ、atoms[m−1] = その
原子の容量。枝iの **star** star[i] = 枝iを含む原子の集合（容量
C_i = Σ_{m ∋ i} atoms[m−1]）。状態は (counts, mover, active):
counts[m][p] = 原子m上のプレイヤーP_pの石数、mover = 手番者、
active = 現役プレイヤー集合。プレイヤーP_pは自分の手番に**合法原子**
（まだ容量が余り、かつ全石をstar内に含む枝が存在する原子）へ1石を
置く。置いた盤面が **maximal**（ある枝i: 全石 ⊆ star[i] かつ
star[i]内の総石数 = C_i）なら**イベント**: 敗者 = mover（その石を
全て除去・activeから除外）、残り1人なら生存者確定、さもなくば
next_active(敗者) が手番者として再帰（**カスケード**: 除去後も
maximal なら直ちに次の敗者を確定し続ける）。置いても maximalで
なく合法手が存在しない**行き詰まり**プレイは結果に寄与しない。

sv(root) = 生存可能ラベル集合、det = |sv| = 1、fl(root) = 第1敗者
（最初のイベントの敗者）ラベル集合。正準領域では各枝に専用原子
e_i ≥ 1 がある（K0862以来のcheck_profile領域）。

## 証明

以下、r ≥ max(M,2) を固定する。M ≥ 2 なら r ≥ M、M = 1 なら
r ≥ 2 > M であり、いずれでも C_i ≤ M ≤ max(M,2) ≤ r。記号 C_Y は
プレイが第1イベントで飽和させた枝Yの容量、t は総石数。

### L1（phase-1 の r 非依存性）

合法手の判定（容量・「全石を含むstarを持つ枝」）と maximal 判定は
**盤面のみ**の関数で、ラベルにも r にも依存しない。よって空盤から
のプレイ（原子列）の木のうち、**第1イベントまで**の部分は r に
よらず同一である。

**イベント深さの同定**。イベントが起こるのは maximal 到達時であり、
maximal は「全石 ⊆ star[Y] かつ総石数 t = C_Y」を強制する。イベント
までに除去は一度も起こらないので t は置石数に等しく単調増加する。
ゆえに:

1. 第1イベントの深さは t = C_Y ≤ M ≤ r。イベントプレイの着手者は
   P_0, ..., P_{C_Y−1} の **相異なる** プレイヤー（C_Y ≤ r なので
   wrapなし）、各自が1石を置く。深さが M を超えたプレイは二度と
   イベントに到達しない（t = C_Y ≤ M が不可能）。
2. イベント時の mover は P_{C_Y mod r}。C_Y < r なら P_{C_Y}
   （r非依存）。C_Y = r のときは P_0 だが、これは
   C_Y = r ≥ max(M,2) ≥ M ≥ C_Y より **r = C_Y = M** のときのみ
   （境界ケース・L2で吸収する）。
3. 行き詰まりプレイはいかなる結果も寄与しない。寄与するのは
   イベントプレイのみで、その深さは ≤ M ≤ r。

### L2（ファントム吸収カスケードと post-event 状態の r 非依存性）

イベント盤面（プレイ p・深さ C_Y）を見る。石はラベル 0..C_Y−1 に
**ちょうど1個ずつ**（L1・1）、ラベル C_Y..r−1 は **0石**（以下
**ファントム**）と呼ぶ。カスケードの規則を素直に追う:

**(a) ファントム接頭辞**。maximal 盤面で敗者 loser の石を除去した
後も盤面が maximal ならカスケードは継続し、次の敗者は
next_active(loser, r, active)。第1イベント直後の active は全員
なので next_active は単に次のラベルを返す。ファントムの敗者は
**除去しても盤面が変わらない**（0石）。盤面は maximal のまま
だから継続条件が成立し、カスケードは P_{C_Y}, P_{C_Y+1}, ...,
P_{r−1} を例外なく喰い進める（**ファントム吸収**）。この間に
停止判定（|active| = 1）が先に成立するのは C_Y = 1 のときのみ:
P_{r−1} 除去後に active = {P_0} となり生存者 P_0（任意の
r ≥ 2 で同一）。

**(b) 境界ケース r = C_Y（= M）**。このとき最初の敗者は P_0 で、
ファントム接頭辞は空。以下の議論は「石持ち敗者の列」の共通部分で
両ケースを同時に扱う。

**(c) wrap後の同一性**。ファントムを喰い尽くすとカスケードは
ラベル 0 に wrapし、石持ち P_0, P_1, ... を順に検討する。石持ちの
石を実際に除去した後に maximal が壊れるか、|active| = 1 になる
かで停止する。ここで重要なのは:

- **盤面の推移は r 非依存**（石持ち除去の列は両ケースで同一の
  0, 1, 2, ...。ファントム接頭辞は盤面を一切変えない）。
- **|active| の推移も r 非依存**: r = M + d のときファントムは
  d = r − C_Y 個で、石持ち j 個を除去した時点の |active| は
  C_Y − j。境界ケースでも M − j = C_Y − j。一致する。

ゆえに停止する場所（どの石持ちで maximal が壊れるか/終端するか、
そのときの盤面・active・mover）は play のみで決まり r に依存
しない。post-cascade 結果は各プレイについて:

- ('term', σ): 終端生存者。σ < C_Y（a の終端は σ = 0、wrap後の
  終端も active ⊆ {0..C_Y−1} 内）。
- ('state', counts, mover, active): counts の石はラベル
  < C_Y のみ、active ⊆ {0..C_Y−1}、mover < C_Y。

**いずれも r ≥ max(M,2) で同一**（正規化した結果はラベル < C_Y の
中だけで書かれている）。なお停止は必ず石持ち除去の直後に起こる:
ファントム除去は盤面を変えないので maximal が持続し、カスケード
が石持ちに到達する前に止まることはない。これがLC2である。

**補題C1′（剛体形・正準領域）**。すべての単一原子が非空
（e_j := atoms[2^{j−1}−1] ≥ 1）なら、停止位置はさらに強く特定
できる: **カスケードは必ず（ファントム接頭辞の後の）P_0 で停止
する**。P_0 の石（y ≥ 1個・すべて star[Y] 内）を除くと、
star Y の総石数は C_Y − y < C_Y で飽和せず、他の枝 j ≠ Y は
「石がすべて star Y 内」だから star j 上の石は共有原子
star j ∩ star Y にのみ載り、その総容量は C_j − e_j ≤ C_j − 1
< C_j で飽和できない。よって post-cascade 状態は剛体形:

- C_Y = 1 → 終端生存者 P_0（ファントム吸収の後）
- C_Y = 2 → 終端生存者 P_1（P_0 除去後 active = {P_1}）
- C_Y ≥ 3 → 状態 (各ラベル 1..C_Y−1 に1石、active = {1..C_Y−1}、
  mover = P_1)

この容量不等式は e_j ≥ 1 が本質的である。**C1′ は広い領域
（単一原子が空を許す）では偽**: 反例 atoms = (0,1,1,1,0,0,1)
（k=3・sizes (2,3,2)・e_1 = 0）でプレイ (e2, s12, s123) を
r ≥ 3 でプレイすると、第1イベント（枝2・C_Y = 3）で敗者 P_0 の
石を除いた後に**枝1が飽和**（e_1 = 0 ゆえ共有容量 C_1 − e_1 = C_1）
してカスケードが P_0 を喰い越す。検証器J9の特別電池（単一原子が
空のプロファイルを含む259個）が剛体形違反91プレイを分離し、
正準電池（cap≤5全域346プロファイル・9,684プレイ）では違反0で
あることを確認した。**定理Jの証明にはC1′を必要としない**
（L2の弱い形で十分）。

### L3（ラベル閉包・post-event 部分ゲームの r 非依存性）

L2の post-cascade 状態 s（a = C_Y ≤ M）から到達可能な状態の
不変条件「active ⊆ {0..a−1}、mover < a、石は active 内ラベル
のみ」を示す:

- 置石は mover ∈ active のみ行い、石は自分のラベルに載る。
- イベントは active を縮小するだけ。
- next_active(p, r, active): p+1, p+2, ... (mod r) を走査し
  最初の active ラベルを返すが、ラベル a..r−1 は不活性なので
  すべて飛ばされる。**{0..a−1} の巡回順で p の次の active を
  返すことは r ≥ a ならば r に依らない**。

遷移規則（合法性・maximal・除去・next_active）がすべて
r 非依存になったので、状態からゲーム値（sv 集合）を返す再帰は
**そのまま r 非依存**。再帰の終末性: イベントは |active| を厳密に
減らし、イベント間の置石回数は全原子容量で抑えられる（除去は
イベント時にしか起きない）ので、プレイの長さは有限で状態DAGは
well-founded。帰納の底（|active| = 1 → 生存者、合法手なし非maximal
→ 値 ∅）も r 非依存。ゆえに s の値は r ≥ max(M,2) で一定。

### L4（接着・fl の再導出と成立域）

- **sv(root)** = イベントプレイごとの post-cascade 結果（終端生存者
  または部分ゲーム値）の和集合。行き詰まりプレイは寄与しない
  （L1・3）。イベントプレイの集合・post-cascade 結果・部分ゲーム値
  がすべて r 非依存なので、sv(root) は r ≥ max(M,2) で一定。det も
  同様。これが (i)。
- **fl(root)** = イベントプレイごとの第1敗者 {C_Y mod r} の和集合。
  ここで C_Y は第1飽和枝の容量なので、和集合は**第1飽和可能な容量
  集合 E** を用いて fl(r) = {c mod r : c ∈ E} と書ける（E は盤面
  のみで決まる r 非依存の集合・E ⊆ {C_i}）。これが (ii′)。
- **正準領域で E = {C_i}**: 各枝Yについて、star Y のみを埋める
  プレイ（各置石は合法: 石は常に star Y 内で包含が保たれ、
  C_Y ≥ 1 で埋め切れる）を考えると、**他の枝 j が先に飽和する
  ことはできない**: j の飽和は「全石 ⊆ star j かつ star j 総石数
  = C_j」を要求するが、このプレイの石は star j ∩ star Y（共有
  原子）にのみ載り、その star j 内総容量は C_j − e_j < C_j
  （e_j ≥ 1）。あるいは K0864と同様に、専用原子 e_Y ≥ 1 への初手は
  以後どのプレイでも枝 j ≠ Y を maximal にできない（初手の石は
  star j に入らず除去されない）。どちらの議論も e_j ≥ 1 が本質的。
  したがって正準領域では fl(r) = {C_i mod r} で、r > M では
  C_i < r で wrap がなく fl = {C_i} に一定。これが (ii)。
- **生存者ラベル**: 終端 σ < C_Y ≤ M、部分ゲームの生存者 ∈
  active ⊆ {0..C_Y−1}。いずれも ≤ M−1。これが (iii)。

証明終わり。証明は k に一切依存しない（k ≥ 1 任意・枝数は
star/容量の構造のみに現れる）。(i) と (iii) の証明は単一原子の
非空性を一切使わないので広域版でもそのまま成立する。J7a（k=2・
サイズ ≤ 6 正準全域56プロファイル）・J7b（k=4電池22プロファイル）・
J9特別電池（k=2/k=3/k=4・広域259プロファイルでsv/det r不変と
σ ≤ M−1 を直接検証）がこの任意 k 性を live 検証している。

## K0902スケッチとの関係

K0902の証明スケッチはプレイライン分解（star[Y] 内の再飽和サイク
ル・共有原子経由の脱出・脱出後の帰納）を軸にしており、その未完点
(a)(b)(c) はすべて「脱出後も同型の議論を帰納的に重ねる」箇所に
集約されていた。ラベル閉包法はこの経路を取らない: 第1イベント
**1個**のカスケードの構造を同定（L2）した後は、残りの全プレイを
「ラベル < C_Y の閉じた部分ゲーム」（L3）として一括し、ラベル集合
の r 非依存性から値の r 非依存性を得る。脱出・再飽和・所有権の
複雑さはすべて部分ゲームの内部に畳み込まれ、外に出てこない。
またスケッチの「第一飽和は敗者index=C_Y で r 非依存」は境界ケース
r = C_Y = M（敗者 P_0）を見逃していた。本証明ではファントム吸収
がこの境界を吸収する（L2・b/c）。

イベント深さ・L2のpost-cascade正規化状態）を独立実装のシミュ
レータで検証する。検証器は head＋K0902機構ブロック（verbatim・

した上で実行し、監査JSONも二重serializeでbyte同一・二重実行で
出力byte同一を確認している。

## 限界

- 定理は**ラベル**（det・sv・fl）のみを対象とする。状態数・順位・
  消滅順序の r 不変性は主張しない（SGガード・消滅順序は r で変わる）。
- 定理J(ii)の {C_i mod r} 形と補題FLは**正準領域**（単一原子非空）
  に限る。広い領域では精緻化形 (ii′)（E集合）が正しい。E を
  {C_i} から特徴づける条件（e_j ≥ 1 で十分）の必要性の完全決定は
  今後の課題（e_j ≥ 1 なしでも E = {C_i} となるプロファイルは
  ある: 特別電池中にも E = {C_i} のものが多数ある）。
- r < max(M,2) の挙動は定理の範囲外で、一般に変化する（系4）。
- サイズ11/12 × r=9..13は電池（J8・N ≤ 17）でしか有限検証して
  いないが、定理自体はこれらを全称的に覆う（系3の4スイープが
  有限確定の残作業）。
- 11×11空盤・二石root・クラスフロンティアは本項と無関係でUNKNOWN
  のまま。
