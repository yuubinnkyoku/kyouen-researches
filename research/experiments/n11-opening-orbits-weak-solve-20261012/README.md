# 11×11空盤の初手D4分類と限定応手probe（2026-10-12）

## 対象と結果

盤面indexは `cell=11*y+x`、中心は60。独立整数幾何で121初手をD4の21軌道へ分割した。K0414の二石root `{60,27}` LOSS、2手の順序不変性、D4対称性から、初手60と `{27,57,63,93}` の2軌道（5マス）がLOSS。残る19軌道・116マスは未確定である。これは空盤面の弱解決ではない。

中央60が非中央の全初手に合法な後手応手であることを、独立Boardで120/120確認した。既知LOSS軌道では応手60が使えるが、他の初手に対する `{first,60}` の勝敗は調べた境界値だけから決めず、中央応手が勝つとも仮定しない。

## 応手探索と初手WIN証明の境界

後手の一つの応手で初手をLOSSとするには、その二石rootがLOSSであることを示せばよい。既知の `{60,27}` では、119個の第三手それぞれに一つのS4 LOSS応手を割り当てる。独立幾何で13,742本の第四手edge、3,384個のcanonical S4 class、367,228本のcanonical S5境界edge、121,088個の異なるS5子を再生成した。S5 exact cacheの境界hitは5,613件（WIN159 / LOSS5,454）。これは一つの二石応手rootを閉じる規模の実測値である。

特定の初手を先手WINと証明する場合は、120通りの後手応手すべてを閉じなければならない。初手の安定化群による応手軌道数は、probeした中心60で20、軸・対角の49/48で各65、一般位置25で120、隅0で65。各代表応手に対して先手の第三手候補と全第四手を列挙し、第四手後のS4全てに少なくとも一つのexact S5 WIN子が見つかる第三手を探した。既存exact S5 cacheのWIN159件は549個のcanonical S4親を覆うが、5初手probeのどの応手軌道にも全S4境界を覆う第三手はなかった。従って既存cacheだけでは初手WIN証明を閉じられず、これは初手LOSSの証明にもならない。

この限定probeで、安定化群で割った全応手軌道の代表ごとに調べた第四手edge数は、中心60で276,868、49で901,084、48で900,406、25で1,664,832、隅0で905,122。これらは有限幾何列挙であってsolver探索node数ではない。S4の勝ち子確認にはsolver-trusted exact S5行を利用し、未ヒットをUNKNOWNのまま残した。初手WINには全120応手を対象にした戦略証明が必要で、特定のLOSS応手を探す仕事よりAND境界が広い。どちらも残り19軌道への一括巨大探索はまだ行わない。

## 再現と信頼範囲

```powershell
uv run --locked python research/experiments/n11-opening-orbits-weak-solve-20261012/scripts/analyze_openings.py
```

`output/opening-analysis.json` は21軌道の全マス、5 probeの代表応手boundary、既存cache coverage、入力SHA-256を保存する。`scripts/analyze_openings.py` はroot proofとS5 cacheを読み、独立 `Board` からD4 orbit、合法手、S3→S4境界、S4→S5親子関係を再生成する。solverは起動しない。exact statusの信頼境界はK0414どおりであり、未分類初手の結論へ拡張しない。
