# 5個の相異なる4点禁止集合：全有限頂点数でのGrundy最大値

2026-10-19。通常プレイの抽象的な有限回避ゲーム。幾何的な共円・共線配置への実現は主張しない。

## 結論（有限完全列挙による全称的な計算機援用証明）

互いに異なる4点集合が**ちょうど5個**あり、それらをすべて占有する手は禁止する。禁止集合に属する頂点の和集合を `U`、残りの自由頂点数を `f` とする。

- 自由点を除いたゲームの空局面Grundy値は **6以下**。値6になるのは `|U|=12` かつ、同型を除いて**ちょうど2種類**の禁止集合族だけ。
- 自由点を含めた任意の有限ゲームの空局面Grundy値は **7以下**。値7になる必要十分条件は、上の2種類のいずれかの12頂点核を持ち、`f` が奇数であること。
- **値7を実現する最小頂点数は13**。自由点を認めない場合、値6の最小頂点数は12。とくに10・11頂点の自由点なし最大値はそれぞれ4・5。
- 以前の「5個の4点禁止集合で12頂点g=6」の存在下界を、全有限頂点数の鋭い上界と完全な達成型分類へ拡張する。

`n=|U|` ごとの全結果。計数は5個の辺に番号を付け、頂点を「5辺への所属型」ごとの個数だけで同一視したもの。同型類数ではない。

4頂点の所属型は1個あるが、相異なる5個の4点辺を作れないため最大値は未定義。全 `n=12` で `g=6` となる所属型は240個、辺番号の置換群 `S_5` で割ると120個ずつの**2軌道**である。

## なぜ無限の頂点数を有限完全列挙できるか

5辺を `E_0,...,E_4` と番号付けする。各 `v∈U` の所属型 `t(v)∈{1,...,31}` を、`v∈E_i` であるビット `i` が1となる整数で定義する。同じ型の頂点の個数を `a_t≥0` とすると

```
for i=0..4: sum(a_t for t=1..31 if t & (1<<i)) == 4
```

を満たす。逆に、この31変数の非負整数解はすべて、頂点の付け替えを除いた5本の番号付き4点辺族を一意に定める。総所属数は20なので `|U|≤20`。重複辺がある解だけ除外する。したがってこの有限列挙は任意の有限頂点数を**漏れなく**覆う。

各辺連結成分の通常プレイGrundy値を、全安全部分集合のmex再帰で厳密に求め、成分間でxor合成する。2つの独立実装は、占有集合の降順動的計画法と、未占有集合の昇順動的計画法という異なる向きで全469,368構造の値別分布まで完全一致した。別のPython係数計算でも、5辺重複の除去に分割束のメビウス反転

`D_5(n)=A_5(n)-10A_4(n)+35A_3(n)-50A_2(n)+24A_1(n)`

を使い、507,549 / 469,368という件数を独立照合した。`A_k(n)` は `k` 本の番号付き4点辺について、重複を許す所属型個数解の数である。

自由点は独立した1手成分なので、`g(total)=g(U) xor (f mod 2)`。核の最大値6と達成型の完全分類から値7の必要十分条件と最小13頂点が従う。

## 達成型と独立した局面検証

12頂点で `g=6` の2軌道の代表は、各辺を頂点番号のビット集合で記して

- `[1066,1091,2188,240,3840]`：初手後の値 `[3,5,3,1,4,5,1,2,0,0,2,1]`、安全部分集合3,078。
- `[2241,3082,204,240,3840]`：初手後の値 `[5,1,2,1,2,2,4,4,3,3,0,0]`、安全部分集合3,141。

どちらも子に0,1,2,3,4,5が存在し、`mex=6`。第一代表に辺へ属さない頂点12を追加すると、13頂点の子の値は `[2,4,2,0,5,4,0,3,1,1,3,0,6]`、`mex=7`。
