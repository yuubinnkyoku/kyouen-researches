# k=7 の `a = |W ∩ C|` による完全な分解

2026-11-20。`finite-field-kyouen-20261120` の第154部。

前項で「90配置」という障壁に当たった。本項は**別の角度**から
`a = |W ∩ C|` による分解を完成させ、三重カウントを閉じる。

## 1. 定理：`a = 2` ⟺ 場合 B

**定理**：`a = |W ∩ C| = 2` であることと、3つの対合が共通対を持つ
（場合 B）ことは同値。

**証明**：対合は「ペンシルの**2割線**」を記録する。すなわち
「`C` と2点で交わる円」である。`W` は `x,y,z` の3点を通るので、
`W` が3つのペンシルすべてに属するのは `a = 2` のとき、かつそのときに限る。
よって共通対は `W ∩ C` であり、`a = 2` ⟺ 場合 B。 □

**注意**：`w = |T ∩ W|` は別の量である。対合は「`C` と2点で交わる円」を
記録するのであって「`T` と2点で交わる円」ではない。
（前項でこの区別を混同して「場合 A = 点集合として素」と誤解した。）

## 2. 検証（q=5）

| `a` | 場合 | 三つ組 |
|---:|---|---:|
| 0 | A のみ | 600 |
| 1 | A のみ | 240 |
| 2 | **B のみ** | 300 |
| | | **1,140** |

**`a` が場合を完全に決定する。**

## 3. 三重カウントの閉形式（定理）

円 `W` の個数を `a` で分類すると（k=7 の `w` 解析で既に証明済み）

```
a=2: C(s,2)·q
a=1: s·(q−1)
a=0: b − 1 − C(s,2)·q − s·(q−1)
```

`W` 上の三つ組は `W \ C` の3点部分集合なので `C(s−a, 3)` 個。よって

```
三つ組(a) = 円(a) × C(s−a, 3)
```

**検証**：

| q | 円 a=2 | 円 a=1 | 円 a=0 | 三つ組 a=2 | a=1 | a=0 | 合計 | `C(n−s,3)` |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 5 | 75 | 24 | 30 | 300 | 240 | 600 | **1,140** | 1,140 ✓ |
| 7 | 196 | 48 | 105 | 3,920 | 1,680 | 5,880 | **11,480** | 11,480 ✓ |

**両方で完全一致。**

## 4. これで何が閉じたか

- **三つ組の総数**：`a` 別に閉形式で書ける（上記）。
- **場合の判定**：`a` で決まる（定理）。
- **`w` の周辺分布**：既に閉形式（第146部）。

**残るのは「`a` ごとの `(w,u)` 分布」**、すなわち
「`a` を固定したときに `T` がどう分布するか」。

## 5. `a` ごとの型（q=5）

| `a` | 型の数 | 分布 |
|---:|---:|---|
| 0 | 5 | (0,1):1 (0,2):2 (0,3):11 (0,4):1 / (0,2):1 (0,3):11 (0,4):2 (0,5):1 / (0,2):5 (0,3):8 (0,4):2 / (0,2):2 (0,3):8 (0,4):5 / (0,3):6 (0,4):9 / (0,2):9 (0,3):6 |
| 1 | 1 | (0,3):2 (0,4):3 (1,1):3 (1,2):6 (1,3):1 |
| 2 | 2 | (0,4):1 (1,2):8 (2,1):2 (2,2):4 / (0,5):1 (1,2):4 (1,3):4 (2,1):1 (2,2):5 |

**`a=1` は1型のみ**（最も単純）。`a=0` が5型で最も複雑。

## 6. 意義

1. **`a = 2` ⟺ 場合 B** という定理を証明した。
2. **三つ組の総数を `a` 別に閉形式で書いた**（q=5,7 で一致）。
3. **前項の「90配置」の障壁を回避する道を示した**：
   `a` で層別すれば `a=1` は1型、`a=2` は2型と単純。
   複雑なのは `a=0` のみ。
4. 対合が「`C` と2点で交わる円」を記録するという**定義の混同を修正**した。
