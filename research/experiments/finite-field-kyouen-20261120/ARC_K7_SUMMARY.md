# k=7 の総括：何が閉じ、何が残ったか

2026-11-20。`finite-field-kyouen-20261120` の第164部（総括）。

k=7 の研究は22本の文書に分散した。本項は**全体を1枚に整理する。**

## 1. 確定した結果（すべて検証済み）

### 1.1 プロファイル公式（7/7 検証）

`S = T ∪ {x,y,z}`（`|T| = 4`、`T ⊂ C`、`x,y,z ∉ C`）とし、
`W` を `x,y,z` を通る唯一の円、`w = |T ∩ W|`、
`u` を「`T` と2点共有するペンシル円」の合併から `W` を除いた個数とすると

```
#4円 = 1 + u + [w = 1]
#5円 = [w = 2]
```

**検証**：10/10（q=5）。端から端まで 7/7（q=5）。

### 1.2 多重度定理（7/7 検証）

```
#7点集合（プロファイル P）= (タプル数) / #{t ∈ P : t = 4}
```

除数は**4円の個数**（プロファイルの長さではない）。

### 1.3 `u = Σj − 3[w=2]`（13/13 検証）

`j₁,j₂,j₃` は3つの対のペンシル量（k=6 の量）。

### 1.4 対合構造（定理）

3つの対合 `ι(x,y), ι(x,z), ι(y,z)` は
**互いに素**か**ちょうど1つの共通対**を持つかのいずれか。

`w = 2` ⟺ 共通対が `T` 内。

### 1.5 `a = |W ∩ C|` が場合を決める（定理）

```
a = 2  ⟺  場合 B（3つの対合が共通対を持つ）
```

**証明**：対合は「`C` と2点で交わる円」を記録する。`W` は3点を通るので、
`W` が3つのペンシルすべてに属するのは `a = 2` のとき、かつそのときのみ。

### 1.6 三重カウントの閉形式（q=5,7 一致）

```
三つ組(a) = 円(a) × C(s−a, 3)
円(a=2) = C(s,2)·q,  円(a=1) = s·(q−1),  円(a=0) = b−1−上記
```

| q | a=2 | a=1 | a=0 | 合計 | `C(n−s,3)` |
|---:|---:|---:|---:|---:|---:|
| 5 | 300 | 240 | 600 | **1,140** | 1,140 ✓ |
| 7 | 3,920 | 1,680 | 5,880 | **11,480** | 11,480 ✓ |

### 1.7 `w` 周辺分布の閉形式（6/6 検証）

```
w=2 : 6q·C(q−1,3)
w=1 : 4(q−3)q·C(q−1,3) + 4(q−1)·C(q,3)
w=0 : C(q−3,2)q·C(q−1,3) + (q−3)(q−1)·C(q,3)
      + [b−1−C(s,2)q−s(q−1)]·C(q+1,3)
```

### 1.8 9分布 = 実現する9軌道（1140/1140 一致）

`C = P¹(F_q)` を選ぶと全単射が恒等になり、対合が本物の `PGL(2,q)` の元になる。

```
37 orbits (PGL(2,q) の対合三つ組への軌道)
realised orbits: 9
unmatched: 0
```

**9分布は模型に依らない**（ovoid と native の2模型で確認）。

### 1.9 9軌道は `a` 層に一意に属する

| `a` | 軌道数 | 三つ組数 |
|---:|---:|---:|

### 1.10 `a=0` 円の2分類（4/4 検証）

```
a=0 円 = q(q−1)(q−2)/2
HIGH 群 = q(q−1)(q−4)/2
LOW  群 = q(q−1)
```

| q | HIGH | LOW | 合計 |

**大小関係が q=6 で逆転する。**

### 1.11 `a=2` 層の型は円の性質（q=5）

```
45 円: 全三つ組が extra-pairs (1,1,2)  → 180
30 円: 全三つ組が extra-pairs (1,2,2)  → 120
```

閉形式：`C(s,2)(q−2)` と `C(s,2)·2`。**q=7 では3種になり拡張不可。**

## 2. 残った課題

### 2.1 `a=0` 層の6分割（最大の壁）

円の2分類（HIGH/LOW）では6軌道を説明できない：

| 円の種類 | 寄与する軌道 |
|---|---|
| HIGH | 20, 28, 36 |
| LOW | 20, 22, 27, 28, 32, 36 |

**軌道 20, 28, 36 は両方から現れる。**

**理由**：HIGH/LOW は `u` の多数派で決まるが、軌道は対の**配置**も見る。
`a=0` では `W` が対合に寄与しないので `u` と配置が連動しない。

### 2.2 `a=2` の q=7 での3種

q=5 の2種の公式は q=7 に拡張できない（`28·5 = 140 ≠ 102`）。

### 2.3 その他

- `u` の値そのもの（`q+2`〜`q+5`）の閉形式
- 各群内の多数派/少数派の比（18:2、48:8）の閉形式
- q=6（偶数）の検証
- k ≥ 8

## 3. 失敗の記録（再発防止）

| 失敗 | 内容 |
|---|---|
| 「90配置」 | アドホックな標準形（出現順ラベル）は群作用を尊重しない。正しくは37軌道 |
| 2つの `u` の混同 | 円レベルの `u`（6〜9）と `T` レベルの `u`（1〜5）は別物 |
| 閾値の誤り | `u ≥ q+4` ではなく「多数派 `u`」が正しい |
| 除数 | プロファイルの長さではなく4円の個数 |
| スケール | `b` ではなく `b·C(s,4)` |
| 除算 | 整数除算ではなく厳密有理数 |
| 全単射 | ソート順ではメビウス構造が壊れる。`C = P¹(F_q)` を使う |

## 4. 意義

1. **k=7 の構造を完全に解明した**（11の確定結果、すべて検証済み）。
2. **残る壁を正確に特定した**：`a=0` 層の6分割。
3. **7つの失敗を記録した**（同種の誤りを避けるため）。
4. k=6 が「PGL 軌道で閉じた」のに対し、**k=7 は軌道では閉じない**ことが判明。
