# k=7 の欠落3プロファイル：すべて閉じた

2026-11-20。`finite-field-kyouen-20261120` の第175部。

前項で `(7,)` と `(6,)` を閉じた。本項は残る `(5,)` を閉じ、
**k=7 の全プロファイルを決定する。**

## 1. `(5,)` の条件（定理）

`(5,)` に数えられるのは、5点円 `C` と外2点 `{x,y}` で
**`{x,y}` を通るどのペンシル円も `C` 上の5点と2点で交わらない**場合。

**理由**：`C'` が `S` から4点取るには、`C'` が `C` と高々2点で交わるので
`C` 上の5点から2点、`{x,y}` から2点を取る必要がある。よって
「`{x,y}` を通り `C` 上の5点と2点で交わる円」が1つでもあれば
`(5,)` にならない。

**定理**：

```
(5,) = b · #{T5 ⊂ C, {x,y} ⊂ C^c : ペンシル(x,y) の円が T5 と2点で交わらない}
```

## 2. 検証

**q=5**（`s=6`、`C(s,5)·C(n−s,2) = 6·190 = 1,140`）：

| 該当ペンシル円の個数 | 組数 |
|---:|---:|
| 1 | 480 |
| 2 | 660 |
| **0** | **0** |

**0 が存在しない** → `(5,) = 0`。実測と一致。

**q=7**（`s=8`、`C(s,5)·C(n−s,2) = 56·861 = 48,216`）：

| 該当ペンシル円の個数 | 組数 |
|---:|---:|
| **0** | **4,032** |
| 1 | 29,568 |
| 2 | 14,616 |

**0 が 4,032 組** → `(5,) = 350 × 4,032 = 1,411,200`。実測と一致。

## 3. 主定理：k=7 の全プロファイル

```
(7,) = b·C(s,7)
(6,) = b·C(s,6)·(n−s)
(5,) = b·#{T5,{x,y} : ペンシル(x,y) の円が T5 と2点で交わらない}
(5,4), (5,4,4), (4,), (4,4), (4,4,4), (4,4,4,4), (4,4,4,4,4), (4,4,4,4,4,4)
     = タプル数 / (4の個数) × b   （プロファイル公式で計算）
```

**検証**（q=5, q=7 の全プロファイル）：

| q | 全数合計 | 組み立て合計 |
|---:|---:|---:|
| 5 | 657,800 | **657,800** ✓ |
| 7 | 99,884,400 | **99,884,400** ✓ |

## 4. 意義

1. **`(5,)` の条件を特定した**（ペンシル円が `T5` と2点で交わらない）。
2. **q=5, q=7 の両方で検証**（0 と 4,032）。
3. **k=7 の全プロファイルが閉じた**。
4. **q=5 で `(5,) = 0`** という極端な例の理由を明示（`s=6` で必ず
   ペンシル円が存在）。
