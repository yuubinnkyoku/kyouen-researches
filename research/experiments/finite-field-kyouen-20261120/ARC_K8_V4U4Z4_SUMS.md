# k=8 の `v4`, `u4`, `z4` の個別の和：k=8 の閉形式が完全に完成

2026-11-20。`finite-field-kyouen-20261120` の第212部。

k=8 の最後のピース `v4`, `u4`, `z4` の**個別の和**を導出した。
**これで k=8 の6類すべてが完全に閉形式になった。**

## 1. 定理

共円な `X` の円を `D` とすると、`T` の選び方で3つに分かれる：

```
#T with |D∩T| = 2  = C(|D∩C|, 2) · C(s−|D∩C|, 2)   → v4
#T with |D∩T| = 1  = C(|D∩C|, 1) · C(s−|D∩C|, 3)   → u4
#T with |D∩T| = 0  = C(|D∩C|, 0) · C(s−|D∩C|, 4)   → z4
```

**よって**

```
sum v4 = Σ_{X 共円} C(k_X, 2)·C(s−k_X, 2)
sum u4 = Σ_{X 共円} C(k_X, 1)·C(s−k_X, 3)
sum z4 = Σ_{X 共円} C(k_X, 0)·C(s−k_X, 4)
```

ここで `k_X = |D ∩ C|`。

## 2. 検証（q=5）

**`|D∩C|` の分布**（共円な `X` 645 個）：

| `\|D∩C\|` | 個数 |
|---:|---:|
| 0 | 450 |
| 1 | 120 |
| 2 | 75 |

**計算**（`s = 6`）：

```
sum v4 = 450·C(0,2)C(6,2) + 120·C(1,2)C(5,2) + 75·C(2,2)C(4,2)
       = 450·0 + 120·0 + 75·1·6
       = 450   ✓

sum u4 = 450·C(0,1)C(6,3) + 120·C(1,1)C(5,3) + 75·C(2,1)C(4,3)
       = 0 + 120·1·10 + 75·2·4
       = 1,200 + 600
       = 1,800   ✓

sum z4 = 450·C(0,0)C(6,4) + 120·C(1,0)C(5,4) + 75·C(2,0)C(4,4)
       = 450·15 + 120·5 + 75·1
       = 6,750 + 600 + 75
       = 7,425   ✓
```

**3/3 完全一致。**

## 3. 分布の意味

| `\|D∩C\|` | 個数 | 意味 |
|---:|---:|---|
| 0 | 450 | `D` が `C` と交わらない |
| 1 | 120 | `D` が `C` に接する |
| 2 | 75 | `D` が `C` と2点で交わる |

**これは第206部の円の分類と整合する**（`|C'∩C|` の分布と同じ構造）。

## 4. k=8 の6類の閉形式（完全版）

```
sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(n−s−q+1,2)
```
