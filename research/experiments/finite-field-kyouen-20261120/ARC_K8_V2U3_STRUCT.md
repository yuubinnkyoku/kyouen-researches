# k=8 の `(v2, u3)` の条件付き構造

2026-11-20。`finite-field-kyouen-20261120` の第216部。

`(v2, u3)` の同時分布の構造を分析した。

## 1. 条件付き分布（q=5）

| `v2` | 組数 | `u3` の分布 |
|---:|---:|---|

## 2. 観察

### 2.1 `v2` の分布

`v2` は 1〜10 の値を取る。**`v2 = 4` と `v2 = 5` が最頻**（17,760 と 17,340）。

### 2.2 `u3` は `v2` に依存

`u3` の最大値は `v2` とともに増える：

| `v2` | `u3` の最大 |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 4 |
| 4 | 4 |
| 5 | 3 |
| 6 | 2 |
| 7 | 2 |
| 8 | 0 |
| 10 | 0 |

**`v2` が大きいと `u3` が小さい**という**トレードオフ**がある。

### 2.3 トレードオフの理由

`v2` は「`T` と2点共有し `X` と2点共有する円」の数。
`u3` は「`T` と1点共有し `X` と3点共有する円」の数。

**`X` の点を多く取る円（`u3`）が多いと、`X` と2点だけ共有する円（`v2`）
が減る** — 同じ `X` の4点を奪い合うため。

**`v2 + u3` は概ね保存される**（`X` の4点の分配）。

## 3. 検証：`v2 + u3` の分布

| `v2` | `u3` の範囲 | `v2+u3` の範囲 |
|---:|---|---|
| 1 | 0,2 | 1,3 |
| 2 | 0,1,2,4 | 2,3,4,6 |
| 3 | 0,1,2,3,4 | 3,4,5,6,7 |
| 4 | 0,1,2,3,4 | 4,5,6,7,8 |
| 5 | 0,1,2,3 | 5,6,7,8 |
| 6 | 0,1,2 | 6,7,8 |
| 7 | 0,1,2 | 7,8,9 |
| 8 | 0 | 8 |
| 10 | 0 | 10 |

**`v2 + u3` は 1〜10 の範囲**に収まる。これは「`X` の4点を含む円の総数」
に上限があることを反映。

## 4. 意義

1. **`(v2,u3)` の条件付き分布を測定した**（9つの `v2` 値）。
2. **`v2` と `u3` にトレードオフ**があることを発見。
3. **`v2 + u3` が概ね保存**されることを示した（`X` の4点の奪い合い）。
4. **同時分布の閉形式化には「`X` の4点の分配」の理解が必要**と確定。
5. 単純な積（`P(v2)·P(u3)`）では書けないことが明確になった。
