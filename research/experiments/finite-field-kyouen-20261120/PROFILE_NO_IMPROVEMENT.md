# 円のプロファイルは上界を改善しない

2026-11-20。`finite-field-kyouen-20261120` の第67部。
円のプロファイル分析が上界改善に使えるかを検証し、**使えない**ことを示した。

## 1. プロファイルの恒等式

最大 3-arc `S`（サイズ `k`）について、次が成り立つ（数値検証済み）：

```
（3点を含む円の数） = C(k,3)
（2点を含む円の数） = C(k,2)·(q−k+3)
（点 p だけを含む円の数） = q²+q − C(k−1,2) − (k−1)(q−k+3)
```

## 2. 導かれる制約

### 制約1：`q−k+3 ≥ 0`

2点を含む円の数が非負であることから

```
k ≤ q + 3
```

**これは λ₂ 上界そのものである。**

### 制約2：`C(k−1,2) + (k−1)(q−k+3) ≤ q²+q`

点 `p` だけを含む円の数が非負であることから

```
C(k−1,2) + (k−1)(q−k+3) ≤ q²+q
```

`k = q+3` を代入して検証：

| q | k=q+3 | 左辺 | q²+q | 成立 |
|---:|---:|---:|---:|---|
| 3 | 6 | 10 | 12 | ✓ |
| 5 | 8 | 21 | 30 | ✓ |
| 7 | 10 | 36 | 56 | ✓ |
| 9 | 12 | 55 | 90 | ✓ |
| 11 | 14 | 78 | 132 | ✓ |
| 13 | 16 | 105 | 182 | ✓ |
| 17 | 20 | 171 | 306 | ✓ |
| 19 | 22 | 210 | 380 | ✓ |

**すべて成立するので、制約にならない。**

## 3. 結論

円のプロファイル分析は

- λ₂ 上界 `k ≤ q+3` を**再現する**が、
- それを**改善しない**。

これは5つ目の失敗である。

## 4. 失敗した手法の一覧（更新）

| 手法 | 結果 |
|---|---|
| 次数 | 制約なし（k ≤ 2q+4） |
| 複数ペンシル | `λ₂+2` のまま |
| 被覆 | q=3 のみ有効 |
| 円ペア | 制約なし |
| **円のプロファイル** | **`λ₂+2` を再現するのみ** |

## 5. 意義

- プロファイルの恒等式は構造の理解を深める（3点円 = `C(k,3)`、2点円 = `C(k,2)(q−k+3)`）。
- しかし上界改善には使えないことを確認した。
- 5つの初等的な手法がすべて失敗したことで、**初等的な数え上げの限界**が明確になった。

## 6. 限界

- プロファイルの恒等式は事後の説明であり、上界ではない。
- より高次のモーメント（4点、5点を含む円の数）は未検討だが、
  同様に恒等式になる可能性が高い。
