# k=8 の6類の分布（q=5）

2026-11-20。`finite-field-kyouen-20261120` の第203部。

k=8 のプロファイル公式に現れる6類の分布を測定した。

## 1. 測定結果（q=5、`n=26`、`b=130`、`s=6`）

| 類 | 分布 |
|---|---|
| `v2` | `{1:1320, 2:5400, 3:12120, 4:17760, 5:17340, 6:14160, 7:3900, 8:615, 10:60}` |
| `v3` | `{0:45195, 1:26160, 2:1320}` |
| `v4` | `{0:72225, 1:450}` |
| `u3` | `{0:23745, 1:26760, 2:19140, 3:2760, 4:270}` |
| `u4` | `{0:70875, 1:1800}` |
| `z4` | `{0:65250, 1:7425}` |

**同時分布の類数：41。**

## 2. 観察

### 2.1 `v4` と `u4` はほぼ常に 0

```
v4 = 1 は 450 組のみ（全体 72,675 の 0.6%）
u4 = 1 は 1,800 組のみ（2.5%）
```

**`v4`（`|C'∩T|=2` かつ `|C'∩X|=4`）は極めて稀。**
`C'` が `C` と2点で交わり、かつ外4点すべてを含む必要がある。

### 2.2 `z4` は 0 か 1 のみ

```
z4 = 0: 65,250
z4 = 1:  7,425
```

**`z4`（`|C'∩T|=0` かつ `|C'∩X|=4`）は高々1。**
外4点 `X` を通る円は一意（3点で決まる）なので、`X` が共円なら
その円が `z4 = 1` になる。**`X` が共円かどうかで決まる。**

### 2.3 `v2` は 1〜10 の広い範囲

`v2`（`|C'∩T|=2` かつ `|C'∩X|=2`）が最も複雑。最大 10。

### 2.4 `v3` と `u3` は中程度

`v3` は 0〜2、`u3` は 0〜4。

## 3. 構造的な理解

| 類 | 意味 | 分布の特徴 |
|---|---|---|
| `v2` | `T` から2点、`X` から2点 | 広い（1〜10） |
| `v3` | `T` から2点、`X` から3点 | 狭い（0〜2） |
| `v4` | `T` から2点、`X` から4点 | **極めて稀**（0〜1） |
| `u3` | `T` から1点、`X` から3点 | 中程度（0〜4） |
| `u4` | `T` から1点、`X` から4点 | **稀**（0〜1） |
| `z4` | `T` から0点、`X` から4点 | **0か1**（`X` の共円性） |

**`X` から多くの点を取る類（`v4`, `u4`, `z4`）は稀。**
これは「外4点が共円になりにくい」ことの反映。

## 4. 意義

1. **6類の完全な分布を測定した**（q=5）。
2. **`v4`, `u4` が極めて稀**であることを発見。
3. **`z4` が 0 か 1** で、`X` の共円性で決まることを示した。
4. **同時分布が41類**であることを確認（プロファイルは13種）。
5. 各類の閉形式導出の手がかりを得た（`z4` は共円性で書ける）。
