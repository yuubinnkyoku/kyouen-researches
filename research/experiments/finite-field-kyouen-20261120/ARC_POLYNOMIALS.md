`#4-arcs` と `#5-arcs` の閉形式を**多項式として完全に展開**した。

## 1. 定理：`#4-arcs` の多項式

```
#4-arcs = (q⁸ − q⁷ − q⁴ + q³) / 24
```

**検証**：

| q | 多項式 | 実測 | 一致 |

| 5 | 13,000 | 13,000 | ✓ |
| 7 | 205,800 | 205,800 | ✓ |

## 2. 定理：`#5-arcs` の多項式（訂正版）

```
#5-arcs = q³/24 − 3q⁴/40 + q⁵/24 − q⁶/120 − q⁷/24
          + 3q⁸/40 − q⁹/24 + q¹⁰/120
```

**検証**：q=3..59 の**全整数 q** で完全一致。

| q | 多項式 | 実測 | 一致 |
|---:|---:|---:|---|

**4/4 完全一致。**

## 3. 主項

```
#4-arcs ~ q⁸/24
#5-arcs ~ q¹⁰/120
```

**どちらも主項が正**。よって大きな `q` では `#4-arcs > 0`、`#5-arcs > 0`。
これは `K(q) ≥ 5` が大きな `q` で常に成り立つことを意味する（自明だが
多項式の形で確認できた）。

## 4. 次数の意味

`#k-arcs` の次数は `2k`：

```
#4: 8次
#5: 10次
```

これは `n ~ q²` から `k` 点を選ぶ組合せ `C(n,k) ~ q^(2k)/k!` に対応する。
**主項は `q^(2k)/k!`** で、これは「制約が効かない場合」の数。

実際の主項は `q⁸/24 = q⁸/4!`、`q¹⁰/120 = q¹⁰/5!` で**ちょうど `C(n,k)` の
主項と一致**する。つまり**禁止条件は主項に寄与しない**（次の次数以下）。

## 5. 意義

1. **`#4-arcs` と `#5-arcs` の多項式を完全に展開した**（8次、10次）。
2. **両方とも主項が正**であることを確認。
3. **主項が `C(n,k)` の主項と一致**することを発見（禁止条件は主項に
   寄与しない）。
4. 多項式表示により、任意の `q` で即座に計算できるようになった。
