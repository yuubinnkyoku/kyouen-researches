# k=7 の q=7：まだ過大カウント（第2の誤り）

2026-11-20。`finite-field-kyouen-20261120` の第169部。

前項でプロファイル公式を修正した（`v` と `|W ∩ T|`）。本項は
**スケールが誤っていた**ことを示し、さらに**まだ過大カウントが残る**
ことを報告する。

## 1. スケールの誤り

前項まで `scale = b·C(s,4)` を使っていた。正しくは **`scale = b`**。

**理由**：タプルループは `C = P¹(F_q)`（1つの特定の円）を固定し、
`T`（`C` の4点部分集合）と `{x,y,z}`（`C` の外の3点）を列挙する。
よって `T` は既に列挙されており、`C(s,4)` を掛けるのは二重。

**検証**（q=5）：

| スケール | bad | arcs | 全数 |
|---|---:|---:|---:|
| **`b`** | **657,800** | **0** | **657,800 / 0** ✓ |
| `b·C(s,4)` | 9,830,600 | −9,172,800 | ✗ |
| `1` | 7,640 | 650,160 | ✗ |

**`scale = b` が正しい。**

## 2. しかし q=7 ではまだ合わない

| q | 全数 bad | 全数 arcs | `scale=b` の bad | `scale=b` の arcs |
|---:|---:|---:|---:|---:|
| 5 | 657,800 | 0 | **657,800** | **0** ✓ |
| 7 | 99,884,400 | **0** | 98,470,400 | **1,414,000** ✗ |

**q=7 の全数では7-アークが 0**（`K(7) = 6` と整合）。
しかし `scale=b` は 1,414,000 個のアークを主張する。

**まだ過大カウントが残っている。**

## 3. 残る誤りの候補

プロファイル公式は q=5,7 で 0 不一致だった（前項）。しかし
**多重度の割り算**が正しくない可能性がある。

多重度定理「#7点集合 = タプル数 / 4円の個数」は、
**タプルが「4円 `C` とその4点部分集合 `T`」を固定して数える**
ことを前提とする。

しかし今回のタプルループは `C = P¹(F_q)` を**固定**している。
よって 7点集合 `S` は、`S` の4円のうち `P¹(F_q)` であるものについてしか
数えられない。

**`P¹(F_q)` が `S` の4円でない場合、その `S` はタプルに現れない。**
一方、`S` の4円が `P¹(F_q)` である場合、`S` は `C(4,4)=1` 回現れる。

**よって割り算 `÷(4円の個数)` は誤り。** 正しくは「`P¹(F_q)` が
4円である `S`」だけを数えているので、割り算は不要（または別の扱い）。

## 4. 現状

- **プロファイル公式**：q=5,7 で 0 不一致（正しい）
- **スケール**：`b`（正しい、q=5 で確認）
- **多重度の割り算**：**誤り**（`C` 固定のため）

**q=5 で偶然合ったのは、`b·C(s,4)` という誤ったスケールと
`÷(4円の個数)` という誤った割り算が相殺したため。**

## 5. 意義

1. **スケールの誤りを特定・修正した**（`b·C(s,4)` → `b`）。
2. **多重度の割り算が誤り**であることを特定した（`C` 固定のため）。
3. **q=5 の「成功」は2つの誤りの相殺だった**ことを示した。
4. **q=7 の全数で7-アークが 0** であることを確認（`K(7)=6` と整合）。
