# 全三点ブロック性は q=7 のサイズ6で完全に普遍的

2026-11-20。`finite-field-kyouen-20261120` の第52部。
「全三点ブロック性」が極値配置だけでなく、**同サイズの全安全集合**で成り立つことを発見した。

## 1. 結果

AG(2,7)（49点・350ブロック）で、サイズ6の安全集合を**すべて**列挙した。

| 項目 | 値 |
|---|---:|
| サイズ6の安全集合の総数 | **1,103,872** |
| うち全三点がブロック上 | **1,103,872** |
| 性質を持たないもの | **0** |

**サイズ6の安全集合は例外なく「任意の三点が同一円または同一直線上にある」。**

## 2. なぜこれが重要か

前項まで「極値配置がこの性質を持つ」という観測に基づいて上界 `K ≤ λ₂ + 2` を導いた。
しかし性質が極値配置に固有なら、上界の根拠は弱い。

今回の結果は、**サイズ6という「十分大きい」安全集合では性質が自動的に成り立つ**
ことを示す。つまり上界の前提は、少なくとも q=7 のサイズ6では常に満たされる。

## 3. 構造的な理由（推測）

サイズ6の安全集合 `S` を考える。`S` の三点組は `C(6,3) = 20` 個。
もし三点 `{a,b,c}` がブロック上にないなら、その三点は「非共線かつ非共円」である。

AG(2,7) では、任意の三点は**必ず**いずれかの円または直線に載るのだろうか？
もしそうなら、性質は自明である。

**検証**：AG(2,7) の任意の三点がブロック上にあるかを確認する必要がある。
もし「任意の三点がブロック上」なら、性質は自明で上界の前提は常に満たされる。

## 4. 検証すべきこと

AG(2,q) で「任意の三点が同一円または同一直線上にある」か？

これは明らかに**偽**である：三点が一直線上になく、かつ一つの円上にもない配置は存在する
（例えば q=7 で (0,0), (1,0), (0,1) は直線上になく、円上にもない... 実際は
任意の三点が円を定めるので、**任意の三点は必ず一つの円上にある**！）

**待った**：ユークリッド平面でも、任意の三点は（一直線でなければ）一意に円を定める。
つまり「三点が円上にある」は**常に真**である。

したがって「全三点ブロック性」は**自明**である！

## 5. 重大な訂正

「任意の三点が同一円または同一直線上にある」は、**三点が一直線でなければ必ず円が存在する**
ので、常に真である。これは共円ゲームの定義そのものである。

つまり：
- 三点が一直線 → 直線ブロック上
- 三点が一直線でない → その三点を通る円が一意に存在 → 円ブロック上

**「全三点ブロック性」は恒真である。**

## 6. 上界の証明への影響

上界 `K ≤ λ₂ + 2` の証明は「全三点ブロック性」を使っていたが、
これは恒真なので**前提なしで成立する**。

証明を再確認：
- `p, q ∈ S` を固定。
- `S\{p,q}` の各点 `r` について、三点 `{p,q,r}` は（一直線か円上なので）ブロック上にある。
- そのブロックは `p,q` を通るので `λ₂` 個のペンシルのいずれか。
- 異なる `r` は異なるブロックを与える（同じなら4点を含み矛盾）。
- よって `|S| − 2 ≤ λ₂`。

**この証明は恒真な事実だけを使っているので、完全に有効である。**

## 7. 意義

- 上界 `K ≤ λ₂ + 2 = q + 3` は**無条件で成立**する（前提なし）。
- 前項までの「全三点ブロック性」への言及は、実は恒真な事実だった。
- 上界の証明は完全に正しい。

## 8. 限界
