# D(n) の連続緩和：凹の場合の扱いと、格子との差 1/2

2026-11-20。`finite-field-kyouen-20261120` の第16部。
[DET_MAX_STRUCTURE.md](DET_MAX_STRUCTURE.md) の記述を精密化し、連続緩和の正しい値を確定した。

## 1. 前回の誤り

前項では「`Delta` は `x` と `y` について分離した凸二次式なので、最大は正方形の角で達成される」
と書いた。**これは誤りである。**

```
Delta(x,y) = alpha·x + beta·y + gamma·(x²+y²) + delta
```

の凸性は `gamma` の符号で決まる：

- `gamma > 0`：凸。最大は境界（角）で達成。
- `gamma < 0`：**凹**。最大は内部（円の中心付近）で達成されうる。
- `gamma = 0`：アフィン。最大は角。

実際 a=5 の三点 `(0,0),(1,0),(4,1)` では `gamma = −1` で、
連続最大は `(1/2, 5)` において `161/4` であり、どの角の値（最大 40）よりも大きい。
a=5 では 7,140 個の三点のうち **840 個**で角の値が連続最大を下回った。

## 2. 正しい連続最大

凹の場合（`gamma < 0`）は、`|Delta|` の最大は

- いずれかの角、または
- 放物面の頂点（円の中心）を正方形に射影した点

のいずれかで達成される。両方を評価して大きい方を取ればよい。

この方法で a ≤ 8 の全三点について連続最大を計算した結果：

| a | 格子最大 | 連続最大 | 差 | gamma の符号 (+,−,0) |
|---:|---:|---:|---:|---|
| 3 | 36 | 81/2 = 40.5 | 4.5 | 258, 258, 44 |
| 4 | 128 | 128 | 0 | 1074, 1074, 152 |
| 5 | 300 | 625/2 = 312.5 | 12.5 | 3384, 3384, 372 |
| 6 | 648 | 648 | 0 | 8800, 8800, 824 |
| 7 | 1,176 | 2401/2 = 1200.5 | 24.5 | 20060, 20060, 1544 |
| 8 | 2,048 | 2,048 | 0 | 41304, 41304, 2712 |

**連続最大は a が偶数のとき `a⁴/2`、奇数のとき `a⁴/2 + 1/2`** である（a ≤ 8 で確認）。

格子最大は `a²⌊a²/2⌋` で、これは

- a 偶数：`a⁴/2`
- a 奇数：`a⁴/2 − 1/2`

である。したがって

```
連続最大 − 格子最大 = 0（a 偶数）、1（a 奇数）
```

## 3. 証明への道筋

この分解は次の2段階に問題を分ける：

**段階1（連続）**：任意の三点と任意の実数 `(x,y) ∈ [0,a]²` に対し
`|Delta| ≤ a⁴/2 + [a odd]/2`。

**段階2（格子）**：a が奇数のとき、格子点での値は連続最大より少なくとも 1 小さい。

段階1は「三点を通る円に関するべきの、正方形上での最大」を評価する問題である。
`gamma` の符号で場合分けし、凸なら角、凹なら角か中心射影、という有限個の評価に落ちる。
残るのは `|gamma|` と中心・半径を三点の座標で上から押さえることである。

段階2は、a 奇数では連続最大を与える点が格子点でない（半整数座標）ことから従う可能性がある。
実際 a=5 の例では最大点は `(1/2, 5)` で、`x` が半整数である。

**ただし段階1も段階2も未証明である。** 上表は a ≤ 8 の全数計算に基づく観測である。

## 4. 副産物：gamma の符号は対称に分布する

表の最右列を見ると、`gamma > 0` と `gamma < 0` の三点の個数が**常に等しい**。
これは三点の順序を入れ替えると `gamma` の符号が反転する（行列式の交代性）ことから
当然であるが、実装の健全性チェックになっている。

## 5. 限界

- a ≤ 8 の全数計算。a ≥ 9 は未計算（三点の個数が O(a^6) で増える）。
- 連続最大の公式 `a⁴/2 + [a odd]/2` は観測であり証明ではない。
- 段階2（格子点での 1 の減少）の一般的な理由は特定していない。
- 凹の場合に「角か中心射影のどちらか」で最大になるという主張は、
  `Delta` が円のべき（中心からの距離の二乗のアフィン関数）であることから従うが、
  本項では数値的に確認したのみ。
