# k=8 の閉形式：単一スクリプトでの完全検証

2026-11-20。`finite-field-kyouen-20261120` の第214部。

k=8 の6類の閉形式を**1つのスクリプトにまとめ、一括検証**した。

## 1. 閉形式（完全版）

```
N_0 = (b−1) − C(s,2)·q − s(q−1)
N_1 = s(q−1)
N_2 = C(s,2)·q

G(y,m) = C(y,3)·C(m−y,1) + C(y,4)

sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(m−q+1,2)
sum v3 = C(s,2)·q · C(s−2,2) · C(q−1,3)·C(m−q+1,1)
sum v4 = Σ_j N_j·C(s−j,4) · C(j,2)·C(s−j,2)
sum u4 = Σ_j N_j·C(s−j,4) · C(j,1)·C(s−j,3)
sum z4 = Σ_j N_j·C(s−j,4) · C(j,0)·C(s−j,4)
sum u3 = s(q−1)·C(s−1,3)·G(q,m)
       + C(s,2)·q·2·C(s−2,3)·G(q−1,m) − sum u4
```

ここで `m = n − s`。

## 3. プロファイルへの変換

```

#5円 = v3 + u4
#6円 = v4
```

## 4. 重要な限界：和では足りない

**6類の「和」だけではアーク数は出ない。**

アーク数の組み立ては

```
#8-arcs = C(n,8) − Σ_P (タプル数(P) / #4円(P)) × b − (7,) − (8,)
```

であり、**プロファイルの分布**（各 `(n4,n5,n6)` のタプル数）が必要。

**和は分布を決めない**（同じ和でも分布が違えばアーク数が変わる）。

**よって現状で閉形式なのは「6類の和」までであり、
アーク数そのものの閉形式は未完成。**
