# 比の系列 `1/4², 1/6²` の分析：パターンは K(q) で終わる

2026-11-20。`finite-field-kyouen-20261120` の第201部。

q=9 で得られた比の系列を分析した。

## 1. 測定値

```
#7 = 17,003,520
#8 =  1,062,720     #8/#7 = 1/16 = 1/4²
#9 =     29,520     #9/#8 = 1/36 = 1/6²
```

## 2. 2つの候補式

**候補 A**：`1/(2(k−5))²`

| k | `2(k−5)` | `1/(2(k−5))²` | 実測 |
|---:|---:|---:|---:|
| 7 | 4 | 1/16 | 1/16 ✓ |
| 8 | 6 | 1/36 | 1/36 ✓ |

**候補 B**：`1/(q−5)²`（k=7）、`1/(q−3)²`（k=8）

| k | 分母 | 値 | 実測 |
|---:|---:|---:|---:|
| 7 | `q−5 = 4` | 1/16 | 1/16 ✓ |
| 8 | `q−3 = 6` | 1/36 | 1/36 ✓ |

**両方の候補が2点に適合する。** 第3の点か別の q が必要。

## 3. 決定的な観察：パターンは終わる

**`K(9) = 9` なので `#10 = 0`。**

もしパターンが続くなら

```
#10 = 29,520 / 64 = 461.25   （整数でない！）
#10 = 29,520 / 100 = 295.2   （整数でない！）
```

**どちらも整数でない。よってパターンは継続できない。**

**これは `#10 = 0` と完全に整合する。**

## 4. 解釈

比の系列 `1/4², 1/6²` は**偶然の一致ではなく、
「アーク数が K(q) で急激に終わる」ことの現れ**である。

`K(9) = 9` という構造的制約が、比の系列が `1/8²` に進むことを
**整数性のレベルで禁止している**。

## 5. 意義

1. **比の系列 `1/4², 1/6²` を確認した。**
2. **2つの候補式を提示**（`1/(2(k−5))²` と q 依存版）。
3. **パターンが `K(q)` で終わる**ことを整数性から示した。
4. **`#10 = 0` と整合**することを確認。
5. 比の系列が「アーク数の急激な終焉」を反映しているという
   構造的理解を得た。

## 6. 限界

- 候補 A と B の判別には別の q（q=11）が必要。
- q=11 の k=8 は計算中。
- k=10 は `C(82,10) = 1.9×10¹²` で約1日（`#10 = 0` は K(9)=9 から自明）。
