# k=8 の円の分類：`|C' ∩ T|` の完全な分解

2026-11-20。`finite-field-kyouen-20261120` の第206部。

k=8 の6類を閉形式化するため、円を `|C' ∩ T|` で分類した。

## 1. 設定

`T` は基準円 `C`（`s = q+1` 点）の4点部分集合。
`C' ≠ C` は `C` と 0, 1, 2 点で交わる。

`k = |C' ∩ C|`、`m = |(C' ∩ C) ∩ T|` とすると `|C' ∩ T| = m`。

## 2. 定理：`|C' ∩ T| = 2`

```
|C' ∩ T| = 2  ⟺  C' が T の2点を通る
```

`T` の2点の組は `C(4,2) = 6`。各組を通る円は `q+1` 個（うち `C` 自身）。
よって

```
#{C' : |C' ∩ T| = 2} = 6q
```

**検証（q=5）**：`6 × 5 = 30`。実測 **30** ✓

## 3. 定理：`|C' ∩ T| = 1`

2つの場合がある：

**(a) `C` と1点（`T` 内）で接する**：`4(q−1)` 個

**(b) `C` と2点で交わり、片方だけが `T` 内**：
`T` の点と `C−T` の点の組は `4 × (s−4)`。各組に `q` 個の円。

```
#{C' : |C' ∩ T| = 1} = 4(q−1) + 4(s−4)q
```

**検証（q=5、`s=6`）**：`4×4 + 4×2×5 = 16 + 40 = 56`。実測 **56** ✓

## 4. 定理：`|C' ∩ T| = 0`

3つの場合がある：

**(a) `C` と交わらない**：`N₀` 個（下記）
**(b) `C` と1点（`C−T` 内）で接する**：`(s−4)(q−1)` 個
**(c) `C` と2点で交わり、両方 `C−T` 内**：`C(s−4,2)·q` 個

**検証（q=5）**：`(b) = 2×4 = 8`、`(c) = 1×5 = 5`。
実測の `|C'∩T|=0` は 43 なので `N₀ = 43 − 8 − 5 = 30`。

## 5. 検証：総数の一致

```
30 + 56 + 43 = 129 = b − 1 = 130 − 1   ✓
```

**完全に整合。**

## 6. 意義

1. **`|C' ∩ T|` の完全な分解を導出した**（3つの場合すべて）。
2. **`|C'∩T|=2` が `6q`** という閉形式を得た。
3. **`|C'∩T|=1` が `4(q−1) + 4(s−4)q`** という閉形式を得た。
4. **`|C'∩T|=0` の分解**（接する + 2点交差 + 交わらない）を明示。
5. **総数が `b−1` に一致**することで検証した。

## 7. 次の段階

`v2`, `v3`, `u3` は「`|C'∩T|` の条件」＋「`|C'∩X|` の条件」で定義される。
上記の分解と `X` 側の同様の分解を組み合わせれば閉形式が得られる。

**`X` 側**：`|C'∩X|` の分布は実測で `{0:42, 1:56, 2:30, 4:1}`（q=5）。
`4` が1個あるのは `X` が共円な場合（`z4`/`u4`/`v4` に対応）。
