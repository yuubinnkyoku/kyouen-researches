# k=7 の q=7：固定 C の数え上げは対称でない（真の原因）

2026-11-20。`finite-field-kyouen-20261120` の第171部。

前項で「6点以上の円」を疑ったが、それは誤りだった。本項は**真の原因**を
特定する。

## 1. 6点以上の円は存在しない（前項の訂正）

`S = T ∪ {x,y,z}`（`|T| = 4`、`T ⊂ C`、`x,y,z ∉ C`）に対し、
`C' ≠ C` は `C` と高々2点で交わるので

```
|C' ∩ S| = |C' ∩ T| + |C' ∩ {x,y,z}| ≤ 2 + 3 = 5
```

**`C` 以外の円は5点までしか取れない。** `C` 自身は `T` の4点のみ
（`x,y,z` は `C` の外）。よって**6点・7点の円は存在しない。**

**前項の「6点以上の円」という診断は誤りだった。**

## 2. 真の原因：固定 `C` の数え上げが対称でない

恒等式を検証した：

```
LHS: b × (固定 C でのタプル数) = 350 × 803,600 = 281,260,000
RHS: Σ_S (S の4円の個数)      = 298,550,000
```

**一致しない。差は 17,290,000。**

**`b` を掛けるのは誤り。** 固定 `C = P¹(F_q)` でのタプル数は、
他の円 `C'` でのタプル数と**等しくない**。

## 3. なぜ対称でないか

`C = P¹(F_q)` は「`0, 1, ∞` を通る円」という特別な円である。
`PGL(2, F_{q²})` は円全体に推移的に作用するので、**円の種類としては**
すべて等価である。

しかし**タプル数は `C` の「外の点の配置」に依存する**。
`C` の外の点は `n − s` 個で、これは `C` によらない。よって
`C(n−s, 3)` も `C` によらない。

**では何が違うのか**：`T` の選び方は `C(s,4)` で `C` によらない。
`{x,y,z}` の選び方も `C(n−s,3)` で `C` によらない。

**よってタプル数は `C` によらないはずである。** それなのに恒等式が
成り立たないのは、**RHS の計算が「4円の個数」を正しく数えていない**
からである。

## 4. RHS の再検討

RHS は「各7点集合 `S` について、`S` の4円の個数を足す」。
LHS は「各円 `C` について、`C` を4円として持つ `S` の個数を足す」。

**この2つは等しいはずである**（同じ組を2通りに数えている）。

差が出るのは、**LHS が「`C` を4円として持つ `S`」を正しく数えていない**
から。固定 `C` でのタプルは `(T, {x,y,z})` であり、`T` は `C` の
4点部分集合、`{x,y,z}` は `C` の外の3点。`S = T ∪ {x,y,z}` は
`C` を4円として持つ。

**しかし `S` が `C` 以外にも4円を持つ場合、`S` は複数の `(T,{x,y,z})`
で数えられる。** 固定 `C` のタプル数は「`C` を4円として持つ `S` の
個数」ではなく「`(T,{x,y,z})` の個数」である。

`T = C ∩ S` は `S` から一意に決まるので、`S` と `T` は1対1。
よって固定 `C` のタプル数 = 「`C` を4円として持つ `S` の個数」。

**ならば LHS = RHS のはず。** 計算を再確認する必要がある。
