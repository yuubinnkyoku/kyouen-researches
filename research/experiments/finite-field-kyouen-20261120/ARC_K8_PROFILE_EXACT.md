## 3. 組み立てロジックの候補

### 3.1 `|C ∩ S| > 4` の多重カウント

タプルループは `T`（`C` の4点部分集合）を固定する。
`|C ∩ S| = j > 4` の `S` は、`C ∩ S` の4点部分集合 `T` が `C(j,4)` 通り
あるので、**`C(j,4)` 回現れる**。

**正しい除数は `n4 × C(j,4)`** であり、`n4` だけでは**過大カウント**。

**しかし符号が合わない**：過大カウント → bad 過大 → arcs 過小。
観測は arcs 過大（784,000 vs 0）。

### 3.2 `(7,)` と `(8,)` の二重カウント

`(7,)` の `S` は `|C ∩ S| = 7`（`C` がその円）なので、タプルループでも
`C(7,4) = 35` 回現れる。**別項として加えると二重カウント。**

**これも過大カウント → 符号が合わない。**

### 3.3 符号の再確認

```
組み立て bad = 536,094,650
真の bad     = 536,878,650
```

**組み立ての bad が 784,000 少ない。**

**過大カウントの候補（3.1, 3.2）はすべて逆方向。**

**よって「過少カウント」の機序が必要。**

### 3.4 過少カウントの候補

**`|C ∩ S| < 4` の `S` はタプルループで生成されない。**
しかし `b` 倍で全円を足すので、`S` の4円 `D` について `|D ∩ S| = 4`
（4円の定義）なので、`D` を `C` とすれば `S` は生成される。

**よって過少カウントは起きないはず。**

**矛盾が残る。**

## 4. 意義

1. **プロファイル公式が q=7 の全数で完全に正しい**ことを確定した
   （7,835,100/7,835,100）。
2. **これで候補は組み立てロジックのみ**に絞られた。
3. **しかし符号の矛盾が残る**（過大カウント候補しかないのに、
   観測は過少カウント）。
4. **矛盾の解決には組み立ての再実装が必要**。
