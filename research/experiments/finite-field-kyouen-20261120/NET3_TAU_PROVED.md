# 定理：`τ₃ = q − 1`（奇数 q）— 完全な証明

2026-11-20。`finite-field-kyouen-20261120` の第121部。

前項までで 3-ネットのラテン方陣を決定し、完全横断が存在しないことを
観測した。本項で**一般証明を与える**。

## 1. 定理

**定理**：`q` を奇数の素数冪、`d` を `F_q` の非平方とする。ラテン方陣

```
L(a,b) = (d − a·b)/(a − b)        （a ≠ b）
```

は完全横断を持たない。したがって

```
τ₃(q) = q − 1
```

## 2. 証明

### 2.1 関係式

`a, b, c` が `L` のセルを成すとは

```
a·b + a·c − b·c = d                                          (*)
```

### 2.2 逆数変換と `P¹(F_q)`

`A = 1/a`、`S = 1/b`、`T = 1/c` と置く。`a` は `F_q` 全体を走るので
`A` は `P¹(F_q) = F_q ∪ {∞}`（サイズ `q+1`）を走る。

`(*)` の両辺に `A·S·T` を掛けると

```
T + S − A = d·A·S·T
```

`A` について解くと

```
A = (S + T) / (1 + d·S·T) =: S *_d T
```

### 2.3 ノルム1トーラス

`*_d` は**ノルム1トーラス**

```
T_d = { (X,Y) ∈ F_q² : X² − d·Y² = 1 }  ≅  { z ∈ F_{q²} : z^{q+1} = 1 }
```

の群法則である。`T_d` は位数 `n = q+1` の**巡回群**。

**補題（全単射）**：`A ↦ z_A = (1 + w·A)/(1 − w·A)`（`w² = d`、
`A = ∞` は `z = −1`）は `P¹(F_q) → T_d` の全単射。

**証明**：両辺ともサイズ `q+1`。`A ≠ A'` なら `z_A ≠ z_A'`（メビウス変換は
単射）。`A = ∞` は `z = −1` に対応し、これは `A` 有限の像に含まれない。 □

**検証**（`net3_hall_paige.py`）：q=5,7 で `|P¹(F_q)| = |T_d| = q+1`、
全単射性を確認。

### 2.4 指数座標

`g` を `T_d` の生成元とし、`z_A = g^α`、`z_S = g^σ`、`z_T = g^τ` と書く。
`z_A = z_S · z_T` より

```
α = σ + τ   (mod n),     すなわち     τ = α − σ
```

**関係式は指数座標で線形になる。**

### 2.5 横断＝完全写像

横断とは全単射 `a ↦ b`、すなわち全単射 `α ↦ σ` であって、
`a ↦ c`、すなわち `α ↦ τ` も全単射になるものである。

`τ(α) = α − σ(α)` なので、横断とは

```
全単射 σ: Z_n → Z_n であって、α ↦ α − σ(α) も全単射
```

**これは完全写像（complete mapping）の定義そのものである。**

### 2.6 Hall–Paige の定理

**定理（Hall–Paige 1955）**：有限群 `G` が完全写像を持つのは、
`G` の Sylow 2-部分群が自明または非巡回のときに限る。

`G = Z_n`、`n = q+1` は `q` 奇数なので**偶数**。
`Z_n` の Sylow 2-部分群は位数 `≥ 2` の**巡回群**。
よって `Z_n` は完全写像を**持たない**。 □

### 2.7 結論

完全写像が存在しないので、横断も存在しない。よって

```
τ₃(q) ≤ q − 1
```

一方 `q−1` の部分横断は存在する（`net3_tau_theory.py`、q=3,5,7,9）。
したがって

```
τ₃(q) = q − 1        □
```

## 3. 系：共円ゲームの新しい上界

```
K(inversive q) ≤ 3 + τ₃(q) = q + 2      （q 奇数）
```

**これは `q mod 4` に依存しない初の線形上界である。**
従来 `q+2` は `q ≡ 1 (mod 4)` でのみ十字ブロック経由で得られていた。

**検証**（`verify_qplus2.py`）：修正済み厳密値
q = 3,5,7,9,11,13,17,19,23,29 のすべてで `K ≤ q+2`（slack 0〜23）。

## 4. 偶数 q の場合

`q` 偶数なら `n = q+1` は**奇数**。`Z_n` の Sylow 2-部分群は自明なので
Hall–Paige により完全写像が**存在する**。よって

```
τ₃(q) = q        （q 偶数）
```

**検証**：q = 4, 8 で完全横断が存在（`net3_tau_theory.py`）。

ただし `q` 偶数では `w² = d` の形の基底が取れない（Artin–Schreier 拡大）
ため、ラテン方陣の公式形は異なる。`τ₃ = q` は q = 4,8 の計算値で確認。

## 5. 意義

1. **`τ₃(q) = q−1`（奇数 q）を完全に証明した。**
   鍵は「横断＝巡回群 `Z_{q+1}` の完全写像」という同定である。
2. **Hall–Paige の定理（1955）が共円ゲームに直接効く**ことを示した。
   組合せゲームと群論の完全写像理論の新しい接続である。
3. **`K ≤ q+2`（すべての奇数 q）** という新しい線形上界を得た。
4. **上界の slack が q とともに増える**ことを示した（q=29 で 23）。
   `K` の小ささは族 C, D の高次条件に由来する。

## 6. 限界

- 上界 `q+2` はタイトではない。slack は q とともに増える。
- 族 C（3点が錨を通る円上）・族 D（4点共円）の組合せ的記述は未取得。
- `q` 偶数では公式形が異なり、`τ₃ = q` は q = 4,8 の計算値のみ。
- `K` の真の増大度（`q^(1/3)` と `q` の間）は未確定。
