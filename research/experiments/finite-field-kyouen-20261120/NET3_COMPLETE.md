# 反転平面の共円ゲーム：3-ネット理論の完成

2026-11-20。`finite-field-kyouen-20261120` の第122部（総括）。

反転平面の共円ゲームを 3-ネットに翻訳し、その構造を完全に決定した。
本項は一連の結果（第118〜121部）を1つにまとめる。

## 1. 出発点：交差比

`P¹(F_{q²})` の4点が共円 ⟺ 射影的交差比が `P¹(F_q)` に入る。

同次座標で `[z_i,z_j] = u_i v_j − u_j v_i`、
交差比 `= [z₁,z₃][z₂,z₄] / ([z₁,z₄][z₂,z₃])`。

**全数検証**（q = 3,4,5,7、計 247,840 個の4点組、不一致 **0**）。

**注意**：`∞` を含む場合は同次座標が必須。非斉次な極限で書くと
q=3 で 72/210 が不一致になる（実際に一度失敗した）。

## 2. 正規化と4つの族

`PGL(2,F_{q²})` の3重推移性により `S = {0,1,∞} ∪ T`、`T ⊂ F_{q²}\F_q`。

| 族 | 形 | 条件 |
|---|---|---|
| A | `{0,1,∞,z}` | `z ∉ F_q` なら自動 |
| B | `{a,b,z,z'}`（`a,b ∈ {0,1,∞}`） | `T` 内の2点条件 |
| C | `{a,z,z',z''}`（`a ∈ {0,1,∞}`） | `T` 内の3点条件 |
| D | `{z,z',z'',z'''}` | `T` 内の4点条件 |

幾何的には「円が `{0,1,∞}` と何点で交わるか」で分類される。

| 円 | 個数（q=7） | 族 |
|---|---:|---|
| 3点（`P¹(F_q)` 自身） | 1 | — |
| 2点 | 21 = `q(q+1)/2` | B |
| 1点 | 123 | C |
| 0点 | 205 | D |

## 3. 族 B は 3-ネットである

`F_{q²}\F_q`（`q²−q` 点）の3つの分割：

```
P₀   : 0 を通る F_q-直線
P₁   : 1 を通る F_q-直線
P_∞  : φ(z) = z/(1−z) による P₀ の引き戻し
```

各分割は **q クラス × サイズ q−1**（q = 3,4,5,7,8,9 で機械確認）。
族 B の条件は「`T` がこの 3-ネットの部分横断」と同値。

## 4. ラテン方陣の完全公式（定理）

`q` 奇数、`F_{q²} = F_q[w]`、`w² = d`（`d` 非平方）。`u = x + y·w` に対し

```
a = x/y,   b = (x−1)/y,   c = φ(u) の方向
```

**定理**：`a ≠ b` のとき

```
c = (d − a·b) / (a − b)
```

**証明**：`x = a/(a−b)`、`y = 1/(a−b)` を `c = [x(1−x) + d·y²]/y` に代入。 □

**検証**：q = 3,5,7,9 で全セル一致（6/6, 20/20, 42/42, 72/72）。

**系**：対角線 `a = b` は空。関係式は `ab + ac − bc = d` と同値で
`b ↔ c` 対称。

## 5. ノルム1トーラス（定理）

`A = 1/a`、`S = 1/b`、`T = 1/c` と置くと関係式は

```
A = (S + T) / (1 + d·S·T) =: S *_d T
```

**これはノルム1トーラス**

```
T_d = { (X,Y) ∈ F_q² : X² − d·Y² = 1 }  ≅  { z ∈ F_{q²} : z^{q+1} = 1 }
```

（位数 `n = q+1` の巡回群）の群法則である。

**補題（全単射）**：`A ↦ (A + w)/(A − w)` は `P¹(F_q) → T_d` の全単射。

**注意**：`(1 + w·A)/(1 − w·A)` は**誤り**（加法関係が 2/20 しか成立しない）。
正しいのは `(A + w)/(A − w)`。

## 6. ラテン方陣は `Z_{q+1}` の加法表である（定理）

`α(A)` を `(A + w)/(A − w)` の `T_d` における指数とすると

```
α: P¹(F_q) → Z_{q+1}   は全単射
```

であり、全セルで

```
α(1/a) = α(1/b) + α(1/c)   (mod q+1)
```

**検証**：q=5 で 20/20、q=7 で 42/42。

**つまり 3-ネットは巡回群 `Z_{q+1}` の加法表そのものである。**

## 7. `τ₃ = q−1` の証明（主定理）

**定理**：`q` 奇数なら `τ₃(q) = q − 1`。

**証明**：

1. 横断とは全単射 `a ↦ b` で `a ↦ c` も全単射になるもの。
2. §6 より指数座標で関係式は `γ = α − β (mod n)`。
3. よって横断とは「全単射 `σ: Z_n → Z_n` であって `α ↦ α − σ(α)` も
   全単射」、すなわち **`Z_n` の完全写像**。
4. **Hall–Paige の定理（1955）**：有限群 `G` が完全写像を持つのは
   Sylow 2-部分群が自明または非巡回のときに限る。
5. `q` 奇数なら `n = q+1` は偶数。`Z_n` の Sylow 2-部分群は位数 `≥2` の
   巡回群なので完全写像は**存在しない**。
6. よって `τ₃ ≤ q−1`。`q−1` の部分横断は存在するので `τ₃ = q−1`。 □

**偶数 q**：`n = q+1` は奇数なので Sylow 2-部分群は自明、完全写像が存在し
`τ₃ = q`（q = 4,8 で確認）。

## 8. 系：新しい上界

```
K(inversive q) ≤ 3 + τ₃(q) = q + 2      （q 奇数）
                            = q + 3      （q 偶数）
```

**奇数の `q+2` は新しい。** 従来 `q+2` は `q ≡ 1 (mod 4)` でのみ
十字ブロック経由で得られていた。3-ネット経由の議論は `q mod 4` に依存しない。

**slack は q とともに単調に増える。** 上界はタイトではない。

## 10. 意義

1. **共円ゲームを巡回群の完全写像問題に帰着させた。**
   組合せゲームと群論（Hall–Paige 1955）の新しい接続である。
2. **`τ₃(q) = q−1`（奇数 q）を証明した。**
3. **`K ≤ q+2`（すべての奇数 q）** という新しい線形上界を得た。
4. **3-ネットのラテン方陣が `Z_{q+1}` の加法表である**ことを示した。
5. **`K` と `q+2` のギャップの正体**を族 C, D の高次条件と特定した。

## 11. 限界

- 上界 `q+2` はタイトではない（slack は q とともに増える）。
- 族 C, D の組合せ的記述は未取得（交差比で直接判定している）。
- `K` の真の増大度は `q^(1/3)` と `q` の間で未確定。
- `q` 偶数では `w² = d` の形の基底が取れず、公式形が異なる。
  `τ₃ = q` は q = 4,8 の計算値のみ。
- q ≥ 13 の `K` は 3-ネット探索では計算時間が大きすぎる
  （q=11 で 2,404 秒、指数的に増加）。
