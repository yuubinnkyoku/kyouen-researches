# k=7 の `(5,)` の閉形式：k=6 の機構で完全に閉じた

2026-11-20。`finite-field-kyouen-20261120` の第178部。

前項まで `(5,)` は「条件付きで数値のみ」だった。本項は**閉形式を与える。**

## 1. 鍵となる気づき

`(5,)` の条件は「`{x,y}` を通るペンシル円が `T5` と2点で交わらない」。

ペンシルは `C` 上の**対合** `ι(x,y)` を定め、円が `T5` と2点で交わるのは
**`ι` の対が `T5` に完全に入る**とき。

**よって条件はちょうど `j({x,y}) = 0`**（`j` は k=6 のペンシル量）。

## 2. 定理

```
(5,) = b · Σ_{n₂} N_xy(n₂) · H(n₂, n₁, 0, 5)
```

ここで `n₁ = s − 2n₂`、`N_xy` と `H` は k=6 の閉形式：

```
N_xy(n₂):  q 奇数 → (q²−1)·C(q,2)/2 個が n₂ = (q+1)/2 − 1、残りが (q+1)/2
           q 偶数 → C(q,2) 個が n₂ = 0、残りが q/2

H(n₂,n₁,j,k) = Σ_a C(n₂,j)·C(n₂−j,a)·2^a·C(n₁, k−2j−a)
```

## 3. 検証

| q | `N_xy` | `H(·,·,0,5)` | 公式 | 実測 | 一致 |
|---:|---|---|---:|---:|---|
| 5 | `{2:120, 3:70}` | `(2,2,0), (3,0,0)` | **0** | 0 | ✓ |
| 7 | `{3:504, 4:357}` | `(3,2,8), (4,0,0)` | **1,411,200** | 1,411,200 | ✓ |
| 8 | `{0:28, 4:1512}` | — | **14,414,400** | 14,414,400 | ✓ |

**3/3 完全一致。**

## 4. なぜ q=5 で 0 になるか

q=5 では `n₂ = 2`（`n₁ = 2`）と `n₂ = 3`（`n₁ = 0`）の2種類。
`H(n₂, n₁, 0, 5)` は「5点部分集合が対を1つも完全に含まない」数：

- `n₂=2, n₁=2`：`H = 0`（5点を選ぶと必ず対が1つ入る）
- `n₂=3, n₁=0`：`H = 0`（`n₁=0` で5点は選べない）

**よって `(5,) = 0`。** これは `s = 6` という特殊事情である。

q=7 では `n₂=3, n₁=2` で `H = 8`（8通りの5点部分集合が対を含まない）
→ `504 × 8 × 350 = 1,411,200`。

## 5. 意義

1. **`(5,)` の閉形式を確立した**（k=6 の `N_xy` と `H` で書ける）。
2. **3つの q（5,7,8）で完全一致。**
3. **k=7 のすべてのプロファイルが閉形式になった。**
4. **k=6 と k=7 が同じ機構（ペンシルの対合）で統一された。**

## 6. k=7 の完全な閉形式（完成）

```
(7,) = b·C(s,7)
(6,) = b·C(s,6)·(n−s)
(5,) = b·Σ_{n₂} N_xy(n₂)·H(n₂,n₁,0,5)
(5,4), (5,4,4), (4,), (4,4), (4,4,4), (4,4,4,4), (4,4,4,4,4), (4,4,4,4,4,4)
     = タプル数 / (4の個数) × b
```

**検証**：q=5 で 657,800、q=7 で 99,884,400、q=8 で 696,190,560
（すべて全数と一致、q=8 は文献値とも一致）。
