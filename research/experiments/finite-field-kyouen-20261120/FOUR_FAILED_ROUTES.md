# q ≡ 3 (mod 4) の上界改善：4つの手法の失敗と現状

2026-11-20。`finite-field-kyouen-20261120` の第57部。
`q ≡ 3 (mod 4)` の上界改善を4つの原理で試み、いずれも失敗した記録。

## 1. 試した4つの手法

### (1) 次数による議論

点 `p` を通るブロックを `S` の点数で分類すると

```
(k−1)(q + 2 − k/2) ≤ q² + q
```

**結果**：`deg = q²+q` が大きいため、すべての q で制約がかからない（`k ≤ 2q+4` 程度）。

### (2) 複数ペンシル

`m` 点を固定して `C(m,2)` 個のペンシルを使う。

**結果**：包除の補正項と必要量が打ち消し合い、上界は `λ₂ + 2` のまま `m` に依らない（m=3..8 で確認）。

### (3) 被覆（円を含む部分集合の数）

ランダムな k-部分集合に含まれるブロックの期待値 `E[f]` を計算。

**結果**：`E[f] = 1` となるのは q=3 で k≈6、q=5 で k=9、q=7 で k≈25。真値（q=5,7 で K=6）と大きく乖離。q=3 のみ有効。

### (4) 使用済み円のペア

使用済み円（`S` の3点を含む円）のペアが共有する `S` の点数を数える。

```
C(k,2)·C(k−2,2) ≤ 2·C(C(k,3), 2)
```

左辺 `k(k−1)(k−2)(k−3)/4`、右辺 `C(k,3)(C(k,3)−1)`。

**結果**：すべての `k ≥ 4` で成立するため、制約がかからない。

| k | 左辺 | 右辺 | 成立 |
|---:|---:|---:|---|
| 6 | 90 | 380 | ✓ |
| 10 | 1,260 | 14,280 | ✓ |
| 12 | 2,970 | 48,180 | ✓ |

## 2. 共通する構造

4つの手法はいずれも「**ブロックの総数や次数が大きい**」ために制約が緩む。

- ブロック数 `b = q³+q` は `C(q²,k)` に比べて小さい
- 次数 `deg = q²+q` は `k` に比べて大きい
- 円の数 `q²(q−1)` は多い

**初等的な数え上げはすべて `O(q)` で係数 ≥ 1 を与え、観測された `K/q ≈ 0.68〜0.86` を下回れない。**

## 3. 唯一成功した手法

`λ₂` による上界 `k ≤ q+3` だけが係数1を達成した。これは「**1組のペアのペンシルが `k−2` 個の異なるブロックを必要とする**」という局所的な議論で、`λ₂ = q+1` という小さな量を使うため鋭い。

しかしこの手法は複数ペアに拡張しても改善しない（上記 (2)）。

## 4. 現状のまとめ

| 手法 | 上界 | 係数 | 有効性 |
|---|---|---:|---|
| triple | `C(k,3) ≤ q³+q` | 1.82 | 常に |
| 次数 | `(k−1)(q+2−k/2) ≤ q²+q` | ~2 | 制約なし |
| **λ₂** | **`k ≤ q+3`** | **1** | **常に（最良）** |
| 複数ペンシル | `k ≤ q+3` | 1 | 改善なし |
| 被覆 | — | — | q=3 のみ |
| 円ペア | — | — | 制約なし |
| 十字 | `k ≤ q+2` | 1 | `q ≡ 1 (mod 4)` のみ |

## 5. 改善への示唆

係数を1未満にするには、初等的な数え上げとは別の原理が必要と考えられる。候補：

- **代数幾何**：円の方程式の構造（`x²+y²+Dx+Ey+F=0`）を使った評価
- **設計論**：3-設計のパラメータ間の関係式
- **加法的組合せ論**：`F_q²` の加法構造と円の関係

いずれも未着手である。

## 6. 限界

- 「係数1未満は不可能」という証明ではない。
