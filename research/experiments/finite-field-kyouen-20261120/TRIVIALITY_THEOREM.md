# 定理：極大集合が一様なら Grundy 値は (T−|S|) mod 2

2026-11-20。`finite-field-kyouen-20261120` の第95部。
ゲームの「自明性」を特徴づける構造定理を発見し、全数検証した。

## 1. 定理

盤の**すべての極大安全集合が同じサイズ `T`** を持つとき、任意の安全局面 `S` について

```
g(S) = (T − |S|) mod 2
```

## 2. 証明

`S` からの任意の完全プレイは、極大集合に到達するまで続く。
すべての極大集合がサイズ `T` なので、`S` からのプレイ長は常に `T − |S|`。

したがって `S` からのゲーム木は**一様深さの木**である。`d = T − |S|` について帰納する。

- `d = 0`：合法手なし。`g = 0 = d mod 2`。
- 深さ `d`：すべての子は深さ `d−1` で、帰納法により Grundy 値は `(d−1) mod 2` の一値。
  mex は `{ (d−1) mod 2 }` の mex なので `d mod 2`。□

## 3. 系

- 極大集合が一様な盤では、**すべての Grundy 値が 0 か 1**。
- 逆に、極大集合が非一様なら、どこかで非自明な Grundy 値が現れうる。

## 4. 全数検証

| 盤 | 極大集合のサイズ分布 | 一様か | Grundy 分布 | 定理 |
|---|---|---|---|---|
| 反転平面 q=3 | {5: 72} | **✓** | {0:202, 1:226} | ✓ |
| 反転平面 q=4 | {5: 2040} | **✓** | {0:2737, 1:2177} | ✓ |
| 反転平面 q=5 | {5:10400, 6:5200} | ✗ | {0:18226, 1:17226, **2**:11700} | — |
| AG(2,3) | {5: 36} | **✓** | {0:129, 1:145} | ✓ |

| 3×3 整数 | {5: 56} | **✓** | {0:149, 1:149} | ✓ |

**一様な4盤すべてで定理が成立**（全局面で照合、不一致 0）。

## 5. 決定的な相関

| 盤 | 一様か | 最大 Grundy |
|---|---|---|
| 反転平面 q=3 | ✓ | **1** |
| 反転平面 q=4 | ✓ | **1** |
| AG(2,3) | ✓ | **1** |
| 3×3 整数 | ✓ | **1** |
| 反転平面 q=5 | ✗ | **2** |
| AG(2,5) | ✗ | **2** |
| 4×4 整数 | ✗ | **5** |
| 5×5 整数 | ✗ | **6** |

**一様な盤は最大 Grundy が 1、非一様な盤は 2 以上。**

## 6. 意義

この定理は、**ゲーム理論（Grundy 値）と組合せ論（極大集合の一様性）を結びつける**。

これまで「なぜ反転平面 q=3,4 は Grundy 値が 0/1 だけなのか」は観測に過ぎなかったが、
この定理が理由を与える：極大集合が一様だから。

また、**非自明な Grundy 値（2 以上）の出現は極大集合の非一様性を必要とする**。
これは Grundy 値の上限を調べる新しい切り口である。

## 7. 限界

- 逆は成り立たない：非一様でも最大 Grundy が 1 の盤がありうる（未検証）。
- 一様性の判定は全安全局面の列挙を要するので、大きな盤では使えない。
- 「極大集合が一様」を幾何から直接判定する方法は未取得。
