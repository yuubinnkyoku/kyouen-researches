# 補題 F2 の証明：gamma = −2·Area

2026-11-20。`finite-field-kyouen-20261120` の第20部。
連続緩和の上界証明で使う補題 `|gamma| ≤ a²` を厳密に証明する。

## 1. 主張

三点 `p1,p2,p3` を `[0,a]²` 内の格子点とする。4×4 行列式

```
Delta(x,y) = det[[x1,y1,x1²+y1²,1],
                [x2,y2,x2²+y2²,1],
                [x3,y3,x3²+y3²,1],
                [x, y, x²+y²,  1]]
```

を最終行について展開したときの `x²+y²` の係数を `gamma` とすると

```
gamma = −2 · Area(p1,p2,p3)
```

（`Area` は符号付き面積）。特に `|gamma| ≤ a²`。

## 2. 証明

最終行 `r = (x, y, x²+y², 1)` についての余因子展開で、`x²+y²` は第3列（添字2）にある。
その係数は

```
gamma = (−1)^(3+2) · det[[x1,y1,1],[x2,y2,1],[x3,y3,1]]
      = − det[[x1,y1,1],[x2,y2,1],[x3,y3,1]]
```

3×3 行列式 `det[[x_i,y_i,1]]` は三点の符号付き面積の2倍に等しい（標準的な事実：
第3列について展開すると `(x2−x1)(y3−y1) − (x3−x1)(y2−y1)` が現れる）。
したがって `gamma = −2·Area`。□

## 3. 系：|gamma| ≤ a²

三点は `[0,a]²` 内にあるので、三角形の面積は正方形の面積 `a²` の半分以下：

```
Area ≤ a²/2
```

よって

```
|gamma| = 2·Area ≤ a²  □
```

## 4. 数値検証

a = 2..6 の全三点（計 28,508 組）で `gamma = −2·Area` を確認した（不一致 0）。

| a | 三点の数 | 不一致 | max\|gamma\| | max\|2·Area\| | ≤ a² |
|---:|---:|---:|---:|---:|---|
| 2 | 120 | 0 | 4 | 4 | ✓ |
| 3 | 560 | 0 | 9 | 9 | ✓ |
| 4 | 1,820 | 0 | 16 | 16 | ✓ |
| 5 | 4,960 | 0 | 25 | 25 | ✓ |
| 6 | 11,480 | 0 | 36 | 36 | ✓ |

## 5. 意義

この補題により、連続緩和の上界証明は次の形に整理できる：

```
|Delta| = |gamma| · |power| ≤ a² · |power|
```

残る課題は `|power|` の評価だが、単純な `|power| ≤ a²/2` は**偽**である
（[DET_PROOF_STEPS.md](DET_PROOF_STEPS.md) §2）。`gamma` が小さいとき `power` は大きくなり、
両者は逆相関する。したがって `a² · |power|` という粗い評価では足りず、
`|gamma|` と `|power|` の積を直接評価する必要がある。

## 6. 限界

- 補題 F2 自体は証明済み（上記 §2）。
- しかし F2 だけでは連続上界は出ない。`|power|` の評価が未解決。
- 数値検証は a ≤ 6 の全数。証明は任意の a で有効。
