# k=8 の単一円プロファイル：q=5 で 0 件を高速列挙で確認

2026-11-20。`finite-field-kyouen-20261120` の第221部。

単一円プロファイルを**高速列挙**で測定する手法を実装し、q=5 で
0 件であることを確認した。

## 1. 高速化の要点

単一円プロファイル `(j,)` は「8点のうち `j` 点が1つの円 `D` 上にあり、
他の4円を持たない」もの。

**素朴な方法**：`(D, j点, 8−j点)` を列挙し、各 `S` について
`C(8,4) = 70` 個の4点部分集合を調べる。**遅い。**

**高速化**：他の4円 `C'` は `D` と高々2点で交わるので、
`C'` は `D` 上の `j` 点から2点、外点から2点を取る必要がある。
**よって外点の2点を通るペンシル円だけを調べればよい。**

```
for yp in C(Y, 2):
    for ck in ペンシル(yp):
        if ck != D and |Tj ∩ ck| == 2: → 他の4円あり
```

## 2. 結果（q=5）

```
n=26, b=130, s=6

```

**q=5 では単一円プロファイルは1つも存在しない。**

これは前項（第218部）の全数探索の結果と一致する。
