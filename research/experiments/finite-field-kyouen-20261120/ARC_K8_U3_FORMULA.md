# k=8 の `u3+u4` の閉形式

2026-11-20。`finite-field-kyouen-20261120` の第209部。

k=8 の最後の類 `u3` の閉形式を導出した。

## 1. 測定値（q=5）

| 量 | 値 |
|---|---:|
| `sum u3` | 74,400 |
| `sum u4` | 1,800 |
| **`sum u3+u4`** | **76,200** |

## 2. 分解

`sum(u3+u4)` は「`|C'∩T|=1` かつ `|C'∩X|≥3`」の三つ組を数える。

`|C'∩T| = 1` の円は2つの族に分かれる：

| `\|C'∩C\|` | 意味 | 個数 | `\|Y\|` |
|---:|---|---:|---:|
| 1 | `C` に接する | `s(q−1)` | `s−1 = q` |
| 2 | `C` と2点で交わる | `C(s,2)·q` | `s−2 = q−1` |

**固定した `C'` に対し `T` の選び方**：

- `|C'∩C| = 1`：`T` はその1点を含む → `C(s−1,3)` 通り
- `|C'∩C| = 2`：`T` は2点のうち**ちょうど1点**を含む → `2·C(s−2,3)` 通り

**`X` の選び方**：`|Y∩X| ≥ 3`。

## 3. 検証（q=5）

**`(|C'∩C|, |Y|)` の分布**：

```
(1, 5): 24 個
(2, 4): 75 個
```

**計算**：

```
sum(u3+u4) = Σ_{C'} (#T with |C'∩T|=1) × (#X with |Y∩X|≥3)
           = 76,200
```

**実測 76,200 と完全一致。**

## 4. 構造的事実

**`|Y| = s − |C'∩C|`**：

- `|C'∩C| = 1` → `|Y| = s−1 = q`
- `|C'∩C| = 2` → `|Y| = s−2 = q−1`

**これは `C'` のサイズが `s` であることから直ちに従う。**

## 5. 定理（完成形）

```
sum(u3+u4) = s(q−1) · C(s−1,3) · G(q, n−s)
           + C(s,2)·q · 2·C(s−2,3) · G(q−1, n−s)
```

ここで

```
G(y, m) = #{X ⊂ 外点, |X|=4 : |Y∩X| ≥ 3}
        = C(y,3)·C(m−y,1) + C(y,4)
```

（`|Y∩X| = 3` または `4`。）

**検証（q=5）**：

```
G(5,20) = C(5,3)·C(15,1) + C(5,4) = 10·15 + 5 = 155
G(4,20) = C(4,3)·C(16,1) + C(4,4) = 4·16 + 1 = 65

sum = 6·4 · C(5,3) · 155 + C(6,2)·5 · 2·C(4,3) · 65
    = 24 · 10 · 155 + 75 · 2·4 · 65
    = 37,200 + 39,000
    = 76,200   ✓
```

## 6. 意義

1. **`sum(u3+u4)` の閉形式を導出した**（q=5 で完全一致）。
2. **`|Y| = s − |C'∩C|`** という構造的事実を確認。
3. **`G(y,m)` の閉形式**（`C(y,3)C(m−y,1) + C(y,4)`）を得た。
4. **`u4` は既知**（共円性）なので、これで `u3` が求まる。
5. **k=8 の6類すべての和が閉形式になった**（`v2+v3` と `u3` は
   分離が残る）。
