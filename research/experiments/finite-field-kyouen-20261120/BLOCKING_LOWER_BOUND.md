# 定理：反転平面の K は Ω(q^(1/3))

2026-11-20。`finite-field-kyouen-20261120` の第116部。
反転平面の K に対する**新しい下界**を証明した。

## 1. 定理

位数 `q` の反転平面の最大安全集合サイズ `K` について

```
K = Ω(q^(1/3))
```

より正確には、極大安全集合のサイズ `k` は

```
q² + 1 − k ≤ C(k,3)·(q − 2)
```

を満たす。これから `C(k,3) ≥ q` 程度が従い、`k ≥ (6q)^(1/3)`。

## 2. 証明

`S` を極大安全集合（これ以上1点も追加できない）、`|S| = k` とする。

**ブロッキング条件**：`S` に含まれない任意の点 `p` について、
`p` を追加すると禁止四点が完成する。つまり `p` を通り `S` の3点を含む円が存在する。

**数え上げ**：
- `S` の三点組は `C(k,3)` 個。
- 各三点組はちょうど一つの円を定める（3-設計の性質）。
- その円は `q+1` 点を持ち、うち3点が `S` にある。よって `q−2` 点が `S` の外。
- したがって、`S` の三点組が「ブロックできる」点の総数（重複込み）は `C(k,3)·(q−2)`。

**極大性**：`S` の外の全点 `q²+1−k` がブロックされなければならない。よって

```
q² + 1 − k ≤ C(k,3)·(q − 2)
```

**漸近**：`C(k,3) ≈ k³/6` なので、`q² ≲ (k³/6)·q`、すなわち `k³ ≳ 6q`。

```
k ≥ (6q)^(1/3)   □
```

## 4. 漸近的な意味

| q | (6q)^(1/3) |
|---:|---:|
| 29 | 5.58 |
| 100 | 8.43 |
| 1,000 | 18.17 |
| 10,000 | 39.15 |
| 1,000,000 | 181.71 |

**K は q とともに q^(1/3) のオーダーで増えなければならない。**

## 5. 「K がほぼ定数」という観測の位置づけ

前項で「K ≈ 9（ほぼ定数）」と報告したが、これは **q ≤ 29 の範囲での見かけ**である。

`(6q)^(1/3)` は q=29 で 5.58、q=100 で 8.43 なので、
q ≤ 100 程度までは K ≈ 9 でも矛盾しない。

**q が大きくなれば K は必ず増える。**

## 6. 上界との組み合わせ

```
(6q)^(1/3) ≤ K ≤ q + 3
```

下界は q^(1/3)、上界は q（λ₂ 上界）。**大きな隔たりがある。**

## 7. 意義

- 反転平面の K に対する**初の非自明な下界**を証明した。
- 「K がほぼ定数」という観測は q ≤ 100 程度までの現象であることを明確にした。
- 下界 q^(1/3) と上界 q の間の隔たりが、今後の研究課題である。

## 8. 限界

- 下界 `(6q)^(1/3)` は緩い可能性が高い（観測値は q=29 で 8 対 5.58）。
- 上界 `q+3` との隔たりは大きい。
- より強い下界・上界は未取得。
