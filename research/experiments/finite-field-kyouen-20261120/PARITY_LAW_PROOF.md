# パリティ法則の証明

2026-11-20。`finite-field-kyouen-20261120` の第101部。
前項で発見したパリティ法則の**厳密な証明**を与える。

## 1. 設定

有限の不偏ゲーム：局面は有限集合 `B` の部分集合（安全集合）、
手は1点の追加、終局局面は極大安全集合。`g(S)` を Sprague-Grundy 値とする。

**定義**：局面 `S` に対し `L(S) = { |M| − |S| : M は極大、M ⊇ S }`
（`S` から終局までのプレイ長の集合）。

## 2. 補題1（一様深さ）

`L(S) = {d}`（単元集合）なら `g(S) = d mod 2`。

**証明**：`d` について帰納する。
- `d = 0`：`S` は終局、`g(S) = 0 = 0 mod 2`。
- `d > 0`：任意の子 `S' = S ∪ {p}` について `L(S') = {d−1}`
  （`S'` を極大集合に拡張すると `S` を含む極大集合になり、それらはすべてサイズ `|S|+d`）。
  帰納法により全子で `g(S') = (d−1) mod 2`。よって
  `g(S) = mex{(d−1) mod 2} = d mod 2`。□

## 3. 定理（パリティ法則）

すべての極大集合のサイズが同じ偶奇 `ε` を持つ（`|M| ≡ ε (mod 2)`）とする。このとき

**(a)** すべての局面 `S` について `g(S) ≡ ε − |S| (mod 2)`。
**(b)** すべての局面 `S` について `g(S) ∈ {0, 1}`。

### (a) の証明

より強い命題を示す：

> `(P_d)` `L(S)` の全要素が `d` と mod 2 で合同なら、`g(S) ≡ d (mod 2)`。

まず、極大集合の偶奇が `ε` なので、任意の `S` について
`L(S) = {|M| − |S|}` の全要素は `ε − |S| (mod 2)` に合同。よって `(P_d)` が使える。

`(P_d)` を `max L(S)` について帰納する。

- `L(S) = {0}`：`S` は終局、`g(S) = 0 ≡ 0 (mod 2)`、`d = 0`。
- そうでなければ、各子 `S'` について `L(S')` の全要素は `d−1 (mod 2)` に合同。
  帰納法により全子で `g(S') ≡ d−1 (mod 2)`。

`g(S) = mex{g(S')}`。全 `g(S')` が同じ偶奇 `p = d−1 mod 2` を持つ。
- `p = 0`：集合は偶数のみ。`1` は含まれない。mex は `0` を含めば `1`、含まなければ `0`。
  いずれも `≡ 1 = (p+1) mod 2`。
- `p = 1`：集合は奇数のみ。`0` は含まれない。mex は `0 ≡ 0 = (p+1) mod 2`。

よって `g(S) ≡ (d−1)+1 = d (mod 2)`。□

### (b) の証明

`g(S) ≥ 2` と仮定する。mex が `2` 以上なので、子の値に `0` と `1` が**両方**現れる。

しかし (a) により、すべての子 `S'` は `g(S') ≡ d−1 (mod 2)` を満たす。
つまり全子の Grundy 値は**同じ偶奇**を持つ。

`0` は偶数、`1` は奇数なので、両方が同時に現れることはない。矛盾。

よって `g(S) ≤ 1`。□

## 6. 意義

- **パリティ法則 (a)(b) は証明済み**。
- 前項の「一様性」定理は、偶奇が揃う特別な場合として従う。
- 本質は「一様性」ではなく「**パリティ**」である。
- 逆は観測だが、完全な二分法が成立する。
