# k=8 の `N_cyc`：外点の共円4点の個数（最後のピース）

2026-11-20。`finite-field-kyouen-20261120` の第211部。

k=8 の最後のピース `N_cyc`（外点の共円4点の個数）を導出した。

## 1. 定義

```
N_cyc = #{X : X は外点の4点部分集合で共円}
```

## 2. 定理

```
N_cyc = Σ_{C' ≠ C} C(|C' ∩ 外点|, 4)
```

**理由**：共円な4点は**一意な円**の上にある。よって各円 `C'` が
`C(|C'∩外点|, 4)` 個の共円4点集合を寄与し、**重複しない**。

## 3. 検証（q=5）

**`|C' ∩ 外点|` の分布**：

| `\|C'∩外点\|` | 円の個数 |
|---:|---:|
| 4 | 75 |
| 5 | 24 |
| 6 | 30 |

**計算**：

```
N_cyc = 75·C(4,4) + 24·C(5,4) + 30·C(6,4)
      = 75·1 + 24·5 + 30·15
      = 75 + 120 + 450
      = 645
```

**直接数え上げと完全一致（645）。**

## 4. 分布の意味

| `\|C'∩外点\|` | 円の個数 | 意味 |
|---:|---:|---|
| 4 | 75 | `C` と2点で交わる（`C(s,2)·q = 75`） |
| 5 | 24 | `C` に接する（`s(q−1) = 24`） |
| 6 | 30 | `C` と交わらない（`N₀ = 30`） |

**これは第206部で導出した `|C'∩T|` の分解と整合する**：

- `|C'∩C| = 2` → `|C'∩外点| = s−2 = 4`（75個）
- `|C'∩C| = 1` → `|C'∩外点| = s−1 = 5`（24個）
- `|C'∩C| = 0` → `|C'∩外点| = s = 6`（30個）

**`|C'∩外点| = s − |C'∩C|`** という構造的事実。

## 5. 定理（完成形）

```
N_cyc = C(s,2)·q · C(s−2,4)
      + s(q−1) · C(s−1,4)
      + N₀ · C(s,4)
```

ここで `N₀` は `C` と交わらない円の個数。

**検証（q=5、`s=6`）**：

```
C(6,2)·5 · C(4,4) = 75 · 1  =  75
6·4 · C(5,4)      = 24 · 5  = 120
30 · C(6,4)       = 30 · 15 = 450
合計 = 645   ✓
```

## 6. `N₀` の決定

`N₀` は「`C` と交わらない円」の個数。全円数から他を引く：

```
N₀ = (b − 1) − C(s,2)·q − s(q−1)
```

**検証（q=5）**：`129 − 75 − 24 = 30` ✓

## 7. 意義

1. **`N_cyc` の閉形式を導出した**（q=5 で完全一致）。
2. **`|C'∩外点| = s − |C'∩C|`** という構造的事実を確認。
3. **分布 `{4:75, 5:24, 6:30}` が第206部の分解と整合**することを示した。
4. **k=8 の最後のピースが埋まった** — 6類すべてが閉形式に。
5. **`v4+u4+z4` の和が `N_cyc` から計算できる**。
