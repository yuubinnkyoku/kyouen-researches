# k=8 の `v4`, `u4`, `z4`：互いに排反で共円性と同値

2026-11-20。`finite-field-kyouen-20261120` の第205部。

k=8 の6類のうち `v4`, `u4`, `z4` が**互いに排反**であることを発見した。

## 1. 定理

```
v4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 2
u4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 1
z4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 0
```

ここで `D` は `X` を通る円。

**系**：

```
v4 + u4 + z4 = [X が共円]
```

**3つは互いに排反で、和が共円性の指示関数になる。**

## 2. 理由

`v4`, `u4`, `z4` はいずれも `|C' ∩ X| = 4` を要求する。
**4点は高々1つの円を定める**ので、該当する `C'` は `D` のみ（存在すれば）。

`D` が `T` と交わる点数で3つに分かれる：

| `|D ∩ T|` | 該当する類 |
|---:|---|
| 2 | `v4` |
| 1 | `u4` |
| 0 | `z4` |

**`|D ∩ T|` は 0, 1, 2 のいずれか**（`D ≠ C` なので `T ⊂ C` から
高々2点）。よって3つは排反かつ網羅的。

## 3. 検証（q=5）

**`(共円性, |D ∩ T|)` の分布**：

| 共円 | `\|D ∩ T\|` | 組数 |
|---|---|---:|
| はい | 0 | 7,425 |
| はい | 1 | 1,800 |
| はい | 2 | 450 |
| いいえ | — | 63,000 |
| | | **72,675** ✓ |

**`(v4, u4, z4)` の分布**：

| `(v4,u4,z4)` | 組数 |
|---|---:|
| (0,0,0) | 63,000 |
| (0,0,1) | 7,425 |
| (0,1,0) | 1,800 |
| (1,0,0) | 450 |
| | **72,675** ✓ |

**完全に整合。** 3つが同時に1になる組は**存在しない**。

## 4. 意義

1. **`v4`, `u4`, `z4` が互いに排反**であることを証明した。
2. **`v4 + u4 + z4 = [X が共円]`** という美しい関係を得た。
3. **3つの類が1つの量（共円性）に還元**された。
4. **`v4`, `u4`, `z4` の閉形式は「外点の共円4点の個数」と
   「`D` と `C` の交点数」の分布から一括で書ける**。
5. 残る3類（`v2`, `v3`, `u3`）に集中できるようになった。
