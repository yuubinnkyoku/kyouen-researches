# 一様盤の Grundy 値はサイズの偶奇で完全に決まる

2026-11-20。`finite-field-kyouen-20261120` の第96部。
前項の定理を、Grundy 値と局面サイズの関係として精密化した。

## 1. 一様盤の完全な構造

一様な盤（極大集合がすべてサイズ `T`）では、定理により `g(S) = (T−|S|) mod 2`。
したがって **Grundy 値は局面サイズの偶奇だけで決まる**。

### 反転平面 q=3（T=5）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5 |
| 1 | 0, 2, 4 |

**完全に偶奇で分離**（`T−|S|` が偶数なら g=0、奇数なら g=1）。

### 反転平面 q=4（T=5）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5 |
| 1 | 0, 2, 4 |

同じく完全分離。

### AG(2,3)（T=5）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5 |
| 1 | 0, 2, 4 |

同じく完全分離。

### 3×3 整数（T=5）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5 |
| 1 | 0, 2, 4 |

同じく完全分離。

**4盤すべてで、Grundy 値はサイズの偶奇に完全一致。**

## 2. 非一様盤では分離が崩れる

### 反転平面 q=5（極大サイズ {5,6}）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5, **6** |
| 1 | 0, 2, 4, **5** |
| 2 | **4** |

**サイズ5に g=0 と g=1 が混在**し、サイズ4に g=2 が現れる。

### AG(2,5)（極大サイズ {3,5,6}）

| g | 局面サイズ |
|---:|---|
| 0 | 1, 3, 5, 6 |
| 1 | 0, 2, 4, 5 |
| 2 | 4 |

同じく混在。

### 4×4 整数（極大サイズ {5,6,7}）

| g | 局面サイズ |
|---:|---|
| 0 | 0, 2, 3, 4, 5, 6, 7 |
| 1 | 1, 3, 4, 5, 6 |
| 2 | 2, 3, 4, 5 |
| 3 | 2, 3, 4 |
| 4 | 3 |
| 5 | 2 |

**ほぼ全サイズに複数の Grundy 値が混在。**

## 3. 決定的な観察

**一様盤では「サイズ → Grundy 値」が関数**（各サイズに1つの値）。
**非一様盤では「サイズ → Grundy 値」が多値**（同じサイズに複数の値）。

これは定理の直接の帰結である：一様なら `g = (T−|S|) mod 2` なのでサイズで決まる。
非一様ならサイズだけでは決まらない。

## 4. 意義

- 「Grundy 値がサイズの偶奇で決まる」という性質は、**極大集合の一様性と同値**に近い。
- 非一様性の「量」が Grundy 値の多様性を生む。
- これは Grundy 値の上限を調べる新しい切り口：
  **非一様性が小さい盤では Grundy 値も小さい**。

## 5. 限界

- 逆（非一様でも Grundy 値が小さい）は未検証。
- 非一様性の定量的な尺度（サイズの分散など）と最大 Grundy の関係は未解明。
- 大きな盤では全列挙ができないので、この分析は小盤に限られる。
