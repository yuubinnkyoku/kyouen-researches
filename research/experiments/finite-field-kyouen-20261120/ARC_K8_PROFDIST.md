## 3. 構造的な観察

### 3.1 `n6 = v4` はほぼ常に 0

13種のうち `n6 = 1` は `(2,0,1)` と `(3,0,1)` の2種のみ（合計 450 組）。
**`v4` が稀**であることと整合。

### 3.2 `n5 = v3 + u4` は 0, 1, 2

`n5 = 2` は `(2,2,0)` と `(3,2,0)` の2種（合計 1,320 組）。

### 3.3 `n4` は 2〜12 の広い範囲

`n4 = 1 + v2 + u3 + z4` なので、`v2` と `u3` の広がりを反映。

## 4. なぜ和では足りないか（具体例）

`(8,0,0)` と `(5,1,0)` は**同じ `n4` の範囲**だが `n5` が違う。
アーク数の組み立ては `÷n4` を含むので、**`n4` の分布**が本質的に必要。

**和 `Σ v2 = 324,000` からは `(v2,u3)` の分布は復元できない。**

## 5. 意義

1. **プロファイル分布を測定した**（13種、72,675 組）。
2. **`(v2,u3)` の同時分布**（28種）を記録した。
3. **`v4` が稀**（450/72,675 = 0.6%）であることを確認。
4. **和から分布は復元できない**ことを具体例で示した。
5. プロファイル分布の閉形式化には `(v2,u3)` の同時分布が必要と確定。
