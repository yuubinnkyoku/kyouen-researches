# k=8 の q=7 の差：系統的な原因候補の消去

2026-11-20。`finite-field-kyouen-20261120` の第225部。

q=7 の差 784,000 について、原因候補を**1つずつ直接測定で消去**した。

## 1. 消去した候補

| 候補 | 測定結果 | 判定 |
|---|---|---|
| `(6,)` プロファイル | 0 件 | **消去** |
| プロファイル公式（q=7） | 500/500 で 0 不一致 | **消去** |
| `(7,)` の過大カウント | 実際 117,600 = 公式値、過大なし | **消去** |
| 多重度定理 | q=5 の13プロファイルで完全一致 | **消去** |

## 2. 残る唯一の候補

**タプル由来の部分が 784,000 少ない。**

```
組み立ての sum(tuples×b/n4) = 535,976,700
真の値                      = 536,760,700
差                          =     784,000
```

**8-アークを 784,000 多く見積もっている**（bad が少ない）。

## 3. 考えられる機序

**プロファイル公式は 500 組のサンプルで正しいが、稀なケースで
`n4` を過大に与えている可能性。**

`n4` が真値より大きいと `tuples×b/n4` が小さくなり、bad が
少なくなる（= arcs が多く出る）。**符号が一致する。**

**しかし 500/500 で 0 不一致だった。** 稀なケース（0.1% 未満）が
サンプルに含まれなかった可能性がある。

## 4. 別の機序：タプルループの `C` 固定

タプルループは `T = C ∩ S` が4点の `S` のみを生成する。
`b` を掛けて全円を足すと、各 `S` は「`S` の4円の個数」回現れる。

**しかし `C` が `S` の4円でない場合、`T = C ∩ S` は4点にならない。**
その場合 `S` は生成されない。

**`b` を掛けるのは「すべての `C` について」だが、`C` が `S` の4円で
ある場合しか `S` は現れない。よって各 `S` は `n4(S)` 回現れる。**

**これは正しい。** よってこの機序は成立しない。

## 5. 残る可能性：`n4` の定義のずれ

プロファイル公式の `n4 = 1 + v2 + u3 + z4` は「`S` の4円の個数」を
意図している。しかし `v2`, `u3`, `z4` は `T` と `X` に依存する量で、
**`S` の4円を正しく数えているとは限らない。**

**500 組のサンプルでは一致したが、`n4` が大きい（10以上）稀なケースで
ずれる可能性。**

## 6. 意義

1. **4つの候補を直接測定で消去した**（`(6,)`、プロファイル公式、
   `(7,)`、多重度定理）。
2. **残る唯一の候補を絞り込んだ**（タプル由来の部分の 784,000 の不足）。
3. **符号の一致**（`n4` 過大 → bad 過少 → arcs 過多）を確認。
4. **稀なケースの可能性**を指摘（500 サンプルでは検出できない）。

## 7. 限界

- 差の原因は未特定。
- 稀なケースの検出には全数検証が必要（q=7 で `C(8,4)*C(42,4) = 7.8M` 組）。
- q=11 の k=8 は実行中。
