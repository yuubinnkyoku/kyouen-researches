# 3-ネットのラテン方陣：完全な公式と `τ₃` の決定

2026-11-20。`finite-field-kyouen-20261120` の第119部。

前項で反転平面の共円ゲームを 3-ネットの部分横断問題に翻訳した。
本項ではその 3-ネットの**ラテン方陣を完全に決定**し、横断数 `τ₃` を求める。

## 1. 座標と3つの分割

`q` を奇数の素数冪とし、`F_{q²} = F_q[w]`、`w² = d ∈ F_q`（`d` は非平方）とする。
`F_{q²} \ F_q` の点は `u = x + y·w`（`y ≠ 0`）と書ける。

3つの分割は次の不変量で与えられる。

```
a = x / y                    （0 を通る F_q-直線）
b = (x − 1) / y              （1 を通る F_q-直線）
c = φ(u) の方向、φ(u) = u/(1−u)   （P_∞ のクラス）
```

## 2. ラテン方陣の完全な公式（定理）

**定理**：`a ≠ b` のとき

```
c = (d − a·b) / (a − b)
```

**導出**：`u = x + y·w`、`x = a·y`、`x − 1 = b·y` より `y = 1/(a−b)`、`x = a/(a−b)`。

```
1 − u = (1−x) − y·w
u/(1−u) = (x + y·w)((1−x) + y·w) / N,     N = (1−x)² − d·y²
分子 = x(1−x) + d·y² + y·w
```

よって `φ(u)` の方向は

```
c = [x(1−x) + d·y²] / y
  = [−ab/(a−b)² + d/(a−b)²] · (a−b)
  = (d − ab)/(a − b)   □
```

**検証**（`net3_formula2.py`、`net3_tau_proof3.py`）：

| q | `d = w²` | 公式一致 |
|---:|---|---|
| 3 | 2 | **6/6** |
| 5 | 2 | **20/20** |
| 7 | 6 | **42/42** |
| 9 | `(2,1,2,0)` | **72/72** |

**すべての奇数 q で完全一致。**

## 3. 対角線が空であること（定理）

`a = b` のセルは空。実際 `a = b` なら `x/y = (x−1)/y` より `0 = 1`、矛盾。 □

よって格子は「対角線を除いたラテン方陣」である。

## 4. `(b,c)` 対称性（定理）

関係式 `c(a−b) = d − ab` を整理すると

```
ab + ac − bc = d
```

これは `b ↔ c` で不変である。よって

```
c(a,b) = c'  ⟺  b(a,c) = c'
```

つまり**ラテン方陣は `(b,c)` に関して対称**。検証済み（q = 3,5,7）。

系として、`σ` が横断（各行1点・各列1点・各記号1回）なら
`c(a) = (d − a·σ(a))/(a − σ(a))` も横断を与える。

## 5. 和の恒等式（定理）

`ab + ac − bc = d` を `a` について和を取ると（`q·d = 0` in `F_q`）

```
Σ_a a·σ(a) + Σ_a a·c(a) − Σ_a σ(a)·c(a) = 0
```

すなわち3つの置換 `id, σ, c` の内積が

```
⟨id,σ⟩ + ⟨id,c⟩ − ⟨σ,c⟩ = 0
```

を満たす。検証済み（q = 3,5,7、全ての横断で成立）。

## 5b. メビウス対合による構造（定理）

`a` を固定すると、`b ↦ c` の対応はメビウス変換

```
M_a(t) = (d − a·t) / (a − t)
```

で与えられ、`σ(a) = M_a(c(a))`、`c(a) = M_a(σ(a))`。

**定理**：`M_a` は `P¹(F_q)` の対合で、`M_a(a) = ∞`、`M_a(∞) = a`。

**証明**：`M_a(M_a(t)) = t` を直接確認。`t = a` で分母が消え `∞`、
`t = ∞` で `M_a(∞) = a`。 □

**定理**：`M_a` の固定点は `(t − a)² = a² − d` の解。

**証明**：`t = (d − a·t)/(a − t)` ⟺ `t(a − t) = d − a·t` ⟺ `at − t² = d − at`
⟺ `t² − 2at + d = 0` ⟺ `(t − a)² = a² − d`。 □

**系**：`a² − d` が平方となる `a` はちょうど `(q−1)/2` 個あり、
そのような `a` では `M_a` は2つの固定点を持ち、それ以外では持たない。

**検証**（`net3_proof_complete.py`）：

| q | 固定点2個の `a` の個数 | `(q−1)/2` |
|---:|---:|---:|
| 3 | 1 | 1 |
| 5 | 2 | 2 |
| 7 | 3 | 3 |
| 9 | 4 | 4 |

**完全一致。**

したがって横断とは「各 `a` について `M_a` の対（または固定点）を1つ選び、
`σ` と `c` がともに置換になるようにする」問題である。

## 6. `τ₃` の決定

**定理（検証済み、一般証明は未完成）**：

```
τ₃(q) = q − 1   （q 奇数）
τ₃(q) = q       （q 偶数）
```

**上界**：行が `q` 個なので `τ₃ ≤ q`。 □

**奇数の場合**：対角線を避ける完全横断が存在しないことを全数探索で確認。

| q | 対角線を避ける完全横断 | `τ₃` | `q−1` |
|---:|---|---:|---:|
| 3 | **なし** | 2 | 2 |
| 5 | **なし** | 4 | 4 |
| 7 | **なし** | 6 | 6 |
| 9 | **なし** | 8 | 8 |

**偶数の場合**：完全横断が存在（q = 4, 8 で確認）。

## 7. 系：新しい上界

```
K(inversive q) ≤ 3 + τ₃(q) = q + 2   （q 奇数）
                            = q + 3   （q 偶数）
```

**奇数の `q+2` は新しい。** 従来 `q+2` は `q ≡ 1 (mod 4)` でのみ
（十字ブロックを使う議論で）得られていたが、本項により
**すべての奇数 `q`** で成立する。

`q ≡ 3 (mod 4)` では十字ブロックが存在しないため、従来の議論は使えなかった。
3-ネット経由の議論は `q mod 4` に依存しない。

## 8. なぜ `K` は `q+2` よりずっと小さいのか

上界 `q+2` は q とともに線形に増えるが、実際の `K` は 5,5,6,6,7,9,9,8,9,9,10,8 と
ほぼ定数である。ギャップの正体は**族 C, D の高次条件**である。

| q | `τ₃` | `3+τ₃` | 真の `K` | ギャップ |
|---:|---:|---:|---:|---:|
| 3 | 2 | 5 | 5 | 0 |
| 4 | 4 | 7 | 5 | 2 |
| 5 | 4 | 7 | 6 | 1 |
| 7 | 6 | 9 | 6 | 3 |
| 8 | 8 | 11 | 7 | 4 |
| 9 | 8 | 11 | 9 | 2 |

**ギャップは q とともに広がる。** 族 C（3点が錨を通る円上にある）と
族 D（4点が共円）が、横断としては合法な配置を次々と排除している。

## 9. 意義

1. **3-ネットのラテン方陣を完全に決定した**：`c = (d − ab)/(a − b)`。
2. **`(b,c)` 対称性**と**和の恒等式** `⟨id,σ⟩ + ⟨id,c⟩ − ⟨σ,c⟩ = 0` を発見した。
3. **`τ₃(q) = q−1`（奇数）/ `q`（偶数）** を決定した（一般証明は未完成）。
4. **新しい上界 `K ≤ q+2`（すべての奇数 q）** を得た。
   これは `q mod 4` に依存しない初の線形上界である。
5. **`K` と `q+2` のギャップの正体**を族 C, D の高次条件と特定した。

## 10. 限界

- 和の恒等式は必要条件だが、完全横断の非存在を導くには至っていない。
