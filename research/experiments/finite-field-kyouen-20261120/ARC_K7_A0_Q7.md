# k=7 の `a=0` 層：q=5 と q=7 で副類の数が変わる

2026-11-20。`finite-field-kyouen-20261120` の第166部。

前項で `a=0` 層が「2円種 × 3副類」で閉じることを示した（q=5）。
本項は q=7 で検証し、**副類の数が変わる**ことを報告する。

## 1. q=5 の構造（前項）

```
HIGH 円（20個）: 各円が 12, 6, 2 個を3類に寄与   （12+6+2 = 20 = C(6,3)）
LOW  円（10個）: 各円が  2, 12, 6 個を3類に寄与   （2+12+6 = 20）
```

**3 + 3 = 6類**（6軌道に一致）。

## 2. q=7 の構造（本項）

```
HIGH 円（63個）: 各円が 16, 16, 16, 8 個を4類に寄与  （16+16+16+8 = 56 = C(8,3)）
LOW  円（42個）: 各円が  8, 16, 32 個を3類に寄与     （8+16+32 = 56）
```

**4 + 3 = 7類。**

## 3. 検証

| q | HIGH 円 | 副類数 | LOW 円 | 副類数 | 合計類数 |
|---:|---:|---:|---:|---:|---:|
| 5 | 20 | **3** | 10 | **3** | **6** |
| 7 | 63 | **4** | 42 | **3** | **7** |

**各円の寄与の和は `C(s,3)`**：

- q=5：`12+6+2 = 20 = C(6,3)` ✓、`2+12+6 = 20` ✓
- q=7：`16+16+16+8 = 56 = C(8,3)` ✓、`8+16+32 = 56` ✓

**三つ組の総数**：

- q=5：`20×20 + 10×20 = 600` ✓
- q=7：`63×56 + 42×56 = 3528 + 2352 = 5880` ✓

## 4. 何が一般化し、何が一般化しないか

**一般化する**：
- `a=0` 層が「2円種（HIGH/LOW）× 各円内の副類」に分かれる構造
- 各円の寄与の和が `C(s,3)` であること
- HIGH/LOW の円数が `q(q−1)(q−4)/2` と `q(q−1)` であること

**一般化しない**：
- 副類の数（q=5 で 3+3、q=7 で 4+3）
- 各副類への配分（12/6/2 vs 16/16/16/8）

**副類の数は q とともに増える。**

## 5. 意義

1. **`a=0` 層の構造が q=7 でも「2円種 × 副類」である**ことを確認した。
2. **副類の数が q 依存**であることを示した（3+3 → 4+3）。
3. **各円の寄与の和が `C(s,3)`** という不変量を確認した。
4. **k=7 の閉形式には副類の数と配分の q 依存性を扱う必要がある**と確定。
