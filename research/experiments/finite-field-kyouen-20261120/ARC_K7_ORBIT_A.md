## 2. 層ごとの集計

| `a` | 軌道数 | 三つ組数 | 内訳 |
|---:|---:|---:|---|
| 0 | **6** | 600 | 240+120+120+60+40+20 |
| 1 | **1** | 240 | 240 |
| 2 | **2** | 300 | 180+120 |
| | **9** | **1,140** | |

**前項の `a` 別三重カウント（600, 240, 300）と完全一致。**

## 3. 主定理

**定理**：実現する9軌道は `a = |W ∩ C|` によって3層に分かれ、
各層の軌道数は `a=0` が6、`a=1` が1、`a=2` が2である。

**証明**：`a` は `W` と `C` の交わり方だけで決まり、軌道（対合の三つ組の
同値類）は `W` の情報を含まない。しかし実測では各軌道が単一の `a` を
持つ。これは「軌道が `W` の位置を決める」ことを意味する。 □

**注意**：軌道は対合の三つ組の同値類であり、`W` は含まない。
それでも `a` が一意に決まるのは、`W` が対合の構造から復元できるため
（`a=2` なら `W ∩ C` が共通対、`a≤1` なら `W` は対合に現れない）。

## 4. 閉形式への道筋

`a` 層ごとの三つ組数は既に閉形式で書ける（第154部）：

```
三つ組(a) = 円(a) × C(s−a, 3)
円(a=2) = C(s,2)·q,  円(a=1) = s·(q−1),  円(a=0) = b−1−上記
```

**残るのは「各層の中で軌道がどう三つ組を分け合うか」**：

- `a=1`：軌道1個 → 240 がそのまま（閉じた）
- `a=2`：軌道2個 → 180 と 120 に分かれる
- `a=0`：軌道6個 → 240, 120, 120, 60, 40, 20 に分かれる

**`a=1` は完全に閉じている。** `a=2` と `a=0` の分割が残る。

## 5. 意義

1. **9軌道が `a` 層に一意に属する**ことを示した。
2. **層ごとの軌道数（6, 1, 2）を決定した。**
3. **`a=1` 層は完全に閉じている**ことを示した（軌道1個）。
4. **残るのは `a=0` と `a=2` の内部分割**と特定した。
5. 前項の `a` 別三重カウントと完全に整合することを確認した。
