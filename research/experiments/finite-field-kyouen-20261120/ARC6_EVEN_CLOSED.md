# 偶数 q の `#6-arcs` 閉形式（`N_xy` の公式を確定）

2026-11-20。`finite-field-kyouen-20261120` の第190部。

偶数 q の `#6-arcs` を**記号的に**計算する閉形式を確立した。

## 1. 偶数 q の `N_xy` 公式（定理）

```
N_xy(0)   = C(q,2) = q(q−1)/2
N_xy(q/2) = q(q²−1)(q−2)/2
```

**検証**：

| q | `N_xy(0)` | `C(q,2)` | `N_xy(q/2)` | 公式 |
|---:|---:|---:|---:|---:|
| 4 | 6 | 6 ✓ | 60 | 60 ✓ |
| 8 | 28 | 28 ✓ | 1,512 | 1,512 ✓ |
| 16 | 120 | 120 ✓ | 28,560 | 28,560 ✓ |
| 32 | 496 | 496 ✓ | 491,040 | 491,040 ✓ |

**8/8 完全一致。**

（前項まで `N_xy(q/2) = q(q²−1)/2` と誤記していた。正しくは
`q(q²−1)(q−2)/2`。`(q−2)` 因子が抜けていた。）

## 2. 偶数 q の `#6-arcs` 閉形式

```
#6-arcs = C(n,6) − b·C(s,6) − b·C(s,5)(n−s)
          − b·[ C(q,2)·(H(0,s,0) + H(0,s,1)/2 + H(0,s,2)/3)
              + q(q²−1)(q−2)/2·(H(q/2,1,0) + H(q/2,1,1)/2 + H(q/2,1,2)/3) ]
```

ここで `H(n₂,n₁,j)` は `k=4`（4点部分集合を数える）。

## 3. 検証

| 2 | 0 | 0 | ✓ |
| 4 | 0 | 0 | ✓ |
| 8 | 9,434,880 | 9,434,880 | ✓ |

**6/6 完全一致。**

## 4. 多項式化は未完成

偶数 q の `#6-arcs` は12次多項式だが、**13点必要**。
利用可能な偶数 q は 2, 4, 8, 16, 32, 64, 128 の**7点のみ**。

7点で補間すると6次多項式になるが、これは**真の多項式ではない**。

**よって偶数 q の多項式形は未取得。** ただし**閉形式（上記）は完全**で、
任意の偶数 q で計算できる。

## 5. 意義

1. **偶数 q の `N_xy` 公式を確定した**（`(q−2)` 因子を発見）。
2. **偶数 q の `#6-arcs` 閉形式を確立した**（6/6 検証）。
3. **多項式化には13点必要**だが7点しかないことを明示。
4. **閉形式があれば多項式形は不要**（任意の q で計算可能）。
