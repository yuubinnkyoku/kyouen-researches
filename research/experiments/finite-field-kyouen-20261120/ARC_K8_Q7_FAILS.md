# 重要な訂正：k=8 の組み立ては q=7 でも破綻していた

2026-11-20。`finite-field-kyouen-20261120` の第223部。

前項まで「k=8 の組み立ては q=5, q=7 で成功」と述べてきたが、
**q=7 でも破綻していることを発見した。**

## 1. 結果（q=7）

```
n=50, b=350, s=8
tuples = 7,835,100
profiles = 21
(7,) = 117,600   (8,) = 350
bad  = 536,094,650
total = 536,878,650 = C(50,8)   ✓
arcs = 784,000
```

**全数（C 実装）では `arcs = 0`**（`K(7) = 6 < 8`）。

**差は 784,000。**

## 2. 差の構造

```
784,000 = b · C(s,6) · 80
        = 350 · 9,800 · 80 / 350 ... 
```

正確には：

```
b · C(s,6) = 350 · 28 = 9,800
784,000 / 9,800 = 80
```

**`80 = s(s+2) = 8 × 10`。**

## 3. これは `(6,)` プロファイル

`(6,)` は「6点が1つの円上にあり、他の4円を持たない」8点集合。

**素朴な上限**：`b·C(s,6)·C(n−s,2) = 350·28·861 = 8,437,800`。

**実際**：784,000（上限の 9.3%）。

**「他の4円を持たない」条件で 90.7% が除外される。**

## 4. q=5 では 0 件だった理由

q=5 では `s = 6` なので `(6,)` は「6点すべてが1円上 + 外2点」。
**外2点が必ず別の4円を作る**ため 0 件だった。

q=7 では `s = 8` なので `(6,)` は「8点円のうち6点 + 外2点」。
**円上に2点残るので、外2点と合わせて4円を作りにくい**場合がある。

## 5. 前項までの記述の訂正

| 記述 | 訂正 |
|---|---|
| 「q=5, q=7 で成功」 | **q=5 のみ成功**。q=7 は 784,000 の差 |
| 「q=7 で成功したのは `s=8` という特殊事情」 | 誤り。q=7 も失敗 |

**正しくは：k=8 の組み立てが成功したのは q=5 のみ。**

## 6. 意義

1. **q=7 の組み立ての破綻を発見した**（重要な訂正）。
2. **差 784,000 = b·C(s,6)·s(s+2)** という構造を特定。
3. **`(6,)` プロファイルが原因**と確定（q=7 で存在する）。
4. **q=5 で 0 件だったのは `s=6` の特殊事情**と説明。
5. **k=8 の組み立ては q=5 でのみ成功**と確定。

## 7. 限界
