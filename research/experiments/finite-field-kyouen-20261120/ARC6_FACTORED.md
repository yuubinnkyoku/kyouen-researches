# `#6-arcs` の因数分解：`(q−3)` 因子の発見

2026-11-20。`finite-field-kyouen-20261120` の第188部。

前項で `#6` の残りを5次多項式としたが、**さらに `(q−3)` で割れる**
ことを発見した。

## 1. 発見

`#6` の残り（`q²(q−1)²(q+1)(q²+1)` を括り出した後）は

```
P6 = q⁵ − 14q⁴ + 76q³ − 189q² + 185q − 15
```

**`P6(3) = 0`** を発見：

```
P6(3) = 243 − 1134 + 2052 − 1701 + 555 − 15 = 0
```

よって `(q−3)` が因子。

## 2. 割り算

```
P6 = (q−3)(q⁴ − 11q³ + 43q² − 60q + 5)
```

**検証**：`(q−3)(q⁴−11q³+43q²−60q+5)` を展開すると
`q⁵ − 14q⁴ + 76q³ − 189q² + 185q − 15`。 ✓

## 3. 4次因子

```
Q(q) = q⁴ − 11q³ + 43q² − 60q + 5
```

**整数根なし**：

| q | `Q(q)` |
|---:|---:|
| 1 | −22 |
| −1 | 120 |
| 5 | 30 |
| −5 | 3,380 |

**2次因子もなし**（`q² + aq + b`、`|a|,|b| ≤ 20` を全探索）。

**よって `Q` は有理数体上既約**（4次）。

## 4. `#6-arcs` の因数分解形（奇数 q）

```
#6-arcs = q² (q−1)² (q+1) (q²+1) (q−3) (q⁴ − 11q³ + 43q² − 60q + 5) / 720
```

## 5. 検証

| q | 因数分解形 | 実測 |
|---:|---:|---:|
| 5 | 5,200 | 5,200 |
| 7 | 1,254,400 | 1,254,400 |
| 9 | 52,781,760 | 52,781,760 |
| 11 | 895,167,680 | 895,167,680 |

**4/4 一致。**

## 6. 因子の意味

| 因子 | 意味 |
|---|---|
| `q²` | 円の選択の一部 |
| `(q−1)²` | 2点の選び方の制約 |
| `(q+1)` | `s = q+1` |
| `q²+1` | `n = q²+1` |
| **`(q−3)`** | **新しい因子**（q=3 で `#6-arcs = 0` に対応） |
| `Q(q)` | 4次の既約因子 |
| `1/720 = 1/6!` | 6点の対称性 |

**`(q−3)` は `q = 3` で `#6-arcs = 0` になることに対応する。**
実際 `#6-arcs(3) = 0`（6-アークは `K(3) = 5 < 6` で存在しない）。

## 7. 意義

1. **`#6-arcs` の因数分解形を得た**（`(q−3)` 因子を新発見）。
2. **`(q−3)` が `K(3) = 5 < 6` に対応**することを示した。
3. **4次因子 `Q` が既約**であることを確認。
4. `#4` の完全分解、`#5` の部分分解、`#6` の部分分解という
   階層構造が明確になった。
