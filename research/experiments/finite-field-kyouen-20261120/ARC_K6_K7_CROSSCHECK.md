# k=6 と k=7 のアーク数：K との整合性の相互検証

2026-11-20。`finite-field-kyouen-20261120` の第181部。

k=6 と k=7 の閉形式が揃ったので、**両者が `K(q)` と整合するかを
相互検証する。**

## 1. 原理

`k`-アークが存在するのは `K(q) ≥ k` のとき、かつそのときに限る。
よって

```
#k-arcs > 0  ⟺  K(q) ≥ k
```

これは定義から自明だが、**独立に計算した2つの閉形式が同じ `K` と
整合する**ことは、両方の正しさの傍証になる。

## 2. 検証

| q | `K(q)` | `#6-arcs` | `#7-arcs` | 6-arcs>0 | 7-arcs>0 |
|---:|---:|---:|---:|---|---|
| 5 | 6 | 5,200 | 0 | ✓ | ✓ |
| 7 | 6 | 1,254,400 | 0 | ✓ | ✓ |
| 8 | 7 | 9,434,880 | 1,048,320 | ✓ | ✓ |
| 9 | 9 | 52,781,760 | 17,003,520 | ✓ | ✓ |

**整合性チェック**：

```
q=5: K=6, 6-arcs ok=True, 7-arcs ok=True
q=7: K=6, 6-arcs ok=True, 7-arcs ok=True
q=8: K=7, 6-arcs ok=True, 7-arcs ok=True
q=9: K=9, 6-arcs ok=True, 7-arcs ok=True
```

**8/8 完全一致。**

## 3. 注目すべき点

**q=5, q=7 では `K = 6`** なので6-アークは存在するが7-アークは存在しない。
両方の閉形式がこれを正しく再現している。

**q=8 では `K = 7`** なので7-アークが初めて存在する。
`#7-arcs = 1,048,320` は文献値とも一致（第177部）。

**q=9 では `K = 9`** なので7-アークが豊富に存在する
（`#7-arcs = 17,003,520`、q=8 の16倍）。

## 4. 意義

1. **k=6 と k=7 の閉形式が `K(q)` と整合する**ことを相互検証した（8/8）。
2. **2つの独立な閉形式が同じ `K` 系列を再現**することで、
   両方の正しさの傍証が得られた。
3. **q=9 の `#6-arcs = 52,781,760`** という新しい値を得た。
4. `K` の階段（6, 6, 7, 9）とアーク数の階段（0, 0, 1M, 17M）が
   整合的に連動することを示した。

## 5. 限界

- 検証は q ≤ 9 のみ。
- k ≥ 8 は未着手。
