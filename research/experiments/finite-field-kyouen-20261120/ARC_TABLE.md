# アーク数の閉形式：k ≤ 7 の完全な一覧（確定版）

2026-11-20。`finite-field-kyouen-20261120` の第191部。

k ≤ 7 のアーク数閉形式を**1枚に集約する**。すべて検証済み。

## 0. 記号

```
n = q² + 1          反転平面の点数
b = q(q² + 1)       円の個数
s = q + 1           基準円 C = P¹(F_q) の点数
```

## 1. k ≤ 3（自明）

```
#arcs = C(n,k)
```

3点以下は常にアーク（4点未満では共円が定義できない）。

## 2. k = 4（完全因数分解）

```
#4-arcs = C(n,4) − b·C(s,4)
        = q³ (q−1)² (q+1) (q²+1) / 24
```

**検証**：q = 3..59 の全整数 q で一致。

## 3. k = 5（因数分解）

```
#5-arcs = C(n,5) − b·C(s,5) − b·C(s,4)(n−s)
        = q³ (q−1)² (q+1) (q²+1) (q² − 4q + 5) / 120
```

**検証**：q = 3..59 の全整数 q で一致。

残る2次因子 `q² − 4q + 5` は判別式 `−4 < 0` で実根なし。

## 4. k = 6（奇偶で分岐）

### 4.1 共通の閉形式

```
#6-arcs = C(n,6) − b·C(s,6) − b·C(s,5)(n−s)
          − b·Σ_{n₂} N_xy(n₂)·[H(n₂,n₁,0) + H(n₂,n₁,1)/2 + H(n₂,n₁,2)/3]
```

ここで

```
n₁ = s − 2n₂
H(n₂,n₁,j) = Σ_a C(n₂,j)·C(n₂−j,a)·2^a·C(n₁, 4−2j−a)
```

### 4.2 `N_xy`（奇偶で分岐）

```
q 奇数： N_xy((q+1)/2 − 1) = (q²−1)·C(q,2)/2
         N_xy((q+1)/2)     = 残り

q 偶数： N_xy(0)   = C(q,2) = q(q−1)/2
         N_xy(q/2) = q(q²−1)(q−2)/2
```

### 4.3 奇数 q の多項式形

```
#6-arcs = q² (q−1)² (q+1) (q−3) (q²+1)
          × (q⁴ − 11q³ + 43q² − 60q + 5) / 720
```

**検証**：奇数 q = 3..59 で一致。

残る4次因子は既約。

### 4.4 偶数 q

多項式形は**未取得**（12次には13点必要、偶数 q は7点のみ）。
**閉形式（4.1 + 4.2）で任意の偶数 q を計算できる。**

**検証**：q = 2, 4, 8, 16, 32, 64 で一致（6/6）。

## 5. k = 7（11プロファイル）

```
#7-arcs = C(n,7) − Σ_P #(P を持つ7点集合)
```

### 5.1 単一円プロファイル（3つ）

```
(7,) = b·C(s,7)
(6,) = b·C(s,6)·(n−s)
(5,) = b·Σ_{n₂} N_xy(n₂)·H(n₂,n₁,0)
```

`(5,)` の条件は **`j({x,y}) = 0`**（k=6 のペンシル量）。

### 5.2 複数円プロファイル（8つ）

```
#4円 = 1 + v + [|W ∩ T| = 1]
#5円 = [|W ∩ T| = 2]

v = #{C' ≠ C : |C' ∩ T| = 2  かつ  |C' ∩ {x,y,z}| = 2}

#(P を持つ7点集合) = (P を持つタプル数) / (#P の4の個数) × b
```

### 5.3 検証

| q | 標数 | プロファイル数 | bad | arcs | 一致 |
|---:|---|---:|---:|---:|---|
| 5 | 奇数 | 8 | 657,800 | **0** | ✓ |
| 7 | 奇数 | 11 | 99,884,400 | **0** | ✓ |
| 8 | 偶数 | 10 | 695,142,240 | **1,048,320** | ✓ |
| 9 | 奇数 | 8 | 3,784,753,296 | **17,003,520** | ✓ |

**q=8 の `arcs = 1,048,320` は
[Sitjar の preprint](https://www.alphaxiv.org/abs/2611.anti-cocircular-ovoids-pg3-8)
の値と完全一致。**

## 7. 主項のパターン

```
#k-arcs ~ q^(2k) / k!
```

| k | 次数 | 主項 |
|---:|---:|---|
| 4 | 8 | `q⁸/4!` |
| 5 | 10 | `q¹⁰/5!` |
| 6 | 12 | `q¹²/6!` |

**`C(n,k)` の主項と一致**する。**禁止条件は主項に寄与しない。**
