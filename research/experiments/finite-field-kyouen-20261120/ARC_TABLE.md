# アーク数の閉形式：k ≤ 6 の完全な検証

2026-11-20。`finite-field-kyouen-20261120` の第142部。

統一ハーネス `arc_table.py` で、k ≤ 6 の閉形式を**すべての q で一括検証**した。

## 1. 閉形式（確定版）

`n = q²+1`、`b = q(q²+1)`、`s = q+1` として

```
k ≤ 3 :  #arcs = C(n,k)

k = 4 :  #arcs = C(n,4) − b·C(s,4)

k = 5 :  #arcs = C(n,5) − b·C(s,5) − b·C(s,4)·(n−s)

k = 6 :  #arcs = C(n,6) − b·C(s,6) − b·C(s,5)·(n−s)
                  − b·Σ_{n₂} N_xy(n₂)·[H(n₂,n₁,0) + H(n₂,n₁,1)/2 + H(n₂,n₁,2)/3]
```

ここで

```
n₁ = s − 2n₂
H(n₂,n₁,j) = Σ_a C(n₂,j)·C(n₂−j,a)·2^a·C(n₁,4−2j−a)

N_xy(n₂):
  q 奇数： (q²−1)·C(q,2)/2 個が n₂ = (q+1)/2 − 1、残りが n₂ = (q+1)/2
  q 偶数： C(q,2) 個が n₂ = 0、残りが n₂ = q/2
```

## 2. 一括検証の結果

| q | n | `K` | 検証した閉形式 |
|---:|---:|---:|---|
| 3 | 10 | 5 | **6/6** |
| 4 | 17 | 5 | **6/6** |
| 5 | 26 | 6 | **7/7** |
| 7 | 50 | 6 | **7/7** |
| 8 | 65 | 7 | **7/7** |

**合計 33/33 完全一致。**

**q=8（標数2）でも k=6 の公式が一致**したことが重要である。
`N_xy` の偶奇分岐が正しいことの強い証拠。

## 4. 検証の方法

`arc_table.py` は

1. アークをサイズごとに全数列挙（`kmax` まで）
2. 各 `k` について閉形式と照合
3. `K` を「カウントが非零の最大 k」として読み取り
4. 既知の `K` と照合

を行う。ノード数は q=8 で 15,665,794（480秒）。

## 5. 意義

1. **k ≤ 6 の閉形式を 33/33 で検証した**（q=3,4,5,7,8）。
2. **標数2（q=4,8）でも成立**することを確認した。
3. **統一ハーネス**により、今後の k ≥ 7 の追加が容易になった。
4. `K` が「アーク数の非零最大サイズ」として一貫して読めることを再確認。

## 6. 限界

- k ≥ 7 の閉形式は未取得（q=5 でプロファイル8種類、複雑）。
- q=8 の全数列挙は 480 秒かかる（これ以上の q は非現実的）。
- `N_xy` の偶奇分岐の幾何的な理由は未解明。
