# k=7 の q=7：プロファイル公式は「6点以上の円」を扱えない

2026-11-20。`finite-field-kyouen-20261120` の第170部。

前項でスケールと多重度の誤りを報告した。本項は**真の原因**を特定する。

## 1. プロファイル公式は完全に正しい

q=7 の**全 803,600 組** `(T, {x,y,z})` で照合した：

```
FULL check 803600 (T,xyz) pairs
  mismatches: 0
```

**プロファイル公式は q=7 でも完全に正しい。**

## 2. しかし組み立てが合わない

| 量 | 値 |
|---|---:|
| 全数の悪い7点集合 | 99,884,400 |
| 全数のアーク | **0** |
| 組み立ての悪い | 98,470,400 |
| 組み立てのアーク | **1,414,000** |

**1,414,000 個が数えられていない。**

## 3. 真の原因：6点以上の円

プロファイル公式が生成するのは **4 と 5 のみ**。しかし q=7 では
`s = 8` なので、**1つの円が `S` から6点・7点取ることができる**。

例：円 `C` 上の6点 + 外の1点 = 7点集合。この集合は
- 6点円を1つ持つ（プロファイルに6が入るべき）
- 同時に `C(6,4) = 15` 個の4点円も持つ

**プロファイル公式は「4円と5円」しか数えないので、6点円を持つ
7点集合を正しく分類できない。**

## 4. なぜ q=5 では問題にならなかったか

q=5 では `s = 6`。円は最大6点。プロファイル公式は4と5しか出さないが、
6点円を持つ7点集合は `(6,)` という**別項**で処理していた。

q=7 では `s = 8` なので、6点円・7点円の両方が可能になり、
`(6,)` という単一の別項では足りない。

## 5. 正しい形

`S` のプロファイルは「各円が `S` から取る点数」の多重集合であり、
`s = q+1` 点まで取り得る。よって

```
プロファイルは 4, 5, 6, ..., q+1 の値を取り得る
```

q=5 では 4,5,6（6 は別項で処理）、q=7 では 4,5,6,7,8。

**一般の q では、4 から q+1 までのすべての場合を扱う必要がある。**

## 6. 意義

1. **プロファイル公式自体は q=7 でも完全に正しい**ことを確認した
   （803,600/803,600、0 不一致）。
2. **組み立てが合わない真の原因を特定した**：6点以上の円。
3. **q=5 の `(6,)` 別項は s=6 という特殊事情**であり、一般化しない。
4. **k=7 の閉形式には「4〜q+1 点の円」すべてを扱う必要がある**と確定。
