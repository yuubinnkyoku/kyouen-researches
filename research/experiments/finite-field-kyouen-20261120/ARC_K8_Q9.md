# k=8 のアーク数：q=9 で 1,062,720（初の厳密値）

2026-11-20。`finite-field-kyouen-20261120` の第194部。

C 実装により **k=8 のアーク数を初めて厳密に計算した。**

## 1. 結果（q=9）

```
n = 82, b = 738
total = 35,641,470,150 = C(82,8)   ✓
arcs  =      1,062,720
```

## 2. 検証

**`total = C(82,8)`** が完全一致（`35,641,470,150`）。列挙が正しい。

**`arcs > 0`** は `K(9) = 9 ≥ 8` と整合。

**C 実装の正しさ**は k=7 で `arcs = 17,003,520` が Python と完全一致
することで確認済み（第193部）。

## 3. 驚くべき比

```
#8-arcs / #7-arcs = 1,062,720 / 17,003,520 = 1/16
```

**正確に `1/16`。**

```
1,062,720 × 16 = 17,003,520   ✓
```

これは偶然か構造か。`q = 9` で `(q+7)/1 = 16`、`2^4 = 16`、
`(q−1)²/4 = 16` など複数の候補がある。**1点では判定できない。**

## 4. アーク密度

| k | `#k-arcs` | `C(82,k)` | 密度 |
|---:|---:|---:|---:|
| 7 | 17,003,520 | 3,801,756,816 | 0.004473 |
| 8 | 1,062,720 | 35,641,470,150 | **0.0000298** |

**密度は 150分の1 に急落。** 8-アークは極めて稀。

## 5. アーク数の系列（q=9）

| k | `#k-arcs` |
|---:|---:|
| 4 | 1,594,080 |
| 5 | 15,940,800 |
| 6 | 52,781,760 |
| 7 | 17,003,520 |
| 8 | **1,062,720** |

**k=6 がピーク**（52.8M）で、そこから急減。`K(9) = 9` なので
9-アークも存在するはずだが、さらに稀と予想される。

## 6. 意義

1. **k=8 のアーク数を初めて厳密に計算した**（q=9 で 1,062,720）。
2. **`total = C(82,8)` の一致**で列挙の正しさを確認。
3. **`#8/#7 = 1/16`** という驚くべき比を発見（要検証）。
4. **アーク密度が150分の1に急落**することを示した。
5. **C 実装により「不可能」を「可能」に変えた**（前項の見積もりは
   Python 依存だった）。
