k=8 のプロファイル公式（第198部）と多重度定理を組み合わせ、
**q=5 で全数と完全一致**した。

## 1. 組み立て

```
#8-arcs = C(n,8) − Σ_P #(P を持つ8点集合) − (7,) − (8,)
```

ここで

```
#(P を持つ8点集合) = (P を持つタプル数) / (#P の4の個数) × b
(7,) = b·C(s,7)·(n−s)
(8,) = b·C(s,8)
```

## 2. 結果（q=5）

```

プロファイル数 = 13
(7,) = 0   (8,) = 0
bad  = 1,562,275  （整数）
arcs = 0
C(26,8) = 1,562,275
consistent: True
```

**`bad = C(26,8)` で `arcs = 0`。** 全数計算（C 実装、第196部）と
**完全一致**。

## 3. 検証の意味

**プロファイル公式 + 多重度定理が k=8 でも成立**することを示す。

- プロファイル公式：第198部で q=5,7 の 5,000 組で 0 不一致
- 多重度定理：`÷(#4円) × b` で整数かつ全数と一致

**両方が正しければ、全数計算なしでアーク数が出せる。**
