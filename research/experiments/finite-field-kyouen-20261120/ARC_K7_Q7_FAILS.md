# k=7 のプロファイル公式は q=7 で破綻する（重要な訂正）

2026-11-20。`finite-field-kyouen-20261120` の第167部。

前項まで「k=7 のプロファイル公式 `#4円 = 1+u+[w=1]`」を q=5 で
検証済みと報告した。本項は**これが q=7 で完全に破綻する**ことを示す。

## 1. 症状

q=7 で組み立てたアーク数が**非整数**になった：

```
bad = 4033248800/143   （整数でない）
```

これは「公式が誤り」を意味する（丸め誤差ではない）。

## 2. 直接照合

`(T, {x,y,z})` の組 20,000 個について、実際のプロファイルと公式の
予測を比較した。

```
checked 20000, mismatches 20000
```

**20,000/20,000 が不一致。** 予測は実際より遥かに多くの4円を含む。

例：

```
actual (4,4,4)      vs predicted (4,4,4,4,4,4,4,4,4,4,4)   3508件
actual (4,4,4,4)    vs predicted (4,4,4,4,4,4,4,4,4,4,4)   3003件
```

## 3. 原因の特定

具体例（q=7、`T = (0,7,14,21)`、`xyz = (1,2,3)`）：

```
実際の4円: {265:4, 305:4, 69:4, 44:4, 194:4}   （5個）
w = 2, u = 8
予測: n4 = 1+8+0 = 9, n5 = 1
```

**予測は9個の4円を主張するが、実際は5個。**

`u` の合併に含まれる9個の円を調べると：

```
union = {193, 194, 69, 70, 265, 44, 205, 110, 189}
すべて |C' ∩ C| = 2
```

**しかし実際に `S` から4点取るのは 4個だけ。**

## 4. なぜか

`u` は「`T` と2点共有するペンシル円」の合併サイズである。
しかし**その円が `{x,y,z}` から2点取るとは限らない**。

円 `C'` が `T` から2点取っても、残りの2点が `{x,y,z}` にない場合、
`C'` は `S` から2点しか取らない（4円ではない）。

**q=5 では `u` が小さく（≤5）、合併の円がたまたま `{x,y,z}` の点を
含んでいた。q=7 では `u` が大きく（≤12）、含まない円が多数現れる。**

## 5. 正しい条件

`C'` が `S` から4点以上取る条件は

```
|C' ∩ T| = 2  かつ  |C' ∩ {x,y,z}| = 2
```

`u` は前者だけを数えている。**後者の条件が欠けていた。**

正しくは

```
#4円 = 1 + #{C' : |C'∩T| = 2 かつ |C'∩{x,y,z}| = 2} + [w = 1]
```

であり、`u` はこの第2項の**上界**にすぎない。

## 6. 影響範囲

**q=5 の結果は有効**（`u` が小さく偶然一致した）。しかし
**q=7 以降は無効**。

影響を受ける主張：

- 「k=7 のプロファイル公式（7/7 検証済み）」→ **q=5 のみ有効**
- 「k=7 のアーク数の組み立て（bad=657800, arcs=0）」→ **q=5 のみ有効**
- 「9分布 = 実現する9軌道」→ **q=5 のみ有効**
- 「a=0 層の2円種×3副類」→ **q=5 のみ有効**

**q=7 の `a=0` 層の測定（第166部）も、`u` を「円レベルの u」として
使っているので、軌道との対応は未検証。**

## 7. 意義

1. **プロファイル公式が q=7 で破綻することを示した**（重要な訂正）。
2. **原因を特定した**：`u` は `|C'∩T|=2` しか数えず、
   `|C'∩{x,y,z}|=2` を数えていない。
3. **q=5 の結果は有効**だが、q ≥ 7 への拡張は無効と確定。
4. **「q=5 で一致したから正しい」という推論の危険性**を記録した。
