# 訂正：多重度定理は正しい（LHS/RHS テストが誤りだった）

2026-11-20。`finite-field-kyouen-20261120` の第220部。

前項で「タプルループが `C(s,4)` 倍過大カウントしている」と結論したが、
**これは誤りだった。**

## 1. 前項の誤り

前項のテスト：

```
LHS = b · C(s,4) · C(n−s,4) = 159,441,874,200
RHS = b · C(n−s,4)          =     759,247,020
比 = 210 = C(s,4)
```

**この2つは別の対象を数えている。**

- **LHS**：`(D, T, X)` の三つ組（`D` は円、`T` は `C` の4点部分集合、
  `X` は外点の4点部分集合）
- **RHS**：`(D, X)` の二つ組

**比が `C(s,4)` になるのは当然**（`T` の選び方が `C(s,4)` 通り）。

## 2. 正しい関係

8点集合 `S` は、タプルループで **`n4(P)` 回**現れる：

- `T = C ∩ S` は一意（`S` から決まる）
- `D` は `S` の4円（`n4(P)` 個）

**よって**

```
tuples(P) = #S(P) × n4(P)
#S(P) = tuples(P) / n4(P)
```

**これは組み立てが行っていることそのもので、正しい。**

## 4. q=9 の差の原因は依然未特定

多重度定理は正しいので、q=9 の差 119,024,640 の原因は**別**。

**残る候補**：

1. **`(j,)` 単一円プロファイル**：q=5 では 0 件だが、q=9 では存在する
   可能性（`s = 10` で `j = 5..8` が可能）
2. **プロファイル公式の破綻**：500 組のサンプルでは 0 不一致だが、
   稀なケースで破綻する可能性
3. **`(7,)` と `(8,)` の別項の式**：q=9 では `(5,)`, `(6,)` も必要

**候補1が最有力**：q=9 では `s = 10` なので、5点円 + 外3点のような
単一円プロファイルが存在しうる。q=5 では `s = 6` で外点が2個以上必要に
なり存在しなかった。
