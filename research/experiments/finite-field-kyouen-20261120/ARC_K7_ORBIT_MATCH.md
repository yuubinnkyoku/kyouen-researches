# k=7 の完全な対応：9分布 = 実現する9軌道

2026-11-20。`finite-field-kyouen-20261120` の第158部。

前項で軌道対応に失敗した。本項は**正しい全単射**（`C = P¹(F_q)` 自身を使う）
により、対応を完全に解決する。

## 1. 鍵となる工夫

ovoid 模型の円 `C` は抽象的な点集合で、`P¹(F_q)` への全単射が
メビウス構造を保たない。

**解決策**：native 模型で `C = P¹(F_q)` 自身（`0, 1, ∞` を通る円）を選ぶ。
この円の点は**そのまま `P¹(F_q)`** なので、全単射は恒等写像であり、
誘導される対合は本物の `PGL(2,q)` の元になる。

**検証**：`arc_k7_identity_circle.py` で `C = P¹(F_q)`（index 58）を使い、
9分布が同じであることを確認。

**定理**：`PGL(2,q)` の対合三つ組への37軌道のうち、
**実際に幾何学的に実現するのは9個だけ**であり、

**証明**：`C = P¹(F_q)` を選べば全単射が恒等になり、対合が本物の

## 4. なぜ37のうち9だけか

37軌道のうち28は**幾何学的に実現しない**。理由は、対合が
「ペンシルの2割線」という特別な形（`C` と2点で交わる円から来る）に
限られるためである。任意の対合の三つ組が3つのペンシルから来るわけではない。

**実現可能性の条件**：3つの対合が「ある三つ組 `{x,y,z}` の3つの
ペンシル」から来ること。これは強い制約である。
