# k=6 の現状：交点表は閉じたが、`N_j` の分離が残る

2026-11-20。`finite-field-kyouen-20261120` の第138部。

前項で k=6 の交点表を完全に閉じた。本項はその結果が k=6 のアーク数に
どこまで届くかを正確に述べる。

## 1. 閉じたもの

**交点表**（6項すべて、12/12 一致）：

```
(2,2) = 6q·C(q−1,2)
(2,1) = 4(q−3)·q·C(q−1,2)
(2,0) = C(q−3,2)·q·C(q−1,2)
(1,1) = 4(q−1)·C(q,2)
(1,0) = (q−3)(q−1)·C(q,2)
(0,0) = 総数 − (2,·) − (1,·)
```

**`j` の総和**：

```
Σ j = b·C(q+1,4)·6q·C(q−1,2)
```

**検証**：q=5 で 351,000、q=7 で 15,435,000。データと一致。

## 2. 閉じていないもの

k=6 のアーク数は

```
#6-arcs = C(n,6) − (6,) − (5,) − [N₀ + N₁/2 + N₂/3]
```

を必要とする。交点表から分かるのは

```
N₁ + 2N₂ = Σ j = b·C(q+1,4)·6q·C(q−1,2)
```

**だけ**であり、`N₀ + N₁/2 + N₂/3` を求めるには `N_j` の**個別値**が要る。

## 3. なぜ交点表では足りないか

交点表は `({x,y}, C')` の**組**を数える。一方 `N_j` は
`{x,y}` ごとの `j` の**分布**を数える。

例（q=5、1つの `(C,T)` について）：

```
j=0 の {x,y}: 32 個
j=1 の {x,y}: 136 個
j=2 の {x,y}: 22 個
```

`Σ j = 0·32 + 1·136 + 2·22 = 180` は交点表から出るが、
`32, 136, 22` の内訳は交点表だけでは決まらない。

**`j` の分布は PGL(2,q)-軌道に依存する**（前々項で確認）。
q=5 では1軌道なので一様、q=7 では2軌道で異なる。

## 4. 現状の整理

| 項目 | 状態 |
|---|---|
| 交点表（6項） | **閉じた**（証明済み） |
| `Σ j` | **閉じた**（証明済み） |
| `N_j` の個別値 | 軌道依存（q=5 で1型、q=7 で2型） |
| k=6 のアーク数 | 軌道ごとの `N_j` が要る |

**したがって k=6 は「交点表レベルでは完全に解決」だが、
「アーク数の閉形式」にはあと一歩届いていない。**

## 5. 残る一歩

`N_j` を軌道の関数として書くには、**軌道 `O` の代表 `T` に対する
`j` の分布**を計算する必要がある。これは

```
j({x,y}) = #{C' : x,y ∈ C', |T ∩ C'| = 2}
```

であり、`C'` は `x,y` を通り `T` の2点を通る円。`T` の2点の選び方は
`C(4,2) = 6` 通り、各2点を通る円は `q` 個（`C` を除く）。

**つまり `j` は「6個の円束のうち、`x,y` を通るものがいくつあるか」**
という問題に帰着する。これは `PG(3,q)` の平面配置の問題である。

## 6. 意義

1. **交点表を完全に閉じた**（6項、証明付き、12/12 一致）。
2. **`Σ j` の閉形式を与えた**：`b·C(q+1,4)·6q·C(q−1,2)`。
3. **k=6 のアーク数に何が足りないかを正確に特定した**：
   `N_j` の個別値であり、それは軌道依存である。
4. **「交点表レベル」と「アーク数レベル」の区別**を明確にした。
   前者は解決、後者は未解決。

## 7. 限界

- `N_j` の個別値は未取得（軌道依存、q=5 と q=7 の数値のみ）。
- k=6 のアーク数の閉形式は未完成。
- k ≥ 7 は未着手。
