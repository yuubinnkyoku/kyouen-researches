# k=8 のプロファイル公式（q=5,7 で完全一致）

2026-11-20。`finite-field-kyouen-20261120` の第198部。

k=8 のプロファイル公式を導出し、**q=5 と q=7 で完全一致**を確認した。

## 1. 設定

`S = T ∪ {w,x,y,z}`（`|T| = 4`、`T ⊂ C`、外4点 `X = {w,x,y,z}`）。

`C' ≠ C` は `C` と高々2点で交わるので

```
|C' ∩ S| = |C' ∩ T| + |C' ∩ X| ≤ 2 + 4 = 6
```

**よってプロファイルの値は 4, 5, 6 のみ。**

## 2. 6つの類

| 記号 | 条件 | `S` からの点数 |
|---|---|---:|
| `v2` | `\|C'∩T\|=2`, `\|C'∩X\|=2` | 4 |
| `v3` | `\|C'∩T\|=2`, `\|C'∩X\|=3` | 5 |
| `v4` | `\|C'∩T\|=2`, `\|C'∩X\|=4` | 6 |
| `u3` | `\|C'∩T\|=1`, `\|C'∩X\|=3` | 4 |
| `u4` | `\|C'∩T\|=1`, `\|C'∩X\|=4` | 5 |
| `z4` | `\|C'∩T\|=0`, `\|C'∩X\|=4` | 4 |

## 3. 定理

```
#4円 = 1 + v2 + u3 + z4
#5円 = v3 + u4
#6円 = v4
```

（`1` は `C` 自身。）

## 4. 検証

| q | 検査数 | 不一致 |
|---:|---:|---:|
| 5 | 5,000 | **0** |
| 7 | 5,000 | **0** |

**両方で完全一致。**

## 5. k=7 との比較

| 量 | k=7 | k=8 |
|---|---|---|
| 外点の数 | 3 | 4 |
| プロファイル値 | 4, 5 | 4, 5, **6** |
| 類の数 | 2（`v`, `w`） | **6**（`v2,v3,v4,u3,u4,z4`） |
| 公式 | `#4 = 1+v+[w=1]`, `#5 = [w=2]` | 上記 |

**k=8 では類が6つに増える**が、構造は同じ「`T` との交点数 × `X` との交点数」で
分類できる。

## 6. 意義

1. **k=8 のプロファイル公式を導出した**（6類）。
2. **q=5, q=7 で完全一致**（0 不一致）。
3. **k=7 の自然な拡張**であることを示した（外点3→4、類2→6）。
4. **プロファイル値が 4,5,6** になるという構造的制約を確認。
5. これで k=8 の**組み立て**が原理的に可能になった（多重度定理が
   必要だが）。

## 7. 限界

- 多重度定理（`#8点集合 = タプル数 / #4円`）は k=8 では未検証。
- 各類の閉形式は未取得。
