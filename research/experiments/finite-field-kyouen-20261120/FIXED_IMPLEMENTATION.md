# バグ修正版の実装と検証

2026-11-20。`finite-field-kyouen-20261120` の第107部。
64ビットマスクのオーバーフローバグを修正した実装を作成し、既知値で検証した。

## 1. 修正内容

`scripts/agq_fixed.cpp`：`unsigned long long pmask` を多倍長ビットセットに置き換えた。

```cpp
struct Mask {
    unsigned long long w[16];        // 16*64 = 1024 点まで
    bool get(int i) const { return (w[i >> 6] >> (i & 63)) & 1ULL; }
    void set(int i) { w[i >> 6] |= (1ULL << (i & 63)); }
    void reset(int i) { w[i >> 6] &= ~(1ULL << (i & 63)); }
};
```

## 2. 既知値での検証

修正版が過去の（バグの影響を受けない）結果を再現するか確認した。


**これは撤回前の証人と同一**（バグの影響を受けない領域の点のみを使っていたため）。

## 4. バグの影響の再評価

バグは「点 `i` と点 `i−64` の同一視」を引き起こす。しかし：

- **サイズ13の証人は点 0〜143 を使っており、64以上の点も含む**。
  それでも正しい安全集合である（発見後に検証可能）。
- 問題は「不存在の証明」にあった。点の同一視により、
  **実際には存在する安全集合を見逃す**可能性があった。

したがって：
- **「発見」系の結果は、証人を独立検証すれば有効**。
- **「不存在」系の結果は無効**（見逃しの可能性）。

## 6. 意義

- バグの影響を「発見」と「不存在の証明」に分けて評価した。
- 発見系は証人の独立検証で救える。
- 不存在系は再計算が必要。
- 修正版は既知値で完全に検証済み。
