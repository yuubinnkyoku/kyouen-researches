# k=8 の組み立て：除数仮説の検証（未解決）

2026-11-20。`finite-field-kyouen-20261120` の第228部。

q=7 の差 784,000 について、**除数の候補を検証**した。

## 1. 検証した仮説

### 1.1 仮説A：重み付き除数 `n4 + 5n5 + 15n6`

**根拠**：4円 `D` が `S` から5点取れば `C(5,4) = 5` 通りの `T` がある。

**結果（q=5）**：

```
除数 n4              -> 1,562,275  = C(26,8)  ✓
除数 n4+5n5+15n6     -> 621,125,425/561（非整数） ✗
```

**仮説A は棄却。**

### 1.2 仮説B：`e4 = n4 − n5 − n6`（ちょうど4点の円の個数）

**根拠**：タプルループは `|C∩S| = 4` のときだけ `S` を生成する。

**結果（q=5）**：

```
除数 n4  -> 1,562,275  = C(26,8)  ✓
除数 e4  -> 1,741,805  ✗
e4=0 のタプル: 960
```

**仮説B も棄却。**

## 2. 現状

**q=5 では `n4` が正しい**（1,562,275 = C(26,8)）。

**q=7 では `n4` で 784,000 の差が出る。**

**同じ除数が q=5 で正しく q=7 で誤る**という矛盾。

## 3. 考えられる説明

### 3.1 q=5 では偶然一致

q=5 は `s = 6` という最小の場合。`n4` と真の多重度が偶然一致した
可能性。

**検証**：q=5 で `n4` 以外の除数も試したが、`n4` だけが整数かつ
`C(26,8)` に一致した。偶然にしては出来すぎている。

### 3.2 q=7 の組み立てに別のバグ

`arc_k8_assemble.c` の実装にバグがある可能性。

**検証**：q=5 では同じコードが正しく動いた。q=7 でだけ壊れるのは
奇妙。

### 3.3 プロファイル分布の取得ミス

`arc_k8_assemble.c` が q=7 で 21 プロファイルを生成したが、
真の分布と違う可能性。

**検証**：プロファイル公式は全数で正しいと確認済み（第227部）。
しかし**分布**（各プロファイルのタプル数）は未検証。

## 4. 次の段階

**q=7 のプロファイル分布を全数で取得し、`arc_k8_assemble.c` の
分布と比較する。**

これが最後の切り分けになる。

## 5. 意義

1. **2つの除数仮説を数値的に棄却した**（重み付き、`e4`）。
2. **q=5 と q=7 で同じ除数が異なる結果**という矛盾を明示。
3. **残る切り分けはプロファイル分布の比較**と確定。
4. **推測ではなく数値で仮説を棄却**する方針を維持。
