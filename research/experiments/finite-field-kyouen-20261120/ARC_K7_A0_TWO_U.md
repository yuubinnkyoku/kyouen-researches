# k=7 の `a=0` 層：円レベルの `u` と `T` レベルの `u` は別物

2026-11-20。`finite-field-kyouen-20261120` の第161部。

前項で `a=2` 層の型が円の性質であることを見つけた。本項は `a=0` 層で
同じことを試み、**2つの `u` を混同していた**ことを発見した。

## 1. `a=0` 層の円レベル構造

`a=0` では `W` が `C` と交わらないので `w = 0` 常に。各円 `W` は
`C(q+1,3)` 個の三つ組を持つ（q=5 で 20 個、30 円で 600）。

円ごとに「その三つ組が与える `u`」を測ると：

| 円の数 | `u` の分布（三つ組あたり） |
|---:|---|
| **20** | `u=7` が18個、`u=9` が2個 |
| **10** | `u=6` が2個、`u=8` が18個 |

**2種類の円。** 集約すると `u=6:20, u=7:360, u=8:180, u=9:40`（合計600）。

## 2. しかし `T` レベルの `u` は 1〜5

一方、6つの分布（`T` 上の `u`）を見ると：

| 分布 | `u` の範囲 | 三つ組数 |
|---|---|---:|
| D1 | 1〜4 | 240 |
| D2 | 2〜5 | 120 |
| D3 | 2〜4 | 120 |
| D4 | 2〜5 | 60 |
| D5 | 3〜4 | 40 |
| D6 | 2〜3 | 20 |

**`u` は 1〜5 の範囲にしかない。6〜9 は現れない。**

## 3. 何を混同したか

**2つの `u` は別の量である**：

- **円レベルの `u`**：三つ組を固定し、その3つのペンシルの対合の対の
  総数。`a=0` では `W` が寄与しないので、他の円から来る対合の対の数。
  値域 6〜9。
- **`T` レベルの `u`**：`T`（`C` の4点部分集合）を固定し、`T` に完全に
  入る対合の対の数。値域 1〜5。

前者は「対合が何個の対を持つか」、後者は「そのうち何個が `T` に入るか」。
**前者が後者の上限を与える**（`u_T ≤ u_circle`）が、値そのものは別。

## 4. 検証

```
T レベルの u 周辺（(三つ組,T) の組）: {1:240, 2:1500, 3:5760, 4:1380, 5:120}
  合計 9,000 = 600 × 15  ✓
円レベルの u 周辺（三つ組）:        {6:20, 7:360, 8:180, 9:40}
  合計 600  ✓
```

両方とも整合的だが、**異なる対象を数えている**。

## 5. 意義

1. **`a=0` 層の円レベル構造を明らかにした**（2種類の円、20 と 10）。
2. **2つの `u` を混同していたことを発見・訂正した**（重要な自己修正）。
3. **円レベルの `u` は `T` レベルの `u` の上限**という関係を明確にした。
4. `a=2` 層で「型が円の性質」だったのは、`a=2` では `W` 自身が
   対合に寄与するため両者が連動していたから、と説明できる。
