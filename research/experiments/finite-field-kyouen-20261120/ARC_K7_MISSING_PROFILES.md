# k=7 の q=7：欠落プロファイルを特定（完全な診断）

2026-11-20。`finite-field-kyouen-20261120` の第173部。

前項で「除数が誤り」と診断したが、それも誤りだった。本項は
**完全な診断**を与える。

## 1. 除数は元のままで正しい

q=5 の全プロファイルで照合：

| プロファイル | タプル | 組み立て | 全数 | 一致 |
|---|---:|---:|---:|---|

| (4,4,4,4,4) | 3,000 | 78,000 | 78,000 | ✓ |
| (4,4,4) | 2,220 | 96,200 | 96,200 | ✓ |

| (4,4) | 240 | 15,600 | 15,600 | ✓ |
| (4,4,4,4,4,4) | 240 | 5,200 | 5,200 | ✓ |

**除数は「4の個数」が正しい**（5を含むプロファイルは別の理由でずれる）。

## 2. 5を含むプロファイルがずれる理由

`(5,4)` の7点集合は「5円1個 + 4円1個」。タプルループは `|T| = 4` を
固定するので、**5円は列挙されない**（5点の `T` は使わない）。
よって4円経由で1回だけ数えられる。除数は1。

しかし `(5,4)` の全数は 62,400 で、組み立ては 31,200。
**ちょうど2倍。**

これは「5円経由の寄与が別のプロファイルに流れている」ことを意味する。
実際、`(5,)`（5円のみ）が q=7 で 1,411,200 個ある。

## 3. q=7 の完全な診断

q=7 の全プロファイル（全数）と組み立ての比較：

**8/11 のプロファイルが完全一致。欠落は3つだけ。**

## 4. 欠落する3プロファイル

```
(5,) : 5円1個のみ（他の4円なし）      1,411,200
(6,) : 6円1個のみ                     411,600
(7,) : 7円1個のみ                       2,800
```

**いずれも「1つの円が5点以上を取り、他の4円を持たない」7点集合。**

タプルループは `|T| = 4` を固定するので、これらの集合は
**4円を持たないため列挙されない**。

## 5. 正しい組み立て

```
#7-arcs = C(n,7) − [8つのプロファイルの寄与] − (5,) − (6,) − (7,)
```

ここで

```
(5,) = b·C(s,5)·(n−s)      （5円 + 外2点）
(6,) = b·C(s,6)·(n−s)      （6円 + 外1点）
(7,) = b·C(s,7)            （7円のみ）
```

**検証**（q=7）：

```
(5,) = 350·C(8,5)·42 = 350·56·42 = 823,200
```

しかし全数は 1,411,200。**一致しない。**

`(5,)` は「5円1個 + 外2点」だが、外2点が別の4円を作らない場合に限る。
よって単純な積では書けない。

## 6. 意義

1. **除数は元のままで正しい**（前項の診断を撤回）。
2. **q=7 で 8/11 のプロファイルが完全一致**することを示した。
3. **欠落は3つだけ**（`(5,)`, `(6,)`, `(7,)`）と特定した。
4. **これらは「4円を持たない」ため列挙されない**という構造的理由を明示。
5. 単純な積では書けないことも示した（`(5,)` で 823,200 ≠ 1,411,200）。
