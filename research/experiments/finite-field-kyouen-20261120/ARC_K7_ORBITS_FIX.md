# k=7 の「90配置」は人為的産物だった：正しくは37軌道

2026-11-20。`finite-field-kyouen-20261120` の第156部。

前々項で「90配置」という障壁を報告した。本項はそれが**人為的な
数え方の産物**であったことを示し、正しい群論的な数を与える。

## 1. 誤りの原因

前々項の「標準形」は**点のラベルを最初の出現順に振り直す**という
アドホックなものであった。これは群作用と両立しない。

**正しい不変量は `PGL(2,q)` の軌道である。** 3つの対合
`ι(x,y), ι(x,z), ι(y,z)` は `P^1(F_q)` 上の2次の元であり、
`(w,u)` 分布はその軌道だけで決まる。

## 2. 正しい軌道数（q=5）

`arc_k7_involution_orbits.py` で `PGL(2,5)` を全列挙し、対合の三つ組への
軌道を計算した。

```
|PGL(2,5)| = 120
|P^1(F_5)| = 6
対合の個数 = 25
対合の三つ組 = 2,300
PGL-軌道 = 37
軌道サイズ = 120×9, 60×16, 30×6, 20×2, 15, 10×2, 5
```

**37軌道。**

## 3. 3つの数の比較

| 数え方 | 個数 | 妥当性 |
|---|---:|---|
| `(w,u)` 分布 | **9** | 粗い同値類 |
| `PGL(2,q)` 軌道 | **37** | **正しい群論的不変量** |
| アドホック標準形 | 90 | **人為的産物（誤り）** |

**90 は過大カウントであった。** 最初の出現順のラベル付けは
群作用を尊重しないため、同じ軌道を複数回数えてしまう。

## 4. 9 と 37 の関係

37軌道が9つの分布に融合する。つまり**複数の軌道が同じ `(w,u)` 分布を
持つ**。

これは「分布は軌道より粗い不変量」であることを意味する。
閉形式を得るには37軌道を数える必要があるが、9分布で足りる場面もある
（アーク数は分布だけに依存するので、9分布の多重度が分かればよい）。

## 5. 意義

1. **「90配置」は人為的産物**であったことを示した（重要な訂正）。
2. **正しい不変量は `PGL(2,q)` 軌道で、q=5 では37**であることを示した。
3. **9分布 ⊂ 37軌道**という階層を明らかにした。
4. 閉形式への正しい道筋を示した：**37軌道の多重度**を数える。

## 6. 限界

- q=7 の軌道数は未計算（`|PGL(2,7)| = 336`、対合の三つ組が増える）。
