# k=7 のプロファイル公式：3点が定める円による完全な分解

2026-11-20。`finite-field-kyouen-20261120` の第145部。

前項で「j-三つ組でも合併サイズでもプロファイルが決まらない」ことを示した。
本項は**正しい分解**を与え、k=7 のプロファイルを完全に決定する。

## 1. 主定理

`S = T ∪ {x,y,z}`（`|T| = 4`、`T ⊂ C`、`x,y,z ∉ C`）とする。

- `W` = `x,y,z` を通る唯一の円
- `w = |T ∩ W|`（0, 1, 2）
- `u` = 「`T` と2点共有するペンシル円」の合併から `W` を除いた個数

**定理**：

```
#4円 = 1 + u + [w = 1]
#5円 = [w = 2]
```

**検証**（q=5、10/10 完全一致）：

| `w` | `u` | 予測プロファイル | 実測 |
|---:|---:|---|---|
| 0 | 1 | (4,4) | **(4,4)** ✓ |
| 0 | 2 | (4,4,4) | **(4,4,4)** ✓ |
| 0 | 3 | (4,4,4,4) | **(4,4,4,4)** ✓ |
| 0 | 4 | (4,4,4,4,4) | **(4,4,4,4,4)** ✓ |
| 0 | 5 | (4,4,4,4,4,4) | **(4,4,4,4,4,4)** ✓ |
| 1 | 1 | (4,4,4) | **(4,4,4)** ✓ |

| 2 | 0 | (5,4) | **(5,4)** ✓ |
| 2 | 1 | (5,4,4) | **(5,4,4)** ✓ |

## 2. 証明

`C' ≠ C` が `S` から4点以上取るとする。`C'` は `C` と高々2点で交わるので、
`T` からは高々2点。よって `{x,y,z}` から2点以上取る必要がある。

- `{x,y,z}` から3点取る → `C'` は `x,y,z` を通る唯一の円 `W`
- `{x,y,z}` から2点取る → `C'` はその2点のペンシルに属し、`T` と2点共有

**場合分け**：

- `w = 2`：`W` は `T` から2点、`{x,y,z}` から3点 = **5点** → 5円が1個
- `w = 1`：`W` は `T` から1点、`{x,y,z}` から3点 = **4点** → 4円が1個増
- `w = 0`：`W` は3点のみ → 4円でない

ペンシル円（`W` を除く）は各々 `T` から2点、`{x,y,z}` から2点 = 4点
→ 4円。その個数が `u`。

`C` 自身も4円。よって

```
#4円 = 1 + u + [w = 1],   #5円 = [w = 2]   □
```

## 3. なぜ前項の2つの試みが失敗したか

- **j-三つ組**：`j` は「各対のペンシル円の個数」の和であり、
  `W` が3つの `j` すべてに重複して数えられる。よって `W` の寄与
  （`w` に依存する 4 or 5）が見えない。
- **合併サイズ**：`W` を除いても、`w = 1` なら `W` 自身が4円になる。
  合併サイズだけでは `w` が分からない。

**`w`（`W` が `T` と何点共有するか）が決定的な欠落情報であった。**

## 4. 意義

1. **k=7 のプロファイルを完全に決定する公式を与えた**（10/10 一致）。
2. **前項の2つの失敗の理由を正確に説明した**：`w` の欠落。
3. **k=6 のペンシル機構を k=7 に拡張する正しい形**を示した：
   2点のペンシルに加えて**3点が定める円**が必要。
4. これで k=7 のタプル数は「`(w,u)` の分布」に帰着する。

## 5. 残る課題

`(w, u)` の同時分布の閉形式。`w` は「3点が定める円が `T` と何点共有するか」
であり、`u` は「3つのペンシルの合併サイズ」である。両者の相関を
数える必要がある。
