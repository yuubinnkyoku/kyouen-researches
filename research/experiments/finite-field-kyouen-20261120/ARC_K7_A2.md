# k=7 の `a=2` 層：q=5 では2種、q=7 では3種

2026-11-20。`finite-field-kyouen-20261120` の第160部。

前項で `a=2` 層が2つの軌道（180 と 120）に分かれることを見た。
本項はその構造を詰め、**q=5 と q=7 で種数が変わる**ことを報告する。

## 1. q=5：型は円 `W` の性質である（重要な発見）

`a=2` 層の 300 三つ組を円ごとに調べると：

```
45 円: その4つの三つ組すべてが extra-pairs (1,1,2)
30 円: その4つの三つ組すべてが extra-pairs (1,2,2)
```

```
45 × 4 = 180,  30 × 4 = 120,  合計 300  ✓
```

**型は三つ組ではなく円 `W` の性質である。** これは大きな単純化で、
`a=2` 層の分割が「2種類の円を数える」問題に帰着する。

**2種類の識別**：`W` の外の点対を通り `C` と2点で交わる円の個数。

| 型 | 追加円の個数 | 円の数 |
|---|---|---:|
| (1,1,2) | **8** | 45 |
| (1,2,2) | **10** | 30 |

`8 = 2(q−1)`, `10 = 2q`。

**閉形式（q=5）**：

```
45 = C(s,2)·(q−2) = 15·3
30 = C(s,2)·2     = 15·2
合計 = C(s,2)·q = 75  ✓
```

## 2. q=7：3種類になる（一般化の失敗）

同じ計算を q=7 で行うと：

| 型 | 追加円の個数 | 円の数 |
|---|---|---:|
| (2,2,3) | 36 | **102** |
| (2,3,3) | 39 | **84** |
| (3,3,3) | 36 | **10** |

**3種類。** 合計 196 = `C(8,2)·7 = 28·7` ✓

**q=5 の2種類の公式（`C(s,2)(q−2)` と `C(s,2)·2`）は q=7 に拡張できない**
（`28·5 = 140 ≠ 102`、`28·2 = 56 ≠ 84`）。

## 3. なぜ変わるか

q=5 では `W \ C` が4点しかないので、三つ組が1種類の構造しか持たない。
q=7 では `W \ C` が6点あり、三つ組の配置に複数の型が生じる。

**これは k=6 で「q=5 では1軌道、q=7 では2軌道」だったのと同じ現象である。**

## 4. 意義

1. **`a=2` 層の型が円 `W` の性質である**ことを発見した（q=5）。
2. **q=5 の2種類を閉形式で書いた**（`C(s,2)(q−2)` と `C(s,2)·2`）。
3. **q=7 では3種類になり、単純な一般化が失敗する**ことを示した。
4. **「小さい q の構造は大きい q に拡張しない」**という一般的教訓を再確認。
