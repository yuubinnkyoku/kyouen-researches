# k=6 の N_j：q=5 では一様、q=7 では2種類

2026-11-20。`finite-field-kyouen-20261120` の第134部。

前項で k=6 のアーク数を「第2円の個数 `N_j`」で分解した。本項は
`N_j` の構造を掘り、**q=5 と q=7 で挙動が変わる**ことを報告する。

## 1. 設定

`(C, T, {x,y})` を固定し、`x,y` を通り `T` とちょうど2点を共有する
円の個数を数える。これを `(C,T)` ごとの分布として見る。

## 2. q=5：完全に一様

```
q=5: n=26, b=130, 1950 (C,T) 組
  相異なる分布: 1
    ((0,32), (1,136), (2,22)): 1950
```

**1950 組すべてが同じ分布。** よって

```
N0 = 130 · 15 · 32  =  62400
N1 = 130 · 15 · 136 = 265200
N2 = 130 · 15 · 22  =  42900
```

全数計算の値と完全一致。

**理由**：反転平面は3重推移的で、その自己同型群は
「(円, その4点部分集合)」の組に推移的に作用する。よって分布は一様。 □

## 3. q=7：2種類に分かれる

```
q=7: n=50, b=350, 24500 (C,T) 組
  相異なる分布: 2
    ((0,284), (1,524), (2,53)): 14700
    ((0,282), (1,528), (2,51)):  9800
```

**24500 組のうち 14700 組が分布 A、9800 組が分布 B。**

| 分布 | 個数 | `N0` | `N1` | `N2` |
|---|---:|---:|---:|---:|
| A | 14,700 | 284 | 524 | 53 |
| B | 9,800 | 282 | 528 | 51 |

**加重平均**：

```
N0 = 350·70·(14700·284 + 9800·282)/24500 = 6,938,400
N1 = 350·70·(14700·524 + 9800·528)/24500 = 12,877,200
N2 = 350·70·(14700·53  + 9800·51 )/24500 =  1,278,900
```

全数計算の値（6,938,400 / 12,877,200 / 1,278,900）と**完全一致**。

## 4. 何が違うのか

2種類の分布は「`T` の4点が円 `C` 上でどのような位置にあるか」に
依存すると考えられる。q=5 では円が6点しかないので4点の配置が
1種類しかないが、q=7 では円が8点あり、4点の配置に複数の型が生じる。

**これは新しい構造的発見である**：`N_j` は `(C,T)` の**配置型**に依存し、
その型の分布は q とともに複雑になる。

## 5. 閉形式への影響

`N_j` の閉形式を得るには、次が必要である：

1. `(C,T)` の配置型の分類
2. 各型の個数
3. 各型に対する `(N0, N1, N2)`

q=5 では型が1つ、q=7 では2つ。q が大きくなると型の数は増えると
予想される。

**したがって k=6 の閉形式は「配置型の分類」に帰着する。**
これは `PG(3,q)` の平面配置の古典的問題であり、未解決。

## 6. 意義

1. **q=5 では `N_j` が完全に一様**であることを示した（3重推移性による）。
2. **q=7 では2種類に分かれる**ことを発見した。
   一様性は一般には成り立たない。
3. **`N_j` の閉形式は「(C,T) の配置型の分類」に帰着する**ことを示した。
4. 加重平均が全数計算と一致することを確認し、分解が正しいことを再確認。

## 7. 限界

- 配置型の完全な分類は未取得（q=5 で1型、q=7 で2型のみ判明）。
- q ≥ 8 では未測定（6点集合の全数計算が重い）。
- k=6 の閉形式は依然未取得。
