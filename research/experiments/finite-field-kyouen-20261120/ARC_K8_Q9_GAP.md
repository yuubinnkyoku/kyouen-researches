# k=8 の q=9 組み立て：単一円プロファイルの欠落（重要な訂正）

2026-11-20。`finite-field-kyouen-20261120` の第217部。

k=8 の組み立てを q=9 で実行し、**全数と大きく食い違う**ことを発見した。
原因は**単一円プロファイルの欠落**である。

## 1. 結果

| 量 | 組み立て | 全数（C 実装） |
|---|---:|---:|
| `bad` | 35,521,382,790 | 35,640,407,430 |
| `arcs` | **120,087,360** | **1,062,720** |

**差は 119,024,640。**

## 2. 原因：単一円プロファイルの欠落

組み立ては `(7,)` と `(8,)` のみを別項として加えていた：

```
(7,) = b·C(s,7)·(n−s) = 6,376,320
(8,) = b·C(s,8)       =    33,210
```

**しかし q=9 では `s = 10` なので、`(5,)` と `(6,)` も存在する。**

| プロファイル | 上限 | 意味 |
|---|---:|---|
| `(5,)` | 11,091,608,640 | 5点円 + 外3点 |
| `(6,)` | 396,128,880 | 6点円 + 外2点 |
| `(7,)` | 6,376,320 | 7点円 + 外1点 |
| `(8,)` | 33,210 | 8点円のみ |

**差 119,024,640 は `(5,)` と `(6,)` の寄与。**

## 3. q=7 では問題にならなかった理由

q=7 では `s = 8`。単一円プロファイルは `(5,)`, `(6,)`, `(7,)` の3つで、
**`(5,)` と `(6,)` は既に別項として加えていた**（第174部）。

q=9 では `s = 10` になり、`(5,)` と `(6,)` の形が変わる
（外点の数が 3 と 2 になる）ため、**別項の式が使えない**。

## 4. 正しい式

```
(5,) = b · #{T5 ⊂ C, Y ⊂ 外点 (|Y|=3) : ペンシル円が T5 と2点で交わらない}
(6,) = b · #{T6 ⊂ C, Y ⊂ 外点 (|Y|=2) : ペンシル円が T6 と2点で交わらない}
```

**`(5,)` と `(6,)` は「他の4円を作らない」条件付きで、単純な積では
書けない**（第174部で `(5,)` について示したのと同じ構造）。

## 5. 意義

1. **q=9 の組み立てが全数と食い違うことを発見した**（重要な訂正）。
2. **原因を特定した**：`(5,)` と `(6,)` の単一円プロファイルの欠落。
3. **q=7 で成功したのは `s=8` という特殊事情**だったことを明示。
4. **一般の q では `(5,)` から `(q+1,)` までのすべてが必要**と確定。
5. **k=8 の閉形式は q=5,7 でのみ検証済み**であり、q=9 では未完成。

## 6. 限界

- `(5,)` と `(6,)` の閉形式は未取得（条件付き）。
- q=9 の組み立ては未完成。
- q=11 の k=8 は実行中（全数）。
