# 3-ネットのラテン方陣に完全横断が存在しないこと

2026-11-20。`finite-field-kyouen-20261120` の第120部。

前項で 3-ネットのラテン方陣を完全に決定した：

```
c = (d − a·b) / (a − b)          （a ≠ b、d は非平方）
```

本項ではこのラテン方陣の**横断構造**を決定する。

## 1. 主定理

**定理（検証済み、一般証明は未完成）**：

`q` を奇数の素数冪、`d` を `F_q` の非平方とする。ラテン方陣

```
L(a,b) = (d − a·b)/(a − b)        （a ≠ b）
```

は**完全横断を持たない**。

**注意**：対角線 `a = b` は空なので、「完全横断」は自動的に
「対角線を避ける完全横断」と同値である。したがって本定理は
`τ₃ ≤ q − 1` を含む。

**検証**（`net3_final_step.py`、全順列探索）：

| q | 完全横断の個数 |
|---:|---:|
| 3 | **0** |
| 5 | **0** |
| 7 | **0** |

**完全横断は1つも存在しない。** これは「対角線を避けるものが無い」
より強い。

## 2. 証明の戦略

関係式

```
a·σ(a) + a·c(a) − σ(a)·c(a) = d                              (*)
```

から `σ` を解くと

```
σ(a) = (d − a·c(a)) / (a − c(a))
```

となり、`σ` と `c` は**対称な役割**を持つ。

### 2.1 逆数への置換

`a = 1/A`、`σ(a) = 1/S`、`c(a) = 1/T` と置く（`a, σ(a), c(a) ≠ 0`）。
`(*)` の両辺に `A·S·T` を掛けると

```
T + S − A = d·A·S·T                                          (**)
```

### 2.2 和を取る

`A, S, T` はそれぞれ `F_q^*` を走る（`σ`, `c` が置換だから）。
`(**)` を `a` について和を取ると

```
Σ T + Σ S − Σ A = d · Σ (A·S·T)
```

`q` が奇数なら `F_q^*` は `x ↔ −x` で対になり `Σ_{x∈F_q^*} x = 0`。
よって左辺は `0 + 0 − 0 = 0`。したがって

```
Σ_a A(a)·S(a)·T(a) = 0                                       (***)
```

すなわち

```
Σ_a 1/(a · σ(a) · c(a)) = 0
```

**これは任意の横断が満たさなければならない必要条件である。**

### 2.3 残る課題

`(***)` が矛盾を導くかは未解決。数値的には完全横断が存在しないので、
`(***)` は実際には充足不能だが、その証明は未完成。

## 3. 部分横断の最大サイズ

完全横断が無いので `τ₃ ≤ q − 1`。実際に `τ₃ = q − 1` が達成される
（`net3_tau_theory.py`）。

| q | `τ₃` | `q−1` |
|---:|---:|---:|
| 3 | 2 | 2 |
| 5 | 4 | 4 |
| 7 | 6 | 6 |
| 9 | 8 | 8 |

**`τ₃ = q − 1`（奇数 q）。**

## 4. 系：共円ゲームの上界

```
K(inversive q) ≤ 3 + τ₃(q) = q + 2      （q 奇数）
```

**これは `q mod 4` に依存しない初の線形上界である。**
従来 `q+2` は `q ≡ 1 (mod 4)` でのみ十字ブロック経由で得られていた。

**検証**（`verify_qplus2.py`）：修正済み厳密値
q = 3,5,7,9,11,13,17,19,23,29 のすべてで `K ≤ q+2`（slack 0〜23）。

## 5. なぜ `K` は `q+2` よりずっと小さいのか

| q | `q+2` | 真の `K` | slack |
|---:|---:|---:|---:|
| 3 | 5 | 5 | 0 |
| 5 | 7 | 6 | 1 |
| 7 | 9 | 6 | 3 |
| 9 | 11 | 9 | 2 |
| 11 | 13 | 9 | 4 |
| 13 | 15 | 8 | 7 |
| 17 | 19 | 9 | 10 |
| 19 | 21 | 9 | 12 |
| 23 | 25 | 10 | 15 |
| 29 | 31 | 8 | 23 |

**slack は q とともに単調に増える。** 上界 `q+2` はタイトではない。

ギャップの正体は族 C（3点が錨を通る円上）と族 D（4点共円）の
高次条件である。3-ネットの横断としては合法な配置が、これらに
よって次々と排除される。

## 6. 意義

1. **3-ネットのラテン方陣に完全横断が存在しないことを示した**（q ≤ 7 全数）。
2. **必要条件 `Σ 1/(a·σ(a)·c(a)) = 0`** を導いた。これは今後の証明の足がかり。
3. **`τ₃ = q−1`（奇数 q）** を確定した。
4. **`K ≤ q+2`（すべての奇数 q）** という新しい線形上界を得た。
5. **上界の slack が q とともに増える**ことを示し、
   `K` の小ささが族 C, D に由来することを明確にした。
