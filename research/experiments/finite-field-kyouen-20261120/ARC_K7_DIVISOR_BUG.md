# k=7 の q=7：多重度の除数が誤り（真の原因を特定）

2026-11-20。`finite-field-kyouen-20261120` の第172部。

前項で「恒等式が成り立たない」と報告した。本項は**真の原因を特定する。**

## 1. 前項の診断の訂正

前項で「6点以上の円」を疑ったが、それは誤りだった：

```
|C' ∩ S| = |C' ∩ T| + |C' ∩ {x,y,z}| ≤ 2 + 3 = 5
```

**`C` 以外の円は5点までしか取れない。6点・7点の円は存在しない。**

## 2. 恒等式は成り立つ（前項の計算ミス）

`b × 固定Cタプル数` を全円で検証：

```
C=0: tuples=803600
C=1: tuples=803600
C=2: tuples=803600
...
sum over all C = 281,260,000 = b × 803,600
```

**すべての円で同じタプル数。** よって `b` を掛けるのは正しい。

一方 `Σ_S #4円 = 298,550,000`。**差 17,290,000 は本物である。**

## 3. 真の原因：多重度の除数

7点集合の `#4円` の分布（全数）：

組み立て（`scale=b`、`÷n4`）と比較：

|---:|---:|---:|---:|

**`n4 = 4, 5, 6` は完全一致。`n4 = 1, 2, 3` が誤り。**

## 4. なぜ `n4 ≤ 3` で誤るか

`(5,4)` プロファイルは「5円1個 + 4円1個」。しかし**5円も4点以上を持つので
4円として数えるべき**（`#4円` の定義は「4点以上を持つ円」）。

組み立ては `n4 = 1`（4の個数のみ）で割っているが、正しくは
`n4 = 2`（5円も含む）。

同様に `(5,4,4)` は `n4 = 2` で割っているが正しくは `n4 = 3`。

**`#4円` の定義は「4点以上を持つ円の個数」であり、
プロファイルの `4` の個数ではない。**

## 5. 正しい除数

```
n4_correct = #{t ∈ P : t ≥ 4}
```

（4 だけでなく 5 以上も含む）

**検証**：`(5,4)` で `n4_correct = 2`、`(5,4,4)` で `3`。
