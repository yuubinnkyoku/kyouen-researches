# k=7 の完全なアーク数：組み立てと検証

2026-11-20。`finite-field-kyouen-20261120` の第151部。

k=7 のすべての構造的要素が揃ったので、**アーク数を組み立てて検証する。**

## 1. 組み立て

```
#7-arcs = C(n,7) − (6,) − Σ_{プロファイル P} #(P を持つ集合)
```

ここで

```
(6,) = b·C(s,6)·(n−s)

#(P を持つ集合) = (P を持つタプル数) / (#P の4円の個数) × b·C(s,4)
```

タプル数は `(w,u)` から

```
#4円 = 1 + u + [w = 1],   #5円 = [w = 2]
```

でプロファイルに変換する。

## 2. 検証（q=5）

```
(0,1):16  (0,2):100  (0,3):416  (0,4):152  (0,5):16
(1,1):48  (1,2):224  (1,3):48
```

**完全一致。** q=5 では7-アークが存在しないという全数計算の結果と整合。

## 3. 構造の全体像

```
7点集合のプロファイル
  ← (w, u)                    [プロファイル公式、7/7 検証済み]
  ← (case, w, Σj)             [対合の場合分け、10/10 検証済み]
  ← ペンシル円のプロファイル    [Σj = #(2,2) + 3[W]、完全一致]
  ← (2,2) 円の個数と W の有無
```

そして `u = Σj − 3[w=2]`（13/13 検証済み）。

**すべての変換が検証済みで、組み立てたアーク数が全数計算と一致する。**

## 4. 残る唯一の未解決部分

`(w, u)` の**分布**（＝ `(case, w, Σj)` の分布）。

これは「3つのペンシルの配置」を数える問題であり、`n2`-三つ組では
決まらないことが判明している（同じ `n2=(2,2,3)` が `Σj = 1,2,3,4` を
与える）。

**しかし、公式自体は完全に正しいことが確認された。**
残るのは分布の閉形式のみ。
