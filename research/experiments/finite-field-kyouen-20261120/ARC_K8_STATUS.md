### 1.5 `v4 + u4 + z4 = [X が共円]`

3つは互いに排反で、和が共円性の指示関数。q=5 で完全整合。

### 1.6 6類の和の閉形式（q=5 で 6/6 検証）

```
sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(m−q+1,2)
sum v3 = C(s,2)·q · C(s−2,2) · C(q−1,3)·C(m−q+1,1)
sum v4 = Σ_j N_j·C(s−j,4) · C(j,2)·C(s−j,2)
sum u3 = s(q−1)·C(s−1,3)·G(q,m)
       + C(s,2)·q·2·C(s−2,3)·G(q−1,m) − sum u4
sum u4 = Σ_j N_j·C(s−j,4) · C(j,1)·C(s−j,3)
sum z4 = Σ_j N_j·C(s−j,4) · C(j,0)·C(s−j,4)

N_0 = (b−1) − C(s,2)q − s(q−1),  N_1 = s(q−1),  N_2 = C(s,2)q
G(y,m) = C(y,3)·C(m−y,1) + C(y,4)
```

## 3. 撤回した誤診（記録）

| # | 誤診 | 撤回の理由 |
|---|---|---|
| 1 | 「6点以上の円」が原因 | `\|C'∩S\| ≤ 6` で6点円は存在しうるが、k=8 の差とは無関係 |
| 2 | 「除数が誤り」 | 8/11 プロファイルが完全一致していた |

**4回の誤診すべてが「数値の一致を構造的証拠と早合点」から生じた。**
