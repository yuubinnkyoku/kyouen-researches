# k=7 の双対構成：9つの型で `(w,u)` 分布を完全に再現

2026-11-20。`finite-field-kyouen-20261120` の第152部。

前項まで `(w,u)` の分布が唯一の未解決部分だった。本項は**双対の視点**
（三つ組を固定して `T` を動かす）で、その分布を**9つの型**に分解する。

## 1. 双対の視点

これまでは `T` を固定して `{x,y,z}` を動かした（primal）。
本項は逆に、**`{x,y,z}` を固定して `T` を `C` の4点部分集合全体で動かす**。

三つ組が決まれば

- `W` = 三つ組を通る円
- 3つの対合 `ι(x,y), ι(x,z), ι(y,z)`

が決まり、`w = |T ∩ W|` と `u`（`T` に完全に入る対合の対の数）は
`T` の関数になる。

## 3. 集約（定理）

双対の数え上げは `(三つ組, T)` の組を数える。primal は `(T, 三つ組)` を
数えるので、`C(s,4) = 15` で割れば変換できる。

さらに `w = 2` のとき、共通対 `W ∩ C` は**3つの対合すべてに属する**ので
双対の `u` はそれを1回含む。primal の `u` は `W` を除くので **1を引く**。

```
u_primal = u_dual − [w = 2]
```

## 4. 意義

1. **`(w,u)` 分布を9つの型に完全に分解した**（10/10 一致）。
2. **双対の視点が primal より構造的**であることを示した：
   三つ組を固定すると `(w,u)` は `T` 上の小さな組合せ問題になる。
3. **`u_primal = u_dual − [w=2]`** という変換則を得た。
4. 各型の分布が `C(s,4) = 15` に和するという健全性チェックも通る。
