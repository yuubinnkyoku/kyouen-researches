# D(n) の三点分解による全数確認（n ≤ 12）

2026-11-20。`finite-field-kyouen-20261120` の第8部。
転送閾値 `D(n) = max |Delta|` を、四点組の全列挙ではなく**三点分解**で計算する方法を示し、
n ≤ 12 まで全数確認した。

## 1. なぜ三点分解か

四点組の全列挙は `C(n²,4)` 通りで、n=8 で 6.4×10^5、n=12 で 1.4×10^7 と急増する。
これに対し、行列式を最後の行について余因子展開すると

```
Delta(x,y) = alpha·x + beta·y + gamma·(x²+y²) + delta
```

という形になる。係数 `(alpha,beta,gamma,delta)` は**最初の三点だけで決まる 3×3 小行列式**である。
したがって

1. 三点 `(p1,p2,p3)` を選ぶ（`C(n²,3)` 通り）
2. その係数から、正方形 `[0,a]²` 上の `|Delta|` の最大を求める（`(a+1)²` 通りの評価）

で `D(n)` が計算できる。`C(n²,3)·n²` は `C(n²,4)` よりはるかに小さい。

さらに `Delta` は `x` と `y` について分離した二次式（交差項なし）なので、
最大は正方形の**境界**で達成される。この性質を使えば評価は `O(n)` に落ちるが、
本実装では単純に全点評価した（n≤12 では十分速い）。

## 2. 係数公式の検証

`det_max_structure.py` の `verify_coeffs` が、n=5 の全三点・全四点について
係数展開の値と直接 4×4 行列式の絶対値が一致することを確認した（不一致 0）。

注意：展開は**大域的な符号規約**の分だけ直接計算とずれる（`|Delta|` は一致する）。
`D(n)` は絶対値の最大なので影響しない。

## 3. 結果：n ≤ 12 で公式と全数一致

| n | a=n−1 | D(n) | 公式 a²⌊a²/2⌋ | 一致 |
|---:|---:|---:|---:|---|
| 3 | 2 | 8 | 8 | ✓ |
| 4 | 3 | 36 | 36 | ✓ |
| 5 | 4 | 128 | 128 | ✓ |
| 6 | 5 | 300 | 300 | ✓ |
| 7 | 6 | 648 | 648 | ✓ |
| 8 | 7 | 1,176 | 1,176 | ✓ |
| 9 | 8 | 2,048 | 2,048 | ✓ |
| 10 | 9 | 3,240 | 3,240 | ✓ |
| 11 | 10 | 5,000 | 5,000 | ✓ |
| 12 | 11 | 7,260 | 7,260 | ✓ |

**n=8〜12 は四点組の全列挙では到達できなかった範囲**であり、
三点分解によって初めて全数確認できた。以前の報告（n≤7 の全数＋n≥8 のランダム探索）を
厳密な全数確認へ格上げするものである。

## 4. 極値配置

各 n で最大を与える三点と四点目は、常に「三隅＋対角点」の形をとる。
例えば n=12（a=11）では三点 `(0,0),(11,0),(0,11)` と四点目 `(5,5)` または `(6,6)` で
`|Delta| = 7260` に達する。これは `−2a²t(a−t)` に `a=11, t=5` を代入した
`2·121·5·6 = 7260` と一致する。

## 5. 残る証明課題

三点分解は**計算**を速くしたが、**証明**は与えない。示すべきは

> 任意の三点 `(p1,p2,p3)` と任意の四点目 `(x,y) ∈ [0,a]²` に対し
> `|alpha·x + beta·y + gamma·(x²+y²) + delta| ≤ a²⌊a²/2⌋`

である。係数は三点の座標の 3×3 小行列式で、`alpha,beta,gamma` は
「三点を通る円の方程式の係数」に他ならない。したがってこれは
**「格子正方形上での円の方程式の値の上界」**という幾何的な主張になる。

現時点で完全な証明は得ていない。ただし次の観察は証明の足がかりになる：

- `gamma ≠ 0` のとき（三点が非共線）、`Delta/gamma` は四点目の円に関する**べき**である。
- 三点が格子点なら円の中心と半径は有理数で、分母は `2·gamma` を割る。
- 正方形の四隅でのべきの最大値が、内部での最大値を支配する（分離二次式の凸性）。

## 6. 限界

- n ≤ 12 の全数確認であり、全称証明ではない。
- 三点分解の計算量は `O(n^7)` 程度で、n=20 程度が実用上限。
- 係数展開の符号規約は実装依存で、`|Delta|` のみを扱う。
