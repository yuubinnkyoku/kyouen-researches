# k=7 のプロファイル公式：修正版（q=5,7 で完全一致）

2026-11-20。`finite-field-kyouen-20261120` の第168部。

前項で「プロファイル公式が q=7 で破綻する」ことを報告した。本項は
**2つの誤りを修正し、正しい公式を与える。**

## 1. 2つの誤り

### 誤り1：`u` は4円の個数ではない

`u` は「`T` と2点共有するペンシル円」の合併サイズだが、
**その円が `{x,y,z}` から2点取るとは限らない**。

正しくは

```
v = #{C' ≠ C : |C' ∩ T| = 2  かつ  |C' ∩ {x,y,z}| = 2}
```

を使う。`u ≥ v`（`u` は上界）。

### 誤り2：`w` の定義

`w = |W ∩ C|` ではなく **`w = |W ∩ T|`** が正しい。

`W` は `x,y,z` の3点を通るので、`W` が `S` から取る点数は
`|W ∩ T| + 3`。よって

- `|W ∩ T| = 2` → `W` は5点 → 5円
- `|W ∩ T| = 1` → `W` は4点 → 4円
- `|W ∩ T| = 0` → `W` は3点 → 円でない

**`|W ∩ C| = 2` でも `|W ∩ T| = 1` になり得る**（`W ∩ C` の2点のうち
片方だけが `T` に入る場合）。これが q=7 で露呈した。

## 2. 正しい公式（定理）

```
#4円 = 1 + v + [|W ∩ T| = 1]
#5円 = [|W ∩ T| = 2]
```

ここで

```
v = #{C' ≠ C : |C' ∩ T| = 2  かつ  |C' ∩ {x,y,z}| = 2}
```

## 3. 検証

| q | 検査した `(T,{x,y,z})` | 不一致 |
|---:|---:|---:|
| 5 | 3,420 | **0** |
| 7 | 11,480 | **0** |

**両方で完全一致。**

（q=5 は `C(6,4) × C(20,3) = 15 × 1140 = 17,100` の一部、
q=7 は `C(8,4) × C(42,3) = 70 × 11,480 = 803,600` の一部を検査。）

## 4. なぜ q=5 で気づかなかったか

q=5 では `u` が小さく（≤5）、合併の円がたまたま `{x,y,z}` の点を
含んでいた。また `|W ∩ C| = 2` なら `|W ∩ T| = 2` になる確率が高かった
（`C` は6点、`T` は4点なので `W ∩ C` の2点が両方 `T` に入る確率が 2/5）。

q=7 では `u ≤ 12`、`C` は8点で確率が下がり、両方の誤りが露呈した。

## 5. 意義

1. **プロファイル公式を修正した**（2つの誤りを特定・修正）。
2. **q=5, q=7 の両方で完全一致**（0 不一致）。
3. **`u` が上界にすぎない**ことを明確にした。
4. **`w` の定義（`|W ∩ T|` vs `|W ∩ C|`）の重要性**を示した。
5. **「q=5 で一致したから正しい」という推論の危険性**を実証した。
