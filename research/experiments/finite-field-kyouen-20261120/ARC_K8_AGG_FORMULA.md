# k=8 の `v2+v3+v4` の閉形式：`C(s−2,2)` 分解

2026-11-20。`finite-field-kyouen-20261120` の第208部。

k=8 の残る3類のうち `v2+v3+v4` の和の閉形式を導出した。

## 1. 測定値（q=5）

| 量 | 値 |
|---|---:|
| `sum v2` | 324,000 |
| `sum v3` | 28,800 |
| `sum v4` | 450 |
| **`sum v2+v3+v4`** | **353,250** |
| `sum u3` | 74,400 |
| `sum u4` | 1,800 |
| **`sum u3+u4`** | **76,200** |
| `sum z4` | 7,425 |
| タプル数 | 72,675 |

## 2. 定理：`sum(v2+v3+v4)` の分解

`sum(v2+v3+v4)` は「`|C'∩T|=2` かつ `|C'∩X|≥2`」の三つ組
`(T, X, C')` を数える。

**固定した `C'`（`|C'∩C| = 2`）に対し**：

- `T` は `C'∩C` の2点を含む必要がある → `T = {a,b} + C` から2点
  → `C(s−2, 2)` 通り
- `Y = C' − C`（`C'` の `C` 外の点）とすると `|C'∩X| = |Y∩X|`
- `X` は外点の4点部分集合で `|Y∩X| ≥ 2`

**よって**

```
sum(v2+v3+v4) = C(s−2,2) × Σ_{C' : |C'∩C|=2} #{X : |Y∩X| ≥ 2}
```

## 3. 検証（q=5）

**`|Y|` の分布**（`|C'∩C|=2` の円 75 個）：

```
|Y| = 4 が 75 個（すべて同じ）
```

**これは構造的事実**：`C'` が `C` と2点で交わるとき、`C'` の残り
`s−2 = 4` 点はすべて `C` の外にある（`C'` のサイズが `s` なので）。

**計算**：

```
Σ_{C'} #{X : |Y∩X| ≥ 2} = 58,875
C(s−2,2) = C(4,2) = 6
6 × 58,875 = 353,250
```

**実測 353,250 と完全一致。**

## 4. `|Y| = 4` の意味

`C'` は `s = q+1` 点の円。`C` と2点で交わるので、残りは `s−2 = q−1` 点。

**q=5 では `s−2 = 4`。** よって `|Y| = 4` が常に成り立つ。

**一般の q では `|Y| = q−1`。**

## 5. `#{X : |Y∩X| ≥ 2}` の閉形式

`|Y| = q−1`、外点は `n−s` 個、`X` は4点部分集合。

```
#{X : |Y∩X| ≥ 2} = C(n−s,4) − C(n−s−(q−1),4) − (q−1)·C(n−s−(q−1),3)
```

（全体 − `|Y∩X|=0` − `|Y∩X|=1`）

**検証（q=5）**：`|Y|=4`、`n−s=20`。

```
C(20,4) − C(16,4) − 4·C(16,3)
= 4845 − 1820 − 4·560
= 4845 − 1820 − 2240
= 785
```

`75 × 785 = 58,875` ✓

## 6. 定理（完成形）

```
sum(v2+v3+v4) = C(s−2,2) · C(s,2)·q · [C(n−s,4) − C(n−s−q+1,4)
                                        − (q−1)·C(n−s−q+1,3)]
```

（`C(s,2)·q` は `|C'∩C|=2` の円の個数。）

**検証（q=5）**：`6 × 15 × 5 × 785 = 353,250` ✓

## 7. 意義

1. **`sum(v2+v3+v4)` の閉形式を導出した**（q=5 で完全一致）。
2. **`|Y| = q−1`** という構造的事実を発見。
3. **`#{X : |Y∩X| ≥ 2}` の閉形式**を得た。
4. **`v4` は既知**（共円性）なので、`v2+v3` が求まる。
5. 残るは `v2` と `v3` の分離、および `u3`。
