# k=7 の `Σj`：ペンシル円のプロファイルによる完全な決定

2026-11-20。`finite-field-kyouen-20261120` の第150部。

前項で `(w,u)` を `(case, w, Σj)` に分解した。本項は `Σj` の構造を
**ペンシル円のプロファイル**で完全に決定する。

## 1. 主定理

`{x,y,z}` の各対のペンシルから「`T` と2点共有する円」を集め、
各円を `(|C' ∩ {x,y,z}|, |C' ∩ T|)` で分類する。

**定理1**：そのような円は必ず `|C' ∩ T| = 2` であり、
`|C' ∩ {x,y,z}| ∈ {2, 3}`。

**定理2**：`|C' ∩ {x,y,z}| = 3` の円は `W`（3点を通る唯一の円）であり、
それが現れるのは `w = 2` のときに限る。

**定理3**：

```
Σj = #{(2,2) 円} + 3·[W が現れる]
```

**証明**：`(2,2)` 円は `{x,y,z}` の1つの対にしか属さないので `Σj` に1回
寄与する。`W` は3つの対すべてに属するので3回寄与する。 □

## 4. 意義

1. **`Σj` をペンシル円のプロファイルで完全に決定した**（周辺分布が一致）。

4. k=7 の全体が「`(2,2)` 円の個数」と「`W` の有無」に帰着した。
