# サイズを使った上界はすべて λ₂+2 より弱い

2026-11-20。`finite-field-kyouen-20261120` の第80部。
「ブロックサイズ効果」を上界に翻訳する試みと、その失敗の記録。

## 1. 試した二つのサイズ利用法

### (1) 重み付きペア数え上げ

各ブロックをサイズ `|B|` で重み付けしてペアを数える：

```
μ₂ · C(k,2) ≤ 3 · Σ_B |B|
```

ここで `μ₂ = Σ_{B ∋ a,b} |B|`（ペアを通るブロックのサイズ和）。

### (2) ペンシルのサイズ和

`p,q` を通るペンシルのブロックは `{p,q}` の外で互いに素なので

```
k − 2 ≤ Σ_{B ∈ pencil} (|B| − 2)
```

## 2. 結果

| q | 重み付きペア上界 | ペンシルサイズ上界 | **λ₂ 上界** |
|---:|---:|---:|---:|
| 5 | 12 | 25 | **8** |
| 7 | 16 | 49 | **10** |

**サイズを使った上界はすべて `λ₂+2 = q+3` より弱い。**

## 3. なぜ弱いか

### 重み付きペア

`μ₂` が大きい（q=7 で 63）ため、左辺が急速に増えて上界が緩くなる。

### ペンシルのサイズ和

ペンシルのブロックは `{p,q}` の外で互いに素なので、サイズ和は
`q²−2` 程度と大きい（q=7 で 47）。したがって `k ≤ q²` 程度の弱い上界しか出ない。

## 4. λ₂ 上界が強い理由

`λ₂` 上界の証明：

> `p,q` を固定。`S\{p,q}` の各点 `r` は `p,q` を通る異なるブロックを必要とする。
> そのようなブロックは `λ₂` 個しかない。よって `k−2 ≤ λ₂`。

**この証明はブロックのサイズを一切使わない。** `λ₂` という「本数」だけを使う。

サイズを使おうとすると、ペンシルのブロックが互いに素であるという性質から
「サイズ和」が大きくなり、上界が緩む。

## 5. 意義

- 「ブロックサイズ効果」は実験的には明確（単一族で K がサイズに単調減少）。
- しかし**上界の証明には翻訳できない**ことが分かった。
- `λ₂` 上界 `q+3` が依然として最良。
- サイズ効果は「実際の K を下げる」が「証明可能な上界を下げる」わけではない。

## 6. 失敗した手法の一覧（更新）

| 手法 | 結果 |
|---|---|
| 次数 | 制約なし |
| 複数ペンシル | `λ₂+2` のまま |
| 被覆 | q=3 のみ |
| 円ペア | 制約なし |
| 円のプロファイル | `λ₂+2` を再現 |
| **サイズ重み付きペア** | **12, 16（弱い）** |
| **ペンシルサイズ和** | **25, 49（非常に弱い）** |

## 7. 限界

- q=5, 7 のみ。
- 他の重み付け（例：`1/C(s,3)`）は未検討。
- サイズ効果を上界に翻訳する別の方法は未発見。
