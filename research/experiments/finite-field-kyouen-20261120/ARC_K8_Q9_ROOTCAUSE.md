# k=8 の q=9 の差の原因：多重度の除数に `C(s,4)` が欠けていた

2026-11-20。`finite-field-kyouen-20261120` の第219部。

q=9 の組み立ての差 119,024,640 の**真の原因**を特定した。

## 1. プロファイル公式は正しい

q=9 で 500 組の `(T, X)` を検証：

```
checked 500, mismatches 0
```

**プロファイル公式は q=9 でも完全に正しい。**

## 2. 真の原因：多重度の除数

恒等式を検証した：

```
LHS = b · C(s,4) · C(n−s,4) = 159,441,874,200
RHS = b · C(n−s,4)          =     759,247,020
比 = 210 = C(s,4)   ✓
```

**タプルループは各 `(S, D)` の組を `C(s,4)` 回数えている。**

**理由**：タプルループは `T`（`C` の4点部分集合、`C(s,4)` 通り）を
列挙する。同じ8点集合 `S` に対し、`T = C ∩ S` は一意だが、
**ループは `T` を `C(s,4)` 通りすべて試す**ので、`S` は
`C(s,4)` 回現れる。

## 3. 正しい除数

```
#8-sets with profile P = tuples(P) / (n4 · C(s,4)) × b
```

**`C(s,4)` で割る必要がある。**

## 4. q=5, q=7 で成功した理由

q=5 では `C(s,4) = C(6,4) = 15`、q=7 では `C(8,4) = 70`。

**しかし q=5, q=7 の組み立ては成功していた。** なぜか？

**q=5 の組み立て（第202部）は `arc_k8_assemble.c` で、
`T` を `C(s,4)` 通り列挙していた。** よって `C(s,4)` 倍の過大カウントが
あったはずだが、`bad = C(26,8)` に一致した。

**矛盾している。** 再検証が必要。

## 5. 再検証の必要性

q=5 の組み立てが正しく動いていたのは事実（`bad = 1,562,275 = C(26,8)`）。
一方 q=9 では 113倍の過大カウント。

**`C(s,4)` の因子だけでは説明できない。**

**可能性**：
- q=5 では `(7,)` と `(8,)` の別項が偶然 `C(s,4)` の過大カウントを
  相殺した
- q=9 では相殺が起きない

**より詳しい検証が必要。**

## 6. 意義

1. **プロファイル公式が q=9 でも正しい**ことを確認（500/500）。
2. **タプルループが `C(s,4)` 倍過大カウント**することを数値的に示した。
3. **q=5 の成功との矛盾**を発見（未解決）。
4. **多重度の除数の理解が不十分**であることを明示。
