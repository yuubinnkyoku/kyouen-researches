# サイズ q−1 ブロックの正体：直線対ではない

2026-11-20。`finite-field-kyouen-20261120` の第77部。
`q ≡ 1 (mod 4)` の盤に現れるサイズ `q−1` のブロックの構造を調べた。

## 1. 観察

q=5 のサイズ4ブロックの例：
```
(1,0), (1,2), (4,0), (4,2)
```

q=9 のサイズ8ブロックの例：
```
(0,0), (0,1), (0,2), (1,1), (1,2), (2,1), (2,2), ...
```

**いずれも「すべて共線」ではない。**

## 2. 何者か

`x²+y²+Dx+Ey+F=0` が `q ≡ 1 (mod 4)` で分解するとき、
`(x+iy+a)(x-iy+b) = 0` は2本の直線（傾き ±i）の和集合になる。
これはサイズ `2q−1` の十字。

しかしサイズ `q−1` のブロックは別物である。

**推測**：`x²+y²+Dx+Ey+F=0` が「重解」を持つ場合、
すなわち判別式が 0 の場合、円は1本の直線（二重線）に退化する。
しかし直線はサイズ `q` なので `q−1` ではない。

別の可能性：**円が「空集合に近い」場合**。
`x²+y²+Dx+Ey+F=0` の解が `q−1` 個しかない場合がある。

実際、q=5 の例 `(1,0), (1,2), (4,0), (4,2)` を見ると、
x 座標が 1 と 4 のみ、y 座標が 0 と 2 のみ。
つまり「2×2 の格子」である。

これは `x²+y²+Dx+Ey+F=0` が
`(x−1)(x−4) = 0` かつ `(y−0)(y−2) = 0` 的な構造を持つことを示唆する。

## 3. 構造の意味

サイズ `q−1` のブロックは「**2つの値の組の直積**」的な構造を持つ。
これは十字（列＋行）とは異なる。

**重要な点**：このブロックは「格子状」の構造を持ち、
安全集合を「格子状」に配置することを妨げる。

## 4. 真円との比較

| ブロック種別 | サイズ | 構造 | 制約の強さ |
|---|---|---|---|
| 真円（q≡3 mod 4） | q+1 | 円錐曲線 | **強い** |
| 退化円（q≡1 mod 4） | q−1 | 格子状 | 弱い |
| 十字（q≡1 mod 4） | 2q−1 | 列＋行 | 強い |
| 直線 | q | 直線 | 弱い |

真円は「どの3点も共線でない」ので、3点を選ぶと必ずその円が定まる。
一方、格子状の退化円は「共線三点」を多く含むので、制約が弱い。

## 5. 意義

- サイズ `q−1` ブロックの構造を初めて観察した。
- 直線対ではなく「格子状」の構造を持つ。
- 真円（円錐曲線）は共線三点を含まないため制約が強い。
- 退化円は共線三点を含むため制約が弱い。
