# k=7 の `(w,u)` 分布：対合の場合分けによる完全な再構成

2026-11-20。`finite-field-kyouen-20261120` の第149部。

前項で `u = Σj − 3[w=2]` を証明した。本項は `(w,u)` 分布を
**対合の場合分けで完全に再構成**する。

## 1. 場合分け

3つの対合 `ι(x,y), ι(x,z), ι(y,z)` は

- **場合 A**：互いに素（840 三つ組）
- **場合 B**：ちょうど1つの共通対（300 三つ組）

**定理**：場合 A では `w ≤ 1`。

**証明**：場合 A では3つのペンシルが素なので、`{x,y,z}` の2点を通り
`T` と2点共有する円は3点目を通らない。`W` は3点すべてを通るので、
`W` がペンシルに属するなら矛盾。よって `W` は `T` と2点共有しない、
すなわち `w ≤ 1`。 □

## 3. 再構成（定理）

`u = Σj − 3[w=2]` を適用すると `(w,u)` が再現される。

| `w` | `u` | 再構成 | 実測 |
|---:|---:|---:|---:|
| 0 | 1 | 16 | **16** ✓ |
| 0 | 2 | 100 | **100** ✓ |

**10/10 完全一致。**

**内訳の例**：
- `(0,4) = A(w=0,Σj=4) 140 + B(w=0,Σj=4) 12 = 152`
- `(1,2) = A(w=1,Σj=2) 96 + B(w=1,Σj=2) 128 = 224`
- `(2,0) = B(w=2,Σj=3) 32 → u = 3−3 = 0`

## 4. 意義

1. **`(w,u)` 分布を `(case, w, Σj)` に完全に分解した**（10/10 一致）。
2. **場合 A では `w ≤ 1`** という定理を証明した。
3. **`u` 公式が分布レベルでも正しい**ことを確認した。
4. k=7 の全体が「対合の場合分け + `Σj` の分布」に帰着した。

## 5. 残る課題

`(case, w, Σj)` の閉形式。`Σj` は3つのペンシルの `j` の和であり、
`j` は k=6 の量（`N_xy`, `H`）で書ける。ただし3つのペンシルが
相関するため、単純な積にはならない。
