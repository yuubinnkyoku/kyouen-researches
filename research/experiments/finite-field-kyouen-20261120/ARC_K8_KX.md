# k=8 の `k_X` 分布：k=8 の閉形式が完全に閉じた

2026-11-20。`finite-field-kyouen-20261120` の第213部。

最後の未取得量 `k_X` の分布を導出した。**これで k=8 の閉形式が
完全に閉じた。**

## 1. 定理

```
#{X : k_X = j} = N_j · C(s−j, 4)
```

ここで

```
N_j = #{円 D ≠ C : |D ∩ C| = j}

N_0 = (b−1) − C(s,2)·q − s(q−1)
N_1 = s(q−1)
N_2 = C(s,2)·q
```

**理由**：共円な `X` は一意な円 `D` の上にある。`|D∩C| = j` の円 `D`
は `|D∩外点| = s−j` 点を持つので、`X` の選び方は `C(s−j, 4)`。

## 2. 検証（q=5）

```
s = 6, n = 26, b = 130

N_0 = 129 − 75 − 24 = 30
N_1 = 6·4 = 24
N_2 = C(6,2)·5 = 75
合計 = 129 = b−1   ✓

#{X : k_X=0} = 30 · C(6,4) = 30 · 15 = 450
#{X : k_X=1} = 24 · C(5,4) = 24 · 5  = 120
#{X : k_X=2} = 75 · C(4,4) = 75 · 1  =  75
合計 = 645 = N_cyc   ✓
```

**実測 `{0:450, 1:120, 2:75}` と完全一致。**

## 3. k=8 の閉形式（完全版）

```
sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(n−s−q+1,2)
sum v3 = C(s,2)·q · C(s−2,2) · C(q−1,3)·C(n−s−q+1,1)
sum v4 = Σ_j N_j·C(s−j,4) · C(j,2)·C(s−j,2)
sum u3 = s(q−1)·C(s−1,3)·G(q,n−s)
       + C(s,2)·q·2·C(s−2,3)·G(q−1,n−s) − sum u4
sum u4 = Σ_j N_j·C(s−j,4) · C(j,1)·C(s−j,3)
sum z4 = Σ_j N_j·C(s−j,4) · C(j,0)·C(s−j,4)
```

ここで `G(y,m) = C(y,3)·C(m−y,1) + C(y,4)`。

**すべて `q` の閉形式。**
