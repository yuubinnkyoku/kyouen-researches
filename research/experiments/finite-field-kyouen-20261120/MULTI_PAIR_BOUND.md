# 複数ペアへの一般化でも上界は λ₂ + 2 のまま

2026-11-20。`finite-field-kyouen-20261120` の第51部。
上界 `K ≤ λ₂ + 2` を複数ペアの干渉で改善できるかを検討し、**改善しない**ことを示した。

## 1. 設定

`S` の `m` 点 `p₁,…,p_m` を固定する。各ペア `{p_i,p_j}` は `λ₂` 個のブロックの
ペンシル `P(i,j)` を定める。ペンシルは `C(m,2)` 個。

`S` の残り `k−m` 点 `s` について、`C(m,2)` 個の三点 `{p_i,p_j,s}` がそれぞれ
ペンシル `P(i,j)` 内のブロックを定める。異なる `s` は各ペンシル内で異なるブロックを与える。

## 2. ペンシルの重なり

`m` 点の三点組 `{p_i,p_j,p_l}` が定めるブロック `B(i,j,l)` は、
3つのペンシル `P(i,j)`、`P(i,l)`、`P(j,l)` に属する。そのようなブロックは `C(m,3)` 個。

4点以上を含むブロックは存在しない（安全集合の定義）ので、
ペンシル同士の重なりはこれらのブロックに限られる。

包除原理で

```
|∪ P(i,j)| = C(m,2)·λ₂ − 3·C(m,3) + C(m,3)
           = C(m,2)·λ₂ − 2·C(m,3)
```

（pairwise の重なりが `3·C(m,3)`、triple の重なりが `C(m,3)`、4重以上は 0。）

## 3. 必要なブロック数

和集合は `C(m,3)` 個の `B(i,j,l)` と、各 `s` に対する `C(m,2)` 個のブロックを含む。よって

```
C(m,3) + C(m,2)·(k−m) ≤ C(m,2)·λ₂ − 2·C(m,3)
```

`k` について解くと

```
k ≤ λ₂ + 2
```

## 4. 結果：m に依らず同じ上界

| m | ペンシル数 | 三点組数 | 上界 |
|---:|---:|---:|---|
| 3 | 3 | 1 | λ₂ + 2 |
| 4 | 6 | 4 | λ₂ + 2 |
| 5 | 10 | 10 | λ₂ + 2 |
| 6 | 15 | 20 | λ₂ + 2 |
| 7 | 21 | 35 | λ₂ + 2 |
| 8 | 28 | 56 | λ₂ + 2 |

**`m` をいくら大きくしても上界は `λ₂ + 2` のまま。**

## 5. なぜ改善しないか

`m` を増やすと、ペンシル数 `C(m,2)` が増えて「使えるブロック」が増えるが、
同時に三点組 `C(m,3)` も増えて「消費するブロック」が増える。
両者が同じオーダーで増えるため、差が一定になる。

具体的には、包除の補正項 `−2·C(m,3)` と必要量の `C(m,3)` が打ち消し合い、
`k ≤ λ₂ + 2` が保たれる。

## 6. 意義

- 上界 `λ₂ + 2` は**この種のペンシル議論では改善できない**ことを示した。
- 改善には別の原理（例えば「ブロックの大域的分布」や「点の対称性」）が必要。
- 負の結果だが、探索範囲を明確に絞れた点で有用。

## 7. 限界

- ペンシル（2点を通るブロックの族）に基づく議論のみを扱った。
- 他の原理（3点を通るブロックの族、ブロックのサイズ分布など）は未検討。
- `λ₂ + 2` が真の上界として最良かは不明。
