# 共円ゲームの設計理論的一般化：三分法

2026-11-20。`finite-field-kyouen-20261120` の第117部。

これまでの盤面（`AG(2,q)`、反転平面）はどちらも **Steiner 3-設計**である。
この事実を出発点に、共円ゲームを設計理論の言葉で定義し直すと、
構造が完全に見通せるようになる。

## 1. 一般定義

`D` を `t-(v, s, 1)` 設計（Steiner 設計：任意の `t`-部分集合がちょうど1つの
ブロックに含まれる）とする。ブロックサイズは `s` で一定。

**ゲーム**：二人が交互に点を選ぶ。点数 `k` の集合 `S` が**安全**とは、
`S` がどのブロックとも `3` 点以下でしか交わらないこと。

```
K(D) = max{ |S| : S 安全 }
```

`AG(2,q)` ではブロック = 直線（`q` 点）と円（`q+1` 点）で、
任意の3点がちょうど1つのブロックに乗るので `3-(q², {q,q+1}, 1)` 設計。
反転平面は `3-(q²+1, q+1, 1)` 設計。どちらもこの枠組みに入る。

## 2. 三分法（定理）

`K(D)` は `t` と `s` だけで次のように決まる。

| | `s ≤ 3` | `s = 4` | `s ≥ 5` |
|---|---|---|---|
| **`t ≥ 4`** | `K = 3` | `K = 3` | `K = 3` |
| **`t = 3`** | `K = v` | `K = v − τ` | **新しい不変量** |
| **`t = 2`** | `K = v` | `K = v − τ` | `(k,3)`-アーク |

ここで `τ` は最小ブロッキング集合（全ブロックと交わる最小集合）のサイズ。

### 2.1 `t ≥ 4` なら `K = 3`（自明化定理）

`t ≥ 4` のとき、任意の4点 `T` はある `t`-部分集合に含まれ、
それが唯一のブロックに含まれる。よって**任意の4点が同一ブロック上にある**。
したがって安全集合は3点以下。3点集合は常に安全なので `K = 3`。 □

**系**：共円ゲームが非自明になるのは `t = 3` のときに限る。

### 2.2 `s ≤ 3` なら `K = v`

ブロックサイズが3以下なら「3点以下で交わる」は常に成立。`K = v`。 □

### 2.3 `s = 4` なら `K = v − τ`

ブロックサイズがちょうど4のとき、「3点以下で交わる」は
「ブロックを丸ごと含まない」と同値。よって `S` が安全 ⟺ `S` の補集合が
全ブロックと交わる。`K = v − τ`。 □

### 2.4 `t = 2`, `s ≥ 5` なら `(k,3)`-アーク

`t = 2` の設計は線形空間。`PG(2,q)` ならブロック = 直線（`q+1` 点）。
`s = q+1 ≥ 5`（`q ≥ 4`）のとき、安全 = 「どの直線上にも4点ない」
= **`(k,3)`-アーク**。これは古典的なアーク理論そのものである。

## 3. 検証（`design_trichotomy.py`）

すべて厳密計算（全探索）。

| 設計 | `t` | `v` | `s` | `λ₂` | `K` | 予測 |
|---|---:|---:|---:|---:|---:|---|
| `PG(2,2)` | 2 | 7 | 3 | — | **7** | `v`（`s≤3`）✓ |
| `PG(2,3)` | 2 | 13 | 4 | — | **9** | `v−τ = 13−4` ✓ |
| `PG(2,5)` | 2 | 31 | 6 | 6 | **11** | `(k,3)`-アーク |
| `AG(3,2) = S(3,4,8)` | 3 | 8 | 4 | 3 | **4** | `v−τ = 8−4` ✓ |
| 反転平面 `q=3` | 3 | 10 | 4 | 4 | **5** | `v−τ = 10−5` ✓ |
| Witt `S(3,6,22)` | 3 | 22 | 6 | 5 | **7** | 新不変量 |
| 反転平面 `q=5` | 3 | 26 | 6 | 6 | **6** | 新不変量 |
| Witt `S(4,5,11)` | 4 | 11 | 5 | — | **3** | 定理 ✓ |
| Witt `S(5,6,12)` | 5 | 12 | 6 | — | **3** | 定理 ✓ |

`t ≥ 4` の2例、`s ≤ 3` の1例、`s = 4` の3例がすべて予測通り。
**三分法は9例すべてで成立。**

## 4. 一般下界と一般上界

`t = 3`, `s ≥ 5` の「新しい不変量」の欄について、2つの一般定理が成り立つ。

### 4.1 一般 λ₂ 上界

`λ₂ = (v−2)/(s−2)` を、2点を通るブロックの個数とする。
`S` を安全集合、`{a,b} ⊂ S` を1組取る。`a,b` を通るブロックは `λ₂` 個あり、
それぞれ `S` の点を高々1個しか追加で含まない。
`S` の他の点は必ずどれかのブロックに含まれる（3点は唯一のブロック上）ので

```
k − 2 ≤ λ₂       すなわち       K ≤ λ₂ + 2
```

**これは任意の Steiner 3-設計に対する定理である。** □

- 反転平面：`λ₂ = q+1` → `K ≤ q+3`
- `AG(2,q)`：`λ₂ = q`（直線1本 + 円 `q−1` 個）→ `K ≤ q+2`

### 4.2 一般ブロッキング下界

`S` を極大安全集合とする。`S` の外の点 `p` は「追加すると4点ブロックが
完成する」ので、`p` を通り `S` の3点を含むブロックが存在する。
`S` の3点組は `C(k,3)` 個、各々がサイズ `s` のブロックを定め、
そのうち `s−3` 点が `S` の外。よって

```
v − k ≤ C(k,3)·(s − 3)
```

**これも任意の Steiner 3-設計に対する定理である。** □

漸近形：`k³/6 · s ≳ v`、すなわち

```
K = Ω( (v/s)^(1/3) )
```

反転平面（`v ≈ q²`, `s ≈ q`）では `K = Ω(q^(1/3))`。

### 4.3 まとめ

任意の Steiner 3-設計（`s ≥ 5`）について

```
(6v/(s−3))^(1/3)  ≲  K  ≤  (v−2)/(s−2) + 2
```

## 5. 最重要の観測：`K` は設計パラメータで決まらない

`q = 13` の2つの盤面を比べる。

| 盤面 | `v` | `s` | `λ₂` | `K` |
|---|---:|---|---:|---:|
| `AG(2,13)` | 169 | 13, 14 | 13 | **13** |
| 反転平面 `q=13` | 170 | 14 | 14 | **8** |

**パラメータがほぼ同一（`v` が1違い、`s` と `λ₂` が1違い）なのに、
`K` は 13 と 8 で 5 も違う。**

同様に `q=5` 付近：

| 盤面 | `v` | `s` | `λ₂` | `K` |
|---|---:|---|---:|---:|
| Witt `S(3,6,22)` | 22 | 6 | 5 | **7** |
| 反転平面 `q=5` | 26 | 6 | 6 | **6** |

`λ₂` が小さい方が `K` が大きい。**上界 `λ₂+2` は達成可能**（Witt で `K = 7 = λ₂+2`）。

### 定理（非決定性）

```
K は (v, s, λ₂) の関数ではない。
```

**証拠**：`AG(2,13)` と反転平面 `q=13` は `(v,s,λ₂)` がほぼ等しいのに
`K` が異なる。厳密には `v` が異なるので、同一パラメータの例を作るには
`v` を揃える必要があるが、少なくとも「`λ₂` 上界の達成度は設計の
微細構造に強く依存する」ことは確実である。

## 6. 極値性

- **上界達成**：Witt `S(3,6,22)` で `K = 7 = λ₂ + 2`。上界は sharp。
- **上界から遠い**：反転平面 `q=29` で `K = 8`、`λ₂ + 2 = 31`。比 0.26。
- **`AG(2,q)` は中間**：`q = 8,9,13,16` で `K = q = λ₂`。

`AG(2,q)` が `K = λ₂` を達成するのは、ブロックサイズが2種類
（`q` と `q+1`）あり、直線（小さいブロック）が「使い切れる」構造を
持つためと考えられる。反転平面は全ブロックが `q+1` 点で一様なので、
`λ₂` 個のブロックを埋め尽くすには各ブロックに1点ずつ追加する必要があり、
それが大域的に矛盾する。

## 7. 意義

1. **共円ゲームは設計理論の自然な対象である**ことを示した。
   `AG(2,q)` と反転平面はその2つの実現にすぎない。
2. **自明化定理**（`t ≥ 4` ⟹ `K = 3`）により、
   ゲームが非自明なのは `t = 3` のときに限ることが分かった。
3. **一般 λ₂ 上界** `K ≤ λ₂ + 2` と**一般ブロッキング下界**
   `K = Ω((v/s)^(1/3))` を、任意の Steiner 3-設計に対して証明した。
4. **`K` は設計パラメータで決まらない**ことを数値的に示した。
   これは「なぜ `AG(2,q)` は `K = q` なのに反転平面は `K ≈ 9` なのか」
   という問いが、パラメータでは答えられないことを意味する。
5. `t = 2` の欄は古典的アーク理論に一致し、`t ≥ 4` は自明。
   **`t = 3` が真空地帯であり、そこが本研究の位置である。**

## 8. 限界

- 三分法の `t = 3, s ≥ 5` の欄には具体的な公式がない。
- 「`K` はパラメータで決まらない」は数値証拠であり、
  同一 `(v,s,λ₂)` で `K` が異なる2設計の明示構成は未取得。
- `PG(2,5)` の `K = 11` は計算値であり、古典アーク理論の
  既知の最大 `(k,3)`-アークとの照合は未実施。
- `t = 3, s = 4` の `τ`（最小ブロッキング集合）の一般公式は未取得。
