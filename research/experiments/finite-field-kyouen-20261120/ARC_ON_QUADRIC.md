# 共円ゲームは楕円二次曲面上のアーク問題である

2026-11-20。`finite-field-kyouen-20261120` の第129部。

ovoid 模型により、反転平面の共円ゲームが**古典的な有限幾何の問題**として
きれいに言い換えられることが分かった。

## 1. 設定

`q` を素数冪、`Q` を `PG(3,q)` の**楕円二次曲面**（elliptic quadric）とする。

**q 奇数**：

```
Q(x₀,x₁,x₂,x₃) = x₀² + x₁² + x₂² + d·x₃²      （d は非平方）
```

**q 偶数**：

```
Q(x₀,x₁,x₂,x₃) = x₀·x₁ + x₂² + x₂·x₃ + a·x₃²   （Tr_{F_q/F₂}(a) = 1）
```

`Q = 0` の零点集合は `q² + 1` 点を持つ（ovoid）。

## 2. 主定理

**定理**：楕円二次曲面 `Q` の4点が共円であることと、
それらが**同一平面上にある**ことは同値。

**証明**：

- 4点が同一平面上にあるなら、その平面は `Q` と4点以上で交わる。
  平面切断のサイズは `0, 1, 2, q+1` のいずれかしかないので、
  4点以上なら `q+1`。すなわち円。
- 逆に円は平面切断そのもの。 □

**検証**（`arc_on_quadric.py`、全数）：

| q | 4点組 | 不一致 |
|---:|---:|---:|
| 3 | 210 | **0** |
| 4 | 2,380 | **0** |
| 5 | 14,950 | **0** |
| 7 | 230,300 | **0** |

**すべて一致。**

## 3. 系：ゲームはアーク問題である

安全集合 = どの4点も共円でない集合。定理により

```
安全集合 = Q 上の「どの4点も同一平面上にない」集合
```

**これは古典的な ARC（アーク）の定義そのものである。**

```
K(inversive q) = 楕円二次曲面上の最大アークサイズ
```

**共円ゲームは、楕円二次曲面上のアーク問題に他ならない。**

## 4. なぜこれが「新しい方向」なのか

従来の定式化は

- `P¹(F_{q²})` 上のメビウス変換（計算が重い、`O(q⁵)`）
- 3-ネットの横断問題（組合せ的だが族 C, D が非線形）

だった。アーク定式化は

- **`PG(3,q)` の部分空間との交わり**という、完全に古典的な有限幾何
- 平面は `O(q³)` 個しかないので計算が速い
- 「4点が同一平面上」は 4×4 行列式で判定できる（`O(1)`）

**計算速度**：q=8 の構成が 453 秒 → **0.6 秒**（750倍）。
q=11 が 2,400 秒 → **5 秒**。

## 5. 特性2の落とし穴（記録）

q 偶数の楕円二次曲面の形を最初は

```
Q = x₀² + x₀x₁ + a·x₁² + x₂² + x₂x₃ + b·x₃²     （両方既約）
```

としたが、これは**双曲的（hyperbolic）**で `q² + 2q + 1` 点を持つ。
q=4 で 25 点（正しくは 17 点）になったことで発覚した。

正しい形は

```
Q = x₀·x₁ + x₂² + x₂·x₃ + a·x₃²      （Tr(a) = 1）
```

で、q=4 で 17 点、q=8 で 65 点となる。

**教訓**：点数の検証がなければ気づかなかった。3-設計公理も
（誤った曲面でも）成立してしまう。

## 6. 既知の結果との関係

楕円二次曲面上のアークは、実は**よく研究されている対象**である：

- ovoid 自身が「すべての平面と高々1点で交わる」集合（アークの極端な場合）。
- 楕円二次曲面上のアークの最大サイズは、q が小さい場合に
  計算幾何の文献で扱われている。

**本研究の貢献**は、共円ゲームの `K` がこの古典的量に**一致する**ことを
示した点である。これにより、既存のアーク理論の結果がそのまま
ゲームの上界・下界に翻訳できる可能性が開ける。

## 7. 意義

1. **共円ゲームを楕円二次曲面上のアーク問題に帰着させた。**
   これは最も古典的で明快な定式化である。
2. **共円 ⟺ 同一平面** を全数検証した（q ≤ 7、247,840 組）。
3. **計算が750倍高速化**した（q=8 で 453 秒 → 0.6 秒）。
4. **特性2の正しい二次形式を特定した**（双曲的との区別）。

## 8. 限界

- 「アーク問題」への帰着は定式化であり、`K` の値そのものは未解決。
- 楕円二次曲面上のアークの最大サイズについて、文献の既存結果を
  まだ照合していない。
- q ≥ 16 の `K` は厳密計算が遅く未取得。
