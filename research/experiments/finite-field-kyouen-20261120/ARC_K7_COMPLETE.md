## 1. 完全な公式

```
#7-arcs = C(n,7) − Σ_P #(P を持つ7点集合)
```

プロファイル `P` は3種類に分かれる。

### 1.1 単一円プロファイル（3つ）

```
(7,) = b·C(s,7)
(6,) = b·C(s,6)·(n−s)
(5,) = b·#{T5 ⊂ C, {x,y} ⊂ C^c :
           ペンシル(x,y) の円が T5 と2点で交わらない}
```

### 1.2 複数円プロファイル（タプル公式から）

```
#4円 = 1 + v + [|W ∩ T| = 1]
#5円 = [|W ∩ T| = 2]

v = #{C' ≠ C : |C' ∩ T| = 2  かつ  |C' ∩ {x,y,z}| = 2}
```

タプル数から

```
#(P を持つ7点集合) = (P を持つタプル数) / (#P の4の個数) × b
```

## 4. 主定理

**定理**：反転平面 `q` 上の7点集合のプロファイルは上記の11種類
（`q=5` では8種類、`q=7` では11種類）に限られ、それぞれの個数は
上記の公式で与えられる。

**系**：`#7-arcs = C(n,7) − (上記の総和)`。

**検証**：q=5 で `arcs = 0`、q=7 で `arcs = 0`。
これは `K(5) = K(7) = 6` と整合する（7-アークが存在しない）。
