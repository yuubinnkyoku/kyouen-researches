# k=6 の分解：2円構造による完全な場合分け

2026-11-20。`finite-field-kyouen-20261120` の第133部。

前項で k ≤ 5 のアーク数に閉形式を与えた。本項は **k = 6** を扱う。
ここで初めて「2つの円」が必要になる。

## 1. 6点集合の分類

6点集合 `S` がアークでない ⟺ 共円な4点を含む。
`S` の4点を含む円の個数を `m`、各円が `S` から取る点数を `t_C ≥ 4` とする。

2円は高々2点でしか交わらないので、`m ≥ 2` なら
`|S| ≥ 4 + 4 − 2 = 6`。`|S| = 6` では `t₁ = t₂ = 4` かつ
共有点がちょうど2点に限られる。

**したがってプロファイル（`t_C` の降順）は次の5種類しかない**：

```
(6,)      6点すべてが1円上
(5,)      ちょうど5点が1円上
(4,)      ちょうど4点が1円上、他の円は4点を持たない
(4,4)     2円が各4点（2点を共有）
(4,4,4)   3円が各4点
```

**検証**（`arc_k6_structure.py`、q=5）：実際に出現するプロファイルは
この5種類のみ。

## 2. 単純な2つのプロファイル

```
(6,) = b·C(q+1,6)
(5,) = b·C(q+1,5)·(n−q−1)
```

**検証**（q=5、`b=130`、`n=26`）：

| プロファイル | 実測 | 公式 |
|---|---:|---:|
| (6,) | 130 | `130·C(6,6) = 130` ✓ |
| (5,) | 15,600 | `130·C(6,5)·20 = 15,600` ✓ |

## 3. (4,*) プロファイル：第2円の分布

`(4,)`、`(4,4)`、`(4,4,4)` は「第2の円がいくつあるか」で決まる。

**設定**：円 `C`（`b` 通り）とその4点 `T`（`C(q+1,4)` 通り）、
`C` の外の2点 `{x,y}` を選ぶ。第2の円 `C'` は `x,y` を通り
`T` とちょうど2点を共有するもの。

**測定**（`arc_k6_pairs.py`、q=5、370,500 組）：

| 第2円の個数 | 組数 |
|---:|---:|
| 0 | 62,400 |
| 1 | 265,200 |
| 2 | 42,900 |

**各プロファイルは「第2円の個数 + 1」回ずつ数えられている**：

```
(4,)    = 62400 / 1 =  62400   ← 実測 62400  ✓
(4,4)   = 265200 / 2 = 132600  ← 実測 132600 ✓
(4,4,4) =  42900 / 3 =  14300  ← 実測  14300 ✓
```

**完全一致。**

## 4. k=6 の分解公式

```
#6-arcs = C(n,6) − b·C(q+1,6) − b·C(q+1,5)·(n−q−1)
                  − [N₀ + N₁/2 + N₂/3]
```

ここで `N_j` は「第2円がちょうど `j` 個」の `(C,T,{x,y})` 組数。

**検証**：

| q | n | b | 悪い6点集合 | アーク | 全数計算のアーク |
|---:|---:|---:|---:|---:|---:|
| 5 | 26 | 130 | 225,030 | **5,200** | **5,200** ✓ |
| 7 | 50 | 350 | 14,636,300 | **1,254,400** | **1,254,400** ✓ |

**両方で完全一致。**

## 5. 残る課題：`N_j` の閉形式

`N_j` は幾何量であり、閉形式は未取得。測定値：

| q | `N₀/total` | `N₁/total` | `N₂/total` |
|---:|---:|---:|---:|
| 5 | 0.168421 | 0.715789 | 0.115789 |
| 7 | 0.328920 | 0.610453 | 0.060627 |

`N₀` の比率は q とともに増える（0.168 → 0.329）。
これは「q が大きいほど第2円ができにくい」ことを意味し、
直感（円が大きくなると交わりにくい）と整合する。

**`N_j` を閉形式で書くには、2円が2点を共有する配置の数え上げが必要。**
これは `PG(3,q)` の平面配置の問題に帰着するはずだが、未解決。

## 6. 意義

1. **k=6 の完全な場合分けを与えた**：プロファイルは5種類のみ。
2. **`(6,)` と `(5,)` の閉形式を証明した。**
3. **`(4,*)` を「第2円の個数」で完全に説明した**：
   ヒストグラムを多重度で割るとプロファイル数に一致。
4. **k=6 のアーク数を厳密に計算する公式を与えた**
   （`N_j` を計算できれば閉じる）。
5. **k=5 との構造的な違いを明確にした**：
   k=5 では「2つの共円4点は同じ円」だったが、k=6 では別々の円になり得る。

## 7. 限界

- `N_j` の閉形式は未取得。したがって k=6 は「閉形式」ではない。
- 検証は q = 5, 7 のみ（q=8 は 6点集合が 82,598,880 個で重い）。
- k ≥ 7 のプロファイル分類は未実施。
