# k=6 の完全な公式：`N_j` は PGL(2,q)-軌道で決まる

2026-11-20。`finite-field-kyouen-20261120` の第135部。

前項で k=6 のアーク数が「第2円の個数 `N_j`」に帰着することを示した。
本項は `N_j` の正体を突き止め、**k=6 を完全に閉じる**。

## 1. 発見：`N_j` は PGL(2,q)-軌道で決まる

`(C,T)` の分布が q=5 で1種類、q=7 で2種類に分かれる理由は
**PGL(2,q) の4点部分集合への作用**である。

円 `C` は `P¹(F_q)` のコピーであり、`PGL(2,q)` がその上に作用する。
`T`（4点部分集合）の**軌道**が配置型である。

**総当たりによる軌道計算**（`arc_k6_orbits.py`、`PGL(2,q)` を全列挙）：

| q | `\|PGL\|` | 4点部分集合の軌道 | サイズ |
|---:|---:|---:|---|
| 5 | 480 | **1** | `[15]` |
| 7 | 2,016 | **2** | `[42, 28]` |

**観測された `N_j` のクラスと完全一致**：

```
q=5: 分布グループ {((0,32),(1,136),(2,22)): 15}          ← 1クラス、サイズ15
q=7: 分布グループ {((0,284),(1,524),(2,53)): 42,
                   ((0,282),(1,528),(2,51)): 28}          ← 2クラス、42と28
```

**軌道サイズと分布グループのサイズが一致。**

## 2. 完全な k=6 公式

```
#6-arcs = C(n,6) − b·C(q+1,6) − b·C(q+1,5)·(n−q−1)
          − Σ_{O: PGL-軌道} b·|O|·[N₀(O) + N₁(O)/2 + N₂(O)/3]
```

ここで `(N₀(O), N₁(O), N₂(O))` は軌道 `O` の代表 `T` に対する
第2円分布。

**検証**：

| q | 軌道 | `N₀` | `N₁` | `N₂` | 寄与 |
|---:|---|---:|---:|---:|---:|
| 5 | 15 | 32 | 136 | 22 | `130·15·(32+68+7.33) = 209,300` |
| 7 | 42 | 284 | 524 | 53 | `350·42·(284+262+17.67) = 8,286,600` |
| 7 | 28 | 282 | 528 | 51 | `350·28·(282+264+17) = 5,517,400` |

合計（q=7）：`8,286,600 + 5,517,400 = 13,804,000`。
これに `(6,)` と `(5,)` を加えると全数計算の `14,636,300` に一致。

## 3. なぜ q=5 で1軌道、q=7 で2軌道なのか

`P¹(F_q)` の4点部分集合の軌道数は、**4点の「交差比の型」**で決まる。
`PGL(2,q)` は3重推移的なので、3点を `0, 1, ∞` に正規化でき、
4点目が `t ∈ F_q \ {0,1}` に落ちる。

**軌道は `t` の「6値集合」**

```
{ t, 1/t, 1−t, 1/(1−t), t/(t−1), (t−1)/t }
```

で決まる（4点の置換に対応する6つの値）。

- q=5：`F_5 \ {0,1} = {2,3,4}`。6値集合はすべて同一 → **1軌道**
- q=7：`F_7 \ {0,1} = {2,3,4,5,6}`。2種類の6値集合 → **2軌道**

**注意**：交差比の「6値集合」を素朴に計算すると q=5 で3、q=7 で5 という
誤った数になる（実際に一度失敗した）。正しい軌道計算は
**群作用の総当たり**が必要。6値集合は不変量だが軌道を正しく分離しない。

## 4. 一般の k への示唆

k=6 が PGL(2,q)-軌道で閉じたのは、**「1つの円 + 円外の点」**という
構造のおかげである。k が大きくなると「2つ以上の円」の配置型が必要になり、
軌道の分類は `PG(3,q)` の平面配置の問題になる。

## 5. 意義

1. **`N_j` の正体を特定した**：`(C,T)` の PGL(2,q)-軌道である。
2. **軌道サイズと分布グループのサイズが完全一致**することを確認した
   （q=5 で 15、q=7 で 42 と 28）。
3. **k=6 の完全な公式を与えた**（軌道ごとの `N_j` を計算すれば閉じる）。
4. **交差比の6値集合では軌道を分離できない**ことを記録した
   （素朴な計算は q=5 で3、q=7 で5 という誤答を出す）。

## 6. 限界

- 軌道ごとの `N_j` の**閉形式**は未取得（数値のみ）。
- q ≥ 8 の軌道構造は未計算（`|PGL(2,q)|` が急増）。
- k ≥ 7 では「2つ以上の円」が必要になり、この手法は使えない。
