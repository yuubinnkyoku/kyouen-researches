# 族 C, D は巡回座標で線形ではない（否定的結果）

2026-11-20。`finite-field-kyouen-20261120` の第123部。

## 1. 動機

前項までで 3-ネットが `Z_{q+1}` の加法表であることを示した：

```
α(1/a) = α(1/b) + α(1/c)   (mod q+1)
```

もし族 C（3点が錨を通る円上）と族 D（4点共円）も巡回座標で
**線形条件**として書けるなら、共円ゲームは `Z_{q+1}` 上の線形代数問題に
還元され、`K` が完全に計算できる。

## 2. 検証

`net3_family_cd_linear.py` は、各錨 `a ∈ {0, 1, ∞}` について
「2点 `u, u'` が `a` を通る共通の円上にある」という関係が

```
p·α + q·β ≡ const   (mod n)
```

の形（`p, q ∈ Z_n`）で書けるかを全数探索した。

**結果（q=5, n=6）**：

| 錨 | 最良の `(p,q)` | 一致率 |
|---|---|---|
| 0 | `(0, 3)` | 94/190 = **0.4947** |
| 1 | `(0, 3)` | 94/190 = **0.4947** |
| ∞ | `(0, 3)` | 94/190 = **0.4947** |

**どの線形条件も 50% 程度（ランダムと同程度）しか一致しない。**

## 3. 結論

**族 C, D は巡回座標で線形ではない。**

これは重要な否定的結果である。3-ネット（族 B）は完全に線形化できたが、
族 C, D は本質的に高次であり、`Z_{q+1}` の線形構造では捉えられない。

したがって「共円ゲームを `Z_{q+1}` 上の線形代数に還元する」路線は
**閉じている**。

## 4. なぜ線形でないか（構造的な理由）

族 C の条件は「3点が錨を通る円上にある」。円は `PGL(2,F_{q²})` の像であり、
`P¹(F_q)` の像ではない。3-ネットの線形構造は `P¹(F_q)`（＝錨3点を通る円）
に由来する。錨を1点だけ通る円は `P¹(F_q)` を `PGL(2,F_{q²})` で
「半分だけ」動かしたもので、その軌道は `Z_{q+1}` の加法構造を保たない。

具体的には、`P¹(F_q)` を固定する部分群は `PGL(2,F_q)` だが、
1点を固定する部分群はそれよりずっと大きく、軌道が線形構造を壊す。

## 5. 意義

1. **族 C, D の線形化は不可能**であることを示した。
   これにより「`Z_{q+1}` 上の線形代数に還元する」路線が閉じた。
2. 3-ネット（族 B）の線形性と、族 C, D の非線形性の**境界が明確**になった。
3. `K` と `q+2` のギャップ（slack）の正体が「本質的に高次の条件」である
   ことが、単なる観測ではなく**構造的な事実**として確定した。

## 6. 限界

- q=5 のみの検証。q=7 以上での確認は未実施（計算量が大きい）。
- 「線形でない」ことは「`p·α + q·β = const` の形でない」ことの証明であり、
  より複雑な（例えば2次）条件の可能性は排除していない。
- 族 C, D の組合せ的記述は依然未取得。
