# (B) への道：線形ギャップ不等式

2026-11-20。`finite-field-kyouen-20261120` の第26部。
「面積が最大でない場合」の評価を、線形不等式の形で定式化した。

## 1. 定式化

示したいのは、バウンディングボックス条件の下で

```
Area · R² ≤ a⁴/4
```

である。面積の最大値は `a²/2`（正方形の半分）なので、これを

```
Area · R² ≤ a⁴/4 − c·(a²/2 − Area)        (c > 0)
```

の形に強めると、`Area < a²/2` のとき右辺は `a⁴/4` より真に小さくなる。
つまり **(B) は線形ギャップ不等式から従う**。

## 2. 検証結果

各 a について、この不等式が成立する最大の `c` を求めた。

| a | 最大の c | c/a² |
|---:|---:|---:|
| 4 | 7/2 | 7/32 |
| 5 | 25/6 | 1/6 |
| 6 | 155/18 | 155/648 |
| 7 | 47/6 | 47/294 |
| 8 | 14 | 7/32 |

**すべての a で `c ≥ 7/2` が取れる。** 最小値は a=4, 8 の `7/2`。

## 3. ギャップの実測

a=4 での面積不足とギャップの関係：

| 面積不足 (a²/2 − Area) | ギャップ (a⁴/4 − Area·R²) |
|---:|---:|
| 15/2 | 231/4 |
| 7 | 191/4 |
| 13/2 | 181/4 |
| 6 | 39 |
| 11/2 | 131/4 |
| 5 | 443/12 |
| 9/2 | 1167/28 |
| 4 | 14 |
| 7/2 | 131/4 |
| 3 | 131/4 |

ギャップは面積不足に対して単調ではないが、常に `(7/2)×不足` 以上である。

## 4. 証明の構図

線形ギャップ不等式が示せれば (B) が従う。示すべきは

```
Area · R² + c · Area ≤ a⁴/4 + c·a²/2
```

すなわち

```
Area · (R² + c) ≤ a⁴/4 + c·a²/2
```

`c = 7/2` を試すと

```
Area · (R² + 7/2) ≤ a⁴/4 + 7a²/4
```

この形なら、`Area ≤ a²/2` と `R²` の上界を組み合わせて評価できる可能性がある。
ただし `R²` 自体は `a²/2` を超えうる（[DET_CENTRE_CASES.md](DET_CENTRE_CASES.md) §2）ので、
`R²` の上界だけでは足りない。

**現時点で証明は得ていない。** しかし「線形ギャップ」という形に問題を絞れたことは
前進である。定数 `c` が a に依らず `7/2` 以上で取れるという観測は、
証明の指針になる。

## 5. 限界

- a ≤ 8 の全数計算。
- 線形ギャップ不等式自体が未証明。
- `c = 7/2` が最良かは不明（a が大きくなれば変わりうる）。
- 中心が正方形の外にある場合は別途評価が必要。
