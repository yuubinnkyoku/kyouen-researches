### 1.3 プロファイル公式（6類）

`S = T ∪ {w,x,y,z}`（`|T| = 4`、`T ⊂ C`、外4点 `X`）。
`C' ≠ C` は `C` と高々2点で交わるので `|C' ∩ S| ≤ 6`。
**プロファイルの値は 4, 5, 6 のみ。**

| 記号 | 条件 | `S` からの点数 |
|---|---|---:|
| `v2` | `\|C'∩T\|=2`, `\|C'∩X\|=2` | 4 |
| `v3` | `\|C'∩T\|=2`, `\|C'∩X\|=3` | 5 |
| `v4` | `\|C'∩T\|=2`, `\|C'∩X\|=4` | 6 |
| `u3` | `\|C'∩T\|=1`, `\|C'∩X\|=3` | 4 |
| `u4` | `\|C'∩T\|=1`, `\|C'∩X\|=4` | 5 |
| `z4` | `\|C'∩T\|=0`, `\|C'∩X\|=4` | 4 |

```
#4円 = 1 + v2 + u3 + z4
#5円 = v3 + u4
#6円 = v4
```

**検証**：q=5 で 5,000/5,000、q=7 で 5,000/5,000 — **0 不一致**。

### 1.4 `v4 + u4 + z4 = [X が共円]`（定理）

```
v4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 2
u4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 1
z4 = 1  ⟺  X が共円 かつ  |D ∩ T| = 0
```

**3つは互いに排反で、和が共円性の指示関数。**

**検証（q=5）**：`(0,0,0):63000, (0,0,1):7425, (0,1,0):1800, (1,0,0):450`
— 合計 72,675 ✓

### 1.5 `|C' ∩ T|` の完全な分解（定理）

```
#{C' : |C'∩T| = 2} = 6q
#{C' : |C'∩T| = 1} = 4(q−1) + 4(s−4)q
#{C' : |C'∩T| = 0} = N₀ + (s−4)(q−1) + C(s−4,2)·q
```

**検証（q=5）**：`30 + 56 + 43 = 129 = b − 1` ✓

### 1.6 組み立ての検証（q=5）

```
n = 26, b = 130, s = 6
タプル数 = 72,675, プロファイル数 = 13, 非整数 = 0
bad  = 1,562,275 = C(26,8)
arcs = 0
```

**全数計算と完全一致。**

### 1.7 除算順序の罠

```
#(P を持つ8点集合) = タプル数(P) / (#4円) × b
```

**この順序は壊れる**（`525/10 = 52.5` が非整数）。
**正しくは `タプル数 × b / #4円`**（必ず整数）。
