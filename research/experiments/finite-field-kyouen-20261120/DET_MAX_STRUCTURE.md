## 1. 係数公式の確認

三点 `p1,p2,p3` を固定し、4×4 行列式を最終行 `r = (x, y, x²+y², 1)` について余因子展開すると

```
Delta(x,y) = alpha·x + beta·y + gamma·(x²+y²) + delta
```

係数は三点の座標の 3×3 小行列式である。a=4 で直接 4×4 行列式と全数照合し一致した。

## 2. 格子最大の分解

各三点について、正方形 `[0,a]²` 上の `|Delta|` の最大を求め、全三点にわたる最大を取ると
`D(n)` が得られる（[DET_MAX_TRIPLE.md](DET_MAX_TRIPLE.md)）。

スクリプトは最大を与える配置を2種類に分類している：

- **A（corner 型）**：四点目が正方形の**角**にある
- **B（nearest 型）**：四点目が円の中心に最も近い格子点にある

a ≤ 12 のすべてで `D(a) = max(A(a), B(a))` が成立し、格子最大は公式 `a²⌊a²/2⌋` と一致した。

## 3. 連続緩和との差（重要な観察）

「連続最大」の列は、四点目を実数 `(x,y) ∈ [0,a]²` に許したときの最大値である。

- **a が偶数のとき**：連続最大 = 格子最大 = `a⁴/2`。差は 0。
- **a が奇数のとき**：連続最大 = `a⁴/2 + 1/2` で、格子最大より **1/2 だけ大きい**。

つまり

```
連続最大 = a⁴/2 + (a が奇数なら 1/2、偶数なら 0)
格子最大 = a²⌊a²/2⌋ = a⁴/2 − (a が奇数なら 1/2、偶数なら 0)
```

両者の差は、a が奇数なら **1**、偶数なら **0** である。

これは証明の道筋を示唆する：

1. 連続緩和の最大が `a⁴/2 + [a odd]/2` であることを示す（解析的な最適化問題）。
2. 格子点では最大が半整数だけ下がることを示す（奇数の場合）。
3. その結果が `a²⌊a²/2⌋` に一致することを確認する。

**ただし 1 と 2 は未証明である**。上表は a ≤ 12 の観測にすぎない。

## 4. 極値配置の形

各 a で最大を与える三点は、スクリプトの出力によれば

- A 型：`(0,0), (a,0), (0,a)` に近い形（三隅）
- B 型：四点目が `(⌊a/2⌋, ⌊a/2⌋)` または `(⌈a/2⌉, ⌈a/2⌉)`（対角点）

であり、既知の「三隅＋対角点」族と整合する。

## 5. 残る証明課題

上記の分解は**計算事実**であって証明ではない。示すべきは：

> 任意の三点 `(p1,p2,p3)` と任意の `(x,y) ∈ [0,a]²` に対し
> `|alpha·x + beta·y + gamma·(x²+y²) + delta| ≤ a²⌊a²/2⌋`

連続緩和の値 `a⁴/2 + [a odd]/2` が正しいとすれば、
格子点での値がそこから十分下がることを示せばよい。
しかし現時点で連続緩和の最大値自体が証明されていない。
