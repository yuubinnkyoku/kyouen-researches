# 連続上界の証明：中心公式とバウンディングボックス条件

2026-11-20。`finite-field-kyouen-20261120` の第24部。
`Area·R² ≤ a⁴/4` を、中心の位置条件を代数的に扱うことで検証した。

## 1. 設定

三点 `p1,p2,p3` を `[0,a]²` 内の格子点とする。`p1` を原点に平行移動し、
`u = p2−p1`、`v = p3−p1` とおく（整数ベクトル）。

```
c = |u × v| = |u_x v_y − u_y v_x|      （面積の2倍）
n1 = |u|²,  n2 = |v|²,  n3 = |u−v|²
```

## 2. 二つの恒等式

**(I) ラグランジュの恒等式**

```
n1 · n2 = c² + s²        （s = u·v）
```

a ≤ 7 の全ベクトル対で検証し、成立を確認した。

**(II) 面積と外接円半径**

```
Area · R² = n1 · n2 · n3 / (8c)
```

これは `R = xyz/(4·Area)`（`x,y,z` は辺の長さ）から従う。

## 3. 中心の公式

外接円の中心 `O` は `2O·u = n1`、`2O·v = n2` を満たすので

```
O_x = (n1·v_y − n2·u_y) / (2c)
O_y = (n2·u_x − n1·v_x) / (2c)
```

a ≤ 7 の全ベクトル対で `|O|² = R²` を確認した（不一致 0）。

## 4. 中心の位置条件

三点と中心 `O` がすべて `[0,a]²` に収まるには、四点 `{0, u, v, O}` の
**バウンディングボックス**が一辺 `a` の正方形に収まればよい：

```
max(x) − min(x) ≤ a   かつ   max(y) − min(y) ≤ a
```

（`x` は `0, u_x, v_x, O_x` の4値。）

## 5. 結果

この条件を課して `Area·R²` の最大を求めると：

| a | 条件を満たす三角形 | max Area·R² | 上界 a⁴/4 | 判定 |
|---:|---:|---:|---:|---|
| 3 | 1,032 | **81/4** | 81/4 | **AT BOUND** |
| 4 | 2,976 | **64** | 64 | **AT BOUND** |
| 5 | 6,672 | **625/4** | 625/4 | **AT BOUND** |
| 6 | 13,272 | **324** | 324 | **AT BOUND** |
| 7 | 23,664 | **2401/4** | 2401/4 | **AT BOUND** |

**すべての a で最大がちょうど `a⁴/4` に一致する。** 極値は常に
「正方形の3つの角」を結ぶ直角三角形（`u = (−a,−a)`、`v = (−a,0)` の形）。

## 6. 証明の現状

確立したこと：

1. `gamma = −2·Area`（証明済み）
2. ラグランジュの恒等式 `n1·n2 = c² + s²`（検証済み）
3. 面積・半径公式 `Area·R² = n1·n2·n3/(8c)`（標準公式から従う）
4. 中心公式 `O = ((n1 v_y − n2 u_y)/(2c), (n2 u_x − n1 v_x)/(2c))`（検証済み）
5. バウンディングボックス条件の下で `max Area·R² = a⁴/4`（a ≤ 7 の全数）

未確立：

- 上記 5 の**任意の a に対する証明**。a ≤ 7 の全数計算のみ。
- 中心が正方形の外にある場合の `Area·max|power| ≤ a⁴/4` の証明。

## 7. 証明の見通し

条件 5 は「整数ベクトル `u,v` と有理点 `O` が一辺 `a` の正方形に収まる」
という制約下での最適化問題である。`O` が正方形内にあるという条件は
`O` の座標が `[0,a]` に入ること、すなわち

```
0 ≤ (n1 v_y − n2 u_y)/(2c) ≤ a
0 ≤ (n2 u_x − n1 v_x)/(2c) ≤ a
```

という4つの線形不等式になる。これと `Area·R² = n1 n2 n3/(8c)` を組み合わせれば、
代数的な評価が可能と考えられるが、本項では到達していない。

**重要な進展**：問題が「4変数の行列式の評価」から
「整数ベクトルと有理点に関する制約付き最適化」に整理され、
しかも上界が鋭い（最大がちょうど `a⁴/4`）ことが確認できた。
