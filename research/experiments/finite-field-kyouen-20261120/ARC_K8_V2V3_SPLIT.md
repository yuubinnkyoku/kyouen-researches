# k=8 の `v2` / `v3` の分離：k=8 の閉形式が完成

2026-11-20。`finite-field-kyouen-20261120` の第210部。

k=8 の最後の課題 `v2` / `v3` の分離を解決した。**これで k=8 の
6類すべてが閉形式になった。**

## 1. 定理

固定した `C'`（`|C'∩C| = 2`）に対し：

- `T` は `C'∩C` の2点を含む → `C(s−2,2)` 通り
- `Y = C' − C`、`|Y| = q−1`
- `X` は外点の4点部分集合で `|Y∩X| = 2`（`v2`）または `3`（`v3`）

```
sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(n−s−q+1,2)
sum v3 = C(s,2)·q · C(s−2,2) · C(q−1,3)·C(n−s−q+1,1)
```

## 2. 検証（q=5）

```
s = 6, n = 26, m = n−s = 20, |Y| = q−1 = 4

#C' with |C'∩C|=2: C(6,2)·5 = 75
#T containing both: C(4,2) = 6
#X with |Y∩X|=2: C(4,2)·C(16,2) = 6·120 = 720
#X with |Y∩X|=3: C(4,3)·C(16,1) = 4·16 = 64

v2 = 75 · 6 · 720 = 324,000   （実測 324,000）✓
v3 = 75 · 6 ·  64 =  28,800   （実測  28,800）✓
```

**両方とも完全一致。**

## 3. k=8 の6類の閉形式（完成）

```
sum v2 = C(s,2)·q · C(s−2,2) · C(q−1,2)·C(n−s−q+1,2)
sum v3 = C(s,2)·q · C(s−2,2) · C(q−1,3)·C(n−s−q+1,1)
sum v4 = #{X 共円 かつ |D∩T|=2} の総和
sum u3 = s(q−1)·C(s−1,3)·G(q,n−s)
       + C(s,2)·q·2·C(s−2,3)·G(q−1,n−s) − sum u4
sum u4 = #{X 共円 かつ |D∩T|=1} の総和
sum z4 = #{X 共円 かつ |D∩T|=0} の総和
```

ここで `G(y,m) = C(y,3)·C(m−y,1) + C(y,4)`。

**`v4 + u4 + z4 = [X が共円]`** なので、3つの和は
「外点の共円4点の個数」×（`T` の選び方）で決まる。
