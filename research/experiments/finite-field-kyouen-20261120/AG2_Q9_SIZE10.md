# AG(2,9) のサイズ10決定：探索空間の分析

2026-11-20。`finite-field-kyouen-20261120` の第32部。
AG(2,9) のサイズ10の存在を決定しようと試み、探索空間の構造を定量化した。
**結論は未確定**であるが、なぜ難しいかの記録を残す。

## 1. 問題

AG(2,9) は 81 点・819 ブロック（直線90・非退化円錐曲線648・十字81）。
安全集合は各ブロックに高々3点。サイズ9は実在（323ノードで発見）。
サイズ10の存在は未確定。

## 2. 試した手法と結果

| 手法 | 結果 |
|---|---|
| ランダム貪欲（4シード × 20,000再起動） | 最大サイズ9、サイズ10発見できず |
| 十字制約のみの DFS | 500万ノードで打ち切り |
| 直線制約のみの DFS | 打ち切り |
| 行マスク DFS（行・列・全ブロック制約） | 打ち切り |
| 十字制約を満たす10点配置の数（DP） | **46,962,682,200**（約470億） |

## 3. なぜ難しいか

### 3.1 十字制約だけでは弱い

十字制約（各列・各行に高々2点、`a_c + b_r − x_{cr} ≤ 3`）を満たす10点配置は
約470億通りある。これは「各列・各行に高々2点」という条件が
9×9 の格子では比較的緩いためである。

### 3.2 直線制約も弱い

AG(2,9) の直線は 90 本（水平9・垂直9・斜め72）。各直線に高々3点。
しかし 9×9 格子で「どの直線にも4点ない」10点配置は多数存在する。

### 3.3 円錐曲線の制約が本質的

648 個の非退化円錐曲線（各8点）が本当の制約を与える。
しかしこれらは「8点が円錐曲線上にある」という大域的な条件で、
局所的な枝刈りに使いにくい。

## 4. 有効な上界

十字ブロックから `K ≤ 14` が従う（[AG2_CROSS_GENERAL.md](AG2_CROSS_GENERAL.md)）。
したがって

```
9 ≤ K(AG(2,9)) ≤ 14
```

## 5. 決定に必要なもの

サイズ10を決定するには、以下のいずれかが必要と考えられる：

1. **SAT ソルバー**。819 ブロックの制約を CNF に落とし、kissat 等で解く。
   リポジトリには kissat の使用例があるが、この環境にはソルバーが入っていない。
2. **対称性の完全な利用**。AGL(2,9) は位数 `9^2 · |GL(2,9)|` の群で、
   点集合に推移的に作用する。最初の2点を軌道代表に固定すれば探索空間が
   大幅に減るはずだが、実装していない。
3. **円錐曲線の構造を使った制約伝播**。8点の円錐曲線は
   `s·t + a·s + b·t + c = 0` の形なので、3点が決まれば残りが決まる。
   この「3点で決まる」性質を使った制約伝播が有効かもしれない。

## 6. 限界

- サイズ10の存在は未確定。
- 試した手法はいずれも打ち切りで、不存在の証明ではない。
- 470億という数は十字制約のみを満たす配置の数で、実際の安全集合の数ではない。
