# k=7 の構造：多重度による完全な分解

2026-11-20。`finite-field-kyouen-20261120` の第143部。

k=7 のプロファイル分解を詰めた。**7種類すべてが「タプル数 ÷ 4円の個数」
で説明できる。**

## 1. 主定理

**定理**：円 `C`、その4点部分集合 `T`、`C` の外の3点 `{x,y,z}` を選ぶ。
`S = T ∪ {x,y,z}` のプロファイルを `P` とすると

```
#7点集合（プロファイル P）= (タプル数) / (#{t ∈ P : t = 4})
```

**証明**：タプルは「4円 `C` とその4点部分集合 `T`」を固定して数える。
7点集合 `S` は、その**4円の個数**だけ異なるタプルに現れる
（各4円について `C(q+1,4)` 通りの `T` があるが、`S` に含まれる `T` は
`C(4,4) = 1` 通り）。よって重複度は4円の個数。 □

## 2. 検証（q=5）

| プロファイル | タプル数 | 4円の個数 | 商 | 実測 |
|---|---:|---:|---:|---:|
| (4,4,4,4) | 1,248,000 | 4 | 312,000 | **312,000** ✓ |
| (4,4,4,4,4) | 390,000 | 5 | 78,000 | **78,000** ✓ |
| (4,4,4) | 288,600 | 3 | 96,200 | **96,200** ✓ |
| (5,4,4) | 171,600 | 2 | 85,800 | **85,800** ✓ |
| (5,4) | 62,400 | 1 | 62,400 | **62,400** ✓ |
| (4,4) | 31,200 | 2 | 15,600 | **15,600** ✓ |
| (4,4,4,4,4,4) | 31,200 | 6 | 5,200 | **5,200** ✓ |

**7/7 完全一致。**

`(6,)` は別扱い：`b·C(s,6)·C(n−s,1) = 130·1·20 = 2,600` ✓

**合計**：`312000+78000+96200+85800+62400+15600+5200+2600 = 657,800 = C(26,7)` ✓
（アーク 0 と整合）

## 3. `(5,*)` は k=6 の機構がそのまま効く

`(5,4)` と `(5,4,4)` は**ペンシルの対合**で閉じる。`|T| = 5` として

```
H(n₂,n₁,j,5) = Σ_a C(n₂,j)·C(n₂−j,a)·2^a·C(n₁,5−2j−a)

(5,4)   = b·Σ_{n₂} N_xy(n₂)·H(n₂,n₁,1,5) = 62,400  ✓
(5,4,4) = b·Σ_{n₂} N_xy(n₂)·H(n₂,n₁,2,5) = 85,800  ✓
```

**`j = 0` は起こらない**（`|T| = 5 > n₁ = 2 or 0` なので、
対合の対が必ず1つは `T` に完全に入る）。

## 4. `(4,*)` は新しい構造を要する

`(4,*)` の5プロファイルは、タプル数から多重度で割れば出るが、
**タプル数自体の閉形式は未取得**。

理由：タプルは「4円 + 3点」であり、3点が2つ目の4円を作るかどうかが
ペンシル（2点を通る円の束）だけでは決まらない。3点が必要なので、
より高次の配置（`PG(3,q)` の平面配置）が関与する。

## 5. 意義

1. **k=7 のプロファイル分解を完全に説明した**（7/7 一致）。
2. **多重度は「4円の個数」**であることを証明した
   （プロファイルの長さではない）。
3. **`(5,*)` が k=6 の機構で閉じる**ことを示した。
4. **`(4,*)` のタプル数が新しい障壁**であることを特定した。

## 6. 限界

- `(4,*)` のタプル数の閉形式は未取得。
- 検証は q=5 のみ（q=7 は `C(50,7) ≈ 1.0×10⁸` で重い）。
- k ≥ 8 は未着手。
