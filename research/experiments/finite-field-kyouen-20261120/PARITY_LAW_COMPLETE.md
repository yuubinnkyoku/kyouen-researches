# パリティ法則の完全な証明（逆も含む）

2026-11-20。`finite-field-kyouen-20261120` の第102部。
パリティ法則の**逆**を証明し、完全な二分法を確立した。

## 1. 主定理

有限の不偏ゲーム（局面＝安全集合、手＝1点追加、終局＝極大安全集合）について

```
すべての極大集合のサイズが同じ偶奇  ⟺  すべての Grundy 値が 0 か 1
```

さらに、前者が成り立つとき `g(S) ≡ ε − |S| (mod 2)`（`ε` は極大サイズの偶奇）。

## 2. 順方向の証明（前項）

`P`（偶奇が揃う）⇒ `Q`（全 g ≤ 1）。

補題：`L(S)` の全要素が `d` と mod 2 で合同なら `g(S) ≡ d (mod 2)`。
これを用いて、`g(S) ≥ 2` なら子に 0 と 1 が両方現れるが、全子の Grundy 値は
同じ偶奇なので矛盾。□

## 3. 逆方向の証明（本項）

`Q`（全 g ≤ 1）⇒ `P`（偶奇が揃う）。

### 補題2（交互性）

すべての `g ≤ 1` なら、**任意の辺 `S → S'` で `g(S) ≠ g(S')`**。

**証明**：
- `g(S) = 1` なら、mex が 1 なので `0` が子に現れ、`1` は現れない。
  全 `g ≤ 1` なので全子は `g = 0`。
- `g(S) = 0` なら、`0` が子に現れないので全子は `g ≥ 1`。
  全 `g ≤ 1` なので全子は `g = 1`。

いずれも `g(S) ≠ g(S')`。□

### 逆方向の証明

`M₀, M₁` を極大で `|M₀|` 偶数、`|M₁|` 奇数とする。
`S = M₀ ∩ M₁` とおく（安全集合。極大集合の部分集合なので）。

`S` から `M₀` へ長さ `d₀ = |M₀| − |S|` の経路、`M₁` へ長さ `d₁ = |M₁| − |S|` の経路がある。
`|M₀|` と `|M₁|` の偶奇が違うので、**`d₀` と `d₁` の偶奇も違う**。

補題2により、任意の経路で Grundy 値は交互に 0,1,0,1,… と変化する。
したがって経路長の偶奇が `g(M) = 0` を決める：
- `g(S) = 0` なら、長さ偶数の経路で終局に至る（`0,1,0,…,0`）。
- `g(S) = 1` なら、長さ奇数の経路で終局に至る（`1,0,1,…,0`）。

いずれの場合も、`S` から到達できる**すべての**極大集合の距離の偶奇は同じ。
しかし `d₀` と `d₁` は偶奇が違う。**矛盾**。

よって `M₀, M₁` は存在しない。□

## 5. 意義

**完全な二分法が証明された**：

```
極大集合の偶奇が揃う  ⟺  全 Grundy 値が 0/1
```

これは共円ゲームに限らず、**任意の有限不偏ゲーム**（局面が集合、手が1点追加、
終局が極大集合）に成り立つ一般的な定理である。

系として：
- 一様な盤（全極大が同サイズ）は偶奇が揃うので、全 Grundy 値が 0/1。
- Grundy 値 2 以上が現れるには、極大サイズの偶奇が混在することが**必要十分**。

## 6. 限界

- 局面が「集合」で手が「1点追加」という構造を仮定している。
  一般の不偏ゲーム（例えば Nim）には当てはまらない。
- 幾何盤での検証は4盤のみ（ただし定理は一般的）。
