# 転送閾値 D(n) の閉形式と残る証明課題

2026-11-20。`finite-field-kyouen-20261120` の第5部。
整数格子から有限体盤への転送を支配する量 `D(n)` について、閉形式の証拠を揃えた記録。

## 1. 量の定義

n×n 格子の四点 `(x_i,y_i)` に対し

```
Delta = det[[x_i, y_i, x_i^2+y_i^2, 1]]
```

とおく。`Delta = 0` が四点共円・共線の判定式である。
`D(n) = max |Delta|`（全四点組）が、mod q 還元で偽の禁止四点が生じないための閾値になる：
**q > D(n) なら `Delta ≡ 0 (mod q)` と `Delta = 0` が同値**。

## 2. 閉形式

`a = n−1` として

```
D(n) = a² ⌊a²/2⌋
```

極値配置は常に「三隅 `(0,0), (a,0), (0,a)` ＋ 対角点 `(t,t)`」で、その行列式は

```
Delta = −2 a² t (a−t)
```

`t` についての最大化は `t = ⌊a/2⌋` または `⌈a/2⌉` で、`|Delta| = 2a²⌊a²/4⌋`。
`a` の偶奇で場合分けすると `a²⌊a²/2⌋` に一致する。

## 4. 残る証明課題

上記は**観測と族内の厳密計算**であって、`D(n) = a²⌊a²/2⌋` の全称証明ではない。
示すべきは次の一点に尽きる：

> 三隅＋対角点の族以外の任意の四点配置は `|Delta| ≤ a²⌊a²/2⌋` を満たす。

`Delta` は四点の座標について 4 次式で、格子 `[0,a]²` 上の整数点での評価である。
素朴な見積もりでは各項が `O(a⁴)` で、係数の評価だけでは族の値と定数倍しか合わない。
族が最大であることを示すには、行列式の構造（3点が円を定め、4点目がその円上にある条件）を
使った議論が必要と考えられるが、本実験では到達していない。

## 5. 実用上の帰結

`D(n)` は n について 4 次で増える。したがって整数 n×n 盤を埋め込める有限体 AG(2,q) は
`q > (n−1)²⌊(n−1)²/2⌋` を満たす必要がある。

| n | 必要な q の下限 |
|---:|---:|
| 5 | > 128 |
| 7 | > 648 |
| 9 | > 3,240 |
| 11 | > 7,260 |
| 20 | > 64,980 |

11×11 を扱うには q > 7,260 の体が要る。これは**有限体盤が整数格子の近似として使えない**ことの
定量的な表現である。
