# k=8 の `z4` の構造：共円性で決まる

2026-11-20。`finite-field-kyouen-20261120` の第204部。

k=8 の6類のうち `z4` の構造を解明した。

## 1. 定義

```
z4 = #{C' ≠ C : |C' ∩ T| = 0  かつ  |C' ∩ X| = 4}
```

`C'` は外4点 `X` すべてを含む。**4点は高々1つの円を定める**ので、
`z4` は **0 か 1**。

## 2. 定理

```
z4 = 1  ⟺  X が共円 かつ その円が T と交わらない
```

**理由**：`X` が共円でなければ `X` を含む円は存在しない（`z4 = 0`）。
`X` が共円なら円 `D` が一意に定まる。`D` が `T` と交われば
`|D ∩ T| ≥ 1` となり `z4` の条件を満たさない（代わりに `v2`/`v3`/`v4`
または `u3`/`u4` に数えられる）。

## 3. 検証（q=5）

`n = 26`、`b = 130`、`s = 6`、外点 20 個。

**共円な `X` の個数**：

```
645 / 4,845   （C(20,4) = 4,845）
```

**`(X が共円か, z4)` の分布**：

| `X` 共円 | `z4` | 組数 |
|---|---|---:|
| False | 0 | 63,000 |
| True | 0 | 2,250 |
| True | 1 | **7,425** |
| | | **72,675** ✓ |

**完全に整合。**

## 4. 解釈

- **`X` が共円でない** → `z4 = 0` 常に（63,000 組）
- **`X` が共円** → `z4 = 1` が 76.7%（7,425 / 9,675）
- 残り 23.3%（2,250 組）は円が `T` と交わるため `z4 = 0`

**`z4 = 1` の割合**：`7,425 / 72,675 = 10.2%`

## 5. 閉形式への道

`z4` の総和は

```
Σ z4 = Σ_{T} Σ_{X 共円} [円(X) ∩ T = ∅]
```

`X` が共円な組の数は**外点集合の4-アーク数**に等しい（外点 20 個の
うち共円な4点）。よって

```
Σ z4 = (#共円 X) × (#T で円(X) ∩ T = ∅ となるもの)
```

`T` は `C` の4点部分集合（15個）。円 `D` が `C` と `k` 点で交わると
`D ∩ T = ∅` となる `T` の数は `C(s−k, 4)`。

**よって `z4` の閉形式は「外点の共円4点の個数」と「`D` と `C` の
交点数」の分布から書ける。**

## 6. 意義

1. **`z4` の構造を完全に解明した**（共円性 + `T` との非交差）。
2. **q=5 で完全に検証**（72,675 組すべて整合）。
3. **`z4` の閉形式への道筋を示した**（外点の共円4点 + 交点数分布）。
4. **`z4` が6類の中で最も構造が単純**であることを確認。
