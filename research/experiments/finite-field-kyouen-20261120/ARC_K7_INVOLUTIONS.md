# k=7 の対合構造：3つの対合は「互いに素」か「1つの共通対」

2026-11-20。`finite-field-kyouen-20261120` の第148部。

k=7 の `(w, j₁, j₂, j₃)` 同時分布を掘り、**3つの対合の関係**を決定した。

## 1. 主定理

`{x,y,z}` の3つの対に対応する3つの対合
`ι(x,y), ι(x,z), ι(y,z)`（`C` 上の対合）について

**定理**：この3つは次のいずれかである。

- **場合 A**：互いに素（共通の対を持たない）
- **場合 B**：**ちょうど1つの共通対**を持ち、他の対は共有しない

**検証**（q=5、1,140 三つ組）：

| 共通対の個数 `(ι₁∩ι₂, ι₁∩ι₃, ι₂∩ι₃)` | 個数 |
|---|---:|
| `(0,0,0)` | **840** |
| `(1,1,1)` | **300** |

**中間の場合（例：`(1,1,0)`）は存在しない。**

## 2. 場合 B の内訳

共通対 `{p,p'}` が `T` に含まれるかで分かれる。

| 場合 | `w` | 共通対が `T` 内 | 個数 |
|---|---:|---|---:|
| A | 0 | — | 680 |
| A | 1 | — | 160 |
| B | 0 | いいえ | 20 |
| B | 1 | いいえ | 160 |
| **B** | **2** | **はい** | **120** |

**`w = 2` は「場合 B かつ共通対が `T` 内」と完全に一致する。**

## 3. なぜか

共通対 `{p,p'}` は3つの対合すべてに属する。これは
「`p,p'` を通る円 `W'` が3つのペンシルすべてに属する」ことを意味する。

`W'` が3つのペンシルすべてに属する ⟺ `W'` は `x,y,z` のうち
2点以上を通り、かつ `T` から2点取る。

- `W'` が `x,y,z` の3点を通るなら `W' = W`（3点が定める円は一意）
- よって共通対は `W ∩ C` であり、`w = |T ∩ W| = 2` と同値

**つまり「共通対が `T` 内」⟺ `w = 2`。** □

## 4. `u` 公式の再解釈

前項の `u = Σj − 3[w=2]` は、この構造から直ちに従う：

- 場合 A：3つの対合は素なので、`T` に完全に入る対は重複しない
  → `u = Σj`
- 場合 B で `w = 2`：共通対が3回数えられる → `u = Σj − 3`
- 場合 B で `w ≤ 1`：共通対は `T` に完全に入らないので寄与0
  → `u = Σj`

## 5. 意義

1. **3つの対合の関係を完全に決定した**（互いに素 or 1共通対のみ）。
2. **`w = 2` が「共通対が `T` 内」と同値**であることを証明した。
3. **`u` 公式の構造的な理由**を明らかにした。
4. k=7 の `(w, j)` 同時分布が「対合の組合せ構造」に帰着することを示した。
