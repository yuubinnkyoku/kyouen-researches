# 連続上界の証明：中心の内外による場合分け

2026-11-20。`finite-field-kyouen-20261120` の第23部。
`Area·max|power| ≤ a⁴/4` の証明に向けた場合分けを確定した。

## 1. 前回の失敗とその原因

前項では `Area·R² ≤ a⁴/4` を試したが、**大きく破れた**（a=5 で 66,625/4 対 625/4）。

原因：`R²` は「中心における power の絶対値」だが、**中心が正方形の外にある場合、
正方形内の点の power は `R²` にならない**。

例：a=5、三点 `(0,0),(5,4),(9,7)` 相当の細長い三角形では
- 面積 `1/2`（ほぼ一直線）
- `R² = 66625/2`（半径 182.5）
- しかし中心は `(111.5, −144.5)` で正方形から遠く離れている

正方形内の点は中心から遠いので `|P−O|² ≫ R²` となり、`power` は `R²` ではなく
`|P−O|² − R²` という大きな値になる。しかしその値は `Area` との積で見ると
上界を超えない。

## 2. 正しい場合分け

中心 `O` が正方形 `[0,a]²` の内側か外側かで分ける。

| a | 上界 a⁴/4 | 中心が内側 | 中心が外側 |
|---:|---:|---:|---:|
| 3 | 81/4 | **81/4**（432組） | 18（84組） |
| 4 | 64 | **64**（1,760組） | 56（388組） |
| 5 | 625/4 | **625/4**（5,424組） | 150（1,344組） |
| 6 | 324 | **324**（13,944組） | 306（3,656組） |
| 7 | 2401/4 | **2401/4**（31,504組） | 588（8,616組） |

**最悪ケースは常に「中心が内側」の場合に達成される。**
中心が外側の場合は上界に対して余裕がある（a=7 で 588 対 600.25）。

## 3. 中心が内側の場合

中心が正方形内にあれば、`power(O) = −R²` なので `|power| ≥ R²`。
実際、最悪ケースでは `max|power| = R²` が達成される（中心そのものが正方形内にあるため）。

したがって中心が内側の場合は

```
Area · R² ≤ a⁴/4
```

を示せばよい。`R = xyz/(4A)` なので

```
Area · R² = A · (xyz)²/(16A²) = (xyz)²/(16A)
```

**中心が正方形内にあるという条件が効く**：中心が内側なら、外接円は正方形と
深く交わる。特に円は正方形内の三点を通るので、`R` は正方形の直径程度に抑えられる
（`R ≤ a√2` 程度）。実際、最悪ケースの `R²` は `a²/2`（a 奇数）または `a²`（a 偶数）である。

`R ≤ a√2` とすると `R² ≤ 2a²`、よって

```
Area · R² ≤ (a²/2) · 2a² = a⁴
```

これは上界 `a⁴/4` の4倍で、まだ足りない。より精密な評価が必要。

## 4. 最悪ケースの再確認

| a | 三点 | Area | R² | 積 |
|---:|---|---:|---:|---:|
| 3 | (0,0),(3,0),(0,3) | 9/2 | 9/2 | 81/4 |
| 4 | (0,0),(4,0),(2,2) | 4 | 16 | 64 |
| 5 | (0,0),(5,0),(0,5) | 25/2 | 25/2 | 625/4 |
| 6 | (0,0),(6,0),(3,3) | 9 | 36 | 324 |
| 7 | (0,0),(7,0),(0,7) | 49/2 | 49/2 | 2401/4 |

a 奇数：`Area = a²/2`、`R² = a²/2`、積 `a⁴/4`。
a 偶数：`Area = a²/4`、`R² = a²`、積 `a⁴/4`。

いずれも `Area · R² = a⁴/4` にちょうど一致する。

## 5. 証明の現状

確立したこと：

1. `gamma = −2·Area`（証明済み）
2. 最悪ケースは中心が正方形内の場合に限る（a ≤ 7 の全数）
3. その場合 `max|power| = R²`（中心で達成）
4. よって示すべきは `Area · R² ≤ a⁴/4`

未確立：

- `Area · R² ≤ a⁴/4` の証明（中心が正方形内という条件下で）
- 中心が外側の場合の `Area · max|power| ≤ a⁴/4` の証明

**中心が内側という条件をどう使うか**が鍵である。中心が内側なら
`R² = |O − p1|²` で、`O` も `p1` も正方形内なので `R ≤ a√2`。
しかしこれだけでは `a⁴` しか出ない。`Area` と `R` の同時評価が必要。

## 6. 限界

- a ≤ 7 の全数計算。
- §5 の「示すべきこと」は未証明。
- 中心が外側の場合の評価も未完成（数値的には余裕があるが、証明はない）。
