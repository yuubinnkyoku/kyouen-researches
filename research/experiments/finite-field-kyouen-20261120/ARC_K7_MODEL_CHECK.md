# k=7 の9分布は模型に依らない（検証）と、軌道対応の失敗

2026-11-20。`finite-field-kyouen-20261120` の第157部。

前項で「正しい不変量は `PGL(2,q)` 軌道で37」と述べた。本項は
**9分布が模型に依らない**ことを確認し、軌道対応の試みが失敗した
理由を記録する。

## 1. 9分布の模型非依存性（検証）

2つの独立な模型で `(w,u)` 分布を計算した。

**ovoid 模型**（楕円二次曲面、`arc_k7_orbit_types.py`）：

```
distinct (w,u)-distributions: 9
```

**native 模型**（`P^1(F_{q^2})`、`arc_k7_native_orbits.py`）：

```
distinct (w,u)-distributions: 9
```

**両方で同じ9分布、同じ多重度**（240, 240, 180, 120, 120, 120, 60, 40, 20）。

**したがって9分布は模型に依らない幾何学的実体である。**

## 2. 軌道対応の試み（失敗）

`PGL(2,q)` 軌道（37個）と実際の三つ組を対応させようとしたが失敗した。

**ovoid 模型での試行**：

```
37 orbits
triples per orbit: {16: 36, 31: 24, 36: 16}
total triples: 76, unmatched 1064
orbits actually realised: 3
```

**1,140 三つ組のうち 1,064 が対応しなかった。**

## 3. 失敗の理由

ovoid 模型の円 `C` は抽象的な `s` 点集合であり、`P^1(F_q)` への
全単射を「ソート順」で作るとメビウス構造が保たれない。
そのため誘導された置換が正しい対合にならない。

```
KeyError: (1, 0, 2, 3, 5, 4)
```

**正しい対応には、円 `C` から `P^1(F_q)` への構造を保つ全単射
（メビウス同型）が必要である。**

## 4. native 模型でも未解決

native 模型（`P^1(F_{q^2})`）では円が `P^1(F_q)` の像なので構造は
正しいが、`PGL(2,q)` の作用を三つ組に制限する計算は未実装。

**9分布は確認できたが、37軌道との対応は未取得。**
