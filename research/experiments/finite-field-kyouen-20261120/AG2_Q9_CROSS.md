# AG(2,9) の構造：81個の「十字」ブロックと上界 K ≤ 14

2026-11-20。`finite-field-kyouen-20261120` の第28部。
AG(2,9) のブロック構造を分解座標で記述し、新しい上界を得た。

## 1. 分解座標

`F_9 = F_3[i]/(i²+1)`（`i² = −1 = 2 mod 3`）とおく。`F_9` 上の可逆線形写像

```
(x, y) ↦ (s, t) = (x + iy, x − iy)
```

は `x² + y²` を `s·t` に移す（`(x+iy)(x−iy) = x² − i²y² = x² + y²`）。
したがって円の方程式 `x²+y²+Dx+Ey+F = 0` は

```
s·t + a·s + b·t + c = 0
```

の形になる。AG(2,9) の 819 ブロックはこの座標で次の3種に分類される：

| 種類 | 個数 | サイズ | 形 |
|---|---:|---:|---|
| 直線 | 90 | 9 | `a·s + b·t = c` |
| 非退化円錐曲線 | 648 | 8 | `s·t + a·s + b·t + c = 0`（`ab ≠ c`） |
| **退化（十字）** | **81** | **17** | `(s+a)(t+b) = 0`、すなわち**列＋行** |

`build_ag(9)` との照合で、819 ブロックが**完全に一致**することを確認した
（点集合として同一、各点の incidence は 91）。

## 2. 十字ブロックの意味

81 個の十字は `9列 × 9行` の全組み合わせに対応する。各十字は
「ある列の9点＋ある行の9点−交点1点 = 17点」である。

**安全集合は各十字に高くとも3点しか置けない。**

## 3. 新しい上界 K ≤ 14

`a_c` を列 `c` の点数、`b_r` を行 `r` の点数、`x_{cr} ∈ {0,1}` を交点の有無とする。
十字 `(c,r)` の制約は

```
a_c + b_r − x_{cr} ≤ 3
```

全 `(c,r)` について和を取ると

```
9·Σa_c + 9·Σb_r − Σx_{cr} ≤ 3·81
9|S| + 9|S| − |S| ≤ 243
17|S| ≤ 243
|S| ≤ 14.29…
```

よって **K(AG(2,9)) ≤ 14**。

既知の下界は K ≥ 9（サイズ9の安全集合が実在）なので

```
9 ≤ K(AG(2,9)) ≤ 14
```

## 4. 十字制約を満たす配置の数

十字制約（各列・各行に高々2点、かつ `a_c + b_r − x_{cr} ≤ 3`）を満たす
10点配置の数を DP で数えると **46,962,682,200**（約470億）であった。

これは十字制約だけでは絞り込みが弱いことを示す。残り 738 ブロック
（直線90＋円錐曲線648）の制約が必要。

## 5. ランダム探索の結果

ランダム貪欲法を 4 シード × 20,000 再起動で実行したが、
最大でもサイズ9しか見つからなかった。サイズ10の存在は未確定。

## 6. 意義

- AG(2,9) のブロック構造が**分解座標で完全に記述できた**。
- 十字ブロックという**大きなブロック（17点）**の存在が分かり、
  そこから初等的な上界 `K ≤ 14` が出た。
- この上界は「各列・各行に高々2点」という組合せ的条件から来ており、
  幾何（円）を使っていない。したがって**他の q にも一般化できる可能性**がある。

## 7. 限界

- 上界 K ≤ 14 は AG(2,9) 固有（q=9 で十字が 17 点になるため）。
- 一般の q で同様の十字ブロックが存在するかは未検証。
  `x²+y²` が分解するのは `−1` が平方のとき（q ≡ 1 mod 4）なので、
  q=5, 13, 17 などでも十字が現れるはずである。
- サイズ10の存在は未確定。
- 分解座標の記述は q=9 で検証したのみ。
