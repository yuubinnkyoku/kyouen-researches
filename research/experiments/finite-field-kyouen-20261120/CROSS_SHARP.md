# 十字上界の改良：K ≤ q + 2（q ≡ 1 mod 4）

2026-11-20。`finite-field-kyouen-20261120` の第44部。
十字ブロックを使った上界を `3q²/(2q−1) ≈ 1.5q` から **`q + 2`** へ改良した。

## 1. 定理

`q ≡ 1 (mod 4)` を素数冪とし、`k ≥ q` とする。AG(2,q) の共円ゲームで

```
K(AG(2,q)) ≤ q + 2
```

## 2. 設定

`−1` が平方なので `i² = −1` なる `i ∈ F_q` が存在する。分解座標

```
(s, t) = (x + iy, x − iy)
```

で、`x² + y² = s·t`。円の方程式は `s·t + a·s + b·t + c = 0` となり、
`ab = c` の退化円は

```
(s + b)(t + a) = 0
```

すなわち「列 `s = −b`」と「行 `t = −a`」の和集合（**十字**）になる。
十字は `2q − 1` 点、`(a,b)` の選び方は `q²` 通りなので `q²` 個ある。

## 3. 証明

`a_c` を列 `c` の点数、`b_r` を行 `r` の点数、`x_{cr} ∈ {0,1}` を交点の有無とする。
十字 `(c,r)` の制約は

```
a_c + b_r − x_{cr} ≤ 3        (*)
```

### ステップ1：各列・各行は高々2点

`(*)` を `r` について和を取ると

```
q·a_c + k − a_c ≤ 3q
(q−1)·a_c ≤ 3q − k
a_c ≤ (3q − k)/(q−1)
```

`k ≥ q` なら右辺は `2q/(q−1) < 3`。`a_c` は整数なので **`a_c ≤ 2`**。
同様に `b_r ≤ 2`。

### ステップ2：2点を持つ列・行は高々2本ずつ

`C₂ = {c : a_c = 2}`、`R₂ = {r : b_r = 2}` とおく。
`c ∈ C₂` かつ `r ∈ R₂` のとき `(*)` は

```
2 + 2 − x_{cr} ≤ 3   ⟹   x_{cr} = 1
```

つまり **`S` は `C₂ × R₂` の全点を含む**。

`|C₂| = p`、`|R₂| = s` とすると、`C₂ × R₂` は `p·s` 点。
しかし各列は高々2点なので `p·s ≤ 2p`、すなわち `s ≤ 2`。同様に `p ≤ 2`。

### ステップ3：結論

2点を持つ列は高々2本、残り `q − 2` 本は高々1点。よって

```
k = Σ_c a_c ≤ 2·2 + (q − 2)·1 = q + 2   □
```

## 4. 検証

十字の交わり構造を機械確認した（2つの十字は「2点」または「q点」で交わる）。

| q | 十字の個数 | 交わりのサイズ | 上界 q+2 | 既知の K |
|---:|---:|---|---:|---:|
| 5 | 25 | {2, 5} | **7** | 6（厳密） |
| 9 | 81 | {2, 9} | **11** | 9（厳密） |
| 13 | 169 | {2, 13} | **15** | ≥13 |
| 17 | 289 | {2, 17} | **19** | ≥17 |

## 5. 上界の比較

| q | 旧上界 3q²/(2q−1) | **新上界 q+2** | 既知の K |
|---:|---:|---:|---:|
| 5 | 8 | **7** | 6 |
| 9 | 14 | **11** | 9 |
| 13 | 20 | **15** | ≥13 |
| 17 | 26 | **19** | ≥17 |

**新上界は旧上界より常に強い**（q=17 で 19 対 26）。

さらに、`K/q ≈ 1.00` という観測と整合する：上界 `q+2` は `q` の1次で、
係数が1である。

## 6. 意義

- 十字上界を `1.5q` から `q+2` に改良した。**証明済み**。
- この上界は `K/q ≈ 1` という観測を説明する形になっている。
- q=5 では上界7に対し真値6で、差はわずか1。

## 7. 限界

- `q ≡ 1 (mod 4)` のみ。`q ≡ 3 (mod 4)` では十字が存在しない。
- `k ≥ q` という条件付き（`k < q` の場合は自明に上界を満たす）。
- q=9 では上界11に対し真値9で、差2。まだ緩い。
- 標数2（q=4, 8, 16）は別種の退化なので対象外。
