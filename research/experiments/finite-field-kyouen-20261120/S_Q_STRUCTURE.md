# `s(q) = k*` の構造：q=8 の完全分解と、貪欲法の失敗

2026-11-20。`finite-field-kyouen-20261120` の第125部。

前項で最小極大集合 `s(q)` がブロッキング上界の最小値 `k*` に一致することを
見た（q ≤ 11）。本項はその**構造**を掘る。

## 1. 欠損（defect）の定義

サイズ `k` の極大安全集合 `S` に対し

```
δ(S) = C(k,3)·(q−2) − (q² + 1 − k)
```

ブロッキング不等式は `δ(S) ≥ 0`。`δ = 0` は「外の全点がちょうど1回ずつ
覆われる」ことを意味する。

## 2. 計算した欠損

| q | `k*` | 容量 `C(k,3)(q−2)` | 必要点数 `n−k*` | `δ` |
|---:|---:|---:|---:|---:|
| 3 | 5 | 10 | 5 | 5 |
| 4 | 5 | 20 | 12 | 8 |
| 5 | 5 | 30 | 21 | 9 |
| 7 | 5 | 50 | 45 | 5 |
| **8** | **5** | **60** | **60** | **0** |

**q = 8 だけが等号。** これは代数から予測できる：`k = 5` で不等式は

```
q² − 4 ≤ 10(q − 2)  ⟺  (q − 2)(q − 8) ≤ 0  ⟺  2 ≤ q ≤ 8
```

`q = 8` で等号になり、`q > 8` では破れる。

## 3. q=8 の完全分解（検証済み）

`q8_tightness.py` で実際の witness を解析した：

```
q=8: n=65, 520 circles
  witness [0, 1, 2, 31, 50]
  outside points      : 60
  covered outside     : 60
  capacity C(k,3)(q-2): 60
  multiplicity hist   : {'1': 60}
  circles disjoint outside S: True
  tight (covered == capacity): True
```

**外の60点がすべてちょうど1回ずつ覆われ、10個の円が `S` の外で
互いに素である。** 予測された完全分解が実現している。

**定理（q=8 の構造）**：`q = 8` の5点極大安全集合は、
`S` の三点組が定める10個の円が `S` の外の60点を
6点ずつ10個に**完全分解**することを強制する。 □

（証明：等号 `δ = 0` は「全点がちょうど1回覆われる」と同値であり、
それは円が外で互いに素であることと同値。）

## 4. 貪欲法は失敗する

`k*` 点の極大集合を**決定的な貪欲法**（各ステップで最も多くをブロックする
点を選ぶ）で構成できるかを試した。

| q | `k*` | 貪欲で極大? | 未ブロック点 |
|---:|---:|---|---:|
| 3 | 5 | **成功** | 0 |
| 4 | 5 | **成功** | 0 |
| 5 | 5 | **失敗** | 2 |
| 7 | 5 | **失敗** | 6 |

**貪欲法は q ≥ 5 で失敗する。**

これは重要である：`s(q) = k*` の上限（存在）は
**単純な貪欲構成では得られない**。ランダム再起動では見つかる
（q=5 で12回、q=7 で27回、q=9 で2回）が、決定的な構成則は不明。

## 5. 何が分かったか

1. **`δ = 0` は q=8 のみ**（`k=5` の場合）。代数から予測でき、検証済み。
2. **q=8 の極大集合は完全分解を強制する**（定理）。
3. **貪欲法は q ≥ 5 で失敗する**。存在は非構成的である。
4. `s(q) = k*` の下限は不等式から厳密に従うが、
   上限は依然として構成的確認のみ。

## 6. 意義

- ブロッキング不等式の**等号条件を初めて具体的に確認した**（q=8）。
- 「なぜ `s(q) = k*` か」に対して、**貪欲法では説明できない**ことを示した。
  これは問題の難しさの所在を明確にする。
- `q = 8` が `k = 5` の境界であることが、代数と幾何の両面から確定した。

## 7. 限界

- `δ = 0` の解析は `k = 5` のみ。`k = 6, 7` の等号条件は未解析。
- 貪欲法の失敗は q ≤ 7 の観測。q = 9, 11 では未実施（計算量）。
- `s(q) = k*` の上限の一般証明は依然未取得。
- q=8 の `build()` に 453 秒かかる（PGL 列挙）。q ≥ 9 は実用的でない。
