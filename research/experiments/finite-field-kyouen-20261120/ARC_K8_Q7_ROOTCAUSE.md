# k=8 の q=7 の差 784,000：プロファイル数の不一致

2026-11-20。`finite-field-kyouen-20261120` の第224部。

q=7 の組み立ての差 784,000 の原因を追跡した。

## 1. 判明したこと

### 1.1 `(6,)` プロファイルは 0 件

`(6,)` の構造を直接測定した（q=7、固定した円 `D` 上）：

```
#ペンシル円が T6 と2点で交わる → 組数
  1: 6,048
  2: 16,128
  3: 1,932
  0: 0        ← 0 件！
```

**`(6,)` は 0 件。** よって差 784,000 は `(6,)` ではない。

（前項で「差 = `b·C(s,6)·s(s+2)` だから `(6,)`」と結論したが、
**数値の一致は偶然だった**。）

### 1.2 プロファイル数の不一致

| 対象 | プロファイル数 |
|---|---:|
| 組み立て（q=7） | **21** |
| 全数（k=7、q=7） | 11 |

**組み立てが21種のプロファイルを生成している。**

（ただし全数の11種は **k=7** のもので、k=8 の全数は測定中。）

## 2. 差の符号

```
組み立て bad = 536,094,650
全数   bad = 536,878,650
差 = 784,000（組み立てが少ない）
```

**組み立てが bad を 784,000 少なく数えている** = 8-アークを 784,000
多く見積もっている。

## 3. 考えられる原因

### 3.1 タプルループが `C` を固定している

タプルループは `T = C ∩ S` が4点である `S` のみを生成する。
**`|C ∩ S| < 4` の `S` は生成されない。**

しかし `b` を掛けることで「すべての円 `C` について」足し合わせるので、
各 `S` は「`S` の4円の個数」回現れる。**よって割り算 `÷n4` で1回になる。**

**この論法は正しいはず**だが、q=7 で合わない。

### 3.2 プロファイル公式が q=7 で破綻

q=9 では 500 組で 0 不一致だったが、q=7 では未検証。
**q=7 で検証する必要がある。**

### 3.3 `(7,)` と `(8,)` の別項が過大

```
(7,) = b·C(s,7)·(n−s) = 117,600
(8,) = b·C(s,8)       =     350
```

これらは「他の4円を持たない」条件を課していない。
**q=7 では `(7,)` や `(8,)` に該当する `S` が別の4円を持つ可能性がある。**

**`(7,)` の上限 117,600 のうち、実際に単一円なのは一部かもしれない。**
