# k=7 の構造：q=5,7 では7-アークが存在しない

2026-11-20。`finite-field-kyouen-20261120` の第141部。

k=6 を閉じた手法を k=7 に拡張する第一歩。

## 1. 結果：7-アークの個数

| q | 7-アーク | `K(q)` | 整合 |
|---:|---:|---:|---|
| 5 | **0** | 6 | ✓ |
| 7 | **0** | 6 | ✓ |
| 8 | **1,048,320** | 7 | ✓ |

**q=5, 7 では7-アークが1つも存在しない。** これは `K = 6` と整合する。
q=8 で初めて出現し、その個数 1,048,320 は
Sitjar の preprint の値と一致（前項で確認済み）。

## 2. q=5 のプロファイル（全数）

`C(26,7) = 657,800` の全7点集合を分類した。**アークは 0**。

| プロファイル | 個数 |
|---|---:|
| (4,4,4,4) | 312,000 |
| (4,4,4) | 96,200 |
| (5,4,4) | 85,800 |
| (4,4,4,4,4) | 78,000 |
| (5,4) | 62,400 |
| (4,4) | 15,600 |
| (4,4,4,4,4,4) | 5,200 |
| (6,) | 2,600 |
| **合計** | **657,800** |

**8種類のプロファイル。** k=6 の5種類より複雑。

## 3. 単純な項の検証

`(6,)` は「1円が6点、残り1点が円外」：

```
(6,) = b·C(q+1,6)·(n−q−1) = 130·1·20 = 2,600  ✓
```

## 4. なぜ q=5,7 で7-アークが無いのか

ブロッキング上界は禁じていない：

```
q=5, k=7: q²+1−k = 20 ≤ C(7,3)·(q−2) = 35·3 = 105
```

**数え上げでは排除できない。幾何的な障害である。**

`K(5) = K(7) = 6` なので、7点の安全集合は存在しない。
これは「6点が上限」という強い幾何的制約である。

## 5. k=6 との構造的な違い

| | k=6 | k=7 |
|---|---|---|
| プロファイル数（q=5） | 5 | **8** |
| 最大の円の点数 | 6 | 6 |
| 円の個数 `m` | ≤ 3 | ≤ 6 |
| アーク数（q=5） | 5,200 | **0** |

k=7 では `m`（4点以上を持つ円の個数）が最大6まで増える。
2円は高々2点で共有するので `|S| ≥ 4m − 2·C(m,2)` だが、
`m=6` では `24 − 30 = −6` となり制約にならない。

**つまり k=7 では「円の配置」が本質的に複雑になる。**

## 6. 意義

1. **q=5, 7 で7-アークが存在しないことを全数確認した。**
2. **q=8 で初めて出現**し、その個数が文献値と一致することを確認。
3. **k=7 のプロファイルは8種類**で、k=6 の5種類より複雑であることを示した。
4. **ブロッキング上界では7-アークの非存在を説明できない**ことを明確にした。

## 7. 限界

- プロファイルの全数分類は q=5 のみ（q=7 は `C(50,7) ≈ 1.0×10⁸` で重い）。
- k=7 の閉形式は未取得。プロファイルが8種類あり、k=6 の手法
  （ペンシルの対合）をそのまま拡張できない。
- k ≥ 8 は未着手。
