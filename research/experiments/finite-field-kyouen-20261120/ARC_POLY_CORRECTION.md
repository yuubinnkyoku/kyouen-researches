# 重要な訂正：`#5` の多項式の誤りと `arcs6` の浮動小数点バグ

2026-11-20。`finite-field-kyouen-20261120` の第189部。

前項までの多項式に**2つの誤り**を発見した。両方修正した。

## 1. 誤り1：`#5` の多項式の書き写しミス

前項（第184部）で記録した `#5-arcs` の多項式は**誤っていた**。

| 次数 | 記録していた値 | **正しい値** |
|---|---|---|
| `q³` | 5/120 | 1/24 = 5/120 ✓ |
| `q⁴` | −15/120 | **−3/40** |
| `q⁵` | 15/120 | **1/24** |
| `q⁶` | −5/120 | **−1/120** |
| `q⁷` | −1/120 | **−1/24** |
| `q⁸` | 5/120 | **3/40** |
| `q⁹` | −5/120 | **−1/24** |
| `q¹⁰` | 1/120 | 1/120 ✓ |

**5つの係数が誤っていた。** 検算すると q=5 で `45875/3`（非整数）になり、
実測 `26000` と一致しないことで発覚。

**正しい多項式**：

```
#5-arcs = q³/24 − 3q⁴/40 + q⁵/24 − q⁶/120 − q⁷/24
          + 3q⁸/40 − q⁹/24 + q¹⁰/120
```

**検証**：q=3..59 の**全整数 q** で完全一致。

## 2. 誤り2：`arcs6` の浮動小数点バグ

`arc_k6_pure.py` の `arcs6` が

```python
contrib += b * cnt * (h0 + h1 / 2 + h2 / 3)
```

と書かれていた。`h1 / 2` と `h2 / 3` が**浮動小数点除算**になり、
`#6-arcs` が 2⁵³ を超えると精度を失っていた。

**症状**：q=45, 53, 57 で多項式検証が失敗。

```
q=45: 67831371675421208  (末尾 208 -- 120 で割り切れない)
q=53: 509877505952427648 (末尾 648)
q=57: 1246734523505016064 (末尾 064)
```

**修正**：

```python
contrib = Fraction(0)
...
contrib += b * cnt * (h0 + Fraction(h1, 2) + Fraction(h2, 3))
```

**修正後**：

```
q=45: 67831371675421200  (整数、120 で割り切れる)
q=53: 509877505952427600
q=57: 1246734523505016000
```

## 3. 修正後の全多項式（q=3..59 で検証）

### `#4-arcs`（8次）

```
= q³(q−1)²(q+1)(q²+1)/24
```

**完全因数分解。**

### `#5-arcs`（10次）

```
= q³(q−1)²(q+1)(q²+1)(q² − 4q + 5)/120
```

**検証**：q=3..59 で完全一致。

（残り2次因子 `q² − 4q + 5` は判別式 `16−20 = −4 < 0` で実根なし。）

### `#6-arcs`（12次、**奇数 q のみ**）

```
= q²(q−1)²(q+1)(q−3)(q²+1)
  × (q⁴ − 11q³ + 43q² − 60q + 5)/720
```

**検証**：奇数 q=3..59 で完全一致。

## 4. 因子の階層（修正版）

| k | 分解 | 残り |
|---|---|---|
| 4 | `q³(q−1)²(q+1)(q²+1)` | なし（完全） |
| 5 | `q³(q−1)²(q+1)(q²+1)` | `q²−4q+5`（2次、実根なし） |
| 6 | `q²(q−1)²(q+1)(q−3)(q²+1)` | `q⁴−11q³+43q²−60q+5`（4次） |

**`#5` も `#4` と同じ因子を持つ**（前項では `q³(q−1)` までしか
括り出せないと誤記していた）。
