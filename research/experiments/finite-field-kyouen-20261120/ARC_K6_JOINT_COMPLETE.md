# k=6 の交点表：完全に閉じた

2026-11-20。`finite-field-kyouen-20261120` の第137部。

前項で `|C' ∩ C| = 2` の3項を閉じた。本項で**残る3項も閉じ、
k=6 の交点表が完全に解決した。**

## 1. 完全な交点表

円 `C`（サイズ `q+1`）、その4点部分集合 `T`、`C` の外の2点 `{x,y}`、
`x,y` を通る円 `C' ≠ C` を考える。

**定理**：`(a, c) = #{({x,y}, C') : |C' ∩ C| = a, |T ∩ C'| = c}` は

```
(2,2) = C(4,2) · q · C(q−1,2)      = 6q·C(q−1,2)
(2,1) = 4(q−3) · q · C(q−1,2)
(2,0) = C(q−3,2) · q · C(q−1,2)

(1,1) = 4 · (q−1) · C(q,2)
(1,0) = (q−3) · (q−1) · C(q,2)

(0,0) = 総数 − (2,·) − (1,·)
```

## 2. 証明

### 2.1 `|C' ∩ C| = 2` の場合

`C'` は `C` と2点 `{u,v}` で交わる。

- `u,v` を通る円は `q+1` 個、うち1つは `C` 自身 → **`q` 通り**
- `{x,y}` は `C'` 上で `C` の外の2点。`C'` は `q+1` 点を持ち
  `C` との共有点が2点なので外は `q−1` 点 → **`C(q−1,2)` 通り**
- `{u,v}` の選び方：
  - 両方 `T` 内：`C(4,2) = 6` → `(2,2)`
  - 片方 `T` 内：`4(q−3)` → `(2,1)`
  - 両方 `T` 外：`C(q−3,2)` → `(2,0)`

### 2.2 `|C' ∩ C| = 1` の場合（接する）

**補題**：`C` の各点 `p` を通り `C` に接する円はちょうど `q−1` 個。

**証明**：`p` を通る円は `q(q+1)` 個。`p` を通り `C` と2点以上で交わる
円は、`C` の他の点 `p'`（`q` 通り）を通る `q+1` 個のうち `C` 自身を
除く `q` 個ずつ、計 `q²` 個。`C` 自身を加えて `q²+1`。
残り `q(q+1) − q² − 1 = q−1` 個が接する。 □

- `C'` は `C` と `p` のみ共有 → `C'` の外の点は `q` 個 → **`C(q,2)` 通り**
- `p` が `T` 内：`4` 通り → `(1,1) = 4(q−1)C(q,2)`
- `p` が `T` 外：`q−3` 通り → `(1,0) = (q−3)(q−1)C(q,2)`

### 2.3 `|C' ∩ C| = 0` の場合

`C'` は `C` と交わらないので `T` とも交わらない → `(0,0)` のみ。
総数から他を引いて求める。

## 3. 検証

| q | (2,2) | (2,1) | (2,0) | (1,1) | (1,0) | (0,0) |
|---:|---:|---:|---:|---:|---:|---:|
| **5 実測** | 180 | 240 | 30 | 160 | 80 | 450 |
| **5 公式** | **180** | **240** | **30** | **160** | **80** | **450** |
| **7 実測** | 630 | 1,680 | 630 | 504 | 504 | 2,940 |
| **7 公式** | **630** | **1,680** | **630** | **504** | **504** | **2,940** |

**12/12 完全一致。**

## 4. 周辺和の閉形式

```
(2,·) = q·C(q−1,2)·C(q+1,2)
(1,·) = (q+1)(q−1)·C(q,2)
(0,·) = 総数 − (2,·) − (1,·)
```

**検証**：q=5 で `(2,·)=450`、`(1,·)=240`、`(0,·)=450`、総数 1,140 ✓
q=7 で `(2,·)=2,940`、`(1,·)=1,008`、`(0,·)=2,940`、総数 6,888 ✓

**興味深い対称性**：`(2,·) = (0,·)` が両方の q で成立している
（450 = 450、2,940 = 2,940）。これは偶然か構造かは未解明。

## 5. 意義

1. **k=6 の交点表を完全に閉じた**（6項すべてに閉形式、12/12 一致）。
2. **接する円の個数が `q−1`** という補題を証明した。
3. **`(2,·) = (0,·)` という対称性**を発見した（未解明）。
4. これで k=6 のアーク数が**完全に閉形式で書ける**。

## 6. 限界

- `(2,·) = (0,·)` の対称性の理由は未解明。
- 検証は q = 5, 7 のみ。
- k ≥ 7 では「2つ以上の円」が必要で、この分解は使えない。
