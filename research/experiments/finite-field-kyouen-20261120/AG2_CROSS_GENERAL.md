# AG(2,q) の十字ブロックと一般上界 K ≤ 3q²/(2q−1)

2026-11-20。`finite-field-kyouen-20261120` の第29部。
AG(2,9) で見つけた「十字」ブロックが一般の q ≡ 1 (mod 4) で存在することを確認し、
上界の一般定理を得た。

## 1. 定理

`q ≡ 1 (mod 4)` を素数冪とする。AG(2,q) の共円ゲーム（円と直線をブロックとする）で

```
K(AG(2,q)) ≤ ⌊3q²/(2q−1)⌋
```

## 2. 証明

`−1` が平方なので `i² = −1` なる `i ∈ F_q` が存在する。線形写像

```
(x, y) ↦ (s, t) = (x + iy, x − iy)
```

は可逆で、`x² + y² = s·t` を満たす。したがって円の方程式は

```
s·t + a·s + b·t + c = 0
```

と書ける。このうち `ab = c` のとき

```
s·t + a·s + b·t + ab = (s + b)(t + a) = 0
```

と分解する。これは「`s = −b` の列」と「`t = −a` の行」の和集合、すなわち**十字**である。

十字の点数是 `q + q − 1 = 2q − 1`。`(a,b)` の選び方は `q²` 通りなので、
十字ブロックは `q²` 個ある。

安全集合 `S` は各十字に高々3点しか置けない。`a_c` を列 `c` の点数、
`b_r` を行 `r` の点数、`x_{cr} ∈ {0,1}` を交点の有無とすると

```
a_c + b_r − x_{cr} ≤ 3
```

全 `(c,r)` で和を取ると

```
q·Σa_c + q·Σb_r − Σx_{cr} ≤ 3q²
q|S| + q|S| − |S| ≤ 3q²
(2q−1)|S| ≤ 3q²
|S| ≤ 3q²/(2q−1)  □
```

## 3. 検証

| q | q mod 4 | 点 | ブロック | ブロックサイズ分布 | 十字の個数 | 期待 q² | 上界 |
|---:|---:|---:|---:|---|---:|---:|---:|
| 5 | 1 | 25 | 155 | {4:100, 5:30, 9:25} | **25** | 25 | **8** |
| 9 | 1 | 81 | 819 | {8:648, 9:90, 17:81} | **81** | 81 | **14** |
| 13 | 1 | 169 | 2,379 | {12:2028, 13:182, 25:169} | **169** | 169 | **20** |

すべてで十字の個数が `q²` に一致した。

## 4. 既知の値との比較

| q | 上界 3q²/(2q−1) | 既知の K | 下界 |
|---:|---:|---:|---:|
| 5 | 8 | **6（厳密）** | 6 |
| 9 | 14 | 9 ≤ K ≤ 14 | 9 |
| 13 | 20 | 未計算 | — |

q=5 では上界8に対し真値6で、差2。q=9 では上界14に対し K≥9。

**上界は緩い**が、初等的で一般性がある。

## 5. 意義

- AG(2,q) の K に対する**初の一般上界**である。
- 証明は幾何（円）を使わず、**組合せ的な十字制約だけ**から出る。
- `q ≡ 1 (mod 4)` という条件は `−1` が平方であることに対応する。
  `q ≡ 3 (mod 4)` では `x²+y²` が分解しないので十字は現れない。

## 6. 限界

- `q ≡ 1 (mod 4)` のみ。`q ≡ 3 (mod 4)` では別の議論が必要。
- 上界は緩い（q=5 で 8 対 6）。
- 十字以外のブロック（直線・非退化円錐曲線）を使えば上界を改善できる可能性がある。
- q=9 のサイズ10の存在は未確定。
