# 連続緩和の上界：証明の組み立てと残る課題

2026-11-20。`finite-field-kyouen-20261120` の第19部。
`|Delta| ≤ a⁴/2 + [a奇数]/2` の証明に向けた構造分析。

## 1. 分解

`Delta(x,y) = alpha·x + beta·y + gamma·(x²+y²) + delta` で、`gamma ≠ 0` のとき

```
Delta(x,y)/gamma = (x−cx)² + (y−cy)² − R²  =: power(x,y)
```

（三点を通る円に関する点 `(x,y)` のべき）。よって `|Delta| = |gamma|·|power|`。

## 2. 二つの補題の検証

上界 `a⁴/2` を出す素朴な道は

- **F2**：`|gamma| ≤ a²`
- **F3**：`|power| ≤ a²/2`

の積を取るもの。a ≤ 7 の全三点で検証した結果：

| a | max\|gamma\| | ≤ a² | max\|power\| | ≤ a²/2 | max\|gamma\|·\|power\| | ≤ a⁴/2 |
|---:|---:|---|---:|---|---:|---|
| 2 | 4 | ✓ | 6 | **✗** | 8 | ✓ |
| 3 | 9 | ✓ | 30 | **✗** | 81/2 | ✓ |
| 4 | 16 | ✓ | 84 | **✗** | 128 | ✓ |
| 5 | 25 | ✓ | 210 | **✗** | 625/2 | ✓ |
| 6 | 36 | ✓ | 330 | **✗** | 648 | ✓ |
| 7 | 49 | ✓ | 896 | **✗** | 2401/2 | ✓ |

**F2 は成立するが F3 は成立しない。** しかし積の上界（F4）は成立する。

## 3. なぜ F3 が破れるか

F3 を破る三点の例（a=5）：`(0,0), (3,2), (5,3)`。

- `gamma = 1`（非常に小さい）
- `power` の最大 = 210（`a²/2 = 12.5` を大きく超える）

`gamma` が小さいということは、三点が**ほとんど一直線**に近いということである。
その場合、円は巨大になり、正方形内の点の「べき」は大きくなる。

逆に、最大を与える三点 `(0,0),(5,0),(0,5)` は

- `gamma = −25`（絶対値が最大）
- `power` の最大 = `25/2`（ちょうど `a²/2`）

である。

**つまり `|gamma|` と `|power|` は逆相関し、積が一定の上界に収まる。**
これが証明すべき本当の構造である。

## 4. 極値の一意性（数値観測）

連続最大 `a⁴/2 + [a奇数]/2` を達成する三点は、a=3,5,7 で**ちょうど2個**：

- `(0,0), (a,0), (0,a)`
- `(0,0), (a,0), (a,a)`

いずれも正方形の「角の直角三角形」で、外接円の中心は正方形の中心 `(a/2, a/2)`、
半径は `a/√2`。中心における `|Delta|` は

```
|gamma| · R² = a² · (a²/2) = a⁴/2
```

である。

a が奇数なら中心 `(a/2, a/2)` は格子点でないので、格子最大はこれより小さい
（観測値 `a⁴/2 − 1/2`）。

## 5. 証明の骨格（未完成）

示すべきは次の不等式である：

> 任意の三点 `p1,p2,p3 ∈ [0,a]²` と任意の `(x,y) ∈ [0,a]²` に対し
> `|gamma| · |power(x,y)| ≤ a⁴/2 + [a奇数]/2`

現時点で確立しているのは：

- `|gamma| ≤ a²`（F2、a ≤ 7 で全数確認）
- 最大は角の直角三角形で達成され、その値は `a⁴/2`
- `|gamma|` と `|power|` は逆相関する（定性的観察）

**不足しているのは、逆相関を定量的に表す不等式である。**
例えば「`|gamma| · |power| ≤ a⁴/2` を直接示す」か、
「`|power| ≤ a²/2 + (a² − |gamma|)·何か`」の形の評価が要る。

## 6. `|gamma| ≤ a²` について

`gamma` は三点の座標の 3×3 小行列式で、`gamma = ±2·Area(p1,p2,p3)` に相当する
（実際 `gamma` は三点が作る三角形の面積の 2 倍に比例する）。
三点が `[0,a]²` 内にあれば三角形の面積は高々 `a²/2` なので `|gamma| ≤ a²` が従う。

**この論法は厳密化できる可能性が高い**が、本項では数値確認に留めた。

## 7. 限界

- a ≤ 7 の全数計算。a ≥ 8 は未計算。
- F2 の証明（面積による上界）は骨格のみで、`gamma` と面積の比例定数の確認が未了。
- 逆相関の定量的な不等式は未取得。
- 極値が2個であることは a=3,5,7 の観測。
