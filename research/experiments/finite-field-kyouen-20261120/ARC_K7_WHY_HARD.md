# k=7 の `(4,*)`：なぜ単純な分解が効かないか

2026-11-20。`finite-field-kyouen-20261120` の第144部。

k=7 の `(4,*)` タプル数を閉じようとして、**2つの自然な分解が失敗する**
ことを確認した。これは重要な否定的結果である。

## 1. 試み1：j-三つ組による分解（失敗）

`S = T ∪ {x,y,z}`（`|T| = 4`）に対し、3つの対 `{x,y}, {x,z}, {y,z}` の
それぞれについて `j` を測り、`(j₁,j₂,j₃)` でプロファイルが決まるかを
調べた。

**結果（q=5）**：

| `(j₁,j₂,j₃)` | プロファイル | 個数 |
|---|---|---:|
| (1,1,1) | (4,4,4,4) | 320 |
| (1,1,1) | (4,4,4,4,4) | 48 |
| (1,1,1) | (5,4) | 32 |
| (0,1,1) | (4,4,4,4) | 224 |
| (0,1,1) | (4,4,4) | 88 |

**同じ `(1,1,1)` が3つの異なるプロファイルを与える。**
**j-三つ組ではプロファイルが決まらない。**

## 2. 試み2：第2円の合併サイズによる分解（失敗）

`j` の重複を除くため、3つの対にわたる第2円の**合併**のサイズを測った。

**結果（q=5）**：

| `\|union\|` | プロファイル | 個数 |
|---|---|---:|
| 2 | (4,4,4,4) | 224 |
| 2 | (4,4,4) | 100 |
| 2 | (5,4,4) | 88 |
| 3 | (4,4,4,4) | 416 |
| 3 | (4,4,4,4,4) | 48 |

**同じ `|union| = 2` が3つの異なるプロファイルを与える。**
**合併サイズでも決まらない。**

## 3. なぜ失敗するか

プロファイルは「各円が `S` から何点取るか」の**多重集合**である。
一方 `j` も `|union|` も「第2円がいくつあるか」しか見ていない。

**決定的な違い**：第2円が `T` から2点取ることは `j` の定義から従うが、
その第2円が `{x,y,z}` から**何点取るか**は別である。

- 第2円が `{x,y,z}` から2点取る → その円は `S` から4点 → プロファイルに4が増える
- 第2円が `{x,y,z}` から3点取る → その円は `S` から5点 → プロファイルに5が現れる

**`(5,4,4)` と `(4,4,4)` の違いはここにある。**
`|union| = 2` でも、片方が5点円なら `(5,4,4)`、両方4点円なら `(4,4,4)`。

## 4. 正しい分解に必要なもの

プロファイルを決めるには、各第2円が `{x,y,z}` から取る点数
（2 or 3）を知る必要がある。

```
第2円 C' が {x,y,z} から3点取る  ⟺  C' は x,y,z をすべて通る
第2円 C' が {x,y,z} から2点取る  ⟺  C' は x,y,z のうち2点を通る
```

**つまり「3点 `{x,y,z}` を通る円が `T` と2点共有するか」**が鍵である。
これは2点のペンシルではなく**3点が定める円**（一意）の問題になる。

## 5. 意義

1. **j-三つ組では k=7 のプロファイルが決まらない**ことを示した。
2. **第2円の合併サイズでも決まらない**ことを示した。
3. **必要な情報は「各第2円が `{x,y,z}` から何点取るか」**であると特定した。
4. k=6 の手法（2点のペンシル）が k=7 では**原理的に不足**であることを
   明確にした。

- 検証は q=5 のみ。
