# `#4-arcs` の因数分解形（美しい閉形式）

2026-11-20。`finite-field-kyouen-20261120` の第187部。

`#4-arcs` の多項式を因数分解したところ、**完全に分解**した。

## 1. 定理

```
#4-arcs = q³ (q−1)² (q+1) (q²+1) / 24
```

## 3. 導出

```
q⁸ − q⁷ − q⁴ + q³ = q³ (q⁵ − q⁴ − q + 1)
                   = q³ (q⁴(q−1) − (q−1))
                   = q³ (q−1)(q⁴ − 1)
                   = q³ (q−1)(q²−1)(q²+1)
                   = q³ (q−1)² (q+1)(q²+1)
```

## 4. 因子の意味

| 因子 | 意味 |
|---|---|
| `q³` | 円の選択（`b = q(q²+1)` の一部） |
| `(q−1)²` | 2点の選び方の制約 |
| `(q+1)` | `s = q+1` |
| `q²+1` | `n = q²+1` の一部 |
| `1/24 = 1/4!` | 4点の対称性 |

**`q²+1 = n`、`q+1 = s` がそのまま現れる**のは構造的で美しい。

## 5. `#5` と `#6` の因数分解

```
残り = (−1/24 + q/12 − q²/24 + q⁴/120 − q⁵/30 + q⁶/120)
```

**`#4` だけが完全に分解する。** これは `#4` の閉形式が最も単純だから。
