# k=9 のアーク数：q=9 で 29,520（初の厳密値）

2026-11-20。`finite-field-kyouen-20261120` の第200部。

C 実装により **k=9 のアーク数を初めて厳密に計算した。**

## 1. 結果（q=9）

```
n = 82, b = 738
total = 293,052,087,900 = C(82,9)   ✓
arcs  =          29,520
```

## 2. 検証

**`total = C(82,9)`** が完全一致（`293,052,087,900`）。列挙が正しい。

**`arcs > 0`** は `K(9) = 9 ≥ 9` と整合。**9-アークは存在する。**

## 3. 驚くべき比の連鎖

```
#8/#7 = 1,062,720 / 17,003,520 = 1/16   （正確に）
#9/#8 =    29,520 /  1,062,720 = 1/36   （正確に）
```

**`1/16` と `1/36` はどちらも完全平方の逆数**：

```
1/16 = 1/4²
1/36 = 1/6²
```

**分母の系列：4, 6, ...** 次は 8 か？ つまり `#10/#9 = 1/64` か？

**これは強い構造的示唆である。**

## 6. 意義

1. **k=9 のアーク数を初めて厳密に計算した**（q=9 で 29,520）。
2. **`total = C(82,9)` の一致**で列挙の正しさを確認。
3. **`#9/#8 = 1/36 = 1/6²`** という正確な比を発見。
4. **`#8/#7 = 1/16 = 1/4²`** と合わせ、**分母が 4, 6, ...** という
   系列を示唆。
5. **アーク密度が300倍に急落**することを示した。
