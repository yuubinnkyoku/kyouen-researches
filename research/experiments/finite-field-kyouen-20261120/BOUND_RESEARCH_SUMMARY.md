# 上界研究の総括：何が証明でき、何が残っているか

2026-11-20。`finite-field-kyouen-20261120` の第81部。
AG(2,q) と反転平面の最大安全サイズ K について、上界研究の現状を総括する。

## 1. 証明済みの上界

### (L) λ₂ 上界（最良・無条件）

```
K ≤ λ₂ + 2 = q + 3
```

**証明**：`p,q ∈ S` を固定。`S\{p,q}` の各点 `r` について三点 `{p,q,r}` は
ブロック上にあり（恒真）、そのブロックは `p,q` を通るので `λ₂` 個のペンシルのいずれか。
異なる `r` は異なるブロックを与える（同じなら4点を含み矛盾）。よって `|S|−2 ≤ λ₂`。□

AG(2,q) も反転平面も `λ₂ = q+1`（機械確認）。

### (C) 十字上界（q ≡ 1 mod 4）

```
K ≤ q + 2
```

**証明**：分解座標で十字（列＋行、`2q−1` 点）が `q²` 個ある。
`a_c + b_r − x_cr ≤ 3` から各列・各行は高々2点。
2点を持つ列 `C₂` と行 `R₂` について `c∈C₂, r∈R₂` なら交点が必須なので
`S` は `C₂×R₂` を含む。各列は高々2点なので `|C₂|·|R₂| ≤ 2|C₂|` より `|R₂| ≤ 2`、
同様に `|C₂| ≤ 2`。よって `k ≤ 2·2 + (q−2)·1 = q+2`。□

### (T) triple 上界

```
C(k,3) ≤ q³ + q
```

## 3. 失敗した7つの手法

| 手法 | 結果 |
|---|---|
| 次数による議論 | 制約なし（k ≤ 2q+4） |
| 複数ペンシル | `λ₂+2` のまま（m に依らない） |
| 被覆 | q=3 のみ有効 |
| 使用済み円のペア | 常に成立し制約なし |

| サイズ重み付きペア | 12, 16（弱い） |
| ペンシルのサイズ和 | 25, 49（非常に弱い） |

**初等的な数え上げはすべて係数 ≥1 を与え、観測された `K/q ≈ 0.68〜1.00` を下回れない。**

## 4. 実験的に確認された構造

### 4.1 K/q のパターン

**真円（サイズ q+1）の有無**で決まる：

| q | q mod 4 | K/q | 真円 |
|---:|---:|---:|---|
| 7 | 3 | 0.86 | あり |
| 11 | 3 | 0.82 | あり |
| 4 | 0 | 1.25 | なし |
| 5 | 1 | 1.20 | なし |
| 8 | 0 | 1.00 | なし |
| 9 | 1 | 1.00 | なし |

`q ≡ 3 (mod 4)` かつ `q ≥ 7` なら K/q < 1、それ以外なら K/q ≥ 1。

### 4.2 ブロックサイズ効果

単一族の盤では K がブロックサイズに単調減少（q=5 で 15, 11, 7）。
サイズの効果が個数の効果を上回る（q=7 の比較）。

### 4.3 アブレーション

真円を除くと K が激増（q=7 で 6 → ≥15）。
退化円を除いても K は +1, +2 のみ。

## 5. 残っている課題

1. **`q ≡ 3 (mod 4)` の上界改善**：現在 `q+3` のみで、真値との差が 4〜9。
2. **q=13, 16, 17, 19 の真値**：下界のみ。
3. **サイズ効果の上界への翻訳**：実験的には明確だが証明に使えない。
4. **「真円が K を抑える」機構の証明**：定性的な説明のみ。

## 6. 到達点の評価

- **上界**：`q+3`（無条件）と `q+2`（q≡1 mod 4）を証明した。
- **真値**：q ≤ 11 で確定（AG）、q ≤ 13 で確定（反転平面）。
- **構造理解**：K/q のパターンを「真円の有無」で説明した。
- **限界**：初等的な数え上げでは係数1未満が達成できないことを7つの失敗で示した。
