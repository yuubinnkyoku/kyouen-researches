# 一様盤REMO計数再帰のLCM周期性（全C ≥ 1・全r ≥ 2・全称証明）

実験: `remo-uniform-factorial-period-20261117`（2026-11-17）
対応項目: K0919

## 命題（定理PER・全称）

K0859定理Dの計数再帰 E(C,r)（一様盤・終端サイズC・r人・
各フェーズでactiveな全員に1石ずつ巡回配分し、ell_h = C − s_h 個
配った直後の次の配分先が敗者・敗者の石は除去）について:

**定理PER**: Q(r) := lcm(1,2,…,r) とおくと、**すべての r ≥ 2 と
すべての C ≥ 1** に対し、

> E(C + Q(r), r) = E(C, r)（敗者全列と生存者が完全一致）

が成立する。とくに Q(r) | r! なので **r! も周期**である。さらに
Q(r) の任意の正の倍数も周期である。

これは新規スイープを含まない純粋な全称証明であり、機械列は
独立検証アンカーとしてのみ用いる。

## 証明（均一オフセット帰納法・全称）

### フェーズ分解

再帰のフェーズ h = 1..r−1 にわたり k_h = r−h+1 人がactive。
フェーズh開始時の状態は (active_h, turn_h, counts_h)（s_h =
active者の石数和）。ell_h = C − s_h がそのフェーズの配分石数で、

> (q_h, t_h) = (ell_h div k_h, ell_h mod k_h) のとき、
> turn_h から数えてオフセット i のプレイヤーは
> q_h + [i < t_h] 個受け取り、敗者はオフセット
> li_h = (turn_h + ell_h) mod k_h（すなわちオフセット t_h）

**補題L（敗者の受領数・全称）**: 敗者はフェーズhでちょうど
q_h 個受け取る（オフセット t_h は追加配分 i < t_h の境界の
直後であり、敗者は追加分を受け取らない）。

### 帰納法

周期候補 T ≥ 1 を固定し、2つの盤 C と C+T を比較する。
帰納法の不変式: **フェーズh開始時に両盤で active_h・turn_h が
同一で、countsの差がすべてのactive者について一様**、すなわち
ある D_h ≥ 0 があって counts'[p] = counts[p] + D_h（全active p）。
D_1 = 0（両盤とも全員0石）。

このとき s'_h = s_h + k_h·D_h より

> X_h := ell'_h − ell_h = T − k_h·D_h

である。条件 **k_h | X_h** を仮定すると:

1. **配分パターン同一**: t'_h = (ell_h + X_h) mod k_h = t_h
   （k_h | X_h）で q'_h = q_h + X_h/k_h。よってオフセットiの
   受領パターン [i < t_h] は同一で、受領差は全員ちょうど
   X_h/k_h（一様）。
2. **敗者同一**: li'_h = (turn_h + ell_h + X_h) mod k_h = li_h
   （k_h | X_h）で、敗者ラベルも同一。敗者は補題Lにより両盤で
   ちょうど q_h / q_h + X_h/k_h 個受領後に除去され、両盤とも
   counts[敗者] = 0 にリセット（active外となるので不変式に影響
   しない）。
3. **turn同一**: 除去後 turn = li_h mod (k_h − 1) は両盤同一。
4. **不変式の継承**: 残ったactive者のcounts差は一様に
   D_h + X_h/k_h になる。

よって不変式はフェーズ全体で保存され、両盤の敗者全列・生存者は
完全に一致する。残るは条件 k_h | X_h の整理。

### 閉形式と保存条件

D_{h+1} = D_h + X_h/k_h = (k_h·D_h + T − k_h·D_h)/k_h = **T/k_h**。
したがって D_h は自明に整数であり、さらに

> X_{h+1} = T − k_{h+1}·D_{h+1} = T − (k_h−1)·T/k_h = T/k_h
> = T/(k_{h+1}+1)　（h ≥ 1）

すなわち **X_1 = T**、**X_h = T/(k_h+1)（h ≥ 2）** の閉形式を得る
（X_h = D_h でもある）。保存条件は:

- フェーズ1（k_1 = r）: r | X_1 = T、すなわち **r | T**。
- フェーズh ≥ 2（k_h = r−h+1 ∈ [2, r−1]）:
  k_h | X_h = T/(k_h+1)、すなわち **k_h(k_h+1) | T**。

### 補題Q（LCM等式・全称）

> lcm({r} ∪ {k(k+1) : 2 ≤ k ≤ r−1}) = lcm(1,2,…,r) =: Q(r)

証明。（⊆）各要素の素数冪は lcm(1..r) を割る: r | lcm(1..r) は
明らか。k(k+1) は gcd(k,k+1)=1 なのでその素数冪 p^e は k または
k+1 を割り、p^e ≤ k+1 ≤ r。（⊇）lcm(1..r) の各素数冪 p^e ≤ r は
LHSを割る: p^e ≥ 4 なら k = p^e−1 ∈ [3, r−1] として
k(k+1) = (p^e−1)·p^e は p^e を割る（gcd(p^e, p^e−1)=1）。p^e = 2
は r = 2 なら r | T に含まれ、r ≥ 3 なら k=2 の 2·3=6 に含まれる。
p^e = 3 は r = 3 なら r | T に含まれ、r ≥ 4 なら 6 に含まれる。
（p^e の小さい値は 2,3,4,5,7,8,9,… で 4未満は 2,3 だけ。）∎

### 定理PERの完成

T が r | T かつ k(k+1) | T（k = 2..r−1）を満たせば帰納法が
走る。これらの条件の最小公倍数は補題Qによりちょうど Q(r) で
あり、条件は「T が Q(r) の倍数」と同値。∎

### 数値

Q(2)=2, Q(3)=6, Q(4)=**12**（r! = 24 ではない）, Q(5)=60,
Q(6)=60（r! = 720 より真に小さい）, Q(7)=420, Q(8)=840,
Q(9)=2520。r! は常に周期だが一般には最小ではない。

## 最小周期（機械測定 r ≤ 9・r ≥ 10 はOPEN）

検証器E3: r = 2..9 の各々で、敗者列と生存者の両列の最小周期が
**ちょうど Q(r)** であることを確認（Q(r)の全真約数が棄却・
elim/survivor両側・完全走査）。実測値は上記数値表と同一。

- r ≥ 10 の最小性、および「周期は必ずQ(r)の倍数である」という
  必要性方向は **OPEN**（証明は十分条件のみを与える）。

## 定理Jとの対比（C方向とr方向）

- **定理J（K0906・全称）** は r 方向の安定化（一様盤では
  sv/det は r ≥ max(M,2) で一定）を与え、**定理PER は C 方向の
  周期性**（周期 Q(r)）を与える。両者は独立の全称定理で、
  一様盤の計数再帰は「r方向に有界窓で安定化し、C方向に
  周期 Q(r) で反復する」。
- E6のプラトー（S(C,r) が r ≥ C で一定）は定理Jの帰結の
  有限アンカーであり、本項の新規主張ではない。P(C)列は
  観察としての記録。

## 限界

- 定理PERは **K0859計数再帰（Δ=0一様盤・定理D域）の主張**
  であり、Δ≠0の非一様盤には一切言及しない（K0859の合成反例の
  とおり非一様盤では r|Δでも生存者が戦略依存になり得る）。
- 最小周期は r ≤ 9 の機械測定。r ≥ 10 の最小性と必要性方向は
  OPEN。r ≥ 10 でも Q(r) が周期であること自体は全称証明済み。
- E1の r=8,9 の層化サンプルは閉形式双子の整合アンカーであり、
  双子の正当性は r ≤ 7 完全走査・出版表84エントリ・E5の15,736
  committed列照合で独立に支えられる。
- E6のプラトー・P(C)列は有限観察（定理Jが全称側）。
- 順位（敗者順序の一部）の安定性は扱わない（E2/E3は敗者全列の
  完全一致を検証しており、帰納法自体は全順位の一致を与える）。
- 11×11空盤・クラスフロンティアは本項と無関係でUNKNOWNのまま。
