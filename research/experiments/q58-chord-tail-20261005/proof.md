# M5,8=16の有限証明区間を半減する

現在の結論の正本はK0331。本ノートは既に確定した厳密値16を変更せず、
全称上界を186から101へ下げることで必要な有限排除を510件から255件へ縮小する。
旧510件の一次資料・検査記録は変更しない。

## 五行・q=8の全称上界101

標準五行整数格子では、一円上の盤内点は高々八点。
八点を持つ円は四行に二点ずつ持つ。これは既存K0331の円係数分母とmod9による証明を使う。
非水平直線は高々五点なので、八点禁止を作る直線は水平行だけである。

安全集合Sと石数不足の対象行Lを固定する。各行の容量は七石、Lの石数bは六以下。
Lの空点を塞ぐ円は、ちょうど七石の既存石と空点を通る八点円である。
対象行にある既存石は高々一つ。もしゼロなら残りの三行から七石を取らねばならず、
各行の円交点数二の上限に矛盾する。
従って全てのblocker円はLに一石、外部三行に二石ずつを持ち、空点を高々一点塞ぐ。

各blockerは三本の外部水平弦を持ち、その弦同士の三組の和はすべて同じ。
相異なる円は同じ弦対を共有できない。
外部の四行の六組の行対について、K0342の鋭い弦energy上界は

\[
 E_7=\frac{2\cdot7^3-3\cdot7^2+4\cdot7-3}{12}=47.
\]

各外部行は七石以下なので、全同和弦対予算は `6×47=282`。
従ってblocker円数yは `3y≤282`、すなわち `y≤94`。
既存石を含めてもLの利用不能点は `b+y≤6+94=100` 点。

ゆえに `m≥101` なら任意の不足行に合法な追加点がある。
全極大集合は35石になり、全安全局面で `g(S)=(35-|S|) mod2`。
これは無界な全mに対する数学的証明である。

## 既存の有限証明を255件だけで組む

旧証明はm=16..185、対象行0,1,2の全510件をCaDiCaLでUNSATとし、
別実装drat-trimで全件検査済み。新しい全称末尾101を使うと、必要なのは
m=16..100の255件だけになる。

`scripts/reduce_manifest.py` は旧manifestと全510件の統合再検査receiptのhashを検査し、
全255件のCNFを既存の同じ生成器で再生成して、保存済みCNF hashおよび変数数・節数・円数と照合する。
保存する `output/reduced-manifest.json` は既存の検査済みrecordを抽出したもの。
SATやDRATを今回新しく実行したとは主張しない。

全m≥101の上記数学的証明と、m=16..100の既存独立検査済み有限排除によりM5,8≤16。
下界は既存のm15・34石安全極大証人であり、M5,8=16は維持される。
境界m16の三CNF・DRAT圧縮ファイルは旧experimentに引き続き保存されている。

```sh
python research/experiments/q58-chord-tail-20261005/scripts/reduce_manifest.py
```

必要なら旧 `q58_certify.py` の `--low 16 --high 100` を使って255件の証明を再生成・DRAT検査できる。
本縮小処理自体は、SAT実行時間が半減したという速度測定ではない。

## 任意の平行線に対するq=2wの統一的な系

整数格子のmod9を使わない場合でも、w≥3本の任意の平行直線上に、各行m個の異なる候補点があるとする。
q=2w、r=2w−1なら、対象行の空点を塞ぐ円は、対象行の一石と各外部行の二石を持つ。
種類0は外部で高々2(w−1)=r−1石しか取れないため不可能。
blocker円一つは `C(w−1,2)` 個の外部同和弦対を使い、全予算は
`C(w−1,2) E_r` 以下。w≥3なのでこの係数は正で、円数はE_r以下。

従って各行に少なくとも `r+E_r` 個の候補点があれば、全不足行に合法手がある。
満容量 `wr`、Grundy式 `(wr-|S|) mod2` は任意の平行線・任意の候補実数座標で成立する。
w=3,q=6では上界21を既存の個別解析と同じ値で再現し、w=4,q=8では一般上界54を与える。
これらは個別の真の閾値（既知9と11）とは別の十分条件である。
