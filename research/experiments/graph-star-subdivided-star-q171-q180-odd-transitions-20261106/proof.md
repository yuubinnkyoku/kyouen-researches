## 証明と検証範囲

\(u=-(r+1)y\)、\(a=(r+2)/(r+1)\) とおく。負根条件は \(F_k(y)=r-y-(a-y)y^k=0\)。\(r≥168\) で \(y≤1\)、\(a≤y≤r\)、\(y>r\) には根がない。最後の範囲は \((y-a)y^k>y-r\) による。したがって根候補は \(1<y<a\) に限られる。\(H_k(y)=(a-y)y^k\) は \(y_*=ka/(k+1)\) で最大。

非存在境界 \(k_-\) では \(H_{k_-}(y_*)<r-a\) を確認すれば \(F_{k_-}>0\)。存在境界 \(k_+=k_-+2\) では \(1<y_*<a\) および \(H_{k_+}(y_*)>r-y_*\) を確認する。\(F_k(1)>0,F_k(a)>0\) より中間値の定理で2根が存在する。\(T_{k,r}(-x)\) の符号変化は2回なのでデカルトの符号法則からちょうど2つの相異なる単実根。正根は係数がすべて正なので存在しない。\(1<y<a\) で \(H_k(y)\) は k とともに厳密増加するため、両境界の結果はそれぞれ全奇数次数へ拡張できる。

\(A=k(r+2),B=(k+1)(r+1)\) とおく。非存在側は
\((r^2-2)(k+1)B^k>(r+2)A^k\)、
存在側は
\((rB-A)(r+1)(k+1)B^k<(r+2)A^kB\)
を任意精度整数演算で確認した。\(B<A\) も検査した。20境界すべてPASS。これは先行q=161〜170の解析枠組みを用いた**新しい有限境界の厳密検証**であり、解析部分の独立再証明ではない。

```python
for q in range(171, 181):
    r = q - 3
    kp = 2353 + 16 * (q - 171)
    for k, exists in ((kp - 2, False), (kp, True)):
        A, B = k*(r+2), (k+1)*(r+1)
        assert B < A
        if exists:
            assert (r*B-A)*(r+1)*(k+1)*B**k < (r+2)*A**k*B
        else:
            assert (r*r-2)*(k+1)*B**k > (r+2)*A**k
    print(q, "PASS")
```
