## 信頼境界

元の終局証明は `../n11-s9-neighbor23-terminal-20261026/verify.py --negative`。9石23根の全合法10石子500辺、相異なる10石子457類すべてを、異なる整数幾何による独立した終局minimaxで検査した。8石の証人親は192類。元証明は外部勝敗表に依存しない。

本ディレクトリの `audit.js` は、元証明の根・葉・親のSHA-256と全合法子境界を別実装の整数幾何で再生成し、**既存の証明限定9石WIN189根・8石WIN1,972類**に重複なく統合する。終局minimaxを再実行するものではないため、元証明の検証と組み合わせる。

既存の8石WINも含めて、凍結8石LOSS294類および独立証明済み8石LOSS76類との衝突を拒否する。凍結LOSSは比較対象であり、WINの根拠には用いない。

8石WINの純増を逆向きに7石親へ投影し、前向き合法着手列挙と逆向きの正準7石→8石辺集合を照合する。監査の既知基準値は9石WIN189根、8石WIN1,972類、被覆対象7石親7,764類、確保済み7石→8石合法着手15,778辺（対称類辺15,776）。

## 再現

リポジトリ直下で次を実行する。

```sh
python3 research/experiments/n11-s9-neighbor23-terminal-20261026/verify.py --negative
node research/experiments/n11-s9-neighbor23-s7-union-20261026/audit.js --negative
```

監査器は純増8石WIN、7石親、着手辺、最少未被覆合法子数、新規全子被覆とWIN/LOSS衝突を機械可読JSONで出力する。証明境界の欠落・重複を拒否する負の試験5件を実施する。
