# 幅6格子における円の格子点数の全称上界 P(6) = 8

## 主張

**定理.** 6行の連続整数格子（6×m、任意の m ≥ 1、行は y = 0..5）上の任意の円が含む格子点数は高々 8。
8点円は実在する（6×13 で 102 本、K0760 census・本実験で再現）。よって P(6) = 8 が厳密。

**系（q ≥ 9 の行分離）.** 幅6・q ≥ 9 では、円は ≤ 8 < q 点、非水平直線は6行と各行高々1点で ≤ 6 < q 点しか持たないため、
行を跨ぐ禁止 q 点集合（共円・非水平共線）は一切存在しない。各 row 直線は独立な容量 q−1 の成分となる。
K0072 と同じ帰結で、全 m ≥ 1・全安全局面 S について

g(S) = (6·min(m, q−1) − |S|) mod 2,　M_{6,q} = q−1。

q = 9, 10, 11, 12 が新規に確定する範囲（q ≥ 13 は K0025 の q > 2w で既にカバー）。
q = 8 は 8点円が実在するためこの手法では未解決。

## 記号と帰着

円を x² + y² + Cx + Dy + N = 0（C, D, N ∈ ℚ）と書く。行 y での格子点は
x² + Cx + (y² + Dy + N) = 0 の整数根であり、行は高々 2 点を持つ。判別式

disc(y) = C² − 4(y² + Dy + N)

について: 行が 2 整数根（二重行）⇔ disc(y) = (x₁−x₂)²（正の平方数）、
行が 1 整数根（接点行）⇔ disc(y) = 0。disc(y) = 0 は y の2次式なので接点行は高々 2 行。
円の盤内格子点数は P = 2d + s（d = 二重行数、s = 接点行数）。

## 第1段: d ≤ 4（K0072 中核の w=6、独立再現）

5つの二重行が6連続行にあれば、その中に距離1のペア（連続する2つの二重行）がある。
二重行 y₁, y₂（D = e/f 既約）では disc(y₁) − disc(y₂) = −4(y₁−y₂)(y₁+y₂+D) ∈ ℤ より f | (y₁−y₂)。
距離1で f = 1、すなわち **D ∈ ℤ**。また二重行の根和 −C ∈ ℤ、
M := C² − 4N = disc(y₁) + 4y₁² + 4Dy₁ ∈ ℤ。
よって disc(y) = M − 4y² − 4Dy（M, D ∈ ℤ）が5行で正の平方数であることが必要。

平方数は mod 9 で QR(9) = {0,1,4,7} に合同する。剰余分類（全 9³ 通りの (M, D, k) について
行 y ∈ {k..k+5} で disc(y) mod 9 ∈ QR(9) となる行数を数える。機械検証の結果、
**最悪でも 4 行**（worstCase M=0, D=1, k=4）。これは手計算でも検証できる有限分類である。
よって d ≤ 4。有限スポットチェック（|M|,|D| ≤ 600）でも 5 行の実例は 0。

## 第2段: d = 4 かつ s ≥ 1 の排除（元の議論）

残る危険な場合（P ≥ 9 になる唯一の形）は 4 二重行 + 接点行。接点 (x₀, y₀) は
x₀ = −C/2 ∈ ℤ から **C = −2x₀（偶整数)**。二重行 y では x₁ + x₂ = −C 偶より x₁ − x₂ 偶で
disc(y) = 4s²（s ∈ ℤ ≥ 1）。接点行で disc(y₀) = 0、すなわち c² := x₀² = y₀² + Dy₀ + N。
そこで t := y₀ − y（≠0）とおくと

disc(y)/4 = (y₀ − y)(y₀ + y + D) = t(y₀ + y + D) = s² ∈ ℤ, s ≥ 1。

D = e/f（既約）とし h := 2fy₀ + e（gcd(h, f) = 1）と書くと y₀ + y + D = (h − ft)/f なので
f | t·h、よって **f | t**。4つの相異なる非零 t ∈ [−5,5] が必要なので f ∈ {1, 2}
（f = 2 の候補は ±2, ±4 のみで4つ丁度、f ≥ 3 は2つ以下）。

**f = 2 の場合**: 二重行は t ∈ {2, −2, 4, −4} 全部。条件 t(h − 2t)/2 = s² から
t = 2: h − 4 = a² > 0、t = −2: −(h + 4) = b² > 0。加えて a² + b² = −8 < 0、矛盾。

**f = 1 の場合**: t(g − t) = s² > 0（g = 2y₀ + D ∈ ℤ）。
t > 0 なら g > t、t < 0 なら g < t < 0 なので、4つの t は同符号でなければならない。
t = −u, g = −G への置き換えで u(G − u) となるため、鏡映により t ∈ {1,2,3,4,5}（4つ選ぶ）、g > 5 としてよい。

各 t の条件: t=1: g−1 = a²。t=2: 2(g−2) = b² → g−2 = 2e²。t=3: 3(g−3) = c² → g−3 = 3w²。
t=4: 4(g−4) = d² → g−4 = u²。t=5: 5(g−5) = p² → g−5 = 5v²。

**t = 3 はどの他の t とも両立しない**（すべて mod 3。平方数 mod 3 は {0,1}）:
- (3,1): a² = g−1 = 3w²+2 ≡ 2。
- (3,2): 2e² − 3w² = 1 → e² ≡ 2。
- (3,4): u² = 3w² − 1 ≡ 2。
- (3,5): 3w² − 5v² = 2 → v² ≡ −2·5⁻¹ ≡ 2。

よって 4 倍集合は {1,2,4,5} 全部を含む。ところが (1,4) は a² − u² = 3、すなわち
(a−u)(a+u) = 3 の整数分解から **g = 5 のみ**。g > 5 と矛盾し（この時 t=2 も 3 = 2e² で不成立）、
d = 4 ∧ s ≥ 1 は存在しない。

## 結論

P = 2d + s ≤ max(2·4 + 0, 2·3 + 2) = 8。6×13 の census で 8 点円が 102 本実在するので P(6) = 8。

系の導出は K0072 と同一: 円 ≤ 8 点・非水平直線 ≤ 6 点 < q により行を跨ぐ禁止集合なし。
各行は「行に q 石で禁止」の独立成分（Grundy は空き容量の偶奇、K0072 の行公式と同一導出）で
g(S) = (6·min(m, q−1) − |S|) mod 2、M_{6,q} = q−1（q ≥ 9）。

## 機械検証（scripts/width6_circle_bound.ts → output/width6_circle_bound.json）

1. mod9 剰余分類: 9³ 通り、worst 4 行（分類そのものの検証）。
2. f=1 接点条件: |g| ≤ 10⁶ で「4つの t が平方」は 0 件（最大 3、例 g=10: {1,2,5}）。
   t=3 の共存も 0 件。
3. f=2 接点条件: |h| ≤ 10⁶ で (h−4, −(h+4)) 両方正の平方数は 0 件。
4. d=5 スポットチェック: |M|,|D| ≤ 600 で 5 行は 0 件（最良 4）。
5. 端末例: x² + y² = 25 は行 0,3,4 二重（±5, ±4, ±3）+ 行 5 接点 (0,5) = 7 点。
   代数（g = 10, t = {1,2,5}）と一致し、接点枠組みの健全性を端末で確認。
6. census 再現: 6×13 = 116 本（7点:14, 8点:102）、6×16 = 176 本（7点:24, 8点:152）。
   K0760 の数値と完全一致。

## スコープと限界

- 標準整数格子（6つの連続整数行）の定理。任意間隔の平行行、w ≠ 6 には主張しない。
- 7/8 点円の個数・漸近には主張しない（K0760 の線形増加観測は有限事実のまま）。
- q = 8（および q = 7）は 8 点円・7 点円が実在するため本系の対象外。M_{6,7} の決定問題
  （K0761、m ≥ 20 候補）はそのまま open。
- M_{6,q} = q−1 の「q−1」は行公式の枠組みにおける安定化長で、K0072 と同一の規約。
