## 命題

κ=1残余ゲーム H(R;(x,1);13) の全 x>=1・全 R>=0 における Grundy 値は次で完全決定される。
記法は K1012..K1016 と同一: O[a,b]=区間内の奇数、E[a,b]=区間内の偶数、I[a,∞)=a以上全域。

値2位置 T(x):
- x=1: {1}
- x偶数 (2<=x<=14): O[1,x+1]
- x奇数 (3<=x<=13): O[1,x]
- x=15（掃引行 d=z+1）: O[1,29] = O[1,13] ∪ O[15,29] = O[1,z] ∪ O[pin,x+y+z]、pin=15
- x>=16（安定域 d>=z+2）: {1,3,5,7,9,11,13,15} = O[1,z] ∪ {pin}、pin=z+2y=15

値1位置 P(x):
- x奇数 (x<=11): ∅
- x偶数 (x<=12): I[x+2,∞)
- x=13（x=z行）: {14} 有限
- x=14（d=z格子行・d+z≡2 (mod 4)）: {14} ∪ I[16,∞)
- x=15（掃引行）: {14} 有限
- x偶数 (x>=16): {14} ∪ O[17,x+14] ∪ I[x+15,∞)
- x奇数 (x>=17): {14} ∪ O[17,x+14]（有限）

tail: R>=x+15 ⟹ H=(x+1) mod 2（= (x+y) mod 2）。
高さのみ縮約: R<=14 (=z+1) ⟹ H(R;(x,1);13) = single_token(x+1,13,R)。

## 証明（A/B/C署名帯表）

x外帰納: x=1 は直接検証（値は T={1}、R>=2で0、R=0で0）。x>=2 で A子が x-1 行の既知値を用い、
B・C子は出版定理の閉形式で評価できる。各 (x,R) の A/B/C署名の帯構造（report付録の
band_signature・検証器と同一コード）が全 R>=1 を互いに素に被覆し、mex が T/P 閉形式を
与える。x<=15 の特異行群（x=11のR=14帯"13"・x=14の格子帯"023"…単一トークンz=xの
2点帯とK1016掃引帯が同時最多の行・x=15掃引帯"01"…子がz=12切片の掃引行を写す）と
x>=16 の偶奇定常帯（x=16のみ A=掃引行15 → 偶帯"12"、x>=17は偶帯"1"、奇帯は
17..x+14 の帯の後 tail に落ちる）が全行の値を確定する。

## 構造則（7則の z=13 での貫徹・有限観察）

1. pin = z+2y = 15（奇数z型・[z偶]=0）— x>=16 の値2定常ピン。
2. 掃引行 d=z+1=14 → x=z+y+1=15 — 値2が O[pin,x+y+z]=O[15,29] へ拡大。
3. 値1基底点 {z+1}={14}（y=1）。
4. 帯開始 z+2y+2=17、帯 parity≡z (mod 2)=奇（O[17,x+14]）。
5. I帯（tail接続帯）は x偶数行のみ（x>=16偶数の I[x+15,∞)）。
6. tail R>=S+z+1=x+15 で H=(x+y) mod 2。
7. 前倒し点: z=13 の d格子（d+z≡2 (mod 4) ⟺ d≡1 (mod 4)）は過渡域で d=13=z の
   x=14行に落ち、格子点 2y+(d+z)/2=15 は x偶数の一般ラダー上端 O[1,x+1] の
   x=14行上端15と一致（z=11のx=12行・点13と同型。z=12では点z+1=13がx=z-1=11行に
   現れる型だったのに対し、奇数zでは格子点がx=z+1行のラダー上端に吸収される差異）。

さらに height-only縮約の 成立域 R<=z+1 のz横断有限観察を行った: z=4..13の全
