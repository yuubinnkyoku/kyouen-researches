# 一辺細分星の奇数次数実根切替：接触二重根の不存在と単一切替定理（2026-11-07）

## 結論

対象は一辺細分星の終局長差多項式

```
T_{k,r}(u) = u^{k+1} + (r+2) u^k + (r+1)^k u + r (r+1)^{k+1},   r = q-3,  k 奇数 >= 3.
```

- **定理A（接触二重根の不存在）** 任意の整数 `r >= 1` と奇数 `k >= 3` について `T_{k,r}` は重複実根をもたない。
  同値に、`F_{k,r}(y) = y^k(y-a) + r - y`、`a = (r+2)/(r+1)` は `1 < y < a` に `F = F' = 0` の解をもたない。
- **定理B（単一切替）** 任意の整数 `r >= 2` について、奇数 `k` に対する `T_{k,r}` の実根数はつねに 0 個か 2 個である。
  すなわち `κ(r) = min { 奇数 k >= 3 : min_{1<y<a} F_{k,r}(y) < 0 }` が存在し、
  `k < κ(r)` の奇数では実根は 0 個、`k >= κ(r)` の奇数では相異なる負の単実根がちょうど 2 個ある。
  `κ(r)` は `r` について非減少で `r → ∞` に発散する。

これにより `graph-star-subdivided-star-general-odd-threshold-20261105/proof.md` が未解決として残した
「負値出現前の接触重根の不存在」が解消され、先行の q ごとの境界表はすべて定理B の特殊な実現であることが従う。
先行の全称部分（κ の存在・単調性・発散、デカルトの上界）はそのまま前提にできる。

標準格子盤の勝敗・最大安全サイズ・ゲームの Grundy 値についての主張ではない。

## 記号と基本形状（補題1）

`a = (r+2)/(r+1) = 1 + 1/(r+1)`、`y_* = k a/(k+1)`、`H(y) = (a-y) y^k`、`F(y) = y^k(y-a) + r - y = r - y - H(y)`。
`u = -(r+1)y` の代入で `T_{k,r}(-(r+1)y) = (r+1)^{k+1} F_{k,r}(y)`（k 奇数）であり、`u > 0` では `T > 0` なので実根は負のみ、したがって `y > 0` の根だけを考えればよい。

1. `0 <= y <= 1` では `y^k <= 1` より `H(y) <= a-y`、よって `F >= r - a > 0`（`r >= 2` で `a <= 4/3 < r`）。
2. `a <= y <= r` では `H(y) >= 0` かつ `r - y >= 0` で、`y=a` では `F = r-a > 0` なので `F > 0`。
3. `y > r >= 2` では `a < r < y` より `y-a > y-r > 0` かつ `y^k >= y > 1` なので `y^k(y-a) > y-r`、よって `F > 0`。
4. `F'(y) = y^{k-1}((k+1)y - ka) - 1`。`0 < y <= y_*` では第1項が `<= 0` で `F' <= -1 < 0`。
   `y > y_*` では `y^{k-1}` と `(k+1)y - ka` がともに狭義増加なので `F'` は狭義増加し、`F'(y_*) = -1`、`F'(a) = a^k - 1 > 0`。
   よって `F'` の正根はただ一つで `y_c ∈ (y_*, a)` にある。

以上から、**負値と実根は `1 < y < a` にしか存在しない**。また `y ∈ (1,a)` で `H(y)` は `k` とともに狭義増加するので、`min_{(1,a)} F_{k,r}` は `k` について狭義単調減少する（設定 `r >= 2`）。

## 補題2：接触条件は1つの2次方程式を含む

`1 < y < a` で `F(y) = F'(y) = 0` とする。`F' = 0` は

```
y^{k-1} ((k+1) y - ka) = 1        ...(2)
```

であり、`(k+1)y - ka > 0` だから `y^k = y / ((k+1)y - ka)`。これを `F = 0`、すなわち `(a-y)y^k = r-y` に代入して両辺に `(k+1)y - ka` を掛けると

```
(a-y) y = (r-y) ((k+1) y - ka)
```

展開して

```
B(y) := k y^2 - [ (k+1) r + (k-1) a ] y + k a r = 0.     ...(B)
```

`(r+1)` 倍すれば整数係数 `k(r+1) y^2 - L y + k r (r+2) = 0`、`L = (k+1) r (r+1) + (k-1)(r+2)`。

## 補題3：判別式の因数分解

`Q0 = r^2 - 2`、`P = r^2 + 2r + 2`、`R = r(r+1)(r+2)` とおくと

```
L = k P + Q0,          P^2 - 4R = Q0^2,
Δ(r,k) := L^2 - 4 k^2 r (r+1)(r+2) = (Q0 k + P)^2 - 4 R.
```

（`L = k[r(r+1)+(r+2)] + [r(r+1)-(r+2)] = k(r^2+2r+2) + (r^2-2)`、`P^2-4R = r^4-4r^2+4 = (r^2-2)^2`。両式は
`verify_no_contact_double_root.py` で直接判別式と 1,500 組一致を確認済み。）

## 補題4：接触が起きるなら Δ は完全平方

接触点 `y` は `B` の根である。`Δ` が平方数でないと仮定すると `B` は有理数体上既約で、`y` の最小多項式は `B` である。

一方

```
G(y) := (r+1)^k F'(y) = ((r+1) y)^{k-1} [ (k+1)(r+1) y - k(r+2) ] - (r+1)^k
```

は整数係数多項式で、零点集合は `F'` の零点集合と一致する。最小多項式が `G` を割るので、
`B` のもう一方の根 `y'` も `G` の根、すなわち `F'(y') = 0` でなければならない。
しかし `B` の根の積は `k r (r+2) / (k(r+1)) = r(r+2)/(r+1) > 0`、和も正なので `y' > 0` であり、`y' ≠ y`（`Δ ≠ 0`）。
これは「`F'` の正根はただ一つ」に反する。したがって `Δ` は平方数である。□

（この補題は `r >= 1` で有効。`F'` の一意性は補題1(4) のみに依存する。）

## 補題5：Δ が平方なら k は 2r+9 未満

`Δ = n^2`、`A = Q0 k + P` とすると `A^2 - n^2 = 4R`、すなわち `(A-n)(A+n) = 4R`。
`R > 0` より `A > n >= 0`。二因子は偶奇が一致し積が `4R` なのでともに偶数、
`a_0 = (A-n)/2`、`b_0 = (A+n)/2` は正整数で `a_0 b_0 = R`、`A = a_0 + b_0`。
`a_0 >= 1` より `A + n = 4R/(A-n) <= 4R`、したがって

```
2A = (A-n) + (A+n) <= 1 + 4R,      A <= 2R + 1/2.
```

`Q0 = r^2-2 > 0`（`r >= 2`）で割ると

```
k <= ( 2R + 1/2 - P ) / Q0 = 2r + 5 + (6r + 8.5)/(r^2 - 2) < 2r + 9      (r >= 4)
```

（最後の不等式は `4r^2 - 6r - 16.5 > 0`、`r=4` で `23.5 > 0`、以降単調増加）。□

## 補題6：r >= 4 なら奇数 k <= 2r+7 で F は正

`H` の最大値は `M(k) = a^{k+1} k^k/(k+1)^{k+1}` だから `M(k) <= a^{k+1}/(k+1)`。
`k = 2r+7` では `ln a^{2r+8} = (2r+8) ln(1 + 1/(r+1)) <= (2r+8)/(r+1) = 2 + 6/(r+1) <= 16/5`、
よって `a^{2r+8} <= e^{16/5} < 34`（`e < 3` より `e^{16/5} < 3^{16/5} = 27·3^{1/5} < 27·1.25 = 33.75`）。したがって

```
M(2r+7) < 34/(2r+8) <= 17/8 < 8/3 <= r - 4/3 <= r - a.
```

`F(y) = r - y - H(y) >= r - a - M(k) > 0` が `1 < y < a` 全体で成り立つ。
`F` は `k` とともに狭義減少するので、**奇数 `k <= 2r+7` のすべてで `min F > 0`**（`r >= 4`）。□

## 定理A の証明

`r >= 4`：接触があれば補題5 より `k` は奇数の `2r+9` 未満、すなわち `k <= 2r+7`。
しかし補題6 よりその `k` では `F > 0` が全域で成り立ち、接触は不可能。□

`r = 1, 2, 3`：補題4 より接触には `Δ` が平方であることが必要。補題5 の範囲で奇数の `k` を有限個調べれば足りる。

| r | q | Δ(r,k) | 接触に必要な平方の有無 |
|---|---:|---|---|
| 1 | 4 | `(5-k)^2-24` | `|5-k|-n` と `|5-k|+n` の積が 24。約数対から `|5-k| ∈ {7,5}`、すなわち k は偶数（10,12）。奇数解なし |
| 2 | 5 | `(2k+10)^2-96` | 上界 `k <= 19.25` の奇数 3..19 で平方なし |
| 3 | 6 | `(7k+17)^2-240` | 上界 `k <= 14.79` の奇数 3..13 で平方なし |

`r=2` の値は 160, 304, 480, 688, 928, 1200, 1504, 1840, 2208 でいずれも平方でない（`47^2=2209` に注意）。
`r=3` は 1204, 2464, 4116, 6160, 8596, 11424 でいずれも平方でない。よって定理A が従う。□

## 定理B の証明

`r >= 2` を固定する。`S = { 奇数 k >= 3 : min_{(1,a)} F_{k,r} < 0 }` とおくと、補題1(4) と `min F` の `k` 単調性から `S` は上側集合である。
`1 < y_0 < a` を固定すれば `F_{k,r}(y_0) = r - y_0 - (a-y_0) y_0^k → -∞`（`y_0 > 1`）なので `S` は空でない。
`κ(r) = min S` とおく。

- 奇数 `k < κ(r)`：`min F >= 0`。定理A より `min F ≠ 0` なので `min F > 0`、実根なし。
- 奇数 `k >= κ(r)`：`min F < 0`。補題1 より `F(1) > 0`、`F(a) = r-a > 0` なので中間値定理で少なくとも 2 実根。
  `T(-x)` の非零係数の符号は `+,-,-,+` で符号変化が 2 回だから、デカルトの符号法則より負根は重複度込みで高々 2 個。
  よって相異なる単実根がちょうど 2 個。□

`κ(r)` の非減少性と発散は先行の一般論（`graph-star-subdivided-star-general-odd-threshold-20261105`）による。
なお `r = 1`（q=4）は `F(1) = 1 - a < 0` となり上の領域解析が使えない。実際 `r=1` では
`F(0) = 1 > 0`、`F(1) = 1-a < 0`、`F(a) = 1-a < 0`、`F(y) → +∞`（`y → ∞`）なので常に 2 個の負実根があり、
デカルトの上界 2 と合わせて**ちょうど 2 個**である。したがって「実根数は 0 個か 2 個」という二分法自体は
`r >= 1` 全体で成立し、`r = 1` では常に 2 個（0 個の相が現れない）となる。定理B の「切替」は `r >= 2` に限る。

## 限界と残課題

- `κ(r)` の閉形式は未証明。本稿が示すのは「切替が1回で接触しない」ことであり、`κ(r)` の値は表の範囲で厳密計算する。
- 接触重根の不存在は代数的証明であり、有限計算に依存しない（有限検査は `r=1,2,3` の3例のみ）。
- `r = 1`（q=4）は実根数が常に 2 個で「0 個」の相がないため、切替定理（定理B）の対象外である。
- 標準格子盤・ゲームの勝敗・最大安全サイズへの主張ではない。
