# 2トークン族の残余2位置集合の閉形式予想（κ=1）

- 日付: 2026-11-16（高速レーン）
- 対象: 残余mex H(R;X;z)（K0832・全t最大値定理の再帰に従う）のうち、未飽和ファイバーの余剰トークンが2個 X=(x,y)（x≥y≥1）の場合の2位置集合 T(x,y,z) := {R : H(R;(x,y);z)=2}
- status: **予想**。閉形式は有限監査（計43,241照合・不一致0・二回実行でbyte-identical）で強く支持されるが、全称証明ではない。既知の証明済みレジーム（単一トークン閉形式・全1族系A・高余裕単一トークン縮約・tailレジーム・Theorem T）とは記号的に厳密に整合する。
- 前提: 残余ゲームの定義・再帰は[全t最大値定理](../vertical-fiber-all-t-grundy-max-20261116/report.md)に従う（A手: トークンv≥2をv−1へ、B手: トークン1を除去しz+1、C手: z≥1ならz−1で値XOR 1、H(0)=0、mex）。

## 概要

[高余裕単一トークン縮約](../vertical-fiber-high-z-multiset-merge-20261116/report.md)は一般多重集合の値2の位置を幅 2S+|X|−3 の有限中間帯に狭めたが、その帯の内部構造は未決定だった。本報告は |X|=2 の族で中間帯の構造を完全に記述する閉形式を抽出し、3種の独立エンジン（素朴・ラベル付き・cap補題付き）と発表済み定理への照合で検証した。

## 記法

- S := x+y、d := x−y ≥ 0、δ := R−2y（R奇 ⟺ δ奇）、q_o(k) := k以下最大の奇数。
- smin(d) := d偶なら d+1、d奇なら d+2（d+1以上の最小奇数）。
- δ_A(z) := z以上の最小奇数。
- y* := (z−d)/2（d≡z (mod 2) のとき整数。d≤z なら ≥0）。
- I(z,d) := {奇数 δ : smin(d) ≤ δ ≤ 2⌈(z+d)/4⌉−1}（d≡z (mod 2), d≤z で定義）。

## 予想1（2トークン族の2位置集合閉形式）

T(x,y,z) は次の3族の非交和的描述（重複は除く）で与えられる:

1. **ラダー** L := {奇数 R : 1 ≤ R ≤ q_o(min(S,z))}。単一トークン族・全1族と同一の「μ型」であり、z=0 では空。
2. **家族B**（中間帯・小トークン側）: d ≡ z (mod 2) かつ d ≤ z のときのみ寄与する。
   - **PT角**: y = y* ≥ 1 かつ I(z,d) ≠ ∅ のとき、{2y+δ : δ ∈ I(z,d)} ⊆ T。y=y* 上の角点でのみ現れる有限区間。
   - **EXT**: z+d ≡ 2 (mod 4) かつ y ≥ y* のとき、2y+(z+d)/2 ∈ T。**y≥y* の全行で現れる**。y*=0（d=z・z奇）を含み、対角線上の「特殊点 R=2y+z」をこの条件が統一的に含意する（z偶の d=z では z+d≡0 (mod 4) なので自然に空）。
3. **家族A**（遠方・大差）: y にほぼ非依存。
   - **ラン**: d = z+1 のとき {2y+δ : δ_A(z) ≤ 奇数δ ≤ 2z+1} ⊆ T。
   - **定常**: d ≥ z+2 のとき 2y+δ_A(z) ∈ T（単一位置）。

### 幾何学的読み方

- 固定 z で (d,y) 平面に T の遠方成分を描くと、家族BのPT角は直線 y*=(z−d)/2（d≡z, d≤z）上の点列、同じ家族BのEXTはその直線の上側（y≥y*）の半直線、家族Aは d≥z+1 の遠方で y 軸方向に並行な直線群である。ラダーは R 軸上の有限奇数列。
- 位置の δ=R−2y 座標は2トークン族の自然な不変量であり、全ての遠方位置は δ が (z,d) だけで決まる値に坍縮する。特に家族Aの定常位置は δ=δ_A(z)、家族BのEXT位置は δ=(z+d)/2 と、どちらも x,y の個別値から独立している。
- ラダーは単一トークン族の証明済み2位置公式（奇数R≤μ）と同じ形を S=x+y で踏襲する。これは証明済みの高余裕縮約（z≥S+R−1でXが総和Sの単一トークンへ厳密縮約）と整合する。全1族 k=2（x=y=1）は本予想に含まれ、証明済み系Aと完全一致する（下記V3）。

## 証明済み定理との厳密な整合（予想の構造的検証）

本予想の遠方族はすべて証明済みレジームの境界の内側に収まる。以下は閉形式に対する初等的な不等式で、機械的にも確認した（V4a/V4b）:

- **高余裕帯**（K0832: z ≥ S+R−1 ⟹ H(R;X;z)=H(R;(S);z）: 帯内 R ≤ z−S+1 では予想は証明済みの単一トークン公式 {奇数R ≤ q_o(S)} に正確に帰着する。実際、家族Aは d≥z+1 を要求するが帯内では d≤S−2<z となり不活性、家族Bの全要素は帯外（R > z−S+1）に落ちる。
- **tailレジーム**（R ≥ S+|X|+z−1 = S+z+1 ⟹ H = S mod 2）: 予想の全位置は R ≤ S+z を満たす。家族Aのラン上限 2y+2z+1 は tail境界 2y+2z+2 の1手手前で止まる。
- **系A回収**（全1族・z偶の特殊点 2k−z+1）: x=y=1（d=0, y=1）ではEXT条件は z≡2 (mod 4) かつ y≥z/2 を要求し、両立するのは z=2 のみ。その位置 R=2·1+(2+0)/2=3 は系Aの特殊点 2k−z+1=3 に一致する。z≤40 の全スライスで系A（全称証明済み）と閉形式・エンジンが完全一致（V3）。
- **Theorem T**（2位置は奇数Rのみ）: 予想の全位置は奇数（V5）。

## 限界と次の課題

1. **全称性は未証明**。有限監査は証明の代替ではない。最有値の道筋は全1族で成功したR前進帰納＋シグネチャ決定性（本族では状態が (x,y,z) 3次元で、比較族の設計が課題）。ラダー族は単一トークン閉形式との構造類似から先に証明可能かもしれない。
2. 監査範囲の外側（x,y>60 または z>40）は未検証。閉形式の各パラメータ依存性（特に家族BのEXT条件 z+d≡2 (mod 4) の法4周期）は外挿であり、反例が存在すればこの周期構造のどこかに現れるはずである。
3. 3トークン族 X=(x,y,w) への拡張。家族A/Bのδ座標の一般化（R−(x+y+w) 型の不変量）が自然な次の問い。
4. 11×11等の大規模レーンへの接続: cap補題と本閉形式で、残余Hの値2が寄与する局面の族が (x,y,z) で完全に予測できるようになった。大規模探索の枝刈り（H≠2 な残余の除去）に直接使える可能性がある。
