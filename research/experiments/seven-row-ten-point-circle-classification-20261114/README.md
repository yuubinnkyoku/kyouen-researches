# seven-row-ten-point-circle-classification-20261114

7連続整数行（7×m 盤・幅は m に依らず横方向制限なし）内に **≥10 個の格子点**を持つ真円の完全分類。
K0764 は P(7) = 10（上界）と 10点円のプロファイル（5二重行+2空行）を全称証明済み。
本実験はその**等号ケースの分類**を与える: 既知の 50 円族に加え、新たな例外 10 点円
R = 4ρ² = 2353705250 を発見し、2つの独立な有限全列挙（R 上界版・弦上界版）で
「範囲内にはこの2つしかない」ことを機械検証した。

## 主結果

**定理 A（機械検証・有限全称）。** m ≤ 1079 の全 7×m 盤（m ≥ 8）において、
≥10 格子点を持つ円はちょうど **2(m−7) = 2m−14 本**で、すべて

- (2x−(2k+1))² + (2y−5)² = 50（中心 (k+½, 5/2)）: 行プロファイル {0,2,3,5,6}、または
- (2x−(2k+1))² + (2y−7)² = 50（中心 (k+½, 7/2)）: 行プロファイル {0,1,3,4,6}

のいずれか（各族ちょうど m−7 本・k は円を盤内に収める範囲で一意）。各円はちょうど 10 点・
5二重行・接点なし（K0764 のプロファイルと一致）。

**系 A1（行 0,3,6 通過）。** m ≤ 1079 の 7×m 盤で ≥10 点円はすべて**行 0, 3, 6 を通る**。
（両プロファイルとも行 0,3,6 を含む。m ≤ 15001 でも後述の例外を含め成立。）

**定理 B（発見・範囲内で一意の例外）。** 行プロファイル {0,2,3,5,6} を持つ第2の 10 点円が存在する:

- 4ρ² = R = 2353705250 = 2·5³·13²·17·29·113（= 25·(9703²+1)・ρ² = 588426312.5）
- 中心 y = 48515/2（2β = 48515）、二重行の弦 u ∈ {5, 623, 763, 985, 1079}
  （Z = 2y−48515 ∈ {−48515, −48511, −48509, −48505, −48503}、u² + Z² = R）
- 最大弦 1079 ⟹ 幅 m ≥ 1080 の盤にのみ出現（m ≤ 1079 には現れない）。
- **弦 ≤ 15000 の全探索と R ≤ 10¹⁵ の全探索で、≥10 点の 7 行窓構成は
  R = 50（窓 {−5..7}, {−7..5}）と R = 2353705250（窓 {−48515..−48503}, {48503..48515}）の
  2 円のみ**（各鏡映ペア）。R = 2353705250 の全 192 個の u ≥ 0 表現は
  `output/exception_R2353705250_reps.txt`（直接 isqrt 全走査による独立検証）。

従って **m ≤ 15001 では 7×m の ≥10 点円 = 50 族 2m−14 本 +（m ≥ 1080 なら）例外族 2(m−1079) 本**
が完全に確定する。例外が無限族か sporadic かは open（R ≤ 10¹⁵ で追加候補なし）。

## 証明の骨子（補題 L1–L3 は数学的証明・探索は有限全列挙）

記号: 中心 (α, β)、行 y の2点 x = α ± u/2（u ∈ ℤ>0 は弦長）、2β = p/q 既約。
Z_y = 2q·y − p（行 y ↔ Z、Z は刻み 2q の等差数列）。

- **L1（行点構造）**: 円と水平整数直線の交点 ≤ 2。二重行が ≥1 個あれば α ∈ ½ℤ となり、
  t² = ρ²−(y−β)² ∉ ½ℤ の行は点を持たず、t ∈ ½ℤ の行は2点（t=0 は接点=1点）。
  よって ≥10 点 ⟺ (5二重行) or (4二重行+2接点行)（残りは ≤7 点）。
- **L2（分母補題・一般 w 行版）**: 二重行 y, y′ は u²−u′² = 4(y′−y)(y+y′−2β) を満たし、
  q(u²−u′²) = 4δ′(q(y+y′)−p)。gcd(p,q)=1 ⟹ **q | 4δ′**。
  7 行に 5 二重行 ⟹ 隣接二重行対（δ′=1）が存在（鳩の巣）⟹ **q ∈ {1,2,4}**。
  4二重行+2接点 ⟹ 6行が7枠 ⟹ δ′ ≤ 2 の対 ⟹ q ∈ {1,2,4,8}。さらに2接点は
  Z = ±√R で共に窓内 ⟹ 2√R ≤ 12q かつ q | Z_t（窓合同）⟹ gcd(Z_t,q)=1 と矛盾し **q=1・R ≤ 36**。
- **L3（q ∈ {2,4} 排除）**: q ∈ {2,4} では窓の Z はすべて奇数（gcd(Z,q)=1）。
  δ′=1 の対は q(u²−u′²) = 4(Z+q) ⟹ q=2: u²−u′² = 2(Z+2) ≡ 2 (mod 4) は平方差で不可能、
  q=4: u²−u′² = Z+4 は奇数 ⟹ u, u′ が互いに奇偶 ⟹ 中心 x の整合（全二重行の u 同一 parity）と矛盾。
  よって **5二重行構成は q=1 のみ**。
- **探索（有限完備性）**: q=1 で残る自由度は隣接対 (Z, Z+2) と (u−u′)(u+u′) = 4|Z+1|。
  - **弦上界版** `stripsearch_u.js`: 全二重行弦 u ≤ UMAX なら 4|Z+1| = u²−u′² < UAX² より
    |Z| ≤ UMAX²/4 で Z は有限範囲。各 Z の因子対を全列挙し R に依らず完備。
    7×m 盤（m ≤ UMAX+1）に乗る円は弦 ≤ m−1 なので UMAX = m−1 で盤について全称。
  - **R 上界版** `stripsearch.js`: R ≤ B の構成を全列挙（|Z| ≤ √B）。
  - **独立 cross-check** `crosscheck.js`: 表現 (X,Z)（X = qu・q ∈ {1,2,4,8}・gcd(Z,q)=1）
    の全ペアバケット化 + 全 7 窓直接検査（因子対論理を使わない独立実装）。
    R ≤ 10⁶ で両者一致（R = 50 のみ・q=2,4,8 は空）。R = 2353705250 は表現全列挙でも直接検証済み。

## K0764・K0817・ゲーム (M_{7,10}) との接続

- K0764 の P(7)=10・サイズ集合 {7,8,10} と整合: 10 点円は確かに実在し、本実験は**等号円の完全リスト**
  （m ≤ 15001）を与える。P(7) 自体の全称上界証明は K0764 による（本項目は依存）。
- rowcov.js（band-extension レーン）の観察「q=10 の 7×m census 円数 = 2m−14・全円が行 {0,3,6} 通過」
  は m ≤ 15001 で**証明付きで確定**（観察からの昇格）。
- M_{7,10} 帯 (m ≤ 587) では ≥10 点危険円は 50 族のみ。行 0,3,6 強制通過は
  def-mode の行被覆解析（行 1,4 は B 族のみ・行 2,5 は A 族のみ・行 3 は全部で被覆）の
  sharp 化に使える可能性（今後の課題）。
- 一般 w 行版: L2 は「w 行・d ≥ 3 二重行 ⟹ q | 4·⌈(w−1)/(d−1)⌉」に一般化でき、
  w = 8..14 の P(w) 決定（K0764 open 帯）への道具になる。

## スコープ

- 補題 L1–L3 は全称数学的証明。
- 定理 A・系 A1・定理 B の一意性は**有限全列挙による機械検証**（弦 ≤ 15000・R ≤ 10¹⁵）。
  弦 > 15000 かつ R > 10¹⁵ の追加例外の不在は主張しない（open）。
