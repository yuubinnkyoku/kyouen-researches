# 一行RUP証明と、SAT化に必要な節削除数

現在の命題は [K0709](../../knowledge/items/K0709-one-line-rup-unbounded-clause-deletion-distance.md)。
証明行数と充足化距離の間の一般的な推論を検査するための、明示的なCNF族である。

## 定義と全称構成

CNF FをSATにするために削除する必要のある最少節数をδ(F)と定める。
節の重みは全て1であり、重複節は用いない。
任意の整数m,k（1<=k<=m）について、変数x_1,...,x_mを持つCNFを

```
F_(m,k) = { (x_i) : 1<=i<=m }
          ∪ { (¬x_i) : 1<=i<=k }
          ∪ { (x_1 ∨ x_j) : k<j<=m }
```

と定める。全変数が出現し、異なる節がちょうど2m個あり、同語反復節もない。
全リテラル出現数や節長分布まで固定した族とは主張しない。

## 証明

各i<=kに対し、単位節(x_i)と(¬x_i)が両方残ればUNSATである。
これらは節として互いに重ならないk個の対なので、SAT化には少なくともk節を削除する必要がある。
逆に負単位節(¬x_1),...,(¬x_k)のk節を削除すれば、全変数を真にして残りの全節を満たせる。
従ってδ(F_(m,k))=k。

一方、k>=1なので(x_1)と(¬x_1)が存在する。単位伝播だけで矛盾し、空節はRUPである。
全てのm,kについて、共通の一行 `0` がUNSATのRUP証明となる（したがってDRAT証明でもある）。

固定したmについて、変数数m・節数2m・一行の証明を共有しながらδは1..mの全値を取る。
特にm=kを任意に大きくすれば、証明行数1のままでδは無界となる。
証明行数だけからδの値や大小順序を決めたり、有限の一般上界を与えることはできない。

また、任意のL>=1について、元からある節(x_1)をL-1回追加してから空節を追加すれば、
同じCNF・同じδのL行RUP証明が得られる。これらの追加はRUPであり、元のCNFは既に単位伝播で矛盾する。
生成された証明の行数は最短証明長ではなく、冗長な追加でも変わる。

## 有限検査

`verify.py` はm=1..5の全15個について、削除する節集合と全真偽割当を独立に列挙してδを求める。
さらに修正版DRAT検証器をソースからビルドし、全15個で同じ一行証明が受理されることを確認する。
m=5のδ=1,5の二つについては、同じ証明を8行へ冗長化しても受理されることを確認する。

```powershell
uv run --locked python research/experiments/proof-length-versus-deletion-distance-20261109/verify.py --tmp D:/tmp
```

`results.json` が入力CNFのhash、検証器ソースhashと各検査結果を含む。
全称命題の証明は上記の構成と上下界であり、15個の有限検査から外挿したものではない。

## 剰余放物線の比較への適用範囲

p=2207/2531/2647で観測したDRAT行数の差は、各実行で生成された証明書の規模の差である。
そこからSAT化に必要な最少節削除数を求めたことにはならない。
幾何的な違反四点組の個数、点の削除数など、別の距離も別に定義・測定する必要がある。

この一般CNF族は、剰余放物線から得る特定のNAE系CNF族の内部で、証明行数と距離に
経験的相関が存在する可能性を否定しない。その相関も、p=2647が他素数より「境界から遠い」
という順位も、現在の証明行数のデータだけでは確認されていない。
