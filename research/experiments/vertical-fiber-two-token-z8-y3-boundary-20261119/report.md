# 2トークン残余ゲーム z=8・y=3 の全Grundy分類（K0986）

- 日付: 2026-11-19
- 対象: H(R;(x,3);8)、全 x>=3・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0984（z=8,y=2）、K0979（z=7,y=3）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

| x | T_8^(3)(x) |
|---:|---|
| 3 | {1,3,5} |
| 4 | {1,3,5,7} |
| 5 | {1,3,5,7,9,11} |
| 6,7,8 | {1,3,5,7} |
| 9 | {1,3,5,7,13} |
| 10,11 | {1,3,5,7} |
| 12 | {1,3,5,7} ∪ O[15,23] |
| x>=13 | {1,3,5,7,15} |

| x | P_8^(3)(x) |
|---:|---|
| 3,5 | ∅ |
| 4 | I[8,∞) |
| 6 | {9} ∪ I[11,∞) |
| 7,9 | {9,11} |
| 8,10 | {9,11} ∪ I[13,∞) |
| 11 | {9,11,13} |
| 12 | {9,11,13} ∪ E[16,22] ∪ I[24,∞) |
| x>=13 odd | {9,11,13} ∪ E[16,x+11] |
| x>=14 even | {9,11,13} ∪ E[16,x+10] ∪ I[x+12,∞) |

全てのx>=3・R>=0で、H(R;(x,3);8)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailはK0832から

    R >= x+12  =>  H(R;(x,3);8) = (x+3) mod 2.

値2の定常位置は{1,3,5,7,15}。x=12だけは15,17,19,21,23が一時的に加わる。

## 証明

R=0は終局で値0。R>=1,x>=4の選択肢は

    A = H(R-1;(x-1,3);8)
    B = H(R-1;(x,2);8)
    C = 1 xor H(R-1;(x,3);7)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0984、CはK0979で評価できる。x=3では二つのトークン減少手が同じ(3,2)子に合流するため、A=B=K0984の値となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す（例: 023={0,2,3}）。mex対応は次の通り。

| 署名 | 01 | 23 | 03 | 0 | 1 | 12 | 023 | 123 | 02 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| mex | 2 | 0 | 1 | 1 | 0 | 0 | 1 | 0 | 1 |

各行はAに帰納仮説、BにK0984、CにK0979を代入した子値集合である。表の区間は互いに素で、各xについて1<=R<=x+11を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+12ではK0832の高R tail定理を各子に適用できる。x奇数ならA=B=C=1で親値0、x偶数ならA=B=C=0で親値1となり、親tail (x+3) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=8,y=3切片のみを扱う。z=8,y>=4、z=9,y>=2、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
