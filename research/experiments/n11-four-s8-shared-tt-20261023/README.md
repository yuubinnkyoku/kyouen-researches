# 11×11・4個の8石LOSSを支える52葉の共有探索表

2026-10-23。標準共円ゲーム・完全指摘・通常プレイ・元先手固定のWIN/LOSS。空盤は **UNKNOWN**。

K0525の4個の8石LOSS根を同時証明する、最小52個の正準10石LOSS葉を対象にする。証明葉集合は変更しない。全103個の9石義務の被覆と葉数52の有理双対下界は既存の n11-four-s8-joint-terminal52-20261023/verify_global.py が担当する。

旧方式から4,332状態（35.28%）削減。同じ制約優先順で別表8,967から共有表7,948への寄与は1,019状態（11.36%）。52葉を逆辞書順に処理する。辞書順処理では7,964状態となる。計算時間、証明書サイズ、空盤探索量の削減率ではない。これらは固定した着手順での観測値で、最適性を主張しない。

制約優先の着手順は、初期10石局面から追加できる点の禁止2点組・3点組・4点組への出現数を数え、100000×2点数＋1000×3点数＋4点数の降順、同点なら盤面位置昇順。手番勝敗は現在の手番側視点でメモ化し、全盤面のD4正準形を鍵にする。偶数10石根では現在の手番側は元先手に一致する。再帰の子で手番側は反転するが、同一盤面の値は根に依存しない。

shared52.cpp は4×4整数行列式、verify_shared52.py は別実装の3×3整数行列式で合法手と禁止組を構築する。両者とも52葉すべてをLOSSと独立再計算し、7,948状態、13,307参照、5,359再利用、13,255再帰辺で一致した。葉ごと別表8,967状態も一致。既存の1,017候補のPython終局検証と境界・被覆検証も通過した。WINの10石局面に1葉を置換するとC++は異常終了する。

再現（repoルートから、C++17とPython3）:

    bash research/experiments/n11-four-s8-shared-tt-20261023/reproduce.sh

既存の証明書や判定表を変更しない。共有表はメモリのみで、並列workerの永続cache統合は行わない。新たな二石root閉鎖なし。11×11空盤は **UNKNOWN**。

## 2026-10-23: 固定係数の再調整（7,636状態）

既存の52葉・被覆証明・整数幾何・D4・逆辞書順を変更せず、着手優先度だけを
`24×禁止2点組出現数 + 8×禁止3点組出現数 − 31×禁止4点組出現数 + 9×中心からのマンハッタン距離`
の降順（同点は点番号昇順）に変更した。旧7,948状態に対し**7,636状態**、312状態（3.93%）減。
C++の4×4整数行列式とPythonの3×3整数行列式で、52葉全LOSS、
共有表7,636状態、参照12,684回、再利用5,048回、再帰辺12,632本が一致。
`reproduce.sh`の末尾でC++ mode 10とPython `reverse weighted`を両方実行し、固定数値を照合する。
係数は小規模な試行で選んだ経験則であり、探索順の大域最適性、
他の根への一般化、実行時間の削減、二石rootの閉鎖を主張しない。


## 葉別着手順の貪欲計画（2026-10-23）

従来の52葉共有D4探索表7,636状態に対し、52個の10石LOSS葉を逆辞書順で処理し、葉ごとに着手順の係数を変えると6,563状態まで削減できた。固定した52葉の終局証明そのもの、103個の9石義務と葉数最小性は変更していない。

- `adaptive52.cpp`: C++の4×4整数行列式による完全終局探索。 `plan` は現在の共有表に対する増分状態数が最小の係数を選び、`verify` は保存係数表を上限なしで再生する。
- `adaptive52-weights.txt`: 539候補の探索から選択された46個の係数候補。元の539候補を使わなくても保存した52行を完全再生成できる。
- `adaptive52-schedule.tsv`: 52葉の逆辞書順の局面鍵と、それぞれに選択した `pair triple quad Manhattan` の4係数。
- `verify_adaptive52.py`: 独立した3×3整数行列式で全52葉のLOSSと共有D4表の状態数・参照数・再利用数・辺数を検証する。
- `reproduce_adaptive52.sh`: 52葉の既存被覆検証、計画表再生成とバイト比較、C++・Python独立再生、改変拒否試験を行う。

実行: `bash research/experiments/n11-four-s8-shared-tt-20261023/reproduce_adaptive52.sh`

期待値: `states=6563, lookups=10944, hits=4381, children=10892`。C++の `children` とPythonの `edges` は同じ再帰辺数。計画中の各候補には9,000状態・25,000参照の打切り上限を適用し、打切った候補は採用しない。**最終の検証処理には上限がない**。この削減は固定52葉に対する探索順の調整であり、二石rootや空盤の勝敗は未解決（UNKNOWN）。
