# 一辺細分星 q=20 の奇数次数実根切替（2026-11-05）

## 定理（全称解析＋厳密有理数比較）

既存の一辺細分星の終局長差多項式
```
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^k u+r(r+1)^{k+1}
```
について、r=q−3、奇数 k≥3 とする。

1. q=20 では奇数 3≤k≤161 に実根がない。
2. q=20 では奇数 k≥163 に相異なる負の単実根がちょうど2個ある。
3. 任意の整数 q≥20、奇数 3≤k≤161 に実根がない。

## 証明

r=17、a=(r+2)/(r+1)=19/18 と置く。既存の変数変換 u=−(r+1)y により、負の実根候補は 1<y<a に限られ、その方程式は
```
F_{k,r}(y)=r−y−(a−y)y^k=0
```
となる。u≥0 では T の各項が非負（定数項は正）なので根はない。負の u について候補区間外に根がないことは、u=−(r+1)y を代入した符号と既存の補題による。

k=161 の H(y)=(a−y)y^161 は [1,a] で y*=161a/162 に最大値を取る。下記の厳密な有理数比較により H(y*)<r−a。よって [1,a] の全点で F_{161,r}(y)>0。1<y<a では y^k が k に単調増加するため、奇数 k≤161 にも根はない。

k=163 では y*=163a/164 が 1<y*<a を満たし、下記の厳密比較により F_{163,r}(y*)<0。一方 F(1)=r−1−(a−1)>0、F(a)=r−a>0 なので中間値定理により少なくとも2根。奇数 k に対し T_{k,r}(−x) の非零係数の符号変化は2回であり、デカルトの符号法則から負根は重複度込みで高々2個。したがって相異なる単根がちょうど2個。k≥163 の奇数については固定 y*>1 で F_{k,r}(y*) が k に関して単調減少するので同様。

r≥17 では候補区間が (1,19/18) に含まれ、固定 y>1 において F_{k,r}(y) は r に関して狭義増加（導関数 1+y^k/(r+1)^2>0）。よって非存在は全 q≥20 に拡張される。

## 再現（Python 3・厳密整数比）

```python
from fractions import Fraction as Q

r = 17
a = Q(19, 18)
k = 161
y = a * k / (k + 1)
assert 1 < y < a
assert (a - y) * y**k < r - a

k = 163
y = a * k / (k + 1)
assert 1 < y < a
assert r - y - (a - y) * y**k < 0
```

上記2つの assert は実行して通過済み。区間全体の非存在は最大値の解析によるもので、有限標本点の外挿ではない。
