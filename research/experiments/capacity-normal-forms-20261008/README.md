# 容量ゲームの局面同型と Grundy 大規模有限検算（2026-10-08）

## 適用範囲と位置づけ

抽象容量占有ゲームで降順占有数 `x=(x_1,...,x_w)`、`0<=x_i<=m`、`sum_{i<=h}x_i<=r`、`2<=h<w` を考える。1手は一列に1を足し、安全性を保つこと。非自明領域は `r<h*m`。K0352 の一般位置平行列盤では `h=d-1` と対応するが、ここでの証明は抽象容量ゲームそのものについて成立する。

## 全称的な二つの局面同型

**飽和列除去。** `x` に `m` の列が `k<h` 本あり、`x=(m^k,y)` と書けるなら、その局面以降の手の木は

```
(w,h,m,r,x)  <->  (w-k,h-k,m,r-k*m,y)
```

と一対一対応する。既に満杯の列には将来一度も着手できず、任意の残りの占有数ベクトル `z` について
`top_h(m^k,z)=k*m+top_(h-k)(z)` だからである。各合法手・終局時期・Grundy 値は保存される。残り列数の差 `n=w-h` も不変。

**共通底上げの除去。** `0<=a<=min_i x_i` のとき、全後続局面を成分ごとに `a` 減算する写像は

```
(w,h,m,r,x) <-> (w,h,m-a,r-h*a,x-a*1)
```

という手の木の同型である。最大高さと上位 `h` 個の和の制約が同じだけ平行移動するため、全合法手の存在と Grundy 値が不変。通常は `a=min_i x_i` に取れば最低列が0の正規化形になる。

**系1：最上位 `h-1` 列が満杯。** `k=h-1` とすると `h'=1`、`r'=r-(h-1)*m<m`。残りの `w'=w-h+1=n+1` 列がそれぞれ独立に高さ `r'` まで進めるだけなので、任意の安全な `y` に対し

```
g(x)=((n+1)*(r-(h-1)*m)-sum(y)) mod 2.
```

特に余剰列数が奇数でも任意の容量余裕で値0か1と全手での反転が成立する。これは勝敗・勝ち手の完全分類である。

**系2：最上位 `h-2` 列が満杯。** `k=h-2` で `h'=2`。残りは幅 `w'=n+2` のペア容量ゲームに完全に帰着する。`n` が奇数なら `w'` も奇数なので K0347 の全 `m,r'` 対応の二最大値 Grundy 核を使って任意の後続局面を評価できる。したがって任意の次元 `d=h+1` でもこの飽和層は無界の全称的な `g<=3` 領域となる。偶数 `n` は K0352 により既に全域 `g<=1` である。抽象ゲーム同型であり、低次元の平行列盤に実際の幾何学的射影が存在することは主張しない。

## 独立検証

[check_isomorphisms.py](check_isomorphisms.py) は同型を仮定せず、すべての合法手によるメモ化 mex で両側の Grundy 値を別パラメータとして評価する。

`4<=w<=8,2<=h<w,2<=m<=5,1<=r<h*m` の全安全降順局面を完全列挙し、次の通りすべて一致した。

```
PASS {'saturated': 66444, 'last_column': 4495, 'translation': 44484, 'pair_reduction': 9826}
memo CacheInfo(hits=501873, misses=149707, maxsize=None, currsize=149707)
```

これは局面同型の独立有限検算。一般結論の根拠は上記の全称的な手の一対一対応である。

## 大きい有限範囲での未解決予想の再検証

[check_global_bound.cpp](check_global_bound.cpp) は、最大 `w,m` を指定すると、その `w,m` で `2<=h<w` かつ奇数 `n=w-h` のすべての `h`、`1<=r<h*m`、全安全降順局面について、石数降順の別実装 mex DP を行う。偶数 `n` は K0352 により二値と証明済みなので計算対象から外す。

```sh
g++ -std=c++17 -O3 check_global_bound.cpp -o /tmp/check_global_bound
/tmp/check_global_bound 10 10
/tmp/check_global_bound 11 11
```

```
PASS w=10 m=10 states=15788236 maxg=3 even_slack_nonbinary=0
g0=6815676 g1=6686730 g2=1395148 g3=890682 g4=0

PASS w=11 m=11 states=80830745 maxg=3 even_slack_nonbinary=0
g0=35029489 g1=34530352 g2=6752586 g3=4518318 g4=0
```

以上の **96,618,981件のパラメータ付き安全降順局面**で `g>=4` は0件、偶数容量余裕 `sigma=r-sum_{i<=h}x_i` で `g>=2` も0件。ただし前者「常に `g<=3`」、後者「偶数余裕は必ず二値」はともに **無界の証明がない予想** のままである。別の範囲・同じ局面がパラメータ付きで複数回計上され得る。有限検査を K item の proved としては扱わない。

## 11×11への接続と制限

同型と数値結果は **一般位置の平行列盤の容量ゲーム** に関するもので、標準2次元の11×11共円ゲームを直接解決・枝刈りするものではない。別ルールの誤った転用を避ける。
