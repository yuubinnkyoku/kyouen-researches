# 容量余裕3の全Grundy値と境界署名（2026-10-08）

## 適用範囲

K0352の抽象容量ゲーム。整数 `2<=h<w`, `m>=1`, `r<h*m`、降順安全状態 `0<=x_w<=...<=x_1<=m`、`sum_{i<=h}x_i=r-3` に対する無界の全称結果。幾何学的平行列盤への移送には別途K0352の一般位置・`q=r+1>2w`等が必要で、標準2次元11×11には適用しない。

記号：`n=w-h`、`b=x_h`、`R=n*b-sum_{i>h}x_i`。余裕3なので `R>=0`。上位 `h` 列のうち非満杯の列のどれかへ1石を足し、降順にした局面 `y` を「上位着手子」と呼ぶ。この子は必ず容量余裕2となる。異なる上位着手子全体を `U(x)` とし（同じ高さの列への着手は1種類にまとめてよい）、`b_y=y_h` と置く。

K0359の閉公式によって、各 `y∈U(x)` に対する次の値は **再帰せずに**計算できる。

```
c_y = #{i<=h: y_i==b_y}
D_y = sum_{i<h}(m-y_i)
eta_y = 1 if (c_y==1 and (y_{h-1}-b_y==1 or D_y==1)) else 0
epsilon_y = (n*(b_y-b)+(n%2)*eta_y) mod 2
S(x) = {epsilon_y: y in U(x)}
```

`S(x)` は空でない `{0}`, `{1}`, `{0,1}` のいずれかとなり、上位の占有形だけで定まる。

## 全称定理：容量余裕3の完全分類

```
S(x)={e}   -> g(x)=(R+e+1) mod 2
S(x)={0,1} -> g(x)=2+(R mod 2)
```

従って **容量余裕3では常に `g(x)<=3`**。奇数 `n` では `g=2,3` の必要十分条件が `S(x)={0,1}` であり、偶数 `n` では `S(x)={0}` で `g=(R+1) mod2` となる。計算量は上位の高々 `h` 本の着手を調べる程度で、残りの全ゲーム木を探索しない。

## 証明：Rに関する閉じたmex帰納

1. 余裕3を保つ合法手は、下位の `b` 未満の列を1増やすものだけである。この操作で `R` は1減るが、上位形、`S(x)`、`b` は変わらない。こうした手は `R>0` のとき、かつそのときに限り存在する。
2. それ以外の合法手は上位着手で容量余裕2へ移る。K0359によりその子のGrundy値は `(R_y+(n%2)*eta_y) mod2`。下位 `n` 列の合計はそのままで `R_y=R+n*(b_y-b)` だから、子の値集合は厳密に `E_R={(R+epsilon) mod2:epsilon in S(x)}`。これは上記の明示的な二値署名であり、余裕3を保つ手を行えば `R` の偶奇だけが反転する。
3. `R=0` では余裕3維持手が存在しない。`S={e}` なら `mex(E_0)=1-e`、`S={0,1}` なら `mex({0,1})=2` であり公式どおり。
4. `R>0` では余裕3を保つ全子が `R-1` を持ち、帰納法を適用できる。`S={e}` の場合は維持子の値が `(R+e) mod2` で、これは上位着手子の唯一の値にも等しいから、mexは `(R+e+1) mod2`。`S={0,1}` の場合は上位子の値集合は `{0,1}`、維持子の値は `2+((R-1) mod2)` なので、mexは `2+(R mod2)`。よってすべての `R` で成立する。□

これは余裕1の K0358 のmex構造を、余裕2が必ず二値である K0359 から **余裕3へ持ち上げた**もの。偶数 `n` ではそもそも K0352 が全局面の二値性を与える。余裕4以上については帰納仮定の子の値が二値でなくなるため、同じ推論を直接繰り返せない。

## 鋭さ：任意の h>=2・奇数 n>=1 で値2・3とも実現

`h=2, w=n+2` の基本族を作る。

- `m=4,r=4,x=(1,0^{n+1})`：余裕3、`R=0`。上位2本への着手の署名は0と1に分かれ、`g=2`。
- `m=5,r=6,x=(2,1,0^n)`：余裕3、`R=n` は奇数。上位2本への着手の署名は0と1に分かれ、`g=3`。

任意の `h>2` には、先頭に `h-2` 本の満杯列 `m` を加え、`r` に `(h-2)m` を加える。K0352 の飽和列除去によるゲーム木同型でGrundyは保存される。必要なら全占有数と容量上限を同じ `t` だけ平行移動し、`r` を `ht` 増やす。この操作もゲーム木同型で、`t` を大きくすると `q=r+1>2w` を満たせる。よって全奇数 `n`・全 `h>=2` について、この上界3は抽象容量ゲームでも幾何学的平行列盤でも **実現可能で鋭い**。
