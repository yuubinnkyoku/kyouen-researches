# N11 二石root `{60,27}` の32個のLOSS4証人がすべて必須であることの幾何監査

## 結果（2026-10-31）

既存の二石LOSS証明書に列挙された32個の四石LOSSクラスを固定し、各クラスのD4軌道に含まれる四石配置のうち、二石root `{60,27}` を含むものを列挙した。残り二点はそれぞれ合法な第三手であり、クラスが被覆できる第三手の集合を独立に構成できる。

全119第三手について、32クラスによる被覆回数は次のとおり。

| 被覆回数 | 第三手の数 |
|---:|---:|
| 1 | **114** |
| 2 | 2（57, 63） |
| 3 | 2（110, 120） |
| 13 | 1（93） |
| 合計 | **119** |

32クラスすべてに、そのクラス以外では被覆できない**固有の第三手**が少なくとも一つ存在する（各クラス1〜4個）。したがって、この**固定された32クラスの部分集合だけ**で119第三手を覆うには、32個すべてが必要である。32個を一つずつ除去する32通りの負例も全て未被覆第三手を生む。集合被覆の下界と上界がともに32となり、既存証明書の32クラス選択は**この候補集合に限って**個数最小である。

既存証明書の32クラスが持つ五石子の宣言数は合計3,297本。どのクラスも除去できないため、同じ32クラスのみを使う方式では、クラス単位でこの3,297本の境界検証を省くことはできない。ただし子局面の共有や別形式の証明書による圧縮余地は否定しない。

## 信頼境界と今後の意味

これは**集合被覆の構造的な最小性証明**であり、四石LOSSの勝敗を終局まで再探索した証明ではない。元証明書のLOSSラベルはsolver-trustedのままである。また、新たな四石LOSSクラスが見つかれば32未満の被覆もあり得る。既存32クラスを並べ替える・間引く最適化は無益と分かるため、二石rootの追加閉鎖には新しいLOSS4証人の生成、または異なる証明構造が必要となる。

二石rootの新規閉鎖は0、標準11×11空盤の勝敗は**UNKNOWN**。
