# 7立方の正四面体4石Pと正三角形3石N

点番号は49x+7y+z、各座標は0から6。
中心(3,3,3)の周りに置いた正四面体
`T={57,89,257,281}`、すなわち `(1,1,1),(1,5,5),(5,1,5),(5,5,1)` はP。
非終端であり、合法な第五手335手を28五石軌道へまとめ、その全境界を処理した。

| 根 | 勝敗 | 局面数 | 辺数 | 終端数 | 独立行列式数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 正四面体4石T | P | 337060 | 419826 | 103556 | 175627813 |
| 正三角形3石 `{61,85,253}` | N | 337061 | 419827 | 103556 | 175627813 |

三石根の勝ち手は285 `(5,5,5)`。完成する四石はTの立方体等長像である。
これは4手終局で処理できない三石根である。全二石調査で組 `{61,85}` の
未被覆42第三手・23三石軌道の一つに入ることも確認した（`parent-boundary.json`）。
同じ組の残り22三石軌道や二石根は今回の証明に含めない。

探索器は `../cube-q5-seven-hybrid-20261023/lazy.cpp`。
前の層の113,795,593候補行から、正四面体+中心の五石probeを経て再開した。
五石 `{57,89,171,257,281}` は追加37,270展開でN、14,070局面の全証明を
独立検査した。その作業を引き継ぎ、Tを追加1,452,201展開でPと確定した。
全候補表を独立検査したという意味ではない。採用した結論は圧縮全証明書を
探索器と別実装のBareiss検査器で検査した結果だけである。

`stage-2.cert.gz` はTからの全AND/OR証明書。三石証明は、Tの証明に一つの
N根を追加したものなので、同じ巨大部分木を重複収録せず `derive_parent.py` で再生成する。
両方を独立検査済み。証明木の最大石数は14であり、この局面からの勝ち側の応手戦略も
証明書に明示されている。7立方空盤の弱解決ではない。

```sh
gzip -dc research/experiments/cube-q5-seven-tetra-20261023/stage-2.cert.gz > /tmp/tetra-four.cert
/tmp/q7-verify-incremental /tmp/tetra-four.cert
python research/experiments/cube-q5-seven-tetra-20261023/derive_parent.py /tmp/tetra-three.cert
/tmp/q7-verify-incremental /tmp/tetra-three.cert
```

初期の大小3正四面体probeは `probe-five.jsonl`。中心を加えた大きさ1・3の根は
各10万展開でUNKNOWNだった。大きさ2だけがこの予算で閉じたため、Tへ対象を絞った。
中心軸四石根の探索は別snapshotで保存してあり、成果を混同しない。
