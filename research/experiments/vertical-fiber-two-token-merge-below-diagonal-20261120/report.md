# 2トークン残余ゲームの対角線下マージ: y=1,2 の全称定理と一般マージ観察のセンサス（2026-11-20）

- 対象: H(R;X;z)（κ=1 残余ゲーム・K0832 の定義と Theorem T に従う）
- 主張: **y∈{1,2} のとき、全 z>=1・全 x>=y・全 R>=0 で x+y<z（対角線下）なら
  H(R;(x,y);z) = H(R;{x+y};z) = single_token(x+y,z,R)**（K0832 出版単一トークン閉形式）。
- 証明: 出版済み閉形式（K1023 の y=1、K1099 の cand2、K0832 の single_token）の
  領域制限どうしの記号的な一致（下記 §2 の場合分け）。型機械は不要。
- 機械: `verify_merge.py`（9チェック・総 13,081,238 照合点・不一致 0・同一cwd 2回＋別cwd 1回で
  `output/audit.json` が byte-identical・SHA-256
  `38299a53b2584c99780d67bc47f3d013dc88fb4e37fd6aaf94691c4cf21da758`・純Python 約9秒）。

## 1. 定理

**定理（対角線下マージ、y=1,2）。** すべての z>=1、x>=y>=1（y∈{1,2}）、S=x+y<z、R>=0 に対して

```
H(R; (x,y); z) = H(R; {S}; z)
```

が成り立つ。右辺は K0832 の出版閉形式 single_token(S,z,R)（z>=S+1 場合は z に依存しない）。

領域は z>=S+1（S は z の対角線より下）。y=1 の定義域は x<=z-2、y=2 は x<=z-3 であり、
これは K1023/K1099 の閉形式でラダー領域と呼ばれた行集合に一致する（ここでは
「マージ行」と呼ぶ）。

## 2. 記号的証明（出版閉形式の場合分け）

補助記号: q_odd(k)=k（k 奇数）または k-1（k 偶数）。single_token(S,z,R) の z>=S+1 場合は

```
R=0 → 0
R<=q_odd(S) → 2 (R 奇) / 0 (R 偶)
R>q_odd(S)  → S mod 2
```

  （K0832 の式。y に依存せず z=S+1 以降で z 非依存でもある。）

**y=1（K1023 の閉形式の領域制限、x+1<z）。**
K1023 の表で行 x<=z-2（偶奇両 z）を制限すると、z に依存しない行関数になる:

- x 偶数: 値2位置 O[1, x+1]（奇数位置）、値1位置 [x+2, ∞)、他は 0。
- x 奇数: 値2位置 O[1, x]、値1位置なし、他は 0。

  single_token(S=x+1) と比較する:
- x 偶数: S 奇数 → q_odd(S)=S=x+1 → 値2は O[1,x+1] ✓、R>x+1 では S mod 2 = 1 →
  [x+2,∞) の値1 ✓、残り 0 ✓。
- x 奇数: S 偶数 → q_odd(S)=S-1=x → 値2は O[1,x] ✓、R>x では S mod 2 = 0 ✓。

**y=2（K1099 の cand2 の領域制限、x+2<z ⟺ x<=z-3）。**
K1099 の表でラダー領域 x<=z-3（偶奇両 z）を制限すると:

- x 偶数: 値2位置 O[1, 2⌈x/2⌉+1]=[1,x+1]（奇数位置）、値1位置なし、他は 0。
- x 奇数: 値2位置 O[1, x+2]（奇数位置）、値1位置 [x+3, ∞)、他は 0。

  single_token(S=x+2) と比較する:
- x 偶数: S 偶数 → q_odd(S)=S-1=x+1 → 値2は O[1,x+1] ✓、R>x+1 では S mod 2=0 ✓。
- x 奇数: S 奇数 → q_odd(S)=S=x+2 → 値2は O[1,x+2] ✓、R>x+2 では S mod 2 = 1 →
  値1領域 [x+3,∞) ✓。

  値1・値2の位置集合の重なりは双方の表で空であり（出版閉形式の assert およびラダー上端 2⌈x/2⌉+1 < x+3）、R=0 は両者 0。全場合で一致し、定理が成り立つ。∎

**系1（対角線下の z 非依存）。** S=x+y<z の行 (x,y) の Grundy 行関数 R↦H は
z=S+1 以降のどの z でも同一（single_token の z>=S+1 場合が z 非依存なため）。
K1023/K1099 の「ラダー領域の値2位置は z 非依存」という記述の全 R 版。

**系2（低R高さのみ縮約の解決）。** K1054 が「次の一手」としていた「低R高さのみ縮約の y=2 全z版」
（z=18..21 で R<=z+2y まで単一トークン一致の観察）は、本定理が全 R・全 z>=1 で直接含意する。

## 4. 一般マージ観察（センサス witnesses・全称主張ではない）

C5〜C7 は「任意トークン多重集合 X でも ΣX=:S<z なら H(R;X;z)=H(R;{S};z)」という
一般観察の有限支持である:

- 2トークン: y=1..40・z<=40 で 348,270 点不一致 0（y>=3 は出版閉形式を持たないため
  生再帰で検証）。
- 3トークン: z<=26 で 156,754 点不一致 0。
- 4トークン: z<=14、5トークン: z<=11 で 8,740 点不一致 0。

  これらは**センサス witness であり、y>=3 または 3トークン以上の全称定理ではない**。
  K1078（z=18,y=3 の x<=14 行）と K1098（z=19,y=3 の x<=15 行）が「S<z なら
  H(R;(x,y);z)=v(x+y,z,R)」を一般未証明の観察として記録していたものの、
  本項は y∈{1,2} を全称証明した。y>=3 は「実験→予想」段階のまま残る。

## 5. 鋭さ（S=z で失敗する）

S=z 行ではマージは**成り立たない**: 正準反例 (z, X, R) = (3, (2,1), 5) で
H=1 に対して H(R;{3};3)=2（C8 で固定・計828件の帯内発散を計上）。
境界 S<z は鋭い。S=z 行の分類（前倒し pin・h=z 行の追加点）は出版済み個別スライスの
対象領域であり、本項はそれらの行には一切触れない。

## 6. 信頼境界

- 主張の全称性は §2 の記号的証明（出版閉形式 K0832/K1023/K1099 の場合分け）による。
  K1023/K1099 の trust 境界（Lean 形式化ではない・型機械の機械掃引による証人境界）を
  そのまま継承する。
- C1〜C4 は有限照合であり証明の代わりではない。C5〜C7 は観察の有限 support であり
  全称主張ではない。C8 の発散計上は有限観察である。
- ゲーム木レベルの素朴な帰納（選択肢分解で (x-1,y)/(x,y-1) 子と {S-1} 子が揃う）
  は S=z-1 行の C 子（対角線上の 2トークン状態と対角線上の単一トークン状態の比較）で
  停止し、出版済みの対角線上理論（h=z 行の pin 構造）を必要とする。
  本項は閉形式比較でこれを回避した。y>=3 の一般化は対角線帯の補題群が 本質的な
  残務である。
