# 射影平面 PG(2,q) のブロッキング集合共演ゲーム（宣言・2026-11-25）

## 目的

共演ゲームを射影平面 `PG(2,q)` へ拡張する。ブロック＝直線（`q+1` 点）で、
「各直線と高々 3 点」の通常プレイ。補集合 `X = V \ S` は
**`(q−2)` 重ブロッキング集合**（各直線と `q−2` 点以上で交わる）であり、
極大安全集合は**最小 `(q−2)` 重ブロッキング集合**の補集合になる。
すなわちゲームは「最小多重ブロッキング集合」の代数・幾何と直結する。

## 対象

- `PG(2,2)` v=7, `PG(2,3)` v=13, `PG(2,4)` v=21（完全 Grundy が可能な範囲）。
- `K_3(PG(2,q))`（各直線 ≤3 の最大集合）を q=2,3,4,5 で ILP 厳密計算。
- 極大安全集合のサイズ・個数・補集合の直線交差プロファイル・(q=3 は) PGL 軌道。

## 手法

- ボードは `F_q^3` の 1 次元/2 次元部分空間から構成（q=2,3,5,7 は素体、q=4 は GF(4)）。
  各点対が一意な直線に載ることを全数検査。
- 完全 Grundy は出版済み `grundy_full.exe`（n≤64）。
- 極大安全集合は DFS で全列挙し、補集合のプロファイルを計算。
- K_3 は scipy HiGHS のバイナリ ILP。

## 期待する結果と検証

- q=2,3,4 の完全 Grundy（すべて `{0,1}` と予想、空盤は先手勝ち）。
- 極大サイズの一覧（q=3: 7,9; q=4: 7,9）と最小多重ブロッキング集合の構造。
- 「全極大安全集合のサイズの偶奇が一様なら Grundy ∈ {0,1}」という
  parity-graded 補題の定式化と適用（設計ボード・PG 盤・反転平面盤の比較）。
- サブエージェント独立検証。
