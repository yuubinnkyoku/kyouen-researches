## 証明書と独立検査

`output/certificate.json`は1281点全てについて、削除証人または負の証明木を持つ。
木のleafは、空障害（保持点だけで禁止四点を作る）か、残予算kに対するk+1個の互いに素な障害のpacking。
branchは未解消の障害Rを選び、Rの全頂点vを削除する場合それぞれについて子を持つ。
選んだvを含む障害を除き、残予算を一つ減らす。
`verify.py`は探索コードをimportせず、元の入力から障害族を再構成する。
branchの全選択肢の被覆、edge番号、残予算、packingの互いに素性を全照合する。
負証明木の受理node数はpacking306、branch123。全6514幾何四点も実検査した。
JSONの重複keyや、改変された入力hash・種・固定点・予算を拒否する。

検査器の一般健全性は次の帰納論証による。空障害はhit不可能。
k+1個の互いに素な非空障害をhitするにはk+1点以上が要る。
非空障害Rをhitする削除集合は必ずあるv∈Rを含み、残りはvで解消されない障害を予算k−1でhitしなければならない。
従ってRの全vの子が不可能なら親も不可能である。これが証明木全体へ帰納する。
実装・コンパイラ一般の形式的健全性やLean形式証明は主張しない。

`regression.json`はn=3の空障害を含む全256族・予算0..3と、n=5の固定乱数200族・予算0..5を
総当たりと照合した2224例。正負双方の証明も再生し、14改変を拒否した。
この有限回帰は上記全称帰納論証と区別する。

## 幾何学的な必要条件

F⊆T、|S∖T|≤5の安全集合Tが、除外点uを含むと仮定する。
各該当qはuとS内の三点からなる禁止四点であり、安全性のためS∖Tはq∖{u}をhitする必要がある。
Fは保持されるので、D=S∖Tは実際には(q∖{u})∖Fをhitしなければならない。
従ってDはH_u全体を五点以下でhitし、負の証明木に矛盾する。
これはTの点数に依らない条件で、複数点の同時追加でも回避できない。
K0727の既存必要条件と合わせ、五点以下の削除による任意の改善Tは上記60点を含めない。

残る1221点を組み合わせた改善の存在・非存在は不明。
五点削除局所最適性、A(2539)=1258、提供辺の完全性は主張しない。
全体範囲1258≤A(2539)≤1271と既存保持側UNKNOWNは変わらない。
