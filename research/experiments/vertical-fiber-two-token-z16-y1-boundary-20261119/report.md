# z=16・y=1 2トークン残余切片の全Grundy分類

- 日付: 2026-11-19
- 種別: x外帰納と全R署名帯表による全称証明＋独立検証器
- 子の依存: K0832（単一トークン閉形式・一般tail・低R縮約）、K1020（z=15,y=1全称分類）

## 命題

κ=1残余ゲームの局面を \(H(R;(x,y);z)\) とする。任意の \(x\ge1\)、\(R\ge0\) について、\(H(R;(x,1);16)\) のGrundy値は次で完全に決まる。

\(O[a,b]\) は区間内の奇数、\(E[a,b]\) は区間内の偶数、\(I[a,\infty)\) はa以上の全整数とする。

### 値2の位置 \(T_{16}(x)\)

- \(x=1\): \(\{1\}\)
- 偶数 \(2\le x\le14\): \(O[1,x+1]\)
- 奇数 \(3\le x\le13\): \(O[1,x]\)
- \(x=15\): \(O[1,17]\)
- \(x\in\{16,17\}\): \(O[1,15]\)
- \(x=18\): \(O[1,15]\cup O[19,35]\)
- \(x\ge19\): \(\{1,3,5,7,9,11,13,15,19\}\)

### 値1の位置 \(P_{16}(x)\)

- 奇数 \(x\le13\)、および \(x=15\): \(\varnothing\)
- 偶数 \(2\le x\le14\): \(I[x+2,\infty)\)
- \(x=16\): \(I[17,\infty)\)
- \(x=17\): \(\{17\}\)
- \(x=18\): \(\{17\}\cup E[20,34]\cup I[36,\infty)\)
- 奇数 \(x\ge19\): \(\{17\}\cup E[20,x+17]\)
- 偶数 \(x\ge20\): \(\{17\}\cup E[20,x+16]\cup I[x+18,\infty)\)

これら以外のRでは値0である。従って全域で

\[
H(R;(x,1);16)=
\begin{cases}
2 & R\in T_{16}(x),\\
1 & R\in P_{16}(x),\\
0 & \text{otherwise}.
\end{cases}
\]

またK0832の一般tailを \(S=x+1,\ |X|=2,\ z=16\) に適用すると、

\[
R\ge x+18\implies H(R;(x,1);16)=(x+1)\bmod2.
\]

低R側もK0832の高さのみ縮約から

\[
R\le17\implies H(R;(x,1);16)=v_{\rm single}(x+1,16,R)
\]

となる。

## 証明

\(R=0\) は値0。\(R\ge1\) で、着手後の三つの子を

\[
\begin{aligned}
A&=H(R-1;(x-1,1);16),\\
B&=v_{\rm single}(x,17,R-1),\\
C&=1\oplus H(R-1;(x,1);15)
\end{aligned}
\]

と書く。Aはxに関する外帰納、BはK0832の単一トークン公式、CはK1020で評価できる。\(x=1\) では二つのトークン除去手が同じ単一トークン子に合流し、Aは存在しない。

各Rでの子値集合 \(\Sigma_x(R)=\{A,B,C\}\) は、K0832とK1020の閉形式を代入すると次の互いに素な帯に分かれる。数字列は集合の要素を昇順に並べたもの（例: 023 は \(\{0,2,3\}\)）である。

| xの範囲 | \(\Sigma_x(R)\) の全帯 |
|---|---|
| \(x=1\) | \(R=1:\ 01;\ R=2:\ 23;\ R\ge3:\ 1\) |
| \(2\le x\le14\)、x奇数 | 奇数 \(R\le x:\ 01\); 偶数 \(R\le x+1:\ 23\); \(R\ge x+2:\ 1\) |
| \(2\le x\le14\)、x偶数 | 奇数 \(R\le x+1:\ 01\); 偶数 \(R\le x:\ 23\); \(R=x+2:\ 03\); \(R\ge x+3:\ 0\) |
| \(x=15\) | 奇数 \(R\le17:\ 01\); 偶数 \(R\le16:\ 23\); \(R\ge18:\ 1\) |
| \(x=16\) | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 023\); \(R\ge19:\ 0\) |
| \(x=17\) | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 123\); 奇数 \(19\le R\le33:\ 1\); 偶数 \(20\le R\le34:\ 123\); \(R\ge35:\ 1\) |
| \(x=18\) | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 123\); 奇数 \(19\le R\le35:\ 01\); 偶数 \(20\le R\le34:\ 0\); \(R\ge36:\ 0\) |
| \(x=19\) | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 123\); \(R=19:\ 01\); 偶数 \(20\le R\le36:\ 02\); 奇数 \(21\le R\le35:\ 1\); \(R\ge37:\ 1\) |
| \(x\ge20\)、x偶数 | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 123\); \(R=19:\ 01\); \(R=20:\ 02\); 奇数 \(21\le R\le x+17:\ 1\); 偶数 \(22\le R\le x+16:\ 0\); \(R\ge x+18:\ 0\) |
| \(x\ge21\)、x奇数 | 奇数 \(R\le15:\ 01\); 偶数 \(R\le16:\ 23\); \(R=17:\ 0\); \(R=18:\ 123\); \(R=19:\ 01\); \(R=20:\ 02\); 奇数 \(21\le R\le x+16:\ 1\); 偶数 \(22\le R\le x+17:\ 0\); \(R\ge x+18:\ 1\) |

表の各行は全 \(R\ge1\) を重複なく覆う。必要なmexは

\[
01\mapsto2,\quad 23\mapsto0,\quad 03\mapsto1,\quad
1\mapsto0,\quad 0\mapsto1,\quad
023\mapsto1,\quad123\mapsto0,\quad02\mapsto1.
\]

従って各帯のmexは上記の \(T_{16},P_{16}\) と一致する。x=1の基底とx外帰納で全xが閉じ、各xの署名帯が全Rを覆うため全称証明となる。tail式はK0832からも独立に従い、同じ分類に接続する。∎

## 構造

- 定常値2の追加点は \(19= z+3\)。
- 掃引行は \(x=z+y+1=18\)、掃引帯は \(O[19,35]=O[pin,x+y+z]\)。
- 値1の基底点は \(z+1=17\)、帯の開始は \(z+2y+2=20\)。
- \(x=15\) は高さ \(x+y=z\) の行で、低R縮約が \(O[1,17]\) を与える。\(x=18\) は掃引行、\(x=19\) はその直後の移行行である。
- \(x\ge19\) では値2位置が9点に固定される。値1の有限偶数帯と、x偶数行にだけ現れる無限tail帯が分かれる。

これは固定z=16・y=1の定理であり、任意zの横断公式を証明したものではない。
