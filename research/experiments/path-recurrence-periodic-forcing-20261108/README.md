# 道再帰への周期強制が周期34を保存するか（K0684の機構プローブ）

## 目的

K0684（任意の固定rank3以下核＋長道のGrundy列は最終的に34周期）の**帰納ステップ**を
幾何から切り出して検査する。核を固定したときの正確な再帰は

```
g(L) = mex( B(L) ∪ {g(L-2)} ∪ {g(i) ⊕ p[L-3-i] : 0 ≤ i ≤ L-3} )
```

である（`rooted-core-tail-periodicity-20261107/proof.md` の式そのもの）。ここで
`p` は裸の道のGrundy（最終周期34）、`B(L)` は核が与える非自己項すなわち

```
B(L) = {A_C ⊕ p[L-1], B_C ⊕ p[L-2]} ∪ {f_{C_u}(L)} ∪ {g(D_u) ⊕ p[L]}
```

定数⊕道シフトと、より小さい核の値 `f_{C_u}(L)`（帰納仮定で最終34周期）からなる。
K0684の帰納法では「`B(L)` が最終34周期ならば `g` も最終34周期」が示されればよい。
この実験はその**抽象的な含意**を、実際の核を一切列挙せずに検査する。

## 方法

`B(L)` を直接与えて `g` を計算し、最終周期を調べる。2系統：

- `arbitrary`: `B(L)` はランダムな整数集合。ランダムな開始以降は周期34で周期的。
- `structured`: `B(L) = {a_k ⊕ p[L+s_k]} ∪ {h_j[L]}`。`a_k` は小さな定数、`s_k` は
  小さなシフト、`h_j` はランダムな34周期列（子核を模型化）。

`onset34` は `g[L] ≠ g[L+34]` となる最後の `L` の次。`min_tail_period` は末尾
`TAIL` 項の最小周期。`eventually_34_periodic` は `onset34 ≤ M-TAIL` かつ最小周期が
34の約数（1,2,17,34）であること。空強制 `B=∅` は対照（34周期になるはず）。

これは抽象再帰についての**観測**であり、K0684の証明でも実際の核についての主張でもない。

## 結果（round 1: `probe.py`, M=2000, TAIL=600, seed=20261108）

- 対照（空強制）: onset34=53, 最小周期34, 最大Grundy 9。34周期。
- arbitrary 25件: **25/25** が最終34周期（最小周期すべてちょうど34）。
  onset34 最小/中央/最大 = 147 / 501 / 768、最大Grundy 16..30。
- structured 25件: **25/25** が最終34周期（最小周期すべてちょうど34）。
  onset34 最小/中央/最大 = 52 / 463 / 688、最大Grundy 9..32。

ランダムな周期強制でさえ解を周期34へ「吸収」した。開始の規模（中央値~500）は
実際の核（K0682の500、六点純三点辺の637）と同じオーダーであり、模型が正確である。

## 結果（round 2: `probe_stress.py`, M=4000, TAIL=900, seed=31415926）

より大きな強制値・大きな選択肢集合・より多くの子・長い子前周期・長い打ち切り長さで
頑健性を攻撃した。全100件が最終34周期（最小周期すべてちょうど34）・例外なし：

- arbitrary255（値0..255・集合最大15・開始≤1500）: 40/40、onset最大1444。
- structured255（定数⊕シフト＋子最大5）: 40/40、onset最大1610。
- arbitrary1023（値0..1023・集合最大25・開始≤2000）: 20/20、onset最大1936。

強制値を1023まで上げても最大Grundyは27に留まる（mexは最小の欠落のみを見るため、
大きな強制値は小さいmexに影響しない）。全配置の詳細は `output/stress.json`・`stress.log`。

## 解釈と限界

round 1は「最終34周期な強制 `B` に対し、道自己畳み込み再帰の解 `g` は最終34周期に
なる」という**一般補題の候補**を強く支持する。これが証明されれば、核サイズに関する
帰納法でK0684が従う（任意の核の `B(L)` は帰納仮定により最終34周期なので）。
ただし本実験は有限個の配置・有限打ち切り長さの観測にすぎず、全称証明でも開始上界でもない。
証明すべき補題の正確な形と強い証拠を与えたことが貢献である。

## 証明の障害（考察・未証明）

なぜ有限窓定理（K0682）がこの補題の存在証明を兼ねないかを明確にする。選択肢集合
`O(L)=B(L)∪{g(L-2)}∪{g(i)⊕p[L-3-i]:0≤i≤L-3}` について `O(L)` と `O(L+34)` を比べる。
`B` は周期34で一致。畳み込みは `i≤L-3-N_p`（`N_p` は `p` の周期開始）で
`p[L+31-i]=p[L-3-i]` となり項が一致する。不一致は次の境界項に局在する：

- `i∈(L-3-N_p, L-3]` の約 `N_p` 項（`p[L-3-i]` が `p` の前周期にある）。
- `O(L+34)` 側に固有の34項 `i∈[L-2,L+31]`（`p[L+31-i]=p[0..33]`）。
- `{g(L-2)}` 対 `{g(L+32)}`。

これら境界項は `L` 近傍の直近の `g` の窓（幅 ~`N_p+34`）に依存する。したがって
`O(L+34)=O(L)` は一段階の恒等式ではなく、`g` の近傍窓が34周期へ落ち着いた後にのみ成り立つ。
すなわち周期性はこの再帰の**吸引的不動点**であり、証明は境界項がmexへ与える影響が
最終的に消える／安定すること（吸収・縮小論証）を示ねばならない。K0682の有限窓定理は
窓が一致した後の無限先を保証する認証規則であって、窓がいつか一致すること（不動点への収束）
は示さない。本実験の150/150収束はその収束が極めて頑健であることの観測である。
