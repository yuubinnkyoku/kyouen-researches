# 異容量・上位2列ゲームの全極大配置と終局石数（全称定理）

**対象**: w>=2 本のラベル付き列、容量 c_1>=...>=c_w>=0、整数 r>=0。安全性は占有数の上位2列の和が r 以下であること。1手で1列を1増やす。これは抽象容量ゲームであり、標準2次元共円ゲームへの適用は主張しない。

## 定理（全整数パラメータ）

c_1+c_2<=r なら、極大配置は全列満杯 x=c のみ。

c_1+c_2>r なら、L=max(0,r-c_1), U=min(floor(r/2),c_2) と置く（L<=U）。全極大占有ベクトルは、各整数 b∈[L,U] に対し A=r-b として、次のものに尽きる。

- A>b: c_j>=A である任意の列 j を一つ選び、x_j=A、他の列 i は x_i=min(c_i,b)。
- A=b: 全列 x_i=min(c_i,b)（1ベクトル）。

b は上位2列の小さい方の占有数なので、異なる b は重複しない。終局石数の集合は厳密に

    {T(b)=r-2b+sum_i min(c_i,b) : L<=b<=U}.

さらに T(b+1)-T(b)=#{i:c_i>=b+1}-2>=0。したがって終局石数に穴がないための必要十分条件は、U=L または #{i:c_i>=L+1}<=3。

A>b の b に対応するラベル付き極大占有ベクトル数は #{j:c_j>=A}、A=b では1。各列に c_i 個の物理的な位置がある場合の極大石集合数は

    N_b=sum_{j:c_j>=A} C(c_j,A)*product_{i!=j}C(c_i,min(c_i,b))  (A>b)
    N_b=product_i C(c_i,min(c_i,b))                            (A=b).

同じ石数の異なる b は個数を加算する。空盤から終局石数 T に達する合法着手順序数は T! * sum_{b:T(b)=T} N_b。

## 全称証明

c_1+c_2<=r の場合、全容量ベクトルが安全なので全列満杯のみ極大。そうでない場合、上位2列の和が r 未満の安全配置には未満杯列が存在し、その列を1増やしても上位2列の和は高々1しか増えないので極大ではない。従って極大配置の上位2占有数は A>=b、A+b=r。

A>b では最大列 j 以外の占有数は b 以下。x_i<b で容量未満の列があれば、その列への着手は上位2列の和を変えず合法だから、x_i=min(c_i,b) が必要。A=b でも同様。逆に提示した形では容量に余裕がある列はすべて b 以上を占め、1増やすと上位2列の和が r+1 以上となるので極大。

存在条件は A<=c_1、b<=c_2、A>=b であり、ちょうど L<=b<=U。A>b で c_j>=A なら、j 以外にも容量 b 以上の列がある（j=1 なら c_2>=b、j!=1 なら c_1>=A）。どの構成も石数は A+sum_{i!=j}min(c_i,b)=T(b)。差分公式は min(c_i,b+1)-min(c_i,b)=[c_i>=b+1] から従う。b+1<=U<=c_2 なので差分は非負であり、該当列数は b とともに非増加。従って最初の差分が1以下であることが、全差分が1以下であることと同値。

各 j の選択と列内位置の二項係数積から個数公式を得る。安全集合の下方閉性より、固定した極大石集合の全着手順列 T! 通りはすべて合法。□

## 実例と監査

c=(5,4,3,2,1), r=5 では終局石数は {5,8,10}、物理的極大石集合数は順に 1,150,360。6,7,9石の終局は存在しない。

独立の全占有ベクトル列挙（定理を使わない合法1手判定）で、2<=w<=6、非増加 0<=c_i<=4、0<=r<=2c_1+2 の4386条件・1,547,619安全局面・11,952極大占有ベクトルを検査し、極大ベクトル集合、終局石数、物理的極大集合数、差分公式に不一致なし。列の順序固定は置換対称性による。検証器 verify.py と出力 verify.log を参照。
