## 0. 対象と記法

対象は他レーンで確立された 2トークン残余ゲーム（K0832離脱点の縦繊維過程）:

- 状態: H(R; X; z)。R ≥ 0 は残り手数予算、X は降順トークン多重集合、z ≥ 0 は協同プロセス深度。
- 再帰（出版正本 H_ordered/H_canonical、本実験dirの audit_frontier.py に逐語転写）:
  - トークン子: 各 v ∈ X について v > 1 なら H(R-1; X\{v}∪{v-1}; z)、v == 1 なら H(R-1; X\{v}; z+1)。
  - z子: z ≥ 1 なら 1 ^ H(R-1; X; z-1)。
  - H(0; X; z) = 0。
- σ(X) = ΣX、κ(X) = |X|。s(x, z, R) := single_token(x, z, R)（出版単一トークン全称閉形式、K0832系列）、ST(x, R) := single_token_val(x, R)（出版 merge 領域プロファイル: R 奇数かつ R ≤ q_odd(x) で 2、x 奇数かつ R ≥ q_odd(x)+1 で 1、それ以外 0）。
- 出典: 転写ブロックは出版 y=18 全称検証器 verify_y18_universal.py（part2・SHA-256 8ddd0c2f…・commit 由来はK1242/K1245出版）から @@TRANSCRIPTION marker で抽出。エンジン 2,022 bytes（SHA-256 e5abe053…）・cand17 ブロック 3,529 bytes（44f1ce4e…・K1240 proved）・cand18 ブロック 3,275 bytes（caf13e80…・K1242 proved）。scripts/check_blocks.py が監査正本内の該当ブロック byte を固定 SHA と照合する。

本レーン（横断法則一般補題化）の目的は、y族ごとの全領域検証（~700万照合点/族）によらず、マージ領域 z ≥ σ+1 を多重度非依用に支配する構造補題を確立し、族追加ごとの検証コストを境界行 z = σ の有限パリティ検査に削減することにある。

## 1. Lemma 0（単一トークン平坦性・出版閉形式の算術恒等）

出版 single_token(x, z, R) の z ≥ x+1 分支は
`m = q_odd(x); R<=m → (R 奇数で 2 / 偶数で 0); R>m → x mod 2`
であり、これは ST(x, R) と各点一致する。すなわち単一トークンではマージ領域 z ≥ σ+1 の値は z 非依存で ST に等しい。これは新結果ではなく出版閉形式の算術恒等式である（本監査の CX/XB 成分が生エンジン対照で anchors）。

## 2. Theorem FR-X（frontier reduction 補題・本研究の主要定理）

**主張**。𝓜 をトークン簡約で閉じた多重集合のクラス（X ∈ 𝓜 ならその全トークン子・消費子も 𝓜 に属する）とし、各 X ∈ 𝓜 に κ(X) ≥ 2 について次の**前沿条件 F±X** が成立すると仮定する: σ = σ(X) とおき、境界行 b_X(R') := H(R'; X; σ) に対して

- σ 偶数: [F+] b_X(奇数 R' ≤ σ-1) ≠ 1、b_X(偶数 R' ≤ σ) = 0、[σ+1, 2σ] の全区間で b_X ≠ 1。
- σ 奇数: [F-] b_X(奇数 R' ≤ σ-2) ≠ 1、b_X(偶数 R' ≤ σ-1) = 0、[σ, 2σ] の全区間で b_X ≠ 0。

このとき 𝓜 の全 X・全 z ≥ σ(X)+1・全 R ≥ 0 で

    H(R; X; z) = ST(σ(X), R)                      （マージ法則）

が成立する。

**注意（有限性）**。F±X の clause は R' ≤ 2σ に限られる。R' ≥ 2σ+1 では出版 tail 定理（R ≥ σ + κ + z - 1 のとき値は σ mod 2、一般Xで全称証明済み）により b_X(R') = σ mod 2 であり、単一トークン境界プロファイル s(σ, σ, R') も R' ≥ 2σ ≥ 2σ で σ mod 2 をとるため、前沿の mex 比較条件は R' ≥ 2σ+1 で自動的に成立する。よって仮定は X ごとに本当に有限（高々 2σ+1 点）の検査で済む。R' = 2σ の点は F±X の第三 clause に明示的に含まれる（tail の下端が κ ≥ 2 で 2σ+κ-1 ≥ 2σ+1 であるため、出版 tail はこの点を被覆しない）。

**証明**。𝓜 上での強帰納法。外側は σ について帰納し、内側で z を昇順、R を昇順に走る。

(i) κ(X) = 0: 自明。κ(X) = 1: Lemma 0 そのもの（マージ領域の値は z 非依存に ST）。これらは帰納の基底であって仮定を要しない。

(ii) κ(X) = n ≥ 2, σ = σ(X) とする。以下、各 (z, R) で H(R;X;z) と単一トークン状態 H(R; (σ); z) = s(σ, z, R) の選択肢集合を比較する。k := z - (σ+1) ≥ 0 で場合分けする。

(iii) k ≥ 1（z ≥ σ+2）。X 側の選択肢:
   - トークン子 X'（σ' = σ-v ≤ σ-1、z は不変、v=1 のとき z+1）: z = σ+2 ≥ (σ-1)+1 だから子はマージ領域にあり、σ-帰納法により値は ST(σ-1, R-1) で全て一致する。
   - z 子: 1 ^ H(R-1; X; z-1)、ここで z-1 ≥ σ+1 だから X についての z-帰納法（内側）でマージ値 ST(σ, R-1)。
   ゆえに X 側の選択肢集合は {ST(σ-1, R-1), 1 ^ ST(σ, R-1)}。一方 (σ) 側は Lemma 0 によりトークン子が ST(σ-1, R-1)、z 子が 1 ^ ST(σ, R-1) で同一の選択肢集合を持ち、mex は等しい。ゆえに H(R;X;z) = s(σ, z, R) = ST(σ, R)（再び Lemma 0）。条件は不要。

(iv) k = 0（z = σ+1・前沿）。X 側の選択肢:
   - トークン子: σ' = σ-1、z ∈ {σ+1, σ+2} ≥ σ'+1 なので σ-帰納法により全てのトークン子の値は一致し ST(σ-1, R-1)（= φ₁ とおく）。消費子（v=1）は κ が減るだけで σ' = σ-1 であり同様に φ₁。
   - z 子: 1 ^ b_X(R-1)。
   よって X 側 mex = mex({φ₁, 1 ^ b_X(R-1)})。
   単一側 (σ; z=σ+1) の選択肢: トークン子 (σ-1; z=σ+1 ≥ σ') → φ₁; z 子 1 ^ s(σ, σ, R-1)（出版閉形式・z=x 分支）。
   単一側 mex = mex({φ₁, 1 ^ s})。
   Lemma 1（下記、C8で全27ケース機械検証）により、この2つの mex が等しいための必要十分条件は
   - φ₁ = 0 のとき [b_X(R-1) == 0] ⟺ [s(R-1) == 0]
   - φ₁ ≠ 0 のとき [b_X(R-1) == 1] ⟺ [s(R-1) == 1]
   である。φ₁ = ST(σ-1, R-1) と s の出版閉形式を素直に代入すると、この条件は R の各点で次のパリティ表現に簡約される:
   - σ 偶数（σ-1 奇数）: φ₁ = 2 ⟺ R 偶数 ≤ σ-1... の代わりに R の偶奇で分ける全検査は、正確には φ₁ ∈ {2, 0, 1} の各帯域と s の値域（奇数 ≤ 2σ-1 で 2 / σ < R' で σ mod 2）の組合せで、F±X の全 clause に機械的に展開される（σ偶数 → F+、σ奇数 → F-、上記の通り）。
   仮定 F±X はまさにこの簡約後の全点条件であり、k = 0 全域で mex が等しい。ゆえに H(σ+1; X; R) = ST(σ, R)。

(v) 内側の帰納順 z ↑ の正当性: z 子でのみ z が減り、簡約子は同じ z 層内で σ' < σ に落ちる（外側）。消費子の z+1 参照は σ' = σ-1 に落ちるため外側帰納法で被覆される。R ↑ は全ての子が R-1 を参照することによる。(iv) の культур点 R = 0 は H(0) = 0 = ST(σ, 0) で成立。∎

**Lemma 1（mex 3値表・C8機械検証）**。t, b, s ∈ {0, 1, 2} に対し
mex({t, 1^b}) = mex({t, 1^s}) ⟺ (t = 0 のとき [b=0]==[s=0]、t ≠ 0 のとき [b=1]==[s=1])。
27ケース全てが audit.json の C8 成分に記録されている（bad 0）。

**系（FR-X の実用的意味）**。マージ領域 z = σ+1 の最初の層（k=0・前沿）を除く全層は無条件にマージ法則を満たす。前沿層は F±X（X ごと有限・境界行単独のパリティ検査）に還元される。したがってクラス 𝓜（例: 2トークン族 (x,y) の y 族全体、3トークン全多重集合、…）について、マージ法則の検証は境界行 b_X の F±X 検査のみに帰着し、~700万点の族全領域検証器を打たずに済む。プッシュ直前の最新main再取得で、y = 20 族全称は K1249 として出版完結していたことが確認できた（FR-X はこの結果と独立な経路による相互整合傍証となる）。y = 21 以降の族のマージ corollary は、族閉形式の全称を待たず境界行検査から直接得られる道が開けた（fit/全称レーン群への接続・干渉なし）。

## 5. 正直な限界と次の課題

- FR-X は F±X を仮定する十分条件の補題である。**F±X 自体の全X証明は含まない**: 前沿の mex 比較を閉じるには境界行 b_X の内部構造（z = σ より下の層 k ≤ -1）に踏み込む必要があり、本レーンでは有限監査のみ（2トークンでは published 族閉形式が、y ≤ 19 で F± を帰結させる: E5 の機械傍証）。FR-X の逆（F±X の必要性）は主張しない。
- GX-M・F±X・BSL・low-R は status observed。11×11 標準盤の root/S2/class には全く触れていない。固定幅・q点版安定化長も本レーンの外。
- BSL の R* 公式の全称証明候補: k ≤ -1 内部層の構造を「z-S スライスの型機械」で圧縮する方向（y族検証器の型理論の逆用）。3トークン境界行の tail onset は σ+1..σ+4 にばらつき、_formula は未確定（3トークンレーン K1247 follow-up の自然課題）。
- 実行誠実記録（published_run.txt）: C8 の t=0 規則の初稿誤り（b==s → [b==0]==[s==0]、スモークテストで自捕捉・訂正は出版前）、tamper T2/T3 の TAMPER-MISSED が comp_m2d の top-level bad 集計漏れ（検出器バグ）を暴き修正したこと（電池が自バグを捕捉した好例）、実行中のサンドボックスフルリセット1回（全素材を出版正本から再取得し全計算やり直し・リセット後の再生成 audit.json が byte-identical・出版数値はすべてリセット後の正本由来、y=20 fit レーンの同種事例と同一扱い）。
