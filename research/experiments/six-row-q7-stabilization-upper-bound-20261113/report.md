## 代入の詳細

K0318 の記号で (w,q)=(6,7):

```
r = q-1 = 6,  a = r-1 = 5,  N = r(w-1) = 30
Q = C(30,3) - 5*C(6,3) = 4060 - 100 = 3960
d0 = C(6,3) = 20,  d1 = C(5,3) = 10
per_point = min( C(30,2)//C(5,2), (C(30,2)-5*C(6,2))//8 )
           = min(435//10, 360//8) = min(43,45) = 43
Y = 5*43 = 215
H = max{ 2x+y : 20x+10y <= 3960, y <= 215 } = 396   (argmax x=198, y=0)
U = r + H = 6 + 396 = 402
```

d0 = 2·d1 なので種類0・種類1曲線の予算効率が等しく
H = floor(2Q/d0) = 396 となる（K0318 の q≥7 系
M ≤ r + floor(2Q/C(r,3)) ともちょうど一致）。
従来の暗黙の一般上界は K0024 の T_{6,7} = min(A,B) = 10,101 で、402 はその 25 分の1。

帰結: m ≥ 402 では全ての不足行に合法点が残り、全極大安全集合は 36 石、
全安全局面で g(S) = (36 − |S|) mod 2。この上界は有限SATのUNSATを根拠としない
（K0318 の全称証明そのもの）。
