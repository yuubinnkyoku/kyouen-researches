# 2トークン残余ゲーム z=9・y=4 の全Grundy分類（K0990）

- 日付: 2026-11-19
- 対象: H(R;(x,4);9)、全 x>=4・R>=0
- 状態: **全称定理**
- 依存: K0832（再帰・Theorem T・高R tail）、K0989（z=9,y=3）、K0987（z=8,y=4）

## 主定理

O[a,b]・E[a,b]は区間内の奇数・偶数、I[a,∞)はa以上の全整数とする。Grundy値2の位置集合T、値1の位置集合Pは次の通り。

全てのx>=4・R>=0で、H(R;(x,4);9)はRがTに属すれば2、Pに属すれば1、それ以外は0である。

高R tailはK0832から

    R >= x+14  =>  H(R;(x,4);9) = (x+4) mod 2.

値2の定常位置は{1,3,5,7,9,17}。x=14だけは19,21,23,25,27が一時的に加わる。定常値2位置はz=9族でy=1..4が「{1,3,5,7,9}∪{z+2y}」（11,13,15,17）を4点連続で満たす。値1の頭部{10,12,14,16}は{z+1,z+3,z+5,z+7}=z+2i+1 (i=0..y-1)でy=1..4の各切片を貫く。x=14の掃引帯O[19,27]はz=9族の掃引位置x=z+y+1（y=1..4でx=11..14）と掃引範囲O[2y+11,2y+19]に一致する。値1帯はtailが1になる側（y=4ではx奇数行）にI[x+15,∞)が付く点でy=3と同型であり、x>=15奇数行のO帯上端x+14はtail内側と接続する。

## 証明

R=0は終局で値0。R>=1,x>=5の選択肢は

    A = H(R-1;(x-1,4);9)
    B = H(R-1;(x,3);9)
    C = 1 xor H(R-1;(x,4);8)

親の値は mex{A,B,C}。Aはxに関する外帰納、BはK0989、CはK0987で評価できる。x=4では二つのトークン減少手が同じ(x,3)子（最大トークン4）に合流するため、A=B=K0989のx=4行となる。

K0832のTheorem Tにより、奇数Rの親の値は高々2、偶数Rの親の値は高々1。署名は子値集合を数字列で表す（例: 023={0,2,3}）。mex対応は次の通り。

|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| mex | 2 | 0 | 1 | 0 | 0 | 1 | 0 | 1 | 0 |

各行はAに帰納仮説、BにK0989、CにK0987を代入した子値集合である。x>=16偶数行とx>=17奇数行では、帯端だけがxに依存し、署名は一定である。これはAがx-1行の閉形式、B・Cがx行の閉形式で、20<=R<=x+13の全域で帯ごとに子値が定数となる（例: 奇数X行のE[20,x+13]でA=(x-1)偶数行のO[19,x+12]内、B=z=9,y=3の奇数行O[17,x+12]外、C=1 xor z=8,y=4の偶数行even(r,18,x+11)内の子値一定性）ことによる。x=15はA子が掃引行x=14を横切る過渡行で、帯端・署名が定常行と異なる。表の区間は互いに素で、各xについて1<=R<=x+13を過不足なく覆う。mex対応を適用すると上記のT/Pが得られる。

R>=x+14ではK0832の高R tail定理を各子に適用できる。x偶数ならA=B=C=1で親値0、x奇数ならA=B=C=0で親値1となり、親tail (x+4) mod 2と一致する。よって外帰納が閉じ、全x・全Rが証明された。

## 限界

本項は抽象残余ゲームのz=9,y=4切片のみを扱う。z=9,y>=5、z=8のy>=5、z>=10、全高さを統合する2トークン値2位置の一般式は未解決。z=9族の定常第6点 z+2y の一般化（y=1..4の4点連続）も観察であり証明ではない。標準二次元盤の固定幅・q点版の真の安定化長へ直接転送する結果ではない。
