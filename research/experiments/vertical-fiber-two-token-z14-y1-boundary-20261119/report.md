## 命題

κ=1残余ゲーム H(R;(x,1);14) の全 x>=1・全 R>=0 における Grundy 値は次で完全決定される。
記法は K1012..K1017 と同一: O[a,b]=区間内の奇数、E[a,b]=区間内の偶数、I[a,∞)=a以上全域。

値2位置 T(x):
- x=1: {1}
- x偶数 (2<=x<=12): O[1,x+1]
- x奇数 (3<=x<=13): O[1,x]
- x=13（h=z行 x+y=14・d=12格子行）: O[1,15] = O[1,q_odd(z)+2ceil(y/2)]（h=z拡張ラダー。
  上端15はd格子ピン2y+(d+z)/2=2+26/2=15と一致し、z=12のx=11行・点13と同型に
  偶数zではx=z-1行の孤立上端として現れる）
- x=14 (=z-1行): O[1,13]
- x=15（d=z行）: O[1,13]
- x=16（掃引行 d=z+1・x=z+y+1）: O[1,13] ∪ O[17,31] = O[1,z-1] ∪ O[pin,x+y+z]、pin=17
- x>=17（安定域 d>=z+2）: {1,3,5,7,9,11,13,17} = O[1,z-1] ∪ {pin}、pin=z+2y+1=17（偶数z型）

値1位置 P(x):
- x奇数 (x<=13): ∅
- x偶数 (x<=12): I[x+2,∞)
- x=14（z-1行）: I[15,∞) = I[z+1,∞)
- x=15（x=z行 d=z）: {15} 有限
- x=16（掃引行）: {15} ∪ E[18,30] ∪ I[32,∞)
- x偶数 (x>=16): {15} ∪ E[18,x+14] ∪ I[x+16,∞)
- x奇数 (x>=17): {15} ∪ E[18,x+15]（有限）

tail: R>=x+16 ⟹ H=(x+1) mod 2（= (x+y) mod 2）。
高さのみ縮約: R<=15 (=z+1) ⟹ H(R;(x,1);14) = single_token(x+1,14,R)。

## 証明（A/B/C署名帯表）

x外帰納: x=1 は直接検証（値は R=1 で2・R=0とR>=2で0）。x>=2 で A子が x-1 行の既知値を用い、
B・C子は出版定理の閉形式で評価できる。各 (x,R) の A/B/C署名の帯構造（検証器の
band_signature・本レポート付記事項と同一コード）が全 R>=1 を互いに素に被覆し、mex が T/P
閉形式を与える。特異行群は x=13（h=z拡張ラダー帯"01"がR=15まで伸び、偶数帯はR>=16で一律"1"）、
x=14（z-1行: R=16の"023"・x=z行の下流I[15,∞)）、x=15（d=z行: R=16..30の"123"…B子の
z=x特殊帯2とC子のK1017値2帯の同時最多）、x=16（掃引行: 奇帯"01"がR<=31へ拡大・
これはA子がz-1行15の"123"帯域を写す）、x=17（掃引行16をA子に持つ移行行: 偶帯"02"が
R<=32=掃引帯上界まで続く）であり、x>=18 の偶奇定常帯は次の2式で全Rを被覆する:
x偶数行は奇帯"1"がR<=x+15で"0"に落ち（tail 0）、偶帯はR>=20で一律"0"（tail 1）、
x奇数行は奇帯"1"が全R>=19、偶帯は R<=x+15 で"0"・R>=x+17 で"1"。
安定域の偶帯境界x+15は C子のz=13切片の奇帯O[17,x+14]の上端+2に一致し、
x=15行では偶帯"123"がR<=30まで、x=16掃引行では偶帯"123"がR=16のみ・奇帯"01"がR<=31
（掃引帯上界x+y+z）まで、x=17移行行では偶帯"02"がR<=32まで続く（いずれもA子が
z-1..掃引行の帯域を写すことの直接の確認である）。

## 構造則（7則の z=14 での貫徹・有限観察）

1. pin = z+2y+1 = 17（偶数z型・[z偶]=1）— x>=17 の値2定常ピン。
2. 掃引行 d=z+1=15 → x=z+y+1=16 — 値2が O[pin,x+y+z]=O[17,31] へ拡大。
3. 値1基底点 {z+1}={15}（y=1）、d=z行 x=15 に現れる。
4. 帯開始 z+2y+2=18、帯 parity≡z (mod 2)=偶（E[18,..]）、I帯はx偶数行のみ
   （x>=16偶数の I[x+16,∞)）。
5. h=z行（x=13）の拡張ラダー O[1,15]=O[1,q_odd(z)+2ceil(y/2)]。d=12格子ピン
   2y+(d+z)/2=15 と同一の点で、偶数zではx=z-1行のラダー上端として現れる
   （z=12のx=11・点13【K1016】と同型。奇数zはx=z+1行の一般ラダーに吸収【K1017】）。
6. tail R>=x+y+z+1−z=x+16 で H=(x+y) mod 2。
7. height-only縮約 R<=z+1=15。z横断有限観察はz=4..13全10値でR<=z+1成立【K1017】だが、
   本項のV14がz=14での15全省・x<=500の直接監査（8,000点・不一致0）を与え、
   有限観察は11値に伸びた（一般証明は依然未解決）。

偶数z族では z=8,10,12,14 の4例連続でラダーO[1,z-1]・pin=z+2y+1・前倒し点のx=z-1行
上端出現が成立し、奇数z族（z=9,11,13）のラダーO[1,z]・pin=z+2y・格子点吸収型と
完全に対照的な2系列構造がz=14で確定した。
