# 一辺細分星 q=14 の奇数次数実根切替（2026-11-05）

## 結論（全称解析＋有理数区間証明）

一辺細分星の終局長差多項式
\[
T_{k,r}(u)=u^{k+1}+(r+2)u^k+(r+1)^ku+r(r+1)^{k+1}
\]
について、r=q-3=11、奇数 k≥3 とする。

- q=14、3≤k≤97（奇数）では実根がない。
- q=14、k≥99（奇数）では相異なる負の単実根がちょうど2個ある。
- 任意の整数 q≥14、奇数 3≤k≤97 では実根がない。

## 証明

先行する一般証明と同じく u=-(r+1)y と置く。奇数 k に対して根の候補は 1<y<a=1+1/(r+1) に限られ、
\[
F_{k,r}(y)=r-y-(a-y)y^k
\]
の零点と一致する。u≥0 に根はない。

r=11、a=13/12 とする。固定 y>1 に対し (a-y)y^k は k に関して増加するため、k=97 で F>0 を示せば k≤97 の全奇数次数で正である。

H(y)=(a-y)y^97 の唯一の極大点は y_*=97a/98。区間 [1,a] を100等分し、各区間 [l,h] に対して z=min(max(y_*,l),h) と置けば H(y)≤H(z) である。付属の厳密有理数検査で全100区間について
\[
H(z)<11-h\le 11-y
\]
を検証する。したがって F_{97,11}>0 が区間全体で成立する。

k=99 では y=1073/1000∈(1,a) で F_{99,11}(y)<0 が厳密整数演算で成立する。以降の奇数 k でも同じ点で負値を保つ。一方 F(1)>0、F(a)>0。中間値定理から2個の負実根が存在し、T_{k,r}(-x) の符号変化は2回なのでデカルトの符号法則から根はちょうど2個で、いずれも単根である。

r≥11 では候補区間 (1,1+1/(r+1)) は (1,13/12) に含まれ、固定 y>1 において F_{k,r}(y) は r に関して厳密増加する（実数 r で偏微分すると 1+y^k/(r+1)^2>0）。よって q≥14 の奇数 k≤97 にも根不存在が及ぶ。

## 再現（Python 3、浮動小数点なし）

```python
from fractions import Fraction as Q

r, k = 11, 97
a = Q(13, 12)
star = a * k / (k + 1)
for i in range(100):
    l = 1 + (a - 1) * Q(i, 100)
    h = 1 + (a - 1) * Q(i + 1, 100)
    z = min(max(star, l), h)
    assert (a - z) * z**k < r - h

y = Q(1073, 1000)
assert 1 < y < a
assert r - y - (a - y) * y**99 < 0
```
