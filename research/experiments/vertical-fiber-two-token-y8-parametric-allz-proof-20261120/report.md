## 記号

O[a,b] は区間内の奇数、O_z[a,b] は区間内で z と同じ偶奇の位置、E[a,b] は偶数、
I[a,∞) は a 以上の全整数。q_odd(k) は k を奇数に切り下げた値（k 奇なら k、
k 偶なら k-1）。d = x - z、S = x + 8 と書く。y=8 は偶数 y で、S=x+8 の偶奇は
x と一致する（y=2,4,6 と同じ型）。マージ行のラダー上端 q_odd(S) は
x 奇なら x+7・x 偶なら x+8。値1の無限帯と tail は偶数 y 型で
**x 奇の行**に出る（両 z 偶奇で共通・z にはよらない）。

## 選択肢分解と x=8 での合流

R>=1 のとき

- A = H(R-1; (x-1,8); z)（x>=9；x=8 では 2 つの減少手が同一多重集合
  (7,8)≡(8,7) 子に合流し A≡B = H(R-1;(7,8);z) = cand7(z,8,R-1)、
  すなわち K1131 の z 行 x=8 閉形式。H は多重集合にしか依存しない）
- B = H(R-1; (x,7); z) = cand7(z, x, R-1)（K1131 全称閉形式・逐語転写）

## 値の構造（y=2..8 の横断観察・一般称主張ではない）

- **値1基底点 y 点仮説の y=8 確定**: 基底点は y 個 {z+1, z+3, ..., z+2y-1}
  が y=1..8 の全称表で確定（y=8 は本項で 8 点 {z+1,..,z+15}・連続 8 例）。
  y>=9 は予想。
- **tail 開始族式 x+z+y+1 の y=2..8 確定**: 7 族連続の全称確定。tail 値
  (x+y) mod 2 も 7 族連続（y 奇で値1無限帯が偶数 x 行・y 偶で奇数 x 行。
  マージ行の値1無限帯も同じ S=x+y 偶奇に従い、y=8 では x 奇の行に出る）。
- **マージ行の境界 x<=z-y-1**: y=1..8 の 8 族で確定（y=8: x<=z-9）。
- **掃引行 x=z+y+1 と帯 O[2y+z, x+z+y]（y=8: O[z+16, x+z+8]）**:
  y=2..8 共通の族式。
- **中間帯（値1）**: O_z[2y+z+2, x+z+y]（y=8: O_z[z+18, x+z+8]）。族式は
  y=3..8 の 6 族連続。
- **定常 pin 2y+z（奇z）/2y+z+1（偶z）**: y=2..8 共通（y=8: {z+16}/{z+17}）。
- **前倒し pin の格子構造**: pin 行 x では (x-y)+z ≡ 2 (mod 4) が成り立ち、
  pin 値は格子公式 pin = 2y + ((x-y)+z)/2 で与えられる。y=8 では奇z の
  pin 行 d∈{-4,0,4,8}（pin z+10, z+12, z+14, z+16）・偶z の pin 行
  d∈{-6,-2,2,6}（pin z+9, z+11, z+13, z+15）。pin 行の d は
  d ≡ y (mod 4)（奇z）・d ≡ y+2 (mod 4)（偶z）に乗る（y=8 は奇z d≡0・
  偶z d≡2）。**格子公式は y=5..8 の 4 族で統一**（一般証明は今後の課題）。
- **対角行 S=z（x=z-y）の連続上端の格子規則 r = z+y - [2(z-y)≡0 (mod 4)]**:
  y=8 の行（奇z 上端 z+8・偶z 上端 z+7）まで y=2..8 の全称表の全 z で一致
  （2(z-y)=2z-16≡0 mod 4 ⟺ z 偶で下げが生じる格子。y>=9 は予想）。
- **型機械の clip 窓**: 必要 clip 半径の族式候補 2y+2 が y=5:12, y=6:14,
  y=7:16, y=8:18 と 4 族連続 tight（K1127/K1131 の予想がともに的中）。
  y=9 では clip 20/番兵 21 が予想される。
- **pin 行の追加値1点 2y+z+1**: 掃引帯を持たない pin 行（y=8 奇z の d=8 行
