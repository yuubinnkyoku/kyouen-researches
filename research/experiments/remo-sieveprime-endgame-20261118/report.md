## 0. 設定と依存

すべて K0928 のpot力学（補題P・フェーズ規則）上の議論である。
各フェーズ: pot の石を active の先頭（ptr）から1個ずつ配り、
active[(ptr+pot) mod k]（k=人数）がちょうど q=pot//k 個受け取った時点で敗者となる
（r=pot mod k 人の先頭側は +1 個余分に受け取る）。敗者の保持石数（受け取り後）
が次の pot、敗者は除去され、ptr は敗者の次のプレイヤーに移る。
この規則は K0928 補題P（配分石数=直前の敗者の保持数・s+pot=C 不変）と同一物で
ある。U/V ゲームは K0928 定理RED の縮約ゲーム:

- V(m): m人・各2石・pot 1・ptr 0・監視ラベル0。base 正準形 F(2,1;m−1)・監視距離 a=1。N := 2m+1。
- U(m): m人・各2石・pot 2・ptr 0・監視ラベルm−1。base 正準形 F(2,0;m)・監視距離 a=1。N := 2m+3。

F(w,h;n) は holdings [w]^(n−h) + [w+1]^h ・pot w・ptr 先頭の円配置
（K0931/K0934 の記法・n=人数・h=w+1 保持者の数）。
監視距離 a は「円の末尾から数えた監視の位置」: 監視の位置は n−a。

依存する出版済み定理:

- K0928: 補題P（フェーズ規則）・定理PAR・定理RED（P(2m+1)=1+2V(m)・P(2m+2)=3+2U(m)）・
  系（偶数C≥4はP≥3・奇数C≥3はP≤C−2）。
- K0934 (LAD-GEN): 第一stretch-w の完全決定（block・breaking・終状態census F(w+1,h2;n2)）。
- K0935 (WATCH-MAP): 境界越え監視写像 a2。
- K0937 (INV-TRACK): 監視が生存する限り全stretch開始状態は F(w,h;n) で
  a=h（V）/ a=h+1（U）（不変量INV）・石数 T=wn+h+w は毎stretch不変
  （V: T=N・U: T=N−1）・死亡合同式「stretch-w で監視が死ぬ ⟺ a=r+1 ⟺ (w+1)|N」

K0937 が残した OPEN は「t=0エンドゲーム（n≤w・ladder regime外）が監視を殺さないこと」
（予想SIEVE-PRIME）だけであった。本項はこの最後の隙間を閉じる:
**エンドゲームは約数篩そのものであり、監視の生死は「円サイズkがNを割り切るか」で完全決定される。**

## 1. 定理END-INV（エンドゲームの構造不変量・全称）

**定理.** V側（s=0）またはU側（s=1）のゲームで、監視が ladder regime を生存して
t=0エンドゲームに入ったとする。エンドゲームの入口状態を
F(w,h;n)（pot=w・ptr先頭）・監視距離 a=h（V）/ a=h+1（U）とする
（ENTRY-LOC（定理3）によりこれは一般性を失わない）。このとき N := 2m+1+s に対し、
監視が生存する限りの**すべての**フェーズ開始状態は、ptr基準の円で

E(P; α, β) = [P]^α + [P+1]^β （k = α+β = 人数）

の形を保ち、監視は位置 α（V）/ 位置 α−1（U・pot block の末尾）にあり、

**N = P(k+1) + β + s**（石数恒等式）

が毎フェーズ成立する。ここで P は pot、α・β は ptr基準 circle の
[P] block 長・[P+1] block 長である（α=0 は pot block 空を許す）。

**証明.** 入口: circle = [w]^(n−h) + [w+1]^h より P=w・α=n−h・β=h・k=n。
V: N = w(n+1)+h（T=N・K0937 INV-TRACK。t=0 では n≤w だが census の形は同じ）。
U: N = w(n+1)+h+1（T=N−1）。恒等式 N = w(n+1)+h+s は明らかに成立。
監視位置: V は位置 n−a = n−h = α、U は位置 n−a = n−h−1 = α−1。

帰納段: 状態 E(P;α,β)（生存中）から1フェーズ進む。q=P//k・r=P mod k とおくと
敗者は ptr基準位置 r、全員が +q、位置 0..r−1 がさらに +1 を受け取る。
敗者の受け取り後の保持は位置 r の block だけで決まる:

- **r < α（pot block 敗者）**: 新 pot P′ = P+q。新円（ptr=敗者の次=旧位置 r+1 から）は
  旧位置 r+1..α−1（P+q）→ 旧位置 α..k−1（P+1+q）→ 旧位置 0..r−1（P+q+1）の順で、
  後ろの2 block はともに P′+1 なので
  **E(P′; α−r−1, β+r)** である。
- **r ≥ α（pot+1 block 敗者）**: 新 pot P′ = P+1+q。新円は
  旧位置 r+1..k−1（P+1+q=P′）→ 旧位置 0..α−1（P+q+1=P′）→
  旧位置 α..r−1（P+1+q+1=P′+1）の順で、
  **E(P′; β+2α−r−1, r−α)** である。

監視位置の遷移: V（旧位置 α）は r<α で新 index α−r−1 = α′（新 [P′+1] block の先頭）、
r>α で新 index (k−1−r)+α = β+2α−r−1 = α′（同先頭。β′=r−α≥1）。
r=α は監視=敗者で**V側死亡**である（ §2 ）。
U（旧位置 α−1）は r≤α−2 で新 index α−r−2 = α′−1（新 pot block の末尾）、
r≥α で新 index (k−1−r)+(α−1) = α′−1（同末尾。α′=β+2α−r−1≥1 は
r≤k−1=α+β−1 から β+α−2≥0、すなわち α′≥1 を得る... 正確には
α′=0 は r=β+2α−1>α+β−1=k−1 が必要で不成立）。
r=α−1 は監視=敗者で**U側死亡**である（ §2 ）。

恒等式の保存: 帰納仮説 N = P(k+1)+β+s・k′=k−1 とすると
- r<α: P′k′+β′+s = (P+q)k+β+r+s。P=qk+r より P+q = q(k+1)+r なので
  (P+q)k = qk(k+1)+rk となり、全体 = qk(k+1)+r(k+1)+β+s = P(k+1)+β+s = N。
- r≥α: P′k′+β′+s = (P+q+1)k+r−α+s = qk(k+1)+rk+k+r−α+s
  = P(k+1)+k−α+s = N−(β+s)+k−α+s = N+k−α−β = N。

生存中の block 非負性: V は β≥1 を保存する（入口 h≥1・β′=β+r≥β または
β′=r−α で r=α は死亡だから生存中 r>α より β′≥1）。したがって V の
「位置 α = [P+1] block 先頭」は常に circle 内である（α≤k−1... 正確には
β≥1 より α≤k−1、α=0 の場合は circle 全体が [P+1] で位置 0 が先頭）。
U は α≥1 を保存する（入口 n−h≥1・α′=0 になるのは r=α−1 すなわち死亡のとき
（r<α 側）のみで、r≥α 側は上記のとおり α′≥1）。∎

機械アンカー: FAMILY（全 family 状態 w≤60・7,198状態・175,086フェーズで
structure・監視位置・恒等式・transition公式・死亡合同の全照合・違反0）。

## 2. 定理END-SIEVE（死亡合同式・全称）

**定理.** エンドゲーム状態 E(P;α,β)（監視生存中）の1フェーズで監視が死ぬのは

- V側: r = α のとき、かつそのときに限る。
- U側: r = α−1 のとき、かつそのときに限る。

そしてこれは **k | N** と同値である。監視が死ぬ場合、そのフェーズの円サイズ k は
N の約数である（エンドゲームの円サイズは n, n−1, …, 2 と1フェーズに1人ずつ
降下するので、監視は N の約数のうち ≤ n で最大のものに到達した時点で死ぬ）。

**証明.** 敗者は ptr基準位置 r、監視は位置 α（V）/ α−1（U）なので死亡判定は
表示のとおり（END-INV の遷移の考察と同じ）。合同式: END-INV の恒等式と
P=qk+r より N ≡ P+β+s ≡ r+β+s (mod k)。α+β=k から
−β ≡ α・−β−1 ≡ α−1 (mod k) なので

- V (s=0): k|N ⟺ r ≡ α (mod k)。r∈[0,k−1] であり、V は生存中 β≥1
  （α≤k−1）なので r ≡ α (mod k) ⟺ r=α。
- U (s=1): k|N ⟺ r ≡ α−1 (mod k)。r∈[0,k−1]・α∈[1,k]（β=0 を許す）でも
  剰余は一意なので r = α−1。

降下について: エンドゲームの各フェーズはちょうど1人を除去する（ゲーム規則）ので
円サイズは n, n−1, …, と降り、k=2 のフェーズを最後に終わる。
監視は k ∤ N のフェーズをすべて生存するので、合成 N なら約数 k で死に、
約数がない（N素数）なら最後まで生存する。∎

機械アンカー: FAMILY の cong（死亡 ⟺ k|N・175,086フェーズ・違反0）。

## 3. 定理ENTRY-LOC（エンドゲーム入口の位置・全称）

**定理.** 素数NのV/Uゲームで監視が ladder を生存し、幅 w で初めて t=0
（n ≤ w）に達したとする。このときエンドゲーム入口状態 F(w,h;n) は

- n ∈ {w−1, w}（V・Uとも）。
- V: 1 ≤ h ≤ min(n, w)、U: 0 ≤ h ≤ min(n−1, w)。

を満たす（**family状態**）。例外は V の m=1（base が F(2,1;0)・円が空の退化形で
生存自明）のみ。

**証明.** h の範囲: K0937 INV により入口でも a=h（V）/a=h+1（U）。
監視位置 n−a ≥ 0 より V は h≤n・U は h≤n−1。ladder census（K0934 終状態
h2 = h−1−r（r<h）または h+w−r（r≥h））は h≤w を保存し、V の生存は h≥1 を
保存する（r=h−1 は死亡）。base（V: h=1・U: h=0）も範囲内。

n ∈ {w−1, w}: n ≤ w は t=0 の定義。w ≥ 3 とし、n ≤ w−2 を仮定して矛盾する。
幅 w は「初めて t=0 になった幅」なので、直前の stretch（幅 w−1）は t′≥1、
すなわち n′ ≥ w（除数は (w−1)+1=w）。K0937 のT恒等式（T=wn+h+w は
全stretch入口で不変）から

T = (w−1)n′ + h′ + (w−1) ≥ (w−1)w + 0 + (w−1) = w²−1。

一方、入口では T = wn+h+w で、h ≤ n（V）/ h ≤ n−1（U）と n ≤ w−2 より

V: T ≤ w(w−2) + (w−2) + w = w²−2 < w²−1、
U: T ≤ w(w−2) + (w−3) + w = w²−3 < w²−1。

矛盾。よって n ≥ w−1。w=2 の場合は base 状態が直接エンドゲームに入る場合で
（stretch を1つも踏まない）、V: n=m−1≤2 より m∈{2,3} で n∈{1,2}、
U: n=m≤2 より m∈{1,2} で n∈{1,2}（m=1 の V は n=0 の退化形）。∎

機械アンカー: ENTRY（素数 m≤200,000 両側・67,716ゲーム・最大入口幅632・違反0）。

## 4. 定理END-SIEVE-IFF（family状態上の完全判定・全称）

**定理.** family状態（n∈{w−1,w}・V: 1≤h≤min(n,w)・a=h・N=w(n+1)+h /
U: 0≤h≤min(n−1,w)・a=h+1・N=w(n+1)+h+1・w≥2）からエンドゲームをプレイした
とき、監視が生存する ⟺ **N は素数**。

**証明.** END-SIEVE により監視は「円サイズ k | N」の最初のフェーズで死に、
それ以外のフェーズをすべて生存する。円サイズは n, n−1, …, 2 と降る。

(N素数 ⟹ 生存): family の N は最小でも5（w,n,h の最小例で N=5）で素数なら
奇数 ≥ 5。降ってくる k は 2 ≤ k ≤ n < N なので k ∤ N。よって監視は死亡せず
（k=2 のフェーズも 2 ∤ N）、最後の1人 = 生存者となる。

(N合成 ⟹ 死亡): spf(N) ≤ √N。family では
V: N = w(n+1)+h ≤ w(w+1)+w = w²+2w < (w+1)²、
U: N = w(n+1)+h+1 ≤ w(w+1)+(w−1)+1 = w²+2w < (w+1)²
なので spf(N) < w+1、すなわち spf(N) ≤ w。n=w のとき spf ≤ n。
n=w−1 のとき spf=w は不可能: V は N=w²+h（1≤h≤w−1）で w∤h、
U は N=w²+h+1（0≤h≤w−2）で w∤(h+1)。よって spf ≤ w−1 = n。
いずれの場合も spf(N) ≤ n であり、spf | N なので、円サイズが
n から spf まで降りる途中（k ≥ spf ≥ 2）に必ず k|N のフェーズが現れる。
監視はそのフェーズ（遅くとも k=spf）で死ぬ。∎

機械アンカー: FAMILY（iff・7,198状態・違反0）。

## 5. 定理SIEVE-PRIME（K0937予想の証明・全称）

**定理.** N=2m+1 が素数なら V(m)=0。N=2m+3 が素数なら U(m)=m−1。

**証明.** N素数とする。K0937 INV-TRACK により、ladder での監視死亡は
死亡合同式「stretch幅 w+1 で (w+1)|N」と同値だが、N素数の約数は 1・N で
w+1 ≥ 3 なので w+1=N しかない。しかし t≥1 の stretch では n ≥ w+1 = N となり
T恒等式（T=wn+h+w）と矛盾する（w ≥ 2 より wN ≥ 2N > N > N−1 = T）。
よって監視は全 ladder stretch を生存し、tracker は t=0 エンドゲームに
到達する（K0937 証明済み部分）。ENTRY-LOC により入口は family 状態で、
END-SIEVE-IFF の素数方向により監視はエンドゲームを生存する。
生存者は監視なので V(m)=0・U(m)=m−1。∎

（機械側でも、素数 m≤200,000 両側67,716ゲームすべてで tracker が
死亡・collapse・window出口なしのエンドゲーム到達で終わることが確認されている。）

## 6. 双子法則の全称完結（LAW1/LAW2）

**定理LAW1.** すべての C ≥ 2: **P(C)=1 ⟺ C 素数**。
**定理LAW2.** すべての C ≥ 2: **P(C)=C−1 ⟺ C+1 素数**。

**証明.** K0928 の系（偶数C≥4: P(C)≥3、奇数C≥3: P(C)≤C−2）と
定理RED（P(2m+1)=1+2V(m)、P(2m+2)=3+2U(m)）に帰着する。

LAW1: C=2 は P(2)=1（ピン）。偶数C≥4 は両側不成立（P≥3 かつ C 非素数）。
奇数C=2m+1≥3 は P(C)=1 ⟺ V(m)=0 ⟺ N=2m+1=C 素数
（⟸ SIEVE-PRIME・⟹ は対偶: C合成なら K0937 SIEVE-COMPOSITE-GEN で
監視が死に V(m)≠0）。

LAW2: C=2 は P(2)=1=C−1・C+1=3 素数（ピン）。奇数C≥3 は両側不成立
（P≤C−2 かつ C+1≥4 偶数で合成）。偶数C=2m+2≥4 は
P(C)=C−1 ⟺ 3+2U(m)=2m+1 ⟺ U(m)=m−1 ⟺ N=2m+3=C+1 素数
（⟸ SIEVE-PRIME・⟹ は K0937 合成側）。

C=1 は両法則の外（P(1)=1 だが1は素数でない）。

**系（K0931 SIEVE予想の全称決着）.** K0931のSIEVE予想（合成Nでは
監視は保持 spf(N)（V）/ spf(N)−1（U）で stretch spf(N)−1 に死亡、
素数Nでは生存し V(m)=0/U(m)=m−1）の素数側が証明され、予想全体が
全称定理となった。K0929のLAW1/LAW2（予想）も含め、
「P(C)=1 ⟺ C素数」「P(C)=C−1 ⟺ C+1素数」（C≥2）は mod類制限なしの
全称定理である。∎

## 8. 範囲と限界

- すべて一様盤・ゼロリセット・K0859計数再帰（K0928定理RED経由）の設定。
  非一様盤・11×11空盤・二石root {49,60}/{59,60}・S2 {59,60}・class1/2/4には
  一切言及しない（**UNKNOWN不変**）。
- ENTRY-LOCは「監視が ladder を生存した場合」の入口位置の定理である。
  family外のエンドゲーム状態（一般の (P;α,β) 以外の円）が他の経路で
  現れる可能性は排除しない（END-INV は入口が family 状態である限りを主張）。
  END-SIEVE-IFF は family 状態上の判定として正当に適用されている。
- P(C) の閉形式（C→P(C) の直接式）は主張しない。本項は素数性との
