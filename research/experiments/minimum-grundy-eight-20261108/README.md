# 値8/9の最少点数と、値2〜9の点数・辺数最適表

純三点禁止族で両値8/9の最少合法点数は10/11。
八辺の点数最小証人と整数座標盤を`verify.py --pruned`で検査する。
全七辺以下の核表と点数下界を組み合わせ、任意点数・辺数についてのPareto前線を確定した。
`catalog_both.py`で集計し、全前線証人を別の残余再帰でも照合する。
証明は[proof.md](proof.md)、完全表は`output/pareto_both.json`、現行知識はK0699。

## 発見時の有界探索

K0690からg8には少なくとも十合法点が必要。
十点のg8局面は最大安全追加数が八以上なので、禁止族に二点以下の頂点被覆がある。
この必要条件を使い、固定被覆{0,1}に交わる三点/四点辺などを標本探索する。
不発見を不存在や最少点数の証明とは扱わない。

`search.cpp`をC++17でコンパイルし、点数・最小rank・最大rank・被覆サイズ・標本上限・目標gを渡す。
初期合法点は全n点。rank混在の冗長辺はゲーム値に影響しないが、達成例の検査時に極小化する。
rank四以上の抽象族を標準共円盤に移せるとは仮定しない。
