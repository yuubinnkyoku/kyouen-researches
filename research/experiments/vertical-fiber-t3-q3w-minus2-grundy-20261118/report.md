# t=3・q=3w−2純ファイバーゲームの全Grundy分類

## 定理

ファイバー数を \(w\ge1\)、各ファイバーの高さを \(m\ge1\)、次数閾値を \(t=3\)、禁止点数を
\[
q=3w-2
\]
とする。占有ベクトル \(c=(c_1,\ldots,c_w)\) の安全条件は
\[
\sum_{i=1}^{w}\min(c_i,3)\le 3w-3
\]
である。以下、底面跡制約のない純ファイバーゲームを扱う。

### \(m\ge3\) の全局面公式

飽和ファイバー集合を \(S=\{i:c_i\ge3\}\) とし、
\[
X=\bigoplus_{i\in S}((m-c_i)\bmod2)
\]
と置く。また \(e_j=\#\{i:c_i=j\}\)（\(j=0,1,2\)）および
\[
L=3e_0+2e_1+e_2
\]
を定める。安全性はちょうど \(L\ge3\) と同値である。

このとき
\[
\boxed{G(c)=X\oplus H(e_0,e_1,e_2)}
\]
であり、残余値 \(H\) は次の閉形式で決まる。

- \(m\) が奇数：
\[
\boxed{H(e_0,e_1,e_2)=(L-3)\bmod2.}
\]

- \(m\) が偶数：\(L\ge3\) のもとで
\[
\boxed{
H(e_0,e_1,e_2)=
\begin{cases}
2,&(e_0\ge1\land e_2=e_0)\ \lor\ (e_0=0\land e_2=2),\\
(e_1+1)\bmod2,&e_0=0\land e_2\le1,\\
0,&(e_0,e_1,e_2)=(1,0,0),\\
(e_1+\mathbf1_{e_2<e_0})\bmod2,&\text{それ以外}.
\end{cases}}
\]

したがって、偶数高さで残余値2となる場所は、\(e_2=e_0\ge1\) または \((e_0,e_2)=(0,2)\) に限られる。

### \(m=1,2\)

小さい高さは次の通り。

- \(m=1\)：\(w=1\) では安全局面は空配置だけで \(G=0\)。\(w\ge2\) では全配置が安全で
\[
G(c)=(w-\sum_i c_i)\bmod2.
\]
- \(m=2\)：\(w=1\) では空配置だけで \(G=0\)。\(w=2\) では安全条件 \(\sum_i c_i\le3\) のもとで
\[
G(c)=(3-\sum_i c_i)\bmod2.
\]
\(w\ge3\) では全配置が安全で、独立二段鎖の直和となり
\[
G(c)=\bigoplus_i((2-c_i)\bmod2).
\]

## 証明

### 飽和鎖の分離

\(c_i\ge3\) のファイバーでは、占有数を1増やしても \(\min(c_i,3)\) は変わらない。そのファイバーは残り \(m-c_i\) 手の単独鎖であり、Grundy値は \((m-c_i)\bmod2\)。従って、これらをXORで分離できる。

未飽和ファイバーは占有数0,1,2の三種類だけである。飽和ファイバー数を \(s\)、未飽和ファイバー数を \(n=e_0+e_1+e_2\) とすると、
\[
\sum_i\min(c_i,3)=3s+e_1+2e_2
\]
なので、安全条件は
\[
3n-e_1-2e_2=3e_0+2e_1+e_2=L\ge3
\]
となる。未飽和ファイバーの手は \(0\to1\)、\(1\to2\)、\(2\to3\) の三種類で、いずれも \(L\) を1減らす。\(L=3\) が終局である。

\(2\to3\) の手は残り \(m-3\) 手の鎖を新たに生む。そのGrundy値は
\[
z=(m-3)\bmod2
\]
である。よって残余ゲームの再帰は
\[
\begin{aligned}
H_z(e_0,e_1,e_2)=\operatorname{mex}\{&
H_z(e_0-1,e_1+1,e_2) \quad(e_0>0),\\
&H_z(e_0,e_1-1,e_2+1) \quad(e_1>0),\\
&z\oplus H_z(e_0,e_1,e_2-1) \quad(e_2>0)\}.
\end{aligned}
\]
終局 \(L=3\) では \(H_z=0\)。

### 奇数高さ

\(m\) が奇数なら \(z=0\)。残余ゲームの全ての終局は、どの手順を選んでもちょうど \(L-3\) 手後に現れる。残り手数に関する帰納法で
\[
H_0=(L-3)\bmod2
\]
を得る。

### 偶数高さ

\(m\) が偶数なら \(z=1\)。\(p=e_1\bmod2\)、\(d=e_2-e_0\) と置く。次表は、帰納仮説を三つの遷移へ代入したときの親値と、合法な子のGrundy値集合である。終局行の子集合は空集合を表す。

| 条件 | 親値 \(H_1\) | 子値集合 |
|---|---:|---|
| \(e_0=0,e_2=0\) | \(1-p\) | \(\{p\}\) |
| \(e_0=0,e_2=1,e_1=1\) | 0 | \(\varnothing\) |
| \(e_0=0,e_2=1,e_1\ge2\) | \(1-p\) | \(\{p,2\}\) |
| \(e_0=0,e_2=2\) | 2 | \(\{0,1\}\) |
| \(e_0=0,e_2=3,e_1=0\) | 0 | \(\varnothing\) |
| \(e_0=0,e_2=3,e_1\ge1\) | \(p\) | \(\{1-p,3\}\) |
| \(e_0=0,e_2\ge4\) | \(p\) | \(\{1-p\}\) |
| \(e_0=1,e_2=0,e_1=0\) | 0 | \(\varnothing\) |
| \(e_0=1,e_2=0,e_1\ge1\) | \(1-p\) | \(\{p,2\}\) |
| \(e_0=1,e_2=1\) | 2 | \(\{0,1\}\) |
| \(e_0=1,e_2=2,e_1=0\) | 0 | \(\{2,3\}\) |
| \(e_0=1,e_2=2,e_1\ge1\) | \(p\) | \(\{1-p,2,3\}\) |
| \(e_0=1,e_2\ge3\) | \(p\) | \(\{1-p\}\) |
| \(e_0\ge2,d\le-2\) | \(1-p\) | \(\{p\}\) |
| \(e_0\ge2,d=-1\) | \(1-p\) | \(\{p,2\}\) |
| \(e_0\ge2,d=0\) | 2 | \(\{0,1\}\) |
| \(e_0\ge2,d=1\) | \(p\) | \(\{1-p,3\}\) |
| \(e_0\ge2,d\ge2\) | \(p\) | \(\{1-p\}\) |

\(L=3\) の終局は \((1,0,0),(0,1,1),(0,0,3)\) の三状態で、表に明記した。表の残りの行は \(L>3\) を満たす。

表から、親値0の行では子集合に0がなく、親値1の行では0を含むが1を含まず、親値2の行では子集合がちょうど \(\{0,1\}\) である。従って各行で親値は子値集合のmexに一致する。これは \(L\) に関する強帰納法を閉じ、偶数高さの閉形式を証明する。

以上と飽和鎖のXOR分離から全安全局面の公式が従う。

## 最大Grundy値の系

この分類から、最大値は
\[
\max G=
\begin{cases}
0,&w=1,\\
1,&w\ge2\text{ かつ }(m\text{ が奇数または }m\le2),\\
2,&w=2,\ m\ge4\text{ 偶数},\\
3,&w\ge3,\ m\ge4\text{ 偶数}.
\end{cases}
\]
となる。

\(w=2,m\ge4\) 偶数では \(c=(0,2)\) が値2を実現する。上界について、\(H=2\) の条件は少なくとも二本の未飽和ファイバーを要する。\(w=2\) で飽和ファイバーが一つでもあれば未飽和ファイバーは一本以下なので \(H\le1\) となり、\(X\le1\) と合わせても \(G\le1\)。従って \(H=2\) の場合は飽和ファイバーがなく \(X=0\) で、\(G\le2\)。\(w\ge3,m\ge4\) 偶数では
\[
c=(0,2,3,m,\ldots,m)
\]
が値3を実現する。一般上界は \(H\le2\) と \(X\le1\) から従う。これはK0832の全次数最大値定理と一致するが、本定理は最大値だけでなく全局面を分類する。

## 独立有限監査

検証器は、偶数・奇数それぞれの残余mex再帰と閉形式を \(0\le e_0,e_1,e_2\le32\) の全安全状態で照合した。さらに、盤面側では \(1\le w\le5,\ 1\le m\le7\) の全安全占有ベクトルを、ラベル付き直接再帰と正準多重集合直接再帰の二方式で計算し、閉形式と照合した。

| 検査 | 件数 | 不一致 |
|---|---:|---:|
| 偶数高さの残余mex対閉形式 | 35,933 | 0 |
| 奇数高さの残余mex対閉形式 | 35,933 | 0 |
| 盤面二方式直接再帰対閉形式 | 51,756 | 0 |
| **合計** | **123,622** | **0** |

二回の完全実行で監査結果はバイト単位で一致した。監査JSONの sha256_without_hash_field は d0fdb8de909ce6f6901bd98c789389a5e7d69d078102d9681cb72d7847a77656。

有限監査は全称証明の代わりではない。全称性の根拠は飽和鎖分離、残余mex再帰、上の全場合表、強帰納法である。

## 適用範囲と限界

本定理は底面跡制約のない純ファイバーゲームに限る。底面係数次数制限付きの部分族、標準二次元共円ゲームの固定幅・q点版の安定化長、複数人対戦への拡張は扱わない。
