# z=6,y=9の2トークン残余スライスを全称証明

- 日付: 2026-11-17
- 作業開始時のmain: a8ff1d814a64565491a8527a7489b97952ec9514
- 対象: \(H(R;(x,9);6)\)、全 \(x\ge9,\ R\ge0\)
- 状態: 全称定理。有限監査だけによる外挿ではない。

## 定理

\(E[a,b]\)を区間内の偶数、\(O[a,b]\)を奇数、\(I[a,\infty)\)をa以上の全整数とする。値2位置は
\[
T_9(x)=\{1,3,5\}\cup
\begin{cases}
\{21\},&x=9,\\
\{23\},&x=13,\\
\{25,27,29,31\},&x=16,\\
\{25\},&x\ge17,\\
\varnothing,&x\in\{10,11,12,14,15\}.
\end{cases}
\]
値1位置は
\[
P_9(x)=
\begin{cases}
O[7,19],&x=9,\\
O[7,25]\cup I[22,\infty),&x=10,\\
O[7,21],&x=11,\\
O[7,27]\cup I[24,\infty),&x=12,\\
O[7,21],&x=13,\\
O[7,29]\cup I[24,\infty),&x=14,\\
O[7,23],&x=15,\\
O[7,23]\cup E[26,30]\cup I[32,\infty),&x=16,\\
O[7,23]\cup E[26,32],&x=17,\\
O[7,23]\cup E[26,x+14]\cup I[x+16,\infty),&x\ge18\text{ 偶数},\\
O[7,23]\cup E[26,x+15],&x\ge19\text{ 奇数}.
\end{cases}
\]
従って全ての \(x\ge9,R\ge0\) について
\[
H(R;(x,9);6)=
\begin{cases}
2,&R\in T_9(x),\\
1,&R\in P_9(x),\\
0,&\text{それ以外}.
\end{cases}
\]

## 証明

\(R=0\)は終局。\(R\ge1\)の選択肢は
\[
\begin{aligned}
A&=H(R-1;(x-1,9);6),\\
B&=H(R-1;(x,8);6),\\
C&=1\oplus H(R-1;(x,9);5).
\end{aligned}
\]
\(x=9\)ではA/Bは同じ \((9,8)\) 子に合流する。\(x\ge10\)ではAはRに関する強帰納仮説、BはK0888、CはK0873で評価できる。

K0832のTheorem Tより、奇数Rの親では選択肢値は0/1だけ、偶数Rの親のGrundy値は高々1である。したがって奇数Rでは選択肢集合が \(\{0,1\}\) ならmex=2、\(\{0\}\) ならmex=1、\(\{1\}\) ならmex=0。偶数Rでは選択肢集合に0が含まれる場合に限り値1となる。

次の表はtailより手前の全 \(1\le R<x+16\) を覆う。各区間は両端を含み、偶奇ごとに2刻みで読む。例えば「22:{0,2,3}」はR=22での選択肢Grundy値集合を表す。

最後の行では \(U=x+15\) if x is even, otherwise \(x+14\)、\(V=x+14\) if x is even, otherwise \(x+15\)。この定常行を得る代入を明示する。\(1\le R<x+16\) で、
\[
A=
\begin{cases}
2,&R\in\{2,4,6,26\},\\
1,&R\in E[8,24]\cup O[27,U],\\
0,&\text{otherwise},
\end{cases}
\quad
B=
\begin{cases}
2,&R\in\{2,4,6,24\},\\
1,&R\in E[8,22]\cup O[25,U],\\
0,&\text{otherwise},
\end{cases}
\]
\[
C=
\begin{cases}
3,&R\in\{2,4,6,24\},\\
0,&R\in O[7,23]\cup E[26,V],\\
1,&\text{otherwise}.
\end{cases}
\]
これはAへ帰納仮説（\(x=18\)では過渡式x=17）、BへK0888、CへK0873を代入したもの。例えばAの値2は子の値2位置{1,3,5,25}をRだけ1つ戻した点、B/Cの値2/3はそれぞれ子の値2位置を同様に1つ戻した点である。値1区間は各アンカーの値1区間を1つ戻し、端点を比較すれば上式となる。これら3式の値集合を併合すると最後の行の奇数・偶数署名表が得られる。

一般tail定理
\[
R\ge S+|X|+z-1\Longrightarrow H(R;X;z)=S\bmod2
\]
に \(S=x+9,\ |X|=2,\ z=6\) を代入すると
\[
R\ge x+16\Longrightarrow H(R;(x,9);6)=(x+9)\bmod2.
\]
よって署名表とtailが全Rを覆い、R強帰納が閉じる。□

## 3族値2位置予想との一致

K0832の3族予想をz=6,y=9に特殊化すると、基本ラダー{1,3,5}に加え、d=x−9=0で21、d=4で23、d=7で25,27,29,31、d≥8で25となる。これは上の全称分類と一致する。今回証明したのはこの切片だけであり、3族予想全体の証明ではない。
