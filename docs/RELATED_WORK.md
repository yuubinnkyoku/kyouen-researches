# 関連研究と本リポジトリの位置づけ

最終確認: 2026-09-23

この文書は、共円ゲームに関して公開されている関連研究のうち、本リポジトリの結果と特に近いものを整理したメモです。網羅的な文献レビューではありません。したがって、以下では「世界初」などの断定は行わず、確認できた公開資料の範囲で位置づけます。

## 1. 岩澤佑樹「共円ゲームのゲーム木探索」（2025年度卒業研究）

神奈川大学・木下佳樹研究室の2025年度卒業研究として公開されている研究です。

- 2人対戦に限定し、共円・共線を客観的に自動判定するルールを採用
- 4点の共円・共線判定に整数行列式を使用
- ゲーム木の完全探索と、勝敗が確定した場合に限定した枝刈り探索を比較
- 3×3〜6×6について勝敗を計算
  - 3×3: 先手必勝
  - 4×4: 後手必勝
  - 5×5: 先手必勝
  - 6×6: 先手必勝
- 7×7以上は計算量の制約により結果を得られず、対称性の利用などを今後の課題としている

この3×3〜6×6の結果は、本リポジトリの分類と一致します。そのため、この研究は先行研究であると同時に、小盤面についての独立な外部クロスチェックにもなっています。

## 2. Math Festa 2024「数学ゲーム『共円』」

Math Festa 2024の要旨集には、Pythonで全局面を出力し、P型/N型判定を用いて共円ゲームを解析した研究が掲載されています。

要旨では、6×6までについて「全ての局面でどれが適切な手かは解析してわかった」とされています。したがって、6×6までの完全探索は少なくとも別系列でも行われていたことが確認できます。

資料:

- Math Festa 2024 要旨集「数学ゲーム『共円』」  
  https://otemae-hs.ed.jp/ssh/dat/2024mathfesta_abstract.pdf

## 3. 山本一揮・平原秀一「共円ゲームの必勝判定」

山本一揮氏は平原秀一氏の指導のもと、共円ゲームの必勝判定問題の計算量を研究しています。

2024年の情報処理学会第86回全国大会では、共円ゲームの必勝判定の計算量クラスを調べる研究が報告されています。続く研究では、追加ルールを課した変種についてPSPACE完全性を示し、その追加ルールを外した元の共円ゲームへ証明を拡張することを目標として研究が進められています。2025年には第19回組合せゲーム・パズル研究集会でも「共円ゲームの必勝判定」が発表されています。

この系列は、特定の有限な n×n 盤面を完全分類する本リポジトリとは方向が異なり、一般の必勝判定問題の計算量を扱う研究です。

## 4. 本リポジトリとの違い

本リポジトリでは、完全指摘ルールの n×n 共円ゲームについて、

- 1×1〜9×9の最適プレイ勝敗を完全分類
- 7×7・8×8・9×9まで分類範囲を拡張
- 9×9では全81初手が先手勝ちであることも個別に確認
- 各盤面の勝敗を順位付きAND/OR証明書として保存
- 探索器とは別の検査器で、危険4点組・合法手・証明書の局所条件を再生成して検査
- Leanで、証明書の局所条件から通常プレイの勝敗が従う一般健全性定理を形式化

という形で、単なる探索結果ではなく、第三者が再検証できる計算機援用証明として結果を残しています。

特に岩澤氏の研究が3×3〜6×6で止まり、7×7以上を今後の課題としていることから、本リポジトリの7×7〜9×9の完全分類は、既存の公開研究から自然に続く計算的な拡張として位置づけられます。

## 5. 新規性についての慎重な表現

2026-09-23時点で確認できた公開資料の範囲では、

> 7×7〜9×9について、完全指摘ルール下の最適プレイ勝敗を完全分類し、さらに独立検証可能な証明書まで公開した先行成果は確認できていません。

ただし、これは網羅的な先行研究調査を完了したことを意味しません。論文データベースに収録されていない研究、学校・部誌・研究会資料、未公開成果などが存在する可能性があります。そのため、本リポジトリでは現時点で「世界初」とは主張しません。

今後、論文・発表等で新規性を明示する場合は、追加の文献調査を行ったうえで表現を更新します。
