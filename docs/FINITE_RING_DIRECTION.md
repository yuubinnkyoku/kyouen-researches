# 共円ゲーム研究を新しい方向へ拡張する：座標環を変えるという軸

2026-11-20。研究提案と実証記録。
既存研究（K0001〜K1057、約1,030項目）が実数平面上の**図形**を変えてきたのに対し、
本提案は**座標環そのもの**を変える軸を導入する。実証として K1058 の有限結果を得た。

## 1. 既存研究の構造と、空いている軸

現在の研究は次の問いに集中している。

- 標準 n×n 盤の勝敗・Grundy（n≤10 解決、[K0023](../research/knowledge/items/K0023-n11-exact-safe-layers-and-unknown-winner.md)、n=11 未決 [K0105](../research/knowledge/items/K0105-n11-empty-root-winner-open.md)）
- 固定幅長方形の一般定理（[K0024](../research/knowledge/items/K0024-fixed-width-q-point-threshold.md)、[K0068](../research/knowledge/items/K0068-standard-fixed-width-parity-threshold.md) ほか）
- 図形変種（共面・共球・二次曲線・多項式持ち上げ、[K0504](../research/knowledge/items/K0504-geometric-rule-variant-comparison.md)）
- 最大・極大配置、再配置、証明書、探索方式

これらはすべて**盤の点は実数平面上の格子点**であり、変えているのは禁止図形か盤の形である。
空いている軸は「**座標をどの環で読むか**」である。

禁止条件は四点に対する行列式

```
Delta = det[[x_i, y_i, x_i^2+y_i^2, 1]] = 0
```

であり、これは任意の可換環で意味を持つ。したがって盤を `F_q²` や反転平面に取り替えても
**同じ規則**が定義できる。図形をいじるのではなく、座標環をいじるのである。

## 2. 実証：分かったこと

詳細は [K1058](../research/knowledge/items/K1058-finite-field-and-inversive-plane-boards.md) と
`research/experiments/finite-field-kyouen-20261120/` にある。要点だけ記す。

### 2.1 有限体盤は q mod 4 で別ゲームになる

AG(2,q) 上では `x²+y²` の等方性が q mod 4 で切り替わる。

- **q ≡ 3 (mod 4)**：非等方。全円がちょうど q+1 点。ユークリッド円の忠実な類似。
- **q ≡ 1 (mod 4)**：`(x+iy)(x−iy)` と分解。円が直線対に退化する。

したがって「有限体版」は単一の族ではない。変種を比較するときは q mod 4 を明記する必要がある。

### 2.2 整数盤から有限体盤への転送は閾値付きでのみ成立する

素朴な期待「整数安全集合を mod q 還元すると有限体でも安全」は**偽**だった
（n=5, q=5 で 151,394 個中 122,168 個が反例）。

正しい形は閾値定理である。`D(n) = max |Delta|` とすると、**q > D(n) のときだけ**
`Delta ≡ 0 (mod q)` と `Delta = 0` が同値になる。

観測された閉形式は `D(n) = (n−1)²⌊(n−1)²/2⌋`（n≤7 で全数一致、a≤30 で族内厳密一致）。
この値は n について4次で増えるので、11×11 を埋め込むには q > 7,260 が必要になる。
**有限体盤は整数格子の近似としては使えない**——これは重要な否定的結論である。

### 2.3 反転平面盤は q mod 4 依存を解消する

「相異なる三点がちょうど一つの円を定める」を公理とした有限構造が反転平面で、
位数 q のそれは 3-(q²+1, q+1, 1) 設計である。古典模型 `P¹(F_{q²})` は全素数冪で存在する。

q=3,5 で 3-設計公理を全数機械検査し（点 10/26、円 30/130、未被覆三点 0）、
全安全局面の Grundy を完全計算した（428/47,152 局面、K=5/6、いずれも先手必勝）。

さらに層サイズの厳密公式を k≤5 で証明した：

```
L_k = C(n,k) − b · Σ_{j=4}^{min(k,s)} C(s,j) C(n−s, k−j)
```

二円がともに4点以上を持つには 6 点必要（二円は高々2点で交わる）ため、k≤5 で事象が互いに素になる。
k=6 では破綻する（q=5 で厳密値 5,200 に対し公式 −156,000）。

### 2.4 トーラス盤は素数位数で AG(2,p) と完全一致する

周期境界を課した `Z_n²` で同じ行列式を mod n で評価すると、**n が素数のとき
禁止四点集合が AG(2,n) と完全に同一**になる（n=3,5,7,11,13 で全数照合）。
`Z_p = F_p` からほぼ直ちに従うが、これは有限体盤が特殊な構成物ではなく
自然な盤の変種と一致することを示す。

n=4（合成数）では一致せず、トーラス盤に 228 個の余分な禁止四点が生じ、
**勝者が後手必勝から先手必勝へ反転する**（K=7 → K=4）。
禁止四点を増やすと勝者が変わる明示例である。

### 2.5 初手値の分布は3型に限られた

完全計算できた盤では、初手の値の分布は「全初手勝ち」「全初手負け」「部分勝ち」の3型のみ。

5×5 だけが部分勝ち（9/25）で、勝ち初手は中心菱形を成す：

```
W = { (x,y) : x+y ≡ 0 (mod 2) かつ |x−2|+|y−2| ≤ 2 }
```

25 点全数で照合し不一致 0。負け初手 16 個はすべて Grundy 値 3。

## 3. この方向が有望な理由

1. **規則を変えずに盤を変えられる**。`Delta` は同じ多項式で、環を替えるだけ。
   図形変種（K0504）とは独立な軸であり、両者を組み合わせられる。
2. **既存の数論的手法と直結する**。研究は既に mod 9・mod 16・p 進的手法を多用している
   （K0072、K0367、K0176 など）。有限体盤はその極端な場合であり、
   「なぜ合同式が効くのか」の構造的理解を与える。
3. **否定的結論も価値がある**。転送閾値が4次で増えるため、有限体盤は整数盤の
   近似には使えない。これを定量的に示したことで、無駄な試行を防げる。
4. **反転平面は理論的に整っている**。3-設計という強い公理系のおかげで
   層サイズが閉形式で書け、k≤5 で厳密証明できた。これは整数格子では望めない構造である。

## 4. その後の進展（2026-11-20 追記）

初版の「次にやるべきこと」のうち 3 つを実行した。

1. **反転平面 q=7 の K を厳密決定**：K=6。サイズ7の安全集合が存在しないことを
   完全探索（255万ノード）で証明。数え上げ上界13との差7は、円が8点と大きいことの効果。
2. **素数冪への拡張を完了**：`F_{q²}=F_p[t]/(f)` と Frobenius 固定体 `F_q={x:x^q=x}` により
   標数2を含む全素数冪を扱えるようにした。q=3..9 で 3-設計を検証。
   円の列挙は「`P¹(F_q)` の PGL(2) 軌道」を BFS で生成（生成元の拡大は原始元を選ぶ必要がある）。
3. **`D(n)` を n≤12 まで全数確認**：三点分解（余因子展開）により、
   四点組全列挙の限界 n≤7 を突破した。全称証明は依然未完成。

追加で得た結果：

- **AG(2,q) と反転平面の K が q≤7 で一致**（5, 6, 6）。点数はほぼ同じだがブロック構造は
  大きく異なるのに最大安全サイズが一致する。偶然か構造的かは未解明。
- **層サイズ公式を q=3,4,5 で検証**：k≤5 で完全一致、k=6 で破綻。
  破綻点が補題の境界（二円が同時に4点以上を持つには6点必要）と正確に一致。
- **misère が通常版の勝敗を完全に反転**（4例すべて）。反転平面では全極大が同石数の
  可能性が高く、そうなら手番数固定から反転が従う。
- **5×5 の勝ち初手は D4 軌道で完全に説明できる**：6軌道がそれぞれ勝ち/負けに揃い、
  勝ち軌道の和が中心菱形。1点あたりの禁止四点数は勝敗と単調でない（最多156が勝ち、最少100が負け）。

## 5. 次にやるべきこと（更新後）

1. **`D(n)` の全称証明**。計算は n≤12 まで済み。残るは「三隅＋対角点の族以外が
   上回らない」ことの証明で、円のべき（power）の評価が鍵。
2. **AG(2,q) と反転平面の K の一致が構造的か**の判定。q=8,9 で両者を計算すれば
   反例が見つかるかもしれない。
3. **q=8,9 の K**。現在は上界のみ（K≤15, K≤17）。
4. **K0504 の他変種との合成**。例えば「有限体盤 × 二次形式パラメータ λ」は未開拓。

## 6. 限界

- 本提案は「座標環を変える」という一つの軸の提案であり、既存研究の代替ではない。
- K1058 の結果は q≤7（K）、q≤5（Grundy）、n≤12（D(n)）、p≤13（トーラス一致）に限る。
- `D(n)` の閉形式は n≤12 で全数確認済みだが全称証明されていない。
- 有限体盤・反転平面盤の勝敗が整数格子盤の勝敗とどう関係するかは、
  閾値 `q > D(n)` の外側では何も分かっていない。
