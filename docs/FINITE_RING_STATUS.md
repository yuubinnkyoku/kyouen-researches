## 0. 最重要：`τ₃ = q−1` の証明（新）

反転平面の共円ゲームを **3-ネットの部分横断問題**に翻訳し、
横断数 `τ₃` を**完全に決定した**。

```
τ₃(q) = q − 1   （q 奇数）
τ₃(q) = q       （q 偶数）
```

**証明の骨格**（奇数 q）：

1. 3-ネットのラテン方陣は `c = (d − ab)/(a − b)`（`d` は非平方）。
2. `A = 1/a` と置くと関係式は `A = (S + T)/(1 + d·S·T)`、
   すなわち**ノルム1トーラス** `T_d`（位数 `q+1` の巡回群）の群法則。
3. `A ↦ (A + w)/(A − w)` は `P¹(F_q) → T_d` の**全単射**。
4. 指数座標で関係式は `τ = α − σ (mod q+1)` と**線形**になる。
5. よって横断とは「全単射 `σ: Z_{q+1} → Z_{q+1}` で `α ↦ α − σ(α)` も
   全単射」、すなわち **`Z_{q+1}` の完全写像**。
6. `q` 奇数なら `q+1` は偶数。`Z_{q+1}` の Sylow 2-部分群は位数 `≥2` の
   巡回群なので、**Hall–Paige の定理（1955）**により完全写像は存在しない。 □

**系（新しい上界）**：

```
K(inversive q) ≤ q + 2      （すべての奇数 q）
```

従来 `q+2` は `q ≡ 1 (mod 4)` でのみ（十字ブロック経由で）得られていた。
3-ネット経由の議論は `q mod 4` に依存しない。

**検証**：q = 3,5,7,9,11,13,17,19,23,29 の修正済み厳密値すべてで `K ≤ q+2`。

## 0c. 高速な反転平面構成（新）

楕円二次曲面（ovoid）模型により `O(q⁵)` → `O(q³)`：

```
Q(x₀,x₁,x₂,x₃) = x₀² + x₁² + x₂² + d·x₃²      （d は非平方）
```

`Q = 0` の零点集合が `PG(3,q)` の ovoid（`q²+1` 点）、
その `q+1` 点平面切断が円。**q=11 が 2,400 秒 → 5 秒。**
q ≤ 11 で 3-設計公理を検証済み。

## 1. 確立した結果（証明済み）

### 1.1 補題：gamma = −2·Area

三点 `p1,p2,p3` に対し、4×4 行列式の `x²+y²` の係数 `gamma` は

```
gamma = −2 · Area(p1,p2,p3)
```

**証明**：余因子展開で `gamma = −det[[x_i,y_i,1]]`、この 3×3 行列式は符号付き面積の2倍。□

**系**：三点が `[0,a]²` 内なら `|gamma| ≤ a²`。

### 1.2 層サイズ公式（k ≤ 5）

反転平面（3-(q²+1,q+1,1) 設計）で、安全 k-集合の数は k ≤ 5 で

```
L_k = C(n,k) − b · Σ_{j=4}^{min(k,s)} C(s,j) C(n−s, k−j)
```

**証明**：二円は高々2点で交わるので、二つの「4点以上」事象が共存するには6点必要。
よって k ≤ 5 で事象は互素。□

q=3,4,5 で完全一致、k=6 で破綻することを確認済み。

### 1.3 トーラス盤と AG(2,p) の一致

`Z_p = F_p` より、素数位数のトーラス盤はアフィン平面盤と禁止集合が同一。□
（p ≤ 13 で全数確認）

### 1.4 一般 Steiner 3-設計の三分法

| | `s ≤ 3` | `s = 4` | `s ≥ 5` |
|---|---|---|---|
| **`t ≥ 4`** | `K = 3` | `K = 3` | `K = 3` |
| **`t = 3`** | `K = v` | `K = v − τ` | **新しい不変量** |
| **`t = 2`** | `K = v` | `K = v − τ` | `(k,3)`-アーク |

**自明化定理**：`t ≥ 4` なら任意の4点が同一ブロック上にあるので `K = 3`。□

**一般上界**：`K ≤ λ₂ + 2`、`λ₂ = (v−2)/(s−2)`。□
**一般下界**：`v − k ≤ C(k,3)(s−3)`、すなわち `K = Ω((v/s)^(1/3))`。□

9つの Steiner 設計で検証済み。

### 1.5 派生設計による上界

`D` を `3-(v,s,1)` 設計、`S` を安全集合、`p ∈ S` とすると、
`S\{p}` は派生設計 `D_p`（線形空間）の2-アーク。よって

```
K(D) ≤ 1 + A₂(D_p)
```

これは `λ₂` 上界を含む（より強い）。□

古典的事実：反転平面 `q` を派生すると `AG(2,q)`、Witt `S(3,6,22)` を
派生すると `PG(2,4)`。

### 1.6 ブロッキング下界

極大安全集合 `S`（`|S| = k`）について

```
v − k ≤ C(k,3)·(s − 3)
```

反転平面では `K = Ω(q^(1/3))`。□

| **ambient `m(3,q)=q+1`** | `k ≤ q+1`（全 q≥4） | **6** | **8** | **10** | **14** | **30** |
| **K1252 の主定理** | **`k ≤ q`（全 q≥7、無条件）** | — | **6** | **9** | **13** | **29** |
| 下界（Sonnino） | `(q+5)/2` | 5 | 6 | 7 | 9 | 17 |
| ブロッキング下界 | `k ≥ (6q)^(1/3)` | 3 | 3 | 4 | 4 | 6 |
| **検証済みの下界／厳密値** | | **6** | **6** | **9** | **10** | **20** |

**現在の最良無条件上界**：**`K ≤ q`（すべての q≥7、無条件で証明済み）**。
奇数は NRC を通る二次曲面の行列式が平方であることから、偶数は Casse–Glynn の分類定理と
族の同値変形から。さらに全 q≥4 で ambient な `K ≤ q+1`。
下界は `(q+5)/2 ≤ K`（Sonnino 1999）と探索による上積み（K1251）。
**文献には反転平面の弧の上界が存在しない**（2026-11-23 の調査、K1251 の文献節）。

### 2.5 アーク問題の現在地（K1250–K1253）

反転平面の弧（どの4点も同一円上にない点集合）の最大サイズ `K(q)` について、
2026-11-23 時点の到達点。

**定式化（K1250）**：`z ↦ (1:z:z^q:z^{q+1})` で `M(q)` の点を楕円二次曲面
`Q⁻(3,q) ⊂ PG(3,q)` に写すと、**円＝切断平面**、**共円＝同一平面上**になる。したがって
「弧＝`Q⁻` 上の一般位置集合」で、これは `[k,4,k−3]` MDS 符号の列集合と同値（K1250）。
`M_4(q)`（4次元 MDS 符号の最大長）の測定値：`M_4 ≥ 5,5,6,8,9,10,12,14`（q=3..13）。

**上界（K1252）**：

```
(q+5)/2 ≤ K(q) ≤ q      （q 奇数、q ≥ 9、無条件）
K(q) ≤ q+1              （すべての q ≥ 4、無条件）
```

- `K ≤ q`：k=q+2 と k=q+1 を排除する（射影＋Segre の q-アーク定理＋2つの二次錐の交わり
  ＋`Q⁻` が `F_q` 有理な奇数次数曲線を持たないこと）。**q=9 で tight**（`K(9)=9`）。
  q=7 は NRC を通る二次曲面の全数分類（楕円型 0、q=5 だけ 20 個）で確定。
- `K ≤ q+1`：`Q⁻` 上の弧は `PG(3,q)` の n-アークでもあるので `m(3,q)=q+1`（Segre 1955 /
  Casse–Glynn 1982）から従う。`q=4` で tight（`K(4)=5`）。
- 文献には反転平面の弧の上界そのものが存在しない（K1251 文献節）。下界の記録は
  Sonnino 1999 の `(q+5)/2`。

**厳密値と数値**：`K(3..9) = 5,5,6,6,7,9,9`（全数列挙・アーク・センサスで厳密）、
`K(11) = 9`（アーク・センサスで厳密）、`K(13..49)` は検証済み下界 `10,12,13,14,16,18,19,20,21,22,25,27,28,30,32`。
q=13 では **4,000万ステップ**（従来の約80倍）の ILS でも 10 のまま。
これらの下界は**独立な2種類の探索（ILS と固定サイズのスワップ探索）が一致**し、さらに「1つ大きいサイズ」を探す試み（q=13 で 11,12,13、q=16 で 13,14、q=17 で 14、q=19 で 15）は**すべて失敗**（罰則が大きく収束しない）ので、最適か最適に近いと考えられる。
q=11 の層サイズも完全に判明（ピークは k=7 の 1,162,064,640、#9-arcs = 5,314,320、#10-arcs = 0）。
0.65q 前後で頭打ち。2種の独立探索が一致し +1 の試みが全滅するので真値の可能性が高いが、q=9 では上界が tight（`K=q`）なので `liminf K/q` は未解決。

**構造**：

- q=9 は「上界 `K ≤ q` が tight な唯一の既知の位数」で、極大アーク（29,520個）は
  `PΓL(2,81)` の**単一軌道**（安定化群の位数 72、K1251）。
- 代数的な構造化族（F_p-線型写像のグラフ、2次元 F_p-部分空間、平方根体上の2次元部分空間）は
  **q=9 でのみ**極大アークを与える（q=8,16,25,27,49 では 0）。機構は未解明。

**ゲーム（K1253）**：q ≤ 9 の全 Grundy（通常＋misère）を厳密計算。q=7 で初めて反転し、
原因は3点局面の拡大軌道の非一様性まで特定（最終機構は未解明）。

### 2.6 非Miquelian 反転平面（新方向、K1254）

偶数位数の反転平面はすべて ovoid の平面切断から作られる。`q = 2^{2e+1}` では ovoid が
2種類あり（楕円二次曲面＝Miquelian、および非二次曲面の **Tits ovoid**）、後者から
**Suzuki–Tits 反転平面**が得られる。Tits ovoid の古典形

```
O = {(1, x^σ + xy + y^{σ+2}, x, y)} ∪ {(0,1,0,0)},   σ = 2^{e+1}
```

を `q=8, 32` で構成・検証（`3-(q²+1, q+1, 1)` 設計であることを全対・全三点で確認）し、
弧とゲームを Miquelian 盤と比較した。

| q | 盤 | 点 | 円 | 最大弧 | 空盤のゲーム勝敗 |
|---:|---|---:|---:|---|---|
| 8 | Miquelian | 65 | 520 | **7** | **先手** |
| 8 | Suzuki–Tits | 65 | 520 | **7** | **後手** |
| 8 | AG(2,8)（参考） | 64 | 548 | **8** | 後手 |
| 32 | Miquelian | 1025 | 32800 | ≥ 22 | — |
| 32 | Suzuki–Tits | 1025 | 32800 | **≈ 14** | — |

**分かったこと**：

- **同じ `3-(65,9,1)` 設計パラメータ・同じ最大弧サイズ 7 でも、ゲームの勝敗は逆**。
  勝敗は設計パラメータではなく円の配置（Miquelian か否か）で決まる。
- 位数32では**弧の大きさも大きく違う**（Miquelian ≥22 に対し Suzuki–Tits ≈14）。
  Miquelian 盤の大きな弧は楕円二次曲面の代数構造に支えられている（K1250/K1252）ためで、
  同じ設計パラメータでも弧の大きさは一意に決まらない。
- 勝敗の差が現れるのは**3点局面の Grundy 値**（Miquelian 0 / Suzuki–Tits 2 / AG 1）。
  Miquelian 盤は `PΓL(2,q²)` が鋭く3重推移的なので3点局面が単一軌道になるため。
- K1252 の `K ≤ q` の証明は `Q⁻` が二次曲面であることを使うので非Miquelian 盤には
  適用できない（ambient の `K ≤ q+1` のみ）。非Miquelian 盤の良い上界は未解決。

## 4. 証明の現在の詰まり（Area·power 定式化）

連続上界の証明は次の形で止まっている：

```
|Delta| = |gamma| · |power| ≤ a² · |power|
```

`|power| ≤ a²/2` は**偽**（`gamma` が小さいと `power` は大きい）。
しかし積 `|gamma|·|power| ≤ a⁴/2` は a ≤ 7 の全数で成立（違反 0）。

**定式化の改善**：`|gamma| = 2·Area` なので、連続上界は

```
Area · max|power| ≤ a⁴/4
```

と同値。a ≤ 7 の全三点で違反 0 で、**最悪値がちょうど `a⁴/4` に一致**（鋭い上界）。

最悪ケースは a 奇数なら角の直角三角形（Area=a²/2, power=a²/2）、
a 偶数なら `(0,0),(a,0),(a/2,a/2)`（Area=a²/4, power=a²）。
面積が半分になると power が倍になる**逆比例**の関係。
