## 1. 確立した結果（証明済み）

### 1.1 補題：gamma = −2·Area

三点 `p1,p2,p3` に対し、4×4 行列式の `x²+y²` の係数 `gamma` は

```
gamma = −2 · Area(p1,p2,p3)
```

**証明**：余因子展開で `gamma = −det[[x_i,y_i,1]]`、この 3×3 行列式は符号付き面積の2倍。□

**系**：三点が `[0,a]²` 内なら `|gamma| ≤ a²`。

これは [DET_GAMMA_AREA.md](../../research/experiments/finite-field-kyouen-20261120/DET_GAMMA_AREA.md) に
証明と数値検証（28,508 組、不一致 0）を記録した。

### 1.2 層サイズ公式（k ≤ 5）

反転平面（3-(q²+1,q+1,1) 設計）で、安全 k-集合の数は k ≤ 5 で

```
L_k = C(n,k) − b · Σ_{j=4}^{min(k,s)} C(s,j) C(n−s, k−j)
```

**証明**：二円は高々2点で交わるので、二つの「4点以上」事象が共存するには6点必要。
よって k ≤ 5 で事象は互素。□

q=3,4,5 で完全一致、k=6 で破綻することを確認済み。

### 1.3 トーラス盤と AG(2,p) の一致

`Z_p = F_p` より、素数位数のトーラス盤はアフィン平面盤と禁止集合が同一。□
（p ≤ 13 で全数確認）

## 4. 証明の現在の詰まり

連続上界の証明は次の形で止まっている：

```
|Delta| = |gamma| · |power| ≤ a² · |power|
```

`|power| ≤ a²/2` は**偽**（`gamma` が小さいと `power` は大きい）。
しかし積 `|gamma|·|power| ≤ a⁴/2` は a ≤ 7 の全数で成立（違反 0）。

観測された構造：

| a | 最悪の三点 | \|gamma\| | max\|power\| | 積 |
|---:|---|---:|---:|---:|
| 3 | (0,0),(3,0),(0,3) | 9 | 9/2 | 81/2 |
| 4 | (0,0),(4,0),(2,2) | 8 | 16 | 128 |
| 5 | (0,0),(5,0),(0,5) | 25 | 25/2 | 625/2 |
| 6 | (0,0),(6,0),(3,3) | 18 | 36 | 648 |
| 7 | (0,0),(7,0),(0,7) | 49 | 49/2 | 2401/2 |

a 奇数は角の直角三角形、a 偶数は `(0,0),(a,0),(a/2,a/2)`。積は常にちょうど `a⁴/2`。

**必要なのは「`Area` が小さいほど `power` が大きいが、その増加は `1/Area` 程度」という
定量的な不等式**である。三角形の面積公式 `R = (辺の積)/(4·Area)` を使う筋道が考えられるが、
定数評価まで詰まっていない。
