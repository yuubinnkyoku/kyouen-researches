# 2トークン残余ゲーム y=3族のパラメトリック全称証明（全z・全x・全R）

実験: vertical-fiber-two-token-y3-parametric-allz-proof-20261120
対象: κ=1残余ゲーム H(R;X;z)、2トークン族 X=(x,3)、全高さ z>=0、全 x>=3、全 R>=0
結論: 下記の陰関数 T_z(x), P_z(x) が全整数点 (z,x,R) で H の値を与える（命题 P3）。
単一オーナー宣言ノート: commit b7a9f7c6a3（先行出版、着手時HEAD cdf3145119）。

参照関係: K1099（y=2パラメトリック全称証明）の「未解決」が明記していた
「y=3族の同型機械化（本項の手法の直接反復）」の実行である。
既出版の y=3 固定z 境界切片
K0879(z=6), K0979(z=7), K0986(z=8), K0989(z=9), K1005(z=10), K1014(z=11),
K1021(z=12), K1026(z=13), K1030(z=14), K1034(z=15), K1050(z=16), K1067(z=17),
K1078(z=18), K1098(z=19) は本命題の z 行の特殊例であり、z>=20 の未着手 y=3
切片も本命題に含まれる（以後の y=3 スライス出版は不要）。
さらに K1101（対角線下マージ定理）が y>=3 について有限センサス観察
（2トークン y=1..40・z<=40・348,270点）にとどめていたマージの y=3 版が
本定理の系として全称に昇格する。

## 記号

O[a,b] は区間内の奇数、E[a,b] は偶数、I[a,∞) は a 以上の全整数、O_z[a,b]
は区間内で z と同じ偶奇の位置とする。q_odd(k) は k を奇数に切り下げた値
（k 奇なら k、k 偶なら k-1）。q_odd(x+3) はマージ行のラダー上端である。

## 定理（値2集合 T_z(x)、値1集合 P_z(x)）

H(R;(x,3);z)=2 ⟺ R∈T_z(x)、=1 ⟺ R∈P_z(x)、それ以外で 0（R=0 は常に 0）。

### 値2位置 T_z(x)（常に奇数位置＋高々1つの孤立pin／掃引帯）

z 奇数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-4 | O[1, q_odd(x+3)]（単一トークン値そのもの） |
| x=z-3 | O[1, z+2] |
| x∈{z-2, z, z+1, z+2} | O[1, z] |
| x=z-1 | O[1, z] ∪ {z+4}（前倒し孤立pin） |
| x=z+3 | O[1, z] ∪ {z+6} |
| x=z+4 | O[1,z] ∪ O[z+6, 2z+7]（掃引行） |
| x>=z+5 | O[1,z] ∪ {z+6} |

z 偶数のとき:

| 行クラス | T_z(x) |
|---|---|
| x<=z-4 | O[1, q_odd(x+3)] |
| x=z-3 | O[1, z+3]（対角行 S=z、連続上端） |
| x∈{z-2, z-1, z, z+2, z+3} | O[1, z-1] |
| x=z+1 | O[1, z-1] ∪ {z+5}（前倒し孤立pin） |
| x=z+4 | O[1,z-1] ∪ O[z+7, 2z+7]（掃引行） |
| x>=z+5 | O[1,z-1] ∪ {z+7} |

z=0,1,2,3 でも例外行は発生しない（判定不能クラスは空になり、同じテンプレート
がそのまま適用される。例: z=0 では x>=z+5=5 行の pin は {7}、x=3 行は
O[1,-1]=∅ で値2なし）。

### 値1位置 P_z(x)

z 奇数のとき:

| 行クラス | P_z(x) |
|---|---|
| x 偶, x<=z-4 | I[x+4, ∞) |
| x 奇, x<=z-4 | ∅ |
| x=z-3 | {z+1} ∪ I[z+3, ∞) |
| x=z-2 | {z+1, z+3} |
| x=z-1 | {z+1, z+3} ∪ I[z+5, ∞) |
| x=z | {z+1, z+3} |
| x=z+1 | {z+1, z+3} ∪ I[z+5, ∞) |
| x=z+2 | {z+1, z+3, z+5} |
| x=z+3 | {z+1, z+3, z+5} ∪ I[z+7, ∞) |
| x=z+4 | {z+1, z+3, z+5} |
| x>=z+5 | {z+1, z+3, z+5} ∪ O_z[z+8, x+z+3] ∪ （x 偶なら） I[x+z+4, ∞) |

z 偶数のとき:

| 行クラス | P_z(x) |
|---|---|
| x 偶, x<=z-4 | I[x+4, ∞) |
| x 奇, x<=z-4 | ∅ |
| x=z-3 | ∅（対角行 S=z は値1なし） |
| x=z-2 | {z+1} ∪ I[z+3, ∞) |
| x=z-1 | {z+1, z+3} |
| x=z | {z+1, z+3} ∪ I[z+5, ∞) |
| x=z+1 | {z+1, z+3} |
| x=z+2 | {z+1, z+3} ∪ I[z+5, ∞) |
| x=z+3 | {z+1, z+3, z+5} |
| x=z+4 | {z+1, z+3, z+5} |
| x>=z+5 | {z+1, z+3, z+5} ∪ O_z[z+8, x+z+3] ∪ （x 偶なら） I[x+z+4, ∞) |

中間帯の偶奇は常に z に追従する（O_z）。T∩P=∅ は全点で成立
（検証器が全照合点で assert）。

### tail

全 z>=0・x>=3 で R >= x+z+4 のとき H(R;(x,3);z) = (x+3) mod 2。
すなわち奇数 x 行は tail で 0、偶数 x 行は tail で 1 になる
（P の I[x+z+4, ∞) と一致）。

## マージ系（対角線下・全称昇格）

x<=z-4（すなわち S=x+3 <= z-1 < z）の全行で

  H(R;(x,3);z) = single_token(x+3, z, R)  （K0832 出版単一トークン閉形式）

が全 R>=0 で成り立つ。明示的に書くと: 値2位置は O[1, q_odd(x+3)]
（=x 偶 2⌈(x+3)/2⌉-1 = x+3・x 奇 x+2 …いずれも x+2 または x+3 の奇数）、
値1位置は x 偶 のみ I[x+4, ∞)、それ以外 0。行全体が z 非依存になる。
これは K1101 が y∈{1,2} で全称証明し y>=3 を有限センサス観察
（2トークン y=1..40・z<=40・348,270点・不一致0）にとどめていた
マージ命題の y=3 版の全称昇格であり、本定理の閉形式から直ちに従う
（single_token の z>=S+1 場合: 値2 O[1,q_odd(S)]・S 奇なら I[q_odd(S)+1,∞)
とマージ行の T/P が一致する。S=x+3 の偶奇が x と反転している点に注意）。
監査機械は全グリッド・probe 点で x<=z-4 のときこの系を直接照合した
（総 1,818,314 点・不一致 0）。

## 選択肢分解と x=3 での合流

R>=1 のとき、トークン減少は一方のトークンだけを 1 減らす操作で

- A = H(R-1; (x-1,3); z)（x>=4）
- B = H(R-1; (x,2); z)
- C = 1 ⊕ H(R-1; (x,3); z-1)（z>=1）

であり H(R;(x,3);z)=mex{A,B,C}（z=0 では C なし）。x=3 では
(3,3) の 2 つの減少手が同一の多重集合 (2,3)≡(3,2) 子に合流し
A≡B = H(R-1;(2,3);z) = H(R-1;(3,2);z)、すなわち K1099 の z 行 x=3
閉形式になる（H は多重集合にしか依存しないため）。
B は常に K1099 の全称閉形式 cand2(z,x,R-1) で評価する。

## 証明構成（K1023/K1099 と同型の機械化）

1. **選択肢分解の健全性**: A/B/C の列挙が素再帰と一致することを、raw エンジン
   （順序保持・降順正準化の二重再帰、出版済みセンサス機械と同一コード）の
   選択肢値集合との一致で錨止めする（検証 C3）。カーネルの B・x=3 の合流子も
   raw 照合で錨止め（C1b）。
2. **恒等式**: cand3 は上表そのものであり、恒等式
   cand3(z,x,R) = mex{A,B,C}（子は閉形式で評価、C は cand3(z-1,・,・)
   の z 外帰納）が R に関する帰納の本体。z=0..48・x=3..56・R<=x+z+40 の
   全点 247,401（C2）、深部 tail z∈{60,72,84,96,108,120,240,400}（C2b）、
   z=0..120・x=3..120・R<=x+z+16 の全点 1,963,225（C12）で直接照合する。
3. **型機械**: 型 = (x==3 ビット, z==0 ビット, z%2, x%2, R%2, 6差分族
   w0=x-z, w1=R-x, w2=R-z, w3=R-x-z, w4=R-2x, w5=R-2z の ±8 旧窓・±9 番兵
   クリップ)。自由座標 v0=x-z, v1=R-x, v3=R-x-z のボックス ±60 を掃引して
   実現型 10,850 個を完全列挙し、各型で (値, 子値列) の効果ベクトルが
   型内で一定（confluence）・証人で恒等式成立を機械検証する。ボックス外の
   型は新規型として現れないことを、v 空間シェル掃引 [61,64]∪[89,92]∪[117,120]
   （936,714 点）、境界多様体 z∈{0..5,29..31,59..61,299..301,999..1001,
   2999,3000}（393,902 点）、seed 付き遠方 probe 20万点（z,x<=3000・
   R<=9000・seed 20261120）、深グリッド掃引で確認した
   （いずれも新規型 0・confluence 不一致 0）。
4. **出版切片の逐語アンカー**: 既出版の z=18（K1078）と z=19（K1098）の

   5,239 点ずつ全一致（C1d・計 10,478 点）。その他の z は census（下記）が
   z=0..80 の生二重再帰で直接照合する。

## 値の構造（既出版切片の記述の一般化・y=1..3 の横断観察）

- **値1基底点 {z+1,z+3,z+5}**: y=3 の値1基底点 y 点仮説（基底点は
  y 個）が本定理により全 z>=0 で確定する（y=1 は {z+1}・y=2 は
  {z+1,z+3}・y=3 は {z+1,z+3,z+5} で各 y 点。z=18/z=19 の観察
  （K1078/K1098）の全 z 拡張）。
- **pin の偶奇分離**: 奇数 z では格子 pin 2y+z = z+6 が x=z+3 行・掃引行
  起点・定常行に現れ、前倒し pin 2y+z-2 = z+4 が x=z-1 行に現れる
  （y=2 にはなかった x<z 側の pin が y=3 で新規に出現）。偶数 z では
  対角行の連続上端・前倒し pin 2y+z-1 = z+5（x=z+1 行）・定常 pin
  2y+z+1 = z+7 の分離（y=2 の x=z 行前倒し pin 2y+z-1 と同じ位置式が
  行位置 x=z+y-2 に一般化して現れる）。
- **掃引行** x=z+y+1=z+4: 帯は奇数 z で O[2y+z, 2z+2y+1]=[z+6, 2z+7]、
  偶数 z で O[2y+z+1, 2z+2y+1]=[z+7, 2z+7]（y=2 の掃引帯公式の
  そのままの y=3 値）。
- **対角行** S=z（x=z-3・偶数 z）: 連続上端 O[1, z+2y-3] で値1なし。
  奇数 z の x=z-3 行の上端 z+2 は格子式 q_odd(2y+(d+z)/2)
  （d=x-y=z-6）と一致（K1100 が z=19・y=4 で観測した d+z 剰余格子の
  y=3・全 z からの一致例。ただし本項は格子規則の一般証明ではない）。
- **tail 境界 x+z+2y-2**: y=2 の tail 開始は x+z+2y-1 だったが、
  y=3 では x+z+4 = x+z+2y-2 で 1 つ早い。y による tail 開始の
  一般式は y=3 で初めて y=2 のパターンから外れるため、一般式は
  未確定（y=4 の全称表が決め手になる）。

## 信頼境界

- 全称性の根拠は、(i) 選択肢分解がゲーム定義そのものであること（raw錨）、
  (ii) 恒等式が正確な mex 再帰であること（有限完全グリッド＋型ごと照合）、
  (iii) 実現型空間が有限でボックス内に証人を持つこと（完全列挙＋シェル・
  多様体・遠方probe・深掃引の新規型ゼロ）、の3点であり、K1023/K1099 と
  同じ trust 境界に立つ。Lean 形式化ではなく、証人境界補題の証明
  テキストではなく機械掃引で裏付ける点も同一基準である。
- 有限監査は転写・実装照合であり、それ自体が全称性の根拠ではない。
- H の定義（Theorem T・単一トークン閉形式）は K0832 に、B 子の評価は
  K1099 に（さらにその子として K1023 に）依存する。それらが成立する
  限りで本項は成立する。
- 本項は y=3 のみを証明する。y>=4 族のパラメトリック機械化、基底点 y 点
  仮説と d+z 剰余格子規則の一般証明、tail 開始の一般式、3トークン以上、
  固定幅・q点版安定化長、11×11 は範囲外。
